# 科研报销流程图

0.5万元以下 → 项目负责人 → 财务处报账

0.5-1万元 → 项目负责人 → 科技处处长 → 财务处报账

1万元-3万元 → 项目负责人 → 科技处处长 → 分管科研副校长 → 财务处报账

3万元以上 → 项目负责人 → 科技处处长 → 分管科研副校长 → 校长 → 财务处报账

注：凡项目负责人经手的开支，本人不能作最后的审批，须上移一级履行签字程序。
