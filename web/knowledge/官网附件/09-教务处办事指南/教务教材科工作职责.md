# 教务教材科工作职责

1.负责日常教学运行管理，教学应急事件处置工作。

2.负责组织完成教学计划录入，完成教学任务审核、下达及落实工作。

3.负责组织完成课表的编排与调整工作。

4.负责组织教材报订及审核工作。

5.负责教学工作量核算、测算、审核工作；计算并协调发放超课时酬金。

6.负责教务系统日常运行及数据管理工作。

7.负责学生课堂考勤数据统计、汇总及处理等工作。

8.负责通识教育选修课、专业拓展选修课和体育课等的选课管理工作。

9.负责教师临时调停补课和节假日课程调整工作。

10.负责主要教学场地的调度管理工作及新生早读晚修安排。

11.负责课程重修管理工作。

12.负责线上课程资源平台及线上课程教学运行管理工作。

13.负责校内实训和实验课程的教学运行与管理。

14.负责大学生体质测试和青年教师导师制的服务工作量的计算。

15.完成上级领导交办的其他任务。
