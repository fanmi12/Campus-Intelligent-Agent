# 复学申请审批流程

## 附件：东莞城市学院复学申请审批流程及申请表格

1. 申请人填写复学申请表
2. 分类审核：
   - 属于因身体疾病申请休学，由医务所审核
   - 属于因入伍申请休学，由武装部审核
   - 属于因心理疾病申请休学，由学生部心理咨询中心审核
3. 学生所在单位学生工作负责人，及单位负责人审核
4. 教务部学籍考务科（行政楼211）复核
5. 教务部分管部长（行政楼219）审批
6. 学生将复学申请表的送相关部门
