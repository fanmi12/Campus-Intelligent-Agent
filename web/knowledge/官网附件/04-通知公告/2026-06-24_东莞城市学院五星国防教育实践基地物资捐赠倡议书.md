# 东莞城市学院五星国防教育实践基地物资捐赠倡议书

## 东莞城市学院五星国防教育实践基地物资
### 捐赠倡议书

致东莞城市学院全体师生及校友：

国防教育是立德树人的重要组成部分。为充实我校五星国防教育实践基地的教育资源、完善实践教学设施，进一步丰富师生的国防科普与军事实践体验，学校特此发起公益捐赠倡议。目前，基地的军事科普器材、展示及配套物资存在缺口较大，难以满足常态化国防教育活动的开展需求。现诚邀全体师生及校友自愿捐赠合规物资，汇聚爱心力量，厚植国防情怀，携手共建优质的校园国防教育阵地。

#### 一、捐赠激励与公示
1. 学校将对所有捐赠单位及人员进行实名登记，通过校园公示栏、校园公众号及国防实践基地宣传区公开致谢，并颁发捐赠证书，弘扬爱国精神深耕公益善行；
2. 所有捐赠物资将永久留存国防教育基地使用，在合适位置挂牌或标明捐赠人，每一份爱心都将成为校园国防教育的珍贵资源，惠及所有受教群体。

#### 二、物资使用说明
1. 所有捐赠物资将统一收纳、登记、造册，专属存放于我校五星国防实践基地，专人管理、妥善保管、定期维护；

2. 捐赠物资全程面向全校师生及校友免费开放使用，专项用于基地国防教学、军事科普、社团实训、主题活动、研学体验、校园国防宣传等公益教育场景；

3. 所有捐赠物资仅作校园公益教育使用，不用于任何商业盈利、出租变卖、私自挪用等违规用途，最大限度发挥物资育人价值；

4. 学校将建立捐赠物资台账，公示捐赠明细，接受全体师生监督。

三、捐赠物资范围

本次捐赠物资须合规合法、安全无害、来源清晰、无产权纠纷、无任何违禁及安全风险，适合校园展示、学习、教育使用，可赠范围包括：

（1）文献书籍与文史资料

1. 国防、军事、党史军史类图书、画册、图集、传记；
2. 军事期刊、杂志、老报纸、文献手稿、纪实资料；
3. 国防教育读本、征兵宣传册、军事科普读物；
4. 军旅回忆录、老兵手记、红色故事集、军史史料档案。

（2）模型与仿真展品

1. 陆海空天装备模型：战机、舰艇、坦克、装甲车、火炮、导弹、军用车辆等比例模型；
2. 单兵装备模型：制式头盔、携行具、装具、战术背包、望远镜、军用罗盘等仿真摆件；
3. 军旗、军徽、臂章、胸标、领章等复刻展品；

4. 军事沙盘、地形地貌模拟教具、作战示意图展板模型。

（3）制式复刻 / 退役合规展品

1. 退役非武器类制式装具：旧军服、老式军用水壶、军用挎包、帆布背包、腰带、制式鞋帽、手套等；

2. 军用生活用品：搪瓷缸、饭盒、灯具、老式行军床配件、野外炊具（无刀具）；

3. 荣誉品类：复刻军功章、纪念章、立功证书、荣誉牌匾、入伍通知书复刻件；

4. 老物件藏品：老式军用收音机、望远镜、指南针、信号灯、行军背包等退役物资。

（4）宣传展示物料

1. 国防主题海报、宣传挂图、军事知识展板、人物画像、英雄模范展板；

2. 红色军旅摄影作品、军旅主题书画、剪纸、手工艺品；

3. 国防知识展板、征兵政策宣传栏、国防法规图解展板；

4. 展馆装饰摆件、军旅文化标语牌、主题标识牌。

（5）实训体验与教学辅助器材

1. 队列训练、体能训练辅助器材（护具、标志桶、训练绳等）；

2. 应急救护、战场救护模拟教具（急救包、包扎模型、救护演示用品）；

3. 野外生存科普教具（帐篷配件、防雨用具、导航教具等，不含危险工具）；

4. 广播音响、讲解扩音设备、展示支架、陈列展柜、收

纳物资架；
5. 真人 CS 对战相关装备（轮胎、水马、油桶、帐篷、医疗箱、枪支、服装等）
6. 400 米障碍活动相关道具（跨桩、壕沟、矮墙、高板跳台、云梯、独木桥、高墙、低桩网八组障碍物）
（6）军旅文创与纪念藏品
1. 国防主题文创产品、军旅摆件、雕塑、工艺品；
2. 军旅主题旗帜、横幅、纪念旗帜、团建旗帜；
3. 老兵留存纪念物品、军旅主题纪念品、集体合影影像资料（照片、影像 U 盘）；
严禁捐赠各类违禁物品、仿真危险品、管制器械、易燃易爆物品，以及破损劣质、存在安全隐患或不符合校园管理规定的物资。

点滴汇聚，可成江海；寸心星火，可耀国防。国防教育的深耕，离不开每一位师生的参与和支持。每一件物资，都是一份爱国情怀的传递；每一次捐赠，都是一次国防初心的践行。
在此，我们再次诚挚倡议全体师生及校友们，积极参与、踊跃奉献，用爱心筑牢校园国防根基，用行动厚植爱国报国情怀，共同把城市学院五星国防教育实践基地打造成有温度、有内涵、有力量的校园国防教育育人阵地，让国防之种根植校园，爱国之心薪火相传！
