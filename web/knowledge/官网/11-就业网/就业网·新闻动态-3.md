# 就业网·新闻动态

【新闻速报】筑梦青春・就业启航｜我校组织毕业生参加广东省高校毕业生招聘活动东莞专场

发布时间：2026-09-11 17:46:08 查看次数：575为深入落实“访企拓岗促就业”专项行动，精准把握当下就业市场形势，拓宽毕业生就业渠道、优化就业服务指导，全力助推毕业生高质量充分就业，9月10日，2026年“筑梦青春·就业启航”广东省高校毕业生招聘活动东莞专场在南城街道海德·汇一城一区外广场顺利举办。

我校高度重视本次招聘活动，统一安排专车接送，贴心保障

超400名毕业生

安全、有序赴现场参与求职对接，为学子外出就业保驾护航。

本次专场招聘会汇聚50多家东莞本地优质企业，集中释放1000余个优质就业岗位。金太阳研磨、杰群电子等知名企业悉数到场揽才，岗位覆盖面广、适配性强，涵盖智能制造、金融银行、新能源、数字经济等当下热门领域，囊括技术研发、市场运营、行政管理等多种岗位类型，全方位满足不同专业毕业生的求职需求，为高校学子搭建了高效、精准的校企人才对接平台。

活动期间，我校

就业与校友服务中心林桂宏副主任、杨俊荣老师

带队亲临现场。依托本次招聘会优质企业资源，林桂宏副主任深入开展访企拓岗调研工作，主动走访各企业招聘展位，与企业负责人面对面深入交流，详细调研当前东莞就业市场整体形势、行业发展趋势、企业人才招录标准以及岗位核心职业能力要求，精准掌握企业用人需求、薪资福利体系、人才培养模式以及应届毕业生就业市场新变化，为学校后续优化人才培养方案、精准开展就业指导、拓展校企合作资源、开拓优质就业岗位积累了详实的一线数据

与此同时，学校同步开展全方位、零距离就业帮扶服务。

就业与校友服务中心罗丽斯老师、新传媒与艺术学院副书记吴娜

驻点现场，为求职者提供一对一专属就业指导，针对性开展简历打磨优化、求职误区纠正、面试技巧讲解、职业规划答疑等服务，实时解决求职困惑，有效提升学子求职竞争力。贴心的包车保障、专业的现场指导、深入的拓岗调研，全方位助力我校学子精准求职、高效择业

本次招聘会创新

融合数智化就业服务与多元化配套服务，现场特设

“AI赋能就业”体验区，依托智通人才集团自主研发的AI就业一体机，为毕业生提供智能简历诊断、AI职业测评、就业方向规划等一站式数智服务，以科技赋能求职，帮助学子精准定位求职方向。此外，现场还设置创业指导区、就业政策咨询区，为有创业意向的学生解读专项扶持政策，解答就业相关政策问题；青春市集、非遗文化展示等趣味互动环节，让紧张的求职过程增添温情与活力。

招聘会现场人头攒动、氛围热烈。我校毕业生精神饱满、积极主动，手持精心准备的简历穿梭于各个企业展位之间，详细了解岗位职责、晋升通道、薪资待遇及企业发展前景，主动与招聘负责人沟通交流、投递简历。不少学生表示，学校统一包车出行十分贴心便利，现场岗位资源丰富、适配度高，加上老师的专业指导和

AI智能求职服务，收获颇丰，对未来就业更有信心。参会企业也对我校学子的精神风貌和综合素养给予肯定，高度认可学校贴心的就业组织服务和精准的人才输送对接

此次活动既是学校落实访企拓岗、深耕就业市场的重要举措，也是全方位、精细化服务毕业生就业的生动实践。下一步，我校就业与校友服务中心将持续常态化开展访企拓岗专项行动，持续深挖优质就业资源，精准对接市场用人需求与学生求职诉求，不断优化人才培养和就业指导服务体系，常态化组织专场招聘、企业走访、就业培训、职业指导等系列活动，全力打通校企就业对接壁垒，助力更多莞城学子扎根东莞、逐梦职场、顺利就业。
