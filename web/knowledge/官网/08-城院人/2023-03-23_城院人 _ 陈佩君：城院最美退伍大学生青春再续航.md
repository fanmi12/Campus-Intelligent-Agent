# 城院人 | 陈佩君：城院最美退伍大学生青春再续航

陈佩君，女，21级英语1班，退伍军人，2019年入伍，2021年退伍回归大学生活。她曾任外国语学院媒体运营中心宣传部和学生社区服务中心干事一职，现任班级团支书、国旗护卫队队长。2021年度被评为“四有”优秀士兵，在校期间，她荣获校园三等奖学金、2021年校运会学生组女子400米项目比赛第五名。

因喜欢看爱国战争片，加上受到父亲熏陶，陈佩君从小便对参军入伍心向往之。选择入伍是为了实现小时候的梦想，更是想要完成爸爸少年时的遗憾！

谈到军旅生活，陈佩君表示新兵连三个月算是最难忘的，在那里可以说是苦中作乐，经历了很多第一次也学到了很多很多东西，第一次离开家乡到上海，第一次跑三公里，第一次汗湿衣服直至滴水...学习了战术，射击，队列，擒敌等等从未接触过的东西，当然在这其中收获了很深的战友情，可以说这种感情是永生难忘的！下连之后分配到总队通信中队，在那里通过了严格的话务训练成为一名正式的话务员，做到电话接转零失误，令出传达零时差。

对陈佩君来说，在部队最大的改变是锻炼成了良好的身体素质，经过不断体能训练，每次考核基本上都可以拿到优秀的成绩。同时也改变了很多不好的习惯和性格，部队生活对个人作风的要求十分严格，苛刻的内务标准让她改掉了平时懒惰的习惯，并且在部队里收获了很多的自信，一改往日胆小内向的性格，敢于尝试各种演讲比赛和舞台。还有忍耐力变得更强了，在部队练战术匍匐前行的时候，浑身上下都是淤青和擦伤，但无论多疼，训练依旧。经历的种种让陈佩君积累了不少生活经验，变得更踏实更有担当。疫情刚出现时，很多军人纷纷申请出战，“我们排长曾问过我们，如果在真的需要我们出战的那天，你们会愿意吗？”“我认为，我从一位地方青年成为一名合格军人，养兵千日，用兵一时，当然是哪里需要往哪里搬！”

提到退伍后发生的最大转变，陈佩君表示，退伍之后的转变更多的是心态变得更沉稳了，经过部队里两年严格的历练变得更有勇气有毅力了，对自己各方面的要求都更加严格。

作为一名退伍军人，陈佩君想对同学们说，“当兵后悔两年，不当兵后悔一辈子”，当然她也并没有后悔这两年，在部队里的锻炼会有你意想不到的收获，不要犹豫，军营生活绝对会是你人生中一段难忘的经历，虽然会掉皮掉肉掉泪，但你不会后悔，甚至会把它当成一生的财富！等你穿上一身戎装，成为那个最可爱的人，你会永生难忘！
