# 城院人 | “泉”心“泉”意当好学生“服务员”

、序言在我们身边，有这样一群人：他们在自己的工作岗位兢兢业业、勤勤恳恳，以拼搏不息的精神，不断开创出新的工作局面，收获累累硕果；他们在知识的海洋恣意畅游，锚定远大目标，脚步踏实坚定，用大学四年的青春光景去描绘灿烂的人生之路。

这些师生党员是九千万中国共产党党员中的一分子，很平凡，但也能散发着光亮去温暖他人；会沮丧，但也能坚定信仰去守住心中希望；是不忘初心，方能历百折而不回、履艰险而不惊。让我们走近听听他们的故事，烛照我们的人生。

真诚·商科实训室的“导游”

黄庆泉，东莞城市学院商学院会计系副主任、商科实训教研室主任，2010年6月入党，2014年入职东莞城市学院。自参加工作以来，黄庆泉以教书育人为根本，以立德树人为己任，在工作岗位上求实鼎新，兢兢业业，勤奋刻苦，时时处处以党员的标准严格要求自己。在东莞城市学院的9年里，黄老师经历许多，也收获许多，下面就让我们一起来听听他的故事吧。

2018年1月，我校商学院调整重建，建立了东莞高校首个高校商科实训中心。商学院的重建、实训中心的创建运营，黄老师皆参与其中，用“陪伴”一词形容商学院与黄老师的关系最为恰当。

“我在城院当了将近七年的‘导游’啦。”在采访中黄老师笑着说道，脸上露出两个酒窝。为什么是“导游”呢？自实训中心成立以来，许多高校慕名而来，如惠州学院、北京理工大学珠海学院、呼伦贝尔学院、三亚学院、广州城建职业学院、广州工商学院等等。当其他学校前来交流时，黄老师就负责设备调试、课程讲解以及经验交流，“导游”之称也由此而来。

黄老师担任商科实训教研室主任期间，商科实训中心建设成为省级实验教学示范中心，所负责的《商科综合实训》课程在教学改革上实行精准化管理，将第一课堂和第二课堂深度融合，在课前教学准备、课堂流程指引、课后实训成果整理等方面独树一帜，影响广泛，商科实训中心吸引了省内外60多所高校教学团队交流学习，上级领导对商科实训中心取得的成绩给予了充分的肯定。

与子同袍，与子偕作，与子同泽。在陪伴实训中心从无到有、从萌芽到取得可喜成绩的这些年里，黄老师自身也得到了发展。黄老师说：“我原本是一个交流能力比较弱的人，当‘导游’以后跟来自五湖四海的人交流相当于给了我锻炼的机会，而且这些年来我的工作能力也得到了很大的提升。”

黄老师对工作抱诚守真、富有责任心，当好“城院导游”的同时亦在发挥榜样力量，促进更多人成为如他一般至真至诚的人。

2、真心·学生口中的“泉二”

除了担任商科实训教研室主任，黄老师还一直承担班主任的工作。因为在兄弟中排行第二，同学们亲切地称呼他为“泉二”。黄老师说：“我就是服务员，学生的服务员。”在聊到学生时，黄老师的笑容无比灿烂。

黄老师每个学期都会去走访宿舍，他的办公室里有一个工具箱，从第一年当班主任时已经开始用于帮助学生解决宿舍问题。洗衣台漏水、浴室地漏堵塞、洗衣机水管接口漏水、寝室开关门噪声大等问题黄老师都会深入学生宿舍帮助解决，所有的维修费用都是黄老师自掏腰包。除此以外，黄老师还会帮助学生搬运行李、拿快递。当问起为什么会想到这样做时，黄老师仅是淡淡道来一句“应该的，都是小事。”

教育是一场爱与被爱的修行，德国哲学家思贝尔思曾说：“真正的教育是用一棵树去摇动另一棵树，用一朵云去推动另一朵云，用一个灵魂去唤醒另一个灵魂。”担任班主任已有9年之久，黄老师讲述着这些年来的悲欢离合：2017年时曾有一名身患骨癌的学生转校到城院，来时已经一条腿截肢。为了帮助如此特殊的学生，黄老师亲自去为其申请较低楼层教室，帮她办理各种手续，这名学生在学习上也非常认真。但最后这名学生还是没能战胜癌症，因病逝退学。在分享这一故事时，黄老师不禁阵阵叹息：“很幸运相遇也很遗憾以这样的方式分别。”人会有生离死别，但真心不灭。

黄老师以真心对待学生、服务学生，春种一颗粟，秋收万粒子。在学生们的心里，黄老师不仅是老师，更是挚友。虽然许多人已经离开了校园，但是会邀请黄老师参加婚礼、会与他分享自己的创业历程、会每学期坚持回校看望黄老师......古往今来，太多太多赞美的话语用在我们心目中好老师的身上，但是千言万语都比不上学生心中对老师的深深挂念。

黄老师最开心的事情就是看到学生成长成才。黄老师所教授的学生中有3名同学通过自己的努力已在建设银行、农商行等银行担任支行行长，谈及学生们取得的成绩，黄老师的骄傲、自豪之情溢于言表。

3、真情·以校为家的“城院人”

在采访中，黄老师提起自己是寮步人并且从小就生活在这里。“从小到大家里都很穷，一直是贫困户，甚至交不上学费。我的父母没有读过大学，母亲的眼睛看不见，我是非常相信学习改变命运的，所以在读书时我很努力，从小学一年级就开始拿奖学金，在每本书上都写着‘一定要考上大学’用来鞭策自己。我上学期间得到了政府和亲友极大的帮助，所以我爱这片土地且感激这片土地上的许多人。”黄老师陷入回忆：“在研究生毕业时，我的老师曾让我留在广州，但是我想回来。”

“生于斯，长于斯，爱于斯，那么我的眼里饱含泪水，因为我对这片土地爱得深沉。”学成归来，黄老师进入城院且以校为家。黄老师现在的家离学校较近，每当学校有事务需要处理，他总是以最快的速度回到学校。责任心和爱使其毫无怨言、乐此不疲。同时，黄老师的爱人和兄长也在为城院服务，他认为城院已经成为了黄老师的第二个“家”。

回到家中，黄老师同样是富有责任心的丈夫、父亲，工作再忙再累也依然坚持接送儿女、为家人做饭。

无论是在校还是在家，黄老师都在以实际行动诠释担当。作为一名党员，黄老师如一面旗帜以身作则；作为一名教师，黄老师的教导如春晖遍四方；作为父亲、丈夫，黄老师则温暖负责有爱。

采访已至尾声，黄老师看了一眼手表说：“我到时间接孩子啦，我们就下回再聊咯。”他挥手示意再见，脸上还是那亲切的笑容以及让人感到温暖的酒窝......

4、学生眼中的黄老师

在我心里，黄庆泉老师是一位平易近人、充满爱心和责任感的好老师。

他担任我们班的班主任已经半年了，这半年来，他扎实的学术功底和富有活力的教学风格让我印象深刻。在我心中，他是一位有着深厚爱国情怀、敬业精神和高尚师德的榜样人物。

最让我难忘的是黄老师的工具箱。我是班长，上学期我陪着黄老师一起去走访同班同学的宿舍。黄老师提着他的“百宝箱”帮同学们处理各种各样、大大小小的问题：修柜子、修风扇等。那时候我就觉得黄老师是个很温暖的人。

在学习上，他还经常化身为“人肉搜索引擎”，为我的问题提供思路和教导，让我学到了很多平时课本上学不到的知识。我认为黄老师还是一个循循善诱的指导者。在我的成长中，他能够清晰地指出我在学习、生活中的不足，并耐心地给我一一指导。他还引导我理解、掌握各种各样的学科知识，并帮助我学会如何正确处理人际关系，激励我更加系统化、理性化地思考的问题。

学生中有“三好学生”，我认为老师中也有“三好老师”——好老师、好同志、好朋友。在我心中黄老师就是这样的“三好老师”。他的品行、教诲深深印刻在我的心中。他是我生命中的一位重要的导师和朋友。有这样一位老师，让我感到特别骄傲和自豪！

——22工商管理7班李灼宏
