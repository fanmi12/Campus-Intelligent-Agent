# 李利民：一片热血铸师魂，一腔丹心育桃李

【教师简介】

李利民，北京师范大学艺术硕士， 副教授，主要从事舞蹈表演与创作研究。曾获广东省首届美育教学基本功大赛＂一等奖＂。编创作品获广东大学生舞蹈大赛，广东省大学生艺术展演等赛事“二等奖”6项、三等奖2项 ; 主持和参与省级课题3项、市级课题2项、校级课题6项 ; 在核心及省级刊物上发表论文9篇。

教书对李利民老师而言，是一种使命，也是一种幸福。李利民老师认为教师不仅是知识的传递者，更是学生心灵的灯塔，能够在他们成长的道路上提供指引和力量。在培养国家未来的建设者和接班人的过程中，与学生们建立起的深厚师生情谊，以及看到他们从青涩走向成熟，最终成为社会的有用之才，让李利民老师感受到了生命的深度与广度，每一次看到学生进步和成功，都是对他最大的奖赏。

城院对李利民老师来说不仅仅是一个工作场所，更像一个大家庭，见证了他与学生共同成长的历程。在城院工作的13年，李利民老师深刻感受到学校的发展与变化，从教学设施的升级到教育理念的革新，都让他深刻体会到教育事业的进步与活力。

【教学理念】

在李利民老师的教学生涯中，他认为每一届学生都有其独特的特点。比如，有的班级集体荣誉感特别强，擅长团队合作；有的班级则个性鲜明，每个学生都有自己的想法和创意。随着时代的发展，他发现近年来的学生更加注重实践与创新，对新技术、新思想接受能力强，同时也更加关注社会问题，渴望在学习中找到个人价值和社会责任的结合点。

谈及如何培养学生的创新思维和实践能力，李利民老师觉得首先需要营造一个鼓励尝试、容忍失败的教育环境。在课堂上，他常常采用案例分析、项目式学习等方式，让学生在解决实际问题的过程中锻炼思维和动手能力。同时，鼓励学生参加实践演出活动、学科竞赛，与企业合作进行实习实训，将理论知识与社会实践紧密结合。培养批判性思维，教会学生如何提问比给出答案更为重要，因为这能激发他们不断探索未知的好奇心和解决问题的能力。

在李利民老师的舞蹈教育之旅中，一系列刻骨铭心的瞬间与学生的故事交织成一幅幅生动的画卷，其中一段经历尤为璀璨夺目。那是一次舞蹈编导课程的实践，李利民老师引领着一群对作品既憧憬又迷茫的学生踏上创作之旅。起初，学生们仿佛置身于迷雾之中，对创作的方向和表现形式满腹疑虑，团队间的讨论充斥着不确定与分歧。

然而，在无数次的思想碰撞与汗水浇灌下，这股起初看似散乱的力量逐渐汇聚成了创新的洪流。他们学会了倾听彼此的声音，将各自的独特视角融入共同的创作中，最终，一座座由灵感与汗水筑成的桥梁横跨了最初的困惑与犹豫。当他们的作品在省级舞蹈比赛的舞台上大放异彩，荣获佳绩之时，他们眼中闪烁的不仅是胜利的喜悦，更是通过不懈奋斗实现自我突破的骄傲光芒。

这一段经历，如同璀璨星辰照亮了李利民老师教育理念的夜空，深刻地启示了他：作为一名教师，他的角色远不止是知识的传递者，更是潜能的发掘者，勇气的点燃者，应鼓舞学生们勇敢跨越舒适区的边界，教会他们在失败与挑战的荆棘路上寻找绽放的花朵。这份经历，不仅镌刻在了学生的记忆中，也成为了李利民老师教育征途上一座永恒的里程碑，提醒他永远不要低估引导与激励的力量，因为它足以点亮无数年轻心灵中的梦想之光。

近几年，“内卷”这一话题引起社会的广泛关注，不少同学对未来比较迷茫甚至焦虑。而李利民老师认为重要的是引导学生树立正确的价值观和人生观。本科阶段是探索自我、奠定基础的关键时期，学生们应当充分利用这段时间广泛涉猎，不仅限于专业知识，也要注重人文素养和社会实践。他建议同学们设定清晰的目标，但同时保持开放和灵活，学会在竞争中寻找合作的机会，培养抗压能力和终身学习的习惯。

【教师寄语】

值此城院二十周年之际，李利民老师想对城院和所有城院学子说：“二十年风雨兼程，见证了无数梦想的起航与实现。愿城院继续秉承教育初心，不断创新，培养更多有社会责任感、有创新能力的时代新人。而城院的学子们，你们正站在历史与未来的交汇点，愿你们珍惜在校时光，勇敢追求梦想，不惧挑战，不懈奋斗。无论未来身在何方，都要铭记‘厚德务实，知行合一’的校训精神，为社会贡献自己的光和热。城院永远是你们温暖的家，期待你们书写更加辉煌的篇章！”
