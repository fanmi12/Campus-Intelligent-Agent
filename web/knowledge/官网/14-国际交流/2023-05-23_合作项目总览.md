# 合作项目总览

一、 项目简介

东莞城市学院高度重视国际化人才培养，积极拓展与全球优质高校的合作网络。为进一步拓宽我校毕业生的升学渠道，助力学子实现更高层次的学术追求，国际交流合作部（港澳台事务办公室）依托深厚的校际合作基础，特别推出境外硕士推荐（保荐）项目。

该项目为城院学子搭建了一条免统考、直通海外及港澳名校的“绿色通道”。通过我校官方保荐渠道申请合作院校的硕士研究生，学生不仅能享受高效便捷的申请指导与校内专属“绿色通道”，更可获得免初试/笔试、学费大幅减免、保底奖学金、免报名费等城院专属优待。项目学历均受中国教育部留学服务中心（中留服）全面认证，为你的海外升学之路保驾护航！

二、 合作院校及项目概览

1.澳门科技大学硕士保荐项目

院校亮点： 澳门规模最大的顶尖综合型大学，QS世界大学排名前列。保荐专业全覆盖，涵盖商管、人文艺术、计算机、法学等我校绝大部分对口热门领域。

城院专属优待：获我校保荐资格者，直接豁免竞争激烈的常规初试环节。

免交500元（澳门币/港币）报名费。

曾赴该校参加过交换生项目的同学享有优先录取权。

2. 澳门圣若瑟大学硕士保荐项目

院校亮点： 采用欧洲学分互认体系（ECTS）的特色名校，国际化师资团队。保荐专业涵盖MBA、设计学（互动设计）、建筑学、环境科学及教育学等。

城院专属优待：凡我校毕业生被录取，就读期间连续两年均尊享20%学费减免特惠（以MBA为例，两年立省约3万元人民币）。

中/英双语授课项目可选，不出国门尽享欧洲教育体系。

3.澳门城市大学硕士保荐项目

院校亮点： 位于大湾区核心城市的知名高校。重点保荐教育学院（教育学硕士），全中文授课，无语言门槛，是进入教育行业的黄金跳板。

城院专属优待：不限本科专业背景，尤其适合汉语言、外语、管理类学生跨界深造。

免初审直达面试：走校内“绿色通道”获得正式推荐名单后，申请材料直接跳过海选初筛环节，录取胜算大幅跃升。

4. 韩国庆星大学硕士保荐项目

院校亮点： 位于韩国釜山的优秀重点综合大学。保荐专业含商管、大数据、艺术设计（音乐/视传）及传媒等，高度契合我校专业设置。

城院专属优待：提供中、英、韩多语种授课模式，其中中文授课项目最快1年即可毕业，无语言障碍。

免国内统考，经推荐面试即录；首学期直接享受40%学费减免（立省超万元），后续依据成绩最高可获100%全额奖学金。

5.英国巴斯斯巴大学硕士保荐项目

院校亮点： 英国著名公立艺术与教育类名校。本次重点保荐舞蹈（Dance MA）等艺术类及相关专业，非常适合我校创意设计/艺术类学子深造。

城院专属优待：可凭参加校内语言测试（BSULT）替代雅思成绩申请直录。

凡获录取生均无条件获得1,500英镑（约1.3万人民币）的专属保底奖学金。

一年制速成：纯正英国1年制授课型硕士，大幅节约时间与生活成本。

三、 硕士推荐项目申请流程

各项目具体申请节点略有不同，通用申请流程如下：【校内报名登记】 关注国际交流合作部发布的当季项目启动通知。有意向的学生需在规定截止日期前，联系负责老师进行意向登记，并获取详细的《申请材料清单》。

【提交校内审核材料】 准备中英文全学年成绩单、在读证明/毕业证、相关申请表等材料，提交至国际交流合作部进行校内初审。

【校方正式推荐/提名】 初审通过后，国际交流合作部将符合条件的学生名单及材料汇总，作为“保荐生”正式提名给境外合作高校。

【官方系统网申】 在部门老师的统一指导下，学生登录对应合作高校的官方招生系统，完成在线网申填报及所需材料的上传。

【考核与录取】 境外高校对提名的保荐生进行材料复核，并视专业要求安排线上面试（大部分项目可免除初试/笔试）。考核通过后，由境外高校正式发放录取通知书（Offer）。
