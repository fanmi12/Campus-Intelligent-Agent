# 东莞城市学院二期项目部招聘公告

一、项目概况

本项目为东莞城市学院学生宿舍楼新建工程，采用

EPC（设计-采购-施工）总承包模式，总建筑面积约13万平方米，涵盖宿舍楼建筑施工、配套水电管网、消防、装修及附属设施建设，是学校重点民生工程。

二、招聘岗位及职责要求

（一）甲方项目经理

1.岗位职责

（

1）统筹项目甲方现场管理，负责进度、质量、安全、成本及合同管控；

（

2）对接各方单位，建立高效沟通协调机制；

（

3）审核签证变更及进度款，组织现场检查、工程验收；

（

4）组织编制项目甲方管理计划、进度管控方案，审核施工组织设计、专项施工方案、进度计划，监督方案落地执行，确保项目按计划节点推进，按期竣工交付；

（

5）监督工程施工质量与安全生产，组织开展现场质量检查、安全巡查，及时发现并督促整改施工过程中的质量隐患、安全问题，协调解决项目施工中的重大技术问题、现场纠纷；

（

6）配合结算审计，定期汇报项目进展。

2.任职要求

（

1）建筑、土木相关专业全日制本科及以上，持一级建造师（建筑工程）证或中级职称证者优先，持安全生产员证书者优先；

（

2）5年以上甲方项目管理经验，有EPC、高校基建项目经验者优先；

（

3）精通项目管理相关规范，具备统筹协调、现场决断及文字汇报能力，能独立处理项目现场各类突发问题，责任心强、品行端正。

（二）土建工程师

1.岗位职责

（

1）协助项目经理负责土建专业现场管理，把控施工质量、进度及安全；

（

2）参与图纸会审、技术交底，审核专项方案，监督关键工序施工及隐蔽工序验收，初审签证变更，整理施工资料；

（

3）监督土建施工安全生产，检查现场安全防护措施、文明施工情况，督促施工单位落实安全整改要求，参与现场安全巡查与隐患排查。

2.任职要求

（

1）建筑相关专业全日制本科及以上，持二级及以上建造师证或中级职称证者优先，持安全生产员证书者优先；

（

2）3年以上土建施工管理经验，有甲方或民用建筑项目经验者优先；

（

3）精通土建施工规范及工艺，具备现场技术处理能力，严谨负责、具备良好的沟通协调能力和团队协作精神，能积极配合项目经理完成各项工作。

（三）水电工程师

1.岗位职责

（

1）负责项目给排水、强弱电、消防等水电专业现场管理，统筹设计、施工、验收全流程；

（

2）参与图纸会审，审核施工及设备选型方案，监督施工质量与进度，审核签证变更，整理相关资料，落实安全管控；

（

3）监督水电工程施工质量，对关键环节检查验收，把控施工工艺、材料质量，杜绝质量隐患；

（

4）协调水电工程与土建、装修等专业的交叉施工，管控水电施工进度，解决技术难题，保障水电工程与整体项目同步推进；

（

5）监督水电施工安全规范操作，检查现场用电、用水安全，督促施工单位做好水电设备防护与安全管理，配合完成专项验收及竣工验收。

2.任职要求

（

1）水电工程相关专业全日制本科及以上，持中级职称证或相关职业资格证书者优先，持安全生产员证书者优先；

（

2）5年以上水电安装管理经验，有甲方或高校基建项目经验者优先；

（

3）精通水电相关规范及流程，具备独立技术处理能力，认真细致、善于沟通。
