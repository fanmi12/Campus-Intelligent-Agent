# 《中国近代教育文献全文检索知识服务数据库》 试用通知

】中国近代教育文献全文检索知识服务数据库

登录方式

【试用时间

】即日起至2023年8月25日

【数据库介绍

】“中国近代教育文献全文检索知识服务数据库”是以“十三五”国家重点图书《中国近代教育文献丛刊》为基础而实施的大型文献数据库项目，该项目于2022年7月成功入选中央文改办“国家文化产业发展项目库”入库项目。

该数据库体系清晰，内容详实，包含1840年至1949年中国学者的著作及译作，并配以由当代教育领域专家学者撰写的相关内容提要。目前已收集整理近代文献5000种，内容分为留学教育、教育史、教育法规、外国教育译介、教育学、地方教育文献等18类，总字数超过4亿字。

该数据库是国内唯一的全面系统性的大型文献资料平台，也是历史上第一次通过网络数据库的形式集中展示新时代中国学者关于“近代教育文献”研究的最新成果，具有重大学术价值和传播价值。
