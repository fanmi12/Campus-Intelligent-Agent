# 图书馆获赠一批高质量专业性强的图书

为了进一步丰富图书馆藏资源，更好的满足读者阅读需求，图书馆积极加强社会的联系，近期获赠一批高质量专业性强的图书。由广东省金融智库联合会捐赠，广东省人民政府金融工作办公室等编撰的《2017广东金融发展蓝皮书（首卷）》、《2018广东金融发展蓝皮书》、《2021广东金融发展蓝皮书》、《2022广东金融发展蓝皮书》等。这些图书均由国内知名出版社出版，内容权威，具有很高的学术价值和实践指导意义。

获赠由国民信托有限公司博士后科研工作站组织编译出版的《外国古代货币词汇》、《世界货币史古代卷》和《外国货币史译丛》等图书。国民信托有限公司博士后科研工作站是经国家人社部和全国博管会批准设立，以推动行业可持续发展、培养高层次人才为目标，依托专业资产管理和投资研发团队，探索信托转型创新研究，致力于成为具有广泛影响力和知名度的博士后科研工作站。

图书馆对这些捐赠文献悉心收藏与整理，除了纳入普通书刊借阅流通书库外，还特设友好书库进行专项收藏和管理。目前，以上获赠图书已进行了加工上架处理，欢迎各位读者前来借阅。同时，图书馆也将积极开展各类阅读推广活动，引导师生充分利用图书馆优质馆藏资源，提高文化素养、创新能力和学术水平。

图书信息中心陈显龙主任表示：“社会渠道，尤其是专业机构的捐赠，对我们图书馆馆藏资源建设具有重要意义。近年来，许多知名机构、著名学者，以及广大校友、普通读者都热心地向我馆赠送各类作品。为了感谢捐赠方的慷慨支持，东莞城市学院图书馆将在馆内设立专门的捐赠墙，展示捐赠方的荣誉证书和感谢信，以此激励更多社会力量关心和支持教育事业，共同为学校发展做出贡献。”
