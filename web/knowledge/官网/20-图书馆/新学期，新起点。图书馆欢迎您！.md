# 新学期，新起点。图书馆欢迎您！

春风拂面，书香满园。伴随着新学期的到来，图书馆也以崭新的面貌，期待着与大家再次在此相遇。新学期图书馆开馆安排等各项事宜通知如下：

一、开放时间：周一到周日8：30--23：00。

国家法定节假日开馆时间另行通知。

二、借还须知：凭借虚拟校园卡即可借阅图书。

学生读者可借阅10册，借期2个月，可续借一次；教师读者可借阅15册，借期3个月，可续借一次。请爱护图书，及时归还，逾期将产生超期款。

寒假期间逾期图书已自动延期，请于

开学后两周内归还。

三、温馨提示：

1.阅览时保持安静，请勿在馆内大声喧哗。

2.请勿占座，离开时带走自己的物品，“人走座空”。

3.请妥善保管好自己的贵重物品，如有遗失，责任自负。

4.图书馆是重点防火单位，严禁携带易燃易爆物品入馆！严禁在馆内任何场所吸烟、用火！

新学期，新起点。图书馆与您一起，在知识的海洋里扬帆起航！如有任何疑问，请咨询图书馆工作人员，我们将竭诚为您服务。
