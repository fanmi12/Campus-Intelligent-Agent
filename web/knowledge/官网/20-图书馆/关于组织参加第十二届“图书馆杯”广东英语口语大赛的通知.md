# 关于组织参加第十二届“图书馆杯”广东英语口语大赛的通知

为进一步宣传贯彻党的二十大精神，凝聚奋进新征程的力量，增强中华文明传播力影响力，推进文化自信自强，铸就社会主义文化新辉煌，讲好中国故事、传播好中国声音，充分发挥图书馆在国际文化互鉴和交流中的推动作用，为全省各馆员和读者搭建起用外语传播中华文化的舞台，广东省立中山图书馆、广东图书馆学会和广东省高校图工委拟于4月至6月期间，举办第十二届“图书馆杯”广东英语口语大赛，鼓励广大读者群众全方位、多层次、广角度讲述新时代湾区故事，传播中华优秀传统文化。

本次大赛分设读者组（包含公共图书馆读者、各高校图书馆读者）与馆员组。在正式比赛开始前，组织单位需按要求提前进行资格申报。

①电脑端报名

通过大赛官方网站进入“选手报名”，选择对应组别、所属图书馆，并填写个人真实信息进行报名，报名成功即可参赛。

②手机端报名

扫码进入官方小程序，选择第十二届“图书馆杯”广东英语口语大赛，进入活动页面进行报名。

05比赛规则

网络初赛

网络初赛采取“14天朗读马拉松计划”赛制，选取14篇包含中国非遗文化、名胜古迹等主题的“中国故事”英语文章，供参赛选手每日朗读打卡。

①在线朗读打卡

通过电脑或手机扫码登录官方小程序，即可进行在线朗读，完成单篇文章朗读后，系统即时评分反馈，产生成绩即视为打卡成功，每篇朗读文章满分为100分。所有文章均可重复朗读，系统自动记录最高得分作为该篇成绩。

②连续打卡奖励

连续打卡3天、5天、7天、10天、14天，会获得相应的连续打卡奖励分数。

③个人总成绩

根据“所有朗读文章成绩×80%+连续打卡奖励×20%”计算。

**网络复赛

**选手围绕大赛主题提交一段3分钟内的英文演讲视频作品。由主办方组织专家评委线上评分，具体规则另行公布。

全省总决赛

采用现场比赛的方式进行，地点为广东省立中山图书馆，具体规则另行公布。

06参赛须知

参赛选手凡按照大赛要求参赛，即视为同意无偿授权本活动各组织机构（主办、承办、支持及有关组织单位）将其参赛作品、录像用于非盈利性/公益用途，包括但不限于以单独或汇编形式的线上及线下展播、媒体报道、网络推广，并同意授权上述组织机构无偿将创作者肖像用于作品展示、公益宣传推广等活动。

各组织机构（主办、承办、支持及有关组织单位）不得将选手参赛录像用于盈利性活动，使用方式和范围须遵守前述参赛选手有关授权规定。

凡符合资格的参赛选手即视为同意上述权利声明及责任承担方式。

07晋级规则

读者组晋级规则

①晋级“网络复赛”说明

（1）个人总成绩在全省排名前100名的选手可直接晋级网络复赛。

（2）各组织单位排名前2名的选手可直接晋级网络复赛，如个人总成绩已在全省排名前100名，则晋级资格顺延至下一名。

（3）任一初赛朗读文章未完成或不合格者无晋级资格。

②晋级“全省总决赛”说明

（1）选手围绕大赛主题提交一段3分钟内英文演讲视频。由主办方组织专家评委线上评分，具体规则另行公布。

（2）“网络复赛”排名前25名的选手，将获得“全省总决赛”预备晋级资格，主办方会对获得“全省总决赛”预备晋级资格的25位选手进行远程面试，面试内容另行通知，通过面试的选手晋级“现场总决赛”。

馆员组晋级规则

图书馆员报名参加“网络初赛”，通过“网络初赛”个人总成绩排名，产生“馆员组”获奖名单。
