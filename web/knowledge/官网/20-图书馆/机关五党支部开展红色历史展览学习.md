# 机关五党支部开展红色历史展览学习

为持续深化党史学习教育，赓续本土红色血脉，锤炼党员党性修养，2026年9月21日上午10时，东莞城市学院机关五党支部全体党员前往学校图书馆，开展东江纵队历史主题展览学习。本次活动配备专任讲解员全程解说，以实景研学形式开展沉浸式党性教育，让支部党员近距离感悟东莞红色革命精神。

东江纵队是党领导的华南抗日主力部队，是华南敌后抗战的重要旗帜，在东莞乃至华南革命史上留下了珍贵的红色印记。本次图书馆主题展览内容翔实、史料丰富，通过历史图片、文献资料、革命实物等多元展陈，系统呈现了东江纵队艰苦卓绝的组建发展历程与浴血奋战的抗战岁月，生动诠释了东纵将士忠诚向党、不畏艰险、扎根群众、无私奉献的崇高革命精神。

参观现场，讲解员围绕东江纵队核心抗战历程、经典战斗事迹和本土革命故事展开细致讲解，带领党员重温华南敌后抗战的峥嵘岁月。全体党员认真聆听讲解、驻足观摩史料，深入了解东江纵队在物资匮乏、环境恶劣的条件下，坚守抗日初心、奋勇保卫家国的光辉事迹，真切感受本土红色文化的深厚底蕴和革命先辈的赤诚家国情怀。

此次学习形式新颖、教育意义深刻，打破了传统理论学习的局限，让党史学习教育更加生动鲜活、入脑入心。全体党员在沉浸式学习中接受思想洗礼、锤炼初心使命，深刻认识到今日的和平生活来之不易。大家纷纷表示，将铭记革命历史、传承东纵精神，把学习成果转化为工作实效，立足机关岗位，履职尽责、实干担当，以优良作风服务师生、助力学校发展。

下一步，机关五党支部将充分依托东莞本土红色资源，常态化开展红色研学、党性教育活动，持续丰富党建学习形式，推动党建与岗位工作深度融合，切实发挥基层党组织战斗堡垒和党员先锋模范作用，为学校高质量发展筑牢红色根基。
