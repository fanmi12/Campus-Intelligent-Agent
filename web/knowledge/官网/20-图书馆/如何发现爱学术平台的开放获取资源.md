# 如何发现爱学术平台的开放获取资源

访问平台首页

www.iresearchbook.cn，点击中间区域的**“查看授权资源”；或勾选搜索框下方

仅看已授权资源**后点击搜索。

2. 在新的页面即可浏览到本馆全部授权的资源。

3. 选择你喜爱的开放资源，点击在线阅读即可开始你的阅读之旅！
