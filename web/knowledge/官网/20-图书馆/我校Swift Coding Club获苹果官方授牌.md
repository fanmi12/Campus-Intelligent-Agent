# 我校Swift Coding Club获苹果官方授牌

5月30日上午，我校联合苹果教育团队成立“Swift Coding Club”，并在图书馆举行了授牌仪式，成立“Swift Coding Club”旨在为学生提供实践iOS生态开发的平台，响应数字化时代对移动开发人才的需求。信息与实验中心主任陈显龙、图书馆副馆长袁秀美、Apple中国教育行业客户总监王浩淼、Apple中国资深技术顾问马泉伟等相关人员出席授牌仪式。

Swift Coding Club是一个全球性项目，主要是提升高校学生App开发技能，通过Swift Coding Club探索新技术、构建自己的App、建立人脉圈来寻找职业机会等，并有机会参加Swift Student Challenge项目。将给予全程培训、辅导并提供竞赛平台，每月/每季将组织线上、线下沙龙活动，通过活动交流，增加Swift Coding Club成员的开发能力。

授牌仪式现场，Apple中国教育行业客户总监王浩淼为大家详细介绍了Swift Coding Club项目。陈主任对Apple一行表示热烈欢迎，随后双方对Swift Coding Club项目的拓展以及合作方式上进行深入探讨。
