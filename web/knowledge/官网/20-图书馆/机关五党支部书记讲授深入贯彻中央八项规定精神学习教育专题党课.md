# 机关五党支部书记讲授深入贯彻中央八项规定精神学习教育专题党课

为深入贯彻中央八项规定精神学习教育，进一步加强支部党员的党性修养和纪律意识，6月11日下午，机关五党支部书记许之鹏以《学习中央八项规定精神，筑牢廉洁自律防线》为题讲授专题党课，支部全体党员参会。

会上，党支部书记许之鹏同志结合典型案例，系统解读了中央八项规定及其精神内涵。党课强调，要纵深推进全面从严治党、党风廉政建设和反腐败斗争，始终把政治建设摆在机关建设首位，要强化理论武装，深刻领悟“两个确立”的决定性意义，坚决做到“两个维护”。要加强作风建设，认真开展深入贯彻中央八项规定精神学习教育，密切联系群众，切实改进作风。要加强纪律建设，加强教育，加强监督。要强化全面从严治党主体责任和监督责任，落实党风廉政建设责任制，一体推进不敢腐、不能腐、不想腐，对违纪问题坚决查处。

党支部书记许之鹏强调，要深刻认识贯彻落实中央八项规定精神的重要性、必要性、长期性，切实提高政治站位，形成落实中央八项规定精神、涵养新风正气的高度自觉，常抓不懈、久久为功、化风成俗，希望支部全体党员干部敬畏纪律，常紧纪律之弦，立足本职岗位，在遵规守纪、清正廉洁基础上，围绕大局，履职尽责，勇于担当。

此次党课，让全体党员对八项规定有了更为深刻的理解。课后，党员们纷纷表示，将严格按照八项规定的要求，在今后的工作中以更高的标准规范自身言行，充分发挥党员的先锋模范作用，为党和人民的事业拼搏奋斗，助力党支部工作迈向新的高度。
