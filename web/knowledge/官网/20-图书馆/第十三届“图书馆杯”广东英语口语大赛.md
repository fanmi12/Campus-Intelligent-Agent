# 第十三届“图书馆杯”广东英语口语大赛

为鼓励广大读者群众用流利的英语讲述湾区文化故事，通过语言的力量，展示文化传承与文化创新精神，助力文明交流互鉴，共绘湾区文化繁荣的崭新篇章，第十三届“图书馆杯”广东英语口语大赛如期拉开帷幕，期待你的参与，共同见证精彩时刻！

一、组织机构

主办单位：广东省立中山图书馆、广东图书馆学会、广东省高等学校图书情报工作指导委员会

组织单位：广东省各公共图书馆、高校图书馆

协办单位：阅途文化集团

二、大赛主题

文化传薪火，“阅”进大湾区

三、参赛对象

广东省各公共图书馆、高校图书馆读者及馆员

四、参赛时间2024年3月至6月

五、参赛平台

1.参赛网站：https://lib.52met.com/gd2024

2.微信小程序：

六、赛程安排

1.网络初赛：2024年3月21日至4月25日

2.网络复赛：2024年4月30日至5月12日

3.复活挑战：2024年4月30日至5月12日

4.全省总决赛：2024年6月2日

七、大赛流程

（一）选手报名参与

大赛分设读者组与馆员组。读者组包含公共图书馆读者和高校图书馆读者；馆员组仅限图书馆在职馆员报名，后期将进行身份核实，如有非馆员误报，成绩作废。

**电脑端报名：**通过大赛官方网站进入“选手报名”，选择对应组别、所属图书馆，并填写个人真实信息进行报名，报名成功即可参赛。

**手机端报名：**通过“MET全民英语”小程序，选择本届大赛进入“选手报名”。

（二）网络初赛

网络初赛采取“7天朗读马拉松计划”赛制，选取7篇包含湾区景点地标、非遗文化等主题的“湾区故事”英语文章，供参赛选手每日朗读打卡。

1.在线朗读打卡

通过电脑或手机扫码登录参赛小程序，即可进行在线朗读,完成单篇文章朗读后，系统即时评分反馈，产生成绩即视为打卡成功，每篇朗读文章满分为100分。网络初赛期间，所有文章均可重复朗读，系统自动记录最高得分作为该篇最终成绩。

2.每日打卡奖励

在初赛期间，每完成一日打卡，即可获得一次额外加分，一次100分，累计上限为7天。

3.个人总成绩

根据“所有朗读文章成绩×90%+每日打卡奖励×10%”计算。

注：在初赛期间，报名信息如有填写错漏，可自行更正，以最新信息为准。如切换组别或机构，原有成绩将被清除，朗读打卡成绩需重新获取。初赛结束后，关闭所有信息修改通道，请务必提前核对清楚，如因个人信息错漏影响晋级或获奖，责任自负。

（三）网络复赛

选手围绕大赛主题提交一段 3分钟左右的英文演讲视频作品，由主办方组织专家评委线上评分。

1.视频提交时间2024年4月30日至5月12日，未在规定时间成功上传视频，或重新上传视频后仍未审核通过，视为自动放弃复赛资格，无获奖证书或证明。

2.视频作品要求

（1）时长：不短于2分钟，不长于4分钟；

（2）格式：MP4格式，分辨率1920*1080（[16:9]1080p，即常见智能手机原相机或单反相机等横屏拍摄情况下的标准尺寸），H.264编码，文件大小不超过800MB，拍摄时采用横屏取景，确保画面高清；

（3）选手出镜时间：不低于2分钟；

（4）内容要求：围绕本次大赛主题，自行拟写英文演讲稿（含中文翻译），并完成演讲视频录制，拍摄内容必须包含主题相关元素，不限表现形式，画面和录音清晰流畅。视频内容应符合相关法律法规的要求，不得出现商业水印、商业广告或个人隐私信息；

（5）字幕要求：视频中含有中英文双语字幕（建议英文在上，中文在下，字体不限，字号大小清晰合理，不出现错字漏字）；

（6）视频导出：完成视频制作后，请注意导出符合1920*1080（[16:9]1080p）要求的高清文件（如需从手机传送至电脑进行上传，须通过蓝牙、邮件、文件等传输方式，避免通过微信等聊天工具传输，以免视频原文件被压缩，影响视频清晰度）；

3.视频提交方式

复赛视频将通过大赛网站上传提交，晋级选手登录大赛网站https://lib.52met.com/gd2024，点击进入“复赛视频”专栏，按照提示上传相关资料。

4.评分标准

评分侧重点包含英文语音语调、演讲内容和结构、表达技巧、语言应变能力、仪容仪表等方面；此外，复赛视频的制作质量也将作为综合评分的一部分，具体包括但不限于画面和声音清晰度、转场流畅度、字幕清晰度以及停留时间设置等方面。

（四）复活挑战

本次大赛增设“复活挑战”环节，**凡完成初赛且个人总成绩超过600分（满分700分）的选手均有资格参与，**并须在网络复赛期间按规定时间提交英文演讲视频作品，具体作品要求与复赛要求一致，视频作品将同步参与线上评分，择优晋级“全省总决赛”（限2名以内）。

（五）全省总决赛

1.比赛时间

赛前彩排：2024年6月2日（周日）9:00-12:00 （8:30开始签到）

正式比赛：2024年6月2日（周日）14:30-17:30

2.比赛地点

广东省立中山图书馆文明路总馆一号报告厅

3.比赛内容

第一环节为定题演讲。选手围绕大赛主题进行限时3分钟的英文脱稿演讲，演讲文稿和其他辅助材料（PPT、图片或视频等）需按要求提前交至主办方审核。第二环节规则另行公布。

4.颁奖仪式

现场为总决赛选手和获得“优秀组织单位奖”的单位代表举行颁奖仪式。

参赛选手凡按照大赛要求参赛，即视为同意无偿授权本活动各组织机构（主办、承办、协办、支持及有关组织单位）将其参赛作品、录像用于非盈利性/公益用途，包括但不限于以单独或汇编形式的线上及线下展播、媒体报道、网络推广，并同意授权上述组织机构无偿将创作者肖像用于作品展示、公益宣传推广等活动。

凡符合资格的参赛选手即视为同意上述权利声明及责任承担方式。

九、晋级规则

（一）读者组晋级规则

1.晋级“网络复赛”说明

（1）个人总成绩在全省排名前100名的选手可直接晋级网络复赛。

（2）各组织单位排名前2名的选手可直接晋级网络复赛，如个人总成绩已在全省排名前100名，则晋级资格顺延至下一名。

（3）任一初赛朗读文章未完成或不合格者无晋级资格。

2. 晋级“全省总决赛”说明

（1）由主办方组织专家评委对“网络复赛”和“复活挑战”中提交的视频作品进行线上综合评分。

（2）在评分中排名前25名的选手，将获得“全省总决赛”预备晋级资格，主办方会对获得“全省总决赛”预备晋级资格的25位选手进行远程面试，通过面试的选手正式获得晋级“全省总决赛”资格。

（二）馆员组晋级规则

图书馆员报名参加“网络初赛”，通过“网络初赛”个人总成绩排名，产生“馆员组”获奖名单。
