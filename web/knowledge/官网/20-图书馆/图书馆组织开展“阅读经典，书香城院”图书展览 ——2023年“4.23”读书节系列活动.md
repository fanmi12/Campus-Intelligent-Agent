# 图书馆组织开展“阅读经典，书香城院”图书展览 ——2023年“4.23”读书节系列活动

值此2023年“4.23”读书日来临之际，图书信息中心组织了一系列的2023年“4.23”读书节活动。4月18日下午，在图书信息中心二楼中厅组织开展“阅读经典，书香城院”图书展览活动，旨在让师生读者们深入了解经典文化，增强阅读兴趣，提升自身修养。图书信息中心全体工作人员真诚欢迎各位读者莅临书展现场。

图书展览活动已经吸引了不少读者前来参观借阅，活动现场不仅有读者前来驻足阅读，也有不少读者阅读后借阅图书。有同学表示，此次图书展览活动，激发了他们更多的阅读兴趣，也开始尝试更广泛阅读。同时，图书信息中心工作人员也在活动过程中向读者介绍更多的文献资源与相关服务。

据悉，本次图书展览活动时间将持续到4月31日。图书信息中心负责人表示，图书馆将继续结合自身资源和特点，组织开展丰富多彩的阅读推广活动，引导读者积极参与阅读，推广经典文化，助力学校文化建设。后续图书信息中心还将陆续组织各种形式的读者活动，为各位读者提供全方位的优质服务和资源支持。
