# 机关党总支携手学生社区党总支举办“三全五导”成长导师制专题培训会

2025年1月8日，机关党总支携手学生社区党总支在行政楼112会议室举办“三全五导”成长导师制专题培训会。学校党委书记章德胜，党委副书记、副校长李海冬，副校长周庆，副校长李振华出席了会议，机关党总支、学生社区党总支全体党员同志、入党积极分子和群众导师参加了培训活动。

机关二党支部书记、国家心理咨询师、广东高校青春健康宣讲团专家詹海都作了主题培训。他首先通过大量数据统计介绍了我校在校学生基本情况，分析了大学生物资生活、学业求职、自我中心意识等总体心理特点与需求，进而阐述了“三全五导”如何“导”这一成长导师亟需的“秘籍攻略”。他从“高校教育的初心使命、围绕育人目标、科学理论指导”三个基本遵循，以及“全面把握指导内容”“如何有效开展指导”，进行了深入浅出的系统分享。他还着重探讨如何通过“三全五导”提升师生交往的质量，分享了师生交往技巧与注意事项，鼓励成长导师们去体验这场“用生命触动生命、以灵魂唤醒灵魂的奇妙旅程”。

李海冬副书记作了总结讲话，并分享了作为三名大学生成长导师的心得体会和工作经验。他肯定3个月来，广大参与“三全五导”成长导师制的机关导师们所作出的努力和成绩。他强调，学校党委推行“三全五导”成长导师制，要求全校教工党员走近学生、深入学生，以党建引领助力青年学生成长成才，是学校党委在新形势下探索做好人才培养工作的新路径。他指出，这是从之前少数人自发，到多数人有组织地开展本科生导师制的过程，是极有必要的工作创新。在分享了自己的经验和思考后，他要求导师们根据学生特点和发展需求，制定个性化的培养方案和辅导策略；不仅要给予学生的学业就业等方面的指导，更要注重学生的心理健康和道德品质教育；不断积累经验，帮助学校建立该项工作的长效机制，促进大学生全面发展。

会议还对机关党总支及学生社区党总支在“奋进新征程学习正当时”学习贯彻党的二十届三中全会精神学习强国学习打卡活动中，获得学习标兵荣誉称号的张兰、周杰、何钊威、叶浩波、梁圣东、赵东敏、吴倩芸等同志进行了表彰。学校党委书记章德胜进行了颁奖。

此次活动也是机关党总支举办的第十期“锦囊分享会”，陈东汉书记主持了活动。
