# “校园秋色美，记录开学季”摄影征集活动

一、活动背景

秋季是校园一年中最美的季节，金黄的落叶、碧蓝的天空、洋溢着青春气息的校园无不让人心旷神怡。随着新学期的到来，校园不仅展现了它美丽的自然景观，也见证了学子们的新起点与新的奋斗历程。为了让师生通过镜头记录下这美好的瞬间，提升校园文化氛围，特举办**“校园秋色美，记录开学季”摄影征集活动**。

**二、**

组织单位

- 主办单位 -『设计师之家数字图书馆』

三、时间安排

1.报名与参赛2024年9月23日至10月24日

2.成绩公布2024年11月

3.发放证书和奖品2024年11月

四、参与对象所有人均可参赛

五、作品要求

作品内容可涵盖多个主题，包括

校园秋日风景，如金黄树叶、清晨薄雾；也可捕捉

校园生活瞬间，如操场上的活力、课堂内的专注或课余时的互动。此外，新学期的活动，如开学典礼、社团招新、运动会等，都是展现校园活力与学生风貌的绝佳题材。这些内容展现了校园秋天的独特魅力与学生们的积极精神。

摄影作品，统一为

JPEG格式，单张照片文件

大小不超过20M，每位参赛者

最多可以上传3次作品，每次提交

最多包含5张照片。

投稿须知

1.投稿作品内容必须符合国家相关法律法规，坚持正确的政治方向、舆论导向、价值取向，确保作品须为原创，无剽窃行为。

2.投稿者须保证拥有投稿作品的完整著作权，凡涉及的包括但不限于版权、肖像权、名誉权等法律责任由作者本人承担。

3.所有投稿作品，主办单位可用于不以盈利为目的的活动（包含商业性使用与非商业性使用），包括但不限于展览、出版、媒体报道、网络推广、文创产品开发等，不需支付稿酬。

4.所有投稿作品恕不退还，请作者务必保留作品源文件。

5.凡投稿者，即视为其已认同且接受本次活动规则。活动举办方对本次活动拥有最终解释权。
