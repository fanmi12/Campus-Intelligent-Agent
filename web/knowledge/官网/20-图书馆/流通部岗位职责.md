# 流通部岗位职责

1.流通服务部部长【负责人】岗位职责

主要职责：制定工作计划；编制预算；管理勤工助学学生

⑴在中心主任的领导下，负责管理、协调读者服务部日常业务工作；并按区域管理责任制要求，负责监督管理各责任人完成区域管理内容及要求；

⑵制定本部工作计划、人员考核细则，负责组织实施并进行工作总结；

⑶负责本部门的业务学习、物资管理、卫生保洁、环境美化和安全保卫工作；

⑷负责对责任区域及各书籍阅览区和期刊阅览区进行日常管理；

⑸负责解决和答复读者提出的有关图书流通和期刊阅览的问题与建议；

⑹熟练运用流通子系统的各项功能，负责流通系统数据库用户的权限管理，严格规范权限范围；

⑺根据经费预算管理制度定期提交经费预算；

⑻负责对本部业务数据进行汇总统计，每月初主动按时向中心办公室递交上月业务报表，并于每年年初向办公室递交上年度报表；

⑼负责做好读者服务部勤工助学学生的录用、培训、考核等管理工作；

⑽完成中心安排的其他工作。

2.总服务台管理员岗位职责

主要职责：图书借出和归还；图书分类

⑴负责图书馆图书的借出和归还工作，负责出借时消磁，入库时充磁工作；

⑵向读者提供图书馆相关咨询服务工作；

⑶负责图书超期滞还、遗失赔损、污损修补等管理工作；

⑷负责将缺数据的图书送回资源建设部重新加工；

⑸负责将归还图书按楼层分类；

⑹负责前台各项工作量的统计工作，每月或依指示主动按时上报部长；

⑺按时交接班，严格履行岗位职责，不得擅自离岗、串岗；

⑻按区域管理负责制，完成区域管理内容及要求；

⑼完成中心安排的其他工作。

3.报纸、期刊管理员岗位职责

主要职责：报纸、期刊的登记，上架整理

⑴按区域管理责任制，完成区域管理内容及要求；及时领取报纸、上架，分送各部门订阅报纸；

⑵准确及时地将各室的报纸和信件送达，负责整理好当月报纸并存到当月存报架；

⑶需要装订的报纸，定期（每半月或一个月）下架一次，要登记、捆绑，送至指定地点，学期末统一装订；

⑷负责图书馆期刊的管理工作，有计划、有重点地进行合理收藏；

⑸负责现刊的接收、验收、登到和上架；要求现刊及时登到上架，不得积压；

⑹向读者提供相关咨询服务；经常巡视期刊阅览区，整理期刊架，保证期刊按类排列；

⑺负责过期期刊的下架、登记；要求登记清楚，并与装订单位交接清楚；及时登记未到报刊，做好未到报刊的催到工作；

⑻负责对勤工助学学生的工作培训、安排与管理；

⑼完成中心安排的其他工作。

4.书籍阅览区管理员岗位职责

主要职责：图书上架、整理

⑴负责按区域管理的要求做好相关一切工作；

⑵及时将新进图书和归还的图书上架，不得积压；

⑶负责新书的接收；在接到资源建设部的通知后，应尽快把已经分类的图书拉到书籍阅览区，并办理好相关手续；

⑷每天进行查架和整架，在读者入库前，保证书架及阅览桌上无散乱的图书和其他杂物，保证图书按类排放；

⑸负责回收自动还书机内的图书；

⑹负责向读者提供相关咨询服务；

⑺负责对勤工助学学生的工作培训、安排与管理；

⑻负责阅览区各种资源利用情况和日常服务工作的统计，每月或依指示主动按时上报部长；

⑼完成中心安排的其他工作。
