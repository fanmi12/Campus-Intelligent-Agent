# 人民邮电出版社电子书平台开通试用

**一、**

试用时间2026年4月7日-2026年10月7日

二、使用说明

PC端：

1. 校内使用：访问网址https://ryebook.ptpress.cn/，无需注册登录，登录个人账号可实时同步个人阅读和学习数据；

2. 校外使用：通过VPN访问、CARSI、或校内注册帐号授权后访问；

3. 在首页、分类、板块等有关区域点击阅读按钮，即可阅读。

4. 屏幕分辨率为1920*1080时，页面呈现效果最佳。

**移动端：**微信扫描下方二维码

**三、**

产品简介人民邮电出版社，1953年10月成立，隶属于中国工信出版传媒集团，是工业和信息化部主管的大型专业出版社。出版领域涵盖科技出版、教育出版、大众出版，涉及信息技术、通信、工业技术、科普、经济管理、摄影、艺术、运动与休闲、心理学、大中专教材等10余个出版门类，在全国图书零售市场的占有率名列前茅，其中计算机类、艺术类、摄影类、运动与休闲类排名第一，设计类排名第二，科普类、美术类排名第四，经管类位居前列。

人民邮电出版社电子书平台依托人邮社自身优质的图书内容资源，为高校图书馆、科研院所、企业等机构用户，提供电子书在线阅读与学习服务。电子书平台中电子书格式为主流的PDF格式，适用于PC端，方便读者学习。学科收录范围包括：计算机和电子信息、工学和理学、经济管理、人文社科和艺术传媒等。现有电子书17000余本，每年更新1000本。

电子图书收录年份从2011年至今，其中32%为近3年出版新书，55%为近5年出版新书。高教教材比例为30%，涵盖经济学、理学、工学、管理学等学科类别，内容设置契合当前高校学科体系建设，难度分阶，满足不同阶段学生的学习需求。

四、样书申请

针对教师，平台特别推出“样书申请”服务，通过认证教师身份即可申请相关教材类纸质书籍。

1. 首页右上角点击样书申请，注册完成点击我的账户进行教师认证，填写完整信息。通过认证教师身份即可申请相关教材类纸质书籍。

2. 在图书板块搜索需要的书籍，点击书籍进入到详情页面，点击【申请样书】填写申请信息之后即可完成申请。

3. 样书申请数量：当月上限 3 本（包含 3 本）。
