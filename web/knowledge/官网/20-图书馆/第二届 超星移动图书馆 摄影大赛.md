# 第二届 超星移动图书馆 摄影大赛

一、活动目的“如果有天堂，那一定是图书馆的模样”，照片是定格最美好瞬间的载体，能直观展现图书馆的氛围与模样。为培养读者良好的阅读习惯，营造书韵深厚的文化氛围，特举办第二届超星移动图书馆摄影大赛活动，展现“我与图书馆”的美好瞬间，珍惜在图书馆读书的时光，用镜头讲述与图书馆的二三事，用镜头诠释与图书馆的不了情。

二、活动主题

第二届移动图书馆摄影大赛以“我与图书馆的故事”为主题，可以是自己与图书馆之间亲历、亲见、亲闻的点滴故事，也可以是记录图书馆各个时期的重大事件、活动、人物的回忆。

三、举办时间

作品征集时间：2023年4月10日8时-4月25日20时

作品排行统计：2023年4月26日-4月28日

获奖名单公布：2023年4月28日

奖品发放时间：2023年5月8日-5月15号

四、参与对象

面向超星移动图书馆APP端、超星移动图书馆小程序端全体注册用户

五、活动流程

1、活动上线阶段

1）活动线上报名后，进行作品提交，每个用户限制最多发表2篇作品，每篇作品可提交多张图片；

2）后台人员对已提交作品进行审核，审核通过作品即展示到作品页面，审核未通过作品作者可进行再次编辑提交，审核已通过作品不可再次编辑；

3）用户可对他人作品进行投送鲜花、点赞和评论，每人每天持有3朵鲜花投票权，最多可对3个作品进行投送鲜花。

2.结果统计阶段

**个人奖项：**后台人员对所有审核通过的作品，按照点赞数+鲜花数之和进行排名，最终评选一等奖-五等奖。

3.结果公示阶段

超星移动图书馆APP端首页、超星移动图书馆小程序端首页公示获奖结果，获奖作品将制作为活动专题进行展示。

六、作品要求

1. 参赛作品内容必须契合主题，取景需在图书馆内及附近，要求真实性与艺术性相结合，展示图书馆良好精神风貌；

2. 作品须由本人原创，严禁剽窃、复制或抄袭，不得有修改、装饰、水印、签名、拍摄软件logo等；

3. 作品不能改变原始摄影，仅可做色彩、色调、亮度适当调整，不可为电脑合成作品；

4. 每人可上传不超过2篇作品，最后获奖名单按作品鲜花数、点赞数综合排名，同一作者的不同作品以最终排名最高的一个入选获奖，即每个用户只有一个获奖名额；

5. 每篇作品需配20字以上说明，并注明作品名称、补充信息。

七、奖项设置个人奖项：本次大赛设一等奖5名，二等奖10名，三等奖20名，四等奖30名，五等奖50名。

奖品如下：一等奖：华为MatePad二等奖：小米手环7pro三等奖：小爱同学蓝牙音箱

四等奖：罗技M330无线鼠标

五等奖：精美笔记本套装

八、投稿方式

超星移动图书馆APP端或超星移动图书馆小程序端
