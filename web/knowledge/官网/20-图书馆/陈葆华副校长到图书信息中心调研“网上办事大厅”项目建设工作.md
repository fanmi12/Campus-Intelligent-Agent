# 陈葆华副校长到图书信息中心调研“网上办事大厅”项目建设工作

8月25日上午，陈葆华副校长到图书信息中心调研“网上办事大厅”项目工作建设情况。

图书信息中心主任陈显龙详细介绍了我校“网上办事大厅”建设思路和路径、前期的调研及准备工作，分析了我校各种线上流程的应用场景，梳理了线上服务事项的分类。

会上邀请了东软集团的周晓光经理介绍了其公司的“网上办事大厅”解决方案，分享了其它同类院校的成功案例。陈显龙主任与东软团队就“网上办事大厅”的平台建设进行了深度讨论。

接下来，图书信息中心将按照学校“一切以学生为中心”的发展理念，认真落实学校的统一部署，实践“IT为管理赋能”，推进“网上办事大厅”项目建设，让业务信息系统建设和应用实现数据共享和一体化服务，由传统分散式服务向集中式服务转变，实现“最多跑一次”、“一网通办”、“一网统管”、“一网协同”、“接诉即办”的目标。“让数据多跑路，让师生少跑腿”，提升办事效率，节约师生时间成本。
