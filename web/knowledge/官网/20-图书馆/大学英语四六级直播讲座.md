# 大学英语四六级直播讲座

【MET外国语言学习馆】邀请专业讲师开展讲座，规划复习进度，圈出考试重点。2022年11月18日，“阅途集团”视频号，19：30-20：30准时开播。

讲座内容：

1.四六级考情分析

2.听力技巧

3.阅读指南

4.写作秘籍

5.考前冲刺计划

参与方式：

1.扫码进入视频号

2.点击“预约”按钮

在预约界面中点击“预约”按钮，开播时将收到来自系统的直播提醒。
