# 机关五党支部圆满完成换届选举工作

为进一步加强基层党组织建设，夯实党建根基，优化支部班子结构，提升党组织凝聚力、向心力与战斗力，依据《中国共产党章程》《中国共产党基层组织选举工作条例》及上级党组织部署，2026年9月11日上午，中共东莞城市学院机关五党支部换届选举党员大会于图书馆四楼会议室召开。会议由上届支部负责人主持，支部全体党员参会，机关党总支书记陈东汉列席指导。

本次换届前期筹备严谨规范。会前支部逐项落实筹备事宜，仔细清点参会党员，实到有选举权党员超应到人数五分之四，达到法定开会标准。针对特殊党员情况，支部已完成上级报批与大会审议，全流程合规，保障选举有序推进。

大会庄重有序开展。陈东汉同志首先宣读支部调整与人事相关文件，明晰组织调整工作要求。袁秀美同志代表上届支委会作工作报告，全面总结思想、组织、作风、廉政建设及党建业务融合成果，客观查摆现存短板，结合支部实际规划后续党建重点任务，报告详实客观，经全体党员举手表决一致通过。随后主持人宣读上级换届选举批复，确认本次选举合法规范。

选举全过程坚持民主、公开、公正、公平原则。大会审议并表决通过选举办法草案，介绍新一届支委候选人情况及产生流程，表决确定候选人名单，同步审议通过监票人、计票人，明晰工作人员岗位职责。无记名差额投票阶段，全体党员严守选举纪律，审慎行使民主权利完成投票；工作人员现场清点、核对、统计选票，流程透明严谨，结果真实有效。

计票完成后，陈东汉同志作总结讲话。他充分肯定上届支委会工作成效，表扬全体党员在党建、校园建设、师生服务中的先锋作用，并对新一届班子提出要求：持续强化理论学习，聚焦党建主责主业，以党建引领业务深度融合，严守纪律作风，凝聚党员合力，推动支部党建提质创新。

会上宣读新一届支委当选名单，大会各项议程全部完成。会后新一届支委第一时间召开分工会议，划定岗位职责、梳理阶段重点工作，夯实组织运行基础。

此次换届进一步筑牢基层战斗堡垒，优化班子队伍，凝聚党员向心力。下一步，机关五党支部新一届支委将履职担当、接续奋进，带领全体党员立足岗位实干争先，持续强化党建引领效能，促进党建工作与学校事业同频发展，为学校高质量发展注入基层党建动能。
