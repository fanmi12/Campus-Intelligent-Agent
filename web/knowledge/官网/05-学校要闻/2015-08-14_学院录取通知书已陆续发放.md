# 学院录取通知书已陆续发放

省内通知书已发放，学院招生办委托城院贴吧微信开放通知书查询业务。

据招生办主任孔增强介绍，广东省内新生录取通知书已全部完成投递，外省新生的录取通知书也将在8月20日左右完成投递。

现城院贴吧微信公众平台已开放新生录取通知书查询系统，不仅可查询到收件地址、收件电话、快递单号，还可查询到实时物流记录，帮助新生了解录取通知书的动态。

【查询方式】

关注【城院贴吧】微信公众平台(微信号:dgcytb)后

发送：通知书+准考证号

例：通知书0981202233【城院贴吧】微信公众平台二维码
