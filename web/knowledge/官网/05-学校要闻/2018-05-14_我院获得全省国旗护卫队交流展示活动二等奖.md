# 我院获得全省国旗护卫队交流展示活动二等奖

5月13日，由广东省教育厅、省国防教育办公室、省军区战备建设局、共青团广东省委员会主办的第二届广东省国旗护卫队交流展示活动在广东医科大学东莞校区举行。来自全省61所高校、近2000名师生参加了交流展示活动，近百所学校和机关企事业单位现场观摩。

我院国旗护卫队首次参加该项活动，在历时一个半月的集训中，队员们克服困难，坚持按时参加训练，凭着过硬技能和良好的精神风貌斩获了二等奖。
