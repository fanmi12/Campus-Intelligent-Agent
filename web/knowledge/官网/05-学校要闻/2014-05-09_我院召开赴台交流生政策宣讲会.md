# 我院召开赴台交流生政策宣讲会

5月8日，由国际交流中心、教务处和学生处联合召开的赴台交流生政策宣讲会在行政楼112会议室举行。

教务处牛熠处长解读了学校关于赴台交流生学籍管理、学分认定等政策规定。学生处杜鹏举副处长介绍了赴台交流生应注意的事项。国际交流中心夏泉源老师对赴台交流的专业、选课、办证等流程作了详细的介绍。他强调赴台交流学习要选择与所学专业相一致或者相近的专业。接着他又分别对义守大学、嘉南药理大学、台中科技大学、淡江大学和台南应用科技大学的专业优势、学习环境做了对比分析，让有意赴台学习的同学对这五所大学有更加全面的了解。

据悉，到目前为止，已有30多名学生报名赴台交流学习。
