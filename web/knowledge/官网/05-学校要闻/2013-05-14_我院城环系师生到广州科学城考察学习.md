# 我院城环系师生到广州科学城考察学习

5月11日，城市与环境科学系2010级资源环境与城乡规划管理专业1班（规划方向）的学生到广州萝岗区的广州市科城规划勘测技术有限公司学习广州科学城的选址、规划与建设经验。

该公司规划一所的孙钦毅所长为同学们详细讲述了科学城的规划与实践，并带我校师生实地参观了科学城中心区。

本次实践教学让学生们对高新技术产业园区的选址、规划与建设特点有一个初步的理解，巩固了课堂所学的理论基础知识。
