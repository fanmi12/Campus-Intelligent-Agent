# 同心协力，再创城市学院新辉煌

会场周书记：同心协力，再创城市学院新辉煌

安院长：领导干部要做好“解放思想、服务东莞、模范带头”三篇文章3月1日，我院在4315会议室召开了部门党政主要负责人工作会议，安排部署今年的工作。

东莞理工学院党委书记周致纳，东莞理工学院副校长、城市学院院长安少华出席会议并做重要讲话。

《工作要点》指导思想明确 工作重点突出

会上，城市学院党委书记朱志德通报了学院2012年工作要点（征求意见稿）。他希望全院教职员工要进一步解放思想，继续深入推进内涵式发展，从7个方面入手，全面提高教学质量，构建和谐校园，打造幸福城院，为东莞实现“高水平崛起”作出贡献。

会议还听取了大家对《工作要点》（征求意见稿）的修改意见。朱书记表示，学院将根据今天与会人员的发言，对《工作要点》做进一步补充完善，报董事会审定后再发文执行。

领导干部要做好“解放思想、服务东莞、模范带头”三篇大文章

院长安少华在讲到今年工作意见时强调，各级领导干部要进一步解放思想，服务东莞“高水平崛起”，发挥模范带头作用。他说，东莞理工学院、城市学院当年的成功创办，是邓小平南巡讲话、思想解放的产物与结晶。在当前民办高校异军突起的大趋势下，谋划学院更大的发展仍然需要解放思想，坚持改革，充满信心，积极应对。学院不仅要服务东莞，更要引领东莞经济社会的发展趋势，为转型升级、高水平崛起提供智力保障。领导干部要事事处处做教职工的表率，身体力行，干好本职工作，努力维护学院的稳定、声誉和发展大局。

周致纳书记在分析城市学院八年办学成绩、迎评促建双获学士学位授予权、新校区工程建设及顺利开学原因时指出，这些成绩的取得是全体教职员工、管理人员共同努力的结果。值得一提的是，东莞理工学院派来的30多位教师做了大量的开创性的工作。

周书记表示，城市学院今年的工作安排，方向明确，切实可行，愿景美好。关于今年的工作，他强调了两点：一是全院教职员工要进一步提高对贯彻执行教育部26号令的认识，二是同心协力顾大局、谋发展、创辉煌。他说，“两校三区”虽然体制不同，但目标是一致的，都是一家人。希望全体教职员工特别是各级领导干部，要积极开展以“三爱一奉献”为内容的创先争优活动，正确对待整体利益和长远利益，主观与客观相适应，忠诚党的教育事业，克服新老校区过渡时期的困难与不适。希望新校区进一步完善办学设施，为平稳过渡创造条件。
