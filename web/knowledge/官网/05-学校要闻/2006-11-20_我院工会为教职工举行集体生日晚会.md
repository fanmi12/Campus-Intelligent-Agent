# 我院工会为教职工举行集体生日晚会

11月16日晚，城市学院学生活动中心一片欢声笑语。我院工会组织策划的第一场教职工集体生日晚会在这里拉开帷幕。来自16个系部，在11月份生日的35名教职工欢聚一堂，共庆生日。院长安少华教授、党委书记朱志德、副院长林世俊教授、党委副书记朱冰等出席了晚会。

晚会由杜鹏举、姜晓琳主持，会场洋溢着喜庆活跃的气氛。晚会播放了饱含全校师生对教职工生日祝福的DV短片，学院领导表演了各自的拿手节目。所有寿星合唱生日歌，分切生日蛋糕。

11月15日，工会已将鲜花和贺卡送到所有过生日的老师手中，表达了学院对他们的祝贺。工会今后每月都将为当月生日的教职工举行一次集体生日聚会。
