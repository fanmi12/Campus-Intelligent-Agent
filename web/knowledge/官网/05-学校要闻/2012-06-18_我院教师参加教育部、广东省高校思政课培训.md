# 我院教师参加教育部、广东省高校思政课培训

6月15日至17日，由省教育厅主办、省高校“思想道德修养与法律基础”教学研究基地承办的教育部高校《基础》课教学研讨会暨广东省高校《基础》课教师培训会在深圳大学举行。我院思想政治理论课教学部主任何鹏举教授及《基础》课任课教师代表参加了培训会。

与会人员听取了国家教育部社会科学司副司长徐维凡教授，教育部《基础》课教学指导委员会副主任委员、北京第二外国语学院党委书记冯培教授，教育部《基础》课教学指导委员会副主任委员、上海理工大学宣传部部长陈大文教授，教育部《基础》课教学指导委员会秘书长、中央财经大学马克思主义学院副院长冯秀军教授的辅导报告。会议指出了高校思想政治理论课建设取得的成绩、存在问题、发展思路及举措，并围绕新媒体环境下高校《基础》课建设的变革与创新，大学生法制教育与道德教育存在问题，《基础》课主题教学群模式的思考与探索等问题进行研讨。

何鹏举教授以广东省高校思想政治理论课教学指导委员会委员的身份主持了6月17日的会议。
