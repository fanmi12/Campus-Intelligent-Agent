# 勤学笃研 我校学子荣登EL期刊

2026国际智能大会（ICI 2026）于2026年5月8日至10日在广东珠海中山大学珠海校区举行。作为智能科学领域具有重要影响力的国际学术会议之一，本届大会聚焦通用人工智能、认知智能、大模型与智能代理、具身智能与机器人等前沿议题，汇聚了来自全球高校、科研机构及产业界的众多专家学者，围绕智能科学理论突破与关键技术展开系统性交流。

表彰先进

在此次会议中，人工智能学院2023级软件工程专业陈琳博、2023级计算机科学与技术专业黄润彬两位学生，在叶梓菁老师、吴帅老师的指导下，以第一作者身份发表了2篇EI会议论文。

两篇论文依托2025年省级大学生创新创业训练计划项目（智能无人机路径规划系统研发—基于改进粒子群优化算法的技术创新），围绕智能无人机路径规划与群体智能优化算法改进方向展开研究。该大创项目由陈琳博、黄润彬、黄子博三位同学联合组队，叶梓菁、吴帅担任指导教师。

会议期间，两位同学以学术海报形式展示研究成果，系统介绍了项目在复杂环境建模、算法改进、仿真验证等方面的研究思路与阶段性成果，与参会专家进行了深入交流，展现了扎实的专业功底与良好的科研风貌。

本次大会还设置了前沿技术展示环节，广东图灵智新技术有限公司现场展示了具身智能实验室解决方案，吸引了众多参会师生驻足交流。现场，各位专家为参会师生详细讲解方案的技术架构与应用场景，我院学子主动参与互动研讨，近距离了解具身智能、机器人开发、多模态交互等领域产业前沿动态与落地实践成果。

活动总结

此次两篇EI会议论文的发表，是人工智能学院坚持以项目驱动科研训练、促进学生创新能力提升的阶段性成果。未来，人工智能学院将持续聚焦具身智能、无人系统、大模型等前沿领域，持续搭建学术交流、科研实践、校企协同平台，鼓励学子深耕专业、勇于探索，全力培育高素质、复合型、应用型创新人才。
