# 管理系组织团干学习“两会”精神

3月22日，管理系团总支组织11级、12级各班团支部书记、团总支干事学习“两会”精神。

座谈会上，老师和同学观看了关于“两会”的报道，师生们一起回顾了“两会”的基本内容和热点问题，并就热点话题展开讨论。其中，食品安全问题、作弊造假行为、制度问题、团队精神、税收以及道德底线成为同学们讨论的重点内容。同学们纷纷发表自己的意见和看法，讨论的氛围既热闹又活泼。讨论中，陈彬老师还提醒同学们要把“中国梦”和“自己的梦”联系起来，要看到社会的进步，根本动力在于个体的进步，坚持向善，踏实前进。

会议最后，辅导员陈文丽老师做了总结。她希望当代大学生要“胸怀祖国，心系天下”，一定要认真学习“两会”精神，领悟两会精神实质，从关心身边的小事做起，做城院的主人，做国家的主人。
