# 市公安局国保支队领导来我院指导工作

3月12日下午，东莞市公安局国保支队副支队长简建中、国保二大队大队长姚冠华，寮步公安分局国保大队大队长梁伟强、教导员刘浩堂等一行来我院指导安全保卫工作，并与院长书记王卫平、副书记章德胜、副院长刘玉侠及学院相关部门领导举行座谈。

王卫平院长对公安部门领导前来指导工作表示感谢，介绍了学院近期在安保、维稳等方面工作的有关情况。王院长指出，学院的安全、有序发展离不开公安部门的关心和大力支持，希望通过双方共同的努力，强化学院的安全服务保障工作，为广大师生创造一个和谐有序的学习环境。

简建中副支队长和姚冠华大队长对我院安全管理工作予以了充分的肯定，并进行了经验交流。
