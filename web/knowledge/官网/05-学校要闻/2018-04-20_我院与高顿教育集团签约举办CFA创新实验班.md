# 我院与高顿教育集团签约举办CFA创新实验班

4月19日下午，我院与高顿教育集团举行签约仪式，成功引入美国特许金融分析师（chartered financial Analys，简称CFA）项目，双方将在金贸系合作开设CFA创新实验班。

高顿教育高校事业部全国销售总监舒畅、南区总经理林华壤、南区销售经理李宗伟，我院副院长周庆、教务处处长赵书山、财务处处长余竹根、金贸系主任米双红出席了签约仪式。

赵书山处长在致辞中指出，双方在学科建设和专业改革中开展深度合作，建立稳健的关系，有利于双方发展。

舒畅总监介绍了高顿教育集团的相关情况，指出校企搭建互帮互助平台有利于双方共同发展，希望未来能不断提升合作空间。

舒畅总监代表高顿教育集团与我院进行了正式签约。

金贸系党总支副书记万文双主持了会议。
