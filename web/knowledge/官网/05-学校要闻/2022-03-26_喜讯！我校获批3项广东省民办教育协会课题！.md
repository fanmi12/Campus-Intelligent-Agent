# 喜讯！我校获批3项广东省民办教育协会课题！

近日，广东省民办教育协会公布了2022年民办高校教育研究课题立项结果，我校史雍真《民办高校党建与“立德树人”深度融合机制研究》，姜海波《广东民办本科院校应用型人才质量保障体系构建》，叶云峰《独立学院转设后品牌建设策略研究——以东莞城市学院为例》获批立项。

学校转设以来，加大科研改革，继续鼓励和支持学校广大教师申报各层次课题研究工作，不断扩展申报课题的领域，有计划培育科研团队，提高立项课题的数量和和提升课立项课题质量，促进产、学、研协同发展，增加投入改善科研条件，营造良好创新氛围，为教职工开展研究工作清除障碍，争取再创佳绩，使我校科研水平再创新高。
