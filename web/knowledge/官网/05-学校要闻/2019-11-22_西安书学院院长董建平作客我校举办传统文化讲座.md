# 西安书学院院长董建平作客我校举办传统文化讲座

11月20日下午，西安书学院院长、中国书法家协会会员董建平作客我校，举办了“中国传统文化发展历程”的精彩讲座。文传学院院长宋秋敏和文传学子聆听了讲座。

中华民族文化在5000年历史长河缓缓淌过，留下了无数携有历史痕迹的文化遗物，见证了华夏文明的璀璨与辉煌。讲座上，董建平院长运用生动活泼的语言，从甲骨文、陶器、玉器、青铜器、瓷器等介绍了中国历史发展时代印记的文化遗产和历朝历代不同的文化。

“大浪淘沙沉者为金”，中华历史文化源远流长、博大精深。董建平院长的讲座犹如一场奇妙的传统文化之旅，引领大学生近距离感受中华传统文化的魅力，增强了大家的文化自信和民族自豪感。
