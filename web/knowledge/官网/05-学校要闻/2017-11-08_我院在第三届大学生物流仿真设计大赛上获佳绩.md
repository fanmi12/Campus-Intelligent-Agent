# 我院在第三届大学生物流仿真设计大赛上获佳绩

11月4日，“百蝶杯”第三届全国大学生物流仿真设计大赛（广东赛区）在广州大学华软学院举行。由我院管理系2014级物流管理专业组成的物流壮志凌云队、物流Lively CDT队参赛分获一等奖和二等奖。两支队伍的指导老师洪树权、张洪、杨娜、赵影老师获得优秀指导老师称号，物流Lively CDT队还获得最佳组织奖。

参赛队伍名单：物流壮志凌云队：刘永昌、陈柏余、徐恩钒。

指导老师：杨娜、赵影;

物流Lively CDT队：翟兆辉、邓玉婷、唐秋敏。

指导老师：洪树权、张洪。
