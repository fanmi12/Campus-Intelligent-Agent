# 政法系学生参加珠三角高校社会工作学生团体发展论坛

3月24日至25日，政法系09级社会工作专业的张志坚和古润宝同学应邀参加由珠海社会工作协会主办、北京师范大学珠海分校社会工作协会协办的“珠三角高校社会工作知识大赛”及“珠三角高校社会工作学生团体发展论坛”。

会上，我院学生和澳门理工大学、华南农业大学、广东外语外贸大学等八所高校进行了沟通和交流。
