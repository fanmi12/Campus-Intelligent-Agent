# 09级计科班向全院同学倡议建设“三风”

学院校风建设动员大会后，计信系各班相继召开校风、班风建设主题班会。10月30日，09级计算机科学与技术班全体师生，在2310课室举行了关于“班风、学风建设月活动”主题班会。

同学们通过认真的讨论，决定向全院同学倡议，建设“三风”从自我做起。为此，他们倡议：不在课室吃早餐；不在课堂打磕睡；考试不作弊；不穿拖鞋或不雅服饰上课；不在校园做过于亲昵的动作；早起早睡，坚持早读和晚自修；讲文明，爱护校园、课室和宿舍卫生，不乱丢乱吐果皮、杂物；学生干部要起带头作用，管理好自己的班集体；同学之间要互相监督，互相约束，为营造良好的班风、学风、校风献计出力。
