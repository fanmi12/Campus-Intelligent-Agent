# “城市学院，我们来了”

四川通江籍的五位同学受到学院领导的热情接待9月15日，装点一新的城市学院校园迎来了2007级的新同学。每年的这个时候，学校里总会异常的热闹，今年也不例外，新同学们像往届师兄师姐一样，拖着沉重的行李箱，满载着对新生活的希冀，步入了心仪的高等学府。

“城市学院，我们来了。”今天，07级新同学真正步入了属于他们的象牙塔。

“一站式”的报到大厅

学院各部门进行了周密的筹划和部署，以确保迎新工作的顺利进行，让学生高兴而来，让家长满意而归。

为保证新生方便快捷的办理报到手续，学院在四号楼大厅设立了总报到处、收费确认处、户口办理处、金龙卡办理处以及各系部的报到点。学院在东莞火车站、东莞汽车东站、东莞汽车总站设立了新生接待站，以确保外地新生顺利到校。

学院提供的 “一站式”服务方式，大大缩短了报到时间，使同学们无须奔波即可顺利办好手续，受到了学生和家长的赞扬。

“人性化”的服务

步入校园，到处可见的交通指示牌指引着上千台接送新生的车辆在校园中有序行驶，报到当日没有出现任何拥堵现象。当新生踏进报到大厅，就可以领取到《新生导航》服务手册，手册刊载着校区平面图、报到流程图、大学生活指南等丰富内容。此外，在大厅中，学院还专门设立了座椅供家长休息，医疗救护、广播咨询、茶水供应等服务项目也应有尽有。

在摩肩接踵的人群中，到处可以看到身着工作服的“大学生志愿者”忙碌的身影。他们或帮助提行李，或帮助填写各种表格，或倒茶送水。志愿者们还向新生派发了《城市学院报·迎新专刊》，专刊上有院长亲切的寄语、教授殷切的希望，还有学院名师、校园文化等内容，以帮助新生尽快熟悉校园，融入大学生活。

“数字化”统计报到率

本次报到工作，全部采用网络系统统计报到人数，各报到终端均可以通过计算机登记新生报到情况，工作人员只要登陆系统就可马上查询到相关的动态数据。

今年首次采用的这种“数字化”统计方式，不仅加快了报到速度，而且可以快速宏观掌握新生的报到情况，即时了解各专业的报到率。

“免费”入学的新生

今年，城市学院继续在革命老区四川通江招收5名贫困学生，全免他们的学费、住宿费。这些同学成为校园中第二批“０学费”入学的大学新生。

学院党委书记朱志德、副院长张林副教授亲切接见了来自通江的5名同学。院领导们勉励他们，要努力学习，不辜负家乡人民的殷切希望，将来回报社会。

目前，我院已有10名来自革命老区的学生。

每年４５万元的“助学金”

城市学院新生报到队伍中，有42名印刷专业的同学备受关注。从本学期开始，印刷专业一些家庭经济困难的同学将会得到世界500强企业德国海德堡公司和华厦集团提供的贫困生助学金。

今年4月，城市学院、华厦国际投资集团有限公司、海德堡印刷设备（深圳）有限公司正式签订了合作开办城市学院印刷专业（本科）、印刷技术专业（专科）协议。协议规定，校企三方共同成立奖学金管理委员会，设立专项经费，用以资助贫困生的学费和住宿费。

据悉，2007级新生将于9月17日参加为期两周的军训，开始他们大学生活的第一课。
