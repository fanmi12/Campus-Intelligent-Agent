# 庆新年、闹元宵、高高兴兴迎接新学期

正月十五是我国传统的元宵佳节，也是我院正式上课的前一天。为了庆祝这个节日，学院把校园布置得焕然一新。红红的灯笼，鲜艳的彩旗和条幅，火树银花，交互辉映，使校园呈现出浓浓的节日氛围。晚上，学院活动中心灯火通明、人头攒动，灯谜条幅挂满了厅堂。各种游艺活动幽默诙谐、妙趣横生，吸引了许多师生前来参加。

学院党委书记朱志徳同志、副书记朱冰同志昨晚来到了活动中心，与师生共度元宵佳节。
