# 图书科技信息中心大楼工程进展顺利

图书科技信息中心效果图

图书科技信息中心作为学院一个重要的硬件建设项目，备受社会各界和全院师生的高度重视，不断有人通过各种渠道询问该工程的相关情况，记者带着大家的问题走访了图书信息中心主任陈伟研究馆员和学院基建办主任叶树标。

从基建办获悉，图书科技信息中心工程概预算8372万元，规划建筑占地面积为3500平方米，建筑面积为29928平方米。拟建地下一层，地上13层，主要包括两部分：1—7层为教学用房（其中1层为小型剧场和会务用房，2层为架空层，3－6层为教学区，设有若干电教室和多媒体室）；7－13层为图书馆。目前，图书科技信息中心工程的第一阶段“地基处理”接近尾声。

基建办叶树标主任告诉记者，这项工程于今年7月动工，现已基本完成了最困难的“地下层”施工任务。虽然夏季的连续暴雨给施工带来一定的影响，但学院会同施工方，想方设法加快框架结构和室内装修的工程进度，力求2009年年底前保质保量交付使用。

图书馆到底是什么样子？与旧馆相比有什么不同？陈伟主任的回答为读者们揭开了她神秘的面纱。

大容积：新馆占七层 藏书逾百万

新图书馆的建筑面积约为24000平方米，在工程中占7层，建成后，藏书将达100万册以上。

陈主任说，新图书馆是我院硬件建设划时代的工程，是学院“上水平”的标志。一座完整独立的图书馆，一个学生自由阅读、学习的空间，这是一所高校成熟的象征。城市学院快将成为一所万人大学，新馆的藏书量可以使得生均拥有100册以上的图书，在高校评估中可以达到优秀。

大开放：“超市型”借阅 “一站式”管理

接受采访时，陈伟主任反复强调新馆的“大开放”管理模式。他说，现在学院由于校舍限制，各门类的图书分放在不同的借阅室，如果借不同种类的图书，往往要重复办理几次借阅手续，非常繁琐。新馆建成后，这个问题将不复不存在，7层图书借阅将全面敞开，采用类似于超市的管理方法，借还统一在一个地方进行，读者只要“一站”就能搞定全部手续。这种科学的现代图书管理方法已应用于世界各大图书馆，对于提高图书流动率和方便读者借还大有裨益。

在问到读者会不会在“超市”中迷了路时，他解释说，馆内张贴书库示意图，分布多台查询机，工作人员在每层值班，相信同学们会很快在这个知识的海洋中愉快畅游。

新布局： 藏、阅、咨一体 书刊放一起

一般图书馆订阅的杂志和报纸统一放置在阅览室，与普通图书分离，但新馆将按照其检索分类放置在该类书附近，并有工作人员可提供咨询。

由于新馆有7层，师生做研究查询资料时，既需要查阅书籍，又需要查阅期刊，为了不让读者辛苦的楼上楼下跑，就设计了这种新的布局。新馆的馆藏资料绝大部分都开放，最大化的为读者提供资料。

陈主任说，如果服务做得好，能让读者在不知不觉中得到享受，这种藏书、阅览、咨询一体的书刊统一布局就是优质服务的体现。

功能多：设备现代化 设施人性化

一所现代图书馆，借还书仅仅只是基础功能，她的延伸功能更加令人惊叹。

陈主任介绍说，新馆一开放，自助借还书设备就将投入使用，既节省人力，又方便了读者，这比东莞市图书馆的设备还先进一些。另外，电子阅览室和文献检索的教学课室机位增加至280个以保证读者查阅资料；新开放音乐欣赏室，可以播放音乐、电影和教学片；增设的个人研究室和讨论室配备了桌椅、电脑等用品，进行学术探究和研讨的读者可以预约使用；教学参考书资料室和社情资料室也将向读者开放。以后图书馆的开放时间将延长为每天8：30—22：30，双休日也将开放。

服务广：主馆加分馆 服务入社区

目前，学院已经为樟村居民办理了图书证，方便他们借阅，并帮助他们在社区建立图书馆。陈主任说，此举措是一块“试验田”，从中，我们看到，居民对于图书馆是有需求的，作为“城市”中的城市学院应该依托东莞市进行发展。我们的设想是，通过设立分馆的形式为社区提供信息服务，同时这项服务还将不断延伸到城市中更广的地方。

以后，图书科技信息中心的图书馆作为中心馆，各系部和社区将成立分馆，以扩大服务面和增加服务对象，同时还将不断挖掘读者的需求，为他们提供更优质的图书信息服务。

最后，记者请陈伟主任概括一下他心目中的图书馆。他沉思了一会儿，说，我从事图书馆工作20余年，深切感觉到，图书馆应该是一个让人留恋、让人放松，同时又有所收获的地方。正如一位阿根廷图书馆长所说的，“图书馆应该是天堂的样子”，我们正朝着这个看似无法企及的目标不断努力。
