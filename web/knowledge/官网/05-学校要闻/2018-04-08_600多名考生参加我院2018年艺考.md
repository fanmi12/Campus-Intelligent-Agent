# 600多名考生参加我院2018年艺考

3月31日，我院举行2018年艺术类专业考试。600多名来自省内外的考生参加了考试，人数比2017年增加近一倍。今年艺考另一大亮点是，由我院财务处倾力打造的“智慧城院”移动支付为考生了提供更为便捷的收费服务。

当天上午8时，前来参加考试的俊男靓女以及陪同的家长们陆续地在综合馆排起了长龙，一派热闹的景象。艺考生们靓丽青春的身影成为城院一道亮丽的风景线。

院长王卫平、财务处处长余竹根、招生就业处处长孔增强等领导来到现场，视察指导考试工作。

据孔增强处长介绍，今年艺术类招生专业为表演专业和舞蹈编导专业，报名人数达600多人，计划录取80多人，竞争较为激烈。今年艺考全面贯彻高标准、严要求、“数量上去了，质量不能下来”的录取原则，考官做到公平公正。

值得一提的是，继本学期伊始我院启用食堂移动支付以来，此次艺考考生报名费也采取了移动支付的方式，为考生提供了便捷的服务。余竹根处长介绍说，“智慧城院”移动支付推出后，600多名艺术类考生通过移动支付缴纳报名费，非常便捷、高效。今后，财务处还将逐步为校内外考生英语四六级考试、普通话考试、计算机资格考试、教师资格证考试及培训等的缴费提供移动支付，进一步增强“智慧城院”的服务功能。
