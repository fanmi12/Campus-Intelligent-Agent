# 2016-2017学年度优秀辅导员评选完成复评

5月22日下午，2016-2017学年度优秀辅导员评选复评活动在行政楼112会议室举行。我院院长王卫平、副书记章德胜、副院长刘玉侠，院长助理、创设院院长林江龙和艺术系主任向智星、金贸系主任米双红、管理系主任张佺举、城环系主任肖红飞、财经系主任罗卫国、计信系主任廉玉忠、文传系主任宋秋敏、外语系主任王锦锋、体育教学部主任邢红林，以及各院系党总支书记、副书记和辅导员老师们出席了本次活动。

复评活动由院办公室主任杜鹏举、招生就业处处长孔增强、人事处副处长李海东、学生处副处长陈建新、党务工作部教授熊劲松、学生处思政科科长陈晓萍担任评委，由学生处副处长罗文芳主持。

今年，我院对优秀辅导员评选活动进行了改革创新，首次与年度考核分开，单独进行评选。初评后，共有13位辅导员晋级校内复评。当天下午，13位辅导员老师依次上台进行工作汇报，通过PPT与大家分享了一年来的工作特色、方法、所取得的成绩以及对未来工作的展望。朴素无华的言语中，让我们看到了辅导员们勤勤恳恳、兢兢业业的工作态度，也看到了他们对学生谆谆善诱、无微不至的奉献精神。

章德胜副书记对此次活动进行点评，表示此次活动给辅导员们提供了一个很好的交流平台，同时给辅导员们的工作给予了充分的肯定。

王卫平院长在总结讲话中肯定了活动的意义，表示今后学院将进一步加大辅导员队伍建设力度，帮助辅导员队伍更好更快地发展。

现场评选结束后，学生处将结合参评辅导员上交材料统计综合评审得分，确定综合评审得分最高的前五名为优秀辅导员人选，并进行为期一周的公示，公示之后，报院长书记办公会审核通过，将授予其年度优秀辅导员称号，并于9月份进行表彰。
