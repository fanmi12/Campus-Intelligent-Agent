# 学院领导视察樟村生活园区建设

9月5日，院长安少华教授、朱志德书记、副院长张林副教授等院领导，亲临樟村教职员工住宿区建设工地视察工作。在认真听取了工程负责人的情况汇报后，安院长指出，樟村生活园区是学院为解决教职工、特别是青年教职工住房难问题而采取的有效措施。学院将投入人力财力物力，保证把樟村教职工生活区建设好。今后还将继续投入，力争将樟村生活区建设成为环境优美、设施完善、具有浓厚人文气息与优雅生活品味的特色亮点生活小区。工程负责人表示，保证第一期工程如期按质按量交付使用，决不影响9月8日的搬迁工作，并将加快工程进度，将樟村生活园区建设好。
