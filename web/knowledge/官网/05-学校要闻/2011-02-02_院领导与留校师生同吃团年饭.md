# 院领导与留校师生同吃团年饭

安少华院长向留校实习学生了解生活情况

师生同举杯 喜迎春来到

院领导向留校教工们敬酒

春节团年是中国人的传统习俗，而学校每年总有一部分师生、教工不能回家过年。每逢佳节倍思亲，随着2011年新春佳节的临近，农历大年三十，学校为这些留校师生们精心准备了丰盛的团年饭，把浓浓的年味带到了他们的身边，让大家在学校都能过上温馨祥和的春节。

中午12时，宴会准时开始，院长安少华、党委书记朱志德、副院长张林、院督学陈丁堂等院领导与春节留守学校的教工、同学同吃了这顿团年饭。席间，安院长与在坐的同学们进行了亲切的交谈，详细询问他们的生活、学习和社会实践情况，院团委书记杜鹏举代表学院为每个留校师生派发了过年红包；院领导们还一同来到师生当中，举起手中的酒杯向师生们送上节日的祝福，祝愿大家过一个欢乐祥和的春节，迎接充满希望和挑战的又一个新年，祝愿我们共同的城市学院大家庭在新的一年里更有新的气象。

晚上，学院为留校师生开放了卡拉OK厅，让大家都能在欢歌笑语之中，喜迎兔年新春的到来。
