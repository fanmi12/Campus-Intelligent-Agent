# 东莞职业技术学院副院长李奎山率队来我院考察交流

2月20日，东莞职业技术学院副院长李奎山率领该院保卫处、图书馆、后勤处、学生处、教育技术中心等部门负责人莅临我院参观访问。党委副书记、新校区管委会副主任朱冰等领导给予了热情接待。

李奎山副院长一行先后深入到我院新校区学生宿舍、图书馆和安保监控中心，重点考察了“一卡通”门禁系统、图书馆现代化管理建设和安保系统等建设情况。宾主双方还举行了座谈会，就校园安保、学生管理等工作进行了深入探讨交流。
