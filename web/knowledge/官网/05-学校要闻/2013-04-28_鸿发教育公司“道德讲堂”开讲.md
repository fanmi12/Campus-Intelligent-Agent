# 鸿发教育公司“道德讲堂”开讲

4月27日，为了传承中华民族优良文化传统，弘扬鸿发集团的企业文化，鸿发集团“道德讲堂系列活动”之教育专场在行政楼112室开讲。院党委副书记朱冰，院长助理麦绮琳，鸿发集团人力资源部副总监、集团工会主席吴季伟出席会议，鸿发教育公司、鸿育后勤公司及艾立森幼儿园等150多位员工参加了会议。

据悉，本次“道德讲堂”主要是由获得鸿发教育公司“道德模范人物”的8位基层员工进行道德宣讲，他们有来自饮食服务中心的拉面师傅、有来自学院“第一道防线”的校卫、也有来自公寓服务中心的宿舍管理员。
