# 【服务东莞·创新发展】政法系在“主题学习讨论活动”中热议专业建设

7月5日，政法系召开了“服务东莞、创新发展”主题学习讨论活动会议。会议由政法系主任刘杰教授主持，政法系全体教职工出席了会议。

与会人员认真学习了关于开展“服务东莞、创新发展”主题学习讨论活动的通知（东理城党〔2012〕6号）文件，尤其认真研读了成洪波书记在“服务东莞、创新发展”学习讨论活动动员大会上的讲话，座谈讨论了“服务东莞、创新发展”的现实意义与内容，并按照学院要求进行了工作安排。

刘杰主任在会议中强调，政法系贯彻落实“服务东莞，创新发展”主题学习活动的基本思路是：立足于专业人才培养，开拓创新服务地方。“法学、社会工作、行政管理”等专业要围绕建设“法治东莞，平安东莞，效率东莞”开展教学工作，要从专业建设培养高素质应用型人才和老师们的自身发展为着力点，更好地服务东莞社会经济的发展，我们的工作大有作为的。
