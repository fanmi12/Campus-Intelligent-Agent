# 我院第一届学生干部培训班进入实训阶段

3月18日，我院第一届学生干部培训班进入实训阶段，培训班前往东莞市明珠亲水公园进行为期一天的野外拓展训练活动，本次野外拓展训练将分为两批进行。

9：00点，队伍到达了位于石碣镇一个小岛上的明珠亲水公园。大家在广场集合完毕，编成铁军一至八队。每个队都有自己最响亮的口号。如“城市学院，我们最强”、“同心协力，共创佳绩”。9：30分，在庄严的升国旗仪式后，一天的“魔鬼式”军训开始了。这次军训的项目都极具挑战性，如五百米障碍跑要求整个队伍通过包括跨栏、爬杆、翻墙、越沙坑、过网、走独木桥等多个障碍，而且是以全队最后一名到达的队员进行计时，这就要求整个团队要有团结协作的精神。而蜘蛛网这个项目则锻练了队员们互帮互助、小心谨慎的能力。它要求队员在其他队员的帮助下，穿过一个个小小的网口，而身体不能有丝毫触及到网线，否则就算失败。不过最惊险的并不是这些，一项水中取物的项目最具挑战。

经过一天的军训，下午16：50分，重头戏——翻毕业墙上场了。望着几米高的木制毕业墙，队员们不禁汗颜，都有点没底了。当第一个队员翻上毕业墙时，队员们都欢呼雀跃起来。有了第一个的经验，接下来大家的行动就更默契了，一个接着一个，下面托，上面拉，不久就有许多人翻过了毕业墙。

18：30分，大家告别了严肃可敬的教官，告别了留下太多美好回忆的训练基地，依依不舍地踏上了回程。通过类似这样的活动，不但培养了学生干部吃苦耐劳、团结协作的能力，更激发了他们的个人潜能，提升了领导力、向心力、执行力，为树立我院学生干部形象、营造和谐的工作环境发挥了很大的作用。
