# 周巍博士应邀担任东莞“社会建设大家谈”论坛主讲嘉宾

9月26日，东莞市社会工作委员会主办的第二期“社会建设大家谈”在市科技馆举行，本次论坛以“加快推进‘三社联动’步伐 积极创新社会管理体制”为主题。我院社会工作教研室主任周巍博士应邀担任此次论坛主讲嘉宾，东莞32个镇街社会工作委员会专职副主任及相关工作人员参加此次论坛。

周巍博士作为主要发言人详细阐述“什么是三社联动，其概念和运作机制如何”，着重强调了社区、社会组织、社工是社会工作的最基础元素，是构建和谐社会的重要基石；详细阐述了在东莞如何建设“以社区为基础、以社会组织为载体、以社工和志愿者为骨干”的三社互动机制。
