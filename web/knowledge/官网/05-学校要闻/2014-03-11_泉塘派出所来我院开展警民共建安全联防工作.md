# 泉塘派出所来我院开展警民共建安全联防工作

3月3日，泉塘派出所麦志斌所长和尹炯贤警官来我院开展警民安全联防工作。我院总务处处长翟耀明、副处长陈辉、保卫办主任刘维仝陪同麦所长一行巡查了校园，并重点检查了监控室。

麦所长对我院的安全防范工作予以肯定，详细了解了我院的警用器材使用状况。他建议，校卫队要加强巡逻，及时发现并排除安全隐患。要教育学生加强自身的安全防范工作，外出要结伴而行，尽量少去人员聚集的地方，不要在网上议论和转发没有根据的涉及敏感话题的言论帖子，切实维护好自身的人身和财产安全，避免上当受骗。宿管人员要做好外来人员进入学生宿舍的证件查验与登记工作。
