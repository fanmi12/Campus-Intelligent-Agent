# 我院开展东莞市机关党务管理系统应用培训

9月19日下午，我院在行政楼407会议室组织开展东莞市机关党务管理系统应用培训。各院系（部）党总支副书记、教工及学生党支部书记，直属支部委员等基层党务工作者参加了培训。党委副书记章德胜出席了会议。

章德胜副书记强调，党务管理信息化建设是党建工作的一项基础性工程。各有关部门要充分利用好东莞市机关党务管理系统，按照市直工委的要求，完成党务工作相关信息资料的录入工作，积极推进系统的日常应用。

党务工作部副部长叶凯贞要求与会部门按时保质保量，确保录入系统的党组织和党员基本信息真实准确，做到不漏项不漏人，在规定时间内完成信息录入及上报工作。她还对新学期党建工作、重点实施计划等作出了安排。

组织科科长范琪对东莞市机关党务信息系统的使用方法进行现场实操和讲解说明，对与会人员提出的问题进行了解答。
