# 我院赴湖北两所高校考察调研

为做好《学院发展战略规划（2011-2020）》编制工作，3月17日至3月21日，党委书记朱志德、副书记章德胜率行政机关、系部主要负责人胡钦华、余竹根、米双红、张佺举等，先后赴湖北荆州长江大学工程技术学院、长江大学文理学院2所全国知名独立学院进行了考察学习。

此次考察不仅考察调研了上述两校的办学思想、办学特色、管理模式、专业建设等学院层面的有关情况，还分别了解了其学院各部门的具体工作，如师资队伍建设、人才培养体系、薪酬体系、党风廉政建设、绩效考核管理及财务管理等。
