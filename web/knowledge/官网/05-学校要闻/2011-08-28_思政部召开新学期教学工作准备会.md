# 思政部召开新学期教学工作准备会

8月28日，思政部在1202教室召开教学准备会议。院督学陈丁堂出席了会议。

会议有三个议程：一是对前阶段迎评工作进行总结，对下一阶段的工作任务进行布置；二是对新学期“一校两区”的教学工作提出基本要求，保证新校区教学工作的正常开展。三是学习胡锦涛七一讲话精神，传达学院中层干部暑期读书班会议精神。

院督学陈丁堂强调“研究无禁区，课堂有纪律”，勉励老师们鼓足干劲，以饱满的精神状态投入新学期的工作。

本次教学准备会，全体教师统一了认识，明确了任务，增强了信心，纷纷表示要提高教学质量，为打造百年名校而努力。
