# 读书节系列活动之数字资源宣传周活动圆满结束

5月26日，为期一周的2011年城市学院4.23读书节系列活动之数字资源宣传活动圆满结束。清华同方、中经网、慧科资讯、EPS数据平台等知名数据库的培训师们，在图书馆电子阅览室为城院师生奉献了一场又一场精彩的数字资源盛宴。

他们针对不同数据库的功能特点、资源特色、使用方法及技巧，为老师和同学们做了精彩的讲解和演示。
