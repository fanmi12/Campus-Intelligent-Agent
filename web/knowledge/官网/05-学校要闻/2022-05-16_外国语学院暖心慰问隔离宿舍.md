# 外国语学院暖心慰问隔离宿舍

面对突如其来的新一轮疫情，为保障广大师生的人身安全与心理健康，外国语学院在严格落实学校关于加强校园疫情防控工作的同时，也对隔离宿舍同学的生活与心理需求给予了高度的重视，积极了解隔离宿舍学生的生活保障状况，送上所需要的生活物资，给予落到实处的真切关心慰问。2022年5月12日下午，外国语学院的志愿者们带着同学们需要的物资暖心慰问隔离宿舍的学生。

在出发之前，学院已经安排志愿者们在企业微信上询问被隔离学生的物资需求，并有针对性的进行了采购，做到了一一落实学生需要。当日上午，志愿者们根据被隔离学生的需要在超市等地采购物资，贴心地为每一位被隔离的学生购买她们所需要的东西。

下午，志愿者们在悦香园食堂进行了物资分配，他们将为每个学生买的物品一一放进环保袋里，并细心地在袋子外面用便签写上了对应的学生姓名和宿舍号，方便学生辨别。雨水打湿了大地，而志愿者仍然冒雨前行，势必将物资送到被隔离的学生手中。疫情隔离了我们之间的距离，却隔离不了外国语学院对同学们的关心和爱。

隔离区的同学们对此次慰问表示热心的感谢，本次慰问为同学们营造了温暖舒适的生活条件和学习环境，同学们深刻感受到了学院的关怀和温暖，并且坚定了共同打好这场疫战的决心。
