# 2011年高校毕业生入伍预征开始网上报名

4月28日，2011年广东省高校毕业生入伍预征工作会议和预征宣传动员启动仪式在广东岭南职业技术学院召开，省军区刘联华司令员，省政府刘昆副省长，省军区王培利参谋长，省教育厅党组副书记、魏中林副厅长，省征兵办公室主任、省军区黄德高参谋长等军地领导出席会议。我院学生处黄竹、凌继峰老师参加了会议。

本次会议主要任务是学习贯彻2011年全国高校毕业生入伍预征工作会议精神，全面部署2011年我省高校毕业生入伍预征工作。

据悉，我院应届毕业生将按照网上报名、初检初审、确定预征对象的程序参加预征。2011年高校应届毕业生网上预征报名系统网址为（http://zbbm.chsi.com.cn），网上报名将从即日起持续到6月15日。6月底前，网上报名通过的学生将参加当地兵役机关会同高校组织的政治初审和身体初检，初检合格的确定为预征对象。12月底前，体检、政审合格的应届毕业生预征对象优先批准入伍。
