# 我校举行2019级新生开学典礼暨军训开训仪式

9月7日上午，我校在运动场隆重举行2019级新生开学典礼暨军训开训仪式。

参加活动的领导和嘉宾有：军训团长、承训海军某部队聂峰中校，东莞理工学院党委副书记、城市学院董事会董事吕琦元，寮步镇副镇长曾明山、寮步镇宣传教育文体局副局长陈国良，广东鸿发投资集团有限公司副总裁、东莞理工学院城市学院董事黎建烨，城市学院董事长代表、广东鸿发教育文化集团有限公司总经理陈超群。全体校领导和有关部门负责人、城市学院学生会主席，以及2019级全体新生参加了开学典礼暨军训开训仪式。典礼由副校长黄兢主持。

大会隆重地举行了庄严的升国旗、奏国歌仪式。学校国旗护卫队以标准、专业的动作将鲜艳的五星红旗在激昂的国歌声中冉冉升起。

章德胜书记宣读了《关于表彰2019年新生奖学金获得者的决定》。梁虹钰、刘施荣等40名同学获得2019年优秀新生校园奖学金，受到大会表彰，免除第一学年学费。

吕琦元、曾明山、黎建烨、陈超群分别为获得新生奖学金的同学进行了颁奖。

王卫平校长在开学典礼上致辞。他告诉同学们，大学不像中学，“大学一年级”不是“高四”，发生了质的飞跃，因为年龄变了、目标变了、知识变了，教师变了、教学模式变了、评价标准变了，上大学会让你的人生气象万千。他教导2019级新生：“今天能踏上大学征途是一种荣耀，明天充满希望与挑战。四年后毕业时你会明白，原来无论昨天今天还是明天，只要心中有梦想有激情，永远是春天”。

王卫平校长要求新生，从现在起，把“树理想、立目标、定行动计划”作为第一要务，做一个对国家、对社会、对家庭有用的人。

在军训开训仪式上，全体军训团教官在热烈的掌声中入场。

后勤保卫处处长王锦锋作了热情洋溢的动员讲话。他强调，作为国防教育的重要组成部分，大学生军事训练已成为我国国防和军队建设培养大批高素质后备人才的有效举措，加强国防教育、增强大学生国防观念已成为当代青年学子的必修课。第一要提高认识，端正态度，积极主动投身军训。第二要吃苦耐劳，经受锻炼，发扬军人的优良传统和作风。第三要严守纪律，争当模范，增强文明修养的自觉性。第四要精心组织、通力协作，确保军训任务的圆满完成。

王卫平校长向军训团团长聂峰海军中校授“东莞理工学院城市学院军训团”团旗，由此拉开了为期半个月的军训大幕。
