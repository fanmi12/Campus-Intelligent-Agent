# 工商银行东莞分行副行长罗亮为毕业生职场支招

大学毕业生如何适应新的环境，打开新的局面，取得好的成绩？6月22日，工商银行东莞分行副行长罗亮应学院的邀请，为毕业生职场支招。

罗副行长从中山大学经济学硕士研究生毕业后，一直从事人力资源管理和人才培训工作，对职场的规则、人力资源架构、员工素质的修炼和潜能的发挥有着较为系统的研究。他认为，毕业生初涉职场须注意以下十个方面的问题：要明确工作目的，参加工作是生存的需要，生活的保障，自身价值的实现；要尽快融入企业文化，遵守单位的规章制度；要刻苦学习业务，掌握技术本领；要增强主人翁意识，有团队协作精神；要认真工作热情高，积极主动有成效；要注意职场礼仪，有职业道德修养；要创造良好的工作环境；要科学管理好自己的时间，讲究工作方法；要分清大事与细节，又好又快地完成本职工作；要主动承担责任，不揽功推过。
