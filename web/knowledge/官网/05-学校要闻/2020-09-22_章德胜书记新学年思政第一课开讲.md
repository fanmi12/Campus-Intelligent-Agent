# 章德胜书记新学年思政第一课开讲

金秋九月，学校党委书记章德胜以“弘扬伟大抗疫精神，做新时代有为青年”为题讲授开学第一课，从“疫情让我们更加领略到国家体制的优越性，疫情让我们更加感受到中国共产党的伟大，疫情让我们更加坚信青年一代能堪当大任”三个方面，勉励广大同学以自己的实际行动展现城院人的精神。

章书记指出，大事难事看担当，危难时刻显本色。在抗击疫情中，城院学子也展现出了应有的担当与奉献，在疫情最凶猛的时候，主动投身疫情防控志愿工作，以自己的实际行动展现了城院人的精神，展现了当代大学生的风采，为打赢疫情防控战作出了贡献。

同时，章书记还寄语新生，要继承和发扬五四精神，坚定理想信念，站稳人民立场，练就过硬本领，投身强国伟业，始终保持艰苦奋斗的前进姿态，同亿万人民一道，在实现中华民族伟大复兴中国梦的新长征路上奋勇搏击。

今年的开学第一课，学校创新采用录播形式，在校内各专业各年级思政课上播放，覆盖面广，同学们参与度高。通过书记第一课的学习，全校同学更加深刻地理解了中国抗疫战争是一部伟大的教科书，要在抗疫中通过不同的方式，作出自己的贡献。
