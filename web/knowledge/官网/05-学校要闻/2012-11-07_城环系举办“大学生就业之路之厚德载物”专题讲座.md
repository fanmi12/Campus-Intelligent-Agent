# 城环系举办“大学生就业之路之厚德载物”专题讲座

11月6日，城环系举办的 “大学生就业之路之厚德载物”专题讲座在莞城校区教学楼1311开讲，该系全体毕业生着正装听讲。此次讲座，荣幸邀请到了广州黄埔军校善为学院国学讲师、广州竞争力顾问培训机构顾问龙海荣老师担任主讲嘉宾。城环系系主任肖红飞教授、城市学院学生处副处长孔增强老师、城市学院招生与就业办主任江小卫老师应邀出席了此次讲座。

在讲座中，龙海荣老师从我国传统历史文化出发，以儒家学派思想为代表，以现代社会中的典型案例为载体，阐述了“德”在我国传统历史文化中的地位及其在现代社会中的重要性，希望毕业生在踏入社会之际，要以广东精神“厚于德，诚于信，敏于行”为标准严格要求自己，做一名诚实、守信的合格大学生。讲座期间，同学们认真听讲、积极提问，现场气氛活跃。学生处副处长孔增强老师为讲座作了总结讲话。

与会学生表示，此次讲座使大家经历了一番思想上的洗礼，同学们开始重新审视自己在面对就业乃至以后工作的态度，为毕业生实现从学校到社会的转变奠定了一定的思想基础。
