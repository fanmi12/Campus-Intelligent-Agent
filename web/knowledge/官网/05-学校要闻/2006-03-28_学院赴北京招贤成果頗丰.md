# 学院赴北京招贤成果頗丰

在3月份召开的北京地区春季招聘会上，我院共收到北京大学、清华大学、中国人民大学、北京航空航天大学、北京理工大学、北京师范大学、北京邮电大学的博士、硕士研究生应聘书260份，签订意向书30份。近日，应聘者已陆续来我院参加面试。

由于学校规模扩大，我院急需招聘一批教学教辅及管理人才。为了改善教师队伍结构，提高整体素质，学院决定到人才集中的北京招贤纳俊。

这次招聘会是由上述7所大学联合举办的。
