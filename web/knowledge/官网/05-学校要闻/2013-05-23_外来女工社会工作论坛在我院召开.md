# 外来女工社会工作论坛在我院召开

5月21-22日，由香港理工大学-北京大学中国社会工作研究中心主办，东莞理工学院城市学院政法系承办的“第二届外来工社区社会工作论坛——外来女工社会工作论坛”在我院隆重召开。中国社会工作研究中心副主任、香港理工大学潘毅教授，城市学院政法系主任刘杰教授，东莞理工学院政法学院副院长邹琼博士，中山大学社会学与社会工作系教师许怡博士，广东省木棉社会工作服务中心刘亚博士，香港理工大学导师李玉仪女士应邀出席论坛，并分别做专题讲话。香港大学邓韵雪博士，香港资深社工刘嘉美女士，和我院社会工作教研室教师与部分学生也参加了此次论坛。

此次论坛本着参与式培训的理念，在提供专业化培训以提升服务技能的同时，搭建一个相互学习的平台。

会后，政法系主任刘杰教授还就我院社会工作专业建设与发展与嘉宾们进行了深入的探讨，他表示这种高层次活动将次论坛推动城市学院社会工作专业的发展。
