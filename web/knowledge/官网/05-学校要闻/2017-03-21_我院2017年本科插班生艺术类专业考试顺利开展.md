# 我院2017年本科插班生艺术类专业考试顺利开展

3月18日，我院2017年本科插班生艺术类专业考试在综合实训楼顺利进行。

签到、填表、等候……上午8点刚到，记者在现场看到，考生已陆陆续续前来准备考试，不少人已经换好了精心准备的服装、有的则利用等待的时间进行考前复习。毕业于广东亚视演艺职业学院的黄仁波今年已是第三次报考我院了，“我比较适应东莞的生活，而城院对于我来说有种亲切感。”

据介绍，今年报考我院艺术系本科插班生的考生人数共计75人，现场签到考生人数58人。录取考生将插入2015级本科班学习。
