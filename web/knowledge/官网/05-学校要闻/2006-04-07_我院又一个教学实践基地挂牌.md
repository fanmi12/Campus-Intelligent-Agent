# 我院又一个教学实践基地挂牌

4月7日，城市学院常务副院长程发良教授、副院长林世俊教授和经贸系主任田野教授来到了广发证券股份有限公司东莞业务总部，在周培胜总经理的陪同下举行了“东莞理工学院城市学院教学实践基地”挂牌仪式。

程副院长代表学院感谢广发证券股份有限公司对我院教学工作的支持，并希望该公司对我院实习学生进行严格的管理和教学指导。
