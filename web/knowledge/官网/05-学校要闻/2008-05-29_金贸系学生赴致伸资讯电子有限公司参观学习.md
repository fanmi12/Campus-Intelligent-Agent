# 金贸系学生赴致伸资讯电子有限公司参观学习

5月28日，金贸系06级国际商务专业90名学生在周浩明博士、任炼老师的带领下，赴东莞致伸资讯电子有限公司参观学习。

公司经理热情接待前来参观学习的师生。叶经理就该公司的管理机制、经营模式、发展战略、校企合作等问题与师生们进行了深入的探讨与交流。会后，师生们还参观了该公司的生产车间。

据悉，致伸集团公司是沿用美商制度及中国式管理模式较成功的企业之一，年销售额达到10亿美元。
