# 首届“城院杯”诗词风云大会完美收官

11月21日晚，第一届“城院杯”诗词风云大会总决赛在学术报告厅举行。院领导章德胜、周庆观看了大赛。大赛由文传系宋秋敏教授、谢友祥教授、陈如碧博士担任评委。

经过层层角逐，汉韵队、逢秋队、琴声剑意队、焚诗队、怜词队、意气风发队等六支进入此次总决赛。

在精彩的朗诵表演后，大赛拉开帷幕。比赛分为“诗词接龙””、“吟风颂月”和“飞花令”三个环节，选手们使出浑身解数，你追我赶，精彩连连。

大赛围绕“青春中国梦、喜庆十九大”进行主题诗歌创作，选手们“指点江山、激扬文字”。意气风发队的《复兴》，让人为之热血沸腾；焚诗队的《国春》随着笛子的演奏，时而高昂、时而婉约；怜词队的《望》、汉韵队的《七绝?喜庆十九大》、逢秋队的《爱国无题》和琴声剑意队的《腾飞》先后亮相，赢得了观众们的掌声。

莞笑社受邀进行了精彩的相声表演，艺术团风格舞队献上了一段唯美的舞蹈表演。

经过几轮较量，焚诗队获得本届诗词风云大会冠军！

谢友祥教授对六支队伍创作的诗词予以高度的评价。他说，举办诗词风云大赛的目的在于督促同学们多读多背，扩大知识面，培养对诗词文化的兴趣爱好。
