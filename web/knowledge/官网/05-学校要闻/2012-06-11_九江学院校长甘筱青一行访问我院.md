# 九江学院校长甘筱青一行访问我院

6月11日，江西九江学院校长甘筱青、招生就业处副处长张外加等一行三人来我院参观访问。东莞理工学院副校长安少华热情接待了客人。

甘筱青校长在详细了解了我院的办学历史和建设发展情况之后，称赞我院办学成效显著，是同类院校中的标杆单位。甘校长说：“我了解到，从九江学院调到城市学院工作的教师，都已在东莞安居乐业，把城市学院当成了自己的家。这从一个侧面体现了城市学院‘以教师为本、教授治校’的办学思想。”

甘筱青校长一行在安少华副校长陪同下参观考察了莞城校区的图书馆。他们从八、九层的藏书阅览区、中厅展览区，一直参观到第十一层的东莞市情资料阅览区，所到之处，客人们对图书馆的特色馆藏、优美的环境和先进的设备表示称赞。临别前，甘校长在图书馆市情资料阅览区挥笔赠言“服务社会，传承文化”，还赠送了纪念品给我院。

艺术系系主任邓星明、高教研究与评价中心教学督导员聂映中、思想政治理论课教学部黄宗理、图书馆馆长陈伟等参加陪同。
