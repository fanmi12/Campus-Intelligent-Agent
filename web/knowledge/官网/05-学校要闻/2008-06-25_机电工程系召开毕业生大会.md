# 机电工程系召开毕业生大会

6月24日，机电工程系在学术报告厅召开毕业生大会。机电工程系主任黄健求教授，副主任孙成访博士，党总支副书记谢明副教授以及机电工程系全体教师出席了大会。

会上，毕业生代表关永昌、李木伙首先发言。他们表达了对母校的留恋与感激之情，表示将牢记老师的谆谆教诲，不辜负学校的殷切期望，做有益于社会的人。

班主任韦荣耀老师和陈伟泉老师也相继发言，希望毕业生充满自信，把在母校炼就的专业技能这把“长剑”应对社会挑战。辅导员代表理阳阳老师希望毕业生常回家看看。陈常祥副教授勉励毕业生要调整心态，积极面对就业问题。

系主任黄健求教授祝贺毕业生顺利完成学业，希望毕业生工作顺利，生活幸福，大展抱负，为机电工程系争光，为母校争光。

毕业生们还向母校赠送了纪念品。
