# 新闻专业学生赴东莞两报参观学习

为切实提高新闻专业学生的专业知识水平，使文传系的“读报评报”活动扎实有效开展，08、09级新闻专业的学生在读报评报活动指导老师、院报主编唐耀碧老师的带领下，于3月25日赴《东莞日报》、《东莞时报》参观学习。

在两报编辑部，同学们参观了《东莞日报》和《东莞时报》的展览馆、图书资料室和报社工作场所，着重阅看了《东莞日报》与《东莞时报》评报栏的文章，听取了《东莞日报》执行副总编雷石鹏有关评报工作的情况介绍。在新闻采编座谈交流会上，同学们与记者、编辑开展自由互动。

据反映，此次参观活动让学生对评报有了直接的了解，认为评报对专业学习大有益处。
