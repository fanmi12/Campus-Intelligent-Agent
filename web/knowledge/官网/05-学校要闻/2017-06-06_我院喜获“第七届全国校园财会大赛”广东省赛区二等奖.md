# 我院喜获“第七届全国校园财会大赛”广东省赛区二等奖

6月4日，第七届中华会计网校杯全国校园财会大赛广东省赛区大赛在广东金融学院举行。我院财经系2014级CPA创新班郑燕璇、何丽娜、陈逸娟三名同学（指导老师：耿玉成、肖文锋）在本科组竞赛中以第二名的成绩获得广东省赛区二等奖的好成绩。

据了解，本项赛事是由中国高等教育学会财经教育分会与正保远程教育（CDEL）联合主办的全国大型财会专业竞赛，广东省赛区共有31所高校参与了本项赛事。
