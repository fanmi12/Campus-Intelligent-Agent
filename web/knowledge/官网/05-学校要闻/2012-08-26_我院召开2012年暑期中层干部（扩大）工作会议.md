# 我院召开2012年暑期中层干部（扩大）工作会议

8月25日，城市学院2012年暑期中层干部（扩大）工作会议在新校区学术报告厅召开。东莞理工学院党委书记成洪波、校长杨晓西、党委副书记吕琦元，城市学院董事长麦照容、董事黎建烨出席会议并做重要讲话。院长杨敏林做大会主旨报告。

党委书记朱志德主持会议。

东莞理工学院党委书记成洪波做重要讲话。成书记首先对与会人员一年来的辛勤工作表示感谢，接着就如何进一步办好城市学院、完成新学年的工作任务提出了三点希望：一是要树立信心，二是要完善制度，三是要谋求发展。他说，我们有信心进一步做大做强城市学院，办百年名校，这个信心来源于市委市政府的支持，来源于鸿发集团的开明与实力，来源于城市学院办学九年积累的经验、良好的社会口碑和办学品牌。信心的建立要通过具体的规章制度的实行来体现。要善待学生，厚待老师，落实好与教师密切相关的各项政策，包括福利待遇、薪酬、个人事业发展等。领导干部要发挥模范带头作用，与全体教职员工一道“心往一处想，劲往一处使”，推动城市学院在新的起点上实现跨越式的发展。各级领导要高度重视教学质量，培养合格人才。全体教职工要共同努力，做好学院过渡期的各项工作。当前，要把办学主体搬迁工作及迎新、开学工作放在各项工作的首位，平稳、有序、顺利。成书记表示，东莞理工学院党委对城市学院的发展充满信心并寄予厚望，将全力支持城市学院的工作和发展。

董事长麦照容在会上表示，城市学院的发展前景一片光明，鸿发集团办百年名校的目标和理念从未改变。城市学院要实现新的跨越，谋求新的发展，在更高更新的起点上再创辉煌。我们要用发展留人，待遇留人，感情留人，让学院成为每个城院人美好的家园。麦董事长还表示，在坚持董事会领导下的院长负责制的基础上，城市学院还要逐步完善各项管理制度。目前有关补贴办法即将出台。希望全体教职工从大局出发，尽力克服暂时的困难。

院长杨敏林在报告中分析了开拓城院新局面的有利条件，安排部署了本学年应着力做好的几项重点工作。杨院长指出，九年来，在东莞理工学院党政班子的正确领导与支持下，城市学院获得迅速发展。鸿发集团投入巨资建设新校区，改善办学条件，为学院做大做强奠定了基础。杨院长指出，截至2012年5月，我院学生规模达到10669人，同时师资力量逐年加强，学生素质逐年提高，办学质量与教学品牌不断提高与增多，社会口碑越来越好。

关于今年的工作，杨院长特别强调了要正确处理好三个方面的关系：一是处理好主办方、投资方、管理方的关系，明确三方的责权利，实现共建共赢。自鸿发集团斥巨资建设新校区，学院真正建立了典型的“公办高校+民营企业”的独立学院办学模式，三者在办学过程中目标一致，共同参与，合理分工，这有利于形成共建共赢的格局，有利于可持续发展。二是处理好“一校两区”的关系。大三、大四的学生将继续留在莞城校区，实行“属地、延伸”的模式进行管理。三是处理好规模与质量的关系。适当扩大招生规模，符合我院的发展实际，是完全必要的。在扩大规模的前提下，我们要依靠全体教职员工，提高学院的学术科研水平和教育教学质量，打造教学品牌，建设特色专业。杨院长对新学年工作提出了九点要求：要同心协力做好学院主体搬迁工作，确保学院平稳过渡；要牢固确立人才培养的中心地位，切实提高教育教学质量；要注重引导，强化措施，全力做好一校两区的学生工作；要加强党风廉政建设工作，发挥党组织的战斗堡垒作用；要加强民主管理，构建和谐社会；要逐步完善学院内部治理结构，充分发挥新机制在创新学院管理中的作用；要立足东莞，服务东莞，助力东莞高水平崛起；要加强国际交流合作，探索宽领域高层次的办学模式；要总结经验，力争以优异的成绩迎接教育部对我院办学的合格验收和省教育厅对我院教学工作的评估。

会上，副院长张林宣读了学院部分管理干部任免通知。

党委副书记朱冰、章德胜，副院长高香林在会上就办学主体搬迁工作、迎新军训工作、新学期教学工作做了安排。据悉，办学主体搬迁工作将于本月31日结束。

中层干部还分组进行了讨论，大家表示会议统一了思想，明确了任务，坚定了继续办好城市学院的信心。
