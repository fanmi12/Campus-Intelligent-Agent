# 学院举办重点学科项目建设评审会

9月12日，学院重点学科项目建设评审会在行政楼401会议室举行。评审会邀请了东莞理工学院科研处处长程发良、华南理工大学工商管理学院副院长李志宏、广东工业大学机电工程学院副院长李笑、华南农业大学公共管理学院副院长廖杨、广东财经大学金融学院保险系主任马莉担任评审专家。

王卫平院长、黄兢副院长、林江龙院长助理和重点学科建设领导小组的相关负责人参加了会议。

机械工程、工商管理两个省级重点培育学科的学科负责人就重点学科建设任务书进行了汇报，社会工作、保险学两个学科负责人对院级特色重点学科的申报书及任务书进行了汇报，并接受了专家的答疑。

与会专家认真听取了汇报并进行了热烈的评议，充分肯定了我院在重点学科建设工作上迈出了积极的步伐；肯定了我院重点学科遴选标准上较好地满足了以服务创新驱动发展战略及地方经济社会发展能力上的需求，肯定了我院重点学科建设在人才引进、学科专业规划上取得的成绩。专家也指出，部分学科服务地方区域经济能力还有待进一步提升，学科方向定位、学科特色凝练、学科面向等方面还需进一步明确，学科团队的学历结构、职称结构、年龄结构、学缘结构等方面还有待进一步优化，学科建设的组织制度、经费保障等保障

措施还需进一步加强。

此次评审会议为推动我院重点学科建设搭建了学科共享交流的平台，使各学科在全面了解自身的优劣及未来的发展方向上进一步明确了方向，为学科建设在人才引进、培养、考核，为学科专业与地方企业共建实践基地、科研平台、联合培养基地等提供了宝贵经验。

会议由研发处处长赵书山主持。
