# 我校学子参与河南卫视“端午奇妙游”，传播传统文化！

端午临仲夏，时清日复长。6月21日晚19时30分，河南卫视精心打造的《2023端午奇妙游》播出，与全国观众见面，受到举世瞩目。我校艺术学院舞蹈系师生，及校国防教育教导团的34名同学参与的东莞石龙新昌鼓表演也在节目中“奋楫争先“，展现广东人的拼搏精神，展现了东莞非遗文化，也展现了我校师生的风采。

我校艺术学院舞蹈系系主任李利民介绍道：今年我校师生很荣幸受邀参加河南卫视的端午节的录制。接到任务后，我校师生认真排练，克服种种困难。寻制当天同学们早上三点起床，开始录制前的化妆、道具搬运等准备工作，最终在东莞旗峰山上圆满完成录制，受到了导演组的肯定。

河南卫视“2023端午奇妙游”开场节目《龙舟竞渡》一亮相，就展现了全国各地端午佳节各地“奋辑争先”的热烈场面，节目中还有国家非遗广东东莞赛龙舟队，国家非遗贵州镇远赛龙舟队和贵州镇远民间艺术表演队的参与。鼓声起，龙舟争先，不仅有浓厚的原汁原味的民俗风情，呈现出“龙舟飞天”的奇观，象征中华民族团结拼搏、力争上游的精气神。

据了解，自2021年以来，河南卫视已经连续3年打造端午特别节目，《端午奇妙游》每每刷屏，成为万千网友追捧的对象，继《唐宫夜宴》之后，再次火爆出圈，成为全网关注的话题，传播了传统文化，引领国风和文化的发展。
