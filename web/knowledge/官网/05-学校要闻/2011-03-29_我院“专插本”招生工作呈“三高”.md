# 我院“专插本”招生工作呈“三高”

3月27日，广东省教育厅对外发布2011专插本考试成绩，文科类最低分数线250分/145分（五科总分/省统考三门总分，英语类按五科总分/省统考二门总分划线），理科类最低分数线225分/125分，英语类最低分数线250分/100分，艺术类最低分数220分/120分。根据这个录取分数线，城市学院的考生共有206人上线。

据学生处副处长陈建新介绍，今年我院“专插本”招生工作呈现出“三高”：招生人数、报考我院考生人数、上线人数均较去年有大幅度的提高。今年我院计划招生150人，比去年增加50人；去年报考我院的考生人数为300人，今年猛增至482人；去年上线人数为147人，今年则超过了200人。
