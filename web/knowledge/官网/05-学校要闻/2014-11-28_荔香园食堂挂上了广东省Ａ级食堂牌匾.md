# 荔香园食堂挂上了广东省Ａ级食堂牌匾

广东省食品药品安全监督管理局通过检查评估，认为我院荔香园食堂符合广东省“Ａ级”食堂标准，颁发了“广东省Ａ级食堂”牌匾。１１月１９日，总务处在荔香园举行了挂牌仪式。

据了解，按照安监局有关文件规定，集体食堂分为“Ａ、Ｂ、Ｃ”三个级别。大中小学校学生食堂必须达到Ｂ级以上。只有达到A级食堂标准，才有资格申报“广东省食品安全示范学校食堂”。１０月１０日，我院向省、市、镇安监部门申报示范学校食堂等级，并邀请其来校评估。目前，评估工作已经结束。
