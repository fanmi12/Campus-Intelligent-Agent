# 我院“青春健康”艾滋病防控项目获省教育厅立项

近日，省教育厅下发了《关于开展2014年高校“青春健康”艾滋病防控项目学校申报的通知》，我院“青春健康”艾滋病防控项目获得立项。

据悉，在此之前，学生处社会工作服务中心递交了项目申报书，并最终在申报的27所高校中被选定为十所试点高校之一。

该项目旨在帮助大学生树立正确的价值观、爱情观，提高大学生性意识和自我保护意识，增加大学生生殖健康、艾滋病防预知识，项目持续时间为3年，省教育厅在此期间将会给予培训、资料、专家指导，以及一定的经费支持。

学生处社工中心的师生已参加了省教育厅组织的“青春健康。同伴教育”培训学习，并邀请在华南地区最具影响力从事性健康服务与教育的NGO组织岭南伙伴在我院开展了“青春健康 同伴教育”讲座，收到良好的效果，学生处积极整合了校内资源，并已成立预防艾滋病和青春健康教育工作领导小组和“青春健康同伴社”。项目负责人曹琴老师说，立项之后，我院将根据实际情况进一步开展“青春健康同伴教育”相关工作，营造有利于大学生青春健康的校园氛围。
