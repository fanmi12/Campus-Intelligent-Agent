# 学院召开教学系部目标管理绩效考核民主测评大会

6月19日，学院在112会议厅召开2013-2014学年教学系部目标管理绩效考核民主测评大会。杨敏林、王卫平等院领导出席会议。

党委副书记、工会主席章德胜主持大会。

章德胜同志在发言中表示，去年12个教学系部主任分别与学院签订了本学年的目标管理绩效考核任务书。各系部通过一学年的努力，取得了很大的工作成绩，达到了目标要求。

民主测评会上，12个教学系部的主要负责人向大会代表进行述职，汇报本单位一年来的工作完成情况。从核心指标完成情况来看，本科英语4级累计通过率，毕业班达到了42.69%的较高水平，三年级本科生通过率超过了毕业班的水平，这说明我院教学、教育的质量处于稳步提高的良好状况。毕业生受到社会的欢迎，初次就业率达到 96.25%，最终就业率达到99.8 %。教学管理、学生管理等指标都顺利完成，比预期的好。

78名教职工代表对12个教学系部及其行政负责人的工作绩效进行了民主测评。
