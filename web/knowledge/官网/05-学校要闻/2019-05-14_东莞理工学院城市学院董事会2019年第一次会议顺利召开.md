# 东莞理工学院城市学院董事会2019年第一次会议顺利召开

5月13日下午，东莞理工学院城市学院董事会在学校行政楼召开2019学年第一次会议。会议由麦照容董事长主持。

会议审议并同意聘任城市学院党委书记章德胜同志为董事。同时，对离任董事杨敏林同志在学校发展尤其是在新校区建设中做出的巨大贡献表示衷心的感谢。

会议审议并通过了学校上学年度工作总结和下学年度工作要点，审议并通过了学校上学年度财务预算执行情况报告及下学年度财务预算方案，审议并通过了学校高层次人才队伍建设方案及其他议题。

会议对近年来城市学院总体工作给予肯定，并要求今后加强党对学校工作的全面领导，进一步加大师资队伍建设力度，培育和凝练学科专业特色，努力打造学校特色品牌。
