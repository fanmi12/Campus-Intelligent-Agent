# 我院举行图书科技信息中心奠基仪式

7月8日，我院举行了图书科技信息中心奠基仪式。东莞市副市长梁国英，东莞理工学院党委书记周致纳，东莞理工学院院长、城市学院董事长杨晓西教授，原东莞理工学院院长张遐龄，东莞理工学院副院长、城市学院院长安少华教授以及东莞市城建局领导，施工方代表等出席了奠基仪式。奠基仪式由城市学院行政副院长张林博士主持，城市学院党委副书记朱冰致辞。

据悉，图书科技信息中心，规划建筑占地面积为3500平方米，建筑面积为29928平方米。拟建地下一层，地上13层。其中地下层为设备用房，一层为一楼小型剧场和会务用房，2层为架空层，3－6层为教学区，设有若干电教室和多媒体室，3楼有一个连廊与现有四号楼2楼连接。7－13层为图书馆。项目总概算为8372万元，计划于2009年年底竣工。项目的设计方为华南理工大学建筑设计院，施工方为青岛建设集团公司，监理方为惠州市工程建设监理公司。图书科技信息大楼建成后，将大大提升我院硬件水平，为师生办公学习的提供更优良的条件，为我院 “上水平，创特色”迈向新台阶做出贡献。
