# 后勤保卫处开展学生宿舍安全大检查

11月24日下午，我院后勤保卫处、学生处、各系部辅导员、院学生会自律会等部门联合对校内12栋学生公寓及校内商铺进行拉网式安全大检查。本次安全大检查是“校园安全月”系列活动之一。

检查分成13个组，分别深入学生宿舍、校内商铺，重点检查宿舍违禁物品、安全用电、消防安全及商铺的防火公约、用电、用油、用气安全等情况。据介绍，检查结果总体令人满意，但仍有个别宿舍存在卫生状况差、室内不够整洁、插座线头外露、违章使用大功率电器等问题。对存在的问题，检查组要求各宿舍现场整改，并将违规使用大功率电器情况进行详细登记在册。

在检查过程中，检查组反复叮嘱同学们要切实增强安全防范意识，注意防火防盗，关好宿舍门窗，保持室内清洁，禁止私拉乱接电线、使用大功率电器，共同维护校园安全。
