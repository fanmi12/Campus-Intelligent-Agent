# 我院召开学生诚信建设工作培训会议

4月16日，我院在新校区206教室召开大学生信用档案建设工作培训会议，辅导员、班主任代表及新校区的学生干部参加了会议。会议由院团委书记、学生部副部长杜鹏举主持。

会上，广东上下五千年资信科技有限公司相关负责人应邀做业务讲座。会议分为三部分内容：一是强调现阶段建立学生信用档案的意义及作用，介绍了现阶段全省各高校学生信用档案建设的成果与经验；二是总结我院2010年学生助学工作情况，讲解如何防范国家助学贷款中的风险问题；三是指导广大师生如何操作使用信用档案系统及如果解决使用中所遇到的各类问题。

与会的老师和学生都认为，在大学生中率先建立信用体系，对于进一步提高大学生的思想道德素质，促进高等教育的改革与发展，全面实施科教兴国战略、人才强国战略和依法治国基本方略等具有十分重要的意义。同时对于我们做好学生管理工作，方便学生就业、企业用人等方面都有积极作用。
