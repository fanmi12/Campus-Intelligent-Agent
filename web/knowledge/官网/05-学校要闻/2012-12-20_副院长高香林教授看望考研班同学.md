# 副院长高香林教授看望考研班同学

12月18日，副院长高香林、教务处副处长葛卫清在培训中心李丽娟主任的陪同下，来到城市学院莞城校区四号楼520室，看望正在紧张复习准备参加2013年硕士研究生考试的同学。

同学们对高副院长的到来报以热烈的掌声，并邀请高副院长在不久的将来参加他们的庆功宴。高副院长愉快地接受了邀请，并叮嘱同学们保持良好的精神状态和身体状态，预祝他们取得好成绩。

据悉，今年参加硕士研究生考试的学生有计信、机电、财经、金贸、文传、政法、城环、管理等系共62名学生。他们根据自己所学专业分别报考武汉大学、南开大学、华南理工大学、兰州大学、华南师范大学、深圳大学、上海理工、暨南大学、广东外语外贸大学、河海大学、南京理工大学等几十所高校。
