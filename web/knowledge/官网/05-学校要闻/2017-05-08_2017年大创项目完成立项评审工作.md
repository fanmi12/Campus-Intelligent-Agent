# 2017年大创项目完成立项评审工作

5月5日下午，研发处组织召开了2017年大学生创新创业训练计划项目立项评审会，广东科技学院副院长兼任创新创业院长陈标新、东莞理工学院高评中心主任陈想平等9名特邀外校专家和我院副院长黄兢参加了本次评审会议。

经研发处、学生处和团委积极组织、广泛宣传，今年我院师生申报大学生创新创业训练计划项目数创历年新高，达到127项，其中创新训练项目102项，创业训练项目11项，创业实践项目14项。

在网上初评结果的基础上，来自东莞理工学院、广东科技学院、广东医科大学、广东创客行、广东广大企业集团有限公司等单位的9名评审专家通过分组审议、集中投票表决相结合的方式，最终评选出60个项目作为2017年院级大学生创新创业训练计划项目进行立项建设，并从中遴选5个项目推荐为国家级大创项目，30个项目推荐为省级大创项目。

研发处处长赵书山主持了会议。
