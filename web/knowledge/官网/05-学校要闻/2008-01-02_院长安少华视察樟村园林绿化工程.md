# 院长安少华视察樟村园林绿化工程

1月2日，新年第一个工作日的清早，院长安少华教授在学院基建办主任叶树标的陪同下，来到樟村教学生活园区视察小区园林绿化工程。

视察过程中，安院长听取了叶树标主任关于园区建设的工作汇报。视察结束后，安院长指示，一定要重视停车场、师生活动场地的建设,，要体现岭南文化特色，使小区具有文化品味。

据悉，樟村教学生活园区园林绿化工作量接近过半，可望按期竣工。
