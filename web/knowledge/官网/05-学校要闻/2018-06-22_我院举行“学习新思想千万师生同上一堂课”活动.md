# 我院举行“学习新思想千万师生同上一堂课”活动

6月21日下午，我院“学习新思想千万师生同上一堂课”授课活动在行政楼112及7B202阶梯课室同时举行。院党委书记王卫平、创意设计学院党总支书记何鹏举分别进行了授课，1000多位师生代表参加了活动。

院党委书记王卫平以《做新时代“四有好老师”，当好学生健康成长的指导者和引路人》为主题，围绕习近平总书记在北京大学师生座谈会上的提出“一个根本任务”、“两个标准”、“三项基础性工作”，结合学校发展实际，就“好‘四有’好老师，做好引路人”进行了阐述。他指出，广大教师要做有理想信念、有道德情操、有扎实知识的教育工作者，为促进人的全面发展，为发展具有中国特色、世界水平的现代教育，培养社会主义事业建设者和接班人作出更大贡献。

创意设计学院党总支书记何鹏举以“不忘初心，牢记使命”为主题，和同学们一起探讨了“什么是初心、共产党的初心是什么、我们如何不忘初心”。他强调，同学们要学习贯彻落实习近平总书记提出的“爱国、励志、求真、力行”要求，勇担时代大任，做德智体美全面发展的社会主义建设者和接班人。

据悉，“学习新思想千万师生同上一堂课”通过现场授课、网络转播等方式走进师生，着力扩大覆盖面和受益面，有机结合“实体课堂”与“网络课堂”等形式，形成“全国千万师生同上一堂课”的生动局面。
