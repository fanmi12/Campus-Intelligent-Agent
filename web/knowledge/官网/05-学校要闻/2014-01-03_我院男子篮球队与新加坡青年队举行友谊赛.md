# 我院男子篮球队与新加坡青年队举行友谊赛

近日，受新加坡国家青年男子篮球队的邀请，体育教学部邢红林主任率我院男子篮球队在东莞市篮球学校体育馆与对方进行了一场交流赛。

面对国家专业篮球队，我院篮球队在比赛中不畏强手，敢打敢拼，不甘落后，每分必争，一招一式都显示出篮球功底和战术水平，彰显篮球竞技魅力和自信心，比赛打成96：88，新加坡队取胜。
