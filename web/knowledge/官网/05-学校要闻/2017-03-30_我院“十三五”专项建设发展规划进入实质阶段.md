# 我院“十三五”专项建设发展规划进入实质阶段

3月29日下午，学院“十三五”专项建设发展规划及二级教学单位“十三五”建设发展规划启动动员大会在行政楼212顺利召开，标志着我院“十三五”专项建设发展规划进入实质阶段。学院领导以及各行政单位、各教学单位、各教辅单位负责人参加了这次会议。

会议由副院长黄兢主持，研发处处长赵书山介绍了我院“十三五”发展规划报告起草的背景、依据及过程，并对此次发展规划的启动工作要求进行了解读。

据了解，我院“十三五”发展规划由学院总体建设发展规划、专项建设发展规划和二级教学单位发展规划三部分组成。我院“十三五”发展规划从2014年开始酝酿，几易其稿，最终形成我院总体的“十三五”发展规划。涉及面之广、参与人之多、研讨之久、历时之长，体现了院领导的高度重视。本次开始启动编制的是学院6个专项建设发展规划及13个二级教学单位的“十三五”建设发展规划两大部分。

院长、党委书记王卫平强调：“十三五”规划是指导和引领全院“十三五”期间各项事业开展的纲领性文件，全院各单位要高度重视，必须统一思想，加强领导。规划工作系统性强、涉及面广、任务重、要求高，全院上下需形成合力，切实保障“十三五”发展规划的贯彻落实。王院长指出：“十三五”期间学院各项事业要进行全面深化改革，各单位必须先做好顶层设计，结合此次规划的起草工作，理清理顺“十三五”期间各单位的工作重点，做好整体规划、统筹安排、明确方向、凝练特色、与时俱进。王院长希望二级单位负责人一定要转变作风，不要做“甩手掌柜”。要明确自身肩负的使命和责任，脚踏实地，真抓实干，把各项工作抓到实处。
