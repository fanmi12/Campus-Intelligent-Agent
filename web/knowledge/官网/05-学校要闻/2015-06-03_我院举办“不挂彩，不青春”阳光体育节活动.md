# 我院举办“不挂彩，不青春”阳光体育节活动

5月28日下午，我院举办了“不挂彩，不青春”阳光体育节活动。活动包括三项挑战赛和彩跑。

此次体育节进行了大胆创新，更具趣味性。在三项挑战赛上，同学们以五人为一组相互配合，完成环湖跑、搬水桶、水池捞球等三个项目。选手不仅要自己完成任务，还要帮助队友，这考验了大家的团结合作意识，而搬水桶等也考验了众人的体力。千人5公里彩跑活动，与追求速度的赛跑不同，比赛不计成绩，同学们可在跑步的过程中，相互撒播彩色荧光粉，享受运动和彩色带来的快乐。
