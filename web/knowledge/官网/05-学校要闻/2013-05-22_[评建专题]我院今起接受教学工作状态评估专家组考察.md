# [评建专题]我院今起接受教学工作状态评估专家组考察

5月22日，广东省教育厅教学工作状态评估专家组莅临我院，深入考察和评审我院教学工作。

专家组由五邑大学教务处处长董超俊教授任组长，华南理工大学计算机学院院长韩国强教授、仲恺农业工程学院经贸学院院长王厚俊教授、东莞理工学院教务处处长王卫平教授、东莞理工学院高等教育研究中心主任陈想平教授任组员。

当天下午，我院举行了评估预备会议。专家组组长董超俊教授通报了三天的评估工作安排。

城市学院院长杨敏林教授发表了热情洋溢的欢迎辞。他代表学院对专家组的到来表示热烈的欢迎和衷心的感谢。他指出，此次评估是对我院教学工作和办学成就的全面检验，专家们的指导为我院进一步加快发展、全面提升办学水平提供了难得的机遇。学院将以此次评审为契机，根据专家们的意见和建议认真整改，加大建设，不断提升办学水平。

杨敏林院长代表校方欢迎专家组的到来

随后，专家组召开评估预备会议
