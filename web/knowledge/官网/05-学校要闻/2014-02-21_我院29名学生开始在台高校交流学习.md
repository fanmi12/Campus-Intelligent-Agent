# 我院29名学生开始在台高校交流学习

新年春节过后，我院29名学生分两批赴台湾国立台中科技大学、义守大学、嘉南药理科技大学学习，为期半年。目前，这些学生已经在新的大学开始紧张的学习生活。

2月11日，国际交流中心召集赴国立台中科技大学、义守大学交流学习的同学召开了赴台学习动员会，党委副书记章德胜、副院长高香林、学生处副处长杜鹏举以及带队学习交流的三位老师出席了会议。会上，学院领导要求赴台交流生把握好求学机会，在新的环境中努力学习，开阔视野，增进友谊，展现城院学子良好风貌，为学院争光。

2月19日，赴嘉南药理科技大学社工系学习的9名同学相聚政法系，与系主任刘杰教授、继续教育中心副主任夏泉源老师、党总支副书记刘军老师、社工专业老师们一起座谈话别，先期赴嘉南药理科技大学交流学习返校的卢淑芳老师给同学们带来了该校的一些信息和准备情况。

据2月12日入台的交流生反馈，他们已在新的环境中开始新的学习生活。
