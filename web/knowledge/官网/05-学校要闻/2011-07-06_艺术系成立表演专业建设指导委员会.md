# 艺术系成立表演专业建设指导委员会

7月5日，艺术系召开表演专业建设指导委员会成立会议。学术副院长程发良教授、教务处处长邓成良教授出席了成立会议，并为外聘专家颁发了聘书。

座谈会上，各位专家对表演专业学科建设、表演专业人才培养计划、课程设置等多项教学相关内容积极献言献策，提出了宝贵的意见和建议。

据系主任邓星明教授介绍，艺术系成立表演专业建设指导委员会，是贯彻和落实学院《关于各系成立专业指导委员会的通知》的精神，有助于更好地对艺术系表演专业的教学进行指导，加快专业建设的步伐，促进专业内涵的发展，培养符合地方经济社会发展需要的表演专业人才。
