# 我院教师受邀参加东莞市社科社团秘书长培训班

2011年9月15-16日，东莞市社科联在清远市举办了东莞市社科社团秘书长培训班，我院思政部石瑞丽老师和东莞社情研究中心的居正老师受邀参加。这次培训班由市社科联副主席龙家玘主持，广东省社科联秘书长周华和广东省社科联学术规划部主任冯达才分别作了报告。
