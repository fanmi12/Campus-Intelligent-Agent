# 机电工程系召开毕业设计暨就业指导会议

3月4日，机电工程系在机电楼工厂二召开08届毕业生毕业设计暨就业指导大会。机电系主任黄健求、系总支副书记谢明副教授以及毕业生各专业指导老师参加了会议。

学院就业指导办主任江小卫老师给毕业生作就业指导报告,向同学们详细分析了今年的就业形势，讲解了新《劳动合同法》的实施给招聘单位带来的微妙变化，提醒同学们在求职过程中要主动出击，积极争取。

机电系主任黄健求教授就同学们的毕业设计进行了动员安排。黄主任对同学们的毕业设计提出了具体要求，希望同学们重视毕业设计，指导老师要严格要求。各专业指导老师分别就毕业设计的各个环节作了详细的介绍。
