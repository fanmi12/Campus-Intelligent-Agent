# 我院获广东省大学生数学竞赛三等奖

10月27日，第四届全国大学生数学竞赛暨第二届广东省大学生数学竞赛在广州大学城举行，我院有54位同学参加了比赛。经过激烈的竞争，我院2011级会计专业袁敏仪、林远婷同学，软件工程专业刘梓豪同学荣获“省级三等奖”，城市学院获 “优秀组织奖”。

由“中国数学会”组织的“全国大学生数学竞赛”，已在全国举办了四届，广东赛区举办了二届，该项赛事已成为全国影响最大、参加人数最多的学科竞赛之一。本次大学生数学竞赛共有38所高校、1601人。
