# 我院2014年教工羽毛球赛圆满结束

4月3日下午6时，东莞理工学院城市学院2014年教工羽毛球决赛在综合馆打响。此次比赛共有14支队伍参与角逐，最终机关一、体育部、金贸系和管理系杀进了决赛。本次比赛采取团体赛，项目分为男子单打、女子单打、男子双打、男女混合双打等5个项目，并采取了三局两胜比赛制。

馆内赛事激烈，场上观众叫好声不断。“好球！”体育教学部刑红林一记精彩扣杀，机关一队的章德胜滚地救球赢得了一阵热烈的掌声。最后，体育部和机关一并列第一，管理系名列第二，金贸系位居第三。

美好的时间总是过得飞快，历时两周的教工羽毛球比赛完美落幕。“这次比赛旨在增强教职工凝聚力，传递城院正能量”，院工会主席章德胜书记如是说。
