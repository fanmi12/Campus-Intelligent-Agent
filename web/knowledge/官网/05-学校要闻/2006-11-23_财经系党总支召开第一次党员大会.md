# 财经系党总支召开第一次党员大会

我院财经系党总支第一次党员大会于11月23日下午在六号楼阶梯教室召开。财经系教工党支部19名党员和学生党支部10名党员、66名预备党员参加了本次大会。会议议程有：1、宣读中共城市学院党委关于成立财经系党总支的通知及下设党支部的批复；2、财经系党总支临时召集人作工作报告；3、选举财经系党总支委员。

财经系主任、党支部书记高香林同志在《加强党的建设，发挥党员作用，建设创新和谐的财经系》的工作报告中指出，财经系自2005年7月成立以来，在学院党委和行政的正确领导以及各职能部门的大力支持下，经过全系师生的共同努力，在学科与专业建设、师资队伍建设、党建工作、教学与科研以及学生教育与管理等方面取得了较好的成绩。他相信，在系党总支的带领下，财经系的整体工作将会迈上一个新的台阶。

通过投票，会议选举出财经系党总支委员会。党总支委员由王炯贤、龙卫洋、叶凯贞、高香林、鞠成晓同志担任。
