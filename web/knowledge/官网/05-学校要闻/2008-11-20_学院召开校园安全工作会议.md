# 学院召开校园安全工作会议

11月17日，学院在315会议室召开安全工作会议，通报安全检查情况，部署下一阶段的安全工作。

院领导朱志德、朱冰、张林出席会议并作重要讲话。学院有关职能部门负责人，院、系学生自律会负责人参加了会议。

会议指出，最近上海商学院发生火灾惨剧，三名女学生不幸跳楼逃生身亡，教训极为深刻。上周周五到周日，学院组织有关职能部门检查了消防设施和应急通道，发现了一些安全隐患，以及少数学生使用“热得快”等大功率电器的现象。对此不可掉以轻心，为此，及时学院召开安全工作会议，检查安全隐患，制定安全措施是非常及时和必要的，具有重要的意义。安全工作搞好了，才能确保全院师生员工的人身安全，安心工作与学习，促进学院和谐和快速发展。

会议进一步强调，继续组织安全保卫、后勤保障人员排查安全隐患，发现一起处理一起，不留空档，不留死角，杜绝安全事故的发生。实行一把手负责制，各单位领导要高度重视，严抓细管，常抓不懈，发现不安全的隐患和苗头应及时上报。运用多种形式，开展消防、饮食、卫生、交通、用电等方面的安全知识教育，帮助学生掌握防身逃生自救的技能和本领。改善安保设施，及时更新水、电、灭火器、消防栓等设施。严禁学生在宿舍里使用“热得快”等大功率的电器，发现一个收缴一个。保卫人员要全天候待命，时刻注意校园安全动态，提早做好预防工作，对发现的问题应采取措施予以解决，维护校园稳定，为师生创造安定和谐的学习和工作环境。
