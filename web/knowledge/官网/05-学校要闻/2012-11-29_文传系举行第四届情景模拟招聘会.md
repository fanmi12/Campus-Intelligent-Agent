# 文传系举行第四届情景模拟招聘会

为让广大学生提高就业技巧，更好地了解应聘的细节，使其在招聘会上有更好的表现，11月27日，文学与传媒系在莞城校区学术报告厅举行第四届情景模拟招聘会。新文传媒集团人力资源总监严永松先生，东莞报业传媒集团广告公司副总经理黎潤昌先生，富港电子有限公司人力资源部经理黄财发先生，城工部外事办袁宇航老师应邀担任评委。

党委副书记朱冰，就业与培训中心主任江小卫，系主任邓星明教授、党总支书记孟颖老师出席会议。

本次招聘会各班按比例报名并通过选拔后，选出11名学生作为招聘会的模拟选手。活动共分三个环节：第一环节是自我介绍及专业评定，选手们分别在台上进行30秒的自我介绍，然后进行专业测评题目的考察，由评委作出点评。第二环节是压力回答，此环节分四个小组轮流进行。评委对每个选手进行针对性提问，要求应聘者进行快速回答，这一环节也是应聘者是否具有专业的知识以及应聘技巧的最好体现。最后，由评审团代表严永松先生针对应聘者的简历及现场表现给予总结性点评，并鼓励同学们要发扬优点及针对性地进行改善，提出建设性的应聘理念。

情景模拟招聘会将求职应聘这一社会实践搬上了舞台，让准毕业生们提前感受招聘现场的气氛，并更清楚地了解自己，查漏补缺，增强了就业信心。

2013届毕业生参加本次招聘会。
