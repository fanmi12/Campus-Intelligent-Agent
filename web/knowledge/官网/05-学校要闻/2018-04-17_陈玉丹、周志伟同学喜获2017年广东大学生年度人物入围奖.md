# 陈玉丹、周志伟同学喜获2017年广东大学生年度人物入围奖

近日，由广东省教育厅指导，广东省高等学校思想政治教育人才培训中心举办的2017年广东大学生年度人物评选活动结果出炉，共从全省400万大学生中评出了102名大学生年度人物。我院艺术系2014级舞蹈表演陈玉丹同学、电子工程与智能制造学院2015级电子信息工程周志伟同学喜获2017年广东大学生年度人物入围奖荣誉称号。这也是我院学子首次获得该省级奖项。

陈玉丹同学在校期间刻苦学习专业知识，多次获得市级、省级、国家级证书。2015年12月获第十届广东省大中专舞蹈比赛一等奖，2017年11月获广东省第七届群众音乐舞蹈花会金奖，2017年11月获CCTV综艺频道舞蹈世界——舞蹈全民星奖。

周志伟同学热爱电子设计，通过计算机二级C语言和嵌入式系统，连续两年荣获一等奖学金，荣获2017年全国大学生电子设计竞赛广东赛区二等奖和2017年美国大学生数学建模竞赛二等奖，同时申请大创项目资金一万元，在实践中不断提高自己的专业技术水平。
