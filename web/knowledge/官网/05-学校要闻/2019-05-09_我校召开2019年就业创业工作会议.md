# 我校召开2019年就业创业工作会议

5月8日下午，我校召开2019年就业创业工作会议。校领导、机关教辅部门负责人，各二级学院院长、书记、副书记，以及招生就业处工作人员参加了会议。

招生就业处处长孔增强主持会议，传达了《教育部关于做好2019届全国普通高校毕业生就业创业工作的通知》和2019届全国普通高校毕业生就业创业工作网络视频会议精神，希望大家面对错综复杂的就业形势，切实提高思想认识，增强政治自觉，把做好毕业生就业创业工作作为一项重大政治任务、一项重大民心工程，不折不扣、扎扎实实地抓紧抓好。

就业中心主任林蓉总结了2018-2019学年度年就业创业工作的特色与亮点，着重对2018届毕业生就业调研报告进行了解读，学习探讨了2018届毕业生社会需求与人才培养报告的反馈与启示，提出了2019-2020学年毕业生就业工作重点。

王卫平校长在总结中强调：一是要加大力度提升全校师资队伍的力量，提升人才培养质量，结合社会需求完善学科专业建设体系，培养出高质量、高素质的应用型人才。二是要紧扣“全方位、全员育人”理念，立德树人，加强城院特色文化建设，积极提倡以“爱心”态度，多关爱学生、多与学生沟通交流，提高服务意识，以爱岗敬业、奉献精神服务好每一位学生。

王卫平校长还与各教学单位签订了2019年毕业生就业工作目标责任书。
