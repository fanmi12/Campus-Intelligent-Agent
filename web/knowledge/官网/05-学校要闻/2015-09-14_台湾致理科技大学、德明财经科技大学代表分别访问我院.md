# 台湾致理科技大学、德明财经科技大学代表分别访问我院

9月11日，台湾致理科技大学副校长谢金贤一行，台湾德明财经科技大学研发长翁顺裕、产学合作组组长林秋香、粤台产业科技学院台方系主任卢瑞山等一行，分别访问我院。院领导章德胜、高香林以及教务处处长牛熠、国际交流中心副主任夏泉源热情接待了来宾，并就教师及学生交流、台湾高层次人才引进等问题进行了深入探讨。

据了解，今年5月，我院分别与台湾致理科技大学、台湾德明财经科技大学签订了学术框架协议。暑假期间，我院还派出金融与贸易系、财经系、管理系的10名教师到台湾德明财经科技大学进行了为期8天的研修。
