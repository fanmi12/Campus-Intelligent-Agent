# 天下父母心

又是一年开学季!5日、6日，城院的迎新日。迎来众多“小鲜肉”的同时，也迎来了冒着黄色高温，扛着大包小包，伫立在综合馆外等待的新生家长。

“对于即将进入大学的孩子，家长们又有什么期待呢？”今天，带着这个问题，记者走进迎新现场，走进家长群，来认识认识2015级“鲜肉”父母。

一位来自佛山的妈妈是这样回答的：“希望他学好知识有贡献！”

来自河源的小谢是电子信息工程的新生，和他一起来报到的爸爸言简意赅：“希望他再接再厉，新的学校，新的开始！”

再来听听东莞的父母怎么说，来自东莞道滘的蔡先生对自己的儿子十分放心，他表示，“机械设计这个专业是他自己选的，他想学什么就学，想做什么就做，开心就好！”

另一位来自东莞石排的黄先生对念市场营销的女儿的要求更是只有“开心”二字，他说，“开心点，放松点，不要有太大压力”。

正如来自湛江的廖先生说的，“说没有期待是假的。”

父母对子女最大的期待，也不过是子女开心。都言“谁言寸草心，报得三春晖。”在此向奔波劳累的“鲜肉”父母致敬，道一声，“您辛苦了！” （大学生记者 卢清琳）

校园那么美，先泡泡图书馆

金秋九月，收获的季节。一批新城院学子在家人的祝福和陪同下，怀着喜悦与期待，又有些许紧张的心情迈进了城院校门。

金贸系2015级国贸班的刘靖怡同学，一进校门就领取了“新生报到流程表”，这让她能快速明确地知道应该如何办理报到手续。交学费、户籍登记、办校卡、领取军训服，一路畅通无阻。靖怡说，虽然是一张简单的“流程表”，但是让人感受到了城院的贴心。

走在校园里，第一次看到如此美丽的校园，靖怡的弟弟天真兴奋地说：“哇！姐姐你读大学好幸福啊！”

当靖怡推开宿舍门，一阵清爽的“透心凉”正面“袭来”，与外面的“烤肉模式”形成强烈对比！原来是室友开了空调！靖怡边打扫卫生边说，“我报考城市学院的其中一个原因，是我了解到它是‘空调学院’。”哈哈，在这样的环境下，整理内务也特别舒心惬意。

刚忙完，靖怡就迫不及待地想参观整个校园。她说，最喜欢的是城院图书馆，觉得它很大气、很现代化。她特别喜欢图书馆顶部的设计，认为它浑圆，极具线条美，让人忍不住停下脚步多看几眼。馆内的沙发摆设让人觉得很舒适典雅。靖怡还谨慎小心却又大胆尝试去使用图书馆内的“自助借书系统”和“图书馆公共书目检索系统”，感叹城院生活的便利与高科技。

最后，这个可爱的“新城院人”还不忘要去参观极具欧美复古风情的图书馆咖啡厅。靖怡表示，进入大学后想通过竞选班干和参加学生会工作锻炼自己，拓宽自己的朋友圈，希望自己能继续保持热情，勇敢尝试自己想做的事。（大学生记者 周淑仪）

温情的拍照“老达人”

“小鲜肉”的到来，整个校园又多了一份青春的气息！

校园里，熙熙攘攘的人群中，少不了跟随新生一起报到的家长，他们忙着把大包小包的行李搬进宿舍、收拾床铺，考察学校环境。但一位步履蹒跚、来自西安的老人，却拿着手机忙着四处拍照。

从综合馆、宿舍、教学楼、下沉广场、中心湖到图书馆、行政楼，老人一下子就拍了200多张相片、6个长达20分钟的小视频。当面对好奇的记者时，老人开心地回答道：“孙子考上大学了，我想多拍几张照片给她住院的奶奶看看。”老人还说，“她奶奶看到那么漂亮的校园，肯定会很开心的！” （大学生记者 杨艳艳）

红领巾系你心

在迎新志愿者队伍中，有一群穿着绿色T恤，脖戴红领巾的，格外显眼。他们是城环系志愿者，不停地为新同学跑报名流程、找宿舍，态度热情，服务细致认真。

一位城环系志愿者告诉记者：“一方面，红领巾相当于城环的一个标志，寓意为学生服务，无私奉献，传承美德。另一方面，佩戴红领巾可以使新生感觉很亲切，产生一种归属感。”（大学生记者 唐春莉）“蓝色海洋”的清凉

在迎新来来往往的人群中，只要稍一抬头，便可看见穿着蓝色马甲的人群。

他们或是举着话筒在跟访，或是拿着笔记本在询问，又或是扛着摄影机在捕捉最美的瞬间。他们就是大学生媒体中心的工作人员，为了传播学院迎新消息，营造文化氛围，在炎炎烈日下，不辞辛苦。

你或者又看见另外一些在校道上穿梭的蓝色马甲人群，他们为新生引路、帮忙提行李。他们就是机电系的团学成员，蓝色的马甲上的两个字“机电”显得光彩夺目。

当然，还有计信系的蓝色马甲，同样在人群中显得格外美丽。

这些蓝色的马甲，汇聚成一片蓝色的海洋，在炽热的太阳下，给迎新增添了一阵阵清凉。

（记者 杨惠忠）
