# 喜讯：我校新增5个学士学位授予专业

根据《广东省学位委员会 广东省教育厅关于平台高等学校学士学位授予审核工作的暂行办法》(粤学位[2014]2号)精神和《广东省学位委员会办公室关于做好2017年新增学士学位授予专业备案工作的通知》(粤学位办[2016]40号)要求，我省49所高等学校对166个拟新增学士学位授予专业进行了论证，对2个拟撤销专业报教育部审批，并向省学位办提交了备案材料。

其中，根据广东省学位委员会关于公布2020年新增与撤销学士学位授予专业名单的通知，我校2020年新增5个学士学位授予专业名单，分别为工程管理、视觉传达设计、网络与新媒体、电子商务、音乐表演。至此，我校经教育部批准（备案）的专业共44个，具有学士学位授予权的专业共34个。今年新获得学士学位授予权的专业将从2020届毕业生开始授予学位。
