# 院领导大年初一看望春节值班人员

1月23日（大年初一）上午，城市学院副院长张林在院办、保卫办、总务、后勤相关负责人的陪同下，顶着寒风，冒雨看望坚守岗位的春节值班人员。

张院长先后来到收发室、图书信息大楼、实验中心、配电房、教工餐厅、学生公寓、校外公寓、保卫室等地，看望值班的教职员工们。每到一处，领导都耐心询问大家的工作、身体情况，过年情况，对他们为保障学院假期工作的有序进行和校园安全做出的努力表示感谢和肯定，并向他们派发新年利是，送上真挚的节日祝愿。在保卫室，领导看见在寒风中衣衫单薄的保卫队员，连忙上前询问，叮嘱他们要及时添衣。值班人员看见领导的冒雨前来，都十分开心，并对学院的体贴关怀表示由衷的感激。
