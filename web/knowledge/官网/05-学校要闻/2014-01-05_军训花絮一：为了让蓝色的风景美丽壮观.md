# 军训花絮一：为了让蓝色的风景美丽壮观

由于军训通讯工作的需要，8名军训团记者需要搬运展板至足球场外围，在后勤部一些同学的帮助下他们顺利完成了任务，为开展军训宣传打好了基础。

在教官的口号声中，30位男生小步靠拢，迈着整齐划一的脚步来到学生活动中心的大厅。望着高达两米的铝制展板，同学们不禁倒抽了一口冷气。8块展板，由4人一组的男生们协作搬运。他们根据自己的情况不停变换位置，以求得效率先行。

当女生上前帮忙出力时，男生们异口同声的说：“你们女生不用帮忙了，这关乎男人的尊严！”同学们都忍俊不禁。在他们身上，体现的是教官乐于助人、塑造健康人格的理念。途经自己的连队，留在队里的同学们或者为扛着展板的同学们喊口号加油鼓劲，或者冲上前去帮忙。瞧！前面四个同学调整好自己的着力点，喊着“一二一二”跑步前进。连路上的行人都忍不住为这浩荡的搬运队伍侧目，本来是一个小小的帮助最终演变为越来越大的正能量。前行过程中，他们没有一丝怨言，这沉重的工作虽累人却也充满欢乐。

提前完成任务的同学们开心的告诉记者：“为城院加油，壮哉我大财经！”说话之间，他们已经返回去帮助还未到达目的地的同学。一块展板很重，而再大的困难在团结的力量面前也变得微不足道。王同学俏皮地说：“这个就叫财管3、4班的友谊，人多力量大！”
