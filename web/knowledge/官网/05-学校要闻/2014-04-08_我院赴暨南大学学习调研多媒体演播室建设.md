# 我院赴暨南大学学习调研多媒体演播室建设

4月4日下午，院党委宣传部部长何鹏举教授、文学与传媒系系主任李上文教授等5名五名教师赴暨南大学进行学习和调研，受到暨南大学副校长刘洁生教授、新闻与传播学院副院长张晋升教授、广播新闻系系主任申启武教授等专家领导的热情接待。

调研中，我院深入学习和调研了多媒体演播室建设、新闻学学科建设等方面工作，并参观了相关实验室。暨南大学专家们根据多年来所积累的办学经验，对我院专业建设和实验室建设提出了意见和建议。
