# 学军事技能理论 展当代大学生风采

“同学们辛苦啦！”“为人民服务！”东莞理工学院党委书记周致纳在检阅军训队伍时与学员互致问候。9月28日，东莞理工学院城市学院军训团在学院田径场隆重举行2007级新同学军训阅兵式。

上午九时，42个方阵的学员迈着整齐矫健的步伐，在军训团团旗的引导下，喊着嘹亮的口号，伴随着雄壮的《解放军进行曲》，依次经过主席台，接受检阅。学员们整齐划一的步伐、严整的军容体现出07级新生不怕困难、坚忍不拔的风采。

阅兵式后，军训学生进行了队列、军体拳表演。学员们精神抖擞、步伐整齐、军容严整、口号嘹亮，得到领导嘉宾和全体参训同学的阵阵掌声。

担任承训任务的沙角部队某团团长徐仕伟中校做了军训总结报告，学院党委副书记朱冰宣读了军训先进集体和先进个人名单，院领导为获奖单位颁发了荣誉证书和锦旗。

这次训练是根据《普通高等学校军事科教学大纲》和我院2007教学计划安排的。9月17日开训，历时两周。参训的2500多名新生，被编成14个连，其中男、女生各7个连，每连3个排。每连配备1名指导员（辅导员兼）和3位教官。由中国人民解放军海军沙角部队42名教官承担训练任务。

军训期间，同学们认真学习了队列知识，观看了军事教育电影片。同时，军训团还为同学们进行了反恐防暴、消防、自救互救等方面的训练，邀请校本部领导及专业技术人员作入学教育报告，讲授安全、卫生、心理健康等知识。

为了增强学生对军训的兴趣，从9月18日开始，各连队分批进行素质拓展训练。受训学员分为7个组，每组6个排，每天训练一组。训练是通过“破冰热身”、“智力电网”、“有轨列车”、“核弹危机”、“千人座椅”等游戏活动进行的。素质拓展训练利用自然环境，通过各种精心设计的活动，使学员达到“磨炼意志、陶冶情操、完善人格、熔炼团队”的训练目的。
