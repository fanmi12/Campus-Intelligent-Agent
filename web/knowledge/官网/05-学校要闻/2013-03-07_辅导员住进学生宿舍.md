# 辅导员住进学生宿舍

学生宿舍是学生学习休息的重要场所，也是进行思想政治工作的重要阵地。为加强学生的思想政治工作，及时处理学生宿舍中的突发事件，我院学生处制定了《辅导员宿舍值班制度》。该制度规定，从3月3日开始，每晚要有两名辅导员（一男一女）住进学生宿舍值班。

据悉，值班实行各系辅导员轮班制度，值班时间为每周日晚上至下周四晚上，值班地点在女生宿舍学1栋1A101、男生宿舍学6栋6C101。辅导员在值班期间，要及时处理宿舍区的突发事件，开展学生思想政治教育工作，了解学生的思想生活动态，积极耐心地向学生解释、回答和处理各种问题，解决学生在住宿生活中遇到的实际困难，帮助同学们保持积极、健康向上的生活态度。

学院为辅导员值班室配备了工作登记本，学生处将定期跟进追踪、检查总结值班情况，及时听取辅导员和学生的意见与建议，不断改进学生思政教育工作。
