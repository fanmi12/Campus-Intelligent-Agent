# 新闻中心举行大学生媒体中心成立仪式

经党委宣传部同意，城市学院大学生记者团正式更名为大学生媒体中心。4月17日，新闻中心在行政楼112会议室举行城市学院大学生媒体中心成立仪式。新闻中心主任何鹏举为“大学生媒体中心”授旗。会议为指导老师、各部部长、秘书、记者分别颁发了聘书或记者证。新闻中心、大学生媒体中心的老师与学生记者，团委书记罗文芳，城市学院历届大学生记者团团长及记者代表（校友）参加了会议，共同庆祝大学生媒体中心的正式成立。

据介绍，随着学校办学规模的扩大，宣传任务的增加，以及新媒体效能的强化，参照兄弟院校的做法，记者团的功能和职责已不适应宣传工作的变化与需要了。经党委宣传部同意，将原大学生记者团更名为大学生媒体中心。“中心”下设编辑部、网络摄影部、电视台、广播台。目前，共有记者108人，分别承担新闻采写、节目录制、网络管理、摄影摄像、广播等宣传任务。

《城市学院报》主编唐跃碧老师解读了各部（台）的工作职责与任务，宣读各部（台）负责人的任职名单。

周健老师宣读了《城市学院大学生媒体中心章程》。

原记者团团长周小萍对前一段的工作做了总结。

大学生记者与历届记者团团长、师兄师姐进行了热烈的互动，分享当记者与毕业后的酸甜苦辣。第一任团长张州烨现就职于中山大学东莞研究所，第二任团长张泽勤创办了自己的传媒策划公司，记者杨玲玲、刘晨爽、曾淑娟都事业有成。他们分别用自己的经历介绍了记者工作对离校后工作生活的影响，勉励学妹学弟要充分利用好“记者”这个平台，抓住锻炼的机会，克服兴趣倦怠情绪，用新闻的敏感性和睿智的语言，写出有真情实感的新闻作品，为今后的生活和职业打好铺垫。

何部长代表党委宣传部、罗文芳书记代表院团委，先后在会上肯定了大学生记者的成绩，希望同学们发扬成绩，借助大学生媒体中心这个优秀平台，提升自己，为宣传城市学院，汇聚正能量，传递好声音再立新功。
