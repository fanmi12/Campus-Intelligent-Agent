# 保护环境 你我有责

“改善生态环境，建设绿色虎门，相约碧水蓝天……”，暑假期间，管理系20名大学生在虎门镇开展了一系列的“保护环境，你我有责”为主题的环保义务宣传。

8月15日，他们选择流动客商多的黄河时装城派发传单，先后共发出传单1000多份。这些传单都是同学们自己设计的，正面印有“保护环境，你我有责”的倡议书，背面印有“联合国人类环境宣言”。市民对大学生的宣传行动非常支持，纷纷主动索取传单。8月24日，同学们又参加了由虎门团委、城市学院管理系等单位联合举办的“中科主场，辩论飞扬”辩论赛。8月25日，该系学生还为市民表演了宣传环保的文艺节目。“大学生们能以自身行动，积极投入到环保活动中来，既体现大学生与时俱进的精神风貌，也是对自身能力的一大锻炼和提高”，一位市民称赞说。
