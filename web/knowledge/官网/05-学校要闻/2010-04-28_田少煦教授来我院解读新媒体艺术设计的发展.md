# 田少煦教授来我院解读新媒体艺术设计的发展

4月27日，我院客座教授、深圳大学数字媒体与视觉文化研究所所长田少煦教授来我院做学术讲座，为学生答疑解惑。文学与传媒系近百名师生参加听讲座。

田教授主讲的题目为《新媒体艺术设计的发展》。讲座内容的重点是分析数字媒体专业的产业背景。他说，数字媒体的科技发展趋势是“三网合一”（互联网、通信网、电视网）和“物联网”，数字媒体艺术产业未来发展的领域将十分广泛。

对于许多同学提出的如何处理计算机制图与手工绘图的矛盾，田教授说，任何一种设计的完成都离不开设计师的基本功，手绘与计算机操作并非对立而是互补，同学们要努力打好基础，为今后的设计拓展广阔的空间。

针对数字媒体专业的教学思路，田教授提出了教学的三个层次，一是培养基本的信息素养，二是学习艺术设计的数字化方法，三是加强数字内容相关的专业教学。他希望专业教师要把握最前沿的专业信息，不断学习和提高，模拟业内工作环境的实际操作，让学生以小组为单位完成课题，培养懂理论、能动手、会合作的设计人才。
