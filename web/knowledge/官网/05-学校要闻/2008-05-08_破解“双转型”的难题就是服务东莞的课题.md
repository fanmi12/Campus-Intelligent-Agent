# 破解“双转型”的难题就是服务东莞的课题

“破解东莞经济社会‘双转型’中的难题，就是学院服务东莞的重要课题，广大教职工要从中找课题，做文章，用气力，以实际行动回报社会，求得政府的支持。”5月7日，学院党委中心学习组在315会议室召开“服务东莞”专题研讨会。东莞理工学院副院长、城市学院院长安少华教授在会上作了主题讲话，对“服务”工作做了全面的安排部署。

会议认为，为东莞经济社会发展提供服务，是学院做出的战略决策，是进一步解放思想、践行科学发展观的需要，是教学与科研的需要，也是全校师生广泛接触社会、提高社交活动能力的需要。安院长就如何做好服务工作讲了一些原则性的意见。他说，我们现在既有能力又有实力，应该为市委、市政府做一些事情。要做好服务东莞的工作，全体教职工必须强化三种意识，落实四条措施，正确处理五个关系，常抓不懈，科学安排，务求实效，善始善终。要树立教育质量是学校生命线的意识，人才兴校是强校之路的意识，服务东莞求支持的意识，机构要健全，人员要落实，经费要到位，精力要保证。院系要分别成立社会服务办公室，统一协调服务事项。各系部要结合专业教学设立研究机构。要借助名牌大学的力量和市委、市政府职能部门的参与，共同做好服务工作，实现互利双赢。从“双转型”中寻找服务课题，提高服务档次。组织师生深入社区，了解民生民情，提供智力和技术等方面的服务。加强管理与指导，做到服务经费专款专用。教职工不得借服务之名，谋取一己私利。正确处理好教学、科研、服务三者的关系，全面规划，有机结合，互为促进。服务工作要注重经济效益和社会效益，使服务单位满意，让学生受益，让市民高兴。

党委书记朱志德副研究员就解放思想大讨论活动第二阶段的工作做了安排。他说，各总支（直属支部）要深入发动群众，紧密联系城院的实际，摆查阻碍学院发展的软肋硬伤和瓶颈，集中全院教职员工的大智大慧，共商城院和谐稳定、健康发展的良策。

学院有关专家学者及院机关相关部门负责人应邀参加了会议，其中有9位专家在会上发言。

副院长张林博士主持会议。
