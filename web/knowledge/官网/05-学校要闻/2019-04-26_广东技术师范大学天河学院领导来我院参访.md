# 广东技术师范大学天河学院领导来我院参访

4月25日上午，广东技术师范大学天河学院张武华副校长一行六人莅临我院进行访问交流。学院院长王卫平、创新创业学院常务副院长孔增强等领导热情接并陪同来宾参观了校史展览馆、大学生创业孵化基地等。

宾主双方就创新创业工作进行了座谈。孔增强介绍了我院“双创”学院的运行机制、教育模式及特色项目等。双方就如何孵化学生团队、打造优秀双创导师团队、产学研建设等方面进行了深入交流。

张武华副校长对我院创新创业工作给予了高度评价，特别是创新创业学院组织架构、大学生创业孵化基地的管理和创业精英班等印象深刻，希望今后两校能加强创新创业工作沟通交流，共同发展。
