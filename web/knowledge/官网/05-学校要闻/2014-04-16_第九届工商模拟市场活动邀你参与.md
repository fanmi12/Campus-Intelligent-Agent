# 第九届工商模拟市场活动邀你参与

记者从管理系工商模拟市场管理委员会获悉，我院第九届工商模拟市场将于4月21日开市。本次工模以“青春梦想 创业共享”为主题，在同学们中宣传创业，让同学们了解创业知识，真实体验创业过程。工商模拟市场划分为美食区、烧烤区、综合区、校友创新创业展示区四大经营区和志愿摊位区，共120个摊位；另设办公服务处、市场监督投诉处、接待处等三大市场管理处。目前已经召开了摊主大会、摊位竞投大会，开展了创业计划书大赛活动。

据了解，本次工模作为创业文化月的主打活动，是我院校庆十周年系列庆典活动之一，特别设置的“校友创新创业展示区”，集中展示我院校友近十年来在创业创新方面的成果，工模期间，还将邀请校友参与相关创业沙龙、举行专题讲座。工模还将开展“微博转发有奖活动”。

“创业文化月”的相关活动还包括：企业家访谈，创业沙龙，创业培训，创业计划书大赛等，目前准备工作正在如火如荼地进行。

附件 第九届工商模拟市场时间安排

营业时间：4月21日——4月25日

开幕时间：4月21日17:00闭幕时间：4月25日 20:00举办地点

学五学六中间的校道（打印店门前）、学六羽毛球场、学六篮球场、学六学七中间的校道

闭幕地点：学六篮球场隔壁的空地
