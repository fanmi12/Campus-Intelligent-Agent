# “享受经典”读书征文大赛颁奖仪式在我院举行

5月21日，2009东莞第五届读书节暨东莞理工学院城市学院第四届读书节“享受经典”读书征文大赛颁奖仪式，在学术报告厅隆重举行。图书信息中心主任陈伟研究馆员、副主任钟兴恭教授，可园博物馆副馆长叶家仔先生，以及本次大赛赞助商东莞广仁驾校代表黄志明先生出席会议并为获奖者颁奖。

本次征文大赛主题为纪念建国六十周年讴歌改革开放的伟大成就，题材为阅读“红色经典”书籍写出读后感。大赛主办单位城市学院图书信息中心共收到来自东莞市各界参赛作品近200份，经专家组评选，财经系08级会计学钟相黎同学《花魂》等20篇文章获奖。

据悉，征文共设置20个奖项。
