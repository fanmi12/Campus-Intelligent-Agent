# 城市学院召开纪念建党八十五周年暨表彰大会

6月29日，东莞理工学院城市学院党委在学院大礼堂召开大会，隆重纪念中国共产党成立85周年，为132名新党员举行入党宣誓仪式，表彰2005—2006学年度先进基层党组织和优秀共产党员。

大会在庄严的国歌声中开始。会议举行别开生面的新党员入党宣誓、老党员重温入党誓词的仪式。新老党员面对党旗，在工作人员的领誓下宣读入党誓词。这铮铮誓言，是我院新老党员的共同心声，体现我院全体党员对中国共产党的热爱与忠诚。

学院党委副书记朱冰在会上宣读了中共东莞理工学院城市学院党委关于表彰2005—2006学年度先进基层党组织、优秀共产党员的决定，决定授予机关二支部、管理系党支部为先进基层党组织荣誉称号，授予张林、何鹏举、黄阳辉、洪燕霞、刘芳、林晓、鞠成晓、理阳阳、董阿妮、林蓉（学生）10位同志为优秀共产党员荣誉称号。

东莞理工学院党委副书记、纪委书记黄碧莲，城市学院院长安少华教授为先进党支部和优秀共产党员颁发荣誉证书。

学院党委书记朱志德在纪念大会上发表了重要讲话。他首先代表学院党委，向学院各级党组织和奋斗在各个岗位的全体共产党员，致以节日的问候和崇高的敬意，向今天刚刚宣誓的新党员以及受到表彰的先进集体与个人，表示热烈的祝贺。他在回顾我们党85年的奋斗历程时指出，85年的历史巨变充分证明：没有共产党就没有新中国，没有党的领导就没有中国的富强和中华民族的伟大复兴，中国共产党不愧为一个伟大的党、光荣的党、正确的党。我们必须接受党的绝对领导，把学院做大做强。如何实现学院“双代会”确定的“十一五”发展规划时，朱志德对全体党员和各支部提出了五点要求：一、必须始终不渝地把思想建设放在首位，坚持马克思主义理论的指导，自觉地以邓小平理论、“三个代表”重要思想和科学发展观武装头脑，指导工作。全体党员要树立社会主义荣辱观，要以“八荣八耻”指导我们的日常行为。要从培养社会主义的合格建设者和可靠接班人的要求出发，全面贯彻落实“育人为本，德育为先”的方针，自觉地把育人工作融入到教育教学的各个环节中去，努力形成“全员育人、全程育人、全方位育人”的良好氛围。二、必须切实加强基层党组织建设；三、必须大力倡导优良学风，努力提高业务水平；四、必须始终不渝地把维护学院稳定放在压倒一切的位置；五、必须始终不渝地坚持党的群众路线，重视发挥广大师生的主动性、积极性和创造性，切实维护师生的合法权益，不断改善师生的学习、工作和生活条件，关心师生的进步与成长，全心全意依靠广大师生员工办好学校。
