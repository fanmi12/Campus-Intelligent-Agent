# 我院参加考研复试的学生均被录取

日前，广东商学院，太原理工大学相继传来消息，我院黄科、赵振廷等6名同学获得研究生入学资格。

据悉，计算机与信息科学系赵振廷同学被“211大学”太原理工大学信号与信息处理专业录取。文学与传媒系黄科同学参加广东商学院思想政治教育专业复试时，专业面试、笔试成绩及综合排名均获第一名，综合表现获得广东商学院复试测评导师组一致好评，被录取为该校研究生。计算机与信息科学系的肖巍同学被太原科技大学检测技术与自动化装置专业录取，财经系的袁凤兰同学被江西师范大学心理学专业录取，文学与传媒系的林润培同学被广西师范学院古代文献学专业录取，计算机与信息科学系的姚小凤同学被重庆邮电大学信号与信息处理专业录取。

据了解，这次共有6名同学参加复试，录取率为100%，录取人数为历年之最。
