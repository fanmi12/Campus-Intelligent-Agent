# 我校召开第十六次学生代表大会

高举旗帜凝聚青春力量，砥砺奋进身担时代使命。6月2日，我校第十六次学生代表大会在学术报告厅召开。

校领导王卫平、章德胜、黄兢、周庆出席了大会。各二级学院、行政教辅部门领导，东莞兄弟院校学生会干部，第十五届校学生会主席团和学生代表、列席代表参加了会议。

大会在庄严肃穆的国歌中正式开幕。

章德胜书记为大会致辞。他说，在纪念五四运动100周年大会上，习近平总书记强调：“新时代的青年要树立远大理想、要热爱伟大祖国、要担当时代责任、要勇于砥砺奋斗、要练就过硬本领、要锤炼品德修为。”他要求新一届学生会加强思想建设，提升政治水平；加强组织建设，提升管理水平；加强作风建设，提升服务水平。希望全校各级学生组织和广大学生干部继续发扬“五四”精神，不负广大师生的期待，团结拼搏、开拓创新，努力使我校学生会工作再上新台阶。

大会听取、审议并表决通过了《东莞理工学院城市学院第十五届学生会工作报告》、《东莞理工学院城市学院第十六次学生代表大会提案工作报告》。报告全面总结了校学生会在过去一年引领同学思想、建设校园文化等方面取得的工作成果。

经过大会选举，王超凡当选新一届校学生会主席，许世龙、庄丹瑜、叶芯瑜、邱建伟、吴童当选副主席。
