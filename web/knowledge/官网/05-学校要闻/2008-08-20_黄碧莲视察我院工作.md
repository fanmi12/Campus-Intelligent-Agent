# 黄碧莲视察我院工作

8月18日，东莞理工学院党委副书记黄碧莲和东莞理工学院审计监察处处长邓耀林来我院视察工作，东莞理工学院副院长、城市学院院长安少华，城市学院党委书记朱志德、副书记朱冰、副院长张林等向黄副书记汇报了学院近期的工作。

黄副书记非常关心我院暑期开工的基础设施改造工程建设情况。她不顾炎热酷暑，亲自到东升学生公寓、樟村学生公寓工地视察。当看到两个工地施工接近尾声，安全和质量都没有问题时，黄副书记非常高兴。同时，她还细致地查看了公寓家具的质量，并就空间分割和排水隔热等问题提出了建议。

她对学院领导和施工负责人说，学校基础设施建设是民心工程，一定要注意施工质量。通过这次改造，城市学院基础建设又上了一个新的台阶，要顺势而上，促进学院各项工作协调发展。
