# 金贸系打造“无手机课堂”

手机，在走进每个人的生活的同时，也走进了大学课堂，不仅一定程度地影响了正常的课堂教学秩序，破坏了良好的班风与学风，也影响了一部分同学课堂的学习质量。但这样被诟病的“微信声、视频声、游戏声，声声不息”的手机课堂景象，将在我院金贸系终结，“笔记声、提问声、读书声，声声入耳”又将成为课堂上一道靓丽的景致。

新学期伊始，我院金贸系经过精心筹备的“无手机课堂”，在2015级金融学3、4班进行试点。

2月20日上午，开学第一天。在试点班级上，记者看到，同学们上课前把自己的手机关机或调到静音，依次按照学号放到手机袋里。老师也根据手机袋的放置情况，进行考勤记录。课堂上，因为没有手机，同学们的专注力提升了不少，提问和回答问题的积极性明显增加了很多，课堂互动和氛围也活跃了许多。班长黄梓杰同学课后告诉记者，“没有手机，课堂参与度高了，老师的提问也有了更多的回应，时间也过得快多了”。

据金贸系党总支副书记刘军介绍，加强学风教风建设将是金贸系新学期的一项重点工作，打造“无手机课堂”便是重要的举措之一。通过“无手机课堂”，维持良好的课堂教学秩序，营造浓郁的学习氛围，提高学生的学习积极性。同时也通过提高学生的学习积极性来“倒逼”教师加强备课工作，提高教学质量，增强师生互动交流，活跃课堂氛围，进而提升教育教学和人才培养质量。目前，“无手机课堂”主要这两个班级进行试点，通过实践检验和进行完善后，将在全系进行推广。

链接：无手机课堂，指高校要求学生上课前要把手机交出来，等下了课，大家再把自己的手机拿走，主要是避免学生在听课的时候玩手机，影响课堂秩序。
