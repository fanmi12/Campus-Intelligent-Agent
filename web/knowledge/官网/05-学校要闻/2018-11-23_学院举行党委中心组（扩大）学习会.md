# 学院举行党委中心组（扩大）学习会

11月22日下午，学院党委中心组扩大学习会在行政楼112会议室召开。广东省高校思想政治教育研究会副理事长、华南理工大学博士生导师刘社欣教授应邀作了学习贯彻习近平总书记视察广东重要讲话精神的主题讲座。

学院领导、党委委员、各单位负责人、党总支（直属支部）书记、党总支副书记、全体辅导员、思政部全体教师和学生代表参加了学习会。院党委书记、院长王卫平主持会议。

刘社欣教授以“背景?情景?前景——学习贯彻习近平总书记视察广东重要讲话精神”为题，传达解读了习近平总书记视察广东重要讲话精神。

刘社欣教授强调，习近平总书记视察广东重要讲话是站在改革开放40周年的重要历史节点，从历史和现实相贯通、国际和国内相关联、现实和实践相结合的宽广视野，对新时代广东改革开放再出发提出了明确要求。

刘社欣教授深刻分析了习近平总书记视察广东的历史背景、重要情景、光明前景。他从党的十八大以来习近平总书记两次视察广东工作的重要讲话、从改革开放四十周年、当前国际形势等背景，从习近平总书记视察广东工作中的亮点、看点、焦点和重点等情景，引导大家带着感情、带着责任、带着使命去更好地学习习近平总书记视察广东重要讲话精神。

会上，王卫平书记代表学院向刘社欣教授颁发了辅导员成长导师聘书。
