# 应对竞争发展 树立理想信念

针对当代中国人尤其是大学生共同面对的理想信念问题，全国著名的政治思想教育专家、中山大学博士生导师郑永廷教授于5月17日在学院大礼堂，为我院师生做了一场关于“竞争发展与理想信念”的精彩讲学。

郑永廷教授首先列举了当代人面临的三个发展上的现实问题，这就是适应性、取向性、和选择性，即面对多变难知所向，面对多样难知所选，面对复杂难知所解，总的表现是迷惘与困惑。接着郑教授分析了产生这三大现实问题的原因。他指出，一是经济原因，经济全球化，市场经济的激烈竞争产生的压力和推动力带来了经济的高速发展，同时也使有些领导、有些部门产生重形象工程、数字工程、轻教育工程、灵魂工程的倾向。商品经济原则渗透到政治生活领域，产生了官场的钱权交易、市场的缺德交易和学场的钱学交易现象。二是政治原因，民主的发展，人们自主权的增强,一方面提高了人的主体性，另一方面出现了不会用和乱用自主权的现象。三是文化原因，科学文化特别是信息化的高度发展，一方面促进了学习与创造，拓宽了知识的容量和范围,另一方面引发了“快餐式”的学习研究与发展异化现象。三大社会因素产生的积极作用巨大，促进了社会发展,但它们引发的不良后果也不容忽视。这些不良后果带来的表现有：＂三场交易＂中的腐败，缺德分子的自我败坏；人们普遍存在急躁、浮躁、烦躁和焦躁的情绪；精神疾病的增加和自杀行为的增多。郑永廷教授说，为了应对这种情况，党中央采取了三个学科的战略应对措施。一是推行了哲学社会科学建设和人的思想道德建设战略；二是推行思想政治教育学科建设战略；三是推行人才学建设的战略。当代大学生应主动应对时代提出的挑战，树立自己正确的理想信念。只有这样，才能在复杂多变、多元难辨的形势下，变压力为动力，化困惑为睿智，保持清醒的头脑和正确的人生坐标，肩负起时代的使命。

郑永廷教授的讲学受到广大师生的欢迎。院长安少华教授、党委副书记朱冰、学生处处长章德胜、新闻中心主任何鹏举和师生们一起听取了讲座，讲座由党委书记朱志德主持。

新闻链接：郑永廷教授曾经担任过武汉大学和中山大学的党委副书记，现为中山大学教授、博士生导师，全国高等学校思想政治教育研究会副会长，全国教育科学规划领导小组德育组专家，教育部社政司主办的《思想理论教育导刊》顾问，全国高等学校思想政治教育研究会会刊《思想教育研究》副主任编委，曾多次参加国家教委、教育部主持的德育教育研讨工作，参加了中共中央国务院16号文件的调研和起草工作，先后担任武汉大学、清华大学、上海交通大学等高校兼职教授。
