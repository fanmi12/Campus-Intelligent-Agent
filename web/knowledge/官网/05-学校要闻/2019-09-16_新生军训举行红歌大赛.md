# 新生军训举行红歌大赛

9月15日晚，经过8天艰苦军训后，2019级新生们终于迎来了期待已久的红歌大赛。

大赛当晚，军训团15个连队在运动场两侧席地而坐，拉歌声此起彼伏。在学校艺术团声乐队洪欣同学带来的《大鱼》的歌声中，红歌大赛拉开了序幕。

大赛中，每个连队热情高涨，唱出了各自的特色。首先出战的一连——艺术学院，以浑厚的歌声和动人的舞姿瞬间抓住了大家的眼球，赢得了一阵阵热烈的掌声。

五连以一首《走向复兴》，唱出了中国人民在新的历史时期面向未来、不怕艰苦、走向民族复兴的一种信念。

十连选曲《我爱你，中国》，他们深情而高亢地歌唱出：“我爱你，中国。我要把美好的青春献给你。”为中华人民共和国成立七十周年献礼！

Kpop韩流舞队带来热舞《fire》、《love shot》，将比赛推上向新的高潮。各连队旗手挥舞着连旗绕场奔跑，在欢呼声中度过了一个难忘的夜晚。
