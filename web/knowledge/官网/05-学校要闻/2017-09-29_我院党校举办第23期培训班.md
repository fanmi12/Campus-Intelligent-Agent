# 我院党校举办第23期培训班

9月28日下午，我院党校第23期入党发展对象培训班顺利开班。学院院长、党委书记王卫平同志为195名学员作了开班动员讲话，并为培训班上了第一堂党课。党务工作部副部长叶凯贞主持了开班仪式。

王卫平书记指出，党校培训是入党积极分子向党组织积极靠拢的重要教育过程，希望学员们珍惜学习机会，学好理论，做好实践，争取早日入党。他通过阐述延安精神等党的优良传统，鼓励学员自觉弘扬践行社会主义核心价值观，不忘初心，坚定不移地跟党走，发奋读书，努力有所作为，在实现中华民族复兴的伟大征程中成就自己有信念、有梦想、有奋斗、有奉献的精彩人生。

党委副书记章德胜围绕入党条件及入党动机作了专题讲座，要求学员端正入党动机，不断学习、不断提高，把思想追求落实到行动当中。党委委员、副院长黄兢志以高考的发展变化为切入点，讲述了中国共产党改革创新的发展史。党委委员、院办主任杜鹏举就如何争做先锋，成为模范学生党员作专题报告。

据介绍，本期培训班包括专题讲座、交流讨论、理论考核等多个环节，还将组织开展《中国共产党章程》等文件学习活动。
