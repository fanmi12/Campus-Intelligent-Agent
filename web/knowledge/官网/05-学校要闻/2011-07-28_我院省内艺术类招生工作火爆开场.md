# 我院省内艺术类招生工作火爆开场

7月27日，记者从学院招生办获悉，我院省内艺术类录取工作目前正在紧张进行当中。据统计数据显示，今年我院省内艺术类招生持续火爆，文化成绩上2A线69人，其中上重本线33人。表演（音乐表演）专业第一志愿出档率超计划数55%，出档最高分481分，超重本院校艺术类录取分数线达130分。

据悉，我院省内本科普通专业录取工作将于7月31日正式拉开序幕。
