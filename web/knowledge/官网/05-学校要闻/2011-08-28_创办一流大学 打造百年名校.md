# 创办一流大学 打造百年名校

城市学院中层干部暑期读书班会场

周致纳、杨晓西、安少华、麦照容出席读书班，并做重要讲话

全体与会代表合影留念8月26日，我院在虎门镇举办中层干部暑期读书班，组织中层干部学习胡锦涛的“七一”讲话精神，安排部署新学期的工作。

在两天的学习活动中，与会人员参观了城市学院新校区；参加东莞理工学院中层干部（扩大）暑期读书班报告会，听取了东莞理工学院思政部吕有云博士学习胡锦涛“七一”讲话的辅导报告，联系学院实际进行了座谈讨论；东莞理工学院领导周致纳、杨晓西、安少华，董事长麦照容做大会讲话；学院领导分别安排部署新学期的工作。

读书班由党委书记朱志德主持。

新校区：校园呈现现代大学气息

参观城市学院新校区，是读书班的重要内容之一。据介绍，3000名建筑工人经过半年紧张的施工，建成了一所高标准、高质量、设施设备配套齐全完善的现代大学，被东莞市委书记刘志庚称赞为“东莞速度”。目前，开学准备工作就绪。呈现在与会人员面前的景象是高楼鳞次栉比错落有致，花草树木青翠浓郁，回廊亭阁曲径通幽，湖光山色相映成趣。“新校区的建成，为创办特色鲜明、一流的本科独立学院奠定了坚实的基础”。机电系系主任黄健求教授表示。

新起点：软件建设任重而道远

院长安少华在讲话中表示，鸿发集团投巨资建设新校区，为我们搭建了新起点的平台，同时也表明软件建设的任务更重、要求更高了。他说，新的工作起点体现在：董事长提出了要创办一流大学，打造百年名校的办学奋斗目标；新校区要执行市委、市政府提出的“城市学院要实行董事会领导下的院长负责制”的批示精神，将完全按照独立学院的办学机制运作；积极应对“一校两区”的新情况，确保新校区4000多名新生、老校区7000多名老生学习、生活秩序的正常；今年要力求学士学位授权单位评估工作顺利通过；并做好准备迎接2013年教学水平的工作评估。

新希望：有信心做大做强城市学院

会上，鸿发集团总裁、城市学院董事长麦照容做了重要讲话，介绍鸿发集团的发展历史与现状，向与会人员提出新的希望与要求。计信系主任牛熠博士在讨论发言中认为，麦董事长的讲话，使大家统一了认识，树立了信心，明确了努力的方向。

麦董事长表示，鸿发人决心经过几代人的努力，将城市学院打造成百年名校、一流的本科独立学院。当他谈到办学的一些理念时，会场报以热烈的掌声表示赞同。他的办学理念主要包括：树立国际视野，把城市学院办成国际化、多元化、高层次的现代大学；依靠专家教授办学治校，大力引进高端人才，挑选优秀教师出国深造，用事业、待遇、感情留住人才；注重校企合作，实行资源共享、优势互补，广泛开展产学研活动。

新发展：城院的明天会更加美好

安院长在分析高等教育形势时指出，当前由于生源逐年下降，势必出现高校之间优胜劣汰、强强联合、重新“洗牌”的竞争态势。我们要居安思危，抢先发展，占据教育“高地”。为此，一是要开源节流将单位和个人的绩效挂钩，消除大锅饭；二是要取得好的办学效益，增强学院的发展后劲，增加教师的幸福指数；三是要坚持以人为本，用科学发展观建设和管理好学校。依托学院处于东莞市中心城区的区位优势，打造以城市学院为重点的寮步“教育链”。麦董事长还提出，当前主要任务是把学院做大，多申办一些东莞急需的专业如土木工程专业；明年新校区要扩大本科生招生数量。要与理工学院携手共进，实现错位发展。
