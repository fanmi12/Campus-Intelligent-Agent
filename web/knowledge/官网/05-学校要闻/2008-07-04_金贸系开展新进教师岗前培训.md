# 金贸系开展新进教师岗前培训

为了进一步充实教师队伍，改善生师比结构，金贸系今年从众多应聘者中择优引进了四名高素质教师。根据学院统一安排，金贸系于2008年7月3日上午在6号楼308开展了新进教师岗前培训，岗前培训由金贸系主任米双红教授主持。

培训从新教师试教开始。新教师试讲后，系主任米双红教授、系党总支书记龙卫洋博士等老教师分别从教学态度、教学效果、教学内容、教学方法等方面进行了点评。然后，米双红主任、龙卫洋书记向新教师介绍了金贸系的专业设置、师资队伍、学生工作、党建工作、教师工作职责等情况。

新教师一致认为通过这样的岗前培训，进一步了解了系情，掌握了更多的授课技巧，获益匪浅，对今后更好地开展教学工作、融入城市学院将起到很大的作用。
