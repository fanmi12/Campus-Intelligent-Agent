# 图书科技信息中心工程进行初检

4月28日，东莞市城建工程管理局组织华南理工设计院、青岛建设集团公司、惠州市工程建设监理有限公司，对我院图书科技信息中心大楼工程进行验收前的现场检查。我院环境与基建办、图书信息中心、总务处、保卫办等部门负责人陪同检查。

检查组对图书科技信息中心大楼1-13层的主体建筑进行了全面的检查，并提出了很多专业性的意见和建议。东莞市城建工程管理局项目负责人要求，施工单位要结合检查组提出的意见，尽快落实相关工作，积极做好配套工程的调试工作。
