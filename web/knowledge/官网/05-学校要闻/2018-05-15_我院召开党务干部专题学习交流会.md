# 我院召开党务干部专题学习交流会

5月11日下午，我院召开学院党务干部专题学习交流会，专题学习习近平总书记在北京大学师生座谈会上的重要讲话以及在纪念马克思诞辰200周年大会上的重要讲话精神。会议由党务工作部副部长叶凯贞主持，各院系(部)党总支副书记参加了会议。

叶凯贞副部长指出，习近平总书记在北京大学师生座谈会上的重要讲话，是对办学规律、教书育人规律、学生成长规律的高度凝练，也是习近平新时代高等教育思想和青年思想的进一步拓展。习近平总书记在纪念马克思诞辰200周年大会上，深情缅怀了马克思伟大光辉的一生，深刻阐释了马克思主义的科学体系、丰富内涵及其巨大贡献，全面总结了马克思主义中国化的壮阔历程和丰硕成果，明确提出了新时代继续推进马克思主义中国化的要求。

会议指出，党总支副书记作为党务干部和思政工作者，要深入学习领会习近平总书记重要讲话精神的丰富内涵和精神实质，要在“学习上深一步、认识上高一筹、实践上先一着”，以上率下，推动重要讲话精神深入广大师生的思想中。要求大家在实践中不断地学习，在学习中不断地实践，做一个实践的思考者、思考的实践者。

会议还对“书记项目”的结题及申报、“共产党员先锋岗”创建活动、“牢记时代使命、书写时代华章”主题党日活动、教师微党课比赛以及基层党组织量化考核等5月份党建的重点工作进行部署。
