# 阳光网推出系列报道助力我院专业建设和招生宣传

6月27日起，东莞主流网络媒体——东莞阳光网在其教育频道，大力主推我院专业建设及招生宣传系列报道，助力我院专业建设与招生宣传工作，取得了良好的传播效应。

在6月25日推出《城市学院举行2018年毕业典礼4857名毕业生开始新征程》后，6月27日东莞阳光网精心制作标题、图文并茂，又连续推出了《“饭堂啥都有 打菜手不抖”：城市学院这个招生广告要火》《城院电子工程与智能制造学院：学生拿奖拿到手软》《城市学院城市与环境科学系：专业实力强 活动多到“爆”》《城市学院文学与传媒系：文以载道，相编成志》系列报道，为我院专业建设及招生宣传打call。

据悉，东莞阳光网近两天还将对我院其他院系及相关专业进行系列报道，敬请关注。东莞阳光网网址：http://edu.sun0769.com/。
