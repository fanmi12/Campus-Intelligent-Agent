# 金融与贸易系领导看望暑期顶岗实习学生

7月17日，金融与贸易系系主任米双红教授、系党总支书记龙卫洋博士冒着酷暑分别到相关单位看望了本系暑期顶岗实习的学生。

在与同学们的交流中，米主任和龙书记详细询问了大家在实践期间的生活和工作上的情况，对同学们表示了亲切的慰问和良好的祝愿，勉励大家秉承“学而知不足”的校训，按照实习岗位的要求，苦练基本功，克服工作困难，出色完成实习任务。领导的关心给参加实习的同学们带来了巨大的鼓舞，他们纷纷表示一定不辜负系里的殷切期望，珍惜机会，以更饱满的激情，更昂扬的斗志交一份圆满的答卷。

据悉，今年暑期，金融与贸易系共选派了200多名学生到中国人保东莞分公司、中国人寿东莞分公司、中宏人寿东莞分公司、东莞证券、世纪和富实业投资股份有限公司等单位进行为期一月的顶岗实习。
