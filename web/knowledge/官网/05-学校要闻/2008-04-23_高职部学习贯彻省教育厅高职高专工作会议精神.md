# 高职部学习贯彻省教育厅高职高专工作会议精神

4月18日，高职部召开全体老师会议，学习贯彻广东省教育厅最近召开的高职高专工作会议精神。

会上，院督学、高职部主任林世俊教授重申了高职部工作的十六字方针：“守好摊子，抓紧建设，拓展功能，做出亮点”，并提出现阶段的中心工作一是做好学生管理工作，二是抓紧部门建设。

林教授指出，本次会议信息量大，内容专业，理论性强，思路创新，全体教师要围绕高职高专教育的性质、目标、培养模式、评估要求和08年省教育厅的部署开展工作。
