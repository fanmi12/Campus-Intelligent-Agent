# 我院管理系黄岳钧老师又一课题获民政部立项

11月5日，民政部2014年“慈善事业创新和发展”理论研究部级课题立项评审结果揭晓，我院黄岳钧老师申报的项目“慈善事业中第三方的独立性及其保障体系研究”确认为自选课题获准予以立项。

据悉，黄岳钧老师至今已有两个课题获民政部立项。两个课题具有较强的相关性，均是对社会组织第三方评估机制进行深入研究，为国家制定相关政策提供理论参考。

据黄老师介绍，他今年3月立项的课题“社会组织第三方评估机制中的风险因素及对策研究”目前已进入结题阶段，已向国家民政部递交了结题报告，评审结果预计于12月初公布。本次再获相关课题在一定程度上表明了民政部对上述结题报告的认可，资料显示一年2次获得民政部研究课题的情况较为罕见。
