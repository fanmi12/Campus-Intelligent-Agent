# 东莞理工学院城市学院2006年工作要点（摘要）

2006年是“十一五”的开局之年，我院工作的指导思想是：坚持以邓小平理论和“三个代表”重要思想为指导，全面落实科学发展观，学习、贯彻党的十六大和十六届四中、五中全会精神，在东莞理工学院党委、行政的直接领导和关心支持下，围绕建设具有地方特色、省内一流、追求卓越的教学型本科独立学院的奋斗目标，求真务实、与时俱进、抓住机遇、开拓创新，进一步深化内部管理体制改革，全面提高教育教学质量，培养高素质的应用型人才，推进学院的跨越式发展，为地方经济建设和社会发展作出新的贡献。

2006年的工作要点是：强化一个中心，凸现两大亮点，提高三个水平，制定四个规划，做好五项工作，促进学院教育教学水平的全面提高。

强化一个中心：在理工学院的领导下，借鉴学习校本部办学和迎评促建经验，进一步强化以教学工作为中心，不断提高教学质量，进一步加强教风、学风、校风建设。加强开放式办学，加强教学督导力度，完善教学基本文件的制定，做好特色专业、实验室建设，重点课程建设，开展评教、评学活动，深入开展社会实践和教学实习工作。

凸现两大亮点：1、凸现与企业合作办学，与行业协会兴办具有地方特色专业的亮点；2、凸现服务东莞走进城市社区，文化下乡，文化演出活动宣传亮点。

提高三个水平：1、提高管理服务水平，加强机关服务意识；2、提高后勤服务和安全保障服务水平，构建和谐校园；3、提高应对突发事件处置水平，做到预案明确，操作性强，防患未然。

制定四个规划：1、学院发展战略规划；2、师资队伍建设和学科建设规划；3、校园基本建设规划；4、校园文化建设规划。通过上述规划的制定和宣传，使全院教职工牢固树立“机不可失，时不再来”的机遇意识；“逆水行舟，不进则退”的竞争意识；“有所为，有所不为”的战略发展意识；“争创一流，追求卓越”的品牌意识；“向外争取支持，向内盘活存量”的资源意识。

做好五项工作：一是加强教风、学风、校风建设。要通过“三风”建设，振奋精神，鼓舞士气，锻炼一支团结务实、开拓创新、精悍高效、善于带领全院师生谋事业发展，富有凝聚力、向心力和团队精神的干部队伍；塑造一支师德高尚、业务精良、纪律严明、“学为人师、行为世范”的教师队伍；营造一个健康文明、安全和谐、奋发上进、生动活泼的治学环境。

二是进一步完善院内人事分配制度，岗位管理体制和考核奖励机制的改革深化，进一步理顺院系两级管理体系，做到责、权、利统一，人权、事权、财权统一，着重提高科学管理水平和工作效率。

三是自觉接受理工学院的领导和业务指导，认真做好学科建设，确保教学工作的中心地位。加强调研，加强规划，认真做好我院的学科建设工作，提升我院的教学科研水平，加快我院特色专业的建设。同时，做好今年的招生和新生入学工作。

四是进一步调整完善基层党支部的设置，特别是系一级学生党支部的建立。设立党委办公室，整合党务工作资源，理顺发展党员程序，加大在学生和青年教工中发展党员的力度。建立健全学生思想政治工作保障体系，加强大学生的思想政治教育力度。推进党风廉政建设工作。加强新闻宣传工作，提升学院的知名度和美誉度，打造城市学院知名品牌。出版城市学院学报和院报发行工作，充分利用网络、宣传栏、广播站等平台，加强教职员工之间，师生之间的信息沟通，继续做好工、青、妇工作，成立教师委员会，开展丰富多彩的校园文体活动。

五是加快学院的基础设施建设，年内建成多功能报告厅、学生二期公寓，争取图书馆工程立项。配合校本部认真做好第七届大运会的协办工作。
