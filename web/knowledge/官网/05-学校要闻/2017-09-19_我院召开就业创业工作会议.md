# 我院召开就业创业工作会议

9月18日下午，我院在招聘大厅召开了就业创业工作会议暨就业指导教研活动。各院系书记、副书记、辅导员，就业指导教研室成员以及招生与就业处全体人员参加了会议。黄兢副院长、院长助理林江龙出席会议，会议由招生就业处处长孔增强主持。

就业中心主任江小卫总结了2017届毕业生就业工作，分析了当前就业工作面临的新形势、新问题，对做好2018届毕业生就业创业工作作出了安排。他提出，各院系和就业工作人员要积极拓宽就业渠道，切实提高就业指导服务能力，努力把学院就业工作提升到一个新水平。

聂振明老师结合目前学院大学生创业孵化基地的建设和第二批项目入孵的申报工作，动员大家为我院学子创业之路打通“最后一公里”。他希望同学们利用学院提供的良好条件，把创业孵化基地作为放飞梦想的地方，尽显青春风采！

会上，就业指导教研室召开本学期首场就业指导教研活动，以提升我院系部老师在就业指导方面的能力。

孔增强处长在总结中，希望大家牢固树立全院“一盘棋”的思想，各单位要全面动员，上下齐心，多措并举，形成推进就业创业工作的合力，持续提高我院毕业生的就业创业质量。
