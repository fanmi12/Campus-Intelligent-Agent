# 新的学期  新的气象

9月1日，经过一个暑期的休整，全院师生又以饱满的热情和积极的心态开始了新学期的学习生活。同学们坐在宽敞明亮的教室里，心情感到格外的高兴和舒畅。他们表示，一定要加倍的用功和努力，争取好的成绩。

据悉，这一天任课教师无一缺席，学生到课率达到99.1%，教材到位率达到100%。学生食宿井然有序。

第一节上课铃声刚响过，院党委书记朱志德副研究员、副院长程发良教授、党委副书记朱冰、副院长张林博士、院办主任王玉、教务处处长邓成良教授、学生处处长章德胜副教授，便早早来到教学区进行巡视。院领导们分为两个小组，特别视察了新课室的使用情况，对良好的课堂秩序表示满意。
