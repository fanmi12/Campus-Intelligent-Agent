# 东莞市第一人民法院在我院举行巡回审判

11月17日，东莞市第一人民法院寮步法庭巡回审判在我院模拟法庭实验室举行。这是东莞市第一人民法院首次将真实的民事案件放在高校进行审判。

副院长高香林教授、教务处处长牛熠教授、政法系主任刘杰教授等老师与政法系2013级、2014级法学专业同学旁听了本次审判。

本次审判的是一起客运合同纠纷案件。法庭经过开庭审理、举证质证，真实展现了合议庭审判民事案件的全过程。

东莞市第一人民法院黄春梅科长也充分肯定了活动的积极意义，认为本次巡回审判活动的开展，一方面可以帮助同学们提高对法学专业实践的认识，另一方面也是一次法治建设工作和高校法学教学实践模式的探索。
