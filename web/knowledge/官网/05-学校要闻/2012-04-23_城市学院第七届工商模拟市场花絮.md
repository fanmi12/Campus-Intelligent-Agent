# 城市学院第七届工商模拟市场花絮

此刻，不只是生意

明明是摆摊做生意，为何志愿者的标志会挂在摊位前？一番询问下，得知档主是台湾商人，他认为社会是用爱来填充的，无时无刻，我们都可以奉献爱。因此这次工模摆摊，除了自己销售产品外，他专门跟我院的志愿队合作，为我院志愿队提供产品，让志愿队进行义卖。赚取的钱会捐到慈善机构，为社会奉献爱心。所以，在工模的大街小道上，我们会惊奇地看见绿衣天使捧着商品在销售。他们不为多大的利润，只为小小的奉献。

志愿者的标志挂在摊前，此刻，不只是生意。

“杜甫继续忙”

最近杜甫很忙很忙，真的很忙。做完机车骑士又要登月，走完T台还得拯救地球……好不容易觅得一个小长假，又得继续忙了。为什么呢？因为啊，咱们的城院工模到了啊。

瞧瞧，这西装笔挺的可不正是咱们最近的大忙人“杜甫”同志？这是到咱们工模干嘛来了啊？啊，原来您老也要搞工模啊？！

可不是吗？这店名儿就是“杜甫搞工模”呢。诸位亲来瞧瞧咱杜甫老先生的店儿卖的什么呢？这个小盆栽满可爱的哇。恩，这手工DIY的小猪也好可爱啊。杜甫老先生的店儿还挺受欢迎的啊，光顾的同学可不少呢。老先生您就别愁着一张脸啦，继续忙吧。

DIY，自己动手更精彩

DIY作为一种新兴的艺术品，被广大的年轻人所喜欢，在工模市场里，你同样可以找到它的足迹。手工油画摊主说：“这些全都是要靠自己制作的画，拿来做礼物，显得更加有心意，收礼物的人会更开心；如果是自己用，自己制作会更有成就感和自豪感，意义也大不一样了。这样的美事，你还犹豫什么？”

更有创意的要数“城院首套纪念明信片”了，摊主将城市学院新老校区有代表性的美景制作成整套精美的明信片。摊主告诉记者：“这些明信片都是我们几个自己拍照、设计和制作的，既有纪念价值又为我们城院做了宣传，一举两得！”

美味蛋糕20种，心动有木有？

自古美女爱美食，瞧瞧10号摊位前面美女如云，是什么东西这么有吸引力，连美女也倾倒。走近一看，一个个小巧诱人的蛋糕隔着透明橱柜发出热情的邀请。贝菲蛋糕美食的摊主一连推出了20多种口味，添加水果、巧克力、果冻等，造型可人，有谁不心动呢？金贸系的尹同学刚买了一个芝士口味的，刚吃了一口就忍不住夸道：“很赞，甜而不腻，还想再试试其他口味。”

动起来吧！“城院市场”

走进工模市场，一时间傻眼了，人潮涌涌，彩色的摊位，来往的人群拎着大包小包。看！那里几个穿着花裙的漂亮女生也顾不上形象了，一只手拿着羊肉串往嘴里塞去，令一只手拿着盒墨鱼丸。人群里，一个个低头吃着，走着。这里是热闹叫卖着，那里吃得正香着。

此时的校园多了几分味道，吃的，穿的，用的，应有尽有。名副其实的“市场”中的校园，校园中的“市场”。当然，在学生中的“市场”卖吃的历来都是最受欢迎的，看来我们还是受不了美食的诱惑。

大学生，商家共聚一堂，想尽办法，各显神通，绞尽脑汁的趣味摊位名字，各种商业技巧，精美的传单，优惠券，买多送多，各种商业绝招一个比一个高深。城院学子，商业头脑并不逊呢。动起来吧！“城院市场”。

风雨中，90后伤得起

令人期待已久的工模终于开幕啦！意气风发的90后早已将一切安排妥当，等待着“顾客”的光临。

可能是工模过热，惹得老天爷妒忌。工模才刚开始，老天爷的脸说变就变，下起雨来，而且连续下了4天。这回真的刺痛了所有经营者的神经。但办法总比困难多，即使是下大暴雨，摊主们也决不放弃销售的脚步。于是“上门推销”和“微博淘宝”就成了新型推销方式。摊主们冒着雨，捏着大包小袋的产品来到各个宿舍销售，或者是通过微博联络达成协议后，亲自送货上门。当她们被问到这样做有何感受的时候，她们笑着说：“也没办法，是有点辛苦，但也很开心，至少还可以体会多一种销售方式所带来的乐趣。”

雨停后，“老板们”又忙碌起来，他们迎客的热情有增无减，服务更周到，工模现场再次热闹非凡。

美味雪糕，炸着吃

城院第七届“工模”市场上，美食遍地开花，花样层出不穷。这不，远远就有一个摊位的招牌写着“炸雪糕”，咦！我就纳闷了，雪糕不都是放在冰箱里的吗？但现在却把它放进油中，你能确定它不会融化，从固体变为液体？

只见摊主娴熟地拿出半盒的雪糕，沾上各种配料，然后放入油中炸。仅一会儿，一个金黄金黄的炸雪糕就成形了，摊主再用镊子把它夹起来，放进小杯子里，吃上一口，外脆里甜，美味的哩！

我忍不住问摊主这是怎么做的，怎么雪糕遇热都不会融化呢？摊主嘿嘿一笑说是商业机密，不方便透露。但她还是告诉我，炸雪糕的原理是利用了二者熔点的不同。

如此美味的雪糕，如此特别的吃法，相信你也舍不得错过吧！
