# 我院四教师荣获东莞市优秀教育工作者和优秀教师称号

日前，东莞市教育局发布了《关于认定2017年东莞市优秀教师和优秀教育工作者的决定》。我院章德胜同志被认定为东莞市优秀教育工作者，宋秋敏、肖文锋和周书楠同志被认定为东莞市优秀教师。

我院自建院以来，高度重视教师队伍建设。经过多年的努力建设，已拥有一支教学经验丰富、研发能力较强、德才兼备、爱岗敬业的教师队伍，更是涌现出来了一批富有“激情、智慧、奉献”精神的优秀教师和优秀教育工作者，为我院和东莞市高等教育事业的建设与发展做出了重要的贡献。
