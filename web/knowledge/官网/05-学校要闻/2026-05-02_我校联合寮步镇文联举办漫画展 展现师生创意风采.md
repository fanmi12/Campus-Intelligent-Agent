# 我校联合寮步镇文联举办漫画展 展现师生创意风采

由东莞市寮步镇文联、东莞城市学院与寮步镇郭冶动漫名家工作室联合主办的“妙笔传神”郭冶肖像漫画暨师生作品展，在东莞市寮步镇文联艺术展览厅隆重开幕。恰逢春末夏初，这场汇聚了名家智慧与师生创意的艺术盛宴，为东莞的文化生活增添了一抹亮丽的色彩。

名家领衔，搭建艺术交流新高地

作为本次活动的核心人物，著名肖像漫画家、东莞城市学院特聘教授郭冶表示：“肖像漫画是幽默快乐的世界语言。本次展览不仅是个人教学与创作成果的积累，更是为了通过‘名家引领、师生共进’的模式，推动动漫艺术在本土的普及与传承。”

展览得到了寮步镇宣传教育文体旅游办公室、寮步镇文化服务中心等单位的大力支持。寮步镇党委委员尹柳嫦，东莞城市学院校长李振华、执行校长方伟华等领导及嘉宾出席了开幕式，并对工作室在挖掘青年动漫人才、丰富学校“第三课堂”实践方面所做出的努力给予了高度评价

五大版块，呈现跨界艺术魅力

本次展览精心策划了五大主题版块，展期将持续至2026年6月28日。观众在现场不仅能欣赏到郭冶教授多年来的获奖及出版精品，还能看到工作室师生的创新之作。

展览内容涵盖广泛，包括

文化科技艺术名人：以幽默笔触勾勒各界名流风骨；

革命先烈及先贤：用漫画语言致敬历史，传承红色基因；

体育影视娱乐明星：展现流行文化的鲜活魅力；

外国各界名人：跨越国界的文化对话；

中华传统与本土IP：特别展示了结合广东非遗文化及横坑历史名人IP的师生绘本作品，实现了传统美德与现代动漫的完美融合。

据悉，为了深化艺术教育功能，展览期间还将特别推出“两周一次小学漫画导览与美育互动”活动。郭冶教授将携手李佩蒽等骨干教师及学生代表，亲自为青少年观众进行导览与互动教学，旨在通过肖像漫画这一独特的艺术形式，激发学生的创意思维，让艺术审美潜移默化地浸润人心。
