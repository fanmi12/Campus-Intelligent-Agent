# 开好三个会议 确保开学紧张有序

学院领导深入各系部、处室检查指导工作。

学生在大厅排队注册

近日，学院领导对开学工作提出明确要求，全院近期要开好三个会议（学院党政联席会议，各系部、机关处室的教师及工作人员会议，学生主题班会），教育师生员工集中思想，振奋精神，将节日的快乐转化为动力，以全新的姿态投入到新的学习、工作与生活之中去。

24日，学院召开党政联席会议，专题研究开学准备工作，提出全院要开好三个会议，确保学生、教师、教材百分之百到位，开学准备工作要周全细致、紧张有序，实现新学期开门红。

近日来，各系部、各处室相继召开会议，迅速传达贯彻学院党政联席会议精神，安排本单位的开学准备工作。教务处会同实验中心和后勤部门检查课室和教学实验设备，并做好教材课本发放工作，确保学生上课有新书。据悉，全院所需的398种课材已到位395种，其余3种将在上课之前发到学生手中。教务处还要求工作人员、各系部教学秘书坚持全日制值班，随时处置不适事情。学生处召开全处工作人员及辅导员会议，对学生的主题班会做出了安排部署，要求班会主题鲜明，重点突出，讲求实效。

为使开学准备工作落到实处，院领导分别深入所分管的部门和联系的系部进行检查指导。据学院办公室综合情况，各部门准备工作充分。
