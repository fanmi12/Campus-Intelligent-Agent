# 学院田径运动会进入倒计时

今天，距校运会开幕只有4天了！参赛运动员和参加开幕式的演职人员，利用最后的时间进行训练与彩排，争取创造最佳的运动成绩。

据体育教学部主任赵涛副教授介绍，运动会开幕式将鸣放礼炮，举行雄伟壮观的运动员入场式、各具特色的方阵表演和精彩的嘉年华音乐演出，展现我院师生奋发上进的精神风貌，文明和谐的校园文化。
