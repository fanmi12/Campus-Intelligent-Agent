# 我校举行2019级新生军训汇报表演

9月20日上午，我校举行2019级新生军训汇报表演。91676部队汤剑飞上校、聂峰中校，校领导王卫平、高香林、黄兢、周庆、林江龙和军训团全体教官、指导员，各单位负责人，以及2019级新生参加了军训汇报表演。

在运动场上，军乐激昂，王卫平校长在军训团长聂峰的陪同下检阅了受训新生队伍。

迎团旗后，受训新生分列式接受检阅。国旗护卫方队、军训团团旗和2019级新生组成的15个连队方阵，在教官带领下，依次走过主席台，接受检阅。同学们英姿飒爽，迈着矫健的步伐，排着整齐的队列，向大家展示了无限的青春活力和奋发向上的精神风貌。

汇报表演过程中，受训新生进行了格斗术、盾牌反恐防暴、军体拳、匕首操、海军旗语等表演，赢得了观众热烈的掌声。

值得一提的是，今年汇报表演还增设了反恐止爆演习，接近真实、精彩的模拟演习，获得了大家的喝彩。

军训团团长聂峰作了军训总结讲话。他说，军训期间，同学们的进步和取得的成绩有目共睹。同学们充分学习并传承了人民军队“不怕苦、不怕累”的优良作风，培养了良好的团队意识和组织纪律观念。这些成果将有利于同学们成为德智体美劳全面发展的社会主义建设者和接班人，成为对国家、社会和人民有用的新一代青年。

后勤保卫处处长王锦锋宣读了《关于表彰2019级新生军训先进集体及先进个人的决定》。大会对在军训期间表现突出、成绩优秀的集体和个人进行了表彰。王卫平、高香林、黄兢、周庆等校领导分别为受表彰集体和个人进行了颁奖。
