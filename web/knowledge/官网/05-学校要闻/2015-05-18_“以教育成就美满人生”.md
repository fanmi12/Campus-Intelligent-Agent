# “以教育成就美满人生”

5月14日，台湾佛光大学总校长杨朝祥教授应邀到我院作演讲。杨教授在演讲中提出的“以教育成就美满人生”的教育观点，受到我院300多名与会教师的认同。

杨朝祥教授认为，对青年大学生要进行“生命教育、生活教育、生涯教育”。通过生命教育，使学生适才适所，正确处理群己关系，让生命发光发亮；通过生活教育，使学生思想有品德、生活有品味，做一个有品质的职员；通过生涯教育，使学生“专业、志业、乐业。”

在谈到生命的意义时，杨朝祥教授认为，一要延续自己的生命，二要珍惜自己的生命，三要提升生命的质量，四要升华生命的意义，五要尊重他人的生命，六要爱护大自然的生命。

杨教授在“三生教育”实践中倡导，青年学生要做好事、说好话、存好心；给人欢喜，给人信心，给人希望，给人方便；追求自己的兴趣，勿好高骛远，勿急功近利；唯有埋头，才能出头；终身学习，智能更新；聪明好不如读书好，读书好不如学问好，学问好不如做事好，做事好不如做人好；活在当下，珍惜拥有。

党委书记王卫平主持演讲会。他介绍说，杨朝祥教授是台湾教育翘楚。担任佛光大学校长期间，潜身研究全人教育，身体力行推动“三生”教育。他今天的演讲，有深度、有高度，观点新颖独到，值得我们借鉴学习。
