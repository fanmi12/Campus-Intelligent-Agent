# 思政课评估专家考察我院思政教学设施

6月6日上午，广东省高等学校思想政治理论课建设评估专家先后在我院主持召开学生代表座谈会，查阅和核实支撑材料，实地考察思政部教学设备和设施等办公条件。

在学生代表座谈会中，专家们听取了学生代表关于思政部在教学、管理、学生培养等方面的意见。学生代表积极发言，如实汇报，气氛热烈融洽。通过座谈，专家们认为，我院思政部教师责任心强、教学方法得当，青年教师精神面貌好，学生对思政课教学满意度较高。

座谈会后，评估专家们实地考察了思政部办公室、会议室、教师备课室、图书资料室、思政宣传栏。专家组成员仔细询问了教师的课时量和学生课外作业及实践的完成情况。在图书资料室，专家们向值班学生了解图书的借阅和勤工俭学的有关情况。在思政部办公室，专家们认真查阅思想政治理论课程建设评估支撑材料。他们严格按照评估各项指标体系，逐一查看每一盒材料，并不时与思政部主任何鹏举、副主任石志民等老师提问，力求更全面了解我院思政课建设工作。

通过实地考察，评估专家组对我院思政部的办公条件和教学设备设施的建设和利用给予了肯定。
