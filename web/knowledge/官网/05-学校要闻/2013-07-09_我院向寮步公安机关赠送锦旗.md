# 我院向寮步公安机关赠送锦旗

7月3日，我院向东莞市公安局寮步公安分局刑警大队、泉塘派出所和横坑派出所赠送 “莞邑卫士、人民公仆”的锦旗，对警务人员为城市学院治安工作的支持与指导表示感谢。

据总务处副处长陈辉介绍，近年来，寮步公安分局有关部门不断强化城市学院校园及周边社会治安治理工作，在学校内设立了警务室，并加大巡视力度，使师生的安全感和满意度大幅提升，受到学院及广大师生的认可与肯定。
