# “城院是我们对孩子期望的延续”

今天，城院格外热闹，不少远道而来的家长正在休息区看着行李，静静地等待着孩子们完成报到手续。

来自湛江的陈阿姨一家昨晚出发今天早上7点多到达学院。一旁的行李箱里，装的不单是物品，更有家长的期望。她边瞅着热闹的校园，边摇着扇子念叨：“这学校环境还真不错，希望孩子尽快适应，学会独立自主。”

在综合馆阶梯旁，一位戴黑色太阳帽的青年正等待办理报到手续的弟弟。“我弟什么都好，就是太内向，怕他交不到朋友。”原来，他弟弟从来没有远离过家，也没有住过校，性格内向，这难免让哥哥有些担忧，“希望学校的各种活动能让他性格变得开朗。”

来自东莞虎门的林叔叔则充满期待：“我很希望儿子能去考研，比别人更胜一筹，将来好找工作。”他还表示，城院的环境让他很放心，相信学校的氛围会激励儿子奋发向上，找到适合自己发展的方向。

每个新生，从到城院报到的这一天起，便携带着每位家长的殷切期望，在这片热土上放飞梦想，从这里扬帆远航！ （大学生记者 崔飞虹）

不负时光年年岁岁花相似，岁岁年年人不同。

转眼间，又是城院一年新生开学季！学校的各个角落都是家长和充满了朝气的大一新生。不知道你们注意到没有，无论在哪，都会有工作人员或学生志愿者为新生及家长指路，帮提东西。这些勤劳的“小蜜蜂们”恪尽职守，用这种默默帮助的方式来欢迎师弟师妹。

计信系的一位师姐告诉记者，为了迎接新生，她们7点半就集合。她们的工作就是为小鲜肉们检查文件，是否开封、再添上名字、发放宿舍钥匙等。为了岗位上时时刻刻都有人，她们轮流着吃饭，辛苦自不必说，但大家觉得很开心。 (大学生记者 隋燕竹）“城院邮局”的情怀

今天，校园处处人员攒动，综合馆内更是热闹非凡。在人群中，一个红色邮箱“城院邮局”吸引了许多人的眼球。

这个以感恩和梦想为主题的“城院邮局”是由管理系学生会设计的。在管理系新生报到处，可免费领取我院原创手绘明信片，提供给前来报道的新生书写心愿与祝福。这些明信片会在迎新结束后，统一免费邮寄到新生们想寄的对象手里。

活动负责人表示：“建立邮箱，是希望以这种形式去迎接他们的到来，感受管理系学生会为学生服务的宗旨。新生们也可以借此表达对父母、朋友的思念和祝福，分享到我们城院的风采和情怀。” （大学生记者 罗飞依）“我们家出了第一个大学生”

大学新生报到，总是家庭的一件大事，全家老小的“总动员”也不在少数。

在家长休息区，来自梅州五华的李爷爷和老伴坐在一起，手上摇着小扇子，等候报到的孙子。见到记者，老人家十分热情地招呼坐下来纳凉。谈到对城院的第一印象时，李爷爷乐呵呵地说，“环境很好，学生很有礼貌又很热心。刚刚我和老伴坐在阶梯那里，有个小姑娘跟我招呼，‘爷爷奶奶，这里坐、这里坐’，特别的好，还给我们送来矿泉水。”

谈及对孙子的希望时，奶奶有些动情，“这是我们家第一个大学生。我们那个年代都没读几年书，他爸妈的文化水平也不高，希望他能完成好自己的学业，成为一个有用的人就好，也希望他在学校里，像今天的志愿者一般，多做一些为他人着想的事，多做一些为学校贡献的事。”（大学生记者 蓝楠）
