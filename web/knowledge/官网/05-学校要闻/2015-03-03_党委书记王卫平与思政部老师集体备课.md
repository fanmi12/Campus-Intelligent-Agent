# 党委书记王卫平与思政部老师集体备课

新学期伊始，党委书记王卫平教授参加思政部集体备课会，并为该部教师做了辅导报告。

会上，王书记还解读了《关于进一步加强和改进新形势下高校宣传思想工作的意见》（中办发[2015]59号）文件精神，传达了广东省今年寒假期间召开的教育工作会议精神。

王书记要求，思政部教师要从政治和全局高度开展思想政治理论课教学工作，讲课内容要以教育部规范教材为依据；要结合城院学生思想实际、学科专业特点、大学生关注的现实问题进行讲授；要以正确的价值观引领大学生构筑中国梦，以积极的人生观鼓励大学生对中国精神的追求，以科学的世界观帮助大学生深刻理解中国特色社会主义理论的内涵，坚定信仰，树立跟着共产党走中国特色社会主义道路的信心与决心。

王书记还指出，要进一步加强对教师、辅导员的思想政治与教学业务的培训工作，积极推进思政课课程的稳步建设，按照应用型人才培养的要求全面提高大学生的思想素养，培养艰苦奋斗的作风。
