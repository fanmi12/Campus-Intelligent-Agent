# 艺术系举办教师教学音乐会

11月22日、24日，艺术系在图书信息中心小剧场分别举办了林伟伦、康慧丽老师的个人教学音乐会。副院长程发良，党委副书记朱冰等领导观看了音乐会。

参与演出的分别来自林伟伦老师和康慧丽老师所任教的艺术系08级、09级、10级的全体学生。11月22日的流行歌曲演唱音乐会场面火爆、座无虚席，不少观众是在站立中聆听了近三个小时的音乐会。11月24日的民族、美声歌曲演唱音乐会格调优雅、赏心悦目，十多首中外经典歌曲给现场观众带来了高雅艺术的享受。

据艺术系主任邓星明教授反映，两场音乐会的成功举办，不仅展示了教师的教学功底，同时也为学生提供了宝贵的演出机会和平台。
