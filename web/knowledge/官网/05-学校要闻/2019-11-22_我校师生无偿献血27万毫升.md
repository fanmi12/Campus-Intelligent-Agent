# 我校师生无偿献血27万毫升

11月19日-21日，由东莞市中心血站联合校团委主办的“献热血，致青春”无偿献血活动，共吸引了我校1321名师生参与，共无偿献血270800毫升。

“每次开展献血活动，我们城院师生都会积极参与，大家献血热情非常高。” 来自城环学院的志愿者许锦峰同学说，此次献血活动也得到师生们的积极响应。活动现场，记者看到前来报名献血的师生络绎不绝，填写信息表、排队验血、献血……有条不紊，给初冬增添了浓浓的暖意。来自金贸学院的谢素娇同学表示：“第一次来献血，感到很紧张，但为了能献上一次爱心，我还是感到无比的自豪与开心。”
