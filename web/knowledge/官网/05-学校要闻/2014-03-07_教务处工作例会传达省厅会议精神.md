# 教务处工作例会传达省厅会议精神

3月3日下午教务处在行政楼212会议室召开了本学期第二次工作例会。高香林副院长出席了会议，牛熠处长主持会议。

会上，牛熠处长首先传达了省教育厅教学工作会议精神，要求与会人员要认真学习，在工作中贯彻落实。随后，教务处各科室分别汇报了开学两周来的教学、开学初补考、学生退伍复学、专插本、制度清理等工作开展情况，并对开展的质量工程等项目中期检查、青年教师讲课比赛等相关工作作了部署。

牛熠处长还就教务处的管理服务水平和工作效率进行强调，他要求大家要注意工作纪律，严格遵守因公因私请假汇报制度，不迟到不早退；秉承“服务为先、管理并重”的工作理念，按照“公平、公正、规范、高效”的原则开展好教学管理服务工作。

高香林副院长在会上肯定了教务处的工作以及取得的成绩，勉励大家要各司其职，继续努力工作，力争教学管理工作与服务水平再上新的台阶。
