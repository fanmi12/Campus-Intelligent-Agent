# 院领导参加文传系和思政部的学习交流会

4月10日下午，院党委书记王卫平、副院长高香林一起参加了文传系、思政部分别组织的“学习教育、听取意见”学习交流会。二个系（部）的全体党员、干部以及民主党派、无党派人士代表参加了会议。

学习交流会上，王卫平对文传系、思政部等二个党总支高度重视、认真组织开展党的群众路线教育实践活动予以肯定。认为二个系（部）制定的教育实践活动实施方案符合上级文件要求，贴近本单位实际，除了完成“规定动作”，还规划了各具特色的“自选动作”，各环节工作考虑较细致。王卫平强调，要正确认识在独立学院开展党的群众路线教育实践活动的重要性与必要性，准确把握活动总要求，结合本部门实际，重点开展 “三风”建设。即建设好进一步管理与服务作风、教风和学风，共建良好的校风。院领导深入基层参加“学习教育、听取意见”活动,旨在疏通诉求表达渠道，加强与教职工的真诚沟通，使党群、干群关系更加贴近，力求把存在的问题找全查细、找准查透。

学习交流会上，王卫平和高香林认真倾听教职工发言，并记录反映的焦点问题，还对教职工关注的有关问题现场作答。

学习交流会充满民主、和谐和轻松的气氛，与会人员踊跃发言，围绕开展党的群众路线教育实践活动、转变干部作风、加强教风与学风建设、提高教学质量、稳定教师队伍、改善后勤服务等方面问题发表了各自的意见与建议。
