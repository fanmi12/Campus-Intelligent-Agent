# 文传系师生参观吴昌硕国画作品展

10月31日，文学与传媒系组织平面设计和数字媒体艺术两个专业的学生一行40人赴莞城美术馆参观我国国画大师吴昌硕作品展。

此次展览的近百件作品，荟萃了浙江省博物馆藏品的精华，内容涵盖了吴昌硕早、中、晚各个艺术发展阶段的书画、篆刻及诗文等多个艺术品类，也是广东省乃至岭南地区近二十年来规模最大、质量最高的个人艺术特展。这次观摩，对学生来说是一次绝好的亲炙大师佳作、感受传统艺术精神魅力、集欣赏与学习于一体的机会。

期间，同学们还在莞城图书馆报告厅听取了关于吴昌硕生平以及绘画特点的学术讲座。
