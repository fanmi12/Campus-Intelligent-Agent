# 深圳证券交易所来我院举办证券知识讲座

7月5日下午，“深交所投资者行为分析及交易监管”知识讲座在我院学术报告厅举行。这次活动是由深圳证券交易所和我院金贸系联合举办的讲座邀请了深圳证券交易所教育中心经理黄祖鹏、投资者教育中心徐良平总监、会员管理部助理经理马睿思、综合研究所博士熊伟、市场监察部朱亦周等专家作为主讲嘉宾。

高香林副院长出席讲座并致辞。他希望同学们在本次与专业知识紧密联系的讲座中，有所收获，能进一步了解证券交易知识，并积极参与互动。

徐良平总监讲解了深交所投资教育中心的规模及分管方向，介绍深交所教育中心作为普及投资知识的作用。他表示，投教中心为投资者提供教育产品、特色服务，受到投资者的欢迎和认可，也能可满足广大学生的需求。

黄祖鹏经理以深交所教育中心的“呼叫易、互动易”两个板块进行演示，分析了深交所的结构和功能。他还向同学们介绍学习证券知识的多种渠道。

马睿思助理经理介绍了交易制度设计中追求确定性、有效性、流动性的设计理念。她表示，投资者适当性管理是证券交易中重视的板块，是对于投资者保护的措施。马睿思助理经理关于证券交易品种及方式等知识的精彩讲述，也让同学们收获良多。

市场监察部朱亦周以自身投资经历为例，生动形象地讲述了理性投资的重要性，呼吁同学们“投资要从理性交易做起”。他还通过投资市场案例分析，具体分析了合规意识、风险意识，对同学们进行了风险意识教育。

金贸系主任米双红表示，通过此次讲座不仅丰富了同学们的专业知识，也为作为未来投资者的同学们开拓了证券投资思路，对证券市场有了更深刻的理解。
