# 学院召开教学工作例会扩大会议

4月25日，学院在315会议室召开教学工作例会扩大会议，院长杨敏林、副院长高香林，院督学陈丁堂出席会议。院办、教务处、学生处负责人与各系部主任参加会议。

教务处处长邓成良教授主持会议。

会上，学生处副处长陈建新分析了2012年的招生形势。

教务处相关负责人传达了广东省本科院校教务处长会议精神，布置了期中教学检查工作。据悉，本次教学检查的重点是：2012届本科生的毕业论文（设计）；上学期课程考试试卷和实验教学工作。

高香林副院长就教学管理、毕业实习、新校区实验室建设等工作向各系部主任分别提出了具体要求。

院长杨敏林教授在讲话中指出，本学期开学以来全院整体教学秩序良好，各项管理工作进展顺利。现阶段全院的主要任务是做好以教学为中心的各项工作，确保平稳过渡，过渡是必然，平稳是关键。我们的每一项工作，都要严格按照高等教育的规律办事，要以人为本。要充分发挥体制机制优势，提高工作效率，促进办学质量和管理水平的稳步提高。
