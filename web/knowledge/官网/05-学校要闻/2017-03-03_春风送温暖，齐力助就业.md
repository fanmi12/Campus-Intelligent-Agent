# 春风送温暖，齐力助就业

继2月25日成功协办“智聚联科，智造未来”2017年东莞春季大型中高端人才招聘会后，3月2日，我院招生就业处又举行了计信系与机电系联合专场招聘会，打响了我院就业服务工作——“春风送温暖，齐力助就业”活动的第一炮。这也是我院招聘大厅落成后举行的第一场招聘会，19家参会企业提供了近300个就业岗位。

当日，市人力资源局寮步分局也派出工作人员到招聘会，进行大学生就业创业政策宣传、解读，并对我院努力搭建校企合作平台所做的努力表示赞赏。

据了解，我院2017届共有本科毕业生4894人。招生就业处将与各院系共同努力，搜集招聘信息，拓展就业渠道，不定期举办各种专场招聘会，提供更多更好的就业岗位，促进毕业生充分就业。

此外，3月9日，招生就业处还将与寮步镇民营科技局联合举办 “寮步镇‘倍增计划’行动—－东莞理工学院城市学院人才专场招聘会”。
