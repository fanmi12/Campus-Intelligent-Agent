# 大学生艺术团为“新莞人”倾情演出

与会领导接见演职人员6月28日夜晚，雨后初霁，凉风习习。为加强校企之间的联系，丰富新莞人的业余文化生活，城市学院艺术团到诺基亚公司，为员工们奉献了一场主题为 “服务东莞，走进企业”的文艺晚会。

东莞理工学院副院长、城市学院院长安少华教授，南城区党委书记谢锦波，南城区副区长张建良，东莞团市委宣传部部长李胜堂，东莞团市委宣传部副部长梁建阳，城市学院党委书记朱志德，城市学院副院长程发良教授，学院党委副书记朱冰、副院长张林专程到诺基亚厂区观看了演出。

学院党委副书记朱冰、诺基亚东莞分公司副总经理暨伟东分别致辞，表达校企双方对举行此次活动的真诚意愿。朱冰副书记说，城市学院一直坚持“立足东莞，走进社区，走进企业，服务东莞”的办学理念，大学生进企业演出既增进了学生对企业的了解，又加深了学院与企业的联系，促进了学院与企业、学校与社区的合作。诺基亚全球享有盛名，又是东莞最大的外商投资出口企业，有着良好的企业形象和很高的产品声誉。这次演出，一定能为今后的校企合作打下基础。

一曲嘹亮高亢的女声二重唱《踏歌起舞》，拉开了晚会的序幕。整台晚会既有民族舞蹈，又有反映现实生活的喜剧小品，受到了企业员工的欢迎。

他们说，大学生到企业来演出，为我们的业余生活增添了新的乐趣，让我们得到了一次高雅的艺术享受。希望大学生多到我们中间来，这样的大学生，我们欢迎。
