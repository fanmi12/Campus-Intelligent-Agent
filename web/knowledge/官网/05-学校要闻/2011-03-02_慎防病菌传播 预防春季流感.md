# 慎防病菌传播  预防春季流感

每年的二、三月份气候变暖，细菌、病毒等微生物繁殖加快，加上气候变化无常，早晚温差较大，导致人的抵抗力下降，正是流感、麻疹、肝炎、霍乱、痢疾等传染病的多发时间，这些病毒细菌，主要通过呼吸道唾沫传播，人与人的直接密切接触传播。开学以来，每天到院医务所就诊的人数明显的增加，多为发热、咽痛、频繁咳嗽等感冒症状病人。医务所提醒广大师生要做好防护措施，如接种疫苗；多运动，提高自身免疫力、合理搭配饮食；在日常生活中，要勤洗手，注意保暖，保持个人和环境卫生；室内常通风，尽量避免到人多拥挤的公共场所；一旦出现感冒症状，应及时就医。
