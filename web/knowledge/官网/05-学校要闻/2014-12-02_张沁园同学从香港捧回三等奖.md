# 张沁园同学从香港捧回三等奖

艺术系2011级表演（音乐表演）专业张沁园同学，在专业老师徐婷婷的鼓励和指导下，参加了2014年“李斯特纪念奖”香港-国际钢琴公开赛，分别获得东莞赛区二等奖、香港总决赛三等奖。

据指导老师徐婷婷介绍，比赛前夕，师生二人共同商定了适合张沁园同学弹奏技术的曲目，并且每天坚持练琴5至6个小时。她采用分段练习的方法，将整首曲目拆分练习。熟练之后，她又将自己每天练习的曲目录下来，和网上的录音进行比对，以求达到更好的效果。
