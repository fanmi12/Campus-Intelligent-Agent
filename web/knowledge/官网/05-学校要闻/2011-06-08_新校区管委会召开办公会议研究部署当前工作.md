# 新校区管委会召开办公会议研究部署当前工作

6月7日，新校区管委会办公会议在新校区筹建办会议室召开。城市学院院长安少华，城市学院董事黎建烨，城市学院党委书记朱志德，新校区管委会领导出席了会议。

据悉，本次会议决定设立综合、人事、教务、学生工作、财务、后勤六个临时机构，其工作范围涉及行政、人事、教学、思想政治、宣传教育、财务、后勤保障等常态化管理的各个方面。会议还宣布了各部主要负责人的聘任名单，安院长就新校区管委会当前的工作做了重要讲话。他指出，成立新校区管委会的目的，是为了使新校区管理到位、责任到人、效率提高。各部要尽快开展工作，明确分工，责任到人，完善制度。暑假之前，要制订出迎新、军训、生活、交通、保卫等工作的预备方案。对新校区的新进教职工要展开岗前培训。加强与东莞理工学院、城市学院老校区、寮步镇政府及周边村委会的联系。力争用2-3年的时间，使新校区形成良好的学风、教风及校风，处处呈现新风貌。充分利用和发挥好新机制的作用，让师生员工看到新的希望，使学院得到新发展。

党委书记朱志德在会上强调，新校区党群工作要同步进行，狠抓落实。

副院长、新校区管委会主任杨敏林在会上要求，新校区各部要尽快落实人员及岗位职责，科学分工，力促各项工作步入正常轨道。他宣布，每周一的上午为新校区管委会办公例会时间。

城市学院董事黎建烨表示，城市学院实行董事会领导下的院长负责制，新老校区“两位一体”都是城市学院，实行统一的领导和管理，现任院长负总责，分管领导负直接责任。大家作为承前启后的开拓者，要主动工作，通盘考虑，整体推进，把好的作风带到新校区，让工作向新校区延伸，使管理更加完善规范，实现新老校区的协调发展。
