# 黄健求、黄广伟老师获两项国家实用新型专利

近日，我院机电系黄健求教授、黄广伟老师研发的皮革用切割刀片、双头皮革切割刀片通过了国家知识产权局专利局审核，获得国家实用新型专利，并于2012年10月31日获得公开授权，专利号分别为：ZL201220171999.2、ZL201220173162.1切割刀片在皮革加工行业中应用广泛，刀片磨损严重影响其使用寿命。而此两款切割刀片正是通过结构上的创新，提高了其使用寿命及利用效率，从而降低了皮革的生产成本，具有较强的创新性与实用性。
