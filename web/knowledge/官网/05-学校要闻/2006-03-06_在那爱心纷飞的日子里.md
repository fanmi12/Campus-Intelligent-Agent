# 在那爱心纷飞的日子里

美食当前，如何抵挡

下午两点半，活动正式开始。整个活动场地已被同学们装饰得格外亮丽。气球是必不可少的装饰品，彩绸、彩灯、各具特色的招牌也让场地增色不少。什么“计信系美食街”、“财经步行街”、“国色天香”、“如果‘爱’”，应有尽有。各个摊位都摆上了自己的招牌菜，招徕过往的顾客。摊位里，做买卖的同学正忙得不亦乐乎；摊位外，络绎不绝的人们也大饱口福。几十个摊位几乎包揽了五湖四海的菜色，有“椰香玉米”、“潮汕鱼蛋”、“梅州腌面”、“砵仔糕”等等。各种特色小吃不但外形独树风格，口味也酸甜苦辣，各不相同。人们接踵磨肩，手里拿着一串串、一碗碗热气腾腾的美食在游玩，眼里还盯着摊位上的各种美食。仿佛在说：今天我要消灭掉所有美食不可！到了晚上人们的热度有增无减，摊位上的美食上了一回又一回，买的人是一批又一批。美食当前，谁不心动？

清洁天使，最美风景

此次活动得到了学院师生的积极响应，从下午2：30开始到晚上9：30活动现场都是人声鼎沸。摊位上的叫卖声、讨价还价声、欢笑声、……各种各样的声音混在一起，分外热闹。

从各个摊位走过，品尝各种食物无疑是一种享受。但你注意到了吗？有些人把废纸、一次性饭盒、竹签等东西随手丢弃。当活动结束，人群渐渐散去，场地一片狼籍。夜幕下，一群身上佩戴着学生会工作证的同学正拿着清洁工具在人群中清扫那些令人厌恶的丢弃物。他们忘情的工作着，放弃了回宿舍休息的机会。正因为有了这些默默奉献的清洁天使，才使整个场地能保持干净。

当我们沉浸在节日的喜悦中之余，我们是否也应注意一下自己手中已不要的东西，不要让它们自由落体呢？ 让我们一起努力，把美食节中的瑕疵去掉，共同营造我们美丽的活动氛围，让美食节的光芒更闪耀。
