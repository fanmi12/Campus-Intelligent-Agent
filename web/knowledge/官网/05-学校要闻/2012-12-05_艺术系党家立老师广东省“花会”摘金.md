# 艺术系党家立老师广东省“花会”摘金

12月3日，广东省第七届群众戏剧曲艺花会在深圳福田区石厦文化馆落下帷幕。我院艺术系党家立老师受东莞市文化馆邀请，代表东莞市参加本届花会，并凭借参演的小品《儿子、老子、孙子》一举夺得戏剧类金奖。

由广东省委宣传部、广东省文化厅主办的广东省群众戏剧曲艺花会，是我省重大的文艺品牌活动之一，每三年一届。是广东省戏剧曲艺界最高级别的文化盛会。本次花会为期4天，共有6场比赛、4场社区展演、闭幕式暨颁奖晚会等11场演出。

据悉，该作品从本届花会众多参赛剧目中脱颖而出，受到省内专家及文化部门领导的一致好评，有望 代表广东参加明年的第十届中国艺术节群星奖戏剧曲艺复赛。
