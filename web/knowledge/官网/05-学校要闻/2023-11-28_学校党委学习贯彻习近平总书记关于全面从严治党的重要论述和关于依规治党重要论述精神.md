# 学校党委学习贯彻习近平总书记关于全面从严治党的重要论述和关于依规治党重要论述精神

学校党委学习贯彻

习近平总书记关于全面从严治党的重要论述

和关于依规治党重要论述精神11月27日，校党委书记章德胜主持召开党委会议，学习贯彻习近平总书记关于全面从严治党的重要论述和关于依规治党重要论述精神。党委委员参加会议。

会议认为，要坚持把依规治党当作管党治党基本方式，要深入研究党的十八大以来全面从严治党取得历史性、开创性成就的原因，深入把握坚持制度治党、依规治党的重要作用，把党章和党规党纪学习教育作为党性教育的重要内容，不断提高党性教育的针对性和实效性。

会议强调，各位领导干部要以身作则，自觉投入到《中国共产党章程》《中国共产党纪律处分条例》等党内法规制度的学习中去，发挥表率作用，做尊规学规守规用规的模范，推动把习近平新时代中国特色社会主义思想转化为坚定理想、锤炼党性和指导实践、推动工作的强大力量。

会议要求，各基层党组织要以“三会一课”、主题党日等党的组织生活制度为基本形式，结合党员不同身份、不同岗位的实际情况，分批次组织党员系统学习党内法规制度，引导党员立足岗位、充分发挥作用，自觉遵守党的法规，提升自我约束的能力。

会议还研究了其他事项。
