# 我校“不忘初心、牢记使命”主题教育领导小组召开工作会议

9月24日下午，我校“不忘初心、牢记使命”主题教育领导小组在行政楼212会议室召开工作会议。

会议由党委书记章德胜同志主持，并就主题教育领导小组、办公室及主题教育联系指导组的职责分工作了说明，对工作进行了部署。

章德胜书记

对领导小组中的二级党组织负责人提出要求：一是要高度重视，学校各级党组织要把开展主题教育作为重要政治任务，切实履行职责，抓好组织领导。要集中精力、统筹安排，充分发挥承上启下的作用，并聚焦实际，认真检视问题，狠抓整改落实。二是认真开展学习，坚持全面系统学、深入思考学、联系实际学。通过学习，提升素质和能力，学以致用，用有所成，把学习成效体现到增强党性、提高能力、改进作风、推动工作上来。三是依据学校《“不忘初心、牢记使命”主题教育实施方案》，制定好本单位的实施方案，并结合本单位及师生的实际情况，创新活动形式，开展师生党员喜闻乐见的教育活动。

刘玉侠副校长指出，教工党支部要充分发挥战斗堡垒作用，切实激发教工党员的积极性，开展有特色有亮点的教育活动，进一步提高教工党员的组织生活质量。

王卫平校长强调，这次是我校第一次在市委指导下独立开展主题教育活动，并接受市委主题教育指导组的指导，充分显示本次主题教育活动的重要性及严肃性。全校各级党组织要高标准、严要求，不折不扣地做好主题教育活动，使我校党建及思想政治工作更上一个台阶。
