# 管理系举行09年考研动员座谈会

5月7日，管理系在1410教室举行管理系09年考研动员座谈会。

管理系辅导员陈彬老师、人力资源教研室黄岳钧老师、文学与传媒系已考上研究生的黄科同学和林润培同学出席座谈会。管理系06、07、08级有意向报考研究生和确定报考研究生的学生近30人参加了座谈会。

会上，陈彬老师讲解了有关考研的细节问题及注意事项，黄岳钧老师与同学们讲述了自己的经历，鼓励大家要为了实现理想而刻苦努力。黄科、林润培同学也和大家分享了考研心得。
