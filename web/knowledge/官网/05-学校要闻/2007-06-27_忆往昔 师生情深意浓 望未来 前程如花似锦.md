# 忆往昔 师生情深意浓  望未来 前程如花似锦

6月22日，福盈门酒楼热闹非凡，不时传出阵阵欢声笑语。管理系在这里举行毕业生座谈会。

会议由傅萱、陈俊杰同学主持，系主

任徐中和

教授致辞。毕业生代表蔡小玲、赵伟雄发表毕业感言，起大学生活的点点滴滴，言语中充满着留恋与不舍。在毕业生们浓浓的回忆中，系学生会精心策划的舞台剧《forever friends》悄然上演。熟悉的情境在音乐的衬托下令毕业生们回味无穷。最后，在系党总支副书记

吴春庚老师的带动下，毕业生全体起立举杯祝酒，将酒会的气氛推向高潮。

座谈过程中，系学生会和团总支向毕业生们派发了由他们精心制作的纪念书签，师兄师姐们同时也向他们表达了深切的寄望和谢意。院党委书记朱志德也来到了现场，为毕业生送去了祝福。
