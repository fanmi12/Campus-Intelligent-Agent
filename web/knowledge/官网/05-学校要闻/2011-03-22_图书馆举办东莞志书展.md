# 图书馆举办东莞志书展

3月21日，“东莞市志书展”在图书信息中心大楼9层开展。本次志书展展示了图书馆收藏的东莞市第一轮（1985-1995）和第二轮（2002-2010）大修志的部分成果，包括东莞市志、部门志、镇街志、村志等。

志书是原生态记录地方历史文化的重要史料，反映了历史的脉络和社会的印迹，是珍贵的精神财富和文化遗产。本次展出的资料在一定程度上反映了东莞文化的厚重和地域文化的特色。
