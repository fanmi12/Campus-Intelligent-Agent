# 科技出版社在我馆设立教材样书库

为了更好地让广大师生了解教材信息，科学出版社技术分社在我院图书信息中心设立了样书专架，陈列该社新出版的教材。

我们根据学院教学实际及课程设置情况，联合各系部挑选出适合于教学用的教材。科学出版社每季度向我中心赠送该社出版的相关教材样书和有关介绍资料。自5月16日起，这些新教材在图书馆二楼书库样书专架展出。
