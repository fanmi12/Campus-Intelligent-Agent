# 第43期大学生科学文化论坛在莞城校区举行

11月22日，城市学院第43期大学生科学文化论坛在莞城校区学术报告厅举行。此次论坛的主题是“定位理论与大学生的职业选择”，由北京大学经济学博士聂秀东主讲。

聂秀东博士指出：我们每个人每天都要进行定位与选择，要确定自己所在的位置，决定想去的地方，并选择怎样去做，选择的关键是定位。我们的一生都在定位和选择，人生其实就是一系列的定位与选择分为说明被动职业选择与主动职业选择两种，不同的选择有不同的结果。可供选择的职业越多，大学生的选择越不易。大学生定位与选择的思路与方法是：第一，可能获得的、你擅长的、能给你带来最大综合效用的职业才是适合你的最优职业。第二，发现和确定你的独特禀赋和特长，鲜明地建立起你的独特形象，让别人认知你。第三，准确定位自我性格，认清我是谁。最后，聂秀东给同学们在面试技巧方面提出了许多具体的建议。
