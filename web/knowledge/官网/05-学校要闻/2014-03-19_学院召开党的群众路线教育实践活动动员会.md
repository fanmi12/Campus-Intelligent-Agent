# 学院召开党的群众路线教育实践活动动员会

3月18日下午，我院党的群众路线教育实践活动动员会在行政楼212会议室召开，各总支（直属支部）书记参加会议，党委副书记章德胜主持会议，党委书记王卫平出席会议并讲话。

王书记对我院开展党的群众路线教育实践活动进行了动员，我院党的群众路线教育实践活动分为制定方案、部署工作；学习教育、听取意见；查摆问题、开展批评；整改落实、建章立制等四个阶段。

他强调，全体党员、干部要力求实效，通过教育实践活动，进一步深化对党的群众路线的认识，充分发挥党员、干部的模范带头作用,对作风之弊、行为之垢来一次大排查,切实解决“四风”方面存在的突出问题，进一步加强学院的工作作风建设。要创新党建工作融入学院教书育人的载体与形式,进一步规范党建工作,优化教风、学风、校风。进一步健全、完善和落实学院的规章制度, 解决师生员工普遍关心的实际问题，让群众受益。

会议还传达了省、市、东莞理工学院纪检监察工作会议的主要精神，通报了党代会筹备工作的情况。
