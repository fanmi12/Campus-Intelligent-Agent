# “形势与政策”知识竞赛总决赛圆满落幕

5月25日，我院“形势与政策”知识竞赛总决赛在学术报告厅举行。院督学陈丁堂教授，党委宣传部部长、思政部主任何鹏举教授，团委书记罗文芳老师，思政部副主任石志民副教授、计信系王强强老师担任比赛评委。思政部老师、各系部学生代表观看了比赛。

经过一个多月的准备和预赛，机电系、城环系、管理系、财经系、政法系、计信系、艺术系、金贸系、文传系共九个代表队进入总决赛。总决赛采取围赛、晋级赛、冠军争夺赛三级赛制进行。九个代表队分成A、B、C三组先进行突围赛。即：一分钟快答题、抢答题两个环节，胜出的六个代表队参加晋级赛。晋级赛分个人必答题、图片题、资讯题三个环节，胜出的三个代表队最后冲刺冠军争夺赛。比赛中，选手们沉着冷静思考，积极回答问题。台下的观众更是喝彩声不断，现场气氛紧张而热烈。

经过激烈竞逐，艺术系代表队获得比赛一等奖，金贸系、计信系代表队获得二等奖，政法系、财经系、机电系代表队获得三等奖，管理系、文传系、城环系获得优秀奖。政法系获得优秀组织奖。

思政部副主任石志民副教授作了本次比赛的总结。他希望通过本次“形势与政策”知识竞赛引导同学们准确分析、判断国内外形势，关注社会时事热点，了解国家方针政策，开阔同学们的视野、思路，克服“两耳不闻窗外事，一心只读圣贤书”的错误观念，使每一位同学都能成长为能融入社会，走向世界的实用型、应用型人才。
