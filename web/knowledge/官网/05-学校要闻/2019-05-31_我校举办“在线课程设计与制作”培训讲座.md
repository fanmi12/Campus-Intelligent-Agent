# 我校举办“在线课程设计与制作”培训讲座

5月30日，教务处与教师发展中心联合举办了“在线课程设计与制作”培训讲座。学校各课程类项目负责人及团队主要成员聆听了讲座。

深圳大学教务部慕课办副主任、UOOC联盟课程制作执行总监吴燕玲应邀担任主讲嘉宾，围绕在线课程的建设要求、总体设计、授课形式、制作方法、制作技术等方面进行了深入地讲解与演示。

教务处处长赵书山表示，举办此次培训讲座旨在各课程类项目负责人帮助掌握了在线课程设计与制作的知识与实用技能，促进现代信息技术与教育教学深度融合，力争建设一批高水平、高质量的在线开放课程。
