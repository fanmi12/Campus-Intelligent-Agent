# 我校城建与智造学院学子获得广东省机械创新设计大赛一等奖

2024年5月5日，我校城建与智造学院组织四支队伍共20位同学，参加了广东省机械创新设计大赛，全部获奖。

其中一等奖一项、二等奖两项、三等奖一项。由陈洵凛、李晓彦老师指导的作品“木影蛙跃”荣获一等奖；由谭海欧、阮育煌老师指导的作品“豌豆自动种植机”和吴蕾、丁娟老师指导的”小型自走式钵苗移栽机”荣获二等奖；由张锦荣、罗彦琦老师指导的“智慧农耕多功能自动播种机”获得三等奖。其中陈洵凛、李晓彦老师指导，何子杰、徐燕婷、邱杰铭、戴兴继、马郁烨同学设计并制作的作品“木影蛙跃”以仿生组第二名的好成绩，获得参加全国竞赛的资格。
