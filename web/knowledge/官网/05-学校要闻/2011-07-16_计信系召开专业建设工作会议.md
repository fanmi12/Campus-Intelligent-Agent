# 计信系召开专业建设工作会议

7月14日，计算机与信息科学系在7号楼会议室召开了“第二届专业建设指导委员会暨实习实践工作会议”，会议由计信系主任牛熠教授主持。牛主任宣读了“关于计信系第二届专业建设指导委员会换届暨实习基地工作的决定”， 教务处处长邓成良教授致辞并为21位委员颁发了聘书。

本次受聘的电子信息工程、计算机科学与技术、软件工程三个本科专业的21位专业建设委员会委员由东莞行业学会、企业家、东莞理工学院教授以及计信系部分专业骨干教师组成，其中9位委员同时被聘为计信系学生实习实践指导教师。

会上，各位委员进行了充分的交流，纷纷为如何做好各专业建设建言献策。委员们表示，要充分发挥行业学会及企业所长，做好专业建设指导工作，进一步深化合作，加强实习实践基地的建设。

据牛熠主任介绍，电子信息工程、计算机科学与技术、软件工程三个专业负责人为召开这次会议做了大量的准备工作。本次会议的召开对进一步推进计信系专业建设和实践基地建设，发挥专业优势，拓展专业技术应用，促进专业教学改革、课程建设、师资队伍建设，完善产学研机制有着重要的意义。会议标志着计信系在适应东莞经济建设和社会发展的需要，更好地为东莞经济和社会各项事业服务的方面，已经形成了相互沟通、紧密联系的产学研合作长效机制。
