# 周致纳、麦照容新校区夜访菁英培训营新生

9月14日晚，2011级新生菁英培训营结束了第二天的培训活动，新同学们对培训活动感触如何，对校园生活是否适应，对住宿饮食是否满意，对新校区有何感想，对新校区今后的建设有什么样的建议？……东莞理工学院党委书记周致纳、东莞理工学院城市学院董事长麦照容和院领导们对此非常关心。

当晚10时30分许，周致纳书记、麦照容董事长、黎建烨董事在杨敏林副院长的陪同下，来到位于4号学生宿舍楼3楼菁英培训营新同学的寝室，看望了培训营新生、辅导员和班主任。

周致纳书记和麦照容董事长和同学们进行了亲切交谈，并十分关切地询问了同学们对培训感受如何，是否适应新的环境，是否习惯校园生活、对住宿与饮食是否满意，还有没有需要改进的地方等问题。同学们对周书记与麦董事长的到来感到非常高兴，纷纷为自己能参加菁英培训营活动而感到骄傲，对能在新校区开始自己的大学生活而自豪。同学们也真诚地交流了自己对新校区的感受和热爱，对正在完善的地方也表示理解，并表达了在努力学习、争取做名优秀学生干部的同时，也为学院今后的发展尽自己一份力量的意愿。
