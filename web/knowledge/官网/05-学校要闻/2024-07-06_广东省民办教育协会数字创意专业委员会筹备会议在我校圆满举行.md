# 广东省民办教育协会数字创意专业委员会筹备会议在我校圆满举行

广东省民办教育协会数字创意专业委员会筹备会议于东莞城市学院隆重召开。参与本次会议的有广东省民办教育协会领导、兄弟院校代表、我校校领导以及创意设计学院相关人员。本次会议旨在推动数字创意教育的蓬勃发展，促进产学研的深度融合，进一步提升广东省民办教育协会的影响力，为广东省民办高校数字创意教育事业赋予崭新的活力与灵魂。

本次会议由东莞城市学院创意设计学院院长何帅主持。

会议伊始，学校党委书记章德胜发表了热情洋溢的欢迎辞，对与会嘉宾表示热烈欢迎和衷心感谢，并对此次会议寄予厚望。

随后，学校执行校长方伟华向与会代表详细阐述了我校发起成立数字创意专业委员会的初衷和深远意义并希望各兄弟院校之间能积极交流与沟通，共同助力广东民办教育高质量发展。

广东省民办教育协会常务副会长张耀荣在讲话中着重指出此次广东省民办教育协会数字创意专业委员会筹备会议是一次重要的里程碑，各院校应当发挥学院所长，共同推进广东数字教育的发展，助力广东教育事业高质量发展。

各院校与会代表围绕数字创意专业委员会的名称、专委会规程、组织架构、理事会名额以及工作方案思路等关键议题展开了深入且富有成效的讨论。

广东省民办教育协会数字创意专业委员会筹备会议的成功召开，无疑标志着数字创意教育领域的合作迈出了坚实有力的第一步，同时也充分彰显了广东省在教育创新与发展道路上的坚定决心和强大力量。
