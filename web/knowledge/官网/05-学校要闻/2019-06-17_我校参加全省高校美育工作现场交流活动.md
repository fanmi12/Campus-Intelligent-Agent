# 我校参加全省高校美育工作现场交流活动

6月14日，2019年全省高校美育工作现场交流活动在华南师范大学举行。教育厅副巡视员邱克楠出席了交流活动并作总结讲话，对新时代全省高校美育工作进行了部署。

我校副校长高香林率领教务处副处长鞠晓红、艺术学院负责人陈建新、创意设计学院副院长何帅等参加了交流活动，并参观了星海音乐学院博物馆、首批省高校中华优秀传统文化传承基地成果，观看了传承基地成果展演。

近几年来，我校立足全方位育人，科学构建美育课程体系，以突出岭南特色、传承中华传统文化为理念，实现了将东莞“非物质文化遗产”进课堂、进比赛、出成果。其中，由非遗数字化团队申报的“数字化背景下的非遗项目保护与传承研究——以龙舟制作技艺数字化传承为例”项目获得2017年度教育部人文社科项目立项。目前，我校正积极申报广东省第二批高校中华优秀传统文化传承基地建设项目。
