# 我院新校区学生食堂正式启用

董事长麦照容（图左）出席食堂启用仪式8月19日，我院新校区学生食堂点火做饭，正式投入使用。当天晚上，新校区管委会在这里举行了盛大的员工聚餐活动，庆祝我院开启新的篇章。广东鸿发投资集团有限公司总裁、东莞理工学院城市学院董事长麦照容、鸿发集团有关领导、城市学院副院长杨敏林等领导参加了聚餐活动。

凌晨4点，新校区学生食堂灯火通明，爆竹声声。在一阵阵喜庆的爆竹声中，食堂工作人员举行了富有深远意义的点火仪式。

最为热闹的场景，还是在晚上6时开始的员工聚餐庆祝活动。来自集团、新校区筹建办、新校区管委会、后勤部的领导、老师、员工，共70多人参加了聚餐活动。一道道美味佳肴呈现在崭新的食堂大厅餐桌上，奋战在新校区建设一线的员工们开怀畅饮，共同品尝辛劳汗水所换来的胜利果实。

鸿发集团总裁、东莞理工学院城市学院董事长麦照容在聚会上致词，他对我院新校区建设所取得的成就表示满意，对为此而付出了辛劳与汗水的广大员工表示感谢。

据悉，我院新校区学生食堂位于新校区中央水景旁的荔香园，规划总建筑面积达16158.7平方米，共两栋，拥有7个独立餐厅，可同时容纳12000多名学生用餐。师生们在这里用餐时，可以观赏到校园美丽的湖光山色。

学生食堂一楼主要是经营早市、夜市小吃。二楼、三楼为大众餐厅，以本土特色的粤式菜为主打，兼具南北风味，提供川、湘等菜式和即点即炒服务，可满足学生的各种用餐需求。四楼按规划设计为员工兼学生餐厅，并设有数间独立的包房，可供2000人的用餐。目前，二、三、四层餐厅正在做最后的设备安装、调试和清洁整理工作。

据工程部负责人介绍，新校区教学楼、学生宿舍、图书馆、综合馆、运动场等单体建筑，将于本月底之前全部竣工投入使用。
