# 东华理工大学长江学院邹自力董事长一行来访

11月2日上午，东华理工大学长江学院董事长、院长邹自力等一行五人莅临我院访问交流。

我院院长王卫平、副院长高香林等领导热情接待了来宾，并在行政楼505会议室进行了座谈。

双方就学校机构设置、教师发展、教务教学等方面进行了交流与讨论。

长江学院客人还参观了校园，并考察了商科虚拟仿真实践教学中心。
