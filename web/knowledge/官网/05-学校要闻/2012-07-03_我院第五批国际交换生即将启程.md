# 我院第五批国际交换生即将启程

张林副院长与王十一（右2）、游玮然（右1）合照留念

我院第五批国际交换生文传系学生王十一将于2012年8月10日启程赴美求学。张林副院长为王十一送上了祝福与寄望，并与他和上一届交换生游玮然一同合照留念。

据悉，我院交换生有“上帮下”的优良传统，每届交换生在美国留学时都会广交人缘，并把美国的朋友介绍给下一届交换生，而且也会为“师弟师妹”们留下大批有用的生活物品，给他们在异乡带来城院大家庭的温暖。现在，我院已有多名学生通过游学、交换等项目在美国北爱荷华大学学习，有些还在项目结束后继续在该校攻读本科或研究生课程。
