# 体育教学部“户外生存”课题获国家体育总局立项

近日，我院体育教学部陈勇军老师主持申报的《基于协同育人东莞市青少年户外生存能力教育》获国家体育局立项。这是我院体育教学研究的一个突破，是全国独立学院中首个国家级体育类课题。

据体育教学部主任邢红林教授介绍：户外生存教育是体育教学部现阶段重点打造的一个课程，从本学期开始体育教学部正式开设户外生存、攀岩等一系列的户外课程。户外生存课程的开设使学生掌握与户外运动相关的知识和技能，将户外运动纳入高校体育课程高校体育教学改革的重要方向，也是培养应用型人才。

据悉，体育教学部将在近期邀请国家体育总局登山中心的领导到我院进行户外安全教育讲座、全国户外安全宣导员的免费培训，同时加强与东莞登山户外运动协会合作对我院学生进行第二期的初级户外培训，争取承办国家体育总局举办“攀岩希望之星”等全国性比赛，提高城市学院在全国的影响力及知名度。
