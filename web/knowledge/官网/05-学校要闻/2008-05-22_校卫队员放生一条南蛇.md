# 校卫队员放生一条南蛇

5月15日，学院保卫办校卫队三班班长韦胜江将一条大南蛇，放归饭堂后山树林深处。

据介绍，这条南蛇，2米长，3公斤重，腹部直径8厘米左右，呈橄榄褐色，属于日行性蛇类，无毒，多出现于农田、果园或树林，动作迅速，擅长爬树，白天常在近水的地方活动。

据保卫办主任王现府介绍，我院一直致力于校园自然生态保护和绿化工作，饭堂后山树林里生活着一些小型野生动物，与人和谐共处，从不主动进攻和伤害人。
