# 学院召开2011-2012学年度先进班集体、优秀学生表彰大会

12月13日，学院在学术报告厅召开2011~2012年学年度先进班集体、优秀学生表彰暨奖学金颁奖会。院长杨敏林、党委书记朱志德、党委副书记章德胜、督学陈丁堂、副院长高香林、鸿发集团工会主席吴季伟以及各系代表出席了会议。

章德胜副书记宣读 《关于表彰2011-2012学年度先进班集体、校园十佳、优秀大学生、优秀干部及奖学金获得者的决定》，18个班级获得“先进班集体”称号，10位同学获得“校园十佳”称号，1577位同学获得“优秀大学生”称号，1005位同学获“优秀学生干部”称号；20位同学获得“鸿发奖学金”，50位同学获得“鸿发励志助学金”，共有1744位同学获“一、二、三等奖学金”及“单项奖学金”。

10级工商管理专业的陈静红同学获得“校园十佳”和“优秀学生干部”荣誉。她代表发言认为：“要尝试、体验、发现自己的潜力。要有责任心，学着奉献、感恩、进取。积极热情参加各项活动。”

来自财经系的黄英立老师，作为“先进班集体”班主任代表与大家分享了工作理念与方法：一要有技巧地选好班干，二要懂得调动学习兴趣，鼓舞学生自主、自立、自强，三要合理控制学生浮躁心理，及时给予鼓励与支持。

副院长高香林号召全体同学向获奖的同学们学习，并要求全体同学要强化学风建设，立德树人；树立科学的价值观，创先争优；保持高昂的学习热情，立志成才，把学习当做责任，用青春、汗水、智慧谱写未来。
