# 总务后勤做好新学期准备工作

春寒料峭，总务后勤部门已经率先提前正式上班了。

2月12日上午，总务后勤召开了开学前工作准备会议。总务处处长翟耀明、副处长陈辉、后勤公司副总经理柳成荫及各中心负责人出席了会议。会议由总务处处长翟耀明主持。

据各中心汇报的情况，在寒假期间，我校后勤工作丝毫没有放松，水电管网设施设备维修、车辆检修、校园环境绿化及卫生保洁工作正常开展。这两天，各中心正在对管理服务范围工作进行全面的检查落实，能够保证正常开放食堂；按时运行校际交通车辆；新学期所需桌椅、多媒体教学设备等都已准备就绪。

翟耀明处长作了工作部署，提出2014年后勤工作的思路是“加强管理、规范管理、提高效益、保障服务水平”。他要求各中心要提早准备，认真抓好细节，确保新学期学校教学、生活秩序的正常运行。
