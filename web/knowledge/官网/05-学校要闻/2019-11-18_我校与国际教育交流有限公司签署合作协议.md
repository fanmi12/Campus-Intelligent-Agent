# 我校与国际教育交流有限公司签署合作协议

11月15日，教育部留学服务中心下属全资子公司嘉华世达国际教育交流有限公司副总经理李大鹏一行来我校访问。

校长王卫平、副校长周庆和国际交流中心负责人热情地接待来访客人，陪同客人参观了校园，介绍了我校概况和国际交流合作等有关情况。

双方举行了座谈，经过平等友好协商，秉承“资源共享、优势互补、责任分担、服务社会”原则，充分发挥各自优势，就有关国际教育领域有关合作签署协议。
