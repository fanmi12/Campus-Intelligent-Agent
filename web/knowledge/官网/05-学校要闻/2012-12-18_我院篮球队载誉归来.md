# 我院篮球队载誉归来

在广东省第十二届大学生篮球联赛中，我院男子篮球队队员们，奋勇拼搏，一路过关斩将，力挫群英，先后战胜中山大学、广东医学院等实力强劲的对手勇夺男子甲组第三名，是我院在广东省大学生联赛上的一次历史性的突破。

本次出征比赛的队员大部分是今年10月刚进队的大一大二的同学，可以说算一支全新的队伍。为了备战本次比赛，尽快实现新老队员的磨合，形成自己的战术风格，教练员和队员们在每天下午的正常训练的基础上，还坚持周六、日的训练。

本次联赛共有26支队伍参加，每支队伍都有着丰富的训练比赛经历，面对一个个强大的对手，我院男篮齐心协力，敢打敢拼，最终取得优异成绩胜利归来。

他们的突出表现，受到了学院领导的表扬与肯定，院领导杨敏林、章德胜、高香林亲切接见了载誉归来的队员、教练和领队。
