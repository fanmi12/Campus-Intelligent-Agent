# 我院新校区将迎来首条城巴路线

来自东莞市交通部门的消息，从下周一起，途经我院新老两校区间的城巴49路线，将正式开通。这是途经我院新校区的首条城巴路线，届时，我院新老校区间的公共交通将变得更为便利。

新路线贯穿两个校区

据了解，城巴49路线为“市第六中学”至“市中医院分院”线路，具体经过以下站点：市第六中学、城市学院正门、城市学院北门（注：即为我院新校区正门与北门）、建新路、园区二站、园区一站、市中医院、古村、万科高尔夫花园、石井支路口、汽车东站、汽车东站西、嘉湖花园、宝城花园南、石井、蓢基湖市场、宝城花园北、上三杞、市妇幼保健院、华生商场、塘边头、实验中学南、大塘头西街、高田坊路口、理工分校、疾病预防中心、城市学院莞城校区、步步高北、东门广场、市中医院分院。

部分公交站点更名

交通部门还表示，原黄沙南路的“大桥村”公交站点将向松山湖大道方向迁移约200米，并更名为“市中医院”（涉及的线路有城巴49路线及小巴X2路线）；原黄沙南路的“古村路口”公交站点更名为“市中医院”（涉及的线路有城巴21、49路线及小巴X2路线）；原东门路的“市中医院”公交站点更名为“市中医院分院”（涉及的线路有城巴9、11、24、36、49路线及小巴X6、X19路线）；原学院路的“城市学院”更名为“城院莞城校区”（涉及的线路有城巴14、18、22、24、25、29、33、51、C3路线）。
