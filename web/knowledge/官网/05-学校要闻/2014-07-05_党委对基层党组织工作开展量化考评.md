# 党委对基层党组织工作开展量化考评

6月10、11日，党委书记王卫平、副书记章德胜、党委委员高香林、黄兢带领各党总支副书记、直属支部书记对全院17个党总支（直属支部）2013－2014学年度的党建工作开展了为期两天的量化考评。

考评采取交叉检查、互评打分的方式进行的。考评的内容包括班子建设、党员学习教育、发展党员工作、日常管理工作、党员活动室建设、分党校建设等六个方面。

考评组首先听取各单位党组织关于基础资料的准备、收集、整理和落实党委工作的情况汇报，然后对部分党组织的会议记录、发展党员、资料整理等基础性工作中存在的不足提出整改意见。

王卫平书记高度肯定了各基层党组织的党建工作。他指出，各单位党组织要强化党建工作的日常性、基础性的工作，更好地发挥基层党组织的作用，并以此为契机总结好党建工作经验，提升党建工作水平，达到以评促建、以评促改的目的。

章德胜副书记表示，各单位要借此机会增进党总支、直属支部之间的交流，互相学习，共同提高。从本单位的实际出发，加强稳改，取得更大的进步，推动我院党建工作再上新的台阶。

据悉，学院党委将在纪念建党93周年之际，对在此次考评工作中取得优异、秀成绩的单位进行表彰奖励。
