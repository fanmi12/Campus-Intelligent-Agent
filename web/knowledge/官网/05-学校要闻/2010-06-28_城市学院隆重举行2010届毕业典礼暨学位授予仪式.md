# 城市学院隆重举行2010届毕业典礼暨学位授予仪式

毕业典礼会场

东莞理工学院党委书记周致纳为毕业生颁发毕业证书

东莞理工学院校长杨晓西为毕业生拨穗

东莞理工学院副校长、城市学院院长安少华在毕业典礼上致词

城市学院董事长麦照容与优秀毕业生合影

城市学院党委书记朱志德为优秀毕业生颁发荣誉证书

毕业文艺演出剧照6月26、27日，2435名2010届毕业生欢聚大礼堂，接受学院领导拔穗礼遇，拍毕业照，聆听领导、教授及老师的离别祝福，集体告别同学和校友。为庆祝2006级（本科）、2007级（专科）学生学成毕业，欢送他们奔赴新的征程，学院在这里隆重举行2010届毕业典礼暨学士学位授予仪式。

东莞理工学院党委书记周致纳、校长杨晓西、副校长安少华，广东鸿发集团总裁、城市学院董事长麦照容，副总裁、城市学院第二届董事会董事黎建烨，城市学院党政领导朱志德、程发良、朱冰、张林，院督学陈丁堂出席盛典，与毕业生们共同话别，颁发毕业证书、学士学位证书，为获得学士学位的同学拨穗。

副院长程发良主持盛典仪式，“毕业了，意味着新征程的开始，愿你们鹏程万里，一路顺风；”“常回学校看看，我们与你们心心相连”；“恩师难忘，定以泉涌相报”……一声声祝福赠言，一句句感恩辞语，体现着浓浓的师生情谊和依依惜别的眷恋。

据教务处介绍，2010届毕业生们在校期间，不仅完成了规定的专业学习课程，还选学了不少的非专业课程。有数字显示，全院共有2435名同学毕业，其中本科生1252人，专科生1183人， 1250人通过毕业答辩获得了学士学位。10名同学考取了华南师范大学、浙江工业大学、广西大学等大学的硕士研究生，11名同学通过了全国司法考试，600多人加入了中国共产党。

毕业生们纷纷表示，自己在城市学院学习所取得的成绩与进步，应归功于学院与老师，是他们培养教育了我们，我们将永远记住老师的好。文学与传媒系黄静杰同学说，城市学院的记忆，我将珍藏一辈子，伴我走遍天涯海角。第一次见到名教授的激动，第一次加入社团的好奇，第一次考试的紧张，仍历历在目，记忆犹新。计算机与信息科学系毕业生刘宗桐同学说，这几年，我们见证了学院的发展，享受了最好的教育教学资源。学院投巨资改造装修教学楼，新建了图书科技信息中心大楼。“学校对我们的好，我将永远记在心里”，政法系于佩同学说，老师不仅教我们学会了学习，还学会了做事，学会了做人。毕业后，一定在工作中争创新业绩，不负“城院人”光荣称号，为母校增光添彩。

典礼之后，师弟师妹们为毕业生盛情表演了文艺节目。
