# 我院召开2014届毕业生代表座谈会

2月26日，我院在莞城校区315会议室召开城市学院2014届毕业生代表座谈会。东莞理工学院党委副书记、纪委书记、副校长安少华，莞城校区管委会主任邢大立，城市学院党委书记王卫平、副书记章德胜出席会议。

有关职能部门负责人到会面对面地听取了30多名毕业生代表对学院工作的意见和建议。

在座谈中，同学们畅谈了大学四年的美好生活与学习收获，感谢母校和老师的关怀与教诲。同时，他们也结合自身实际对母校的工作提出了许多好的意见和建议，如进一步完善人才培养计划，创新人才培养模式，简化离校手续，加强就业指导，增加实践机会，优化教务信息系统等。

与会领导和老师认真听取了同学们的发言，并就具体问题作出了解释和表态。

安少华副书记感谢同学们对学校工作的支持和理解，有关职能部门对同学们提出的问题要想办法尽力解决，进一步把工作做好。老师要多关心、多指导，帮助毕业生就业。同学们在就业过程中，要注意了解广东省和东莞市的形势，尽快融入社会，转换好角色，开启新生活，为各地的经济社会双转型贡献力量，开创自己的新天地。
