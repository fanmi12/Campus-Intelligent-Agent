# 文传系召开“创一流大学、办百年名校”务虚会议

2月28日，文传系教工党员就关于开展“创一流大学、办百年名校”的战略思想进行了专题讨论。

一、关于学院建设。学院应坚持育人为本，大力推进素质教育，探索适应不同类型教育和人才成长的管理体制和办学模式，提高办学和人才培养水平。同时，要引入先进、科学的教学评价机制，促进教师教学水平的提高。办学要有长远目光，不要急功近利，不要局限于眼前的蝇头小利。要有长远规划，凡是对学校发展有利、对教师发展有利、对学生发展有利的决策，要以学院文件的形式确定下来，不因人而变。在硬件建设方面，学院应加强图书馆建设，为学术期刊网数据库续费，方便师生查阅资料。

二、关于学院管理。会议提出，希望区分高校教育管理与企业管理的差异，加强对教育事业的认识，分清企业与办学校的区别，专业建设的投入要舍得。应考虑重新制定、规范学院的管理制度和办公流程，提高工作效率。

三、关于教师待遇。希望提高教师待遇，稳定教师队伍。加大科研的力度，提高教师科研积极性。同时加强对青年教师课题申报和职称评审指导，建立完善的教师再提高体系。学院应降低教师额定工作量，提高教学质量，增强学院稳定性，提高教师的信心。
