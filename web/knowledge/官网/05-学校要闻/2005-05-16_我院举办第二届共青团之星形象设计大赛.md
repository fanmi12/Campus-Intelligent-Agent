# 我院举办第二届共青团之星形象设计大赛

5月8日晚，由我院团总支主办的第二届共青团之星形象设计大赛决赛在院学生活动中心举行。党总支副书记朱冰、学生办主任丘永辉等领导和各部辅导员出席观看了本次大赛。

比赛共分三个环节进行：首先是自我介绍，然后通过党团以及时事知识的问答，最后进行才艺表演。

当天晚上，活动中心灯火辉煌，激情澎湃，十名参赛选手尽显风采，他们以柔和的歌唱、动情的朗诵、激情的英语演讲、精彩的相声以及动人的钢琴弹奏等丰富多彩的才艺表演赢得了在座观众的阵阵掌声。经过一番激烈的角逐，方莹莹以其优雅的琴声获得了一等奖兼最佳才艺奖，刘禄源和钱昊天分别以他们新异的歌词和精彩的相声获得了二等奖和三等奖，郑海燕同学获得了最佳台风奖,赵志芬等6位同学获得了优秀奖。

据悉，我院将从获奖选手中选拔一名同学参加理工学院的决赛。
