# 市府在我院召开大学生环卫检查员座谈会

3月19、20日，根据市委市政府的指示精神，我院抽调320名大学生前往东莞32个镇区的596个社区开展了东莞市整治环境卫生大检查。检查评分工作结束后，3月24日，市政府在我院315会议室召开参加检查的学生检查员座谈会。东莞市城市管理局副局长陈旭坚、市环卫整治办常务副主任徐少钢、学院党委副书记朱冰、党委宣传部部长何鹏举、市环卫整治办工作人员、环卫检查带队教师代表和大学生代表参加了座谈。

座谈中，各检查组反映了某些镇区环卫中的问题，如：车辆乱停乱放，摊担占道经营，家禽家畜散养，“牛皮癣”小广告清理不彻底等。同时，同学们对检查工作中的不足也直言不讳，比如有些基层领导对检查工作的重要性认识不足，资料不齐；存在突击清扫、应付检查的现象，检查面不广泛；学生检查员对有些评分标准难以掌握从而导致评分不准确等。

对上述问题，同学们和带队老师纷纷建议：要坚持定时检查与突击检查相结合的办法，防止发生“应付”检查的现象；切实加强宣传力度，帮助居民，特别是农村居民从思想上提高环卫意识；取消陪检员，让检查员任意检查；开展加强对大学生检查员的培训，使他们对评分标准有更深入的了解；检查表中，应减少硬件项目的分值，重视各镇区的工作努力程度。

东莞市城市管理局副局长陈旭坚听取意见后表示，“环境卫生整治工作是市委市政府的一项十分重要的工作，是提升东莞综合竞争力和软实力的重要指标。我们选调大学生担任检查员，引起了学院领导的高度重视，老师和同学们认真负责，基本达到了预期效果，非常感谢大家的支持。今天，大家反映的意见和建议非常好，我们收集整理后将上报市政府，使检查方法和评判标准更为科学合理。大学生检查员制度我们将坚持下去，培训工作也将持续开展。我们相信，在大家的共同努力下，东莞市的环卫工作将会取得长足的进步。”

社会科学系06级法学专业的李海波同学说：“我们非常感谢市政府对我们的信任，感谢学院为我们提供深入社会实践的好机会，这不仅提高了我们人际交往的沟通水平，也锻炼了我们解决实际问题的动手能力。作为检查员，我们应本着对政府负责、对市民负责的态度进行工作，让领导放心，让人民放心，检查时认真评判，同时做好环卫宣传，用自身的行动使东莞越来越靓。”

随后，市环卫整治办常务副主任徐少钢向各位检查员代表通报了各镇区的检查结果。

据悉，东莞市整治环境卫生大检查每季度开展一次，我院大学生将继续配合市环卫整治办开展此项工作。
