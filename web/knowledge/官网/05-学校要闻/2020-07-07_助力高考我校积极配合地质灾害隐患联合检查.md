# 助力高考我校积极配合地质灾害隐患联合检查

2020年7月6日，为做好高考应急处置工作，东莞市应急管理局梁达辉局长带队教育管理中心、水务部门、自然资源分局、第六高级中学等相关部门负责人对东莞市第六高级中学高考点周边的易涝点、地质灾害点进行实地检查。我校后勤保卫处副处长刘维仝热情予以接待并陪同此次联合检查。

检查组仔细听取了刘维仝副处长对我校各隐患点的情况及防治工作介绍。检查组结合我校实际情况给出了专业化建议，进一步强调了地质灾害防治工作的重要性。

刘维仝副处长表示，高考在即，我校不仅祝各位莘莘学子考出理想成绩，同时也会在各方面给予支持并积极配合有关部门做好周边环境治理工作，加强值班值守，落实信息报送，切实做好对地质灾害隐患的巡查监测，及早预防，及时预警预报，确保师生生命财产安全。
