# 羊年开学首日  教学秩序井然

3月2日，我院2014—2015学年第二学期开学上课。

这天上午9时，院领导杨敏林、王卫平、高香林等领导率领教务处、学生处等部门的负责人，对全院的上课情况进行了巡视。各系部主要领导、辅导员也到教学楼检查本单位教师、学生上课情况。从检查和各系（部）反馈的情况来看，开学上课情况正常。据了解，教师准时到堂、认真授课；学生按时上课，课堂纪律较好；教学设施、设备运行正常，后勤保障人员提前到岗。教材到位率接近100%。

为保障顺利开学，教务处几天前就召开了各系（部）教学管理人员会议，对开学的各项准备工作进行了布置安排。教务处、实验中心、总务处还对教学楼及各实验室、实习设施进行了全面检查。各系（部）领导高度重视，精心做好开学前的各项准备工作，确保新学期正常开学上课。
