# 学校党委前往广东省东莞监狱 开展警示教育

为筑牢党员干部拒腐防变思想防线，推进党风廉政建设常态化长效化，5月13日，学校党委组织学习教育读书班学员、党委理论学习中心组成员及中层干部前往广东省东莞监狱开展警示教育，以身边事教育身边人，近距离接受廉洁教育。

在监狱民警引导下，党员干部深入监区监舍，实地观摩监狱规范化日常管理与教育改造工作，切身感受

“高墙铁网”下的纪律约束与法律威严。在警示教育报告大厅，监狱民警系统介绍了东莞监狱概况、服刑人员生活与改造情况。尤为震撼的是观看了两名服刑人员的“现身说法”视频，两名服刑人员结合自身蜕变为罪犯的人生轨迹，深刻剖析了自己背离初心使命、突破纪律底线、滥用权力谋取私利的违纪违法过程，声泪俱下的忏悔和触目惊心的教训，让在场的每一名党员干部都接受了一次直击心灵的思想洗礼。

大家纷纷表示，此次警示教育发人深省、令人震撼，在今后的工作中一定会从案例中汲取深刻教训，时刻绷紧纪律规矩这根弦，自觉守住廉洁自律的底线，始终保持共产党员清正廉洁的政治本色。

本次警示教育是学校党委推进党风廉政建设的重要安排，进一步增强了广大党员干部拒腐防变和抵御风险的能力，强化了党员干部的纪律意识和规矩意识。下一步，学校党委将持续坚持正面引导与反面警示相结合，引导广大党员干部以案为鉴、防微杜渐，时刻紧绷廉洁自律这根弦，始终做到知敬畏、存戒惧、守底线，持续营造风清气正的校园政治生态。
