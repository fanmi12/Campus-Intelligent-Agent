# 广东省第十二届大学生篮球联赛传来捷报

11月18日，今年10月成立的城市学院男子篮球队首次外出比赛旗开得胜，以全胜成绩获得广东省第十二届大学生篮球联赛甲组八强。

据领队、体育教学部主任邢红林教授介绍，本次比赛共有230多参赛队伍，分类甲乙丙三个组，即本科院校组、体育院校（系、专业）组和专科院校组。甲组分成四个小组在广东金融学院展开比赛，我院先后与南国商学院、佛山科技学院、培正学院、仲恺学院交锋，以全胜的战绩取得第一名进入甲组八强。

院长杨敏林、党委副书记章德胜为参赛同学们接风洗尘。

我院篮球教练接受电视台采访
