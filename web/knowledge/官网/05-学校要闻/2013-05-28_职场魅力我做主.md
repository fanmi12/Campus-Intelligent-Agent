# 职场魅力我做主

近日，中国移动第四届高校精英训练营总决赛在东莞理工学院隆重举行。我院11级新闻传播专业谢舜珠同学荣获本次比赛的总冠军，11级人力资源管理专业赖彦光和12级机械设计制造及其自动化专业张木先两位同学获得季军。我院团委书记罗文芳出席本次决赛，并担任评委。

据悉，参赛选手来自东莞理工学院、东莞理工学院城市学院、广东医学院、东莞职业技术学院、广东科技学院。谢舜珠同学还获得了最佳职场风采奖，赖彦光所在的闪光队获得魅力团队奖。
