# 我校参加寮步青年人才驿站揭牌仪式

7月3日上午，由寮步镇人才办、寮步镇人社分局、退伍军人办公室联合打造的“寮步青年人才驿站”在鼎昊人才公寓举行揭牌仪式。我校党委书记章德胜、就业中心主任林蓉受邀参加了揭牌仪式。

揭牌仪式后，受邀的领导和嘉宾还参观驿站配套和功能区。

我校党委书记章德胜还到看望了已入住驿站的毕业生，了解毕业生的生活、住宿、就业情况，并与毕业生合影留念。

出席当天揭牌仪式的领导有东莞市人社局副局长吴柏安、市委组织部人才二科科长徐文鑫、寮步镇党委副书记梁仲辉、党委委员陈宝玲、东莞人才发展研究院院长陈亮和东莞理工学院就业指导与服务中心主任贺松健等。
