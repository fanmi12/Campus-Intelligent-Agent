# 2013年城市学院好新闻评选结果出炉

《城市学院报》自创刊以来，今年首次评选好新闻。这次评选的内容是2013年的新闻作品，共有42件优秀作品获奖。

据悉，评选的类别分为消息、标题、通讯、图片、版面、专题七类。这些好新闻从不同的角度，运用不同的体裁，充分报道了校园丰富多彩的文化生活、校园建设成就、教学科研成果、莘莘学子奋发有为的优秀事迹，对引领校园舆论导向、加强校风教风学风建设起到了促进作用。例如，消息“微博调侃城市学院是‘空调学院’”，及时报道了校园硬件建设情况及优越的办学条件，为考生解惑答疑，帮助考生填报城市学院。

据悉，这条消息的读者点击量达到4万多人次，大一新生及家长100%的阅读了这条新闻。

唐跃碧主编说，本次评选标准是按照《中国高校校报协会好新闻评选办法》执行的，学校还在这些好新闻中选出一部分作品，参加中国高校校报协会和广东省高校校报协会的年度好新闻评选。
