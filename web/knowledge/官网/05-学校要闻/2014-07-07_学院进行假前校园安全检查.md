# 学院进行假前校园安全检查

7月7日，校内老师和同学都已经进入了暑假假期，院党委书记王卫平、院长助理麦琦琳在总务后勤相关部门负责人的陪同下进行校园安全检查，并对暑假期间的校园安全保障工作提出指导意见。

据悉，暑假期间，学院将加强校园24小时值班巡查，并通过视频监控等多种手段确保校园安全。针对学院部分道路及设施进行修缮保养，安排专人负责跟进新生宿舍床位、空调等设施，专设假期窗口继续为留校师生提供服务，开通校园

http://vpn.ccdgut.edu.cn/访问通道，方便师生们从校外访问学院数据及资源。
