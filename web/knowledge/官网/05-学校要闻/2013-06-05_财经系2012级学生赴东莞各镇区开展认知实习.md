# 财经系2012级学生赴东莞各镇区开展认知实习

6月1、2日，财经系系主任罗卫国教授带领2012级900多名学生到各镇区开展认知实习，先后参观了东孚石油化工有限公司、宏杰精密机械有限公司等多家国内外知名公司。

“这样的实习，使我们对所学专业有了进一步的了解和认知，提高了对专业的兴趣和热情，同时对自己的职业规划及就业方向提供了一定的参考。”财经系会计学9班的学生叶树荣说。

据财经系实践办主任肖文锋老师介绍，实习的主要内容是到企业或事业单位，了解与财务相关的基本情况，如财务部门岗位设置与职责、业务审批流程、企业经营范围和有关经营制度等等。
