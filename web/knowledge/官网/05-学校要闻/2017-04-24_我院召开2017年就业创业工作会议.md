# 我院召开2017年就业创业工作会议

4月20日下午，我院2017年就业创业工会议在招聘大厅召开。院领导黄兢、刘玉侠，机关教辅部门负责人、各院系（部）主任、书记，教研室主任、就业工作辅导员、招生就业处全体人员参加了会议。

会上，黄兢副院长代表学院与各院系主任签订2017年就业工作目标责任书。

就业中心江小卫主任对我院2016年就业创业工作进行了总结，就“2016届毕业生社会需求与人才培养质量综合报告”进行了重点解读。江主任还从工作总体思路、总体目标和主要措施等方面，对2017年就业创业工作作了相关安排，并勉励大家脚踏实地、克难攻坚、锐意进取，努力将学院就业创业工作提升到一个新的水平。

黄兢副院长在总结讲话中，要求大家要认清形势，充分认识到就业创业工作的重要性，夯实基础，全面提升人才培养质量，提高毕业生就业创业质量，努力谱写我院就业创业工作新篇章。

会议由招生就业处处长孔增强主持。
