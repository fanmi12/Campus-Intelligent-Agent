# 我校斩获第十五届挑战杯广东赛区一等奖

5月25日至26日，第十五届“挑战杯”广东大学生课外学术科技作品竞赛终审决赛在佛山科学技术学院举行。我校61名同学参加了决赛，并首次摘获该项赛事一等奖，实现了历史性的突破。

被誉为中国当代大学生科技创新“奥林匹克”的“挑战杯”已有30历史。本届广东赛区共吸引了全省137所高校参赛，省校两级参赛人数超过10万人，参赛作品达2627件，再创历史新高。最终，共有751件作品入围终审决赛。

据悉，自去年11月校团委开始启动校内初审和复赛，我校共推报20件作品参加省赛，最终18件作品获得了省级奖项。

学校党委书记章德胜出席了大赛开幕式。
