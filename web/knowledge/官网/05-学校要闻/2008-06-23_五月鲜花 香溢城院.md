# 五月鲜花 香溢城院

原声独唱、钢琴独奏、舞蹈、小品、时装表演、朗诵，一朵朵文艺之花在城院五月尽情绽放。6月3日晚的城市学院大礼堂，华灯璀璨，人头攒动，文学与艺术系“五月鲜花”文艺晚会在这里隆重举行。城市学院院长安少华教授，党委书记朱志德，副书记朱冰，副院长张林博士，督学林世俊教授等院领导莅临现场观看了晚会。

“雄鹰在蓝天飞翔，承载着母校的荣光……”，大合唱《感恩母校》句句表达了对母校的感激之情。ndrew、Mario等外教老师与袁宇航、李玲玲等英语老师合唱《My love》，这一创新的节目形式使全场的气氛达到了高峰。精彩的小品是赢得掌声和笑声的最多的节目。小品《追尾之后》通过生活中一个小矛盾的产生与调解过程，来向观众说明“人与人之间总会有摩擦，但要相互谅解”这个道理。《短信风波》通过描述一个经常受到短信骚扰的家庭，闹出许多误会的故事情节，说明垃圾短信的危害与影响。

由史德松老师作词作曲的《心同此情》，伴随着点点烛光唱响城院。“拉着你的手，热泪洒满胸襟”，演员们用歌声祈福灾区人民，感动现场观众，领唱之一的陈煜丽老师因感动还流下了眼泪。

整台晚会节目风格各异，极具艺术魅力，真可谓是一份丰盛的艺术大餐，使观众大饱眼福。钢琴独奏《拉赫玛尼诺夫音画练习曲》，舞蹈《旅途》，歌曲《爱狼说》、《天路》、《火把节的火把》，歌剧选段《绣红旗》等节目，无不凝聚了师生们的心血。

文学艺术系党总支书记孟颖老师表示，本次演出，为同学们打造了展示艺术才华的大舞台，表达出全院师生对母校的感恩，对奥运和灾区人民的支持与关怀。
