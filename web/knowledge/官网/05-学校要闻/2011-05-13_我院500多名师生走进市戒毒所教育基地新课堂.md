# 我院500多名师生走进市戒毒所教育基地新课堂

何鹏举主任代表学院向戒毒所授予城市学院思想政治教育实践基地的牌匾

安院长、戒毒所教官与师生一起听取思政课现场教学5月12日，院长安少华、党委书记朱志德与思想政治理论课教学部500多名师生，走进东莞市戒毒所开展思想政治理论课现场教学活动。戒毒所教官带领大家参观了戒毒人员的学习和生活场所，观看了“珍爱生命，远离毒品”图片展览和禁毒宣传教育片。

思政部主任何鹏举教授代表学院向戒毒所授予了城市学院思想政治教育实践基地的牌匾，并赠送了一批图书。何主任在授牌仪式上说，思政部将东莞市戒毒所设立为教育实践基地，是思政课教学实践的一种新尝试。把思想政治理论课开到社会、走进戒毒所，让学生近距离接触戒毒人员，能增强学生抵制不良现象的自觉性。让戒毒人员现身说“教”，使思政教学更具形象力和感染力。这种实践教学形式，今后还将进一步开展和推广。

授牌仪式后，何主任还为学生现场上了一堂思政课，并带领师生庄严宣誓：“崇尚科学，加强修养，拒绝毒品，珍爱生命，感恩父母，幸福生活！”

艺术系10级音乐表演班的李晓霞同学在参观后深有感触地说：“这种学习方式很好。老师上课时经常提醒我们要‘珍爱生命，远离毒品’，但都是一些理性的认识，今天通过零距离接触戒毒人员，倾听他们的心声，真的从内心体会到毒品对生命、家庭和社会的危害。通过参观，使我们树立了正确的人生观和价值观，增强了抵制不良诱惑的能力。”

思政部副主任石志民副教授说，戒毒所的教官与高校教师有其内在的相似之处，都是通过教育去感化人。教官们在对待戒毒人员所体现出来的那种真挚的爱和强烈的责任意识、历史使命感都很值得我们学习。只有发扬爱岗敬业精神，教好书育好人，才能培养出对社会有用的人才。

此次活动受到正在东莞市戒毒所视察办公的公安部、省公安厅、市公安局有关领导的赞扬，他们认为这是禁毒教育走进课堂的好形式。
