# 我院开展系列心理知识讲座

11月6日、9日，学生处先后举办了主题为“走近你我——人际关系心理学”、“关注心理健康——大学生情绪管理”的心理专题讲座，200多名同学前来听讲。

讲座中，余琼老师结合诸多心理咨询案例，讲述了大学生在人际交往过程中容易产生的心理问题及解决这些问题的一般方法。余琼老师还赠给同学们四句箴言：“把自己当做别人，把别人当做自己，把别人当做别人，把自己当做自己。”

陈浩老师通过具体的案例分析，向同学们着重讲解了各种不良情绪，以及抑郁症的相关问题。最后，陈浩老师还指导同学们如何正确进行情绪管理。

据悉，这次系列心理专题讲座是我院心理普查后续工作的一部分，目的在于让更多同学了解心理健康的重要性，宣传心理健康理念，让同学们了解心理求助的途径。
