# 2012年教工排球赛开赛

11月6日开始，我院在校内排球场举行2012年教工排球赛。比赛吸引了众多学生前来观看，并为老师们加油喝彩，现场掌声阵阵，热闹非凡。

比赛精彩纷呈，教职工们配合默契，各队打起十二分精神，一踮一传一扣，相互配合，不给“对手”留余地，充分体现了排球运动拼搏和团队合作的精神。

杨敏林院长也参与了本次的比赛。杨院长表示:举行本次比赛有利于活跃校园文化，增强教职工之间的凝聚力，增强团队协作精神。党委副书记、工会主席章德胜表示：比赛的结果不重要，重要的是过程，重要的是团队的合作。

据悉，教工排球赛从11月6日持续到11月19日，总共有十二支队伍参与比赛。
