# 我院学生参与新校区校门设计

文传系师生在听取新校区建设情况讲解5月26日下午，我院文学与传媒系近60名师生在系主任陈庆祝的带领下，赴新校区工地参观，参与新校区校门设计的实地勘察。参与此次校门方案设计的主要为2009级数字媒体艺术专业和平面设计的同学们，随后他们将分组提交设计效果图。

新校区筹建办领导热情接待了到访的老师和同学们。在筹建办会议室，工程部宋云龙老师向大家演示讲解了新校区建设效果图，并通报了目前的建设情况，详细说明了新校区大门所处的地理位置、周边建筑、空间关系，为同学们提供了翔实的材料。随后，合约工程部经理陈俊凯就目前已有的部分设计方案，做了一些分析，就现代与传统两种设计风格分别向大家做了展示和讲解。

文传系主任陈庆祝博士鼓励同学们，新校区的建设受到了社会各界和学院领导的极大重视，今天我们看到了新校区的蓝图很受鼓舞，希望大家能够积极认真的参与此次设计，将平时所学应用于实践。

会后，同学们到新校区工地实地进行了测量考察。

据悉，东莞理工学院城市学院新校区位于东莞市松山湖大道文阁旁，占地1200亩，总建筑面积66万平方米，计划投资近20亿元人民币。其中一期建筑面积45万平方米，将于2011年9月交付使用。
