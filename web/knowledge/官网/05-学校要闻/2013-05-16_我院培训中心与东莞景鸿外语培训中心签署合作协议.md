# 我院培训中心与东莞景鸿外语培训中心签署合作协议

为促进校企结合，为在校生、毕业生提供一个更广阔的继续深造平台的选择。5月15日下午，东莞理工学院城市学院就业指导与培训中心与东莞景鸿英语中心签订了正式合作协议。苏振强经理对双方的合作充满信心，并表示东莞景鸿致力于在城院大力推动人才培养和发展。

据了解，东莞景鸿英语培训中心业务涉及外语培训+游学一站式完善服务。是一个有着十多年丰富教学经验的本土专业机构。
