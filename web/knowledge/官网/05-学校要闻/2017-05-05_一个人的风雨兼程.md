# 一个人的风雨兼程

考研，是一场没有硝烟的“战争”。胡迪，独自一人，看不见对手，却依然风雨兼程，奋战在考研的漫漫征程上，终于收获了一封来自江西农业大学行政管理专业的硕士生录取通知书，成功地为这场“战争”画上圆满的句号。

当家人的建议与你的梦想背道而驰的时候，怎么选？倔强的胡迪毅然地选择踏上自己的圆梦之旅——考研！尽管作出这个决定的时候，已是6月份，距离其他同学考研复习的时间已经过去了3个月。

在确定了考研的目标学校和专业之后，胡迪开始制定自己的复习计划，把每天要做的事情做成可行性强的计划清单，把目标具体量化，坚定地执行“当日事当日毕”的原则。

坚定的目标，确定的方向，积极进取的心态，是胡迪在漫漫考研路上坚持下去的动力和勇气。谈及考研过程中遇到的困难，胡迪说，“在考研的过程中，我最大的收获就是学会了坚持，不放弃。当时，自己的心理压力比较大。随着复习时间越来越少，任务越来越重，那么多知识点要背，内心很煎熬。我也想过放弃，但是最后还是咬紧牙关坚持了下来。” 面对繁重的复习量和沉重的心理压力，胡迪用听歌、跑步来缓解情绪，保持自己的学习热情。

作为2013级行政管理专业唯一一名奋战在考研之路上的学生，胡迪在备考的过程中倍感孤单。身边没有同行的队友，前方看不见竞争的对手，她独自负重前行，风雨兼程。在独自备战的时候，政法系的韦朝毅老师向她伸出了援手——无论是目标学校的确定，还是在复习过程中的答疑解惑，他的建议和帮助对胡迪而言，无异于是雪中送炭。

“同时还要感谢一直关心着我的父母和男朋友，他们听过我抱怨，也默默忍受着我的牢骚，永远坚定地鼓励我、支持我。”胡迪感激地说。

回忆起走出考场的时候，胡迪心里一片坦然，努力奋斗的她问心无愧，“希望所有正在备战考研的师弟师妹们，能够做到坦诚、坦荡、坦然、坦率，要相信所有的坎坷终成坦途。”

对于未来，胡迪的计划是争取机会读博，将来做一名大学教师。
