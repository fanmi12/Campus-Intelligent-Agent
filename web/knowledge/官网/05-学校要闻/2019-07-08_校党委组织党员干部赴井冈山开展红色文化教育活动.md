# 校党委组织党员干部赴井冈山开展红色文化教育活动

7月5日-7日，为进一步加强开展“不忘初心，牢记使命”主题教育活动，我校党委组织党员干部前往井冈山，开展红色文化教育实践学习活动。参加此次主题教育实践学习班的成员有校党委委员章德胜、高香林、黄兢，本学年优秀党务工作者以及各二级学院优秀党员代表等。

6日上午，学习班举行了开班仪式。校党委书记章德胜为学习班授班旗，并作动员讲话。他强调，各位学员要以此次开展“不忘初心，牢记使命”主题教育学习为契机,重温井冈山革命斗争史,感悟先辈的革命精神，接受井冈山精神熏陶,进一步加强党性修养、坚定理想信念、保持优良作风,努力为我校教育事业的发展贡献力量。

团中央革命传统教育基地兼职教授、井冈山干部教育学院特聘教授、原井冈山市委常委李炳华应邀作了《井冈山斗争与井冈山精神》专题讲座。全体学员进一步重温了井冈山革命斗争历史，深入学习了井冈山精神，在思想上和心灵上都得到洗礼。

学习期间，全体学员身着红军军服，前往北山烈士陵园、黄洋界、小井红军医院、井冈山革命博物馆等红色文化教育基地开展了现场教学活动，接受红色文化主题教育。

在紧张紧凑的学习活动中，学员们纷纷反映，在井冈山实地开展“不忘初心，牢记使命”主题教育活动感触深刻、收获巨大，不仅更加深刻地理解了井冈山精神的内涵，也深深为先烈的革命精神所折服、所感染。学员们表示，今后将坚持以习近平新时代中国特色社会主义思想为引领，树牢“四个意识”,坚定“四个自信”,坚决做到“两个维护”, “不忘初心，牢记使命”，把井冈山精神真正融入到工作和学习中去，努力把学校建设成为特色鲜明的高水平应用型本科院校。
