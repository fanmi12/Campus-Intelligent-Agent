# 我院举行2017年暑期主任沙龙

8月28日，我院举行2017年暑期主任沙龙。主任沙龙由王卫平院长主持。城市学院董事会黎建烨董事、广东鸿发教育文化集团有限公司总经理陈超群、副总经理韩春华以及学院全体院领导和中层干部参加了本期沙龙。

?? 与会人员围绕我院2017－2018学年度的工作重点，展开了热烈讨论。针对如何有效开展教育教学中心工作、促进学院内涵式发展、加强校园文化建设等方面的改革与创新，大家各抒己见，畅谈新学年的工作思路和创新方法。

???广东鸿发教育文化集团有限公司总经理陈超群指出，城院中层干部是学院的中坚，大家要进一步树立忧患意识、大局意识，立足本职工作，知行合一，共谋发展。

?? 黎建烨董事代表董事会充分肯定了城市学院管理团队和全体教职员工在过去一学年所取得的工作成绩，要求大家与时俱进，坚定办学信心，认真做好学院二期建设的有关工作，全面提升后勤服务保障工作水平，实现又好又快发展。

???院长王卫平在总结中强调，在新学年里，我们要围绕 “大力加强学院各级党组织的党建工作、切实做好意识形态领域的安全工作，深化教育教学工作改革，深化学院人事制度改革、进一步完善全员绩效考核制度，深化团学工作改革、大力加强校园文化建设，进一步加大后勤保障体系改革力度，大力推进创新创业教育工作”等六项学院重点工作，统一思想，提高认识，深化改革，不断推进，使城院发展再上一个新台阶。
