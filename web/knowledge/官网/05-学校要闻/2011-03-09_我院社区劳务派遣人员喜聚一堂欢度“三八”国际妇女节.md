# 我院社区劳务派遣人员喜聚一堂欢度“三八”国际妇女节

3月8日，我院发展与联络办公室教工与樟村、堑头社区22位劳务派遣人员怀着轻松愉快的心情，在大王洲喜聚一堂，欢度“三八”国际劳动妇女节。

在春色满园的农家小岛上，热情、纯朴、勤劳的大嫂们畅所欲言，尽情的谈论着工作和生活中的乐趣。她们对学院为她们量身设置的弹性作息制度表示了感谢，认为该制度不仅有效地解决了她们工作和家务的冲突，还体会到了一种被关心、被尊重的温暖。大嫂们纷纷表示，要自立、自信、自尊、自强，在工作岗位上和家庭中积极发挥半边天的作用。
