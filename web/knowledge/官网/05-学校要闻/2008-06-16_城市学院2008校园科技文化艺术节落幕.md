# 城市学院2008校园科技文化艺术节落幕

“我们用曲艺演绎六月的多彩，用舞步旋转六月的欢欣；我们踏着青春的旋律走在时代的前沿，带着青春的风采走向辉煌的明天。”6月15日晚，我院在学院大礼堂隆重举行2008校园科技文化艺术节总结表彰大会暨闭幕式文艺晚会。

东莞理工学院副院长、城市学院院长安少华教授，城市学院党政领导朱志德、程发良、朱冰、张林，各系部、院直机关各部门负责人及1600多名师生出席和参加了闭幕式，并观看了文艺演出。

院学生会主席姚衡同学对校园科技文化艺术节进行了总结发言。他说，本次活动各系部积极配合，内容丰富，形式多种多样；同学们积极性高，参与面广，影响比较大，取得了累累硕果。组委会副主任章德胜副教授在闭幕式上宣读了城市学院《关于表彰2008校园科技文化艺术节先进集体和个人的决定》。

据悉，本届校园科技文化艺术节的主题是“迎接奥运，崇尚科学；舞动青春，创建和谐。”历时3个多月，活动内容涵盖科技、文化和艺术，先后开展了“网页设计大赛”、“DV大赛”、“校园工商模拟市场”、 “舞林大赛”、“口语表达比赛”、“奥运伴我行征文比赛”、“校园十大歌手比赛”、“绿色畅想环保宣传海报设计比赛”等18项活动。

颁奖仪式结束后，学院大学生艺术团为师生们献上了一场精彩的晚会。晚会围绕科技文化艺术节的主题分为四个篇章——《情系灾区》、《迎接奥运》、《舞动青春》和《创建和谐》。四个篇章高潮迭起，全场掌声欢呼声一浪高过一浪。

“512”这三个沉重的数字成为中华民族不能磨灭的记忆与伤痛，由朱志德书记作词、韦荣耀老师作曲以及学生处全体老师和各系辅导员合唱的一首歌曲《向前看》，把城院人众志成城与灾区同胞患难与共的决心表现得淋漓尽致，将希望的曙光洒在灾区重建家园的土地上。2008年是奥运年，这一年将记录在炎黄子孙的生命里，篆刻在中华民族的历史长河中。冰韵舞队一曲《奥运圣火》舞出了奥运圣火传递的一路荆棘一路风采，跳出了世界人民共同期盼北京奥运的激情与梦想。模特秀《环保精灵》则体现出城院学子们的创新思维、环保意识以及青春向上的风采。最后，晚会在悠扬动听的歌舞《美丽之路》中落下帷幕。
