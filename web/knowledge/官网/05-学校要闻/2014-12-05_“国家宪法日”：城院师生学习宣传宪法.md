# “国家宪法日”：城院师生学习宣传宪法

12月4日，是首个“国家宪法日”。城市学院师生以不同形式学习宣传宪法，纪念这一国家节日。

12月4日，文传系召开全体教师和学生党员会议，邀请院党委宣传部长何鹏举教授讲解十八届四中全会精神，重点阐述依法治国首先要依宪治国。

12月4日，政法系派出学生分赴莞城区寮步镇与市民共庆我国首个“国家宪法日”。许利娟老师、钟建勋律师等带领法学班的同学为广大群众免费提供法律咨询、派发传单。

12月4日，计算机与信息科学系组织全体党员学习十八届四中全会精神，原原本本学习国家宪法。

12月4日，思政部围绕宪法进课堂，依法治国为主题开展说课比赛。

12月5日，财经系利用早自习时间，组织1000多名大一新同学分班集中学习宪法。

党委宣传部唐跃碧老师说，师生们在“国家宪法日”集中学习宪法，有利于增强宪法意识，维护宪法权威，更好地贯彻习近平总书记“依法治国”的战略思想。
