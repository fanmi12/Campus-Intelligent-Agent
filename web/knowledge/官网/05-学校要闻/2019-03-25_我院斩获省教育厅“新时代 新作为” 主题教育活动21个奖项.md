# 我院斩获省教育厅“新时代 新作为” 主题教育活动21个奖项

日前，广东省教育厅公布了2018年“新时代 新作为——立志?修身?博学?报国”主题教育系列活动评选结果。在这次征集评选活动中，我院共斩获21项奖项，其中1个一等奖、2个二等奖、9个三等奖、9个优秀奖。

2018年，根据“新时代 新作为——立志?修身?博学?报国”主题教育系列活动要求，我院开展了初赛海选，并报送了一批优秀作品到省厅参加决赛。不仅夺得了21个奖项的骄人成绩，学院还获得优秀组织奖。
