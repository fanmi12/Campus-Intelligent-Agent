# 教育部评估中心院校评估处刘振天处长来我院视察

8月29日，教育部评估中心院校评估处刘振天处长来我院视察。东莞理工学院副校长安少华与东莞理工学院城市学院院办主任黄兢及东莞理工学院肖鹏博士一起接待了来宾。刘处长对我院所取得的办学水平表示充分肯定，对学院在短短九年的时间里取得的办学规模及成果表示惊讶，并鼓励我院再接再厉把学校办得更好。
