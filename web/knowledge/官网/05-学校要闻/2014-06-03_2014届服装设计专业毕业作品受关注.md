# 2014届服装设计专业毕业作品受关注

5月29日，东莞理工学院城市学院艺术系服装设计专业2014届毕业生作品发布会在寮步校区综合馆隆重举行，吸引了社会各界关注，东莞阳光网更是以《城市学院服装设计专业毕业生作品缤纷惹眼》为题置于《莞视界》首页展示。

时空斗转，本次展演以“意象岭南”为主题, 展出了应届毕业生的200多套优秀服装设计作品，主要体现原生态,回归自然与国际时尚潮流相结合的,岭南文化与现代文化的交汇。本次展演主角们将生活中的艺术与时尚相结合，承袭岭南美学元素，通过层次感的搭配、简约的廓型和灵动的色彩，加上不时迸发的灵感的细节点缀，一针一线编织出细腻的霓裳，引领观者品味对比中的和谐，简约中的优雅，赏析作品中的古典与现代、东方与西方、技术与艺术的碰撞。

2号设计师谭思源同学作品《Timing》，运用了永恒色——黑与白、简洁立体廓型、流畅的线条及复古的金色蕾丝。表现出香奈儿式的简约、优雅、干练、高贵，充分的展现出了都市之时尚精神。

4号设计师陈静怡同学作品《Hey! Gentlemans》以“绅士”为设计元素，硬朗的线条为主，简洁大方独特立体的款式突显着衣者的个性，精致的细节和搭配的轮廓更加完全体现时尚与前卫的感觉，也体现年轻、独立、愉悦轻松的理念。

据李秀琴副教授介绍，服装设计专业自创办以来，一直秉持“亲产业”的办学理念。本次发布会，就是与东莞山水乐人服饰公司通力合作下进行的。设计研发并展示的户外成衣作品系列《自然》，在创作的过程中,黄照阳、陈宏侃等学生融入了岭南传统服饰中的拼接等特色元素,表现了一种朴素的生活态度,创造了自然、简朴、高雅的氛围，可以说是设计与市场的完美融合。

中国新闻周刊安记者认为：城市学院的服装设计专业，使服装专业的毕业生为地区产业发展带来无限活力，从而助推东莞由“东莞生产”到“东莞制造”的产业转型升级，诠释了城市学院“服务东莞”的办学理念。
