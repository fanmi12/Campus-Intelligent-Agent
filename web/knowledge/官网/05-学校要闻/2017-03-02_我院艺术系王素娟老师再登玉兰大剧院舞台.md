# 我院艺术系王素娟老师再登玉兰大剧院舞台

2月24日晚，由广东省音协指导，东莞市文联、东莞玉兰管委会主办，东莞市音乐家协会、东莞保利玉兰大剧院管理有限公司承办的“2017年东莞市音乐家协会中外声乐精品音乐会”在东莞玉兰大剧院上演。我院艺术系优秀青年教师王素娟老师与其它七位同样来自东莞的歌唱者同台献唱，为观众献上了耳熟能详的中外艺术歌曲和经典歌剧唱段。我院艺术系2013级学生陈榕作为这场音乐会的钢琴伴奏之一，也在舞台上一展风采。

当晚，玉兰大剧院大剧场1600多个席位座无虚席，应邀出席音乐会的有来自广东省音乐家协会名誉主席刘长安、副主席金旭庚，秘书长乔建军，星海音乐学院声乐歌剧系主任男高音歌唱家杨岩，女高音歌唱家崔峥嵘，东莞市委宣传部副部长赵国营、东莞市文联主席周汉标及市音乐家协会各级领导等。我院各级领导也高度关注了这次音乐会，王卫平院长、章德胜副书记、周庆副院长、刘玉侠副院长以及学院各处室主任等领导亲临现场观看演出。

我院艺术系优秀青年教师王素娟老师曾于2014年11月在东莞玉兰大剧院成功举办过“音乐时代”专场音乐会。此次再度登上玉兰大剧院舞台，她为观众献上了独唱歌曲《春天年年来到人间》及俄罗斯民歌《夜莺》、男女声二重唱《啊，可爱的姑娘》、女生小合唱《我的深情为你守候》，并参与由全体演员共同演唱的曲目《我爱你中国》、《我的太阳》。王素娟老师以她甜美的嗓音、精湛的演唱功力、科学的发声技巧和深厚的艺术修养，赢得了在场观众经久不息的阵阵掌声与喝彩。

王素娟老师一直坚持着以赤诚的艺术热情和精益求精的敬业精神，投身于她所深爱的声乐教育事业，在声乐教学工作中始终以严谨的治学态度严格要求学生，并积极参与各类大型声乐大赛、大型演出，为学生树立榜样，“潜移默化”“言传身教”带动学生积极参加与专业相关的社会实践活动，积累舞台经验，为日后更好的走向社会工作打下坚实的基础。此次王素娟老师再度登上玉兰大剧院的舞台，不仅受到在校学生的热烈捧场，许多毕业生，甚至在外地的，也特意赶回东莞，为恩师捧场，一睹恩师在玉兰大剧院再次华丽绽放。
