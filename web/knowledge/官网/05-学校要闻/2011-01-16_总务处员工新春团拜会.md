# 总务处员工新春团拜会

1月15日，学生活动中心灯火辉煌，喜气盈盈。总务处在这里隆重举行后勤员工迎春团拜会。辛勤工作一年的200多名员工带着成功的喜悦，从各自岗位来到团拜会会场，说成绩，话体会，品美酒，赏佳肴，共祝愿，载歌载舞庆贺昔日的成功，展示对新年的憧憬。

院领导安少华、朱志德、程发良、朱冰、张林，院督学陈丁堂，以及院机关各部门负责人也来到团拜会，与员工们同贺同乐。

行政副院长张林在团拜会上发表了新春致辞。他说，院领导集体出席团拜会，这说明学院对后勤工作的重视，对员工们的亲切关怀。学院的发展离不开后勤工作，所取得的成绩也有后勤员工的一份功劳。“同志们辛苦啦，院领导、全院师生感谢你们。”张副院长的讲话，获得与会人员的热烈掌声。

总务处处长李奇希望全体员工发扬成绩，再接再厉，以校为家，以服务为荣，为学院的发展作出新的贡献。

副处长、党总支书记龙海燕宣读了总务处关于表彰优秀员工的决定。

接着，员工们表演了自创自编的文艺节目。舞台上，炊事员、保安员、宿管员、绿化工、送水工、水电工.....，各个部门的员工轮番表演；勺子、扫把、水桶、报话机....，工作用具都是道具；唱歌、跳舞、小品、家乡小戏，形式多样，集中表达了员工们“幸福城院”、“我们来自五湖四海”、“都是城院人”、“工作不分贵贱”的心声。
