# 我院开展暑假第三阶段迎评加班工作

评建办工作人员正在整理迎评材料

思政部召开迎评加班工作会

政法系召开迎评加班工作会议8月20日，我院各迎评单位工作人员纷纷返校，积极开展暑期第三阶段迎评加班工作。

上午9：00记者进行了采访，在学院“迎评促建”工作办公室，工作人员正在有条不紊地整理着各受评单位送来的堆积如山的各种迎评材料。思想政治理论课教学部召开迎评加班工作会，对前期评建准备工作进行了全面总结，并针对已发现的问题如试卷整理等提出具体的修正意见。政法系刘杰主任主持召开该系暑期迎评加班工作会议，全面部署迎评工作。

“迎评促建”工作办公室秘书长李先庆副教授告诉记者，我院评建工作已进入第三阶段，由于评估时间提前，原计划第四、五阶段的工作任务都要挪到本阶段完成，因此显得时间紧迫，任务艰巨。有关领导强调，各单位要夯实基础，真抓实干，力争迎评促建工作有序有效推进。
