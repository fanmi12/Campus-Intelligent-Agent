# 学院党委中心组召开学习研讨会

为贯彻落实广东省委《关于开展“继续解放思想，坚持改革开放，争当实践科学发展观的排头兵”学习讨论活动的通知》精神，3月14日，学院党委中心组在315会议室举办了“继续解放思想，谋求新的发展”的学习研讨会。

东莞理工学院党委委员、副院长，城市学院院长安少华教授到会并做重要讲话。

党委书记朱志德副研究员在会上首先传达了院党委2008年1号文件精神。他介绍说，根据省、市委及东莞理工学院党委的指示精神，学院党委决定在全院开展“继续解放思想，坚持改革开放，争当实践科学发展观的排头兵”学习讨论活动。要求全体教职工特别是广大党员要继续解放思想，不断改革创新，着力查找和解决影响学院发展的思想观念、发展思路、措施方法和体制机制等方面存在的问题，着力探索促进学院发展的新思路、新途径、新举措，推动学院“上水平、创特色”。这次学习活动分为“学习宣传、讨论调研、决策部署”三个阶段进行，5月底结束。

朱书记进一步指出，为了搞好第二阶段的学习，院党委印发了“继续解放思想，为城市学院谋求新发展”的调研参考题。各单位、总支（直属支部）要结合工作实际，认真开展调查研究活动。

在本次研讨会上，计算机与信息科学系主任牛熠博士、教务处处长助理李先庆副教授、社会科学系主任陈丁堂教授、金融与贸易系龙卫洋博士、社会科学系赵书山副教授和林晓老师，根据调研参考题的内容，分别就中国30年改革开放的思想源动力、办学模式、教学基础设施、师资队伍、实践基地、扩充系部权力等方面发表了自己的学习体会与工作建议。

院长安少华教授在讲话中强调，解放思想，首先是领导干部的思想要解放。思想是否解放，最根本的是看实践，看实际效果。要允许大家讲真话，说错话。专家学者的建议与措施非常好，有利于学院的发展。各单位的负责同志要做学习型的干部 ，不断了解新的信息和民情民意，正确处理好大环境与小环境的辩证关系，不断谋求学院新的发展。
