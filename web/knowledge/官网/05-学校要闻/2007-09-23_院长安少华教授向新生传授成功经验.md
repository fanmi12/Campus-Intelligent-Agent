# 院长安少华教授向新生传授成功经验

“大学生怎样才能成功？”9月20日，东莞理工学院副院长、城市学院院长安少华教授在新生入学教育第四讲中，畅谈成才之道，传授成功妙招，受到2000多名新生的好评和赞同。

安院长运用许多毕业生从这里走向社会、功成名就的典型事例，深刻阐述了自己归纳总结的学生三条成功经验：上大学深造是人生的最佳选择，是走向成功的必由之路；显现强大生命力的城市学院助同学们成功；创造机遇比抓住机遇更重要。他说，高中毕业后的李扬钦先生，成为全国知名的民营企业华夏集团董事长后，深感自己的学识学历学位不够，下决心补上了大学课程，最终成为清华大学的客座教授。据调查，东莞32个镇区领导班子成员中，20个镇区有我们的毕业生。

安院长指出，城市学院是求学深造的最佳地方。因为这里区位优势好，管理机制活，师资力量强，专业设置合理，更重要的是，城市学院经过几年的打拼，已经得到东莞人民的认可，成了你们高考首选的学院。这是你们明智的选择，是成功的开始，感谢各位同学和家长对城市学院的厚爱。

安院长希望同学们牢牢记住五句话：“不能输第二次”；“不懂的问题在图书馆里搞掂”；“笨鸟先飞，我加倍努力”；“天生我材必有用”；“社团是我家，成才靠大家”。安院长说，这五句话是五位毕业生的经验之谈，也是他们的成功之道，愿这五句话伴随你们走向成功。

在这一讲座中，我院96届毕业校友、客座教授、香港得利钟表制品有限公司副总经理刘仁博士，为同学们介绍了自己的成才经验。
