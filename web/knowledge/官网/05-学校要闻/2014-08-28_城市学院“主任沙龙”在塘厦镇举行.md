# 城市学院“主任沙龙”在塘厦镇举行

8月26日至27日，城市学院在塘厦镇举行主任沙龙，麦照容董事长、东莞理工学院党委副书记吕琦元亲临会议，杨敏林院长主持会议。会议期间，东莞理工学院校长李琳接见了与会人员。城市学院院领导杨敏林、王卫平、张林、陈丁堂、章德胜、高香林、麦绮琳以及各系部、机关处室的主要负责人参加了会议。

与会人员畅所欲言，献计献策，就如何深化改革、完善顶层设计、提高教育教学质量、优化管理与服务等关系城市学院未来发展的重大问题展开了热烈讨论，提出了许多宝贵的建议。

与会人员认为，今年学院招生生源火爆，省线以上第一志愿录取新生5000多人， 说明我院教育教学质量及管理水平不断得到社会认可，同时给城市学院建院10周年增添了光彩。在兴奋之余，我们务必保持清醒的头脑，居安思危，不断进取，力求快速发展中讲质量，全面深化改革，完善顶层设计，以提高教育教学质量为核心，加强师资队伍建设，优化师资管理，提高服务教师发展进步、学生成长成才的工作水平，深入探索适应地方经济社会发展需求的应用型人才培养模式，加快学院办学的转型发展。许多与会者建议，应进一步完善董事会领导下的院长负责制，尽快建立教授委员会，实行年金制，管理重心下移，优化应用型人才培养方案，完善财务制度、薪酬制度、加强青年教师培养，让广大师生更多更好地参与到学院的整体发展中来，凝心聚力，为把城院建设成百年名校而共同努力。

在认真听取与会者的发言后，麦照容董事长发表了热情洋溢的讲话。他首先衷心感谢东莞理工学院的信任和支持，高度赞扬城市学院管理团队的工作成绩。他说“主任沙龙”这个形式很好，有利于推心置腹地沟通交流、分析问题和献计献策，今后应坚持下去；希望城市学院通过“感情留人、待遇留人、发展留人、环境留人”，不断凝聚优秀人才，让大家安居乐业，实现学院和个人共同发展；城市学院的管理团队要大胆尝试与创新，把大家的好想法变成具体的行动；与会人员要把会议精神传达到全体教职员工。他还明确表示，鸿发集团和他本人全力支持城市学院的工作，下定决心把城市学院办成百年名校，并借助城市学院的智力资源、管理资源增强鸿发集团的发展后劲，相信城市学院和鸿发集团的明天一定会更加美好。

东莞理工学院党委副书记吕琦元同志做了简短讲话。他在肯定城市学院多年来的办学成绩后指出，事实证明，东莞理工学院与鸿发集团合作办学是利国利民的大好事，不断得到了社会各界尤其是学生和家长的认同，并表示城市学院的事情就是东莞理工学院份内的工作，今后将全力支持城市学院的快速健康发展。

杨敏林院长主持会议时表示，城市学院有一支水平高、素质好、责任心强的教学与管理服务团队。在董事会的正确领导下，我们将创造性地开展工作，把各项工作提升到更高的水平。
