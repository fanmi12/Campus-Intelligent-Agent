# 广东省教育厅副巡视员邱克楠一行莅临我院调研

5月3日下午，广东省教育厅副巡视员邱克楠、广东省高等学校毕业生就业指导中心副主任刘卓、广东省教育研究院高等教育研究室副研究员田峰、广东省创业教育指导委员会秘书长王华、广东轻工职业技术学院创业学院副院长卢应涛等一行6人莅临我院调研就业创业工作。调研活动旨在贯彻落实广东省2018年高校毕业生就业创业工作会议精神，以创业带动就业，以创新引领发展。调研组认真听取了我院近年来就业和创新创业工作情况汇报，并实地调研就业指导服务场所和创新创业实践场地等。

学院院长王卫平、董事长代表陈超群、院党委副书记章德胜、副院长黄兢、院长助理林江龙等及有关部门负责人陪同调研。

座谈会上，王卫平院长对邱克楠副巡视员一行莅临我院指导工作表示热烈欢迎，对省教育厅长期以来对我院教育事业发展的支持表示衷心感谢。王卫平院长介绍了学院基本概况，围绕“学院高度重视、强化目标责任，深化创新创业教育改革，打造线上线下就业创业双平台，精准帮扶、层层落实毕业生就业创业工作责任制，落实‘四到位’，存在问题与对策”等方面重点汇报了学院就业创业工作情况。

邱克楠副巡视员对我院精准提供就业创业服务、积极推进产教融合的工作给予了肯定和称赞。邱克楠副巡视员要求学院做好对就业困难学生的帮扶，动员全院力量完成好省厅部署的工作任务；完善创新创业工作的激励机制，加强创业教育组织与管理的力量，为创新创业提供有力的组织与制度保障；以第四届“互联网+”大学生创新创业大赛为契机，充分发动学生参赛，同步做好“青年红色筑梦之旅”的相关动员组织工作。

邱克楠副巡视员强调，省教育厅正着力贯彻落实国家创新驱动发展战略，积极推进“大众创业、万众创新”，希望东莞理工学院城市学院加大力度深化创新创业教育改革，完善创新创业工作队伍建设，加强创新创业场地建设，推进创新创业工作迈向新台阶。

调研期间，邱克楠副巡视员一行先后参观了商科虚拟仿真实践教学中心、创意设计学院、招聘路演大厅、大学生创业孵化基地等创新创业实践场地。邱克楠副巡视员与我院学生创业团队进行亲切交流，鼓励同学们继续努力，为推动区域经济发展助力。
