# 我校邓星明教授应邀担任东莞市广告设计师职业技能大赛评委

2012年9月7日、8日，由东莞市总工会、东莞市人力资源局主办、东莞职业技术学院承办的《东莞市广告设计师职业技能大赛》在东莞职业技术学院举行，我校文学与传媒系主任邓星明教授应邀担任大赛的评委。大赛分职工组和学生组进行，内容有理论比赛和设计实操比赛。
