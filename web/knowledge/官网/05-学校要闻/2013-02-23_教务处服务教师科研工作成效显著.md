# 教务处服务教师科研工作成效显著

2012年学院获得的市级及以上科研项目一览表

教务处在着力抓好教学工作和教学研究工作的同时，大力推进科研工作，及时给教师传递科研工作信息，组织教师申报科研项目，为地方的社会经济建设服务取得明显成效。2012年，我院共有24个科研项目获国、省、市有关部门立项。

有资料显示，该处一是组织开展了广东省与东莞市科技计划项目的申报工作，共有7个项目获准立项。其中广东省科技计划项目2项，东莞市科技计划项目5项，共获得科研经费67.5万；二是组织开展了2012年国家社会科学基金重点项目的申报工作，管理系帅建华教授申报的“儒学的现代人本管理价值研究”获准立项，获科研资助经费25万元；三是组织开展了广东省思想政治教育课题的申报工作，有2项课题获准立项，获得科研经费1万元；四是组织开展了东莞市社科规划项目的申报工作，有10个项目获准立项，共获科研经费8万元。五是鼓励教师开展横向研究，共立项3项。

与此同时，教务处还组织开展了3个省级和2个市级科技计划项目的结题验收及鉴定工作。3个省级项目分别是：智能计算在SOC中的应用研究；快速油品质量分析仪的研制；广东省科技宣传与公众认识科技工作研究。2个市级项目分别是：纳米气象二氧化硅在储能用胶体蓄电池中的作用机理及应用研究；软开关双丝脉冲MAG焊电源装备及其嵌入式控制关键技术研究。评审组专家们对纳米气象二氧化硅在储能用胶体蓄电池中的作用机理及应用研究的研究给与了高度评价，认为该项目的研究成果达到国际先进水平。
