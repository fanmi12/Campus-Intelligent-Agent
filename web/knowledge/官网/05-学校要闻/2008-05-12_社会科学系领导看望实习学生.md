# 社会科学系领导看望实习学生

5月8日，社会科学系主任陈丁堂教授、教学实践办王雄文主任一行专程到中国新闻社东莞支社、中国建设银行东莞分行、东莞光盈科技公司等单位看望毕业生。

陈主任每到一处，与实习生亲切交谈，问寒问暖，了解学生实习中遇到的困难，勉励学生虚心学习、戒骄戒躁；感谢实习单位为学生提供了很好的学习条件。

据悉，实习单位对我院的毕业实习生评价很高。90%的实习生已经与所在的单位达成了就业意向。
