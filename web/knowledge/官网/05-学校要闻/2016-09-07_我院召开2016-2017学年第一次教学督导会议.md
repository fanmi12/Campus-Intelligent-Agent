# 我院召开2016-2017学年第一次教学督导会议

9月2日，我院新学年度第一次教学督导工作会议在行政楼207会议室召开。王卫平院长、研发处赵书山处长、教务处副处长鞠晓红和学院全体教学督导员参加了会议。

专职督导员宋欣荣教授对上学年的督导工作进行了总结，并对本学期的督导工作要点及要求作了具体说明。赵书山处长表示，今后将继续坚持督导工作原则，坚持督与导的结合，坚持督教、督学、督管的结合，坚持常规督导与专项督导的结合；着力发现、总结、推广教师中的先进教育教学经验，反映广大师生员工的心声，做广大教师的良师益友。

王卫平院长在讲话中指出，学院历来重视教学督导员队伍的建设，重视教学督导工作在提高办学质量系统工程中的重要作用。本届新成立的教学督导员队伍是由各相关专业的经验丰富、德高望重的教授组成，并特别邀请了来自台湾高校的钟明仁博士加入，队伍结构更趋合理。他希望督导组能够在新学年的工作中，进一步规范教学行为和管理行为，在鼓励、发动教师的教学研究热情以及积极向上的工作态度上继续发挥重要作用，在青年教师的培养上起到引领作用。

会上还给兼职督导员颁发了聘用证书。
