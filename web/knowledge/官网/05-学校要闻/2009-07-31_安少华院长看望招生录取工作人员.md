# 安少华院长看望招生录取工作人员

7月31日上午，院长安少华教授在党委副书记朱冰、院办主任王玉的陪同下，来到2009年招生录取现场，看望参加招生录取工作的有关人员。

安院长说，今年我院第一志愿报考率再创新高，在省内众多名牌大学举办的独立学院中名列第五，这充分说明了东莞城市的魅力越来越大，东莞理工学院和东莞理工学院城市学院的办学水平越来越高。招生成绩的取得，是学院知名度和美誉度双双提高的综合反映，是学院办学指导思想和奋斗目标得到切实有效贯彻执行的结果，是学院管理和教学水平得到广东人民，尤其是东莞老百姓认可的表现，是全院师生员工辛勤工作的结晶。希望招生工作人员一定按照招生政策，确保录取工作顺利进行，多做让考生及家长高兴的事。在场的录取工作人员表示，一定在录取工作中秉公办事，按规定的招生程序操作录取。
