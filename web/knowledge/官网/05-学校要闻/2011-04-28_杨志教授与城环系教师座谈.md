# 杨志教授与城环系教师座谈

4月25日，中国人民大学经济学院教授、循环经济领域理论研究第一人杨志教授在结束城市学院大讲堂后，在315会议室与城环系的老师们进行了座谈交流。杨教授在听取肖红飞主任对城环系，特别是低碳经济研究中心的发展现状的简要介绍之后，对我院的低碳工作提出了建议，她希望我院能与英国爱丁堡大学合作，逐步开展低碳管理的培训工作，争取创办低碳管理方面的相关专业。
