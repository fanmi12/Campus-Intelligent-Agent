# 我院女教职工登山赏春

水濂山风光旖旎，微风习习。3月8日下午，为庆祝国际妇女节，丰富教职工文体活动，院工会组织我院百余名女教职工登水濂山，观景踏春。

参加活动的老师们饱览秀丽的湖光山色，一路谈笑风生，其乐融融。大家不畏山势陡峭，发扬“不到长城非好汉”的精神登上了山顶。学院党委副书记朱冰也饶有兴致的参加了活动，并在活动结束后与大家合影留念。

据悉，3月8日这一天，许多女教师都收到了同学们赠送的鲜花和小礼物。
