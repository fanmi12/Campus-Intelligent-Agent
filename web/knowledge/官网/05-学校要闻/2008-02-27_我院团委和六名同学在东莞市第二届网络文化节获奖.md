# 我院团委和六名同学在东莞市第二届网络文化节获奖

近日，我院梁志娜、王育德、莫冰、陈嘉慧、胡嘉敏、罗雪芳等六名学生在东莞市文明办、共青团东莞市委、东莞市青年联合会、东莞市教育局、东莞市文化广电新闻出版局、东莞广播电视台等八家单位联合举办的“青春东莞•魅力宽带”东莞市第二届青少年网络文化节中获奖，院团委荣获“优秀组织奖”。
