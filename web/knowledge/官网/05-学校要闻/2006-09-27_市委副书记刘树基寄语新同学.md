# 市委副书记刘树基寄语新同学

9月26日，中共东莞市委副书记、东莞理工学院党委书记刘树基，莅临我院作新生入学教育报告。2300多名新同学在田径场聆听了刘书记的报告。一些新同学告诉记者，面对面地听市委领导作报告，还是第一次。

刘书记对今年入学的新生深情地说，大学的学习生活是人生中难得的时期。在你们长身体、长知识的时候能够踏进大学的殿堂学习深造，这是人生的一大幸事，是一次极好的机会，希望你们加倍珍惜！同时你们要感谢党和政府，感谢社会、感谢父母亲对你们的关怀，为你们创造了条件。

刘书记说，社会在发展，时代在进步，世界的未来属于年青一代，东莞的未来属于你们。东莞经过20多年的改革发展，发生了翻天覆地的变化，这与充分培养和大量使用人才分不开。今后20年东莞要实现持续、稳定的发展，必须靠科技、教育的发展来支撑。东莞理工学院和城市学院承担了重要责任，使一批又一批有用之才从这里走向东莞的各行各业。东莞的发展寄希望于城市学院，东莞的前途寄希望于你们。

最后，刘书记给新生们提出了四点希望：一是要做有理想、有抱负、对国家、民族和社会有用的时代新人，要有为国家、为民族的振兴而努力奋斗的决心，要有为社会、为人民做贡献的思想。二是要加强思想磨练和道德修养，做到诚实、勤劳、勤俭。不断弘扬中华优秀传统美德，培养新的时代精神，练就自立自强的能力。三是要勤奋学习，刻苦研究，掌握扎实的知识和过硬的本领。四是要做到一专多能，全面发展。既要有突出的专业特长，又要有厚实的人文素质，良好的英语水平和电脑技能，以适应经济全球化和知识经济快速发展的需要。

东莞理工学院副院长、城市学院院长安少华教授出席会议。院党委书记朱志德主持大会。常务副院长程发良教授、副院长林世俊教授、党委副书记朱冰及各系部的主要负责人在主席台前排就坐。
