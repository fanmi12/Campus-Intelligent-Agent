# 我院合唱团赴市倾情演出，庆祝党的生日

“我的家在东北松花江上，那里有森林煤矿……”，7月1日，我院合唱团在东城影剧院，倾情演唱红色经典脍炙人口歌曲《松花江上》，为东莞市庆祝中国共产党成立89周年暨首届东莞市合唱节闭幕式音乐会献上大礼，获得与会领导与观众的高度评价。

市领导黄双福、严小康、庞国梅、王道平、张顺光等出席了音乐会并为获奖单位颁奖。

倾情演出 庆祝党的生日

合唱音乐会上共演唱了《松花江上》、《雪花》等10首歌曲。歌手们倾情歌唱，庆祝中国共产党建党89周年。据悉，在东莞音乐合唱节上，三个获金奖的单位中，只有城市学院合唱团参加了庆祝会的演出。

技压群雄 勇夺金奖

合唱《松花江上》,以倾诉性的音调贯穿全曲，真切感人，旋律以环回萦绕，反复咏唱的方式引伸展开，感情真切激动，当尾声唱出呼天唤地似的旋律时，歌曲达到了高潮，歌声深深打动了在坐的每一位。

本次活动由市委组织部、市委宣传部、市直工委等13个部门和单位联合主办。
