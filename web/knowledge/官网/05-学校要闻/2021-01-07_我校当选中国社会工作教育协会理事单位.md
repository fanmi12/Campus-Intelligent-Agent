# 我校当选中国社会工作教育协会理事单位

12月26-27日，中国社会工作教育协会2020年会暨“全面建成小康社会背景下社会工作发展研讨会”通过腾讯会议在线上召开，我校成功当选成为“中国社会工作教育协会理事单位”！

法学院将在学校作为理事单位的基础上，积极与中国社会工作教育协会合作，培养专业化的社会工作队伍、服务最广泛化的有需要群体、形成更加成熟的社会工作实践模式，从而为国家善治、人民幸福做出更加积极的贡献！

会议特邀嘉宾、中国社会工作教育协会各理事单位、会员单位近千人次通过线上会议、网络直播等形式参加了本届年会。国际社会工作学院联盟(IASSW)主席安娜玛瑞亚教授、原主席丽娜·多米内利教授通过视频发来了热情洋溢的祝贺。

此次年会内容丰富，设有第二届青年学者论坛、第二届研究生论坛、督导与医务专委会论坛、司法社会工作专委会论坛、儿童社会工作专委会论坛、妇女社会工作论坛、社会工作伦理、实验教学等多个分论坛，对当前社会工作各个领域的发展进行深入探讨。

国际社会工作学院联盟原主席、大湾区香港社会服务专业联盟联席主席、香港理工大学原副校长阮曾媛琪教授致辞中提到，希望通过主办此次年会，加强各高等院校与中国社会工作教育协会合作的广度和深度，从而不断提升社会工作教育质量，使社会工作日益成为不可替代的专业领域。同时号召全体会员团结一心，共同为高质量社会工作学科建设做出努力，为实现国家治理体系和治理能力现代化做出社会工作教育界的贡献。
