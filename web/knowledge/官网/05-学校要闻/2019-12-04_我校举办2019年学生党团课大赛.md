# 我校举办2019年学生党团课大赛

为扎实开展好学校“不忘初心、牢记使命”主题教育， 11月28日，我校在行政楼112室举行了“激扬青春梦，奋进新时代”学生党团课大赛决赛。

担任本次决赛评委的是：校党委委员杜鹏举、党务工作部副部长叶凯贞、学生处副处长蔡小锋、校团委书记李瑶、马克思主义学院专任教师、博士石瑞丽。各二级学院党总支副书记、学生党支部书记、团总支书记也出席了决赛现场。

决赛在庄严的国歌声中拉开帷幕。党课组张利成以“青春梦与新时代”为题，通过一百年前的青年与新时代的青年对比，为大家诠释了什么是青春梦，如何实现青春梦；团课组李玥彤同学与现场观众一同探寻新时代下青春的航向，并号召青年一代清空标签，用行动为自己正名；团课组谭云扬开门见山向大家提问：我们青年人能为国家做什么，随后结合自身和身边优秀同学的经历诠释了她的理解。

各参赛选手的讲课内容紧紧围绕大赛主题，结合自己的切身感受，既有理论深度，又有实践意义，让现场观众感受到了青年党员、团员意气风发的精神面貌。

杜鹏举委员总结要求青年党员、团员从自身做起，认真学习党章、团章，以及党的十九大精神及习近平系列重要讲话精神，深刻把握新时代主题，找准自身发展方向，勇做走在时代前列的奋进者、开拓者、奉献者。
