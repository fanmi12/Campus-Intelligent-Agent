# 北京师范大学刘象愚教授莅临文传系讲学

6月20日，北京师范大学教授、博士生导师刘象愚教授应邀来我院，与中文教研室、英语教研室部分教师座谈比较文学和和文学理论的一些学科前沿问题。文传系主任陈庆祝教授主持了座谈会。

刘象愚教授是我国著名比较文学及文学理论专家，他《文学理论》（译著）、《比较文学概论》（编著）等教材在学界产生强烈而持久的影响，长期从事外语研究、比较文学研究、文学理论研究，并担纲翻译世界文学名著《尤利西斯》。

刘象愚教授在文传系着重介绍了比较文学并就相关问题与老师们进行了学术探讨。
