# 我院荣获省高校宣传思想工作优秀作品评选二等奖

2018年广东省高校宣传思想工作优秀作品征集评选活动结果近日揭晓。我院《“牢记时代使命，书写时代华章”——学习进行时专题展》作品荣获“优秀媒体融合报道作品”二等奖。

2018年广东高校宣传思想优秀作品评选活动是由广东省教育厅主办，共评选出优秀新闻作品、优秀新媒体作品、优秀校报版面作品、优秀媒体融合报道作品、优秀网络设计作品等五大类作品。

去年，我院举办“牢记时代使命，书写时代华章”——学习进行时专题展，融合了微信、网站、校报、广播、宣传栏等传播平台，差异化、立体式地进行宣传，在全院展开主题学习教育活动。校内各基层党组织以观展为契机，开展党员教育活动，做好宣传工作，营造了良好的政治学习氛围。

据介绍，依托现场展览、微信推文、官方网站、校报、校园广播、宣传专栏等媒体融合进行宣传，全院参与学习习近平总书记系列重要讲话精神的师生员工、校友共计超过2万人次，对我院自觉以习近平新时代中国特色社会主义思想为指引并付诸实践，具有重要的现实意义。
