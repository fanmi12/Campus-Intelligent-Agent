# 东莞理工学院召开两校区教学工作协调会

7月5日，东莞理工学院在校本部召开两校区教学工作协调会。东莞理工学院副院长安少华教授、教务长林养素教授以及两校区各系部和机关负责人共30多人出席了本次会议。

会上，安院长总结了今年上半年的教学工作情况。他指出，今年第一学期的教学工作圆满完成任务，总的情况不错，但是我们必须认真总结经验，进一步加强教学管理，充分调动教师教学的积极性，发挥他们的教学水平，进一步提高教学质量。随后，城市学院和成教学院也分别汇报了今年上半年的教学工作情况，与会人员还就教学上存在的问题进行了商讨。
