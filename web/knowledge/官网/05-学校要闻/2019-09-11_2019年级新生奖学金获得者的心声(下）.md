# 2019年级新生奖学金获得者的心声(下）

气有浩然，学无止境。高考有点失意，本以为考不上想去的学校将是我人生中一件很难过的事情，但是当我进入城院之后我瞬间萌发了一个想法——我的人生才刚刚开始！我相信在这个美丽的校园里通过自己的努力能够不断进步、成就更好的自己！

——19级外国语学院英语2班 梁虹钰

很荣幸能获得新生奖，感谢学校对我的肯定与鼓励，让我更有信心的迈入大学生活。我会脚踏实地地学好专业知识，积极参加社团活动和讲座演讲，锻炼并提升自身能力。在我看来，大学与中小学的区别在于一个“大”字，心大、胆大、格局大！我希望四年后的我能像“大”字靠近一步，能做到无悔于自己的青春年华。

——19级外国语学院商务英语4班 方绮婷

开学典礼和开训仪式给我的感觉就是非常隆重，让我感受大学的氛围，也明白了军训的必要性。获得新生奖学金，让我产生了荣誉感，也减轻了家里的负担，很感谢学校对我的鼓励。未来我会认真学习专业知识，在课余培养自己的兴趣爱好，尽快去适应和融入大学生活。

——19级文学与传媒学院 汉语言文学3班 叶晓燕

新生奖不仅使我的内心振奋，更坚定了我要努力充实自己，让自己变得更加好的愿望。大学四年一定要多接触外面世界，多找机会学习，并乐在其中。未来可期！

——19级商学院会计3班 谢泳强

进入大学，学习专业性知识，探究的问题很深很广，并不容易上手。我觉得我们应该脚踏实地学习。当我拿到新生奖时我很意外，意外的是我竟然是高分段学生，同时也很感谢学校给我这个奖项。

——19级文学与传媒学院网络与新媒体2班 刘施荣

一开始得知录取结果挺难受的，因为志愿没报好掉到二本，总觉得自己的努力白费了。直到开学后的第二天收到学生会的通知进行颁奖彩排，才觉得自己的努力是有回报的，家人知道这个消息后也非常开心。希望自己能够不荒废时间，充实自己，尝试考教师资格证，实现自己的梦想！

——19级商学院会计10班 刘静雯

我很高兴能获得新生奖学金这一很难得的荣誉！我的高考成绩在我看来并不理想，但我必须接受这个结果，继续往前走。我相信，我命由我不由天！也正是因为这个荣誉，我变得更加自信。高考，不是我人生的最后一战，我还能走其他路去成长，所以我相信我有能力学好做好玩好。我希望，能在大学里不断挑战新的自己，走向更大的舞台！

——19级外国语学院英语2班 刘佩欣

很开心可以获此殊荣，自己高中的努力没有白费。我希望在城院能认识更多有趣的朋友，学好自己的专业，不断地充实自己、提高自己，做最好的自己。

——19级法学院法律5班 卢思婷

很感谢学校的肯定，这也是我继续前进的动力。希望可以尽快转变自己的心态，切换到大学生的角色，希望可以在班上或者部门中争取一个职位，培养一下自己的能力，在自己力所能及的范围内做更多的事，专业的课程也希望可以学习得很出色。

——19级文学与传媒学院网络与新媒体3班 梁子兰

很感谢学校对我们的肯定和鼓励，在上千人面前抱着瞩目的奖状令我激动。在那个瞬间，更增强了我想要更上一层楼的信心。

——19级文学与传媒学院 网络与新媒体专业4班 周妃燕

拿到奖学金的时候挺开心的，毕竟帮家里节省了一笔钱。以后也要好好读书吧，争取拿更多奖学金，不要浪费大学四年时光，不要辜负家长对自己的期望！

——19级商学院 会计专业1班 邓慧铭

（大学生记者 姚星 郑淑君 温海琳 陈晓欣 詹钰莹 张子璇 杨文浩 曾香洲 徐怡清 魏静 黄燕菲 罗思琪 杨文浩 ）
