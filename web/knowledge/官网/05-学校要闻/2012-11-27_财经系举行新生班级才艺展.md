# 财经系举行新生班级才艺展

以“我耀我财经，‘艺’起更精彩”为主题的财经系2012年新生班级才艺展11月23日在新校区学术报告厅火热上演。

在简短的才艺展启动仪式上，财经系主任罗卫国教授手持火炬，点燃屏幕上的鞭炮，拉开了才艺展的序幕。

首先登场的舞蹈《monica》青春活泼、动力十足，尽显财经学子的朝气蓬勃。《贺十八大颂党恩》朗诵表演展示了城院学子对党的热爱及向往、别样的趣味舞蹈《just show show》展现出财经系新生们的活泼与幽默、合唱《一路走来》在回忆大学生活中显示了班级的团结与友爱、温柔动听的《一首简单的歌》，一个个精彩的节目都让在场的嘉宾和观众不断报以热烈的掌声，也让晚会的气氛不断活跃。手语舞蹈《舞出青春》回忆了大一新生踏入城市学院以来的大学生活，他们用创意十足的表演表达着他们对于离家的思念以及对大学生活的向往和憧憬，更彰显了当代大学生应有的青春与活力，动情的表演让在场大一新生感同身受，许多同学为之动容。

才艺展晚会期间还邀请了财经系11级优秀班集体代表展示优秀班集体风采，此外，我院第八届校园十大歌手冠军何权修和财经系2012年才艺大赛歌唱组冠军邹新蓉为晚会共同献唱《窗外》。在晚会的尾声，财经系新一届团学干部进行走秀表演，每一位干部的出场都引起了现场观众的不断欢呼，使晚会达到高潮。

来自财经系12级会计学7班的手语舞蹈表演《舞出青春》力压群雄，勇夺桂冠，舞蹈《歌舞青春》、舞蹈《just show show》和合唱《一路走来》荣获二等奖，朗诵《贺十八大颂党恩》、舞蹈《monica》和歌唱《一首简单的歌》获得三等奖。院团委书记罗文芳、财经系主任罗卫国教授以及财经系党总支书记叶凯贞分别为获奖班级颁奖。
