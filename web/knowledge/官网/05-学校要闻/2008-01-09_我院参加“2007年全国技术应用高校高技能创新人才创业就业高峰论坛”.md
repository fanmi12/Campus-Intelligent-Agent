# 我院参加“2007年全国技术应用高校高技能创新人才创业就业高峰论坛”

上月27日至28日，由上海第二工业大学、北京联合大学、天津职业大学为主办单位，上海高校就业指导中心、上海高校就业促进会、清华大学就业指导中心、北京大学就业指导中心为指导单位的“2007年全国技术应用型高校高技能创新人才创业就业高峰论坛”，在上海第二工业大学召开，来自全国各地的60多所应用型高校以及部分在沪的大型高科技企业应邀参加了此次高峰论坛，我院就业指导办公室主任江小卫代表城市学院参加了会议。

会议期间，与会人员共同探讨了技术应用型高校高技能创业新人才培养模式，以及如何构建技术应用型高校高水平的就业指导和创业教育工作体系，如何构建就业与创业课程体系建设等问题。会上，来自上海市教委、清华大学、北京大学和上海高校就业促进会的领导进行了精彩的发言，各参会高校和企业就培养人才创新能力和就业能力深入交换了意见。
