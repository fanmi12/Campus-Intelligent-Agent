# 400名新生聆听人生励志讲座

“李嘉诚、比尔盖茨的成功人士励志故事我们听多了，今天就来听一听我们身边成功人士的故事。”东莞电视台著名主持人方亮此番点评，为讲座拉开了帷幕。

11月20日，思政部在学术报告厅开展了“《思想道德修养与法律基础》之人生励志讲座”。东莞台科精密机械有限公司总裁刘文聪担任了讲座嘉宾，主持嘉宾是东莞电视台著名主持人方亮。

刘文聪为同学们细细地讲述了他坎坷而不平凡的一生。他始终以“不认命、不服输、不走寻常路”的精神态度打拼人生。他没有上过大学，仅是机电一体化专科毕业生。1998年，他在虎门一家五金厂的担任作业员。2002年刘文聪和六位同伙在偶然的机会下，踏上了创业的艰苦之路。从最初的加工店到现在成为东莞台科精密机械有限公司总裁，公司年产值过亿元。

“人生就是一所社会大学，学习也不是一成不变的，重要的是多动脑去悟去学，才能学到更加丰富的知识！”刘文聪认为，作为一名当代的大学生，应该具备以下两点：1、树立正确的人生观；要理智地理解成功不仅仅是做老板，当官，或者拥有财富，而是以后能为人们造福，为社会做贡献，让自己的人生价值得到体现。2、确立人生目标；把学业学好的同时，确立正确的人生目标，并为之奋斗，打好基础。现在，刘文聪还在清华大学攻读EMBA，坚持终生学习。

据悉，刘文聪的有关视频资料，已在思政部教学网站登出，同学们可以上网观看。
