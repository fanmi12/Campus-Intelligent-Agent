# 文学与传媒系举办青年教师说课活动

3月29日，文学与传媒系英语教研室举行青年教师基本功说课活动。本次活动由英语教研室主任刘浔教授主持，高教研究与评价中心屠大华教授应邀出席。

5位青年教师分别从课程教学目标，课程的地位和作用，课程章节的安排，逻辑联系及重、难点，主要的教学活动，课后阅读书目等对某门课进行讲解和说明。严谨而生动的说课过程反映出老师们为了上好每堂课，讲好每个知识点在课后所付出的辛勤劳动。

张云老师就《跨文化交际》课程进行说课时非常欣慰的提到，她的毕业生反馈说由于他经常和外国人打交道，《跨文化交际》在他的工作中发挥了很大的作用。罗笑婷、聂琳、梁琳婉、黄燕丽老师也先后就《第二外语（日语）》、《英语听力》、《英语国家概况》、《论文写作》进行了说课，每位老师讲解结束后均安排了提问、讨论环节，并提出意见与建议。

同时，老师们还就如何提高学生素质，情感与道德、学习习惯的培养；图书信息资源，毕业论文，人才培养方案，任课教师继续教育等多方面提出了独到的见解和建议。
