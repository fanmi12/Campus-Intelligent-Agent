# 高校社区互助共建  加强就业援助力度

6月20日，“服务东莞、共建和谐社区”启动仪式在315会议举行。出席仪式的领导和嘉宾有，市劳动局副局长叶太湖、东城区委副书记、办事处主任卢润江、东城区委委员徐建文、东城区劳动分局局长袁汝钦、堑头社区党总支书记黎惠成、樟村社区党总支书记卢敬崧、堑头社区副主任陈建华、学院党委书记朱志德、行政副院长张林、学院相关部门负责人及各系系主任。参会的还有30余名樟村、堑头的社区居民代表。

日前，为继续实施“创业东莞”工程，加强就业培训和就业援助力度，在市劳动局、市民政局、东城区政府的大力支持下，东莞理工学院城市学院与东莞市东城区樟村、堑头两个社区联合举办了社区居民“创业培训班”。

培训班于4月24日开班，由城市学院管理系罗余才教授、徐中和教授等相关专业骨干教师担任培训任务，培训对象主要是两个社区的待业人员，培训内容为创业及就业前的技能教育，共有60余名学员参加了为期近两个月的培训。此外，学院还以劳动外包的形式，为樟村、堑头两社区提供了20个就业岗位，帮助社区化解居民就业难题。

启动仪式上，朱志德书记讲话指出，服务东莞求支持，面向市场求创新，是我院的办学宗旨，共建和谐社区是学院服务东莞的一项具体内容。我们通过为社区服务这个平台，为师生提供一个施展才华的平台。在市委市政府的领导下，学院有信心把服务东莞的工作做好，为东莞经济社会双转型提供智力支持。

东城区劳动分局局长袁汝钦为培训班学员代表颁发了结业证书，朱志德书记宣布堑头社区首批10名居民以劳动外包形式在我院就业上岗。

随后，东城区委委员徐建文发表了讲话。他首先代表东城区委、区办事处对活动的举行表示热烈的祝贺，感谢市、区劳动部门和城市学院的工作。他说，就业是民生之本，也是建设和谐社会的重要内容，这次以社区和高校联合举办的就业培训班，并由社区外派劳动力到高校工作是第一次新的尝试。“创业东莞”工程的实施，必将推动我区居民就业工作走上一个新的台阶。

据悉，学院专门成立了社区事务办公室和东莞社区研究中心两个专门机构，配备了10名教师。本次“服务东莞，共建和谐社区”系列活动包括文体活动、家庭教育、心理咨询及党建宣传等内容。

会议由行政副院长张林博士主持。
