# 东莞理工学院纪委来我院考核反腐倡廉工作

7月5日，东莞理工学院党委副书记、纪委书记黄碧莲率纪委考评组，对我院反腐倡廉工作进行量化考评。

朱书记代表学院党委向考评组就城市学院近年来在反腐倡廉制度建设、主要工作、取得的成绩、存在的不足，以及今后的工作意见等情况做了详细的汇报。党委纪检委员章德胜同志按照东莞理工学院纪委反腐倡廉考核指标体系，从四个方面汇报了城市学院具体的工作情况，党委委员王玉、夏勇也分别就各自分管的工作做了汇报。

听取完学院汇报，黄书记对城市学院近年来在反腐倡廉工作中取得的成绩给予了高度的评价和充分的肯定，她认为城市学院党委克服了工作任务重、人手少等诸多方面的困难，在党风廉政建设方面取得了较好的成绩，希望继续努力，建设健康、和谐城院。
