# 我校召开党委中心组（扩大）学习会

5月9日下午，我校召开党委中心组（扩大）学习会，传达学习全省教育大会及全省学校思想政治理论课建设推进会的会议精神。全体校领导、党委委员，各单位负责人及各党总支（直属支部）书记参加了会议。会议由党委书记章德胜主持。

校长王卫平传达了全省教育大会会议精神。强调学校要坚持以习近平新时代中国特色社会主义思想为指导，扎扎实实办好人民满意的教育，为培养担当民族复兴大任的时代新人，培养德智体美劳全面发展的社会主义建设者和接班人作出新的更大贡献。一要正确把握新时代发展广东教育的大局大势，全力做好新时代高等教育工作。二要全面落实教育优先发展战略，全力推进教育强省建设。三要加强党对教育工作的全面领导，全面加强教育系统党的建设，严格落实意识形态工作责任制，抓好各项工作任务和政策举措的落实，确保学校的教育改革发展沿着正确方向行稳致远。

王卫平校长还传达了全省学校思想政治理论课建设推进会的会议精神。指出要深入学习领会习近平总书记关于思政课建设重要论述精神，充分认识办好思政课的重大意义，旗帜鲜明地用习近平新时代中国特色社会主义思想铸魂育人，理直气壮开好思政课，切实把思想政治工作贯穿教育教学全过程。一要全面落实“六要”标准，不断加强思政课教师队伍建设。二要着力推动思政课守正创新，全面提升学校思政课质量。三要加强组织领导，落实工作责任，为加强和改进学校思想政治教育提供强有力保障。

章德胜书记强调，校内各单位、各党总支（直属支部）要深刻学习领会全省教育大会及全省学校思想政治理论课建设推进会的会议精神，切实抓好各项工作落实。马克思主义学院要按照省委教育工委的建设指标，夯实基础，勤练内功，加强自身建设。各二级学院负责人、党总支（直属支部）书记要切实担负起本单位党建工作、思想政治工作、意识形态工作的主体责任，以党建促进各二级学院的发展与建设。

会上还印发了《关于2019年校党委理论学习中心组中层干部和教职工政治理论学习安排的通知》。章德胜书记要求，各单位要积极组织开展形式多样、内容丰富的学习活动，根据学校的“三会一课”制度，做好学习计划和学习记录，切实加强政治理论学习，把思想和行动统一到全省教育大会及全省学校思想政治理论课建设推进会会议精神上来。
