# 安保布控擒小偷，校园安全有保障

6月8日晚，学校保安监控室发现一名形迹可疑的男子在单车棚附近逗留，同时保卫办便衣伏击队员也发现此人，立即通知各部门密切留意此人动向，经过布控，门岗两名队员一举将盗车嫌疑人抓获，缴获被盗自行车一辆，作案工具若干。通过审问，该男子对自己的偷窃行为供认不讳。该嫌疑人现已交泉塘派出所作进一步处理。

保卫部门提醒大家要提高安全防范意识，看管好自己的财物，将单车有序停放在单车棚内，做到人离车锁，不给犯罪分子可乘之机。保卫部门最近也通过加强视频监控监视，安排便衣队员伏击，加强门岗盘查等一系列措施，确保校园安全。
