# 就业中心江小卫主任作客东莞广播电视台《与法同行》栏目

6月17日晚，就业中心江小卫主任应邀作客东莞广播电视台“阳光1008直播”《与法同行》访谈栏目。栏目围绕“高考毕业那些事”这一主题，就学生高考录取防骗、求职兼职陷阱与就业权益保护，以及学生假期安全等问题，为考生和家长进行解答和在线互动。
