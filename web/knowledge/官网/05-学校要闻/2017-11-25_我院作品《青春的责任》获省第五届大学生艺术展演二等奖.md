# 我院作品《青春的责任》获省第五届大学生艺术展演二等奖

11月11日、12日，广东省第五届大学生艺术展演活动在华南理工大学大学城校区举行。经过广东省教育厅组织专家集中评审，我院小品《青春的责任》获得戏剧小品类甲组二等奖。

《青春的责任》由艺术系龙乐源老师指导的艺术团言韵话剧队表演。小品把支教老师进山支教的故事淋漓尽致地演绎出来，展示了当代大学生的朝气蓬勃。

大学生艺术展演是广东省迄今为止规模最大、影响最广的大学生艺术盛会，呈现了广东高校艺术教育改革的最新成果，展现了广东大学生艺术才华和青春正能量。
