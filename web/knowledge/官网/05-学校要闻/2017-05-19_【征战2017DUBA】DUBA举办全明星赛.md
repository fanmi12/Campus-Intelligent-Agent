# 【征战2017DUBA】DUBA举办全明星赛

5月17日晚，2017年东莞大学生篮球联赛“南博杯”全明星球赛在广东科技学院举行，来自东莞十所高校的30名优秀球员上演了一场精彩的篮球盛宴。

我院男篮10号黄明健、19号叶锐城和25号叶照晃以高额票数入选全明星球赛，加入由B组球队组成、广科主教练彭俊峰担任主帅、我院教练钱丽娜作为助教的“荣耀队”。尽管10号黄明健表现突出，为团队贡献了10分，但“荣耀队”最终以79：85不敌A组为代表的王者队。

活动中，广科、中大新华、技师学院啦啦队还进行了现场表演。在“三分王”大赛中，我院7号黄志陆代表我院男篮参加对决。
