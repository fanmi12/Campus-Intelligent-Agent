# “双代会”代表讨论热烈

5月20日，各代表团在听取了院长安少华教授所作的学院工作报告、章德胜同志所作的工会工作报告、黄甜源所作的工会财务工作报告以及认真阅读《倡议书》后，纷纷展开了激烈的讨论。

第一代表团在团长夏勇，副团长黄研晖的带领下，在4410会议室开展讨论，代表们一致认为学院领导对学院的发展倾注了大量的心血，安院长的报告起到统一思想、催人奋进的作用，代表们表示个人的发展要和学院的发展相联系，加强主人翁的思想，要关注学院的发展，要充分利用区位优势，努力使学院成为东莞人民的学院。

代表们提出：对于年轻的教师要继续完善聘用制度，要把职称、进修问题制度化、多元化，对教职工的待遇要不断提高，结合东莞的实际搞科研，齐心协力，同学院共命运，使城市学院的明天更美好。

第三代表团在团长张林、副团长牛煜的带领下，在4315会议室开展讨论，与会代表畅所欲言，我院常务副院长程发良教授也以普通代表的身份参加讨论。

代表们认为，安院长的报告客观公正地总结了过去，全面深刻地分析了目前我院办学所存在的机遇与挑战，实事求是。

同时代表们也提出了建设性的意见，例如：学院应当对中青年教师所关注的热点问题予以解决，不断完善教师住宿环境以及适当处理好工作量与酬劳之间的问题。在学生课程设置上应当予以不断完善，根据各专业目标的不同制定不同的要求。
