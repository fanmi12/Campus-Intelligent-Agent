# 北大青鸟乔洁博士来我院做学术报告

6月5日晚，东莞远见软件科技开发有限公司董事长、北大青鸟东莞佳杰培训中心校长乔洁博士学院学术报告厅与我院学生畅谈东莞软件业发展与东莞经济转型问题。

乔洁博士向大学生们详细介绍了北大青鸟的发展历程、经营理念，讲述了个人发展与奋斗的经历，并结合东莞经济转型问题介绍了软件业在东莞发展的现状与前景。

与会学生对这个年仅29岁的北京大学硕士、香港大学博士、软件公司董事长、培训中心校长等众多头衔和职务的女精英深感敬佩，纷纷向她跃提出了有关个人成长与发展、中国软件业的现状、个人创业等问题。

讲座结束后，北大青鸟员工还组织了现场抽奖，乔洁博士、教务处副处长谭汪洋副教授先后为中奖的同学颁发了奖品。
