# 城市学院第九届工商模拟市场盛大开幕

4月21日17：00，以“创业梦想?青春共享”为主题的东莞理工学院城市学院第九届工商模拟市场“（以下简称工模）在学6宿舍楼篮球场盛大开幕，党委书记王卫平、副院长张林、院督学陈丁堂、副院长高香林、院长助理麦琦琳，团市委有关领导，管理系主任张佺举、党总支书记帅建华等出席了开幕式并为市场开市剪彩。

管理系总支书记帅建华致开幕词。他说，经过近十年的摸索、探讨和提升，“工模”已经成为城市学院校园文化的一大特色和品牌活动，是教学实践的大平台，是大学生创业的试验场。

随后，副院长张林向“工模”赞助商东莞市梦语文化传播有限公司等商家的代表赠送锦旗，第九届“工模”管理委员会主任麦颖同学为摊主代表颁发营业执照。

剪彩仪式结束后，王卫平书记宣布东莞理工学院城市学院第九届工商模拟市场开幕。

据悉，本次“工模”总共拍出120个摊位，许多学生经营理念超前，摊位设计新颖，卖品形式多样，促销方式灵活，广告宣传手段先进，吸引了众多师生前来购物。整个市场体现了大学生敢于创业、敢于成就自己的青春风采，将自己的创业梦想付诸行动。

第九届工模是庆祝城院十周年系列活动之一。由城院学子组成的“梦晴天”原创明信片工作坊（105号摊主）的同学们，以“献礼城院十周年”为主题制作了一套手绘明信片，也在工模开幕当晚举行了首发式。总策划郭浩鹏同学向记者表示，本次明信片共印出1000份，工作团队为此准备了两个多月，内容反映的都是城院的校园风景，很受同学们的青睐。开幕不到两个小时，就出售了50余套。据记者调查，市场共有十余个摊位经营此类商品。

第九届“工模”将从4月21日持续到4月25日，为期五天。开幕期间，各种美食、DIY展品、文艺演出等特色活动将会一一呈现。

特别值得一提的是，本届“工模”赞助商东莞市梦语文化传播有限公司董事长萧丽仙女士，就是我校2012年毕业生。她坦言，自己大学期间连续三年参加“工模”市场，是学校“工模”市锻炼了自己的胆识，培养了自己的能力，如今开办公司事业小有所成，很乐意支持师弟师妹们开展此类实践型的活动。
