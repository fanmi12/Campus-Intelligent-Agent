# 《南方日报》驻东莞办事处肖开润主任来访我院

安院长与肖主任（左5）一行合影留念4月30日，《南方日报》驻东莞办事处主任、东莞记者站站长肖开润，携该站记者一行6人来我院参观交流，受到院长安少华和党委宣传部部长何鹏举的热情接待。

座谈中，肖主任回顾了我院与南方日报社的友好合作，高度评价了校园新闻大学生联络站在城市学院设立以来所取得的成绩。安院长表示，南方日报校园新闻大学生联络站和城市学院南方日报东莞办事处教学实践基地的设立，开创了校媒合作的先例，有利于新闻采访与大学生的新闻实践教学,切实提高了大学生的综合素质和实践能力。

会后，安院长率校乒乓球队师生与肖主任一行进行了一场乒乓球友谊赛。
