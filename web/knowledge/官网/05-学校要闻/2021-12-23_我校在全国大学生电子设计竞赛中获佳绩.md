# 我校在全国大学生电子设计竞赛中获佳绩

喜讯，喜讯！2021年全国大学生电子设计竞赛落下帷幕,从全国组委会获悉，由广东省组委会推荐的我校参赛13207F代表队获得全国二等奖。

我校高度重视教学改革，将“以赛促学、以赛促练、以赛促教”的教学模式贯穿大学生学习之中，出台了相关制度，鼓励广大教师积极参加各类专业竞赛。

今年收到参赛通知后，我校智能制造学院精心组织教师团队指导7支队伍参加。在省级赛上，获得一等奖两项，二等奖2项，三等奖1项的成绩。随后在国家级大学生电子竞赛获得全国二等奖，总成绩位列全省民办高校第1名。

获得全国二等奖队伍成员：周锐深

黄友杰张科威

广东省一等奖获奖成员：肖文杰

刘呈扬詹昆霖

广东省二等奖获奖成员：陈赵婷、高瑞平、徐煜俊

广东省二等奖获奖成员：梁伟哲、何锡渝、张雄

全国大学生电子设计竞赛是教育部和工业和信息化部共同发起的大学生学科竞赛之一，是面向大学生的群众性科技活动，目的在于

推动高等学校促进信息与电子类学科课程体系和课程内容的改革。

据悉本次竞赛有浙江大学、电子科技大学、华中科技大学、华南理工大学等全国各个省市赛区999所高等院校，15602支队伍参加（广东省1227支），近5万大学生参加。是参加院校、学生最多、规模最大，最具影响力的国家级电子设计竞赛，得到了全国各大专院校的认可和支持，许多院校给予获奖学生免试保送研究生的机会。今年由于疫情影响，本次竞赛首次采用参赛队线上演示、专家组线上、线下集中评审的模式进行。最终，全国专家组评选出322个参赛队获全国一等奖（获奖比例：2.06%）、790个参赛队获全国二等奖（获奖比例：5.06%）。
