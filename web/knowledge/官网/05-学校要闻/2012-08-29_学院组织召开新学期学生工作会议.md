# 学院组织召开新学期学生工作会议

8月28日，学院在四号楼209组织召开新学期学生工作会议，党委书记朱志德、副书记章德胜、学生处副处长杜鹏举出席会议，各系部党总支副书记及学生处工作人员与会。

会上，章德胜副书记传达了25日学院召开的中层干部会议精神，布置了新学期两个校区的学生工作，对新进辅导员培训、学生报到注册、专插本学生报到、大一新生报到以及搬迁等工作做了安排。会上还确定了莞城校区学生工作延伸管理的人员名单。

朱志德书记在会上对学生工作提出了三点要求：一，稳定压倒一切。他强调，学生管理工作关系着学院的安全稳定和进一步发展，学生管理工作者要不断地提高自身素质；二，做好新老校区的衔接工作。学生处和各系部要贯彻执行我院的学生工作计划，理清下阶段学生工作思路，力争学生管理工作更上一个新台阶。三，做好搬迁工作。要求在最短的时间内做好准备工作，严格按照学院的统一安排进行搬迁。
