# 我院召开党务干部专题培训会议

为进一步贯彻落实学院基层党组织建设三年行动计划（2018-2020年），11月21日下午，学院党务干部专题培训会议在行政楼407会议室召开。全体学生党支部书记参加了会议。

党务工作部副部长叶凯贞主持会议，传达了学习贯彻习近平总书记视察广东重要讲话精神。她强调习近平总书记重要讲话内容思想深刻、内涵丰富、要求明确，具有很强的理论性、指导性和操作性，要求与会人员深刻认识习近平总书记视察广东重要讲话的重大政治意义、现实意义和深远的历史意义，进一步增强学习贯彻的自觉性、主动性、坚定性。

会议对东莞理工学院指导组检查我院党建工作的意见进行了反馈，对学院基层党支部的工作建设提出规范化要求，强调各党总支、学生党支部应当抓好自身工作，着力解决基层党组织设置不规范、党员教育管理不规范、基层党建标准不规范等突出问题。

党务工作部组织科科长范琪对各院系学生党支部书记进行了发展党员工作业务能力培训，强调党员发展工作应遵从“控制总量、优化结构、发挥作用、提高质量”的方针展开工作，要求在“申请人、入党积极分子、发展对象、预备党员、正式党员”等五个阶段严格按照相关规定开展工作。

各学生党支部书记在会上进行了工作交流与讨论。
