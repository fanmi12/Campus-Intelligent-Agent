# 金融与贸易系召开“学风建设月”动员大会

11月15日， 金融与贸易系在学术报告厅召开“学风建设月”活动动员大会。党委书记朱志德、副书记章德胜出席大会。系主任米双红、党总支书记龙卫洋、副书记李阳桂及金贸系全体师生参加了会议。

会上，米双红主任对“学风建设月”的活动进行总体部署，并着重强调了学风建设的重要性；龙卫洋书记宣读了活动实施方案，明确了活动的指导思想、活动目标与任务、具体的实施措施。

为加强学风建设指导工作，金贸系还成立了由学生组成的以“倡导文明、普及常识”为宗旨的文明礼仪督导队，副书记李阳桂在会上宣读了文明礼仪督导队的职责。

朱志德书记在会上对该系制定的《金贸系学生管理制度汇编》和独创的《学生道德素质发展存折》等学风建设工作给予高度评价，并用时尚新潮的词语和幽默诙谐的话语进行点评，在给同学们带来阵阵笑声的同时，也为同学们进行了一次心灵洗礼。朱书记指出：精神懈怠和能力不足，是同学们共同的“敌人”，同学们要克制自己、团结一心打败这些“敌人”。

章德胜副书记亲自为文明礼仪督导队授旗并讲话，对开展“学风建设月”活动也给予了肯定并提出希望。他认为金贸系学风建设活动具有整体性、完整性和全员性的特点，希望金贸系通过“学风建设月”活动，把教师的教风、学生的学风建设落到实处，使学风建设探索出新内涵、新方法、新形式。

金贸系全体师生表示，以教风促学风，用学风促教风，营造刻苦学习的新风气， 为构建和谐校园添砖加瓦。
