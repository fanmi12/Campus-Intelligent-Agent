# 我院举行大会隆重庆祝第28个教师节

“教师们辛苦了，教师节快乐”！9月7日，学院在学术报告厅举行大会隆重庆祝第28个教师节。吕琦元、黎建烨、杨敏林分别在会上代表理工学院党委行政、城市学院董事会、城市学院党委行政，向全院教职员工表达了诚挚的节日问候和良好祝愿。

大会首先表彰奖励肖红飞等31位教书（管理、服务）育人先进个人、万文双等7位优秀辅导员、郭忠林等19位优秀班主任。

获奖代表城市与环境科学系系主任肖红飞教授发表了获奖感言，表示要与教师同仁们一道携手开创城市学院美好的明天，为教书育人作出更大的贡献。

东莞理工学院党委副书记吕琦元、城市学院董事会董事黎建烨、城市学院院长杨敏林，在会上发表了热情洋溢的讲话。他们表示，城市学院新校区已经高标准、高质量建成，一所现代化的大学呈现在大家面前。最近，我们又顺利完成了办学主体搬迁工作。新校园，新发展，新希望，新跨越。我们希望全体教职工要凝心聚力、坚定信心，推动城市学院在新的起点上实现跨越式的发展，实现办百年名校的宏伟目标。广大教师要一如既往满怀信心，发扬优良传统，继续致力于提高学院的教育教学质量和学术科研水平，打造教学品牌，建设特色专业，提升协同创新能力，服务东莞经济与社会的发展。我们有理由更有信心，通过全体教职工的努力与精诚合作，城市学院一定能克服和解决所面临的一切困难，迎来新的发展，实现新的跨越，再创新的辉煌。

城市学院党委书记朱志德主持会议，并宣布了学院关于教师节、中秋节、国庆节慰问大礼的消息。

大会在庄严的国歌声中开始
