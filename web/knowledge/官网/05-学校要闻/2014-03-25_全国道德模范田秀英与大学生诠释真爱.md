# 全国道德模范田秀英与大学生诠释真爱

3月24日，中华孔子学会副会长、叶剑英元帅的女儿凌孜率全国道德模范、中华孔子学会传统文化讲师田秀英一行6人（慈善志愿者、义工）来我院演讲，受到杨敏林、王卫平等院领导的热情接待。300多名学生在学术报告厅聆听了他们的精彩演讲。

客人们在学术报告厅做了“弘扬优秀传统文化，共筑国家民族梦想”的专题报告。

全国道德模范、中华孔子学会传统文化讲师田秀英以20多年亲身经历诠释了中国传统文化对自己的影响，验证了“有一个好母亲就有一个幸福美满的家”的事实。据介绍，田秀英儿子6岁的时候，不幸被火烧伤，受伤面积达65%。在儿子生死攸关时刻及后来的人生道路上，她不离不弃，以伟大的母爱精心照料伤残的儿子。在医生的精心治疗下，儿子从死亡线上活了过来。后来她的儿子考上了山东轻工业学院，四年后又以全国第一名的成绩考上了北京师范大学教育经济与管理专业硕士研究生，现在就职于青岛一家上市公司任总经理助理。田秀英又以博大的孝心赡养照料瘫痪在床6年的公公。田秀英也因此多次获得“中国十大孟母”、“中国十大孝贤”、“全国十大道德模范”等荣誉称号，曾先后两次受到胡锦涛同志的亲切接见。

田秀英生动感人的事迹和演讲口才获得同学们的欣赏与赞美。

凌孜副会长对中国传统文化有较深的研究和学术造诣。她在演讲中讲述了中外传统文化的对比、中国传统文化的源流与传承、中国传统文化对当代大学生的影响等内容。她指出，中国的传统文化源远流长，具有5000多年的文明史，经过无数代人的传承和丰富发展，形成了“和”、“孝”、“礼”、“仁”、“义”、“博爱”等鲜明特色的中国传统文化。希望当代大学生要弘扬中国传统文化，共筑国家民族伟大梦想。

院领导陪同凌孜女士一行参观了校园和图书馆。
