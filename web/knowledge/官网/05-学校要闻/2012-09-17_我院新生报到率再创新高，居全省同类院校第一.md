# 我院新生报到率再创新高，居全省同类院校第一

9月15、16日，为期两天的迎新报到工作，以报到率创新高的喜人成绩完美落幕。资料显示，今年我院计划招生4967人（不含专升本345人），截至16日17时，实际报到已达4654人，报到率为93.7%。据悉，今年的报到率超过了去年创造了新的记录，并居全省同类院校第一。

今年是第二届新生在新校区报到读书，也是从今年开始，不再招收专科学生，因而2012级新生全部是本科生。“在全部招收本科生的新情况下，能达到如此高的报到率实属不易。”金融与贸易系主任米双红教授认为，“这说明城市学院的教育教学质量和校园建设，得到了社会的广泛认同。”

据学院迎新工作有关人员介绍，报到率位居前三名的是金融与贸易系、文学与传媒系和财经系，分别为96%、94.5%、94%。金融学、会计学、资源环境与城市规划管理、人力资源管理、物流管理、数字媒体艺术等专业，报到率达到了98%以上。

今年的迎新报到工作准备早，工作细，氛围好。学校在迎新大厅增设了10多个服务窗口并联网互通，减少了新生排队等候的时间。学生宿舍中的设备清一色的新，每个楼层都配备了洗衣机、公用饮水机和电话，让新生有家的感觉。更值得一提的是，寮步镇政府派了40多名交通协管员和城管队队员，帮助我院维持校园交通秩序。

东莞理工学院党委书记成洪波视察工作时，对我院迎新工作表示了充分的肯定。他叮嘱院领导说，新同学来了，校园学生多了，领导和老师的责任加重了。董事会及院、系领导是建设和谐平安校园的第一责任人。社会治安不能出小问题，更不能出大问题。要关爱每一个学生，特别是要关注贫困学生，创造条件，优化环境，让教职工工作舒心、学生学习专心，使学生在四年的时间里能真正学到知识，高高兴兴地毕业！
