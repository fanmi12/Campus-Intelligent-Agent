# 我院召开2014年招生工作新闻发布会

4月14日，我院在407召开2014年东莞理工学院城市学院招生工作新闻发布会，东莞电视台、东莞阳光网、东莞日报、南方日报、广州日报、南方都市报、羊城晚报、东莞信息时报等近10家媒体前来参加。

会上，学生处副处长孔增强向记者介绍了2014年我校艺术校考、专插本进行的情况及普通高考招生等相关情况。教务处助理处长李先庆解答了现场记者对我院新增市场营销、环境工程、物联网工程等专业的培养目标、课程设置、开设、就业前景及师资配套等问题。

据孔副处长介绍，我院整体今年招生计划与去年持平。作为独立学院中唯一拥有表演专业艺术校考资格的学校，我校将从参加艺术校考近700考生中录取100人左右；我校专插本录取工作也准备开始，将从报考我校的800多名考生中录取上线考生361人，报考人数和招生人数均创历史新高。
