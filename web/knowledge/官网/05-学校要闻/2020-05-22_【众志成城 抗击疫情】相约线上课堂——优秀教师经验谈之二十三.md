# 【众志成城 抗击疫情】相约线上课堂——优秀教师经验谈之二十三

我校坚决贯彻落实教育部、省教育厅、省委教育工委的重要部署，从3月起全面开展线上教学活动，全体任课教师坚守岗位、锐意创新、勇挑重担，全力做好线上教学工作，展现了良好的师德师风。前二十二期我们精选刊发了一批优秀教师线上教学经验谈后，在全体教师中产生了良好的反响，受到广大师生的欢迎和点赞。今天刊发第二十三期，推介城建与环境学院胡娉婷、法学院董进、马克思主义学院赵卫丽三位老师的线上教学心得体会，供大家分享。

城建与环境学院胡娉婷老师线上教学心得体会：课前准备：（1）通过网络提前释放知识点，视频要筛选合理时长，做到即提前学习又不占太多时间。（2）活跃气氛，考勤选项设置有趣问题。

课中互动：（1）练习要求发群里，提交的速度和正确性关联平时成绩提高积极性，做错的地方给学生即时反馈。（2）连麦提问注意既结合视频知识点又能联系实际。（3）分层教学对个别学困学生再课后私聊。

课后反馈：（1）了解学生的学习效果，开投票窗口，收集重要知识点真实理解比例，灵活调整上课进度。

工具补充：直播灯、电容笔（结合iPad投屏）。

教师寄语：线上教学是一种全新的模式，需要我们师生共同摸索合适的学习方式，希望同学们对自己的学业有个合理的规划，疫情结束校园再相逢，未来可期！

法学院董进老师线上教学心得体会：从近2个月的线上教学工作来看，学生普遍反应良好，个人线上教学体会如下：

1.备课时，要提前准备好教学资料和PPT课件，因为疫情关系，同学手头还没有教材，要提前建立好授课微信群，将教学资料统一发到班级群里，通知同学们做好预习工作，同时，认真准备好PPT课件，标明每节课讲授的重点问题，通过线上文件展示功能来展示PPT，保证教学进度顺利推进。

2.线上课程开始前，授课老师要提前10分钟左右上线，主要是检查相关网络是否通畅、声音是否清晰，输出上课二维码，制作签到表进行线上考勤工作，保证课堂的出勤率与线上教学质量。

3.线上课程讲授过程中，要利用线上讨论功能与同学保持沟通，一方面能够及时反馈同学对知识点的理解情况，对难点问题进行解答；另一方面，了解网络传输的情况，如果有多数同学反映网络卡顿，将会马上采取措施进行修复。

4.在课后，要通过建立的授课微信群来及时了解同学对于本次课程的学习情况，并且要及时回答同学们提出的相关问题。

教师寄语：同学们，办法总比困难多，面对困难，保持认真的学习态度是顺利完成学业的基础。

马克思主义学院赵卫丽老师线上教学心得体会：个人感觉线上和传统课堂教学有相同也有不同，教学方法有的可以沿用课堂教学，如刚上课不直接讲课程内容，而以身边或社会发生事例切入，引导学生树立正确观点，逐步带入课堂以达到良好课前亲和效果，为授课奠定良好互动沟通基础。二者也有不同，因线上教学每节课时间不宜过长，不能及时把握学生上课状态等特点，更需要多进行互动沟通以检验学生上课状态和学习效果。

教师寄语：有规律的生活才能忙而不乱。疫情当前，不能相见，同学们在注意个人安全防护前提下，安排好自己的时间，做好学习规划。相信一切都会好起来，期待和大家早日相见！
