# 思政部召开2014级新生《基础》课教学研讨会

7月3日，思政部在7C201、7C202、7C217教室召开2014级新生《思想道德修养与法律基础》课教学研讨会。思政部全体专兼职老师参加了会议，教学部副主任石志民副教授主持会议。

会议首先由夏晓楠、王贺、赵卫丽三位兼课教师分别对《基础》课进行说课和讲课。与会人员大家结合基础课课程和三位老师的公开课进行了评课和讨论，共同探讨教学思路、教学方法、教学特点，并对有针对性的对三位老师的教学细节进行交流。

院督学陈丁堂教授、思政部主任何鹏举教授对三位老师的说课进行了点评。他们认为，思想政治理论课教学不是灌输，不是将教师头脑里的知识灌输到学生的头脑里去，而应当是一种对话、一种沟通、一种合作。基础课最主要的教学逻辑和备课思路就是“如何把教育我的教育”转化为“我自己的教育”，并对这一观点进行深入解读。他们表示，这一转化的基本方法分为满足需求、启发思考、引导践行三个方面。满足需求，一要精，要突出重点，二要管用，联系实际，让理论回归生活；三要用“心”，用真理的力量去说服学生，以人格的力量感染学生。启发思考，一方面用理论知识与客观现实的矛盾，创设问题情景，启发学生思考，另一方面对学生以为是“空话、官话”而又十分重要的观点，主动质疑问难，揭示客观现实的复杂性，激起学生思维的波澜；引导践行，既可以引导学生写道德笔记，可以适当的组织社会实践活动，例如在校内开展大学生文明行为调查并进行讨论，还可以通过操行自我评定改革考试方式。他们语重心长地说，承担基础课的教学任务，既是我们谋生的手段，更是我们的精神寄托。做好了，我们可以在学生今天的爱戴与明天的追忆中，寻找富有乐趣的教育人生，发现自己的人生价值。否则，就是一种痛苦的精神折磨！

教授们的肺腑之言，引起了大家的共鸣。

石志民副主任还对放假前的教学工作和假期工作注意事项，尤其是社会实践课程的指导工作做了说明、布置和安排。
