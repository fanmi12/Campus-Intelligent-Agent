# 机电系举办第二届毕业作品展

6月14日下午， 2017届机电工程系优秀毕业设计作品展在8A404拉开序幕。我院副院长高香林，院长助理林江龙和各系部主任、单位负责人等出席了毕业作品展开幕式。

在开幕式上，机电系党总支书记、副主任殷素峰致开幕词。他说，这次毕业生作品展是机电学子们求学四年成果的汇报和展出。毕业生们充分利用3D打印、机电控制、三维建模、数控加工、数值模拟、逆向制作、模具设计等多方面专业知识，突出工程应用，侧重动手实践，将可操作性实物呈现在大众面前。他说，机械专业与印刷专业近几年在科研专利取得了优异成绩，“自动分币装置”“自动仓储装置”等作品在全国机械创新设计大赛斩得一、二等奖，“定时水龙头”获得国家专利等。开幕式上播放优秀作品的制作以及实用性的演示操作过程。“无人机”远行航拍，机械手精准投物，无动力小车避障前行等精彩的作品充分展现了学生的专业素养和创新实践能力，也获得在场嘉宾观众的一致肯定，本届优秀作品毕业展为期三天。

据悉，本届毕业展共展出了72份优秀毕业设计作品，分别来自机械设计制作及其自动化和印刷工程。其中涵盖实验室项目、生产项目、教师科研项目等。

机电工程系遵循机械制造“创新性，实践性，交叉性”的学科属性和特点，把“创新能力”作为一项重要的培养目标，形成了工程实践和创新设计并重的特色。在全系师生的共同努力下，本届毕业设计质量整体水平显著提高，亮点层出不穷，学生专业技能、创新能力得到了有效训练，为学生能够尽快适应社会、服务社会奠定了良好的基础。
