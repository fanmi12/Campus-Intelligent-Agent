# 城环系400名志愿者为校园再添新绿

3月13日，一年一度的植树节期间，城环系举行了以“十载城院情?百年育人梦”为主题的植树活动，在新校区打造了一个属于城院的“桃花源”，并借此为城院成立十周年献上祝福。

院督学陈丁堂教授、城环系主任肖红飞教授、院团委罗文芳书记、系党总支副书记张海勇、系辅导员陈桂玲、曹镭及学院其他老师，在7A教学楼前环湖路旁的绿地为植树节活动揭幕，并种下桃花树苗。参与本次活动的同学们更是热情澎湃，挖坑、栽种、浇水，纷纷种下桃花树苗、挂上心愿卡并拍照留念。

据悉，此次参加人数共有400余人，共募捐及种植桃花树苗120余棵，是我系开展植树节活动以来，规模最大型的一次。

此次活动中，我院师生积极参与，以实际行动说明了他们对环境保护的重视和支持，“绿色、环保”理念更加深入校园。“十年树木?百年树人”，愿城院的明天桃李芬芳，春华秋实。
