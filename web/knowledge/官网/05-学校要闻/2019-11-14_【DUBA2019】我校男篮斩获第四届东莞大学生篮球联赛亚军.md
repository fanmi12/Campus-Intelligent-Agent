# 【DUBA2019】我校男篮斩获第四届东莞大学生篮球联赛亚军

11月13日晚，2019第四届东莞大学生篮球联赛迎来总决赛末轮之战。我校客场以57∶79惜败广东科技学院队，凭借8胜1负的骄人战绩摘得大联赛亚军。我校还荣获优秀赛区称号，主教练钱丽娜获得优秀教练员荣誉。

校领导王卫平、章德胜和体育教学部主任王艳云，以及100多名同学亲临比赛现场为我校男篮加油助威。

当晚赛事竞争激烈，双方士气高昂，各有精彩表现。我校6号庾世聪、12号李晓宇、77号曾梓航、19号叶锐城均有精彩表现。广科队凭借主场优势，表现出色， 夺得第四届东莞大学生篮球联赛冠军，我校男篮获得亚军。

本赛季，我校男篮克服了一切困难，勤于训练，敢打敢拼，团结友爱，将我校篮球与体育精神发挥得淋漓尽致，充分展示我校大学生良好的体育精神风貌。
