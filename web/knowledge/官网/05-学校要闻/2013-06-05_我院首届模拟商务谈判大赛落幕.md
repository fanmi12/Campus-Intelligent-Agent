# 我院首届模拟商务谈判大赛落幕

6月4日，城市学院首届模拟商务谈判大赛在学术报告厅隆重举办。本次大赛是由城市学院主办，金融与贸易系承办。城市学院督学陈丁堂教授、东莞平安保险公司总监喻朴中、中国平安公司经理丁文铭担任本次大赛的嘉宾。

代表长城贸易进出口公司的机电系梦之队担任卖方，代表维斯新亚服装有限公司的金贸系闪耀队担任买方。比赛一共分三个环节，一是双方先进行背对背的演讲，接着是面对面的谈判。第三个环节是双方进行商务谈判总结，陈督学、喻总监、丁经理、金贸系总支副书记龙卫洋博士做点评。比赛结果，金贸闪耀队以总分86分获得冠军，机电系梦之队以总分84分获得亚军，文传系谈到底队获得季军。最佳选手则分别由计算机与信息科学系的刘基、艺术系陈雅双、管理系姚汉豪、高等职业技术教学部吴素芬和曾冬儿、城市与环境科学系谢嘉伟、政法系刘绍声、财经系文景杨和机电系杨英才同学获得。
