# 我院男子篮球队亮相校园

10月17日，我院男子篮球队正式成立。

据悉，城市学院男子篮球队共有20名队员，他们是从全院400多名篮球爱好者中挑选出来的。

成立城市学院男子篮球队，旨在活跃学生课余体育活动，提高我院篮球竞技水平，与兄弟院校开展篮球技艺交流。

城市学院男子篮球队的领队是邢红林教授，负责教练是钱丽娜老师。
