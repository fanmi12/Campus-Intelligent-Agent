# 城市学院获广东省数控技能大赛三项大奖

6月22—27日，在省教育厅主办的，广东省高等院校数控技能大赛中，城市学院学生何荣辉（04级模具一班）、黄锦和（04级汽贸班）、吴焕标（04级数控班）获团体三等奖和个人优秀奖，教师黄江航、卢国满（实验中心）获教师个人二等奖。

数控技能大赛每两年举办一次。今年有广东省工业大学、深圳职业技术学院等几十所院校参加，比赛地点在深圳市。

为了在比赛中取得好的成绩，我院选手们认真钻研数控技术，着力训练实际操作能力。经过两个月的积极备战，终于如愿以偿。
