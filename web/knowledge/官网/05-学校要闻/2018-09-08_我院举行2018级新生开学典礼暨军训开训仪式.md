# 我院举行2018级新生开学典礼暨军训开训仪式

9月8日上午，我院2018级新生开学典礼暨军训开训仪式在运动场举行。

参加典礼的领导有：军训团长、承训海军某部队田建伟中校，军训副团长、承训海军某部参谋长秦学伟少校，东莞理工学院党委副书记、城市学院董事会董事吕琦元，城市学院董事长代表、广东鸿发教育文化集团有限公司总经理陈超群，学院领导和有关部门负责人、城市学院学生会主席，以及全体2018级新生参加了开学典礼暨军训开训仪式。大会由副院长周庆主持。

大会举行了隆重的升国旗、奏国歌仪式。

章德胜副书记宣读了《关于表彰2018年新生奖学金获得者的决定》。陈晓欣、陈瑞芳等40名同学获得2018年优秀新生校园奖学金，黄乐怡、黄曦莹等10名同学获得2018年北部湾财产保险公司新生奖学金，受到大会表彰。

今年暑期代表我院参加广东省教育厅“助梦扬帆”优秀大学生海外研学项目、2015级物联网工程1班陈军名同学作为学生代表发言。他表示，城市学院是读书学习的圣地，有学识渊博的老师传道授业、答疑解惑；这里是知识的殿堂，有藏书百万的图书馆供查阅资料，有好学勤思的师兄师姐一起探讨问题；这里有创业孵化基地、大学生创新创业训练项目、展翅计划等实践平台，让大家能充分锻炼自己的专业技能，提高综合素质。希望学弟学妹认真规划自己的未来，充实地度过四年大学生活。

王卫平院长在开学典礼上致辞。他教导2018级新生，大学生活将是人生历练的重要阶段，大家将逐渐体味到人品、情商、态度和能力的重要。

王卫平院长的致辞妙语连珠，他说：“凡事有交代，件件有着落，事事有回音，那才是一个靠谱之人或者诚信之人。做人，其实就是拼人品、情商、智商这三样东西。心中无缺才叫富，被人需要才叫贵。”“学习和成长中每一天的良好感觉叫幸福，掌握世界万物发展的规律叫智慧。说话让人喜欢，做事让人感动，做人让人想念，这叫人格魅力。给人希望，给人智慧，给人快乐，给人自信，给人方便，充满精气神，传播正能量，这是你每天应该思考和践行的必修课。”“成功的人不是贏在起点处，而是赢在转折点上。当你变得有德、有用、有料、有量、有容、有趣、有心的时候，也就人见人爱了”……

王卫平院长寄语新生，从现在起，把“树理想、立目标、定行动计划”作为第一要务，以践行社会主义核心价值观为出发点，做一个对国家、对社会、对家庭有用的人。

在军训开训仪式上，刘玉侠副院长作了热情洋溢的动员讲话。“国无防不立，民无兵不安”，她表示，作为国防教育的重要组成部分，期望新生加强组织纪律，提高思想素质，学会克服困难，争取圆满完成军训任务。她要求同学提高认识，端正态度，吃苦耐劳，经受锻炼，严守纪律，争当模范，发扬军人的优良传统和作风，积极主动投身军训，确保军训任务的圆满完成。

王卫平院长向军训团团长田建伟海军中校授“东莞理工学院城市学院军训团”团旗，拉开了军训大幕。

据了解，从9月8日开始，2018级新生将进行为期半个月的军训，训练内容包括国防教育、爱国主义教育和素质拓展、军体拳、战术基础动作等。
