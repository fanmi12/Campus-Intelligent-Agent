# 我院应邀参加CERNET第二十一届学术年会

11月21日-27日，我院图书信息中心副主任陈显龙在北京参加了CERNET第二十一届学术年会。该年会由中国教育和科研计算机网CERNET管理委员会主办，CERNET网络中心、CERNET专家委员会、北京市教育委员会协办，清华大学、北京大学和北京邮电大学承办。

本届年会以 “育人为本、技术为先，安全为重，CERNET与中国互联网同行” 为主题，开展了一系列的学术交流和国际交流。大会学术论坛内容涉及领域广泛，内容丰富，涵盖了校园网络领域的空间安全、网络新技术及应用、虚拟化与云计算、校园网络工程、Ipv6下一代互联网技术、数字化校园应用、无线移动应用技术等诸多科学技术问题。
