# 我院成功组织全国大学英语四、六级考试工作

12月20日，我院2014年下半年全国大学英语四、六级考试在7号教学楼进行。其中四级考试共设227个考场，报考学生6500人；六级考试共设86个考场，报考学生2432人。参与监考与考务工作的教职工近500人，是我院四、六级考试有史以来规模最大的一次。

院长杨敏林教授、党委书记王卫平教授、分管副院长高香林教授等均亲临考场，并进行了全面巡视。学院各系部、各职能部门积极配合，从监考工作安排和后勤服务等多方面保证了考试相关工作的有效落实。

本次考试过程组织有序，考生考风端正，监考教师认真负责，各方面工作得到学院领导及省巡视员的充分肯定和表扬。
