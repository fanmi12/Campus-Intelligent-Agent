# 城市学院第三届“法在我心•与法同行”法律知识竞赛圆满结束

4月28日，由城市学院团委暨政法系举办的“法在我心，与法同行”法律知识竞赛决赛于学术报告厅举行。出席本次决赛的嘉宾有城市学院学生处杜鹏举副处长、政法系主任、党总支书记刘杰教授、政法系主任助理危兆宾博士、政法系党总支副书记刘军老师、城环系党总支副书记张海勇老师、政法系实践办王雄文副教授等。

决赛队伍由金贸系、文传系、机电系、城环系、管理系以及政法系六支代表队组成，每支代表队都热情饱满，士气高涨，最终金贸系代表队凭着在抢答环节中建立的优势荣获本次决赛冠军，政法系代表队、机电系代表队获得斩获本次决赛亚军，季军由管理系代表队、城环系代表队和财经系代表队获得。此外，在竞赛全部环节都有着出色发挥的机电系获得了本次竞赛的最佳组织奖。整个决赛在紧张有序的气氛中圆满结束，赛后，嘉宾们为各获奖代表队颁发锦旗和证书以及一起合影留念，并勉励他们再接再厉，在下一次比赛中争取更好的成绩。

通过本次竞赛，极大地激发了同学们学习法律知识的热情，使同学们学会用法律的武器来维护自身的合法权益，让公平正义的法律理念在校园中得到普及，为法治社会建设做出自己的一份贡献。
