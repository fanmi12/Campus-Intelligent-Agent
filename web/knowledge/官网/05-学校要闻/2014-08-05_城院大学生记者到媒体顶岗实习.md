# 城院大学生记者到媒体顶岗实习

7月8日，城市学院大学生媒体中心电视台台长、艺术系二年级学生梁施艳来到东莞日报新媒体中心报到，开始她为期50天的暑期顶岗实习。新媒体中心给她的第一个任务就是跟随记者采访东莞著名的音乐人吴群老师，为东莞日报微电台制作第一期节目。

据大学生媒体中心指导老师石晨介绍，今年，新闻中心组织了32位同学到东莞电视台、东莞日报、南方都市报、新快报、南方网等9家媒体单位实习。

城市学院为顺利开展大学生记者暑期媒体实习，7月4日专门召开了动员大会，会议邀请了东莞日报、南方网等报社媒体记者与同学们在现场交流经验。东莞日报新媒体中心主任谢晓波现身说法，从自己的实习经验出发，告诫同学们要脚踏实地，“没有人的成功是偶然的”。

这几天，新闻中心主任何鹏举老师带队赴各媒体实习单位了解了同学们的实习情况，他鼓励同学们积极主动地融入媒体工作，把在学校所学知识应用到实践之中，并叮嘱同学们在实习过程中要注意安全。

《新快报》东莞站杨英杰主任表示，“城市学院的学生，基础扎实，为人诚恳，态度端正，我们会根据他们每个人专长及特点，指派专门的指导老师。你给我优秀的学生，我还你合格的记者。”
