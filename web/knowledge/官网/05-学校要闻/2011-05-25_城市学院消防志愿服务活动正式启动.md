# 城市学院消防志愿服务活动正式启动

城市学院消防志愿者虚位以待更多同学的加入5月24日，城市学院消防志愿服务队在6号阶梯教室举行了“志愿消防与巡逻，学校安全大家护”的启动仪式。

院团委书记杜鹏举，院保卫办主任理阳阳，院学生会主席翁梓朋和各系志愿队负责人出席了本次活动。

加大消防巡逻，增强安全意识

在启动仪式上，院保卫办主任理阳阳强调了成立消防志愿者服务队的意义。他在讲话中引用发生在学生宿舍的案例，说明学生增强安全防范意识的重要性，同时要加强校园的巡逻工作，做到双管齐下，维护校园治安环境。随后，我院青年志愿队队长黄志钦带领全体志愿者宣誓。理主任向黄志钦队长授旗，并宣告消防志愿分队成立。

消防安全初体验，巡逻校园形式新

在启动仪式结束后，我院200多名消防志愿者在校园内外开始进行消防与巡逻初体验。巡逻时间近一个小时，目的在于让志愿者们熟悉巡逻的路线和环境。

消防巡逻志愿者表示，这样的活动很有新意，可以让志愿者更加明白自己的工作。在今后的日子里，城市学院将出现一群分别穿着绿色和黄色消防队服的志愿者，穿梭于学院各个角落，为广大师生建立一道财产和生命安全的防护墙，成为学院一道独特的风景线。
