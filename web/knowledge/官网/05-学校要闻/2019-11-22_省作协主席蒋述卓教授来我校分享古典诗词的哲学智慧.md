# 省作协主席蒋述卓教授来我校分享古典诗词的哲学智慧

为了普及诗词知识、了解古人的生活、领略诗词之美， 11月20日下午，由广东省作家协会主席、原暨南大学党委书记蒋述卓教授主讲的《中国古典诗词的生命精神与哲学智慧》讲座在7B209举行。此次讲座是我校举办的中华美育传承系列活动之一。

蒋述卓教授通过两个角度带领同学们去解读中国古典诗词：一是从生命精神的角度，去理解古人的生命探索，二是从哲学智慧的角度，去领会古典诗词的思想意蕴。他列举了杜甫的“万里悲秋常作客，百年多病独登台”、曹操的“譬如朝露，去日苦多”等诗句证明诗词的悲情体现生命精神。

蒋述卓教授分别用六个智慧阐述了诗的思索，体现哲学智慧。古人通过诗去思考、探索人生真理和社会真理，给后人留下无穷的智慧启发和生命的动力。

蒋述卓教授希望同学们在平常读诗学诗的过程中，不要局限于表面，要细品其中的韵味，感悟诗词中的人生哲学。
