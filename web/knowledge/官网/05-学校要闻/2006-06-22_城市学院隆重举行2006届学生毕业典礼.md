# 城市学院隆重举行2006届学生毕业典礼

6月22日，院长、教授、博士、老师、系部负责人、学院机关干部、在校学生代表和毕业生相聚学院大礼堂，共叙离别情谊。东莞理工学院城市学院教学点2006届学生毕业典礼在这里隆重举行。

大会在庄严的国歌声中开始。

东莞理工学院院长、城市学院董事长杨晓西教授首先致辞。他代表学院向圆满完成学业、即将离开学校踏入社会的毕业生表示热烈的祝贺，向辛勤工作、精心育人的全院教职工表示亲切的慰问和衷心的感谢。杨院长说，同学们入校几年来，伴随着学院发展的步伐，在城市学院度过了宝贵的大学生涯，取得了思想与专业上的进步。今天，你们满载着学校和亲人的期望，从这里出发，就要开始新的更加壮丽的人生旅程。在离别之际，杨院长对毕业生们提出三点希望作为离别赠言：志存高远，终身学习；脚踏实地，勇于创新；自强不息，爱校荣校。

陈悦瑶、王志伟同学分别代表在校学生和毕业生在会上发言。

东莞理工学院院长杨晓西教授，东莞理工学院副院长、城市学院院长安少华教授向毕业学生颁发了《毕业证》。

典礼在老师和同学们合唱的《毕业歌》歌声中结束。

大会由常务副院长程发良教授主持。

又讯：6月21日，学院在315会议室召开毕业生代表座谈会，听取毕业生对学院建设、管理、教学工作的意见和建议。
