# 我院举办《红楼梦》系列学术讲座

3月19日，梁克文副教授在五号楼阶梯教室为文学爱好者们带来了精彩生动的讲座——曹雪芹与《红楼梦》。

《红楼梦》是我国四大名著之一，是现实主义文学的最高峰。梁教授就《红楼梦》的起源，曹雪芹为什么能写出《红楼梦》等问题进行了讲述。

《红楼梦》系列讲座共六讲：曹雪芹与《红楼梦》，贾宝玉的使命；林黛玉的爱情故事；薛宝钗的人生哲学；王熙凤与贾宝玉；《红楼梦》的启蒙主义以及人文思想。

梁克文是中国石油大学人文社会学院中文副教授，从事古代文学教学工作30多年，中国红学会会员，现任我院教学督导。
