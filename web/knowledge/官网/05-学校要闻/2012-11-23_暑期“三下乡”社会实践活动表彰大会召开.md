# 暑期“三下乡”社会实践活动表彰大会召开

11月23日，我院在学术报告厅举行了2011—2012学年度暑期“三下乡”社会实践活动表彰大会，表彰在暑期实践中表现优秀集体和个人。党委副书记章德胜出席了会议。

学生处副处长杜鹏举宣读暑期“三下乡”社会实践活动的获奖名单。团委决定，“梦起晨曦，晴暖夕阳，爱心路上团旗飘”实践分队等7支团队获“优秀团队”称号，陈浩等7名老师获“社会实践活动优秀指导老师”称号，洪洁欣等740名同学获“社会实践活动积极分子”称号。

党委副书记章德胜发表了讲话。他对本次暑期社会实践活动取得的成绩表示祝贺，对今后的活动提出了四点要求：一，要牢固树立实践出真知的观念，要多参加社会实践；二，要坚持理论联系实际，用实践丰富书本知识；三，要认清时代需要，积极服务社会，服务地方经济，服务民众；四，社会实践活动形式要创新，内容要具体，选题要贴近实际，调查要深入，多做“雪中送炭”、“锦上添花”的事情，让学生、政府、老百姓满意。
