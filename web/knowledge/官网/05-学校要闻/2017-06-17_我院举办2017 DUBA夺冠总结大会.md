# 我院举办2017 DUBA夺冠总结大会

6月15日下午，我院男子篮球队获东莞大学生篮球联赛总冠军总结大会在行政楼112举行。王卫平、章德胜、高香林、林江龙等院领导和各院系（部）主任、体育教学部全体教师参加了会议。

学院体育教学部主任、男子篮球队领队邢红林一一介绍了参加本届东莞大学生篮球联赛的球员，对他们的辛苦付出表示感谢。他用“感谢、积淀、团队、精神”八个字表达了对本赛季的感受，并生动地引用了我院招生形象片的主题——“一朝遇见，一世眷恋”，对城院男篮夺冠表示热烈祝贺。

运动员代表叶照晃、城院球迷协会代表彭菲先后上台发言，他们表示将继续发扬城院男篮拼搏精神，为城院争光，再创辉煌。

院长、书记王卫平在讲话中，盛赞城院男篮团结拼搏的精神，并对城院男篮寄于厚望。他说，城院男篮是我们城院的品牌，是学院的形象代表，在大赛中，他们展现出的不骄不躁、谦虚友好的精神风貌，得到了组委会、各校负责人的高度赞扬，值得大家好好学习。

总结会上，王卫平院长为本届篮球联赛工作人员麦可辛、彭菲等颁发了优秀工作人员证书。
