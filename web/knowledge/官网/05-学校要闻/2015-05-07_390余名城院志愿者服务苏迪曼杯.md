# 390余名城院志愿者服务苏迪曼杯

2015年VIVO?苏迪曼杯世界羽毛球混合团体锦标赛即将开赛，4月29日上午，我院300多名志愿者们参加了在东莞市篮球中心广场举行的志愿者上岗宣誓仪式。财经系丘嘉文同学带领全市600名志愿者宣誓。

东莞市副市长喻丽君在仪式上作了讲话，并向志愿者代表授予苏杯纪念卡。

据悉，在本次VIVO?苏迪曼杯世界羽毛球混合团体锦标赛我院将有392名同学从事司仪、裁判助理等志愿者服务工作。
