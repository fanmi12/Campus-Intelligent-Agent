# 学院教学检查专家组莅临财经系指导工作

2008年11月19日中午，以教务处副处长谭汪洋为组长的2008—2009学年第一学期期中教学抽查专家组到财经系检查指导工作。

财经系高香林主任对检查专家组莅临财经系指导教学工作表示衷心的感谢和热烈的欢迎，并向检查专家组作了财经系本科教学工作汇报。汇报着重从办学指导思想、教学基本建设、教学管理、教学改革、教学效果、特色项目等方面进行阐述，同时也指出了目前存在的不足之处。听完汇报后，检查专家组分别对财经系系级教学管理档案、上学期考试试卷、学生作业进行了检查，还召开了教师代表座谈会和学生代表座谈会。

在教师代表座谈会上，检查专家组听取了会计教研室和经济学基础教研室各老师的意见后，与大家进行了深入交流。针对老师提出的加强实践教学工作的问题，教务处副处长谭汪洋指出，学院目前一方面加强对实验室的建设管理，逐年增加对教学设备的投入；另一方面加强对教师的培训，已经多次举行了教师讲课比赛，今后还将开展教师技能比赛。院督学陈丁堂指出，现在我们要注重培养学生专业的敏感性，在学习理论专业知识的同时还要加强实践环节，培养应用型人才。他希望各老师积极参加教研科研活动，推动学院教学工作再上一个新台阶。

在学生代表座谈会上，各年级学生代表就本学期学习、工作、生活等方面相互交流经验，然后学生代表就本学期教学中存在的问题踊跃发言，对理论课及实验课的任课教师做出了评价，同时也提出了意见和建议。教务处副处长谭汪洋表示，会上提出的问题，学院领导会积极改进、认真解决。同时他也希望同学们能够多为学院献计献策，以学院为家，为学院的美好明天添砖加瓦。
