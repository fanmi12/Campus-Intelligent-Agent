# 我校开展线上答辩，为学生毕业保驾护航

我校毕业论文（设计）线上答辩于4月23日拉开序幕，5675名应届毕业生将在5月25日前分批完成答辩工作。这让许多应届毕业生吃了定心丸，这也将是他们一生中难忘的经历。尽管本次答辩工作转移到线上进行，答辩的学术水平要求和程序均与线下答辩保持一致，保证规范、公正、公开。

学校为了做好这次毕业论文（设计）线上答辩，经过了反复研究、多次测试，组织技能培训，不断优化线上答辩程序，确定采用企业微信直播、企业微信会议、腾讯会议等为线上答辩工作主要方式。

为了保证毕业论文（设计）线上答辩效果，各教学单位努力克服困难，分别面向教师和学生开展线上答辩培训与测试工作，并在条件允许的情况下安排答辩教师在现场集体听取学生线上答辩。在线上答辩过程中，各教学单位积极以做好答辩记录、采集答辩现场照片、制作直播回放链接、答辩全程录屏等方式开展答辩过程的管理工作，为后期进行答辩质量研究和分析工作提供保障。
