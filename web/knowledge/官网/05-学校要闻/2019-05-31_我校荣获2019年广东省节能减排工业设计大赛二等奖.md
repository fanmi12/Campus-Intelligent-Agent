# 我校荣获2019年广东省节能减排工业设计大赛二等奖

5月26日， 在华南理工大学举行的2019年“南网杯”广东大学生节能减排工业设计大赛决赛中，我校城环学院代表队作品荣获二等奖。

该项赛事是由共青团广东省委员会、广东省教育厅、广东省科技厅等主办，华南理工大学承办，决赛共有382份作品入围。我校城环学院代表队在方伟成老师指导下，由梁逸扬、苏秋熙、刘冠聪、梁瑛杰、许嘉茵、马燕菲、邱琳等同学共同创作的《“沁水之舟”——基于水体修复的一体化生态浮岛装置》荣获赛事二等奖。
