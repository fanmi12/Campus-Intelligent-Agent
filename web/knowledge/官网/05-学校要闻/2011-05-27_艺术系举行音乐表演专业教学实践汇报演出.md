# 艺术系举行音乐表演专业教学实践汇报演出

5月25日晚，艺术系在图书馆小剧场举行08级音乐表演专业教学实践汇报演出。院长安少华，党委书记朱志德、副书记朱冰，副院长张林，院督学程丁堂等观看了汇报演出。

此次演出是图书馆一楼小剧场落成后的首场活动。新近安装、调试完成的灯光、音响、舞台为学生的汇报演出提供了良好的展示平台。

08音乐表演专业的学生们轮番上台，通过声乐、器乐等形式展示了3年来的教学成果。演出在李伟健同学演唱的《祖国，慈祥的母亲》雄厚的歌声中拉开帷幕。台上同学们放声高歌，台下观众掌声此起彼伏，观众时而被《红旗颂》、《乡音乡情》中优美的歌声深深打动，时而跟随着吉他弹唱《别来无恙》的欢快昂扬曲调欢呼鼓掌，时而为古筝伴奏《人生何处不相逢》优雅的曲调而叫好，时而为《肖邦圆舞曲》、《歌剧2》展示出来的西方风情而陶醉。全班同学以大合唱《青春舞曲》圆满结束了本次汇报演出。

演出结束后，艺术系主任邓星明教授做了简短而又热情洋溢的讲话。邓主任代表艺术系全体师生感谢学院领导对艺术系的高度关怀和大力支持，为学生们的舞台实践提供了机会，并表示将不定期的继续举行此类教学实践演出活动。

院领导对艺术系音乐表演专业的教学给予充分肯定，并与全体演出学生合影留念。
