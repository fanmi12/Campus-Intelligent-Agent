# 华农珠江学院领导参观我院图书馆

3月11日，华南农业大学珠江学院汤永熙馆长等一行5人来我院图书馆参观考察。图书信息中心陈伟馆长热情接待了客人。

陈伟馆长向客人详细地介绍了图书馆大开放管理模式、各楼层的功能与布局、特色服务，以及新馆建设中的一些情况，双方就资源建设、服务措施、管理制度等方面进行了交流。
