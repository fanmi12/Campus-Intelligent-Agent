# 【征战2017DUBA】力克中大新华  我院男篮再下一城

4月21日下午，我院男篮主场迎战中山大学新华学院队（以下简称：中大新华学院），凭借出色发挥以77∶66力克对手，收获两连胜。

首节比赛方就进入白热化，我院在7号黄志陆率先飙首中3分的带领下，打出一波10∶2的小高潮。中大新华也表现不俗，13号莫启文和4号陈焕奎各取4分。

第二节，中大新华抓住机会，连续命中3分，一度将比分反超为27∶25。我院19号叶锐城挺身而出，稳住局势，以30∶29的微弱优势进入下半场。

易边再战，中大新华开场再次命中3分。但我院突然爆发，完全掌控着比赛节奏，直接轰出一波20：7。

第四节，中大新华奋起直追缩小分差，一度追至60:55。然后，最后5分半钟，我院男篮次做出调整，火力全开，打出了11:0的小高潮，最终以77:66锁定胜局。

球员数据方面，我院队员黄明健发挥出色，获得全场最高26分。
