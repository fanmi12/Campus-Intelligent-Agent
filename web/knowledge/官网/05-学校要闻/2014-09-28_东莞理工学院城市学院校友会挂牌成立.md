# 东莞理工学院城市学院校友会挂牌成立

9月27日，我院在行政楼112会议室举行城市学院校友会成立揭牌仪式。学院领导，各系部主任、副书记，40多名理事会代表出席揭牌仪式，共同见证了这一时刻。

大会审议并通过了《东莞理工学院城市学院校友会章程》、《东莞理工学院城市学院校友基金捐赠及管理办法》、《东莞理工学院城市学院校友会机构设置》，选举产生了校友会第一届理事会成员。其中，院长杨敏林教授担任会长，学生处处长杜鹏举老师担任副会长兼常务秘书长，04级计辅专业的校友袁冠华是广东南安消防工程有限公司总经理，现担任校友会常务副会长，院办主任黄兢老师等16人任副会长，郭建波等64位校友担任理事。周惠文老师等16人任校友会副秘书长，11级机械专业黎成丰等4人（校内外各两人）任校友会常务副秘书长。

校友会与城市学院发展与联络办公室合署办公。

杨敏林院长对校友会的成立表示了热烈祝贺，并对校友提出希望。他说，参天大树，必有其根；环山之水，必有其源。母校是校友的娘家，校友是母校办学重要的人才资源，校友会是校友与校友、校友与母校联系的纽带。希望校友们利用好这个平台，广泛联系校友，交流信息，传递友谊；校友会要为校友提供优质服务，有效开展活动，迅速编印《校友通讯录》；校友们应常回母校看看，为母校的建设发展建言献策。

常务副会长袁冠华、校友代表宋蜜蜜表示，为校友多担责、多服务、多谋事，把校友会变成“校友之家”。
