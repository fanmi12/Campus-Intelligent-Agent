# 计信系在广东省首届网络创意大赛中获佳绩

4月21日，首届广东省大学生“思科”杯网络创意大赛在广东外语外贸大学南校区八角楼隆重举行。我院计信系由孙军科老师和孙兴春老师指导、09级计算机科学与技术专业的谢超、张盛伟等6位同学组成的两只代表队参赛，参赛题目是“上网行为管理”、“基于3G的远程应急医疗系统的实施方案”，经过紧张的比赛，两只队伍都荣获大赛三等奖。

据悉，此次大赛由广东省计算机学会主办、广东外语外贸大学承办，思科系统（中国）网络技术有限公司冠名赞助。
