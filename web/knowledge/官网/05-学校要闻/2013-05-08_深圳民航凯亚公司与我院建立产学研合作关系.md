# 深圳民航凯亚公司与我院建立产学研合作关系

5月7日，文学与传媒系系主任邓星明教授率队赴深圳与中国民航信息集团深圳民航凯亚公司签订 “东莞理工学院城市学院移动终端多媒体研究中心&中国民航信息集团深圳民航凯亚公司产学研”合作协议。

据悉，深圳民航凯亚有限公司成立于1995年4月，是由中国民航信息集团公司控股，深航、深圳机场、南航、国航、海航、川航共同投资入股组成的民航信息技术服务性公司。该公司经营的业务主要是为深圳及其周边地区的航空公司、机场提供民航网络技术服务，承担本地区民航网络、民航订座和离港等系统的设计、建设、开发和维护工作。是民航实时订票系统和机场实时旅客处理系统的运营保障机构，是区域内该领域唯一拥有系统核心技术的单位。
