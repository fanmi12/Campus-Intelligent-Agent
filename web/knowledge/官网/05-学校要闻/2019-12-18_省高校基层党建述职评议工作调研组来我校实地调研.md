# 省高校基层党建述职评议工作调研组来我校实地调研

12月17日上午，以中山大学南方学院党委书记李建超、中山大学新华学院党委书周云和党务骨干为组员的调研工作组，代表省委教育工委来我校进行基层党建工作实地调研。学校党委书记章德胜，校长王卫平、党委委员杜鹏举、党务工作部副部长叶凯贞等领导出席了会议。

根据《中共广东省委教育工委关于开展全省高校基层党建述职评议工作实地调研的通知》，调研工作按照《广东省民办高校党建工作评价体系》的指标体系内容逐项展开，工作重点是查阅资料、实地查看。

调研组查阅了落实主体责任、加强理论学习、加强思想政治建设、基层组织建设、党员发展、教育、管理与服务、党建带群团建设、保障体系等方面的相关制度、方案、佐证材料。调研组还实地走访了我校获得省党建“双创”标杆院系的商学院党总支，并对基层党建工作给予了高度评价。
