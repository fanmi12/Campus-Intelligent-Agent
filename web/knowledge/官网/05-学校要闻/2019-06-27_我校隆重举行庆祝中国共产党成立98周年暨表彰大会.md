# 我校隆重举行庆祝中国共产党成立98周年暨表彰大会

6月27日，我校隆重举行庆祝中国共产党成立98周年暨表彰大会。学校党委委员、校领导、全体教职工党员及学生党员代表参加了大会。

大会由党委委员、副校长高香林主持。

在庄严的党旗面前，党委委员杜鹏举作为领誓人，新党员宣读入党宣誓，老党员重温入党誓词。

大会宣读了《关于表彰2018－2019学年度先进基层党组织、优秀党务工作者及优秀共产党员的决定》，对商学院党总支、金贸学院党总支、创意设计学院党总支、机关一党支部、机关四党支部等5个基层党组织授予“先进基层党组织”称号，对惠梦瑶、何伊丽、敖谦、陈晓萍等4名教工党员授予“优秀党务工作者”称号，对陈淑儿、曾惠娴等39名教工党员授予“优秀共产党员”称号，对黄义旺、陈华敏等37名学生党员授予“优秀共产党员”称号，并颁发荣誉证书。

优秀学生党员代表、商学院2019届毕业生伍奕婷在大会上发言。她回顾了四年大学生活和入党历程，表示是党组织让自己得到锻炼，让自己找到了闪光点。她说，作为新时代青年党员，深知肩负着重任，在未来新时代的广阔天地中，努力让青春尽情绽放。

先进基层党组织代表、创意设计学院党总支书记何帅以“传承优秀传统红色文化，引领师生文创成果转化平台建设，打造服务型+平台型党总支”为主题，介绍了创意设计学院党总支在开展党的建设和专业建设，传承优秀传统文化和红色文化等方面的工作经验和取得的成绩。

校党委书记章德胜回顾和缅怀中国共产党从1921年建党以来98年的光辉历程。他强调，缅怀党的奋斗历程，重温党的光荣历史，回顾党的丰功伟绩，弘扬党的优良传统，从而坚定信念，凝聚力量、激发斗志。他要求全校党员进一步继承和发扬党的优良传统，主动用习近平总书记系列重要讲话精神武装头脑、指导实践、推动学校各项事业的发展。

章德胜书记对本学年学校党建工作取得的成绩进行了总结分析，指出广大党员围绕中心，服务大局，在继承中巩固，在巩固中创新，在创新中提升，以坚定的决心、超常的举措、扎实的工作，出色地完成了各项工作任务。

章德胜书记对我校“不忘初心、牢记使命”主题教育进行了部署，要求基层党组织和广大党员以“从严从实”为标准，进一步强化从严治党责任；以“不忘初心、牢记使命”主题教育为抓手，进一步强化思想政治建设；以“正风肃纪”为关键，进一步强化党风廉政建设，不断开创学校党建工作新局面，在推动学校建设特色鲜明的高水平应用型本科院校的进程中再创佳绩，再立新功。
