# 政法系:三风建设的主力是教师

10月29日，政法系召开“三风”建设动员会议，安排部署11月份的主要活动。会议号召教师要成为“三风”建设的主力军，事事处处做学生的榜样。党总支书记、系主任刘杰教授主持本次会议。

刘杰主任强调，三风建设的关键是教风，教风好了，校风、学风才会真正的好。教风正，则学风正。教师要敢抓敢管，严格维护课堂秩序，端正学生的学习态度，纠正不良风气。
