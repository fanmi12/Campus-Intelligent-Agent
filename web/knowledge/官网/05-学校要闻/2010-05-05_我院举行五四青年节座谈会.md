# 我院举行五四青年节座谈会

座谈会现场

安院长向全院青年学生致以节日的问候

与会老师与青年学生们座谈交流

青年学生代表发表热情洋溢的讲话5月4日，由院团委主办的“弘扬五四精神 放飞青春梦想——城市学院五四青年节座谈会”在315会议室举行。

院长安少华，党委副书记朱冰，院督学陈丁堂，学生处处长章德胜，党委宣传部部长何鹏举与来自院、系的40多名团学干部进行了座谈交流。

座谈会由院团委书记杜鹏举主持。

会上，思想政治教学部刘珍教授为大家回顾了五四运动和五四青年节的相关历史和背景。与会的80年代、90年代青年学生和40年代、50年代、60年代、70年代的“青年”代表们，就五四精神的传承及现代青年人的社会责任等问题进行了热情洋溢的发言。

安院长代表学院向与会的青年学生，并通过他们向全院的团员青年致以“五四”青年节的节日祝贺和问候。安院长指出，五四精神的核心内容是“爱国、进步、民主、科学”，中华民族今日的崛起离不开91年来一代又一代青年的不懈努力，全院团员青年要将“五四精神”进一步发扬光大。安院长还对学院团干部和广大学生干部以及奋战在学生工作一线的老师们表示感谢，他号召学院的广大青年要充分发挥先锋作用，为城市学院的发展再立新功。
