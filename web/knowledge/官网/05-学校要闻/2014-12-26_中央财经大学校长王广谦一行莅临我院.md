# 中央财经大学校长王广谦一行莅临我院

12月20日，中央财经大学校长王广谦、副校长史建平一行莅临我院，受到院长杨敏林、党委书记王卫平等领导的热情接待。

王广谦校长、副校长史建平分别就“学校治理?学科建设”的专题进行交流。他们分析了广东经济社会快速发展的主因，介绍了国外高校建设发展的态势，民办高校与独立学院的发展空间等方面的信息，对我院的发展提出宝贵的建议。

杨敏林院长对两位校长的指导与建议表示感谢和赞同，希望两校今后加强交流与合作。

王广谦校长一行人参观了校园和校史展厅。
