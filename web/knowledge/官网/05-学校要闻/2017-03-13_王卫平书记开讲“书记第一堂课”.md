# 王卫平书记开讲“书记第一堂课”

3月10日，院长、党委书记王卫平在教学楼7A107教室开讲“书记第一堂课”，生动讲述了当代大学生如何培育和践行社会主义核心价值观。部分学生代表和行政干部、思政教师参加了讲座。

王院长从当代大学生成长、成才到成功的过程，分析了当代大学生的几个特点和局限。从国家层面、社会层面和个人层面，讲述了社会主义核心价值观二十四字的内涵。王院长指出，当代大学生怎么样培育和践行社会主义核心价值观？要从具体工作做起，从一点一滴做起，在具体的活动中培养。如何看人？应该从四个方面来看：讲信用、无官气、有条理、少大话。如何成长？第一要有志，第二要有识，第三要有恒。如何做人？胸怀要大度，视野有宽度，理论有深度，工作有力度，事业有高度，寿命有长度。

“人不能忘本，心不能忘恩。事不能蒙混，情不能二心。”书记第一堂课让在场听讲的学生心潮澎湃，心中的理想信仰之花正悄然绽放。
