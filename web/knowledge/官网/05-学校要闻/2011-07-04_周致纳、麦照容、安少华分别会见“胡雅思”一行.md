# 周致纳、麦照容、安少华分别会见“胡雅思”一行

周致纳书记会见胡敏教授

麦董事长与胡教授座谈

安院长与胡教授座谈7月2日，东莞理工学院党委书记周致纳，城市学院董事长麦照容，城市学院院长安少华，在广东鸿发集团分别会见了新航道国际教育集团总裁兼校长胡敏教授一行，并就国际教育等项目的合作协议进行了座谈交流。城市学院董事黎建烨，城市学院领导朱志德、杨敏林、张林等出席了座谈会。

座谈会上，麦照容对城市学院与新航道集团的合作项目表示肯定和支持。他表示，本次合作项目具有很大的可行性，为城院学子未来的发展开辟出了一条新路子。他希望双方拓宽合作渠道，共同打造华南地区乃至全国知名的国际教育品牌。

周书记对胡教授一行的到来表示热烈欢迎，并预祝合作取得圆满成功。他说，城市学院充分发挥新机制办学优势，主动走出去与国际教育机构合作办学的做法很好，这种开放式的办学模式具有广阔的发展前景。新航道国际教育集团一直关注城市学院的发展，如今广东鸿发投资集团投巨资建设城市学院新校区，这是很好的发展契机，希望双方共同努力，培养具有国际视野的本土人才，为东莞教育事业的发展作出更大的贡献。
