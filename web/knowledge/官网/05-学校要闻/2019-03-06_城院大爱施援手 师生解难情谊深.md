# 城院大爱施援手  师生解难情谊深

3月5日下午，2016级法学4班罗俊涛同学的母亲将一面“师生情无价 相聚也有缘”的锦旗送到政法系领导手中，真情感恩城院师生对罗俊涛同学的关爱和帮助。

2018年12月22日中午，罗俊涛同学因头痛头晕，去医务室就诊时突然昏迷。获知情况后，同班钟友娟、洪越强、郭宝莹等同学随即赶到医务室，并陪同120救护车将罗俊涛同学送往同济光华医院进行抢救。

12月24日上午，经院方专家最终确诊为脑血管瘤，当日下午成功实施手术，治疗费用花费了近10万元。罗俊涛同学家庭并不富裕，父母都是地道的农民，为支持两个孩子完成学业已是负债累累。面对巨额的医药费用，举家发愁束手无策。政法系领导和师生得知该情况后，立即组织全系师生为罗俊涛同学进行募捐，并在全院发动献爱心活动。募捐活动在学院及社会爱心人士中共筹集资金近7万元，缓解了罗俊涛同学家的燃眉之急。

目前，罗俊涛同学已康复返校，正全身心地投入到了紧张的学习中。
