# 财经系会计知识文化月拉开帷幕

3月29日，财经系第五届会计知识文化月拉开帷幕，近300名选手在四号楼大厅参加会计知识竞赛初赛。

有来自财经系09、10级以及高职部的学生参加了此次初赛。竞赛内容涉及《基础会计》、《税法》、《财经法规》等各方面知识。

据悉，财经系第五届会计知识文化月从3月开始一直持续到4月底，活动内容包含会计技能证宣讲会、会计职业必备技能经验交流会、会计知识竞赛初赛、会计知识竞赛决赛等活动。会计知识竞赛文化月中的一项重要活动，初赛成绩优秀的学生将代表城市学院，参加5月19日在广东科技学院举办的2012年东莞地方高校会计知识邀请赛。
