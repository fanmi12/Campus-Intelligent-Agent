# 我院2015年暑期“三下乡”活动获团省委表彰

日前，经团省委、省学联认真研究与评估，我院2015年暑期“三下乡”社会实践活动中的19实践分队“关爱空巢老人、寄情美丽夕阳服务队”荣获“2015年广东省大中专学生志愿者暑期‘三下乡’社会实践活动优秀团队”称号，同时获奖的还有我院苗琳、李响老师，张诗静、林银芝、何辉熊同学荣获了“2015年广东省大中专学生志愿者暑期‘三下乡’社会实践活动优秀个人”称号。

2015年暑期，我院积极响应团省委、省学联开展的“实践出真知，锤炼真本领”的暑期“三下乡”社会实践活动，学院各实践分队从社会热点现象出发，全身心投入社会实践活动之中。
