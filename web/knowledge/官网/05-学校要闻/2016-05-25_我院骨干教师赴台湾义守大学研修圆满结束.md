# 我院骨干教师赴台湾义守大学研修圆满结束

5月15日-21日，我院教师发展中心组织选派17名骨干教师赴台湾义守大学进行了为期一周的研修活动。

此次研修活动的主题是“如何上好一堂课”,17位骨干教师按专业方向分到义守大学各个院系进行深入交流学习。老师们一方面通过和各个院系负责人、老师们的交流，了解义守大学的专业设置与课程设置。另一方面，听取各个院系优秀教师的讲课，感受义守大学的学习气氛。通过这两种方式的学习，研修团整体上把握了义守大学的专业设置、学生培养、教学模式等。

据义守大学大众传媒系系主任陈瑞芸介绍，与大陆高校相比，义守大学更加注重实践，许多科目的学习都要进行动手操作，以交作品的方式完成。我院的交换生汪同学也表示，在义守大学确实非常注重实践方面的学习。

本期研修活动，让教师们对两岸的教育也有了更进一步的认识，收获丰硕。参加研修学习的老师们表示，此次的研修活动办得非常好，以后应该多办，惠及更多的老师。我们不仅要埋头苦干，更要开阔视野，通过这种境外交流学习，取长补短，提升我院教师的教学水平。
