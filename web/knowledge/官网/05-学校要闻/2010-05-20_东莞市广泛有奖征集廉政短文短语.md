# 东莞市广泛有奖征集廉政短文短语

为营造良好的反腐倡廉社会环境和舆论氛围，推进廉政文化建设，市纪委、市检察院、市监察局决定在全市开展有奖征集廉洁短文、短语活动，学院希望全院师生积极参加征集活动，踊跃投稿。

据悉，短文作品1000字以内，无长句，内容充实，文字优美，契合“廉政”主题，鼓励充分发扬东莞本土袁崇焕、却金亭、廉泉等廉政文化，文体不限。短语50字以内，精妙、简练、朗朗上口，契合“廉政”主题（范本：持廉守正，你我同心）。

投稿作品统一按要求上传至东莞时间网大赛专题网页面（www.timedg.com\lz2010），并同时发送至城市学院有奖征集活动专用信箱
