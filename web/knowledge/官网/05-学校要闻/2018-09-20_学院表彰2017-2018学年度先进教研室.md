# 学院表彰2017-2018学年度先进教研室

9月19日，学院举行了2017-2018学年先进教研室表彰大会, 保险教研室、财务管理教研室受到表彰。

大会上，王卫平院长为获得先进教研室称号的代表进行授牌，希望受表彰教研室再接再厉、再创佳绩，发挥好示范带头作用。全体教师要认真学习先进经验，争先创优，进一步提高我院教学质量和人才培养质量。

据了解，为加强教研室建设，发挥教研室的作用，增强教研室的凝聚力与战斗力，我院于今年5月开展了2017-2018学年度先进教研室评选工作。经各教学单位推荐、教务处初审、教学工作委员会投票表决及全院公示，学院决定授予金贸系保险教研室、商学院财务管理教研室为“先进教研室称号”。
