# 广西侨务办公室及广西华侨学校领导来我院参观访问

6月13日上午，广西壮族自治区侨务办公室主任冯祖华、副主任陈宁、经济科技处处长陈洁及广西华侨学校校长陈进超等一行6人，来到我院新校区参观访问。学院董事长麦照容给予热情接待，并陪同客人参观了新校区。

在我院新校区建设期间，冯祖华主任曾两次前来参观，见证了新校区一期工程高标准、高质量建设完成，并投入了使用。此次，冯主任率领广西侨办和广西华侨学校领导一行来我院考察和交流，先后深入学生宿舍、学生食堂及图书馆等进行实地参观、考察。

我院学生宿舍的组团式建筑、“一卡通”的运用与管理、节能型的热水供应、空调设施、学生食堂的错层出入口、餐饮管理服务等，都受到客人的赞赏和高度评价。客人们尤其欣赏我院具有岭南建筑特色、造型优美的图书馆，以及其先进的软硬件设施和图书管理办法。
