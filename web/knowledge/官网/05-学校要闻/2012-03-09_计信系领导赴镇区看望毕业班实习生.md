# 计信系领导赴镇区看望毕业班实习生

近日，计算机与信息科学系主任牛熠教授、总支书记廉玉忠教授带领该系12位老师，分成4个小组赴东莞各镇区检查、看望毕业班实习学生，了解他们的实习、生活情况和实习中存在的问题，并与用人单位就人才培养模式的创新等问题交流了意见。

检查的老师勉励同学们虚心学习，利用实习机会，积累工作经验，克服困难，争取在实习单位赢得就业机会。

走访过程中，各镇区实习单位对毕业实习生评价很高，对我院“服务东莞”的办学宗旨给予了充分肯定。
