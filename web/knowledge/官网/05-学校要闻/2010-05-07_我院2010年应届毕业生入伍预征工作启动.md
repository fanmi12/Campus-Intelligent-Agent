# 我院2010年应届毕业生入伍预征工作启动

动员会现场

朱冰副书记对毕业生入伍预征工作进行部署动员

为贯彻落实教育部、省教育厅《关于做好2010年普通高等学校应届毕业生入伍预征工作的通知》精神，5月6日，我院在3202召开2010年应届毕业生入伍预征动员会。党委副书记朱冰、学生处副处长陈建新出席了动员会。

会上，朱冰副书记传达了广东省2010年高校毕业生入伍预征工作电视电话会议精神，并对我院即将开展的预征工作进行了部署动员。她指出，今年是开展普通高校应届毕业生入伍预征工作的第二年，工作任务重，时间紧，要求高。职能部门要充分认识预征工作的重要性，协同配合，广泛动员，认真做好工作，保质保量地完成任务。

陈建新副处长向与会人员大家介绍了我院预征工作的流程和国家相关优待政策，并分解了各系部的工作任务。

另据学生处凌继峰老师介绍，今年我院有两个专业符合士官征集的要求，目前已上报东莞军分区，正等待批复。士官征集工作将于本月中旬启动。
