# 我院举办首届英语戏剧大赛

12月7日,我院首届英语戏剧大赛决赛在学术报告厅举行。

这次比赛是由院团委、外语系联合举办，经过初赛角逐，从70多支来自各院系的队伍中，选拔出来8支队伍进行决赛。决赛模拟奥斯卡颁奖典礼的形式，将8支队伍的剧目按照体裁分为最佳外国童话、最佳中国戏剧、最佳外国戏剧三类进行。

经评委评定，《Cinderella》剧组与《The return of pearl》剧组获得了一等奖；《Snow White》剧组、《Once upon a time》剧组、《king Lear》剧组获得二等奖；《Sharp Tools》剧组、《A Midsummer Night's Dream》剧组、《The Necklace》剧组获得了三等奖；此外，《Snow White》剧组获得最佳人气奖；《The Return of Pearl》剧组获得最佳台风奖。
