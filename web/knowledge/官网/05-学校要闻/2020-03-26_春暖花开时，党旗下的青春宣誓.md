# 春暖花开时，党旗下的青春宣誓

3月25日，我校收到河源市紫金县凤安镇居委会发来的表扬信，表扬我校创意设计学院视觉传达专业郑桐彬同学在抗击疫情期间，利用寒假积极投身防疫志愿者工作，工作积极认真，在全力抗击这场没有硝烟的疫情防控战役中，用实际行动彰显了新时代青年的责任和担当。

自疫情爆发后，郑桐彬便在紫金县凤安镇居委会做志愿服务工作，主要负责对过往车辆进行外来人员信息登记、测量体温，以及记录车辆始发地和目的地。

哪里有需要，哪里就会有他的身影。当一线防疫工作人员紧缺时，他不怕被疫情感染，主动站出来担任外来人员体温测量、登记工作，由于外来人员数量较大，郑桐彬便利用自己所学的知识，将社区手工登记升级为网络二维码登记，设计了移动端数据采集库，大大地提高了办公效率，也减少了工作人员的感染风险。

在疫情最严重的那段时间里，郑桐彬同学坚持每天三班倒值班，只要轮到自己值班，不管是白天还是深夜，他都坚持在自己的岗位上，即便是吃饭，也不离开岗位。

在志愿者工作期间，郑桐彬还需要特殊照顾一些体温异常的人。通常这种情况下对方比较紧张情绪激动，不愿配合检查隔离工作，郑桐彬一边帮他们消毒一边耐心疏导沟通，安抚情绪，让对方放下思想包袱，同意积极配合接下来的工作，再陪同他们乘坐防疫专车至指定的卫生院接受检查。

他的班主任和同学听到了他的事迹，纷纷表示并不惊讶，他平时就是这样一位阳光乐观大男孩，学习主动认真，专业知识扎实，拿过很多设计赛事的奖项。在学校时也是关心集体、乐于帮助同学的典范，多次参加各种志愿服务工作。

一年前向党组织提交入党申请书时郑桐彬说“加入中国共产党是我一直以来最大的心愿”。他说：“共产党员总是要冲在在最危险、最艰苦的前线的，这次爆发的新冠肺炎疫情，在党中央的领导下，全国上下众志成城，万众一心抗击疫情，让我备受鼓舞，更坚信中国共产党的力量是无穷的！在这场没有硝烟的战斗中，虽然我还是一名入党积极分子，但我始终以一名共产党员的标准来严格要求自己。”据悉，创意设计学院已经召开总支委员会议，一致同意发展其加入党组织，等到春暖花开，返回校园的那一天，再到党旗下宣誓入党！
