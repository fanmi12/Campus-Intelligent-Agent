# 我院第一届宿舍美化设计大赛圆满结束

经过初赛、复赛，5月25日下午3时，城市学院第一届宿舍美化设计大赛颁奖大会在六号阶梯教室隆重举行。据悉，报名参加本次大赛的宿舍达到一百多间，经过评比，有15间宿舍进入了最终的决赛。

以大自然的色彩为主题的9#617宿舍最终技压群芳，夺得一等奖。总务处周林冲副处长对本次大赛的胜利举行表示祝贺，同时希望借此大赛，营造良好的学生宿舍卫生环境、学习氛围，同时增强同学们的集体凝聚力，提高同学们的创造力。

颁奖大会在热烈的掌声中落下帷幕，同时也表明城市学院第一届宿舍美化设计大赛圆满结束。
