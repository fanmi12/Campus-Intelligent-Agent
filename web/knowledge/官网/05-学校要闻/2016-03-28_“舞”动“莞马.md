# “舞”动“莞马

“舞”动“莞马”

旭日初升，春风送暖。和煦的阳光为大地洒下无限的活力与跃动，“莞马”也被笼罩其中。

一群来自我院K-POP韩舞队、LT街舞队，以及艺术系的青春少女们，穿着火辣的衣裙，在舞台上尽情展现自己青春的姿态，释放青春活力。这支《跃动青春》给“莞马”注入了更多鲜活的元素。

“我们练了将近一个月，这也是我作为大四即将毕业的最后一次表演，虽然挺累的，但我很珍惜这个机会，也非常荣幸能在舞台上为‘莞马’助威加油。”该舞蹈负责人微笑着说，脸上洋溢着青春的活力和满满的自信。

欢乐“莞马”

早上7点，太阳刚过升到半空，城院的小伙伴们已早早到达“莞马”现场。在赛事来临之前，大家一面当做热身，一面找起了“乐子”——踢毽子。

只见一群人围成了一个大圆圈，毽子在他们灵活的肢体下自由穿梭，飞速跳跃，时不时传来充满活力的欢声笑语，吸引了许多路人驻足旁观，也让更多人经受不住“诱惑”纷纷加入了踢毽子队伍当中。

城院的小伙伴们用快乐传递给身边的每一个人，也为即将开场的赛事增添了许多乐趣。

“相框”里的世界

若留意便会发现，“莞马”城院摊位处摆放着一个泡沫胶质材的“相框”，小伙伴们都争着与“相框”合照，连老师也不亦乐乎。

据悉，该“相框”是城院贴吧的小伙伴们构想设计的，它的用处就是供人拍照、宣传、。

“我们用了一个星期的时间去做预算、采购之类的准备，虽然有辛酸，但觉得很开心，城院的小伙伴们都很棒！”城院贴吧负责人如是说。

一杯水，甜在心里“您好！辛苦了，请喝杯水吧！”

“谢谢你！”

这段对话重复不断地演绎在摊位前面的过道上。每当选手们冲刺终点后筋疲力尽地走过，城院摊位的小伙伴们就会赶紧递上一杯水，为了补充运动员损耗的体力，小伙伴们还特地在水中加入了葡萄糖，更有贴心的同学将风油精都准备好了。

一杯简简单单的水，甜在口中，更甜在心里。
