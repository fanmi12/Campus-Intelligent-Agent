# 【办学战略思想讨论之三】“一流”辨析

城市学院在成长的过程中形成了“依托母体保质量，面向市场谋创新，服务东莞求支持，追求卓越创品牌，科学发展做贡献，三年打基础、扩规模，五年上水平、创特色，打造省内一流独立学院”的办学方针。首次明确了学院发展目标是省内一流独立学院。在这一办学方针的指导下，经几年努力学院已颇具规模，正在致力上水平，在省内市内已有相当的口碑。在学院即将“转制”之际，办学方提出要把城市学院办成国内一流本科院校的奋斗目标，并决心加大投入，城市学院人深受鼓舞。兴奋之余，首要厘清我们的奋斗目标，才能更好地为之奋斗。

一流是何意？一流就是一等，不是二等、三等，是最好！如何办最好的独立学院，有各种理解。有说要抓紧机遇扩大规模；有说要招最好的教师，加大投入，要把科研搞上去；有说要办得不比理工学院差（把理工学院当参照物）；也有说要找个名声响的母体挂靠……众说纷纭。

教育部副部长吴启迪有一段讲话发人深醒：“我们要转变在精英教育阶段形成的单一的学术型质量观，树立全面的、多样化的、动态质量观。不同的高等学校要从实际出发，根据自身条件和经济社会发展的需要，在发展目标、层次、类型、专业、服务面向等方面合理定位。不同层次类型的高等学校，都可以在它自己的层次类型上办出一流的水平和质量来。”这段话的要义有三点：1、要转变单一的学术型质量观，树立全面、多样化的、动态的质量观。其中单一和多样是关键词，从中可体会“一流”的标准是多样的，不是只有一个标准！2、不同层次类型的高等学校，都可以在它自己的层次类型上办出一流的水平和质量来。3、不同的高等学校要从实际出发，根据自身条件和经济社会的需要，在发展目标、层次、类型、专业、服务面向等方面合理定位，分类发展，在自己的层次上做到最好，也是一流，可见合理定位是创一流的关键。

那么我院的合理定位在何处？相关的一流标准是什么？

首先，让我们思考一下我院层次的定位。

2007年广东省教育厅厅长罗伟其在广东省高等职业技术教育综合改革座谈会上的讲话中指出。根据分类指导原则，当前我国高等教育应该分为三类去思考：第一类是“985”、“211”工程高等学校，这类学校的任务是在培养高层次的创新型人才，为国家创新体系建设作出贡献。第二类是除此之外的本科院校，应该集中在应用型本科教育上，包括培养高层次技能型人才。第三类就是高职高专教育，高职高专教育就应该培养高技能人才。罗厅长的“包括培养高层次技能型人才”的指示仍对今天设计我院层次定位、培养目标定位有指导意义。

根据有关文献的观点，结合我院生源特点，城市学院培养目标应是有技术型人才特色的工程型人才。

我院（含理工学院）机械专业课程力学课设置只有理论力学和材料力学，不难看出我院的培养目标更接近技术师。工程师的工作是应用基本理论去构思，其工作重在构思。因此对现代科学理论及前沿应非常熟悉，厚基础、宽基础要落到实处，不熟悉谈何应用。

其次，思考如何做好科学研究，也有个定位的问题。

科学研究以创新为目标，研究范畴大体分为两个方面。其一是教学研究。教学研究为教学改革提供思想、方案。在信息爆炸的今天如何构筑专业基础理论内容，给学生打下适度宽、厚、深的基础是需要大智慧，下大力气的；我们认为：如何落实学生行动体系智能的培养，吸收高等职业教育的专业课开发经验,是我们开展教学研究的重点。其二是科学研究。科学研究如果没有创新是浪费国家资源，制造垃圾。而创新可存两个层次。高层次是发现新的自然规律和发现基本原理等。这是科学家及以科学家牵头的团队的目标。教学型学校即使产生了这样的成果，也没有典型意义。应用基本理论去创造一些经济地利用材料和自然力为人类服务的方法，设计产品和生产系统则是下一个层次科学研究的目标。我们学校的科研应该属于这个层次。这种研究其实是工程师工作范畴。这样讲好像降低了我院科研的地位，其实是目标更清晰，科研更有社会意义了，成果鉴定的标准也明确了。如果能落实这个目标则教师自己会做工程师工作，才能知道如何培养工程师；其成果对促进东莞经济升级转型有实际意义。美国把研究生毕业作为工程师资格申报的门栏，则我院开展研究生教育也有了基础。

这样的研究，听起来降低了身价，实际却提高了难度，对研究者提高了要求。建议学院成立研究所，挑选和引进有能力、有担当、有思想的科研带头人，宁缺勿滥，在财力和团队组织上加大投入，踏踏实实地做几年研究，对东莞经济社会才有真作用。

其三：如何为社会服务的思考。

作为东莞本地区少数几所大学之一，为东莞服务应是广泛的，是大有作为的,但关注点应在高层次。要能深层次的融入社会，还要从高校三大功能着眼，教学上转变人才培养思路，培养出有特色的为东莞社会经济急需的各层次人才；科研上做实事为东莞经济转型升级提供新产品，新系统；以研究所和实训基地为依托，开门办学，为东莞各行各业的工程技术人员提供充电提高的学习机会，把我院办成立足地方的开放式大学。
