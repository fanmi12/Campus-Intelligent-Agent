# 我院召开安全工程专业学士学位授予权申报评审会

2月27日，我院在8C313会议室召开城市与环境科学系安全工程专业学士学位授予权申报评审会。东莞理工学院、城市学院的专家和有关领导出席了会议。会议由专家组组长东莞理工学院教务处副处长陈想平教授主持。

会上，城环系主任肖红飞教授介绍了近四年安全工程专业的建设情况。

随后，专家组查阅了安全工程专业建设、教学档案等相关资料，并对安全工程专业实验室和资料室进行了实地考察。考察工作结束后，专家组对安全工程专业的考察意见和建议进行了及时反馈。与会专家和领导对安全工程专业的建设成效给予了肯定，同时对人才培养方案、实践教学、毕业论文（设计）等方面提出了宝贵的建议。专家组一致认为，安全工程专业的建设工作总体良好，但也存在一些不足，希望进一步加强与校外企事业单位的合作办学，促进应用型人才的培养，也希望学院继续大力支持新增学士学位授予权专业建设工作。

据悉，安全工程本科专业于2010年2月经教育部批准而设置。据2014年申报材料称，安全工程专业主要培养具有建筑安全、化工安全、机械安全、职业卫生、安全管理等方面知识的社会急需的安全工程应用型人才。
