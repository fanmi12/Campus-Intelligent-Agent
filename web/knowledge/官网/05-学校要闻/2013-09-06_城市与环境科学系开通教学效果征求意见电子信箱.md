# 城市与环境科学系开通教学效果征求意见电子信箱

为提高教师教学质量，贯彻落实学院《关于推进应用型本科人才培养模式改革工作的方案》等文件精神，进一步深化教学模式的改革，提高教师的教学能力和教学质量，加强教风和学风建设，城市与环境科学系日前开通了教学效果征求意见电子信箱（ccdgutdces@163.com），征求广大师生对教学工作的意见与建议。
