# 计算机与信息科系“JAVA软件工程师”课程置换班开班

计算机与信息科学系与“东方标准”联合举办第三届“JAVA软件工程师”课程置换班于7月13日开班。

东方标准东莞授权中心市场经理刘经理说，课程置换班是以JAVA课程为核心，辅以开设数据库、Struts2框架编程等5门课程。课程考核方式为完成项目任务，以此来提高学生的IT专业技能与实践能力，提高学生的团队合作能力。

据计算机与信息科学系主任牛熠博士介绍，本届共有50个同学通过筛选进入课程置换班学习，为期一个月。

据悉，通过课程置换学习，同学们增强了实践动手能力，提前基本掌握了企业运作所需的计算机实践知识。往届课程置换班学生就业率比非置换班学生要高。
