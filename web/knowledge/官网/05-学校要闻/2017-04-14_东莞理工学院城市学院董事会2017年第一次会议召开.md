# 东莞理工学院城市学院董事会2017年第一次会议召开

3月21日，东莞理工学院城市学院董事会2017年第一次会议召开，全体董事出席了会议。

会议由麦照容董事长主持。

会议审议了东莞理工学院城市学院2016年工作总结及2017年工作要点，审议通过了上一年度预算执行情况，并原则通过本年度财务预算。

董事会充分肯定了学院一年来的工作，并对学院发展提出新的要求。会议要求，下一阶段要进一步培育和凝练专业特色，加强开放办学和国际化办学，加大高层次人才引进及青年教师发展支持力度，继续加强党建和思想政治工作。
