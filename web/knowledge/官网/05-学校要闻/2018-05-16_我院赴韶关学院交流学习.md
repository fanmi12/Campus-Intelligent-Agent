# 我院赴韶关学院交流学习

5月12日，在王卫平院长、高香林副院长的带领下,我院教务处领导、督导办专兼职督导员赴韶关学院，就教学质量监控、教学督导与教学管理等工作开展交流学习。

韶关学院党委委员、教务处处长赵三银向学习组详细介绍了该校专业办学特色、教学管理经验、迎接教育部审核评估的准备工作等情况。教学质量监控与评估中心主任吴邵兰介绍了韶关学院教学质量监控与评估中心的发展历史，以及在教学质量监控方面实施的“三全两多六贯通”工作模式等所取得的成功经验。

王卫平院长向韶关学院有关领导介绍了我院办学的特色和经验，并向韶关学院赠送了纪念品。学习组还参观了韶关学院校园。
