# 我院开展2008年新进教职工岗前培训

6月30日，我院2008年新进教职工岗前培训班在315会议室举行了启动仪式。会上，院长安少华教授作了主题讲话，对新加盟我院的新同志表示热烈欢迎，介绍了学院办学历史、发展现状和前景，分析和阐释了学院的工作重心、学院定位、建设任务、人才培养模式、可持续发展战略以及存在的问题，使新进教职工对城市学院的概况和发展有了一个清晰的认识，明确了今后工作的方向。安院长还鼓励大家热爱高教事业，做到德才兼备；立足本职岗位，努力把自己锻炼成为所在岗位的行家能手；关心学院的建设和发展，为维护学院良好的校风、教风和学风做出应有的贡献。

院党政领导朱志德、程发良、朱冰、张林、院督学林世俊及机关各处室负责人和各系部主任出席了会议。来自五湖四海的39名新进教职工进行了自我介绍，并与领导合影留念。

据人事处处长夏勇博士介绍，自去年6月份以来，我院又加盟了54名教职工。新进教职工来自中国艺术研究院、北京师范大学、北京理工大学、中山大学、哈尔滨工业大学、华中科技大学等名牌大学，其中有从事教学工作20年的老教授，有美国留学归来，从事印刷工程专业研究的博士，也有26岁就获得博士学位的年轻教师。他们将参加为期5天的培训，部分人员还将参加华南师范大学举办的广东省高校教师岗前培训。
