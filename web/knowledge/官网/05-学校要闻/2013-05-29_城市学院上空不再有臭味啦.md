# 城市学院上空不再有臭味啦

东莞市环保局重视师生诉求，认真办理政协委员的提案，大力整治城市学院周边的空气质量。经过两个月的整治，城市学院周边飘来的臭气“不见了”。

市政协委员牛熠博士提案：需对寮步镇文昌路一带空气污染进行治理3月25日有网友@CY 宇杰Liang 在新浪微博上反映，寮步文昌路片区的企业违法排污排气，致使城市学院周边经常飘来臭气，令人恶心作呕。城市学院教务处处长牛熠博士自从担任东莞市政协委员、民进委员以来，认真履行政协委员的职责，在东莞市政协第十二届二次会议召开之前，根据师生们反映的臭气问题，也写出了一份委员提案，案由是“关于对寮步镇文昌路一带空气污染治理”的建议。该提案指出，“城市学院周边的一些企业不顾这里的居民、师生和游人的健康，乱排乱放，特别是利用晚上的时间集中排放，对当地居民和师生员工的身体造成了严重的威胁。”城市学院办公室也多次呈文反映空气污染问题。东莞市副市长吴道闻就这一问题做出了批示，要求市、镇环保部门认真整治城市学院周边工厂违法排污排气问题。

寮步镇环保分局：查处三家企业偷排放废气

寮步镇寮步环保分局根据牛委员的提案对寮步镇小坑村、长坑村、井巷村的27间企业进行了排查，共出动执法人员76人次，最终发现有3间企业在生产过程中产生废气异味，分别是东莞悦龙薄膜有限公司、东莞市长利鞋材有限公司、东莞森崧木器有限公司具体情况是：东莞悦龙薄膜有限公司正在报批建设环境影响评价文件，主要是生产塑胶薄膜，挤吹塑工序产生废气异味，已配套有相应的污染防治设施，废气经活性炭吸附处理后排放。

东莞市长利鞋材有限公司没有报批建设环境影响评价文件，主要是生产鞋材纸板，磨浆、湿抄工序产生异味，没有配置相应的污染防治设施。寮步环保局对该厂的环境违法行为做了现场取证工作，并发出了《行政处罚决定书》和《责令改正违法行为通知书》。

东莞森崧木器有限公司主要是生产木制配件，设有一燃柴锅炉。寮步环保分局对该厂发出了《环境违法行为限期改正通知书》，并责令其停止使用燃柴锅炉，限期进行锅炉整治改造，该厂负责人向执法人员表示，工厂将于5月份搬迁。

市环保局：认真回复政协委员提案

市政协第十二届二次会议提案委员会对牛熠委员的这一提案给予了立案，并交由市环保局办理。

市环保局认真办理牛熠委员的提案，并将治理结果向吴道闻副市长和牛委员做了专题汇报和答复。汇报材料说，今年1—3月，市局先后组织市、镇执法人员86人次，对寮步镇文昌路区域工业企业进行了全面排查，共检查企业43家，其中发现有4家企业涉嫌违法排污。调查初步认定寮步镇文昌路区域即城市学院上空的空气污染主要是由该区域部分工业企业违法排污及附近群众乱烧杂物等原因造成。对此，该局已对其中1家存在较重环境违法行为的企业发出了《行政处罚决定书》和《责令改正违法行为通知书》，对其他3家企业发出了《环境违法行为限期改正通知书》。经复查，这3家企业其中有2家已完成整改工作，1家已停产搬迁。与此同时，市环保局还函请寮步镇按照有关程序和法律规定，加强该区域城市生活垃圾的管理和井巷村垃圾处理的综合整治，防止发生垃圾臭味扰民现象。

城院师生：飘来的臭气“不见了”

记者近日访问了城市学院部分师生，他们表示飘来的臭气“不见了”，但偶尔还是会闻到一些异味。
