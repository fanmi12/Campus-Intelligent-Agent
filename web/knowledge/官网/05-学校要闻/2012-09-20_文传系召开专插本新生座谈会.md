# 文传系召开专插本新生座谈会

9月19日，文学与传媒系在老校区系会议室召开了2010级专插本新生座谈会。据悉，今年该系共有23名专插本学生。

会上，2009级专插本成功的学生谈了学习经验。他们认为刚到新的环境时会不太适应，也有一定的困难，但只要坚持信念和努力奋斗，就一定能追赶上其他同学。2010级刚插班学习的同学则表示，到了新的班级后会与同学们友好相处，尽快适应新的课程。

系主任邓明星教授表示，学院和系一定尽最大的努力帮助大家解决学习上的困难，并引用俗语“只要功夫深，铁杵磨成针”鼓励学生，希望大家要花精力和时间，填补充实专业知识，争取全面提高。
