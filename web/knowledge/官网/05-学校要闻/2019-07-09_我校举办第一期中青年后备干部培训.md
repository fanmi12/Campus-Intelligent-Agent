# 我校举办第一期中青年后备干部培训

7月6日-7日，我校举办了第一期中青年后备干部培训活动。校领导王卫平、刘玉侠，学校董事长代表陈超群和首期27名后备干部参加了培训活动。

6日上午，培训活动举行了开班仪式。刘玉侠副校长主持了开班仪式。

学校董事长代表陈超群阐明了学校在新形势下培养后备干部的重要意义，希望后备干部珍惜培训机会，提高政治站位，日常工作中要勤于学习、善于思考、敢于主动担当，从学校长远发展的角度去思考问题。他表示，中青年后备干部培养要纳入学校常态化培养体系，努力造就一支综合素质高、能担当重任、经得起考验的高素质中青年后备干部队伍。

王卫平校长强调，中青年后备干部是学校改革发展的中坚力量，后备干部要不断拓展视野、积累经验、多学知识，提升修养。无论是现在与将来，学校都将严格坚持德才兼备、以德为先的干部选拔原则，为广大优秀中青年教师提供发展平台。

6日下午，东莞市党校谭汪洋教授应邀作了“提升自我修养，做新时代好干部”的专题报告。他以中国传统文化修身为研究视角，指出干部修身要以道德自律为基本模式，回归到党性修养，内化为自己的价值追求和奋斗目标。

7日上午，东莞理工学院副校长杨敏林教授应邀作了“地方高校国际化的战略思考与实践”的专题报告。他详细讲解、分析了高等教育国际化的八大指标，分享了东莞理工学院国际化办学实践经验，阐述了东莞高校要抢抓粤港澳大湾区建设机遇，领导干部要全面提升国际化战略意识，以国际化战略思维，推动办学国际化、学生国际化、科研国际化、教师国际化的理念。谈及创新粤港澳台合作模式，杨敏林教授认为，要坚持“以我为主，为我所用”的原则，结合实际，因地制宜，制定国际化发展战略，做好顶层设计，稳步推进学校国际合作与交流。

据介绍，我校将以素质能力教育为核心，重点开展理想信念、道德品行、工作作风、知识技能等方面对中青年后备干部进行培养，以提高干部的思想觉悟和理论基础，培养干部的战略思维和世界眼光。我校对本期中青年后备干部培养进行持续1-2年的中短期课程培训，以专题讲座、互动研讨、考察交流、反思总结等形式开展教育培训，与中长期的工作实践相结合，致力于培养更多优秀的年轻干部。
