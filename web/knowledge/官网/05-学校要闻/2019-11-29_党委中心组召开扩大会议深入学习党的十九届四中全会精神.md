# 党委中心组召开扩大会议深入学习党的十九届四中全会精神

11月28日，学校党委中心组召开扩大会议，深入学习党的十九届四中全会精神，开展警示教育。学校党委委员、校领导、各单位负责人、二级党组织书记参加了会议。会议由党委书记章德胜主持。

马克思主义学院直属支部书记史雍真作了党的十九届四中全会精神宣讲。全面介绍了党的十九届四中全会，阐述了其重大意义。她通过三个“一”、13个显著优势、13个“坚持和完善”、落实四件大事等关键词，带领大家深刻领悟《中共中央关于坚持和完善中国特色社会主义制度、推进国家治理体系和治理能力现代化若干重大问题的决定》的重要精神，并积极贯彻十九届四中全会的重大战略部署。

章德胜书记对学校深入学习贯彻党的十九届四中全会精神宣讲活动作了工作部署。他指出，全体党员干部要充分认识学习贯彻全会精神的重要意义，将学习全会精神融入“不忘初心、牢记使命”主题教育工作中，深入学习领会《决定》的内涵，掌握核心要义和内在要求，进一步坚定中国特色社会主义“道路自信、理论自信、制度自信和文化自信”。他强调，要切实把学习宣传贯彻党的十九届四中全会精神作为当前和今后一段时期的首要政治任务，做好宣讲工作，把全会精神传达到每一个基层党组织、每一名党员干部，确保实现全覆盖，在全校迅速兴起学习宣传贯彻热潮，确保全会精神落到实处、取得实效。党员领导干部要身体力行率先垂范，带头学习领会贯彻落实。各基层党组织要以主题党日、“三会一课”等形式，组织党员集中学习讨论交流，确保广大党员、干部全面准确掌握全会精神。

为进一步加强我校二级单位决策水平，规范二级党组织委员会会议及二级单位党政联席会议制度，会议还进行了关于落实会议制度的专题培训。章德胜书记就我校《二级党组织委员会会议议事规则》《二级教学单位党政联席会议议事规则》中的原则和要求，进行了讲解和说明。他强调各单位领导干部要注意会议的程序性和纪律性，发挥民主集中制原则，提升单位的科学决策水平。二级党组织会议要认真落实“第一议题”制度，突出抓好党的政治建设。

会上，章德胜书记还通报了近期意识形态工作会议的重要精神，就当前特别防护期的安全维稳工作进行了部署。

会议还开展了警示教育，观看了《叩问初心》警示教育片。要求各二级单位结合主题教育专题民主生活会和组织生活会进行对照检查，认真开展批评和自我批评，确保主题教育取得明显成效。
