# 我院一个班、两名同学获省级殊荣

近日，广东省教育厅、共青团广东省委员会联合发文，表彰全省普通高校三好学生、优秀学生干部和先进班集体，我院一个班、两名同学榜上有名：管理系05级人力资源管理本科1班获广东省普通高等学校先进班集体荣誉称号，文学与艺术系宋蜜蜜同学获广东省普通高等学校优秀学生干部荣誉称号，计算机与信息科学系邓锦溏同学获广东省普通高等学校三好学生荣誉称号。
