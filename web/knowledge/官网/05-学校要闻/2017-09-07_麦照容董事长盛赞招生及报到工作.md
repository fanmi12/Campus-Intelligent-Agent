# 麦照容董事长盛赞招生及报到工作

9月7日，我院录取的2017级5139名新生入学报到。早上8时，迎新工作渐入高潮，综合馆人头攒动，各单位报到点呈现出一派忙碌的景象。

上午10时，东莞理工学院城市学院董事长麦照容先生亲临报到现场，全体院领导和广东鸿发教育文化集团有限公司总经理陈超群也一同看望前来报到的新生及家长，慰问参与迎新工作的师生。

麦照容董事长来到各个报到点，与工作人员握手攀谈，询问新生报到及系部的建设情况，并合影留念。在管理系报到点，麦照容董事长握住来自祖国宝岛台湾、刚入职学院的沈圣伦博士的手，亲切询问其生活、工作情况，鼓励他安心工作。他说，大陆的经济发展将为每个人才提供广阔的发展空间。在与同样来自台湾的院长助理林江龙教授的交谈中，麦照容董事长希望他把台湾先进的教育教学经验带到学院，促进城院发展，促进与台湾地区高校的学习交流。

麦照容董事长还听取了财经系主任罗卫国教授对招生、迎新工作的汇报，对财经系举办ACCA(国际注册会计班)创新班给予了高度赞赏。

在迎新工作座谈中，麦照容董事长对今年招生工作和迎新工作给予了充分肯定。他表示，今年将继续加大对学院建设的投入，广东鸿发教育文化集团有限公司也要继续加大支持力度，努力实现打造“百年名校”的目标。同时，麦照容董事长还指出，要充分发挥校友会的作用，加强新闻宣传和校园文化建设等工作，多请名人、大师作客“城院大讲堂”，加强对学生的引导和教育，帮助他们树立正确的人生观、世界观和价值观，多渠道、多举措宣传学院的良好形象，提升城市学院的知名度和美誉度。
