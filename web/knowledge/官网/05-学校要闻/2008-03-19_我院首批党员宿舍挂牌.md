# 我院首批党员宿舍挂牌

3月18日，学院在学生党员活动室前坪举行学生党员宿舍挂牌仪式。学院党委副书记朱冰，党委委员、学院办公室主任王玉，团委书记丘永辉，各系部党总支副书记和220名学生党员代表参加了仪式。仪式由王玉主任主持。

仪式上，朱冰副书记对此次挂牌的党员宿舍的同学提出了两点希望：第一，学生党员们要严格自律，成为学习和生活上的标兵，真正做到“一名党员一面旗帜”，为构建和谐校园和服务东莞地方经济作出贡献；第二，小小的“牌匾”既光荣，又象征着一份责任与义务，希望党员同学们要变压力为动力，积极树立党员意识，时时处处起模范表率作用，为同学们营造一个健康和谐的良好氛围。

学生党员代表颜细照在发言中表示，这次挂牌，通过明示党员身份，树立党员的良好形象，接受同学们的监督，我们一定会不负党组织的希望，认真学习、努力工作，提高自己的政治思想觉悟，内强素质，外树形象，做一名合格的共产党员。

随后，朱冰副书记亲自为部分宿舍挂牌。她亲切地对党员同学说：“你们一定要发挥先锋模范作用，把‘党员宿舍’的招牌打响打好，成为大家学习的榜样。”

据悉，这是我院首次给学生党员宿舍挂牌，本次共有160间宿舍授牌。
