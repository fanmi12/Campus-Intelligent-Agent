# 党委书记朱志德到艺术系视察工作

9月23日，院党委书记朱志德副研究员莅临艺术系视察指导工作。艺术系主任向智星教授、总支书记丘永辉向朱书记汇报了开学以来的教学和学生工作。

朱书记在听完汇报后指出，艺术系作为新开办的系，要克服各种困难，迎难而上；在培养方法上，要针对艺术系学生的特点，重点加强教育教学和学生管理工作；继续发挥高雅艺术在学院的方向标作用，为培养全体大学生的艺术鉴赏能力做出贡献。
