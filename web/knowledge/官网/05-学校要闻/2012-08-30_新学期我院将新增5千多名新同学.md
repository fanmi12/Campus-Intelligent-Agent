# 新学期我院将新增5千多名新同学

据党委副书记章德胜在学院暑期中层干部（扩大）工作会议上通报，我院今年秋季招生共录取新生5312人，超计划完成招生任务。新生报到后，在校学生总数将达到1.3万人。

据通报，广东省考试院新政策规定，从今年开始城市学院不再招收专科生。根据这一规定，为满足广大考生上大学的愿望，我院在总结往年招生工作经验的基础上，采取了“省内不分区域招生”的办法展开招生录取工作。招生结果表明，计划招生5300人，实际录取5312人（含本科插班生345人）。其中，莞籍生源仍占我院生源的大头。更为可喜的是，珠海、深圳、广州 、汕头的生源大幅增长。理科考生最高分为535分，文科考生最高分为546分，其中有22名考生的分数上了2A录取线。补录的分数线也大大高于省线。从考生报读的专业来看，会计学（国际会计）、机械设计制造及其自动化（设计制造方向、机械自动化方向）、英语（商务方向）、金融学、工商管理等仍是我院的热门专业，计划完成率分别达到400%至159%以上。艺术类专业受广东考生的热捧，在粤的招生也超额完成计划，并首次出现高于合格线录取的喜人景象。

据悉，新生入学通知书已于8月14日发出。尚未收到入学通知书的考生，请速与城市学院招生办联系（0769-230663373）。管理系、政法系、计算机与信息科学系、机电工程系、城市与环境科学系、艺术系、文学与传媒系的新生报到时间是9月15日，财经系、金融与贸易系的新生报到时间是9月16日上午。
