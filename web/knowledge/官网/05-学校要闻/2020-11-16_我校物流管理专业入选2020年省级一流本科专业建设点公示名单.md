# 我校物流管理专业入选2020年省级一流本科专业建设点公示名单

根据《广东省教育厅关于实施一流本科专业建设计划的通知》和《广东省教育厅关于开展2020年一流本科专业建设点遴选工作的通知》，经学校申报、专家评审等程序，广东省310个普通本科专业被推荐为2020年省级一流本科专业建设点，并予以公示。我校物流管理专业成功入选此名单。

物流管理专业是我校商学院设置专业，面向文理科招生，授予管理学学士学位。专业与虎门港集团、顺丰速运、巡航集团等多家大中型物流企业建立了实习基地，并在科研方面开展了多项产学研项目的开发与合作。同时，校内实践环节除了课堂实践教学、企业调研分析与讨论外，建立了大型物流综合实验室。该实验室于2014年被东莞市科技局列为“东莞市重点实验室”，配备了多套先进的3D物流实训软件。
