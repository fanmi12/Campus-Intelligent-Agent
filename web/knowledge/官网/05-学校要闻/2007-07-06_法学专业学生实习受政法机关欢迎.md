# 法学专业学生实习受政法机关欢迎

根据教学计划安排，社科系法学班学生从6月24日开始，分别到东莞市中级人民法院、东莞市司法局、东莞市国土资源局和各镇区行政机关进行专业实习，时间为30天。

本次实习学生受到用人单位的好评。东莞市司法局负责人表示，东莞理工学院城市学院实习学生工作热情，积极上进，敢问敢学，服从分配，虚心好学，吃苦耐劳，配合所在部门开展工作，是一支优秀的实习队伍。
