# 财经系召开结合教学服务东莞动员会

5月8日，财经系在5201召开全系教职工会议。会议的主题是转变工作作风，提高教学水平，动员教职工结合教学服务东莞。会议由系主任高香林教授主持。

高主任在会上指出，目前我系教学秩序正常，工作运行状况良好，老师敬业精神强。但也存在一些问题，比如个别老师上课不认真，不负责，临时改教案；有的工作人员工作不积极，不主动，缺乏创新精神；工作讲条件，讲待遇，有畏难情绪；抓工作不落实，浮于表面；对学生缺乏热情等。希望全系教师认真排查整改，不断转变工作作风。

他最后强调，财经系服务东莞主要体现在两个方面：一是对东莞民营企业提供财务服务，二是对东莞经济发展的现状进行研究，争取在这两个方面出成绩、出成果。
