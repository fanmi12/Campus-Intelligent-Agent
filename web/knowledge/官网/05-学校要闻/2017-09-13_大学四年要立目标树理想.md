# 大学四年要立目标树理想

9月11日晚，院长、书记王卫平在综合馆以“怎样度过这美好的四年”为题，为2017级新生作了大学第一堂讲座。

王卫平院长从大学的历史，引出“大学即博学，大学要有大楼，大学要有大师，大学要有大气，大学一定大成”的内涵。通过对我院的发展历程和办学成果的介绍，王院长希望大家树立“城院是我家”、“终生城院人”的观念，牢记“学而知不足”的校训，以社会主义核心价值观为引导，做到爱国爱家爱校。

大学生活已经拉开序幕，如何愉快地度过美好的四年？王卫平院长给出了建议：在大学里，要认真思考自己为什么要读大学，从而树理想、立目标，制定好行动计划；要逐步提炼并选择知识；选择适合自己的良师益友，选择适合自己的良好生活方式，这将有助于自身选择职业、选择未来。

“读万卷书，行万里路。”王院长还向新生分享了自己的阅读爱好。他表示，每天无论工作多么繁忙都会留出一个小时来读书，希望同学们早日养成爱好阅读的习惯！
