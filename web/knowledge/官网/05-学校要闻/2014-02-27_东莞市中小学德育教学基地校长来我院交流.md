# 东莞市中小学德育教学基地校长来我院交流

2月25日，东莞市中小学德育教学基地江校长一行2人，来我院交流学习。副书记章德胜、新闻中心主任何鹏举、学生处思想政治教育科科长陈晓萍热情接待了嘉宾。

双方对学生的德育教育工作进行了深入探讨，江校长对我院的德育教育给予了充分的肯定，并希望我院能提供优秀毕业生去德育教学基地实习。
