# 我们毕业啦！

我院图书信息中心9楼设立的“我们毕业啦”的留言板吸引了许多毕业生前来留念。图书信息中心设立留言板，旨在让毕业生们抒发对我院和图书馆感恩之情和让毕业生有个留念的地方。此活动很受毕业生的欢迎，纷纷前来留言拍照。

记者摘录其中几句，以飨读者：——图书馆是城院里我最喜欢的地方，我永远会记得2011在图书馆的奋斗史。一个靠窗的位置，一个安静的角落，我与图书馆同在。

——因为高考我遇上了城市学院，过去我曾认为大学时光是灰暗的，因为有了图书馆，从此找回了我的快乐，并喜欢上了这里，喜欢这里的每一本书。

——谢谢城院陪伴我度过了三年多的时光，在这里留下了许多的奋斗与汗水。

——图书馆最有归属感。还有一个月多我就要走了，但一定会回来，重温大学时光！

——母校，我永远怀念的地方，承载着所有青春的地方，总有一天，我们会荣归故里，重温校园找寻青春的足迹。

——让所有即将离开校园的你，再一次感受校园的爱与回忆！
