# 我校开展学生社区垃圾定点分类投放试点工作

为全面贯彻落实《东莞市生活垃圾强制分类工作方案》，营造良好的校园环境，引导全校师生做好垃圾分类工作， 11月11日，我校学生社区垃圾定点分类投放试点工作正式启动。

11日上午，我校正式使用绿色的垃圾分类箱。本着方便的原则，学校在每栋学生宿舍楼出入口设置有专门的垃圾定点分类投放点。

开展垃圾定点分类投放工作也是我校开展“不忘初心、牢记使命”主题教育的检视问题和整改问题的重要举措。垃圾分类是一种新的时尚生活方式，需要全体师生的大力支持和积极参与，我校也将继续推进垃圾定点投放工作，不断加强垃圾分类监督力度，营造阳光育人环境，打造文明卫生的校园。

此次由后勤保卫处与学生处联合发起的垃圾分类工作，是我校本学年重点工作之一。从目前试行情况看，同学们都能够自觉将垃圾进行分类投放。
