# 艺术系林伟伦老师获2018年度广东省优秀音乐家称号

3月17日，2018年度广东省优秀音乐家奖、第十届广东省鲁迅文艺奖（音乐类）颁奖典礼在广州市东山宾馆举行。广东省音乐家协会为表彰在音乐工作中获得成就、作出积极贡献的个人和团体，评选出年度“优秀音乐家奖”、“优秀地市音乐家协会奖”。我院艺术系林伟伦老师荣获 “2018年度广东省优秀音乐家奖”称号。
