# 第一届“城院杯”羽毛球团体比赛激战正酣

4月3日下午，由院学生会体育部、羽毛球俱乐部共同举办的第一届“城院杯”羽毛球团体比赛在院内羽毛球场打响了开幕战。第一天登场的是财经系VS管理系、计算机与信息科学系VS文学与艺术系两场重头戏。经过两个多小时的激战，财经系、计算机与信息科学最终都以4：1取得胜利，双双赢得开门红。

据悉，本届“城院杯” 羽毛球团体比赛将历时十天，比赛项目有男子单打、女子单打、男女混合双打、男子双打和女子双打，比赛采用五场三胜制，由院内5个系派出各系羽毛球队进行单循环赛，决出前四名进入第二轮淘汰赛，最终决出冠军得主。
