# 讲席专家王雄文副教授应邀参加东莞市政府的专题调研

调研组全体人员合影，前排右4为王雄文副教授5月28日至31日，东莞市委市政府组织市民政局、市社工委、市委政研室、市财政局等部门就“东莞市社区政务服务中心建设”问题开展了为期4天的专题调研。我院讲席专家王雄文副教授应邀全程参加了调研活动。

调研组深入黄江、厚街、莞城、横沥等4个村级体制改革试点镇（街）共8个村（社区），采取驻点调查、征求意见、专家研讨的方式，重点调查了村（社区）目前承担的行政工作、公共管理任务、考评项目和财政补助项目等内容，广泛征求各村（社区）有关意见和建议。

据悉，此次调研目的是要进一步明晰社区政务服务中心的职责与定位，理顺市、镇（街）、村（社区）三级事权责任和财权分配关系，为今年7月份市政府出台村级体制改革提供依据。
