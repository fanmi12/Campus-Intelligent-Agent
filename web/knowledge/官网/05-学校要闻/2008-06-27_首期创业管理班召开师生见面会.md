# 首期创业管理班召开师生见面会

6月26日，城市学院第一期创业管理班在2202课室召开师生见面会，通过创业管理班资格审查和素质测试共23位同学参加了会议。

会上，管理系主任罗余才教授通报了本期招生、课程开设和创业班管理等情况。

根据教学安排，08－09第一学期创业班将开设《创业管理概论》、《创业与企业家》、《创业机会的发现与识别》、《商务英语》、《商务财务管理》、《商务礼仪》等课程，安排优秀教师担任教学。课程将采用案例教学、研讨式教学、诊所式教学等先进教学方法，并广泛开展实践活动和第二课堂。
