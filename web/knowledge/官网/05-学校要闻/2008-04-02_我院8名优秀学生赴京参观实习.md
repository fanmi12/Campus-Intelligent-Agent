# 我院8名优秀学生赴京参观实习

吴国华处长和聂秀东博士到宾馆看望实习同学

在商务部政策研究室，吴国华处长为学生指导论文写作

国务院国资委徐东华研究员在工业经济管理研究院与同学们合影留念3月27日至4月1日，我院何浩朋等8名优秀学生前往北京商务部和国资委机械工业经济管理研究院参观实习。

在国资委机械工业经济管理研究院期间，同学们受到了城市学院院聘讲座教授聂秀东博士的热情接待和指导，国务院国资委徐东华研究员也接见了同学们，并对同学们的论文写作提出了指导性意见。在商务部行政大楼，商务部政策研究室吴国华处长与同学们就我国目前加工贸易的话题展开了讨论。

据悉，这8名同学分别来自人力资源管理专业和国际经济与贸易专业。今后，他们还将有机会参与商务部政策研究室或国资委机械工业经济管理研究院进行课题研究。
