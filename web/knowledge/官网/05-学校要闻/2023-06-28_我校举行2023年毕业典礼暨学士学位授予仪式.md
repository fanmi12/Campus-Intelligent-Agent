# 我校举行2023年毕业典礼暨学士学位授予仪式

青春六月，骊歌唱响2023届毕业生是极不凡的一届

他们经历疫情，面对多种挑战

在城院留下了成长的足迹

不负热爱，奔赴山海

长风破浪会有时，城院与我共扬帆6月27日，我校2023届毕业典礼暨学士学位授予仪式在综合馆隆重举行。5725名应届毕业生将带着怀揣着学校、老师们的殷切希望和深情嘱托，从城院启航，踏上人生新征程，投身新时代。学校执行董事陈超群，校长陈明，常务副校长方伟华，副校长刘玉侠、周庆、陈葆华、李海冬，相关职能部门负责人及学校学位评定委员会成员出席此次典礼。2023届全体毕业生、校友代表、学生亲友参加了典礼仪式，大家一同见证着5700+毕业生的重要时刻。陈葆华副校长主持毕业典礼。

毕业典礼分为上午和下午两场。上午创意设计学院、艺术学院、法学院、城建与环境学院、数字经济学院、智能制造学院等六个学院举行，下午商学院、人工智能学院和语言文化学院三个学院。

典礼开场暖场环节上，一段毕业生视频，见证了大学四年的时光，也充满了在校领导、师生满满的祝福。方伟华常务副校长向广大毕业生说了一段充满感情的心里话。他回顾了学校四年来与毕业生们的共同成长，感慨万千。他表示，毕业是人生的一个重要节点，也是一个全新的起点。四年前，在场的学子满腔热血，怀揣梦想，带着亲人的嘱托，立志城院求学。今天，学业有成，也将各自奔赴，肩负人生的使命，阔步走向社会，开启未来的梦想！他希望广大毕业生们能够珍惜这段宝贵的校园时光，继续保持学习和进步的态度，迎接未来的挑战和机遇。

随后，各毕业方阵在辅导员带领下，呼喊着“艺文艺舞，德艺双馨”“学聚城院，商赢未来”“扬帆起航，语你同行”...此起彼伏，在综合馆上空回荡。一段篮球秀和街舞秀，让毕业典礼的气氛瞬间点燃。各学院毕业学生带来了歌曲串烧《如愿》《最美的太阳》《凤凰花开的路口》，城院学子动人的歌声，唱出了毕业分离的不舍，更是唱出了对未来的展望。

随后在艺术学院100多名学生在艺术学院院长张征教授引领下，与台下师生进行了大合唱《二十年后再相会》和《老师，我总是想起你》，歌声配以舞蹈和情景表演，融入歌声中。动人的旋律，难舍的情怀，扬着嘴角任泪水在眼眶打转。此次离去不是终点，而是开启新的旅程。

典礼在高昂的国歌声中拉开序幕，全体师生庄严肃立，高唱中华人民共和国国歌。

学校校长陈明向毕业生代表颁发了毕业证书。

学校常务副校长方伟华宣读了优秀毕业生表彰决定。根据学校优秀毕业生评审条件，经各学院评选推荐，教务处和学生处审核，学校研究决定授予李国龙等255位同学2023届优秀毕业生荣誉称号。

陈超群执行董事为优秀毕业生颁发证书。

学校副校长、党委副书记刘玉侠宣读了“立志奖”表彰决定。2023年，刘力献等99名应届毕业生，他们不断追求进步，考上了境内外知名高校的硕士研究生，为鼓励广大城院学子向他们学习，授予了“立志奖”。

周庆副校长、李海冬副校长为“立志奖”学生获得者代表颁发了荣誉证书。

数字经济学院优秀毕业生代表方俊棠、人工智能学院优秀毕业生代表林卓煌在毕业典礼中发言，他们回顾大学四年成长的点滴，在国省市各项大赛中屡获佳绩，他们同时感谢学校和老师们对他们的指导和支持，让他们在学术和实践上都取得了不俗的成绩。他们表示，即将踏上新的人生征程，他们会继续努力学习，不断提升自己的能力，为社会做出更多的贡献。最后，他们祝愿所有毕业生前程似锦，未来可期。

艺术学院优秀校友代表赖欣怡、语言文化学院优秀校友尹嘉蔚在毕业典礼发言中，他们回忆起在校期间的点滴回忆和成长经历，感谢母校为他们提供的优良学习环境和丰富的学术资源。同时，他们也希望学弟学妹们能够珍惜现在的学习机会，锻炼自己的能力和素质，为将来的发展打下坚实的基础。最后，他们再次祝愿城院发展越来越好，祝学弟学妹们前程似锦！

来自法学院教师代表陈程鼓励2023届毕业生在未来的职业生涯中，要不断

学习和探索，创新和拓展，以应对未来的挑战和机遇。她同时提醒毕业生们，要时刻牢记社会责任和使命，用自己的专业知识和技能，为社会和人民服务。最后，他祝愿所有毕业生前途似锦，勇攀高峰，实现自己的人生价值和梦想。

语言文化学院教师代表舒俊婷在毕业典礼上发表了简短而温馨的祝福。她表示，毕业是一个人生的重要转折点，意味着告别校园，迎接未来的挑战和机遇。她希望所有毕业生能够顺利地走出校门，踏上新的人生征程，刻苦努力，勇于拼搏。在工作和生活中，要保持积极向上的心态，勇于迎接挑战，不断学习和提高自己的能力。最后，她再次祝愿所有毕业生前程似锦，生活幸福，实现自己的理想。

学校校长陈明发表致辞。他代表学校向全体毕业生表示热烈的祝贺和祝福，向勤勉奉献的老师们、向关心学生成长、支持学校发展的家长亲友和社会各界朋友表示感谢！

陈明校长与同学们共同回顾了2023届毕业生的“防疫抗疫”时光，他为城院人迎难而上、坚守岗位，用无私和奉献构筑起守护校园的铜墙铁壁，广大学子争当防疫志愿者，用责任与担当为青春抹上一层绚丽的色彩而骄傲。他表示，在全体师生共同努力下，我校获批国家级一流本科专业建设点1个，省一流本科专业8个，6个专业获批省级特色专业，2个学科获批省级重点培育学科，多门课程获批省一流课程。学校基层党组织更加坚实有力，1个党支部获评为国家级“双创”样板支部，2个党总支荣获省级“双创”标杆院系称号，1个教师党支部获评省级“双带头人”教师党支部书记工作室。他寄语广大毕业生，要以正确的世界观、人生观、价值观来指导自己的选择，要做一名终身学习者，要发扬“厚德务实、知行合一”的校训精神，坚定地做务实派、行动派、建设派，要有敢于攻坚克难的精神，要常怀感恩之心。他希望广大毕业生常回来看看！

随后，举行了学士学位授予仪式。学校学士学位评定委员会办公室主任、科研部部长杨勇虎宣读了学位授予决定。经学校学位评定委员会审议，决定授予5365名普通高等教育本科毕业生学士学位，其中法学学士学位422名，工学学士学位1633名，管理学学士学位1138名，经济学学士学位563名，理学学士学位90名。文学学士学位1152人，艺术学学士学位367名。

在学士学位授予仪式环节中，学士学位评定委员会委员为到场的每一位毕业生拨穗正冠、颁发学士学位证书。

毕业学生依次上台、拨穗礼成、颁发证书、合影留念，一系列动作不过十秒，但却为大学生涯画上句号。

仪式上，毕业生们纷纷与学士学位评定委员互动留影，做出拥抱、花式比心、剪刀手、竖大拇指等动作，大家纷纷拍照留念，记录下这一珍贵的时刻。

仪式结束后，全体学士学位评定委员会委员起立，目送2023届毕业生出发。
