# 我院视频新闻试开通运行

为进一步加强新闻宣传报道工作，提高新闻的可视性，学院于近日试开通了视频新闻。到目前为止，已播出八条视频新闻。

视频新闻由城市学院影视制作中心制作。读者可登陆学院视频新闻网（网址：/newscenter/cymt/）进行浏览，或在学院新闻网主页中点击链接“城院媒体”也可以进入。

视频新闻将聚集校园动态，及时报道校园新闻事件。
