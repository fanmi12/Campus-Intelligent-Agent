# 东莞理工学院城市学院模特队捧回一摞奖牌

3月5日,东莞市南城步行街举行了一场精彩的模特才艺大赛，参加总决赛的16名选手中有9名选手是城市学院的模特队学生。

此次比赛分两个环节进行，3月5日是时装表演,3月26日模特才艺展示。在这两个环节中，城市学院模特队同学技压群芳,向观众呈现了她们青春、智慧的一面，并以自己独特的风格展现了大学生的自我风采。

经评选，城市学院模特队队长箫洁莹获得二等奖,廖文美、麦笑梅等9名同学分别获得优秀模特奖和十佳模特奖。
