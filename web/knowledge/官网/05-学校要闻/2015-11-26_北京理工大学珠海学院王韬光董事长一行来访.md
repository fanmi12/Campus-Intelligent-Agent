# 北京理工大学珠海学院王韬光董事长一行来访

11月26日上午， 北京理工大学珠海学院王韬光董事长携赵显利院长、庞思勤书记等一行11人莅临我院进行交流访问。麦照容董事长、黎建烨董事和王卫平书记等院领导热情接待了客人。

宾主双方在行政楼212会议室举行座谈，就教师队伍建设、应用型人才培养、教学科研及独立学院未来发展思路等方面进行了深入交流探讨。

王韬光董事长一行还就校园建设进行了实地考察。
