# 提升核心竞争力，掌握招生工作主动权

“三个突破”、“首次”、“两降两升”、成为我院近日召开的招生工作总结会议上出现频率最高的“热词”。11月5日，我院在行政楼212会议室召开2014年招生工作总结会议。会上，招生办负责人孔增强副处长在会上介绍了我院2014年招生工作的总体情况、工作特点，展望了来年招生面临的新形势及将会出现的新情况，提出了应对的措施。

院领导杨敏林、王卫平、张林、陈丁堂、章德胜、高香林出席会议，机关各处室负责人、各系系主任及党总支负责人参加了会议。

据孔增强副处长介绍，2014年我院招生工作实现三个突破：实际招收新生首次突破5100人；报到率首次超95%，位居广东省同类院校前列；生源质量上新台阶，省内普通类全部是线上第一志愿录取。本科插班生报名、录取“双创新高”，各专业之间包括新增设的专业生源出现冷热不均的现象，省内市外生源比例扩大，市内生源首次跌破2000人。

杨敏林院长在会上作了重要讲话。他首先充分肯定了今年我院招生工作所取得的骄人成绩、工作思路及其招生举措。他说，其中一些亮点工作和作法值得巩固和延续，出现的新情况要引起在座各位领导的高度关注与破解。2011年、2012年，我院招生规模连年翻番，这是学院发展史上一个里程碑式的标志。来之不易的招生形势，得益于办学实力与核心竞争力的增强，得益于社会各界及学生家长对我院办学成果与教育教学质量的认可。

杨院长对做好2015年的招生工作做了强调，他希望全院教职工要通力合作，尽早谋划准备，明确工作重点，瞄准市场需求，提升核心竞争力，保持良好的招生工作势头。我们要认清招生工作面临的新形势新情况，增强忧患意识。我们应该清醒地看到，目前全国有一批高校正在转型发展，谋求新的发展空间，生源之战将更加激烈；一批高校扩权自主招生改在统考之后进行，艺考改革新政即将出台，中学不分文理科；当今考生不仅看重办学母体、学校所处地理环境，更看重办学品牌和办学的软硬条件。根据这些新情况，我们要全力应对，逆势而上。

会上，与会人员就明年的招生工作发表了意见与建议。
