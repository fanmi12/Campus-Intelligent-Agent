# 庆三八，献爱心，筹善款

三•八”善款美食系列活动是我院一年一度的文化活动的重头戏，旨在“庆三•八、筹善款、 献爱心”，希望通过这一活动筹到更多的款项，捐献给爱心基金会。

3月5日我院在莞城校区校道上举行盛况空前的——第一届“三八”善款美食嘉年华。在欢歌笑语中，我院党委副书记朱冰同志宣布开始。

我院文学与艺术系、计信系、机电系、财经系、管理系以及32个社团中幸运抽到摊位的5个社团在校园内各张旗鼓，各种海报风起潮涌，校道上可谓是人山人海，喜气融融。谁说天公不作美，今天是有柔和的风又有缠绵的雨，都说“风是爱的呼唤，雨是情的交融”，风雨更增了不少风情。你唱我和，琳琳琅目的食物，让人想说不爱你都不行！特别是文学与艺术系的“滋润的季节”--绿色食品，清凉美容；财经系的“花果年华”—创新食品，美味可口；一切从健康出发，同时还增强了同学们的环保和创新意识。

活动一直持续到晚上9点30分。同学们一个个兴高采烈地说此次活动真是让他们收益匪浅，在品尝到美味小食的同时，又可为贫困地区的人们募捐，大家都乐在其中。不仅学到了营销的方法--薄利多销，更重要的是学会了如何尊重人、如何让自己的人生变得更加有意义……
