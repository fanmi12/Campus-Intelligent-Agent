# 我院教师参加东莞市发改局课题评审

4月28日，我院米双红教授、张佺举教授和龙卫洋博士受东莞市发改局委托，对《东莞市服务业十二五发展规划》的课题进行评审。

据悉，参加本次评审专家组共有7人，其余4人分别来自华南师大、暨南大学和东莞理工学院。

《东莞市服务业十二五发展规划》的内容涵盖了金融、物流、社保、职业教育、文化旅游、演艺娱乐、社区服务等方面。
