# 城市学院赈灾募捐倡议书

亲爱的老师们、同学们：2008年5月12日下午14时28分，四川省汶川县发生7.8级地震，四川省及周边地区都受到很大影响。这场突如其来的自然灾害，给灾区群众造成了巨大的经济损失和精神创伤，夺走了1万多条鲜活的生命。灾区人民正面临着缺电少水、供应短缺、交通阻塞、通讯不畅、居无定所等严重困难。地震发生之后，胡锦涛总书记立即作出重要指示，要求尽快抢救伤员，关怀灾区人民的生命安全。温家宝总理亲赴灾区，现场指挥救灾工作。与此同时，全国各地迅速掀起了赈灾捐款高潮。

中共东莞理工学院城市学院委员会、东莞理工学院城市学院工会、共青团东莞理工学院城市学院委员会、东莞理工学院城市学院学生会特向广大师生员工倡议：让我们为逝者默哀安息，为伤者祈祷平安，向家在灾区的师生及家人表示深切慰问；伸出我们的双手，献出我们的爱心，用每个人力所能及的付出，汇成爱的洪流；用我们共同的力量，为缓解灾区人民困境、帮助灾区人民重建家园贡献微薄之力。

为了便于老师和学生向灾区捐款，院工会、院团委决定于5月14日14：30—18：00、5月15日9：30—18：00为捐款时间，并在四号楼大厅设置捐款箱，捐款时间至5月16日。工会将把所有的捐款通过中国红十字会总会发放给灾区人民。捐款咨询电话：22639421。

广大老师、同学也可以自行联系中国红十字会总会（www.redcross.org.cn）了解捐款事宜。
