# 邓浩宏：把城院男篮精神发扬光大

邓浩宏，我校男篮队长，大前锋，球队核心。一身10号球衣，一个篮球梦想，一腔青春热血，一次次投篮入筐，一声声欢呼呐喊，邓浩宏在赛场不断为自己大学篮球生涯画上浓重的一笔。

作为学校男篮队长，在本届东莞大学生篮球联赛中，邓浩宏展示了一个极强的领袖气质和得分能力，带领男篮以小组赛六连胜的辉煌战绩进入半决赛。

与球结缘，逐青春热血校园韶华

懵懂少年，与篮球结缘。邓浩宏告诉记者：“因为父亲非常喜欢打篮球，在我小时候，他就极力培养我在这方面的兴趣。也是从那个时候，篮球成了我最喜爱的运动。”

热血新生，在校队逐篮球梦。大一时，邓浩宏在师兄引荐的契机下，加入校篮球队，开始了系统地训练。与篮球朝夕相处中，篮球—早已成为他生活中不可或缺的一部分。

在学校男篮四年的篮球经历里，邓浩宏坦言：“虽然会有疲倦期，但及时调整，用积极的心态去面对挑战。”比起身体上的累，邓浩宏更享受与队员们在赛场上逐梦的过程，哪怕再累，他都从未想过放弃。从大三开始担任校队男篮队长，邓浩宏更清楚自己肩上的责任。在球队正面临“新老交替”的阶段，团队的磨合和配合度有待提高的情况下,他以极强的领队能力带领男篮逐梦第四届大联赛，并一举打出小组赛六连胜的辉煌战绩。

坚持不懈，用汗水浇灌篮球成长

传球、转身、跳跃、扣篮，一气呵成，邓浩宏潇洒流利的动作让场下的观众欢呼声掌声持续不断。然而邓浩宏刚进学校篮球队时，由于没有接受过系统的训练,高强度的训练使他一下子难以适应。

世上哪有什么天赋异禀，不过是日复一日的努力罢了。邓浩宏回忆起自己初入校队时的经历，“虽然训练很累，但是咬咬牙就坚持过来了。”三年来，他用自己的行动诠释了这种坚持不懈的城院男篮精神。“有付出，才有收获”，简单的一语道出了邓浩宏对于篮球运动的态度。

从饮食作息上注重规律，在思想上动员自己，身体上磨练自己。不打无准备的仗，无论比赛大小，邓浩宏都会做好充足的准备。赛后，他还会根据技术统计和录像找出自己的不足，并及时调整，以期在下一场比赛中发挥出更好的效果。不久前在对阵东莞理工学院队时，他奋力救球不慎受伤，处理完伤口休息片刻，他又重返赛场。“我们球队一直都有一种拼搏的精神——轻伤不下火线。况且当时比分正处于胶着状态，我没有顾虑太多，只想为这个团队贡献一份力量，给予队友一份鼓励。”

前路坦荡，成长“不止于篮球”

加入校篮球队这四年里，邓浩宏不仅收获了更多的篮球技巧，还结识了一群志同道合的伙伴，懂得了如何为人处世。作为队长，更是学到了管理好团队的丰富经验。他始终相信，凝聚力才是团队的核心所在。一个“领头人”也是团队里不可或缺的部分，这两者的结合才能让一个团队走得更远。

流光易逝。如今他已进入大四阶段，面对日常的篮球训练与繁重的学业，他能有条不紊地分配时间，篮球学业两不误。

对于未来和个人，他内心有着明确的方向和清晰的规划。

对于学校男篮，他希望在未来，新鲜血液涌入球队里，能够继续发扬城院篮球队的精神，带领球队取得辉煌……
