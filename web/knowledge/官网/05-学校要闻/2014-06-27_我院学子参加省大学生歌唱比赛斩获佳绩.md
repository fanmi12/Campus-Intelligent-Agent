# 我院学子参加省大学生歌唱比赛斩获佳绩

近日，我院从广东省教育厅获悉，大学生艺术团“Weirdo”阿卡贝拉清唱团在“2014年广东高校‘唱响中国梦、百歌颂中华’歌咏活动”中表现优秀、发挥出色，荣获大赛“一等奖”；艺术系黄家伦同学的个人独唱荣获大赛“二等奖”。

此次获奖，让我院学子深受鼓舞，同时也是对我院开展艺术工作水平给予的充分的肯定和鼓励。

参赛信息：一等奖：“阿卡贝拉”清唱团参赛曲目：《北京的金山上》；成员：林思炜、鲁志垚、陈黛蓝、何绮雯、刘嘉明；指导老师：张宏渝。

二等奖：黄家伦参赛曲目：《祖国慈祥的母亲》；指导老师：关丽颖。
