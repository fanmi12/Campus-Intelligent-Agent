# 我院赴武汉“招硕引博”

12月15日，学院组织人事处陆枫、李柱坚、孙福群一行三人赴武汉参加由湖北高校就业指导中心举行的“全国知名企业湖北‘985’‘211’院校联合招聘会” ,引进“三高”（高职称、高学历、高素质）人才。

我院工作人员向求职人才分发了宣传册，介绍了学院的基本情况及2013年的人员招聘信息、介绍了东莞市和学院人才引进政策。同时，我院工作人员还对前来应聘的硕士、博士应届毕业生在职业生涯规划、发展平台选择优势等方面做了进一步的宣传，进行了面对面的交流。

许多求职人员对我院表现出了浓厚的兴趣，期待能到东莞创业发展。此次招聘会共收到博士、硕士求职简历200余份，拉开了我院2013年“招硕引博”工作序幕。
