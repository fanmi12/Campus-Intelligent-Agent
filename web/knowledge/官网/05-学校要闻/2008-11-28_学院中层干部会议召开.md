# 学院中层干部会议召开

11月27日，学院在315会议室召开中层干部会议，传达贯彻广东省教育厅关于加强反腐倡廉建设工作会议精神，安排部署学院近期的反腐倡廉、校园安全、毕业生就业指导工作。

会上，人事处处长夏勇传达了省教育厅反腐倡廉工作会议精神。他说，省厅会议要求，全省各高校要把反腐倡廉工作纳入到学校的全局工作之中，把改革的推动力、教育的说明力、制度的约束力、监督的制约力、惩治的威慑力，融入到反腐倡廉建设工作之中。要旗帜鲜明地支持改革者，鼓励创业者，宽容失误者，开导保守者，追究诬告者，严惩腐败者。

党委书记朱志德主持会议并就校园安全工作作了重要讲话。他指出，最近校园内发生了几起盗窃事件，学生宿舍也存在违规使用大功率电器等安全隐患。各级领导必须对此高度重视，采取有力措施，确保校园安全。为此，学院要求：一、近期要拉网式地排查安全隐患；二、制定安全措施，落实责任人，保卫办、总务处要更多地承担安全、消防等方面的工作责任。发现隐患要及时上报，并加以排除。三、教职工和学生都要学习掌握消防、灭火、逃生自救的知识和技能。

东莞理工学院副校长、城市学院院长安少华，对以下四个方面的工作做了安排部署。一、关于反腐倡廉工作。安院长说，反腐倡廉，我们要警钟长鸣。机关干部特别是领导干部，要廉洁自律，以身作则。要制定和完善有关制度，用制度管人管事，用好手中的权力。要堂堂正正做人，干干净净做事，努力营造一个让干事的人不吃亏、人人争着干事的良好氛围。二、关于安全工作。安全无小事。要创新安全工作的思路，树立群防群治的思想，协助周边地区建立现代文明社区，与社区共同建立防范网络。安全工作要从小事、细节抓起，把事故苗头消除在萌芽状态。有关职能部门特别是保卫、总务，要定期开展安全检查，发现一处处理一起，不留隐患。三、关于“和谐”工作。和谐则兴，团结合作是事业成败的关键因素。领导与领导之间，上下级之间、新老教师之间、师生之间的关系都要和谐，合作共事。各级领导要以自身魅力、以及学识去影响和感染自己的下属，从而形成一个优秀的团队。四、关于毕业生就业指导工作。毕业生就业质量，决定一个学校的成效。就业好，说明办学就成功了。我们要举全校之力，抓好就业指导工作。就业是一项系统工程，需要全校各部门协同配合，齐抓共管。近期要组织一批有资质、有影响的企业参加校园招聘会。就业指导人员要开拓视野，转变观念，深入企业，了解人才需求信息。

继续开展十大工作创新奖、“教工校园十佳”评选活动，进一步落实“问责制”。
