# 第十九届校园十大歌手诞生

5月15日晚，东莞城市学院第十九届校园十大歌手决赛，在学校综合馆隆重上演！

本次十大歌手比赛以“音浪潮头，青春领航”为主题，唱响了城院的声音，唱响了城院人的力量。出席本次十大歌手比赛的有：东莞市流行音乐协会主席、东莞青年艺术家、广东省十佳歌手纪国维，校长李振华，副校长康贤刚，党委办公室主任叶凯贞，学生部部长、党委学生工作部部长林蓉，学校办公室副主任（主持工作）冯江博，品牌与招生部副部长（主持工作）叶云峰，学生部副部长、后勤保卫部副部长刘智航，校团委书记、学生部副部长范琪，各二级学院党总支书记、副书记，学生代表等参与。

由大学生艺术团炫舞团的开场舞蹈，《玫瑰新章》，拉开了本场十大歌手决赛的帷幕。

灯影变幻 流光溢彩，我们一同沉醉音乐世界，随着音乐节奏挥舞起双手，一同见证音乐的力量，感受青春的澎湃活力，掌声如浪 欢呼不断。

欣赏完精彩演出后，接下来就到了，今晚最激动人心的时刻，十大歌手颁奖时刻！

东莞城市学院副校长康贤刚为季军陈思燃颁奖

东莞城市学院校长李振华为亚军陈彦彤颁奖

东莞市流行音乐协会主席纪国维为冠军彭博桢颁奖

夏夜滚烫 乐动青春，梦想之声 高昂嘹亮，城院人唱出自己的精彩，未来舞台必将更加辽阔，未来的我们一定唱得响亮！
