# 我院举行现场书画及工艺创作大赛

广东省书法协会副主席、广州美术协会主席周国城现场挥毫。

书画家现场为同学们做创作指导

创作现场

部分作品

“和谐城院，牵手亚运”。 5月27日，我院在四号大厅举行了2010年城市学院现场书画及工艺品创作大赛。中国书画艺术交流协会主席顾冠群，广东省书法协会副主席、广州美术协会主席周国城，中艺美术馆馆长、广州美术协会理事赵应伦及香港书法家协会、东莞市书法家协会等书画家莅临现场为师生做创作指导。

本次比赛分为自由创作、工艺品、绘画、硬笔书法和软笔书法五大项目，200多位参赛者同台竞技，场面异常壮观。在工艺品创作区，记者发现，本次工艺品创作题材多以迎亚运为主题，以广州城五羊标志、亚运会吉祥物、运动场为创作元素，作品形象生动，工艺精湛，反映了我院学生对手工技艺的热爱及对亚运会的关注与支持。世博会上的“中国馆”及“我的城院”等工艺品吸引了现场观众的眼球。书法区更是热闹非凡，同学们的草书、行书、楷书及隶书的毛笔书法博得嘉宾的称赞。嘉宾们还为参赛选手做现场指导，指出作品创作中应注意的地方。广州美术协会主席周国城现场挥毫，写下条幅“翰墨飘香，书写春秋”，现场师生赞叹不已。

比赛历经4个小时，主办方将组织专家老师对参赛作品进行评比，并在校内展出。
