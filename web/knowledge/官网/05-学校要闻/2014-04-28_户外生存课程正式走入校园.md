# 户外生存课程正式走入校园

4月24日下午，体育教学部联合东莞市登山运动协会开设的初级户外课程正式开班。

据体育教学部主任邢红林教授介绍：高校公共体育课是面向全体大学生,在课程内容和授课模式的选择上,应以满足大多数学生的基本需求为目标。此次户外初级课程是大学生生存能力教育与培养探索，打破传统的体育教学模式,更加注重对人的自然属性的塑造。大学生生存能力培养,把原有的仅限于学校体育课堂的竞技性很强的跑、跳、投、攀爬、跨越等基本内容拓展到社会和大自然中,有利于激发学生的学习原动力、培养学生的学习兴趣、挖掘学生的学习潜能。此课程的开设受到同学们热捧，近百名同学报名，但是因为师资及场地原因只接收了30名学生上课，为此体育部将积极培养该方面的专业老师，拓展资源，以满足学生的需求。
