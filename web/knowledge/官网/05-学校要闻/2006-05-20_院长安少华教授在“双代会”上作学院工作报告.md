# 院长安少华教授在“双代会”上作学院工作报告

5月20日上午，在我院第一届教职工代表大会和工会会员代表大会上，院长安少华教授作了题为《与时俱进，开拓进取，为建设省内一流、追求卓越的本科独立学院而努力奋斗》的工作报告。

报告共分四个部分：第一部分，建院以来的主要工作回顾；第二部分，学院面临的机遇和挑战；第三部分，“十一五”时期学院规划建设和发展的指导思想、目标、思路；第四部分，学院2006年工作重点。

最后，安院长号召全院师生进一步统一思想，坚定信念，充分发挥教代会、工会和共青团、学生会以及各民主党派的作用，转变发展观念，创新发展质量，锐意进取、真抓实干，为实现“十一五”发展目标，建设省内一流、追求卓越的教学型本科独立学院而努力奋斗。
