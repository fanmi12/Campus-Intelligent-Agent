# 讲席专家赵书山应邀为莞城基层党员干部做专题讲座

应莞城街道办、市科学技术协会的邀请，5月29日，我院讲席专家赵书山副教授，为莞城区基层党员干部做了题为《东莞社区管理与服务的组织架构、运行模式及管理创新》的讲座。

赵副教授根据东莞正在开展的村改居和社区综合服务中心建设工作的政策精神，结合厚街、黄江镇社区建设模式以及长富社区、林村社区和新莞人社区建设的实践，比较国内外社区建设的经验教训，既进行社区管理与服务的知识普及，又对社区管理与服务作出创新性探讨，理论与实践结合，深入浅出，生动有趣，产生积极的效果。

来自莞城街道办、东莞市科学技术学会、莞城街道办科协、社区办的领导以及莞城辖区各社区、居委会党员干部200余人聆听报告。报告会结束后，赵书山副教授与社区办和部分居委会主任进行座谈交流。
