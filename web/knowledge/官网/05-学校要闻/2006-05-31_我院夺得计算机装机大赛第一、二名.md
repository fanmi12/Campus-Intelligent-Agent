# 我院夺得计算机装机大赛第一、二名

5月29日下午，“光明杯”三校区联合装机大赛总决赛在城市学院大礼堂隆重举行。

来自广东医学院、东莞理工学院和城市学院三所院校代表队的10支参赛队伍，在城市学院作最后的较量。决赛分两个阶段进行，首先是以最快的装机速度完成计算机的硬件组装，然后再通过计算机知识抢答的形式给予加分。经过激烈的角逐，城市学院代表队B＆G（赵子贤 罗妙岚）两名同学，以3分55秒的最快成绩赢得本次大赛的第一名。第二、三名分别由城市学院代表队“砌砌整整”和广东医学院东莞校区代表队“沙漠飘雪”获得。
