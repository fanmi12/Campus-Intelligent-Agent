# 社区研究中心组织教师赴虎门镇作报告

高考结束了，对即将到来的大学生活，该做何种心理准备？如何规划大学生活？受虎门镇团委的邀请，7月12日在虎门镇政府二楼大会议室，社区研究中心程建新老师就这一主题作了《如何让大学生活更加充实、有意义》的报告。报告会由虎门镇团委盖德泉副书记主持，一百五十多名高中毕业生参加了报告会。

程建新老师从什么是大学、大学生活设计中值得注意的七个问题、大学毕业以后做些什么、对大学的评价和态度四个方面，结合自己的经历，用大量的实例和图片进行了讲解。告诫同学们进入大学后不要放松对自己的要求，要有所作为，珍惜人生中这段最美好的时光。

同学们听完后纷纷表示很受启发，对大学的性质、功能、重要性，以及如何处理通识教育与专业学习的关系、理论与实践的关系，怎样对待大学期间的社会交往、看待社团活动和其他兼职等问题，都有了初步的认识。有的同学表示要充分利用好这个暑假，以饱满的精神状态去迎接人生中的下一个重要的驿站——大学。
