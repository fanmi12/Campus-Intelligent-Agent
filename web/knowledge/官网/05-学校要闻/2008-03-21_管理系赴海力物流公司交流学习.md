# 管理系赴海力物流公司交流学习

3月14日，管理系教师一行11人，在系主任罗余才教授的带领下，前往东莞市海力物流系统设备有限公司参观学习。

双方对企业战略发展、人力资源开发、企业融资等方面进行了详细的交流，并对以后如何加强双方联系、共建校企文化等问题达成了共识。会后，老师们在公司经理的陪同下参观了生产车间。

据悉，东莞海力物流系统设备有限公司是城市学院的实习基地，该公司年产值7000万元，居国内同行领先地位。
