# 智能制造学院举行2019届优秀毕业生作品展暨揭牌仪式

6月4日，智能制造学院2019届优秀毕业生作品展暨揭牌仪式在8号楼一楼大厅举行。校领导王卫平、章徳胜、高香林、周庆、林江龙和有关职能部门负责人、各二级学院院长、书记出席了活动。

据介绍，智能制造学院共有639位应届毕业生，经各教研室组织推荐，此次共展出120件作品，其中机械类作品75件、电信与物联网类作品45件，获得第十五届“挑战杯”广东大学生课外学术科技作品竞赛二等奖、三等奖的四件作品亦在展览之列。

与会领导为智能制造学院进行了揭牌。

智能制造学院院长连元宏表示，今后学院将本着“育生如子、爱校如家”的初心，坚持“负责任、求创新、创特色、树品牌”的办学理念，努力把智能制造学院建设得更美好。

王卫平校长祝贺智能制造学院正式挂牌成立，对原机电系、原电子工程与智能制造学院取得的办学成绩给予了充分的肯定。他希望智能制造学院全体师生不忘初心、锐意进取、砥砺奋进，把智能制造学院建设得越来越好。
