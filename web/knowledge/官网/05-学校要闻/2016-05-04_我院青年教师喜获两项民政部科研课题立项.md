# 我院青年教师喜获两项民政部科研课题立项

4月21日，民政部2016年“中国社会组织建设与管理”理论研究部级课题立项评审结果揭晓，我院管理系黄岳钧副教授申报的“我国社会组织从业人员职称制度的模式选择”项目、黎伟博士申报的“社会组织统计指标体系研究”项目均获准立项。

自2014年来，管理系已连续三年共承担4项民政部科研课题，前两项已顺利结题，其中1项获民政部优秀研究成果奖。2016年，管理系已获得了3项省部级课题立项。

据悉，近年来，管理系加强青年教师的教学科研工作，取得了较大的成绩，“以科研促教学”的氛围正逐渐形成。
