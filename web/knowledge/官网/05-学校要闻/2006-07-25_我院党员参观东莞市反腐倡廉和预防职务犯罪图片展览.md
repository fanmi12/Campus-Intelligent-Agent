# 我院党员参观东莞市反腐倡廉和预防职务犯罪图片展览

7月24日，我院50多名党员干部到东莞市图书馆参观东莞市反腐倡廉和预防职务犯罪图片展览。

这次图片展览是由中共东莞市纪律检查委员会等六家单位联合举办的，其目的是为了进一步贯彻落实党中央《建立健全教育、制度、监督并重的惩治和预防腐败体系实施纲要》，不断加大党风廉政建设和反腐败工作力度，努力减少和遏制职务犯罪的发生。本次展览共分为六个部分。图片展现了不同历史时期、不同阶段党和国家反腐倡廉工作的措施和惩治力度，以及全国各地清正廉洁的典型和贪污腐败的犯罪事例。

通过参观，党员们受到了一次深刻的反腐倡廉教育，表示要树立正确的世界观、人生观、价值观、权力观、利益观和荣辱观，增强廉洁自律意识，做一个思想品德高尚的人。
