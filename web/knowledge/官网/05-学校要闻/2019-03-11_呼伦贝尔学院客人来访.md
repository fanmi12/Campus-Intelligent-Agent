# 呼伦贝尔学院客人来访

3月11日上午，呼伦贝尔学院党委委员、副院长梁秀梅等一行四人莅临我院访问交流。学院党委委员、副院长高香林，教务处处长赵书山、商学院院长罗卫国、计信系主任廉玉忠等热情接待了客人。

高香林副院长陪同客人参观了校史馆，介绍了我院办学、建设与发展等有关情况。双方还举行了座谈，着重就产教融合、校企合作交流等方面进行了经验交流与探讨，并互赠礼物。

梁秀梅副院长一行还参观了校园，并重点考察了我院商科虚拟仿真实践教学中心。
