# 军训报道之四：校友熊勇昭成了师弟师妹的军训教官

“当兵后悔两年，不当兵后悔一辈子，”从城市学院管理系参军入伍、现为沙角部队军训教官的校友熊勇昭感慨地说。2009年11月，人力资源专业的熊勇昭同学向往军旅生活，告别母校走进了军旅。如今，，他又以一名虎门沙角部队的士官的身份重返母校，成了我院二连二排（12级财经系会计学专业）“小女兵”们的军训教官。他对记者说：“我非常留恋校园生活，但也为走进军营而自豪。”

熊教官12岁时曾去新西兰留学两年，后来又考入城市学院，18岁参军。年纪轻轻的他谈到部队生活时笑着说：“军队训练比大学生军训强度大多了，当时我们每天都在40度高温的户外训练，晚上宿舍里的温度不比白天低，也有40多度。10个人的宿舍里，只有一台风扇，每天早上起床，一滴滴的汗水就从席子里流出来。”他告诉我们，多年来的训练，强健了体魄，磨练了意志，也留下了一些“纪念品”。 他右手手臂上有一条如食指般粗的疤痕，说起这块伤疤，他陷入了深深的回忆之中，淡淡地说：“那是一次他在训练新兵时，为了保护战士而被子弹擦伤留下。”熊教官坦言，当时由于自己偏胖，为了不拉部队的后腿，除完成部队规定的训练外，自己还主动要求增加训练时间，每天早晚多跑五公里。

早上六点钟集合，军事训练，摸爬滚打，这样的生活，很多人或许会觉得无聊，但他不以为然，认为军人就是要吃苦，打仗时才不会吃亏。几年来，他一直是这样做的。不久，他被部队提拔为士官，先后受过8次“嘉奖”，每年都获得了“优秀士兵”的称号。他表示退伍后考虑重返校园，争取考硕士研究生。

在谈及对军训学弟学妹的评价时，熊教官骄傲地说：“城院学子，个个都是好样的。”
