# 城院学子助力“苏迪曼杯”万人长跑活动

为迎接第十四届“苏迪曼杯”世界羽毛球混合团体锦标赛，纪念“五四运动”96周年，5月4日上午，东莞团市委、市体育局、市文明办联合在市行政中心广场举行“青春飞扬，‘苏’写精彩”东莞市迎苏迪曼杯长跑活动。市直各单位、中央和省驻莞有关单位、各高校、各街道及社会报名近万人。我院财经系2014级财务管理1、2班全体学生在老师的带领下代表系(部)加入城院方阵，助力本次万人长跑活动。

9时20分，万人长跑队伍震撼开跑。知名人士李永波、李宁、白岩松以及以奥运冠军林丹为首的中国羽毛球队也齐来助阵。作为我院方阵的排头兵，财经学子身穿统一运动服，高喊“东莞‘羽’你共精彩”口号，挥舞着院旗，沿市中心广场一带奋力奔跑，在长跑方阵中形成一道青春靓丽的风景线。
