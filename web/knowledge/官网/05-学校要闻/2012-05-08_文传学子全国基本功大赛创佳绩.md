# 文传学子全国基本功大赛创佳绩

近日，第四届“全国大学生语言文字基本功大赛”传来捷报，我院文传系学子斩获多项殊荣，谢小燕等6名同学获一等奖，王礼珍等10名同学获二等奖，方嘉玲等13名同学获三等奖。李瑶老师被评为优秀指导教师。

第四届“全国大学生语言文字基本功大赛”由教育部语言文字应用管理办公室和国家语委语言文字报刊社共同主办，此次活动2011年6月启动，历时近一年。全国共有300余所高等院校13万名大学生参赛。
