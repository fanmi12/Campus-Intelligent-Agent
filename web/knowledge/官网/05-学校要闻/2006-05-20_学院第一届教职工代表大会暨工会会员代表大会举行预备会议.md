# 学院第一届教职工代表大会暨工会会员代表大会举行预备会议

东莞理工学院城市学院第一届教职工代表大会暨工会会员代表大会于5月19日在五号阶梯教室举行预备会议。出席今天会议的代表共有73人。

学院党委书记朱志德、常务副院长程发良教授、党委副书记朱冰、大会秘书长章德胜和各代表团团长夏勇、高香林、钟兴恭、张林在主席台就座。在主席台就座的还有东莞理工学院工会副主席何献青。

本次会议共进行了8项议程：（一）大会秘书长、学生处处长章德胜副教授代表本次大会筹备工作领导小组向大会作筹备工作报告；（二）学院党委书记朱志德宣读中共东莞理工学院城市学院党委关于召开城市学院第一届教职工代表大会暨工会会员代表大会的请示的批复；（三）东莞理工学院工会副主席何献青宣读东莞理工学院关于召开城市学院第一届教职工代表大会暨工会会员代表大会的请示的批复；（四）听取代表资格的审查报告；（五）审议通过大会表决办法；（六）审议通过大会议程；（七）审议通过各代表团团长、副团长名单；（八）审议通过大会主席团成员建议名单和秘书长、副秘书长建议名单。

大会用举手表决的办法，一致通过了上述有关议程。

城市学院第一届教职工代表大会暨工会会员代表大会将于5月20号上午9时举行开幕式。
