# 财经系召开教职工学习研讨会

3月18日，根据学院关于深入开展“继续解放思想，坚持改革开放，争当实践科学发展观的排头兵”学习讨论活动的通知，财经系召开了专题研讨会。城市学院党委书记朱志德副研究员到会指导,全系教职工参加了会议。会议由系党总支副书记叶凯贞老师主持。

财经系主任高香林教授对我院的教育模式和办学思路谈了自己的看法，鼓励全系教职工要不断创新、解放思想，为学院的发展贡献自己的力量。

邓传海教授、肖文锋、张海勇、郑阿泰等老师先后就教师队伍建设、培养中间层学生、提高教师自身素质、建设和谐校园等方面谈了各自的理解与建议。

朱书记指出，财经系是学生人数最多的系部之一，工作的好坏直接关系到全院的发展，希望大家要不断解放思想，敢说真话，争当实践科学发展的排头兵，不断探索新途径、新思路，围绕“上水平、创特色”的目标做好本职工作，为城院建设添砖加瓦。
