# 校园科技文化艺术节拉开帷幕

4月15日夜晚，城市学院田径场灯火通明，琴声悠扬，2007校园科技文化艺术节开幕式暨庆祝共青团成立85周年交响音乐会在这里隆重举行。

市政协、东莞理工学院新老领导王江水、黄碧莲、安少华、姚锦柏、周文媛，城市学院董事会成员和城市学院党政领导出席了开幕式并观看了交响音乐会。

学院党委书记朱志德宣布科技文化艺术节开幕。党委副书记朱冰致开幕词。他说，校园科技文化艺术节，是我院校园文化建设的重要举措，是办学过程中形成的一道亮丽风景线，是新时期加强和改进大学生思想道德建设的重要内容和有效载体，也是学院素质教育成果的展示。艺术节系列活动的开展，有利于提高同学们的学习兴趣，增强动手能力和创新能力。

开幕式上，珠影交响乐团应邀为我院8000多名师生员工倾情演奏了《北京喜讯到边寨》、《天鹅湖》、《c小调第五交响曲》(命运)等中外名曲。

据悉，这次艺术节历时45天，6月1日结束。艺术节期间，院、系及各学生社团将开展“校园工商模拟市场”、“博客设计”、“DV制作”、“辩论赛”、“青春色彩摄影比赛”、“校园十大歌手比赛”、“数码科技产品展示”等25项活动。
