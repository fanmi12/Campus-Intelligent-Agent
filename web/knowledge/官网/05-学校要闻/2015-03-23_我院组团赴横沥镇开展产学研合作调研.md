# 我院组团赴横沥镇开展产学研合作调研

3月19日，副院长黄兢率计算机与信息科学系、机电工程系、政法系的负责人及教师代表赴横沥镇开展产学研合作调研，受到镇领导陈锡稳、黄志明的热情接待。

调研期间，重点考察了该镇模具行业生产与科研情况，研讨产学研合作方式与项目，并与政府职能部门有关负责人召开了座谈会，双方围绕模具研发、电子商务、社会工作服务及教学实践基地建设等问题进行了充分的讨论，并就一些具体的问题达成了共识，确定了对接与合作意向。
