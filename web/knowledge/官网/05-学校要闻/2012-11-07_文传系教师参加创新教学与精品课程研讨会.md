# 文传系教师参加创新教学与精品课程研讨会

11月2日至4日，文学与传媒系英语教研室主任刘浔教授、李玲玲、谭波老师赴广州参加由广东外语外贸大学举办的创新教学与精品课程研讨会。

会上，广东外语外贸大学王桂珍教授、王初明教授、欧阳护华教授、郑超教授分别就《精品课程的建设与呈现》、《“以写促学”新论》、《CLT: theory and application》、《中级英语写作》中的亮点介绍——跨洋互动网站及相关校际合作计划等方面做了主题发言。

广东外语外贸大学英文学院以本院多门国家级精品课程、省级精品视频公开课和精品资源共享课为实例，以课堂观摩和工作坊的模式，介绍了他们的精品课程建设与创新教学模式的理念与实践。同时，还通过研讨和互动的方式，帮助与会人员讨论设计自己的课程建设与教学方案。

精品课程建设是教育部质量工程建设的重要内容，是一项有利于学生、有利于学科、有利学校的一项重大的系统工程。学院派出三名教师学习兄弟院校精品课程建设的经验，体现了对精品课程建设工作的高度重视。
