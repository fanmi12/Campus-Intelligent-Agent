# 学院召开纪念五四运动90周年座谈会

5月4日，学院在315会议室召开纪念五四运动90周年座谈会。学院领导安少华、朱志德、朱冰出席座谈会。会议由院团委书记杜鹏举主持。93级学生会主席、现任凯怡家具董事长、总经理谭凯帆，各系部的辅导员、学生会干部、团员代表近40人参加了座谈会。

座谈会开始前，大家观看了纪念五四运动90周年专题片。朱冰副书记向与会学生详细介绍了谭凯帆践行五四创新精神的创业事迹。谭凯帆96年从东莞理工学院毕业后，在东莞市物价局工作。两年后，他辞去了物价局工作，接手管理父亲创办的小作坊式的家具厂。谭凯帆从生产一线做起，经过十三年的努力，把家具厂打拼成一家拥有近千余名员工的大型企业，所生产的现代时尚家具远销海外。

谭凯帆的成功，让在坐的学生代表深感钦佩。院学生会主席陈逸斌同学问道：“师兄，您认为我们现在做学生会主席或者说做学生会工作，对今后有帮助吗？”谭凯帆回答说：“大学期间做一些群众性的工作，能提高与人沟通、合作的能力，能加深与同学间的感情，进而为将来的就业发展奠定人脉基础。无数事实表明，做学生工作是个很好的锻炼机会。”

座谈会上，与会人员就弘扬五四精神展开了热烈的讨论。

安院长在座谈会上指出，五四精神最核心的东西是科学、民主，90年前的今天，我们国家请进了 “德先生”（民主）和“赛先生”（科学），促进了思想大解放，也促进了整个社会的大发展。30年改革开放后的今天，我们国家要实现可持续发展，需要青年人发奋努力，传承和发扬五四精神，为国家、为社会作出更大的贡献。纪念五四，其目的是教育广大青年学生要弘扬民主、科学精神。青年强则国家强，青年智则国家智。

他要求城院青年学生宏扬五四精神，向谭师兄学习，充分利用学校资源提高自己的创新能力，做好深入社会一线与基层工作的思想准备，既要有远大抱负和长远眼光，有历史使命感，又要脚踏实地。他意味深长地说：事实证明，一定条件下，情商比智商重要，工作态度比工作能力重要，青年学生要口勤腿勤，扎扎实实地做好手头上的小事，不断历练自己。

院团委书记杜鹏举在总结讲话时认为，本次座谈会是学院纪念五四运动90周年系列活动的一部分。通过这些活动，教育广大青年学生，传承五四精神，勇挑时代重任，实现人生价值，展现时代风采。
