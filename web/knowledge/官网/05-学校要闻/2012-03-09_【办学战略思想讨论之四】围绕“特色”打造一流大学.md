# 【办学战略思想讨论之四】围绕“特色”打造一流大学

城市学院要打造一流大学，我个人认为必须进行制度创新，在特色办学当中发展自己。

在“学院定位”上形成特色

城市学院在某些办学领域要有人无我有，人有我好，人好我优的特质，探索性地把教学、科研与社会服务联在一起，把大学从社会的边缘推向社会的中心，成为大学直接为社会服务的典范。城市学院的定位应立足东莞，服务于珠三角，以本科教学和学生能力培养为基础，以综合职业技能为主线，强调培养德智体美全面发展且适应未来人才市场需求的高素质应用型人才为主要人才培养模式，积极为地方经济建设、区域社会和行业发展服务。

在“专业品牌”上形成特色

学科特色是大学特色中最主要、最鲜明的标志。城市学院要建立自己的学科专业品牌，根据珠三角经济发展的需求发展某些重点专业，使之成为品牌专业，并率先在优势专业领域为社会发展做出显著成绩，比如重点打造会计、保险、社会工作等热门专业。

在“师资人才”上形成特色

教师是形成办学特色的关键，在办学特色建设中，教师至少承担着两种角色：一是办学思想的实践者，是学校已有特色的传承者；二是特色的创造者。大师、名师就是大学的招牌和特色的标志。学科和专业是否有特色，在一定程度上取决于师资队伍是否有特色。城市学院要建设一流大学必须拥有一流的师资人才。可以采取培养与引进相结合的方针，增加师资培训经费，鼓励教师攻读国内一流大学或学科水平一流的大学博士学位，出台人才引进策略，建立柔性引进机制，加大专项资金的投入力度，大力引进学科带头人和学术骨干。

在“能力培养”中形成特色

城市学院应打造成以学生能力培养为特色的大学，重视学生组织能力、协调能力、表达能力、动手能力等综合能力的培养。可以把丰富多彩的第二课堂作为学生能力培养的重要阵地，打造品牌活动，如：打造特色跳蚤市场，锻炼学生综合能力；组建义工团队，定期组织志愿活动；开设周末影院，定期放映励志主题影片或人物传记；开展学术沙龙活动，邀请知名专家与学生探讨热点问题等等。

在“服务地方”中形成特色

城市学院要适应现代教育发展的新潮流，创造出优质多样的社会服务。要加强为东莞社会经济发展服务的能力，在东莞打造文化名城的进程中，做出积极的贡献。要在调研的基础上积极调动师生的积极性，提供优质多样的服务，努力在服务中形成特色，才能共赢，才能得到持久的发展后劲和广泛的社会影响力。
