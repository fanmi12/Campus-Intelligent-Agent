# 华南师范大学增城学院客人来访我院

来宾参观我院图书馆3月18日，华南师范大学增城学院办公室主任汪永红一行15人来我院参观访问，交流经验。副院长张林、院办公室主任王玉等接待了客人。

我院与华师增城学院均是迎接教育部本科学士学位评估的单位，座谈会上宾主双方就此问题交换了意见。双方还就如何提高行政人员工作能力和管理水平，如何提高行政工作效率、增强服务意识，转变民办高校粗放型行政管理模式等问题进行了深入的交流与探讨。

会后，来宾参观了我院图书馆和校园。
