# 我院圆满完成本学年“创新强校工程”考核自评工作

7月4日，我院圆满完成了“创新强校工程”2016-2017学年考核自评工作，并启动了2018年“创新强校工程”资金申报工作。

根据《广东省教育厅关于开展2017年度本科高校“创新强校工程”考核及2018年“创新强校工程”资金申报的通知》要求，我院“创新强校工程”领导小组积极组织院办、人事处、教务处、研究与发展规划处等有关部门，对应用型民办本科高校“创新强校工程”考核的6个一级指标、21个二级指标及49个三级指标进行全面分解和部署。各部门填报了考核数据表格，研究与发展规划处统筹完成了考核自评报告和自评打分、佐证材料和佐证材料目录、2018年拟安排专项资金二级项目支出基本情况表和绩效目标申报表，并按规定时间报送了省教育厅。
