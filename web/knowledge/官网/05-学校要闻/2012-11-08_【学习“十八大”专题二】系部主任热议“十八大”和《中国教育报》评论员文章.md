# 【学习“十八大”专题二】系部主任热议“十八大”和《中国教育报》评论员文章

各系部主任组织老师在网上观看学习“十八大”的新闻，并结合11月2日《中国教育报》的评论员文章《育人为本是教育思想的深刻变革和理论创新》展开讨论。

大家认为，该文对“育人为本”的教育思想进行了深刻的阐述。9年来，我院始终坚持“育人为本、德育为先”的教育理念，积极研究“育人为本”的内涵，努力探索学院“三育人”工作的有效载体，形成了教书育人、管理育人、服务育人的良好氛围。《中国教育报》的这篇评论文章，对我院今后更好的地坚持和发展“育人为本”的理念具有重要指导意义。

为此，本网现将全文下载，供大家参阅学习。
