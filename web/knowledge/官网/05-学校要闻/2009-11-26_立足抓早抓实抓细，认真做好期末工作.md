# 立足抓早抓实抓细，认真做好期末工作

“期末临近，年关将至，一切工作都要立足于抓早抓实抓细，力争全面完成年初确定的计划与任务。”11月25日，院长安少华在学院召开的中层干部会议上，就如何完成全年工作任务向与会人员提出了明确的要求。

会上，东莞理工学院副校长、城市学院院长安少华作重要讲话，通报了省民办高校会议精神和广东鸿发投资集团近日考察城市学院校园建设等有关情况。

学院领导朱志德、朱冰、张林，院督学陈丁堂代表程发良分别就年末所分管的工作做了安排部署。他们要求，年前要召开好党委中心组民主生活会、实施教学质量工程讨论会、校园招聘会、民主党派和无党派人士座谈会、教职工代表大会、新年音乐会、春节团拜会等重要会议；积极开展诚信考风教育、教师绩效考核、校园十佳和十大工作创新奖评比、安全维稳教育等活动；进一步做好学士学位申报评估、考试考务、优质课程与达标课程申报验收准备、后勤保障与教学服务、图书科技信息大楼开馆准备、学生评优评奖、党建量化考评等工作。

会议强调，干劲可鼓不可泄，工作标准不能降低，教学质量的弦不能松，年初确定的任务必须坚决完成。
