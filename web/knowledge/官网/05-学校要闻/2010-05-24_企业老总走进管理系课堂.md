# 企业老总走进管理系课堂

5月21日，国内资深管理实战派专家杜勇华先生，应邀为管理系07工商本科学生讲授管理思想在企业中的实际运作。

杜勇华先生以朴实的语言，向同学们讲述了成功的关键要素，企业运行的基本关注点，老板需要的人才，大学生初入职场应当具备的基本素质和能力等内容。

据介绍，杜勇华先生具有数十年大型集团高层管理的经历，曾任台湾致伸集团（东聚电业）人资课长、鸿泰机电高级经理、台湾声宝集团筹建主任及管理部经理、徐福记国际集团总部人资处处长（曾被誉为徐福记三剑客）、晟泰集团副总经理、康迪远东集团行政总监，现任广东领航者咨询公司资深专家顾问。
