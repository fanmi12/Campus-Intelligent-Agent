# 宁波大学科学技术学院来我院交流访问

3月19日上午，宁波大学科学技术学院党委书记邓建平、副院长罗思明一行6人莅临我院访问交流。

院长王卫平、院长助理林江龙热情接待邓建平书记一行，双方就人才培养体系、专业建设、大学生创新创业等方面的工作经验，进行了交流探讨。

院办主任杜鹏举、教务处处长赵书山、招生就业处处长孔增强、计信系主任廉玉忠参加了座谈。
