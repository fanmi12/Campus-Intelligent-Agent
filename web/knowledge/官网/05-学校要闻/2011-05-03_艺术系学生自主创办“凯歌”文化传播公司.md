# 艺术系学生自主创办“凯歌”文化传播公司

我院艺术系07级影视表演专业学生赖欣怡自筹资金，开设了名为“凯歌”的文化传播机构，从事广告制作及文化宣传活动，并邀请了3名同班同学参与创业。

4月29日，艺术系主任邓星明、党支部书记丘永辉专程看望赖欣怡等同学。系领导详细询问了同学们的创业情况，对他们的创新思维和勇于开拓的精神给予了充分的肯定和高度的评价。邓主任鼓励同学们：“创业是艰辛的，需要勇气和毅力，艺术系将大力支持你们的创业活动。如果在创业过程中遇到什么困难，有需要大家帮忙的地方，随时欢迎你们来找我。”
