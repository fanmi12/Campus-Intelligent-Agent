# 东莞市志愿者周末讲堂城院开讲

9月28日，院团委承办“2013年东莞市志愿者周末学堂暨第十五期基层志愿培训班”在我院教学楼7B206课室举行。

本期周末学堂邀请了市志愿者协会社工邓巧梨、莞城敬老院社工刘英、大众社会工作服务中心社工刘嘉琪三名嘉宾出席本次活动，讲座以“如何促进大学生志愿者与社工的密切合作”为主题，院志愿队同学与社工们进行了相互交流。针对同学们提出的问题，社工嘉宾们一一作出了回答。

社工邓巧梨希望志愿者应多尝试参与社工工作，主动联系社工，体会社工工作的基本理念、手法和价值观，学习社工服务的相关知识。社工刘英更是强调，志愿者就是奉献者，要有充分的心理准备，明确志愿者与社工之间的关系是亦师亦友。

院团委李伟健老师表示，志愿者与社工之间的交流更有助于提升我院校园志愿者队伍的整体素质和服务水平，此类活动将会持续的办下去，把爱心传播下去。
