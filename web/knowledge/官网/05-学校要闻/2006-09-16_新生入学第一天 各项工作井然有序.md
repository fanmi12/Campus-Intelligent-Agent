# 新生入学第一天  各项工作井然有序

“优良的地理位置、美丽的校园环境、和谐的校园氛围、亲切的同学和老师，带给我们的是舒畅欢愉的心情和家一般的温馨。”来自湖南的2006级新生张军同学兴奋地告诉记者。9月16日，是城市学院新生入学的第一天。上午8点30分，院长安少华教授等领导和各系主任在学院报到大厅里迎接新同学的到来。院长安少华教授还发表了公开信《追求卓越，共同成长——致2006级新同学的一封信》，对新同学的到来表示热烈欢迎和良好的祝愿。截止下午5时，已有2100新生缴费注册完毕。

记者在校园里看到，在学院的统一调度安排下，迎接接待等各项工作井然有序。报到注册现场，新生咨询、报到、缴费、户口迁移以及家长接待等工作都在有条不紊地进行。学院各系也成立了新生接待点，为新生报到、住宿等工作提供帮助和服务。

在来自全国各地的新同学中，有4位同学特别引人注目。他们分别是文学与艺术系的蒋敏、何美莹、杨静和计算机与信息科学系的魏民。为落实中央统战部和老区扶贫基金会关于对革命老区扶贫的指示精神，今年城市学院在原红四方面军总部所在地——四川省通江县招收了一批贫困大学生，并免收他们的学费。这4名来自老区的同学及其家长在学院的接待室里，受到城市学院院长安少华教授、文学与艺术系主任张林教授等领导热情地接待。
