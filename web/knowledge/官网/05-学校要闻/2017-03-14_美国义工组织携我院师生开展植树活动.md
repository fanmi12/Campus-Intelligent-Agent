# 美国义工组织携我院师生开展植树活动

3月6日, 美国义工组织CCI Greenheart到我院开展中美文化交流，并共同举办了公益植树活动。

当日上午，CCI Greenheart两名美国代表Adriana和Renee抵达我院参观访问。外语系主任王锦锋、外语系副书记都振华、国际交流中心副主任夏泉源等老师会见了客人。

下午，两位美国代表与我院外语系师生一同进行了植树活动。在一片欢声笑语师中，大家植下了25颗玉兰树苗。

随后，两位美国代表还举行了公益讲座，为同学们解读了义工精神，以及他们到世界各地进行的公益活动经历等。期间，同学们讨论热烈，现场气氛活跃。

一位参与活动的学生表示，这次植树活动很有收获，亲手种下了一株小树苗，使自己对学院的一草一木的爱护更有使命感。同时，跟两位美国义工一起交流，不仅提升了自己英语交流的自信，还了解到了很不一样的义工概念。
