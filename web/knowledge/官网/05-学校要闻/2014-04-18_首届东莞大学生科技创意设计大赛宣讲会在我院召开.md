# 首届东莞大学生科技创意设计大赛宣讲会在我院召开

4月15日，首届东莞大学生科技创意设计大赛“时代为你疯狂”宣讲会在我院7B202召开。东莞市科学技术协会科技咨询中心副主任杜志尧、东莞市伟旺达电子有限公司副总经理廖健化出席了会议。

会上，杜志尧主任介绍了大赛的活动形式。他说，大赛将以全新的综艺节目的形式进行全程拍摄，将借鉴《爸爸去哪儿》和美国的《飞黄腾达》节目形式，直接表现参赛选手最真实的想法，记录参赛选手科技创意的过程。而主办方将为选手们提供最优质的保障，安排专车全程接送，指定指导老师全过程辅导。并邀请各高校参赛代表团到企业、研究院深度体验交流，了解产品的设计与生产。

作为本次大赛的合作企业之一的伟旺达公司廖健化副总经理在会上介绍了公司的基本情况，以及产品的设计、试制试产等设计流程。随后，我院导师谭海欧老师介绍了参赛的报名方式和要求。

据了解，本次大赛将于2014年4月至9月举行，由东莞市科学技术协会主办，东莞地区六大高校、多所企业和研究院共同协办。主办方希望通过本次大赛我市大学生增强科技创新意识，提升科普素质，欢迎同学们踊跃报名参赛。
