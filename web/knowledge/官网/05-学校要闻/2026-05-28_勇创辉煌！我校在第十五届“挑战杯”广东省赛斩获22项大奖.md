# 勇创辉煌！我校在第十五届“挑战杯”广东省赛斩获22项大奖

5月22日至24日，由共青团广东省委员会、广东省教育厅、广东省科学技术厅等八大部门联合主办的第十五届“挑战杯”广东大学生创业计划竞赛主体赛与河源“百千万工程”专项赛终审决赛，在广东技术师范大学圆满落幕。

本届竞赛以“青创潮涌汇南粤，挑战建功百千万”为主题，紧扣省委“1310”具体部署与“百县千镇万村高质量发展工程”工作要求，聚焦科技创新、乡村振兴、绿色低碳、社会治理、文化创意五大核心赛道，吸引全省160所高校、逾10万名大学生参赛，1940件作品跻身省赛，210个项目闯入终审决赛，组委会拟授金奖127个、银奖389个、铜奖905个。同时，本届赛事积极搭建服务地方发展平台设置河源“百千万工程”专项赛结合河源市委“138”具体安排融合“十带百坊千创客”培育行动围绕高端水产业、智能农机研发、古城保护、数字游民生态等21个领域“出题张榜”吸引全省140所高校3万余名青年学子“揭榜挂帅”累计产出3351份专题方案与特色作品为河源发展注入青春活力，每个榜题仅5至7支团队入围终审决赛，组委会拟授金奖21个、银奖84个、铜奖775个。

学校党委副书记、副校长康贤刚，校团委书记范琪，城建与智造学院党总支书记、副院长曹镭，携3支项目团队师生赴现场参赛。经过激烈角逐，我校共荣获22项大奖，其中银奖3项、铜奖19项，获奖数量较上届赛事翻倍增长，再创历史新高！尤为亮眼的是，我校在河源“百千万工程”专项赛中脱颖而出，三支队伍斩获专项赛银奖，成为广东省民办本科高校中唯一斩获三项省赛银奖殊荣的院校，充分彰显我校在服务地方高质量发展中的创新实力与示范作用。

本届省赛我校参赛作品覆盖智慧消防、AI助盲、智能农业、乡村文旅、非遗活化、文化出海等多个领域，紧扣时代需求、扎根基层实践，以青春科创力量助力“百千万工程”落地见效。

自校内选拔赛启动以来，学校党政领导高度重视、亲临指导，教务部、科研部、创新创业学院等部门协同保障，校团委与各二级学院精心组织。赛事共吸引315个作品申报，经严格评审，24个项目晋级校决赛，优中选优、全力备赛，为省赛大捷奠定坚实基础。

对比广东省内民办本科高校，本届赛事多数院校获奖数集中在10至18项。我校以22项大奖、其中3项专项赛银奖、获奖数翻倍的亮眼成绩，稳居广东民办本科高校第一梯队，实现数量与质量双突破。

未来，学校将持续深耕“挑战杯”品牌赛事建设，完善赛事培育、全程指导、项目孵化全链条机制，坚持以赛促学、以赛促练、以赛促创，不断激发学子创新创造活力，为青年成长成才搭建更高平台，为学校高质量发展与广东“百千万工程”建设续写更多出彩篇章！
