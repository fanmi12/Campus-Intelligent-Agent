# 管理系举办首届“勇往职前·城院之星”模拟招聘会

管理系团总支学生会成功举办东莞理工学院城市学院第一届“勇往职前·城院之星”模拟招聘会。

模拟招聘会决赛于10月18日下午2:30在学术报告厅隆重举行，本次活动邀请到管理系党总支书记、资深人力资源管理专家帅建华教授、中心人才市场培训中心经理符浩南、东莞联通校园市场营销中心总经理黄静担任本次活动的点评嘉宾，学生处处长杜鹏举、金贸系主任米双红教授、计信系主任牛熠教授、财经系主任罗卫国教授、院团委书记罗文芳、管理系人力资源管理教研室主任王晓春、枇杷润茶闽中华南区销售部经理林龙飞、东莞联通城区分公司副总经理牛磊担任评委。

11名选手在自我介绍、VCR展示、评委问答、简历制作等4个环节中向评委展示了自我才能、成长经历、求职意向以及与求职职位的匹配度。面对评委们犀利的提问，选手们从容地对答，获得评委的肯定。经过两个半小时的激烈角逐，最终产生了一、二、三等奖以及优秀奖。其中，郑潇乾同学摘得第一名桂冠。

据悉本届模拟招聘会于今年6月底举行初赛，11名选手进入决赛。模拟招聘会组委会在赛前邀请了银城酒店人力资源培训师甘志德以及管理系党总支书记、资深人力资源管理专家帅建华教授，分别就大学生求职礼仪、大学生应聘说话技巧对11名选手进行了培训。
