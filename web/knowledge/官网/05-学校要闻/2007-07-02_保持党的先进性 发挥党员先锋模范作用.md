# 保持党的先进性 发挥党员先锋模范作用

6月28日，城市学院近千名共产党员在大礼堂隆重集会，纪念中国共产党成立86周年。东莞理工学院党委委员、副院长、城市学院院长安少华教授，党委书记朱志德，党委副书记朱冰，副院长张林，党委委员王玉、夏勇、章德胜出席并参加了会议。

会议由党委副书记朱冰主持。会议首先举行了新党员入党宣誓仪式，共有169名大学生党员面向党旗庄严宣誓。

党委委员、人事处处长夏勇宣读了《关于表彰2006－2007学年度先进基层党组织、优秀共产党员和优秀党务工作者的决定》，授予机关一支部、财经系党总支先进基层党组织荣誉称号；授予夏勇、章德胜、黄健求、钟兴恭、黄研晖等13名教工党员和黄健棠、傅萱等9名学生党员优秀共产党员荣誉称号；授予黄阳辉、理阳阳优秀党务工作者荣誉称号。

优秀共产党员学生代表高政和优秀共产党员教师代表蒋伟分别发言，表示在今后的工作、学习和生活中，牢记共产党员这一光荣称号，在政治上、工作上、纪律上、作风上、能力上保持先进性，立足本职，不断进取，做一名合格的共产党员。

党委书记朱志德发表了重要讲话，他希望广大学生党员要以振兴中华为己任，勤奋学习，求实创新，带头参加学术科技活动，培育创新意识，树立科学精神和人文精神，不断提高运用知识服务社会的本领，在成长成才中发挥先锋模范作用。广大教师党员，要加强教学方法研究，讲究课堂艺术，追求教学效果，提高教学水平；要积极开展科学研究，多出成果，早出成果，出好成果，在人才培养、科学研究中发挥先锋模范作用。

大会在嘹亮的国际歌歌声中圆满结束。
