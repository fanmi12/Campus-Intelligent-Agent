# 社区研究中心组织教师暑假赴堑头社区讲课

暑期来临了，如何引导学生正确运用网络，成为许多家长头痛的问题。应堑头社区方面的邀请，7月16日上午，我院社区研究中心组织陈浩、程建新、林晓等老师赴堑头社区妇女学校，就青少年网络沉迷这一现实问题进行开讲，堑头社区30多名家长及青少年参加了讲座。

讲座由学院心理健康教育与咨询中心陈浩老师主讲。陈浩老师先后取得国家心理咨询师、户外拓展培训师资格，现任东莞心理卫生协会理事，擅长青少年心理咨询及团体辅导。他深入浅出地讲解了青少年网络沉迷的表现、界定、症状、原因、对策等相关知识，并通过实例进行剖析，与听众进行亲切的互动。陈老师鼓励家长与子女建立良好的互信互动关系，共同面对网络对青少年的负面影响。讲座受到在场堑头社区居民的热烈欢迎。
