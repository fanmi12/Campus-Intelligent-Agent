# 我校深入推进主题教育系列报道之一

编者按：今年9月19日，在东莞市委主题教育第十一指导组的指导下，我校召开“不忘初心、牢记使命”主题教育动员部署大会，动员全校各级党组织提高政治站位，扛起政治责任，以高度的政治责任感，认真负责地把主题教育组织好、开展好，确保取得实实在在的成效。

从11月25日开始，新闻中心推出系列报道，全面反映我校各二级学院开展“不忘初心、牢记使命”主题教育取得的实效。

“不忘初心、牢记使命”主题教育作为我校当前及今后一段时间的首要政治任务与工作。法学院、城环学院、金贸学院按照中央和省市“不忘初心、牢记使命”主题教育工作会议精神和学校的部署，围绕全面把握“守初心、担使命，找差距、抓落实”的总体要求，坚持抓思想认识到位、抓检视问题到位、抓整改落实到位、抓组织领导到位，结合各自学院的实际和特色，在全院党员干部、师生群众中，广泛开展特色鲜明、富有创新的主题教育工作。

结对共享共建

城环学院党政领导班子高度重视主题教育的深入开展工作，按照学校主题教育部署，既保质保量完成规定“动作”，又挖掘城环学院自身特色不断推陈出新。

要开展好主题教育，必须加强理论学习。10月17日、24日，城环学院学生党支部、教工党支部分别召开《习近平关于“不忘初心、牢记使命”论述摘编》专题交流分享会，学原著悟原理，从中汲取精神滋养和前行力量，积极推动学院工作高质量发展。同时积极开展主题教育专题党课，党总支书记何鹏举教授以《党的政治建设》为主题为全院师生党员及入党积极分子，阐述了什么是党的政治建设、为什么要加强党的政治建设以及如何加强党的政治建设。

要开展好主题教育，铸造坚强有力的基层党组织作用尤为重要。10月18日，城环学院党总支召开廉政教育警示会，共同观看了廉政教育警示片《铸魂》。24日，党总支举行批评与自我批评组织生活会，院长、书记率先开展批评与自我批评，查找问题，发现问题、提出建议。全体教工党员，深入剖析了自身及学院、日常教育教学工作、生活学习中存在的问题，寻找解决方案，落实整改措施，共同促进各项工作高质量开展。11月7日，召开了对照党章党规找差距专题教育会议，副校长刘玉侠参会。肖红飞院长带头与全体党员同志对照党章、《准则》和《条例》开展了自我批评，检视了自身的问题，明确整改措施和努力方向。

要开展好主题教育，创新必不可少。11月7日，城环学院党总支与东莞市自然资源局机关第二党支部在市规划展览馆举行党建共建仪式，实现共同学习理论、共同服务群众、共同促进发展，提升党员素质，积极发挥党建特色的要求。通过共建，双方依托优势互鉴，相互提高党员综合素养，形成共建发展的良好格局。

传承“红色基因”

法学院依托建设在广东东江纵队纪念的东莞红色文化研究中心实践基地，以传承红色文化、弘扬红色精神为己任，将“不忘初心、牢记使命”主题教育办得有声有色。

广东东江纵队纪念馆位于东莞市大岭山镇大王岭村，是展示广东人民抗日游击队东江纵队历史的专题纪念馆，第四批全国青少年教育基地。在此成立东莞红色文化研究中心，将我校智力资源与东纵纪念馆红色资源优势，共建共享，传承红色基因，把东莞红色资源利用好、发扬好。该实践基地的建设，不仅为法学院，也为全校广大师生党员和入党积极分子搭建起了一个研究与实践平台。9月28日上午，学校“不忘初心、牢记使命”主题教育领导小组赴广东东江纵队纪念馆开展革命传统教育活动，继承和发扬东江纵队高度的爱国主义精神和艰苦奋斗、不怕流血牺牲、一往无前的革命精神。

10月21日，法学院党总支书记江小卫在为学生党员讲授“追寻红色东纵，牢记初心使命”专题党课时，通过重走东纵路对“初心” “使命”进行深刻诠释，希望同学们发扬“东纵精神”，传承“红色基因”，奋力走好新时代的长征路。

两个月来，法学院党总支以传承“红色基因”，开展学革命精神牢记使命党日活动、赴东莞革命烈士纪念碑缅怀先烈等等一系列主题教育活动，勇于挖掘东莞本土红色文化，弘扬革命精神。

此外，结合专业特色，10月24日法学院党总支到寮步第一人民法院参加“党建引领，与法同行”之庭审旁听活动，法学院师生党员第一次共同参与旁听庭审，认真观摩了庭审的每一环节，对庭审的流程也更为了解。庭审旁听活动,有利于进一步增强党员同志证据意识、程序意识，感受司法的权威与魅力，激发专业自豪感，坚定“与法同行”的信念。

“立德树人”是高校的初心，法学院院长刘杰铭记于心。11月13日-16日，他走访了湖南大学、湖南师范大学、湖南工商大学、湖南警官学院的法学院系，就人才培养的国标定位、人才培养方案的适时修订，专业师资队伍建设、课程设置及其教学内容、方式的改革，不同层次院校人才培养的差异性以及“新文科”背景下地方院校高素质法律、行政管理、社会工作应用型专门职业人才培养方式等进行了深入的交流，旨在进一步创新法学院人才培养。

开展系列活动

开展“不忘初心、牢记使命”主题教育，铭记“为中国人民谋幸福，为中华民族谋复兴”的“初心”和“使命”，金贸学院领导班子积极动员部署，开展了系列丰富多彩的主题教育活动。

《我爱你，祖国》《我骄傲，我是中国人》《我们都是追梦人》……9月29日，金贸学院学生党支部举办了以“颂红诗，扬青春，筑党魂”主题党日活动。学生党员代表用真切的情感昂扬的斗志诵读等红诗，表达了自己对党的忠诚和信仰，对祖国的热爱。

10月18日，金贸学院党总支组织全体师生党员赴浮竹山烈士陵园和东莞市规划展览馆开展“不忘初心、牢记使命”主题教育活动。10月25日，金贸学院举行微党课决赛， 参赛选手以“激扬青春梦，奋斗新时代”为主题，表达了坚持奋斗、为梦想坚持拼搏的心声。10月31日，邀请马克思主义学院刘学勤老师为学生党员和入党积极分子进行“不忘初心，牢记使命”主题教育宣讲，使同学们了解新中国奋发有为的发展之路，不断提升自己，为中国之崛起不断奋斗。

“真人图书馆”党员分享会，可谓是金贸学院主题教育一项特色活动。李冰倩、张慧、刘娅、贺智丽四名学生党员在“真人图书馆”分享他们的成长历程。李冰倩以“保持微笑、面对压力”为主题，讲述到要以乐观的态度面对生活中以及学习中的各种问题与压力。学生党员张慧以“走出舒适圈，重新认识你自己”，介绍了她的成长之路。刘娅以“仰望星空、脚踏实地”为主题，向入党积极分子们解说了仰望星空，脚踏实地意义，强调了要做一个有规划的人，并要有为他人无私奉献的精神。贺智丽以“心怀善意、披荆斩棘”为主题，鼓励入党积极分子候选人们在入党过程中始终坚持如一。四名学生党员的分享为入党积极分子提供了良好的精神动力，更加坚定了入党信念。

“不忘初心、牢记使命”主题教育，用党的创新理论武装头脑，推动全党更加自觉地为实现新时代党的历史使命不懈奋斗。法学院、城环学院、金贸学院正是通过主题教育，将引领广大群众全面了解党的历史，爱党、拥党、护党，进一步感党恩、听党话、跟党走，艰苦奋斗、攻坚克难，为实现中华民族伟大复兴的中国梦而努力奋斗！
