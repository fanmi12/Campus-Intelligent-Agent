# 第四代表团讨论热烈

6月3日，中共东莞理工学院第一次代表大会已经进入了大会日程安排的第二天。城市学院与教辅、成教学院、后勤集团共同组成了第四代表团，朱志德同志任第四代表团团长。

上午9：30,第四代表团讨论在4号会议室进行，代表团就学院临时党委工作报告、纪委工作报告进行了讨论并一致通过了其决议的草案。代表们还审议了关于党费收缴、使用和管理情况的报告。其中城市学院代表们围绕党委报告中对城市学院的发展定位展开了热烈的讨论。当天还召开了主席团第二、三次会议。
