# “中国散裂中子源科普论坛”在我院成功举办

5月25日下午，由东莞市科技局主办、东莞市科学技术博物馆和东莞理工学院城市学院承办的“中国散裂中子源科普论坛”在我院学术报告厅举行。中国科学高能物理研究所副所长陈延伟研究员作为主讲人，就中国散裂中子源项目为城院学子进行了一次精彩的科普教育。东莞市科学技术博物馆陈晓洪副馆长、我院黄兢副院长与各院系热爱科技的学子一道聆听了讲座。

黄兢副院长在致词中表示，为了更好地扩大对中国散裂中子源的教育和宣传力度，提高大学生与公众对散裂中子源的认识，提升东莞本土高校师生的科学素养和探索精神，特举办本次专题科普讲座。他希望能通过本次讲座，激起我院广大师生以饱满的热情和锐意创新的精神投入到科学研究和创新实践之中。

在热烈的掌声中，陈延伟研究员围绕“探索微观世界的有力武器——散裂中子源”为主题展开，并从“加速器、国家大科学装置及大科学工程管理、中子散射及应用与散裂中子源工程进度”等四个方面，通过宏观与微观的角度，介绍了大科学工程下中国散裂中子源的发展历程。

陈延伟研究员用通俗易懂、生动形象的比喻和图文并茂的ＴＴＰ，将晦涩、高深的高科技工程项目——散裂中子源，生动传神地科普给现场师生。

陈延伟研究员还重点介绍了中国散裂中子源项目(CSNS)。该项目是国家“十一五”期间立项、“十二五”重点建设的重大科技基础设施，选址就在东莞市大朗镇，由中国科学院和广东省共同建设，计划于2018年前后建成。届时将成为发展中国家拥有的第一台散裂中子源，与世界上正在运行的美国散裂中子源、日本散裂中子源和英国散裂中子源一起，构成“世界四大脉冲散裂中子源”。

在随后的互动环节，陈延伟研究员还对现场同学的提问进行了耐心细致、通俗的解答。他表示：“散裂中子源项目的建立对东莞是一个机遇，虽然科研成果的转换需要一个过程，但它能极大带动地区的区域经济发展。其次便是人才聚集的效应，项目能够作为一个应用平台吸引高精尖人才与企业的到来，并带来整个城市形象的提升。”他还表示，“未来这个项目能够引进很多国家先进技术与东莞高校合作推进，能够给大学生带来的就是更多的平台与科技学科设立” 。

论坛由学院研究与发展规划处处长赵书山主持。

人物简介：陈延伟研究员，是中国科学院高能物理研究所副所长，高能所东莞分部主任，中国散裂中子源工程办主任，曾参加兰州重离子加速器建造和运行，担任兰州重离子加速器总值班长;在意大利核物理研究院南方国家实验室做访问学者，参加了该实验室重离子加速器建设;参加了北京正负电子对撞机 (BEPC) 运行，担任直线加速器运行维护负责人;参加了北京正副电子对撞机重大改造工程 (BEPCII) 建设，担任副主任工程师。2007 年至今，负责中国散裂中子源项目立项、建设和工程管理、科普宣传等方面的工作。
