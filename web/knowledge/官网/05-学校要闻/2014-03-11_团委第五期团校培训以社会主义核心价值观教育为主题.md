# 团委第五期团校培训以社会主义核心价值观教育为主题

3月6日，团委在教学楼7C607举办东莞理工学院城市学院第五期团校培训班，团委各部门负责人及150名团校学员参加了培训班的学习。

据悉，举办本期团校培训班的意义和目的在于加强我院团组织的基础建设，增强青年对中国共青团的认识，对入团积极分子进行团的基本知识、光荣传统和思想道德教育，促进青年用马克思主义理论武装自己，践行社会主义核心价值观，增强青年历史使命感和责任感，为团组织输送新鲜血液，为党组织培养优秀的生力军和后备军。

团校培训班为53名入团积极分子正式加入共青团举行了宣誓仪式。
