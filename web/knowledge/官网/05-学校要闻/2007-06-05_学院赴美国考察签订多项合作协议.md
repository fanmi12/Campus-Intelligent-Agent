# 学院赴美国考察签订多项合作协议

2007年4月28日，由学院副院长程发良教授带队，一行10人，赴美国进行了为期两周的考察访问，于5月13日返回学院。

访美期间，考察团成员考察访问了北爱荷华大学、芝加哥大学和西北大学，观赏了芝加哥、华盛顿和纽约的城市风光，受到同行们的热情接待，并与北爱荷华大学签订了多项合作协议。

考察北爱荷华大学，是考察团的一项重要行程。据介绍，该校位于美国风景优美的爱荷华州雪松瀑布市，现有学生15000人，可提供ESL、大学部和研究所的课程。UN连续6年被《美国新闻与世界报道》评为中西部顶级公立大学第二名，并在《吉普林个人理财杂志》中获选为美国前100名最有价值的大学。去年7月，该校国际交流中心主任Yana.A.Cornish访问了我院。

5月2日，北爱荷华大学自然科学学院举行晚宴，欢迎我院考察团一行。化学系主任DR.Duane E.Bartak,计算机系副主任DR.Wallingford等出席了宴会，工业技术系主任Professor M.F.Fahmy代表工业技术学院院长Dr.Mhammed Fahmy 致欢迎词，宾主进行了亲切友好的交谈。考察团还参观了校园及化学实验室，观看了硕士学位授予仪式，应麦克尔教授的邀请到其家里做客。

艾伦校长与我院考察团经过商谈，签订了多项合作协议，包括暑假期间双方互派20名交换生，教师互访，运用“2+2培养模式”（学生在北爱荷华大学、城市学院各读2年，双方颁发毕业证书）培养学生等内容。

据悉，芝加哥大学、西北大学也是美国著名的大学。
