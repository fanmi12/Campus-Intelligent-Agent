# 广东省本科高校教学工作研讨会在我院召开

3月9日，广东省本科高校教学工作研讨会在我院召开。会议由广东省本科高校教学管理指导委员会主办、我院承办。省教育厅党组副书记、副厅长邢锋，高教处处长郑文、调研员吴念香、副处长邓荣海等领导出席了会议。来自中山大学、暨南大学、华南理工大学等63所高校、130名高校主管教学副校长、教务处处长、副处长参加了研讨会。

我院院长王卫平在大会致辞中感谢省教育厅的信任，对大会在城市学院召开倍感荣幸，对各高校领导的莅临表示热烈欢迎。王院长还简要介绍了我院的发展概况，并指出此次会议的召开必将进一步促进我院的发展，尤其是在提高教育教学质量方面意义重大。

省教育厅高教处处长郑文以《不忘初心，写好高校本科人才培养“奋进之笔”》为题作了专题报告。郑文处长从“坚定高校人才培养光荣使命”、“系统总结我省高校本科教学工作”、“扎实推进2018年本科人才培养重点工作”等方面，总结了全省高校本科教学工作，并对高教处2018年高校本科教学工作要点进行了详细介绍。郑文处长指出，“高校办学的初心就是培养人才”，“以学生为中心的高等教育”就是党执政理念的体现。他还提出了“一流大学是目标，一流学科是条件，一流本科是根本，一流专业是基础”的建设理念，以及“以人才培养分类前提、以体制机制改革为动力、以专业结构调整为重点、以评估体系完善为保障，形成多元成才、充满活力、适应需求、质量过硬的人才培养体系”的高校本科人才培养思路。

省教育厅高教处调研员吴念香对“广东省普通高等学校本科新设专业评估实施方案”和“广东省普通高等学校本科专业评估方案（试行）”，从实施背景、意义、评估具体内容和工作安排等方面进行了详细地解读。

研讨会还分成了工科组、师范组、医学组、综合一组、综合二组等五个小组进行了讨论。各小组代表在大会上发言，反馈了小组讨论上的有关建议和意见。

省教育厅党组副书记、副厅长邢锋作了重要讲话。邢锋副厅长从落实立德树人根本任务、加大高等教育“创新强校工程”统筹力度、深化“新工科”建设与改革、推进“新师范”建设、加强本科专业建设和管理等方面，对2018年高校本科教学工作要点进行了全面部署。邢锋副厅长强调，“改革总是在进行时”，要求各高校以本科教育为中心，立德树人，抓住高等教育发展机遇，不断进取、不断创新、不断改革，开创高校人才培养的新局面。

会后，邢锋副厅长、郑文处长在学院董事长麦照容、院长王卫平等领导的陪同下，还参观了我院商科虚拟仿真实践教学中心和作为广东省“试点学院”建设单位的创意设计学院。
