# 【众志成城 抗击疫情】我校举行新冠肺炎疫情应急处置演练

按照省委教育工委、省教育厅的部署，为全面做好学校新冠肺炎突发疫情应急处置工作，保障广大师生员工身体健康和生命安全，3月27日下午，我校举行新冠肺炎疫情应急处置演练。学校防控新型冠状病毒感染的肺炎疫情工作领导小组全体成员、二级学院党总支副书记、辅导员及相关部门工作人员、学生志愿者参加了演练。

此次新冠肺炎疫情应急处置演练分为两项，模拟疫区学生返校、突发异常情况等场景下，进行发现疫情、上报信息、隔离观察、及时送诊、消毒警戒等应急处置工作的过程。

在第一项实战演习中，一名同学自湖北荆州返校，学校从掌握返程高铁车次、专人迎接，签放《医学观察告知书》、测量体温、专人专车带至学六集中医学观察区留观等环节，严格按照预案规定流程进行处置。第二项实战演练主要模拟了学生返校上课后，宿舍某学生出现发热（腋下体温超过37.5℃）、咳嗽症状。从辅导员接到学生报告，学校防控新型冠状病毒感染的肺炎疫情工作领导小组进行了全过程处置流程演练。演练项目包括学生健康监测日报、疫情信息校内通报反馈、现场应急隔离、流行病学史调查、疫情信息上报、疾控医务人员紧急处置、患者转移至东莞定点医院、密切接触者转运隔离观察、现场环境应急消杀、集中隔离观察点管理，以及核酸接检测、警情解除等环节。整个演练过程严格按照预案规定流程进行，分工明确、反应迅速、协调有序。通过应急演练，学校进一步规范了应急处置流程，提高了防控工作人员应对新冠肺炎的防范意识和应急水平，提升了学校疫情防控应急处置的作战能力。

演练总指挥、学校党委书记章德胜总结强调，此次演练是为进一步加强学校新冠肺炎疫情防控工作，全面提高学校疫情防控应急处置能力的一次检验。各单位要高度警惕、认真履职，严格贯彻省委教育工委、省教育厅的部署，根据东莞市教育局的指引，要对应急处置流程了然于心，决不可麻痹大意，切实将疫情防控工作一项项落实到位，为顺利开学打下坚实的基础。
