# 党委中心组举行扩大会议深入学习党的十九大精神

今日下午,学院党委中心组在行政楼212会议室举行扩大学习会，深入学习贯彻党的十九大精神。院党委委员、院领导和各党总支（直属支部）书记、副书记参加学习。

院长、党委书记王卫平作了题为《高举新时代中国特色社会主义伟大旗帜，深入学习、努力贯彻党的十九大精神》主题报告。

王卫平书记从党的十九大主题以及主要成果、习近平新时代中国特色社会主义思想、过去五年的历史性成就和变革、中国特色社会主义进入新时代、我国社会主要矛盾已经发生变化、两个一百年奋斗目标的战略部署、我国经济社会发展重大战略部署、坚定不移推进全面从严治党等八个方面，对党的十九大精神进行了宣讲。

王卫平书记强调，当前学院党委正通过党委中心组（扩大）学习会议等形式，带头深入学习、深刻领会、大力宣传、努力贯彻党的十九大精神。各党总支（直属支部）要按照《东莞理工学院城市学院党的十九大精神宣讲行动实施方案》，统一部署，分期分批组织全院师生集中学习，让大家真正领会党的十九大精神，并付诸行动，努力贯彻。

王卫平书记要求全院党员干部、师生员工在党的十九大精神指引下，认真做好本职工作，凝心聚力，推进学院的各项工作又好又快地发展。

会议还传达了《中共广东省委教育工委关于组织开展全省高校基层党建述职评议考核现场核查工作的通知》精神，要求各级党组织及有关部门做好相应的工作。

章德胜副书记主持了会议。
