# 中学校长为城院发展把脉支招

“城市学院招生工作，要与高考制度改革同步。建设特色鲜明的应用技术型示范院校的定位，非常符合现代化教育的规律及东莞的实际需要。”东莞市第五中学校长叶照伦建议城市学院尽快启动第二期工程建设项目，建设好实训实验楼。5月13日，我院诚邀东莞市中学校长召开座谈会，为学院的发展把脉支招。学院领导杨敏林、王卫平、章德胜、高香林到会听取校长们的意见与建议。

党委书记王卫平主持会议。他首先代表学院对各位校长的光临表示热烈的欢迎，感谢在招生等方面的工作支持。

院长杨敏林介绍了学院的办学定位和指导思想，近几年的办学概况及今后的工作展望。他恳请各位中学校长为办好本土高校出谋划策。

党委副书记章德胜在会上通报了城市学院2014年的招生计划及招生工作的新特点。

中学校长们在发言中表示，城市学院软硬条件好，师资力量强，办学定位正确，办学思路清晰，专业设置对路，教育教学质量稳步提高，学生就业创业意识强，受到东莞老百姓的认可，为东莞的高等教育事业作出了重要贡献。东莞有800万外来务工人员，其中子弟200万，城市学院要多招收务工人员的子弟入学，实现生源、课程、就业多元化。要整合办学资源开设新专业，专业设置要紧贴东莞的实际，多开办一些类似学前教育、音乐、美术、体育等方面的专业，为特长生提供出路。加强招生指导，扩招指标要向莞籍学生倾斜，确保东莞子弟有书读。学校人才培养目标的修订要与高考制度的改革同步，逐步扩大理工类招生比例，争取后续发展的主动权。加强招生宣传，多宣传毕业生就业创业的成功案例，促使打算在东莞就业的考生在东莞读大学，充分利用本地人脉资源和就业信息。要与行业和协会携手合作，共同培养实用技术型大学生。
