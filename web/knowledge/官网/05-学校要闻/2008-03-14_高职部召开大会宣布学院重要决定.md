# 高职部召开大会宣布学院重要决定

3月12日，高职部在部务会议室召开教职工会议。学院党委书记朱志德副研究员、院督学林世俊教授出席会议并发表了重要讲话。

人事处夏勇处长宣读了学院关于高职部主要负责人的任职文件。学院决定，院督学林世俊教授兼任高职部主任。

朱书记在讲话中希望高职部全体教职工在新的班子带领下，和衷共济，团结奋斗，努力工作，刻苦钻研，努力开创新的工作局面。

林督学表示，不辜负学院领导的期望，加强管理，关爱学生，抓紧建设，拓展功能，打造亮点，进一步办好高职部，为学院争光添彩。
