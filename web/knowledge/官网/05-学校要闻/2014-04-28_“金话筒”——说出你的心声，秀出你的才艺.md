# “金话筒”——说出你的心声，秀出你的才艺

4月16日，文传系承办的东莞理工学院城市学院“金话筒”主持人大赛海选赛，在叶畔湾门前拉开了序幕。

本次比赛的场地和形式都突破了以往的模式，不再局限于封闭的教室里，只有评委和选手们的单独“对望”，而是将赛场搬至公共场合，给参赛的“主持人”们一个真实的舞台，给观众一个“观战”的机会。

整个海选赛主要分为口头答卷和才艺展示两大部分。每一位参赛选手需抽取一道题目，再现场回答。选手们面对众多的观众，从容淡定地回答抽中题目和评委提出的刁钻问题。在才艺展示环节俄，大部分选手选择了唱歌和讲笑话的方式，悦耳的歌声，幽默有趣的表演，赢得了现场观众热烈的掌声。

本届“金话筒”主持人大赛海选赛采取现场报名现场比赛的独特形式，吸引了众多学生的关注和参与。
