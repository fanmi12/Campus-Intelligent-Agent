# 我校四件作品获全国高校校报好新闻奖

12月23日，中国高校校报协会公布了“2018年度全国高校校报好新闻”的评选结果，我校共获得好新闻二等奖3项、三等奖1项。

此次我校校报共报送了消息、通讯、图片、版面、新媒体五大类作品各1件参加评选，其中，《张超同学成东莞高校捐献造血干细胞第一人》（作者：张银辉、李小妹、肖泽鑫）、《我院举行2018级新生军训汇报表演》（作者：林嘉欣）、《@妈，您上城院官微啦！》（作者：莫玮娟 黄慧玲 陈怡晴）分别获得二等奖，校报第228-230期第2版获得版面类三等奖。
