# 艺术系谭绮娜同学获“欧洲?萨尔茨堡音乐舞蹈艺术节”古筝四重奏金奖、独奏银奖

我院艺术系2014级学生谭绮娜在今年暑期奥地利举办的“欧洲?萨尔茨堡音乐舞蹈艺术节”中，荣获古筝四重奏金奖及古筝独奏银奖。

据了解，此次艺术节作为一场国际性的艺术盛会，邀请到许多国内外的艺术名家担任评审委员，是由奥中文化交流协会及新加坡国际音乐舞蹈交流促进会共同主办的一个具有国际性、权威性及专业性的艺术节，主旨是为了推动东西方音乐舞蹈事业的发展以及促进文化的交流，为优秀的音乐人才提供展现自我的机会与空间，达成相互交流、进步与学习的目的。

谭绮娜同学在众多优异的选手及高标准的评选中，获得了优秀的成绩。
