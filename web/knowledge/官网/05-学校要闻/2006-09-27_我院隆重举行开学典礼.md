# 我院隆重举行开学典礼

“请同学们记住，拥有梦想，就拥有未来，拥有青春就尽情飞翔，尽情放飞你的梦想，不断地超越自己，追求卓越。”在开学典礼仪式上，院长安少华教授寄语新同学。9月25日下午，我院在田径场隆重举行开学典礼， 2006级新生开始了新的学习与生活。

会议首先向同学们一一介绍了在主席台就座的学院领导、各系处负责人和教师代表。在这些领导和教师中，有的是校本部东莞理工学院建院初期的老同志，有的是来自知名院校的名教授和博士，有的是享受国务院特殊津贴的专家。新同学李施施告诉记者，城市学院有这么多才华横溢的教师，是我们的荣幸。

院长安少华教授在典礼仪式上发表了重要讲话，向同学们提出了四点希望：一、希望同学们尽快转换角色，适应新环境，适应大学新生活。二、希望同学们学会做人，做一个真诚的人，一个具有社会责任感的人。三、希望同学们学会学习，培养创新精神。要在学习中学会发现，在生活中学会欣赏，在实践中学会创造，通过大学三四年的学习，积人文之底蕴，倡法制之文明，养浩然之正气。四、希望同学们学会做事，提升各种能力。要从小事做起，不断积累经验，锻炼独立的生活能力，提高独立选择、判断、处理问题的能力和应对各种情况与各种环境的能力。

文学与艺术系教师、刚从北京大学毕业的硕士研究生贾静波，管理系学生林颖胤分别代表新教师、新同学发言。

各系辅导员也分别与新同学见面，并作了自我介绍。
