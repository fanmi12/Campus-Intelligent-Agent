# 广东科技学院客人来我院访问交流

4月13日,广东科技学院投资方南博集团董事兼南博研究院院长谢小鹏一行3人来我院访问交流。副院长黄兢、刘玉侠及有关部门人员热情接待了谢小鹏院长一行。

黄兢副院长介绍了我院的基本情况，并陪同客人参观了校史馆。

双方还在行政楼505会议室就“科研管理及创新创业教育实践工作”及“东莞传统文化研究现状与发展”进行了交流、研讨。谢小鹏院长对我院的整体发展，给予充分肯定和高度评价。刘玉侠副院长表示，希望两校之间长期保持交流、学习，共同促进东莞高等教育发展。
