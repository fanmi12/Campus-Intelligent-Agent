# 发展联络中心主任杨光强拜会香港城市大学副校监梁乃鹏博士

发展联络中心主任杨光强（左3）拜会香港城市大学副校监梁乃鹏博士（左2）6月29日，我院发展联络中心主任杨光强赴香港拜会香港城市大学副校监、TVB副行政主席梁乃鹏博士，双方就我院与香港城市大学合作办学事宜进行了沟通。

据悉，祖籍东莞的梁乃鹏博士曾是东莞理工学院建校时的第一位捐款者。
