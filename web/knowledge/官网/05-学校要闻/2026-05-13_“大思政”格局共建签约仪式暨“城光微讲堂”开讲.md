# “大思政”格局共建签约仪式暨“城光微讲堂”开讲

为深入学习贯彻习近平新时代中国特色社会主义思想，全面落实立德树人根本任务，充分发挥社区党建育人主阵地作用，推动优质思政资源下沉社区、浸润一线，5月8日下午，马克思主义学院与学生社区党总支在智慧教室7C103联合举行“大思政”格局共建签约仪式暨“城光微讲堂”活动。校党委书记魏东初，校党委副书记、副校长康贤刚，党委办公室主任叶凯贞、学生部部长林蓉、马克思主义学院院长许修杰、马克思主义学院副院长向前、马克思主义学院党总支副书记刘军、马克思主义学院形势与政策教研室主任周琳、学生部副部长、团委书记范琪、学生部副部长、武装部副部长刘维仝、学生部就业与校友服务中心主任都振华等领导出席。马克思主义学院全体老师、学生部各科室负责人、各学生社区功能型党支部书记、辅导员及学生社区育人党支部入党积极分子代表参加活动。本次会议由学生综合事务管理中心主任詹海都主持。

活动伊始，校党委副书记、副校长康贤刚为本次活动致辞。他指出，“大思政”格局共建是学校深化思政教育改革的重要举措，对于服务学生成长成才具有重要意义。此次共建以社区为落脚点，打通理论教学与社区日常思政 “最后一公里”，是校社协同育人的关键一步。本次共建是学校育人工作的一件大事，承载着学校对思政教育创新的高度重视，希望“城光微讲堂”能够真正贴近学生需求，让同学们在课程中有实实在在的收获。

随后，在全场热烈的掌声中，马克思主义学院院长许修杰、学生部部长林蓉上台签署“大思政”格局共建协议并合影留念。本次签约标志着双方协同育人迈入新阶段，正式构建 “马克思主义学院 + 学生社区” 双轮驱动的思政育人共同体，将有力推动思政教育与学生工作深度融合。

签约仪式后，“城光微讲堂·铸魂篇”第1期正式开讲。马克思主义学院副教授周琳以《聚焦学生需求，打造有温度的形策课》为题带来教学分享。

她首先借助学习通平台邀请师生共同参与答题过程，在角色转换中体悟学生的真实需求。基于这一理念，她分享了育人案例，一名学生课后就时政问题向她请教并专程致谢，这件小事让她深感教师用心回应能留下持久印记。正是这种对学生个体需求的关注让形策课有了生命力，唯有教师备课紧扣学生脉搏、理论学习呼应现实关切，才能让下沉到社区的思政课堂真正接地气、有温度、见实效，让大思政格局真正接地气、有温度、见实效。

互动环节气氛热烈、交流坦诚。现场围绕前期征集梳理的社区学子思想困惑与成长疑问，开展面对面答疑交流。针对青年学子关心的 “十五五” 规划对青年成长成才部署、入党积极分子如何紧跟时代主动作为等相关问题，校党委书记魏东初作系统深入解读，立足国家发展大局，为青年学子明晰成长方向、校准理想坐标。

随后，与会师生围绕各类议题深入交流。校党委副书记、副校长康贤刚结合自身阅历与行业发展实例，生动阐释读懂政策、紧跟时代大势对青年成长成才的重要意义，分享通俗易懂、极具启发价值的人生感悟。

马克思主义学院副院长向前指出正确的政治立场与价值认知能够沉淀为个人综合能力，品德修养可内化为成长才干，青年要在日常学习生活中多体悟、多践行，做到融会贯通、知行合一。

校党委书记魏东初在总结发言中提到，构建“大思政”育人格局是落实立德树人根本任务的必然要求。此次共建打破了专业教学与学生思政的壁垒，实现了理论教学与日常思政的同频共振，更是推动思政资源系统性下沉社区、赋能社区党建育人的重要里程碑。他对下一步工作提出三点希望：共建共享让机制实起来、需求导向让课堂暖起来、协同育人让队伍融起来。魏书记强调，思政育人是久久为功的事业，要以共建为起点，汇聚合力，书写思政教育高质量发展新篇章。

思政力量下沉社区，协同育人涵养初心。本次活动标志着学校思政育人资源下沉社区一线，正式建立 “校院联动、社区主责、支部落实” 的思政育人新机制是推动思政教育扎根社区、浸润心灵、铸魂育人的重要起点。全体参会人员合影留念，活动在热烈的掌声中圆满落幕。
