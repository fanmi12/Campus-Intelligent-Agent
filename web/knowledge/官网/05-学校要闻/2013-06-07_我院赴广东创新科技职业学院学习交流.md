# 我院赴广东创新科技职业学院学习交流

为借鉴兄弟院校经验，提升我院党建工作水平，6月7日，院督学陈丁堂、院党委副书记章德胜率党委办公室主任黄兢、党委宣传部部长何鹏举等一行6人，赴广东创新科技职业学院学习交流，受到了党委书记麦韬芙、常务副院长李玉春、党委副书记郑士览的热情接待。

本次学习交流，重点考察了该校党务建设的先进经验，参观了校园，并与接待单位举行了座谈，详细了解该校党务工作日常管理、运行机制等方面的做法与经验。
