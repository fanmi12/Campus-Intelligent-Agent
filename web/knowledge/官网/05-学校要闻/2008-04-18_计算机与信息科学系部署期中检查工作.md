# 计算机与信息科学系部署期中检查工作

为迎接学院期中教学检查和教研室首次评估工作，4月17日，计算机与信息科学系在系主任办公室召开了系务会议，会议由系主任牛熠博士主持，全体系务委员参加了会议。

会上，牛熠主任对期中教学检查工作作了详细的部署和安排，宣布成立了以系领导、教研室主任、实验室主任为成员的期中教学检查小组，采取教师自查、分专业师生座谈、教研室内部互评、系内交叉检查等多种方式进行。他要求，部门负责人要充分重视期中教学检查工作，严格按照学院的要求进行检查，特别是对教师的教学进度、实验环节和作业批改情况要重点检查，解决存在的问题。各部门负责人对检查结果以文字形式向系务委员会汇报。

各教研室主任汇报了本教研室的评估情况。牛主任在总结讲话中充分肯定了各教研室主任在教研室管理工作中所付出的辛勤劳动，要求教师必须以教研室、院系工作为重，不计较个人得失，努力为学院的发展作出自己应有的贡献。各教研室主任表示，要“以评促建”，高标准，严要求，进一步加强教研室的建设与管理工作。
