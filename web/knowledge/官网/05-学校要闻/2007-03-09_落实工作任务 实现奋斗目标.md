# 落实工作任务  实现奋斗目标

今年的工作重点是什么？如何保证任务的完成？3月7日，学院在315会议室分别召开机关行政和教学教辅部门负责人工作会议，安排部署2007年的工作，以及完成任务的措施。东莞理工学院副院长、城市学院院长安少华教授在会上发表了重要讲话，学院党政领导就各自分管的工作讲了原则性的意见。

会议指出，今年是我院实施“上水平、创特色”战略目标的开局之年，全年的工作成效对实现学院可持续发展至关重要。最近，教育部批准我院增设6个本科专业，这对学院来说，既是喜事，更是压力。全院干部职工要变压力为动力，努力做好今年的工作。

会议要求，以可持续发展观为指导，制定城市学院发展规则、校园建设规划和学科与师资建设规划。重点建设好“一山”、“两湖”、一楼（图书信息中心的大楼）。

认真落实首届教学工作会议精神，进一步提高教学质量；全年争取引进10个教授和3—5个外籍教师，按比例配足本科专业的教授、副教授和博士，改变教师中中高级职称偏低的状况；继续开展青年教师讲课比赛活动，设立教师授课风尚奖；坚持用导师制培养青年教师；规范多媒体教学，定期组织教师观摩多媒体教学；教学管理人员每年至少公开发表5篇教学管理方面的文章；尽快制订实验室建设方案，今年重点建设物流和电子实验室；坚持互利双赢原则，开展校企共同建设实验室活动；推行院、系、教研室三级管理模式，将人权、事权、物权重心下移；探索合作培训师资的新途径，争取与兰州大学、天津理工大学合作办学签约成功；坚持以就业为导向的办学方针，用特色专业、特色课程、自编教材的办法，培养适合东莞社会经济发展需要的复合型应用人才；力争今年输送50名学生出国留学深造；加强基础性工作，逐步建立听课、教学活动、系务会议、实验室活动登记制度；学院研究与评估中心对教学工作要制订出评估项目和评估指标。

建立激励、问责机制，调动各方面的工作积极性。尽快制定出台新的分配办法，按民办院校机制运作，工作绩效与奖金、职称挂钩，拉开奖金档次；对一般性的工作失误，给予通报批评、扣发奖金和行政处分；院办和评估中心要尽快制订问责办法，并运用《工作简讯》的形式通报情况，做到一月一期。开展评选城市学院十大工作创新奖、校园十佳学生、十佳教职工的评选活动，并给予重奖。

宣传部、新闻中心，两块牌子一套人马。办好城市学院大讲堂，一周一次科学论坛，编写学院简介，拍摄反映学院工作的电视短片；继续办好新闻网，搞好对外宣传，提高学院的知名度。成立学院中心学习组，组织院领导班子成员定期进行理论学习。做好新党员的培训和发展工作。

院领导、各系部及机关各部门主要负责人要向“双代会”述职，接受民主测评，测评结果作为考察干部和年终评奖评先的依据。进一步活跃工会工作，畅通民主渠道，搞好教工福利，帮助教工和临工参加医保、社保。

成立学生宿舍管理办公室，配备专职的管理员，把学生管理工作延伸到学生宿舍；以大学生艺术团等社团组织为载体，广泛开展学风建设月、文化月、师生演讲比赛等文体活动。

依靠社会力量办学，发挥校友的作用；成立城市学院理事会，开辟校友网，创办校友联谊专刊；财务部门要尽快编制各部门财政预算方案，做好开源节流工作；设立治安内保干事，提高科技防控能力。

会议强调，全体教职员工特别是各单位、各部门负责人，要进一步转变思想观念，增强创新意识、团队意识、服务意识和参谋意识；要改进作风，加强政策法规的学习，提高领导能力和业务能力。各级党组织要充分发挥战斗堡垒作用，组织和带领教职工为实现全年的工作目标而共同努力。
