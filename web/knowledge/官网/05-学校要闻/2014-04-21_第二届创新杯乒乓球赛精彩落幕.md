# 第二届创新杯乒乓球赛精彩落幕

4月17日，为丰富校园文体生活，帮助同学们提高乒乓球的竞技水平，我院在乒乓球馆成功举办第二届创新杯乒乓球赛。本次比赛参赛选手都是2013届的学生，比赛项目分为女子单打、男子单打和男女混合打。

比赛选手势均力敌，现场气氛紧张激烈，其中最精彩的要数文传系与艺术系的男女混合双打。身着黄色上衣的艺术系选手在完美的配合下不断扣杀，屡占上风，连连得分。但是文传系的选手也不示弱，适好调整打法，使比赛进入了白热化的阶段，各种球技不断上演，使球迷们大开眼界，场内不时响起热烈的喝彩声。比赛结果，艺术系以2:11、11:6 、8:11的比分取胜文传系。

经过热烈的角逐，金贸系、财经系、管理系分列前三名。
