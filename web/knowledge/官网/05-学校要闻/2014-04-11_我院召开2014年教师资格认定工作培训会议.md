# 我院召开2014年教师资格认定工作培训会议

为做好2014年高校教师资格认定工作，4月10日，组织人事处在行政楼212室召开了2014年高校教师资格认定政策解答及网上报名系统培训工作会议， 33名教师参加了会议。

会上，师资科科长罗的庆总结了近几年我院教师资格认定工作情况，传达省教育厅今年召开教师资格工作会议精神，解读今年我省高校教师资格认定的相关政策，并就报送材料的整理及要求做了详细说明，对网上报名系统进行了演示培训。

据了解，广东省教师资格认定办公室要求，凡是参加资格认定的教师都需进行教育教学能力测评和体检。为此，组织人事处将对申报认定的各个环节进行指导与严格的监控，确保我院教师资格的认定与申报顺利通过。
