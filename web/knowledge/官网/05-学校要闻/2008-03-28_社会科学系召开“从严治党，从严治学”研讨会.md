# 社会科学系召开“从严治党，从严治学”研讨会

3月27日，社会科学系全体教师在410党员活动室召开“从严治党，从严治学”研讨会，会议由系党总支副书记石志民副教授主持。

系主任陈丁堂教授首先阐述了“从严治党，从严治学”的重要性。他指出，严是爱，松是害。我们必须从对学生负责、对教师负责、对学校负责的高度，充分认识党风教风学风的重要性。他进一步阐述了“严”的科学含义，认为严并不是通常所说的严厉或尊严，而是严谨、严格、严明、严肃。

刘杰教授以“严谨治学，自律他律”为题，从教师要专心、专注、专业于所教的课程，严肃对待他人的研究成果，以及如何形成良好学风的外部条件等方面，深入分析了大学教师应具备的学格、学品与学识。

赵书山副教授结合亲身经历，介绍了他对教师职业的认识和做人、做事的体会。他说：“做人可以低调，做事不可马虎”，教师对学生要严中有爱，爱中有严，严爱统一，才能使学生不断进步，他的讲话使大家产生了人格只能用人格培养，美好心灵只能用美好心灵塑造的共鸣。夏立明教授从自己所教《思想道德修养》课程的特殊性，谈论到党性与严谨治学的科学性。

研讨会中，老师们踊跃发言，各抒己见。最后，石志民副教授用“党性、人性、师德、师风密不可分”一句作结。

这次研讨会，使年轻教师进一步明了做人、做事、治学的辩证关系。
