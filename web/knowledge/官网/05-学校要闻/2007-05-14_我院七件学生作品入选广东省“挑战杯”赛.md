# 我院七件学生作品入选广东省“挑战杯”赛

第九届挑战杯广东大学生课外学术科技作品竞赛组委会通知称，我院有七件作品获奖。这些作品是：《可调节高度的高跟鞋》（作者：机电工程系符泽森），《磁控防水安全开关》（作者：计算机与信息科学系谭志强）《电子企业的优化改革问题研究》（作者：计算机与信息科学系肖巍），《ACTIVEX技术在WEBGIS中的应用》（作者：计算机与信息科学系潘亮），《东莞天乐家政股份有限公司的调查报告》（作者：社会科学系黎洁梅），《城市学院办学条件调查》（作者：社会科学系陈东汉），《珠江三角洲地区高校大学生就业特点调查报告》（作者：社会科学系梁聪敏）。参赛作品于5月16、17日在广州大学展出。
