# 思政部教师赴广东商学院参观交流

3月17日，院督学陈丁堂教授，宣传部部长、思政部主任何鹏举教授率思政部全体老师及部分宣传部成员赴广东商学院参观学习与交流。

广东商学院思政部张荣国书记、谭德礼教授等领导热情接待了全体教师。在座谈会上，谭德礼教授介绍了广东商学院思政部的基本情况。随后，双方进行了课程建设的交流，具体讨论了形势与政策课、中国近现代史纲要等课程的教学方法与手段、教学特色等内容。何鹏举教授向广东商学院的老师们介绍了部门的基本情况，并就精品课程建设、思想政治理论课教学存在的主要问题及如何提高思想政治理论课教学效果等与老师们进行深入的探讨和交流。

双方表示，希望在以后的教学工作中加强沟通交流，互相学习借鉴，取长补短，切实提高思想政治理论课的教学水平。
