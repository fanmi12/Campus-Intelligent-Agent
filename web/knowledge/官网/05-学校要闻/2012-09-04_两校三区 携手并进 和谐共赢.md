# 两校三区　携手并进　和谐共赢

9月2日，我院在莞城校区召开2009级、2010级的学生干部代表座谈会，听取同学们的意见。

东莞理工学院副校长安少华，东莞理工学院校长助理、东莞理工学院莞城校区管委会主任邢大立，城市学院党委副书记章德胜，东莞理工学院莞城校区管委会副主任王玉，东莞理工学院莞城校区临时党总支副书记丘永辉出席会议。

信守承诺：哪里入学哪里毕业

城市学院党委副书记章德胜首先向同学们介绍了城市学院办学主体搬迁到寮步校区的情况。章副书记表示，办学主体搬迁以后，学院仍将一如既往地关心大三、大四学生的学习与生活。从这一学期开始，我们对城市学院莞城校区的学生采取“属地、延伸”的办法进行管理。学院设立莞城校区工作部，负责莞城校区的学生工作和教务工作，其他工作则由东莞理工学院莞城校区管委会承担。学生处和各系部均有相关工作人员为同学们服务直至到毕业。

管理模式：“属地延伸”“5+1”

章副书记通报说，本学期开始，3700名东莞理工学院大一新生、4000多名城市学院大三、大四学生，将在这里学习与生活。为了加强莞城校区的管理服务工作，东莞理工学院决定成立东莞理工学院莞城校区管理委员会，下设综合办、学生办、教务办、总务办、财务办，以及与城市学院莞城校区工作部，共同管理好这里的日常工作。

副校长安少华：共创和谐共赢校园

东莞理工学院副校长安少华强调，无论同学们来自哪个学校，都是一家人，要和谐相处，互学相长，共同进步。同时，他对学生干部提出了三点希望：第一，把维护莞城校区的安全放在第一位。学生干部要帮助大一新生尽快适应莞城校区的生活，快乐学习，安全生活。第二，学生干部要有主人翁意识和维权意识。同学们对管理服务方面出现的问题，要及时向学校反映，并监督和跟进解决的过程。第三，继续发扬优良传统，传承校园文化。学生干部要做好表率，发扬优良的传统，改变不良的习惯，做一个合格的师兄师姐。要有整体意识、大局意识，形成合力，统筹兼顾。
