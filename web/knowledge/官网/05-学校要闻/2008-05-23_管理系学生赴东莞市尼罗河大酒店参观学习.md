# 管理系学生赴东莞市尼罗河大酒店参观学习

5月22日，管理系07级酒店管理专业一班共30名学生在吴雪梅老师的带领下赴东莞市尼罗河大酒店参观学习。

尼罗河大酒店是是管理系酒店管理专业学生的实习基地之一。同学们参观了酒店餐饮、娱乐、康体及客房等部门。参观的过程中，大家向该酒店人事部的万经理详细了解了酒店的管理机制、经营理念、组织结构、各层管理人员的权责范围以及其经营特色等，还观看了该酒店的宣传短片。

学生都说这是一次很好的认知学习。酒店方面表示，欢迎同学们多来参观实习。
