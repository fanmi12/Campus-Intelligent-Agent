# 我院获广东省艺术类招生单独考试资格

近日，广东省教育厅发出通知，确认我院广东省艺术类招生单独考试资格。据通知精神，城市学院在2010年广东省高考艺术类招生时，可对其音乐表演、舞蹈表演两个专业单独组织考试。该通知还指出，考生必须先参加城市学院的单独考试方可报考其相关专业。

据悉，单独考试时间定于3月13—14日，报名和考试地点在城市学院学生活动中心。音乐表演专业的考试科目有：声乐、器乐主专业各准备一个作品；视唱练耳（现场抽题）；综合素质（表演小品、形体舞蹈）。舞蹈表演的考试科目有：舞蹈剧目一个，基本功（跳、转、翻），即兴模仿（抽考，剧目自选）；视唱练耳（现场抽题）；综艺表演（演唱一首歌曲或演奏一个曲目）。
