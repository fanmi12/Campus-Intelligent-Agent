# 2012年值得珍藏的城院  新闻

一、城市学院获独立颁发学位权，17个本科专业全部获得学士学位授予权

广东省学位委员会文件《关于批准广东省独立学院新增学士学位授予单位和专业名单的通知》称，城市学院通过学士学位授予单位评审，17个本科专业全部获得学士学位授予权。

这次获得本科学位授予权的17个本科专业分别是：计算机科学与技术、软件工程、电子信息工程、机械设计制造及自动化、印刷工程、人力资源管理、工商管理、物流管理、会计学、表演、汉语言文学、英语、法学、行政管理、资源环境与城乡规划管理、国际经济与贸易、保险。

据悉，本次全省共有17所独立学院申报了304个本科专业，其中286个获得通过，城市学院等7所高校通过率为100%。

二、新生规模突破五千大关，新生报到率居全省同类院校前列

今年我院计划招生4967人，实际报到4659人，连同专升本345人，新生规模超过5000人。2012级新生报到率达到94%，超过了去年创造的记录，位居全省同类院校的前列。

今年是第二届新生在新校区读书，也是从今年开始城院不再招收专科生。金融与贸易系主任米双红教授表示，在全部招收本科生的新情况下，能达到如此高的报到率实属不易，这说明城市学院的教育教学质量和校园建设，得到了社会和家长的广泛认同。

三、城市学院办学主体顺利搬迁，教学管理大楼、教师公寓交付使用，各项工作平稳过渡有序展开推进

本学期之初，我院面临办学主体搬迁、一校两区、5000名大一新生入驻等新情况，教学、管理、保障工作难度加大，对各级领导和管理人员的能力与智慧是一次重大考验。学院党政领导在东莞理工学院党委行政和董事会的领导下，沉着应对，大胆决策，周密部署，职能部门协同配合，从而使搬迁工作平稳过渡，教学、管理、保障等工作实现整体推进。

四、世界著名物理学家、诺贝尔奖获得者杨振宁博士，当代著名书画大师范曾莅临我院签名赠书4月27日，杨振宁博士携妻子翁帆女士，北京大学博士生导师范曾来我院参观访问，为学生和图书馆签名赠书。周致纳、杨晓西、麦照容、黎建烨等领导陪同二位嘉宾参观了校园。

五、教学科研工作有新的突破。杨敏林教授、帅建华教授的科研课题分获国家自然科学基金、国家社科基金立项资助。我院获得广东省教育质量工程项目经费104万元

城市学院院长杨敏林教授为负责人研究的“低温余热除湿的分布式能源系统及其集成机理研究”科研课程，获国家自然科学基金立项。该项目为面上项目，国家拨付研究经费80万元。

管理系帅建华教授申报的课题“儒学的现代人本管理价值研究”，获国家社科基金“重点项目”立项资助，资助经费25万元。据悉，今年广东省获全国管理学科类“重点项目”的仅此一项。

六、广东省评估专家盛赞我院思想政治理论课建设，青年讲师王芳仪老师获广东省思政课青年教师讲课比赛一等奖6月5日，省教育厅组织中山大学、暨南大学、华南农业大学、广大工业大学、广州大学李辉、程京武、杨乃良、刘国建、罗明星等教授组成的广东省思想政治课建设评估小组来我院评估思想政治课建设工作。

评估组认为，城市学院是全省独立学院思政课建设的标杆单位，与全省普通本科院校相比也不弱，其经验可在全省推广。

9月15日，王芳仪老师从城市学院讲台登上了广东省思政课青年教师讲课比赛一等奖的领奖台。为了参加省赛，她利用假期备课3个月，查阅了大量的资料，制作了精美的课件，反复进行试讲。据悉，面对中山大学、华南师范大学等130所大学200名参赛选手，王老师不畏强手（其中不乏博士），沉着应对，脱颖而出，不仅进入了决赛（19人），而且最终还获得一等奖。

七、我院考研学生成绩骄人，一批学生分别以第一、二名的成绩考取中山大学、暨南大学、华南师范大学等名牌大学硕士研究生

今年，全院共有13名学生的总成绩到达硕士生录取分数线。其中，政法系李苏杰同学、城市与环境科学系赵晋宜同学的成绩分别排在暨南大学、中山大学相关专业全国考生的第一、二名，赵晋宜同学跨专业考取中山大学哲学专业。机电工程系有6名学生考取研究生，其中3人被全国印刷类顶级学校北京印刷学院录取。

据悉，政法系已连续三年有学生（于佩、汤文杰、李苏杰）的成绩位居中山大学、暨南大学相关专业全国考生中的第一名。我院政法系校友、华南师范大学法学专业硕士研究生于佩，也于今年考取美国南卫理工会大学博士研究生。

八、我院本科教学工作状态评估全面启动10月25日，我院在学术报告厅召开迎接省厅对我院教学工作状态评估动员大会，全面部署评建工作。院长杨敏林教授在会上要求，我们要聚全院之心、集全院之力，全面推进评建工作，切实把我院教学工作提高到一个新的水平，促进学校发展。

根据评估工作方案，我院设立评估指标为一级指标7个，二级指标22个，观测点44个。此次评估工作分为四个阶段进行，2013年6月之前完成自评。从11月14日开始，评建工作已进入第二阶段即自查与整改阶段。

九、我院男篮胜中山大学、广东医学院，获省十二届大学生篮球联赛甲组第三名

在广东省第十二届大学生篮球联赛中，我院男子篮球队一路过关斩将，力挫群雄，杀入甲组八强，并战胜实力强劲的中山大学队进入甲组四强，最终战胜广东医学院获得甲组第三名。

担任本次比赛的领队是体育教学部主任邢红林教授，教练是体育教师、前广东省女子篮球队队长钱丽娜。
