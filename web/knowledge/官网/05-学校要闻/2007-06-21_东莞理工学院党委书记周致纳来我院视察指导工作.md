# 东莞理工学院党委书记周致纳来我院视察指导工作

6月21日，东莞理工学院党委书记周致纳在东莞理工学院副院长、城市学院院长安少华教授的陪同下来到城市学院，专题听取我院图书信息中心、樟村教学生活园区、新校外学生公寓三项建设改造工程的工作汇报。院领导程发良、朱冰、张林及学院相关部门负责人在315会议室向周书记汇报了学院的工作。

会上，张林副院长向周书记汇报了图书信息中心工程重新启动的原因、变更的设计方案、造价估算和工程招投标等工作。汇报过程中，周书记不时地询问一些具体细节，并就工程的基本数据、结构安全等方面的问题同与会人员开展了讨论。

周书记说，城市学院的发展快形势好，大有可为。希望院领导以教学为中心，做好管理工作，进一步办好学校。对于工程建设要敢于放手，但不能撒手，一定要认真做好工程造价的预算以及质量安全工作。看准的问题要抓住时机，加快建设。发挥学院的体制优势，逐步改善办学条件和住宿环境，解除教职工的后顾之忧。

会后，周书记在院领导的陪同下，视察了樟村教学生活园区和新校外学生公寓建设改造工地。
