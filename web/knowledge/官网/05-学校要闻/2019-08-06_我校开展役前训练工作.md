# 我校开展役前训练工作

根据东莞市征兵办计划安排，8月3日起，我校在校内开展应征入伍役前训练。校后勤保卫处副处长、征兵工作站站长刘维仝以及征兵工作站凌继峰老师参训。

在训前动员会上，刘维仝首先感谢同学们踊跃报名应征，为保家卫国尽自己的义务。同时，他还介绍了目前部队的各种情况，并以自身在部队的经历鼓励大家。他讲到，作为当代大学生，把爱国之心化为报国之行，把热血挥洒在实现强军梦的伟大实践之中。他强调，征兵工作涉及

学校、学生的

切身利益，社会关注度高，大家

要切实提高法纪观念和自律意识，征兵工作开展以来，学校成立了廉洁征兵监督员，接受大家在廉洁征兵过程中的监督与投诉。凌继峰老师给同学们介绍了接下来的工作流程以及注意事项。
