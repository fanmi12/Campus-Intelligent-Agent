# 张佺举教授《物流管理》由北京大学出版发行

我院管理系主任张佺举教授主编的《物流管理》一书，近日由北京大学出版社出版发行。全书共60万字，分为15个章节。

该书定位于应用型本科的物流管理、物流工程专业的入门教材,也适用于其他经管类专业的物流管理辅修教材。书中对现代物流管理的基本原理和基本方法作了深入浅出的全面介绍,涵盖了物流管理最主要的几个方面。该书在编写体例上力求做到结构设计新颖、合理,书中每个章节的写作均以教学要点、导入案例、正文、小结、关键术语、知识链接、习题和案例分析作为主线编写，教学过程全部得到了展现。

该书由张佺举和张洪担任主编，王兴、洪树权担任副主编，参与该书编写的人员还有管理系赵影和杨娜老师。

据悉，该书被列入21世纪全国高等院校物流专业创新型应用人才培养规划教材。
