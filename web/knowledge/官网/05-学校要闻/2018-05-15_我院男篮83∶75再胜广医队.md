# 我院男篮83∶75再胜广医队

5月11日下午，在第六轮小组赛上，我院男篮客场对战广东医科大学队（以下简称：广医队），以83∶75取得胜利。

因天气原因，比赛在东莞理工学院举行。甫一开场，尽管广医队先发制人快攻拿下第一个进球，但我院男篮势如破竹，很快打出一波15∶0的小高潮。广医球队尽管奋力追赶，第一节仍落后20分。

第二节，我方乘胜追击，屡屡快攻上篮得分。广医队变现也可圈可点，25号白云龙更是在单节拿下12分。我院仍以43∶26保持领先优势。

易边再战，广医队经过调整手感炽热，一度打出9∶0的小高潮。但我方加强攻防力度，配合愈发默契，不断突破对方内线，最终以83∶75赢得了小组赛的第5场胜利。
