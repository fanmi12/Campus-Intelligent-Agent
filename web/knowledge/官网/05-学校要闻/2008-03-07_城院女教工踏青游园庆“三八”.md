# 城院女教工踏青游园庆“三八”

3月6日，风和日丽，春意盎然。在国际妇女节到来前夕，院工会组织全院女教工前往大王洲渔村踏青游园。

大王洲渔村四周环水，风光旖旎。阳春三月，桃花正艳，水面上一群群绿头鸭悠然自得地游水嬉戏。老师们走在田埂和乡间的小路上，呼吸新鲜的空气；或步入硕果累累的草莓种植园，亲身感受“收获”的喜悦；或踏入梦境一般的玫瑰园，当一回 “采花大盗”；或在田间地头仔细寻觅，寻找属于自己的“神秘礼物”。

晚上，大家欢聚一堂，共享晚宴。席间，党委副书记朱冰在致词中说：“今天我们走下讲台，远离城市的喧嚣，投入了大自然的怀抱，放松心情，欣赏田园风光。平日里，作为女教工，不仅要做好自己的本职工作，还要照顾家庭，非常辛苦。我代表学院感谢你们所做出的贡献，祝大家节日快乐。” 游园活动结束时，个个“满载而归”。
