# 军训花絮三：穿行在“蓝色海洋”

穿行在“蓝色海洋”的指导员们

——大学生记者 钟沛芬

放眼整个校园，到处都是穿着蓝色迷彩服的13级军训学员。在这“海洋”中，每天都可以看到辅导员忙碌的身影，他们不停地与各连队教官沟通、指导，督促着同学们认真军训。

“你们好，你们是记者团的同学吗？你们有空的时候去看看我们计信系的同学们好吗？他们在素质拓展，给他们拍拍照，鼓励一下他们。”一位年轻漂亮的女老师匆匆跑来说到。得到答应后，“那我先去看看别的同学了哦”说完，她又奔跑到蓝色的海洋里，看望别的同学去了。

记者游走在蓝色海洋里，看到一个连队的女生特别精神抖擞，走近一问才知道是4连的女生们。原来，她们每个人都把长发盘到了帽子里面，训练起来少了头发的阻碍。

“你们怎么都把头发盘起来了呢？看起来特别有精神啊！”记者好奇问到。“是我们苗姐要求的，她说有中式的，有韩式的盘发任我们选择，盘上去就好了，我也觉得这样很好看。”“苗姐？”——“对啊，听说今天下午苗姐又会来看我们了，今晚应该还会和我们一起拉歌吧。”说着，一位同样英姿飒爽的女子穿梭在蓝色海洋里，迎着风向我们走来，哦，原来是是4连指导员苗琳老师！

十四个连队角逐“宣传报道奖”

——大学生记者 蔡冰儿

随着军训工作的深入，各项军训评比活动陆续展开。其中军训团宣传部特设的宣传报道奖各连的角逐尤其激烈。

宣传部负责人余琼老师表示，各连队对此次评比相当重视，参与的热情亦十分高涨。军训次日，便收到各连送来的军感悟4000余篇，其中更不乏来自教官和指导员老师们的优秀稿件。评比活动将持续到本月12日，宣传部每日都会对稿件进行筛选统计，分为“一般、良好、优秀”三个等级，并按阶计入连队军训总分，作为评比的指标。

据悉，宣传报道奖的评比以连为单位进行，依据各连送交稿件的数量多少、稿件的质量优劣和被选用照片的数量，最终评选出一等奖1名，二等奖2名，三等奖3名。优秀的稿件还将会在足球场对面的各连队宣传展板上展出。军训团宣传部负责人希望同学们在军训中都能有所获得，有所感悟，得到成长，用文字稿件与大家分享军训的心得体会。

军训感悟摘抄：“身体虽然疲惫，但我们的心还是暖的。因为我们有他——郑教官。他做事有自己的原则，有自己的底线，记得他总爱强调的几句话：‘训练的时候就得有训练的样子，课间就得有课间的样子。’‘整齐’ 、‘礼仪、礼貌和作风……’这些我们都铭记在心，不仅是在军训受用，更适用于我们的日常生活。” ——七连 彭标元“清晨，气温依旧微凉，我们早早地起了床去进行早训，路上满是军绿色的风景。一张张笑脸写满了期待，迎着太阳升起，我们辛苦而开心的训练正式开始了。” ——五连 邓洁萍“迷彩是我喜欢的混合色，它犹似一个天性的装扮师，平凡略显娇弱的我们的脸上无形中增添一些英武。我在想，一些迷彩的生动为我们的天空增加了无数艳丽的色彩。今天我又一次穿上迷彩服，开始了我第二‘号’的军训之旅。” ——四连谢玲玲“我开始喜欢上站军姿的感觉，那种挺拔总会给我一种自信，一种由内而外的骄傲。而也是在那时，我体会到了对军人最重要的——荣誉。我是光明磊落的，是一种正气。而训练我们的教官也是可亲的，看着他们并不大的年龄，却有一种让我羡慕的经历。”——周舒扬“训练过程中，在太阳下抬头挺胸，纹丝不动的军姿依旧会惹来久违的汗水，这种汗珠划过鼻子尖的感觉让人不住想伸手去擦拭，但意志力下的忍耐还是成功弹去了不适。因为我知道，我现在身着军服，就必须严格遵守军训纪律，学着做一名‘大学生临时军人’。” ——四连 陈泽鑫

内务检查来啦

——大学生记者 孙钰银

“你们都给我听好了，回去该洗的洗该擦的擦，都别给我闲着！”军训第三天，13级军训学员们接到了一项重要的任务，那就是内务整理。

内务整理可谓是军训中的“必修课”，教官们直接在操练场上给学员们演示叠被子。看着教官们把被子摊平﹑分界，把两边向中间靠拢折起，最后拉直四个被角。这些动作一气呵成，叠起的被子就像豆腐块那样规整，引得学员们拍手叫好。

内务评比除了检查基本卫生，还要求规整。学员们队列训练后回到宿舍，忙着拖地板﹑擦门窗﹑洗厕所，连风扇和空调的灰尘都不放过。

教官说了“军队里的内务管理要求严格，而军人每天都坚持着军容。城院的军训学员们也很努力，做好内务整理。

面对记者的采访，八连四排的柴同学说道，“今天把宿舍整理得很好，连水池都刷得干干净净的，以后也要保持这么干净。”

患病见真情 文传递温暖

——大学生记者 肖田佩

四连的训练场地附近怎么围着一群人？原来是刘佳怡同学发现叶易凌不对劲，不一会儿她已蜷成一团晕倒在地。其他同学见状便快速围上去。颜萍萍同学在一旁急得乱叫：“她都已经晕倒了，赶快送医务所！”在这紧急时刻，数媒班男同学周鹏达过来帮忙，一个“公主抱”，将患病同学送往医务所。只是这英雄救美没有救到底，抱到半路该男生便支撑不住了。于是又有一位男同学挺身而出，接着抱起她，几经周折，叶同学终于到达了校医室。在等待校外救护车的过程中，叶易凌全身发冷，两个女生为她急的哭了出来。抵达中医院后，苗琳老师也及时赶到现场并安抚同学们的情绪。经过专业医生的诊断，叶易凌同学很快就好了，又回到军训队列之中。

军训中独特的拓展训练

——大学生记者 陈欣茹

今天在城院的篮球场中,四连的四个排分别分成了六个队,共同来完成2013新生军训素质拓展训练。

在平日紧张的训练时间中安排的素质拓展训练，对于大家来说都特别新鲜。其中“旋风跑”就是这样一个有活力有意义的游戏。“旋风跑”顾名思义就是跑起来。身穿黑色运动服的指导员在分别带领六个队熟悉游戏规则之后，一队已经做好了分工的准备。

各组成员屏气凝神，在白线之后扎好马步，每组成员共同抓紧一根红色的木棒，像一只只准备冲锋的战马。一声号响，第一组已经冲出去了，身前红色的木棒稳稳地握紧，脚步不停地交换着，围着第一个“木桩”跑完一个圈之后，场外的队员激动的满脸通红并不停地为她们加油打气“一队加油，一队加油！”，游戏就在这样紧张的气氛中结束了。

游戏结束后，一队以6分41秒的成绩获得了这场游戏的冠军，她们的队长说到：“其实在游戏中我们都是互不相识的人，但是我们却都有着一个共同的目标，为集体的荣誉而战，军训中的拓展训练或许就是为了教会我们像横幅上写的‘挑战自我，熔炼团队，完善人格，陶冶情操’这个道理吧！

自律自强自觉的军训

——大学生记者 陈欣茹“四连四排的小伙伴们集合了!”

一大早当你在湖边散步时,肯定会被这一句独特的声音吸引住而不由自主的望向桥边。只见四连四排的女生们都自觉的从湖的两旁迅速集合到一起，认真整好队伍。同时她们把各自的长发都裹在帽子里面，整个队伍就带给人一种精神抖数的感觉。

挺拔的军姿，自信的脸庞，闪亮的目光，她们挺起胸膛，把手自然的垂在身侧，脚跟并拢脚尖向前打开60°，站直身板。或许有人认为她们正在训练，其实这是4排的女生们在教官没来之前，自觉地站好军姿等待着教官的到来。

班长张淑芳说到：“军训就是为了让我们学会挑战自我，自律自强。在这之前我们就该学会自觉，有了自觉性我相信我们会做的更好更加出色。”

军训感悟

——大学生记者 钟沛芬

暖暖的冬日里，阳光下。13级新生们开始了他们的军训之旅，与他们同行的还有潇洒帅气的教官们和认真负责的指导员们，这次军训带给他们的是不一样的收获，不一样的感悟。

十三连 学生 梁彩婷：从教官身上感受到温暖

我看见了自己的教官，他只比我们大两岁，一个内向的大哥哥。在他身上我感受不到疏远，取而代之的是一种温暖。除了对我们进行严格的训练外，在休息的时候，他会和我们在一起，陪我们聊天，回答我们的所有问题。他用自己的亲身经历，让我们明白了许多道理……军训中我们都学到了许多课本上无法学到的东西。

四连 学生：欧阳红彦腿受伤了却心系归队

我不想错过军训里的每一个细节，哪怕是无聊的，难受的，辛苦的。亲眼看见他们训练总觉得有特别亲切的感觉……我却因脚伤无法归队，像个局外人一样，无法融入他们……我也想站在军训的队伍里和大家一起哭，一起笑。

八连 郝连长：与学生共享大学里的快乐时光

来到这里，我和同学们一起完成党和国家交给我们的必修课，很高兴。实际上，这也是在和同学们分享他们大学里的快乐时光，我们一起拉歌，一起游戏。

四连 指导员苗琳：欣喜能够成为老师伴随学生训练

望着他们一张张年轻而又饱满的脸庞，犹记起自己当年那些学生时光……我依旧内心欣喜，欣喜自己在时空转换间，成了一名可爱的老师，欣喜自己每日的生活里能够伴随一群朝气蓬勃的学子。陪伴他们训练，看着他们成长。
