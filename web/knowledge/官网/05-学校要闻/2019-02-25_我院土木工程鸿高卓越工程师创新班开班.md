# 我院土木工程鸿高卓越工程师创新班开班

2月24日下午，我院2018级土木工程（路桥方向）“鸿高卓越工程师”创新班举行开班仪式。广东鸿高建设集团有限公司常务副总经理李丰收、行政人事部经理张红杰、技术部经理吴连雄、工程经济管理部经理谢清福、行政人事部副经理胡文进、曾叶平，我院副院长高香林、城环系主任肖红飞教授、教务处副处长赖忠孝等领导，以及城环系教师代表参加了开班仪式。

胡文进副经理对学院的信任表示感谢，并表示鸿高集团将全力支持推进创新班建设，培养出更多的建筑工程行业优质人才。

土木工程教研室主任兼创新班班主任刘波博士希望同学们严格要求，珍惜机会，好好学习，天天向上,全面展现创新班优良的风貌。

学生代表张广俊同学表示会严格自律，努力学习，满怀自信迎接未来的学习生活，在新学期里争取得更大的进步。

李丰收副总经理分析了未来行业发展，介绍了创新班的优势，增强了同学们对创新班的建设和未来发展的信心。

高香林副院长对创新班的成立表示热烈祝贺，希望同学们把握好机遇，努力学习，将所学运用于实践，锐意改革创新，为未来的就业和事业发展奠定厚实基础，为校企合作办学树立典范，为师弟师妹们做出榜样。
