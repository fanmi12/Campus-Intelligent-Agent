# 我院新进教职工顺利完成岗前培训

7月13日，我院18名新进教职工来到华南师范大学，参加由广东省高等学校师资培训中心举办的2014年广东省高校教师岗前培训。

通过为期15天的岗前培训,我院新进教职工系统全面的学习了高等教育学、高等教育心理学、高等学校教师职业道德修养、高等教育法规概论等高校教师入职所需的必备课程,有效指导我院新进教职工在今后的工作中掌握如何树立先进的教育理念，如何培养崇高的职业理想、良好的职业道德、必备的学术规范与心理素养和更多的教学教育技能等多项教育教学方法，为其今后的教师生涯发展奠定良好基础。
