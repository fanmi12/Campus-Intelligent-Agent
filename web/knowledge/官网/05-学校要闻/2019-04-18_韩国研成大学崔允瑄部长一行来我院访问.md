# 韩国研成大学崔允瑄部长一行来我院访问

4月17日下午，韩国研成大学国际交流部长崔允瑄一行莅临我院访问交流。

学院副院长周庆、国际交流中心负责人陈峰等热情接待了客人，并陪同客人参观了校史馆及校园。双方还对本科“2+2”项目、短期交流项目等进行了洽谈。

据了解，研成大学成立于1976年，是一所四年制的大学。学校以“ACTIVE21”为发展战略目标，以培养高素质的应用型高级专门人才为教学目标，向社会培养和输送具有创新精神和竞争能力的专门技术人才。
