# 院、系领导视察开学与学生返校情况

2月16日是开学第一天，校园处处又闻朗朗读书声。第一节课铃声刚响过，程发良副院长和教务处处长邓成良教授深入各教学楼，视察上课情况，他们对教师的授课状态和学生的学习态度表示满意。

2月15日晚上，党委宣传部部长何鹏举副教授、金贸系系主任米双红教授、系党总支书记龙卫洋博士、辅导员及各班班主任，分别到校内学生公寓、校外学生公寓、东升学生公寓、樟村学生公寓看望了返校学生。他们每到一处，都详细询问学生的开学准备情况，了解宿舍生活条件。老师们还认真核对了各班学生的报到情况，对尚未到校学生一一问明了原因。米主任叮嘱同学们，返校后要赶快“收心”，调整心态，迎接新的学习任务。

据悉，当晚，各系部领导、辅导员、班主任也分别深入宿舍看望了本系的同学。
