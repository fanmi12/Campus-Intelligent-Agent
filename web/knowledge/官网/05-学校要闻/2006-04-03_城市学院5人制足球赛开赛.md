# 城市学院5人制足球赛开赛

3月30日下午，我院5人制足球赛在学院足球场拉开了帷幕。本次足球赛旨在检阅我院足球成绩、丰富校园体育活动、培养同学们的团结协作精神。

尽管当时天色灰暗，大雨即将来临，但丝毫没有影响同学们观看球赛的热情。赛场上队员们健步如飞，运球自如，不时地踢出了一个个好球，获得同学们的阵阵掌声。观看球赛的同学们被精彩的场面感动得热情洋溢，加油声、欢呼声和掌声在赛场上此起彼伏，交汇成一首动听的乐曲。今天共进行了五场球赛。

据悉，本次足球赛共有38支球队参赛。通过循环赛决出前18名，赛期12天，4月13号举行冠亚军决赛。
