# 我校隆重举行国学馆揭牌仪式

11月20日下午，我校大力打造的国学馆在文学与传媒学院隆重举行揭牌仪式。

出席活动的嘉宾有：广东省作家协会主席、原暨南大学副校长、党委书记蒋述卓教授，西安书学院院长、中国书法家协会会员董建平先生，腾讯大粤网东莞总编辑、原东莞日报报社副社长谭军波先生，东莞快创信息科技有限公司董事长安伟先生，潇湘文化传播有限公司总经理罗建云先生。校领导高香林、黄兢、周庆、刘玉侠、林江龙，以及有关部门负责人、各二级学院领导等出席了揭牌仪式。

文传学院院长宋秋敏致辞表示，国学馆的建成将为文传学院国学文化类课程教学科研提供了颇具特色的实践场所，为文传学院开展传统文化和地方文化讲座、沙龙提供了专属空间，进一步推进我校对中华民族优秀传统文化的传承。

周庆副校长在讲话中表示，国学馆的建设是我校美育教育工作的一项重要举措，也为广大学子们搭建了一个文化展示平台，让学子们从眼观、耳听切身感受传统文化，从而感受国学文化给予的学术力量，进一步增强广大师生对传统文化的自信和对中华民族的自豪感。学习人文知识能倍添人格魅力，借助国学馆的建成，国学之风、中国文化之风将会吹向校园的每一个角落，让校园国学文化和美育教育焕发出勃勃生机。

揭幕仪式上，文传学院吴士田老师和陈徽音、张洁蕾、甘博等同学还奉上了《寒鸦戏水》《汉家礼仪》《滚滚长江东逝水》等颇具国学韵味的才艺表演，让在场嘉宾感受到文传学院浓厚的国学文化底蕴和文传学子主动学习、传承文化的精神。

与会嘉宾为国学馆进行了揭牌。

蒋述卓教授表示，国学是中国文化的血脉，是历史的记忆；传统文化是建设中国特色社会主义基础、动力、源泉；文化自信是最基础、最深远的一种艺术。对我校国学馆的未来建设，蒋述卓教授送上了良好的祝愿。
