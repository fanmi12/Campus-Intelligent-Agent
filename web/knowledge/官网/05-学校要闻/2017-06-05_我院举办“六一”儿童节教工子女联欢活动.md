# 我院举办“六一”儿童节教工子女联欢活动

6月3日，学院工会为庆祝“六一”国际儿童节，在学术报告厅举行了“我的节日我来秀”——迎“六一”儿童节教工子女联欢活动，丰富多彩的演出展现了我院教职工子女们的多才多艺和童真童趣。

五彩缤纷的气球、彩带装饰着绚丽的舞台。随着音乐伴奏的缓缓流淌，身着节日盛装的孩子们倾情地展示自己的才艺——有翩翩起舞、活力四射的舞蹈表演，有美妙悦耳、余音绕梁的歌唱表演，有绘声绘色、生动形象的讲故事表演，更有各种精彩的乐器演奏，让观众叹为观止，掌声不断。

活动还为孩子们的绘画书法作品举办了展览，有欢度“六一”，也有童真世界；有中国风的水墨画，也有西方多彩的油画，展现出了城院子弟天马行空的想象力和精湛的绘画功底。

活动还评出多个奖项，对才艺表演、画作优秀的孩子们颁发礼物，让孩子们度过一个美好难忘的节日。
