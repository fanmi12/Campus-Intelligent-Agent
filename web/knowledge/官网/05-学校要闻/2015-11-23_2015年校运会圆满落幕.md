# 2015年校运会圆满落幕

11月20日下午，历时两天的2015年校运会在完成各项赛事后圆满落幕,并刷新了三项校运会纪录。

经过两天激烈角逐，文传系和后勤队并列教工组第一名，城环系、教工机关一则分别位居教工组第二、三名；在学生女子组中，金贸系、财经系、文传系分获前三甲；在学生男子组中，城环系、金贸系、管理系囊括了前三名；在学生组团体总分上，金贸系再次不负众望，第8次夺取了校运会学生组团体总分第一，蝉联“八连冠”，而管理系、财经系则分别摘取了亚军和季军桂冠。此外，文传系和财经系分获体育道德风尚奖，而新增的最佳入场式创意奖则由管理系摘取。

据了解，本届校运会共有8名女同学打破三项目校运会纪录：文传系江嘉玲同学打破了女子200米校运会纪录；金贸系吴晓苹、财经系廖雅芬、陈芷欣同时打破女子800米校运会纪录；金贸系4名女同学打破4x100米校运会纪录。这三项破纪录都诞生在学生女子组中，这也证明我院女生体育教育方面取得长足发展。

在2015年校运会闭幕式上，王卫平等院领导及各系部主任、各部门负责人出席了闭幕式，并为获奖集体和运动健儿颁奖。
