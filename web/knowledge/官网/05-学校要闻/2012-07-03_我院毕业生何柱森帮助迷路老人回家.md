# 我院毕业生何柱森帮助迷路老人回家

6月28日，我院金贸系2012届毕业生何柱森同学等3名同学，在吉之岛回学校的路上发现了一个老人蹲在地上，一只脚受着伤，身体很脏，浑身发臭，旁边还有个大袋子，但神志清醒。看着老人一个人在街边，很可怜。于是，他忍不住问老人家住哪里。老人告诉他自己从肇庆出发，想去番禺找儿子，在车上钱包和行李被抢，颠簸走到了东莞。何柱森立即买了面包和水给老人，并问清老人的姓名、住址和亲人的联系方式等详细信息。回到学校后，他先是联系了肇庆派出所，然后又发了微博帮助老人寻找亲人。

第二天早上，肇庆派出所还是没有任何消息，何柱森等不及了，一早过来看望老人。老人告诉了他的儿媳妇在番禹一家模具厂上班。问清楚名字后，何柱森通过网络顺利找到了那家模具厂并通过人事部找到了老人的儿媳。他拨通电话让老人和儿媳妇联系，并垫付了300块钱打的送老人安全到家。

事后，老人的儿子酬劳何柱森，他拒绝了：“看到爷爷能平安回家就放心了，不用谢!”
