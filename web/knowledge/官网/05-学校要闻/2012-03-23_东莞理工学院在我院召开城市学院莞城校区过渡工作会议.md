# 东莞理工学院在我院召开城市学院莞城校区过渡工作会议

3月22日，东莞理工学院在我院4315会议室召开城市学院莞城校区过渡工作会议。会议宣布成立东莞理工学院城市学院莞城校区过渡工作领导小组，以及7个工作小组。东莞理工学院党委书记周致纳要求各工作小组和城市学院各单位要密切配合，做到过渡工作与学院日常工作两不误。

东莞理工学院党委书记周致纳，校长杨晓西，党委副书记吕琦元，副校长安少华、邹晓平、戴炳源、李忠红以及有关部处领导，市人资局、市财政局、市国资局、市审计局有关领导出席会议。东莞理工学院城市学院全体中层干部与会。会议由吕琦元副书记主持。

会上，校长杨晓西宣读了《东莞理工学院关于成立东莞理工学院城市学院莞城校区过渡工作领导小组的通知》（莞工［2012］4号）文件。并指出，城市学院搬迁是全市上下、师生员工关注的大事情。成立过渡工作领导小组，是为了保证国有资产安全，保证城市学院顺利过渡，维护师生员工的共同利益。

副校长、城市学院院长安少华在会上指出，城市学院过渡工作责任重大，任务艰巨，时间紧迫，他要求城市学院各职能部门积极配合支持，将任务逐项落实到人，使过渡工作有条不紊地开展，确保适时平稳有序过渡。

周致纳书记在会上讲话。他说，城市学院八年办学成果丰硕，这是东莞理工学院党委行政、城市学院全体教职员工共同努力的结果。为了贯彻落实教育部26号令，更好地适应东莞市提出的高水平崛起的战略要求，东莞理工学院决定成立城市学院莞城校区过渡工作领导小组。他强调指出，过渡期间，各部门、各单位要做到过渡工作和日常工作两不误。全体教职工要顾大局，求实效，谋求城市学院新发展。各党组织要发挥政治堡垒作用，党员干部要带好头，在过渡工作中发挥党员模范带头作用。

据悉，过渡工作领导小组下设七个工作小组，即：综合组、教学组、学生组、人事组、资产组、财务组、审计组。
