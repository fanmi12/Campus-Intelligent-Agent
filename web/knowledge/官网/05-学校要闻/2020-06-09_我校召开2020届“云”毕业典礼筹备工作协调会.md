# 我校召开2020届“云”毕业典礼筹备工作协调会

6月9日，我校召开2020届“云”毕业典礼筹备工作协调会，对“云”毕业典礼筹备工作进行部署。校长王卫平、党委书记章德胜和有关职能部门负责人及二级学院院长参加了会议。会议由党政办主任孔增强主持。

在全国人民共同抗击疫情并取得重大胜利的形势下，举办“云”毕业典礼对学校和毕业生都具有特殊的意义，既可以让同学们尽情抒发对美好大学时光的依依不舍和对母校的感激之情，学校也可以借此机会对每一位毕业生的人生启航之旅送上深深的祝福。会上，宣传部副部长苗琳通报了“云”毕业典礼的整体部署情况，以及各教辅机关的分工和总体工作任务与筹备安排。

校长王卫平、党委书记章德胜强调“云”毕业典礼是学校一项非常重要的工作，各部门和二级学院要高度重视、紧密配合此次筹备工作，做好各项准备，确保“云”毕业典礼的顺利开展。
