# 著名音乐家罗艺峰教授受聘我院客座教授

9月26日，西安音乐学院副院长、著名音乐学家、博士生导师罗艺峰教授受聘我院客座教授。

受聘仪式后，罗教授围绕课程设置、论文撰写、对唐代音乐的探讨等学术理论问题与艺术系教师交流座谈。

当晚，罗教授在五号阶梯教室为艺术系师生做了主题为《谈当代艺术教育的几个问题》的学术讲座。罗教授以生动的语言和案例，为师生们解读了自己对古典音乐智慧的追寻与思考，内容涉及当代艺术教育综合的性质、音乐的文化及美育的民族化。罗教授勉励师生要关注古典音乐，复归民族价值。

据悉，罗艺峰教授长期从事音乐美学、音乐人类学和中国音乐思想史的教学和研究，获得过国家级、省部级以及高校间横向科研课题多项，是进入马来西亚婆罗洲热带雨林进行人类学考察的第一位中国音乐学家。曾获国家级教材二等奖（《音乐鉴赏》,合作,任副主编）、陕西省高等学校人文社会科学研究一等奖（《音乐人类学的大视野》,合作,为第一作者）、陕西省艺术科学研究一等奖（《中国西部音乐论》）和省政府高等学校教学一等奖（音乐美学） 。
