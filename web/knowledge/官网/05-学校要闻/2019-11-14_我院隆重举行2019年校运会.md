# 我院隆重举行2019年校运会

11月14日-15日，我校2019年校运会在田径场隆重举行。

14日上午，校运会举行了隆重的开幕仪式。王卫平、章德胜、高香林、黄兢、周庆、刘玉侠、林江龙等校领导和各部门、二级学院负责人，以及裁判员、运动员、师生代表等出席了开幕式。

随着运动员进行曲的指引，步伐矫健、神情庄严，高擎着五星红旗的国旗护卫队昂扬迈入会场，开幕式拉开了序幕。

鲜花方阵、彩旗方阵、裁判员方阵、各二级学院运动员方队、教工方阵、勤方队等依次通过主席台前，大家精神饱满、昂首阔步，即将以积极进取、勇于拼搏的精神投入体育竞技之中。

在庄严的国歌声中，五星红旗在田径场上空冉冉升起。

高香林副校长在致辞中表示，本届运动会的主题是“运动彰显力量，激情放飞梦想”，是我校开展“不忘初心、牢记使命”主题教育在体育工作上的延伸，是检阅我校体育教学工作，展现全体师生精神风貌的一次良机。他强调，体育工作是学校精神文明与校园文化建设的重要一环。希望全体运动员发扬“更高、更快、更强”的奥林匹克精神，赛出成绩，赛出风采。希望全体裁判及工作人员恪尽职守，力争将本届运动会办成一个“团结、有序、精彩”的体育盛会。

运动员代表、裁判员代表先后宣誓。运动员将遵守纪律、尊重裁判、尊重对手，裁判员将做到认真、公平、公正、公开，文明裁判，确保运动会顺利进行。

王卫平校长随即宣布“2019年校运会”正式开始。

在动人的乐声中，由二级学院组成的啦啦队开始了精彩纷呈的文体表演。大型团体操表演，城院学子用优美的舞姿共同演绎一曲“我和我的祖国”，用青春告白祖国，用青春告白学校。太极、跆拳道、瑜伽等表演刚柔并济、美轮美奂，彰显了城院学子的青春活力，体现了我校在体育教学中取得的丰硕成果。在健美操表演中，演员们踏着青春的节拍，整齐划一的动作，蔚然壮观的视觉效果征服了现场的观众，将开幕式的气氛推向了最潮。

随后，运动员、裁判员和工作人员投身到了为期两天的精彩赛事之中！
