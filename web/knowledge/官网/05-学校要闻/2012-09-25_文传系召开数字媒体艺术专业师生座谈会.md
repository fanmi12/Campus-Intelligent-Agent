# 文传系召开数字媒体艺术专业师生座谈会

数字媒体艺术专业经过三年多的办学，效果怎样，学生怎么看？9月24日，数字媒体艺术专业师生召开座谈会，就这一问题展开讨论。出席会议的有系主任邓星明教授、系副书记、教研室主任、教师代表以及2009级学生代表。

会上，学生们就这几年来的专业学习谈了自己的体会，普遍认为数字媒体艺术专业确实是一门非常适应社会发展的好专业，希望学校能加强对该专业的投入和建设。同时，同学生也就课程设置、师资力量、上课方式、专业发展、就业方向等问题，提出了自己的想法和建议。针对这些，系主任邓星明教授及专业教师都进行了耐心解答，并提出了一些具体解决办法，同时希望同学们要积极调整心态，找准个人定位和发展方向，在专业方面发展的更高、更深、更远。
