# 商务部吴国华副司长莅临我院讲学

9月5日，国家商务部流通发展司副司长吴国华教授在莞城校区为师生们解读“国家促进民营企业和小微型企业发展的政策”。

吴国华教授分析了我国上半年的经济形势，指出在投资、消费和出口“三驾马车”的拉动下，我国经济增长“稳中趋稳”，但由于国际金融危机和欧债危机的影响，全球经济放缓，一定程度上也阻碍中国经济的发展。在此背景下，东莞经济也受到较大的影响。东莞经济主要依赖出口，且东莞的企业多为小微型企业，随着人民币的升值、贷款利率升高，产品的生产和出口难度加大，民营企业和中小微型企业的生存更为不易。

吴国华教授还具体分析了国家为促进民营企业和小微型企业发展而出台的政策。包括加强和改善宏观调控；加强税费改革，扩大对小微型企业实行减半征收营业所得税的范围；鼓励小微型企业从事绿色、节能产品的研发和生产，并给予财政支持；鼓励银行等金融机构向小微型企业提供贷款，解决小微型企业融资难、贷款难的问题；培育和支持小微型企业创业基地，更好地为小型、微型企业服务。

吴国华教授鼓励同学们把握机会，好好学习，为自己的未来做好规划，毕业后无论是就业还是创业，都能创造美好前程！
