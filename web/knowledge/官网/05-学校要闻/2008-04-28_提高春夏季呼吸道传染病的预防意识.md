# 提高春夏季呼吸道传染病的预防意识

每年的春夏季，由于气候变化使各种细菌、病毒的繁殖加速，各种传染病的发病率也大量增加。为此，学院医务所提醒广大师生，要养成良好的卫生习惯，增强呼吸道传染病的预防意识。

医务所万玉君医生告诉记者，常见的呼吸道传染病有流行性感冒、麻疹、水痘、风疹、流脑、流行性腮腺炎、猩红热等，在高发期，应适当采取一些综合性预防措施，如：适时开窗通风，保持室内空气新鲜；尽可能不要到人多拥挤的地方去，如必须去，最好戴上口罩；养成良好的卫生习惯；根据天气变化适时增减衣服，避免着凉；按计划免疫的要求，按期接种相关的预防疫苗。除此以外，大家还要经常锻炼身体，保持均衡饮食，注意劳逸结合，提高自身抗病能力。

万医生特别提醒老师和学生，如果有发热、咳嗽等症状，应及时到医院检查治疗，不要随意购买和服用药品，特别注意不要滥用抗生素。当被确诊为传染病时，应主动报告医务所，并与健康人群隔离，尽量不要去公共场所，防止传染给他人。

据了解，为提高传染病预防意识，学院除了在校道宣传栏刊出预防流感常识外，还专门拨款7000余元在各饭堂免费供应预防流感的凉茶，供师生饮用。
