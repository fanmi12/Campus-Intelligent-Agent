# 学院物联网工程专业建设指导委员会委员会议召开

1月20日下午，电子工程与智能制造学院召开物联网工程专业建设指导委员会委员会议，院长王卫平和相关部门负责人及物联网工程专业建设指导委员会委员参加了会议。

会上，王卫平院长为物联网工程专业建设指导委员会委员颁发了聘书。

王卫平指出，物联网工程是我院新增专业，前期建设取得了很大的进步，但仍然存在一些问题。我院2018年将面临人才培养计划的改革，将更多的学习自主权交给学生，努力提高学生的综合素质，请各位评委严格把关，把我院物联网工程专业建设工作推上一个新台阶。
