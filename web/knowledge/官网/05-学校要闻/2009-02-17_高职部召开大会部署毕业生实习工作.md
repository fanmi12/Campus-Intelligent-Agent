# 高职部召开大会部署毕业生实习工作

2月16日，高职部在1#408课室召开毕业实习动员大会，安排部署计算机辅助设计和计算机应用专业的毕业实习工作。

会上，谢俊副主任作实习动员讲话，宣布了实习领导小组和指导老师名单，组织毕业生学习《东莞理工学院城市学院专科毕业实习管理暂行办法》的文件。随后，黄旭辉老师对毕业实习的时间、要求、评定、答辩等事项作了具体说明。

高职部林世俊主任结合当前的就业形势，要求毕业生好好利用实习机会，将实习与谋职有机地结合起来，在本职岗位上虚心学习、踏实工作，迈好步入社会的第一步。
