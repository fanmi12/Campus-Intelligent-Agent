# 41个教学改革与研究项目立项

4月25日，学院教学工作委员会在315会议室召开全体会议，审定2007年度教育教学改革与研究项目。这次共审定立项41个项目，其中招标项目2项，重点项目4项，一般项目35项。

据悉，招标项目与重点项目的研究期限为2年，一般项目的研究期限为1年。
