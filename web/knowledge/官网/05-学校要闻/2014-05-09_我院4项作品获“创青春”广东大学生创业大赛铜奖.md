# 我院4项作品获“创青春”广东大学生创业大赛铜奖

近日，从“创青春”广东大学生创业大赛组委会获悉，我院4份大学生创业计划书《盆城有限公司》、《疯旅车站便当》、《Beegreen》、《小伙伴潮流代go》获得铜奖。

据悉，本次大赛由团省委主办、广东金融学院承办，学院团委将组织入围参展作品的指导老师及团队成员于5月17、18日前往广东金融学院学习观摩终审决赛。
