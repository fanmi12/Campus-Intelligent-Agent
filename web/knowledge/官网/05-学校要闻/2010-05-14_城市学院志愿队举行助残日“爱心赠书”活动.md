# 城市学院志愿队举行助残日“爱心赠书”活动

在全国助残日来临之际，城市学院志愿队于5月12—13日举办了以“扶残助残，你我同行”为主题的爱心赠书活动。

本次捐书活动设置樟村公寓，校外公寓6、7栋，第一饭堂前校道三个捐书点。活动所捐书籍将会送往助残联合会。记者在现场看到，所捐书中有小说、作文选、时尚杂志等。
