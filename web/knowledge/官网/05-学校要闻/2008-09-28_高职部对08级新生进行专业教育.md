# 高职部对08级新生进行专业教育

9月27日，高职部召开2008级新生专业教育动员大会，会议由总支书记黄研辉主持。高职部主任林世俊在讲话中指出，高职教育要注重职业道德、职业技能、继续学习能力的全面培养。他还阐述了高职教育的特点。通过教育，使新生对专业有了初步的了解，给自己的学习目标找到了准确的定位，增进了学习信心。财经系郑阿泰副教授、管理系李传国副教授、高职部谢俊副主任分别在会上介绍了会计电算化、物流管理和通信技术三个专业的培养计划、主要课程、学习方法和就业前景。
