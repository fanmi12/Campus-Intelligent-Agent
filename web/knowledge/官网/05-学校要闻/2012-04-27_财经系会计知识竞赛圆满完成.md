# 财经系会计知识竞赛圆满完成

4月26日，由东莞理工学院城市学院举办，财经系承办的第五届会计知识竞赛决赛在莞城校区大礼堂举行。

本次决赛的参加队伍共有六支，比赛分有问必答环节、计算技能比拼、90秒快速连答、互动抽奖问答、猜专业词汇比赛、点钞友谊赛、你来我往问答等八个环节。经过角逐，09会计学代表队以480分勇夺冠军。

财金系高香林教授、罗卫国教授、郑阿泰副教授、郑勇副教授担任本次活动的评委。
