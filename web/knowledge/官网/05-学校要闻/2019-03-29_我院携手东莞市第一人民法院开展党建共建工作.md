# 我院携手东莞市第一人民法院开展党建共建工作

3月29日下午，我院政法系携手东莞市第一人民法院在该院举行党建共建签约仪式。

学院党委书记章德胜，政法系主任刘杰、党总支书记江小卫和师生党员代表参加了签约仪式。东莞市第一人民法院院党组成员、政工科科长黄春梅、机关党委专职副书记廖蔚、寮步法庭机关支部书记林玉坤等给予了热情接待，并在寮步法庭党员活动室进行了座谈交流。

黄春梅科长对我院一直以来为东莞市第一人民法院提供优秀实习生资源，为人民司法事业培养了一批又一批优秀接班人表示感谢。她希望双方能够深入学习交流党建工作经验，加强沟通协作，使共建活动开展得有声有色、富有成效，共同构建基层党建工作新格局。她还表示，未来将与我院继续保持合作共赢的理念，在队伍建设、文化交流、法制建设等方面进一步拓展合作空间，携手加快法治人才培养，繁荣法学理论研究。

章德胜书记表示，多年以来，城市学院与东莞市第一人民法院建立了良好的合作伙伴关系，在教学实践、学生就业等方面都取得了良好的成效。此次开展“党建共建”合作，为双方党建工作提供了新的思路和灵感，带来了新的生机与活力，对双方提升党建工作水平、推动教育及司法工作创新发展都具有重要的意义。
