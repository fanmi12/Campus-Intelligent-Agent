# 我院召开新校区任课教师工作会议

9月24日，新校区任课教师工作会议在我院新校区公共教学楼召开。院领导安少华、杨敏林、程发良、朱冰、张林，院督学陈丁堂及各系部主任出席了会议。

会议由教务处处长邓成良主持。

新校区教务部部长高香林介绍教学管理等情况。

副院长程发良要求新老校区的教务管理工作人员要加强沟通、交流，把工作做得细致、周全、到位。全体任教老师在教学工作上要以认真、负责的态度，把新校区的教学工作做好、做扎实。

安少华院长在会上做了重要讲话，他要求新校区管委会和教务管理工作人员，要“始终把老师和学生放在第一位”，做好服务工作。老师要上好每一节课，“老师把每节课上好了，就是为学院打造了品牌。”要根据学生的特点因材施教，“不能让一位同学落后”。

会后,包括东莞理工学院在城市学院新校区有教学任务的44位教师在内的276位教师，前往各自授课的教室熟悉教学环境和教学设施，并参加了当晚在新校区举行的城市学院庆国庆军民联欢晚会。
