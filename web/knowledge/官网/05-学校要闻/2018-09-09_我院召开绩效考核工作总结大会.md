# 我院召开绩效考核工作总结大会

9月8日下午，2017-2018学年绩效考核工作总结大会暨新学年绩效工作布置会在行政楼212会议室召开，学院领导和二级单位党政负责人参加了会议。会议由副院长刘玉侠主持。

人事处副处长李海冬汇报了2017-2018学年绩效考核工作整体实施情况，具体分析了各项考核指标的实施效果，指出了绩效考核工作取得的成效和存在的问题，并对新学年的绩效考核工作作出了计划安排。

刘玉侠副院长指出，要进一步完善绩效考核实施制度，加强绩效考核的导向性作用，总结问题，完善指标，强化管理。她要求教职工加强对绩效考核工作的重视程度，充分发挥绩效考核的作用。

王卫平院长肯定了上学年绩效考核工作取得的成绩，要求各单位总结经验，提出建设性意见，并按照新学年绩效考核工作的要求和部署，贯彻落实好各项绩效考核工作。
