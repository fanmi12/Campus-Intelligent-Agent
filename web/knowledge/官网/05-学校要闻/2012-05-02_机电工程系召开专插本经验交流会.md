# 机电工程系召开专插本经验交流会

4月27日，机电工程系在机电楼308会议室召开了专插本经验交流会，系主任黄健求教授、系总支副书记谢明副教授，以及打算明年专插本的部分学生参加了会议。

系主任黄健求教授勉励同学们要增强信心，相互学习，认真做好复习准备，争取考出好成绩。

据悉，今年该系有多名同学成功专插本。09印刷技术专科全班13人，考取3人；09模具班专科全班35人，考取9人。
