# 我院举办2017年暑期中层干部读书班

8月27日，我院举办了2017年暑期中层干部读书班。全体院领导和中层干部参加了读书班，旨在进一步统一认识、达成共识、形成合力、推进发展。广东鸿发教育文化集团有限公司陈超群总经理应邀参加了读书班。

上午在行政楼112会议室，章德胜、高香林、黄兢、周庆、刘玉侠等院领导分别就各自分管的工作做了报告，对2016-2017学年的工作情况进行了总结回顾，并提出了新学年的工作思路及重点。

王卫平院长作了《凝心聚力 深化改革 ——强化管理与服务意识，切实提高工作效率与质量》的学院工作报告，对2016-2017学年“进一步完善学院‘十三五’规划”、“深化有关教育教学工作改革”、“进一步强化招生与就业工作”、“加强党建工作，推进师德师风建设”等学院九项重点工作的完成情况进行了总结；对2017-2018学年学院工作进行了部署，将“大力加强学院各级党组织的党建工作、切实做好意识形态领域的安全工作，深化教育教学工作改革，深化学院人事制度改革、进一步完善全员绩效考核制度，深化团学工作改革、大力加强校园文化建设，进一步加大后勤保障体系改革力度，大力推进创新创业教育工作”等六项工作列为学院重点工作。

在报告中，王卫平院长还着重就“如何当好领导干部”进行了阐述，强调领导干部要时刻以“三严三实”警示自己，同时传达了2017年全省民办高校领导暑期高级研修班、2017年全省高等学校领导干部暑期读书班的主要精神。

下午，读书班分成四个小组围绕院领导的工作报告进行了深入探讨。大家认为，读书班的创新形式让人耳目一新，为之振奋，大家提出了许多富有建设性的意见与建议。分组讨论结束后，各小组召集人汇报了讨论的有关情况。

最后，王卫平院长作了总结发言，对小组讨论中提出的部分问题进行了回应与解答，并希望全体师生员工提起“精、气、神”，集合队伍，整装出发，共同推进学院各项事业的发展。
