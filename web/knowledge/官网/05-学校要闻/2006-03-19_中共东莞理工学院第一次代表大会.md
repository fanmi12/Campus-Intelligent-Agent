# 中共东莞理工学院第一次代表大会

城市学院代表选举大会召开3月16日，我院在5号楼阶梯教室召开中共东莞理工学院第一次代表大会城市学院代表选举大会。

院党委书记朱志德同志主持会议并做了重要讲话，他指出，东莞理工学院第一次党代会是学院教职工政治生活中的一件大事，号召我院全体党员认真履行好《党章》赋予的权利。党办、院办主任王玉同志宣读了有关党代表选举的通知。我院145名党员、预备党员出席大会，有选举权的正式党员88名。

大会采用无记名投票方式从17位教职工代表候选人中选出14名代表。从2名学生代表候选人中选出一名党代表。选出的15名党员代表名单将上报中共东莞理工学院委员会审批。
