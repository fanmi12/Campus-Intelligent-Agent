# 学校召开中层干部会议，陈明任我校校长

2月17日，我校在行政楼112会议室召开中层干部会议。学校董事长代表陈超群、全体校领导、中层干部等参加会议。学校党委书记章德胜主持会议。

学校董事长代表陈超群宣读了《东莞城市学院关于陈明同志职务任命的决定》，经学校董事会研究决定，任命陈明同志为东莞城市学院校长。董事长代表陈超群向陈明教授颁发了聘书。

陈明作了发言。他回顾了自己在中央财经大学学习和工作的经历，谈到了他与鸿发集团，与城市学院的缘分。那是2015年，学校的举办方——广东鸿发投资集团为中央财经大学捐赠了“彦桐楼”。他非常赞赏鸿发集团尊师重教，大力支持教育事业发展的厚德善举。他表示很荣幸加入东莞城市学院，作为学校的一员，他将按照董事会的要求，竭尽所能，不遗余力，尽心尽力尽责地做好本职工作，为学校的建设发展作出自己应有的贡献。他将和大家为“创一流大学，办百年名校”的目标而努力！

董事长代表陈超群发表了讲话。他指出，学校的发展离不开热爱学校的干部队伍，离不开广大员工的支持。他希望全体教职员工热爱城院，扎根城院，以校为家，用心工作。特别是党员干部，要充分发挥模范先锋带头作用，树立“遇事克服困难，千方百计解决困难”的工作信念，给广大教职员工和学生以正能量的引导，为学校发展做出新的贡献。

最后，他希望广大干部在陈明校长的带领下，增强必胜信心，踔厉奋发、攻坚克难，笃行不怠，形成“创一流大学，办百年名校”的强大合力，开拓创新，共创新的辉煌。

陈明同志简介

陈明，男，汉族，江苏省连云港市人，中共党员，研究员，中国书法家协会会员。1983年7月毕业于中央财政金融学院并留校工作，曾任中央财经大学副校长、党委副书记、纪委书记。主要研究方向为高教管理。在《中国大学教学》《中国教育报》《教育艺术》《高校后勤研究》等刊物上发表学术论文多篇。人民网、新华网等均有其书法艺术专栏介绍。
