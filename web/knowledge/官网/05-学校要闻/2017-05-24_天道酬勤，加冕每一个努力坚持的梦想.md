# 天道酬勤，加冕每一个努力坚持的梦想

“当你默默地来回走在图书馆的路上，当你为梦想而甘愿经历时间的磨炼，当你错失了许多擦肩而过的美好，我坚信，当梦想成真时，一切都是值得的。”

多少人认为，只要经历了艰辛的高中三年，便要迎来幸福悠哉的大学四年。但对于城环系2013级土木1班的王加雷同学来说，大一的自己也曾叛逆过。初尝大学新滋味，总想闯闯外面的新鲜世界，为满足好奇心也去做过各类兼职。等收获到人生的第一桶金，却也荒废了一年的学习，挂掉的一门大学计算机课程，成了大学的一场遗憾。

总是踩过坑后，才知道路该怎么走。终于领悟到学习才是正路的王加雷，踏上了新的征程。他在日往月来中，坚持着自己的学习规划，图书馆从此成了他每天的“归宿”。自大二以来，就一路斩获了一等奖学金与国家奖学金的他，为圆高考失利而未实现的梦想，在大三下学期，王加雷作出了一个决定——考研。

每个出类拔萃、把来路说得云淡风轻的人，都曾为自己现在所站的位置，付出着咬紧牙关的灵魂。作为第一届土木工程专业的学生，王加雷没有师兄师姐的指导，只能请教几位老师进行辅导。“数学对大多数人是硬伤，它非常难，即使期末考有90多分也不能说明学得好”，王加雷开始着手高等数学与线性代数等习题的训练，直到大三那年暑假前才把这场“小打小闹”的数学课本和习题过一遍。

真正进入备考状态是在放暑假的时候。虽然学校因为人数不够而开不成考研班，但王加雷也做出了明确的时间规划。从7月份起，他自定每两月为一轮复习周期，坚持着数学刷题、英语单词、政治与专业课真题的多遍练习与记忆。大三3月份到大四12月份的整个复习过程中，孤军奋战的压力也就成了这位考研人最难熬的心理关。

回忆起考前那一晚，王加雷表示当时心理很平静，也许是经过了差不多一年的复习准备，许多紧张不安的心理都被时间消磨殆尽。可在进入考场的时候，无形的压力接踵而至，做题的速度随着心跳加速而越来越快。由于座位在第一排，监考老师就坐在前面，手心一直疯狂冒汗，当时的压力如春雷阵阵，愈发强烈。

如出一辙，复试过程也是一场与压力的无声鏖战，王加雷只能不断暗示自己要放轻松，不断自我鼓励“没问题的”。王加雷提到当时去广州大学交资料后，第二天上午便进入面试环节。坐在等待室里，听着自己的号码越来越近，压力感不断袭来，但是他没有停止收集有用的讯息，同一组的同学出来后，便立马询问并拿纸记住问题。大致总结出考官的问题方向后，他集中背那方面的知识。“我觉得面试，最重要的是一定得让教授们开心，让教授记住你的存在，不要给自己挖坑。教授问你会什么，就答熟练的知识，不要太紧张，表现自然，还要自信，回答问题要大声。”功夫不负有心人，王加雷最终以328分被广州大学建筑与土木工程专业硕士录取。

“考研可以转换专业提升学历，也可以换城市，还可跟着一位能给自己提供发展平台的导师。既能提升自己的综合素质，又能获取更好的教育资源，也是改变自己思维的方式，更有利于拓展自己的视野，积累人脉。”王加雷更是认为，相比而言，高考是一个选拔性的考试，而考研会比高考更加公平也相对容易些，“四年下来，虽然学得不精，但专业基础还在。我想通过考研锻造自己，提升自己的知识水平，并在本科的知识层面上，拓宽理论知识的领域。”
