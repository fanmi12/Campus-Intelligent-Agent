# 我院召开全员绩效考核制度宣讲会

3月1日下午，我院全员绩效考核制度宣讲会在212会议室举行。宣讲会由副院长刘玉侠主持，二级单位负责人参加了宣讲会。

人事处副处长李海冬对我院推行的全员绩效考核制度进行了重点讲解。从本学年开始，我院按照“重在激励、拉开差距，分类考核、量化标准”的原则，制定全员绩效考核体系，实行多劳多得、优劳优酬，相继出台了《教职工绩效考核办法（试行）》《专任教师绩效考核实施办法（试行）》《教学单位绩效考核实施办法（试行）》《职能部门绩效考核实施办法（试行）》等绩效考核管理制度，进一步调动全院教职工的积极性，提升全院管理服务工作水平，推进学院创新发展。

王卫平院长指出：这次改革突出岗位职责，按照定性与定量相结合、过程考核与目标激励相统一原则，实施多元化、多层次、多维度考核。今年6月就要按照文件进行绩效考核，7月份兑现。希望各二级单位负责人高度重视，细读文件，分头组织大家认真学习，做到心中有数，有问必答，严格按制度执行。
