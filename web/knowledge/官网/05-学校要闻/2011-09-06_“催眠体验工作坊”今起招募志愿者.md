# “催眠体验工作坊”今起招募志愿者

学生处心理健康教育与咨询中心（莞城校区）将于近期举办免费的“催眠体验工作坊”。该“中心”欢迎感兴趣的同学前来报名参加体验，报名时间为周一至周五，上午8:30-12:00，下午14:30—17:30，预约电话0769-22625570，也可以直接到4206报名。

据资料介绍，催眠有助于解决失眠，建立信心，缓解焦虑、紧张、恐惧等情绪，具有建立良好的生活习惯，解除情感及肉体创伤，控制体重，改善生活品质，减轻压力等效果与作用。在催眠的过程中，体验者会感到非常的放松舒适，像经历了美妙的梦境一般。

催眠是在“受催眠者”自愿的情况下进行的，如果“受催眠者”不配合，催眠无法进行，即使在催眠的过程中，“受催眠者”想要终止催眠，都可以在任何时候终止。因此，请参加催眠体验的同学放心体验。

“催眠体验工作坊”由学生处心理健康教育与咨询中心的余琼老师为大家做催眠体验，欢迎同学们前来报名。
