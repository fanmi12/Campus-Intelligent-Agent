# 38名城院学子光荣入伍

9月17日上午，随着接兵干部“出发”的口令，学院入伍的女兵廖雅芬从东莞出发，奔赴军营。

据介绍，今年征兵工作对入伍新兵的素质要求更高，体检政审把关十分严格。在学院老师、家乡父老的动员和支持下，城院学子积极响应号召，踊跃报名参军，充分展现了城院学子立志军营、保家卫国的崇高志向。

据了解，从9月10日开始，我院共有七批次新兵穿上崭新的军装，带着老师、同学和家乡父老的美好祝福奔赴军营，踏上保家卫国的新征程。截止到9月17日，我院共计38名同学光荣入伍，其中，男兵35人、女兵3人，并有13人从学院入伍。
