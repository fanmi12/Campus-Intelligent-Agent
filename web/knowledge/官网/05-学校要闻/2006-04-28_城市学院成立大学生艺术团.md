# 城市学院成立大学生艺术团

为了丰富校园文化生活，促进精神文明建设，让学生有一个展现自我的平台，经院领导同意，院团委决定成立东莞理工学院城市学院大学生艺术团。

大学生艺术团内设舞蹈队、街舞队、风烙舞队、声乐队、器乐队、戏剧队、模特队、武术队、跆拳道队和健美操队，以及办公室、公关部、策划部、后勤部四个职能部门。

院学生处罗文芳老师担任大学生艺术团团长，文学与艺术系艺术教研室主任史德松老师为艺术总监。

4月27日晚，大学生艺术团在学院大礼堂隆重举行成立庆典文艺演出活动。

学院党委副书记朱冰同志为大学生艺术团成员颁发了证书。
