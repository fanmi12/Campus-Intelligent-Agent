# 我院举行2014级新生军训教官见面会

按照教学计划的安排，大一新生的第一课是军训。9月14号下午5时，承训部队海军沙角部队的全体教官抵达城院。我院在行政楼112室举行教官与指导员见面会。院党委书记王卫平、副书记章德胜、副院长高香林等领导出席本次会议。

王卫平书记首先发表讲话，感谢沙角部队官兵对我院军训工作的支持，并对军训团工作提出几点要求，希望军训教官把部队吃苦耐劳的精神和一丝不苟的优良作风传递给学生们，因材施教，严格训练。

军训团团长、海军中校韩加强讲话时表示，这是他第二次带队来城市学院，深感责任重大，军训团的全体教官一定和指导员共同把本次军训工作做好，让学校和新生们满意。接着，他对军训工作做了具体安排和布置。

忙碌而充实的军训即将拉开帷幕。
