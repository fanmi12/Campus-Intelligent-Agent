# 省赛一等奖！学科竞赛再添喜讯

我校创意设计学院工业产品设计系学子在“两岸新锐设计竞赛·华灿奖”及“广东省高等学校大学生工业设计大赛”中表现优异，分别斩获省级一等奖和省级二等奖。

东莞城市学院产品设计专业立足东莞智造，赋能湾区创新。专业坚持“以赛促学、以创赋能”的育人理念，将学科竞赛深度融入教学实践。依托大湾区产业资源，专业注重培养学生的设计表达与产品开发能力，此次获奖不仅是对创意设计学院设计教学成果的肯定，更激励着师生们在创新设计的道路上持续探索。

“两岸新锐设计竞赛・华灿奖”是入选教育部学科竞赛白名单、普通高校大学生艺术与设计大类五星级综合设计赛事。 在此次大赛中，我校创意设计学院工业产品设计系学生叶凯、陈毅洪、李瀚钊、邓锐铳，李俊翰设计的作品《掌握》凭借独特的设计理念与扎实的创作功底，荣获广东省赛区赛省赛一等奖，这也是我校在该赛事中获得的最好成绩。

根据广东省教育厅发布的《关于公布2025年广东省高等学校大学生工业设计大赛获奖名单的通知》，我校工业产品设计系专业学生梁家瑜、陈好好共同设计创作的作品《宫缩监测仪》在赛事中取得优异成绩，荣获省级二等奖，作品实物样机模型在广州美术学院大学城校区美术馆一层展厅展出。

华灿奖——省级一等奖。作品名称:掌握一可穿戴手部康复训练装置及

数字化交互训练系统设计作者：叶凯、陈毅洪、李瀚钊、邓锐铳，李俊翰。广东省高等学校大学生工业设计大赛——省级二等奖作品名称：宫缩检测仪，作者：梁家瑜、陈好好。

长期以来，创意设计学院始终坚持将专业竞赛融入课程体系，持续优化“理论讲授、案例研讨、项目实践、竞赛孵化”的教学模式。产品设计作为学院重点建设专业，积极引导学生在高水平学科竞赛中锤炼专业本领，此次获奖正是该系深化教学改革、践行以赛促学理念的生动体现。

未来，创意设计学院工业产品设计系将继续发挥专业优势，坚持以学科竞赛为驱动，强化设计教学与产业需求、社会创新的深度融合，充分激发学生创造潜能，以更优异的成绩铸就专业口碑，为粤港澳大湾区建设贡献智慧与力量。
