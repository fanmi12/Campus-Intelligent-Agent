# 一批优秀中青年教师提前晋职

9月16日，东莞理工学院城市学院学术委员会在315会议室召开二届一次会议。

会议决定，东莞理工学院城市学院第二届学术委员会成员名单。新一届学术委员会委员由15名教授或博士组成。

经会议评定和委员们投票表决的，同意一批优秀的中青年教师提前晋职。他们是：郑阿泰老师为院聘副教授；陈显龙、林岩、胡良兰、李玲玲、王芬、王成军、张灿灿、曾爱明7位老师为院聘讲师。

会议还审议了我院申报专业技术资格人员的名单。
