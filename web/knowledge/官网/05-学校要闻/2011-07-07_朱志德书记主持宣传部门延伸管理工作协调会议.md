# 朱志德书记主持宣传部门延伸管理工作协调会议

7月6日，党委书记朱志德在4410主持召开宣传部门延伸管理工作协调会议，部署安排期末工作、暑假工作及下学年度工作。党委宣传部部长何鹏举、新校区综合部副部长张琮及部门全体工作人员参加了会议。

何鹏举就暑期的值班、加班工作及下学期工作作了部署和安排。张琮就新校区的摄影、摄像器材和广播设备验收等工作任务提出了要求。

朱书记要求宣传部门两校区全体人员树立一校两区，两位一体的全盘工作思路，加强沟通协调与合作。根据工作重点和阶段的不同，合理调配好人力、物力。工作中要加强网站、微博等新型宣传阵地建设，注意宣传的真实性、时效性、准确性，动员全院师生参与到宣传工作中来，共同树立、维护城市学院的良好形象。
