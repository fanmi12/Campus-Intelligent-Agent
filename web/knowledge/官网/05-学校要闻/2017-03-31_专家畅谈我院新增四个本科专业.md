# 专家畅谈我院新增四个本科专业

教育部最近发布教高﹝2017﹞2号文件，公布了2016年度普通高等学校本科专业备案和审批结果，我院获批工业设计、舞蹈编导、秘书学、投资学四个专业。新增四个本科专业的喜讯在我院产生了积极的反响。今天上午，林江龙等几位专家接受了记者的采访。

创意设计学院院长林江龙谈起来有点兴奋：“我院申报的工业设计偏重艺术设计和产品设计，不同于一般的机械设计，具有更强的优势。工业设计将成为创院的火车头，学院聘请台湾的大学博士，成立学生工作室，按照上学如上班、毕业即就业的模式进行培养。学习工业设计的学生也可以选择学习数字媒体设计或者视觉传达设计的专业课程，参加应用型设计比赛。”

连续四年，我院共有13个本科专业获得审批通过，表明学院办学实力不断增强，也为城院招生规模名列东莞之首奠定了坚实基础。艺术系主任向智星说：“舞蹈编导专业与表演、音乐表演形成了三足鼎立的格局，成为艺术系赖以生存发展的生命力。我们的目标就是要培养多样化、多元化的艺术人才，形成一专多能、一主二副、一书多证的人才培养模式。”

开设投资学意味着什么？金融与贸易系主任米双红说：“一是招生面广；二是现代社会投资理财受到人们关注，投资学必将成为热门专业；三是目前东莞市投资公司已经超过2000多家，人才缺口大。全市中小企业两万多家，融资是个难题；四是弥补了金融学的不足，对系部专业的发展起到了平衡作用。”

文学与传媒系副主任陈跃接受了记者的采访：“秘书学与汉语言文学、网络新媒体三个专业互为犄角，是文学与传媒系发展壮大的需要。秘书学专业的毕业生能够在各级党政、企事业单位从事文秘工作，在企事业单位胜任文化宣传、营销策划以及公共关系等岗位的工作。”

据了解，至此我院共有了38个

本科专业。教务处处长牛熠认为：我院设置和调整专业，既主动适应国家和区域经济社会发展需要，适应知识创新、科技进步以及学科发展需要；也严格遵循高等教育规律和人才培养规律，符合学校办学定位和办学条件，促进学校办出特色。

牛熠处长说：“工业设计、投资学等四个本科专业具有开阔的市场和就业前景，能较好地满足粤港澳大湾区的经济转型发展、产业升级对相关专业人才的需求。我院开设这些专业后，能够为地方经济社会发展培养基础知识扎实、实践能力强、具有创新创业精神的高素质应用型人才。”
