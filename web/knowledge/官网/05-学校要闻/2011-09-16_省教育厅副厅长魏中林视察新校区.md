# 省教育厅副厅长魏中林视察新校区

魏中林副厅长（前排中）视察我院新校区

魏中林副厅长（右1）与新生菁英培训营的同学们亲切交谈

领导合影留念

在东莞理工学院城市学院即将迎来2011级新生入学报到之际，9月16日上午，广东省教育厅党组副书记、副厅长魏中林莅临城市学院新校区视察、调研，陪同视察的还有中山大学副书记、副校长喻世友，省教育厅规划处处长汤贞敏，省教育厅安全保卫处副处长王自成，省教育厅高等教育处副处长金正林，省教育考试院高等教育招生考试部副主任陈雪杰等领导。东莞理工学院党委书记周致纳、校长杨晓西，东莞理工学院城市学院董事长麦照容、院长安少华、董事黎建烨、副院长杨敏林等领导热情接待了魏中林副厅长一行。

“设施、布局非常不错！校园硬件堪称一流！”上午11时30分许，魏中林副厅长在城市学院新校区视察时，对眼前优美的校园环境、独具特色的校园建筑，赞赏有加。“我去法国、美国等国家也考察、参观过很多优秀的大学校园，城市学院新校区的硬件堪称一流。” 魏中林副厅长肯定了新校区的建设成就，并誉之为“一步到位，一流校园，是优质教育资产！”

在视察中，幽美俊秀的中央湖景、枝繁叶茂的百年荔枝林、挺拔遒劲的百年秋枫、兼具岭南建筑特色与客家文化风格的图书馆、气势恢宏的教学楼建筑群……，这一切给了魏中林副厅长非常好的印象，并用“你们不用解说，校园已经说了；我也不多说，校园自己已经都说了！”这句话表达自己的感受。

随后，魏中林副厅长特意来到公共教学楼的教室，视察教学环境与硬件建设情况。看着一排排崭新的桌椅，多媒体教学等先进设备，魏中林副厅长赞叹现代教学设施越来越好，越来越先进，并坐在课椅上深情地回忆起自己读书时代的一些情节，与大家分享。

在综合馆视察时，城市学院2011级新生菁英培训营正在进行培训活动，现场氛围十分热烈。魏中林副厅长示意陪同人员不要打扰同学们的培训，然而艺术系的宋歌、财经系的莫梓湘等同学还是热情地迎了上来，主动向领导们问好并介绍自己。在获悉同学们在中学时都是优秀学生干部，具有音乐、艺术等特长并获得各类奖项时，魏中林副厅长非常欣赏，还亲切地询问了同学们的籍贯、学习生活等情况。在谈到对新校区的感受时，同学们表达了自己对新校区的热爱，认为这里非常适合大学学习、生活，校园建设比预想要好得多，并相信通过大家的努力今后一定会发展得更好。魏中林副厅长对此感到非常欣慰，并勉励同学们“好好念书，早日成材！”
