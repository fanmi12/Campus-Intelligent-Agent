# 新学期 新气象

3月5日，近7000名师生带着新春的祝福和节日的喜悦，又一次走进课室，开始新学期第一天的学习。宁静的校园恢复了往日的欢乐、紧张、忙碌的景象，处处是匆匆的脚步、朗朗的读书声和挑灯夜读的身影。

学术副院长程发良教授便带领教务处、学生处有关负责人到各教室检查上课情况。据查，课任老师全部到岗到位，学生上课出勤率达99%，288种课本及教学参考书已到280种，学生上课手中都有新书。

开学准备工作，院领导高度重视，各职能部门主动配合。寒假期间，教务处就在网上公布了课程表，并用文字通知的形式将开学注意事项印发给每一位任课老师。总务处对教室里的电灯、多媒体、桌椅进行了“查漏补缺”。 3月1日，学院召开各系教学秘书会议，专题部署开学准备工作。3月2日，校本部领导周致纳、杨晓西、安少华专程到我院检查开学准备工作，听取院领导的工作汇报。

副院长程发良教授和教务处处长邓成良博士检查开学工作

同学们以饱满的热情开始新的学习
