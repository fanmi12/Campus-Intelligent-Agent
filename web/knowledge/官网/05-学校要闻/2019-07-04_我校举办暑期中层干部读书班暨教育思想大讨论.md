# 我校举办暑期中层干部读书班暨教育思想大讨论

7月3日-4日，我校举办2019年暑期中层干部（扩大）读书班暨教育思想大讨论，以统一思想、凝聚力量，深化改革创新，全面推动学校内涵式发展。校领导，董事长代表，校内各单位正副职、教研室主任、院长（处长）助理，各党总支（直属支部）书记、副书记参加了读书班活动。

原东莞理工学院副校长邹晓平教授应邀作了《用高质量的本科教育为城市学院百年发展奠基》主题讲座。他从怎样界定今天的本科教育、怎样界定“本科教育质量”等五个方面，阐述了本科教育是大学办学之“本”、立校之“本”的理念，并结合我校实际为如何打造高质量的本科教育提出了建议。

华南理工大学广州学院副校长林颖教授应邀作了《华南理工大学广州学院专业认证的探索与实践》主题讲座。她着重介绍了广州学院专业认证思路和措施、实施情况与成效，为我校实施专业认证提供了路径参考。

华南师范大学高等教育学专业博士生导师、广东省教育厅高等教育处处长郑文应邀以《当前高校专业建设的问题与对策》为题，介绍了专业建设的内涵，指出专业建设存在盲目性、同质性、封闭性的主要问题，进而提出了“以专业建设规划为引领、以教师队伍建设为重点、以课程建设为基础、以教学评估为保障、以机制建设为动力”等主要对策来提高专业建设水平。

王卫平校长作了学校工作报告，总结了2018-2019学年“政治建设与党建工作、人力资源管理机制改革、教育教学工作改革、学生工作体系改革、后勤保障体系改革”等重点工作的完成情况，对下学年重点工作提出了构想和思路。

读书班分成五个小组围绕上述三场讲座和学校工作报告，就教育思想和学校发展进行了大讨论，大家纷纷为学校下学年的工作建言献策。

王卫平校长在总结时指出：此次暑期中层干部读书班暨教育思想大讨论创新形式、内容丰富，了解了国内外高等教育发展的新形势，更新了教育理念，加强了沟通，增进了相互了解，也初步厘清了教育思想，厘清了发展方向。

王卫平校长希望在新学年，各二级教学单位党政领导加强合作，落实贯彻好党政联席会议制度，加强党的领导，发扬民主。学校广大干部要管理好各项事务，更要凝聚好人心，加大对广大师生员工的人文关怀。继续做好党的建设、人力资源管理机制改革、教育教学工作改革、学生工作体系改革等重点工作，加强特色培育、特色提炼，打造城院品牌，努力把学校建设成为特色鲜明的高水平应用型本科院校。
