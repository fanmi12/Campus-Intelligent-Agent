# 杨振宁、范曾来我院签名赠书

4月27日上午，世界著名物理学家、诺贝尔物理学奖获得者、东莞理工学院名誉校长、90岁高龄的杨振宁博士携妻子翁帆女士，当代著名书画大师、北京大学中国画法研究院首任院长、博士生导师的范曾莅临城市学院新校区进行参观访问，并向新校区图书馆签名赠书。东莞理工学院党委书记周致纳、校长杨晓西，东莞理工学院城市学院董事长麦照容、董事兼院长杨敏林、董事黎建烨、党委书记朱志德，院领导班子成员以及新校区管委会各部门负责人陪同参观。

上午10时30分，当杨振宁博士夫妇十指相扣，与范曾大师出现在新校区图书馆前时，现场掌声雷鸣。周致纳书记、麦照容董事长向杨振宁博士、范曾大师就城市学院新校区做了简要的介绍。当听到广东鸿发投资集团有限公司斥资近20亿元建设城市学院新校区时，杨振宁博士握住麦照容董事长的手说：“这是功德无量！”

随后，杨振宁博士夫妇、范曾大师还与陪同参观的领导及现场师生合影留念，并向新校区图书馆签名赠书。

在访问结束离开新校区之前，杨振宁博士特意紧紧握住妻子的手，迈上图书馆前的台阶，在自己亲笔题字的“图书馆”三个镀金大字下合影留念。

据悉，杨振宁博士夫妇、范曾大师此次来莞的目的是参加东莞理工学院建校20周年系列庆典活动。
