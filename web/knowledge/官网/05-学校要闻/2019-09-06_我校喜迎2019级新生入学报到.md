# 我校喜迎2019级新生入学报到

9月5日、6日，我校迎来2019级新生入学报到。5500名2019级新同学怀着喜悦和期盼走进大学校园，开启人生新的篇章、新的征程。

从5日清晨开始，校园内呈现出一番生机勃勃的景象，洋溢着一派喜庆的氛围。志愿服务、答疑解惑、秩序维护、行李搬运、绿色通道……迎新工作人员和志愿者早早地等候在综合馆报到现场，个个精神饱满，在各自的岗位上为新生与家长们提供舒心、周到的服务。整个校园车水马龙，热闹非凡。

拿出城市学院录取通知书，扫一下条形码，新生便完成了报到流程。继去年“集中接待、集中办公”的方式，新生注册工作、绿色通道申请、新生入学教育、财务缴费、在线选择宿舍等迎新工作已提前在我校智慧城院APP上完成。现场扫取条形码后领取宿舍钥匙便完成了报到手续。如此依托大数据，简化流程，让迎新工作更加便捷高效有序。

5日上午，东莞理工学院党委副书记吕琦元、东莞理工学院城市学院董事长麦照容、广东鸿发教育文化集团有限公司总经理陈超群，学校领导王卫平、章德胜、高香林、黄兢、周庆、刘玉侠、林江龙等来到综合馆报到现场检查指导迎新工作，慰问工作在一线的师生员工。

吕琦元副书记、麦照容董事长来到每个二级学院报到处，细致了解迎新工作情况，并和大家合影留念。他们叮嘱工作人员增强服务学生的意识，要把工作做细、做实，让每名新生切实感受到学校的热情和关爱，让学生家长们放心。

我校新生入学报到工作也得了寮步镇政府及相关部门、中国移动、中国电信、小坑村等村委的大力支持，为我校新生报到提供了交通、通讯、水电及校园周边治安安全等保障服务。

据悉，我校今年面向全国18个省市共录取招生5500人，其中，广东省5100人，省外400人。
