# 学院团委召开表彰大会

5月15日， 城市学院2007—2008年度优秀团员、团干及先进团支部表彰大会在学术报告厅召开。

会上，学生处处长章德胜副教授宣读了表彰决定和优秀团员、优秀团干部、先进团总支的名单。其中优秀团员527名，优秀团干部126名，优秀团支部14个，先进团总支2个。党委副书记朱冰及学生处处长章德胜副教授、院团委副书记杜鹏举老师、院学生会主席姚衡分别为获奖同学和团体颁奖。
