# 春伴和谐校园美 师生同贺过大年

大年初一，风和日丽。“同志们，大家新年好！”学院党政领导朱志德、朱冰、张林和院办主任王玉一行，一大早就来到校园，给正在值班的保安、清洁工人和留校学生拜年，代表全院师生向他们表示新春的祝福。继年前的团拜会之后，学院组织有关人员美化校园，院领导走访、宴请留校师生,使校园处处呈现出喜庆吉祥的气氛,让留校过年的师生感受到异乡的浓浓亲情。

从2月10日开始,学院进行了为期一周的校园迎春美化工作，在学院大门两侧﹑人才之星广场﹑教师公寓﹑学生饭堂等景点，分别吊挂了许多大红灯笼与各式彩灯，摆放了大量的鲜花和象征富贵的金桔盆景。

16日,院长安少华教授﹑副院长张林副教授及院办主任王玉﹑人事处处长夏勇看望了留校过年的老教授代表。晚上，院领导并在福迎门酒楼宴请了老教授及其家属。

院领导对留校学生更是厚爱有加。年三十中午，学院设酒席宴请了留校学生，并给每一位学生派发了利是。春节前后，学院卡拉OK厅免费为师生开放。

春联、彩灯和鲜花，把校园装点得吉祥喜庆。

院长安少华教授亲切接见留校学生，并与学生代表合影留念

学院领导与留校学生同饮新春喜酒，互致新年的祝词。
