# 我院赴沙角部队慰问官兵

“八一”前夕，我院由王卫平院长、周庆副院长、后勤保卫处刘维仝副处长、后勤保卫处凌继峰老师组成的“八一”拥军慰问团来到沙角部队，慰问人民子弟兵。

王卫平院长代表学院向部队官兵致以节日的祝贺和诚挚的问候，并介绍了我院发展的基本情况。

王卫平院长

还表示，沙角部队一直以来积极参与和支持我院的建设与发展，特别是每年为我院新生开展国防教育和军事训练等方面做了大量工作。我院将坚定不移地弘扬拥军优属传统，积极推动学院与部队的建设。

沙角部队副司令胡孔齐上校对慰问团的到来，表示热烈欢迎。他指出，沙角部队与城市学院一直以来都保持良好的友谊。城市学院每年都到部队慰问和看望部队官兵，部队广大官兵将以实际行动回报党和人民的厚爱，努力为促进城市学院百年名校建设作出更大的贡献。
