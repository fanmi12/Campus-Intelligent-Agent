# 致公党东莞理工学院城市学院支部委员会正式成立

6月19日上午，中国致公党东莞理工学院城市学院支部委员会正式成立。

东莞市政协副主席、致公党东莞市委会主委、东莞市中级人民法院副院长陈树良专程前来祝贺，并和东莞市委统战部副调研员聂开贵，我院院长、党委书记王卫平，致公党东莞市委会参政议政专委会副主任、东莞理工学院城市学院支部主委、管理系主任张佺举一道，为致公党东莞理工学院城市学院支部委员会揭牌。

出席今天上午成立大会的领导还有：东莞市政协委员、致公党东莞市委会副主委、东莞市教育局安全管理科科长明晖，东莞市政协常委、致公党东莞市委会委员、秘书长黄蔚然，我院党委副书记章德胜，党委委员、副院长高香林，党委委员、副院长黄兢，党委委员、学院办公室主任杜鹏举，东莞市政协常委、民进东莞市委会副主委、学院教务处处长牛熠等。

致公党东莞理工学院城市学院支部成员黄岳钧、付文玉、洪树权、蒋楚楚、黄龙参加了成立大会。
