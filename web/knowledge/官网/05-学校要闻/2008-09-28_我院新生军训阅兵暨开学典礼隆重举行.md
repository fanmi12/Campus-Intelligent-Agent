# 我院新生军训阅兵暨开学典礼隆重举行

9月27日上午9时，在雄壮的国歌声中，东莞理工学院城市学院2008级新生军训阅兵暨开学典礼在田径场隆重举行。出席大会的领导与嘉宾有东莞市政协副主席朱伍坤，东莞理工学院党委书记周致纳，东莞军分区副司令员李建军，南海舰队沙角训练基地副司令员王建龙，东莞理工学院党委副书记、城市学院董事王江水，东莞理工学院副校长、城市学院院长安少华，城市学院董事会部分董事，樟村、堑头社区领导，城市学院领导朱志德、程发良、朱冰、张林、陈丁堂，各系部、各处室负责人，以及3000多名受训学生。

本次阅兵采取阅兵加会操的形式进行。周致纳对军训方队进行了检阅。阅兵式上，16个方阵队的新生军训团不负领导厚望和教官的辛勤训练，展现了他们训练有素的学子风貌和积极向上的精神状态。在军事科目会操中，队列展示、军体拳、女子防身术表演气势磅礴、步调一致，博得在场领导

和老师的热烈掌声。

军训领导小组组长、党委副书记朱冰宣读了军训先进个人与先进集体的名单。 随后，院长安少华发表了热情洋溢的讲话。他首先对广大新生即将开始的新生活给予了真诚的嘱咐和殷切的希望。他希望同学们尽快转换角色，适应新环境；学会学习，培养创新精神；学会做人，塑造完美的人格；学会做事，全面提升自己的能力。 新生代表李伟建在发言中表示，不辜负老师和家长的期望，珍惜光阴，努力学习，提高素质，使自己早日成才。

各系辅导员在主席台一一与新生见面。

院办主任王玉、学生处处长章德胜分别主持阅兵式与开学典礼。
