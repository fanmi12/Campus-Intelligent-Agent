# 学院第六届教工男子篮球赛开幕

5月14日下午，我院第六届教职工男子篮球比赛在教工篮球场拉开序幕。

本次比赛分为两个阶段，为期两周。第一阶段有11支队伍，约165人参赛，在比赛期间还增加了女子花样投篮环节，充分体现了篮球运动的大众性；第二阶段由教工联队、体育代表队、保卫代表队及后勤代表队四支队伍参赛。
