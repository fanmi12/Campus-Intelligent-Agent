# 2019新年贺词

日月开新元，天地又一春。转眼又到了辞旧迎新的美好时刻，在2019年元旦来临之际，我谨代表学院党政领导班子，向全体师生员工、离退休老同志以及海内外校友，送上诚挚的问候和新年的祝福！向长期以来关心和支持城市学院发展的各级领导、社会各界朋友致以衷心的感谢和美好的祝愿！

即将过去的2018年，在党的十九大精神指引下，在上级党委和学院董事会的正确领导下，依靠全体教职员工的齐心协力，我们紧紧围绕学院总体发展目标和年度工作重点，以抓铁有痕、不折不挠的工作作风，攻坚克难，全面深化学院各项工作的改革，有效地推进了学院的内涵式发展。学院社会影响力不断扩大，综合竞争力进一步加强。

这一年，学院进一步优化整合办学资源，成立商学院、创新创业学院，成立监察处，调整有关职能部门，进一步完善内部治理结构，提升管理与服务水平。

这一年，我院招生规模和生源质量再创新高，在招生工作面临新挑战的形势下，继续保持火爆的招生态势，录取新生6200多人，普通类文理科均以第一志愿满档出档，实际录取最低分数线均超出省线20分以上，圆满完成招生计划。实际报到率继续位居省内同类院校前列。2018届毕业生初次就业率达到95%。

这一年，学院认真落实《东莞理工学院城市学院关于全面推进应用型人才培养模式改革的实施意见》，稳步推进教育教学改革。大力开展校企深度合作协同育人，与新道科技有限公司共建财务管理专业，开设云财务卓越班；与高顿教育集团合作开设CFA创新实验班；与北部湾财产保险公司共建保险学专业，共建实践教学基地，并开设保险学创新班；与广东鸿高建设集团共建土木工程专业（路桥方向），开设“鸿高卓越工程师创新班”。实践教学取得长足进步，商科虚拟综合实训中心正式启用。按照教育部有关要求，结合学院各专业的特点，深化改革，修订并实施2018版人才培养方案，开展专业结构性调整，启动专业评估工作，大力推进人才培养质量提升。学院获准招收国际留学生，办学开放性与国际化不断拓展。

这一年，我院学科建设取得新进展，机械工程、工商管理等2个省级重点培育学科以及一批校级重点学科建设进展较快，成果初显。“创新强校工程”和“质量工程”建设取得新进步，教研与科研工作水平进一步提高。

这一年，学院师资队伍建设不断加强，制定并落实《“百名博士人才工程”建设实施方案》，大力度招揽和培育人才，人才聚集效应初显；按照广东省“放管服”文件精神要求，结合学院实际，建立健全职称评审配套制度，首次自主并顺利开展职称评定工作。

这一年，学院党建工作进一步加强，思想政治建设、制度建设、干部队伍建设稳步推进；新闻与宣传工作取得新进步，校园安全工作平稳有序；团学工作改革取得明显进步；城院学子在各类学科竞赛中摘金夺银，捷报频传。

过去的一年，我院内涵式发展取得新进步，催人奋进。这些成绩的取得离不开上级党委和学院董事会的正确领导，离不开上级有关部门的关怀与指导，离不开全院师生员工的凝心聚力和努力拼搏，离不开社会各界人士的大力支持。在此，我们表示衷心的感谢！

展望2019年，豪情满怀。我们将不忘“创一流大学、办百年名校”的初心，牢记立德树人的使命，以改革创新的姿态继往开来。在新的一年里，我们将以党的十九大精神为引领，以习近平新时代中国特色社会主义思想为指导，围绕学院总体发展目标,在保证学院各项工作健康稳定发展的同时，我们将在新的一年重点开展以下工作：深入学习贯彻落实习近平新时代中国特色社会主义思想和十九大精神，大力加强党建工作，充分发挥党组织在学院各项工作的政治核心作用，高度重视意识形态安全工作的责任落实，做好2019年上半年第三次学院党代会召开筹备工作；深化学院人力资源管理机制改革；深入学习贯彻落实“新时代全国高等学校本科教育工作会议”精神，深化我院教育教学工作改革；深化团学工作体系改革，加强校园文化建设，助推学生成长成才；本着“三服务、二育人”理念，继续加大力度深化后勤保障体系改革；大力加强学院文化品牌建设。

潮平岸阔催人进，风劲扬帆正当时。2019年是新中国成立70周年，也是我院建校15周年。在新的一年，让我们紧密团结在以习近平同志为核心的党中央周围，高举习近平新时代中国特色社会主义思想伟大旗帜，不忘初心，牢记使命，坚定走内涵式发展道路，群策群力，务实进取，撸起袖子加油干，努力使我院各项工作水平迈向新台阶！

新年的钟声即将敲响，衷心祝愿全院学子学业进步，健康成长!祝愿全体教职员工新年快乐，万事如意！

东莞理工学院城市学院党委书记、院长

王卫平2018年12月29日
