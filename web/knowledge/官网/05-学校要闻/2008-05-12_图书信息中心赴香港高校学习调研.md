# 图书信息中心赴香港高校学习调研

为学习借鉴先进图书馆的经验与做法，做好我院新馆建设与管理的准备工作，5月8日，院图书馆主任钟兴恭教授、发展与联络中心杨光强主任带领几名工作人员，赴香港科技大学及香港城市大学进行考察调研。东莞同乡会荣誉会长、香港太平绅士王霖老先生不顾年迈、不辞劳苦为我院开展调研工作提供了周到的服务，并陪同考察了香港城市大学图书馆。

香港科技大学图书馆关慕霞老师热情地接待了调研人员，详细介绍了馆内的区域布置、硬件设施及藏书资源等情况。

第二天，调研人员在香港城市大学郭键动博士的带领下，参观了该校图书馆，杨副馆长亲自担任讲解员介绍情况。

科技大学李兆基图书馆总面积约10000平方米，环境非常优美。该馆在设计理念上以人为本，高效便利，充分利用了空间，如靠窗望海的位置全部摆放了自习桌；使用电动密集书架，充分利用藏书空间；在走廊等区域挂上精美的油画，加强图书馆艺术气氛的渲染等。该馆在管理和设计上独具一格，根据读者需求的变化适时调整和增设藏书内容、服务方式和服务内容；在校外设有远程藏书库，专门放置3年内使用不多的书籍；设置了自助借书机；一些细节的处理和家具的布置令参观人员耳目一新。

钟兴恭教授向两所高校图书馆赠送了纪念品。
