# 黄碧莲副书记深入我院检查指导巾帼文明岗创建工作

5月26日，东莞理工学院党委副书记黄碧莲，东莞理工学院妇委会主任韦洛霞,深入我院财经系检查指导巾帼文明岗创建工作。

财经系主任高香林、系党总支副书记叶凯贞老师向检查组汇报了巾帼文明岗创建活动情况。

黄碧莲副书记听完汇报后指出，创建优秀巾帼文明岗活动，是妇女工作的一个品牌项目。通过创岗活动，激发广大女教工的工作积极性，提高个人的修养和教学管理水平，推动和谐校园建设工作。她还从活动的组织领导、创建口号、保障措施、宣传特色、创建成效五个方面肯定了财经系的创岗工作。

韦洛霞主任说，开展创建优秀巾帼文明岗活动，主要目的是促进各部门相互学习，相互借鉴，取长补短，更好地打响巾帼文明岗的品牌，使妇女工作得到学校、社会的广泛认可。
