# 高职部召开励志教育暨考前动员大会

5月24日,高职部在大礼堂召开“励志成才，从容考试”励志教育暨考前动员大会。

政法系龙凤兰老师首先为学生做了主题为“以积极的心态引领自己的人生”励志讲座。她结合自己的亲身经历，用幽默风趣的语言为同学们讲述自己的奋斗历程，并勉励同学们要坚定信心，迎难而上，坚持到底，取得成功。

讲座结束后，谢俊副主任作考前动员讲话。他总结分析了高职部学生的优势，预测了各个专业的就业前景，勉励同学们开心学习，积极备考，诚实守信，杜绝作弊，考出自己真实的水平。

会议还为高职部网页设计大赛和系徽设计大赛获奖者颁奖。
