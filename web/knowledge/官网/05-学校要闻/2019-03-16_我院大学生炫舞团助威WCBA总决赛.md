# 我院大学生炫舞团助威WCBA总决赛

3月15日晚，2018-2019WCBA全国女子篮球赛联赛总决赛在东莞市大朗体育馆举行，广东队主场对阵八一队，CCTV-5进行了全程直播。我院炫舞团被邀请作为此次赛事的啦啦队，为大赛热舞助威。

开赛之前，炫舞团为观众献上了一支韵味十足、婀娜多姿的舞蹈，瞬间点燃现场激情而欢快的氛围。比赛随后火热进行，经过一个多小时的激烈追逐，广东队最终以89：93惜败八一队。

赛事中，我院炫舞团在暂停时间、各节比赛结束休息间隙为观众带来了一个又一个身段优雅、轻盈柔美的精彩舞蹈，让球迷们欢呼雀跃，赢得了一阵又一阵久久不息的掌声。

当比赛打得难分难解时，炫舞团还在场边为参赛球员加油打气，整齐划一的手势与高声呐喊，气势如虹，给大家留下深刻的印象。
