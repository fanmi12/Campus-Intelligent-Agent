# 我院召开党的群众路线教育实践活动调研工作座谈会

4月2日，学院召开党的群众路线教育实践活动调研工作座谈会。出席会议的院领导有院督学陈丁堂同志、院党委副书记章德胜同志、副院长高香林同志，院内各系(部)行政负责人,各党总支（直属党支部）书记参加会议，党委书记王卫平同志主持会议并讲话。

党委书记王卫平同志在讲话中指出：我院党的群众路线教育实践活动经过前期准备、动员，从4月1日起进入学习教育、听取意见环节。在这一环节的活动中，我们要把学习教育和听取意见有机地结合起来，既要创新学习方法，进一步深化认识，要采取多种有效的形式广泛听取意见、深入调研，切实做到边学边查、边查边改，取得实效。

王卫平同志在讲话中强调：要正确处理教育实践活动和日常工作的关系，真正做到“两手抓、两不误”，相互促进。院领导将深入基层党总支(直属支部)和广大党员、干部共同学习、讨论、查摆问题，听取意见。各单位要在教育实践活动中统一思想、提高认识、精心组织、突出重点，真正使党员、干部作风得到真正转变、群众关心的热点难点问题得到认真解决。

会议认真听取了参会人员关于开展教育实践活动的意见、建议以及日常工作中存在的突出问题。

会议要求，教育实践活动是当前的一项重要的政治任务，当前各党总支(直属支部) 的工作侧重点是要组织学习文件、提高认识、明确目的。各级党政负责人要站在讲政治的高度，切实履行职责，亲自安排、带头行动、深入调研，及时解决活动中出现的新情况和新问题，确保教育实践活动取得实实在在的效果。
