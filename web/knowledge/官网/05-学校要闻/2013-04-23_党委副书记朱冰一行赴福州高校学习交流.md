# 党委副书记朱冰一行赴福州高校学习交流

4月18至19日，党委副书记朱冰、院督学陈丁堂率队先后赴福州师范大学协和学院、福州大学阳光学院两所独立学院学习交流。

在座谈会上，我院与考察学院就独立学院的办学思想、办学特色、管理模式等学院层面的问题进行了探讨，并对两校的发展战略规划、国际合作办学、师资队伍建设、应用型人才培养模式、学科专业建设、校园规划等方面的工作做了交流。

此次跨省调研行程紧凑，主题突出，信息丰富，为我院制订发展规划找到了对比参考资料。
