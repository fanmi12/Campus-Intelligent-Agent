# 2015年我院继续面向全省招收本科插班生

从省考试获悉，2015年，我院获准继续面向全省招收本科插班生150人，共21个专业方向。

2015年本科插班生于2015年1月10日至13日（共四天）为网上预报名时间，考生通过互联网登录http://www.ecogd.edu.cn/cbsbm，进入“广东省本科插班生网上报名系统”进行预报名，逾期不再办理预报名手续。2015年1月14日至1月16日(共三天)为网上报名确认时间。考生须持有关报名材料，亲自前往东莞理工学院城市学院确认报名点校验报名材料及电子摄像等。

欢迎广大考生报考城市学院！

详情请登陆城市学院招生网查询：http://zsb.ccdgut.edu.cn/pages/Front/showArticle.do?id=297
