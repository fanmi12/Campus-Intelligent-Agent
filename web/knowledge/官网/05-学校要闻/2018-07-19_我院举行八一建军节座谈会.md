# 我院举行八一建军节座谈会

为迎接中国人民解放军建军91周年，学习和发扬军人的光荣传统和优良作风,7月17日，我院举行庆祝“八一建军节”座谈会。院长王卫平、副院长刘玉侠、周庆，学院办公室主任杜鹏举、招生就业处处长孔增强、后勤保卫处处长王锦锋，以及全院40多名转、复、退教军人职员工和学生参加了会议。

座谈会上，老兵畅所欲言，重温了在部队的峥嵘岁月。曾服役于某集团军、现思政部副主任石志民和大家分享了在部队和学院的经历，表示虽然已经脱掉了军装，但忘不了部队的情怀和铁的纪律。同时也感谢学院一直以来，对转、复、退军人的关心，大家将继续以军人的标准干好本职工作。

国旗护卫队指挥员、2015级电子信息工程专业赖志明同学汇报了这些年在部队和学院的历程。他表示炽热的军旅生活锻炼了自己的意志，形成了良好的军人作风，回校复学后，将以实际行动回报母校。

刘玉侠副院长在讲话中，充分肯定了我院转、复、退军人为学院发展所作的贡献，并向他们送上节日的问候。同时希望大家继续发扬在部队的光荣传统和优良作风，在工作方面，敢于亮剑，当好标杆、当好先锋、当好表率，继续为学院的发展贡献力量。
