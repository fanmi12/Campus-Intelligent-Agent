# 金贸系举行城院首届舞林大会

5月18日，由城市学院主办、金融与贸易系承办的“炫动全城，唯舞独尊”08校园科技文化艺术节城院首届舞林大会在大礼堂隆重举行。

学院党委副书记朱冰同志、学生处处长章德胜副教授、金融与贸易系主任米双红教授、金融与贸易系书记龙卫洋博士、团委书记丘永辉老师和团委副书记杜鹏举老师等观看了晚会。

进入决赛的13支队伍都极具感染力，不仅表现题材新颖，舞者投入其中的澎湃激情更是呈现出的打动人心的艺术美感。无论是独具创意的现代舞、优雅柔美的民族舞，还是激情动感的街舞、高贵典雅的交谊舞，都让观众们眼前一亮，获得了评委老师的好评。

经过激烈角逐，OLT舞队凭借《雨溅音盒》的精彩演出夺得了首届舞林大会“舞林盟主”称号。
