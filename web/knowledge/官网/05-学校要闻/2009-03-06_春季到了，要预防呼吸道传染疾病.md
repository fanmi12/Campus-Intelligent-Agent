# 春季到了，要预防呼吸道传染疾病

春季气候变暖，细菌、病毒等微生物繁殖加快，加上气候变化无常，早晚温差较大，导致人的抵抗力下降，是流感、麻疹、风疹、腮腺炎、甲肝、乙肝、霍乱、痢疾等传染病的多发季节，医务所医生要求广大师生注意预防呼吸道传染疾病。

为此，学院医务所万玉君医生提供了一些预防方法：接种疫苗是预防传染病的特效措施，是阻击传染病的最积极的手段，也是投资小、收效大的预防措施；养成良好的个人卫生习惯，饭前便后、外出归来一定要洗手，勤换、勤洗、勤晒衣服、被褥，不随地吐痰；常开门窗，使教室、宿舍空气流通。
