# 第三届大学生职业规划大赛报名突破3000人

由我院招生与就业办公室承办的第三届大学生职业规划大赛6月8日全面启动并网上接受报名。

据统计，截至7月2日，经省教育厅确认,我院成功报名参加大赛人数已达3048人，占全校人数的40%多，并有部分同学已经完成作品。

大赛组委会建议,参加比赛的同学应广泛收集有关资料,做好知识储备。暑假期间，应多到相关行业实践或访问相关人员，以获取具体、准确的职业信息，以便较快较好完成作品，较科学地规划大赛。

招生与就业办公室主任江小卫认为，有的大学生进入大学后的学习比较盲目，缺乏对以后职业的规划，举办职业规划大赛就是为了促进和帮助大学生提前树立职业理想，按照一定的目标发展和完善自我，为以后顺利就业做好准备。

据了解，网上报名截止时间为8月15日。
