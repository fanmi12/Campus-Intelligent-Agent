# 岗前培训“科目”多  新进教师收获大 学院各系部开展新进教工的岗前培训

为使新进教职工尽快提高业务能力和工作水平，从7月1日开始，新进人员开始到所属系部接受形式多样的岗前培训，接受培训的老师都称培训“科目”多，收获大。

基础篇：转变角色

参加培训的人员中大部分是刚刚走出校园的应届毕业生，他们普遍没有工作经验，对于学院情况和管理制度不了解，正处于从学生到教师的角色转变阶段。

文学与艺术系主任陈庆祝教授要求新教师们尽快转变角色，按优秀教师的标准要求自己，不仅做一个知识文化的传播者，也做一个道德品格的塑造者。

计算机与信息科学系主任牛熠博士强调，个人能力强固然重要，但团队精神同样不可或缺。作为年轻教师要树立团结互助的意识，不盲目单干，不随便蛮干，发挥集体的力量和优势，使整个教学工作和谐稳定的发展。

新老师们纷纷表示，他们通过培训，终于深刻理解到“教师的职责是教书育人，但育人又是第一位的，要做一名言传身教、行为师范、受人尊重的教师并非一件易事。”

提高篇：站稳讲台

记者一早来到3208课室的时候，机电系孙成访博士正在讲授关于臭氧层的一个知识点，她妙趣横生的语言和五彩缤纷的幻灯片吸引着台下的“同学们”聚精会神的边听边记录。

为了使新教师能尽快站稳讲台，新教师人数较多的文艺系、机电系和计算机系等系部均开展了示范教学、观摩录像、模拟教学、专家点评等形式多样的培训。

计算机系更是别出心裁，推出了“同一堂课上两遍”的新举措，即：新教师自己准备一节课的内容进行讲授，由专家来挑毛病，然后新教师进行整改，再次备课，再上第二次课。牛熠主任说，这样做是有压力，但压力是可以转化为动力的，这个办法的目的就是帮助新教师尽快站稳讲台，养成备好课、讲好课的好习惯。

总结篇：自我总结

岗前培训其实是一个发现问题、解决问题的过程。许多老师感觉在培训过程中收获颇丰。

宫恩天老师拿给记者看他做的笔记，说，以前是做学生时听过无数节课，现在要做老师了，听示范教学时候的心态不一样，我不是在听内容，而是在“听”这种授课的形式，例如：怎样合理运用多媒体，怎样因材施教，怎样组织教学，怎样培养学生学习的兴趣。我们从老教师身上学到了很多。

机电系新来的女博士李萼老师也说，虽然感觉自己学了很多知识，但想要把茶壶里的饺子倒出来也绝非易事。我们今天听了3位老师的课，各个精彩，却又各不相同，怎样使授课内容贴近学生，怎样和学生形成互动，避免“一言堂”等都是我要不断学习的内容。

据悉，新进教工在完成院内岗前培训后，7月21日将赴华南师范大学参加广东省高校教师资格的理论培训，他们将在那里学习《教育学》和《教育心理学》、《教师职业道德》等课程。
