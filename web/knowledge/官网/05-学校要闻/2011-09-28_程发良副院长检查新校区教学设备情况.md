# 程发良副院长检查新校区教学设备情况

新生军训即将结束，文化课程将正式开课。为使教学设备建设工作落到实处，9月27日，副院长程发良在教务处、图书馆、新校区管委会等部门领导的陪同下来到新校区检查教学设备的建设和准备工作情况。

程发良副院长检查了计算机房、中心机房、公共教学楼课室和图书馆，了解到，当前最为先进的校园网络信息中心已经建成，图书馆的藏书、杂志、报刊也都已到位，多媒体教学设施能够正常工作。

程发良副院长一行认为，新校区已万事俱备，完全符合正式上课的要求。
