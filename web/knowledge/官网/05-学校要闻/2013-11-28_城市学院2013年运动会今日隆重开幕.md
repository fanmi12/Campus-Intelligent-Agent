# 城市学院2013年运动会今日隆重开幕

雨过天晴，运动场经雨水洗涤过后更显宽广壮丽。标语牌“锻炼身体、增强体质、展示活力、超越自己”，“知识为头脑充电、运动为健康加油”醒目地环绕在运动场的四周。11月28日，2013年运动会在这里隆重开幕。东莞理工学院城市学院董事黎建烨，学院领导杨敏林、朱志德、朱冰、张林、陈丁堂、章德胜、高香林、麦绮琳出席开幕式并在主席台就座。

高香林副院长为开幕式致辞。他强调，生命不息，运动不止。本次运动会以“青春、运动、友谊、健康”为主题，希望运动员们在赛场上奋力拼搏，赛出风格，赛出水平，充分展现城院人的风采。裁判员和工作人员要确保比赛顺利进行、圆满成功。

运动员代表岑荧菲和裁判员代表周翔先后发表誓言，立誓积极参与，公正裁判，再创佳绩。

伴随着激昂的《运动员进行曲》，国旗方队、院旗方队、献花方队、彩旗方队的健儿们迈着矫健的步伐昂首进场，瞬间使赛场置身在猎猎旗海中。随后各系代表以饱满的精神、自信的笑容，通过主席台接受领导检阅，他们或高举条幅誓言，或喊着嘹亮的口号助威，或变换队形彰显个性，充分展现了城院学子朝气蓬勃、拼搏超越的风采。寒风中，着装火辣的啦啦队和篮球宝贝健美操的表演将现场气氛推向高潮，动感的节奏、舞动的倩影、高难度的腾空跨越，无不散发着旺盛的青春活力，更是预示着运动员们超水平的发挥和本次运动会的圆满成功。教工们和着广播体操的音乐，表演了第九套广播体操。他们一丝不苟的态度和标准的动作更是赢得一阵又一阵的欢呼。

由我院体育教学部教师自编、自排的《活力健身带》、《梦想起航》、《青春飞扬》的系列表演精彩夺目，为全体师生带来了一场视觉享受。伴随着悠扬的青春节拍，360名大一女生挥舞着手中的彩带，不断变换队形，诠释着“我锻炼、我健康；我快乐、我青春”的健康理念。623名青春少女尽情地挥动手中的彩扇，时而用扇面组成“2013”或城院的英文字母简称的字样，时而变幻出翱翔的海鸥，让现场的师生大饱眼福。武术表演队，太极扇和跆拳道表演方阵也让现场观众热血沸腾，刚柔并济的动作，一招一式都颇具力量，体现出“兼收并蓄、勇于创新”的办学理念与城院精神。35名跆拳道表演队员用拳和腿击破对方手中的木板，更是喻示我院的明天如破竹之势，节节胜利。随后，各项比赛相继展开。

据悉，为期两天的运动会将进行100米、200米、400米、800米、跳高、跳远、铅球等29个项目的比赛。运动会还为教职工设立了“保龄球”、网球掷准、慢骑自行车、一分钟跳绳、二人三足等趣味运动比赛项目。
