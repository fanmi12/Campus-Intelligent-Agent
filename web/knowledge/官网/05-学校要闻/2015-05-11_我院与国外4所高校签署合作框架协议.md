# 我院与国外4所高校签署合作框架协议

近日，国际交流中心与美国北爱荷华大学、英国阿伯泰大学、北安普顿大学、安格利亚鲁斯金大学进行了学术交流与合作洽谈，顺利签署了合作框架协议。

据悉，根据我院与国外高校的专业匹配程度，国际交流中心正在进行17个专业的课程对接工作。基于校际课程及学分互认，我院学生届时可自由申请上述高校的2+2、3+1模式的本科阶段学士学位，也可以申请攻读上述高校的硕士学位。
