# 喜讯！我校会计学专业入选国家级一流本科专业建设点

近日，教育部印发《教育部办公厅关于公布2020年度国家级和省级一流本科专业建设点名单的通知》（教高厅函﹝2021﹞7号）。我校会计学专业入选2020年度国家级一流本科专业建设“双万计划”建设点名单。会计学专业入选国家一流本科专业建设点名单，是我校在专业建设上的一项重大历史性突破，标志着我校在专业建设、教育教学改革上取得了显著成效，开启了专业内涵建设的新篇章。

会计学专业目标定位与人才培养上上积极响应粤港澳大湾区建设国家战略，立足东莞高端制造业，面向湾区经济社会发展，顺应智慧财务发展趋势，突出“会计+AI”管理会计人才培养，产教融合，服务湾区地方经济社会发展，以立德树人为根本，全面践行“三全”育人，培养具有国际化视野、数据思维和创新创业精神的国内一流应用型管理会计人才。

据了解，我校会计学专业于2006年经教育部批准正式招生；2011年11月通过广东省学士学位授权评审；2014年被列为校级重点建设专业。2016年被列为东莞市财会人才培养重点教学基地；2017年建成为广东省应用型人才培养示范专业。

此次会计学专业入选为国家级一流本科专业建设点，正逢学校转设之际，我校继续发挥专业建设特色优势的同时，积极探索数字化和人工智能化新财会人才培养的路径，不断加强专业建设，提高人才培养质量。
