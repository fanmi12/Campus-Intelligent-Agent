# 郭世杰同学荣获广东省2018年“首席实习生”荣誉称号

12月2日，广东省2018年“首席实习生”评选活动总决赛暨颁奖仪式在广东技术师范大学举行。商学院郭世杰同学在总决赛上，以第2名的佳绩荣获广东省2018年“首席实习生”荣誉称号。我院团委也获得了2018年“首席实习生”评选活动突出贡献单位。

在总决赛个人主题演讲环节，郭世杰同学运用在华硕公司的实习经历，精彩地诠释了“欲戴皇冠，必承其重”的主题。在团队情景模拟环节，面对评委的提问，他妙语连珠，巧妙应答，其出色表现赢得了评审团的一致赞赏。

据悉，广东省2018年“首席实习生”评选活动自开赛以来，吸引了全省23718名选手报名参赛，大众投票阶段吸引近267万人次参与投票，竞争十分激烈。我院共有4078名同学踊跃报名参赛，成为全省报名人数最多的高校，并有5名同学成功进入150强。
