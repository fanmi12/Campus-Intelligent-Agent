# CCAT授权考试中心落户我院

我院与全国信息化计算机应用技术水平教育培训管理中心深化合作再添佳话，3月21日，全国信息化专业技能认证（简称CCAT）项目在我院继续教育中心举行授牌仪式。CCAT广东省管理中心副主任程奇出席了授牌活动。

据介绍，CCAT项目是为社会大规模培养信息化发展所需的应用型、管理型、决策分析型专业技术人才，以重点培养实践能力和管理能力为主要特色的、全国性的培训、认证项目，考试认证体系与国内、国际多所权威机构实现互认，其证书国内、国际认可。目前，CCAT项目有机电、设计、网络、信息技术、电子、商务管理六大认证体系，各认证科目分为三个级别：高操作员级，助理工程师级，工程师级。CCAT项目在广东省共与75所院校机构设有考试、培训中心。

此次CCAT项目考试中心落户我院，为城院学子学习提供了便利条件，更好地契合学院对应用型人才培养的发展要求，有利于满足广东省经济社会发展与产业结构调整对高校实用型人才的需求。
