# 城市学院首届书香社征文大赛揭晓

在学院团委的授权下,书香社于去年底组织开展的以大学生“立志•修身•博学•报国”为主题的征文比赛最近揭晓。本次征文活动共收到稿件300多份,经评议共有25名同学获奖。这次活动得到了学院团委学习部，宣传部的大力支持。获奖名单见附表。
