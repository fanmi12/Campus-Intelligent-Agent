# 【众志成城 抗击疫情】相约线上课堂——优秀教师经验谈之四

我校坚决贯彻落实教育部、省教育工委、省教育厅的重要部署，从3月起全面开展线上教学活动，全体任课教师坚守岗位、锐意创新、勇挑重担，全力做好线上教学工作。前三期我们精选刊发了十位优秀教师线上教学经验谈后，在全体教师中产生了良好的反响，受到广大师生的欢迎。今天刊发第四期，推介马克思主义学院向前、计算机与信息学院张宗杰、外国语学院张艺馨三位老师的线上教学心得体会，供大家分享。

马克思主义学院向前老师线上教学心得体会：

1.把握线上、线下教学的区别与联系，分析各自的优势和不足。

2.掌握线上教学技术，总结线上教学规律，尽可能使教学的手段、方法、目的有机结合。

3.选用操作简便、界面友好的教学平台，如“课堂派”等。

4.补充MOOC课程所没有的新思路而不仅是新知识，给学生以获得感，也体现本校老师的价值。

5.综合使用音、视频和文字进行互动，给学生展示的机会。

6.在平台及时记录学生各教学环节的表现，给学生以看得见的成绩，提高学生的成就感。

计算机与信息学院张宗杰老师线上教学心得体会：

1、备课：由于上课时长相较传统课堂有所缩短，因此，一定要聚焦所授章节的重、难点，充分凝炼知识要点。

2、上课：对于本节课的重、难点，深入浅出的着重讲解；对于学生较易理解的知识点，采用提问和总结的方式让学生充分参与进课堂。

3、课后：鼓励学生将疑问知识点和习题通过班级企业微信群交流，充分利用课后时间进一步讨论和巩固所学内容，了解学生薄弱的环节，将需要强化的内容分享在交流群。

外国语学院张艺馨老师线上教学心得体会：线上教学作为疫情期间的一种特殊教学形态意外打开了我教学路上的新天地，原本担心没有课堂教学互动效果好，但我发现只要老师把教学内容组织好，透过屏幕学生会更敢也更愿意发言，通过视频直播让学生“看见”老师，学生会更有现场感，教学不仅是通过语言来传播的，老师的肢体语言，神态，表情其实都参与了教学，通过直播时的留言互动老师也可以及时了解学生对知识的掌握程度，同时，半个小时的讲解更能够突出重点，提炼精华。
