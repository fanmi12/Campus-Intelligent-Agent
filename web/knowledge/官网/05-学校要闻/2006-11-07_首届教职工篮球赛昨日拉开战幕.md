# 首届教职工篮球赛昨日拉开战幕

11月6日，城市学院第一届教职工篮球赛在教工球场拉开战幕。经过激烈的角逐，男子，机关23：8战胜机电系，计算机与信息科学系24：21险胜社会科学系。女子，机关24：2战胜管理系，机电系20：2战胜教辅。

本届篮球赛参赛单位包括机关、教辅、总务处以及各系代表队。全院9个系部，18支参赛球队分男女进行单循环赛。比赛将持续11天，于11月17日结束。男队冠军还将于次日与体育教学部加赛一场。
