# 东莞电视台青春励志微电影《心•湖》在我院招募演员

4月15日下午，由东莞广播电视台、盈丰湖景壹号联合拍摄的青春励志微电影《心•湖》在我院招募演员。我院艺术系、艺术团以及各院系表演艺术爱好者100多人参与招募活动。

东莞电视台对报名者进行了初审、才艺展示、角色试镜等环节的考核。负责招募活动的东莞电视台罗欣记者表示，本次考核的演员各项素质都很好，剧组将根据具体角色需要进行筛选，并希望本次活动后，能够有更多的同学积极参与到微电影拍摄中来，充分展现才华。

据悉，《心•湖》是一部围绕责任、传承、爱情的青春励志微电影，讲述的是年轻的家族企业继承人在父亲病重后，面对突如其来的多重压力，从退缩、逃避到主动承担的人生蜕变过程。该剧反映了当代都市“80后”青年理想爱情与责任压力矛盾交织的生活状态，是当代社会正能量故事的真实写照。

本次微电影演员东莞地区招募活动共分4场进行，分别在东莞理工学院城市学院、湖景壹号销售中心、东城世博广场和厚街明丰广场举行。入围名单将择日宣布。
