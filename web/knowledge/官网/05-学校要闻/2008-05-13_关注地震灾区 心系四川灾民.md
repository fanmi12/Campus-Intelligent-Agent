# 关注地震灾区 心系四川灾民

5月12日下午，当四川省汶川县发生7.8级地震的消息在媒体公布以后，我院师生员工无不为之震惊，纷纷关注各类媒体关于灾情的报道。

当大家看到一幅幅惨烈的灾情画面时，许多同学流下了同情的泪水，痛恨万恶的地震又一次夺走了多少个鲜活的生命。据记者观察，昨晚全院各宿舍区显得出奇的安静。

财经系陈玲玲同学说：“地震无情人有情。我们坚信，有党中央、国务院的正确领导，灾区人民一定能战胜灾害，度过难关，重建美好家园。如果需要我们支援一点什么，一定尽力而为。”

据记者从有关方面了解，东莞近期不会发生地震，院领导希望大家安心学习，安心工作，用实际行动支援抗灾斗争。
