# 我院举行校长交流会暨招生形象片发布会

6月13日下午，我院在行政楼112会议室举行了校长交流会暨招生形象片发布会，并对石龙中学等9所中学进行优质生源基地授牌仪式。

石龙中学、市第五高级中学、万江中学、厚街中学、市第六高级中学、市第七高级中学、济川中学、市第四高级中学、常平中学等中学的校领导，东莞理工学院、广东医科大学、中山大学新华学院、东莞职业技术学院、广东亚视演艺职业学院、广东创新科技职业学院、广东科技学院、广东酒店管理职业技术学院等高校的校领导，以及学院董事会代表陈超群和学院院领导王卫平、章德胜、高香林、黄兢、刘玉侠等出席了会议。

我院教务处牛熠处长、招生就业处孔增强处长分别向大家介绍了我院专业建设情况和2017年招生计划情况。据介绍， 2017年秋季，我院38个本科专业，其中新增“舞蹈编导、秘书学、投资学、工业设计”四个专业，计划招生5150人；2017年本科插班生已完成招生354名。我院整体计划招生共计5504人，再创历年新高。

会议还对石龙中学、万江中学、厚街中学等9所中学进行优质生源基地授牌，这标志着我院与授牌中学之间搭建一座新的桥梁，有助于加强双方的交流互动和优质教育共享，促进共同发展。

王卫平院长表示，希望以此次“优质生源基地”的建立为起点，双方开展更多层次、更多内容的合作，互惠双赢、共同发展。

会上，东莞理工学院城市学院招生形象片——《一朝遇见 一世眷恋》进行首次公映发布会。招生形象片主要通过四名有所成就的城市学院毕业生依照约定回到母校，在参观母校的过程中，回忆起过往的点点滴滴，深深体会到学院在生活、学习、成长各方面给他们带来的深远影响，展现城市学院“人生导师”的形象。短片的一大特色意是从学生的视角出发，将校园生活中琐碎的场面展现在学生面前，通过在读学生的叙述，让在城市学院的大学生活徐徐展开。“学生”在这部片子中居于核心地位，学生完完全全做了主角，大有“我的地盘我做主”的韵味。更重要的是在短片中，通过学生的叙述能够感受到城市学院对学生的关怀，不仅体现在生活上的无微不至，还表现在为他们提供实现梦想的条件。而它所培养出来的学生又将这种关怀运用到了实际中，他们通过自己的努力和行动去关怀社会、回报社会。
