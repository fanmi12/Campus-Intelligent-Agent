# “大学生都是活雷锋”

3月3日，市文明办、团市委、市志愿者协会共同举办的“学雷锋·做义工”志愿服务月---便民集市活动在莞城文化广场举行。四个城区及城市学院的志愿者参与了本次活动。

活动现场人山人海，气氛热烈，特别是城院志愿队的摊位前聚集了不少家长和小朋友。记者在现场看到，原来这是手工DIY，志愿者们在教小朋友们做纸花，小朋友们及家长、志愿者一个小时就做好了320支纸花。小朋友阿华的妈妈说，她们做的小花将要送放到雷锋照片前以表对雷锋的纪念和崇敬。

我院志愿队还开展免费为居民维修电脑的项目，同样也吸引了不少的居民。一个下午的时间，同学们共维修了8台电脑。张奶奶的电脑图像不清楚，机电系陈志和同学查找了原因，告诉张奶奶现场修复的难度大，在征得张奶奶的同意后，将电脑带回学校，表示修好后送到她家去。张奶奶非常感谢他，连声说；“大学生都是活雷锋！”

据了解，城市学院志愿者们还将在校园开展植树、捐衣、修电脑等活动。
