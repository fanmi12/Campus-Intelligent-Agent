# 我院学生参加第三届亚洲（东莞）国际激光加工装备应用技术论坛

5月14日，我院计信系与机电系50位学生在谢俊、陈浩华和唐征玲三位老师的带领下，赴东莞市科学技术博物馆参加第三届亚洲（东莞）国际激光加工装备应用技术论坛。

中国科学院院士、华南师范大学信息光电子科技学院院长刘颂豪，中国光学光电行业协会激光协会分会名誉理事长邓树森，上海市激光技术研究所所长张伟，百超（上海）精密机床有限公司董事总经理王鹤龄、Newport&Spectra-Physics中国区项目经理孙春峰，中国科学院长春光电所研究员王立军等专家领导，以及来自各高校、科研所的专家学者出席了本次论坛。

专家们在论坛上分别作了《激光加工装备的核心技术—激光器研究现状与展望》、《振兴制造业中的激光加工》、《激光精细加工的产业应用与发展》、《高速激光切割》、《脉冲激光在精细加工中的应用》、《大功率半导体激光作为直接光源的加工技术》等学术报告。

同学们与专家学者面对面，并认真地听取了他们的学术演讲。据学生反映，这些现代前沿的科技知识使他们拓宽了视野、增长了见识。
