# 副市长成洪波为我院实践基地“东正社区综合服务中心”揭牌

近日，东莞市人民政府副市长成洪波、东莞理工学院副校长、东莞理工学院城市学院院长安少华为我院社会实践基地“东莞市莞城东正社区综合服务中心”揭牌。

成洪波副市长在挂牌仪式上，对我院社会工作教研室成立以来积极参与社会建设，在科研和实践方面不断探索新的发展模式、给东莞发展提供智力支持和政策倡议、促进社会和谐等工作表示了高度的肯定。他指出：做好综合服务中心建设，还要在硬件配套、人性化管理、制度化建设等方面加强改善，在服务需求挖掘、服务模式探讨等方面继续探索，给东莞社会建设提供榜样和参考。

据社工教研室主任周巍介绍，东正社区综合服务中心是全市首批二十个社区综合服务中心示范点之一，作为东莞理工学院城市学院的实践基地，由社会工作教研室和莞城东正社区共建共管。中心共分28个功能室，以“尽我所能，服务社群”为服务宗旨，致力于残康服务、长者服务、家庭服务、青少年服务等社区工作，为社区居民提供高质量的新莞人服务，社区组织孵化培育服务，便民利民服务等一系列专业服务活动。服务中心还将成为我院社区管理、社会工作等专业的在校学生实践平台，并提供毕业生就业岗位。

东莞市民政局局长杨东如、莞城街道办书记刘林宏、莞城街道办主任陈慧贞、莞城区区长梁丰和我院政法系主任刘杰教授、社工教研室主任周巍等出席了揭牌仪式。
