# 学院召开2012年度本科教学质量年报编写协调会

9月29日，学院在行政楼207会议室召开2012年度本科教学质量年度报告编写协调会。院督学陈丁堂教授、副院长高香林教授出席会议，学院办公室、组织人事处、高教研究与评价中心等相关职能部门负责人及工作人员参加会议。

会上，高教研究与评价中心副主任王锦锋传达了省教育厅关于编制2012年度本科教学质量年报视频会议精神，详细介绍本科教学质量年度报告的关键内容、核心数据的内涵，对我院撰写2012年度本科教学质量年度报告的工作任务进行了分解，提出了具体要求。

院督学陈丁堂教授在会上指出，教学质量年度报告事关学校发展，各部门要明确任务，各司其责，认真落实，全面准确地反映我院的教学质量，同时要反思、找准学院在人才培养和教学质量中存在的问题，有针对性地提出改进的措施。

高香林副院长强调，2012本科教学质量报告的撰写工作时间紧、任务重，各部门要克服困难，根据2012年教学工作的实际情况，统筹本部门材料的整理与撰写工作，齐心协力做好教学质量年报工作。
