# 金贸系男篮连续四年卫冕冠军

11月2日下午， 2017-2018赛季“城院杯”篮球联赛决赛在综合馆内进行。金贸系队与机电系队上演了一场精彩的巅峰对决！最终，金贸系队以73:52第四次蝉联冠军，机电系队和管理系队分别获得亚军和季军。

随着主裁一声哨响，机电系队率先抢得球权，并得分。金贸系队谨慎开场，未能“梦幻”开局，以8:11结束首节。

第二节，落后的金贸系加大“2-3”联防力度，随着4号尹伟权命中一记稳定军心的3分球而开始渐入佳境，打出一波17:1的小高潮。上半场战罢，金贸系队以38:21领先。

中场休息，精彩的3分球大赛引爆全场，来自各院系（部）的3分射手尽显其能。最终，金贸系14号球员钟宏旭凭借出色的发挥将“三分王”桂冠收入囊中。

易边再战。机电系队开始通过防守拼抢加快比赛节奏，6号刘振荣开场便命中一记3分球，鼓舞了士气。金贸系队迅速做出调整，在19号叶锐城投中3分后，球员们打出了一波行云流水的进攻，以60:37的绝对优势结束本节。

最后一节，金贸系队气势如虹，11号何彦昭手感滚烫，连突带投单节砍下9分。面对大比分落后的局面，机电系队始终奋力追赶，打出一波力挽狂澜的10:0高潮，但因分差相距过大，最终以总分52:73不敌金贸系队。

第五届篮球文化节经过15天的激烈追逐，计信系、财经系、政法系分别获得第四、五、六名。金贸系队员何彦昭获得本届篮球文化节MVP，陈芷慧等15人获得优秀工作人员奖，岑根源等10人被评为优秀裁判奖，黄荣斌等10人获得优秀运动员奖，韩德超等6人分获得摄影大赛一、二、三等奖。

个人单项奖方面，大赛还评选出了最受欢迎篮球宝贝张莹莹、联赛篮板王曾志城、得分王何彦昭，以及最佳新人奖庾世聪。

优秀集体奖方面，政法系获得体育道德风尚奖，城环系获得啦啦操比赛最佳编排奖，财经系啦啦操体操队夺得第一名。

相关报道：成功源自全队目标一致

——访第五届篮球文化节MVP、金贸系队员何彦昭同学

记者：你认为是什么原因让金贸系队蝉联四连冠？

何彦昭:首先，我们队员的目标都是一致的，都是奔着总冠军去的，所以大家很团结。而且我们也会把院队的篮球训练方式及比赛技巧分享给其他队员，让整个队共同进步。大家良好的篮球素质是获得总冠军的重要原因。

记者：在第一节中比分落后的情况下，是如何调整追平比分的？

何彦昭:我们先观察第一节球员们的比赛节奏，根据出现的漏洞，在第二节对人员和战术进行调整，取得了满意的效果。

记者：作为一个大四学生，在毕业前拿到MVP和得分王有何感想？

何彦昭:我很高兴能拿到这些奖项，很感谢我的队友们，这两个个人奖项离不开整个球队的队员的努力付出。希望金贸系能延续我们总冠军的传统，在今后篮球文化节中继续夺冠，“称霸”城院CBA。
