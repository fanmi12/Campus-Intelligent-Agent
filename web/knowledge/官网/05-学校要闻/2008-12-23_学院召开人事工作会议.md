# 学院召开人事工作会议

12月18日，学院在大礼堂召开人事工作会议，全院教师参加了会议，党委书记朱志德主持会议。

会议首先听取了人事处处长夏勇关于人事工作的情况通报。报告认为，学院人才引进的层次不断提升，已由“求数量”转为“求质量”；师生比和教职工职称结构不断优化，高级职称教师已占专任教师的25%；岗前培训、青年导师制、青年教职工暑假社会实践等师资培训工作初见成效，先后有60多名教师赴国内外重点高校参观考察和学习，近10位教师正在攻读博士学位。对于明年人事工作的设想，夏处长介绍说，学院将创新策略力争引进高层次人才；加大考核力度，严格执行设岗定编方案，认真贯彻实施09版绩效考核管理办法，真正做到优胜劣汰，全面实施师资队伍建设的各项新举措。

张林副院长在会上做了题为《新形势下的人事工作思路和举措》的报告。他在报告中指出，面对新形势，我们要认真分析新情况，形成新思路，采取新举措，开创新局面，实现新发展。他认为，学院已顺利完成打基础、扩规模的工作，重心将转移至“上水平、创特色”。我院经过几年的努力，学科布局、师资队伍建设基本完成，职称结构渐趋合理，薪酬待遇有了较大幅度的提高，规章制度逐步建立健全。张副院长说，今后，学院在人才引进和管理工作上，将“突出重点”，引进高层次人才；“拾遗补缺”，引进各学科和专业紧缺的人才；“拓宽渠道”，主动寻找推荐人才；用“特殊政策”留住特殊人才；严格合同管理，维护职工和学校的权益；进一步明确岗位设置与岗位职责，加强绩效考核与薪酬管理，不断完善师资培训与职称晋升等制度。

东莞理工学院副校长、城市学院院长安少华在会上发表了重要讲话。他要求院系领导应继续解放思想，通过人事工作的创新促进学院的发展。要顺应国家人事制度改革的大趋势，由固定用人改合同用人，由身份管理改岗位管理。作为公益性教育事业单位，我们要克服官僚化倾向，在用人机制上要充分发挥独立学院的优势，认真执行并严格遵守教代会通过的定岗定编方案。进一步完善薪酬体系和考核机制，做到人权、财权、事权协调统一。按“能者上，平者让，庸者下”的原则，岗位既可以低职高聘，也可以高职低聘，实行末位淘汰制度。

安院长进一步强调，要继续保持和发扬城院创业时艰苦奋斗、勤俭办校的优良传统，树立主人翁意识。他表示，城市学院的未来与发展，寄希望于青年教职工。45岁以下的青年教师与他们的父辈有很大的区别，他们的父辈生活在计划体制下，工作无压力，但也无动力。现在的青年教师居于计划体制之外，有更多的自由，也有更大的创造力和活力，但压力大，未来方向不清，前途不明，而这一批人（约占全院教职工总数的80%）却代表着城市学院的未来，所以，要特别关爱他们。我们要形成共识，教师收入有了大幅度提高的情况下，应该着力提高教育教学质量，控制办学成本，为城市学院创造辉煌的明天。
