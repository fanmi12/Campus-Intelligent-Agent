# 东莞文化创新学堂启动仪式在我院举行

5月22日下午，由东莞市文化广电新闻出版局主办，东莞市城市品牌创新中心承办，我院创意设计学院、东莞广州美院文化创意研究院、东莞市文化产业发展促进会协办的“2018年东莞文化创新学堂启动仪式”在我院举行。东莞市文化广电新闻出版局副局长蔡国康，学院党委副书记章德胜、院长助理林江龙等领导出席了活动。

活动公布了2018年东莞文化创新学堂活动计划，并举行了学堂新设项目“文创工作坊”的揭牌成立仪式。同时，聘请广州美术学院视觉艺术设计学院院长、广州美术学院国家广告产业园负责人曹雪，好合苑文创品牌执行董事暨品牌执行长、东莞台商协会莞城分会会长杨琦兰，东莞本土视觉设计师、艺术指导谢瑞康，东莞市商业设计协会副会长、TOB商业设计集团董事总经理、深圳市八零社广告有限公司总监理刘征国，东莞金马会副会长、东莞市斯乐克电子董事长徐作为，鲁能集团华南区域设计总监吴坤等6位文创领域的知名人士为“文创工作坊”首批导师。

据了解，为推动东莞市文化产业向高端迈进，东莞市文化广电新闻出版局于去年开始举办“东莞文化创新学堂”系列活动，以文创公开课、课堂研究、项目拓展等形式，汇聚文创大家、高校学者、新锐文创先锋人物、文创企业，以及行业协会和媒体等资源，旨在打造文化产业信息交流、行业发展研究、文化创意人才与资源链接、文创项目品牌培育与传播的多功能共振平台。

蔡国康副局长表示，文化产业是智力密集型产业，文化产业的发展离不开人才的支撑。“文化创新学堂”在探索打破制约文化产业高质量发展的瓶颈、活跃文化氛围、提升人才技能、培育新生力量等方面取得了明显成效。今年，“文化创新学堂”继往开来，承载了东莞市文化产业发展的重要使命。一是提升文化创新水平，成为产业助推器；二是链接文化创新资源，成为产业连接器；三是孵化优质文化项目，成为产业孵化器。

院长助理、创意设计学院院长林江龙表示，“文创工作坊”的成立，是创意设计学院“建设广东省试点学院”项目的又一项重要举措和标志性成果，标志着在对接东莞文创产业、产教融合及有效促进创新创业及专业发展方面迈出了新的一步。深度参与在地文化建设，与在地文化主管部门、行业协会和企业共建产学研实践平台是高校设计类专业应用型本科建设的一个重要环节，文创工作坊将为学院师生提供一个链接政府、企业及在地文化的重要平台。

创意设计学院副院长、东莞市文创工作坊负责人何帅介绍说， “文创工作坊”将作为东莞文化学堂的平台升级的抓手，按照产学研平台的发展方向，开展人才培育、产品创作与应用、品牌孵化与传播等三方面的研究与实践，将整合各类资源，力争三年内形成品牌效应。

活动还举办了2018年东莞文化创新学堂首场文创大咖公开课。广州美术学院视觉艺术设计学院院长、广州美术学院国家广告产业园负责人、广州首个城市形象LOGO设计者曹雪教授进行了“本色与角色”主题分享。
