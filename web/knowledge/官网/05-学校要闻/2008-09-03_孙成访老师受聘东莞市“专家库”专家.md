# 孙成访老师受聘东莞市“专家库”专家

9月2日，记者从东莞市经济贸易局［2008］207号文件中获悉，我院机电系教师孙成访博士受聘“东莞市节能降耗与清洁生产专家库”专家。首批32位专家都具有工程师以上的技术职称。

为充分发挥我市专业人才资源优势，更好地推动我市节能降耗和清洁生产各项工作，东莞市经贸局决定成立“东莞市节能降耗与清洁生产专家库”。专家库专家的主要职责是，以客观公正、认真负责的态度，积极参与节能降耗和清洁生产政策推广、规划编制、项目评审、技术培训等工作，并为企业开展相关工作提供咨询服务。
