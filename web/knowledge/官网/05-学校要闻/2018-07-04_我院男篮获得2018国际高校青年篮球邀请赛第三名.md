# 我院男篮获得2018国际高校青年篮球邀请赛第三名

2018国际高校青年篮球邀请赛6月28日在澳门大学正式打响，来自世界各地的大学生篮球健儿同台竞技。我院男子篮球队参加了本次大赛，并获得“德晋杯”第三名。此外，黄明健同学获得优秀运动员称号。

比赛中，我院男篮先后与台湾国立体育大学、香港大学、中国华侨大学、五邑大学等境内外强队对阵。经过5天激烈的角逐，我院男篮获得“德晋杯”第三名的好成绩，队员黄明健获得优秀运动员称号。

最终，韩国代表队获得大赛冠军。
