# 大学生科技文化论坛第五十四期开讲：娱乐化时代与青春的诗意

11月26日，大学生科技文化论坛第五十四期在学术报告厅开讲。本讲座邀请北京师范大学文学院谭五昌教授，为我院师生讲授主题为“娱乐化时代与青春的诗意”的精彩演讲。文传系领导李上文、孟颖、吴士田、东莞广贸外语科技专修学校副校长肖章洪、凤岗文联副主任林汉筠、诗人汪雪英等出席讲座。文传系主任李上文主持了讲座。

谭教授以其独特的视角和诗一般地语言，阐释了一个重要的主题——娱乐化时代，作为学子应该理性选择自己的立场，做时代“文化英雄”。

在演讲中，谭教授阐明一些很有见地和价值的观点。例如：现代社会人们价值观存在过于“娱乐化”的问题。勉励城院学子不要受“娱乐化”的影响，要树立正确的文化价值取向，努力成为对国家社会和文化发展起到推动作用的“文化英雄”。他还认为：诗歌离我们的生活很近，诗歌在文化融合和人文关怀上具有重要意义。指出，诗歌不仅是社会文化的百科全书、民族文化永恒的记忆，一首诗歌就是一部历史，还能为受伤的民族带来精神的慰藉。他还认为：中国人要有诗歌的语言，诗歌是语言浓缩的精华，是彰显文化素质修养的重要载体。他殷切地期盼城院学子：要读诗、赏诗、写诗，关注诗人，关注诗歌，热爱诗人，热爱诗歌，以梦为马，与诗歌同行。

谭教授以其独特方式和维度以及激情，生动地演绎了诗歌的文化内涵和价值。学生们反应热烈，积极提问，与谭教授对话，表现出对诗歌文化兴趣的浓厚。
