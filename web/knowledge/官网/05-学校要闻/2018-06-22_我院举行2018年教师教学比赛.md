# 我院举行2018年教师教学比赛

我院2018年教师教学比赛结果近日揭晓，计信系杨宇老师以综合得分90.5分获得一等奖。

6月7日下午，学院举办2018年教师教学比赛决赛。王卫平、刘玉侠、林江龙三位院领导出席了活动。牛熠教授担任大赛评委组组长，评委组由宋欣荣、赖忠孝、何力平等七位老师组成。教务处处长赵书山主持比赛。

12位参赛老师现场从五个规定课题中抽取其一个，进行限时15分钟的课堂教学展示。评委组从教学内容、教学组织、教学方法、语言教态和教学特色等五个方面进行评分。参赛老师们通过循循善诱、深入浅出地帮助学生理解知识,热情高涨的课堂互动,激发了学生的听课热情，展现了我院教师精湛的教学水平。

经过角逐，计信系杨宇老师以综合得分90.5分获得一等奖，政法系丛珊、城环系胡静姝老师获得二等奖，机电系田乐园、外语系李小冰、文传系李玫莹、金贸系毛新平、商学院洪树权老师获得三等奖。艺术系徐婷婷、电智院刘运城、创院俞敏、思政部刘学勤老师获得优秀奖。

据悉，在比赛中表现优异的老师将被推荐参加省级教学比赛。
