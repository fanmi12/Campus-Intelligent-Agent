# 我校在全国计算机能力挑战赛取得优异成绩

近日，第七届全国高校计算机能力挑战赛全国总决赛结果正式揭晓。我校学子凭借扎实的专业功底、出色的实践能力和创新思维，在这场国家级赛事中脱颖而出，取得了优异成绩。本次赛事我校共有315人次报名参赛，在区域赛（省赛）中，我校学生获一等奖15人，二等奖55人，三等奖63人，累积133人次获奖；其中70人入围国赛。在国赛（决赛）中，我校学生获一等奖2人，二等奖4人，三等奖25人，累计31人次获奖。其中，杨健、胥建鹏、吴观全、崔燕茹、王芳芳、胡良兰、徐俊龙和尚新萍等多名老师获“优秀指导老师”；我校获“优秀组织奖”单位，展现了我校人工智能和计算机相关专业教育教学的丰硕成果和师生学子的良好专业素养。

全国高校计算机能力挑战赛由全国高等学校计算机教育研究会主办，是进入中国高等教育学会发布的《全国普通高校学科竞赛排行榜》观察目录的国家级赛事，赛事以“以赛促教，以赛促学，以赛促产教融合”为初心，备受全国各高校认可。第七届赛事吸引了全国1500余所高校的4万余名学生参与，竞争十分激烈。赛事设置大数据挑战赛、人工智能挑战赛、Office高级应用赛、程序设计挑战赛、数字媒体创新设计赛五大赛项13小赛项，分设个人赛与团队赛，历经区域赛、全国总决赛两个赛段层层选拔。

此次在全国高校计算机能力挑战赛中取得佳绩，是我校深化产教融合、推进人工智能和计算机教育教学改革的重要成果，不仅检验了我校学生的专业知识和实践应用能力，也为学子们提供了展示自我、交流学习的优质平台。同时，赛事的备赛与参赛过程，也进一步提升了我校教师的实践教学能力和赛事指导水平，为后续人才培养积累了宝贵经验。

未来，我校将继续以学科竞赛为抓手，深化“以赛促教、以赛促学、以赛促练”的人才培养模式，不断优化课程体系，强化实践教学环节，着力提升学生的专业核心能力和创新创业能力，为新时代培养更多兼具理论知识和实践能力的人工智能和计算机领域高素质应用型人才，助力学校学科专业建设再上新台阶。
