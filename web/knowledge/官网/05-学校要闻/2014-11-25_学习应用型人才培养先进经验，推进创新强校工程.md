# 学习应用型人才培养先进经验，推进创新强校工程

11月19日，我院在行政楼212会议室召开关于暑期赴台研修总结的座谈会。院领导杨敏林、张林、陈丁堂、章德胜、高香林、麦绮琳，机关各处室负责人、各系部主任以及暑期赴台研修人员参加会议，会议由党委副书记章德胜同志主持。

财经系鞠成晓老师等10位代表在会上汇报赴台学习的有关情况，重点介绍了台湾义守大学的发展规划、顶层设计、专业设置、应用型人才培养、通识教育、公共服务体系建设等方面的经验与作法，结合学院发展实际献言献策。

院长杨敏林在会上作了重要讲话。他肯定了赴台研修的学习的形式与成果，认为义守大学的一些亮点措施和服务理念值得借鉴和学习，今后要进一步加强赴台学习的针对性。学院要成立专题小组，以项目的形式进行深入研究。赴台研修人员要写出观感和体会并汇编成册，供全院教职工参考学习。所学所得要运用到教学管理工作中。同时，对于学院的改革发展要大胆尝试和创新，将好的想法变成具体的行动，推进学院创新强效工作。

据悉，为提高我院应用型人才培养模式教学管理实践水平，加强我院同台湾高校的交流与合作，今年暑期党委书记王卫平带领41名一线教师和管理干部赴台学习取经。
