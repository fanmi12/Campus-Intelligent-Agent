# 我院艺术系剧作在东莞市科普剧大赛中获奖

由广东省科技馆研究会、东莞市科技局、东莞市科协主办，东莞科技馆承办的2011年东莞市科普剧大赛于12月23日顺利落下帷幕。我院艺术系主任邓星明教授和任蓓露老师创作、臧莹竹老师导演、党家立老师及艺术系2011级影视表演班学生参演的《秋游趣事》，经过激烈角逐荣获大赛三等奖。

本次科普剧大赛共有40多所学校报名参加。经过剧本筛选，22支代表队进入了比赛环节。表演内容贴近学生生活，以普及科普知识为主，科学知识性强，表演形式活泼，体现了科学与艺术的结合，具有很强的感染力。
