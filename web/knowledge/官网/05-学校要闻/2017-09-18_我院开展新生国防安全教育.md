# 我院开展新生国防安全教育

9月17日晚，新生国防安全教育知识讲座在综合馆开讲。新生军训承训部队政治教导员、军训团副团长罗强龙少校作了“前进中的人民海军”的主题报告。

罗强龙少校以“台湾问题要统一”、“南海问题”等热点问题来阐明在当今形势下，海军力量在国防中的重要地位——谁掌握“海上钥匙”，谁就掌握了主动性。

罗强龙少校介绍了我国人民海军的四个主要发展阶段和现代人民海军的构成及发展现状，为同学们重温了我国海军军事力量由弱变强的过程，感受了人民海军的血性与爱国情怀。

罗强龙少校表示，我国国防事业日趋成熟、强大，有能力、有信心捍卫国家的安全。讲座中，他幽默风趣的语言和亲身经历，给同学们带来了一场别开生面的精彩演讲，赢得掌声不断。
