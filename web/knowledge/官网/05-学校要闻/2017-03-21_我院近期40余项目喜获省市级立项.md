# 我院近期40余项目喜获省市级立项

近日，广东省教育厅、东莞市科学技术局和东莞市社会科学联合会分别公布了2016年省教育厅科研项目、2017年东莞市社会科技发展一般项目和2017年东莞市哲学社会科学规划课题的立项名单，我院共有42项课题获得立项。

我院2016年申报了10项省教育厅科研项目，其中特色创新类项目5项，青年创新人才类项目5项，经省教育厅组织形式审查和专家评审，该批全部获得省厅立项。2016年底，我院申报了13项东莞市社会科技发展一般项目，其中12项获得东莞市科技局立项，这是我院迁入新校区以来申报该局项目立项率最高的一次。2017年2月，经研发处组织动员、老师积极申报，我院申报东莞市哲学社会科学规划课题高达51项，其中20项获东莞市社科联立项，这也是我院历年来立项课题数最多的一年。

近年来，我院修订了科研项目管理办法和经费使用办法，制定了教科研积分奖励办法，进一步加大了对科研项目的资助范围和奖励力度，为我院教师从事科研活动提供了有力的保障。同时，研发处多次组织召开了课题申报相关主题的宣讲会，有效地提高了教师参与科研工作的积极性。

这一大批省市级项目的立项，是我院教师对我院前期实施的一系列激励措施的认可，也是广东省教育厅、东莞市科技局和东莞市社科联等省市级科研项目管理部门对我院教师科研水平的一大肯定。我院将继续做好科研项目的管理工作，为老师开展科研活动提供最大的支持和帮助，也希望老师们再接再厉，积极申报课题，主动参与学术研究活动，为提高我院整体科研水平，推动科研型教师队伍的快速成长贡献自己的力量。
