# 领导与员工《相约周末》

6月9日晚，城市学院总务处工会小组在学院卡拉OK厅,开展了以《相约周末》为主题的文娱晚会。

院党委副书记朱冰、院工会主席章德胜、总务处处长翟耀明、副处长马兴顺、周林冲与总务处150多名员工共度周末。活动以卡拉OK、跳舞和台上台下有奖互动等游戏形式进行。朱书记和翟处长精彩的合唱拉开了帷幕，晚会持续近2个小时，在大合唱“明天会更好”的歌声中结束。

《相约周末》是总务处工会小组第一次活动。
