# 我院举行教师节庆祝大会表彰优秀教师

9月10日，我院在综合馆隆重举行教师节表彰大会，庆祝第三十个教师节。院长杨敏林、党委书记王卫平寄语全体教师，为人师表，行为示范，立德树人，带头践行社会主义核心价值观。

院领导王卫平、张林、陈丁堂、章德胜、高香林、麦琦琳为获奖教师颁奖。

在过去的一年里，我院教师在人才培养、科技创新、社会服务和科学管理等方面做了大量的、卓有成效的工作，作出了应有的贡献，涌现了一批优秀的教师。会上，学院党政领导班子决定对一批优秀教师进行大会表彰。其中，政法系系主任刘杰、管理系系主任张佺举获城市学院第四届名师光荣称号，张宏渝等36名教师获“三育人”先进个人称号，苗琳等7名老师获优秀辅导员称号，万文双等20名老师获优秀班主任称号。

党委书记王卫平在教师节讲话中，他首先代表杨院长、学院行政和党委，向辛勤工作在教学、科研、管理和服务岗位上的全体教职工致以节日的祝贺。接着他围绕教师是一个什么样的职业、大学需要什么样的教师、如何做一个受学生欢迎的老师等问题阐述了自己的看法，对广大教师提出了希望与要求。他说，作为一名合格的教师，必须对这些问题有清晰的认识。我们要认真学习习近平总书记在北京师范大学的讲话精神，并贯彻到教育教学工作中去。广大教师要勤于思考，积极上进，主动作为，成为传承中华文明、弘扬社会主义核心价值观的倡导者与践行者。要担“育人”之责，为学生“传道、授业和解惑”。要为人师表，行为示范。要刻苦钻研业务，了解学生，关爱学生，使学生成为爱祖国、爱人民、有知识、有能力的优秀人才，为学院的发展、为国家的教育事业作出应有的贡献。

“三育人”先进教师代表郑勇副教授在会上发言，畅谈教书育人的感悟。
