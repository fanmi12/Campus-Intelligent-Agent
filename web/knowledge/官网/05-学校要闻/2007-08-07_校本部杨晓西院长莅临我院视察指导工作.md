# 校本部杨晓西院长莅临我院视察指导工作

8月6日下午，东莞理工学院院长、城市学院董事长杨晓西教授在东莞理工学院副院长、城市学院院长安少华教授的陪同下莅临我院，看望我院暑期加班的教职工，视察指导各项基建工作。

城市学院党委副书记朱冰，行政副院长张林副教授及有关部门负责人随同校本部领导前往正在建设（改建）中的临时停车场、教职工饭堂，校外新学生公寓、樟村教学生活园区等多个工程施工现场，向杨院长汇报了有关情况。杨院长对城市学院的工作给予了充分的肯定。他明确要求，工程施工方必须保证我院校外学生公寓和樟村教师公寓工程按时按质完工，确保我院新生和教职工的正常入住。
