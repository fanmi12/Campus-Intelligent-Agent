# 东莞理工学院城市学院教职工住房公积金管理暂行办法

东莞理工学院城市学院

教职工住房公积金管理暂行办法

东理城人字〔2006〕05号

为贯彻落实国家发布的《住房公积金管理条例》（国务院令350号），充分发挥住房公积金制度的优越性，特制定此管理办法。

一、我院住房公积金缴存范围、比例和基数

（一）缴存范围。聘进的且已签订劳动合同的教职工（离退休人员、兼职人员、按课时取酬人员以及协议不缴存人员均不属于本办法规定的范围）。教职工个人缴存的住房公积金和学院为教职工缴存的住房公积金，属于教职工个人所有。

（二）缴存比例。教职工和单位住房公积金的缴存比例，2006年1月

-2006年6月为教职工上年度月平均基本工资和绩效工资的10%，从2006年7月起调整为15%。

（三）缴存基数。我院以教职工本人上年度月平均基本工资和绩效工资之和为缴存基数。

（四）缴存时间：2006年1月31日前入职的教职工，从2006年1月开始缴存。

2006年2月

-- 5月入职的教职工，从2006年7月开始缴存。

2006年6月1日后入职的教职工，从2006年11月开始缴存。

（五）缴存金额。教职工住房公积金的月缴存额为个人的缴存基数乘以缴存比例。

二、住房公积金缴存程序

（一）教职工个人缴存的住房公积金，由学院每月从其工资中代扣代缴。学院在每月发放教职工工资之日起5日内,将单位缴存的和为教职工代缴的住房公积金汇缴到住房公积金专户内，由中国建设银行东莞市分行计入教职工住房公积金账户。

（二）每个教职工只能有一个住房公积金账户。如果教职工在以前单位已经购买过住房公积金，现在已停买，且账户未消，则须到中国建设银行东莞市分行各住房公积金业务经办网点办理住房公积金帐户转移手续。

（三）单位与教职工终止劳动关系的，应当自劳动关系终止之日起30日内到市住房公积金管理中心办理教职工住房公积金帐户转移或者封存手续。
