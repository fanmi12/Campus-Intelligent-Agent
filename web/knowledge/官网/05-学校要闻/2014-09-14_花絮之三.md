# 花絮之三

政法系派送迎新小册子

在迎新现场，各种版本的迎新小册子受到新生及家长的喜爱，其中有的将长期保存留作纪念。一份由政法系学生制作的《政法系14级迎新小册子》别具一格、迅速在新成员中流传开来。记者看到，该小册子取羊皮纸为背景色，A3纸尺寸，可折叠为巴掌大小，内容精悍，图文并茂，主要包括了新生寄语、政法系简介、系专业设置介绍、手绘城院地图、以及系领导、班主任和辅导员等系工作人员的联系方式五大板块，新生寄语还采用七言文格式，加入了最近社会各界十分关注的新生返校安全问题贴士。

正在外地实习的政法系大三学子钟文举同学在电话中向记者说道，制作这份小册子我们大概花了半个月时间，搜集了许多信息，手绘地图则由陈伟峰、陈思沛两位同学根据城市学院实景图，事先画在A1纸上，再扫描存为电子档，在电脑上一一标明各建筑名字，十分贴心。（作者： 吴炳然 ）“巨人”宿舍

来到2C102，只觉得眼前的视线被四座大山一样高大且有2米长特制的床遮挡住了，四个床的旁边都分别建有一条大楼梯，中间是一条过道。这间宿舍住着4位高人，他们来自不同的专业，却都有着1米9以上的身高，记者站在他们旁边，只觉得自己愈发渺小。

“我觉得我的身高并不会带来什么困扰，这得谢谢学校的关注，为我们四个特制了这样的床。”来自安全工程专业的刘永航则满含憧憬期待地对我们说：“当然，在以后的大学生活里我还希望我可以参加学生会。如果有机会的话，我想加入学校篮球队，在篮球队闯出一片天。”

据了解，新生中的高个子比较多，城环系1.95米以上的男生有3个，艺术系1.8米以上的“高材生”也有3个。 （作者：何金珊）

细微处尽一份爱心

匆匆人流中，负责综合馆清洁工作的阿姨们可能是最不起眼的人。我们看到的是汗流浃背的志愿者，看到的是热情满满的新生们，却鲜有人注意到手持扫把、不断弯腰捡垃圾的清洁工阿姨们。

从综合馆到校道，她们不断地弯腰清洁，没有宣传，没有交流，默默地维持着综合馆周围环境的清洁。由于报到人数多，人流量也大，新的垃圾不断产生，她们不断地弯腰，捡起，再弯腰，再捡起。满头大汗却依旧一丝不苟的工作，在细微处也为迎新工作尽了自己的一份心意。（作者：钟沛芬）
