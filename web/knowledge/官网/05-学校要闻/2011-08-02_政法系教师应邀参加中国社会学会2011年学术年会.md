# 政法系教师应邀参加中国社会学会2011年学术年会

7月23-25日，我院政法系社会工作教研室李细香老师、王海洋老师，应邀参加了在江西省南昌市召开的中国社会学会2011年学术年会。

本届年会以“新发展阶段：社会建设与生态文明”为主题，开展了一系列的学术交流和国际交流。除大会学术报告外，本届年会还设立了33个分论坛。分论坛主题涉及领域广泛，内容丰富，涵盖了生态文明与社会变迁，社会建设与社会管理，社会稳定与社会政策等社会发展的诸多领域，以及诸如城市社会学，消费社会学，女性社会学，社会工作等分支社会学研究。此外，第九届东亚社会学学术研讨会也同时举行。中国、韩国、日本的社会学家及国内各高等院校和研究机构的社会学者共计800多人参加了本次年会。

我院与会教师参加了多个分论坛，与全国各地学者进行了广泛的交流，特别是在当今社会问题、社会管理及社会工作发展等方面进行了深入探讨，获得较高的评价。
