# 我院2017年新增学士学位完成授予专业备案

我院2017年新增的财务管理、土木工程、建筑电气与智能化、自然地理与资源环境（转设专业）、人文地理与城乡规划（转设专业）等五个本科专业的学士学位通过省学位委员会备案确认。5月29日，《广东省学位委员会关于2017年广东省普通高等学校新增学士学位授予专业备案的通知》（粤学位函﹝2017﹞4号）对我院上述五专业基本信息予以确认，并备案公布。

据了解，为做好学院2017年财务管理、自然地理与资源环境、人文地理与城乡规划、土木工程、建筑电气与智能化共五个本科专业新增学士学位授予专业备案工作，我院根据《关于做好2017年新增学士学位授予专业备案工作的通知》（粤学位办﹝2016﹞40号）文件要求，自2016年9月开始启动本项工作。成立了学院学士学位授予备案工作领导小组；制定实施方案；多次组织院内自评专家到系部检查迎评资料，逐项提出改进措施并督促落实到位；召开学院学位委员会会议对各专业资料进行集中评议；邀请知名同行专家及学位教育管理专家对送评材料进行评审；根据评估专家意见进一步整改，保质保量完成迎评的各项任务并将备案材料上报至举办方东莞理工学院，后报省教育厅。
