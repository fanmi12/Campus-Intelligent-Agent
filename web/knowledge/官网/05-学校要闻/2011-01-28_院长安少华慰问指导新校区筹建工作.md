# 院长安少华慰问指导新校区筹建工作

1月28日，东莞理工学院副校长、城市学院院长安少华带领学院党政领导等一行人到新校区筹建办慰问并指导筹建工作。鸿发教育投资有限公司总经理夏为民、筹建办主任杨敏林与安少华院长一行人进行了亲切地交谈。

座谈会上，安少华院长听取了夏为民经理和杨敏林主任关于新校区项目建设情况的汇报，充分肯定了新校区筹建办的工作，对新校区筹建办全体人员付出的艰辛努力表示衷心感谢。
