# 金贸系主任米双红教授喜获“南粤优秀教师”称号

9月10日上午，广东省庆祝2012年教师节暨表彰优秀教师大会在广州隆重举行，省领导汪洋、朱小丹等出席。会上，省委常委徐少华宣读了《关于表彰广东省2012年南粤优秀教师和南粤优秀教育工作者决定》，我校金融与贸易系主任米双红教授名列其中，喜获“南粤优秀教师”荣誉称号。
