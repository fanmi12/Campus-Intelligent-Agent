# 军训教育专题之三：秦兴和将军做国防知识教育报告

9月20日，海军某部秦兴和将军在综合馆做的一场精彩的国防知识教育报告，将我院2012级新生军训推向了高潮。同学们表示，将军的报告使我们加深了对军训重要意义的认识，也更加明了学好知识、振兴祖国、巩固国防的责任感与时代感。

秦将军的报告内容及其丰富，都是同学们所急需了解的内容，也是当前的热点问题。他既讲了国际的形势，又讲了中国周边的安全形势，既讲了“三岛”（台湾岛、钓鱼岛、南沙群岛）形势，又讲了我国陆海空二炮四大军种发展建设情况。

面对当前国际国内的形势，秦将军希望同学们要认清形势，理性爱国，把思想统一到党中央对形势的科学判断和决策部署上来，充分认清国家安全的复杂性、多变性；要看到世界力量的对比、国际体系的变革以及中国与世界的关系；善于从宏观上思考问题，富国强民才是唯一的出路，只有自己强大了别人才不敢欺负；不图口舌之快、不逞一时之勇；要厚积勃发，练好本领，以实际行动维护改革发展稳定的良好局面。

他激励同学们说，高考成绩只能代表过去，城市学院给大家提供了优质的教育教学资源，要充分利用。他语重心长地说，爱国是当代青年的核心价值观，要培养知识能力等爱国的本钱；他还告诫同学们要学会感恩，感谢父母，感谢社会，感谢学校，感谢师长；要学会说话，学会办事，学会做人，发奋成才。秦将军抑扬顿挫，真情流露，表现出他对党的忠诚，对国防建设的热爱，对学生的关爱。每当他讲到动情之处时，同学们报都以热烈的掌声表示感谢和赞同。他在不到2个小时的报告中，赢得了同学们40多次的掌声。

学院以精心打造的校园文化品牌活动《城市学院大讲堂》推出这一报告，这是第四十三讲。报告会之前，党委书记朱志德、副书记章德胜和秦将军进行了交流，感谢秦将军对城市学院的关心和支持。

据悉，秦将军的报告将于今日上传到学院网站。
