# 东莞市保密局、教育局领导来我院检查指导保密工作

4月7日，东莞市保密局副局长李国培带领由市保密局、市教育局组成的联合检查组来我院检查保密工作。副院长张林等热情接待了检查组成员。

教务处处长邓成良、院办公室副主任黄研晖分别从健全和完善保密制度、试卷保密工作培训、完善保密防范措施和组织开展保密自查等方面，向检查组做了汇报。检查组听取情况汇报后，重点了解了我院大学英语四、六级考试试题的保密工作，并检查了学院保密室的防盗和监控系统。李副局长对我院的保密管理工作给予了充分的肯定，认为城市学院保密工作做到了领导重视、管理到位、工作扎实、措施得力，效果良好。
