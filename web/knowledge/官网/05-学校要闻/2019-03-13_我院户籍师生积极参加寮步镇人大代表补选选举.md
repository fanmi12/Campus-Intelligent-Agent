# 我院户籍师生积极参加寮步镇人大代表补选选举

3月13日上午，在寮步社区第四选区领导小组的指导下，我院250名户籍师生积极参加寮步镇第十六届人民代表大会代表补选选举。

选举自9时开始，选民们认真填写选票，并以无记名的方式进行了投票。

师生选民投票结束后，工作人员严格按照相关要求密封流动票箱，并按规定时间将密封票箱交至主会场。整个选举过程，选民严肃、认真，秩序井然。经过周密组织和安排，此次选举得以顺利进行，充分保障了我院选民依法行使公民的政治权利。
