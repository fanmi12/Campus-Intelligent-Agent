# 城市学院首届教工篮球赛暨第三届田径运动会开赛在即

为了活跃广大教职工和在校学生的业余生活，增强师生们的身体素质，我院即将开展教工首届男、女子篮球赛和第三届田径运动会。

其中，教工篮球赛的参赛单位包括：总务处（包含保卫）、机关、管理、机械、文艺、财经、计算机、社科、教辅，各派男女两队参赛，分设Ａ、Ｂ组，采取单循环赛制。球赛将于１１月６日开始，共持续１１天，冠军将于１１月１７日下午决出，其中男队冠军还将于次日与体育教学部加赛一场。

此外，第三届田径运动会竞赛也将于11月24日—25日举行，比赛分为教工组和学生组。教工组以工会小组为单位按照年龄划分为甲乙丙三组进行比赛；学生组比赛将以系为单位进行组队。竞赛项目包括：100米、200米、400米、800米、1500米、3000米、400米栏、100米栏、跳高、跳远、铅球、 4×100米接力、4×400米接力等。

篮球赛和运动会具体赛程均可在办公信息网站上查阅。
