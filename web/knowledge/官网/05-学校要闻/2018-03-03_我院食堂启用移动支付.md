# 我院食堂启用移动支付

好消息！忘带校园卡，用微信、支付宝也一样可以在学院各大食堂消费了！

新学期伊始，我院启用移动支付，在荔香园、悦香园食堂各窗口均可使用微信、支付宝进行消费。

3月3日上午，王卫平、章德胜、高香林、周庆、刘玉侠等院领导视察了新学期食堂的准备工作，并

来到悦香园三楼

体验了移动支付用餐的便捷性。

另据财务处处长余竹根介绍，为方便广大学生电费充值，从3月3日开始，学院开通了微信支付功能。只要在微信搜索并关注“智慧城院”微信公众号后，点击“电费充值”菜单，根据指引即可完成微信电费充值。
