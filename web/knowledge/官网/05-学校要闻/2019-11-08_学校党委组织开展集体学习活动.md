# 学校党委组织开展集体学习活动

11月6日，学校党委组织开展集体学习活动。学校党委书记章德胜重点组织学习研读了习近平总书记在党的十九届四中全会上的重要讲话和全会精神。

会议认为，党的十九届四中全会是在中华人民共和国成立70周年之际、实现“两个一百年”奋斗目标历史交汇点召开的一次极其重要的会议。习近平总书记在全会上的重要讲话高屋建瓴、思想深邃、内涵丰富，回答了“坚持和巩固什么、完善和发展什么”一系列重大政治问题，坚定了制度自信，指明了前进方向，标志着我们党对国家制度和国家治理体系的认识升华到一个新高度、新视野、新水平。

会议强调，要全面深入学习贯彻习近平总书记重要讲话和四中全会精神，自觉把思想和行动统一到党中央的部署要求上来。

会议还认真通读了《习近平总书记在中共中央政治局第十八次集体学习上的重要讲话》，重点研读了习近平总书记关于“把区块链作为核心技术自主创新重要突破口 加快推动区块链技术和产业创新发展”的重要论述。会议一致认为，要依照习近平总书记的讲话精神，加强人才队伍建设，建立完善人才培养体系，强化基础研究，提升原始创新能力，占据创新制高点、取得办学新优势。
