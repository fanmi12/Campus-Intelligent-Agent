# “如何开展思想政治教育研究”

3月25日下午，由教师发展中心举办的青椒工作坊之教师沙龙研讨活动在行政楼212会议室举行。活动以“青椒科研之路：如何开展思想政治教育研究”为题，邀了何鹏举教授、赵书山副教授、孔增强副教授担任本次活动主讲人。学院党委副书记章德胜、副院长刘玉侠等领导和50多名青年教师参加了活动与研讨。

赵书山副教授着重介绍了我院科研项目类型及科研项目中的注意事项、方法与技巧，以及“科研协会”规定改动的部分项目内容、项目研究与后期研究接轨问题，并与大家分享了“如何做好课题申报”的经验，还结合往年经验与报名项目情况，鼓励青年教师在做充足的前期准备的基础上积极申报项目。

何鹏举教授以思政类科研项目的积累、凝练及论文写作做了详细的说明，重点强调了选题思路和选择原则，以及对遵守论证规范和要求。何教授还提倡“新思想、新理论、新观点、新资料、新视角、新语言”，提醒青年教师要有科研意识以及关注学术界的研究、了解动向，逐步形成自己的风格。

孔增强副教授就开展大学生思想政治教育研究提出了现今的“学术贫困”，并进行了分析及思考，鼓励青年教师对待科研要“诚心”，养成正确的科研习惯。

在教师自由发言环节，几位青年教师以现身说法，表示今后“多学习、多积累、多动笔”，并希望青椒工作坊多开展交流活动，“抱团前行”，帮助解决青年教师们在科研路上的疑惑与困难。

学院党委副书记章德胜指出，本次活动旨在学风队伍发展，号召青年教师团队重视并做好科研工作，“沉下心来把路放宽”，提高科研能力，积极发表学术报告。青年教师们希望青椒工作坊多开展交流活动，“抱团前行”，帮助解决青年教师们在科研路上的疑惑与困难。
