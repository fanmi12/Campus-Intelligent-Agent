# 我院召开安全工作会议

4月18日，我院召开安全工作会议。周庆副院长主持会议，学生处、后勤保卫处、学院全体辅导员及各区域安全工作负责人参加了会议。

后勤保卫处副处长刘维仝对近期校园安全情况和加强校园安全建设系列工作进行了汇报，并传达了省教育厅关于做好校园安全稳定工作的通知和相关文件精神。

周副院长充分肯定了各部门在校园安全稳定方面所做的工作，对进一步做好校园安全工作提出：第一，高度重视，深刻认识；第二，认清形势，正视问题，增强责任感和紧迫感；第三，突出重点，狠抓管理，牢固树立“安全第一”的思想意识，做到“人人讲安全，事事讲安全，处处讲安全”，共同筑牢校园安全防线，切实保障广大师生生命财产安全，共建平安、和谐校园。
