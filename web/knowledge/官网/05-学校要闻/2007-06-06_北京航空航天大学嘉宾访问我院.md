# 北京航空航天大学嘉宾访问我院

“城市学院的发展速度的确令人惊喜，通畅的就业渠道，科学的人才培养定位，必将为之带来更为广阔的发展前景。” 北京航空航天大学的老领导们在参观访问我院后这样感慨道。

6月5日，雨后初霁的校园，迎来了北京航空航天大学6位客人，北航原副校长方复之教授，原教务长陈孝戴教授，原研究室主任邓耀荣教授等。

院长安少华教授，学院党委书记朱志德与客人们在405会议室进行了亲切交谈。安院长向来宾介绍了学院的机制和办学情况，以及城市学院近些年的发展与变化。宾主双方就办学特色、招生规模、师资力量特别是艺术类专业的教学、师资、就业情况交换了意见。方复之教授在座谈中表示，东莞市发展速度是惊人的，为城市学院创造了十分优越的办学条件。学院有灵活的办学机制，一定会有更大的发展空间。

座谈结束后，客人们在学院领导的陪同下，参观了学院办学成果展。参观过程中，他们对我院校园文化建设、校友录征集等工作大加赞赏。

临别时，院领导与客人们在“人才之星”合影留念。
