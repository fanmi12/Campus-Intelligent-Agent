# 我校获广东省教育教学成果奖二等奖

5月19日，广东省教育厅正式公布了2021年广东省教育教学成果奖获奖项目名单，我校罗卫国、肖文锋、郑阿泰、耿玉成、鞠成晓、李红岩、宋键、洪树权等人共同完成的项目《“校企协同、宽融分合”新商科应用型人才培养模式探索与实践》获得高等教育类二等奖。

这次荣获广东省教育教学成果奖是对我校探索“新商科”专业人才培养模式的肯定，是我校商学院“会计学”专业获得“国家级一流本科专业建设点”，“物流管理、财务管理、工商管理”三个专业获得“广东省一流专业建设点”的又一重大成果。

广东省教学成果奖是彰显全省学校人才培养工作水平和教育教学改革创新成效的核心指标，代表了全省各级各类教育教学工作的先进水平，每四年评选一次，分基础教育、职业教育、高等教育三个大类。

我校将进一步深化教育教学改革，在教育教学中充分发挥示范引领作用，力争取得更多具有示范带动作用和推广价值的高水平教育教学成果，努力推动教育教学质量和水平实现新的提升，矢志打造一所高水平的、创新性、应用型、国际化都会大学。
