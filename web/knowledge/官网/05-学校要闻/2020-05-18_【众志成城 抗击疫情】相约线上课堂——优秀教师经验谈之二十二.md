# 【众志成城 抗击疫情】相约线上课堂——优秀教师经验谈之二十二

我校坚决贯彻落实教育部、省教育厅、省委教育工委的重要部署，从3月起全面开展线上教学活动，全体任课教师坚守岗位、锐意创新、勇挑重担，全力做好线上教学工作，展现了良好的师德师风。前二十一期我们精选刊发了一批优秀教师线上教学经验谈后，在全体教师中产生了良好的反响，受到广大师生的欢迎和点赞。今天刊发第二十二期，推介商学院章文、智能制造学院纪宠兴、法学院朱凤群三位老师的线上教学心得体会，供大家分享。

商学院章文老师线上教学心得体会：受疫情影响，线上教学成了老师和学生之间相互联系的新桥梁。经过8周的摸索，我对线上教学逐渐驾轻就熟，甚至逐渐形成了自己的“主播”风格。线上教学最大的优势在于突破了时间和空间的限制，能够更加全面的利用网络平台与学生进行交流和互动。学生们也不再像传统课堂教学一般拘束，而是能够通过直播互动，自由地发表看法，或是及时向老师提问。我也在线上教学中跟同学们建立了浓厚的师生情谊。通过两个月的在线教学，我发现在以后的教学过程中需要做以下改进：第一，关于平台的使用技巧。目前，我常用到的技巧有签到、讨论、作业等功能。在以后的线下教 学中，应该灵活应用投票、测试等功能，以提高教学的有效性和互动性。第二，教学理念。比起教学技巧，教学理念的更新更为重要。如何吸引学生们的注意，与同学们高效互动，都是要不断思考和加强的内容。在以后的工作中，我将以此为契机，更新教学理论，将线上课堂和线下课程做到真正的有机结合。

教师寄语：疫情虽然阻隔了我们的身体距离，我们的心却因为线上教学联系在一起。

智能制造学院纪宠兴老师线上教学心得体会：线上教学确实可以做为一个很好的教学手段，尤其对偏理论性质的课采用线上教学手段，教学效果会更好！学生可以回看、反复看、不限地点看。但对于偏实践的理工科课程，尤其需要软硬件结合的课，存在较大的挑战和困难。此外考勤、课堂掌控等方面线上教学是不如线下教学的。

要做好线上的理工科教学，教师和学生均需要想方设法补充硬件基础设施，可以依据实际情况采用网购或者自己搭建仿真平台等手段，这样才能更好地提升线上教学的教学效果。

教师寄语：线上教学确实和线下教学存在很大差异，二者教学手段各有优缺点，可以互补但无法互相替代。

法学院朱凤群老师线上教学心得体会：一是结合教学方案设计和课程特点，充分备课，包括整合教学资源，准备图片、视频、课件，制作PPT，并分享给学生预习、复习。

二是结合“线上线下教学模式”和企业微信远程直播，课前布置任务，引导学生自主学习。讲课中分重点、难点讲解，提问巩固、答疑解惑、交流探讨，课后适当布置作业。

三是结合教学实际情况和教学反馈意见，总结经验，改进不足，进一步提升网络教学质量和学习效果。

教师寄语：亲爱的同学们，无论我们处于怎样的时光、怎样的困境，都要珍惜当下，把握今天。尤其在这段抗疫的特殊时期，我们要更加自律，更有担当，更好地成长，待我们再聚校园那天，能以更加朝气蓬勃、自信从容的姿态和一颗坚定、温暖、丰盈的心灵迎接每一天！
