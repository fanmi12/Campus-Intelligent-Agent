# 我校举办“用技术打造好课堂”教师专题培训活动

11月21日下午，我校组织专任教师、兼课教师300余人在学术报告厅开展“用技术打造好课堂”专题培训。华南师范大学教育信息技术学院焦建利教授应邀担任主讲。

焦建利教授是我国现代教育技术领域著名专家，是引领我国课堂教学革命、引领技术支持下教师专业发展的领军人物。焦建利教授指出，移动互联网信息技术的迅猛发展使我们的生活方式、学生的学习方式发生了翻天覆地的变化，教师可以利用手机让学生参与到教学中。他介绍了“纸条范”教学工具的日常应用，回顾了慕课的基本含义、当今发展现状以及设计理念，并详细讲解了近年来学界最前沿、最实用的教育技术制作成果。通过生动的案例与深入浅出的讲解，展示了其团队的极简教育技术与快速教学设计在教学实践中的应用。

焦教授用“纸条范”教学工具创建课堂教学互动环境，对教师提出的相关问题进行了实时互动、问题讨论，使参训教师切身感受互联网技术支持下增强师生课堂教学互动的强大力量。

专题培训为我校教师分享了最前沿的教育技术理念和技术，也加深了对信息时代下高校教师面临的教与学的新挑战的思考。

专题培训由教师发展中心副主任张兰主持。
