# 我院开展2012年“感动城院校园”大学生年度人物评选活动

由院团委主办，财经系承办的“城院榜样，你我模范——2012年‘感动城院校园’东莞理工学院城市学院大学生年度人物评选活动”正如火如荼地展开。

评选委员共收到48份参选人员的资料，他们感动的事迹各有不同，背景各异，但是他们通过各自的故事，深刻地诠释了城院学子德、智、体、美、劳各方面优秀的素质，让大家你我感受榜样的风貌，感悟生命的美丽，在灵魂震撼下产生不断前行的动力。

据了解，本次活动将评选出“年度道德风尚人物”、“年度博学人物”、“年度志愿人物”、“年度自强人物”以及“年度领袖人物”。最终获奖人员名单将根据微博投票人气情况和征集候选人个人纪实视频，并结合专家的意见来确定。
