# 四川省陶雷同学成为被我院录取的首名考生

7月7日，我院完成了对四川省的艺术类专业招生录取工作。四川省内江市的陶雷同学成为今年我院录取的首名考生。得知被我院艺术专业录取的消息后，陶同学全家无不高兴异常。陶雷告诉记者：“我从城市学院网站和招生简章上看到了有关城市学院的相关情况介绍，经过多方面了解并结合自身的情况，我第一志愿毅然填报了城市学院，现在终于被顺利录取了，真盼着早日开学，投入期盼已久的大学生活！”

据悉，我院2009年招生录取工作于7月6日正式拉开帷幕，将于8月23日结束。今年我院将面向全国19个省、直辖市、自治区招生2400名，其中本科1200人，专科960人，高职240人，全部通过计算机网上录取。
