# 学校开展2018-2019学年度基层党组织量化考评工作

5月30日至31日，学校党委组织开展2018-2019学年度基层党组织量化考评会，分别对各党总支、直属支部进行了工作考核。校长王卫平，党委书记章德胜，副校长高香林、黄兢，党委委员杜鹏举，各党总支书记、副书记和直属支部书记及教师党员代表参加了会议。

根据量化考核的指标和内容，各二级学院党总支书记、直属支部书记分别作了工作总结报告，汇报了党建工作的特色和总体工作情况，指出存在的不足和未来工作展望、规划。测评团进行了公平、公正地评分。

王卫平校长、章德胜书记对学校基层党建工作的成绩给予了充分肯定。章德胜书记指出，今年是我校全面完成“十三五”规划和全面深化改革的关键之年，要坚持以习近平新时代中国特色社会主义思想为指导，坚持不懈地抓好党建工作，切实落实好党建工作的主体责任和第一责任，强化各级党组织的责任担当，进一步加强党的政治建设、思想建设、组织建设、作风建设、反腐倡廉建设和制度建设，不断提升党建工作科学化水平。
