# 我院举行新学年督导员聘任仪式暨学年工作会议

9月13日，我院在行政楼401会议室举行新学年督导员聘任仪式暨学年工作会议。王卫平院长、黄兢副院长及全体教学督导员出席了会议。

黄兢副院长向每位教学督导员颁发了聘书。

会上，督导办副主任宋欣荣对督导员上一学年的工作进行回顾和总结，要求新学年督导工作要做到“保证面上的覆盖、保障点上的细节”。

院领导在讲话中表示，将大力扶持年轻教师站稳、站好讲台，发现优秀，树立典范，宣扬城院名师风采。

会议由研发处处长牛熠主持。
