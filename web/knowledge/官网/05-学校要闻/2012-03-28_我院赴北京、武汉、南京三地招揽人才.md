# 我院赴北京、武汉、南京三地招揽人才

3月17日至3月24日，副院长程发良、副书记朱冰、院督学陈丁堂等领导率人事处有关工作人员先后赴北京、武汉、南京参加当地的招聘会，揽招人才。

在三地的现场招聘过程中，我院工作人员向求职者宣传城市学院2012年人才招聘信息和相关要求，介绍学院的基本情况、新校区的建设成就，以及学院和东莞市政府关于人才引进的政策。

据悉，北京大学、中国人民大学、南开大学、武汉大学、华中科技大学、南京大学、南京师范大学等一大批全国知名高校的研究生相继前来应聘，共收到200多份“含金量”较高的应聘者的简历，其中，有不少的应聘者具有博士学位或海外留学经历。

对前来应聘的优秀人才，院领导对他们进行了现场考察与交流。许多重点院校毕业的博士等高层次求职人员对我院表现出浓厚的兴趣，当场表达了强烈的就职意向，期待着能加盟城市学院，到东莞来创业发展。
