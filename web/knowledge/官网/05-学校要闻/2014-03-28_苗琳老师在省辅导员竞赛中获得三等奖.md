# 苗琳老师在省辅导员竞赛中获得三等奖

3月18日至23日，第三届广东省高校辅导员职业能力培训暨竞赛活动在南方医科大学顺德校区举行，我院文学与传媒系辅导员苗琳老师，经过为期6天激烈的竞赛角逐成功入围决赛，并获得三等奖荣誉。

辅导员职业技能培训暨竞赛活动由广东省教育厅主办，教育部高校辅导员培训和研修基地(华南师范大学)承办。本次比赛全省各高校共按比例选派辅导员168名参赛，本次比赛分别设有一等奖、二等奖、三等奖及优胜奖，活动历时一个星期，分培训和竞赛两部分交叉进行。竞赛环节围绕辅导员日常工作与能力要求，设置了7个竞赛项目，分别为自我介绍与工作展示、主题班会策划、基础知识测试、写作能力测试、现场案例分析、现场谈心谈话、即兴主题演讲。其中，自我介绍及工作展示和主题班会策划以提交视频作品的形式参赛，其余5个比赛环节为现场测试或比赛。比赛环节的设置既考查辅导员的理论功底与基本技能，又考察辅导员的应变能力与处理问题的水平，其中案例分析、谈心谈话和主题演讲均为现场抽题并即时作答，综合考察了辅导员的综合素质。
