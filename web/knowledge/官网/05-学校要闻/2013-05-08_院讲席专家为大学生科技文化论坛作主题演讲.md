# 院讲席专家为大学生科技文化论坛作主题演讲

5月4日，我院大学生科技文化论坛第四十五期在学术报告厅开讲。城市学院讲席专家、政法系王雄文副教授应邀作了《推进我国法治政府建设的难点与对策》的主题演讲。政法系法学专业、行政管理专业300多名学生参加了此次论坛。

本次讲座分为四个部分：一、我国推进法治政府建设的必要性，改革开放以来党和政府推进法治政府建设的历程；二、法治政府建设的理论内涵；三、我国推进法治政府建设的诸多难点和问题；四、我国法治政府建设难点的对策和建设。王雄文副教授在讲座过程中，结合我国和东莞实际，针砭时弊，运用生动具体的案例、庄谐并重的语言，深入浅出地分析了法治政府建设中的种种难题，获得与会者的一致好评。

会上王雄文副教授向在座的青年大学生表示了节日的祝贺，并寄语大学生要努力学好专业知识和技能，勇于作为，敢于担当，担负起历史赋予给青年们的时代责任。
