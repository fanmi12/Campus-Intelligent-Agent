# 我院第十三期院党校培训班开课

10月18日，我院第十三期院党校培训班顺利开班，全院老校区302名学员、新校区195名学员分别在老校区学术报告厅和新校区7B206参加了党校培训。

学院党委副书记、党校校长朱冰出席培训班开班并发表重要讲话，她围绕怎么样做一名合格的学生党员这个问题，在今后的思想、学习、工作、生活等方面如何发挥党员的先锋模范带头作用提出了希望和三点要求。第一，要通过学习提高对共产党的认识，端正入党动机，入党意味着要为人民、为集体、为国家作贡献；第二，要有正确的政治立场，在各个层面上体现个人的示范性和先锋带头作用；第三，要有较强的判断是非的能力，不能盲目跟从。

老校区院党校由党委宣传部部长何鹏举教授主讲，他以“重温党的光辉历史，教导学员们要温故而知新，好好学习和不断发扬党的优良传统，要树立远大的理想，为社会主义现代化而奋斗终身。

新校区院党校由政法系副主任赵书山教授主讲，他以“筑道德之防线，养廉洁之党性”为主要内容，从中国传统道德文化里的修身、养廉的角度，要求学员们树立自己的道德情操提高自己的党性修养。

我院党校第十三期培训班还将有三次培训。
