# 我校首届专业实践嘉年华启幕

5月26日下午，我校首届专业实践嘉年华暨第五届“党建引领，五彩融媒”品牌文化节在前山公园启幕。

学校党委副书记、校长李振华，党委书记魏东初，执行校长方伟华，副校长周庆，党委副书记、副校长李海冬，党委副书记、副校长康贤刚，东莞潮光摄影公司负责人杨怀，企业嘉宾，相关行政部门负责人、二级学院院长、书记与师生代表齐聚现场，活动以党建为引领、实践为核心、融媒为特色，主会场仪式庄重热烈，六大分会场各具亮点，全面展现学校育人成果与学子风采。活动由执行校长方伟华主持。

前山公园主会场，鼓点激昂、醒狮腾跃，一场气势磅礴的醒狮表演正式拉开活动帷幕。

李振华校长在开幕式上致辞。他表示，本次活动紧扣学校“厚德务实，知行合一”校训，彰显立德树人根本使命，充分体现学校扎根粤港澳大湾区、坚持应用型办学的鲜明特色。他指出，专业是学校的立足之本，高质量专业建设是学校高质量发展的关键，首届专业实践嘉年华正是展示专业成果、检验产教融合成效的重要平台。

近年来，学校投入数千万元升级数字创意媒体实训中心、智慧融媒体中心等硬件设施，建成一批现代产业学院与省级实验教学示范中心，与深圳优必选共建智能机器人产业学院，不断深化产教融合协同育人。同时，他鼓励各学院积极探索实践教学新模式，用好网络电视台等融媒体平台，强化专业宣传与品牌传播，助力招生工作。

本次活动通过全程直播，向广大考生、家长及社会各界展现学校活力与潜力，集中展示各学院专业实践成果。李校长希望以此次活动为契机，进一步提升专业建设水平与办学影响力，推动学校事业持续高质量发展。

随后，文艺展演环节精彩上演，新传媒与艺术学院谢雨钊老师指导的学生所带来的歌曲《中国少年说》旋律激昂，他们用嘹亮歌声唱出青春报国之志。活动现场还举行了第二届网络电视台作品征集大赛颁奖仪式。校领导依次为获奖师生颁发证书，表彰他们在融媒体创作中的优秀成果，鼓励更多学子投身专业实践与内容创新。

颁奖结束后，由新传媒与艺术学院荆琦老师指导的学生所带来的舞蹈《林鸟趣话》为现场的观众带来了一场视觉盛宴，以富有诗意的肢体语言展现自然和谐之美。

在全体嘉宾与师生的共同见证下，校领导、企业嘉宾、相关部门负责人一同登台，为网络电视台AI漫剧梦工厂揭牌。红色幕布揭开的瞬间，现场掌声与欢呼声交织，标志着学校在人工智能与融媒体融合育人领域迈出了崭新一步。

最后，校党委书记魏东初宣布东莞城市学院首届专业实践嘉年华暨第五届“党建引领 五彩融媒”品牌文化节正式开幕，全场气氛达到高潮，六大分会场同步开放，各项精彩活动全面启动。

分会场一：工作坊揭牌暨“我为专业代言”直播启动

该分会场设于AI漫剧梦工厂，由品牌与招生部组织。执行校长方伟华，党委副书记、副校长李海冬、康贤刚等领导与企业嘉宾共同为新文科美育创新工作坊、摄影摄像创意工坊、融媒体学生社团党支部先锋队绿映突击队揭牌，标志着学校实践教学与融媒体育人平台再添新阵地。

同步启动的“我为专业代言”直播活动，以新媒体形式推介专业特色与办学优势，构建线上线下联动的展示窗口，有效扩大学院办学影响力。

分会场二：毕业设计作品展及非遗陶瓷体验

由创意设计学院承办，集中展示视觉传达、环境设计、产品设计等方向优秀毕业作品，充分体现学生扎实的专业素养与创新思维。现场还开展非遗陶瓷体验活动，师生在动手实践中感受传统工艺魅力，实现艺术创作与非遗传承的有机融合。

分会场三：古风摄影活动

语言文化学院在前山公园左侧山顶平台打造古风摄影专区，汉服秀表演衣袂翩跹，尽显传统服饰之美。现场免费提供汉服、道具及基础妆造，师生沉浸式体验古风拍摄，定格国风韵味，成为活动一道亮丽风景线。

分会场四：专业介绍市集

品牌与招生部沿前山公园山路设立专业介绍市集，各学院通过展板、资料、现场讲解等形式，系统介绍特色专业、培养方案与就业前景，帮助学生清晰规划学业方向，搭建专业认知与交流平台。

分会场五：法律大转盘

法学院在山腰凉亭打造法律大转盘趣味互动区，以知识问答、转盘抽奖等轻松形式普及法律常识，将法治教育融入趣味活动，寓教于乐，有效提升师生法治意识与法律素养。

分会场六：山顶星空影院

傍晚，品牌与招生部在前山山顶平台架设大型幕布，开启星空影院，播放青春励志影片。现场贴心提供坐垫、驱蚊水等物资，师生在星光与山景相伴下沉浸观影，为嘉年华画上温馨句号。

本次活动以专业实践嘉年华为载体，将党建引领、融媒创新实践育人、文化传承融为一体，全面展示学校办学特色与育人成效，进一步激发学生专业热情与创新活力，助力应用型人才培养再上新台阶。
