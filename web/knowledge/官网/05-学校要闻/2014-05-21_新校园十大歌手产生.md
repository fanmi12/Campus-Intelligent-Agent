# 新校园十大歌手产生

拾取魅力知音，追逐城院梦想。5月20日，以“拾音逐梦”为主题的第十届校园十大歌手在学术报告厅圆满谢幕。24位候选歌手闪亮登场，角逐“十大歌手”桂冠。经过投票，郑雍、王嘉伟、崔庭瑞、谭凯琳、谢嘉豪、谢铕、张梓健、杨宇秋、陈晓婷、杨晓宇获得“十大歌手”称号。团委书记罗文芳表示：“愈唱愈精彩，特别是谢铕同学对歌曲《向天再借500年》把握到位，带动了全场气氛，真的不简单。”
