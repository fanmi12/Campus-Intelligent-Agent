# 我校召开综合素质养成教育计划阶段性交流会

5月16日下午，东莞城市学院“综合素质养成教育计划阶段性交流会”在学生活动中心3楼招聘大厅顺利举行。副校长陈葆华，校长助理、学生处处长任广新，教学科研部部长杨勇虎，品牌中心副主任万文双、学生处副处长刘维仝等领导出席交流会，二级学院党总支书记，全体辅导员参加交流会。学生处副处长、校团委书记范琪主持交流会。

学生处副处长、校团委书记范琪主持交流会

陈葆华副校长对综合素质养成教育计划进行总体的介绍

陈葆华副校长介绍了我校课外学分的历史沿革，并结合上《深化新时代教育评价改革总体方案》与《关于在高校实施共青团“第二课堂成绩单”制度的意见》等文件精神，对我校开展综合素质养成教育计划的出台作了说明。她指出学校为有效提升在校学生综合素质，“锻造全人”，全面提升学生的综合竞争力，通过“第二课堂”“城院大讲坛”等途径，为学生提供多元选择，达到提升学生人文素养、陶冶学子情操、健全学生人格，有效落实三全育人机制，实现“立德树人”的目标。

教学科研部部长杨勇虎对综合素质养成教育计划的后续部署进行说明，他指出综合素质养成教育计划对我校人才培养的重要性，希望全校上下共同努力，继续开展落实好各项养成教育计划项目课程。

教务处处长助理周杰对综合素质养成教育计划的实施细节进行详细说明，对养成教育计划的学分要求、类别、认定标准以及项目负责单位进行简介，并对近期实施过程中反馈的主要问题进行了回应。

校团委专职副书记陈浩华从总体部署时间轴、目前已实施的举措、待后续规划与展望三部分对养成教育计划部分课程的实施与反馈进行汇报。

交流会上，各二级学院党总支书记和辅导员等作了发言。大家针对“部分实施项目的学分设置”“必修学分课程隐性课程大纲实施进程”以及“新版大纲中部分项目课程如何实施认证”等问题进行了交流讨论。

校长助理、学生处处长任广新对本次交流活动的开展给予了肯定，他希望各二级学院党总支及辅导员要把会议的精神传达到同学之中，要充分认识我校综合素质养成教育计划开展的重要意义，要把综合素质养成教育计划落实好，顺应高等教育综合改革潮流，服务大局，找准定位，成为吸引凝聚青年学生的品牌活动课程。
