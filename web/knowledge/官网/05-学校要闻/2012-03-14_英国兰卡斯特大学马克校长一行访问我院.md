# 英国兰卡斯特大学马克校长一行访问我院

近日，英国著名大学——兰卡斯特大学（Lancaster University）校长马克?史密斯（Mark?Smith），副校长罗伯特?麦克金雷（Bob Mckinlay）、史蒂文?布拉德利（Steve Bradley），在广东外语外贸大学党委副书记、校长仲伟合及校长助理、国际学院院长陈林汉等领导的陪同下，来到我院新校区参观考察。广东鸿发投资集团有限公司总裁、东莞理工学院城市学院董事长麦照容及广东鸿发投资集团有限公司副总裁、东莞理工学院城市学院董事黎建烨等领导热情接待了来访客人。

马克校长一行兴致勃勃且极为认真地参观、考察了我院新校区，并深入到综合馆、图书馆、电子信息大楼、工业技术中心大楼等考察了运动场馆、图书馆系统、数字校园、多媒体设施、物理实验室、金工实习车间等建设情况，对新校区在基础建设、教学教研等方面所取得的成绩给予了充分的肯定。

据悉，马克校长此行目的是为兰卡斯特大学在中国寻求合作伙伴，实施跨国合作办学战略。兰卡斯特大学在1964年获英国皇家特许状成立，学校位于英格兰的兰开夏郡，现有学生17000多名，享有非常好的学术声誉，2012年在英国113所大学中名列第九位。
