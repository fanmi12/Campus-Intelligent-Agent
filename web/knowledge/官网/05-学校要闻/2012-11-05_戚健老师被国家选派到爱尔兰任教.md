# 戚健老师被国家选派到爱尔兰任教

近日，国家汉办来文称，城市学院文学与传媒系英语教师戚健，经考试合格，被国家选派到爱尔兰科克大学孔子学院任教。

据悉，今年教育部在全国共选拔了271名教师分赴有关国家孔子学院任教，时间为两年。日前，戚健老师已参加了汉办举办的为期一个半月的岗前培训，将于本月底赴爱尔兰国。
