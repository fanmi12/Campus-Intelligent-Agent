# 开学在即  万事俱备

经过一个暑假的紧张施工，校园装扮得更加亮丽、温馨而舒适，处处展露出美丽的姿容。据有关职能部门负责人介绍，开学前的准备工作已进入最后的冲刺阶段，除个别例外，所有的工程队将于8月29日完工退场。各系部及院机关处室按照学院的统一部署，紧锣密鼓地做好迎新准备工作。目前，万事俱备的校园，正舒展双臂迎接6000多名老同学和3000多名新同学的到来。

据悉，今年暑假期间，学院对校舍、饭堂、图书馆、教学楼、电力线路和网线等进行了大面积的装饰装修和改造。通过改造和租赁办法，全院又新增1200张床位，可以满足新生入住。

记者走在刚刚装修完工的教学楼中，崭新的课桌椅和空调，使课室焕然一新，散发着时代气息。明亮洁净的玻璃窗挂着新购置的素色窗帘，白炽灯、电源开关、滑动黑板都是新的。改建完成的学生公寓设施完善齐全，给人以家的感觉。

8月27日，学院召开中层干部会议，就迎新工作做了全面的安排部署。会议要求，各系部、各职能部门要把迎新准备工作进一步细化，相互衔接沟通，确保教师到位，教材到位，确保教学、生活秩序正常，让学生和家长放心满意。
