# 学校党校举行第27期入党发展对象培训班

9月19日-21日，学校党校举办第27期入党发展对象培训班。

党务工作部副部长叶凯贞主持了开班仪式，对此次培训目的、课程安排、课堂纪律及考核办法进行了说明，希望学员们珍惜学习机会，通过培训系统地掌握党的基本理论，坚定共产主义理想信念。

党委委员、校长王卫平以“继承发扬革命优良传统，做新时代合格大学生”为题，要求学员们继承和弘扬井冈山精神、延安精神、西柏坡精神，努力培育和践行社会主义核心价值观，积极投身到粤港澳大湾区建设中。

党委书记章德胜围绕入党条件和入党动机这两方面，与学员们进行了深入探讨与分享。他重温了入党条件，希望大家能不断自我反省、提炼和改进，不仅要力争在组织上入党，更要在思想上入党。

党委委员、副校长高香林为学员们梳理了《党章》的发展历程和十九大修改的主要内容。党委委员、副校长黄兢带领学员们一起了解了“国际视野下的中国共产党”。

党委委员、校办主任杜鹏举以“不忘初心，争做先锋”为主题，让同学们深入理解了什么是初心，如何不忘初心发挥大学生党员的先锋模范作用。

党务工作部副部长叶凯贞讲解了党员发展制度和发展党员必经的五阶段二十五流程。

马克思主义学院党支部书记史雍真带领学员们回顾了新时代党的伟大斗争、伟大工程、伟大事业和伟大梦想。

通过学习，学员们对党的性质、宗旨、作风等有了更深刻的认识，进一步增强了责任感和使命感，进一步端正了入党动机，坚定了入党决心。
