# 新生军训汇报表演今天上午隆重举行

九月骄阳似火，青春岁月如歌。9月22日上午9时，2017级新生军训汇报表演在学院运动场隆重举行。全体军训教官、指导员和2017级新生参加了军训汇报表演。

观看今天军训汇报表演的领导有：东莞理工学院副校长杨敏林，城市学院董事黎建烨，广东鸿发教育文化集团有限公司总经理陈超群，承训91676部队汤剑飞中校、罗强龙中校，院领导王卫平、章德胜、黄兢、周庆、刘玉侠、林江龙等。

雄壮的军乐声中，在军训团长汤剑飞中校的陪同下，王卫平院长检阅了受训新生队伍。

整齐划一的队列、矫健有力的步伐、斗志高昂的士气，由2017级新生组成的方阵在教官的带领下，依次通过主席台接受检阅，展现了我院学子的青春活力和良好的精神风貌。

声势震撼、动作有力的军体拳、格斗表演，训练有素、令人耳目一新的盾牌反恐防暴、战地救护、海军旗语等项目表演，展示了同学们14天来艰辛训练取得的丰硕成果，获得了阵阵掌声和欢呼。在海军旗语表演中，同学们送上“祝城市学院明天更美好”，赢得了全场雷鸣般的掌声。

汤剑飞团长在军训总结中，赞扬了同学们头顶烈日挥汗如雨坚持不懈的可贵精神和“不怕苦、不怕累”的优良作风，希望大学军训成为同学们勇往直前、超越自我的催化剂，帮助大家成为对国家、社会和人民有用的新一代青年。

通过检阅、汇报表演，2017级新生在承训部队教官、指导员的严格教导下，以优异的成绩圆满地完成了大学第一课——军事训练任务。在军训中涌现的一批先进连队、先进个人，受到了大会的隆重表彰。
