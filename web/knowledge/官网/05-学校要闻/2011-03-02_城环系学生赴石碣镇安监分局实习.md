# 城环系学生赴石碣镇安监分局实习

3月1日，城市与环境科学系08级安全技术管理专业的7名学生，在系主任肖红飞教授的带领下来到石碣镇安监分局，进行为期三个月的实习。

石碣镇安监分局局长何锦昌对我院师生的到来表示热烈的欢迎，副局长何齐英向实习学生介绍了分局的基本情况，并对实习工作做了具体的安排。

据悉，石碣镇安监分局是城环系去年年底新增的实习基地。
