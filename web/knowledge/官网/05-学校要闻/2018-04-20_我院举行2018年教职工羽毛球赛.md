# 我院举行2018年教职工羽毛球赛

4月19日下午，历时两周的学院教职工羽毛球赛在综合馆落幕。经过激烈角逐，体育教学部与机关一并列第一名，机关二位居第二，机电系获得第三名。

本次比赛共有14支教职工队伍参加，采用了混合团体赛赛制，设有男子单打、女子单打、男子双打、混双四个比赛项目。

整个赛程在拼搏与友谊的良好氛围中进行，参赛选手们英姿飒爽，全身心投入比赛当中，为师生呈现了一场又一场精彩的比赛，进一步丰富了教职工的业余文化生活。
