# 【众志成城 抗击疫情】相约线上课堂——优秀教师经验谈之十四

我校坚决贯彻落实教育部、省教育工委、省教育厅的重要部署，从3月起全面开展线上教学活动，全体任课教师坚守岗位、锐意创新、勇挑重担，全力做好线上教学工作。前十三期我们精选刊发了四十位优秀教师线上教学经验谈后，在全体教师中产生了良好的反响，受到广大师生的欢迎和点赞。今天刊发第十四期，推介金融与贸易学院彭军、计算机与信息学院王苏明、艺术学院王蓉三位老师的线上教学心得体会，供大家分享。

金融与贸易学院彭军老师线上教学心得体会：本学期按学校的要求，采用了线上平台与企业微信直播结合模式进行教学。通过一段时间的教学实践，主要有以下的心得体会：

1.针对线上教学特点，完善课程的知识结构、重点内容及难点的讲授时间安排等，主要是完善教学PPT、做好各种教学参考资料的电子化文档、明确相关实际案例的互联网网址等。

2.利用平台提供的网络资源、文字、图片、视频、课件等，与课程教学内容形成互补，如平台的教学内容是偏向于管理决策方法的，本课程内容是偏向于经营理念的，互补能够丰富相关的教学内容，开阔学生的专业视野。

3.事先布置课程问题，通过预习、课堂学习、提问等，解决网课中的实际问题。

教师寄语:机会总是留给有准备的人，同样留给会选择的人。

计算机与信息学院王苏明老师线上教学心得体会：直播授课对于我来说是第一次，有很多地方需要摸索和尝试，在这段时间的直播授课中，我有以下几点体会：

1、做好软硬件基础设施的保障

工欲善其事必先利其器，在第一次授课之前就跟同事交流直播授课的方式并进行多次试课以检查各项软硬件。考虑到数学科目需要板书比较多，向学院申请购买了数位板，自己又购买了摄像头等，有效地保证了教学直播的效果。

2、精心做好备课工作

网络授课不能与学生面对面交流，所以在网络授课时要做到图文结合、讲解精炼、生动有趣。认真钻研教材，把握重难点，努力搜集优秀网络资源、视频录播等作为补充，按学情不断调整教学任务。

3、认真上好每一节课

网上授课对于学生的学习状态难以掌握，上课前将本次学习的内容与目标及预习视频在企业微信群里发布，让学生学有方向。上课时力求避免枯燥的讲解，时刻关注互动对话框，与学生互动，鼓励学生质疑、讨论、连麦发言。

4、抓好课后答疑环节

配合授课内容，及时布置适量的作业进行巩固练习，借助于企业微信群进行交流答疑解惑。

疫情之下，网络之上，七个星期的线上教学已经结束。对我来说，线上教学就是一个不断实践不断学习不断完善的过程。它虽是初次尝试，却是对我们师生教法学法改革的一次严峻考验，更是教会了我和同学们如何面对困境，如何在逆境中不断成长。

教师寄语：上下同欲者胜,风雨同舟者兴。

艺术学院王蓉老师线上教学心得体会：新年伊始，一场突如其来的疫情，注定了这是一个特殊的学期。疫情防控期间，大家克服种种困难，把客厅、卧室、走廊能利用的空间都变成了“舞蹈室”，数码设备也都成为教具。根据舞蹈专业特殊性，我们即要讲到位，又要练到位。做好课前预习、课后练习。因此采取了直播和会议两种模式。直播主要示范并讲解重点难点，播放ppt增强学生专业知识。会议主要指导学生练习。通过这些教学环节达到了预期的效果。停课不停学，让我们全校师生齐心战“疫”。
