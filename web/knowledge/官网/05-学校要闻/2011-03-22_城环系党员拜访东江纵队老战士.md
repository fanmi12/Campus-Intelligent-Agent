# 城环系党员拜访东江纵队老战士

3月19日，城市与环境科学系党总支组织教工党支部、学生党支部60名党员前往厚街松山公园，拜访东江纵队老战士，听他们讲述革命故事。被拜访的老战士有：厚街东江纵队粤赣湘边纵队老战士联谊会会长方应森，会员王树、李天培、王玩兴。城环系主任肖红飞教授、党总支支副书记孔增强参加了此次活动。

我院师生首先拜访了老战士王玩兴，他们夫妇都是东纵老战士。二位老人向同学们赠送了一些历史书籍。接着大家又瞻仰了王作尧将军的塑像。

东莞电视台对这一活动进行了全程跟踪采访。
