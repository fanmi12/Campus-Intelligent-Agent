# 新年新学期  处处书声朗

程院长一行视察开学工作

学生领到了新教材

同学们开始了新学期的第一课

送走了春节，迎来了新学期，全体师生又投入了紧张的工作与学习，校园处处又见读书人。

2月18日开课第一天，副院长程发良教授、教务处处长邓成良教授一行巡查了全院上课情况。据了解，全院教师到课率为100%，学生上课出勤率为98.3％，课堂纪律良好，教学秩序井然。

另外，从教务处获悉，本学期应到教材348种，实到321种，有27种教材因天气原因未能到位。据悉这些教材将于近日陆续到位。
