# 金贸系领导看望暑期社会实践学生

今年署期，金贸系实施“提前进岗”计划，选派近200名学生到中国人寿东莞分公司、中宏人寿东莞公司、中国人保东莞分公司、东莞证券等单位进行为期三周的进岗实习。

2011年7月25日至8月3日，金融与贸易系系主任米双红教授，龙卫洋博士分别到相关单位看望了暑期进岗实习的学生。学生们表示通过进岗实习获益匪浅，除了学习理论知识外，还学习了社交、礼仪、团队协作等内容。用人单位对我院学生的表现给予了高度评价，并对我院的人才培养提出了很好的建议。
