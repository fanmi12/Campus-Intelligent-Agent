# 学院隆重举行2008庆国庆、迎新生暨军民联欢晚会

9月25日，东莞理工学院城市学院2008级“庆国庆、迎新生”暨军民联欢晚会在田径场隆重举行。

东莞理工学院党委书记周致纳，东莞理工学院校长、城市学院董事长杨晓西，东莞理工学院党委副书记黄碧莲，东莞理工学院副校长、城市学院院长安少华，著名爱国人士、全国政协委员、香港太平绅士、香港金城营造集团有限公司董事长王锦辉先生及其夫人，以及3000名新生观看了晚会。

在晚会开始之前，东莞理工学院城市学院党委副书记朱冰主持了“金城营造革命老区大学生励志奖学金”颁赠仪式。香港金城营造集团有限公司董事长王锦辉先生及其夫人为我院5名08级四川通川籍新生颁发了6万元奖学金。城市学院副院长程发良教授为我院08年优秀毕业生香港大学硕士研究生陆正祥同学颁发奖金1万元。

昨晚的演出内容丰富多彩，教官与同学们同台演出，共展技艺，分享军民联欢的快乐，台上台下，歌声、笑声、欢呼声融成了一片欢乐的海洋。
