# 评审专家考察我院新校区

11月22日，省学位办对我院新增学士学位授予单位和专业审核进入实地评估的第二天。上午9时，评审委员会主任徐真华及专家组成员王元良教授、苏运法高级会计师、鲍鸿教授、李青教授、桂寿平研究员、卫海英教授、战荫伟教授一行，在安少华、朱志德、杨敏林、程发良、朱冰、张林等院领导的陪同下对我院新校区进行实地考察。

专家们首先参观考察了综合馆，并听取了新校区管委会教务部副部长胡钦华的汇报讲解，对该馆集体育馆、大礼堂及体育系、艺术系办公教学于一体的多功能用途和特色，及可同时容纳5000名学生开会、举办大型体育赛事、体育教学活动和文艺演出的功能，表示赞许。

随后，专家们还参观了运动综合区、学生生活区、学生活动中心等区域，并重点考察了图书馆。

专家们先后参观考察了图书馆的网络机房、展览区、图书阅览室和计算机房等，并听取了有关图书馆建设规划、建筑特色、功能布局、数字化建设、管理服务模式等情况的汇报，并饶有兴致地观看了工作人员对“自助借还书系统”、“RFID图书定位系统”等先进设备的演示和介绍。新校区图书馆高标准、高规格的建筑特色和设施，以及先进的图书管理设备、先进的管理服务模式等都让专家们留下了良好的印象。

与此同时，杨敏林副院长还向专家们详细地介绍了新校区的区位环境、整体规划、建筑特色、功能布局、建设成就及教学管理等情况，并阐述了新校区“山、水、树、人”的建设规划理念。专家们一边听取汇报，一边观看鸟瞰图，连连赞叹新校区建设“一步到位”，具有科学和长远的战略眼光；对新校区的建筑布局、教学设施和教学管理等工作，给予了充分肯定与赞扬。

参观考察结束时，专家们和院领导还在图书馆前合影留念。
