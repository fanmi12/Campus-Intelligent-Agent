# 城市学院管委会第二次主任办公会议召开

5月25日，管委会主任麦照容主持召开了城市学院管委会第二次主任办公会议，重点讨论城市学院新校区延伸管理模式及日常管理架构问题。

会议决定，学院成立新校区管委会，杨敏林任主任，学院党委副书记朱冰及鸿发集团麦绮琳任副主任，下设相应工作部门，具体负责新校区工作。

会议强调，城市学院中层干部和全体教职工，要以确保九月份新生进驻新校区为硬任务，整合资源，做好延伸管理方面的各项工作。

会议拟定于8月份举办城市学院中层干部学习班，会议的主题是如何创建特色鲜明、国内一流的独立学院，动员全院中层干部建言献策，共同研究城市学院未来发展的措施。
