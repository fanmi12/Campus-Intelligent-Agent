# 黄碧莲书记：廉政纪律教育工作要常抓不懈

10月28日，东莞理工学院党委副书记、纪委书记黄碧莲，审计监察处处长汪璟一行分别走访了我院两个校区，视察我院党风廉政纪律教育工作。座谈会上，黄书记听取了我院党委领导的工作报告，并对我院提出廉政纪律教育工作要常抓不懈的要求。

稳定大形势 两校三区和谐共处

城市学院党委书记朱志德，城市学院党委委员、学生处处长章德胜向黄碧莲书记汇报了城市学院党风、教风、学风建设情况和纪律教育工作。

朱志德书记介绍，城市学院党委经研究决定成立了新校区临时党总支，并采用延伸管理的办法，由各系党支部负责，其主要目的是要加强两校区的党建工作力度，发挥党组织的战斗堡垒和政治保障作用，共同把两个校区的党建工作做好。

黄碧莲副书记赞扬城市学院党政队伍精干，执行力强。城市学院不仅圆满地完成了新校区建设和招生迎新工作，“迎评促建”更是在时间紧、任务重、压力大的情况下，高效地开展了各项工作。针对目前两校三区的新形势，城市学院党委要积极做好协调工作，稳定人心，确保各项工作顺利开展。

寄望新校区 党员发挥带头作用

在新校区座谈会上，城市学院党委副书记、管委会党总支书记朱冰就城市学院新校区党建等工作做了汇报。

东莞理工学院党委委员、城市学院副院长杨敏林还就新校区的教学管理工作做了介绍。目前教学工作进展顺利。接下来将进一步丰富学生、教职工的课余文化生活，完善党团组织建设、工会组织建设。

黄碧莲副书记希望新校区临时党总支和管委会做好学生安全教育，提高后勤服务水平，并不断丰富师生的文化生活。新校区条件艰苦，党员干部要积极发挥带头作用，克服困难，积极投入工作。
