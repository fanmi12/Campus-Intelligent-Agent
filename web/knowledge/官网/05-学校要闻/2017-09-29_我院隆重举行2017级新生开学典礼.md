# 我院隆重举行2017级新生开学典礼

今日上午，2017级新生开学典礼在学院运动场隆重举行。东莞理工学院副校长杨敏林，城市学院董事黎建烨，广东鸿发教育文化集团有限公司总经理陈超群，院领导王卫平、章德胜、黄兢、周庆、刘玉侠、林江龙，以及学院各单位负责人出席了典礼仪式。

在庄严的升国旗仪式中，开学典礼拉开序幕。

院党委副书记章德胜宣读了《关于表彰2017年新生奖学金获得者决定》，对外语系叶韦静、城环系陈满庭等40名获得优秀新生奖学金的同学进行了表彰，奖金总额高达88万元。

院长、书记王卫平发表了热情洋溢、深含哲理的致辞。他对新同学们为学院带来的八方锐气和欢歌笑语，表示热烈欢迎，期待大家在这里快乐生活、快乐学习、健康成长。

王卫平院长教导新生:“今天踏上大学征途是一种荣耀，昨天那些值得回味的点点滴滴已成为故事，明天充满希望与挑战。”他指出，最大的动力是理想，最大的兴趣是学习，最大的欣慰是奉献，最大的财富是健康，最大的快乐是知足，最大的幸福是感悟，最大的享受是成功……

在谆谆教导中，王卫平院长告诫同学们“清醒坦诚是做人之本、聪明智慧是做事之源”，希望同学们从今天起，“树理想、立目标、定行动计划”，知晓人生，做个“明白人”。
