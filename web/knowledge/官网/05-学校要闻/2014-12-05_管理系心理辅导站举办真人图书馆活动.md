# 管理系心理辅导站举办真人图书馆活动

“书籍”也能开口讲话了？图书馆只借人不借书？12月2日晚，管理系在图书馆5楼“校园时光”咖啡厅举办首场“真人图书馆”活动，吸引了不少读者前来“借阅”、听“书籍”讲话。

活动现场六本“真人书”与同学们围坐一圈，分享自己的人生故事，畅谈关于大学的心得与体会。

本次活动的主题是“这个冬日阅读我，温暖你”。本期推出的真人图书共有六本，分别是创业书、学霸书、干部书、口才书、情感书、旅行书。

第一本“创业书”是管理系模拟招聘会亚军获得者李露冰，她讲述的故事题目是“创业?梦想——我要成为一名咖啡师”， 创业体会是“千万不要吝惜自己的勇气，要大胆地做，勇敢地尝试”；“口才书”是演讲协会会长黄永亮，他讲述的主题是“挑战自我，真诚表达”；“旅行书”古意讲述的主题是“大学与旅行”；“学霸书”管理系国家奖学金获得者郑梦芬讲述的主题是“我不想沦为学霸”；“干部书”第九届管理系团总支书记许超云以“快乐服务，提升自我”为题，讲述了自己在团学工作中服务学生、不断完善自我的成长经历；“情感书”李海静同学结合自己的亲身经历跟师弟师妹们探讨了大学生的“情感与生活”。

同学们反映，“每个人的经历本身就是一本读不完的书。”
