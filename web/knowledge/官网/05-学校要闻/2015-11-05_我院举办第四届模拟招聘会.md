# 我院举办第四届模拟招聘会

11月4日晚，我院第四届“勇往职前，城院之星”模拟招聘会在学术报告厅举行。分众传媒东莞分公司总经理张红光先生、恒缘心理向晓萍女士、环众软件有限公司董事长蓝仁昌博士等嘉宾参加了模拟招聘会。

模拟招聘会在院党委副书记章德胜热情洋溢的致词中拉开序幕。比赛共分5个环节：自我展示、职场问答、专家点评、岗位推荐和专业评分。

来自2012级金贸系的“小眼睛”廖彬想成为一名“探索教育引导员”，最终他的表现赢得了分众传媒东莞分公司的青睐；2012级财经系张俊芳、机电系林启文、文传系黄琳更是凭借自己的妙语和急才博得了阵阵掌声以及各家公司的好评。想成为“销售助理”的财经系梁银花、想成为“项目执行助理”的管理系邓思如和想成为“电台广播员”的艺术系郑茜任都是2014级的学生，她们的表现毫不逊色于师兄师姐。郑茜任还借助舞台告诉观众，“不要因为别人的闲言碎语而放弃自己的梦想。”

经过精彩角逐，分众传媒东莞分公司获得了廖彬、林启文和郑茜任的选择，品宅装饰则和黄子芬、梁银花达成共识，而张俊芳选择了汇丰银行，黄琳选择了东莞天使秘书会。

经过评委们的评定，林启文荣获一等奖，黄琳获二等奖，张俊芳获三等奖和人气奖；郑茜任获“最具职场魅力奖”，梁银花获“最具潜力奖”，廖彬获“最佳才智奖”，“优秀奖”是黄子芬和邓思如。

其间，OLT街舞队和歌手曾楚璘的精彩表演为模拟招聘会增添无限活力。
