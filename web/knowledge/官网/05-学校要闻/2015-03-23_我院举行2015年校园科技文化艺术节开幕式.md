# 我院举行2015年校园科技文化艺术节开幕式

3月19日，2015年城市学院校园科技文化艺术节开幕式暨第四届“女生节”闭幕式在下沉广场隆重举行。党委副书记章德胜，党委委员、学生处处长杜鹏举出席本次活动。

杜鹏举处长在讲话中指出，今年的科技文化艺术节以“践行核心价值观，共筑青春中国梦”为主题，旨在进一步活跃校园文化生活，激发同学们学科技、用科技的学习热情。希望广大师生以此为契机，创新活动形式，丰富活动内容，提升活动质量，为校园科技文化建设、培养应用型创新人才贡献力量。

据介绍，本次科技文化节历时两个月，活动内容包括篮球文化嘉年华、创业计划书大赛、第十届工商模拟市场等21个活动项目。

在开幕式上，K-pop组合、戏剧社、院学生会女生部先后表演了舞蹈《nice body》、《girl’s time》和小品《疯狂的电视台》等十多个节目。
