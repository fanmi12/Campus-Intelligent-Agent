# 学院举办文秘人员业务知识培训班

为了规范办公室工作程序，提高文秘人员的工作效率和工作能力，发挥办公室参谋助手作用，学院于6月15日在315会议室，举办了全院文秘人员业务知识培训班。参加培训的有院机关各处室、系部主要负责人及办公室文秘人员。

东莞理工学院党委委员、办公室主任李忠红副教授，应邀为培训班介绍了办文、办会、办事、档案管理的工作流程和注意事项，以及自己的工作经验与体会。

院长安少华教授在培训班上对文秘人员提出了三点希望：一是要端正服务态度，满腔热情地为领导服务，为教师和学生服务；二是要提高工作效率，减少和杜绝工作差错；三是提高工作能力和水平，深入实际，熟悉情况，为领导决策提供科学依据，发挥参谋助手作用。
