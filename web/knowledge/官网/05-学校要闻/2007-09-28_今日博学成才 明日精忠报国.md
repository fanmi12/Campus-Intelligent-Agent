# 今日博学成才  明日精忠报国

丹桂飘香，金风送爽。9月28日，在开学典礼仪式上，我院2500名07级新同学，相聚在田径运动场，与校本部领导、学院负责人、系部主任和辅导员现场见面，共同见证新学期开始的幸福时刻，携手掀开人生新的篇章。

东莞军分区副政委喻清明大校，中国人民解放军海军沙角训练基地副司令员肖继生中校，东莞理工学院党委书记周致纳，东莞理工学院党委副书记、院长、城市学院董事长杨晓西教授，中国科学院院士徐建中教授，东莞理工学院党委副书记、城市学院董事王江水，东莞理工学院副院长、城市学院院长安少华教授，原解放军通讯学院中将副院长博士生导师谢希仁教授，中国科协直系中南集团分公司董事长、城市学院顾问杨元惺先生，东莞理工学院教务处长、城市学院董事阮湘元教授，东莞理工学院财务处处长、城市学院董事刘文成同志，城市学院党政领导朱志德、程发良、朱冰、张林，院督学林世俊出席了典礼仪式。

院长安少华教授首先致辞。他说：热烈欢迎同学们来到城市学院，开始新的学习生活。今年我院共录取来自全国20个省、市2521名新同学。目前，全校在校学生达8000人。我们一定尽最大的努力，为你们提供良好的学习、生活环境，帮助你们完成好学业。同时，也希望同学们尽快转换角色，适应新环境。从今天开始，你们将在一个全新的环境里开始一种不同于中学时代的集体生活。新的生活环境 ，新的人际关系，新的授课方法，新的管理模式，新的奋斗目标，会带给你们激动，也许还会带给你们一些失落。你们要积极学习，勇敢面对，尽快适应大学的新生活。希望同学们学会做人，塑造完美人格，做一个真诚的人，一个具有社会责任感的人。希望同学们学会学习，培养创新精神。在学习中学会发现，在生活中学会欣赏，在实践中学会创造，通过大学三四年的学习，积人文之底蕴，倡法制之文明，养浩然之正气。希望同学们学会做事，培养各种能力。从小事做起，不断积累经验，锻炼独立的生活管理能力和独立选择、判断、处理问题的能力与应对各种情况与各种环境的能力。希望同学们能够珍惜这个来之不易的学习机会，刻苦学习，努力使自己各方面得到良好的发展，让这几年的大学生活变得充实而有意义。

刘杰教授、刘文晓同学分别代表教师和新同学在会上发了言。

根据城市学院“金城营造”励志奖学金有关规定，学院为来自革命老区四川通江地区贫困大学生颁发了6万元奖学金。

今年新聘用的辅导员在典礼仪式上与新同学见面，并作了简短的自我介绍。
