# “榜样城院”感动你我他

为表彰先进、树立典范，我院于12月7日晚在综合馆隆重举行“榜样城院”颁奖典礼，表彰2013-2014学年度先进班集体、优秀学生干部、优秀大学生、校园十佳、各类奖学金获奖者以及市级以上竞赛获奖的学生团队。

学院院长杨敏林、董事会董事黎建烨、党委书记王卫平、副院长张林、院督学陈丁堂、党委副书记章德胜、副院长高香林、院长助理麦绮琳、各系部处主要负责人等领导和嘉宾出席了本次颁奖典礼。

此次表彰中，2011级高级文秘2班等25个班级荣获先进班集体称号，杨仲宇等753名同学荣获优秀学生干部称号，林文聪等591名同学荣获优秀大学生称号，郑梦芬等9名同学荣获校园十佳、国家奖学金称号，谭启等20名同学获得鸿发奖学金，黄秋萍等50名同学获得校园各类奖学金，院学生篮球代表队等3个学生团队获得市级以上竞赛奖。

会上，院党委副书记章德胜宣读了表彰决定，文传系优秀学生干部梁舒琪、艺术系鸿发奖学金获得者谭启等在台上分享了自己在大学中一路走来的经验与感悟，并决心把荣誉化为不竭的动力，以此来回报学院与老师辛勤栽培。

杨敏林院长在颁奖典礼上作了重要讲话。他首先向获奖学生和集体表示祝贺，对他们过去一年的表现与付出给予了充分肯定。他说：“这些获奖同学的身上彰显了城院精神，展现了当代大学生的风采，是城院的骄傲、同学们的榜样”。杨院长希望广大学生虚心向他们学习，像他们那样具有积极进取、奋发向上的时代精神，刻苦勤勉、踏实求真的学习态度，乐于奉献、团结拼搏的城院精神。用自己的努力证明自身的价值，用汗水和智慧换取骄人的成绩。

最后，我院2013-2014学年度先进集体、优秀个人表彰大会暨颁奖典礼在先进班集体2012级影视表演专业的同学带来的一段优美舞蹈中落下帷幕。

本次“榜样城院”颁奖典礼活动是我院党委树立优良学风、校风，彰显 “正能量”的一次盛会；是争先创优活动的一次总结；是一堂生动的思想政治教育课。我们身边的优秀学生干部、优秀大学生、先进班集体、校园奖学金获得者、企业奖学金获得者、国家奖学金获得者、青年志愿者、各种竞赛的积极分子都是同学们努力践行社会主义核心价值观中传递正能量的榜样。

据悉，“榜样城院”活动将进一步拓展、完善和提升，作为我院的品牌活动传承下去。

附件：2013-2014学年度先进班集体、校园十佳、优秀大学生、优秀学生干部及奖学金获得者名单
