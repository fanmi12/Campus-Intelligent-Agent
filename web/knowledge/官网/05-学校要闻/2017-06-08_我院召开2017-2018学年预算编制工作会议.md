# 我院召开2017-2018学年预算编制工作会议

6月1日下午，我院召开了2017-2018学年预算编制工作会议。学院领导王卫平、黄兢、周庆、刘玉侠和各单位负责人出席了会议。

财务处罗晓婷科长介绍了下一学年预算编制的主要程序、预算经费的申报方法和工作要求。余竹根处长对预算编制过程中需要注意的事项进行了补充，并对与会人员提出的疑问进行了解答。

周庆副院长指出，各单位应结合本部门下一学年的工作目标及重点开展好预算编制工作，并做好财务预算的管理工作。

王卫平院长强调，学院预算经费要做到有的放矢，紧密围绕学院的年度工作重点，确保重点工作的经费优先安排。
