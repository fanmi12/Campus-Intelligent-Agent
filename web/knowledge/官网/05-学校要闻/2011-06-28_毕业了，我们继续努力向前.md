# 毕业了，我们继续努力向前

毕业典礼主会场

周致纳书记为毕业学生颁发学位证书

杨晓西校长为毕业学生拨穗

安少华院长向毕业生代表颁发毕业证书

麦照容董事长与优秀毕业生代表合影

优秀毕业生代表与领导合影留念6月，是一个告别的季节。6月的校园，处处洋溢着一种离别的淡淡酸涩，但同时也充盈着一种开启人生崭新征程的豪情。今天，我院在大礼堂隆重举行2011届本科生毕业盛典，欢送毕业生奔赴祖国各地开始人生新的征程。

东莞理工学院、鸿发集团、城市学院周致纳、杨晓西、安少华、麦照容等领导以及各学科学术带头人出席了典礼仪式。

会议首先播放了毕业生在校活动的DV短片，院长安少华教授向毕业生代表颁发了毕业证书，朱冰副书记宣读了2011届优秀毕业生表彰决定，麦照容董事长向优秀毕业生代表颁发荣誉证书。

毕业生代表07级影视表演班杜鑫在发言中，表达了对母校深深的眷念和感激。教师代表徐中和教授的发言，博得现场一阵又一阵的热烈掌声。

安少华院长发表毕业致辞，对同学们深情寄语，并向同学们表达了美好的祝愿（全文见新闻链接）。

最后，学院举行了庄重的拨穗仪式，各级领导为毕业生拨穗并颁发学位证书。

仪式结束后，优秀毕业生代表与领导合影留念。

今年我院共有3000余名本专科学生毕业。修完了课程，顺利拿到毕业证书。其中，有704人加入了党组织。绝大多数同学已经落实工作单位，就业形势喜人。一些专科毕业班学生通过自己的努力考上专插本，多位同学考取中山大学、华中科技大学、华南理工大学、华南师范大学等全国知名院校的研究生，其中政法系2007级的汤文杰同学名列中山大学刑法专业全国第一名。艺术系杜鑫同学成为了海南航空的一名飞行员，即将飞向蓝天拥抱自己的梦想。

我院2007级毕业生，见证了城院的日新月异的发展。文传系沈星同学说，学生公寓数量越来越多，住宿条件越来越好。崭新的图书信息大楼建成。 2010年，城市学院新校区筹建工作开始启动，新生9月将入住新校区，我们不仅见证了城院的发展，四年的时间里也见证了自己的青春、成长和点点滴滴的进步。政法系张洁茹同学表示，我们在城院收获了学业，收获了友情，收获了青春的历练。今天从这里又重新出发，必将走得更为潇洒，更加豪迈。

对于这些即将走出校门、走向社会的毕业生，城院的每一位老师都对他们送上了深深的祝愿，希望自己的学生能将在大学里学到的知识技术、文化修养带到工作中，正直做人，踏实做事，一步一个脚印的朝着自己的目标前进。机电系主任黄健求教授认为，每一个城院学子，都是城院的骄傲。
