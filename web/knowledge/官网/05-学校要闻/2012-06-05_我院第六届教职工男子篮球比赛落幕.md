# 我院第六届教职工男子篮球比赛落幕

经过两周的鏖战， 5月29日下午，我院第六届教职工男子篮球赛最后两场赛事在莞城校区教工篮球场展开，分别由新管会代表队对阵机关代表队争夺冠亚军、教辅代表队对决机电系代表队争夺三四名。

下午5时，教辅队与机电队的对决率先开赛。经过四节激烈争夺，最终教辅队更胜一筹，摘得季军。

紧随其后举行的冠亚军争夺战，成为大赛的焦点，新管会队与机关队双方队员以饱满的精神状态展开激烈的角逐。整个赛事高潮迭起，精彩不断。尽管机关队在年龄上不占优势，但顽强的拼搏精神、神勇的表现，获得现场啦啦队的青睐，不断赢得阵阵喝彩与加油声。而新管会队凭借技术及体能优势，从比赛伊始就保持比分领先优势，并将优势持续到比赛结束，以72︰63将冠军纳入囊中。

冠亚军争夺赛事期间，组织者还增加了女子花样投篮环节，为对阵双方助阵，并将投篮成绩计入决赛比分，充分体现了篮球运动的大众性与参与性。
