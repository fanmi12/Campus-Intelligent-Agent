# 金融与贸易系学生赴虎门港参观学习

5月23日，金融与贸易系2011级国际经济与贸易专业1、2班共98名同学在张超老师的带领下，赴虎门港参观学习。

在虎门港服务大楼一楼的展示厅，同学们观看了虎门港全景沙盘的认知及相关视频。在东莞保税物流中心、西大坦商贸主港区，了解了虎门港物流管理的最新动态及国际贸易港口发展的趋势。在参观过程中，工作人员对同学们提出的相关问题作了回答。通过此次参观，同学们纷纷表示，增长了见识，在以后的学习中要不断探索创新、进一步巩固专业知识、拓展实践能力。
