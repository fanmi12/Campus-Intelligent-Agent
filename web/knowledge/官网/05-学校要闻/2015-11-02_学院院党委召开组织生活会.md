# 学院院党委召开组织生活会

根据中共东莞理工学院党委有关文件精神，2015年11月2日上午，学院党委以“三严三实”为主题召开了组织生活会。

会议认真学习讨论了习近平总书记以普通党员身份参加所在党支部组织生活会的讲话，对照党章等党内规章制度、党的纪律、国家法律、党的优良传统和工作惯例，以实事求是为原则，联系个人思想、工作和作风实际，围绕我院改革发展建设目标任务，进行了批评和自我批评，并对加强组织建设和下一步工作部署提出了具体要求。

王卫平书记要求，要在院内广泛开展“三严三实”专题教育学习，分层次、分单位，在学院党委、党委中心组及各单位党总支中召开组织生活会，组织广大党员参与讨论，开展批评与自我批评，推动学院的改革发展。
