# 华厦集团来我院商谈学生实习事宜

5月21日，华厦国际投资集团有限公司董事、总经理莫俊锋一行3人，前来我院商谈印刷专业学生实习事宜，受到院长安少华教授、学术副院长程发良教授的热情接待。教务处处长邓成良教授、实验中心主任周梓荣教授、机电工程系刘武辉博士也参加了座谈。

华厦集团是东莞市著名的大型民营企业，与我院建立了较为紧密的合作关系。2006年5月两个单位开启了校企合作仪式，2007年达成合作开办印刷专业的意向并开始招收印刷工程专业的学生。2009年下半年，这些专业的学生将开始专业实习。华厦集团作为该专业的实习基地，主动与我院商谈学生实习事宜，表示愿为学生提供实践平台，院领导对此表示感谢。

主客双方就印刷工程专业学生的专业实习问题展开洽谈。安院长表示，“校企合作”可以使双方达到互赢的目的，华厦集团可以提供学生的实践场地，我院也可以为华厦集团的员工培训提供师资等条件。

莫总经理一行还参观了我院印刷工程实验室，对我院的印刷专业建设给予了高度评价。
