# 【办学战略思想讨论之二】服务与建设互为促进

我是来自基层一线从事教学工作的一名教师，就“服务东莞高水平崛起 建设一流独立学院”谈谈自己的一些看法，提出一些不太成熟的建议，供学院领导参考。

第一，服务东莞高水平崛起和建设一流独立学院的关系。我认为，二者相辅相成、互为促进。服务东莞高水平崛起能为学院的进一步发展提供更好的发展动力，营造更好的发展氛围，获得更好的发展契机和外部资源；建设一流独立学院能培养更多实用的人才来服务东莞高水平崛起，能更好地为东莞高水平崛起提供智力支持和决策参考，能更多地寻找到服务东莞的途径和方法。服务东莞高水平崛起不能流于形式，不能单纯地为服务而服务，服务的目的之一应是能为建设一流独立学院提供更多的动力和资源。当然，建设一流独立学院也不能仅仅是在学院内部进行，应结合服务东莞高水平崛起来推进。因此，我建议，今天这样的座谈会除了在学院层面召开之外，还应联合市社科联、市教育局等单位在全市层面召开一次，集聚全市各方面包括政府、企业、民众等各阶层的智慧，共同研讨这一主题，从而推动二者更好地契合。

第二，服务东莞高水平崛起，应从以下三方面入手：一是建议学院设立服务东莞高水平崛起办公室。指派专人具体负责服务东莞的事务。根据前不久院宣传部收集到的我院服务东莞的相关信息和数据进行分析，哪些是我院服务东莞的强项、特色，哪些地方还没服务到位的，然后统一谋划，制定方案，以讲席专家为基础组织专业服务队伍，有所侧重地服务东莞高水平崛起；二是成立东莞高水平崛起研究中心。对涉及东莞高水平崛起的重点难点问题展开多学科的联合研究，找出我院服务东莞高水平崛起的切入点和具体服务领域，从而从学院实际和服务能力有所侧重地开展服务工作；三是建立服务东莞高水平崛起的激励约束机制。对服务东莞做出较大实绩和较大贡献的师生进行适当的物质精神激励，如报销差旅费等；反过来，对师生服务东莞也应建立约束机制，对师生在服务东莞过程中的不适当行为进行相应的惩处，以防范其不当言论及行为对学院声誉和美誉度的损害。

第三，建设一流独立学院，要正确看待院情，找准定位。我院在全国相关独立学院排行榜中的排名并不靠前，人气排名在100名左右，综合排名在200名左右，离一流独立学院的要求差距还比较大，在省内虽取得了本科学士学位单位授予权和17个本科专业授予权的好成绩，但也存在科研不太强、青年教师培养力度不太够等方面的短板，因此，必须充分分析和认识到我院的现实状况，制定切实可行的建设一流独立学院的规划和具体方案，组织专门力量来加以实施。我个人认为，当前应具体从以下几方面着手：1、学院迎评办对在迎评促建过程中收集到的省内其他独立学院公示的院级自评报告、简况表和专业简况表，组织研究力量就专业特色、师资队伍、学科优势等进行详细地横向比较，分析我院在全省独立学院中的优劣点和未来竞争点，分析各专业的特色和短板，为学院制定下一步第二次跨越的内涵发展规划提供基础性的决策依据；2、结合东莞高水平崛起的要求，认真梳理和讨论现有专业设置和人才培养方案的适用性，对专业和人才培养方案进行适当的微调，以更好地因应东莞高水平崛起的人才需求。3、应积极主动地进行多方沟通和协调，理顺政府、举办者东莞理工学院、办学者城市学院、投资方鸿发等方面的利益关系，形成合力共进的氛围，确立学院公益性办学的主体理念，构建四方联席沟通协商机制，明晰各方的责权利，重视现有教师队伍的合理诉求和稳定，防范办学过程中存在趋利偏差，从而推进学院真正朝建设一流独立学院的正道上奋力前行。
