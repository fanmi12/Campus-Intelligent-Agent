# 我校召开学习贯彻习近平新时代中国特色社会主义思想主题教育动员部署会

9月27日下午，我校在行政楼112会议室召开学习贯彻习近平新时代中国特色社会主义思想主题教育动员部署会。市委教育工委委员、市教育局党组成员、副局长杜润江同志，校党委委员、校领导、纪委委员、中层干部和党总支副书记出席会议，会议由党委副书记刘玉侠主持。

会上，党委书记章德胜作了动员讲话并对学校主题教育工作进行了部署。他指出，在全党深入开展学习贯彻习近平新时代中国特色社会主义思想主题教育，是党中央为全面贯彻党的二十大精神、动员全党同志为完成党的中心任务而团结奋斗所作的重大部署，是深入推进新时代党的建设新的伟大工程的重大部署。全体领导干部要深刻认识开展这次主题教育的重大意义，牢牢把握“学思想、强党性、重实践、建新功”的总要求，坚持学思用贯通、知信行统一，真正把马克思主义看家本领学到手，自觉用习近平新时代中国特色社会主义思想武装头脑、指导实践、推动工作。

章德胜强调，要全面把握主题教育的总体要求，把握正确政治方向，深刻领悟“两个确立”的决定性意义，增强“四个意识”、坚定“四个自信”、做到“两个维护”。要按照第二批主题教育有关文件要求抓好贯彻落实，对学校党委各级党组织的普通党员干部不同群体特点，作出合理安排；要突出问题导向，既解决党员干部自身存在问题，又解决教育领域人民群众急难愁盼问题，既解决制约高质量发展的问题，又解决全面从严治党中的问题；要强化基层基础，增强基层党组织政治功能和组织功能，充分发挥基层党组织战斗堡垒作用和党员先锋模范作用；要注重开门搞教育，虚心听取群众意见，自觉接受群众监督，主动接受群众评判，用群众的教育获得感、幸福感、安全感检验主题教育效果；要坚持严实作风，遵照党中央统一部署，根据中央、省委、市委的要求，全力以赴、精心组织，以这次主题教育为契机，真抓实干、担当作为，全力推动学校各项事业高质量发展。

市委教育工委委员、市教育局党组成员、副局长杜润江对我校动员部署工作表示肯定，他强调，开展主题教育是当前的一项重大政治任务，要压紧压实责任，明确具体安排和推进措施；要力戒形式主义、官僚主义，做好风险管控，在注重实效、提高质量上下功夫，不做表面文章、不搞花样翻新，把工作抓实、基础打实、步子迈实，确保主题教育取得扎实成效。

党委副书记刘玉侠表示，新时代风帆正举，新使命重担在肩，学校将在市委教育工委的指导下，牢牢把握“学思想、强党性、重实践、建新功”的总要求，以高度的政治责任感，响应号召、深入学习、全面落实，以学铸魂、以学增智、以学正风、以学促干，做奋进新征程的实干者、践行者，推动学校高质量发展再上新台阶。
