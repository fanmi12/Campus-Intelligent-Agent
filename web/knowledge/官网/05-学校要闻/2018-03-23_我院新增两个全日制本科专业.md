# 我院新增两个全日制本科专业

近日，教育部发布《教育部关于公布2017年度普通高等学校本科专业备案和审批结果的通知》，我院有两个专业获得通过，分别为机械电子工程（080204）、商务英语（050262），将在今年开始招生。至此，我院全日制本科专业达到40个。

据介绍，机械电子工程专业是培养德、智、体全面发展，具有一定的文化素养和良好的社会责任感，掌握必备的自然科学基础理论和专业知识，具备良好的学习能力、实践能力、专业能力和创新意识，毕业后能从事专业领域和相关交叉领域内的设计制造、技术开发、工程应用、生产管理、技术服务等工作，学制为四年，毕业授予工学学士学位。商务英语专业是培养具有良好的综合素质、扎实的外语基本功和专业知识与能力，掌握相关专业知识，适应我国对外交流、国家与地方经济社会发展、各类涉外行业、外语教育与学术研究需要的各外语语种专业人才和复合型外语人才，学制为四年，毕业授予文学学士学位。
