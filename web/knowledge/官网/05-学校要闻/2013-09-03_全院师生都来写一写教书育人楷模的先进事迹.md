# 全院师生都来写一写教书育人楷模的先进事迹

近日，教育部决定在全国开展教书育人楷模推选活动，省教育厅也相应发出文件进行了具体布置。

城市学院党委宣传部要求，全院师生要广泛参与这一活动，各系部要组织专人撰写本单位优秀教师的先进事迹材料，然后上报省教育厅。推选材料电子版发至：gdedursc@126.com据悉，宣传部将对这些优秀教师的事迹通过报纸、广播、网络、宣传栏进行宣传，对优秀推荐材料给予奖励。希望通过“推选”活动，在我院形成尊师重教、终身从教、精心育人的浓郁氛围。
