# 东莞理工学院城市学院召开教职工大会

9月1日下午，城市学院在5号阶梯教室召开全院教职工大会。常务副院长程发良主持会议，并向与会人员介绍了学院各系、部、处、室负责人。会上，学院党总支书记朱志德宣读了学院关于表彰2004-2005学年度教书（管理、服务）育人先进个人的决定、关于表彰优秀主讲教师的决定以及关于表彰杨春等同志勇擒抢劫歹徒的通报。接着，他和学院副院长林世俊分别传达了学院于8月22日召开的2005-2006学年度工作会议的两个报告，即党务工作报告和学院行政工作报告。学院院长安少华在会上作了总结讲话。
