# 我院学生会组织篮球赛

图为财经系和计算机与信息科学系的比赛进行的如火如荼3月7日下午，学生篮球场人头涌动，由我院学生会体育部组织的学生篮球友谊赛拉开了帷幕。

首先亮相进行比赛的是财经系男子篮球队和计算机与信息科学系男子篮球队。

比赛中两队各自队员互相鼓励，发挥团队精神，把技术发挥得淋漓尽致。但计算机与信息科学系不管是进攻能力还是防守能力都是技高一筹，最终以62：51拿下比赛。

赛场的另一边则是我院学生会男子篮球队和机电系男子篮球队的比赛。场上，一个个篮球健儿英姿矫健，一条条优美的抛物线，在夕阳的渲染下，成就了校园美丽的风景画。机电系实力稍强，最终以78：57夺得胜利。

此次比赛赛出了我院学生竞技水平和竞技风格，球员们在握手中宣告比赛结束。
