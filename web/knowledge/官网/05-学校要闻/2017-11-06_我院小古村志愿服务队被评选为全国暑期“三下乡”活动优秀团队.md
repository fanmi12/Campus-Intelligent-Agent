# 我院小古村志愿服务队被评选为全国暑期“三下乡”活动优秀团队

今年7月至12月，由中共广东省委农村工作办公室、省住房和城乡建设厅、团省委、省教育厅、省精神文明建设委员会办公室、省扶贫开发办公室、南方报业传媒集团、省志愿者联合会等共同开展“我为美丽乡村绘蓝图”——2017年南粤村庄（整治）规划志愿行动，动员全省城乡规划设计及相关专业人员、高等院校城乡规划相关专业师生，以志愿服务的形式推进2277条省定贫困村村庄（整治）规划编制，把省定贫困村建成新农村示范村。

此次志愿活动，我院作为唯一一所参与此项目的东莞高校，结合城市与环境科学系城乡规划专业一共派出了四支志愿队伍，分别对接河源及清远的四个贫困村。

11月4日，团中央学校部、全国学联秘书处对在2017年全国大中专学生志愿者暑期“三下乡”社会实践活动中表现突出集体和个人开展总结通报工作，经基层申报、省级团委审核推荐、专家评审等环节，我院河源小古村志愿服务队被评选为暑期“三下乡”社会实践活动优秀团队。这是我院在社会实践活动项目取得的新的突破。

目前，我院四支志愿队伍皆完成与村庄的对接并开展规划工作，展现出了我院志愿者的精神风貌，为农村精准扶贫和社会主义新农村建设贡献了一份力量。
