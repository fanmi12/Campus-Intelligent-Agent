# 高职部召开学生座谈会

<3月27日，高职教学部在1209教室召开学生座谈会，向学生介绍专业知识，征求学生对专业学习的意见。会议由党支部书记黄研晖主持，院督学、部主任林世俊教授，副主任谢俊高级工程师及高职部全体老师参加了会议。

首先，林督学传达了教育部关于大力发展高职高专教育的文件精神，以及高职教育的重要性与紧迫性。他通过对比本科教育和中职教育，阐明了高职教育的特点，指出高职高专人才的培养在我国经济社会发展进程中具有不可替代的作用。高职部将通过“校企合作、工学结合”的方式，培养学生具有良好的职业道德和动手实操能力与继续学习的能力。

黄研晖书记结合亲身体验和身边的实例，教育学生要明确学习目的，注重心理健康和素质的提高，学有一技之长，自信地面对学习与生活。

高职部的老师们分别就人才培养计划、专业学习、实习实训等具体问题，回答了同学们的提问。同学们畅所欲言，师生有问有答，会议开得非常成功。

同学们纷纷表示，通过今天的会议，对自己的专业有了进一步的认识，对未来的发展方向有了更明确的目标。
