# 全国独立学院第九次法学教育年会在我院成功召开

由全国独立学院法学教育协作机制和东莞理工学院城市学院主办的全国独立学院第九次法学教育年会，5月14日在我院成功召开。全国独立学院法学教育协作机制理事长刘杰、秘书长刘红，东莞市律师协会会长陈锡康，东莞理工学院政法学院院长强昌文，我院院长王卫平等领导，以及全国43所独立学院或民办高校70余位法学院系领导、专家、学者出席本次大会。

王卫平院长在致词中表示，由衷地欢迎和感谢各位代表朋友的到来，并简要介绍了我院的发展历程，以及在应用型人才培养模式方面上取得了一系列理论、方法和实际成果。

全国独立学院法学教育协作机制秘书长、武汉学院刘红副教授作协会2015年年度工作报告，回顾了去年协会的工作情况，并就应对新时期网络挑战，大胆提出“互联网+慕课”的教学方式，打造一个从传统封闭到开放灵活的O2O网络教育资源平台。

会上，东莞理工学院政法学院院长强昌文作了“法学教育的发展方向”主题报告；东莞市律师协会会长陈锡康结合当前广东省律师业实际情况，作了“法律服务业的新趋势与应用型法律职业人才能力模块”主题报告；浙江师范大学行知学院黄彤院长和我院政法系实践教学办公室主任王雄文分别作了主题演讲；国家移动互联网创新创业公共服务平台副主任张棣以“互联网+时代教育创新与联合”为主题，阐述了“互联网+战略和高校双创人才培养的密切关系”。

与会代表还围绕着“法律职业资格考试制度改革与应用型法律职业人才培养”主题，进行了讨论与交流。

最后，全国独立学院法学教育协作机制理事长、我院政法系主任刘杰教授作了年度总结。
