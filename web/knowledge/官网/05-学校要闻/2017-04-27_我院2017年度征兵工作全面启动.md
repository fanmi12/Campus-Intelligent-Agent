# 我院2017年度征兵工作全面启动

4月26日下午，我院在行政楼407会议室召开2017年度征兵工作动员会。院长书记王卫平、副院长周庆和相关部门负责人参加了会议。会议由后勤保卫处负责人袁秀美主持。

后勤保卫处副处长刘维仝通报了2016年度征兵工作的情况。去年，我院报名参军人数男生1876人，女生39人，入伍人数达到46人。年度征兵工作被广东省人民政府征兵办公室、东莞市人民政府征兵办公室评为征兵工作先进单位，在广东省本科院校排名第六。

今年，学院成立了以院长书记王卫平为组长、副院长周庆为副组长、各机关处（室）和各院（系）部分辅导员为成员的征兵工作领导小组，分工明确，统一部署，保障了征兵工作的有效开展。

3月份征兵工作站统一组织了全院学生兵役登记。我院学生积极响应国家号召，截止到4月25日，网上报名人数已有339人。

记者获悉，我院计划在5月下旬组织入伍宣传知识讲座，6月份开展以“参军报国尽义务，热血青春竞风流” 为主题的宣传周活动。
