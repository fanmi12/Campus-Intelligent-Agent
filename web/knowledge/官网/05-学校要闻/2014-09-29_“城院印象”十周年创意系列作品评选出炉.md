# “城院印象”十周年创意系列作品评选出炉

9月25日，我院在教学楼7B108举行了印象城院十周年创意系列大赛评比及颁奖仪式。

本次比赛共分LOGO、海报设计和微电影制作三个项目，评委们根据选手作品的主题、创意、风格、配色等方面进行比较打分，并在LOGO设计作品作品中，有的童趣可爱，有的寓意丰富，有的色彩线条匀称协调。微电影有2个作品入围，梁施艳同学的《选择》，用对比的手法展示了一个发生在城院的一个小故事，看后让人沉思。欧迪鹏同学的《印象城院》采用延迟拍摄的手法展示了城院的风景，其中有1万多张包括了建筑、人物方面的照片动态与静态结合，给人视觉上的震撼。

经过评委们的打分，叶振中同学获LOGO设计第一名，康乐伟同学获海报设计第一名，欧迪鹏的短片《印象城院》摘得微电影类桂冠。
