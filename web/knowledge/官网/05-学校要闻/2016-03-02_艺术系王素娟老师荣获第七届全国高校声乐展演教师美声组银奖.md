# 艺术系王素娟老师荣获第七届全国高校声乐展演教师美声组银奖

我院艺术系声乐教师王素娟在2016年1月22日结束的“神州唱响”第七届全国高校声乐展演中，获得教师美声组银奖。东莞阳光网、东莞日报以题目为“从声乐教师王素娟的进莞之路看东莞文化事业的进步之路”对其进行了专题报道。

据悉此次大赛此次比赛由中国音像与数字出版协会、中国音协高校音乐联盟、东莞市东城街道办事处主办，将高水平音乐展演引入东城，同时弥补了国内赛事较少面向综合性院校的不足，为全国各地的音乐学员进行交流碰撞提供一个平台，也旨在促进本土声乐人才的成长。比赛由来自全国高校的346名教师、学生组成庞大参赛团队，经过5天的激烈角逐，为观众奉献了一场高质量的声乐盛宴。
