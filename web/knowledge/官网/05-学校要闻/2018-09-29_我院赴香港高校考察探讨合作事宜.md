# 我院赴香港高校考察探讨合作事宜

9月27日至28日，副院长周庆率领由教务处、财务处、国际交流中心等单位

负责人组成的考察团，赴往香港高校进行考察交流，旨在进一步深化学院与香港高等院校的交流合作，推动我院师生赴港研修、学术交流及学历提升等项目的落地。

考察团访问了香港高等教育科技学院。在该院蔡宏院长、黄永根副院长、潘国良教授及陈舜宏博士的热情陪同下，参观了建筑科技与工程、食品与健康科学等专业实验室，就双方学生短期交流、本科“2+2”双学位共同培养、教师科研项目合作等进行了深入探讨，双方达成了合作意向。

在香港岭南大学，考察团受到社会科学学院魏向东院长和持续进修学院吴志荣院长的热情接待。双方就城院学子赴岭南大学深造硕士学位的合作模式进行了磋商。双方达成了合作意愿，希望尽快推动合作落地，为城院学子赴港深造开启便捷通道。

此次赴香港进行考察交流，是学院积极探索教学实践的创新尝试，有利于学院提升国际化办学水平。
