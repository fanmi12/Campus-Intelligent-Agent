# 期中教学检查专家组赴城环系调研检查

4月30日，院期中教学检查专家组开始检查城市与环境科学系的教学工作。

城环系副主任孙成访博士从教学工作指导思想、教学基本建设、教学管理、教学改革、教学效果和教学特色6个方面向专家组作了汇报。专家组对城环系上半年的教学工作表示满意，给予了充分的肯定。接着，专家组成员分组检查了该系的档案管理、教师课堂考勤、作业批改、教案书写等资料。

专家组组长、财经系主任高香林教授召开了城环系教师座谈会，听取教师对学科建设、实验室建设、年轻教师发展等方面的意见。专家组成员、管理系主任罗余才教授还听取了城环系学生代表关于教学、学习、生活的意见与建议。
