# 学院实践基地又添新军

5月30日，东莞理工学院城市学院党委书记朱志德、机电系主任黄健求、计算机系主任牛熠、招生与就业指导办主任陈建新以及30多名学生代表们来到塘厦镇广东易事特电源股份有限公司，与该公司董事长何思模共同举行了“东莞理工学院城市学院教学实践基地”挂牌仪式。

广东易事特电源股份有限公司组建于1989年，位于东莞市塘厦镇大坪工业区，占地面积两万多平方米，标准厂房建筑面积四万多平方米，注册资金7710万元，用户遍及东南亚、美洲、欧洲及非洲等60多个国家和地区，是中国酒泉卫星发射中心电源供应商，“神舟一号”至“神舟六号”载人航天飞船发射唯一指定电源供应商。

挂牌仪式后，我院师生参观了公司的研发中心和生产车间。
