# 成长诗记，诗化舞台

为展示浓郁的文学特色，欢迎和庆祝新生的到来，10月25日晚上7点30分，文学与传媒系在学术报告厅举行迎新诗歌朗诵会。出席晚会的嘉宾有院党委副书记朱冰，院宣传部部长何鹏举，学生处处长杜鹏举，团委书记罗文芳，文学与传媒系系主任邓星明教授，党总支书记孟颖，团委书记罗文芳，党总支副书记卢淑芳、副主任刘浔教授等出席了晚会并观看了文艺节目。

晚会的序幕在一段迎新视频中徐徐拉开，绚丽的灯光，华美的舞台，处处充满着青春、文艺的气息。晚会主题为“成长诗记”，巧妙地通过视频插播和诗歌表演相互穿插的方式讲述了一位毕业生回顾大学四年的点滴生活，并在大学四年中诗意般的成长，向我系新生们展示了大学生活的精彩与成长。整个晚会分为四个部分，分别是 迷雾、新阳、烈日、闪耀，刚好对应成长的四个阶段：迷茫、找到目标，为目标而奋斗和努力之后的收获与成长，充分地演绎了大学生成长中的跌宕起伏。诗歌表演中，既有充满离愁别绪的合唱《送别》，又有热情洋溢的朗诵《祖国啊，我要燃烧》；既有温婉婉转的独唱《在水一方》，又有激情澎湃的《以青春的名义宣誓》。一首首，一曲曲灵动的诗歌充满着青春浪漫的气息，展现着文学的魅力，把观众带到了一个美轮美奂的境界，观众席上不时响起热烈的掌声。
