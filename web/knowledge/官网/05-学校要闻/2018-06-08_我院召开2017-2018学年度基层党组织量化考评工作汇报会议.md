# 我院召开2017-2018学年度基层党组织量化考评工作汇报会议

6月8日下午，学院2017-2018学年度基层党组织量化考评工作汇报会议在行政楼112会议室召开。院党委委员王卫平、章德胜、高香林、黄兢、杜鹏举出席了会议。

来自学院11个院系党总支书记分别做了8分钟的工作汇报。大家围绕党总支组织建设，理论学习和宣传，学习型、服务型、创新型党组织创建等方面，分享了成功的经验与成果，介绍了各自工作的特色和亮点，也剖析存在的不足，汇报了下学年党建工作的安排计划。

章德胜副书记总结发言指出，本次会议既是各基层党总支量化考评工作汇报，也是党总支书记的述职汇报。大家的工作汇报充分展示了党总支在各院系中的战斗堡垒和政治核心作用，打造了一批富有特色和创新的品牌活动，可谓亮点纷呈，各具特色。他强调，此次工作汇报会议也是各基层党总支相互学习交流的平台，希望大家在取得好成绩的同时，及时总结经验，将党组织建设进一步提高和升华。

章德胜副书记还代表学院党委向各党总支及全体党员干部为学院党建工作兢兢业业作出了重要的贡献，表示衷心的感谢！

党务工作部副部长叶凯贞主持了会议。学院7个直属党支部将于6月11日另行量化考评工作汇报。
