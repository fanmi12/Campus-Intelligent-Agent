# 我院举办第十四届校园十大歌手大赛

5月20日晚，中国新歌声东莞理工学院城市学院第十四届校园十大歌手大赛决赛在学术报告厅举办。东莞知名音乐人，中国新歌声导师纪国维、学生处副处长罗文芳、艺术系党总支副书记张宏渝担任大赛评委嘉宾。

WONDER4乐队的开场表演“燃爆”全场后，十二组选手按顺序进行演唱。选手们不同的表演方式，迷人的声色，轮番为观众带来一场精彩的视听盛宴。

经过角逐，丁柔仰同学获得季军，李洋毅同学斩获亚军，陈依潮同学夺得本次大赛的桂冠，三位选手也获得了价值2980元的第五套同号珍藏纪念册一份。陈祖昊林晓君组合、林宏声、刘立松、谢婉莹、何颖岚、黄湘粤、袁浩峰分别获得第4-10名。金贸系获得本次大赛最佳组织奖，何颖岚获得最佳人气奖。

大赛期间，艺术团OLT街舞队、上一届十大歌手决赛冠军许敏还带来了精彩的表演。据悉，中国新歌声东莞校园赛将在我院举行。
