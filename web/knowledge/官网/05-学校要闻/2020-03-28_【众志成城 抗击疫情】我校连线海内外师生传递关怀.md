# 【众志成城 抗击疫情】我校连线海内外师生传递关怀

当前，全国疫情防控形势持续向好，基本得到控制。但境外新冠肺炎感染者数量却不断持续攀升，疫情形势严峻。我校在湖北、在境外地区的师生们现状如何，深深地牵动着全校师生的心。3月26日，我院校领导王卫平、章德胜、高香林、黄兢、周庆、刘玉侠和有关部门负责人，与身处湖北以及海外地区师生进行视频连线。通过线上面对面的方式，了解他们的生活、学习和工作现状，送去了学校的慰问和关怀。

“疫情发生以来，学校坚决贯彻落实党中央、国务院和各级政府的决策部署，及时启动应急预案，建立健全工作机制，落实落细防控措施，主动担当奉献社会，全面贡献战‘疫’的城院力量，防疫工作成效显著”。在线上，校领导们代表学校，向湖北及海外地区的师生送上了诚挚的问候，并通报了学校疫情防控工作情况，“新冠肺炎疫情发生以来，学校在抓好校内疫情防控工作的同时，一直密切关注每一位身在湖北及海外的城院师生。有什么困难，希望大家要及时向学校、向老师报告，学校会尽最大的努力帮助大家”。

视频连线中，身在境外的城院师生介绍了海外疫情的相关情况，以及他们在海外的生活情况。学校领导希望大家要时刻关注疫情发展变化，做好疫情防控工作，无论身在何处，你们始终都与母校心手相牵。希望海外师生对防疫高度重视，加强防护，确保个人健康。既要保持乐观心态，又要清醒认识新冠肺炎的高传染性，要减少外出、不聚会，不举办、不参加人员密集的活动。要养成良好的个人卫生习惯，保证规律的作息，适当的锻炼，不断增强自身免疫力。近期有回国计划的师生，要按照国内疫情防控工作要求，提前报备，对自己和他人的健康负责。希望海外师生心无旁骛，潜心学习工作，争取更大成绩。越是在困难时刻、特殊时期，越是要沉心静气、稳扎稳打，踏实治学、努力工作，把疫情的危机变成发展进步的契机，不断取得新的、更大的成绩。希望海外师生尊重差异，增进理解，传播中国声音。人类是一个命运共同体，新冠肺炎疫情防控，需要“全球一盘棋、各国共进退”。中国疫情防控形势积极向好的态势，再次有力证明了中国共产党的领导和中国特色社会主义制度的显著优势。希望大家在海外讲好中国故事，也要尊重所在国家的防控政策，增进交流理解。

“身虽远，心犹在。我们每天关注着国内的情况，心念学校。看到国内疫情好转的新闻，心里也踏实了不少。感谢学校领导及全体师生的牵挂，学校细致周到的关心关注让我们特别感动。”在海外地区的师生们纷纷表示，“应对新冠肺炎疫情，我们会做好个人防护，照顾好自己，保证完成学习、工作任务，请学校和老师们放心。我们坚信，一起守望相助，共待春暖花开，中国和世界一定能早日战胜疫情”。

师生们双向传递的关怀，既抚慰了海外师生的思乡情绪和对祖国、对学校的牵挂，也给予了国内师生莫大的鼓舞，拉近了学校身处各地师生的距离！
