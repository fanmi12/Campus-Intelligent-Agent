# 文学与艺术系表彰一批优秀学生

2月21日,文学与艺术系在五号阶梯课室召开2006—2007学年度学生评优评奖表彰大会。系党总支书记孟颖老师，辅导员陈煜丽、李海冬老师，各班班主任出席了表彰大会。

会上,孟颖老师总结了文学与艺术系去年的工作，对获奖的同学表示祝贺，希望他们再接再厉不断进步，同时,她号召全体同学要虚心学习先进,并牢记“你为生活懒惰几分，你的生活将苦涩几分；你为生活努力几分，你的生活将收获几分”的人生格言。

据悉,文学与艺术系2006—2007学年度共有227名同学获各类奖项。其中，1人荣获“校园十佳”称号，3人荣获“优秀大学生标兵”称号，103人荣获“优秀大学生”称号，54人荣获“优秀学生干部”称号。12人荣获一等奖学金，23人获二等奖学金，31人荣获三等奖学金，35名同学荣获单项奖学金。
