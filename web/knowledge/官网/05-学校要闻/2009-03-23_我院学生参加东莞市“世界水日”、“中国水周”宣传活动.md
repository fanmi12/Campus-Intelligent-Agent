# 我院学生参加东莞市“世界水日”、“中国水周”宣传活动

3月22日，我院城市与环境科学系30位学生应邀参加了在东莞市文化广场举行的第十七届“世界水日”与第二十二届“中国水周”大型宣传活动。

此次活动由东莞市城市管理局、城镇供水协会及莞城区公共事业服务中心举办，旨在向广大市民宣传“保障安全优质供水，促进经济社会双转型”。

我院学生配合东莞市城市管理局向来往市民派发了宣传单，开展问卷调查，利用自己的专业知识向市民们解答疑问。同学们的工作获得了东莞市城市管理局领导和广大市民的好评。大批市民被图文并茂的展板、传单、供水设施的展示吸引了前来参观，并纷纷在节约用水的条幅上签名题词。
