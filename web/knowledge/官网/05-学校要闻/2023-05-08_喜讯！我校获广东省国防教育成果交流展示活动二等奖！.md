# 喜讯！我校获广东省国防教育成果交流展示活动二等奖！

4月23日至24日，2022年广东省学校国防教育成果交流展示活动在江门五邑大学举办，我校国旗护卫队积极备赛，全力迎战，与来自全省的各大院校代表队同台竞技，斩获此次活动二等奖。此前，我校国旗护卫队在广东省学校国防教育成果交流展示活动中已连续荣获两次一等奖和一次二等奖。

据悉，本次活动由广东省教育厅、广东省国防动员办公室、广东省军区战备建设局、广东省军区动员局、共青团广东省委员会主办，五邑大学承办，广东省国防教育会执行。本次比赛共有200多所高校报名参加，各高校以学校为单位组织参加，每个学校限报1支队伍。

本次比赛采用抽签一轮制进行上场展示，我校国旗护卫队面对众多实力高强的对手时，从容出场，身姿挺拔，目光如炬，每一步都尽显自信威仪，以出色的动作升起了鲜艳的五星红旗，最终取得二等奖的佳绩。

在校党委和武装部的精心培养下，国旗护卫队接续传承，勇于开拓，在过去的两届广东省学校国旗护卫队展示交流活动中，我校国旗护卫队与来自全省的各大院校代表队同台竞技，都连续获得了“一等奖”好成绩，今年，在面对之前疫情导致多次延期、一等奖名额从往年的12支队伍缩减成6支队伍，并且赛前临时修改了部分动作要求等诸多困难，东莞城市学院国旗护卫队的队员们仍坚持不懈迎难而上，在公办高校全取一等奖的情况下，顶住压力顺利冲进民办高校排名前列！

学校党委非常关心与支持训练情况。备赛期间，校党委书记章德胜寄语国旗护卫队，希望全队上下刻苦训练，认真备赛。久久为功方可善作善成，荣誉的背后是无数的汗水和坚持，国旗护卫队必须以“咬住青山不放松”的定力树立远大追求，在活动中再创佳绩，一展城院风采。

全队上下以此为动力，紧盯任务，咬住目标，进行长期高强度的备赛集训。最终在此次比赛中取得了优异的成绩。

一日护卫国旗，终生无上荣光。一直以来，我校积极响应加强国防建设的号召，注重提高学生的国防意识和军事素养，引导队员在艰苦的训练和不懈的坚持中磨炼意识，砥砺品格，坚守忠诚信仰，献身护旗事业，在这大好青春中不断进取，绽放出自己最耀眼的青春光彩！

荣誉的背后是无数的汗水和坚持，是一代代国护人持之以恒努力的结果。我校国旗护卫队由指导老师刘维仝于2017年牵头组建，并且一路耕耘，夜以继日地指导训练，打造了一支纪律严明、训练有素、作风硬朗的优秀队伍，培养了一批批热爱祖国、忠于国旗的城院国护人。

身正率范，修己育人。国旗护卫队指导老师刘维仝曾在部队带兵服役将近17年，在他的带领下一大批优秀军人参加北京大阅兵，他并且参与全军条令条例修改工作，提出了得以实行的建设性方案，先后荣立三次三等功，全军优秀人才奖等荣誉。到城市学院工作以来，始终坚定信念，发扬军人优良作风，干一行爱一行专一行，继续投身国防教育事业，将国旗护卫队打造成爱国教育的平台、正能量传播的电台、实践养成的舞台。在他的培养和影响下，国旗护卫队累计已有9人光荣入伍，把满腔爱国信念撒向祖国山河大地。

东莞城市学院国旗护卫队从无到有，从小到大，圆满完成一个又一个的任务，取得一个又一个的荣誉，一路上一步一个脚印逐渐发展壮大，凝聚了一代又一代国护人的心血与汗水。自成立以来，国旗护卫队始终以护卫国旗为使命，以弘扬爱国主义精神为己任，以爱国、爱校、团结进取、积极向上的精神风貌为目标，展现当代大学生在校的一面校园文化旗帜，不断强化校内外青少年的爱国主义教育，用汗水与奉献书写对党和国家的忠诚。
