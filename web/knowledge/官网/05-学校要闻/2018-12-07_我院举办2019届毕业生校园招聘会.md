# 我院举办2019届毕业生校园招聘会

12月6日下午，我院2019届毕业生大型校园招聘会在田径场举行。根据我院学科专业的特色和毕业生的需求，通过精选出来的350家知名企业携带超过10000个专业对口岗位前来揽才，吸引了5000多名包括我院在内的东莞高校应届毕业生前来应聘。东莞市人才办主任吴德阳、东城区人力资源分局局长王毅、南城区人力资源分局就业办主任蔡月媚，兄弟院校就业部门负责人，我院院领导王卫平、章德胜、黄兢、周庆、林江龙等亲临现场指导工作。

招聘会现场，人头攒动，摩肩接踵。企业根据不同的行业分为9个区域，一顶顶蓝色帐篷贝联珠贯，蔚为大观。毕业生们身着正装，风华正茂，手捧精心制作的求职简历，仔细研究相关企业招聘要求，根据自身的需求寻找心仪的工作岗位。他们积极主动地向招聘企业咨询，了解用人单位的情况，满怀自信地去应聘自己心仪的企业。记者看到，许多热门企业摊位都被围得水泄不通。

据招生就业处负责人介绍，今年招聘会可谓亮点纷呈：一是增加名优企业比例，提升岗位质量。本届招聘会从1500家报名参展企业中精选出了350家参会，其中248家为国营单位、上市公司、行业500强、民营500强等名优企业。上市公司占17%，倍增企业占19%。二是就业岗位专业对口率高。所有参会企业涵盖了智能制造、机电、电子信息、互联网技术、会计财务金融、贸易服务、物流运输、房产建筑等行业，提供的岗位涵括了我院2019届33个本科专业。三是招聘企业地域相对集中。参会单位逾九成来自珠三角地区，与我院近三年就业的首选地域一致。

值得一提的是，今年我院招生就业处还加强了与智通人才网的合作。按照精准帮扶毕业生就业的思想，在招聘会召开之前，智通人才网便对我院4000多名毕业生的求职简历进行了诊断，并提供了量身定制的就业指导，使我院应届毕业生更加明确自身的就业方向，便以发挥自己的优势与特长。

另一个颇具用心与特色的是，今年所有招聘摊位进行了统一定制。在每个企业的摊位上方都清晰地表明了企业简介、招聘岗位详细信息、企业地址与电话，使毕业生更加容易判断与选择适合自己的岗位。在会场周围，招生就业处还制作了许多暖心的横幅标语，营造温馨而人性化的求职氛围。

东莞市立敏达电子科技有限公司负责人叶惠钟在接受记者采访时表示，虽是第一年来城院进行校园招聘，但城院学子对求职的热情与主动令他颇为惊喜。谈起来城院招聘人才的原因，叶惠钟不禁赞叹：“公司里面有员工就是来自城院的学生，他们都很优秀，工作中对自己的要求比较高，很有想法，所以今年特意来城院多招收一些人才。”他还建议：“对于应聘者来说，能力比专业对口更加重要。虽然有些企业对专业知识会有很高的要求，但更主要的还是希望学生主动学习，积累经验，提升自己的综合素质能力。”

来自商学院的毕业生赵芮仟告诉记者，今年到学校来招聘的企业都很出色，虽然自己已经收到了不少公司的录取邀请，但还是被招聘的企业吸引了过来。谈及如何选择企业时，赵芮仟表示：“会更偏重自己感兴趣的企业，能力比专业对口更加重要。”记者采访发现，今年相对于往年“专业对口”理念，招聘企业都更加注重综合能力，其次才是专业要求。
