# 我院举行2017年普通高校艺术类专业校考

3月25日，我院2017年普通高校艺术类专业校考在综合馆顺利进行。来自全省各地的330多名考生参加了本次艺考。

本次校考为表演专业及表演（影视方向）专业；考试科目有剧目表演、基本功展示 、即兴命题表演、才艺、形体展示、歌曲表演等。据了解，专业的录取将采取文化成绩上线后，按校考成绩择优录取！

黄兢副院长到艺考现场指导工作，并对考官、工作人员、志愿者的工作和考风考纪给予了充分肯定。
