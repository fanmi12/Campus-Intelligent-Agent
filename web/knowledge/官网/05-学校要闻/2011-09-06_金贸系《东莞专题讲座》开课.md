# 金贸系《东莞专题讲座》开课

经过金融与贸易系老师的精心准备，该系《东莞专题讲座》于9月2日下午正式开课，系主任米双红教授讲授第一课。

办学以来，我院把服务地方发展作为办学的重要目标之一，绝大多数学生来自东莞。东莞这座魅力之城，近30年的发展有哪些内在规律，这是学生应该了解的。为此，金贸系通过反复调研，决定在本系学生中开设《东莞专题讲座》。今年暑假期间，金贸系8位老师编写了《东莞专题讲座》讲义。该讲义共八章，涉及东莞历史、政治、经济、文化等多个方面。
