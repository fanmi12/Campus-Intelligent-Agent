# 文传系举行学风建设月系列活动

12月13日，文传系在7B208室举行了学风建设之学习榜样交流会。

文传系党总支副书记卢淑芬表示，举办这次交流会就是希望同学们能够虚心学习自己身边的好榜样。希望同学们借鉴他人优秀的学习方法，结合自己的实际情况，在学习上有更大的突破。

据悉，文传系在学风建设月中还举行了征文比赛，海报比赛，每个活动都得到同学们的积极参与。
