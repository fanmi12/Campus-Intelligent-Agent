# 政法系学生国家司法考试通过率再创新高

近日，备受社会瞩目的2012年国家司法考试成绩正式放榜，我院政法系2009级法学本科班12人顺利通过。本次司法考试，我院共有33名学生参加集中培训并报考，通过率为36.4%，参考人数及通过率均创历史新高。

今年是我院第四次组织学生参加国家司法考试。在学院领导的支持和关心下，政法系调整了法学专业人才培养方案和教学计划，完善了人才培养体系，使学生有足够的条件和时间准备司法考试，提高了司考通过率。另一方面，鼓励学生正确对待司法考试，将其作为法学本科学生必须参加的考试。法学专业学生学习氛围深厚，很多学生暑假期间在校积极准备，全力备考。本次优异成绩的取得，既是对我院学生能力的肯定，也是对我院狠抓教学质量的最好回报。

国家司法考试号称“天下第一考”，每年举行一次，是国家统一组织的从事特定法律职业的资格考试。初任法官、初任检察官和取得律师资格必须通过国家司法考试。通过国家司法考试的人员，由司法部统一颁发《法律职业资格证书》。
