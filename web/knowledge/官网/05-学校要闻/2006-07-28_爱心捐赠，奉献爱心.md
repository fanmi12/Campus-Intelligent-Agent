# 爱心捐赠，奉献爱心

28日上午10：05分，学院四号楼大厅救灾捐款点收到第一笔捐款，总数1670元。

由学院组织的这次捐款，旨在救助受第4号热带台风“碧利斯”及低压槽影响的粤北、粤东和珠三角部分地区的受灾群众。

根据省教育厅《关于开展教育系统救灾捐赠活动的紧急通知》（粤教发电[2006]14号）、东莞市委办《关于开展救灾捐赠活动的紧急通知》（东委办[2006]75号）的精神，学院于7月28日上午10：00——12：00，在院四号楼大厅、校教工宿舍分别设立两个捐款点，开展救灾捐赠活动。

活动得到了校领导和教职工的积极响应，纷纷慷慨解囊，捐献自己的一份爱心。截至中午12点，两处捐赠点共募集救灾款12342元。

赈灾捐赠活动仍在继续之中。
