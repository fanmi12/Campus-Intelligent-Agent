# 第十三届创新创业工商模拟市场今日开幕

11月5日下午，由学院团委、创新创业学院主办、商学院承办的第十三届创新创业工商模拟市场正式拉开帷幕。工模开幕式在秋枫广场前举行，学院董事长代表陈超群，副院长高香林、周庆、刘玉侠，院长助理林江龙和各单位负责人等出席了开幕式。

商学院院长罗卫国为开幕式致欢迎辞。他指出，工商模拟市场秉承打造品牌教学实践活动的宗旨，开展了多层次创业培训、创业实训和创业项目孵化实践，不仅承载着城院学子的创新创业梦想，也为社会输送许多优秀的创业型人才和职业经理人，形成了城市学院独特的创新创业实训文化。

在学院领导、嘉宾共同为城市学院第十三届创新创业工商模拟市场进行了剪彩后，副院长高香林宣布城市学院第十三届创新创业工商模拟市场正式开幕。

据介绍，本届工模以“智汇城院?创享未来”为主题，汇集了社会企业、校友、在校大学生共同参与，对校企资源进行了整合，以打造了多元化的创新创业实践教育模式。活动中，共设有校友创新?创业?创意区、综合区、品牌推广区和爱心志愿摊位等70余个摊位, 将有利于同学们从创业意识培养、与企业家经验交流、项目计划、实施和总结中，更深层地体验创业过程，并在工模中收获到更多的创业实践经验，全方面锻炼创业实践能力、组织协调能力、创新发展能力。高香林副院长在接受采访时表示：“与以往不同，今年工模融入了更加丰富的创新创业元素，着力培养同学们创新创业意识，提升创新创业实践能力，积累实战经验。”

开幕式上，风格舞队、YMCA模特、艺术团声乐队等送上了一场精彩纷呈的文艺演出，为工模助威造势。

本届工商模拟市场活动还得到华为（东莞）有限公司大力支持。
