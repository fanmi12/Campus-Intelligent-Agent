# 林伟伦老师参加第八届世界合唱比赛斩获银牌

7月16日，林伟伦老师与广州星海合唱团一行24人（参赛团员包括8男16女），远赴拉脱维亚首都里加参加第八届世界合唱比赛，获室内混声组冠军赛银牌。

据悉，本届世界合唱比赛共有来自世界五大洲480个优秀合唱团参加。本届比赛规模之大、水平之高都是历届之最。
