# 【“十八大”专题五】管理系党总支开展学习党的“十八大”系列活动

11月15日，管理系学习“十八大”精神动员大会在7C414召开。管理系系主任张佺举教授、党总支书记帅建华教授以及管理系全体教师、学生党员和入党积极分子参加了动员大会。

高香林副院长出席会议并对管理系的各项工作做了高度的评价,他希望管理系党员干部要把握十八大会议精神，扎扎实实地开展教育教学工作，抓亮点、创特色，取得更大成绩。

党总支书记帅建华教授做动员讲话，部署相关工作。他在讲话中要求，要把十八大精神落到实处，紧密结合当前的工作实际和工作重心，调动全体师生的积极性，开展应用型人才培养大讨论，创造性地开展教学评建工作，以此提高教育教学质量，开创管理系新局面。

据了解，管理系党总支为此成立了领导小组，同时还成立了专门的学习小组，成员包括全体教师党员、辅导员、学生党员。

管理系学习“十八大”的系列活动主要有：举办教师学习研讨会；举行专题报告会；以班为单位组织召开主题班会；开展学生座谈会和经验交流会；举办学习“十八大”知识竞赛；开展“宿舍安全文明建设周”活动；开展 “学风建设月”活动等。
