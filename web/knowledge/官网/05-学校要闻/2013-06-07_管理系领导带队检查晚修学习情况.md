# 管理系领导带队检查晚修学习情况

6月5日晚，管理系党总支书记帅建华教授和副书记吴春庚老师，带领辅导员与专职班主任深入教学楼检查2012级学生晚修学习情况。

在两个多小时的时间里，两位领导逐一走访查看了该系所有的教室，并向学生会干部作了深入了解。帅教授在察看时指出，大学生要学会学习，自觉地学习，坚持不懈地学习。要发扬“三人行，必有我师”的精神，向老师和同学们学习，在学习中发现自我，成就自我。希望同学们认真查找学风中存在的问题，为即将召开的管理系学风讲评会出主意提意见。

21时，系领导又来到学生宿舍检查宿舍卫生和学生在宿舍里学习的情况。
