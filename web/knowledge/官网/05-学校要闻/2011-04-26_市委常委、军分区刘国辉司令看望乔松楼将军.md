# 市委常委、军分区刘国辉司令看望乔松楼将军

刘国辉司令员（图左）与乔松楼将军（图右）座谈

乔松楼将军与刘国辉司令员、秦兴和将军（左二）、安少华院长合影留念4月20日，中共东莞市委常委、东莞军分区司令员刘国辉，海军某部将军秦兴和，东莞理工学院副校长、城市学院院长安少华专程看望了国防大学教授乔松楼将军。

刘司令欢迎乔将军再次来到东莞，安院长感谢乔将军再次做客城市学院大讲堂。

座谈中，乔将军回忆起当年在城市学院讲学的情景，赞叹东莞6年来的巨大变化和城市学院的快速发展。乔将军说，东莞被誉为“全国文明城市”、“十佳中国魅力城市”，真是个“外地人听了就想来，来了不想走，走了还想来”的好地方。乔将军还即兴赋诗一首，表达了他对城市学院的热爱之情：“这里有一片蓝天；这里有一方沃土；这里有诲人不倦的恩师；这里有学而不厌的高足；这里有艰苦创业的精神；这里有拼搏向上的抱负；这里有让人陶醉的环境；这里有令人羡慕的书屋。假如时光能够倒流，我真心诚意地渴望，在这里和大家一起重走一次人生的路。”
