# 我院召开机械专业建设座谈会

2月24日下午，我院在行政楼505会议室召开机械专业建设座谈会。会议邀请东莞理工学院协同创新办公室领导、机械工程学院有关领导和专家参加，我院机电系领导及机械专业骨干教师参加了座谈会。此次座谈会得到院领导、教务处领导的重视，有关领导出席了会议。

会议围绕我院已获批立项的广东省民办教育专项资金高等教育资助课题—机械设计制造及其自动化、省级实验教学示范中心—工程训练教学中心的建设方案和资金使用方案展开了充分讨论，取得了良好共识。

座谈会上，东莞理工学院机械工程学院主要领导介绍了“卓越工程师教育培养计划”试点专业的实施情况。

同时，建议我院机械专业在项目实施过程中，应注意学生基础能力的培养和师资建设，大力支持学生参加各类专业竞赛。理工学院有关专家简要介绍了组织学生参加全国机械创新作品竞赛的经验，有关领导专家还建议项目资金应结合专业建设和课程建设统筹考虑，资源共享，通力协作。

这次座谈会对我院机械专业建设、有关项目将来通过省教育厅验收评估具有很好的促进作用。
