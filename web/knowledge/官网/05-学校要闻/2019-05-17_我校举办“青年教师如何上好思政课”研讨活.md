# 我校举办“青年教师如何上好思政课”研讨活

5月17日上午，教师发展中心联合马克思主义学院开展“青年教师如何上好思政课”教学研讨活动。校党委书记章德胜、副校长刘玉侠、教务处副处长赖忠孝，马克思主义学院副院长石志民和石瑞丽、刘军老师担任点评专家。学校全体思政课教师、辅导员参加了活动。

研讨会上，八名青年教师进行了教学展示，展现了思政课教师队伍的精彩风貌。点评专家进行了精彩的点评和建议。宗卫菊老师作了教学示范。

章德胜书记表示，办好思政课的关键在教师，我校要打造一支政治立场坚定、素质优良、专兼结合的思政课教师队伍。作为思政课教师，必须要坚持基本的政治立场、守住底线，要严格落实课程大纲的各项教学要求，要勤学习，多花时间研究课程内容和课程创新，理直气壮地开好思政课。
