# 机电工程系系主任带队看望生产实习学生

9月3日机电工程系09级机械设计制造及其自动化专业1、2班全体学生开始了为期3周的专业实习任务。9月12日，系主任赵天婵教授、副书记谢明教授、机械教研室主任殷素峰老师及实验室主任张锦荣老师一行赴大同机械厂、东莞精锐电器五金有限公司探望生产实习学生，了解实习的具体情况。

期间，系领导向带队实习的老师及学生表示了慰问，询问学生实习的具体情况，并希望同学们能够借此机会来增长自己的实践知识，开拓视野，增加阅历，使自己各方面的能力得到切实锻炼。

最后，系领导与实习单位领导共同探讨了完善示范性实习基地的建设事宜，双方表示将进一步加强校企合作，为培养应用型人才共同努力。
