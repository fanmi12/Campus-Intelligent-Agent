# 省食品检测站：城院餐具消毒符合卫生标准

“城市学院餐具消毒是按照规定流程操作的，可放心使用。”省、市食品检测部门在我院检测餐具消毒工作时表示。日前，饮食服务中心主动邀请广东省质量监督食品检验站、东莞市食品药品监督管理局的专家来我院检查餐具消毒工作。

据悉，检测是按照GB 14934-1994《食（炊）具消毒卫生标准》执行的。我院餐具消毒坚持“一冲二洗三消毒”分池冲刷，消毒温度达到100度。
