# 学院召开考研学生座谈会

2月28日，学院在405会议室召开2008年考研学生座谈会。副院长程发良教授、院督学林世俊教授、教务处处长邓成良教授、计算机与信息科学系黄乾辉副教授到会听取了今年参加研究生入学考试同学的意见。

座谈中，同学们对复习备考、志愿填报、考场感受等方面发表了自己的看法。报考西南财经大学的何晓伟同学介绍经验时说：“我觉得英语和数学主要考基础，政治主要靠考前冲刺，专业课考试内容没有很大的变化，关键是要注意收集往年的试题做好备考工作，平时千万不可放松对基础课的学习。”报考华南师范大学的陆正群同学从入学时就坚定了考研的志向，他说：“‘考研还是找工作’往往是同学们的困惑，我建议师弟师妹们应该根据各自的具体情况尽早定下目标，如果决定考研就从大一、大二着手准备，明确了方向就要加倍的努力。”报考暨南大学的林同良同学在谈到他的复习过程时说：“考研很艰苦，所以一定要坚定信念，只有这样，才不会有畏难情绪。学院给了我们很好的学习环境，老师们也关心我们的进步，无论结果如何，我们都感激母校给予我为梦想奋斗的机会。”

督学林世俊

教授以苏联数学家斯米尔诺夫的学习经历激励同学们：“城市学院为每一个有志向的同学提供平台，你们的努力不仅能为自己赢得美好的未来，也能为学院树立良好的学风做出了贡献。”副院长

程发良教授赞扬同学们说：“你们考研的过程，不仅是对知识的总结，更是对人生的一次挑战，无论结果如何，都可以无怨无悔地说一句‘我努力过’。”

据悉，今年我院共有9名学生参加了研究生入学考试。明年我院将有1000多名本科生毕业，预计考研人数将会大幅度增加。新一轮的考研培训将于近日开始，首讲由黄乾辉副教授讲授《考研数学》。
