# 市城建局丁海潮局长来我院调研建筑工程

施工方和我院有关职能部门负责人向丁局长（右二）汇报图书科技信息大楼工程的建设情况。

6月22日，市城建局局长丁海潮再次来我院对图书科技信息大楼建设工程进行调研，受到院长安少华、党委副书记朱冰、院基建办主任叶树标及施工方负责人的热情接待。

施工方和我院有关职能部门负责人向丁局长汇报了工程建设进度、室内外装修用料、消防、水电供给系统的配置、周边环境美化、整体工程的验收等方面的情况。丁局长对工程的后期工作提出了明确要求：8月25日前，完成工程排障拆卸，整治好周边环境；9月20日前，工程完工并移交学院；装修材料不必追求名牌，要遵循实在、实用、优质的原则；工程各方要明确职能，尽职尽责，通力合作；做好工程预算。

据悉，图书科技信息大楼工程已建至第12层，将于7月初封顶， 9月20日工程竣工。
