# 我校揽获2019年度省高校学生心理健康教育 系列活动评比七项大奖

日前，广东省教育厅公布了2019年度高校学生心理健康教育系列活动结果。我校七项心理作品获奖，其中一等奖3项、二等奖2项、三等奖2项。

据悉，为加强高校心理健康教育工作，广东省教育厅于今年5月至9月在全省高校组织开展了“放飞青春梦想”心理漫画征集活动、“激扬青春活力”心理剧征集活动、“追逐青春理想”心理健康主题演讲征集活动等5个心理健康教育活动。

我校精心组织师生积极参与申报，最终送选的作品在5个心理健康教育活动评选中均获佳绩。

心理漫画一等奖《夺命手机》 作者：陈建业

心理漫画三等奖《你还有我们》 作者：吴颖琛

心理公益广告一等奖《关爱抑郁症患者01》 作者：朴福美

心理公益广告一等奖《关爱抑郁症患者02》

作者：朴福美
