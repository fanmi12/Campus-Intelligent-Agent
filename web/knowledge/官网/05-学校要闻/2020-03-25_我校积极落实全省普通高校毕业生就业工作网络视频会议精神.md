# 我校积极落实全省普通高校毕业生就业工作网络视频会议精神

3月25日，省教育厅召开2020届全省普通高校毕业生就业工作网络视频会议。校长王卫平、党委书记章德胜和相关部门负责人在我校分会场参加了会议。

省教育厅副巡视员邱克楠针对目前高校毕业生就业形势进行了剖析。一是充分认识就业形势十分严峻，毕业生数量再创新高，岗位刚性需求大，岗位因疫情萎缩明显；二是全球性疫情爆发导致外贸行业风险加剧；三是招聘形式过于单一，线下招聘活动全面暂停，单独依靠线上招聘形式；四是部分企业降薪、裁员而导致离职人员再就业的情况增多，社会人员再次流向社会，加大了就业竞争。

邱克楠副巡视员指出，要深入贯彻学习习近平总书记精神，千方百计做好毕业生就业服务工作。一是做好重点群体就业工作；二是多措并举，增加就业机会；三是进一步提高毕业生参军入伍比例；四是开展好三支一扶西部计划、特岗计划等基层就业项目。五是创新形式，大力推行线上招聘，引导毕业生积极参加我省18场线上专题系列供需活动，组织好毕业生参加3-6月期间举办的“木棉花暖”高校毕业生大型公益网络招聘活动。积极推动全体学生利用好高校毕业生就业创业智慧服务平台，并将平台推送至全体学生。同时要引导组织毕业生参加教育部的24365校园招聘服务活动，关注省高校毕业生就业创业智慧服务平台战役专区。同时要精准加强毕业生就业指导服务。各高校要依托平台，充分发挥线上招聘、线上签约、线上办理就业手续的一站式服务作用，积极使用视频宣讲、视频面试等网络视频人才对接新形式。六是要做好就业质量跟踪调查。七是要加快推进毕业生签约，今年我省首次全面推行毕业生在线的就业签约，并定期公布就业率。八是千方百计促进“顶岗”，并有机结合“顶岗”和“落实岗位”，引导毕业生先就业再择业。九是落实就业政策，帮助毕业生疏导好焦虑情绪和减轻求职的心理压力，推出线上咨询指导课，加强对毕业生的关怀和求职的心理疏导。

邱克楠副巡视员还强调了中国国际“互联网+”大学生创新创业大赛的工作，要求高校做到备赛“三不误”，学校领导层面要高度重视，积极动员，明确工作任务和目标责任，确保参赛落到实处，取得实效。要采用线上线下相结合的方式，分赛道、分层次，分阶段，对项目开展针对性、精细化、进阶式的指导和培育。当前重点是要推动参赛项目做好项目计划书的撰写和完善的工作。同时，要充分做好参赛的保障工作及激励措施。

视频会结束后，我校就高校毕业生就业工作进行了进一步部署，要求切实提高政治站位，积极落实本次视频会议精神，借助线上的新形式，研究制定具体工作措施，切实把毕业生就业工作抓紧、抓实、抓好。
