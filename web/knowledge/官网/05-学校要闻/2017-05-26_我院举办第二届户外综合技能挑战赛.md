# 我院举办第二届户外综合技能挑战赛

5月25日下午，我院举办第二届户外综合技能挑战赛。这次活动由体育教学部主办，户外教育研究中心承办，城院登协、山脊户外俱乐部协办的，吸引45支参赛队伍、450名户外爱好学子同台竞技。章德胜副书记、高香林副院长亲临开幕仪式，为选手呐喊助威。

学院炫舞团用青春性感的舞蹈拉开序幕后，运动员代表翁怡、裁判员代表纪浩瀚代表全体运动员、裁判员庄严宣誓。在黄嘉豪、蔡仲斌老师献上“难度攀爬”与“速度攀爬”表演的同时，“毅行百里磨坚锋 共创佳绩越龙门”，“为他人着想 坚持不懈 有担当”，“安全户外 乐享自然 激情户外 挑战自我”、“安全 科学 环保 自主 团队”的横幅从天而降。

章德胜副书记随即宣布城院第二届户外综合技能挑战赛正式开幕。

本届开幕式主题为“激情户外 挑战自我”，共有45支参赛队伍、450人参赛。150名工作人员兢兢业业奉献在岗位上，确保活动顺利进行。大赛设置了“车轮滚滚、越野跑、绳结操作、绳降、营地生活、旗语、烟波钓徒、急救包扎、迷宫定向、骑跑交替、坐地起身”等景点项目，不仅磨炼了选手的意志，也增添了比赛的乐趣。

经过两个多小时的激烈比拼后，“搞搞震队”获得了本届户外挑战赛第一名，“老虎队”获得第二名，“野鸡队、特工游击队、山鹰野鸡队”分别获得第三、四、五名。“密浪都队、叉烧双拼队、五月嗨翻天队”分别获得了人气奖一、二、三名。

大赛还受到了东莞日报、羊城晚报、新浪网、腾讯网、网易网、搜狐网等媒体的全方位报道。青柠檬工作室还出动无人机对赛事实况进行记录，并在斗鱼直播平台对赛事进行网络直播。

学院各部门负责人，各院（系）主任、书记参加了开幕仪式。
