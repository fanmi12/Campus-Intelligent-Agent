# 首届教职工混合排球赛拉开战帷

6月18日，城市学院首届教职工混合排球赛在学院田径场火热开赛。

本次排球赛共有10个代表队、120名教职工参赛。比赛采取小组单循环赛制，每局每队至少有一名女队员上场。预赛实行3局2胜制，决赛采取5局3胜制，赛程预计为14天，将于6月26日决出冠亚军。

据悉，排球赛由学院工会组织，体育教学部工会小组承办，是继去年教职工篮球赛之后又一全院性的大型的比赛活动。
