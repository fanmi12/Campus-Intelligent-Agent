# 我院“服务东莞”获得普遍认同

7月12日至23日，广东省高校哲学社会科学教学科研骨干研修班在广东省委党校举行，研修班工作简报全文登录了我院谭汪洋副教授题为《服务社会、实现共赢》的发言稿。谭汪洋老师也被评为优秀学员。

本次骨干研修班有近200名来自省内各高校的老师参加，绝大多数参加培训的老师具有副教授以上的职称。来自省委宣传部、省教育厅、省政府办公厅、省委外宣办、环保局、保密局的领导及几大高校的专家学者作了14场报告，这些领导、专家从不同的领域、不同的角度介绍了广东在经济、政治、文化、教育、环保、信息安全等各方面的情况，阐述了一系列哲学社会科学原理，并就解决当前我国社会所存在的突出问题提出了新观点、新见解和新思路。

研修班还安排学员对一些热点问题展开了研讨。在“如何推动教学科研成果转化，促进广东经济发展方式转变”的研讨会上，我院谭汪洋老师作为小组代表做了题为《精心打造“服务东莞”名片，实现校地共赢》的主题发言，从“根据市场需要设置专业、为企业升级转型出谋划策、与社区携手和谐共建、创新社会服务方式”四个方面介绍了我院“服务东莞”的做法，引起了与会老师的共鸣，认为东莞理工学院城市学院“服务东莞”的做法具有启示意义，值得其他高校借鉴。一些老师会后还向谭汪洋老师咨询我院服务地方的具体操作方法。
