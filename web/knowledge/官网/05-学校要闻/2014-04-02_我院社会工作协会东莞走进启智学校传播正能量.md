# 我院社会工作协会东莞走进启智学校传播正能量

3月27日，我院社会工作协会手语队前往东莞东城南路的启智学校，与该校启聪部师生开展一场以“没有什么不同”为主题的交流活动。

手语队42名队员参加了本次活动，活动主要内容包括手语表演、游戏互动、赠送礼物、交流对话和合照留念等。活动以手语队全体成员的手语介绍拉开帷幕，主持人全程用手语主持。开场歌舞《没有什么不同》的手语展示拉近了在场学生与队员们的距离。表演结束后主持人还邀请在场的所有学生和他们一起做手语歌词“虽然没有天生一样的，但在地球上我们是一样的。因为我们没有什么不同，天黑时我们仰望同一片星空”。在手语诗歌《我看见你》作为赠言后，队员们把亲手做的手工纸花和书签寄语送给在场每一位师生，并与他们互相拥抱。

活动中队员与师生们一同感受了欢乐与感动。游戏中夸张的动作、欢乐的气氛使现场的笑声不断。在以拥抱交换礼物和相互交流的环节中，手语队队员的耐心关怀给孩子们带来了力量，他们在便签上纷纷写下“开心”、“希望哥哥姐姐们再来”的心声。这次活动中，社工协会的同学们利用所学知识，给他人带来欢乐之余，也为启智学校的孩子们带去了“城院正能量”，在生命面前，我们“没有什么不同”。
