# 新学期开学各项工作准备就绪

经过周密部署、全院总动员，我院办学主体搬迁工作正紧张有序顺利地进行。8月31日至9月1日，学院行政机关已全面入驻新校区行政大楼，各系部也全部迁入所在的系部大楼进行办公。随着办学主体搬迁工作的顺利进行，标志着城市学院开始了又一个全新的时代。

根据学院的部署与安排，8月31日是全院行政人员及教辅人员在新校区的新办公场所上班的第一天。全体有关人员以饱满的精神、高昂的士气投入到新工作的环境中，迎接新的起点，开拓新的局面。

同时，按照学院的工作安排，9月1日我院全体任课老师也按时在新校区到岗，提前开始新学期教学的准备工作。

城市学院董事黎建烨，院领导杨敏林、朱志德、朱冰、张林、章德胜、高香林等亲临新行政大楼到各科室、各系部办公室看望慰问广大教职工，询问大家对新工作环境的感受，鼓励大家在新的环境、新的起点做出新的成绩。

据了解，9月2日是我院大二至大四学生开学报到的日子，9月3日将正式开学上课。当前，学院包括教学、后勤、生活等各项保障工作已全部准备就绪，所需教材已全部采购到位，将在开学上课前全部发放到学生手中。目前，学生已陆续分赴两个校区迎接新学年。
