# 我校今起开出在线教学课程505门

同心协力，共克时艰。3月2日我校2019-2020学年第二学期正式“在线开学”。

开课首日，按照“停课不停教、停课不停学、学习不延期”的要求，全校教师以连线代替见面，用屏幕替代黑板，通过在线教学方式，开讲新学期第一课。全体任课教师均尽最大努力在这全国上下决胜抗击疫情战役的关键时期，以自己的实际行动守护教学阵地，使同学们能够居家安心学习、学有所获。

在本周内，全校将陆续开出在线教学课程394门，1077门次，学生线上学习人次将达102106人次。第二周，学校还将通过企业微信远程教育平台开出111门、226门次线上课程，学生线上学习将再增加28190人次。

随着在线教学工作的全面开展，学校教学检查和监督工作也制定了有针对性的方案，将全力做好课程跟踪和教学质量监控工作。疫情挡不住学习的热情，挡不住知识的传授。
