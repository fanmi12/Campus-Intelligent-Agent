# 近600名师生再次走进东莞32个镇区检查环境卫生

6月19日，我院近600名师生参加了为期一天的东莞环境卫生检查。

据悉，从2008年开始，城市学院的师生们便承担东莞市32个镇区、591个社区环境卫生大检查的任务，共计约5000人次，至今已是第11次。参加本次活动的同学都是党员、预备党员或入党积极分子。近三年来，他们秉着公平公正的原则和负责任的工作态度认真评分，受到东莞市各环境卫生部门的一致好评。

院党委组织科科长黄阳辉老师表示，这是培育锻炼学生党员的极好机会，不仅使他们更广泛地接触社会和居民群众，丰富社会知识。让同学们对党的思想有更深一步的认识，提高他们的社会阅历。
