# 商洛学院党委副书记、校长权雅宁一行到我校考察交流

11月20日，商洛学院党委副书记、校长权雅宁一行6人到我校考察交流。校党委书记章德胜、执行校长方伟华、副校长李振华及学校办公室、科研部、品牌与招生部等部门负责人出席接待，并召开座谈会。

会上，章德胜书记对权雅宁校长一行表示热烈欢迎。他简要介绍了我校的发展历程、办学特色及取得的成绩，希望两校加强交流合作，共同探讨应用型高校办学发展经验。章德胜强调，通过互惠共建、互通有无，可以加强两校之间的交流与合作，为双方提供更多的发展机遇。

执行校长方伟华详细介绍了我校在师资队伍建设、产教融合校企合作以及学生就业指导等方面的成功经验和具体措施。他重点推介了我校数字媒体、国际学院的121中美合作项目，介绍了网络电视台等建设情况。近年来，我校通过专业建设、赛教融合，在特色打造，品牌铸造上已取得了一定的成效。

李振华副校长从教学科研的角度出发，分享了我校近年来在学科建设、科技成果转化等方面的进展。他表示，希望通过此次交流，双方能在教学方法、科研课题等方面找到更多合作点，共同推动高等教育事业的发展。

权雅宁校长对我校的热情接待表示衷心感谢，介绍了商洛学院的基本情况。她指出此次到粤港澳大湾区考察学习，主要是访企拓岗，学习兄弟院校的先进管理经验，看望在粤实习实训学生，探访创业就业校友。她希望通过此次访问，能够加深两校交流，在人才培养、专业建设、学科建设方面互相交流学习，为进一步校校合作打下良好基础。

座谈会后，执行校长方伟华陪同权雅宁校长一行参观了国际学院。双方详细了解了国际学院的办学理念、办学环境、课程教学模式等情况，并就一些具体问题进行了深入交流。

商洛学院党委委员、党办主任刘勇，发展规划处、学科办公室主任崔孝炜，生物医药与食品工程学院院长赵永平，国内合作与校友工作处副处长任桂婷，直播产业学院院长房琳等也积极参与了此次考察交流活动。

此次访问不仅增进了两校之间的友谊，也为未来开展多层次、多领域的合作奠定了坚实基础。双方均表示，将继续保持密切联系，共同探索更多合作机会，携手共创美好未来。
