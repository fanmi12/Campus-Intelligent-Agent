# 我院招生就业处微信公众号进入全国高校前十

9月5日，《南方周末》数据实验室公布了最新一期（8月20日-8月26日、8月27日-9月2日）《中国高校微信排行榜》校务机构排名。我院招生就业处微信公众号在全国3000多个高校公众号中脱颖而出，连续在两期榜单中跻身全国高校15强，其中WCI指数（权威地反映微信公众号的整体传播力和影响力）位列全国第七，是入选全国榜单TOP10的两所广东高校之一。

据悉，《中国高校微信排行榜》是《南方周末》推出的新媒体项目，该榜单对全国各大高校官方微信运营数据进行统计分析，为读者提供有价值的数据参考。《南方周末》每周通过收集全国各大高校微信推送后台反馈的真实数据，来反映推送文章的质量和受欢迎程度，以及广大粉丝对各高校文化魅力的认可程度。

2016年9月27日，我院城市学院招生就业处微信公众平台正式认证开通。近一年来，招生就业处微信公众平台以文字和图片等形式向广大师生、校友和社会人士发布最新招生政策动态、就业创业信息、以及最具价值的时事要闻、网络热点，累计推送了578条校园资讯，绝大多数均为原创，其中《教师风采、榜样励人》、《名师说创业》等栏目都备受广大师生的喜爱和支持。招生就业处微信公众平台为学院师生及时沟通架起了桥梁，对树立学院良好形象、塑造美誉度和知名度起到了助推作用。

经过近一年的运营，招生就业处微信公众平台功能日渐完善，涵盖了招生录取查询、就业服务、创业服务、考生问答等功能。它与学院招生就业处官方网站一起构成为我院招生就业宣传平台。
