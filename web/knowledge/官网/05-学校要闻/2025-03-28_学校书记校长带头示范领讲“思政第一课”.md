# 学校书记校长带头示范领讲“思政第一课”

学校党委深入贯彻落实习近平总书记对学校思政课建设的重要指示精神，将“思政第一课”作为落实立德树人根本任务的关键抓手，守正创新推动思政课建设内涵式发展。学校党委书记、校长“双上讲台”，带头示范上好“思政第一课”，各二级学院党政领导纷纷走上讲台，将思想政治教育深度嵌入专业教育全链条，有效推进了思想政治教育从思政课堂向专业课堂的自然拓展。

从青年奋斗历程探寻使命担当与精神图谱章德胜书记讲授“思政第一课”。

3月27日下午，学校党委书记章德胜以“从青年奋斗历程探寻使命担当与精神图谱”为题，面向2024级各专业学生代表讲授新学期“思政第一课”。章德胜书记结合青年奋斗精神，分享了宇树科技王兴兴、深度求索梁文锋等新时代科创青年的故事，激励同学们以这些青年为榜样，将个人理想融入国家发展，在时代坐标中找准人生定位。从“相信”理想信念，到以“信仰”指引行动，既要在学习中积累知识，更要在实践中锤炼精神韧性。勉励同学们要正确认识国家和民族赋予的历史使命和时代责任，坚定信心，锐意进取，奋进新征程、建功新时代。

课后，马纯英同学表示要赓续红色血脉，以革命先辈为精神坐标，将个人理想融入国家发展大局，以实际行动践行青年使命。陈嘉诚同学明确表态要立足新时代要求，着力锤炼有理想、敢担当、能吃苦、肯奋斗的综合素质，努力成长为堪当民族复兴重任的时代新人。

在文化强国建设中书写青春答卷陈明校长讲授“思政第一课”。

3月26日下午，学校校长陈明以“守正创新担使命 以文化人向未来——在文化强国建设中书写青春答卷”为主题，为2024级汉语言文学专业学生讲授新学期“思政第一课”。陈明校长从“文化”概念溯源展开，系统阐释中国特色社会主义文化的科学内涵，回顾中国共产党文化政策百年演进。寄语青年学子在乡村振兴的火热实践中贡献青春力量，以创新之笔书写非遗华章，以文化为纽带，以创新为动力，赋能乡土中国，守护文化根脉，以“强国有我”的使命感投身文化传承。

听完陈明校长的思政课，同学们深受鼓舞，纷纷表示要以青春实践投身文化强国建设。其中，钟春媚同学认为，要树立文化自信，自觉传承发扬中华优秀传统文化，让中华文明的薪火代代相传，为民族的伟大复兴贡献出青春力量。曾倩茹同学表示，要自觉传承弘扬中华优秀传统文化，在实践中不断增强文化自信。

据了解，学校自2024年起创新建立集体备课机制，通过理论阐释、案例剖析与教学研讨相结合的方式，全面提升思政课程育人实效。

2025年3月13日，学校举办2025年春季学期“思政第一课”集体备课会。学校党委书记章德胜、校长陈明及各二级学院院长、书记，马克思主义学院教师代表出席活动，会议聚焦新时代思政课建设核心任务，邀请马克思主义学院李立菊教授、刘学勤老师进行了课程专题教学示范，围绕教学重点与学情特点展开深度交流，为春季学期领导干部上好“思政第一课”扎下坚实基础。
