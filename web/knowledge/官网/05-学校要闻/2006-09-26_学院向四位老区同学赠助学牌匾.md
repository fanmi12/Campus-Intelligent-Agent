# 学院向四位老区同学赠助学牌匾

9月24日，学院在迎新文艺晚会上隆重举行助学赠牌仪式，为四位来自革命老区——四川省通江县的同学颁发免收学费、住宿费的纪念牌。中国科协中南集团董事长、城市学院顾问杨元惺先生为他们授牌。

四川省通江县是原红四方面军总部所在地，也是我国较为贫困的地区。为落实中央统战部和革命老区扶贫基金会关于对革命老区扶贫的指示精神，今年5月，院长安少华教授带队到该地区进行教育扶贫考察。本学期我院在该县共招收了4名大学生，他们分别是文学与艺术系的蒋敏、何美莹、杨静和计算机与信息科学系的魏民。学院决定，对他们在大学4年期间的学费、住宿费予以免收，每人共计约6万元。
