# 我院第四届心理情景剧大赛圆满落幕

由院团委主办、以“关爱心灵，绽放青春”为主题的第四届心理情景剧大赛决赛，于5月24日下午在新校区学术报告厅举行。

决赛首先通过大屏幕回放了预赛的精彩花絮。在经过预赛的激烈竞争和专业选拔，《梦想》、《梦想与坚强》、《拐杖》、《遇》、《We Are Here》、《不再沉默》六个剧目脱颖而出，在决赛中向冠军发起角逐。

艺术系音乐表演班带来的《拐杖》，取材于现实中“子欲养而亲不待”的故事，深情的演绎、动情的眼泪，诠释了父爱的深沉，感动了在场的观众。由财经系带来的《梦想》，真实地再现了大学生在追逐梦想的途中，遇到的现实冲击与坎坷，但他们以青春的姿态，放声高歌，驱散阴霾，赢得观众的掌声与共鸣。相遇是这个世界难得的美丽，但《遇》则讲述了但两个曾经是校园传奇的他们，在落魄后的相遇却只能选择向对方撒谎的无奈，诉说曾经的梦想，打动了观众的心灵……

穿插在比赛中，“一反常态”的观众互动环节也将现场的气氛推向高潮。

经过一番精彩的演绎与角逐，最后，《遇》凭借从容的台风、专业的演出，以91 .8分的好成绩夺得本次大赛的桂冠。《拐杖》获得二等奖，《梦想》获得三等奖，《We Are Here》、《不再沉默》、《梦想与坚强》均获优秀奖。
