# 胡钦华处长入选市首批百名优秀中青年领导干部培养计划

4月18日，东莞市百名优秀中青年领导干部培养计划（一期）开班动员会在市委党校举行。首批学员在市委党校预训后，将派往新加坡和国内先进城市进行为期5个月的学习培训和挂职锻炼。我院组织人事处处长胡钦华副教授荣幸成为首批学员。

东莞市委常委、组织部部长甄瑞潮出席了动员会并讲话。他指出，实施“百名优秀中青年领导干部培养计划”，是市委为适应新形势、新任务的要求，为东莞科学发展、转型发展提供可持续人才支撑而采取的一项战略举措，目的在于造就一批具有坚定的理想信念、坚实的理论修养、宽广的世界眼光、全面的战略思维、科学的决策能力的复合型党政领导干部人才。

据了解，“百名优秀中青年领导干部培养计划”自2013年起实施，每年选派20名，连续5年共选派100名中青年领导干部进行培养锻炼。
