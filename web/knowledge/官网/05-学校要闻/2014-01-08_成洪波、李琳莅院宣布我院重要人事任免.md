# 成洪波、李琳莅院宣布我院重要人事任免

◆ 杨敏林任东莞理工学院副校长、城市学院院长

◆ 王卫平同志任城市学院党委书记1月7日，我院在行政楼112会议室召开中层干部（扩大）会议，通报省委任命决定，宣布城市学院党委书记、副书记的任免决定。

东莞理工学院党委书记成洪波，校党委副书记、校长李琳，校党委委员、组织部部长李培经，城市学院董事黎建烨等领导在主席台就座。

院长杨敏林主持会议。

校长李琳通报了省委任命杨敏林同志为东莞理工学院副校长的决定。

李琳同时还宣布了东莞理工学院党委决定：杨敏林同志继续兼任城市学院院长；王卫平同志任城市学院党委书记、章德胜同志续任城市学院党委副书记；朱志德、朱冰二位同志不再担任领导职务。

成洪波书记、李琳校长在会上发表了讲话。他们指出，这次院党委班子领导成员的变动，是正常的人事调整，是东莞理工学院党委对“两校三区”工作通盘考虑而做出的决定；书记校长双双出席今天的会议，充分说明东莞理工学院党委十分看重城市学院这块阵地，也显示出城市学院在党委工作中的份量与位置；王卫平同志政治性强，为人正派，是东莞市引进的第一位博士，从教30年，曾在多个部门担任主要领导职务，有较丰富的基层工作、管理工作经验；朱志德、朱冰二位同志为城市学院的创办、壮大、发展作出了较大的贡献，因年龄原因，他们要卸任领导职务；希望城市学院在座的各位特别是教授和中层干部要凝心聚力、真诚团结，支持新同志的工作，发挥好体制机制的优势，为学院的创新发展，为教职工谋求更大的红利而共同努力。

成洪波书记对我院领导班子提出了三点要求：一是要加强理论学习。要认真学习习近平总书记十八大以来的一系列讲话精神，按照东莞理工学院党委第二次党代会提出的总目标、总要求，一项一项地抓落实，办好城市学院的事情，继续保持良好的发展势头。二是要坚持改革创新。改革创新是十八大的主旋律，同时也为高校提供了发展机遇与空间。我们要“先行先试，快人一步”，真作为，大作为，抢占广东的“高教”高地，办出高水平的现代大学，为培养全面发展的学生、促使学生尽快成长成才做好服务工作。三是要加强班子建设和队伍建设。教职工对学院党政班子、对管理团队有较高的期望，城市学院党政领导班子成员和各级管理干部要加强作风建设和廉政建设，正人先正己，提高工作能力和工作水平。

新任党委书记王卫平以“ 感谢、尽力、期待”三句话六个字简述了自己的就职感言。他表示，感谢校党委和同志们的信任，将尽职尽责努力做好工作。不辜负大家的厚爱，也期待全院教职工多支持多包容，共同做好各方面的工作，把学院做大作强。

老书记朱志德同志在发言时深情的表示，坚决拥护校党委的任免决定；感谢东莞理工学院几任领导和城市学院教职工的信任与支持，给了自己施展才华与能力的舞台；今后将继续关注、关心城市学院的发展。
