# 我校学子斩获广东省第六届“魅力讲师”大赛一等奖

11月21日下午，由广东省教育厅主办的第六届大学生预防艾滋病同伴教育“魅力讲师”大赛决赛在广东外语艺术职业学院举行，我校2018级金融学1班黄泽灏同学荣获“魅力讲师”赛一等奖，学生处詹海都、许奕玲荣获优秀指导老师。

据悉，此次比赛共吸引了全省高校252名大学生参与，分初赛、复赛培训、复赛和决赛4个环节，竞争十分激烈。黄泽灏同学荣获的一等奖是我校在此类大赛首个一等奖，我校也连续多届获评优秀组织奖。

我校新苗社会服务中心自成立以来，一直致力于青春健康教育及预防艾滋病工作，形成了一套成熟的同伴讲师培训成长体系，新苗社会服务中心开展的活动在全省乃至全国都颇具知名度。此次大赛获得多个奖项也是对我校青春教育及防艾宣传教育工作的肯定，我校将会继续加大对青春健康及预防艾滋病教育的宣传，培育更多优秀的青春同伴教育“魅力讲师”，号召更多大学生关注性与生殖健康问题。
