# 我院成立教师发展中心

为不断提高我院教育教学水平，进一步提升我院教育教学质量，推动我院教师专业化发展，尤其是占我院主体地位的中青年教师的成长发展，学院决定特成立教师发展中心。

据介绍，教师发展中心为学院直属机构，与组织人事处合署办公，是面向全院教师的服务导向型组织，“中心”由“教师发展咨询委员会”和“业务部门”两部分组成，教师发展咨询委员会负责为“中心”工作提供指导、咨询与建议；业务部门负责统筹协调“中心”工作。为了分类开展工作，“中心”依托各职能部门下设教师培训与发展部（依托组织人事处）、教师能力提升部（依托教务处）、教学资源保障部（依托图书信息中心）、教学质量评估部（依托高教评价中心）及教学专题研讨部（依托各系部）。

教师发展中心坚持“尊重、服务、支持、发展”的工作理念，致力于教师教学能力和科研能力提升，服务区域社会发展，打造一支师德高尚、业务精湛、结构合理、充满活力的高素质、专业化的教师队伍。中心要成为我院集服务、咨询、指导、培训、研究与职业生涯规划等多功能于一体的职能机构。

教师发展中心主要计划有：新教师入职培训计划、教师教学能力提升计划、教师科研能力提升计划、干部管理能力提升计划、教师咨询服务计划、教学改革研究计划、教学资源共享计划及教学质量评估计划。本学期近期计划主要有：出台《“青年教师发展基金”管理办法》，制作教师发展中心网站，完善新教师入职培训内容，出台《骨干教师选拔和培养管理办法》，出台《骨干教师出国研修选拔办法》及开展教师发展调研工作等。
