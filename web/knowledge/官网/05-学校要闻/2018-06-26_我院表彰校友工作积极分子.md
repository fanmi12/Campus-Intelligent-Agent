# 我院表彰校友工作积极分子

6月22日，我院2018届校友工作联络员聘任仪式在行政楼112会议室召开。院长王卫平,学院办公室、校友会秘书长杜鹏举和2018届104名校友工作联络员，以及教师代表、校友代表参加了会议。

杜鹏举秘书长宣读了《关于聘任2018届校友工作联络员的决定》与《关于表彰“校友工作积极分子”的决定》，对“校友工作积极分子”进行了表彰，向校友工作联络员颁发了聘书。

校友代表、2014级国际会计专业2班黎婉诗发言表示，校友联络员是校友与校友之间、校友与母校之间沟通交流的重要枢纽，这是一份荣誉，也是一份使命。校友联络员将心系母校，牢记自己的义务和责任，竭尽所能做好自己本职工作。

2005级软件工程专业邓锦溏校友代表分享了他的校友工作心得。他认为，作为一名校友联络员，要以校友会作为据点，以服务校友作为触点，多为校友工作谋划策、建桥梁、开通道。城院人以自身独有的归属感和团结精神，必定会在校友事业上节节高升。

王卫平院长向受聘的104位校友工作联络员表示祝贺。他指出，校友联络员承载了母校对校友个人的肯定与厚望，是校友与母校之间沟通的重要纽带。校友工作联络是个人学习与锻炼的机会，也为在校学生提供了可贵的人际交往平台。希望每一位校友联络员能够自觉履行校友职责，积极主动地组织校友联络工作，为母校与校友做贡献。学院也将加大校友工作建设的支持力度，促进母校和校友共同发展。
