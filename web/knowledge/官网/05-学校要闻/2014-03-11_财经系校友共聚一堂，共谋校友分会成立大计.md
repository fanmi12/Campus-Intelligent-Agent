# 财经系校友共聚一堂，共谋校友分会成立大计

3月8日，财经系历届校友代表与该系师生共聚一堂，在新校区5A220会议室召开财经系校友分会第一次筹备委员会会议。财经系系主任罗卫国、党总支副书记唐洁、全体辅导员以及各届学生干部代表、在校学生代表等出席了会议。

罗卫国主任致欢迎辞，简要介绍了财经系的概况以及未来的发展。与会人员分别作了自我介绍，各位校友畅谈了自身工作的经验和感受，并感谢母校一直以来的关怀与教诲。

会议就“财经系校友分会筹建方案”进行深入探讨，校友们踊跃发言、各抒己见，气氛十分热烈，大家都表示愿意为财经系校友分会贡献一份力量。会议最终确定了校友资料收集的负责人、校友分会章程的部分内容、校友分会成立的时间、校友会未来的发展等内容。

借城市学院成立10周年之际，财经系筹建校友分会，必定会增进财经系校友与母校的联系，促进校友之间的相互交流，团结互助、共同发展。
