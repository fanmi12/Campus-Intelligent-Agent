# 学院召开人事制度改革座谈会

4月17日，我院组织教职工在四号楼315会议室召开人事制度改革意见座谈会。党委书记朱志德副研究员、行政副院长张林博士、人力资源管理体系课题小组部分成员及30余名教职工代表出席和参加了会议。

会上，人力资源管理体系课题小组成员对学院人事管理制度再设计（定岗定编方案、绩效考核方案及薪酬调整与管理方案）作了总体介绍。教职工代表就改革方案的一些细节进行探讨并提出了意见和建议。学院领导对教职工代表的疑问作了相应的解答。

会后，人力资源管理体系课题小组将根据教职工代表所反映的情况进行综合分析，对人事制度改革方案作进一步的充实与完善。
