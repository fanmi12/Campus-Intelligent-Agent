# 学院党委举办2018年春季学期思想政治理论课集体备课会

3月23日下午，学院党委在行政楼212会议室举办2018年春季学期思想政治理论课集体备课会。学院党委书记、院长王卫平，党委副书记章德胜，各院（系）党总支书记、主任及思政部有关教师参加了集体备课会。党务工作部副部长叶凯贞主持了会议。

章德胜副书记传达了《广东省教育厅关于做好2018年春季学期高校党委书记、校长和院（系）党组织书记、院长（系主任）上第一堂思想政治理论课工作的通知》精神，要求

各院（系）党总支书记、主任

旗帜鲜明地站在宣传思想和意识形态工作第一线，贯彻落实习近平新时代中国特色社会主义思想和党的十九大精神及2018年全国两会精神。他要求，各院系（部）加强协调，制定科学、可行的实施方案，在3月30日前全部完成任务，同时做好宣传工作及后期课件、教案等材料的上报工作。

思想政治理论课教学部副主任石志民对上课时间、讲课内容及重点工作要求等进行了讲解与安排。

思想政治理论课教学部赵卫丽老师进行了示范教学。她以《思想道德修养与法律基础》为例，结合自身教学教改的经验与成功做法，对课程的主要要求、特点和教学难点、教学方式等进行了详尽的讲解和演示。

王卫平书记总结了2017年秋季学期学院党委书记、院长和各院（系）党组织书记、主任上思想政治理论课的有关经验。王书记要求，各院（系）党总支书记、主任严格贯彻落实省教育厅的文件精神，在思想上给予高度重视，积极准备，认真备课，从政治和全局的高度上好2018年春季学期这堂思想政治理论课。
