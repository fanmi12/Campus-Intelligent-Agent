# 2012年春季赴美交换生今日启程

1月4日，我院金贸系09国贸1班学生游玮然登机赴美国，开始他在北爱荷华大学为期四个月的修学生活。

据悉，我院与北爱荷华大学的交换生项目已经进行了三年，每年春秋两季都有一名学生赴美交流，游玮然是我院第五批交换生。从2012年开始，每年秋季学期（8月至12月）我院将派出两名优秀学生赴美学习，报名时间定于2月初。
