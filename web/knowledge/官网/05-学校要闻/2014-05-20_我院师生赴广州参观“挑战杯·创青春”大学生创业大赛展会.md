# 我院师生赴广州参观“挑战杯·创青春”大学生创业大赛展会

5月17日，团委书记罗文芳带领我院6名学生到广东金融学院参观“挑战杯·创青春”广东大学生创业大赛优秀作品展。

据悉，本届“挑战杯·创青春”创业大赛由团省委、省教育厅、省人力资源和社会保障厅、省科技厅、省科协、省学联共同主办，共展出92所高校331件作品。其中有我院获“铜奖”的四件作品。

我院大学生通过此次参观学习，加深了对创业大赛的认识，拓宽了创新创业的视野。同时，也为我院今后开展创新创业工作提供了借鉴经验。
