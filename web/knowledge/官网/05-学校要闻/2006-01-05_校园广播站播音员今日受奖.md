# 校园广播站播音员今日受奖

1月5号，在校园广播站小小的办公室内，我院新闻中心给校园广播站的播音员们颁奖并发出聘书。

校园广播站是同学、老师、沟通的纽带和桥梁之一，对此，在幕后默默工作的播音员作出的贡献功不可没。经过对广播站播音员一学期工作的考核、评估，新闻中心决定给刘哲、陈玲玲、冯奕源、程奇敏四位同学颁发优秀播音员证书；并授予十位同学2005—2006年度校园广播站播音员的聘书。
