# 我院两工作室获批为广东省高校骨干辅导员工作室

近日，从“广东学工”公众号获悉，我院两个辅导员工作室进入到广东省高校骨干辅导员工作室遴选公示阶段。其中，张宏渝老师的“大学校园文化活动指导工作室”入选“广东高校骨干辅导员工作室建设对象”，陈浩华老师的“大学生思想理论教育工作室”入选“广东高校骨干辅导员工作室培育对象”。这不仅实现了我院建院以来在此领域的新突破，“大学校园文化活动指导工作室”更是广东省独立学院填补了该领域的空白。

建院以来，我院高度重视辅导员队伍建设，不仅开展优秀辅导员评选活动，还聘请了十九大代表陈小花、华南师范大学魏则胜教授等7人担任我院辅导员成长导师，进一步加强了辅导员队伍建设，提升了辅导员职业化、专业化水平。近年来，我院辅导员在教育部、教育厅组织的辅导员年度人物评选、辅导员职业能力大赛等都有了新的突破，同时指导学生获得多个省级奖项。
