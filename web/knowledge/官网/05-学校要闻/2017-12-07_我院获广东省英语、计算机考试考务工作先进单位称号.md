# 我院获广东省英语、计算机考试考务工作先进单位称号

12月1日，广东省高校英语应用能力考试、计算机水平考试考务培训会议在广州华南师范大学召开。

会议对2012-2016年在英语、计算机考试组织和考务管理工作进行了总结，对表现突出的院校和个人进行表彰。我院被授予“2012-2016年度广东省英语、计算机考试考务工作先进单位”称号。

在历年英语、计算机考试工作中，我院考务组织工作规范严谨，实现“零事故”、“零错误”，获得了评审单位的高度认可。
