# 中科院科学家金雅芬做客我院解析创新

3月19日下午，中国科学院数学与系统科学研究院研究员金雅芬应邀为我院学子作“创新之解析”专题讲座。该讲座也是第十届大手牵小手“东莞市科普报告”巡回活动之一。党委书记章德胜与师生代表齐聚学术报告厅聆听了讲座。

金雅芬老师回顾了我国由模仿借鉴到自主创新的科技发展史，点明创新必要条件和关键要素包括良好的社会环境、国家的规划、人才以及组织强有力的财力支持。讲述了数学家华罗庚的科研创新事迹，并分享了出自华罗庚的至理名言——“无论对国家还是个人，创新都是第一位”的内涵。

在谈到当代大学生应如何将空想转化为实际的创新行动时，金雅芬老师激励同学们应积极投身实践活动，多主动参加各类科技夏令营等，直接接触一线科研活动，增长见闻，提高实践能力。

金雅芬老师还科普了人工智能的发展现状。在与同学们互动时，她站在专业角度、结合自身经历即时为同学们答疑解惑，对社会上的热点问题提出了自己的观点和看法。

金雅芬老师根据网络信息时代大科学传播的新特点，设计制作了多家数学科普网站。她致力于传播华罗庚等老一辈科学家的先进事迹和治学思想、科学精神，撰写了许多科普文章。
