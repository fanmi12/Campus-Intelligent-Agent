# 我院党校第二期入党积极分子培训班第二讲开讲

3月23日下午，我院党校第二期入党积极分子培训班第二讲在学院大礼堂开讲。本次讲课的题目是：“三个代表”重要思想的科学内涵及深远意义。我院李建中教授担任主讲教师。本次讲课历时两个小时。

李教授讲课引经据典，幽默风趣。课后，他还热情地回答了同学们关心的问题，并希望入党积极分子认真学习三个代表思想，多读书，读好书，争取从思想上、组织上完全入党。

第二期培训班共有四讲。
