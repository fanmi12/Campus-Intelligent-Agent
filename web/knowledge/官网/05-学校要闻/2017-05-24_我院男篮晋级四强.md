# 我院男篮晋级四强

5月22日，我院男篮客场以83∶68战胜广东创新科技职业技术学院队，昂首挺进四强。

一声哨响，我院7号黄志陆便以2记3分球奠定开场优势。在对方的奋力追赶之下，我院仍以26∶15的优势结束首节。

次节中，双方火力有增无减，不断利用中投和突破，连连得分。比分交替上涨。

易边再战，双方增加防守强度，都以杀入篮下、快攻得分为主。我院虽然不断突破制造罚球，但对方仍顽强地把分差缩小到个位数。关键时刻，我院10号黄明键挺身而出命中关键3分，鼓舞了士气再次将扩大优势，以61∶49比分进入末节。

第四节，创院对进攻操之过急，失误频频。我院抓住机会，拉大分差，我院5号黄荣斌发挥出色，多次杀入篮下进攻得手，最终我院以83∶68战胜对手，顺利晋级四强。
