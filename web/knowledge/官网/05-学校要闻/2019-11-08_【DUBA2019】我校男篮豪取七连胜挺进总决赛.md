# 【DUBA2019】我校男篮豪取七连胜挺进总决赛

11月7日晚，2019第四届大学生篮球联赛进行半决赛对决。我校主场迎战东莞职业技术学院队，激战四节之后以69∶63击败对手，将与广东科技学院队会师总决赛。

时隔一年，再战东职。比赛伊始，对方球员先下两分，随即双方火力全开，你来我往，第一节比赛结束时， 我校以12 ∶17落后。

次节，双方球员各自为营，加大攻防火力。我校以快攻为主节奏，奋力追赶，以 32∶30 将比分反超。

易边再战不久，10号球员邓浩宏连续射进两记“3分球”成为亮点，全场掌声雷动。我校男篮士气高涨，几次逼停对方24秒。随后，东职队迅速调整战略，拼命追赶，一度将比分差距缩小。战况一度陷入胶着状态，难舍难分，上演了“棋逢对手”的好戏。

第四节，双方球员奋力为荣誉而战。东职队一记3分一度将比分反超。我校男篮稳住阵脚，紧密配合，10号邓浩宏打出一记“2+1”，气氛瞬间燃爆。随后，更是打出一波连续抢断、完美配合的高潮，给观众带来一场视觉盛宴。终场哨声响起，比分定格在69∶63，我校获胜！

主教练钱丽娜赛后表示：“我队技术落后于对方，此次艰难获胜，主要是细节方面我们更胜一筹。凭借敢打敢拼的精神，击败整体实力强于我们的东职队，拼搏精神值得肯定！”她希望在总决赛时，队员们能够调整心态，将城院男篮的精神在赛场中更好地体现出来。
