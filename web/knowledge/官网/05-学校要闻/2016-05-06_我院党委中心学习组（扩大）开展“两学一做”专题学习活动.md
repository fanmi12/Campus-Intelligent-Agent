# 我院党委中心学习组（扩大）开展“两学一做”专题学习活动

5月5日下午，我院党委中心学习组（扩大）在行政楼212会议室开展“两学一做”专题学习活动。院领导王卫平、章德胜、高香林、刘玉侠和各部门负责人，各院系（部）主任、书记参加了学习活动。

党委中心学习组认真组织学习了中共中央办公厅印发的《关于在全体党员中开展“学党章党规、学系列讲话、做合格党员”学习教育方案》重要精神。

党委宣传部部长何鹏举同志对文件作了细致解读，并讲解了“两学一做”的重要内涵及学习要求。

党委副书记章德胜同志主持了学习活动。他要求全院党员加强理论学习，在学习、工作、生活中发挥党员先锋模范作用，做一名讲政治、有信念，讲规矩、有纪律，讲道德、有品行，讲奉献、有作为的合格党员。

党委书记王卫平同志作了总结发言，要求党员同志在埋头工作的同时，也要用党的最新理论武装自己，时刻与党中央保持一致。并要求各党支部按照“三会一课”制度和党委部署，深入开展“两学一做”学习教育活动，加强理论知识学习，增强政治意识、大局意识、核心意识、看齐意识，扎扎实实地工作，积极服务广大师生员工。
