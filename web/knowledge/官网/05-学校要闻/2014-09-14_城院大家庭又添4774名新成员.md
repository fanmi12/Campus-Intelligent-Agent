# 城院大家庭又添4774名新成员

9月14日，为期两天的2014级新生报到工作完美收官。据学生处有关负责人介绍，截至今日下午5时，全院实际报到的新生有4774人，报到率为94.84%，再创历史新高。

据悉，今年我院共录取新生5034人，比去年增加42人。超过学院总报到率的有政法系为97%，其余的还有文学与传媒系、财经系和艺术系。
