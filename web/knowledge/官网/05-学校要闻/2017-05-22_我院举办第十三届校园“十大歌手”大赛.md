# 我院举办第十三届校园“十大歌手”大赛

5月21日，“星声筑梦”——“第十三届校园十大歌手”决赛惊艳学术报告厅，唱响整个城院。

决赛分成两轮：第一轮从十二位歌手中选出分数最高的前六位，第二轮由前六位歌手进行排名赛。随着陆湃乐队的一首《Friends》开场，瞬间全场氛围“爆燃”起来。十二位歌手陆续闪亮登场，他们的演唱各具特色，时而缠绵婉转，时而激情四射，赢得掌声不断。

中场休息期间，嘉宾OLT舞队带来的特别节目《Oh my gosh》，再度推高现场气氛。

第二轮，可谓高潮迭起，六强毫无保留的演唱获得了全场师生的一致认可。其中，许敏以一首《最长的电影》获得本届“十大歌手”大赛的冠军，许志浩、叶乐轩获得亚军，陈婕、莫贝儿与吴嘉颖组合、蓝旸获得季军。蓝旸还摘获了最强人气奖，计信系则获得最佳组织奖。

值得关注的是，上届校园“十大歌手”冠军凤翔作为嘉宾倾情演唱了《天空之城》。
