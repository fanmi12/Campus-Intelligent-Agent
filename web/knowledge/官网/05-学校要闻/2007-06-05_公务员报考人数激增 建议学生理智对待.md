# 公务员报考人数激增  建议学生理智对待

东莞市2007年公务员招考报名工作5月27日在我院结束。据悉，这次计划招录130多人，但应聘者却多达7000多人，其中个别职位报名人数竟有300多人。

根据国家有关政策规定，本次公务员招考取消了户籍限制，东莞市经济快速发展，吸引了众多外地来莞寻找发展机会的博士、硕士及本科生，加之去年下半年没有招考，所以这次报考人数比往年大大增多。根据现场观察，报考工商局和地税局的人较多，报名的队伍约40多米长。但一些有特殊要求的职位如外办侨办，需要应聘者懂得希腊语，报名的人却很少。

据了解，我院一些毕业生也参与了本次招考。学院就业指导办的老师,希望同学们要理智面对公务员报考热潮，应根据个人具体情况选择工作单位。择业时要考虑自己的专业、兴趣和特长，在学校及早进行职业规划设计。
