# 政法系新学期的工作安排早开局好

2月27日，政法系召开教师大会，安排开学准备工作，要求教师上好新学期的第一节课。党委书记朱志德出席会议并发表讲话。

系主任刘杰教授向大家表达了新年的问候，要求大家努力做好开学前的准备工作，重温“两张表”，强化教学纪律意识，确保教学秩序正常进行，保障“教育教学”工作的顺利开展，为新学期的工作开好头。

副主任赵书山在会上就开学前的几项主要工作做了详细的安排。

朱志德书记指出，政法系开学准备工作动员早，安排细，教师全部上岗就位，这是好的开始。朱书记还介绍了学院今年的工作重点，要求全体教师狠抓教学质量，增强创新意识，努力建设学习型组织，发扬成绩，克服不足，努力开创新局面。
