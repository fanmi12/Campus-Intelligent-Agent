# 我院举办2018年高校毕业生就业培训讲座

9月27日下午，2018年高校毕业生就业培训讲座活动在学术报告厅举行。东莞市人力资源局寮步分局就业培训股股长邓镇铎、人才服务股副股长叶志坚，学院招生就业处处长孔增强、商学院副书记李玉春出席了活动。

此次活动是由东莞市人才管理办公室主办，我院招生就业处与东莞市人力资源局寮步分局承办，其主题为“实名服务、精准到人、助力高校毕业生就业创业”，旨在认真贯彻人力资源和社会保障部及省人力资源和社会保障厅相关文件精神，深入实施就业创业促进计划，助力我院毕业生就业创业，提升毕业生就业质量。计划分别在9月27日、10月13日、14日、20日为我院2019届应届毕业生，举办四场讲座。
