# 2014年校运会是节点更是新的起点

11月21日，历时两天的东莞理工学院城市学院2014年运动会在夕阳的余晖中落下帷幕。

院领导杨敏林、王卫平、张林、陈丁堂、章德胜、高香林、麦绮琳及各系部主任出席闭幕式，并为获奖集体和运动员颁奖。

据悉，本届运动会有5个项目的比赛成绩刷新了校运会记录；院长杨敏林为成绩优异的金贸系代表队颁发了“校运会特别贡献奖”。

师生签名院旗入驻校史馆永久保存

伴随着庄严的院歌声，签名院旗收旗仪式开启。工作人员把置于主席台前签名纪念的巨幅院旗整齐折叠，然后由体育教学部主任邢红林将院旗交给学院办公室主任黄兢。在这面特殊的院旗上，有4000多名师生的签名与祝福语，表达了对城市学院明天的美好期待。这面院旗将永久保存在学院校史馆里，作为城市学院“十年校运?十年精彩”的纪念。

5项校运会记录被刷新

在闭幕式上，总裁判长、体育教学部主任邢红林教授宣布了本届运动会特大喜讯，本次运动会有5个运动项目打破了校运会记录，创造了骄人的成绩。管理系运动员刘佩婷同学、金贸系运动员岑荧菲同学打破了女子100米栏校运会记录，金贸系运动员梁艳敏同学破女子200米校运会记录，金贸系运动员利伯康破男子200米校运会记录，金贸系代表队破10*30米、女子4*100米校运会记录。邢主任话音刚落，赛场上顿时爆发出热烈的掌声为“王者”喝彩。

“巨无霸”金贸系囊获“4个总分第一”

金贸系代表队以突出的表现和骄人的成绩，囊括学生组女子团体、男子团体、运动会团体及全年体育活动团体总分4个第一名。值得一提的是，该系在历年的校运会中每年都是总分第一名，学院决定给予特别奖励，院长杨敏林为他们颁发了“城市学院校运会特别贡献奖”锦旗。据悉，管理系、城环系代表队分获2014年城市学院团体总分二、三名，教工组团体总分城环系和后勤并列第一，教辅名列第二，计信系列第三名。计信系、文传系、城环系、财经系分获教工组体育道德风尚奖。

颁奖结束后，各系部成员高举着系旗环绕运动场奋勇奔跑，欢庆城市学院2014年运动会画上完美句号。

团体操表演精彩纷呈

主题为“祥和?奋进?拼搏?飞扬?十年”的大型团体操表演是本届运动会又一亮点，获得运动健儿的一致点赞。它是由我院体育教学部策划主创，以“十年校庆，十年精彩”为理念，由2000名大一新同学共同表演完成的。

体育教学部主任邢红林谈起这次开幕式团体操表演时大加赞叹。他介绍说：“这是城市学院运动会有史以来规模最大、参与人数最多、服装道具最为艳丽的一场团体操表演，朋友圈内有人调侃说是‘奥运会的标准’”。

据悉，此次团体操表演分为五大章，即“祥和太极”、“奋进 搏击”、“拼搏 武术”、“飞扬 青春”、“十年 翻花”。

据记者了解到，为了办好这一台节目，体育教学部全体老师及相关同学花费了近两个月的心血。暑假期间，彭国华老师专程赴海南学习搏击操。返校后，李珊珊、彭国华、张莉三位老师自编了富有城院特色的搏击操全套动作。李珊珊老师在排练期间，家人出车祸住院，仍天天坚持在排练现场。从10月18日开始，体育教学部全体教师全天候与学生在一起训练和排练团体操。学院拨出专款，为团体操运动员购置了服装和道具。

“创新·有趣”彰显运动会特色

据邢主任介绍，今年校运会较往年新增了不少的活动内容与亮点，吸引师生广泛参与各得其乐。趣味活动增加了系部主任拔河比赛和教工的“猪八戒背媳妇”负重比赛。在学生组竞技项目中，新增了世界青年奥运会8X100和五项全能，其中五项全能包括100米赛跑、100米跨栏、跳高、铅球和800米。校运会单项颁奖仪式的颁奖领导，由各系部负责人轮流担任。裁判员着统一颜色的马甲，成了赛场一道风景线。为凝聚师生心力，在开幕式上新增了院旗签名活动，体育教学部专门制作了一幅10X15米的院旗铺放在运动场的中央，供全院师生签名。据悉，有近4000名师生签名题词。体育教学部陈勇军老师利用攀岩技术在综合馆及主席台的上方，利用航拍技术拍摄校运会的精彩瞬间。

三大赞助商给力校运会

在闭幕式上，学院办公室主任黄兢将一块“热心公益事业，关爱学生健康”的牌匾赠，送给东莞市天使医疗投资有限公司副总经理李毓霞女士，用以感谢该公司对运动会的大力支持。据悉，今年共有三大公司友情支持校运会。东莞市天使医疗投资有限公司赞助赛场四周的横幅还特别制作了“活力城院人，健康新生活”的横幅标语，激励城院有更多的师生参与户外运动。同时，还提供了200箱矿泉水。红牛饮料销售有限公司东莞分公司为我院篮球文化节和本次校运会提供了40顶帐篷、凯乐石服饰有限公司赞助裁判员服装250多件。
