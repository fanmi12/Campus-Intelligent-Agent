# 我院官微在广东省本科院校中排名第22位

11月5日，广东省教育厅官方微信公众号“广东教育”权威发布“广东高校官方微信公众号9月排行榜”，我院官微位居该排行榜的第22位。

据统计，我院官微在9月份共发送推文52篇，以开学、迎新、军训、招新等内容为主。阅读总数11W+，点赞总数1538次，平均阅读量2271次，其中超过5000次点击量的达5篇。

据介绍，新学期以来，我院新闻宣传工作以新媒体为突破口，以微信公众平台建设为抓手，在内容生产方面下功夫。我院官微从推文的内容、形式进行了改革，推文质量、阅读量、评论数都有了一定的提升。但相比排名靠前的院校，我院官微在粉丝基数、阅读量、点赞数上还有一定的差距，还需广大师生的支持和关注。
