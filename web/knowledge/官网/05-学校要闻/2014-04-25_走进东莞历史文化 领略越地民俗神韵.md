# 走进东莞历史文化 领略越地民俗神韵

4月24日，我院文学与传媒系邀请东莞著名历史文化研究学者杨宝霖先生在学术报告厅做关于东莞方志及族谱的文化讲座。

杨宝霖先生通过流传下来的七种方志展开了话题，他说：“顺治东莞县志交代了东莞人的来历，南北朝时期，北方兵荒马乱，北方人将中原文化带到东莞，清明时折杨柳枝挂树梢头以及“拾金”，即将尸骨捡起存在罐中留作文物的习俗至今仍保留着，尤其是从中原带来的勤劳朴素的品质与中远无大区别。”

杨宝霖先生说，根据崇祯年代的东莞县志所记载的史料，他曾单身匹马赴广西舌战群儒，以周密的考证，无可辩驳的事实，证明了袁崇焕的出生地是东莞。当讲到康熙年间的东莞县志时，老先生遗憾地此书在说中国已失传，最近，通过与香港学者的交流，终于托人辗转从日本购得。康熙年的县志对清朝初年的情况记录的非常详细。在雍正年的县志中，杨老讲述了东莞义学的兴起及东莞古名“宝安”的来历，通过水路的开发展现东莞的建设历程。由于清末连年战乱，内忧外患，百姓民不聊生，所以道光、咸丰、宣统、光绪年间都无县志。

杨老先生感叹，现在的族谱不重视文化材料，对于功名、读书功绩丝毫不提。同学们被老先生曾经在乡间寻找族谱的轶事逗乐了。

讲座接近尾声，杨宝霖先生与学生积极互动，与学生亲切地交流。
