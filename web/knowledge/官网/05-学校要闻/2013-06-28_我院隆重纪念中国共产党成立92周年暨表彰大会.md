# 我院隆重纪念中国共产党成立92周年暨表彰大会

6月27日，我院党员在学术报告厅集会，隆重纪念中国共产党成立92周年，表彰2012—2013年度先进基层党组织、优秀党务工作者和优秀共产党员。会议要求，全体党员同志和全院教职工，要虚心向先进单位和优秀党员学习看齐，做好表率，凝聚力量，为学院的发展和稳定、共筑“城院梦”而不懈努力。

会议认为，我院各级党组织和广大党员尽职尽责创先进、立足岗位争优秀，涌现了一大批先进基层党组织和优秀共产党员。党委决定授予财经系党总支等4个支部为“优秀基层党组织”称号，授予邢红林等4名同志为“优秀党务工作者”称号，授予樊腾腾等29名教工党员为“优秀共产党员”称号，授予袁小燕等13名学生党员为“优秀共产党员”称号。

党委书记朱志德在大会上发表讲话。他首先回顾总结了党委一年来所取得的十大方面的工作成绩，分析了学院当前和今后一段时间所面临的任务。为此，他向与会人员提出了四点希望：一是希望全体党员认真学习领会党的“十八大”精神，自觉地以邓小平理论、“三个代表”重要思想和科学发展观武装头脑，全面贯彻落实东莞理工学院第二次党代会精神。要正确树立社会主义荣辱观，要从培养社会主义的合格建设者和可靠接班人的要求出发，全面贯彻落实“育人为本，德育为先”的方针，自觉地把育人工作融入到教育教学的各个环节中去。为实现学院的战略目标贡献力量。二是希望全体党员要坚定信心，以校为家。不为任何风险所惧，不为任何干扰困惑，主动服务学院的各项工作，在城院扎根、在东莞扎根。三是希望广大学生党员要以振兴中华为己任，勤奋学习，求是创新，带头参加学术科技活动，培养科学精神和人文精神，不断提高运用知识服务社会的本领。四是希望受到表彰的同志和党组织要谦虚谨慎，戒骄戒躁，继续创先争优，在教学、管理、科研、服务中发挥先锋模范作用。

大会还举行了新党员宣誓仪式。

党委副书记章德胜主持大会。
