# 抓作风 促教风 带学风  建设好的校风

为扎实有效地开展校风建设月活动，建设一个好的校风，学院于11月8日、11月9日、11月22日，先后三次分别召开加强教风、学风、机关作风建设动员会议，进一步动员和组织师生员工深入开展校风建设月活动。院领导程发良、朱冰、张林分别到会作重要讲话。

程副院长指出，校风包括教风、学风和机关干部的工作作风。校风是学院的灵魂，直接影响着学院的声誉、教学质量和办学目标的实现。为此，学院决定每年的11月份为校风建设月活动时间。在这一个月里，各单位、各部门、各班级要联系校风建设实际，查摆问题，分析原因，制定整改措施。

朱冰副书记说，经过几年的努力，我院形成了一个好的校风。可以这样说，“三风”是端正的。但是，也还存在一些问题，各级领导和老师必须对此引起高度重视。比如，一些学生学习目的不明确，学习态度不端正，上课迟到早退，不认真听课，专业思想不牢固，忽视文化课的学习，学习成绩不理想。

张林副院长将机关不正之风归纳为“十大”表现。他说，有的机关干部责任心不强，不思进取，执行能力不强，纪律松懈，作风漂浮，工作不务实，办事不讲原则，搬弄是非，工作效率不高。针对这些问题，他进一步指出，院机关是学院的司令部、参谋部，机关干部代表学院的形象，机关工作作风对树立好的教风、学风，起着至关重要的作用，机关干部要带头搞好校风，进而带动和促进教风、学风的根本好转。当前，机关作风建设的主要内容是：摆正位置，明确工作职责；加强队伍建设，增强服务意识；创新管理模式，提高执行能力。通过整顿，把我们的机关建设成为和谐型、服务型、学习型、思考型、创新型、具有责任心的团队，使每一个机关干部都具有非常强的服务意识和执行能力，当好参谋助手，发挥带头、保障作用。这次整顿的方法是，一是要对照问责制和年初的工作计划，回顾总结一年来的工作，狠抓各项工作的落实；二是要结合创新奖的评选 ，创新工作机制和工作方法，找准问题，制订措施，提高工作效率；三是以评选“十佳”活动为契机，向先进人物学习，纠正不正之风，形成良好的工作氛围。

院领导最后强调，开展校风建设月活动，是推进校风建设的最好形式之一，一定要认真开展起来，善始善终地坚持下去，不走过场，不草草收场。对查摆出来的问题，要坚决整改，务求取得实效，争取每年有进步。学院决定，年底时将对校风建设月活动情况进行检查评比，专题听取各单位、各部门的情况汇报。
