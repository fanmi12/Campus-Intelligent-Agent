# 我院召开2016-2017学年度基层党组织量化考核工作汇报会议

6月1日、2日下午，我院召开了2016-2017学年度基层党组织量化考核工作汇报会议。学院党委委员王卫平、章德胜、高香林、黄兢、杜鹏举和各基层党组织书记、副书记出席了会议。

各基层党组织负责人主要围绕班子建设情况、党员学习教育情况、发展党员工作、日常管理工作、党员活动室建设、分党校建设情况、特色亮点工作情况等七个方面，依次进行了总结汇报。

章德胜副书记对各基层党组织的党建工作特色和亮点，给予了充分肯定。他说，相比往年基层党组织量化考核工作的形式，今年评选更利于各党总支间的相互交流与学习，并希望各基层党组织做到相互学习、相互借鉴，共同提高。
