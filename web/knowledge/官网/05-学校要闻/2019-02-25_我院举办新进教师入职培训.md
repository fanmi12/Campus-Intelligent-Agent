# 我院举办新进教师入职培训

2月24日，25名新入职教师参加了由学院教师发展中心组织的入职培训活动。院长王卫平，书记章德胜，副院长高香林、周庆、刘玉侠，院长助理林江龙和学院办公室主任杜鹏举、人事处副处长李海冬等领导出席了入职培训开班仪式。

此次培训活动共设七个专题讲座，涵盖校情校史、师德师风、政策规范、馆藏资源利用、多媒体教学设备使用等专题，内容丰富，形式多样。

学院非常重视新教师的师德师风主题教育，并由王卫平院长担任主讲。他代表学院向新入职教师表示热烈欢迎，期待大家在未来的新工作生活中不断进步，为城市学院带来新的活力。

王卫平院长强调，教师的职责是教书育人，是知识的传授者，要品德立身、立德树人，坚守教师道德底线，成为学生的好榜样。作为新时代的青年教师，要尊重学生个性，鼓励学生多元化发展，做学生的引路人。他同时强调，新教师要兼顾教师自身进步与学校发展，荣辱与共，砥砺前行。

刘玉侠副院长作校情校史专题主讲，就我院发展历程、办学理念和办学特色、人才培养成效、教师发展成效、办学成果等方面做了讲解，并解读了学院未来发展规划和发展愿景。

教务处副处长鞠晓红解读了教学管理制度，财务处欧阳小芬老师解读了财务管理制度，人事处副处长李海冬解读了人事管理制度，图书信息中心副主任陈显龙解读了馆藏资源利用,现代教育技术中心叶浩波主任主讲多媒体教学设备使用等学院相关政策法规及设备使用方法。

据介绍，学院教师发展中心通过举办入职培训旨在帮助新教师缩短适应期，尽快适应岗位角色。参训新教师们表示，培训有助于大家更加系统、全面地了解学院发展现状、教学与人事管理规章制度和教学工作等，有助于大家顺利度过入职适应期，为顺利开展教学科研工作奠定良好的基础。

人事处副处长兼教师发展中心副主任张兰主持了开班仪式。
