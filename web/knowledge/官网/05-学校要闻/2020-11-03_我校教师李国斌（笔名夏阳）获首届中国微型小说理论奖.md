# 我校教师李国斌（笔名夏阳）获首届中国微型小说理论奖

近日，中国微型小说理论研讨会暨理论奖颁奖典礼系列活动在浙江宁波举行。24日下午，来自全国各地的微型小说理论评论学者、作家、杂志编辑以及当地作者80余人聚首南塘老街城南书院参加颁奖典礼。会上，我校文学与传媒学院李国斌老师荣获首届中国微型小说理论奖。

中国微型小说（小小说）理论奖由《文艺报》提供学术支持，中国微型小说学会和宁波市文联、海曙区文联联合主办，三年一届，永久落户宁波。微型小说理论奖的设立，旨在加强中国微型小说的理论研究和学术交流，表彰成绩突出的微型小说理论工作者，促进微型小说创作的繁荣。本届中国微型小说理论奖的主题为“微型小说的叙事艺术与文体特征”，李国斌等三位作家获理论奖。中国微型小说学会会长夏一鸣表示，此次表彰成绩突出的微型小说理论工作者，是希望能进一步推动新时代中国微型小说理论事业的高质量发展，促进微型小说创作的繁荣。

评委认为，李国斌（笔名夏阳）的参评论文《夏阳微型小说创作理论作品》系列，显示了作者致力于微型小说创作理论研究的深度和广度，为当代微型小说作家提供了理论与实践的镜鉴。其理论专著《小小说的写作艺术》是一部具有指导意义的微型小说写作学论著，兼具理论思考与技术指导，辅以示范分析，对微型小说写作艺术进行了深度探讨，尤为难能可贵。

2020年10月23至25日，中国微型小说理论研讨会暨理论奖颁奖典礼系列活动在浙江宁波举行

微小说是近年来新兴网络文学形式之一，除了具有短小精悍的特点，还具有随时与读者互动的特征。它因其精短简洁、意蕴深远、轻松有趣而广受读者喜爱，尤其为处在快节奏工作生活状态的现代人所青睐。互联网时代信息阅读纷繁复杂，发展迅猛的移动媒介决定了人们阅读的篇幅，加上微博等社交媒体平台的发展，微小说这种文学形式迎来了属于它快速发展的黄金时期。

李国斌（夏阳）

李国斌，笔名夏阳，我校文学与传媒学院专职教师，中南大学访问学者，惠州学院客座教授兼创意写作中心成员。现系中国作家协会会员，文学创作二级，广东省小小说学会副会长，集作品创作、理论研究和大学教学于一体，为“小小说四门功课”写作理论创立者。荣获第五届（2009—2010年度）全国小小说金麻雀奖、首届全国微型小说理论奖、首届全国小小说擂台赛一等奖、首届中国武陵杯小小说年度图书奖、第二届扬辉小小说成就奖、广东省30年小小说特殊贡献奖等奖项。作品《好大一棵树》入选中国改革开放40周年40篇最具影响力小小说。

先后发表作品两百余万字，出版个人著作《马不停蹄的忧伤》《丧家犬的乡愁》《小小说写作艺术》和《丰城纪事》等十一部。主要研究方向为小说创作与理论研究，主讲文学写作、写作实训等课程。
