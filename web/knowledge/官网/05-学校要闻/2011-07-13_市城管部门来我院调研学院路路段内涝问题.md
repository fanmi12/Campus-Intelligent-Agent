# 市城管部门来我院调研学院路路段内涝问题

根据东莞市《关于落实2010年市政府十件实事和主要工作任务的通知》的要求，7月12日上午，东莞市政府水务局排水科李科长和东莞市莞城区街道办城市管理办张主任一行，来我院调研学院正门道路内涝整治问题。学院办公室、总务处、环境与基建办公室有关负责人参与现场办公会议。

据院办副主任、基建办主任叶树标介绍，当下适逢雨季，每逢降水较大时，学院正门前道路便出现严重积水，导致交通堵塞甚至瘫痪，这给全院师生和通过学院路的行人、车辆带来诸多不便，同时也存在多方面的安全隐患。

与会人员对我院两湖边主干道的排水系统进行了实地勘察，提出了利用我院两湖临时储水泄洪的初步整治方案，拟于今年进行全面规划设计，明年实施，预期能大力改善洪涝期学院路段的积水问题。
