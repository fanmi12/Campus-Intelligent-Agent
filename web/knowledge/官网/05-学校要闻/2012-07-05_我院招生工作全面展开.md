# 我院招生工作全面展开

截至今日，伴随着3名四川省艺术类考生出档并被录取，我院招生工作全面展开，目前，各项工作正在紧张有序的进行。

据招生办负责人介绍，目前艺术类第一志愿报考我院的上线考生207人，计划招收117人。其中音乐表演专业预计招生89人，目前上线人数达到165人。以第一志愿填报我院的上线考生较往年有较大增加。
