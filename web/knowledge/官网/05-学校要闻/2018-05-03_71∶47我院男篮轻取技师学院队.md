# 71∶47我院男篮轻取技师学院队

5月2日晚，我院男篮客场对阵东莞市技师学院队，以71∶47的优势取得二连胜。

一声哨响，我方迅速进入状态，15号黄荣斌抓住对方失误直入内线首个得分。接着6号庾世聪与4号李鹏杰跳投入两记3分球，9号叶志诚多次快攻得手，士气大涨，一度将比分拉至两位数。对方请求暂停过后，7号王耀辉杀出重围进球得分，5号李宗进与4号何健分别打入3分球，将比分差距缩小至个位数，首节以19∶12结束。

次节开局，两队球员皆手感冰凉，双方都积极组织了数次进攻，均无分进账。技师队率先打破尴尬局面，5号李宗进上篮频频造成我方失误，将比分咬紧。我方及时调整后，内外线火力全开，19号叶锐城快攻直杀篮下，7号黄志陆3分得手，再次将分差拉至两位数。上半场战罢，我方以32∶19领先。

易边再战，双方手感迎来大爆发，我方多点开花，尤其7号黄志陆手感滚烫，下起一波3分雨，单节拿下四个3分球。6号庾世聪紧跟其后，再中一记3分球，逼迫技师队进行战术调整。对方15号彭超富、9号许晓峰、7号王耀辉先后冲破我方内线上篮得分，尽力缩小比分差距。本节结束，我方55∶37领先。

末节，落后的技师队重提士气，开场便打出了6:0，场面陷入胶着状态。我方7号黄志陆挺身而出，投入关键3分球，士气大涨。6号庾世聪与4号李鹏杰手感滚烫，屡获3分，锁定胜局。最终，我方以71∶47取得首个客场胜利。

数据方面，我方7号黄志陆手感炽热，夺得全场个人最高分22分。
