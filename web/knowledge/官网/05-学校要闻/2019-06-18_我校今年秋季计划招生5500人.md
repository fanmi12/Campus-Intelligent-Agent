# 我校今年秋季计划招生5500人

经省教育厅批准，我校2019年普通本科计划招生5500人，创历史新高。其中，广东省内计划招生5100人，省外计划招生400人。

值得一提的是，我校今年紧贴社会人才需求，新增互联网金融专业（文理兼招），招生本科专业达到37个，将面向广东、河北、辽宁、吉林、黑龙江、江苏、浙江、福建、江西、河南、湖北、湖南、广西、海南、四川、云南、陕西等18个省份进行招生。

此外，我校还推出了云财务卓越班、金融学2+2国际班等一批特色招生项目。云财务卓越班是我校与新道科技股份有限公司校企合作共建。金融学2+2国际班采用双学位、双校园、双班主任和双语教学的“四双”培养模式。
