# 我校与韶关仁化县教育局一行召开对口帮扶工作推进会

5月11日下午，中共仁化县委教育工委书记、仁化县教育局党组书记、局长李子初，中共仁化县委教育工委纪工委书记蒙万胜一行8人来到我校。学校校长陈明，副校长李海冬等校领导，教学科研部、图书信息中心、人力资源部、学生处、团委等部门负责人参加对口帮扶工作推进会。

韶关仁化县教育局局长李子初一行参观了我校的图书馆、学术报告厅、学生活动中心、体育馆、智慧教室和商科实训中心等设施。观看了我校宣传片，了解了我校基本情况、办学理念、教学科研、专业课程，办学特色以及人才培养成绩等相关情况。

座谈会上，李子初局长对我校办学环境、办学特色与取得的成绩高度赞赏，尤其对我校智慧教室、图书借阅等教育信息化建设，印象深刻。他希望我校能围绕“科技赋能教育”主题对仁化县中小学信息化教学开展帮扶工作，重点做好校长信息化能力提升培训班、骨干教师信息教学技能提升培训班，加强校与校之间的合作交流等方面帮扶仁化县基础教育高质量发展。

陈明校长对仁化县教育局一行到来表示热欢迎，他表示，我校将根据仁化县教育局提出的需求，本着实事求是的工作作风，与仁化县教育局形成共识，切实达成有效成果，有针对性地完成该项工作。

李海冬副校长从我校师资培训、信息化建设、资源共享、提供硬件支持等方面对仁化县的基础教育进行了具体的帮扶工作介绍。

随后，双方进行了交流与协商，共同研究仁化县基础教育提升工作，细化工作方案，落实具体帮扶举措。
