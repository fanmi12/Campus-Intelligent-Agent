# 我院召开党总支副书记选任测评会议

7月1日上午，我院在行政楼112会议室召开党总支副书记选任测评会议，对符合条件的竞聘者进行了民主测评。院党委副书记章德胜同志主持了会议。

会上，来自文学与传媒系等9个单位的13名符合条件的竞聘者先后上台进行8分钟的竞聘演讲。由院领导、教学单位负责人、相关职能部门负责人、党总支（直属支部）书记组成的测评团在听取竞聘者的演讲后，进行现场打分选出优胜者。
