# 苗琳老师荣获“省民办院校第三届微党课比赛”一等奖

10月26日-27日，广东省民办高校党建研究会举办的第三届微党课决赛在广州华商职业学院举行，来自全省31所院校的48名选手参加了比赛。我院文传系党总支副书记苗琳老师荣获大赛一等奖，思政部党支部书记史雍真老师荣获三等奖。

据了解，比赛要求参赛选手用10-15分钟的时间，围绕党的基本知识、基本理论、基本路线等方面自行选题，结合十九大精神，从不同角度诠释党的章程、党的建设、党的理论与实践创新等内容。

比赛中，苗琳、史雍真老师经过精心准备，以生动的PPT课件，富有感染力的言语、精彩的讲演，赢得了评委和观众的认可，分别以平均分92.60分、87.6分获得大赛一等奖和三等奖。
