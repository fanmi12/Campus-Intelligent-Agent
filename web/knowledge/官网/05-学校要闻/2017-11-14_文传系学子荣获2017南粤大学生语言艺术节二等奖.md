# 文传系学子荣获2017南粤大学生语言艺术节二等奖

11月11日，由广东省委宣传部、省教育厅、省语言文字工作委员会共同主办的“青春梦?2017南粤大学生语言艺术节”决赛在华南师范大学举行，来自中山大学、暨南大学、华南师范大学等45所高校、4000多人参加了比赛。

我院文传系甘博同学通过层层选拔进入决赛，荣获“姓?家?国——主题故事大讲坛”比赛二等奖。
