# “抗击疫情——我们相约线上” 主题征文活动评比揭晓

为抗击新冠肺炎疫情，我校坚决贯彻落实教育部、省教育工委、省教育厅的重要部署，从3月2日起全面开展线上教学活动，全体任课教师坚守岗位、锐意创新、勇挑重担，全力做好线上教学工作；广大学生学习热情高涨，积极投身到线上学习。学校宣传部（融媒体中心）、教务处联合在今年3月面向全校学生开展“抗击疫情——我们相约线上”征文活动，各二级单位积极参加，学生踊跃投稿，本次征文活动共收到稿件167份。其中，66篇征文已在学校官网发布。经专家评审，特评出一等奖3个，二等奖5个，三等奖8个（获奖名单附后）。

获奖证书将由教务处分发至各二级教学单位，请获奖者在返校后到所属学院教学秘书老师处领取证书。

宣传部 教务处2020年7月8日
