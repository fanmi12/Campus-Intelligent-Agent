# 我院启用电子发票报销

6月5日，学院财务处通知，正式启用电子发票报销。

电子发票是税务系统改革推行的新举措之一，因电子发票可能存在重复打印、重复报销等弊端，给企事业单位的财务审核工作带来困惑和一定的财务、税务风险。

学院财务处本着服务全体师生员工的宗旨，从6月5日起启用电子发票报销。据介绍，财务处

经过多次调研及实践测试，结合学院实际情况，切实解决了电子发票重复打印报销等问题。同时也提高了工作效率，提升了服务质量。

财务处处长余竹根提醒报销人员，电子发票打印时要保存票面清晰、整洁、平整，在粘贴时要注意保持二维码的清洁和完整。
