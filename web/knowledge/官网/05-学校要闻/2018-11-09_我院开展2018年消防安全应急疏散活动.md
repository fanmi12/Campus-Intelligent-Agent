# 我院开展2018年消防安全应急疏散活动

11月8日下午，我院2018年消防安全应急疏散活动在运动场举行。寮步消防大队大队长文理华，学院副院长刘玉侠、有关部门负责人和2018级新生参与了演练。

刘玉侠副院长在致词中，对寮步消防大队的大力支持表示感谢，并强调“做好安全工作是促进学院稳定发展的关键。”希望广大师生能通过这次演练，提高自身安全意识，掌握消防安全知识。

此次消防演练分为如何使用灭火设备、被困人员解救、消防栓灭火器灭火、消防设备参观与体验等五部分内容。寮步消防大队消防员为同学们详细地讲解了灭火器使用的常识。在场的学生积极使用灭火器灭火，参观了消防设备，掌握了基本的消防知识。

此次消防疏散演练旨在进一步贯彻落实《消防法》，增强消防安全意识，提升消防安全处置能力、自救互救能力。
