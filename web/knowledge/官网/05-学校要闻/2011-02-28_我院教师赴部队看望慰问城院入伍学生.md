# 我院教师赴部队看望慰问城院入伍学生

陈建新副处长（左一）给袁阳同学（图中）送上慰问金2月23日，学生处陈建新副处长赴江苏省徐州装甲部队，看望慰问2010年从我院应征入伍的新兵，为他们送去全院师生的关怀和问候。

部队首长热情接待了陈副处长一行，并举行了座谈。部队首长介绍了我院学生新兵在部队的学习、生活和训练情况，肯定了他们在部队中的表现。

座谈后，陈建新老师到宿舍、食堂、训练场地看望了解学生新兵们的训练和生活情况。来自四川的2010级英语专业的袁阳同学说：“虽然来到部队只有两个多月时间，但我们已经习惯了这里的生活，这是部队和学校领导关怀的结果。请老师和同学们放心，我们一定会在部队努力学好军事本领，做一名优秀的军人。”
