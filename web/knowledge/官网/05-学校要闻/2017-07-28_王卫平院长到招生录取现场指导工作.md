# 王卫平院长到招生录取现场指导工作

7月22日上午，东莞理工学院城市学院招生录取阅档工作正式开始。王卫平院长在招生就业处处长孔增强的陪同下，来到我院招生录取现场，检查招生工作进展情况，看望并慰问了现场的录取工作人员。

王卫平院长指出，招生录取工作肩负着为学院选拔优秀生源的重任，同时又事关考生、家长的切身利益，他勉励大家本着对社会、对考生、对家长和对学院高度负责的态度，认认真真做好每一个环节的工作，确保顺利、圆满地完成2017年度我院招生录取工作。希望大家严格执行招生录取工作有关规定，规范工作流程，坚持站好招生录取工作这班岗，确保学院招生录取工作安全、稳定、有序进行，给考生、学院和社会交上一份满意的答卷。
