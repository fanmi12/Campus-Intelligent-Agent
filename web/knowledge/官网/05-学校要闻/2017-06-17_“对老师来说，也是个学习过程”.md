# “对老师来说，也是个学习过程”

在6月12日、13日举行的总决赛中，我院邓思如同学荣获本届大赛本科组一等奖,我院荣获“优秀组织高校奖”，我院招生就业处就业中心主任、大赛总负责人江小卫荣获“优秀组织者”奖，指导老师苗琳老师荣获“优秀指导老师奖”等获得集体和个人四项大奖。

为此，记者特地采访了“优秀指导老师奖”

获得苗琳老师。

记者：苗老师，就指导参赛选手方面，谈谈您的心得体会

苗琳：我一直认为，每一个学生都会绽放出不一样的烟火，只要给他一片夜空。有幸作为邓思如同学的指导老师，一路上相伴相辅。对备战大赛而言，最深刻的感受便是要做学生的“良师益友”，不仅要在专业知识上给予她最前沿、最创意的理论知识指导，更重要的是要有一颗平等而互相尊重的心灵合力！

在大赛指导中，经验也弥足珍贵：要做到“谋在创意，重在经验，赢在坚持”；学生的核心竞争力需要挖掘加以放大；优秀选手的经验需要学习，所谓师夷长技以制夷；最后，再苦再累需要坚持，笑到最后的才是真正的赢家！

当然，教学相长是不断进步的过程，作为老师也是学习的过程。

记者：这次大赛，邓思如同学获得了本科组一等奖。您对她还有什么话要说？

苗琳：思如同学是个坚强乐观笃实好学的女孩子，除了对她的恭喜和祝福外，希望她在规划里有一个有趣的人生，送她一句最喜欢的话：“愿你走出半生，归来仍是少年。”
