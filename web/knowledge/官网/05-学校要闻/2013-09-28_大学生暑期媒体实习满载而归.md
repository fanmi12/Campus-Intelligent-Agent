# 大学生暑期媒体实习满载而归

9月25日，我院新闻中心在教学楼7B312举行2013年大学生暑期媒体实习总结汇报会，为本次暑期媒体实践活动划上圆满句号。南方日报、南方都市报、南方网、寮步电视台等媒体记者应邀出席了汇报会。40名大学生记者团暑期实践分队队员、城院学生媒体中心成员、城市绿洲报社记者参加会议，分享了暑期媒体实习的体会。

汇报会对在暑期实习期间表现优异、工作出色的9名同学被评为媒体实习实践活动积极分子。他们分别是财经系陈鹏、城环系欧迪鹏、文传系孙宇涵、尹婉媚、谢燕娴、张巧玲、周蔚余、杜静欣、刘若筠等同学。

党委宣传部部长何鹏举教授发言致辞。他认为暑期实践活动的成功在于学院领导、老师、实习单位的支持与团队的配合，也有实习生个人的努力。并表示会将这一活动作为学院的品牌文化和实践活动持续做下去，为同学们提供发展自己、认识社会的优质平台。

据汇报会介绍，大学生记者团暑期实践分队共40人，分别在南方日报、南方都市报、信息时报、新快报、南方网、东莞阳光网、寮步电视台共7家媒体单位实习，共采写发表了486篇新闻报道，内容涉及经济、政治、文化等各个方面，包括“2013东莞动漫展”、“东莞新攻辩”等大型项目。南方都市报一家媒体就接收了我院14名实习同学，南方都市报首席记者 饶德宏对他们的工作高度赞扬，尤其夸奖史晓然同学，认为她悟性很高，行文很快，能跑敢跑，已具备新闻记者的基本素质。

汇报会后，同学们还分小组进行了分享活动。各媒体记者现场进行了指导和点评。南方网东莞站主任陈伟赞、南方日报记者吴少敏、东莞寮步电视台记者也李连苏称赞我院实习生动手实践能力较强、写作水平高、主动肯干，也给同学指出了以后继续努力的方向，并对实习过程中的一些细节作了说明和分析。实践分队队长陈鹏同学认为，本次实习总结会，让参加实践的同学更加认识到暑期进媒体参加实践的目的意义，互相学习了经验，也让其他没有参加本次实践的同学有了了解和学习的机会。

据悉，学院新闻中心专门为参加暑期媒体实践的同学编印了《2013年暑期媒体实习心得汇编》和《2013年暑期媒体实习成果汇编》。
