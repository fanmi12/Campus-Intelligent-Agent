# 教职工代表民主测评机关、教辅部门的工作

机关、教辅部门今年的工作怎么样？教职员工满意不满意？12月26日，学院在学术报告厅召开民主测评会议，请各系部教工代表、特邀民主党派与无党派代表，对机关、教辅部门2012年的工作测评打分。

院办、组织人事处、学生处、教务处、新闻中心、财务处、总务处、就业指导与培训中心、图书信息中心等单位的负责人，分别向大会报告了本单位2012年的工作成绩、经验与体会、存在的问题，以及将来的工作打算。

接着，与会代表根据各单位的工作报告进行评分与投票。

党委副书记、工会主席章德胜主持会议。

党委书记朱志德做主题讲话。他指出，对机关、教辅部门的工作进行民主测评，是我院一项常规工作，至今已坚持了8年。经验表明，民主测评是实行民主治校、民主管理的一项重要举措，有利于增强机关工作人员的服务意识和竞争意识；有利于改善机关作风，提高办事效率；有利于机关去行政化，克服机关门难进、脸难看、事难办的衙门作风。朱书记表示，这次测评结果，将张榜公布，并与工作绩效考核挂钩。
