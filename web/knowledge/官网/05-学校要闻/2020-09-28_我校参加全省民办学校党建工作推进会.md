# 我校参加全省民办学校党建工作推进会

9月28日下午，广东省委教育工委召开全省民办学校党建工作推进会，我校在行政楼401会议室设立分会场，学校党政领导班子全体成员、组织（统战）部、宣传部及有关部（处）负责同志参加了视频会议。

会上，广东科技学院、广州城建职业学院等六个基层单位进行了经验分享。

省委教育工委副书记、教育厅党组副书记李大胜充分肯定了各民办学校党建工作，梳理党建工作开展过程中存在的问题和薄弱环节，并指出整改方向。他强调要深入贯彻学习习近平新时代中国特色社会主义思想，根据中央、省市有关文件精神，充分发挥民办学校党组织的政治引领作用，完成好民办学校党的建设工作重点任务，结合实际抓好工作落实。

省委教育工委委员、教育厅副厅长那佳强调，各民办学校要传达学习贯彻好会议精神，狠抓工作落实，列时间表，画路线图，对标重点任务逐条逐项开展，充分发挥党组织的战斗堡垒作用和党员干部的先锋模范作用。要坚持党建引领和疫情防控两手抓，强化政治站位，筑牢学校安全防线，做好党建工作、疫情防控、教育教学、思想政治教育、学生工作、后勤保障、社会服务等工作。

会议总结交流了全省民办学校党建工作经验，部署今后一段时期全省民办学校党建工作重点任务，推动民办学校进一步加强基层党建工作，提升基层党组织规范化制度化水平，落实民办学校规范达标计划，为实施民办学校品牌提升计划、办人民满意教育提供坚强的组织保障。
