# 【2015运动会花絮七】文传女汉子不让须眉

文传女汉子不让须眉20日上午，各类赛事正在火热进行中。

“各就各位！砰！”枪声一响，在女子100米跨栏赛上，选手们就如脱弓之箭一样飞奔出去了。“加油！加油！”啦啦队的呐喊声振奋人心，选手们跑得更快了。

“摔倒了，有人摔倒了！”人群中焦急的声音响起，原来是文传系的一位女生在跨栏的时候不小心摔倒在地。但她并没有放弃比赛，她挣扎着站起来，面带倔强，又开始冲向终点了！

她就是2013级文传系商务英语专业的谢怡婷。在受伤后，她依然一直是面带微笑，“既然参加了比赛，就要坚持把它跑完。”在上午的400米女子决赛中，带伤上阵的她获得了第三名的佳绩，这种顽强拼搏的精神令人敬佩！ (黄钰然)

勇往直前，一“钻”到底20日下午,运动场下起了蒙蒙细雨，但这丝毫没有减弱健儿们的运动热情。在主席台前的橡胶跑道上，正举行一项非常有趣的运动项目——学生组勇往直前！比赛还未开始，赛道两旁便挤满了观众，都在等着“好戏”开场！

比赛中最引人注目的，当属“钻洞”了。只见工作人员在跑道上平整地铺置着四张蓝色塑料制成的“洞”，一声令下，两男两女迅速低头钻进洞口内再钻出。瞧！动作最快的当属一个身材瘦小的女生了，在其他选手还困在洞内苦苦挣扎之际，她已迅速脱离“洞”口，朝下一个关卡迅速奔去。

这充满趣味与活力的一幕幕，不仅给运动会增添了一道不一样的色彩，更给观众们带来许多轻松与快乐，也展现了我院大学运动生活的多姿多彩！ (胡越余)

那旗帜，挥舞的是热血青春

闭幕式结束的那一刻，旗手们手舞系旗，在跑道上纵情狂奔!轻雨微风，不能阻挡他们的热血，在他们运动会的最后时刻，用一面面挥舞着青春热血的旗帜，为本次校运会写下完美的句号。

在运动会上，每当运动员在赛道中飞驰时，他们总会高举大旗，划出一道道红色的风暴，为运动员们助威。虽然，他们不是运动员，但他们也同样有一颗张扬青春、为集体争光的心。他们是旗手，系旗是他们坚守着的岗位。他们挥舞着的旗帜，就是运动员们努力拼搏的动力。（张雨霆 吴炳然 ）“铁人”大一新生杨立柱

撑开雨伞遮住头部，疲劳得就这么睡在操场上。2015级管理系杨立柱同学在这次校运会，可谓把“铁人”精神发挥得淋漓尽致。他参加的三项考验耐力比赛都获得不错的名次，其中4X800米接力赛获得第一名，400米赛跑第三名，800米赛跑第四名。

“都是选择适合自己优势的项目才报的，自我感觉耐力比较好。”他还透露，没报铁人五项，是因为没有了解清楚这个项目，所以只好明年才报。让我们一起期待杨立柱明年的出色的表现吧！（莫琳）

暖心的搀扶，胜过千万句鼓舞

也许，对于在赛场上驰骋之后的运动员而言，最感动的不是站在领奖台的一瞬，而是在他们拼尽全力之后，总有几个暖心的小伙伴搀扶着你，陪你度过激烈后的恍惚。

在运动场上，我们经常看见这样的场景：运动员们拼尽全力完成最后的冲刺，到达终点后，同学们立即拥上前来，拭去运动员头上的汗珠，扶着他们慢慢踱步，帮助他们从激烈的比拼中恢复过来。

那一刻，所有的疲惫都被暖心的友情驱散，所有的不适都因贴心的同学情谊逐渐变好。这，便是友情的力量，团结的力量。（卢文斌）

快乐分享

“谁在最需要的时候，轻轻拍着我肩膀？谁在最快乐的时候，愿意和我分享……”也许，朋友就是这样，在你最需要的时候安抚你的伤口，在你最开心的时候和你分享你的喜悦。

一声声银铃般的笑声回荡在运动场，一张张青春的笑脸点缀着整个赛场。一个人的胜利是集体的狂欢，一个人的快乐也可以集体分享，赛场上的你，并不孤独！（卢文斌）

奋力一搏，挑战自我11月20日上午，学生组男子铅球赛场上，一位被观众所看好的重量级选手闪亮登场。然而，在他坚定的目光中有着一丝担忧。当他扔出铅球的一瞬，眉头紧皱，表情狰狞，最终只扔出了7.29米的成绩，却赢得场上观众的掌声。

原来，这位重量级选手是来自2015级文传系的谭浩同学，几天前为了校运会努力训练时，右手不小心受了伤，加上在昨日的拔河比赛上执手一搏，新伤旧痛一并爆发。尽管如此，谭浩并没有因此而放弃铅球比赛，而是勇敢地走上赛场，奋力一搏，为的就是给自己一个交代！（卢文斌）
