# 捷报！我校摘得省大学生跆拳道锦标赛一金一银三铜

11月14日，广东省大学生跆拳道锦标赛在中山大学珠海校区举行。作为省内大学生跆拳道最高级别赛事，共吸引了全省42所高校的750位运动员参赛。我校跆拳道代表队展现出强劲实力、百折不屈的精神，共斩获1金1银3铜等7枚奖牌，取得了团体总积分第五名的优异成绩。

跆拳道作为奥运会的常驻项目之一，具有独特的赛制和排名方式：单项角逐金银铜牌，最终以获奖名次计算出相应的团体积分。在指导老师王煜的带领下，我校代表队本次获得的奖项分别是：跆拳道校队品势第一名、竞技第二名、第三名等；社联跆拳道协会品势第三名、第五名、第七名；艺术团跆拳道队竞技第五名，品势第七名、第八名；男子团体品势第三名，男女混双第五名。
