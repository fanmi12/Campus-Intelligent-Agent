# 学校2020届毕业生就业工作第二次推进会召开

为了传达广东省推进高校毕业生就业工作电视电话会议的重要讲话精神，切实保障疫情期间我校2020届毕业生就业工作扎实推进，5月15日下午，我校在行政楼212会议室召开了2020届毕业生就业工作第二次推进会。校长王卫平，党委书记章德胜，各二级学院院长、副书记，相关职能部门负责人、就业中心全体人员参加了会议。会议由学生处处长杜鹏举主持。

校党委书记章德胜强调：第一，各二级学院领导班子要强化做好毕业生就业工作的政治担当；第二，各二级学院针对自身的专业特点和优势，分析研判，落实相应的就业工作方案；第三，面对就业定位不够清晰、犹豫而错过就业机会的毕业生，要落实“人盯人”制度，逐一解决；第四，加强本学院对就业数据上报工作的重视程度，保证就业数据精准和真实性。

校长王卫平针对就业工作提出要求：第一.强化组织领导。各二级学院就业工作小组要加强组织领导，广泛动员各专业教师参与到就业工作中。第二.优化分工合作。通过周期性会议、就业工作台账等形式，加强领导小组对实时工作的了解，强化网格化管理，分工合理，形成合力。

杜鹏举处长通报了目前广东省本科平均就业率、我校就业率以及各二级学院就业率的情况。提醒各二级学院要高度重视毕业生就业工作，找差距，抓落实；各学院就业工作小组要合理分工，明确职责，避免出现互相推诿的状况；就业工作人员应该积极主动，熟悉就业政策和操作流程，完善“辅导员-班主任-毕业生”联动模式，层层压实。

下一阶段我校就业工作将进一步下大力气，拓宽高校毕业生就业渠道， 精准开展高校毕业生就业服务，做好困难毕业生帮扶，鼓励毕业生自主创业，落实好毕业生就业“百日冲刺”行动。
