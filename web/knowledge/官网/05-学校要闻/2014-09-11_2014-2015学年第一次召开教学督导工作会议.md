# 2014-2015学年第一次召开教学督导工作会议

9月9日，学院在行政楼207会议室召开本学年第一次教学督导工作会议。院党委书记王卫平教授，院督学陈丁堂教授与全体教学督导员及督导办公室工作人员出席了会议。

会上，副主任王锦锋副教授宣读了东莞理工学院城市学院《关于聘任2014-2015学年度教学督导员的通知》，王卫平书记为各位兼职督导员颁发聘用证书。专职督导员聂映中教授对上学期的督导工作进行了总结，并对本学期的督导工作要点及要求作了具体说明。

院督学陈丁堂教授进一步阐述了我院督导员工作的指导思想与具体要求。他指出：我院各级领导重视督导工作。过去一学年专职督导员尽心尽责，认真督教、督学与督管，对学院工作提出了许多中肯的意见和宝贵的建议，对落实杨院长提出的“提升张力，确保质量”起到了很好的建设性作用。

陈督学在讲话指出，我院的督导工作坚持“以导为主的原则”，着力发现、总结、推广教师中的先进教育教学经验，反映广大师生员工的心声。这一指导思想符合上级要求，得到了广大教师的支持。一批老教授担任督导员后成了青年教师的良师益友，受到青年教师的尊重与爱戴。今后我们要继续坚持“以导为主”的督导工作原则。陈督学还指出：“以导为主”并不是不要监督，对于教育教学中存在的一些不良现象和突破师德底线的不良行为要及时督查，严肃处理。这也是对学院、对教师、对学生负责任的一种表现。

王卫平书记在会上发表了重要讲话。他对我院督导工作给予了热情的肯定，代表学院对各级督导员表示衷心的感谢！他在讲话中指出，我院督导工作要进一步把工作重点放在课堂教学的督导上，着力于规范教学行为和管理行为。督导员要及时反映广大教师的心声，做广大教师的良师益友。王书记还对督导员的工作、生活表示了热情具体的关心。王书记的讲话博得了督导员的热烈掌声。
