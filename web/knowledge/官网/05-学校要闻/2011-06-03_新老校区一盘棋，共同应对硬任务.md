# 新老校区一盘棋，共同应对硬任务

会场安院长强调：理顺体制，建设新校区，使城市学院迎来新一轮的大发展。

城市学院副院长、新校区管委会主任杨敏林(左一)，新校区管委会副主任朱冰(图中)、麦绮琳(右一)

“城市学院中层干部和全体教职工，要以确保九月份新生进驻新校区为硬任务，紧急动员，整合资源，周密安排，全力做好延伸管理工作。”6月2日，我院在315会议室召开中层干部会议，传达董事会二届四次会议和城市学院管委会5月24日的主任办公会议精神，宣布重要人事决定，动员和组织教职工做好延伸管理工作，确保董事会提出的“9月份新生进驻新校区”硬任务的完成，安排部署期末主要工作。

党委书记朱志德主持会议并传达董事会二届四次会议的决议和城市学院管委会主任办公会议纪要。据传达，董事会决定聘任杨敏林为城市学院副院长；城市学院管委会决定成立新校区管委会，杨敏林任新校区管委会主任，城市学院党委副书记朱冰、鸿发集团麦绮琳任副主任。管委会主任办公会议还重点讨论研究了新校区延伸管理模式及日常管理架构等问题。

东莞理工学院副校长、城市学院院长安少华在会上着重强调了三个问题：一、市委市政府、东莞理工学院党委行政、城市学院董事会十分关心和支持城市学院谋求更大的发展。把城市学院做大做强做出品牌是各级领导和东莞人民共同的心愿。新校区从征地、拆迁到动工建设，工作之顺，速度之快，标准之高就充分说明了这一点。我们要十分珍惜和维护城市学院发展大局。二、新校区管委会的成立，领导力量的加强，是建设好、管理好新校区的一个重大举措。经验表明，这种管理模式适应于一校多区的情况，可以起到管理到位、责任到人、效率提高之目的。城市学院新校区管委会在城市学院党政领导下，负责新校区的全面工作。城市学院要对城市学院管委会、董事会、东莞理工学院负责。城市学院党委要坚决接受东莞理工学院党委的领导。这次东莞理工学院、鸿发集团、城市学院选派的三位同志，工作能力强，经验丰富。杨敏林同志具有教授、博士的职称和学历，曾先后担任东莞理工学院新老校区、城市学院新校区的筹建办主任。麦绮琳从国外知名大学留学归来，为人谦和，办事认真细致。三、理顺体制，建设新校区，将会使城市学院迎来新一轮的大发展。安院长在简要总结回顾城市学院八年的办学历程、成绩、体会和问题，以及董事长麦照容的办学理念、处事风格和人生追求时指出，要实现新一轮的发展，必须在观念、体制、模式上有所突破、有所转变、有所创新。

关于期末的工作和新校区的延伸管理，安院长向全院教职工提出两点要求，一是要认真履行好新校区的建设和管理职责。正确处理好新老校区的关系，正确处理好“迎评促建”工作与新校区的建设、新生开学工作的关系。他指出，新校区顺利开学，是“迎评促建”工作的前提条件；“迎评促建”顺利通过，是城市学院的最大品牌。学院全面工作包括教学教务、学生管理、财务人事、图书信息等都要向新校区延伸，各单位、各部门要积极主动做好延伸工作。为了稳定、发展大局，新老校区之间不分你我，做到新校区要人给人、要物给物、要钱给钱。二是全力做好毕业生离校、期末考试、学位证颁发、招生就业、师资培训、人才引进及开学准备工作。

城市学院董事、鸿发集团副总裁黎建烨在讲话中，简要介绍了新校区的筹建情况及鸿发集团近期的发展战略设想。他表示，城市学院实行董事会领导下的院长负责制，新老校区“两位一体”都是城市学院，实行统一的领导和管理，现任院长负总责，分管领导负直接领导责任。希望中层干部要树立新老校区“一盘棋”、”一体化”的工作思想，通盘考虑，整体推进，把好的作风带到新校区，让工作向新校区延伸。

新任副院长杨敏林在会上表示，感谢东莞理工学院和董事会的信任，感谢城市学院教职工的支持，将尽全力做好本职工作，为学院谋发展，为教职工谋福利。
