# 学校党委理论学习中心组开展革命传统教育

7月4日，学校党委理论学习中心组到广东东江纵队纪念馆开展革命传统教育，深入学习领会习近平总书记关于党的革命传统的重要论述，进一步传承红色基因，赓续共产党人精神血脉，推动党史学习教育走深走实。校领导章德胜、王卫平、高香林、黄兢、刘玉侠，党委委员杜鹏举、孔增强、李海冬、卢淑芳，党史学习教育领导小组办公室相关负责人参加活动。

东江纵队纪念馆是一所纪念广东人民抗日游击队东江纵队的专题纪念馆，是广东省爱国主义教育基地、红色旅游示范基地、国防教育基地、党史研究基地，2014年被列入首批国家级抗战遗址名录。

广东人民抗日游击队东江纵队和以其为基础发展建立起来的中国人民解放军两广纵队和粤赣湘边纵队，是中华民族优秀儿女组成的人民革命武装。在反抗日本帝国主义侵略和争取民族解放的伟大事业中，这支人民革命武装在中国共产党的领导下经受了革命战争的洗礼和考验，建立了不朽的功勋。在抗日战争时期，东江纵队孤悬华南敌后，立下了辉煌的战绩。他们在异常艰苦的条件下，由200多人的游击队伍发展壮大为拥有11000多人的抗日武装力量，作战1400多次，毙伤日军、伪军6000多人，被称为“广东人民解放的旗帜”。1945年，朱德总司令在中共七大军事报告《论解放区战场》中将东江纵队、琼崖纵队与八路军、新四军并称为“中国抗战的中流砥柱”。

学校党委理论学习中心组一行在东江纵队纪念馆内，认真聆听革命故事，仔细瞻仰一幅幅历史照片和珍贵的革命文物，深入了解东江纵队武装抗日的艰难历程，共同缅怀革命先烈的崇高革命精神。

随后，面向鲜红党旗，校党委书记章德胜带领全体成员重温入党誓词。铮铮誓言表达了对党的忠诚和为共产主义事业奋斗终身的坚定信仰。
