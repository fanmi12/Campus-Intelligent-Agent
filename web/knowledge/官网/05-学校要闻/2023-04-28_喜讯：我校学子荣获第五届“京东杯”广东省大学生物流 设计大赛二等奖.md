# 喜讯：我校学子荣获第五届“京东杯”广东省大学生物流 设计大赛二等奖

近日，在

广东省教育厅指导，广东省本科高校物流管理与工程类专业教学指导委员会、广东省物流与供应链学会、广东省电子商务协会主办的第五届“京东杯”广东省大学生物流设计大赛决赛

上，我校百事顺风队《农产品溯源平台服务》创业项目，同全省20余所高校同台竞技，获得二等奖殊荣。

本次大赛围绕

“一带一路”及粤港澳大湾区建设、国内国际双循环新发展格局构建，针对物流与供应链、电子商务、交通运输、港口与航运等领域发展的焦点、热点及难点开展创新研究，设计创业方案。我校物流管理专业师生在商学院精心部署下，动员师生积极组队参赛。最终我校百事顺风队《农产品溯源平台服务》创业项目，同全省20余所高校同台竞技，经过两轮复赛评审，在60多支队伍中脱颖而出，挺进决赛。

在决赛环节中，队长黄奥林同学（2020级物流管理专业1班）代表团队进行了7分钟汇报展示，其他成员李彩文（2020级物流管理1班）、刘慧媛（2020级物流管理1班）、包海燕（2020级工商管理1班）、于佳鑫（2020级工商管理1班）积极回答

来自不同高校教授和企业高管组成的评委提问。整个答辩过程我校学子沉着应变，冷静思考，积极应答，最终获得二等奖殊荣。

百事顺风团队能取得二等奖成绩，得益于物流管理专业全体老师在指导学生学科竞赛方面沉淀的多年丰富经验。夏良华教授在学生校内模拟答辩的时候给出了非常多的建设性意见，洪树权、熊小婷、邹亮、胡丽艳老师从方案撰写、PPT制作、答辩技巧方面倾囊相助。指导教师团队史祎馨、张洪、赵影老师也全程陪同学生修改方案、集思广益。总之，此次省赛二等奖的成绩是我校物流管理一流专业建设的成果之一，体现了我校师生在专业领域的能力与风采。

据了解，广东省大学生物流设计大赛对标全国大学生物流方案设计大赛（教育部学科竞赛目录赛项），每两年举办一次，是由广东省教育厅指导，广东省本科高校物流管理与工程类专业教学指导委员会主办年的一项物流管理专业学科竞赛。从2015年开始设立，已成功举办了四届，旨在培养学生的创新精神、创业意识和创新创业能力。在广东省本科院校物流管理专业学科竞赛中形成广泛影响力，是各高校物流管理与工程类专业师生公认的“省级物流奥赛”。
