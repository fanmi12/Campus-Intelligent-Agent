# 我院3名青年教师获赴清华大学等校访学资助

近日，从省教育厅相关文件中获悉，我院林岩、李玲玲、张灿灿3位老师获得了2013年广东省高等学校中青年教师国内访问学者计划的资助，分别被清华大学、广东外语外贸大学、中南财经政法大学录取为访问学者。

今年，我省加大了青年教师国内访问的资助力度，最高每人可资助2.5万元。此次亦是我院首次获得这一资助。

据悉， 广东省高等学校中青年教师国内访问学者计划既是贯彻落实省政府关于全面实施“强师工程”，建设高素质专业化教师队伍的重要举措，也是充分利用国内优质资源培养青年骨干教师的重要途径。2013年广东省共有20名教师获教育部高等学校青年骨干教师国内访问学者项目资助，432名教师获广东省高等学校中青年教师国内一般访问学者资助。
