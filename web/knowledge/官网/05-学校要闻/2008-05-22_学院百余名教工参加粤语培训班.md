# 学院百余名教工参加粤语培训班

为使非粤籍教工克服粤语方言的听说障碍，更好地融入东莞，学院工会昨日举办了教工粤语培训班。截至开班前，共有120多人报名参加培训。

5月21日，培训班初级班在2209课室首次授课。平时在讲台上口若悬河的教师们此时都成为牙牙学语的学生，跟着老师练习粤语发音。

据工会负责人介绍，培训班的教学内容将融合现代生活的礼仪交往、生活起居、职业工作以及文体娱乐等各方面的惯常用语，通过系统学习，使学员了解到粤语的发音规律，能够进行日常生活对话，并在追寻粤语的渊源时学习到相关的历史、习俗、典故等知识。

据悉，学院为每位学员提供粤语培训教材，授课教师为本校教师陈东汉（一班）和刘红艳（二班）。培训班上课时间为：周三下午17：00——18：00（一班），每周四下午17：00——18：00（二班）。欢迎广大教工参加培训班学习。
