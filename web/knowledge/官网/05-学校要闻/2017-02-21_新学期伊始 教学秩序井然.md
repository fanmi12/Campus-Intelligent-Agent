# 新学期伊始 教学秩序井然

2月20日，新学期正式开课，院长王卫平、副院长高香林等院领导，教务处、督导办、各院系（部）等部门领导对课堂教学情况进行了全面检查。

当天，全院教学秩序良好，教师教学准备充分、讲课有热情，课堂效果好；学生能按时到课，精神饱满，认真听课；各教学场地的教学设施、设备运行正常。

据悉，为保证新学期顺利开学，各单位做了大量的准备工作。教务处分别组织院系（部）主任及教学秘书召开了教学工作会议，对新学期教学工作等进行了布置安排；教务处、实验中心、后勤保卫处等部门还对学院教学楼及各实验、实习场地的设施、设备进行了全面检查；各院系（部）领导也高度重视，精心做好各项工作，确保了新学期各项教学工作的顺利开展。
