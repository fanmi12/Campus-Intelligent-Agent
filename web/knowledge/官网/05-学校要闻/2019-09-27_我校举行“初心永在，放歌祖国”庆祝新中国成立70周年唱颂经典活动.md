# 我校举行“初心永在，放歌祖国”庆祝新中国成立70周年唱颂经典活动

为热烈庆祝中华人民共和国成立70周年，9月26日下午，我校隆重开展“不忘初心、牢记使命”主题教育—— “初心永在，放歌祖国”唱颂经典活动。学校党政领导班子，全体教师和各二级学院学生上万人参加了活动。

金秋时节，阳光灿烂，风清气爽。校园内，处处挂满了鲜艳的五星红旗，洋溢着浓浓的庆祝新中国70华诞的喜庆氛围。一幅巨型的五星红旗悬挂在图书馆正门的蓝色玻璃幕墙上，成为学校的网红圣地。

下午16时，从图书馆小广场到映月湖桥上，延伸至秋枫广场，国旗飘扬，二级学院几千名学生组成的10个方阵身着红色衣衫，整齐排列，连成了一片红色的海洋。

16时30分，学校党委书记章德胜同志为活动致辞。他深情地说，“风雨砥砺，岁月如歌，70年披荆斩棘，70年风雨兼程，我们即将迎来伟大的中华人民共和国70华诞。学校隆重举办‘初心永在，放歌祖国’唱颂经典活动，旨在坚定全校师生对马克思主义的信仰、对中国特色社会主义的信念，激发爱党爱国的革命情怀，传承红色基因，增强‘四个意识’，坚定‘四个自信’，做到‘两个维护’，自觉在思想上政治上行动上同以习近平同志为核心的党中央保持高度一致，始终忠诚于党、忠诚于人民、忠诚于伟大的祖国。”

章德胜书记号召全校师生以奋发有为的精神状态、真抓实干的工作作风，勇于创新、开拓进取，朝着中华民族伟大复兴的光辉彼岸，继续破浪前行！用嘹亮的歌声把最美好的祝福送给华夏大地，祝愿伟大的祖国更加繁荣富强。

随着王卫平校长宣布“东莞理工学院城市学院‘初心永在，放歌祖国’唱颂经典活动开始”，学校全体教师身着正装，站在图书馆台阶上，个个精神昂扬，挥舞着小国旗，放声高歌——《不忘初心》：“你是我的一切我的全部

向往你的向往 幸福你的幸福

不忘初心 继续前进万水千山最美中国道路……”

嘹亮的歌声，拉开了“初心永在、放歌祖国”活动的大幕！

在雄壮的歌声中，穿着墨绿色戎装、英姿飒爽的学校国旗护卫队手持鲜红的五星红旗，迈着庄严、矫健的步伐，缓缓向秋枫广场走去……

当学校国旗护卫队走来时，艺术学院方阵的同学个个洋溢着无限的青春活力，一首《歌唱祖国》，专业而饱含深情，唱出年轻学子对祖国的无比热爱。

随后，全场师生共同放歌，唱响《我和我的祖国》：“我和我的祖国

一刻也不能分割

无论我走到哪里

都流出一首赞歌……”

红色的海洋沸腾了，响彻校园的歌声，唱出了全校师生的款款爱国深情！

随后，校领导和教师们纷纷来到二级学院学生队伍当中，和同学们一起高声放歌。《国家》《故乡的云》《龙的传人》《走向复兴》《在灿烂阳光下》《走进新时代》《春天的故事》《我的中国心》，一首首经典的爱国歌曲逐次在校园中响起，将全校师生喜迎新中国成立70周年的喜悦之情，尽情地表达在嘹亮的歌声之中！

“我爱你，中国！我爱你，中国！我爱你，中国！”，活动在一万多名师生向祖国母亲告白声中圆满落下帷幕！“初心永在，放歌祖国”庆祝新中国成立70周年唱颂经典活动的成功举办，必将进一步坚定全校师生的理想信念，振奋精神士气，推动学校各项工作取得新业绩、再上新台阶、开创新局面。
