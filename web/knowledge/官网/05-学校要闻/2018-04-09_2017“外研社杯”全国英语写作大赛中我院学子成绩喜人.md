# 2017“外研社杯”全国英语写作大赛中我院学子成绩喜人

近日，我院外语系45名学子在2017“外研社杯”全国英语写作大赛初赛中喜获佳绩。其中，梁桂芝、潘琪琪同学荣获特等奖。

本次大赛是由外语教学与研究出版社、教育部高等学校大学外语教学指导委员会、教育部高等学校英语专业教学指导分委员会和中国外语与教育研究中心联合主办，旨在提升大学生英语写作能力并引领高校外语教学的改革与发展。

大赛启动以来，外语系学子积极备战，共有45名同学获得了优异的成绩，充分展示了外语教育教学成果和学子风采。

获奖名单如下：特等奖：梁桂芝、潘琪琪

一等奖：黄颖因、杨丹琳、刘珊珊、陈颖诗

二等奖：莫晓敏、苏冰珊、刘晓君、黄锦标、陈婕、王子欣、黎仙银、王永君、叶倩如、谭炜杰、袁芷晴、郑嘉怡、符娜莉；

三等奖：蔡晓彤、严志成、龙晓璇，陈梓键、陈琳镕、严钰瑶、黄振杰、黄美雪、吴惠丹、邓慧英、吴汝轩、林雯静、徐嘉欣、卜依祯、张家文、郑翠珊、覃梦怡、李金穗、张靖怡、潘楚欣、陈冲。
