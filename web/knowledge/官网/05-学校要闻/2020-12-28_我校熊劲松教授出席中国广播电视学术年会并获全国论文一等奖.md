# 我校熊劲松教授出席中国广播电视学术年会并获全国论文一等奖

2020年12月17日，2020年度中国广播电视学术年会在广东省中山市召开，我校文学与传媒学院熊劲松教授受邀参加年会，撰写的主题征文《论新闻扶贫对革命老区振兴的独特作用》荣获全国论文一等奖。

年会邀请国家广电总局、中广联合会、广电媒体、高等院校的领导、专家、学者从不同角度作深入演讲，由中广联合会城市广播电视学术研究基地进行融合案例分享，向主题征文获奖作者颁奖。我校教授熊劲松撰写的《论新闻扶贫对革命老区振兴的独特作用》荣获全国论文一等奖。

熊劲松教授毕业于中国社会科学院研究生院，现为东莞理工学院城市学院文学与传媒学院教授。曾荣获全国广播电视“百优”理论人才称号。现为中国范仲淹研究会理事、中国历史唯物主义学会理事、中国广播电影电视社会组织联合会会员、中国电视艺术家协会会员、湖南省新闻系列高级职称评审委员会评委、湖南新闻奖评审委员会评委、广东省精神文明学会副秘书长。先后在《中国广播电视学刊》《中国新闻年鉴》等刊物发表学术论文80多篇，出版学术专著3部，《电视传播兴奋点》荣获全国广播电视学术著作评比二等奖。主要研究方向为新闻传播、影视艺术、毛泽东思想研究，主讲影视文化、创意写作等课程。

本届中国广播电视学术年会由中国广播电视社会组织联合会和中山广播电视台联合主办，旨在回顾总结“十三五”时期的广播电视理论研究工作，规划部署“十四五”时期广播电视理论研究工作。

中国广播电视社会组织联合会会长范卫平，中广联合会副会长、广东广播电视台台长蔡伏青，中广联合会副会长兼秘书长黄炜，国家广电总局机关服务局副局长刘新航，国家广电总局发展研究中心副主任杨明品，中国广播电视社会组织联合会副秘书长周然毅，中国人民大学教授郑保卫，广东省中山市副市长徐小莉等领导以及来自全国广播电视业界、学界代表共170余人参加了会议。
