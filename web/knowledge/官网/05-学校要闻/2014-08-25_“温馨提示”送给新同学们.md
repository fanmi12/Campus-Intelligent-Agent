# “温馨提示”送给新同学们

新生入学时间日益临近。今年９月我院将有5000多名新同学跨进城市学院的大门，开始四年的大学生活。城市学院热烈欢迎新生的到来。

为确保新生的平安到来，根据上级教育主管部门的指示精神，学院有关部门提醒新同学注意：

1、即将入学的新同学，要调适好心情，做好入学前的准备工作，以全新的姿态迎接新的学习任务。

2、新生及家长要认真阅读我院编印的《新生入学安全知识手册》，增强安全意识，注意上学途中的安全，防止意外事故的发生。该册子已同录取通知书一并寄送。

3、谨防诈骗。关注学院官方信息，不要轻信社会上的虚假广告，以防止上当受骗。不要参加传销活动。

4、录取通知书及贵重行李应在报到时随身带来，不要交给快递公司投寄，以免丢失。

5、学费应通过银行划转到城市学院专户账号，尽量不要携带过多现金。
