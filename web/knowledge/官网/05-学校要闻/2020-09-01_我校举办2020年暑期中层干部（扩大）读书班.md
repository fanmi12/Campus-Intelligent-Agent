# 我校举办2020年暑期中层干部（扩大）读书班

8月30日

-31日，我校举办2020年暑期中层干部（扩大）读书班。本次读书班旨在

凝聚共识“深学习”，践行使命“再谋划”，统一思想、抓住机遇，迎接挑战，开创学校发展新篇章。

校领导，董事长代表，校内各单位正副职、教研室主任、院长（处长）助理，各党总支（直属支部）书记、副书记参加了读书班

研讨活动。

东莞理工学院马克思主义学院执行院长唐元松教授应邀作了《习近平谈治国理政》（第三卷）学习导读，从权威著作怎么学的角度，讲解了19个专题92篇文章的相关内涵。深入学习贯彻习近平新时代中国特色社会主义思想，是全党一项长期的重大政治任务，是广大党员干部的基本功、必修课。要学好用好《习近平谈治国理政》，领会精髓要义，紧密联系实际，把学习成效转化为增强“四个意识”、坚定“四个自信”、做到“两个维护”的具体行动，转化为应对风险挑战、推动事业发展的能力和水平，全力投身决战决胜全面建成小康社会、乘势而上全面建设社会主义现代化国家的伟大实践。

章德胜书记作了题为《不忘初心谋发展

砥砺奋进谱新篇》的书记工作报告。报告提及省教育厅厅长景李虎在全省高校领导干部读书班上的11问，章德胜书记指出要加强党对高校的全面领导，“用高水平党建引领高校高质量发展。”强化问题导向，不断提高党建和思想政治工作水平。要坚持理论学习不松懈，学深悟透并落实在行动上；要抓好意识形态工作，高度重视意识形态安全；要着力构建新时代“大思政”育人体系，把立德树人贯穿于教育教学、服务管理全过程，努力实现新时代高校人才培养新作为。

王卫平校长作了学校工作报告，总结了2019-2020学年党建工作、体制机制改革、教育教学工作改革、学生工作发展、转设准备工作、疫情防控工作等重点工作的完成情况，对下学年重点工作提出了构想和思路。

读书班上，职能部门负责人代表、教务处处长赵书山作了《疫情时代我校教育教学改革》报告，分析了我校线上教学工作的开展情况，结合时代大背景，提出应坚持

“互联网+”的线上线下教学模式，同时学校教育教学、专业课程设置和人才培养模式等要符合时代诉求，要注重挖掘“互联网+”“人工智能大数据”和专业匹配度，应变而变，推动我校教育教学改革，打造真正意义上的“新工科”“新文科”。

学生处处长杜鹏举就《新时代中国特色社会主义高校育人体系

——三全育人》向在座中层干部，分享了三全育人的“育人目标”“育人理念”，根据十项对标标准，讲解了“三全育人”综合改革试点工作实施方案，提出要以新思政观引领改革，构建一体化育人体系，打通育人“最后一公里”，切实做足育人大文章，唱响育人最强音。

人事处处长李海冬作了《民办高校体制机制改革思考》报告，从民办高校的体制和机制、民办高校体制机制的优劣势、基于人事制度的民办高校体制机制改革体系这三个方面提出了新思考，人事工作改革要朝着下放二级管理权限，调整人力资源管理理念，建立一整套科学合理的适合现代大学发展的人力资源管理制度，以及创新人才动力机制，建立导向明确、精准科学、规范有序、竞争择优的人才考核评价机制等方向去规划、探索，真正意义上激励人才始终保持创新发展的活力。

王卫平校长作了《转设工作报告》，就从学校办学历史、转设工作政策背景、转设工作进展成果、“过渡期”事宜等方面向大家进行汇报，对标转设指标进行说明。他强调，转设工作既要保障学校师生的利益，又要支持学校今后的发展，达到有利于学校优化资源配置，有利于学校深化综合改革，有利于加快推进实现建设广东省一流，特色高水平的大学建设发展目标。

学校将按照普通高等学校本科教学工作合格评估指标体系，着力抓好以下方面：一是坚持党对学校的全面领导。坚持正确的政治方向，坚持正确的育人方向，把政治建设放在首位，切实发挥党委的政治核心作用，在前进道路上，牢牢把握学校发展的政治方向，坚决保证办学过程的稳定安全。二是实施人才培养质量提升工程。以

“新工科”“新文科”为指导持续深化教育教学改革，重点推进学科专业建设、课程体系构建、实践教学建设和教师队伍建设，突出学生能力素质培养，积极探索多样化人才培养渠道和手段。建立内部治理长效机制。

董事长代表陈超群转达了麦照容董事长对学校发展的关心和期望。他指出，独立学院转设是我国当前高等教育发展的大趋势，把握历史机遇促成飞跃，学校各项工作开展，一是要把握高等教育发展形势，抢抓学校发展历史机遇；二是要做好顶层设计，明确发展目标，谋划学校高水平发展；三是要扩大办学规模，增强发展后劲，实现学校跨越式发展；四是要创新体制机制，完善内部治理体系，实现学校内涵式发展；五是要秉承

“城院是城院人的城院，城院人是城院的中坚力量”的理念，做好民生工程，保障教职员工福利，实现学校“共同体”发展。

31日上午，读书班分成

四个小组围绕上述讲座和报告，就

教育教学改革、转设工作

和学校生存

发展等问题

进行了认真

讨论。同时，大家纷纷为学校下学年的工作建言献策。

王卫平校长在总结时指出：此次暑期中层干部读书班创新形式，加入了职能部门工作报告，内容丰富，全体中层干部要借助此次读书班

全面系统学，及时跟进学，深入思考学，联系实际学，争取

取得良好成效。

同时，读书班上，大家沉下心思考、敞开心交流，大家学习了新思想，凝聚了新共识，谋划了新工作，了解了学校发展大势，也初步厘清了教育思想，厘清了发展方向。

王卫平校长希望在新学年，各部门各单位要抢抓历史机遇，高标准严要求，全面落实各项转设工作任务，夯实基本办学条件，积极做好转设迎评。在党建引领方面，要用高水平党建引领学校发展，持续强化思想政治建设和政治引领，以庆祝建党100周年活动为契机，着力把基层党组织建设成为坚强的战斗堡垒。要继续深化推进学校内部治理结构改革、教育教学管理体制改革、人力资源管理机制改革、学生工作体系改革

等工作，进一步明确学校育人工作的目标、任务、思路和举措，积极推进学校“三全育人”体制机制建设。全体党员干部在这个历史机遇期，要提振精气神，勇于改革创新，强化责任担当，齐心协力

开创学校发展新篇章，努力把学校建设成为特色鲜明的高水平应用型本科院校。

本次暑期中层干部（扩大）读书班学习，使全校领导干部进一步坚定了政治方向、提升了政治理论素养；进一步认清了发展形势、理清发展思路、提升了办学治校能力。大家纷纷表示，在这个历史机遇期，将做好事业发展的思想准备和行动自觉，以更加饱满的热情和良好的精神状态全力投入到新学年工作中，推动学校各项事业高质量发展。
