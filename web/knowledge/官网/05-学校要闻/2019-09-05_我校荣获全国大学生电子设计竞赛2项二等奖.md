# 我校荣获全国大学生电子设计竞赛2项二等奖

9月4日，记者获悉，2019年全国大学生电子设计竞赛结果在上海同济大学复揭晓，由广东省组委会推荐的我校参赛代表队13203D、13205D分别获得全国二等奖。

暑假期间，我校由智能制造学院、计算机与信息科学学院精心组织的指导教师团队，带领10支队伍参加了全国大学生电子设计竞赛，并获得了广东省一等奖3项、二等奖1项、三等奖2项，取得了全省独立学院第2名、全省所有高校第8名的好成绩。此后，全国专家组对各自赛区推荐的一等奖优秀代表队进行综合测评及复评测试，评选出全国一等奖队伍296支（获奖比例1.72%）、全国二等奖队伍847支（获奖比例4.93%），我校获得2项全国二等奖。

据了解，今年共有来自电子科技大学、同济大学、东南大学、华南理工大学等全国500多所高校、17178支队伍参加（广东省876支）此次大赛，是参加院校、学生最多、规模最大，最具影响力的国家级电子设计竞赛。多年来，大赛的影响力进一步提升，许多院校给予获奖学生免试保送研究生的机会。

今年，我校在大学生电子设计竞赛中取得良好成绩得益于学校领导的高度重视和各职能部门、二级学院的大力支持。学校出台了《东莞理工学院城市学院教科研积分管理办法》、《东莞理工学院城市学院本科生课外学分管理实施细则》，从制度层面保障了指导教师和参赛学生的积极性。
