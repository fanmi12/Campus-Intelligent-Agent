# 实验中心培训兼职资产管理员

为了提升我院固定资产管理信息化水平，实验中心于12月20日组织各单位兼职资产管理员学习新启用的固定资产管理系统使用技术。

济南国子数码科技有限公司工程师对固定资产管理系统操作流程以及固定资产增加、变动、查询、清查、处理等6个方面做了详细讲解。接着，资产管理员上机实操。

此次培训工作的开展，对执行固定资产管理制度，增强教职工对固定资产管理工作的思想意识，实现对固定资产科学、精细、动态、高效的管理起到了积极的作用。
