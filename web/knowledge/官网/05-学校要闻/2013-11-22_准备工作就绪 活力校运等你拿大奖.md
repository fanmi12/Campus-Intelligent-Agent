# 准备工作就绪 活力校运等你拿大奖

为办好城市学院2013年运动会，11月20日,体育教学部召开城市学院2013年运动会准备情况通报会议。据了解，校运会一切准备工作就绪。

体育教学部主任邢红林教授传达了学院运动会协调会议精神，并对开好校运会提出了四点要求：与会人员要尽职尽责，按时按质做好准备工作；各参赛单位思想上要高度重视，各负其责，密切协作，做好各项工作；认真组织，积极参赛，加紧备战；既要积极参与、赛出成绩、赛出风格，又要确保安全、防止安全事故的发生；做好学生组织工作。

据悉，现在运动会赛前准备工作已经就绪。“篮球文化节”中啦啦操比赛的优胜队伍也将出现在开幕式，将成为本次运动会的一大亮点；1503人的团体操表演方阵现正在进行最后的排练；裁判员的前期培训工作和运动器械的准备工作已经到位，各主管老师的分工明确，整体运作情况良好。

本次运动会以“青春、运动、友谊、健康”为主题，展示当代大学生蓬勃向上的精神面貌，尽力为大学生提供一个展示自我的平台。
