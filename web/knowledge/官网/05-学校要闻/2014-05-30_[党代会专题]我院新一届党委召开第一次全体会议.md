# [党代会专题]我院新一届党委召开第一次全体会议

5月24日，我院在行政楼接待室召开中国共产党东莞理工学院城市学院第二届委员会第一次会议。经无记名投票，会议选举王卫平同志任党委书记，章德胜同志任党委副书记。

王卫平、章德胜同志在会议上发表了重要讲话。他们高度评价第一届党委艰苦奋斗、开拓进取、创造性地开展党务工作，为新一届党委会工作打下了良好的基础，积累了宝贵的工作经验。要求第二届党委委员不负全院师生员工的重托，攻坚克难、努力工作、继往开来；充分发挥党组织在学院的政治保障作用，支持学院行政工作，促进学院持续健康发展；坚持围绕中心、服务大局、强化功能，大力加强党的基层组织建设，不断提高党组织的凝聚力和战斗力；心系广大师生员工，坚持群众观点不动摇，扎扎实实深入开展党的群众路线教育实践活动，真正做到转作风、出成果、见成效。

会议强调，当前，我国高等教育已进入大改革、大发展、大提高的关键时期。我们要以改革创新为动力，以人才培养为中心，坚定不移地走以质量为核心的内涵式发展道路，这是我院发展的必然战略取向和选择。面对新形势、新机遇、新挑战，党委要科学谋划，统筹部署，扎实工作，继续开创学院发展的新局面。

会议号召，今后四年是学院发展的重要战略机遇期，全体党员和教职员工，要紧密团结、更新观念、协同创新、迎接挑战，深入探索符合中国高等教育发展战略要求、适合学院发展需求的教育改革模式，不断提升学院的综合实力，努力将我院建设成为特色鲜明的应用型本科院校。
