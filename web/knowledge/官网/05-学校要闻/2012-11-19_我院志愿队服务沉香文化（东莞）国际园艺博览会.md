# 我院志愿队服务沉香文化（东莞）国际园艺博览会

“你好！请问博览中心应该怎么去？”

“您好！前面直走，再右转就是了。”我院志愿者梁晓敏同学微笑回答，并挥手示意。

11月18日，2012年中国（东莞）国际沉香文化园艺博览会迎来了最后一天，城市学院志愿队为博览会服务了4天，共有90名志愿者参加了本次活动。

统一的制服，挺直的站姿，微笑。这就是志愿者的形象，他们成为博览会一道亮丽的风景线。志愿队队长叶健忠说：“我们的工作是维持博览会的秩序和安全保障，展现城院学子的良好风貌。”

2012年中国（东莞）国际沉香文化园艺博览会主会场是寮步香市影视城，另一个会场是寮步的牙香街，两个会场都有我院志愿者的服务身影。
