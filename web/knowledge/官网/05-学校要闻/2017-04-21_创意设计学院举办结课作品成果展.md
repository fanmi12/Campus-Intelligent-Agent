# 创意设计学院举办结课作品成果展

4月20日上午，高香林副院长、教务处副处长鞠晓红参观了创意设计学院结课作品展和定格动画工作营。

学院院长助理、创意设计学院院长林江龙，创意设计学院党总支书记何鹏举等介绍了该院特色结课作品展和定格动画工作营情况。

高香林副院长对学生制作的作品给予了高度评价，对以作品展示的方式来促进教育教学表示赞赏。
