# 快乐游园夜  快乐女生节

“万千宠爱，汇聚计信，快乐女生，有你真好。”猜谜语、绕口令、吹蜡烛、盲人击鼓、钓鱼、夹乒乓球、套圈、飞镖、弹球……3月23日晚上，教工食堂旁篮球场人山人海，计信系首届“女生节”游园活动在欢声笑语中拉开了序幕。

场内共设置了11个游戏摊点供全院师生一起游玩，参与者可以凭奖券获得各种精美礼品，很多项目前都排着长长的队伍，场内笑声、欢呼声不断。计信系主任牛熠和党总支书记廉玉忠也前来“游园”，并将自己的奖券送给了两个女生，祝她们节日快乐。牛主任满面笑容地说：“此次活动的创意非常好，不仅展现了计信系的特色，也让计信系的同学们过上了一个非常开心的节日。”

据悉，本次女生节期间，计信系还开展了“动感缤纷摄影比赛”、“万千宠爱送温馨”、“魅力城院，美丽女生”美容知识讲座等系列活动。
