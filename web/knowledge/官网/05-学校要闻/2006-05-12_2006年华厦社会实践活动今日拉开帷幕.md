# 2006年华厦社会实践活动今日拉开帷幕

为期7个月的2006年华厦卓越We mobile WXG3000真情义卖大行动今日在我院正式开始。

这次活动是由城市学院和东莞华厦集团联合举办，旨在通过义卖活动，帮助别人，提升自我，在义卖活动中体现浓浓爱心，为同学们打造一次全新概念的暑期社会实践，为大学生的职业生涯发展提供广阔的平台。

活动启动仪式5月11日晚在学院大礼堂举行。

本次活动于今年12月底结束。
