# 我校举办2018-2019学年度优秀辅导员评选活动

5月27日下午，我校2018-2019学年度优秀辅导员评选活动在行政楼112举行。

章德胜书记出席了活动并致辞。他肯定过去一年辅导员工作取得的优异成绩，希望大家通过评选活动互相学习和借鉴，取长补短，做出更大的贡献。

此次评选活动是在二级学院初评后，选出九名优秀辅导员进11行决赛。他们分别是金融与贸易学院李伟健、外国语学院蔡超明、文学与传媒学院曹镭、智能制造学院何珊珊、祁晓恩，商学院张庆文、王玺，城建与环境学院刘子瑜及法学院徐媛媛。选手们分别汇报2018-2019年度的工作，通过PPT总结了学生心理工作、党建工作、思政工作、教学与创新成果等取得的成绩和经验，也分享了过去一年的工作感悟以及对未来工作的期望。

活动经评委团打分后，学校将结合参评辅导员材料与职能部门统计综合评审得分确定最终评选结果，公示后将对胜出者授予年度优秀辅导员荣誉称号。
