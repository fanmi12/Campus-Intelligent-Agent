# 2014年城院艺考花絮

从“半路出家”到真心喜爱

（大学生记者 余创鹏）3月15日，我院艺考拉开序幕，各类艺术生齐聚城院，乐器声、歌声不绝于耳，整栋艺术楼沉浸在一片艺术的氛围中。

“最初会选择学习声乐,是因为我的文化成绩不理想”，声乐考生李志浩告诉记者。为了能考上市里的重点高中，他毅然“半路出家”，改学音乐，踏上了从艺的旅程，转眼间已经有四年多的艺龄。

当在被记者问到是否会后悔当初的决定时，李志浩笑着说：“我正试着将声乐和流行音乐更好地结合起来，我考试的时候要演唱的歌曲也是一首流行歌，音乐让我觉得自己有价值。”

他微笑着走出考场

（大学生记者 吴倩淳）

在音乐表演候场区，有一个齐刘海，戴着大黑框眼镜，穿着墨绿色帽衫，背着一个大书包的男生在站着等待。

“别紧张，加油！”当他走进声乐组考场时，一个志愿者为他打气加油。透过考场的玻璃门，只见他左手微微扬起，歌声透过门缝飘出考场，高亢悠扬。也许是太紧张，唱完一曲之后，他就走出考场，经过志愿者提醒他才想起还要才艺表演。“咚咚咚……”轻快的钢琴声又从他的指尖流过。

在视唱练耳考场外，他领到一张两行五线谱的小纸片，这可能是考试的内容吧。他手中一直拿着纸片，右手在大腿上轻拍节奏，时而盯着纸片，时而口中哼唱。

考完出来后，记者看到他嘴角带着微微的笑容。

楼梯口的琴声

（大学生记者 蔡冰儿）

上午10时，艺考候场区家长和考生都已严阵以待。来自阳江的考生杨方婷在妈妈的陪同下便在场外的楼梯口练起了古筝，引起不少人驻足观看。灵活的手指在琴弦上熟练地划过，就像舞动的精灵。“很早就看到这个女孩在这边练琴了，弹得不错！”在一旁观赏的考生家长也不吝为她的勤奋点赞。杨妈妈透露，方婷从小学开始就学古筝，因为自己的爱好最终也选择了从艺这条道路。“早上8点多就来到了学校，让孩子提前适应考场。学校的环境不错，希望能考上。”

“我才不紧张”

（大学生记者 丁雪冰 陈嘉琳）时光就像七弦琴上的音符，轻快地流淌，红了樱桃，绿了芭蕉。考试现场佳人才俊正在焦急的等待。

一位陪同女儿前来参加考试的母亲面对记者，相视一笑，高兴地接受了采访。

记者：“女儿进入考场了，您紧张吗？”

家长：“我怎么会紧张呢，闺女紧张嘛，我才不紧张。”

记者：“当初怎么会选择报考城市学院呢?”

家长：“听人说城院环境好啊，是空调学院呀。”她幽默地答道。

……

在接下来的十几分钟里，综合馆门口总能看到一个踱着步子焦虑张望的身影，或许读者都猜到了，就是那位不紧张的母亲……

透过她的身影，我们感受到的是最细腻最深沉的母爱，也是人世间用言语最道不尽的亲情。

“城院学生非常热情，我非常高兴”

（大学生记者 王源源）

当记者问到对城院印象如何时，一位考生的妈妈看了看身边的志愿者说：“城院学生很热情，我非常高兴，尤其是这些穿绿色衣服的志愿者给我留下了深刻印象，他们不厌其烦地帮我们搬乐器，指引缴费，真的是非常满意。”

记者还了解到，她来自广州，是第一次来城市学院。昨天考完舞蹈后便与女儿在校园逛了逛，她们感觉这里环境非常不错，绿树环绕，空气清新，认为能让女儿在这读书非常满意。

一大群美女涌向城市学院

（大学生记者 王源源）

又是一年艺考时，3月15日、16日，是东莞理工学院城市学院的艺考时。一大早，就有不少考生前来报名、候考。记者发现，虽然今年少了一个影视表演专业，可前来报考的学生仍然很多，美女更是不少，或长发飘飘，或挽髻插簪，或面若凝脂、柳叶弯眉，或双眉紧蹙、不失清丽……她们穿着表演服装，上了妆，简直是美若天仙，志愿者们也频频吐槽：好多美女啊，好漂亮啊。

她们不仅长得亭亭玉立，而且才华横溢！古筝、架子鼓、钢琴、竖笛、二胡……那可都是拿得出手的！

为梦起航

（大学生记者 孙钰银）

闲暇的周末，湿润的空气里夹杂着慵懒的味道。而城院这天的周末醒的特别地早，因为又到了艺术生校考的日子了。

8点还不到，来自各地的考生们就早早地赶到了考场，身着绿色志愿服的志愿者们也有序地迎候在各个考场，帮助考生指路、引导车辆进出......人群中一对姐妹花引起了记者的注意。她们是来自韶关的肖瑜和蓝京荣同学，她们脸上一直挂着阳光般的笑容，互相为对方化妆，认真的样子不禁让人心生暖意。从交谈中，记者了解到她们都是自个儿来参加考试的，没有老师也没有父母的陪伴。因为相同的爱好，进了同一个考前培训班，又因为同一个梦想结伴来到城市学院报考艺术系。

城市学院是肖瑜报考的第四站，独特的建筑风格以及较好的教学设备吸引她来到城市学院报考，肖瑜开心地说：“自己一个人来考试并没有什么，为了梦想，没什么可以害怕的。城院的师兄师姐都很热情，我也很喜欢学校独特的风格，来了学校之后更坚定了我当初的信念，今后我们会好好学习的”。

有机会就得争取

（大学生记者 肖田佩）

在艺考现场，只见一位身着绿色长礼服的女孩面对周围陌生的面孔，既担心老师严苛又害怕对手强劲，这让来自河源市尔崧中学的江海燕脸上始终挂着一丝紧张。

报考声乐专业的她，在演唱《山娃》歌曲时，因为没有开嗓，所以嗓子高度紧张，唱完后她始终不敢直视老师的眼睛。面试老师问起音程、和弦与模唱的性质时，她也一时语塞不知怎么回答。一个激灵后才匆匆答道：“大六度！”考场出来后遇到几个同学，她露出了笑脸，互相讨论着视唱练耳的考试内容：“我抽到的五线谱最简单，你们也快去考吧。考试乐理时千万不要紧张，有机会就要抓住。”
