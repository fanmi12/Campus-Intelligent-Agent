# 东莞社区研究中心成员到樟村、堑头两社区调研

6月10日至17日，东莞理工学院城市学院东莞社区研究中心主任陈丁堂教授、常务副主任程建新老师、赵书山副教授、黎诚讲师、林晓老师到樟村、堑头两社区开展调研活动。

樟村社区总支书记卢敬崧、堑头社区总支书记黎惠成、堑头社区副主任陈建华热情接待了调研组成员。

通过调研，调研组对两社区的情况有了初步的了解，并对居民所关心的具体问题和困难有了进一步的认识。双方对下一步如何开展社区服务与社区工作研究达成了共识。
