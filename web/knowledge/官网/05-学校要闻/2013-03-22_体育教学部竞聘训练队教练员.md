# 体育教学部竞聘训练队教练员

为提高城市学院各训练队的竞技水平，激发教练员的积极性，体育教学部决定为各训练队竞聘教练员。3月21日，体育教学部在部会议室召开教练员竞聘会。院长杨敏林，副院长高香林，体育教学部主任邢红林出席了竞聘会。此次竞聘会主要是为男篮、羽毛球、乒乓球、足球、女篮、排球、跆拳道、武术八个运动训练队竞聘教练员。

会上，各竞聘老师介绍了自身的学习经历、工作成果和教学方式，展示未来几年自己的训练计划以及所要达到的目标，并回答了关于竞聘的有关问题。

杨敏林院长分享了自己曾在体校的成长经历和感受，对会议中各竞聘老师展现出的个性风采，认真和执着的精神加以肯定，表示将对这一工作给予大力支持，希望老师们能在三至五年内创造出好的训练成绩，形成城院的体育品牌。

杨院长还为受聘的教练员颁发了聘书。
