# 我院新增“互联网金融”全日制本科专业

日前，教育部公布了2018年度普通高等学校本科专业备案和审批结果。我院申报的“互联网金融（020309T）”专业获得教育部审批通过，将于今年秋季开始招生。至此，我院全日制本科专业达到41个。

据介绍，互联网金融专业旨在培养学生德、智、体、美、劳全面发展，具有一定创新能力和创业能力，并具备坚实的经济学、金融学理论知识和互联网金融业务能力，能在金融企业和非金融企业的相关部门（含事业单位、政府部门）开展互联网金融业务活动，以及从事互联网金融管理工作的兼爱尚和、精诚务实、求实创新的高素质应用型人才，学制为四年，毕业授予经济学学士学位。

欢迎参加2019年高招考试的考生积极报考我院“互联网金融”专业。
