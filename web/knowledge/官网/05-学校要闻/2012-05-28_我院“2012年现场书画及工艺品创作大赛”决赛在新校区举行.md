# 我院“2012年现场书画及工艺品创作大赛”决赛在新校区举行

5月24日下午，我院新老校区350名书画与手工创作爱好同学齐聚新校区综合馆，参加了以“你我携手?共创新篇”为主题的“2012年现场书画及工艺品创作大赛”决赛。

决赛现场，选手们个个聚精会神，或一笔一画地书写作品，或笔尖在宣纸不断地舞动，或挥毫泼墨作画，尽情地展示自己的才艺。而手工艺品选手们的作品精巧细致、创意十足，将自己的心灵手巧展示得淋漓尽致……

决赛还特邀广东省教育科学“十一五”规划课题主持人、中国教育学会书法教育专业委员会会员黄斌武副教授现场指导，并为本次决赛题字。所提的“奔驶”二字，寄托了黄斌武副教授对城市学院及新校区快速发展的希望，也希望参赛选手能够发挥自己所能，增添校园人文气息。

新校区管委会综合部副部长张琮出席了决赛并致辞。

据悉，本次决赛共分硬笔书法、软笔书法、绘画和工艺品四个组别，作品评选将由评委老师评选和网上投票两部分组成，结果将于下月初出炉。
