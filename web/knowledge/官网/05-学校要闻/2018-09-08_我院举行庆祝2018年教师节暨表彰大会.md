# 我院举行庆祝2018年教师节暨表彰大会

9月8日下午，我院在综合馆隆重举行庆祝2018年教师节暨表彰大会。院领导王卫平、章德胜、高香林、黄兢、周庆、刘玉侠、林江龙和全体教职工参加了大会。庆祝大会由副院长刘玉侠主持。

大会对荣获学院2017-2018学年度先进个人、优秀辅导员、优秀班主任荣誉称号的教师和2018年院级教师教学比赛获奖的教师进行了表彰，向38名十年校龄的教职工颁发了纪念章。

获得2018年南粤优秀教师荣誉称号的殷素峰老师受到大会表彰。

殷素峰博士代表教师在大会上发言。他回顾了2006年入职以来，与机电系共同成长的点点滴滴，为机电系取得省重点培育专业（民办）和重点培育学科建设等系列成绩而自豪。他表示，将不断加强师德修养，提升自己专业素质，坚持立德树人的根本标准，把个人理想、本职工作与学生、学院的发展紧密联系起来，不忘初心，以饱满的热情投入到今后的工作中去。

“有一种爱无法忘记,有一种情刻骨铭心,那就是老师的深情教诲和无私奉献。”王卫平院长在讲话中指出，过去一年，全体城院人齐心协力，攻坚克难，有效推动学院各项工作顺利开展，以更好质量和效率完成了2017-2018学年的重点工作。2018年招生工作再上新台阶，招生总数突破6000大关。

王卫平院长还对2018-2019学年的几项重点工作进行了部署，并希望全体教职工群策群力、不折不扣地落实执行。

王卫平院长代表学院董事会、党政领导班子, 向辛勤工作在各个岗位上的教职员工们致以崇高的敬意和节日的问候！
