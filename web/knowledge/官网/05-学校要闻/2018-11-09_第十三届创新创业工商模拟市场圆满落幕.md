# 第十三届创新创业工商模拟市场圆满落幕

11月8日下午，由学院团委、创新创业学院主办，商学院承办的第十三届创新创业工商模拟市场顺利闭幕。

商学院院长罗卫国、书记卢淑芳、副院长郑阿泰出席了闭幕式。

商学院党总支书记卢淑芳致词指出，当今，创新创业不再是少数人的事情，而是大多数人的机会，通过创新创业使更多人实现了自己的人生价值。她表示，工商模拟市场经过了13年的沉淀和积累，多层次开展创业培训、创业实训和创业项目孵化，打造了多元化创新的教育模式。大学生作为新时代的青年，应该知行合一，做实干家，敢于创新，敢于创业。

本届工模管理委员会主任陈可倩在总结时表示，工商模拟市场经过多年的发展，比以往更加成熟。工模不仅吸引了广大城院学子的关注，在莞其他高校也有不少学生也参与其中。

闭幕式上，由艺术团阿卡贝拉清唱团、OLT街舞队、商学院歌手组、艺术团跆拳道队、CM模特队献上了精彩的表演，动听的歌声、炫酷的姿态将闭幕式气氛推向高潮。

据悉，本届创新创业工商模拟市场以“智汇城院?创享未来”为主题，融入了更加丰富的创新创业元素，培养了同学们的创业意识，锻炼了创业实践能力、组织协调能力以及创新发展能力，积累了创业实践经验，加强了理论与实践相结合，活跃了校园气氛，丰富了校园文化，激发了同学们的创新创业激情，推动了创业实训文化建设。
