# 朱志德书记到思政部指导思想政治理论课专项建设评估工作

4月23日，院党委书记朱志德研究员、院督学陈丁堂教授到思政部2#310会议室指导思想政治理论课专项建设评估工作。

朱书记和陈督学认真审阅了思政部已准备好的迎评材料、自查报告、领导汇报提纲等，对思政部的迎评工作给予了充分的肯定。并指出，汇报材料要充分体现我院重视优质课程和精品课程建设、加强青年教师培养、改善办公条件、切实开展学生社会实践、有效实施教学示范活动、教学改革等方面的特色、亮点。

两位领导和思政部主任何鹏举教授、副主任石志民副教授探讨了下一步的工作重点，并对具体工作进行了安排布置。朱志德书记说，杨敏林院长十分重视思想政治理论课建设评估工作，希望把教学管理工作做仔细，把迎评材料做扎实，不满足于通过，要力争获得优秀。
