# 两家便利店开张迎客

装饰一新的便利店开张营业。

同学们排着队进入便利店。

店内齐全的商品受到同学们的欢迎。

装饰一新的位于学生活动中心的美宜家便利店、百轩礼品店，于3月23日隆重开张营业。

据总务处周林冲副处长介绍，食品安全关系到广大师生的身体健康和生命安全，关系到学院形象与办学声誉。过去，院内商店是个人承包经营的，存在着商品质量得不到保证、价格不规范、周边卫生状况差等问题。为了提高服务质量，保障食品卫生安全，学院总务处决定，引进东莞两家著名连锁店进校园开店。新店子的开张，有利于统一管理，服务质量、商品质量、价格标准接受总店的管理和总务处的监督。

据便利店负责人介绍，他们针对学院的消费群体和所处的地理位置，将为广大师生提供更全面、更人性化的服务，经营的项目及服务有日常生活用品、学习及体育用品、资料复印、废旧电池回收、毕业及节日礼品设计、学生创意礼品制作等。
