# 周巍老师应邀到桥头镇做专题讲座

9月12日，我院周巍老师应邀到桥头镇做“推进社区服务发展”专题讲座。桥头镇领导、社区（村）主要负责人、民政干部等150多人参加听讲座。

周巍老师以“小社区，大改革——东莞村（社区）管理体制改革分析”为主题，从深入浅出地阐述了社区服务基本内涵内容与发展现状，分析了近几年来东莞社区管理体制改革的进程，着重讲解了社区综合服务中心、社区政务服务中心的建设要求、标准等问题。
