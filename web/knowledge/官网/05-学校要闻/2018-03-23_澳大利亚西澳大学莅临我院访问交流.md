# 澳大利亚西澳大学莅临我院访问交流

3月21日下午，西澳大学英语语言教学中心、国际游学、语言测试中心主任Mr.Callum Cowell一行三人，来我院进行访问交流。

国际交流中心负责人陈峰等热情接待了西澳大学客人。双方就暑期Study tours项目、学期交流项目等合作事宜进行了洽谈。

Mr.Callum Cowell主任一行还参观了校园。

据了解，澳大利亚西澳大学创建于1911年，是世界知名研究型大学，世界100强名校，澳洲八大名校之一，每年毕业生中包含超过250名博士生，名列前茅。西澳大学以办学质量和创业精神驰誉国际，校舍建筑以地中海罗马式风格为主，是澳洲最美的校园之一。
