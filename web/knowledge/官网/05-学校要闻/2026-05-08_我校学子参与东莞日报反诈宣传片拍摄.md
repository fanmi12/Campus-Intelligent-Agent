# 我校学子参与东莞日报反诈宣传片拍摄

为进一步深化反诈宣传教育，创新宣传形式，扩大反诈知识覆盖面，切实提升青年群体的识诈、防诈、反诈意识，4月28日至29日，由东莞日报组织拍摄的反诈宣传片在东莞城市学院取景，东莞城市学院党委宣传部统筹协调，联动创意设计学院、学生知行社区、敏行社区，选拔了多名学生参与拍摄，协助专业团队完成了校园场景、反诈情景演绎等多个环节的摄制工作，以青春力量为反诈宣传注入鲜活动能。

参与拍摄的学子提前打磨台词、反复走场排练，结合自己对常见诈骗套路的理解，生动演绎了刷单返利、校园贷、冒充客服退款等典型诈骗场景，用青年视角还原诈骗发生过程，展现了被骗后造成的危害与后果，也呈现了遇到诈骗时及时止损、报警求助的正确处理方式。本次校企联动的反诈宣传形式，打破了传统反诈宣传的说教模式，以学生喜闻乐见的短视频形式传播反诈知识，既为青年学子提供了参与社会实践的平台，也能借助学生群体的传播力，让反诈知识触达更多年轻人，共同筑牢全民反诈的安全防线。

此次反诈宣传片拍摄，是东莞城市学院深化“平安校园”

建设、落实反诈宣传进校园要求的具体举措，也是校企协同开展社会服务、传递反诈正能量的生动实践。活动前期，学校党委宣传部高度重视，精准对接东莞日报拍摄需求，联合创意设计学院、知行社区、敏行社区，筛选拍摄人员

——8名学生均具备良好的表达能力和镜头表现力，2个参与拍摄的宿舍整齐有序、氛围积极，充分展现了城院学子的良好精神风貌。

拍摄过程中，同学们严格遵守拍摄安排，在东莞日报专业拍摄团队的指导下，快速进入状态，认真揣摩角色情绪和动作细节。宣传片以校园生活为切入点，聚焦大学生易遭遇的刷单返利、冒充客服退款、校园贷等典型诈骗场景，将反诈知识自然融入日常学习生活画面，通过真实还原诈骗陷阱、生动传递防范技巧，让反诈宣传更接地气、更具感染力，打破了传统反诈宣传的枯燥说教模式，实现了“让学生演、学生看、学生传”

的宣传效果，助力反诈知识从“被动听”

变为“主动学”。

此次参与反诈宣传片拍摄，不仅让参与学生深入学习了反诈知识，增强了自我保护意识和社会责任感，更发挥了高校学子的示范引领作用，推动反诈宣传向校园、向社区延伸。下一步，学校将持续深化与主流媒体的合作，依托创意设计学院的专业优势和学生社区的阵地作用，创新反诈宣传形式，丰富宣传内容，开展更多形式多样、贴近师生的反诈宣传活动，推动反诈知识入脑入心，切实守护好师生的“钱袋子”，同时引导学子主动成为反诈宣传的“主力军”，带动身边人提升反诈意识，共同营造“人人识诈、人人防诈、人人反诈”

的良好社会氛围，为建设“无诈校园”、平安东莞贡献城院力量。
