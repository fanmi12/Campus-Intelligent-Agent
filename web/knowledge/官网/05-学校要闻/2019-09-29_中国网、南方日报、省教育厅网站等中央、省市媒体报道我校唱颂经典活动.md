# 中国网、南方日报、省教育厅网站等中央、省市媒体报道我校唱颂经典活动

9月26日，为热烈庆祝中华人民共和国成立70周年，我校成功开展“不忘初心、牢记使命”主题教育—— “初心永在，放歌祖国”唱颂经典活动。活动不仅在全校师生中赢得了广泛好评，连日来，中国网、广东省教育厅网站、羊城晚报、南方日报、广州日报、东莞日报等中央、省市媒体进行了广泛报道，获得了社会各届的点赞和热议！

9月27日，中国网以《东莞理工学院城市学院创新举办庆祝新中国成立70周年唱颂经典活动》为题，进行了长篇报道。广东省教育厅网站在“广东教育”栏目以《“初心永在，放歌祖国”：东莞理工学院城市学院万名师生唱响经典红歌》为题，对活动进行了大篇幅的报道。

同时，《羊城晚报》《广州日报》《南方日报南方+》《东莞日报》《i东莞》《东莞阳光网》等省市媒体也相继进行了报道，使我校“初心永在，放歌祖国”唱颂经典活动获得了社会各界的广泛赞誉，进一步激发了广大师生的爱国热忱。
