# 我校赴南部战区训练基地慰问

7月27日，校长王卫平、后勤保卫处副处长刘维仝一行赴南部战区训练基地开展“八一建军节”拥军慰问活动。

王卫平代表学校向基地全体官兵致以节日的祝贺和诚挚的问候。他表示，一直以来，南部战区训练基地和我校保持着密切联系，驻地官兵历年来积极参与和支持我校的建设与发展，特别是每年为我校新生开展国防教育和军事训练等方面做了大量工作。学校将坚定不移地弘扬拥军优属传统，积极推动学校与基地的建设与发展。

南部战区训练基地主任刁海东对慰问团的到来，表示热烈欢迎。刁海东首先介绍了基地目前的基本情况，指出基地与学校一直以来都保持良好的交流，全体官兵将以实际行动回报党和人民的厚爱，并努力为促进城市学院实现百年名校建设作出更大的贡献。
