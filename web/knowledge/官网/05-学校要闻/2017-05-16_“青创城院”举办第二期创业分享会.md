# “青创城院”举办第二期创业分享会

5月15日下午，第二期“青创城院”创业分享会在大学生创新创业发展中心举行，慕薇化妆品有限公司创始人李园女士分享了自己的创业之路。

李园女士作为国家高级化妆师、中国十大纹绣名师、中国十大肌肤管理专家，在分享会中认为，大学生应该重视自我形象管理和演说的能力，以此培养自己的人格魅力。同时，她还以自身创业经历，讲述了积累经验对于创业的重要性。

当同学问及如何坚持创业这条路时，李园女士表示创业之路实属不易，但看到身边还有许多人支持着自己，就坚持下来了。让她感到幸运的是，在创业途中找到了志同道合的人一起去做喜欢的事。

分享会沿袭了首届“创业大咖面对面”的讲座模式，拓展了同学们的知识面，激发了同学们的创业激情，也鼓舞了正在创业之中的城院学子。
