# 我院举行申请新增学士学位授权评建工作责任书签字仪式

会场各责任单位的负责人与院长安少华教授签订责任书

安院长：全院上上下下、方方面面都要将迎评促建工作当做自己义不容辞的责任。

各系各专业负责人在计信系参观学习3月24日，城市学院申请新增学士学位授权评建工作责任书签字仪式在4315会议室举行。院领导安少华、朱志德、程发良、张林、朱冰，院督学陈丁堂出席了仪式。参加会议的有院机关、各系部及相关专业负责人。副院长程发良教授主持仪式。

院督学陈丁堂教授首先宣读了责任书。据了解，责任书从6个方面明确了责任单位及责任人的职责与任务，以及学院对各单位的具体要求。

会上，各责任单位的负责人向院长安少华教授递交了责任书。

安院长在会上强调，责任书代表着一种责任，全院上上下下、方方面面都要将迎评促建工作当做自己义不容辞的责任，将迎评工作列入单位的重要议事日程；要服从学院的统一安排，抓紧工作；要提高工作效率，注重工作细节，逐级逐人落实工作问责制；要按时按质完成责任书中规定的任务。安院长鼓励与会人员，要以饱满的热情、坚定的信念、高度的责任感解决工作中的问题，开展评建工作。

签字仪式结束后，财经系系主任高香林教授、计信系彭义春老师分别介绍了会计学专业和软件工程专业评建工作的做法、经验以及存在的问题。

会后，学院还组织各系各专业负责人到计信系参观学习。
