# 我院召开安全工作会议

5月25日，我院安全工作会议在410会议室召开。副院长张林出席了会议。参加会议的有各系部行政秘书和机关相关人员。

会上，保卫办负责人理阳阳通报当前学院的治安状况，对学校即将出台的一些治安管理办法做了说明，以及学院今年1-5月份出现的一些安全事故和师生员工治安方面需要注意的问题。

张副院长强调，全院教职工要充分认识治安工作的重要性，增强安全意识，认真遵守学院制定的安全保卫措施，杜绝意外事故的发生，确保校园安全、和谐。要群防群治，共建平安校园。安全工作不仅仅是保卫部门的事，是大家共同的责任。要主动防范，切实加大学生安全工作的力度，为别人、为自己、为大家共同建设一个平安、和谐、幸福的校园。
