# 我校参加全省教育系统党史学习教育动员部署会

3月5日，广东省全省教育系统党史学习教育动员部署会召开，深入学习贯彻习近平总书记在党史学习教育动员大会上的重要讲话精神，全面落实党中央和省委关于党史学习教育的决策部署，动员教育系统严格对照中共中央《关于在全党开展党史学习教育的通知》要求，把党史学习教育作为当前和今后一个时期的重大政治任务，高标准高质量推进落实，以实实在在的成效庆祝建党100周年。

广东省委教育工委书记、省教育厅厅长景李虎出席并讲话。我校在行政楼401会议室设立分会场，全体校领导、职能部门负责人、二级学院党总支书记参加视频会议。

视频会议后，章德胜书记强调，各职能部门要通力配合，贯彻落实党中央、省委以及省委教育工委有关决策部署，做好党史学习教育工作开展方案，周密部署，突出重点、把握要求，高质量高标准开展党史学习教育，坚持学史明理、学史增信、学史崇德、学史力行，切实增强“四个意识”、坚定“四个自信”、做到“两个维护”，不断提高政治判断力、政治领悟力、政治执行力，真正做到学党史、悟思想、办实事、开新局。同时要加强宣传引导，营造良好舆论氛围，推动学习教育深入群众、深入基层、深入人心。
