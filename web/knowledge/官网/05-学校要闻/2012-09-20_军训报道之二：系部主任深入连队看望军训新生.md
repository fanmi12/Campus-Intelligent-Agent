# 军训报道之二：系部主任深入连队看望军训新生

军训已进入第四天，新同学能否吃得苦撑得住，完成军训任务，达到军训目的，成了院系领导最牵挂的问题。连日来，领导们通过各种形式看望和慰问军训师生，鼓励他们发扬军人的优良作风，向解放军学习，取得军训的好成绩。在

此选取两个片断：金贸系主任米双红教授：不怕苦不怕累，克服困难战胜自己9月19日，金贸系主任米双红教授在党总支副书记李阳桂的陪同下，来到训练场看望了金贸系2012级新生。

截止今天，金贸系2012级新生共报到1090人，报到率达95.28，在校学生人数保持了全院第一的记录。今天为新生军训第三天，金贸系四个连队的学生在教官的带领下保持着良好的精神面貌和高昂的斗志。

为给同学们鼓劲加油，让同学们克服困难将这种好的精神面貌继续保持，米双红主任分别对四个连队的同学提出了希望和要求。一是希望同学们不怕苦不怕累，克服困难战胜自己；二是希望同学们在教官的严格要求下保质保量的完成每一个动作；三是同学们遇到任何问题困难都可以及时向金贸系的领导、老师、辅导员寻求帮助。

文传系主任邓星明教授：女兵巾帼红妆，男兵雄姿英发9月18日，学生军训第二天，文学与传媒系主任邓星明教授就来到学生军训场地看望了正在参加军事训练的2011级学生，并慰问军训教官。邓主任看望了正在参加训练的学生，对他们刻苦认真参加军事训练的行为给予了充分肯定，并盛赞女兵巾帼红妆，男兵雄姿英发。鼓励大家发扬精神坚持到底，完成军训任务，并提出了训练的要求与希望，争取好成绩。
