# 城市学院今日喜迎2012级新同学

9月15日是我院录取的4967名2012级本科新生的第一个报到日。晨曦中的新校园在彩旗招展中开始变得繁忙起来，一批批来自省内外的青年学子承载着青春的梦想跨入城院，开始自己的大学生活。

从早上7时开始，新同学陆续前来报到，校道再次呈现出一派车水马龙的忙碌景象。

在综合馆，学院各职能部门、系部接待工作人员以及迎新学生志愿者各司其职，迎接新同学的到来。新同学更是带着喜悦的心情，在家人的陪伴以及学院志愿者的帮助下，有序地办理入学手续。

在校内，活跃着我院800多名学生志愿者，他们或与安保人员一道指挥交通，或帮助新生提携行李，或帮助新生办理入学手续，或帮助新生整理寝室，使和谐的校园显得更加温馨。

在报到现场，东莞理工学院党委书记成洪波、校长杨晓西，省政协委员、东莞理工学院城市学院名誉董事长周致纳，东莞理工学院城市学院董事长麦照容、董事黎建烨放弃周末休息，亲临综合馆视察、指导报到工作，并与城市学院院领导班子一同看望了新同学和迎新接待工作人员。

今年的招生迎新工作，引起了南方日报、南方网、羊城晚报、东莞电视台、寮步电视台等十多家媒体的高度关注，并前来采访报道。据了解，一所院校一次迎来近5000名本科新生前来报到的规模，在东莞高校中尚属首例。

据了解，9月15日主要是2600多名2012级管理系、政法系、文学与传媒系、计算机与信息科学系、机电系、城市与环境系、艺术系新生注册报到；9月16日为2300多名金融与贸易系、财经系新生注册报到。
