# 学院开展党建工作检查

5月19日，学院党委办马兴顺、余国鑫、黄阳辉一行根据院党委的工作安排，对机电工程系党建工作进行检查。

检查过程中，机电系党总支向检查组汇报了一年来的党建工作以及工作特色。检查组对系党总支基层组织的班子建设、党员学习教育、发展党员工作、日常管理工作、党员活动室建设和党章学习小组六个方面的工作进行了全面的检查。

检查组表示，机电系党建工作，与去年相比有很大的提高并形成了自己的特色，其中有的工作也很有创意。检查组对该系党建工作提出了改进的意见。
