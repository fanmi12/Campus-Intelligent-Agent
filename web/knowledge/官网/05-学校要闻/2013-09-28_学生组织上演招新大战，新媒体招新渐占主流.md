# 学生组织上演招新大战，新媒体招新渐占主流

9月27日，随着13级新生的到来，我院各大学生组织的招新工作在紧锣密鼓进行中，院学生会、院团委、系部学生组织上演招新大战。

院学生会副主席赖汝旺告诉记者，仅半天的时间，院学生会14个部门就有10062人次参与报名，院团委5个部门2767人次参与报名，城院学生媒体中心4个部门1025人次参与报名，初试工作将在28、29日紧张而有序地进行。我院7个系部也将于10月中旬启动招新工作，为各系部的发展注入一股新活力。10月下旬我院社团将同步上演“百团大战” 招新纳贤。

招新花样 新颖别致

在招新现场，各学生部门摊位使出“浑身解数”吸引新生的注意。乔巴、小黄人、花师奶一家、哆啦A梦、小黄鸭……可爱动漫形象为报名现场增添几分童趣成为全场最大的亮点。“缺师弟、缺师妹，快到我们碗里来”体育部大声吆喝吸引新生注意。院办公室、勤工助学两个部门共同合作利用音响器材，现场表演了一段潇洒的街舞，再配上旁边搭档的热情解说，果然吸引了大批同学的驻足观看和报名。城院电视台作为今年新增的部门摊位绞尽脑汁使出新站要鹤立鸡群，他们将曾经拍摄的校园视频作为招新宣传片，三脚架、摄像机、采访麦各种专业器材成为现场一道亮丽的风景线。

微博招新 渐成主流

“师弟师妹们，这里是你们想要的大家庭，帅哥美女样样有。学生会社团联合会是你们居家旅游的不二之选哦！”9月24日，城院学生社团联合会发布了这条招新微博吸引了大批新生转发评论，为招新报名当天做足宣传打响头炮。

此外，东莞城院大学生记者团微博“#JION NOW!#即刻加入城院大学生记者团吧，你是否有敏锐的视角，积极的生活态度，来城院大学生记者团吧！大学生记者团隶属我院党委宣传部，是新闻中心学生组织之一。我们以学生记者的视角,探讨你们所探讨的,为城院学生的一大‘喉舌’”以转发量33条稳居学生组织招新微博榜首。

据学生会副主席赖汝旺介绍，今年整个招新过程中文化氛围很浓郁，每个部门为了招新都铆足劲创新招新模式，勤工俭学中心、自律会等均通过QQ群、网站以及微信群的方式招兵买马。
