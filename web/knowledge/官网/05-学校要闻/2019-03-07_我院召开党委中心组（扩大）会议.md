# 我院召开党委中心组（扩大）会议

3月7日下午，学院召开党委中心组（扩大）会议。全体院领导、各单位正副职负责人、党总支（直属支部）书记、副书记参加了会议。会议由党委书记章德胜主持。

院长王卫平传达了2019年全省教育工作会议精神。

党委书记章德胜传达了全省教育系统党的建设暨意识形态安全工作会议精神。

会议对2019年意识形态安全工作和学校安全稳定工作进行了部署，并举行了责任书签字仪式。
