# 城市学院第七届会计知识竞赛初赛顺利开展

城市学院第七届会计知识竞赛初赛于4月17日下午1500在综合馆隆重举行。全院共有近500多名学生参加了初赛。

竞赛现场，各考生都专注地审题、计算、答题；监考老师、巡考人员严格遵守考场纪律进行监考任务。

本次的会计知识竞赛初赛得到了同学们的热烈响应。据现场参考学生反映，今年的单项选择题比较简单，而不定项选择题由于涉及成本学和税法而略显困难。另外，从监考老师方面了解到，今年学生的表现比往年要更积极主动，在考场上能沉着应对考题，对会计专业知识也有了很大的提高。

赛后，考卷由我系专业老师改阅，保证了竞赛的专业性和公正度。

据悉，本次会计知识文化月比以往加大了前期宣传力度，通过微博、微信、海报等各种媒体渠道拓宽报名方式，对各兄弟系部抛送了大量“橄榄枝”以吸引全院会计知识爱好者共同参与这场会计知识头脑风暴。会计知识文化月初赛已经落下帷幕，决赛将在五月中旬举行，届时将会将本次会计知识文化月推上另一个高潮。
