# 【众志成城 抗击疫情】我校召开疫情防控紧急会议

1月27日上午，东莞理工学院城市学院防控新型冠状病毒感染的肺炎疫情工作领导小组在行政楼505会议室召开了新型冠状病毒感染的肺炎疫情工作紧急会议。领导小组组长王卫平校长和章德胜书记主持本次会议。学校董事长代表陈超群及党政领导班子成员，学校办公室、人事处、学生处、教务处、后勤保卫处、新闻中心、图书信息中心等相关职能部门负责人与会。

会议传达了广东省教育厅、东莞市教育局、等上级部门的有关肺炎疫情防控工作的系列文件精神，集体学习研究解读了《关于做好学校新型冠状病毒感染的肺炎疫情防控工作的紧急通知》、《广东教育系统疫情防控八条》精神。会议研讨部署了《东莞理工学院城市学院新型冠状病毒感染的肺炎疫情防控工作方案》、《东莞理工学院城市学院新型冠状病毒感染的肺炎疫情防控应急预案》的重要内容及要求。会议部署了各职能部门、各教学单位在共同防控肺炎疫情工作中必须承担起的重要职责，必须采取的有力举措和应急预案，包括每日疫情监控及报告、疫情隔离区设置及后勤保障、学生实习调整及开学准备工作、校园安全保卫等具体内容。会议要求全校各单位要切实负起主体责任，做到守土有责、守土尽责，对自己单位的人员逐个摸清情况，确保全覆盖、不漏一人，点对点、一人一策将疫情防控精神及措施落实到位；要求各单位负责人要亲自靠前指挥和跟踪督办，决不能当二传手，全力确保疫情防控工作全面高效有序开展。董事长代表陈超群对我校肺炎疫情防控工作提出了具体要求：一是做好师生员工身体健康状况登记排查工作，如实填报相关信息；二是加强宣传引导教育，要求师生增强自我防护意识，加强锻炼增强免疫力，自觉居家隔离观察14天，不与传染源接触，尤其是从易感区往来的师生请务必自觉实施自我隔离；三是树立大局意识，听从学校统一指挥，确保校园安全。领导小组组长王卫平校长、章德胜书记强调，校内各单位负责人一定要高度重视此次肺炎疫情防控工作，提高政治站位，守土有责、守土尽责，切实把思想和行动统一到习近平总书记重要指示精神和党中央、国务院、教育部、省教育厅部署上来，严格按照上级有关精神和文件要求，密切关注节假日期间疫情发展情况，提前对春季开学有关情况做出科学研判，动态细化开学前后疫情防控工作预案，务必做到全覆盖、无盲区，心中有数、安排周密、举措有力，形成合力、竭尽全力确保师生员工的生命安全和身体健康，坚决遏制疫情蔓延势头。据悉，学校高度重视肺炎疫情防控工作，自疫情发生以来，即在全校成立应急工作小组开展防控工作，并随即建应急工作微信群、疫情防控工作领导小组微信群，截至1月27日未发现感染病例。
