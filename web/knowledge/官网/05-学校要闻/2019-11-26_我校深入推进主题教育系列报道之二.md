# 我校深入推进主题教育系列报道之二

寻芳陌上花似锦 折得东风第一枝——外国语学院、文传学院、智能制造学院主题教育掠影2019-11-26作者：莫玮娟

发文单位：学校要闻

在“不忘初心、牢记使命”主题教育深入开展之际，我校外国语学院、文学与传媒学院和智能制造学院坚持理论与实践相结合，力求形式多样，效果入脑入心，推动主题教育走深走实。

统筹组织 分院实施

我校外国语学院、文学与传媒学院和智能制造学院认真围绕“不忘初心，牢记使命”主题教育“守初心、担使命，找差距、抓落实”十二字总要求，结合学院实际，开展了内容丰富、意义深刻的学习活动，如组织师生前往东纵纪念馆革命传统教育学习、东莞图书馆参观主题教育档案文献展等，让广大师生更加深入参与到主题教育活动之中。

为唤醒党员责任意识，勇于担当作为，充分发挥党员的先锋模范作用，三个学院基层党组织开展了“亮身份、亮职责、亮承诺”活动。

外国语学院要求参加活动党员都要佩戴党徽，设立党务公开栏，公开党员职责、学习心得，用心践行“亮身份、亮职责、亮承诺”活动。

在智能制造学院的活动中，王卫平校长为该学院党员师生代表挂牌 “智汇先锋”和“学生党员宿舍”，要求党员在任何岗位、任何地方、任何时候都要铭记党员身份，履行党员义务，不断增强党员意识，带头承诺践诺。

文学与传媒学院在东莞荔香湿地公园开展“亮身份、亮职责、亮承诺”活动，全体党员佩戴党徽，公开亮出党员身份，以此进一步唤醒党员责任意识，勇于担当作为，将作风践行在行动上，发挥党员的模范作用。

新进预备党员陈婧妙表示“作为一名预备党员，我承诺在牢记学习任务、刻苦学习专业知识的同时，加强自己的政治思想素养，以一名共产党员的先进模范标准严格要求自己。”

加入党组织已有四年多的余巨涛同志表示：“活动很有仪式感，亮明了党员的身份，重温了入党誓词。今后在工作和生活中，我会常用党章这面镜子时刻检查对照自己的言行，以实际行动兑现党员庄严承诺。”

创新特色 注重实践

为进一步弘扬爱国主义精神，激发党员的家国情怀，提高党性修养，我校三学院根据自身特点，开展了具有特色亮点的主题活动。

为了响应习近平总书记向全党发出的伟大号召，外国语学院举办了“不忘初心，牢记使命”主题征文活动。参与此次征文活动的同学从自身实际出发，书写“不忘初心，牢记使命”理念，抒发爱党爱国情怀，弘扬正能量，观点鲜明正确，回应时代关切，彰显当代大学生精神风貌。

征文活动不仅推动学习贯彻习近平新时代中国特色社会主义思想往深里走、往心里走、往实里走，更是进一步扎实推进“不忘初心、牢记使命”主题教育，丰富了学生的文化生活，营造了校园良好爱国氛围，提升了学生爱国爱党意识。

征文比赛一等奖获得者王银珊同学说：“作为一名中共预备党员和学生党支部的干部，不忘初心，牢记使命，也是我们身为一名大学生具有的优秀特质。这个优秀特质引导着我们在学习中，领会十九大精神的核心要义与精髓，也时刻提醒着我们保持初心，督促着我们争做有理想、有担当的优秀大学生。”

今年11月13日，智能制造学院学生党支部在我校图书馆开展了“爱书籍、留书香”的志愿活动。8名学生党员参加了本次活动，志愿者们根据各自的岗位和分工，分别负责了图书的排架、图书整理、清洁卫生等。通过“爱书籍，留书香”的志愿活动及自身的工作体验，深刻体会图书馆既需要规范管理也需要读者们文明阅读，才能营造良好的读书环境。

智能制造学院另一个入党积极分子小组开展了“清扫落叶美丽校园”志愿服务活动。通过此次活动，使党员能够身体力行，从实事做起，一步一个脚印，脚踏实地培养能力，培养社会责任感。

形式多样的志愿服务活动体现了党员同志应在社会主义建设发展中当标兵、作模范，做到平常时候看得出来，关键时刻冲得上去，把党员先锋形象树立起来。

11月1日下午，文学与传媒学院在东莞党建文化主题公园开展“不忘初心、牢记使命”主题党日活动，接受红色教育的洗礼。

党员们在庄严的红色长廊进行关于“不忘初心、牢记使命”主题诗歌朗诵及讲述红色故事。学生党员代表朗诵了诗歌《致国歌》，分享了《杨靖宇的英雄事迹》等红色故事。活动尾声，通过不同主题的诗词飞花令，歌唱红歌及分享老党员事例的“游戏惩罚”中，使党员们在轻松有趣的氛围中接受传统文化的熏陶，坚定了入党初心与使命。

本次活动具有强烈的文传特色，增强了在场同志们热爱党、忠于党的意识，坚定了伟大理想信念，传递了红色正能量，不断强化了党性意识、责任意识和先进性意识，加强了党性修养，进一步增强了文传党组织的吸引力和凝聚力。

聚焦问题 谋划未来

以活动实践为展示，以理论学习为基础，外国语学院、文学与传媒学院和智能制造学院除了开展实践活动践行主题活动，还以理论学习为基底，深入探讨学习主题思想，为各学院日后发展谋划未来。

10月11日，智能制造学院党总支召开学院“不忘初心、牢记使命”主题教育意见建议征集工作部署会。唐洁书记带头认真解读学校提出的具体要求，要求领导班子和领导干部要带头抓好整改落实工作，要压紧压实责任，做到责任明确到位、措施落实到位、问题解决到位，努力为大家营造良好的教学工作氛围。

外国语学院党总支召开了对照党章党规找差距专题教育会议。刘浔书记导读了党章部分章节。赵东林院长导读了《关于新形势下党内政治生活的若干准则》，并结合自身经历谈了自己的学习体会。都振华副书记导读了《中国共产党纪律处分条例》中关于各类违纪行为处分的具体情形。全体领导班子成员还逐一对照中央关于党章党规提出的“18个是否”进行了发言，报告了自己存在的主要问题和差距，剖析了产生问题的原因并提出了主要整改措施和努力方向。

文学与传媒学院党组织开展主题教育专题党课，结合本学院特色，走进学生党员中去。学院党总支书记宋秋敏以“探索古典诗词中的理性思索及现实意义”为主题，指出传统文化的精髓是我国的文化自信、民族自信。中国国力的不断提升，让世界各地的人们都能学习到中国古典诗词创作的深远意义，也有利于实现中华民族文化的真正复兴。

在“不忘初心、牢记使命”主题教育工作中，各学院结合自身特色开展主题会议和党课，有利于帮助党员重新反省入党动机，深刻领会中国共产党党员的核心内涵，提高党性修养，进而发挥提高党支部的战斗堡垒作用，为后续基层党组织工作的开展提供助力。
