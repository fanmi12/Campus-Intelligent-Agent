# 军训花絮二：军中浪花

“团结就是力量，这力量是铁，这力量是钢......”校园里军歌嘹亮，威武雄壮，这厢刚唱完，那边又响起“我是一个兵”的歌声。这是13级军训的新生们在操场拉歌。军训学员身着统一的蓝色迷彩服，按连队围坐在一起唱歌。配合着银色的灯光，放眼望去，他们就像是涌动的蓝色浪花。

“教官切歌切歌...”一首未曾听过的革命歌曲把八连的同学们难倒了，和教官们打起了“游击战”想要换首歌曲。而这时的教官们也一改操练场上的严肃形象，这不，教官们开始和同学们配合起哄让郝连长献歌。

“郝连长到了吗”—“没有”“为什么没到啊”—“他害羞”

在教官和同学们的“夹击”之下，郝连长又一连唱了好几首。这些歌声，唱出了军人的自豪；这些歌声，唱出了城院学子共同的心声;我们是骄傲的军中浪花。
