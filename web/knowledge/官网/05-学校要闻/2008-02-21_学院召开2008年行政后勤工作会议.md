# 学院召开2008年行政后勤工作会议

2月20日，学院在315会议室召开2008年行政后勤工作会议，安排部署行政后勤工作。会议由副院长张林博士主持。院办主任王玉、人事处处长夏勇博士、总务处处长章德胜副教授、基建办主任叶树标、保卫办主任王现府在会上作了发言。

各部门负责人在发言中回顾了去年的工作，提出了新一年工作的初步计划。表示要继续提高行政人员的办事效率，不断提高服务水平；通过举办培训班，提升行政人员的综合素质；开展“星级文明办公室”的评选活动；召开跨部门的工作会议，加强各部门的联系；进一步完善绩效考核办法，结合岗位建立健全薪酬分配机制；继续加大人才引进力度，重点引进高层次人才和外教；继续推行青年教师导师制，继续组织教工进行暑期社会实践；制定优质服务措施，促进服务档次的提升；进一步加强职工培训，建立一支学习型团队；强化成本意识，优化资源配置，提高资源利用率；图书馆工程年内破土动工；进行教学楼改造；制定详细的应急预案，进一步搞好保卫设备的维护和更新。

副院长张林在总结发言中提出两点希望：一是希望各部门要认真贯彻十七大精神，继续解放思想，落实科学发展观，围绕“上水平，创特色”的目标高标准地做好本职工作；二是希望工作人员“增强服务意识，正确行使行政权力，提高机关办事效能”。
