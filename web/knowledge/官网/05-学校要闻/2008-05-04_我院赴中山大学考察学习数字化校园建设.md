# 我院赴中山大学考察学习数字化校园建设

4月29日，学院办公室副主任黄研晖带领各部门数字化建设负责同志一行9人，前往中山大学考察学习数字化校园建设，受到该校信息与网络中心副主任吴汝明的热情接待。

吴主任向我院考察组介绍了数字化校园建设的意义以及中山大学数字化校园建设的历程与经验，中大信息与网络中心信息管理部辛小霞老师介绍了校务管理系统的应用情况，该中心的技术人员演示了校务管理系统的各个子系统。我院考察组的同志根据学院的实际情况，就有关问题与中大信息与网络中心的人员进行了交流。

通过一天的考察学习，考察组同志认识到数字化校园建设不仅能提高工作效率和效益，还能提高学院的综合竞争力。考察组表示，将根据考察的情况，为学院数字化校园建设提出建议。
