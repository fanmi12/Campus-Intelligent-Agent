# 中山大学博导周全华教授为我院学生讲授生态信仰

5月22日，中山大学社会科学教育学院教授、博士生导师周全华教授应邀，在7B202课室为我院师生作主题为“生态文明和可持续发展——当代大学生生态信仰的构建”的学术讲座。

在讲座中，周教授紧紧围绕生态文明，列举生活实例引入探讨主题，深入浅出得介绍了生态主义的基本思想，如生态价值观、生态历史观、生态伦理观，旁征博引地重点讲解了生态信仰的构建，提出很多鲜活的观点和思想。

互动环节，同学们表现踊跃，积极提出问题，与周教授进行探讨，整场讲座精彩生动，在良好的氛围下，使同学们加深了对生态主义的认识。

思政部主任何鹏举教授主持讲座，他感谢周全华教授给师生们带来了一场生动的理论盛宴。周教授学贯东西、深入浅出的报告使师生间产生思维的火花碰撞，深受同学们的欢迎，以后，学校会组织更多人文社科类的学术讲座，让同学们有机会与专家进行对话与交流。
