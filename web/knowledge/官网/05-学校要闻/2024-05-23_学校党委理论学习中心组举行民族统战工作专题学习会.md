# 学校党委理论学习中心组举行民族统战工作专题学习会

5月22日，学校党委理论学习中心组举行民族统战工作专题学习会，深入学习贯彻习近平总书记关于做好新时代党的统一战线工作的重要思想、关于加强和改进民族工作的重要思想。党委书记章德胜主持学习会并讲话。校党委理论学习中心组成员参加会议。

会上，学校校长助理赵书山、党委组织（统战）部副部长陈东汉作主旨发言，与会成员分别聚焦主题，结合学习内容，围绕“如何推动学校民族、统战工作高质量发展，不断凝聚统一战线力量”，进行研讨交流发言。

会议指出，习近平总书记的重要讲话是做好新时代统战工作、民族工作的根本遵循，要完整、准确、全面贯彻落实。要牢牢把握团结奋斗的时代主题，自觉扛牢新时代爱国统一战线的历史使命，把党的领导和铸牢中华民族共同体意识贯穿学校民族统战工作全过程、教育教学全方位、人才培养全链条和党建思政工作始与终，全面推进新时代学校民族团结进步创建工作。

会议强调，要深入学习贯彻习近平新时代中国特色社会主义思想，深刻学习领会习近平总书记关于做好新时代党的统一战线工作的重要思想中“十二个必须”的实践要求，坚持不懈用党的创新理论最新成果武装头脑、指导实践、推动工作。要坚持党的领导，提供凝心聚力的坚强组织保障。要坚决把党的领导贯彻到学校统战工作和民族工作全过程，全面完整准确地贯彻落实习近平总书记提出的新理念新思想新战略，切实履行主体责任，坚持完善党委统一领导、统战部门牵头协调、各有关部门协调配合的大统战工作格局，继续支持民主党派统战团体加强自身建设，形成强大合力，凝心聚力开创统战工作和民族工作新局面，为学校事业发展提供广泛力量支持。
