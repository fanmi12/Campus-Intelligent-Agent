# 督导办公室召开2014-2015学年度第一学期教育教学信息员会议

11月13日，我院2014-2015学年度第一学期教育教学信息员会议在7B201教室召开，督导办公室全体工作人员和学生信息员参加会议。

督导办公室陈玲玲老师对上一学年学生教育教学信息员工作进行了总结，并对参加“我心中的好老师”征文活动的同学给予了充分肯定与表扬，希望今后有更多的学生信息员为老师点赞，积极写稿。

会上，聂映中教授宣读了关于表彰2013-2014年优秀信息员的决定，王锦锋副主任和聂映中教授为获奖学生颁奖。

优秀信息员罗杰城同学获奖学生发言。他感谢学院各部门及督导办公室及时解决学生反映的问题。特别对宿舍搬迁、饭堂菜价、暑假停水、学生申请课室等问题的处理感到满意。

院督学陈丁堂教授代表学院对学生信息员及时反映教学和生活中情况以及同学们诉求的负责任态度表示了肯定。陈督学指出，上学年对于同学们所关心的学风建设、网络、饭菜价格、生活用水、垃圾处理、宿舍调整等方面的问题，督导办公室都做了认真处理，学校领导和有关职能部门高度重视同学们的意见，能解决的问题都及时解决了。对一些短时间内难以解决的问题如校园中心湖水质差，校外公交车少，校园空气污染等问题涉及各种复杂因素，学校已经与市政府相关部门协商沟通，将逐步得到解决。这些工作难以做到尽善尽美，希望同学们理解。陈督学强调了学生信息工作的重要性及特点，鼓励同学们坚持实事求是的态度，要尽职尽责，敢于仗义执言讲真话。反映问题要真实、具体、快捷，并提出了学生在校期间要学得好、吃得好、睡得安稳、玩得高雅的理念。陈督学的讲话，博得了同学们的阵阵掌声。
