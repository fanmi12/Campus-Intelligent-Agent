# 我院教工子女六一活动精彩纷呈

6月1日，院工会举行了主题为“我们的节日?幸福在城院”教工子女六一联欢活动，让近百名孩子在这里度过了一个愉快的节日。

23名小选手的才艺大比拼，歌舞、器乐、武术、魔术花样百出；12名小宝宝爬行比赛的可爱表现给观众们带来欢笑；几十名孩子们在游泳池里的捉鱼比赛精彩激烈，收获颇丰；碧波荡漾的泳池，自由自在的鱼儿，与孩子们灿烂的笑容相映成趣。
