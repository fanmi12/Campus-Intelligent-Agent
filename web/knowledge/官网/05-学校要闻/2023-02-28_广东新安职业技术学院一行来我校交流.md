# 广东新安职业技术学院一行来我校交流

2月27日，广东新安职业技术学院党委委员、综合管理部部长邹侨尉一行9人莅临我校，就迎接广东省法治测评工作检查工作进行了交流座谈。学校校长助理、学校办公室主任、法制办公室主任孔增强，学校办公室副主任叶凯贞等人接待了广东新安职业技术学院一行，并在六楼会议室举行交流座谈会。

座谈会上，校长助理、学校办公室主任、法制办公室主任孔增强对广东新安职业技术学院一行的到来表示热烈欢迎，并介绍了我校基本情况，希望通过加强交流，共同做好依法治校工作。

学校办公室副主任叶凯贞介绍了我校作为试点单位迎接广东省法治测评工作检查的总体情况和具体做法。随后，双方围绕依法治校工作、校领导分管法治工作和规章制度建设、内部治理结构、法律风险防控、师生法治教育与权益保护、法治工作机构和队伍建设、法治工作成效等方面工作进行了深入交流。

广东新安职业技术学院一行还参观了我校图书馆、学术报告厅、悦香园、学生活动中心、学生饭堂、体育馆、运动场等地。
