# 每份荣誉背后都有一段艰辛的成长历程

“比你优秀的人比你还努力，你还有什么资格不去奋斗！”这是我院管理系2014级

市场营销2班邓思如同学的励志格言。这两天，她作为今年“金湾杯”广东省第七届大学生职业规划大赛本科组一等奖获胜者，频频出现在学院各大公众号推文中。

“去年工作学习太忙没赶上系部初赛，就错过了。”从大一开始就已收获满满工作经验的邓思如，想在毕业前再体验一翻校园舞台的滋味，踏上了2017年大学生职业规划大赛的征途。

成功，源自不懈的坚持

进入大学，邓思如对自己的未来也有过规划，但从未像比赛这样通过书面作品或者PPT演讲，系统地去分析思考。大赛让她由衷地感觉到这确实是一个很好的平台。邓思如介绍说，比赛内容非常多，除了规划书和PPT展示，复赛基本都需要现场发挥。一个半小时做PPT设计，现场90秒即兴演讲，三个半小时准备情景模拟和演讲，一个晚上准备主题演讲和PPT展示等等，都很难提前去做好充分的准备。

在复赛时，因考核需要，来自不同高校的学生组成四个团队，邓思如和其他高校的精英组成了一个叫“十人精神”的团队。让邓思如赞叹的是，在复赛PPT审核环节中，组员们都慷慨地把自己私藏的PPT共享，大家互相帮助。“我们不仅是对手，更是弥足珍贵的战友。令人骄傲的是，十人精神组的组员们分别拿下了大赛特等奖，还有2个一等奖、1个二等奖和6个三等奖。”

“最大的收获是得到了领导和老师们的帮助，收获了友谊，成就了全新的自己。”这一路走得确实很艰难，邓思如对给过她莫大帮助的老师们心怀感激。决赛的每个环节都得到了及时的帮助，不管是在演讲稿的调整、规划书的修正，情景剧的剧情和呈现方式，亦或是演讲的指导，再到后面自信满满地与各高校的精英同台竞技，都成为了邓思如大学期间最大的锻炼。

每一步艰难，折射愈夺目的闪亮

眼泪的存在，并不总是代表懦弱，它或许更能证明成功已在来的路上。

大赛让最令邓思如刻骨铭心的，就是备战决赛那段日子。她连续三天只睡了7个小时，一边修改规划书，一边排练情景模拟，还要准备演讲稿。“当时压力大到在宿舍边敲键盘边哭，而且还有其他工作要同时监管安排，压力非常大。”邓思如透露，决赛前10天，她根本不敢松懈，一方面是学校的重视，另一方面来源于对自己的严格要求。

每一条通往成功的道路，都不会让人走得轻松。因为没有接受过职业规划系统化、专业化的知识，在撰写职业规划书时，邓思如也曾万般茫然。在决赛中，占50%分数的是职业生涯规划书，而职规书中所包含的理论知识、测评工具、决策模型、分析模型，她都比较陌生。得知其他选手大多都经过系统化的学习时，压力也曾如空气环绕。“其他选手都很优秀，一旦掉以轻心，就会被比下去”，然而邓思如从未犹豫过前进的脚步。

每个人都希望自己站在舞台上是光彩夺目的，是最优秀的，邓思如也不曾例外。直率的她坦言，就是奔着特等奖而来。虽然决赛时演讲获得第一，但后来情景模拟环节中出了些许瑕疵，导致不够时间将剧情完全演绎，她说，“我是追求完美的人，即使拿了一等奖，但还是会因为没做到自己心目中的完美而失落。”

万变的时代，走目标坚定的道路

在瞬息万变的21世纪，邓思如认为，作为大学生都要把握好自己所从事的行业发展趋势。“不要急着求回报，不要太在意眼前的得与失”，职业规划是长远的，一定要知道自己所从事的职业行业发展趋势，才能更好地把握自己的职业生涯，更好地适应时代的发展。

“比赛让大家关注和记住了东莞理工学院城市学院，记住了我是这个学校的学生。”邓思如表示，这次比赛使她积累了人脉、提高了综合实力，也提升了自己的核心竞争力。她认为，大学生应该保持谦卑，不要给自己太多的限定，多尝试体验，“一生当中会遇见很多意外，当意外来临时，我们要去接受、去面对，并且努力去实现自己的目标！”
