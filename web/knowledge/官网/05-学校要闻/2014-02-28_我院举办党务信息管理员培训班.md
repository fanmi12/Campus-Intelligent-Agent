# 我院举办党务信息管理员培训班

为加强我院党务工作数字信息化建设，2月27日，组织人事处组织科在图书馆T114机房举办党务信息管理员培训班。参加培训的有各总支、各直属支部党务信息管理员，组织科李钰副科长担任培训主讲。

通过本次培训，各部门对党务信息管理系统的结构、数据管理员的权限、职责等有了全面的了解。信息员们表示在组织科的指导及各党总支、直属支部的共同努力下，一定能充分利用好党务信息管理系统的平台，把学院的党建工作做得更好。

据悉，党务信息管理系统是我院自主开发的一个在线平台，今年2月正式投入使用。
