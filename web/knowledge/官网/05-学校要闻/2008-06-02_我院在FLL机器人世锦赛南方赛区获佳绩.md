# 我院在FLL机器人世锦赛南方赛区获佳绩

5月25日，首届FLL机器人世界锦标赛中国南方区公开赛在深圳会展中心举行。由我院梁利姣、张娟老师指导的计算机与信息科学系代表队（肖亦贤、袁子豪、周健峰同学组成）荣获二等奖。

比赛共分4个组：小学组、初中组、高中组以及成人组，每组都有10余支代表队参加。在比赛中，选手们充分发挥想象力，运用所学到的理论与技术，提出了解决问题的科学办法。

据悉，FLL（First LEGO League）是面向青年学生开展的一项以科技设计与实践为导向的国际性公开教育活动，已成为目前最具影响力的国际性青少年机器人竞赛活动之一。
