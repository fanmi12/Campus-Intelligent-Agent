# 学校党委学习贯彻习近平总书记在二十届中共中央政治局第九次集体学习时的重要讲话精神

学校党委学习贯彻

习近平总书记在二十届中共中央政治局

第九次集体学习时的重要讲话精神11月2日，校党委书记章德胜主持召开党委会议，学习贯彻习近平总书记在二十届中共中央政治局第九次集体学习和习近平总书记关于民族工作系列重要讲话精神。党委委员参加会议。

会议认为，习近平总书记在集体学习时的讲话，充分体现了以习近平同志为核心的党中央高度重视民族问题和民族工作，意义重大。习近平总书记关于民族工作的新理念新观点新要求，进一步阐明了筑牢中华民族共同体意识的重大意义，为新时代做好民族工作指明了方向。

会议强调，要深刻学习贯彻习近平新时代中国特色社会主义思想和习近平总书记一系列重要讲话精神，深刻领会丰富内涵、核心要义和实践要求，以党的创新理论为指导，不断加强和改进学校民族工作。

会议要求，全校各单位要按照习近平总书记重要讲话精神和“铸牢中华民族共同体意识”的民族工作主线，继续丰富活动形式来提升少数民族学生教育、管理和服务水平，并持续做好少数民族教育、管理和帮扶，不断提高少数民族学生的思想政治教育工作效果和质量，做好学校的民族工作，增强各民族学生的情感联系、文化共性和心灵共鸣，教育引导少数民族学生坚定理想信念，铸牢中华民族共同体意识，坚决拥护中华民族团结，为中华民族伟大复兴凝聚力量。
