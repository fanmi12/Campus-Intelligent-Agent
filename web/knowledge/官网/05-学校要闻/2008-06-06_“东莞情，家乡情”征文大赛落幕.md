# “东莞情，家乡情”征文大赛落幕

为丰富校园文化生活，鼓励文学创作，挖掘文学人才，进一步提高学生的文学创作水平，学院在科技文化艺术节期间开展了旨在反映祖国改革新貌，展现学子浓浓乡情的“东莞情，家乡情”征文大赛。

本次征文大赛面向全院师生征稿，要求参赛师生在征文中以歌颂东莞、赞美家乡为题材，畅谈生活、学习中的体会和感受，描绘家乡日新月异、翻天覆地的巨大变化，表达浓厚的家乡情节，展现独特的地域文化。

经过4月25日－5月20日的为期一个月的全院征集，大赛组委会共收到参赛作品110余份。院党委宣传部部长、新闻中心主任何鹏举副教授，《城市学院报》主编唐耀碧老师，新闻中心刘哲老师，思想政治理论课教学部徐小娟老师、吴晓斐老师及《城市绿洲》报社社长黄科同学担任本次比赛的评委。

评委们普遍反映，本次比赛作品主题鲜明，文风朴实，且作品体裁丰富，既有抒情散文，亦有优美诗歌，同时不乏真情流露的记叙文等。同学们用手中笔，抒发了自己对家乡的浓浓情意，热情讴歌了对家乡的热爱之情。
