# 我院首届口语表达大赛圆满落幕

由院团委主办，文学与艺术系团总支、学生会承办的2008年首届口语表达大赛决赛于5月22日晚在学术报告厅举行。院党委朱冰副书记，陈庆祝、孟颖、叶凯贞等系领导到现场观看了比赛。院办主任王玉，学生处副处长、院团委书记丘永辉，院团委副书记杜鹏举，徐世杰教授和唐耀碧老师担任本次大赛的评委。

参加决赛的两支队伍分别来自财经系和文学与艺术系。经过主题演讲、即兴演讲、现场采访和辩论赛四个环节的比赛后，文学与艺术系以476.9的高分摘得口语表达大赛桂冠，财经系以465.75分获得亚军。

比赛结束后，丘永辉老师对活动给予了高度的评价，徐世杰教授就整场口语大赛进行了点评。

此外，管理系获得本次比赛最佳组织奖，社会科学系和金融与贸易系获优胜奖，财经系于歌、文艺系梁羡雯、文艺系宋蜜蜜三名同学分别获“优秀辩手”、“优秀采访者”及“优秀演讲者”称号。
