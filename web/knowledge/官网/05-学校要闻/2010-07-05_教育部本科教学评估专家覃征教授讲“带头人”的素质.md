# 教育部本科教学评估专家覃征教授讲“带头人”的素质

教学、科研、管理者带头人应具备哪些素质？6月30日，教育部本科教学评估专家、清华大学博士生导师、城市学院兼职教授覃征，就这一问题为我院系部主任、教研室主任、教务处机关工作人员、教学秘书做了两个小时的精彩报告。

覃征教授认为，“带头人”总的任务是：承担科研课题，培养工作团队，打造精品课程，获得研究成果。具体来说，就是上好课，做好科研工作，干好份内事。

关于上课的问题，他认为，“带头人”都要上本科生的课，治学要达到“三境界”，课程要精雕细刻。讲课方法归结为四句话12个字：讲什么，怎么讲，是什么，为什么。课前，要确立教学目标，梳理学科知识的脉络；寻找产业背景应用；选择合适的案例与素材；加强各学科间的联系，搭建知识网。课中，运用启发式教学。

关于科学研究的问题，他认为，“带头人”的任务是科研攻关，组织研发，获得项目。一是能从“863”计划、国家自然科学基金等国家、省、市以及职能部门的“盘子”里找到科研项目和经费；二是有较多的论文被发表，有自己的著作和专利；三是在研发过程中善于进行合理的团队成员配置，科学合理的任务分工，建立合理有效的奖惩机制。

关于管理工作问题，他认为，“带头人”要干好一件重要的份内事情，就是带好自己的团队。无数经验证明，团队产生科学精英，现代科学只有在团队中才能获得成功，个人只是团队中的一员。“带头人”要让团队中的每一个成员都知道为什么干，谁来干，怎样干的问题。要善于使用那些肯做事、肯吃亏、虚心接受批评、有创新精神的人；为他们提供服务，配置好人、才、物，搭建施展才华的平台。

总之，高校要大力培养“教学—科研—管理带头人”，搭建优质的平台，建立合理的机制，给他们更多的荣誉与权威，更多的的机会和资源，使他们敢于、勇于、善于承担风险；想做事，能做事，做成事，出成果；不怕吃亏，不怕吃苦，不怕失败。
