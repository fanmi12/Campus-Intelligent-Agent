# 开学首日 我院教风学风浓郁

度过了为期一个月的愉快寒假假期，2月13日迎来了开学的第一天，我院新老校区全体师生以全新的面貌和愉悦的心情迅速投入工作和学习之中。

清晨刚至，同学们便个个精神饱满地按时到课室早读、上课，而任课老师们也准时到岗为同学们奉上一场场精彩的课程，整个校园内学风浓郁、教风斐然、气氛活跃、秩序井然……

这一切让前来视察的学院领导们为之欣喜。上午第一节铃声刚响，学院领导杨敏林、程发良、朱冰在教务部门邓成良、高香林等的陪同下，来到公共教学楼和工业技术大楼视察开学首日的开课情况。在抽查多间课室时，看到同学们认真听课、积极答问、精神状态良好，老师们精心备课后的精彩授课，院领导感到非常满意。随后，院领导又来到位于工业技术大楼的金工实习车间，看到经过寒假加班建设好的实验车间里，各项硬件、软件和安全设施都已准备到位，投入教学而感到欣喜，并叮嘱老师和实验员要注意教学安全。

据教务处统计，开学首日，我院任课教师全部按课表安排到岗上课。本学期共需各类教材477种，已到位458种，到位率96%，剩余教材将于本周内到位。
