# 新学期工作部署会议顺利召开开启国际教育新征程

2025年2月22日早上，国际教育学院新学期工作部署会议在学院学生活动中心隆重举行。学院领导班子及全体教职工齐聚一堂，共同明确新学期工作方向，部署重点任务，以饱满的热情和昂扬的斗志迎接新挑战，开启国际教育新征程。

会议伊始，赵书山院长传达了学校新学期工作会议精神。他表示新学期学院将推进新型英语人才培养模式、全英语授课模式及多语言共存外语教学模式改革。完善人才培养方案、做大121中美合作项目、做强中外合作项目、做稳国际学历教育升学项目、抓好师资队伍建设、升级改造实训室。实现港澳台华侨生成建制招生及中外合作项目的突破。建立全英语授课教师资格认证制度，打造“外语+”双技能型教师。提升教育质量与品牌建设，深化中学合作，规范培训机构合作，创新宣传方式。

随后，方伟华执行校长的发言明确了学院未来的发展目标和方向，重点围绕国际化、专业建设、教学改革和招生策略展开。成立语言中心并推进英语教学改革，制定标准化考核体系，以成果为导向，用硬核考试水平证明教学质量。全英教学是重点，计划借鉴其他院校经验，围绕“1+2+1”项目展开，同时推进“4+0”项目，方校强调，2025年和2027年是学院最艰难的时期，需同心同德，坚持党的领导和教学基本规律，在发展中解决问题，争取在年内取得阶段性成果，实现超越性发展。

丛蕊副院长聚集教学工作展开部署。强调守区创新计划通过组建合英教学团队，提升英语商务基础和公共外语能力，并结合跨境电商和对外汉语拓展模块，全面增强语言应用能力。同时，考研团队提供基础、专项和冲刺服务，确保学生在考研各阶段获得针对性支持。整体服务内容丰富，旨在满足多样化的学习需求，提升综合竞争力。

刘亚雷副院长围绕学院发展建设、学历提升项目与多元国际项目协同驱动的教育生态展开，短期研修、联合科研等国际项目则深化跨国合作，拓展师生全球视野与实践能力。与此同时，学院聚焦英语科研发展，以团队建设、项目管理、成功转化为三大支柱，打造跨学科国际化科研团队，以科研反哺教学、以合作链接全球，构建可持续发展教育范式。

紧接着，罗文芳党总支书记指出指出党总支、团总支、学生会等的组织建设工作已提上日程，计划召开学生干部及教工党员座谈会，广泛听取师生意见。学生返校后，学院领导与全体学工班主任通过召开班会、走访宿舍等方式，向学生传达了本学期党建及学生工作的思路，并部署了近期重点工作，确保各项工作有序推进。

此次新学期工作部署会议的顺利召开，为国际教育学院新学期的工作明确了方向，凝聚了共识，激发了全体教职工的工作热情。相信在学院领导班子的带领下，通过全体教职工的共同努力，国际教育学院将在国际教育领域取得更加优异的成绩，为培养适应全球化发展需求的优秀人才书写新的篇章。
