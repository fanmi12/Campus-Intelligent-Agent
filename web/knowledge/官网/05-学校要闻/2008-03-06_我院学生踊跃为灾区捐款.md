# 我院学生踊跃为灾区捐款

春节以来，学院团委学生会积极组织同学们捐款救灾。据统计，到目前为止，全院共募捐21000元。

今年，湖南、湖北等地区遭受罕见的雨雪冰冻。为响应中央关于支援和帮助受灾地区的指示精神，学院开展了募捐活动，活动的口号是“人的心不是用钱的多少来衡量，能力有大小，但爱心是同样珍贵和无价的，让我们一起奉献爱心吧！”
