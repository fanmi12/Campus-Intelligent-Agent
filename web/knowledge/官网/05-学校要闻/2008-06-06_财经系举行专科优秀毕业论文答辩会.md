# 财经系举行专科优秀毕业论文答辩会

<6月5日，财经系2008届专科优秀毕业论文答辩会在学术报告厅举行。

答辩小组由系主任高香林教授以及邓传海教授、郑阿泰副教授等6人组成。08届会计、电子商务、会计电算化三个专业的16名学生参加了答辩。会计教研室全体教师以及毕业生参加了旁听。

答辩会上，答辩学生首先结合课题的选题背景、国内外的研究现状、思路和方法、研究成果、参考文献等方面运用多媒体陈述报告。随后，答辩组成员对课题的研究环节进行分析和询问。最终，答辩学生针对老师的提问，结合自身在做毕业论文过程中的认识，综合分析思考与答辩。

本次答辩历时3个小时。高香林教授说，论文答辩不仅检验了毕业生的论文质量，也有助于他们进一步完善自己，为今后的学术研究打下坚实基础。
