# 党委通报基层党组织“量化考评”情况

5月27日，学院党委在410会议室召开总支（直属支部）书记会议，通报基层党组织工作量化考评情况。

据通报，今年5月，院党委组织各总支、直属支部书记对管理系等单位进行了党组织工作量化考评。考评结果表明，各总支（直属支部）非常重视考评工作，扎扎实实地做了大量的工作，注重党建工作原始材料的归档与整理，狠抓党务工作规章制度的建立与落实，基层党建工作制度化已具雏形，逐步走上了正轨。工作中存在的主要问题有：会议主题不明确，会议记录不够规范，原始资料收集不完整，党员活动室建设滞后，党员活动形式单一，入党积极分子的思想汇报材料缺乏真情实感。

党委要求，各总支（直属支部）要以这次考评为契机，正视存在的问题，制订整改措施，使我院的党建工作更加制度化、规范化，迈上一个新的台阶。

党委书记朱志德就“七一”表彰会及评优工作做了安排部署。
