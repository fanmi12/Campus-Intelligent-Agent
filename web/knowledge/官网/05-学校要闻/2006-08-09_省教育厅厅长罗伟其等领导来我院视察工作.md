# 省教育厅厅长罗伟其等领导来我院视察工作

8月9日上午，省教育厅厅长罗伟其，市委副书记、东莞理工学院党委书记刘树基，大运会组委会副主任、副市长吴道闻等在院长安少华教授的陪同下来到我院视察工作。

罗厅长等领导视察了校容校貌，观看了我院为大运会举办的体育摄影展览，并询问了校园建设、新生录取等工作情况。

罗厅长等领导视察结束后与院领导合影留念。
