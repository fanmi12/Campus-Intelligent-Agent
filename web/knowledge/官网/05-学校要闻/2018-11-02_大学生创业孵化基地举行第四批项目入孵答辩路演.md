# 大学生创业孵化基地举行第四批项目入孵答辩路演

11月1日下午，我院大学生创业孵化基地路演暨第四批申请入孵项目答辩会在招聘大厅顺行。担任大赛评审有:广东盛创蜂果孵化器有限公司董事长赖万里、天盛投资发展有限公司创始人、海西人才孵化基地创业导师许曼芬、东莞市蚁巢科技企业孵化器有限公司联合创始人兼董事长黄德玉、广州赛智信息技术有限公司总经理罗志坚、商学院沈圣伦博士、创新创业教育指导教研室主任邓葵璋。

黄兢副院长出席了活动并致辞。他对导师评审团表示真挚的感谢，对创业孵化基地前三批路演的创业团队给予了高度评价。同时也对本次路演的创业团队寄予了厚望，希望通过大学生创业孵化基地提供的场地、技术、辅导等多种创业指导与服务，能抓住机会，展示才华，扶持更多的项目落地。

此次答辩分为三个环节:项目展示，公开答辩，导师点评。各创业团队在15分钟之内通过PPT展示、实物展示等方式对创业项目进行解说。各团队的精彩演说和答辩将现场气氛推向高潮。

在答辩环节，评委们从多角度出发，对每个项目提出问题。主讲人从容而冷静地回答，展示了团队的能力与自信，赢得了阵阵掌声，也让在场的观众观看了一场精彩的“思维碰撞”。

各评审人也对团队进行了精辟的点评，对团队的建设和接下来的发展提出了可行的建议，使参与者和观众受益匪浅。
