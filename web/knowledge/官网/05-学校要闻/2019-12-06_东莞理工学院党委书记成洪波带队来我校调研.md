# 东莞理工学院党委书记成洪波带队来我校调研

12月3日上午，东莞理工学院党委书记成洪波、组织部部长彭晓波、监察处处长邢大立来我校开展调研工作，听取了我校工作汇报和学校领导班子建设情况，并进行工作指导。我校党委委员、党政领导班子等领导干部参加了会议。

针对当前我校在党建、机构设置、队伍建设、二级单位建设等方面存在的主要问题，我校党委书记章德胜、校长王卫平分别就学校近期党建、主题教育、人才培养等情况向成洪波书记进行了专题汇报，并提出了相关整改措施及改进思路。

成洪波书记听取了汇报，并对我校党政领导班子“不忘初心、牢记使命”主题教育专题民主生活会、专项整治等工作提出了重要意见。他指出，主题教育是加强党的建设、把短板补齐的一次重要契机，城市学院党政领导班子应该充分珍惜、重视这次机会，守初心、担使命，找差距、抓落实。要深刻领会党的十九届四中全会重要精神，完善学校治理体系，认真思考如何实现城市学院治理体系现代化建设这一重要命题。

成洪波书记强调，学校领导班子要迅速健全党委工作机构，切实加强党的组织建设；切实完善办学治校的领导体系和运行机制，实现依法办学、依法治校；加快提升党的基层组织的组织力，提升工作及服务水平；全面加强教师队伍建设，为教师提供良好的工作环境；严格落实安全稳定的各项责任，切实维护学校的安全稳定。学校党政领导班子要团结一致，以主题教育为契机，抓紧落实整改，提升党的组织建设，发挥党员先锋模范带头作用，不辜负上级和师生群众的支持与信任。

学校党委书记章德胜代表学校领导班子，对成洪波书记来我校调研并提出宝贵意见致以诚挚的感谢。他表示，学校领导班子将根据成洪波书记的意见精神，尽快落实主题教育及民主生活会工作整改，并以更高更严的要求做好党的建设，促进城市学院的健康发展。
