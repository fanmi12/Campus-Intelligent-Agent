# 东莞理工学院城市学院董事会召开一届六次会议

4月25日，东莞理工学院城市学院董事会在315会议室召开一届六次会议。城市学院董事会、监事会全体成员参加了会议。

本次会议的主要议程有：审议通过了学院2008年财务预算和2008年招生计划；听取和审议了财务管理有关问题的说明；听取了副董事长、院长安少华教授关于落实教育部26号令文件精神及全省独立学院工作会议有关情况的通报。

东莞理工学院院长、城市学院董事长杨晓西教授主持会议并讲话。
