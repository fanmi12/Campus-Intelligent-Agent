# 我院荣获全国软件设计竞赛二等奖

计信系由王浩亮老师指导学生设计的“基于安卓的移动应用开发”获得“中国软件杯”大学生软件设计大赛二等奖。

“中国软件杯”大学生软件设计大赛由工业和信息化部、教育部、江苏省人民政府联合举办，今年为第一届。本次大赛历时5个月，于8月底结束。大赛采用命题形式，全部题目均来源于软件企业生产过程中的实际问题，有些是业界迄今没有很好解决的问题。此次大赛堪称中国软件行业中规格最高、最具影响力的顶级软件大赛。全国共有500所院校4500余名大学生报名参赛，其中“211”类和“985”院校参赛队占49%，共有100支队伍进入决赛。最后20强争1个特等奖和4个一等奖。特等奖和一等奖由中科院软件所（研究生）、清华大学、南京航天航空大学等五所院校分别获得，我院王浩亮老师带领09级软件工程名为“蜂”队的莫栋鸿、袁卓航、刘慧鹏3名学生设计的“基于安卓的移动应用开发”获得二等奖，同时获得二等奖的还有华南理工大学等队。
