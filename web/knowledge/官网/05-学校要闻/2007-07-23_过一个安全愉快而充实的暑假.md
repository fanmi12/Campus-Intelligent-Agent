# 过一个安全愉快而充实的暑假

7月22日，学院在315会议室召开全院中层干部会议，安排部署暑假期间的工作，让教职工过一个愉快而有意义的暑假。

学院副院长

张林副教授就暑假期间的工作发表了重要讲话。他说：学院决定学生和教职工分别于7月21、23日放假，9月2日

开学上课。虽然放假休息，但学院多项工作不能停，安全保卫不能松，不仅如此，还要做得更好，只有这样，才能确保新学期顺利开学。为此，学院要求，当前应认真做好以下几方面的工作：一、注意安全，做好防火防盗工作。近日，由院办牵头有关部门参加，对安全工作进行一次大检查。二、院、系领导应带头坚持值班制度，做到通讯、网络通畅。三、抓好樟村教工生活园区、教工饭堂、新学生公寓、停车场、汽车进出自动刷卡系统等工程建设，确保按时交付使用。四、严格执行招生政策，提高生源质量，完成招生计划。五、维护整修好学生宿舍、课室等场所的环境、教学的设备和仪器。制订学生、教师住宿方案，及时采购寝室卧具。六、做好留校师生的水电及饭菜供应工作，图书馆要按时开放。七、关心和慰问参加社会实践的青年教工。八、做好开学前的一切准备工作。

学院党委委员、院办主任王玉主持会议。
