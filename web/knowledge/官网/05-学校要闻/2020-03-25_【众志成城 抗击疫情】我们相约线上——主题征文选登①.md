# 【众志成城 抗击疫情】我们相约线上——主题征文选登①

我校坚决贯彻落实教育部、省教育工委、省教育厅的重要部署，从3月2日起全面开展线上教学活动以来，学校共有498位任课教师、15900名学生开展了1303门次课程线上教学工作，教学秩序平稳，在线教学质量稳步提升,广大师生的优异表现彰显了新时代的城院精神。学校领导强调，我校重点关注学生在线学习的效果，切实保障网络课堂的教学质量。3月19日，我校组织了《我们相约线上》学生主题征文活动。从今日起，精选刊发部分优秀征文作品。

一、网与课

——文学与传媒学院 许子欣

庚子岁初，一场突如其来的新冠肺炎袭击了我们。延长的寒假不得不让很多学校开始网上上课，每个老师都变成了主播。对我个人来讲，线上学习远不及在学校的课室里上课那么有趣，因为在家，线上学习会受到许多外界的干扰因素，从而使我不会那么专心地投入到学习中。但是上了三周的课程，我觉得还是比第一周的时候好很多了。为此我在心里给自己鼓个掌。

虽然在家学习没有在学校效率高，但是我们不管在哪里学习，都要保持着自己的那份热爱与激情，对于学习，我们不容一丝懈怠，需要全身心地投入到学习中，一步一步地突破自己，而不是想着在家里我们就可以放飞自我，不好好听课。一次病毒使我们与网课连接在一起，网课是网与课，网络不要沉迷太多，上课要预习，下课要复习，跟在学校一样。

二、用心上网课

——法学院 庄斯慧

今天是我为了防控疫情在家待的第2个月，也是我在家上网课的第20天。起初，由于我作为一名学习委员，需要核实班上同学是否注册进入课群时，我自己也弄得头晕目眩，但好在最后网课还是顺利开展，我也开始投入到紧张的学习中。

说实话，我的自制力有点弱，在家学习我特别容易受到周围环境的干扰，但是我有自己非常喜欢的老师，特别是我的刑法老师申思琦。我觉得她讲课好温柔，而且讲得很细致，也会与同学们互动。这样子我们一来一回的，我觉得我也学进去了。当然其他老师也特别好，每个老师都讲得很好……我会用心读书的！

三、疫情之下的网课

——文学与传媒学院 黄丽环

疫情无情，人间有爱。虽然我们未能齐聚在教室里上课，但是网课学习也更加考验自己的学习自主和自律。网上课堂丝毫没有消减掉老师们对同学们的关爱。无论是课上授课，还是课后答疑，老师们乐意悉心教导着同学。在这个特殊时期，作为城院文传人，尽管我们不能够与广大医护人员以及科学家并肩作战，但我们能够以笔为武器，认真上好每一节网课，做好防疫措施，这便是我们最好的作战。在全员的配合和努力之下，我们总可以等到那个春暖花开之日，待到那时我们齐聚在校园，感受那来之不易的美好！
