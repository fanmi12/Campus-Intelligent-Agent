# 我院78名学子为莞商大会志愿服务

9月18日，我院与东莞理工学院、广东医学院、东莞职业技术学院四所高校组成400余名学生志愿者队伍，为世界莞商大会服务。

据悉，我院78名志愿者主要是在市会议大厦主会场、东荣酒店、新城国际酒店、铂尔曼酒店从事会务协助和接待引领嘉宾等工作，其中6名同学担任小组长工作。

我院志愿者们的积极表现，得到了东莞团市委的充分肯定。志愿服务工作结束后，市领导李小梅、张科、钟金泉与我院志愿者在会议大厦合影留念。
