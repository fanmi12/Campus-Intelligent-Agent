# 我院深入开展党的群众路线教育实践活动专题网站上线

3月6日，由东莞理工学院城市学院党的群众路线教育实践活动领导小组办公室主办、院党委宣传部承办策划的学院深入开展党的群众路线教育实践活动专题网站隆重上线。

该网站是学院教育实践活动信息交流的重要平台，是城院师生参与和活动的重要载体。网站设有“城院动态、上级精神、领导讲话、学习园地、媒体评论、案例漫画、宣传挂图” 等栏目，具有新闻宣传、案例展示、学习服务等功能，将全方面、多角度、立体化反映我院群众路线教育实践活动的开展情况，及时关注活动进程，集中展示活动成效。

广大师生可以直接通过学校首页的图片链接访问该网站。
