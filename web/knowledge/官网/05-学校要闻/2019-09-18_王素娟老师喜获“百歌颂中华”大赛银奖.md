# 王素娟老师喜获“百歌颂中华”大赛银奖

9月17日晚，由省委宣传部、省直机关工委、省教育厅等承办的“我和我的祖国——广东省第十三届‘百歌颂中华’歌咏活动”精品展演在广东艺术剧院圆满落下帷幕。我校艺术学院王素娟老师喜获歌手（组合）类银奖。

本届“百歌颂中华”歌咏活动自5月份启动以来，全省参赛歌手（组合）共约2000组，总参赛人数超过5.5万人，赛事精彩纷呈，竞争非常激烈。

王素娟老师代表中共东莞市委宣传部参赛，值得一提的是担任钢琴伴奏的是艺术学院优秀毕业生陈榕。两位珠联璧合的演绎充分展现出我校师生的精神风貌和专业水准，一曲《边境的小鸟》以饱满的激情和嘹亮的歌声赞颂了边疆的大好景色和伟大的祖国，向祖国传递真挚的祝福，抒发南粤人民迈步新时代的万千豪情。
