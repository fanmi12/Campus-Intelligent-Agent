# 东莞理工学院城市学院董事会2014年第二次会议召开

董事会研究决定：聘任黄兢、周庆、刘玉侠同志为东莞理工学院城市学院副院长；免去张林同志副院长职务，免去陈丁堂同志院督学职务12月29日，城市学院董事会2014年第二次会议在城院行政楼504会议室召开。董事长麦照容，副董事长李琳，董事吕琦元、麦建红、黎建烨、杨敏林、王卫平、麦绮琳出席了会议。

会议由麦照容董事长主持。

会议决定，聘任黄兢、周庆、刘玉侠同志为东莞理工学院城市学院副院长；免去张林同志副院长职务，免去陈丁堂同志院督学职务。

会议审议通过了学院2012-2013学年度、2013年-2014学年度预算执行情况，审议并原则通过了学院2014-2015学年度预算方案。会议要求，学院应成立投资与预算委员会，设立学院发展基金，科学统筹、管理学院的办学经费；加强预算执行情况的监督及管理，提高管理效能，完善相关制度建设，确保预算的制定及调整有章可循。

会议审议了学院2013-2014学年度工作总结，审议并原则通过了学院2014-2015学年度工作要点。会议一致认为，在杨敏林院长的带领下，学院教学状态良好、管理工作高效。董事会希望城市学院在新的学年里，进一步加大国际合作力度，加强师资队伍建设，加快薪酬福利体系改革等方面的工作力度，推动学院的稳健发展。

会议还审议并原则通过了学院发展战略规划，审议了学院新增专业申报的报告。
