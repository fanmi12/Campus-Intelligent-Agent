# 学生处召开2012年学生事务管理交流暨研讨会

12月10日，学生处在学生活动中心217室召开学生事务管理交流暨研讨会。各系部党总支书记、学生处相关工作人员以及学生辅导员参加会议。

会上，孔增强副处长就高校学生事务管理的定义范畴、结构体系、应急处置、工作重点等方面做了详尽的解读，并结合时事热点与我院学生管理工作中出现的具体问题发表了自己的看法与建议。

文传系、城环系、财经系作学生事务管理专题工作的经验介绍。文传系的“五星党员规范化管理”在项目理念与项目运作上都具有可操作性与规范性，不仅优化了党员的队伍素质，而且增强了党总支的凝聚力与号召力。财经系以培养青年领袖为逻辑起点，以党员带动群众，将党风建设深入到学生的学习实践中。城环系分析学风建设中学校和学生两个层面存在的问题，提出了加强“班主任助理”工作的思路和对策。管理系、艺术系、计信系、金贸系代表也作了主题发言。财经系的专题工作“理想与青春共成长——基于青年领袖理论的学生党员成长项目”凭借规范的管理、显著的成果、精彩的讲演脱颖而出，被选送参评省级学生事务管理精品项目。

党委宣传部部长何鹏举做了总结发言。他充分肯定了学生管理工作者队伍的敬业和高水平，认为此次交流会不仅对以往的工作做了思考、研究和总结，而且对今后的工作起到了积极的促进作用。他认为，教育与管理一直是学生工作的两大主题，全体学生工作者既要埋头苦干，认真工作，又要抬头看路，善于总结，使学生工作做成具有创新特色、东莞特色。
