# 拼出青春实力  享受运动快乐

5米05！叶翠诗同学跳出广东省大学生运动会跳远项目女子甲组最好成绩，夺得该项赛事冠军！

助跑、踏板、腾空、落地，叶翠诗同学轻捷的身影在省运动赛场上划出一条美丽的弧线，像只轻盈的蝴蝶落在沙坑……5月19日，广东省第十届大学生运动会田径女子甲组跳远决赛在广东外语外贸大学进行，我校外国语学院2018级叶翠诗同学以5米05夺得冠军，成为我校参加广东省大学生运动会以来的首枚金牌。

第一步，助跑跳出积攒的力量

虽然不是体育生，但赛场上的每一次起跳，叶翠诗都会奋力跳出积攒已久的力量。

叶翠诗同学是东莞本地人，自小学三年级第一次参加洪梅镇运会后，便与跳远运动结下了不解之缘。每年，她都会去参加洪梅镇和学校的运动会。在去年我校运动会上，她以4米28的好成绩获得女子跳远比赛第一名，从而受到学校田径队教练徐吉祥老师的青睐，并邀请她加入田径队。

叶翠诗加入了田径队，开始为本届广东省大学生运动会备战。田径队的训练时间是周一、三、五下午四点开始，晚上八九点才结束。叶翠诗介绍说，训练过程十分枯燥、辛苦，为了把一个动作练到位，每天都要不断地重复着一样的动作，一次有又一次的助跑、踏条、跳跃……。沙池推平了再跳，跳了再推，不断地寻找自己的不足，一点点地进步与改善，努力突破自己。

她告诉记者，由于省大运会即将到来，每天训练时间也渐渐有所增加。寒假期间，在同学们都陆续离校后，叶翠诗和她的队友们仍留校进行了为期九天的加训。

功夫不负有心人。在教练耐心的指导下，叶翠诗学到了跳远的动作要领以及技巧，在此次省大运动会中赛出了5米05的佳绩，夺得了金牌。

第二步，踏板跨出坚定的信念

学校组建田径队是为了参加省大运动会，这是一支信念感极强、目标十分明确的队伍。叶翠诗同学表示，自己备受这种坚定的信念鼓舞，作为田径队的一名运动员，深受城院坚持、努力、刻苦的体育精神感染。

“正是有这种赛前刻苦训练、用平稳心态的态度面对比赛、争取发挥最好实力的这种信念，让我在比赛中超常发挥。”决赛共有12名选手参赛，叶翠诗同学实力冠绝全场。她第一跳就以4米78排在第一。稳拿冠军后的叶翠诗同学进入自我突破境界，第二跳5米05刷新个人最好成绩。

“对于这个成绩，我自己也有点意外。在赛前的几次训练中，我还存在踏不上板的小失误。教练鼓励我不要畏惧，大胆犯规，所以当时在比赛的时候也没有给自己多大压力。”叶翠诗表示，“体育竞技，规则是残忍的，机会是不容错过，需要坚定的信念，轻松、良好的状态去发挥最好的水平。”

最后一跃，腾空展开有力的翅膀

田径场之外的叶翠诗同学兴趣也很广泛，喜欢美食、看书、唱歌。她说，训练之时，则好好训练。空闲之时，则用功学习，努力做到训练与学习两不误。

作为大一学生，叶翠诗也有着明确的学习目标。她想去台湾交流学习，当个交换生，为此正在努力学习提高成绩。她对自己还有着“远离电子产品，多看看书”的生活要求。她说，“生活中的我们需要多读一读书，可以在书海中看到丰富多彩的世界，扩宽人生的宽度与深度。”叶翠诗同学不仅在运动赛场上收获佳绩，在学习生活中也腾空展开有力的翅膀，迎接更美好的大学生活。

生命在于运动。省大运会比赛不仅扩宽了叶翠诗同学的视野，感受赛场上的激烈和运动的极限，也让她有机会结识其他高校的体育健将，收获了深厚的情谊。

叶翠诗说：“很开心来到了田径队这个大家庭，有这个机会去参赛。感谢学校的栽培，感谢教练的耐心指导和队友的鼓励，也感谢自己的努力。希望同学们走出网络，走出寝室，走向操场，享受运动，享受健康，开启阳光的大学生活。”
