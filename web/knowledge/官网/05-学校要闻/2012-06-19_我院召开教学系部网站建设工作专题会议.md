# 我院召开教学系部网站建设工作专题会议

6月18日，我院在4315会议室召开网站建设工作会议。党委书记朱志德、副书记章德胜出席会议。相关处室、系部领导及各部门网络管理人员参加了会议。

会上，新闻中心主任助理徐斌老师通报了各系部网站的建设管理情况，并现场链接演示进行说明。与会人员就下一步如何加强网络建设与管理工作提出意见和建议，认为当前存在的问题主要有规章制度不完善，个别领导重视不够，网络技术有待提高，管理人员工作量大、变动较多以及缺少专门资金。

章副书记主持会议，并针对目前网站建设中存在的问题，要求各单位要统一思想，提高认识，端正态度，克服困难，统筹兼顾，充分利用现有资源，把网站办好办活，发挥网络的宣传舆论作用。

朱书记在会上强调，各系部网站是自己的脸面，是学校的形象，也是学生和社会各界了解学校的信息平台，特别与招生工作有着密切的联系。各单位要高度重视这一工作，以“办百年名校”的思路去建一流网络。
