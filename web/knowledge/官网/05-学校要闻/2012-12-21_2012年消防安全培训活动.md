# 2012年消防安全培训活动

12月20日，学院保卫办在学术报告厅组织消防培训讲座，并在学6前小广场举办了消防培训演练。学院总务处处长翟耀明、总务处副处长陈辉、学生处副处长孔增强出席了讲座并参加演练。此次培训由“广东省消防协会会员单位”“省消防科技协会服务站”消安防火宣传中心的大力支持。

消防讲座由学院总务处处长翟耀明主持，消安防火中心教员谭建团授课。400多名教职工和学生代表参加了本次培训。在本次消防培训讲座上，谭建团教官为参与人员讲解了火灾的引发原因，杜绝办法，和如何自救互救等，还现场演示了消防器的使用方法。在进行理论授课后，参会师生员工积极地参加了使用灭火器灭火的实际演练。

此次培训旨在进一步加强消防安全宣传，切实增强师生的消防安全意识，提高师生自防自救互救等消防能力；动员广大师生员工积极参与学校消防安全工作，形成我院消防工作群防群治的局面，为我校创建平安校园、和谐校园，营造良好的消防环境。
