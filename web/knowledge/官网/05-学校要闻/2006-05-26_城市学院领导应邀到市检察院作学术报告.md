# 城市学院领导应邀到市检察院作学术报告

5月25日，我院党委朱志德书记、副院长林世俊教授、社会科学系何鹏举副教授、石志民副教授和周巍、马莉老师等应邀参加市检察院普法宣讲团培训班开学典礼。

朱志德书记在贺词中说，城市学院以服务求支持，以贡献求发展，积极融入东莞的“三个文明”建设。各级领导高度重视普法工作，希望以此为契机为创建“和谐东莞”作一点贡献。他代表学院全体师生向宣讲团发出真诚的邀请，欢迎宣讲团到城市学院宣传法律知识。

在开班仪式上，林院长以“课堂组织、教学内容组织及教学方法的运用”为主题作了一场精彩的学术报告。他在报告中分三个方面论述了报告主题：一、内容上要做到“四性统一”（科学性、思想性、系统性、逻辑性的统一）；内容必须做到概念明确，观点正确，条理清楚，深浅适度，重点突出，实现内容与形式的完美统一；二、应以“四备原则”（备教材、备教法、备学生、备学习）作为备课的原则， “明白不明白者为什么不明白才是明白人”；三、讲课过程中应讲究课堂艺术，减少失误，做到师生和谐互动。

何鹏举和石志民两位副教授在培训班上也分别作了专题讲座。

我院教授、学者的谦虚态度、敬业精神和演讲风格与内容受到检察院领导、学员的赞赏。
