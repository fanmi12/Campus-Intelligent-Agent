# 服务教职工，共建和谐城院

5月20日，在我院第一届教职工代表大会暨工会会员代表大会上，我院工会主席章德胜同志做了题为《凝聚人心，推动工作，为学院的改革、发展和稳定作贡献》的报告。

报告回顾总结在过去几年的时间的工作：以服务学院为中心开展工作；加强自身建设，提高了工会的工作水平；通过体育交流、利用节日闲情，促进了教职员工之间的感情交流，利用工会的活动添加许多欢乐，心系教职工，做到为教职工办实事谋福利。

本次大会，对今后的工作进行了部署，即完善教代会制度，推进学院民主建设进程；以师德建设为重点，造就一支高素质师资队伍；丰富校园文化，关注教职工身心健康；增强服务意识，努力为教职工多办实事；进一步加强自身建设，不断提高工作水平。

最后，章德胜同志早报告中指出，本次“双代会”选举产生的新一届工会委员会一定要凝聚全院教职工的力量，开创我院工会工作新局面，为建设和谐校园，为学校的改革、发展和稳定作出新的贡献！
