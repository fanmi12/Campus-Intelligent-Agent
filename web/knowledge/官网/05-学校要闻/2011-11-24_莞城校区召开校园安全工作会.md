# 莞城校区召开校园安全工作会

11月23日，东莞理工学院莞城校区校园安全工作会在4315会议室召开。东莞理工学院成教学院段雄春院长，东莞理工学院培训中心冒云辉主任，东莞理工学院莞城校区管委会、城市学院老校区及新校区的分管领导，城市学院各职能部门相关负责人参加了会议。

东莞理工学院副校长、城市学院院长安少华教授出席会议并做了重要讲话。安少华副校长在听完各职能部门负责人关于近期校园安全情况的汇报之后作了重要指示：一、要加强安全防范措施，提高安全防范意识；二、加强技术防范能力，人防物防相结合；三、群策群力，群防群治，共同维护校园安全。

城市学院张林副院长就校园安全工作做了安排：一是各单位要在近期组织开展安全教育活动；二是要加强与周边社区的联动机制，警民联动共同进行安全防范；三是保卫、总务等职能部门近期要进行安全检查，查缺补漏，消除安全隐患；四是要加强出入校园人员及车辆的管理力度，落实安保制度。

会议由东莞理工学院莞城校区管委会副主任王玉主持。
