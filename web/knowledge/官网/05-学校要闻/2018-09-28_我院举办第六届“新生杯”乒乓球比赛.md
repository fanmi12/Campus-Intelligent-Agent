# 我院举办第六届“新生杯”乒乓球比赛

9月27日下午，由学院体育教学部主办的“第六届新生杯”乒乓球赛在乒乓球馆举行，共有65名新生参加了比赛。

此次比赛分为小组循环赛和淘汰赛。每组前两名进入淘汰赛，依次决赛出男单女单前八名。本着“友谊第一，比赛第二”的原则，比赛在轻松、友好的气氛中进行。选手们直拍、横拍、扣球、旋转球、弧圈球等精湛的球技令人折服，赛场气氛非常活跃。

经过四个小时的激烈角逐，邹盛彬、谢惠珍同学技压群芳，分别夺得第六届“新生杯”乒乓球男子单打和女子单打决赛的第一名。欧阳志聪、毛素武、吴龙跃等八名同学获得男子单打决赛第2-8名，廖雨珊、温清扬、陆嘉琦等八名同学获得女子单打决赛第2-8名。

比赛负责人梁小龙老师表示，赛事为新生们提供了一个乒乓球技术交流的平台，强化竞争意识，丰富了校园运动文化。
