# 陈少芬的调查报告获市综治委好评

近日，东莞市社会治安综合治理委员会发函我院，对城市学院东莞社情研究中心的工作表示感谢。

今年寒假，我院社会科学系陈少芬等五位学生，在学院东莞社情研究中心周巍老师的指导下，对禁摩后东莞城区居民生活满意度进行了一次社会调查，并根据调查情况撰写了《禁摩后东莞市城区居民社会生活满意度的调查报告》。该报告以科学的调查方法，翔实的调查材料，全面、客观地反映了群众对改善社会治安的意见与建议，因而得到东莞市社会治安综合治理委员会的肯定。
