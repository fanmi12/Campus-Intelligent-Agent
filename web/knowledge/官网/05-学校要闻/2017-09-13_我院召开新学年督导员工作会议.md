# 我院召开新学年督导员工作会议

9月9日，新学年督导工作会议在行政楼401会议室召开，王卫平院长、高香林副院长和全体督导员参加了会议。

研发处处长赵书山主持会议，并宣读了《关于聘任2017-2018学年度兼职教学督导员的通知》。

督导办副主任宋欣荣回顾了上学年督导工作，对新学年工作进行了安排。

高香林副院长对督导办的工作予以肯定，鼓励大家继续发挥“督”与“导”的重要作用，为学院提高教学质量建言献策。会上，他向督导员颁发了聘用证书。

王院长指出，学院历来重视督导员队伍的建设，聘任各专业经验丰富的教授组成督导队伍，对督教、督学工作的顺利开展，对青年教师的培养都起到了重要作用，希望大家继续努力，再创佳绩。
