# 文传系召开青年教师教学科研工作座谈会

3月21日，文传系在系会议室召开青年教师教学科研工作座谈会。座谈会由系主任邓星明教授主持，35岁以下的青年教师参加会议。

宋秋敏博士和杨振同副教授应邀在会上分享了自己教研科研工作的体会，曾在2012年全校青年教师讲课大赛上获奖得主黄璀、杨玥、陈东汉三位老师谈了各自的教学心得。与会人员对照先进找差距，话责任，谈措施，纷纷表示要与学校共命运同发展，不断成长进步。

会上，邓主任宣读了《东莞理工学院城市学院“青年教师发展基金”管理办法（试行）》，并介绍学院关于促进青年教师成长发展的一系列举措，希望全系青年教师抓住机遇，外因促内因，争取在2013年的教学科研工作中获得双丰收。
