# 2012级新生正式上课

10月8日，经过10多天的军训与入学教育的2012级新同学，浩浩荡荡分别走进各自的大学课堂开始学习。早上8点30分，党委副书记朱冰、副院长高香林教授、教务处李先庆副教授以及各系部领导分别到课室巡查上课情况。

据悉，任课教师及上课学生百分之百到岗到堂，每个学生都有新课本。据反映，同学们上课纪律良好，情绪饱满，显示出强烈的求知欲望。上课老师提前来到课堂，讲课认真，专注投入。

另据了解，从今天开始，大一新生早晚必须到规定的教室自修。
