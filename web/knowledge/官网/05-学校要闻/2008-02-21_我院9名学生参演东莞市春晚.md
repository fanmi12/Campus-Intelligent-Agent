# 我院9名学生参演东莞市春晚

2月1日，我院大学生艺术团街舞队的陈锐元、钟建荣、王充、谢灵辉、黄家良、邓汉松、叶镇洪、王文杰和李昌健9名同学，参加东莞市春节联欢晚会节目《变变变》的演出。

东莞市2008年春节文艺晚会在市会议大厦隆重举行，整台晚会共13个节目，我院学生参演的节目是与东莞歌舞团的演员们联合演出的。大学生演员们以娴熟的舞蹈技巧带给了观众青春的热情与动感。东莞电视台新闻综合频道对本次晚会进行了全程直播。

据介绍，中央电视台第七套节目在农历大年初十晚的“特别节目”中播出了东莞春节晚会部分节目，我院学生参演的节目《变变变》也在其中，向全国人民展示了城院学子的风采。
