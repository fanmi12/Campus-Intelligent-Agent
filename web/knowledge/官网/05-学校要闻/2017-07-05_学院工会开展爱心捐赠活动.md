# 学院工会开展爱心捐赠活动

6月下旬,学院工会根据广东省教育厅关于开展爱心捐赠活动通知的有关文件精神要求，在全院工会会员中开展“慈善在心，量力而行”理念的爱心捐赠活动。

爱心活动得到了全院教职工的积极响应，共募集到了11730元善款，该捐赠款项已转到省教育厅指定的广东省教育基金会账户。

据了解，今年广东省扶贫济困日活动的主题是“关爱贫困人口，助力攻坚脱贫”，各校募集的款项主要用于精准扶贫精准脱贫任务。
