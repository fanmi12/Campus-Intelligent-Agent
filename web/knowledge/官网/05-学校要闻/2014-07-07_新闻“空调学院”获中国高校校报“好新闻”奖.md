# 新闻“空调学院”获中国高校校报“好新闻”奖

近日，记者从中国高校校报协会评奖文件中获悉，我院《城市学院报》记者唐跃碧老师采写的新闻作品《

微博调侃城市学院是“空调学院”

》，获2013年度中国高校校报“好新闻”三等奖。

新闻《“空调学院”》从一个侧面反映了城市学院大力改善办学条件，加强学生生活设施建设。给学生的课室、宿舍安装空调，这在全国大学中是少有的事情。该新闻的采写也说明记者具有较强的新闻敏感性，以小见大，反映城市学院的办学实力在大大提高。

据悉，城市学院的所有课室、学生宿舍、图书馆、综合馆等室内公共场所全部安装了空调。新闻见报后，读者点击量达到40多万人次。
