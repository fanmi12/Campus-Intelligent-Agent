# 我院举办第八届广东省大学生职业生涯规划教学大赛校赛

5月24日上午，第八届广东省大学生职业生涯规划教学大赛东莞理工学院城市学院校赛在招聘路演大厅举行。党委副书记章德胜、教务处处长赵书山、副处长赖忠孝，招生就业处处长孔增强，学生处罗文芳副处长，人事处张兰副处长出席了活动。

来自各院系的10位选手均是大学生职业生涯规划教学的一线骨干教师，他们通过设计丰富的教学内容、运用多样的教学形式，从大学生职业生涯规划的方法、兴趣探索、技能探索、价值观探索、时间管理和规划、职业认知等角度，呈现了一场精彩的大学生职业生涯规划指导教学课。10分钟的现场授课演讲展示了选手们各具特色的教学风采。

经过激烈角逐，计信系邓雁虹老师获得一等奖，外语系都振华、机电系何珊珊老师获得二等奖，创意设计学院付妍、城环系高政、商学院陈文丽老师获得三等奖。同时，邓雁虹、都振华、何珊珊老师将代表我院参加第八届广东省大学生职业生涯规划教学大赛。

赵书山处长充分肯定参赛老师的表现，对老师们的教学技巧、知识点与教学方法等方面提出良好的建议，同时希望大家能结合评委们的评价，认真总结经验，不断增强教学能力，提高教学水平。
