# 我院学生在2008国际文化艺术节荣获两金一银

2008年2月11日—13日，2008国际文化艺术节全国总决赛在深圳举行。黄念恩同学荣获专业钢琴大赛青年A组金奖,张思源同学荣获专业声乐（通俗）大赛青年A组金奖,王佩玉同学荣获专业声乐（通俗）大赛青年A组银奖。他们的指导老师林伟伦获得国际优秀导师奖。

此次比赛由中国国际文化艺术交流协会、中华文化五洲行组委会主办，1000余名选手参加了比赛，不少选手来自港澳台地区和国外，有较高的演艺水准。
