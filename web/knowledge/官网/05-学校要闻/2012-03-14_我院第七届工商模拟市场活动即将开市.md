# 我院第七届工商模拟市场活动即将开市

近日，我院第七届工商模拟市场相关活动拉开了序幕。本届工商模拟市场首次引进SYB课程创业就业指导，以“携手经营，创业共赢”为主题，宣传团队合作理念，让同学们体会合作共赢的重要性。届时，工商模拟市场将分别在莞城和寮步两个校区举行，凡是我院师生提交申请通过的均可享有退还10%摊位费的优惠政策。

据悉，新老校区的工商模拟市场采用分开管理的形式，共有设置美食区、烧烤区、综合区、时尚精品四大经营区和爱心摊位、创业摊位、志愿摊位三处特色摊位，另设办公共服务处、市场监督投诉处以及接待处等三大管理处。莞城校区共有103个摊位，寮步校区为83个摊位。

以下是第七届工商模拟市场活动日程安排：3月14日

至3月31日：创业就业指导（引进SYB课程）3月29日

下午2点30分：工商模拟市场咨询会3月16日

至3月30日：交企业计划书和报名表4月5日

下午2点30分：工商模拟竞标会4月16日

至4月19日：第七届工商模拟市场（莞城校区）4月22日

至4月26日：第七届工商模拟市场（寮步校区）
