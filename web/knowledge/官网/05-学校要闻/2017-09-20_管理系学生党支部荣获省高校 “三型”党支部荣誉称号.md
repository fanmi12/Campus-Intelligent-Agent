# 管理系学生党支部荣获省高校 “三型”党支部荣誉称号

9月20日下午，管理系党总支学生党支部在5A325会议室举行广东省高校学习型、服务型、创新型党支部揭牌仪式。院党委书记王卫平、党委副书记章德胜出席了仪式，与管理系党总支书记卢淑芳、学生党支部书记陈文丽等领导一道进行了揭牌。

在今年广东省委教育工委组织开展的广东省高校学习型、服务型、创新型党支部创建评选活动中，我院管理系党总支学生党支部被授予为广东省“三型”党支部。

章德胜书记宣读了《中共广东省委教育工委关于命名广东省高校学习型、服务型、创新型党支部的通知》。

王卫平书记对管理系党总支学生支部获得该荣誉表示热烈的祝贺。他充分肯定了管理系党总支和学生支部取得的成绩，表示这一成绩具有重的意义，有助于深化学院党建工作改革。

据了解，管理系党总支学生支部成立于2006年11月，共有学生党员47名。去年以来，该支部围绕“两学一做”等主题，开展线上线下理论政治学习；利用“两微一网”，对先进典型进行宣传；定期开展“悦读会”活动，提升党员修养，打造学习型党支部。通过书记项目，落实党员服务计划；定期开展服务地方社会实践活动，组织“免费午餐”等志愿服务活动，每周人均服务时间不少于3小时，创建服务型党支部。构建竞赛促成长机制，组织党员参与“挑战杯”等竞赛，多次获佳绩；围绕“爱国”“创业”等主题创新党日活动；重视“互联网+党建”宣传工作的开展，打造创新型党支部。

该支部经过对“学习型、服务型、创新型”党支部的系统建设，取得优异的成绩，与中山大学孙逸仙医院急诊科一支队等156个基层党支部被命名为广东省高校学习型、服务型、创新型党支部。
