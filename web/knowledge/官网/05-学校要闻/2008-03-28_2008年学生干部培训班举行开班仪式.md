# 2008年学生干部培训班举行开班仪式

3月27日，我院2008年学生干部培训班开班仪式在学术报告厅举行。

学生处副处长、院团委书记丘永辉老师在开幕词中指出：“开展培训班的目的是为了更好地帮助学生干部解放思想，交流经验，提高学生干部队伍的整体素质。”

本次培训班班主任由院团委副书记杜鹏举老师担任。杜老师介绍说：“本次干部培训班的时间与经费的投入比以往都要多，而且培训的形式也比较活，内容是大家所喜欢的。其目的是为了把学生干部培训好，为搞好学生工作奠定基础。

来自院团委、院学生会和系团委、系学生会90名干部代表参加了培训。培训班为期两个月，培训时间主要集中在周末。培训采取集中授课、户外拓展及交流Party 等形式进行。培训结束后，每个学员须交一份2000字的学习心得。据悉，本次干部培训班的第一次活动是集中观看《如何打造一支高素质的学生干部队伍》视频，将于3月28日晚在学生活动中心二楼进行。
