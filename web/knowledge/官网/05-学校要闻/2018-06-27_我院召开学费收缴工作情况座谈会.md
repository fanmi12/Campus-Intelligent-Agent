# 我院召开学费收缴工作情况座谈会

6月26日下午，我院召开2017-2018学年学费收缴工作情况座谈会。院领导王卫平、章德胜、周庆出席了会议。学生处副处长罗文芳，以及教务处、各院（系）负责学费收缴工作的书记、副书记参加了会议。会议由财务处处长余竹根主持。

余竹根处长介绍了我院2017-2018学年学费收缴的工作情况，并对最近三年的收缴情况进行了比较分析。

会上，与会人员对学费收缴工作进行了经验交流分享。

王卫平院长总结强调，学费收缴是我院的一项重要工作，各有关单位要给予高度重视；同时，各院（系）也要对欠费学生的家庭情况进行摸底排查，对家庭贫困的学生要给予重点关注，优先为贫困生开展助学工作，提供绿色通道。
