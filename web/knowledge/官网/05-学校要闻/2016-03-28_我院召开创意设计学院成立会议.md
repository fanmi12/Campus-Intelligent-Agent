# 我院召开创意设计学院成立会议

3月25日，我院在5C115召开“创意设计学院”成立会议。院长王卫平、副院长黄兢，创意设计学院院长林江龙、党总支书记王锦锋和创意设计学院全体教师参加了会议。

会上，黄兢副院长宣读《关于成立创意设计学院院长、书记任命通知》。

创意设计学院院长林江龙教授做任职发言，表示感谢学院对创意设计学院工作的大力支持，将进一步加强与台湾高校的合作，拓宽国际合作，建设优质的教学科研环境，提升人才培养质量，通过提供大量实践项目，提高教师教学水平、提高学生专业水平。

随后，文传系主任李上文教授、党总支书记孟颖及创意设计学院党总支书记王锦锋发言表示，将全力配合、支持创意设计学院和林江龙院长的工作，群策群力使创意设计学院向更高水平发展。

会上，院长王卫平教授对创意设计学院提出三点希望：一是希望创意设计学院能够切实成为优秀学生脱颖而出的摇篮；二是希望求真务实、多出作品，成为人才培养模式改革的先行者和引导者；三是希望以此为纽带，使学院与台湾高校的合作变得更加紧密。

据悉，创意设计学院的成立是为了更好地应对社会、经济、技术和环境的变革对设计与创新的需求，特别是面对东莞市转变经济增长方式，转型升级的发展需求，积极寻求新发展的重要举措，旨在通过引进台湾优质资源培养特色设计人才，营造学院艺术人文氛围，打造学院办学特色。创意设计学院现有“数字媒体艺术专业”及2016年新设“视觉传达设计专业”。

会议由学院党办组织科副科长李钰主持。
