# 树立“五心学工”品牌 提升三全育人质量

5月15日下午，我校五心学工品牌发布会暨第四届辅导员、班主任素质能力大赛案例研讨决赛在行政楼112顺利举行。东莞城市学院党委书记章德胜，校长陈明，常务副校长方伟华，校长助理、学生处处长任广新、副处长林蓉、刘维仝、范琪，各二级学院党总支书记、全体五心学工团队出席大会现场，会场采取线上线下同步开展。深圳大学高等研究院副院长、党委副书记韦阳、全国高校最美辅导员获得者、北京科技大学辅导员孙晓丹、学校党委办公室主任姜虹、教师发展中心主任张兰、品牌中心副主任万文双、学生处思政科科长詹海都担任评委。

章德胜书记、方伟华常务副校长出席大会

陈明校长出席大会

校长助理任广新介绍“五心学工”品牌

发布会上，校长助理、学生处处长任广新首先介绍了“五心学工”品牌探索历程，“五心学工”品牌的形成是对“阳光学工”的传承与创新，是学校从顶层设计层面完成学生工作总体布局，“五心学工”品牌突出学生工作“以生为本”的育人理念和服务学生成长成才的工作宗旨，强化过程和结果导向，落实立德树人根本任务，推进学工队伍专业化、事业化发展，秉承我校“厚德务实，知行合一”的校训，建立并落实‘551’学工育人机制，即锻造“五心”一体化育人学工团队；实施“五大”软硬一体化育人学工建设工程；形成“一套1234567”三全育人体系提升学生工作质量。

五心学工品牌发布会仪式

会上，校党委章德胜书记发表讲话，重点强调了“五心学工”团队要做到三个加强：一是要加强政治理论学习。思想政治辅导员、班主任作为高校思想政治工作的重要力量，需要具备较高的政治理论水平，才能更好地引领和带领青年学生与时代同步、推动中华民族伟大复兴。二是要加强学工品牌建设。目前学校已经正式发布了五心学工品牌，辅导员、班主任要加强学习，认真领悟，内化于心，外化于行。做到三个铭记：即时刻铭记551工作机制、铭记五心学工内涵、铭记五大工程；做到三个力求：即力求付诸行动、力求融入实践、力求锻造品质，促进学生工作高质量发展。第三是要加强大学生思想引领，促进大学生全面发展。习近平总书记特别强调了，高校思想政治工作关系着培养什么样的人、如何培养人、为谁培养人这个根本问题，辅导员、班主任应当立足于立德树人这一中心环节，牢牢抓住全面提高人才培养能力这个核心点，努力把学生培养成为“有理想、有本领、有担当”的中国特色社会主义事业建设者和接班人。

章德胜书记讲话

发布会后，第四届辅导员、班主任素质能力大赛案例研讨决赛顺利举行。本届案例研讨决赛对标最新国赛赛制，比赛以“我提问，你回答”的方式开展，每组选手依次进行提问与回答，围绕案例共同辨析原因、研讨对策、总结规律。比赛综合考查了辅导员、班主任的语言表达能力、思想教育和心理辅导能力、日常事务处理能力和应急处突等多方面知识和技能，全方位展现了辅导员、班主任的个人素养、知识储备和专业技能。据悉，本届辅导员、班主任素质能力大赛是参赛人数最多，竞争最激烈的一届，79名辅导员、班主任经过初赛、复赛，共有10名选手成绩突出进入决赛，经过激烈的角逐，智能制造学院班主任王金钗斩获本届辅导员、班主任素质能力大赛案例研讨决赛一等奖，李伟健、关飞斩获二等奖，魏薇、邱少华、赵甜甜获三等奖，许峰泓、朱佳丽、冯国丝、谢婷荣获优胜奖，智能制造学院和人工智能学院在初赛、复赛组织过程中表现突出，荣获优秀组织奖。
