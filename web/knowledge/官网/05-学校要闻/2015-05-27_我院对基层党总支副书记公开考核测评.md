# 我院对基层党总支副书记公开考核测评

5月21日，我院在行政楼112会议室召开基层党总支副书记考核测评大会。学院党委委员、各系（部）党总支书记和副书记参加会议，学生代表列席会议。

会议对全院的基层党总支副书记进行考核测评。八名系（部）党总支副书记按照考核要求，结合自己的工作实际进行述职。学院党委委员针对他们的述职进行考核提问，并由考核小组成员进行评分。

最后，党委书记王卫平同志讲话，对测评对象提出了三点希望：恪尽职守，积极主动地协助书记和系主任开展工作，促进系（部）发展；取长补短、互相学习，为学院的发展建言献策；热情服务学生和老师，做好师生的思想政治工作。
