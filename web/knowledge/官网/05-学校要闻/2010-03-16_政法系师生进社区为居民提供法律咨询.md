# 政法系师生进社区为居民提供法律咨询

3月14日，政法系深入罗沙社区开展以“推动依法治国，服务科学发展”为主题的法律咨询活动。

法学教研室教师与06法学班通过国家司法考试的同学，为群众提供法律咨询，内容涉及劳资关系、房屋转让合同、婚姻关系等方面。

罗沙社区党总支副书记、居委会副主任翟俊看望了我院师生。
