# 心连心，相聚在财经——2008年财经系迎新晚会成功举行

2008年11月14日

晚，由财经系举办的主题为“心连心，相聚在财经”2008年迎新晚会在学院大礼堂成功举行。财经系四百多名师生一起度过了一个愉快而难忘的夜晚。

在财经系全体成员的共同努力下，经过1个多月的精心筹备，晚会现场从音乐效果到舞台灯光，从道具准备到人员调配，一切都井然有序，而精彩纷呈的节目更是把同学们的热情推到了沸点。整场晚会持续一个半小时，其中有妖娆动人的民族伞舞《青花瓷》；精彩而又感人的话剧《传说》；来自08国际会计2班的郑力瑜同学带来一曲独唱《幸福山歌》，其高亢的歌声让所有观众交口称赞；

08会计学模特队精彩的时装秀走出了时代气息；令人爆笑的相声《学讲普通话》、钢琴伴奏独唱《

Yesterday once more》精彩绝伦；最后，晚会以多人情景剧《似水年华》结束了表演。演员们精彩的表演中加上优美的表情和姿态，展现出了他们自己的个性和青春，给观众们留下了深刻的印象。晚会节目精彩不断，高潮迭起，掌声欢呼声不绝于耳，让现场观众尽享视觉和听觉盛宴。

整台晚会不仅充分展现了财经系学子的风采，而且通过同学们相互之间的互动交流，增强了大家与学院的共融和归属感，增近了同学之间的情意，也增强了财经系内部的凝聚力，为今后更好的学习交流创造了契机。

财经系党总支副书记叶凯贞说，迎新晚会的成功举办，为我系广大有才艺的同学提供了一个展现自我的舞台，体现了我系学子优良全面的艺术素质和力求完美的精神风貌，希望他们在今后的学习中同样展示自己的精彩和优势。
