# 中山大学南方学院副院长龚鸣一行来我院参访

9月11日，中山大学南方学院副院长龚鸣一行6人来我院参观交流，受到副院长高香林及图书信息中心负责人的热情接待，并在行政楼前合影留念。

图书信息中心负责人陈显龙向到访的客人们介绍了我院的发展历程、办学特色以及图书馆建筑布局、馆藏规划、管理方式、服务模式等情况。双方就图书借阅管理、勤工助学学生管理、读书协会运作等业务工作进行了交流。

中山大学南方学院副院长龚鸣一行对我院的热情接待表示感谢，期待今后在图书馆业务工作、读者服务等方面有更多的交流与合作。
