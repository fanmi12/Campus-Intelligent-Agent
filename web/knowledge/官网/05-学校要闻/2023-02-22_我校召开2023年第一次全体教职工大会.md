# 我校召开2023年第一次全体教职工大会

2月21日下午，学校在综合馆召开2023年第一次全体教职工大会，大会以“立足高质量发展，聚焦内涵式建设”为主题吹响东莞城市学院新学期的奋斗号角。校领导出席，全体教职员工参加会议，党委书记章德胜主持会议。

会议现场

党委书记章德胜主持会议

常务副校长方伟华作《学校工作报告》

常务副校长方伟华从党建工作、学科专业建设、科研项目、平台建设、人才培养、招生就业、师资队伍建设、对外合作交流、服务保障等方面回顾总结了学校2022年的各项工作与取得的成就，并指出了学校在发展中面临的问题。方伟华对学校2023年的重点工作作了安排，集中体现在十个方面：

一、强化党建引领发展，努力建成全省党建工作示范校；二、保障基本办学指标建设，确保通过转设过渡期检查验收；三、完善学校发展顶层设计，大力推进依法治校；四、推进人才培养模式改革，加强学科专业建设，深化教育教学改革；五、坚持“以生为本”，优先保障教学设施更新，全面启动大学满意度建设；六、构建产业学院，实施科研促教学工程，提升科研水平；七、提升就业率，强化招生工作；八、加强人才引进和培养，优化岗位和部门设置，多措并举激发活力；九、 拓展对外合作办学新路径，加强国际交流合作；十、加强后勤服务质量，健全财务制度，提升服务水平。

副校长陈葆华作《教学工作报告》

副校长陈葆华作了《扎实推进评估评建工作 推动教育教学高质量发展》的工作报告。她从看清形势，把握规律；明确方向，狠抓落实；有效监控，提升质量三个方面做了报告。她指出本科教学合格评估是国家对本科高校的底线要求也是强制性要求，在重视高等教育的高质量发展背景下，对民办高校的本科教学合格评估要求越来越严格，作为民办高校的我们应该规范和特色两手抓，遵循教育规律和市场规律，重视专业内涵建设，根据民办高校学生特点实现个性化应用型人才培养，依托现代产业学院和乡村振兴学院开展深度产教融合，落实四层递进的实践教学体系，同时强调要逐步构建全方位、全链条的教学质量保障体系为教育教学高质量发展保驾护航。

最后指出我校要开展“四个一”建设，即一师一优课、一院一亮点、一生一梦想，一生一规划，将日常工作和评估工作、专项工作和评估工作高度结合，重点完成本学期八项任务。

党委副书记刘玉侠作《党建工作报告》

党委副书记、副校长刘玉侠作题为《党建引领促发展 砥砺奋进谱新篇》的主题报告。报告从强化思想引领，落实党建工作责任；夯实组织建设，打造坚固战斗堡垒；创新育人模式，提升思政工作水平；围绕中心服务大局，促进各项事业健康发展等方面全面回顾总结了过去一年我校党建工作取得的成绩和在工作中形成的经验。刘玉侠指出，2023年是贯彻落实党的二十大精神的开局之年，全校上下要全面贯彻落实党中央决策部署，始终保持战略清醒、战略自信、战略主动，努力实现全年目标任务，打开事业发展新天地、开创卓越发展新局面。提出“强基、提质、创优”三年行动计划，构建“六引领、五育人”的工作格局的目标，并从六个方面强调了学校党建下一步工作思路和措施：

一、深入学习党的二十大精神，切实增强思想引领力；二、着力加强基层党组织建设，切实增强组织战斗力；三、着力培养高素质党务干部，切实增强群众组织力；四、着力发挥先锋的带头作用，切实增强标杆影响力；五、着力构建党建“朋友圈”，切实增强社会号召力；六、着力抓好基层党组织生活，切实增强师生凝聚力。

校长陈明作总结讲话

陈明校长作总结讲话。他充分肯定了近年来学校发展取得的成绩。陈明表示，近20年来，城院扎根莞邑大地，培养了大量服务社会经济发展的优秀人才。经过全体城院人的不懈努力，城院办学声誉良好、实力日趋雄厚。如今正式成为一名“城院人”，深感责任重大。今后将和全体教职员工一起，努力拼搏，攻坚克难，早日把东莞城市学院建设成为创新型、应用型和国际化的高水平大学。这几年，学校力争在学科建设上能够有所突破，能够再上一个新台阶。

他指出，大学是师生共治的学术共同体，要始终以师生为本，坚持一切为了师生、一切依靠师生。

他强调，人才是学校发展的第一资源，我们要持续汇聚和培育一流人才，坚持人尽其才、才尽其用，努力打造开放包容、生机勃发的人才生态。

他强调，我们要坚持以发展为要义。加快高质量学科专业建设，聚焦内涵式建设，回应新时代对我国高等教育发展提出的新要求。

会议召开后，在城院师生员工中引发了强烈反响，大家纷纷表示大会的召开为新的一年指明了工作方向和奋斗目标，要铆足干劲、担当作为、只争朝夕，以实际行动实现“开年就开跑”“起步即冲刺”的新气象和新作为！
