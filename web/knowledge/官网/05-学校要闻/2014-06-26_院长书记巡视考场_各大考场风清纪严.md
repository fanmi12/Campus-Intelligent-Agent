# 院长书记巡视考场?各大考场风清纪严

6月23日，期末考试的第一天，院长杨敏林、党委书记王卫平、副院长高香林在教务部门负责人的陪同下巡视考场。院领导对考试的组织工作以及同学们应考的态度表示肯定。

教务处组织督导员、各系部、院机关处室负责人及期末考试巡视员分别对千人大考场和各教学单位分考场的考试情况进行了巡查。

据统计，本次期末大考要持续到7月3日下午，共10场，科目130门，考生人数46912人次。

各教学单位的领导非常重视这次考试，考前进行了考风考纪教育，营造良好的考试氛围，对本单位的考试工作进行了周密的组织。监考老师尽职尽责，严格监考。考场地面干净整洁，座位布局合理，秩序井然。学生认真应考作答，没有出现违纪现象。
