# 我院参加莞城区“城市精神”辩论赛

为进一步增强创新创业的意识，深化对城市精神的思考，7月19日，由莞城区宣传办主办，城区科技园开发管理公司、城市学院协办的“莞城区城市精神大讨论——如何看待创新创业的”辩论赛在市民广场举行。市文明办副主任宋媛女士、东莞理工学院工会副主席李建中、《文化周末报》总编蔡洪波先生担任赛事评委。我院团委书记丘永辉老师也应邀出席。

比赛由我院理阳阳老师主持。我院代表队作为反方与正方的莞城区科技园代表队就“是否应主张创新创业”的辩题展开了唇枪舌剑。双方高超的辩论口才与技巧不时博得观众的热烈掌声。

赛后，蔡洪波总编辑与李建中副主席分别对本次大赛作了点评，称赞双方在比赛中都发挥出了高水平。我院代表队宋蜜蜜同学获得“最佳辩手”称号。
