# 我院召开新学期党建工作专题会议

2月21日下午，我院召开党建工作专题会议，明确坚持“围绕中心抓党建、抓好党建促发展”的工作理念，积极创新学院党建工作，发挥政治核心作用。

党委副书记章德胜就新学期党建工作重点进行了部署，要求全院基层党组织高度重视并扎实做好党建工作，进一步开阔思维和眼界，以党建促团建、促学风、促教风，全面提升党建水平。

院党委书记王卫平强调：在新形势下，学院党委要全面贯彻党的十八大、十八届六中全会精神，要切实抓好总书记在全国高校思想政治工作会议上的重要讲话精神的传达学习和贯彻落实，积极创新学院党建工作，发挥政治核心作用。为此，学院在年前成立了党务工作部，加强力量，便于统抓统管，形成合力，按照党委的要求切实做好党建工作，有利于强化意识形态工作取得实效。

各党总支（直属支部）主要负责人参加了会议。
