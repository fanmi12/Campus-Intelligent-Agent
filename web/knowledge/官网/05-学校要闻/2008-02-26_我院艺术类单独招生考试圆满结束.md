# 我院艺术类单独招生考试圆满结束

2月23日、24日,我院对舞蹈表演与音乐表演专业的考生进行了艺术类单独招生考试。

这次考试设三个考场，评委由黄英森、向智新、史德松、马新川等教授担任。

为了更好地做好今年的艺术类单独考试招生宣传工作，学院招生办在去年就进行了整体策划，全面部署，今年年初全面开展了各种招生宣传活动。据统计，今年的艺术类单独考试报考人数为去年的三倍。整个招生考试工作井然有序，考生水平也高于往年。
