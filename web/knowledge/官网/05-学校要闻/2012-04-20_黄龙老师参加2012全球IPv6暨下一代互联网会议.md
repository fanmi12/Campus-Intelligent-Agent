# 黄龙老师参加2012全球IPv6暨下一代互联网会议

4月10日-11日，2012全球IPv6暨下一代互联网高峰会议在北京市新世纪日航酒店举行，我院新校区网络组黄龙老师和来自国内外IPv6业界几百位专家代表出席了本次会议。会议旨在通过广泛的交流讨论，共同推动全球IPv6事业的发展。

据了解，去年年底，国务院明确了以IPv6大规模部署和商用为基础的下一代互联网路线图与主要目标。今年3月29日，发改委、工信部等七部委联合发布了《关于下一代互联网“十二五”发展建设的意见》，对这一重大战略部署作出了详细阐释。中国的互联网有望实现整体跃升，进入“6”时代。

虚拟化与智能化程序将是未来。中山大学网络中心郭教授的《如何打造IPV6环境下的教育云服务体系》，提出了教育云以“设施、资源、服务、运营”为核心的体系架构与实施方法。下一代的校园网将是多业务融合，实现语音、视频和数据三网融合。

城市学院未来的数字化校园建设中，将运用Ipv6技术。

新闻链接：名词解释：IPv6是“Internet Protocol Version 6”的缩写，它是IETF(Internet Engineering Task Force 译：互联网工程任务组)设计的用于替代现行版本IP协议-IPv4-的下一代IP协议。

目前全球因特网所采用的协议族是TCP/IP协议族。IP是TCP/IP协议族中网络层的协议，是TCP/IP协议族的核心协议。

IPv6正处在不断发展和完善的过程中，它在不久的将来将取代目前被广泛使用的IPv4。每个人将拥有更多IP地址。
