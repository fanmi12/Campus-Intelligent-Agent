# 【服务东莞、创新发展】新闻中心：大学生记者团暑期媒体单位实践活动于近日启动

我院大学生记者团“服务东莞、创新发展”暑期媒体单位实践调研活动于近日正式启动。今天下午我院新闻中心主任何鹏举一行三人走访了南方都市报东莞站，探望部分参加实践调研的学生，南方都市报东莞站站长钟跃东、副站长丰雷与我院师生就“服务东莞、创新发展”主题活动进行了交流。

据悉，今年暑假，新闻中心大学生记者团选拔了43名来自全院大一至大三年级的学生分别赴南方日报、南方都市报、东莞日报、东莞时报、东莞阳光网等14家市内外媒体单位进行实践调研活动。

其中，在南方都市报实习的学生共有13人，在为期两个月的实践调研活动中，学生们将在南方都市报的组织下对东莞社会进行新闻采访、调查等活动，他们参与的第一个大型调查活动就是对东莞市的垃圾分类的调研以及问题对策的分析。

新闻中心主任何鹏举首先感谢南方都市报领导对我院工作的支持和关心，赞扬肯定了同学们牺牲暑假休息时间，参与实践实习活动的学习精神，鼓励同学们勤奋工作、不耻下问、积极主动抓住每一个学习的机会，在做人做事中锻炼提高自己的综合素质。

来自2011级的新闻传播专业的张巧玲同学说：“南方都市报的领导和老师对我们都很关心，每个学生都有一个专职记者担任我们老师，我对暑假未来两个月的实习充满信心和期待”。

来自2011级的新闻传播专业的范游輅同学说：“第一天的实习让我有很多感慨。我被分配到房产线，老师就带我去采访关于东莞市房地产行业发展的情况，这也让我从侧面了解到不同行业发展对人才需求情况的影响。”
