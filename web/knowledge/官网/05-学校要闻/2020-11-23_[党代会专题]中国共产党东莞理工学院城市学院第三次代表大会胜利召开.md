# [党代会专题]中国共产党东莞理工学院城市学院第三次代表大会胜利召开

▲省委教育工委发来贺信

▲东莞理工学院党委副书记吕琦元出席大会并致辞

▲东莞理工学院城市学院党委书记章德胜同志作第二届党委工作报告

▲大会选举产生中国共产党东莞理工学院城市学院第三届委员会、纪律检查委员会11月22日，中国共产党东莞理工学院城市学院第三次代表大会在学术报告厅胜利召开。本次大会主题是高举习近平新时代中国特色社会主义思想伟大旗帜，全面贯彻落实党的十九大和十九届二中、三中、四中、五中全会精神，把握新时代教育新使命，抢抓学校转设发展机遇，进一步解放思想、凝心聚力、守正出新，开启建设新时代高水平应用型本科高校新征程。

东莞市教育局副局长邓柏松，东莞理工学院党委副书记吕琦元，东莞理工学院党委组织部（统战部）部长彭晓波，东莞理工学院城市学院党委原书记朱志德，学校董事长代表陈超群等领导嘉宾出席大会。章德胜、王卫平等大会主席团成员，第三次党代会党代表出席了大会。校内党外人士代表列席大会。王卫平同志主持大会。

大会在庄严的国歌声中拉开序幕。

大会宣读了中共广东省委教育工委发来的贺信，省委教育工委对中国共产党东莞理工学院城市学院第三次代表大会的顺利召开表示热烈祝贺，对学校各项工作所取得的成绩给予充分肯定，希望各位党员代表不负重托，认真履行职责，正确行使权力，以高度的政治责任感和严肃认真的态度，选举出坚强有力的新一届党委领导班子，开成一次承前启后、继往开来的大会，凝聚人心、团结奋进的大会，振奋精神、鼓舞斗志的大会。

东莞理工学院党委副书记吕琦元向大会致辞。他代表东莞理工学院党委对大会的顺利召开表示热烈祝贺，向城市学院全体党员和师生员工致以亲切的问候，对城市学院第二次党代会以来，党委领导班子团结带领广大党员、师生员工在办学治校、立德树人、党建引领、思政育人、教育教学、学科建设、服务东莞地方经济社会发展等方面所取得的成绩给予了充分的肯定。他希望新一届党委继续全面加强党的领导和党的建设，继续落实立德树人根本任务，继续深化改革，继续推动学校高质量内涵式发展，为加快建成特色鲜明的地方性应用型本科高校而团结奋斗。

章德胜同志向大会作了题为《凝心聚力 守正出新——开启建设新时代高水平应用型本科高校新征程》的报告。

报告认为，第二次党代会召开以来，在上级党委的正确领导下，在历届学校领导班子和全体城院人打下的坚实基础上，学校党委团结带领全体党员和师生员工，抢抓机遇、改革创新、内涵发展，推动学校各项事业不断向前，开创了学校建设发展的崭新局面。

报告指出，新时代学校的历史使命是：全面落实立德树人根本任务，加快推进应用型本科建设，真正实现内涵式发展，加快建设特色鲜明的高水平应用型民办本科高校，努力实现“创一流大学，办百年名校”的办学愿景。今后五年学校的发展目标是在实现学校转设成功的基础上，准备迎接教育部本科高校合格评估，争取申报获批专业硕士授权建设单位，为学校高水平发展打下坚实的基础，清晰的勾画百年名校的发展实现路径。

报告指出，未来五年是开启建设新时代高水平应用型本科高校新征程的关键时期。要实现这个目标，我们要扎实推进“紧紧围绕立德树人根本任务，全面提高人才培养质量；推进‘四新’建设，培育优势学科专业；加强专业建设，提升专业竞争力；以创新强校工程为抓手，提高教科研水平；加快实施人才强校战略，优化教师队伍；加强中外合作办学，积极拓展与境外高校的深度交流与合作；加强大学文化建设，弘扬大学精神文化；强化资源条件保障，建设和谐平安校园”等八项重点建设工程。

报告指出，在新的时期，必须全面贯彻习近平新时代中国特色社会主义思想，准确把握和全面落实新时代党的建设总要求，坚持和加强党的领导，全面推进党的政治建设、组织建设、作风建设及纪律建设，为学校的改革发展提供坚强的政治保障和组织保障。未来要着力加强党的政治建设，高举社会主义办学旗帜；夯实思想政治工作，牢牢筑就理性信念根基；深化基层组织建设，充分发挥战斗堡垒作用；抓好党员干部教育，充分发挥先锋模范作用；推动全面从严治党，营造风清气正的政治生态。

会议号召，全校党员同志和师生员工更加紧密地团结起来，在上级党委的正确领导下，围绕党代会提出的目标与任务，统一思想，同心同德、求真务实，开拓创新，凝聚起奋进新时代的磅礴力量，为建设新时代高水平应用型本科高校而努力奋斗。

全体党代表分成五个小组，举行代表团会议，审议关于第二届党委工作报告的决议，党费收缴、使用和管理办法，大会选举办法、 “两委”委员候选人预备名单及大会选举监票人名单。代表团会议上，代表们认为报告实事求是地回顾总结了第二次党代会以来的工作，深刻分析了学校所处的历史方位和面临的发展机遇及挑战，明确提出了今后一段时期学校发展的总体思路和主要任务，为学校事业进一步发展指明了前进方向，对今后的学校各项事业发展及党的建设具有十分重要意义。

大会采取差额选举的办法，选举产生了中国共产党东莞理工学院城市学院第三届委员会和纪律检查委员会。章德胜、王卫平、高香林、黄兢、刘玉侠、杜鹏举、孔增强、李海冬、卢淑芳等9名同志当选为第三届党委委员，黄兢、陈东汉、赵颖娴、都振华、林蓉同志当选为纪委委员。

大会在国际歌歌声中胜利闭幕。

第三次党代会结束后，新一届党委举行第一次全体会议，选举章德胜同志为党委书记，王卫平、高香林、黄兢同志为党委副书记；新一届纪委举行第一次全体会议，选举黄兢同志为纪委书记。
