# 我院男篮四战皆捷

DUBA小组赛正如火如荼地举行。我院男篮分别在5月4日、7日对阵东莞理工学院队（简称：莞工队），在势均力敌的拼杀中，以70∶68、77∶75击败对手取得四连胜。

5月4日晚，我院男篮迎来小组赛第三场，主场对阵莞工队。7号黄志陆以成功跳投三分球拉开战局。莞工队不甘示弱，咬紧比分，打得难分难解，上半场以26∶26握手言和。

在城院艺术团啦啦队带来精彩的表演后，易边再战。双方你来我往，势均力敌，比分一度僵持在一分之差。比赛最后18秒，双方再次将比分战平，进入白热化。在最后倒数3秒时，我方19号叶锐城快攻上篮得分，绝地反杀以70∶68险胜莞工队。

5月7日晚，两队再次相逢在东莞理工学院篮球场。一声哨响，莞工队先发制人，7号李庆源快攻上篮拿下两分。我方6号庾世聪随即一记三分球还以颜色。对方凭借内外线紧密配合、防守有度，不断快攻，将比分紧紧咬死。第三节结束时，我院以51∶55落后。

末节，我院男篮及时总结经验，改变策略，内外线火力全开，一开场便不断快攻上篮将比分反超。随后，双方不断加强攻防力度，第四节以69∶69进入到加时赛。

加时赛中，双方依然难分伯仲，多次追平比分。在最后36秒，对方失误，我方抓住机会，命中关键两球，比分赶超，最终以77∶75再次战胜莞工队，夺得小组赛四连胜。

两场比赛，我方10号黄明健发挥出色，分别以19分、18分拿下全场个人最高分。
