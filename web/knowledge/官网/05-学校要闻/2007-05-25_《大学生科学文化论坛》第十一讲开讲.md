# 《大学生科学文化论坛》第十一讲开讲

5月24日，城市学院学术报告厅不时爆发出热烈的掌声，《大学生科学文化论坛》第十一讲开讲。行政副院长张林副教授以“中西文化漫谈——涉外交往中的礼仪细节”为主题，向同学们奉献了一场妙趣横生的讲座。

张院长从礼仪与文化的关系入手，通过举例向同学们揭示出中西文化在社交礼仪（姓名称谓、见面礼节、日常礼仪、领地观念）上的异同，使同学们受益匪浅。

本次论坛由教务处处长邓成良教授主持。
