# “城院贝利文体发展基金”开展东莞校园足球文化建设推广活动

5月17日上午,东莞理工学院城市学院贝利文体发展基金在石碣袁崇焕中学举行东莞校园足球文化建设推广暨校园足球第二课堂示范体验活动。

东莞市体育局竞技体育科副科长尹昌锦，市教育局教研室体育教研员冯伟华，石碣镇宣教文体局副局长张昌忠、副局长刘敏锋，袁崇焕中学校长吕文彬、副校长于克，广东贝利体育文化传播有限公司董事长吴志斌，我院副院长黄兢、体育教学部党总支书记刘健出席了活动。参加活动的还有石碣镇各中小学领导、师生代表、企业代表、媒体代表等。

吴志斌董事长致词表示，袁崇焕中学校园足球氛围浓厚，广东贝利体育文化传播有限公司将与袁崇焕中学携手推进校园足球文化建设，为我国足球的梯队建设提供优秀的储备人才。未来，贝利也会加大投资力度，联合东莞理工学院城市学院大力发展足球文化事业。

吕文彬校长说，袁崇焕中学秉承“文武双修，德才兼备”的校训，树立“健康第一”的教学理念。从2012年起，袁崇焕中学评选“六好学生”就将“身体好”作为第一考核因素。

张昌忠副局长感谢贝利文体发展基金对袁崇焕中学的认可与支持。他说，近年来，袁崇焕中学女子足球队多次在各项赛事上获奖，足球教育事业蓬勃发展，希望将来能与社会各界一起培养体育人才，推动包括东莞足球在内的体育项目更好、更快地发展。

黄兢副院长在发言中表示，作为一个足球迷，非常高兴看到贝利文体发展基金对东莞足球发展做出的贡献。非常荣幸地代表城市学院为东莞足球和中国足球的发展献上绵薄之力，希望能早日看到中国足球走出亚洲、走向世界。

活动举行了一场别开生面的女子足球邀请赛、校园足球第二课堂公开课、校园足球文化宣传等活动。

我院炫舞团受邀在活动上进行了精彩的表演。

据介绍，“贝利文体发展基金”由广东贝利体育文化传播有限公司与东莞理工学院城市学院联合发起，是一项以推动东莞校园足球发展为目标的公益计划，也是东莞高校发展本土足球文化建设的首例校企合作项目。
