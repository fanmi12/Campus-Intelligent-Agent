# 文传系驻港部队参军学生来信

5月13日，文传系2011级平面设计班收到了邓华诗同学的来信。邓华诗，文传系2011级平面设计专业的学生，上学期弃笔从戎，毅然走上大学生参军的道路，也是我院唯一一个进入驻港部队的巾帼英雄。

信中，邓华诗同学表示，部队的生活虽然艰苦，但是她始终相信梅花香自苦寒来，总有一天，她会成为一个优秀的军人。自始至终，邓华诗在心中流露出的都是一种乐观积极的精神。信的最后，还不忘鼓励同学们努力学习。

以下内容为邓华诗来信的原文：平面设计全体同学：我很想你们，也很怀念校园生活。首先，为我迟到的信表示歉意，希望大家原谅！因为这三个月的新兵训练生活很紧张，一些军事科目训练目的是让我们从一名地方青年华美转身为一名合格的驻港军人。每天都是训练，为了考核每天还得加班加点训练，考核完了又迎来营区开放，表演给香港民众看，所以直到今天才给你们写信。

我是去年11月26日来到香港的，刚到这里真的好想家，好想学校那样自由的生活。我从11月26日到现在，除了出去拉练过一次之外，我就没有出过营区的大门。我们不可以用手机，不可以用任何的数码产品，我快闷坏了，驻港部是全封闭的。现在偶尔会想家、想学校、想你们，其他的都还好啦，因为习惯了。

这里的女兵很少，部队对我们的礼节礼貌、内务要求都特别高。我们6点钟起床，然后出早操，跑三千米，三四组仰卧起坐，三四组俯卧撑（一组20个）。我从没有经历过强度这么大的训练，全身酸痛，现在熬过来了。男兵要负重30公斤跑5千米，我们算轻松了。出完操回来只给10分钟把那被子叠得方方正正的，叠不好的要全连点名通报批评。叠完被子就洗漱、打扫卫生。这里的一切都很有规律，“时间”、“空间”观念特别强，班长都会拿秒表测时。假如做一件事没有达到要求，班长就要我们重复做，说让我们长记性。其实我觉得他在锻炼我们的忍耐力。我也想过逃避，我也想回家，但这是不可能的，都是要面对的。在这里很重要的是自我调节心态，上级下达的就是命令，无论你想不想，都是要完成的，这是军人肩负的使命。即将面对的是香港回归十五周年阅兵，我们现在的军姿训练是最辛苦的，要挂枪站三四个小时，要一动不动，那把枪重3.3千克，肩膀、腰、脚都麻，有些人晕了都是站着的，直直地倒下。

我在这里要帮连队出墙报，制作小DV之类的。你们要好好珍惜学习时间，知识总会用到的，我现在好后悔当初怎么没学好、学会。你们是幸福的，要好好学。

来到了这里已经四个多月，我也确实看到了自己的改变，包括心理素质和身体素质，学到了许多社会上学不到的知识，学会了为人处世，也吃到了平常人吃不到的苦。

让我们好好学习吧，我和你们一起努力！我希望你们能告诉我校友和校园中消息，我会一如既往地关注你们的！

祝老师、同学们：身体健康！工作顺利！学业有成！

敬礼邓华诗2012.5.3
