# 我院校运会盛况多家媒体倾情报道

忙碌的校内外记者

为期两天的异彩纷呈的校运会胜利落下帷幕，但喜悦与兴奋通过报纸变成文字仍留存在我院师生与广大读者的心中。校运会开幕式上，04年雅典奥运会女子10米双人跳台冠军劳丽诗、CBA联赛冠军广东东莞银行队球星陈大伟和王征受邀出席参加我院09年校运会开幕式，并与城院学子进行交流，为校运会增添了一大亮点，也激励城院师生朝着“更高、更快、更强”的目标拼搏。运动会的盛况，吸引了不少媒体记者前来采访报道。

奥运冠军、CBA球星助兴，媒体也“疯狂”04年雅典奥运会女子双人10米跳台冠军劳丽诗以及CBA联赛冠军广东东莞银行队球星陈大伟和王征的到来，成了各大媒体报道的亮点。例如：阳光网的《东莞理工学院城市学院运动会开幕》，广州日报的《追‘星’也疯狂》，羊城晚报的《奥运冠军助兴校运会》，东莞时报的《与城市学院学子面对面，奥运冠军劳丽诗畅谈人生经历》、《体育明星嘉宾受追捧》、《我的感情现在是空白，愿亲手做甜品给人吃》，东莞日报的《劳丽诗：我想开个甜品店》、《东莞理工学院城市学院运动昨开幕》、《劳丽诗、陈大伟、王征受邀参加，明星进校园引发追星潮》，南方日报的《大学老师也跳校园集体舞》、《奥运冠军今出席城市学院运动会开幕式》，新快网的《体育明星齐聚城市学院校运会》等图文，都以大量的篇幅进行了报道。

媒体不惜浓墨重彩报道了奥运冠军劳丽诗与城院学子面对面精彩的交流，以及CBA球星与城院学子互动的精彩瞬间。媒体的“疯狂”，把城院好好地宣传了一番。

教工集体舞，记者独特眼光

校运会开幕式上，我院300名教职工身穿白色服装，伴随着欢快的旋律，踏着青春的节拍，跳着集体舞。南方日报、东莞阳光网等媒体的记者以独特的眼光，进行了充分的报道。这些报道都成了广大读者了解城市学院的信息窗口。
