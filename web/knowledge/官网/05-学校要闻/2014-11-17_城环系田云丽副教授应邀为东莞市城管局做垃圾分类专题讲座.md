# 城环系田云丽副教授应邀为东莞市城管局做垃圾分类专题讲座

11月7日，我院城环系田云丽副教授应东莞市城市综合管理局的邀请，在学术报告厅为给东莞市镇街干部以及社区、村环境负责人做了题为《厨余垃圾处理》的培训讲座。

在讲座过程中，田云丽副教授结合东莞市生活垃圾处置现状深入浅出地讲解了兄弟城市生活垃圾的处理方式及工作中的难点与对策，并与培训人员进行了热烈互动，回答了大家普遍关心的生活垃圾处理所需要的设备、资金和工艺问题。

田云丽副教授讲座专业而又不乏生动性，现场反响热烈。培训人员表示，继续深入开展垃圾分类工作很有必要，而厨余垃圾的处理，又是重中之重，只有各方配合，这个工作才能有效开展起来。
