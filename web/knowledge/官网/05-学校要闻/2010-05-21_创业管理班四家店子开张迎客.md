# 创业管理班四家店子开张迎客

5月20日，管理系07级创业管理班开办的“温馨鲜花店”、“善誉中介所”在我院北门外开张。管理系主任罗余才、党总支书记吴春庚，院团委书记杜鹏举出席了剪彩仪式。

在鲜花店里，摆满了仙人掌、芦荟、满天星等绿色小盆栽，售价在8元至20元不等。中介所里，墙上贴满了兼职的单位及待遇。许多同学听到消息后都赶来观看是否有适合自己的工作。07级的阿海同学说：“我一直在寻找兼职工作做，赚点生活费，今天在中介所终于找到了，感谢创业班的同学。”

据悉，07创业管理班张少江同学的“师源家教培训中心”，莫嘉敏同学的“城院瑜伽班”已于4月份开张营业。据创业管理班负责人介绍，目前师源家教培训中心的学生有10多名，瑜伽班学生将近30名。
