# 【征战2017DUBA】客场力克广酒，我院男篮获三连胜

第二届东莞大学生篮球联赛进入第四轮，4月26日下午，我院男篮首战广东酒店管理职业技术学院队，也是我院首次客场作战，但受天气影响，比赛转移到东莞轻工业学校室内体育馆进行。

本场比赛，我院男篮依然保持强劲的势头，攻防得当，配合默契，牢牢掌控着比赛节奏。黄志陆、黄明健等队员发挥出色，屡有斩获，大建奇功。最终，我院男篮以58:24高出34分的绝对优势大败对手。

我院男篮教练员钱丽娜老师赛后点评本场球员时，表示“在贯彻教练意图上，十分坚决，12位球员都得到上场锻炼的机会，每个人也都发挥了自己的水平，对大家都挺满意的。但有些新队员则表现不够沉稳，需要慢慢历练，增长经验。”
