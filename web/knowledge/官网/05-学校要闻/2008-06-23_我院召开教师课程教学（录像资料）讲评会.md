# 我院召开教师课程教学（录像资料）讲评会

6月19日，我院教师课程教学（录像资料）首次讲评会在4号楼放映室举行。院督学林世俊教授，财经系主任高香林教授，院督导组督导员及财经系部分教师集中观看了课程录像。

会上，各位督导员和老师集中观看了财经系陈益云老师讲授的《统计学》课程录像。录像放映后，大家畅所欲言，讨论热烈，就教学的形式、方法和内容等方面交流了意见。与会人员认为，陈益云老师的这节课内容丰富，教学基本功扎实，值得大家学习，但讲课中出现的用词准确性及某些数学概念的解释还需要推敲与改进。

会后，林督学对课堂教学提出了具体要求，他概括为 “八字”（清晰、准确、简练、生动）、“四化”（通俗化、形象化、戏剧化、艺术化）、“三适中”（音量、语速、频率适中），希望各位老师以此为标准，审视自己的教学水平。

据悉，高教研究中心还将在下学期继续推行讲评课程录像资料这一督导模式。
