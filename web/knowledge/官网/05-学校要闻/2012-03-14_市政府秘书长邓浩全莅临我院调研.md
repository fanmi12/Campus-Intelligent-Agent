# 市政府秘书长邓浩全莅临我院调研

杨敏林副院长（左1）向邓浩全秘书长（左2）、何绍田镇委书记（右2）汇报新校区情况。

3月13日,东莞市政府秘书长、市政府办公室主任邓浩全在寮步镇委书记何绍田等领导的陪同下，莅临我院新校区调研。邓浩全秘书长一行实地参观考察了新校区，并细致地听取了杨敏林副院长关于新校区建设、校园概况及教学等方面情况的汇报。
