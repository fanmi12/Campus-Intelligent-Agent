# 这位新同学是律师

8月31日，我院政法系12级法学2班迎来了一位特别的同学，名字叫钟建勋，今年35岁，是一名职业律师，已经在广东蔚然律师事务所工作了11年，今年通过专升本考进城市学院。

当天下午两点半，政法系系主任刘杰教授，主任助理危兆宾博士，系总支部副书记刘军在5C313室与这位专插本“高龄”新同学见面交流。

据钟建勋同学介绍，他家住寮步镇，在长期的司法实践过程中，深悉自己需进一步提升专业理论知识水平。他给自己在城院学习定了三个目标：获得本科文凭；通过国家司法考试并考取律师Ａ证；继续攻读硕士研究生。他认为城市学院政法系师资力量雄厚，教学水平和教学质量高，有助于他对于专业知识的获取。

刘杰主任勉励钟建勋与同学们和睦相处，互相学习，取长补短，共同进步。
