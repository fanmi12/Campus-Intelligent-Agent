# 机电系毕业生党员拍摄文明离校倡议短片

5月22日，机电系2012级林启文、叶晓艳、陈桂瑾、黄智伟、陈彩云五位毕业生党员录制推出了文明离校倡议书的短片——“感恩母校之我爱城院”。

四年城院人，一生城院情。四年来，我们用步伐丈量大学的广博，用年轻感知大学的生动，用思想领悟大学的浑厚——“感恩母校之我爱城院”短片倡议，感恩就在生活小事中，留一本好书给师弟师妹，整理好温馨的宿舍，爱护好学校的桌椅，给同窗送上最美好的祝福等都是爱母校感恩母校的表现。

机电工程系这五位毕业生党员表示，自己会做好先锋模范作用，文明离校，并以此倡议全院毕业生。“母校四年的栽培，每一个人都不能忘，所以2012级党员用实际行动来证明了自己的成长与成熟，为母校留下一份美好的记忆”，他们倡议全院的毕业生用自己的行动给在校的师弟师妹充当文明向上的向导，以良好的精神面貌告别校园，让校园因为每一位城院人曾经的足迹而更加美好！

通过短片，机电工程系2012级党员希望传达文明离校的思想给每位城院毕业生，并倡议大家——“我爱城院，文明离校，为母校做一件事”。
