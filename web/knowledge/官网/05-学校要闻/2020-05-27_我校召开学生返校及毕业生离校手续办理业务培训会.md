# 我校召开学生返校及毕业生离校手续办理业务培训会

为保障学生的身体健康与生命安全，扎实做好本学期学生返校准备工作，确保学生返校工作安全有序进行，5月25日下午，我校学生返校及毕业生离校手续办理业务培训会议在行政楼112召开，党委书记章德胜、相关职能部门负责人、各二级学院党总支书记、副书记、全体辅导员及学生工作部（处）人员参加会议。

会上，学生处思政科詹海都科长从学生返校线上申请、返校条件审核、返校当日安排、返校后的学生日常管理、突发状况应急处理、防疫教育、心理援助、毕业手续的办理等方面解读了我校学生返校及毕业生离校工作方案的各项安排，希望各位老师们集思广益，提出更加方面与安全的意见和建议，共同完善方案。

后勤保卫处蔡小锋副处长针对学生返校后的快递物流、饮食、宿舍管理等方面工作作了补充。

最后，党委书记章德胜逐一询问各学院对即将返校第一批学生的跟进情况，是否对每一个返校学生的信息了解到位，并对之前的疫情防控工作进行了总结，他强调，疫情就是命令，防控就是责任。一是思想认识到位，必须提高政治站位，高度重视疫情防控期间的各项工作；二是制度落实到位，规范各项工作流程，切实落实工作要求，确保工作及时到位；三是责任意识到位，各学院党总支副书记、全体辅导员及班主任要层层落实，以高度责任心，做好学生报到及学生返校后的各项管理工作；四是关心关爱学生，经常与学生沟通，密切家校联系，润物无声做好心理疏导工作。
