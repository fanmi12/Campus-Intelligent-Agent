# 学生处举办第七期学生个案分析工作坊

6月14日，学生处在新校区学生活动中心举办第七期学生个案分析工作坊。本次工作坊研究的主题是：“辅导员的技能与提高”。党委副书记朱冰、章德胜，督导办屠大华教授，院团委书记杜鹏举出席。新老校区辅导员以及学生处工作人员等参加了工作坊。

工作坊第一阶段，由代表城市学院参加省辅导员技能大赛的两位辅导员陈桂玲、邓雁虹老师介绍参赛体会。她们亲身的经历、赛后的感受和反思，使到会人员产生共鸣。第二阶段是由文传系辅导员江玲和管理系辅导员陈文丽分别介绍工作中遇到的学生个案供大家讨论。

章德胜副书记对本期工作坊做了总结。他指出，一方面辅导员的职业特点决定了辅导员技能的宽广性，辅导员要做杂家，“上知天文，下晓地理“，明星八卦微博火星语都要有所涉猎。另一方面，只有在某一领域具有一技之长，成为专家，辅导员的职业生命才是长久的。朱冰副书记强调，要好好学习和研究两位辅导员带回来的经验与体会，增强职业责任感和使命感，克服职业倦怠情绪，制定出适合自己长远发展的职业规划，做一个合格的职业辅导员。
