# 2014年“鸿发杯”东莞理工学院城市学院“激辩十年”辩论赛决赛

6月5日，文学与传媒系主办的2014年“鸿发杯”城市学院“激辩十年”辩论赛决赛在学术报告厅举行。党委书记王卫平，院督学陈丁堂，院长助理麦绮琳，东莞边防检查站副政治处主任黄雄中校，东莞边防检查站政治处主任胡飞鸿中校等十位警官观看了比赛。

季军争夺战在财经系、机电系代表队中进行。比赛中，正方双方围绕“英语大热会不会摧毁中国传统文化”的辩题展开辩论。财经系通过对英语在中国的应用性和应试性的剖析出发，认为从长远角度来看，无论是在社会层面还是在精神层面，英语的大热会逐渐瓦解中国的传统文化，不利于对母语、传统文化的保护；机电系则从摧毁一词入手，考虑到传统文化的包容性，以印度为例证，坚持英语是能和传统文化相平衡而并处。比赛过程中，双方辩手妙语如珠，巧舌如簧，为自己的观点进行辩护，激烈的比赛赢得现场阵阵喝彩。

而冠军赛则在文传系与金贸系中拉开帷幕，双方就“儒家思想能不能成为转型期中国的价值依托”各抒己见。现场火药味儿十足，正方金贸系灵巧的借用了城院的十年发展辐射现今转型期中国，以校训“学而知不足”的儒家语录阐述观点，以儒家两千多年的正统地位作为自己的有力武器，证明儒家思想的仁、义、礼、智、信、恕、忠、孝、悌 还是可以作为现今提倡的和谐社会、幸福中国的价值依托；儒家思想固然优秀，但是否适合现在社会的发展呢？实力雄厚的文传系以此论证，中国在转型，面临的是市场经济体制、全球经济化。在法治社会，以提升个人价值为主的儒家思想并不再能成为中国的价值依托，我们现在是以社会主义核心价值体系、八荣八耻作为主流思想。在你来我往的唇枪舌战中，两支队伍不相伯仲，博古论今，以小见大，掀起一场激烈的头脑风暴。

经评委打分，财经系以87分赢机电系85分，取得季军；文传系以89夺得桂冠。
