# 周庆副院长大年初一慰问在岗后勤职工

农历大年初一，副院长周庆、总务处处长翟耀明慰问看望节假日期间坚守工作岗位的后勤员工。

周庆副院长指出，在过去的一年里，城市学院实现健康稳定发展，各项工作取得新成绩，后勤职工功不可没，值得点赞。在新的一年里，希望大家再接再厉，为建设更加美好的城市学院继续作出新的贡献。
