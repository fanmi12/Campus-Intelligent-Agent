# 政法系召开新学年教职工工作会议

8月28日，政法系召开教职工会议，安排部署新学期的工作。

会上，系主任刘杰教授对上学期及暑假期间的工作进行了回顾和总结。他特别提到，许多教职工在暑假期间，冒着高温酷暑，开展调研活动，精神可嘉，收获很大。

刘主任对新学期的主要工作进行了全面部署。他强调，全系上下要继续执行院、系年初制定的工作计划，按时保质保量完成各项任务；教学常规工作要经常抓、狠狠抓、规范地抓，抓出成绩，抓出效果；要加强专业建设，努力建设重点课程和网络课程，开展课题申报和教学改革工作，拓展专业实践教学基地；要看好“三张表”，站好三尺讲台，努力提升自身素质，提高教学教育水平；要进一步强化责任心，统一思想，更新观念，坚守传承，改革创新，开创政法系工作新局面。
