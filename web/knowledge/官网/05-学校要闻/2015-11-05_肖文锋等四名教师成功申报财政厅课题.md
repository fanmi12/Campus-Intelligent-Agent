# 肖文锋等四名教师成功申报财政厅课题

近日，我院财经系喜讯连连，肖文锋、申飞虎、耿玉成、刘琦四名老师成功申报广东省2015-2016年度会计科研课题。

据悉，本次申报的会计课题156项，评定中标会计课题91项，申报竞争非常激烈。我院财经系四名教师在本次申报中取得成功，是省财政厅对我院财经系科研实力的肯定。

申报的课题名称及其主持人名单如下：

1.行政事业单位内部控制体系建设及实践研究 肖文锋 副教授;

2.东莞市管理会计应用调查研究 申飞虎 讲师;

3.“互联网+”背景下的企业会计业务流程重组研究 耿玉成 讲师

4.基于绩效评价视角的政府会计改革问题研究 刘琦 讲师
