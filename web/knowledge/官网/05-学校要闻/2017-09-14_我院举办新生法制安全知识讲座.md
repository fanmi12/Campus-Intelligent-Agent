# 我院举办新生法制安全知识讲座

9月13日晚，新生入学教育系列讲座第三讲开讲，东莞市寮步公安分局刑警大队黄东城警官在综合馆为2017级新生作“以案说防”法制安全知识讲座。

黄警官从“电信诈骗、校园贷、毒品危害、校园盗窃”等方面，通过多个发生在同学们身边的法制案例，介绍了大学校园常见的各类犯罪活动，提醒同学们加强安全防范意识，谨防校园电信诈骗及校园贷，远离毒品，养成时时防范和洁身自好的好习惯。

黄警官特别提到，要谨慎防范冒充司法机关工作人员或熟人进行电信诈骗、发布虚假中奖信息或贷款信息、虚假网络购物等几种常见的电信诈骗犯罪手段。针对陌生电话、短信等，黄警官告诫同学们千万不要贪图蝇头小利，要与家人沟通、核实，必要时拨打110报警电话寻求帮助。

讲座中，黄警官以幽默的语言、生动的案例，讲述了同学们身边的法制小知识，为新生们敲响了警钟，提高大家的安全防范意识。
