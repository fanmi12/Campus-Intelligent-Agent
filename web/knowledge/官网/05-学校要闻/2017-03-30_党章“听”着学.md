# 党章“听”着学

为深化“两学一做”学习活动，文传系党总支于3月中下旬组织全系师生党员及入党积极分子，开展了为期15天的“听党章学党章”系列学习活动。

文传系党总支为创新党建活动，加强组织学习，积极创特色树品牌，推出了“听党章学党章”系列学习活动，通过录制 “先锋之音”系列音频，创新并丰富了党章的学习方式。

在“听党章学党章”活动中，文传系党总支结合了专业特色将党章按章节分别录制，并刻录成“先锋之音”系列光碟以供传阅。活动采取集中收听和分散收听、线上线下收听相结合的方式，组织大家学习。其中，3月8日——活动开展首日，组织全系师生党员和入党积极分子在课室集中收听党章总纲部分。活动期间又利用“城院文传先锋”公众号，每日陆续播出“先锋之音”党章音频。只要登录该微信公众号，点击“先锋之音”栏目，标准普通话播出的党章语音就会响彻耳旁。此时，只要抽出15分钟的时间，静下心来就可轻松地学习党章。

自开展以来，活动取得了热烈的反响，党员和入党积极分子们还纷纷在微信平台上留言，分享学习党章的体会。据统计，现已共收到了150多条留言，点击量达2500多次。

据文传系党总支书记宋秋敏介绍，“听党章学党章”活动新颖，与专业紧密结合，通过“音频党章”让党章学习变得更便捷、更轻松，在全系营造了“人人读党章、人人听党章，人人学党章”的浓厚学习氛围。
