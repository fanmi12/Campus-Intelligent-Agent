# 我省召开2017届高校毕业生就业创业工作视频会议

4月19日下午，广东省教育厅召开我省2017届高校毕业生就业创业工作暨第三届中国“互联网+”大学生创新创业大赛广东分赛动员部署网络视频会议。

记者了解到，这次会议主会场设在广东省教育厅，同时在东莞理工学院城市学院、深圳大学等18所高校设立分会场，全省共320人参加了视频会议。在城市学院分会场参加会议的有：东莞理工学院副校长马宏伟，城市学院副院长黄兢，还有广东医科大学、广东科技学院、东莞职业技术学院、广东创新科技职业学院的院级领导和主管负责人。

广东省委教育工委书记，省教育厅党组书记、厅长景李虎出席会议。景李虎厅长充分肯定了我省就业创业工作所取得的成绩，并对下一步做好高校毕业生就业创业工作提出了明确要求：一是全省教育系统要认真学习贯彻习近平总书记对广东工作的重要批示精神，要为广东全面落实“四个坚持、三个支撑、两个走在前列”提供支撑和保障。二是高等教育要认真研究国家经济社会发展需求，把准教育大方向，将人才培养与社会需求对接。三是创新人才培养机制，倒逼人才培养，提高人才培养的质量和水平。四是共同努力做好高校毕业生就业创业工作，确保高校毕业生更高质量就业。

会议由广东省教育厅副巡视员邱克楠主持。会上，邱克楠同志对第三届中国“互联网+”大学生创新创业大赛广东分赛作了动员和部署。
