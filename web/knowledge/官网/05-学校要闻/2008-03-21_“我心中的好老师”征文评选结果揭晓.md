# “我心中的好老师”征文评选结果揭晓

为展示为人师者的形象和风采，弘扬爱师尊师的良好传统，推动我院教学改革，积极宣传教师教书育人的先进事迹，高等教育研究与评价中心、新闻中心于去年11月开始，联合举办了《我心中的好老师》征文活动。

这次征文活动，受到广大学生的热烈欢迎，共收到各类文章400多篇。广大学生从不同角度、不同侧面，记叙教师的治学与育人事迹，真切地抒发了对老师独特的感情，歌颂了优秀教师的美好品格，反映了我院师生积极向上的精神风貌。经过专家学者的评选，文学与艺术系邹丽花、古海莲、欧阳思琴，管理系李丽勤，机电工程系赵伟同学获一等奖，黄科等10名同学获得二等奖，王星皓等20名同学获得三等奖，机电工程系和文学艺术系获组织奖。
