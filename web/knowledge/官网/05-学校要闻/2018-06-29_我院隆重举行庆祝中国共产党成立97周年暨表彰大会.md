# 我院隆重举行庆祝中国共产党成立97周年暨表彰大会

6月29日下午，我院隆重举行庆祝中国共产党成立97周年暨表彰大会。

王卫平等院党委委员和院领导、全体教职工党员及学生党员代表参加了大会。

大会由院党委副书记章德胜主持。

在庄严的党旗面前，院党委委员杜鹏举作为领誓人，带领与会党员重温入党誓词。

大会宣读了《关于表彰2017－2018学年度先进基层党组织、优秀党务工作者和优秀共产党员的决定》，对商学院党总支、金贸系党总支、城环系党总支、机关一党支部、机关四党支部等5个基层党组织授予“先进基层党组织”称号；对万文双、徐媛媛、杨佳青 陈东汉等4名教工党员授予“优秀党务工作者”称号；对曹琴、刘建、王雄文等37名教工党员授予“优秀共产党员”称号；对梁思慧、何国正、刘绮婷等37名学生党员授予“优秀共产党员”称号，并颁发荣誉证书。

优秀学生党员代表、商学院2018届毕业生郑少杰同学在大会上发言。他表示，作为一名大学生党员，要始终不忘初心，牢记使命，端正牢记自己的入党动机。毕业后，他将始终遵循“做好事、做成事”的人生态度，把在城院四年的宝贵学习经验带到职场，用一件件小事，一点一滴的行动，履行自己的工作职责，诠释一名共产党员对事业的追求。

先进基层党组织代表、金贸系党总支副书记万文双以“开拓创新奋斗不息，立德树人永不停止”为题，介绍了金贸系被中共广东省教工委命名为省高校学习型、服务型、创新型党支部的工作经验。她表示，“打铁还需自身硬”，作为基层党务工作者，要不断强化自身建设，热爱本职、牢记使命，勇挑重担，努力适应新形势新任务的要求，为学院的发展和学生的成长提供更为专业和优质的服务。

会上，院党委书记王卫平回顾了97年来，党在革命、建设、改革的伟大历程和取得的伟大成就。特别是党的十九大站在发展新起点上，提出“中国特色社会主义进入新的发展阶段”的重大战略判断和基本方略，习近平“新时代中国特色社会主义思想”，实现了党的指导思想又一次与时俱进，开启了中华民族伟大复兴中国梦的新征程。

王卫平书记对本学年学院党建工作取得的成绩进行了总结分析，对下学年学院党建工作进行了部署。

王卫平书记强调，学院取得今天的办学成就，是全体师生员工、特别是全体党员共同奋斗的结果，并号召全院师生员工向受表彰的先进集体和先进个人学习。希望同志们“不忘初心、牢记使命”，励志改革、勇于创新、锐意进取，永做新时代合格共产党员，为学院的改革发展做出新的、更大的贡献。
