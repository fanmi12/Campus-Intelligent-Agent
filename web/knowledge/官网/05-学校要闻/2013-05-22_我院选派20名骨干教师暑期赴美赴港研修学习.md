# 我院选派20名骨干教师暑期赴美赴港研修学习

为推进我院高层次人才队伍建设，加快教师队伍国际化进程，提升中青年教师的创新能力和学术水平,近日，我院选拔出10名中青年骨干教师于今年暑假期间赴美国北爱荷华大学进行教师职业道德、国外先进的教学理念及教学方法和相关专业课程的研修学习培训，时间为15天。

今年暑假期间，我院还将选派10名骨干教师参加由校本部东莞理工学院在香港理工大学举行的高校教学管理专题研讨班和现代教学法研讨班，学习有关香港高校管理模式与运作、项目为本教学法、多元化教学法等课程，并赴香港大学、香港理工大学、香港科技大学等高校考察交流。
