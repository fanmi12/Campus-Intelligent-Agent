# 我院顺利开展2019年本科插班生招生考试工作

今日上午8时，广东省2019年本科插班生招生考试新增考点——东莞理工学院城市学院“专插本”招生考试顺利开考。

今年，我院本科插班生共确认报名考生2907人，创历年之最。经广东省考试院研究决定，首次在我院开设本科插班生招生考试考点，承担报考我院考生的考试工作。

为做好此次考试工作，我院成立了以王卫平院长为组长的“本科插班生考试考务领导小组”，考前多次组织各相关部门和人员召开协调会，对各项考试工作进行了精心的准备和周密的安排。

此次考试共为期两天，将于明日下午结束。目前，考试正在井然有序地进行。
