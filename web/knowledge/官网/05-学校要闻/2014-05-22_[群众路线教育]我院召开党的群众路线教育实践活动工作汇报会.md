# [群众路线教育]我院召开党的群众路线教育实践活动工作汇报会

5月20日下午，以丁纪平同志为组长的广东省委教育工委教育实践活动指导组一行四人，莅临我院检查指导工作。指导组在我院进行实地考察并听取汇报后，对我院教育实践活动给予高度评价，一致认为我院教育实践活动实施方案符合上级党委要求和文件规定，活动内容充实、计划周密细致；学习教育紧扣主题，突出特色；坚持开门搞活动，深入基层听取意见；查找问题有清单、整改有台帐，知行合一、边学边改。非常好！

院党委王卫平书记感谢指导组莅临我院检查指导工作，重点汇报我院教育实践活动自 2月26日以来，在东莞理工学院党委高度重视和直接领导下，认真贯彻党中央和广东省委教育工委文件精神，紧密结合办学实际，坚持“照镜子、正衣冠、洗洗澡、治治病”的总要求,聚焦作风建设，围绕保持党的先进性和纯洁性，切实加强全院党员马克思主义群众观点和党的群众路线教育。

院党委坚持学习教育领先，筑牢思想基础，牢牢抓住 “开展理想信念、党性党风党纪和道德品行教育，开展马克思主义群众观点和党的群众路线专题学习讨论”这条主线，深入开展学习教育，调查研究，听取意见，使党的群众路线在全体党员、干部中深深扎根，使践行党的根本宗旨成为党员、干部的普遍自觉。

院级领导干部坚持深入基层，听民声、识民意、接地气，认真调研，听取意见。全覆盖深入12个教学系（部），采取座谈会的形式广泛听取党员、干部 、教职工和学生代表的意见和建议，共收集到意见和建议11类118条，取得阶段性成果。

学院党委坚持回应群众关切，维护群众利益，注重解决实际问题。把改进作风的要求真正落实到基层，真正让群众受益。确保教育实践活动不虚不空不偏，不走过场。

杨敏林院长在会上重点汇报了学校办学情况。他说，自2011年以来，学院步入发展快车道。学生人数增加，办学层次提高，原有的办学思维和管理模式显然不相适应。学院认为保证学院稳定健康发展，直接反映了教职工最大的关切和利益。在教育实践活动中，学院注重结合办学思路、发展定位、优化管理等开展活动。展开创办应用技术型大学讨论，将教育实践活动融入学校教书育人中心工作的载体与形式,进一步优化教风、学风、校风，进一步提高办学水平。
