# 星河城举办首届城院微电影展映礼

7月4日晚，2015年星河城首届“繁星璀璨，青春不散”城市学院微电影展映礼，在星河城正门广场隆重举行。学院副院长高香林、教务处处长牛熠、学生处处长杜鹏举，文传系系主任李上文等领导和东莞微电影协会副秘书长李笑天、理事林建勋出席了活动。

我院制作的微电影《跟我走》、《续途》、《爱不停，歇》在此次展映礼中首次上映，分别以爱情、旅行和亲情作为主题，各具特色，赢了得观众的一致好评。

展映礼上，演员走红地毯；晚会活动中，我院艺术团OLT街舞团、阿卡被拉组合、风烙舞队进行了精彩的表演，展现了我院学子的时代风采，受到现场观众的热捧。
