# 学院党委召开思想政治理论课集体备课会

9月19日下午，学院党委在行政楼212会议召开2017年秋季学期思想政治理论课集体备课会。院长、党委书记王卫平，党委副书记章德胜，各系主任、党总支书记及思政部部分教师参加了集体备课会。党务工作部副部长叶凯贞主持了会议。

章德胜副书记传达了《中共广东省教育工委关于做好2017年秋季学期高校党委书记、校长和院（系）党组织书记、院长（系主任）上思想政治理论课的通知》精神，要求各系主任、党总支书记旗帜鲜明地站在宣传思想和意识形态工作第一线，在9月30日前全部完成任务，并做好宣传工作及后期课件、教案等材料的上报工作。

思想政治理论教学部副主任石志民对时间安排、讲课内容及重点工作要求等，进行了讲解与安排。

思想政治理论教学部宗卫菊、赵卫丽老师进行了说课，分别对《思想道德修养与法律基础》《中国近现代史纲要》这两门课的主要要求、课程概况、课程特点、教学难点、教学方式等进行详细讲解。她们还结合自身教学教改的经验与成功做法，介绍了思政课教学优化路径及课堂教学创新模式，为与会人员提供参考。

王卫平书记要求各系主任、党总支书记给予高度重视，积极准备，认真备课，从政治和全局的高度上好这堂思想政治理论课。
