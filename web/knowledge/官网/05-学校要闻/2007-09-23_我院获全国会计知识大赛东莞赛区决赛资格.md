# 我院获全国会计知识大赛东莞赛区决赛资格

全国第三届会计知识大赛东莞赛区比赛，分为选拔赛（笔试）、复赛（口试）、决赛三个阶段进行。

9月19日选拔赛时，全市有60支代表队、191名选手参加比赛，选出12支代表队进入复赛。东莞理工学院城市学院代表队（由财经系韩静、张灿灿、郑阿泰三人组成）在选拔赛中以第二名的成绩进入复赛。

9月21日，12支代表队进行复赛，选出了6支代表队进入决赛。城市学院代表队又以第二名的成绩顺利进入决赛。

东莞赛区决赛将于2007年9月28日进行，决出前三名，届时东莞电视台将进行实况转播。
