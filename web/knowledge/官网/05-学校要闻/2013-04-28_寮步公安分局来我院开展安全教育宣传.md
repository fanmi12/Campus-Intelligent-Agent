# 寮步公安分局来我院开展安全教育宣传

4月25日，东莞市寮步公安分局巡警大队、泉塘派出所一行10余人在巡警大队副大队长梁少全警官带领下，来我院开展“共创平安公交、共建和谐东莞”的安全教育宣传活动。院总务处副处长陈辉、保卫办主任刘维仝及部分校卫队员参加了此次活动。

在活动现场，学生们仔细阅读了宣传图片，踊跃领取安全出行小册子，并向警官们详细咨询了安全出行的各种问题和措施。警官们耐心解答了学生提出的问题，讲解了在出行时应注意的各种扒盗、抢夺、诈骗手段，并强调同学们出行时应提高警惕，掌握基本的防犯措施，不给犯罪份子可乘之机，保护好个人人身安全和财产安全。
