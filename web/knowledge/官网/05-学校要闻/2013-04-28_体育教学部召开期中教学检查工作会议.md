# 体育教学部召开期中教学检查工作会议

4月27日，体育教学部召开2012-2013学年第二学期期中教学检查工作会议，会议由体育部主任、书记邢红林教授主持，体育部全体教师参加。

会议开始首先由邢红林教授传达学院期中教学检查的通知并对如何做好本学期的期中教学检查工作做了细致的布置，同时重点围绕着通过期中教学检查及学院教学状态评估为契机更好的提高体育课堂教学质量这一主题进行了讨论和交流，教师们在会议上针对本学期的教学工作开展情况，并结合各自专项教学的实际进行了分析，就教学质量、教师道德及本学期学风建设等问题展开热烈讨论。 参会教师达成一致共识：遵循人才培养方案，合理分配课程资源，注重程序，狠抓细节，严格把关，稳固提高教学质量。

此次期中教学检查会议的召开，有利于体育教学部教学质量的提升。
