# 我院在“第八届全国大学生计算机应用能力与信息素养大赛”中获得佳绩

5月25日-27日，第八届全国大学生计算机应用能力与信息素养大赛（暨海峡两岸产业核心技能素养大赛）分别在首都经济贸易大学和中央民族大学举办。我院获得一等奖2项、二等奖5项，并获得计算机基础赛项团体一等奖、Office商务应用能力赛项团体三等奖的佳绩。这是我院第二次参加该项赛事。

本届大赛除了传统的计算机基础、Office商务应用和专业英文词汇与对话赛项之外，还特别增加了反映时代趋势与潮流的大数据技术与应用赛项。通过激烈的技能竞技，我院代表队脱颖而出，取得了优异成绩。其中，崔燕茹老师指导的郑沛章同学和郑丹如同学分别获得本科组计算机基础赛项全国一等奖和本科组Office商务应用能力-文字处理全国二等奖；胡良兰老师指导的16级机械本1班邓浩锋同学获得本科组Office商务应用能力-文字处理全国一等奖；张黎明老师指导的姚博智同学、谢安丽同学和文树琦同学分别获得本科组计算机基础赛项全国二等奖和本科组Office商务应用能力-电子表格全国二等奖；王丽莉老师指导的黎泳琪同学获得本科组Office商务应用能力-文字处理全国二等奖。我院获得计算机基础赛项本科组团体一等奖、Office商务应用能力赛项团体三等奖的佳绩。

全国大学生计算机应用能力与信息素养大赛是由全国高等院校计算机基础教育研究会、全国高等学校计算机教育研究会、工信行指委计算机类专业指导委员会和《计算机教育》杂志社等单位联合主办的。本届大赛共有185个院校代表队、近19000名同学参加，最后进入总决赛的院校代表队有145个，参赛选手数为878人。
