# 新校区开展“百年城院 百年爱心林”植树活动

秋高气爽，阳光灿烂。10月29日，来自广东鸿发投资集团有限公司（以下称鸿发集团）及东莞理工学院城市学院的600多位爱心人士，继9月3日在新校区首次开展的“百年城院 百年爱心林”大型公益植树活动之后，再次掀起了“百年城院 百年爱心林”公益园林建设活动高潮。

植树活动之前，东莞理工学院党委书记周致纳首先感谢参与本次公益园林建设活动的各位爱心人士。他说：“种下一棵树，就是立下一座永久的丰碑！在大家的支持和全院教职工的努力下，城市学院的明天一定会更美好！”

鸿发集团总裁麦照容，副总裁麦燕娣、黎建烨、刘镇庭、麦建红等领导及各子公司负责人，东莞理工学院城市学院副院长杨敏林等领导出席了活动。

城市学院董事长麦照容表示，对认养树木的单位或个人，将以挂牌等形式作永久纪念，以感谢大家对城市学院的贡献、对东莞高等教育所奉献的爱心。

“十年树木，百年树人。兴办教育事业，功在当代，利在千秋。”麦照容总裁深情地寄语城市学院广大学子。

随后，在位于学院的东门右侧的“百年爱心林”举行了隆重的揭牌仪式。

记者发现，前来植树的嘉宾中有的是全家参与，有的家庭推着婴儿车前来，小朋友更是热情高涨，爱心林洋溢浓浓的爱心与温情。他们纷纷来到各自捐赠或认养的树木前，细心地飞锹培土、种植。

据悉，本次植树活动共有600多位爱心人士捐赠或认养了400多株各类名贵树木，包括黄花梨、海红豆、玉蕊、木棉、大树菠萝、黄花风铃木、香樟等树种。在植物配置设计中，根据花期花色的不同进行合理搭配，将使整个校园和“百年爱心林”的植物景观产生花期错落、四季花香、姹紫嫣红的效果。
