# 我校摄影作品《我校开展消防安全演练》荣获省优秀新闻作品三等奖

近日，据广东省教育厅文件通知，我校谢昀潼同学的新闻作品《我校开展消防安全演练》在2019年广东省高校宣传思想工作优秀作品评选中荣获优秀新闻作品新闻摄影类三等奖。

据悉，本次评选活动经各高校积极响应，精心组织实施，涌现出一批宣传思想工作优秀作品，经组织评审，共评出一等奖18件、二等奖30件、三等奖55件。

本次评选活动旨在学习贯彻习近平总书记关于宣传思想工作的重要思想，加强对我省高校宣传思想工作成果的宣传展示，进一步增强宣传策划能力，创新传播手段和话语方式，生动鲜活的讲好广东高校故事，全面立体展示广东高校风采，唱响主旋律，传播正能量，切实推动“举旗帜、聚民心、育新人、兴文化、展形象”使命任务落实。
