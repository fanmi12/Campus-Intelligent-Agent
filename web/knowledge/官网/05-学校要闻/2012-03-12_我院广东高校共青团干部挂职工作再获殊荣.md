# 我院广东高校共青团干部挂职工作再获殊荣

3月9日，共青团广东省委、中共广东省委教育工作委员会，在广州召开广东学校团干部到县级团委挂职工作2011年总结表彰大会。会上，我院荣获“2011年广东高校共青团干部到县级团委挂职工作优秀组织奖”称号。林胜凯老师荣获“2011年广东高校共青团干部到县级团委挂职工作挂职团干部标兵”称号。

据悉，为贯彻落实团中央、教育部党组《关于从全国高等学校中选派共青团干部到县级团委挂职工作的通知》精神，2011年共青团广东省委、中共广东省委教育工作委员会联合组织选派了158名高校团干部到广东、贵州、广西县级团委挂职。我院积极响应，全力配合上级指示，选派了计算机与信息科学辅导员林胜凯老师赴广西平南县挂职。在挂职期间，林老师心系群众，扎根基层，整合校地资源，创新工作方法，积极推动了当地团的基层组织建设和基层工作，形成了校地合作推进团工作的新机制，受到广泛好评。
