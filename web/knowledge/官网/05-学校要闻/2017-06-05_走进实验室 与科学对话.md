# 走进实验室 与科学对话

“走出宿舍、走下网络、走进实验室”。6月1日、2日，城环系举办第二届“与科学对话——走进城环实验室”之实验室开放日活动，24支队伍、120多名同学亲身体验科学实验，感受科学魅力。

1日下午，实验室开放日活动启动仪式在8B503课室举行。城环系主任肖红飞对活动的意义给予了充分的肯定，对活动内容和方式的创新给予了高度评价，并预祝活动顺利举行。

据了解，此次实验室开放日活动共设置GPS定位夺宝、秘密情书(科学实验)、火山喷发(科学实验)、一触即燃(科学实验)和灭火大行动等五个同学们都感兴趣的项目，都具有一定的科普性和实用性。各参加队伍在工作人员的指引下，在规定时间内完成所有活动项目。虽然天气较热，但参加的同学热情不减，团结协作，共同完成了相关项目。

经过两天别样的体验与角逐，最终，“搬砖生产队”获得第一名，荣获“科学大师”称号；“爱因斯坦归来”、“TheOnly”和“TheOne”三支队伍分别荣获“科学达人”、“科学能手”、“科学小将”等称号。

据介绍，城环系第二届实验室开放日活动吸引了全院学生的关注，活动前期将近400名学生报名，最终120名学生（24支队伍）通过审核后参加活动。参与活动的学生来自全院各系部，其中外系学生占60%。通过开展实验室开放日活动，参与活动的同学纷纷表示受益良多，感受不同的学科文化，激发了学生对科学研究的兴趣，营造了良好的科技学术氛围。
