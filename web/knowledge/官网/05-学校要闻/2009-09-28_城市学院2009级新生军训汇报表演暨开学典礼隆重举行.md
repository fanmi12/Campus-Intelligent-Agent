# 城市学院2009级新生军训汇报表演暨开学典礼隆重举行

东莞理工学院党委书记周致纳检阅军训方阵。

东莞理工学院校长、城市学院董事长杨晓西为获奖连队颁奖。

院长安少华向全体新生发表了热情洋溢的讲话。

军训团长韩加强做军训总结讲话。

军训方阵接受检阅

女子、男子军体拳表演

素质拓展训练“人体多米诺”向观众展示了力与美的漩涡。

四连成为此次军训评比的赢家，一举获得三项一等奖。

秋风送爽，旌旗猎猎。9月28日上午9时，我院2009级新生军训汇报表演暨开学典礼在学院操场隆重举行。检阅了军训成果，表彰了在军训中取得突出成绩的连队和个人。

东莞军分区副政委喻清明大校，沙角海军训练基地副司令员肖继生上校，东莞理工学院党委书记周致纳，东莞理工学院校长、城市学院董事长杨晓西，东莞理工学院副校长、城市学院院长安少华，学院领导朱志德、程发良、朱冰、张林及院督学陈丁堂等出席了会议。各系部主要负责人也在主席台就座。

东莞理工学院党委书记周致纳检阅了军训方阵。检阅过程中，“学习刻苦，立志成才”的口号如浪涛般响彻全场。随后，军乐响起，同学们迈着威武有力的步伐以连为单位走过主席台，接受入会领导的集体检阅。14天的艰苦训练，汗水和泪水都烟消云散，此刻，同学们由齐步而正步，坚定地向前，向前，向前！台上的领导为每一个方阵鼓掌。

部分连队表演了精彩的军训项目。女子军体拳表演动作轻灵，步调整齐，柔中带刚。男子军体拳遒劲有力，虎虎生风，让人热血沸腾。紧接着他们还进行了格斗、卧倒、停止间动作演示等精彩表演。城市学院军训的特色项目素质拓展训练表演开始了。只见新生们瞬间围成一个螺旋多米诺队列，指挥员一声令下，大家如多米诺骨牌一般向后倒下去，又逐波站起，向观众展示了力与美的漩涡。始于07年的军训特色项目——素质拓展训练，其目的是为了激发潜能，培养团队精神。最后同学们还进行了旗语表演，展示了忠于党、忠于祖国和人民、刻苦学习、崇尚成功的决心。

军训团长韩加强做了军训总结讲话。他对同学们冒酷暑、顶烈日，刻苦训练，终于取得优异成绩表示祝贺。祝愿同学们继续发扬军训精神，在今后的学习中取得更好成绩。

学院党委副书记朱冰宣读了表彰决定。以连为单位分别评选出队列、内务卫生、宣传报道、作风纪律、团体优胜一、二、三等奖，评选了136名军训积极分子。

在随后举行的开学典礼上，院长安少华向全体新生发表了热情洋溢的讲话。他首先对一贯支持我院工作的东莞军分区、沙角海军训练基地的官兵表示衷心感谢，对09级全体新生表示热烈欢迎。他简短回顾了城院的发展历史，勉励同学们把自信写在脸上，把理想装在心中，把目标付诸行动，用辛勤和汗水谱写人生新的华章。

院学生会主席陈逸斌及新生代表张媄淅先后上台发言。各系辅导员按顺序上台与新生们见面。
