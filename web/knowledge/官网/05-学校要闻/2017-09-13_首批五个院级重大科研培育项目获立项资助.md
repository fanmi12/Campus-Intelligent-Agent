# 首批五个院级重大科研培育项目获立项资助

9月10日下午，我院召开了院级重大科研培育项目立项工作评审会。来自华南理工大学、东莞理工学院等高校的五位教授作为特邀评审专家出席了会议。副院长黄兢参加了评审会，研发处处长赵书山主持会议。

2016年，我院启动了院级重大科研培育项目的申报立项工作，以激励教授、博士等骨干教师从事科研活动，为学院今后申报省级及以上重大科研项目奠定基础，从而推动学院科研创新快速发展。经院内自主申报及资格审查后，宋秋敏博士申报的“宋代士风嬗变与词体演进研究”、殷素峰博士申报的“精密端子连接器多型腔注塑封装工艺的稳健性”、刘武辉博士申报的“薄膜电致发光片的研制及应用开发”、肖红飞博士申报的“一种基于生物秸秆的高效生物质能回收装置的研究”、李洪超博士申报的“基于机器视觉的数控刀片检验包装自动化柔性系统”等五个项目进入立项评审阶段。

特邀评审专家组对这五个项目的申报材料进行了严格审查，逐项给出了客观、中肯的评审意见，认为该批项目具有较好的前瞻性和基础性，具备良好的应用前景，未来2-3年内有望达到省级以上项目立项的标准。经评审会集中讨论、投票表决，同意这五个项目的立项资助申请，成为我院首批院级重大科研培育项目。

据悉，我院未来还计划在院级重大科研培育项目中，增设港澳台引进博士类项目，用于鼓励和支持引进的港澳台地区高层次人才开展高水平科研活动。
