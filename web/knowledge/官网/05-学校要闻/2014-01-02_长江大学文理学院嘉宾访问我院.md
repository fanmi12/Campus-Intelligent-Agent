# 长江大学文理学院嘉宾访问我院

12月30日，湖北长江大学文理学院院长沈光明、副院长郭睦庚、办公室主任简志虹、评估办主任曹骥、就业指导服务中心主任解礼元、外国语系主任许晓艳一行6人来我院考察交流。院长杨敏林、党委书记朱志德、副书记章德胜热情接待了来宾。

学院办公室、组织人事处、高等教育研究与评价中心、就业指导中心、文学与传媒系等单位的负责人参加座谈会。

双方在教学管理大楼会客厅就共同关心的独立学院评估与验收、学生就业、人事管理等问题进行了深入的交流。

沈光明院长一行了解我院规划建设情况

双方在行政楼会客厅举行座谈

院长杨敏林会见来宾并与客人合影

党委书记朱志德与客人交谈
