# 印刷专业学生在2014年中国创意包装设计大赛中喜获佳绩

日前，2014年中国包装创意设计大赛在浙江工商大学艺术设计学院落下帷幕，我院机电系印刷专业学生在比赛中共获得7个奖项。

据悉，中国包装创意设计大赛由中国包装联合会主办、世界包装组织支持，由中国震动工程学会包装动力学专业委员会《包装世界》杂志社联合承办，是包装行业的最高赛事之一，参赛对象包括各包装工程院校、美术设计院校、包装企业及日、韩、英、法、德等国的部分院校师生，共有300多所院校近5000件作品参赛。

唐淑娴同学的《7支装牛奶包装盒》获得本科学生组包装结构类三等奖；唐淑娴同学的《黑色与彩色》、林春烨同学的《阳光茶饮》、张紫君同学的《大白兔奶糖》获得本科学生组装潢设计类三等奖；还有钱笑仪同学的《银色树骨瓷茶杯包装盒》、陈元等同学的《日记本套装》、陈家丽同学的《给生活留白》获得入围奖。
