# 医务人员提醒师生防控病毒感染性腹泻

据广东省教育、卫生部门有关文件通报，开学初以来，广州的5所学校陆续发生诺如病毒肠胃炎疫情，患者表现为腹泻、恶心、呕吐,少数病例出现发热症状。据判断，传播途径以食源性传播为主。现在，疫情虽已控制，但为有效防控诺如病毒肠胃炎及食物中毒等突发公共卫生事件的发生和流行，保障广大师生的身体健康和生命安全，根据文件要求和专家意见，我院医务人员建议：

一、一旦发生传染病流行疫情，要及时向院医务室及系部领导报告。

二、加强以预防肠道传染病为重点内容的宣传教育工作，增强卫生防病意识，养成良好的卫生习惯。

三、加强食品和饮用水卫生管理，加强食堂卫生及从业人员健康检测，增设洗手池等卫生设施。

四、全面开展一次餐厅、宿舍、课室、图书馆等场所的彻底清洁消毒工作，保持室内环境的通风透气。

据悉，学院近日将会对食堂等重点场地进行一次大检查。
