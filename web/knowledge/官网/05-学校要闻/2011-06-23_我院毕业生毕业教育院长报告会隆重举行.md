# 我院毕业生毕业教育院长报告会隆重举行

6月21日，我院毕业生毕业教育院长报告会在学院大礼堂隆重召开。城市学院院长安少华教授为1100多名毕业生党员、干部上了精彩的一堂教育课。

安院长指出，作为即将走出校门、走向社会的大学毕业生，必须坚定地追求自己心中的理想，只有坚持理想才会有做好事情的动力。机会对每个人来说都是均等的，但机会却始终留给有准备的人。安院长例举了许多我院往届成功学生的事例鼓励大家，一个成功者，必须要有坚持梦想的决心和毅力，不要因为一时的平凡就心灰意冷。要从小事做起，接受不同的考验，相信梦想终会实现。人生如同一场球赛，每一刻都充满精彩。

安院长强调，作为新时代的学生党员、干部，作为学院的优秀毕业生，走上社会后将要肩负起未来社会管理者的重任。这就要求我们从现在开始，不仅要充分掌握最新的科技信息和科学技术，适应社会，更要引领社会。

安院长还为同学们讲解了《人民日报》最近发表的几篇重要文章，就如何培育正确的社会心态、“异质思维”、“弱势心态”等当下热门问题进行了分析。安院长鼓励同学们要注重培养创新型思维，用新思想、新观念、新方法来武装自己，并运用到未来的社会管理当中。

安院长还指出，毕业生党员、干部，要继续发挥先锋模范作用，发扬我院学生“肯干、好用、实在”的优良传统，把握好同学、老师的资源，踏实做好工作，为城院增光。

最后，安院长勉励大家要坚持不懈，克服困难。今天坚持多一点，明天成功希望的就会多一点。不一定都要当大官，但一定要有做大事胸怀和气度。
