# 4886名城院学子今日毕业

今日，我院2013级4886名学子顺利毕业！

伴随毕业的喜悦和淡淡的离愁，在一派欢乐祥和的氛围里，东莞理工学院城市学院2017年毕业典礼暨学士学位授予仪式在综合馆隆重举行！

东莞理工学院党委副书记吕琦元，东莞理工学院城市学院董事会董事长麦照容、董事黎建烨，广东鸿发教育文化集团有限公司总经理陈超群，学院院长、书记王卫平和全体院领导，各院、系（部）领导，各单位负责人，以及毕业生班主任、教师代表、毕业生家长代表和全体毕业生出席了毕业典礼。毕业典礼由高香林副院长主持。

“青春，不说再见”

综合馆里，一部精心制作的毕业短片《青春，不说再见》，将2017届毕业生的四年大学生活，在一幕幕的画面中，一一重现。

短片通过老师和毕业生们对大学期间点点滴滴、难忘瞬间的回忆，表达了对青春、对大学、对城院的难舍与眷恋之情。毕业生

对母校深情款款的祝福，激起现场热烈的掌声。

224名“2017届优秀毕业生和46名立志奖获得者受到大会表彰

在庄严的国歌声中，毕业典礼拉开了帷幕。

大会上，王卫平院长代表学院向2017届毕业生代表颁发了毕业证书。

章德胜副书记宣读《关于表彰2017届优秀毕业生的决定》及《关于授予黄伟杰等46名毕业生立志奖的决定》。申玉婷、王斯婷、陈韵如等224名同学被授予“2017届优秀毕业生”荣誉称号。黄伟杰等46位即将进入研究生学习阶段的同学被授予“立志奖”。麦照容董事长、吕琦元副书记、黎建烨董事分别向获得表彰同学或代表颁发了荣誉证书。

学生代表：“城院四年，收获了勇敢去实现梦想的自信”

城市与环境科学系优秀毕业生代表刘佳同学在发言中，回顾了自己大学四年的精彩生活，对母校和恩师们的培养和教育表示由衷的感谢。她表示，在城市学院最重要的是收获了青春最美的回忆，收获了勇敢去实现梦想的自信和对生活的感激！未来，她将把“学而知不足”的校训铭记于心，更加勇敢、坚强、成熟地面对社会，开创美好的未来!

管理系优秀毕业生代表李露冰同学，用一首《小幸运》一句：“爱上你的时候还不懂感情，离别了才觉得刻骨铭心”，表达了对母校、对同学和对大学生活的眷恋与感谢。她用“从

不愿意穿上军训服，到今天不愿意脱去学士服”的情愫，表达对城院四年来的培育的感谢之情。她饱含深情地说：“如果没有城院、没有你们，我不会度过如此精彩的四年。”

教师代表：“带有温度地去享受人生风景”

面对身着学士服、意气风发的2017届全体毕业生，计信系曹丽娟老师代表全体教师送上了诚挚的祝福。她建言同学们，始终保持一种空杯心态，从零开始，从小事做起，虚心学习，真诚请教。生命不息，学习不止。希望大家一定要学会做人，学会做事，学会合作，永远不要怕吃亏。

政法系付佳荣老师在发言中，代表学校全体教师向圆满完成学业的各位同学表示最诚挚的祝贺！他希望，同学们今后“以未来的视野去工作、用体验的风格去生活”，“历事练心，带有温度地去体会和享受不同的人生风景” 。

麦照容董事长：母校永远是你们坚强的后盾

麦照容董事长在致辞中，代表董事会对同学们的顺利毕业表示祝贺！对四年来同学们用勤勉努力、用包容理解、用进步给学校增添光彩，表示感谢！

麦照容董事长叮嘱毕业生们，牢记“学而知不足”的校训，“不忘初心，稳步前进，以远大的目光和包容的态度奉献社会”。他表示，“母校永远是你们坚强的后盾和温暖的家”。

王卫平院长寄语：人生只有拼出来的精彩，没有等出来的辉煌

再续去年毕业典礼上的妙语连珠、金句连连，今年，王卫平院长再次深情饱满地向全体毕业生致辞，寄语同学们谋划好自己的人生格局，“对个人，对家庭，对社会，对国家承担起自己的责任”。

“时间就像单行道，四年的光景再回不去了”，王院长心怀眷恋地告诫同学们：“经历过冷嘲热讽、人情冷漠、三番五次的跌倒、几乎绝望还咬牙前行，那才叫信念；朝思暮想、做梦都想、时刻都想，一想起来就热血沸腾，那才叫目标；只有经历过半夜抱头痛哭、经历过内心的孤独寂寞与寒冷而依然坚定初衷，那才叫坚强；面对疑惑而毫不动心、面对打击而面不改色，纵然困难重重也依然微笑前进，那才叫淡定；只有在一起经历过风雨洗礼、浴血奋战、荣辱与共、艰难困境，依然迎难而上，创造出奇迹，那才叫团队。”

“希望各位同学，谋划好自己的人生大格局。做人像铜钱那样内方外圆，做事像无固定形态的水，随方就圆。修身用减法， 交友用加法，齐家用乘法，干事用除法。” 王院长语重心长、谆谆教诲同学们：人生只有拼出来的精彩，没有等出来的辉煌。

在学士学位授予仪式上，毕业生们身披学位袍，逐个登台。王卫平院长、高香林副院长以及各院系主任为全体毕业生一一进行拔穗正冠，合影留念。
