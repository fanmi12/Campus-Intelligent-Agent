# 财经系积极开展广播体操训练

为了迎接校运会，财经系主任、书记、教职工齐上阵，积极开展广播体操训练。

每周二、周三、周四下午五点半，财经系教职工在5A大门口列队整齐，有序地做着第九套广播体操训练。教职工中有刚进校的青年教师，也有返聘老教授，他们面带笑容、动作协调、浑厚有力，彰显青春魅力，形成了一道闪亮的风景。

据财经系工会组长陈海娥老师介绍，第九套广播体操通俗易懂、科学合理、健康强身，能提高关节灵敏性，促进血液循环，每天训练半个小时，既达到健身效果，又为即将到来的比赛做好了准备。
