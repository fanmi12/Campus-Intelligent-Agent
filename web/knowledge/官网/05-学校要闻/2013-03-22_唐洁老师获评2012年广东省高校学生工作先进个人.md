# 唐洁老师获评2012年广东省高校学生工作先进个人

3月20日，广东省高校学生工作专业委员会2012年年会在珠海市召开。大会表彰了一批长期从事学生工作,为人师表、爱岗敬业、无私奉献的优秀学生工作者，我院财经系党总支副书记唐洁荣获“2012年广东省高校学生工作先进个人”荣誉称号。

大会还揭晓了“2012年高校学生事务管理精品项目”的评选结果，我院报送的财经系“理想与青春共成长——基于青年领袖理论的学生党员成长项目”获“2012年高校学生事务管理优秀项目”。据悉，财经系自2009年以来，在理顺学生党员数量和质量的关系、保持学生党员整体素质的基础上，着重进行了“基于青年领袖理论的学生党员成长计划”的探索，并取得较好的成效。几年的实践表明，基于青年领袖理论的学生党员成长计划研究项目的实施，有效提高了学生党员思想政治素质，增强了为人民服务的意识，强化了与时俱进、开拓创新的能力，在实践中体现了共产党员的先进性。
