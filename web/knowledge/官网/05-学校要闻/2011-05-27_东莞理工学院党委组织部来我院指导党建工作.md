# 东莞理工学院党委组织部来我院指导党建工作

李培经部长高度评价我院党建工作5月26日，东莞理工学院2011年党建工作量化考评组一行10人在校党委组织部部长李培经的带领下，来我院检查考评近两年党建工作的开展情况。院党委班子成员朱志德、朱冰、王玉、夏勇、章德胜热情接待了考评组的同志。

党委书记朱志德代表院党委向考评组汇报了城市学院近两年党建工作情况，着重介绍了党委工作的特点、亮点和创新点。考评组走访了城环系党总支和文传系党总支，详细查看了我院发展学生党员工作相关资料。

李部长对我院党建工作开展情况给予了高度评价。他说，城市学院党建工作队伍精干，工作规范，亮点纷呈，成果显著。这些好的做法和经验值得宣传和推广。李部长对我院制度建设、发展党员等方面的工作提出了建议和希望。
