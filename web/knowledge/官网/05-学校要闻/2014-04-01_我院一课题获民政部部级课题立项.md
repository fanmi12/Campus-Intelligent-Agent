# 我院一课题获民政部部级课题立项

3月31日，民政部2014年“中国社会组织建设与管理”理论研究部级课题立项评审结果揭晓。我院管理系黄岳钧老师申报的项目“社会组织第三方评估机制中的风险因素及对策研究”获准立项。

据悉，民政部“中国社会组织建设与管理”理论研究部级课题每年初面向高等院校、科研院所、社会机构公开发布课题招标指南，该课题立项率仅9%—11%，是公共管理研究领域难能获得的部级课题之一， 2014年民政部共批准立项82个。
