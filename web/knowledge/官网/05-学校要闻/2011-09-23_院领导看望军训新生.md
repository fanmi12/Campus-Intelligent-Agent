# 院领导看望军训新生

9月21日上午，院长安少华，党委书记朱志德、副书记朱冰等领导亲临新生军训现场，看望慰问新同学和军训团官兵。

领导们在新校区运动场认真观看了新生的军训活动，看到同学们不怕苦、不怕累，认真细致做好教官所教的每一个动作时，感到非常满意和欣慰。安院长强调，学院相关部门要努力做好后勤工作，当好承训官兵的后勤保障兵，做好官兵和学生的服务工作，要做到“一切为了学生，为了一切学生”。
