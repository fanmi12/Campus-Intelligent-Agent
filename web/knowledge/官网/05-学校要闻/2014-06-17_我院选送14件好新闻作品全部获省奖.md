# 我院选送14件好新闻作品全部获省奖

记者昨天从广东省高校校报研究协会网上获悉，2013年全省高校校报好新闻评选结果已经公布，我院有14件作品分获二、三等奖。据非官方人士打分排名，城市学院获奖分数在全省100多所高校中排名第35位，居独立学院类第2名。

据悉，这次评选好新闻分为消息、通讯、标题、言论、图片、专题、版面7大类，半月刊小报每类限报2件作品。根据这些规定，我院共报送了14件作品，这些作品全部获奖。据通报，全省好新闻作品获奖率仅为70%。
