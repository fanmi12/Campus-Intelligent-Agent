# 我院组织收看全省教育系统全面从严治党工作视频会议

3月16日下午，广东省委教育工委组织召开了2018年全省教育系统全面从严治党工作视频会议。这次会议旨在为全面深入学习贯彻党的十九大精神，全面落实十九届中央纪委二次全会、教育部全面从严治党工作视频会议、省委十二届二次、三次全会、省纪委十二届二次全会部署，分析研判教育系统全面从严治党形势，部署安排全年工作，全面加强全省教育系统党的建设。我院领导和各单位负责人、各党总支书记在行政楼212会议室组织收看了视频会议。

省纪委驻省教育厅纪检组组长阙定胜传达了十九届中央纪委二次全会和省纪委十二届二次全会精神。

省委教育工委书记、省教育厅党组书记、厅长景李虎同志总结部署工作。景李虎厅长要求，全省教育系统党建工作必须切实提高政治站位，以习近平新时代中国特色社会主义思想这一强大思想武器为科学指南和根本遵循，谋划工作，推动实践；必须充分发挥领导干部等“关键少数”的带头和表率作用；必须树立党的一切工作到支部的鲜明导向；必须把制度建设贯穿于党建工作；必须进一步加强民办学校党的领导；必须严抓作风建设和纪律建设，深入推进反腐败斗争，深入整治“四风”。

景李虎厅长对2018年全省教育系统党建重点工作进行了部署。一是要把党的政治建设摆在首位，坚决维护以习近平同志为核心的党中央权威和集中统一领导。二是要用习近平新时代中国特色社会主义思想武装头脑，扎实推进党的思想建设。三是要聚焦政治功能和组织力提升，扎实推进基层组织建设。四是要突出政治标准，加强教育系统干部和人才队伍建设。五是要厚植党执政的群众基础，扎实推进党的作风和纪律建设。

视频会议结束后，王卫平院长在讲话强调，全院党员干部要认真传达学习贯彻落实视频会议精神，加强学校党建工作和纪律检查工作，做好全面从严治党工作。王卫平校长要求大家“从我做起、以身作责”，加强党性修养，从思想上、行动上与党中央保持一致，扎实推进党的思想建设和作风纪律建设。
