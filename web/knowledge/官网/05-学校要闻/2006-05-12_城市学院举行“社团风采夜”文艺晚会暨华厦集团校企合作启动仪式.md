# 城市学院举行“社团风采夜”文艺晚会暨华厦集团校企合作启动仪式

5月11日，城市学院 “社团风采夜”暨华厦集团校企合作启动仪式在学院大礼堂隆重举行。院长安少华教授等学院领导与华厦集团高层管理人员同聚一堂，共同见证这一历史时刻的到来。

本次晚会旨在展示我院社团文化、社团风采，同时正式启动校企双方合作。晚会前，院党委书记朱志德首先致辞。朱书记代表学院对华厦集团客人的到来表示热烈的欢迎，寄望双方的合作像东莞的明天一样美好。李扬钦董事长也上台讲话，衷心祝愿城市学院以最快的速度成为广东省一流本科院校。随后，他向两位同学分别赠送了手机和自己出版的书籍。常务副院长程发良教授代表学院向华厦集团赠送“城市学院教学实践基地”牌匾。紧接着，安院长与李董事长携手触摸玻璃圆球开关举行亮灯仪式，宣布校企合作正式启动，文艺晚会正式开始。

启动仪式之后，大学生艺术团表演了精彩的文艺节目。演出期间，还进行了抽奖活动和互动游戏。
