# 省教育厅教育信息化建设检查组莅临我院检查指导工作

11月13日，省教育厅教育信息化专家组和省教育厅信息中心办公室张永忠主任等来我院检查指导教育信息化建设工作。党委书记朱志德，常务副院长程发良教授等接待了专家组一行。

图书信息中心主任钟兴恭教授向检查组汇报了我院教育信息化建设和应用情况。经过几年的努力，学院网络建设已具一定规模，累计投入资金260万元。全院已有157门课程使用多媒体，有电子期刊和图书20多万种，并与校本部共享信息资源。

检查组指出，城市学院教育信息化建设工作基础较好，院领导对信息化教育建设工作以及在教学和管理方面的应用高度重视，并做到与校本部资源共享。专家组组长黄云森教授在总结会上指出，希望城市学院在教育信息化建设方面，做好总体规划，加强骨干技术人员的引进和培训，加大基础设施建设投入和设备更新，在校务管理方面进一步统一设计，整合资源，形成较为完整的系统。

会后，检查组一行检查了我院图书馆、电子阅览室和网络中心的有关工作。
