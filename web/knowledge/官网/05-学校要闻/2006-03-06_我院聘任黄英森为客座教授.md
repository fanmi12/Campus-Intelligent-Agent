# 我院聘任黄英森为客座教授

3月3日下午,我院聘任星海音乐学院原师范系主任、硕士生导师黄英森教授为客座教授。东莞理工学院城市学院院长安少华教授代表城市学院向黄英森教授颁发了聘书。副院长林世俊教授主持了会议。

黄英森教授是我国著名作曲家、音乐教育家，毕业于上海音乐学院 ，曾任全国高等师范院校作曲理论学会副会长、广东省音乐家协会理事、星海音乐学院师范系主任，全国优秀教师, 硕士生导师，享受国务院特殊津贴。黄教授创作了大量脍炙人口的优秀音乐作品，培养了数以千计的音乐专业人才。

聘任仪式后，黄教授为我院文学与艺术系老师进行了现代的音乐教学思想与课堂理念的学术讲座。
