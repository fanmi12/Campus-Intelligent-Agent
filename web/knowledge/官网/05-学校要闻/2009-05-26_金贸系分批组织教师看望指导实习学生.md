# 金贸系分批组织教师看望指导实习学生

近期，金贸系全体教师在系主任米双红、书记龙卫洋的带领下，分成五个小组赴全市25个乡镇看望实习生，了解学生实习情况，解答学生提出的问题，勉励学生立足岗位、踏实工作，通过实习弥补自身的不足，不断增强核心竞争力。同时，实习指导老师主动与实习单位协调，加强对实习工作的指导。由于各方面的关心支持，金贸系学生实习表现很好，进步很大，获得了所在单位的充分肯定。

东坑镇领导苏东就主任评价说：“金贸系在我镇政府实习的学生工作主动性强，能吃苦,能力不错，是我们的好帮手！"
