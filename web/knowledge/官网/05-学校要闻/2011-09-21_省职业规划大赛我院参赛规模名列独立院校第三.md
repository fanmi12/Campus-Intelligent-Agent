# 省职业规划大赛我院参赛规模名列独立院校第三

截至9月15日，第六届广东省大学生职业规划大赛组委会确认，我院2386名学生共提交有效作品为2284份,在独立学院高校中名列第三，并获得4个省复赛的名额。据悉我院提交数量最多的是金融与贸易系，共计650份；其次是财经系、管理系，分别有311份和272份。

日前，我院大赛组委会已组织各系（部）进行初赛选拔，挑选出优秀的作品，学院招生就业办对进行院级初赛的同学进行了面试。 10月份，既定将在大礼堂举行“十佳之星”院级决赛。届时我院也将从“十佳”中挑选四位同学参加省级复赛。
