# 图书馆召开读者代表座谈会

11月4日，图书信息中心在图书馆10楼会议室召开读者代表座谈会。中心主任陈伟研究馆员、教辅党支部书记钟兴恭教授、图书馆各部室负责人，各系（部）及书香社的30名学生代表参加了座谈会。

会上，同学们踊跃发言，在充分肯定图书馆工作的同时，对图书馆自习位和咖啡屋等相关便民措施给予建言献策。老师们也就电子资源的使用、图书馆内抽烟、喧哗、占座等不文明行为与大家进行了面对面的沟通交流。
