# 新华网、省电视台报道我校战“疫”文艺作品征集活动

近日，新华网新闻客户端、广东广播电视台现代教育频道对我校组织开展的“同心战‘疫’，中国加油”主题文艺作品征集活动及优秀作品进行了报道。

此次“同心战‘疫’，中国加油”主题文艺作品征集活动由我校党委宣传部主办，从2月7日正式开始面向全校师生征集文学、绘画、书法、摄影、视频等作品，鼓励广大师生通过文艺作品创作，为武汉加油，为中国加油。

自活动开展以来，师生们积极投稿，作品形式多样，内容丰富。不到1个月，我校已收到100多份作品，其中60多份优秀作品以推文的形式通过学校微信企业号推送给全校师生，表达了师生对抗“疫”斗士的崇高敬意及对赢得这场战“疫”的必胜决心，展现了城院师生的爱国爱家爱校情怀。
