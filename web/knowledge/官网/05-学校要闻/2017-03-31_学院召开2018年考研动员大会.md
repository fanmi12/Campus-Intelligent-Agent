# 学院召开2018年考研动员大会

3月30日下午，我院2018年考研动员大会在行政楼112会议室召开。考研辅导班赵书山教授，黄璐、马陵勇、徐生兵老师以及100位准备考研的同学参加了会议。

继续教育中心副主任夏泉源主持会议，并介绍了我院历年考研及考研辅导班的基本情况。

2017年研究生考试获得成功的

城环系王佳雷、政法系杨慧玲两位同学，分享了各自的考研经历与复习心得。

准备参加2018年考研的代表城环系张梓涵同学在发言中，表达了自己对考研的看法及决心。

赵书山教授等四位考研辅导老师介绍了各学科的难易程度和复习侧重点，建议同学们合理分配时间，根据自身实际选择报考院校。同学们现场提问，与老师们交流考研有关事宜。

据悉，继续教育中心考研培训班将于4月份开班。
