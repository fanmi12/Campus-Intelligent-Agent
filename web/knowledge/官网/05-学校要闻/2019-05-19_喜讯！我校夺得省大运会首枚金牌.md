# 喜讯！我校夺得省大运会首枚金牌

今日上午，在广东省第十届大学生运动会田径女子甲组（本科公共体育组）跳远比赛中，外国语学院叶翠诗同学以5.05m的好成绩摘得冠军。这是我校在广东省大学生运动会上获得的第一枚金牌。

此外，在本届大运会乒乓球混合双打比赛中，智能制造学院张潘同学（男）与商学院覃诗烨同学（女）也一路过关斩将，战胜了众多强手，喜获亚军！
