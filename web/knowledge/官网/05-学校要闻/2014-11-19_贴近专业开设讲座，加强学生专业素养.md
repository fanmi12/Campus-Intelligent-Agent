# 贴近专业开设讲座，加强学生专业素养

11月16日，大学生科学文化论坛第53期“建筑工程施工技术应用”讲座在学术报告厅开讲。本次讲坛邀请中国建筑第五工程局东莞分公司项目总工程师苏赐从先生主讲，土木工程、安全工程专业400多名学生听讲座。这也是“城环专业大讲坛”系列讲座内容之一。

主讲嘉宾苏赐从先后担任过东莞玉兰大剧院、东莞第一国际、东莞寰宇汇金中心、珠海中信湾、惠州星河坍堤项目等多个大型工程项目技术负责人，其参建工程获得国家优质工程“鲁班奖”、“广东省优质工程”等荣誉，获得工法2篇、专利4项、论文5篇。他利用深厚的理论知识和丰富的实践经验对建筑施工新技术应用和绿色建筑发展趋势进行了详细介绍，包括：跳仓法施工技术、地下工程预铺反粘防水技术、集成式升降平台技术、模架体系施工技术、特殊模架体系施工技术、绿色建筑概述、绿色施工技术等。

苏工的讲座赢得了台下同学的阵阵掌声，同学们纷纷表示开阔了眼界，增长了见识，学到了不少专业方面的新知识，希望以后能多听到一些理论与实践相结合的专业知识讲座。

为响应省教育厅创新强校工程，突出应用型人才培养，加深学生对专业知识的理解，学院大学生科学文化论坛将进一步联合各系部邀请既具有深厚理论知识又具有丰富实践经验的行业专家开设类似的专业知识讲座。
