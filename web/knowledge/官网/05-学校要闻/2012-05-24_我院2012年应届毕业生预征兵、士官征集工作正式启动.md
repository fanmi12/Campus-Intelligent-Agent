# 我院2012年应届毕业生预征兵、士官征集工作正式启动

根据广东省教育厅和广东省征兵办统一部署、东莞市军分区和东莞理工学院武装部的工作安排，我院成立了由党委副书记章德胜为组长的预征兵工作领导小组。近日，领导小组在3202召开了2012年应届毕业生预征兵、士官征集工作动员会。

会上，学生处陈建新副处长传达了省教育厅关于2012年预征兵工作的文件精神，部署2012年预征兵和士官征集的工作，并将毕业生返校时间列为入伍预征宣传周，辅导员、2012届毕业生代表参加了会议，向每位到会的同学发放资料。据了解，今年高校应届毕业生预征兵网上报名时间为4月20日

－7月20日、士官征集报名（应届毕业生东莞户籍的同学回户籍所在地武装部报名、外地生源在学生处报名）时间为5月底前。
