# 学院为教研室下拨建设经费

今年上半年，学院首次对教研室建设工作进行了评估，共评选出8个优秀教研室。

本学期伊始，学院就为各教研室拨付了一定的建设经费。与以往不同的是，本次建设经费直接下拨到各教研室，由教研室主任掌握使用，教研室所在系不干预教研室经费的使用。这种做法增强了教研室经费的使用效率，凸显了教研室的自主权，为提高教研室的管理水平、教学水平和科研水平提供了经费保障。
