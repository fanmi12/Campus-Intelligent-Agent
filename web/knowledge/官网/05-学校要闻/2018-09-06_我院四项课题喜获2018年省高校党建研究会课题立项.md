# 我院四项课题喜获2018年省高校党建研究会课题立项

日前，广东省高校党建研究会2018年度党建研究课题立项结果公布。我院史雍真同志《高校推进全面从严治党的路径研究——“以政治建设为统领”的内在逻辑与实践探索》、李玉春同志《高校大学生新时代社会主义意识形态价值认同传播育人策略研究 ——基于新媒体的视角》、杨佳青同志《高校体验式党课教学的应用研究》、曹镭同志《大学生党员社会实践评价指标体系的构建》等四项课题从全省777项申报的课题中脱颖而出，均获广东省高校党建研究会研究课题立项。
