# 2017年校运会成功举办

11月17日下午，为期两天的2017年运运会圆满结束。王卫平、章德胜、黄兢、周庆等院领导和各单位负责人出席了闭幕式。

经过两天激烈角逐，管理系以395分的好成绩夺得学生团体组冠军，金贸系、城环系分位列第二、三名。后勤保卫处与城环系并列教工组团体冠军，金贸系、艺术系分获第二、三名。城环系与艺术系获得学生团体组“体育道德风尚奖”。财经系与计信系获得教工团体组“体育道德风尚奖”。管理系、政法系获得团体操大赛一等奖。团体操大赛 “网络最佳人气奖 ”由政法系摘得。

据了解，为了让更多师生参与进来，今年校运会新增设了拔河、综合能力大比拼等新项目。值得一提的是，管理系罗春燕同学去年打破校运会女子组800米记录后，今年又以2分41秒的成绩再次刷新记录。
