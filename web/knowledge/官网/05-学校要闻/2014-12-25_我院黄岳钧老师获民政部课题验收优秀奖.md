# 我院黄岳钧老师获民政部课题验收优秀奖

12月9日，国家民政部发布2014年“中国社会组织建设与管理”理论研究课题验收暨获奖名单公告。

我院黄岳钧老师主持完成的课题《社会组织第三方评估机制中的风险因素及对策研究》的研究成果（课题报告）通过验收评审，并荣获民政部2014年理论研究部级课题研究成果优秀奖。这是我院管理系青年教师第一次获得国家部委科研成果奖。

据悉，针对本次验收评审，民政部成立了由民政部政策研究中心、上海交通大学、浙江大学、中央财经大学、中央党校、北京师范大学等公共管理领域专家组成的评审委员会，采取匿名评审方式，并召开验收评审会，严格标准，严格程序，最终共有78个课题成果符合验收要求，通过验收评审。
