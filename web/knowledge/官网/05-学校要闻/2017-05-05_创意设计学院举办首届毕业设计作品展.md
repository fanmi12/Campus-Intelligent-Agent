# 创意设计学院举办首届毕业设计作品展

5月4日-5日，创意设计学院首届毕业设计作品展在法商楼举行，将2013级数字媒体艺术专业全体毕业生的毕业设计作品悉数与观众见面。

4日上午，创意设计学院为展览举办了简洁的开幕仪式。王卫平、章德胜、高香林、黄兢、周庆等院领导，学院院长助理、创意设计学院院长林江龙，各系部主任、书记和各部门负责人参加了开幕仪式。

王卫平院长在讲话中，祝贺创意设计学院获得“广东省试点学院”这一标志性项目，对创意设计学院成立一年来取得的成绩给予了充分的肯定和赞扬。他指出，此次举办毕业设计作品展更是凸显了创意设计学院取得的长足发展和师生们高涨的创作热情。学院将对创意设计学院试点所取得的经验，进行全院推广。他表示，学院将继续加大支持力度，努力把创业设计学院办得越来越好。

据介绍，本届毕业设计作品展作品涵括工业包装设计、家具家私设计、工艺制作、版式设计和动画动漫等设计作品和实物展示，充分展示了创意设计学院在教育教学创新和应用型人才模式探索上取得的丰硕成果。
