# 新闻传播专业学生参观东莞日报社

3月24日，在新闻中心唐耀碧、刘哲及班主任钟丹老师的带领下，2010级新闻班的同学前往东莞日报社参观学习，近距离接触新闻记者，体验新闻单位的工作氛围。报社领导和记者热情接待了我院师生。

报社安排专业人员带领同学们参观了东莞报史展览馆，介绍东莞报业的发展历史和取得的成果，新闻采编和报纸的印刷流程。在报社领导、记者与同学们的互动环节中，他们希望同学们要有忧患意识，热爱新闻工作，以积极和自信的心态面对竞争，抓紧时间学习，并对同学们提出的问题做了解答。
