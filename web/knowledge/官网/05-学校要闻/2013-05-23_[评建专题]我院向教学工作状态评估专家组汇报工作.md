# [评建专题]我院向教学工作状态评估专家组汇报工作

5月23日上午，根据省教育厅有关文件精神要求，教学工作状态评估专家组在我院举行东莞理工学院城市学院教学工作状态评估汇报会。专家组全体成员出席会议，专家组组长董超俊教授主持会议。

汇报会召开之前，东莞理工学院党委副书记吕琦元致欢迎词。吕副书记代表东莞理工学院，欢迎专家组莅临东莞理工学院城市学院考察指导工作，并希望城市学院各级领导及教职员工要认真听取专家组的整改意见，以此为契机，加强内涵建设，全面加强教学管理工作，提高整体教学质量和办学水平，为培养应用型人才作出贡献。

院长杨敏林教授向专家组汇报了我院教学工作的全面情况。杨院长的报告共分三大部分：第一，学院的基本情况；第二，确保本科教学质量的主要措施和成效；第三，主要问题及改进思路。

城市学院董事黎建烨、学院领导、院内各单位正副职负责人参加了汇报会。

汇报会后，专家组将深入课室随机听课，今日下午考察图书馆、体育馆、学生宿舍、食堂、公共实验室，召开教师、学生、教学管理人员代表座谈会。
