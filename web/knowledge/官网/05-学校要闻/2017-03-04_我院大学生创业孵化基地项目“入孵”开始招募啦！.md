# 我院大学生创业孵化基地项目“入孵”开始招募啦！

东莞理工学院城市学院大学生创业孵化基地作为我院大学生创新创业的实践载体和服务平台，是我院创新创业教育工作的重要组成部分，由招生就业处负责运营管理，依照《东莞理工学院城市学院大学生创业孵化基地管理办法（试行）》的相关规定，以扶持大学生自主创业为核心目标，以公益性、示范性、专业性为主要特征，帮助我院大学生创业团队实现创业加速。

为营造“大众创业，万众创新”的浓厚氛围，引导创新创业与学科专业知识和东莞地方产业特点发展相结合，为我院有创业新意识、创业激情的学子提供创业实践的平台，大学生创业孵化基地现已正式开始接受首批入孵项目申报。

欢迎有强烈创业意愿、有获奖创业项目、有科技发明成果的大三大四学生或毕业两年内的校友（团队）积极申请入孵。
