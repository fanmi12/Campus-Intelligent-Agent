# 我院第五届校园主持人大赛圆满落幕

11月22日，我院第五届校园主持人大赛决赛在学院大礼堂举行，学院党委副书记朱冰、学生处处长章德胜、就业办主任江小卫、院团委书记杜鹏举等观看了比赛。

来自各个系部的14名选手参加了角逐。比赛分“模拟直播间”和“主持人模拟”两个环节进行。选手两两配对，讲述着不同的主题，包括微博、360与QQ大战、街头文化等。值得一提的是，每对组合演讲过程中都会播放一段短片，其中第一组的短片“图书馆趣事”，搏得全场观众开怀大笑。随后3、4号选手模拟直播热点时事微博，现场播放VCR“都是因为校运会”，以夸张的色彩贴切地表现了微博强大的传播力度，把现场的气氛推向了高潮。选手们巧思妙想，以其优美的语言和良好的形象赢得观众的一致好评。

第一轮比赛在艺术团绿袖子组合一曲悠扬的《彩云追月》歌声中结束，其中有7名选手顺利晋级第二轮“模拟主持人”比赛。选手们自选角度，从“小视角，大不同”到“对话城院”，从“科普一刻”到“公益进行时”，作品角度新颖，构思独特。

经过激烈的角逐，最后来自文学与传媒系的罗婷婷同学获得了本次主持人大赛的冠军，来自金融与贸易系的杨荟与魏然同学分获二、三名。
