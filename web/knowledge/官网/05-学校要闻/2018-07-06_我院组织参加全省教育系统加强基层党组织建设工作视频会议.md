# 我院组织参加全省教育系统加强基层党组织建设工作视频会议

7月6日上午，广东省委教育工委组织召开了2018年全省教育系统加强基层党组织建设工作视频会议。会议旨在认真贯彻党的十九大精神、全面贯彻落实习近平新时代中国特色社会主义思想，推动全省教育系统基层党组织建设。我院领导和各单位负责人、各党总支（直属支部）书记在行政楼212会议室组织参加了视频会议。

省委教育工委书记、省教育厅厅长景李虎同志指出，当前我省教育系统的基层党建工作还存在主题责任不明确、基层党组织组织力有待提升、基层党建体制机制建设不健全、民办学校党建基层建设落后、贯彻落实党建工作存在差距等问题。各基层党组织要高度重视，以问题为导向，加强整改。

景李虎同志要求，各基层党组织要深学笃行习近平新时代中国特色社会主义思想，坚持社会主义办学方向，抓好政治安全稳定工作，落实意识形态“六项责任制”，认真落实书记抓党建工作述职，加强党建规范化建设，加强党建阵地建设，加强基层党务干部培训，创造基层党建工作品牌，做出亮点和特色。

会上，宣读了党建工作先进集体先进个人等表彰通报。

五个基层党支部还交流了建设经验。

视频会议结束后，党委书记、院长王卫平同志强调，各级党组织要认真贯彻会议精神，继续加强教师党支部和学生党支部建设，把我院党建工作做出亮点，做出特色。
