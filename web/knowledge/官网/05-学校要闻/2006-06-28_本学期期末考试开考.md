# 本学期期末考试开考

城市学院2005—2006学年第二学期期末考试于6月26日开考。全院共有113个班，共4400多名学生参加考试。考试场地主要设在4号楼大厅和学生饭堂。据4号楼大厅考点统计，每场参考人员近千人。本次考试，每个同学平均要考试5门课程，每天考一场，7月5日结束。

考试期间，适逢炎热天气，气温高达34℃，但由于考前动员较早，学生复习认真，组织工作周密，加上每天只考一场，因此，考场纪律良好，考生心态平常，老师监考认真。考生们反映，考题容量很大，难易适中，绝大多数同学能够考出好的成绩。
