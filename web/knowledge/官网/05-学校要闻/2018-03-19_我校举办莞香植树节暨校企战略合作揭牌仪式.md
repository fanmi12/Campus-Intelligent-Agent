# 我校举办莞香植树节暨校企战略合作揭牌仪式

3月18日，我院举办校企战略合作授牌仪式暨莞香林植树活动。活动由寮步镇政府和东莞市工商联指导，我校和东莞市沉香协会主办，寮步镇政府宣传办、旅游办、文广新局给予了大力支持。

参加活动的嘉宾有寮步镇人大副主席黄镇源，镇文广新局主任韩富强，中国沉香文化博物馆副馆长尹景滔、东莞市沉香协会会长尹丰田等。我校党委副书记章德胜、办公室主任杜鹏举、后勤保卫处处长王锦锋、学生处副处长罗文芳、就业中心主任江小卫出席了植树活动暨校企战略合作揭牌仪式。

揭牌仪式上，尹丰田会长表示：“东莞市沉香协会与城市学院开展合作，有利于莞香文化进入大学校园，有利于日后开展莞香文化课程，进一步宣传和推广莞香文化。”

章德胜副书记指出，城市学院作为东莞市在校学生人数最多的高校，在寻求与企业合作、协会合作有很大需求。通过校企合作，有利于我校学生将理论运用到实际，进而获得全方位的发展。

黄镇源副主席作了讲话和授牌。

在图书馆旁，与会嘉宾和领导还开展了莞香树植树活动。
