# 迎新工作紧张有序   新生、家长和院领导满意

9月18日，我院开始了2005年迎新工作，各系、部、处、室领导及工作人员全部到位。

我院迎新工作中心设在四号楼大厅，上午7时，各部门的迎新工作人员和200多名的青年志愿者进入了自己的工作岗位，为我院的迎新工作竭诚服务。上午9时，新生报到形成高潮，报到现场内外人头涌动，人山人海，车水马龙，几乎每个办事窗口都排起了长队，场面非常壮观。青年志愿者热情地帮助新生熟悉注册流程，带他们去领军训用品，还将他们送到宿舍，受到新生和家长的好评。

据悉，今天报到注册人数已超过1000多人。
