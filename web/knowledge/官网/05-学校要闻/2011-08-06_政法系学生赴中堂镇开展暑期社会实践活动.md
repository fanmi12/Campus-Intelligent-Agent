# 政法系学生赴中堂镇开展暑期社会实践活动

7月15日至8月1日，在政法系社会工作教研室主任周巍等老师的带领下，09社会工作专业的15名同学赴中堂镇新莞人家园开展了半个多月的暑期社会实践。

本次社会实践活动内容包括开办新莞人子女暑期培训班及联合香港“友晴天”义工团队走访社区，探访贫困新莞人。活动得到中堂镇社会事务办公室及新莞人家长的一致好评。
