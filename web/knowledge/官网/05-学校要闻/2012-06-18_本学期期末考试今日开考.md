# 本学期期末考试今日开考

根据学院教学计划安排，2011—2012学年度第二学期期末考试今日在老校区四号楼大厅开考。上午9时整，首场考试正式开始，院领导杨敏林、朱志德、高香林等巡视了各考场。

据教务处介绍，本次考试从6月18日持续到7月4日，涉及考试课程共计179门，参加班次712个，考试地点主要集中在老校区四号楼大厅和新校区综合馆。上午的考试，各考场秩序井然，进展顺利，未出现违纪行为。

考前，各系部分别召开了学风建设动员会，要求学生认真复习，诚实守信，遵守考场纪律，交出满意的答卷。同学们也签订了“诚信考试承诺书”，表示要诚信参考，从自身做起。
