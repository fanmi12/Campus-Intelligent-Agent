# 我院师生“东莞居民幸福指数”调查数据被市府采用

11月2日，我院东莞社情研究中心主任周巍博士在接受东莞日报记者采访时表示：幸福基于民生，但不至于民生。访谈内容全文刊登在东莞日报。

据悉，访谈之前，周巍博士带领政法系社工专业的师生，分赴东莞32个镇街进行“东莞市居民幸福指数的调查”活动。该活动共发放问卷1300份，有效回收率为98%。据市政府有关职能部门负责人反映，该调查样本代表性高，符合统计分析要求，调查结果真实性强、可信度高。
