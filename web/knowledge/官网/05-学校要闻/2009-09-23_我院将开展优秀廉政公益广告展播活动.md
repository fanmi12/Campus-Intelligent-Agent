# 我院将开展优秀廉政公益广告展播活动

为深入贯彻落实党的十七届四中全会精神，大力加强廉政文化建设，加强和改进大学生思想政治教育，营造风清气正的和谐校园氛围，我院将于近期组织各系部师生学习、观看或收听廉政公益广告。

届时，我院广播、网络、电子LED屏、报刊、宣传栏等宣传阵地将陆续展播“扬正气、促和谐”全国优秀廉政公益广告。活动展播期间，欢迎广大师生积极响应。（学院主页视频专栏链接地址：/newscenter/ShowArticle.asp?ArticleID=3824）

据悉，“扬正气，促和谐”全国廉政公益广告创作评选及展播活动是由中央纪委、中央宣传部、工商总局、广电总局等有关部门联合举办的，已经评出45件优秀廉政公益广告。
