# 台湾义守大学来我院洽谈深度合作

9月2日，台湾义守大学颜志荣副校长携教务长周兆民、理工学院院长古志生、国际交流与两岸事务处副处长叶建宁一行来我院访问，受到我院党委书记王卫平、党委副书记章德胜、副院长高香林的友好接待。

颜志荣副校长对我院稳健发展给予了高度赞扬。

王卫平书记结合我院在义守大学暑期研修班的学习经验，对义守大学的办学模式给予了充分肯定，认为有很多经验值得学习和借鉴。

两校负责人在座谈中，提出了关于学生交流、教学、科研合作等方面进一步合作的设想，双方希望在此开设特色班，借用义守大学的师资及课程体系等方面，加强深度合作。
