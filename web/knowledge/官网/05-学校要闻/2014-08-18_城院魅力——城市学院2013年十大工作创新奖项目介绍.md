# 城院魅力——城市学院2013年十大工作创新奖项目介绍

“校企携手·人才共育”应用型人才培养模式的新探索项目所属单位：财经系项目负责人：罗卫国项目参加者：肖文锋、唐洁、韩静、鞠成晓、郑阿泰、卢效坚

该模式的内容包括：与东莞市政府有关部门及行业协会建立战略伙伴合作关系；建立校外导师库：与立信会计师事务所达成定向人才培养的合作意向，即建立立信班，共同培养具有高素质的会计师事务所需要的应用型人才。

该项目的实施，开创了我院与政府部门、行业协会合作的先河，为教学、实习、改善师资队伍结构起到了一定的促进作用。

财经系：我院隆重举行战略合作校企合作校外导师签约聘任仪式

移动终端多媒体研究中心，协同创新发展新思路、新模式项目所属单位：文学与传媒系项目负责人：何帅项目参与者：李上文、吴宇、王宁、周旋、李姗姗、陈秀南、邓星明、刘仲生

该项目的实施，使校企“产学研”合作平台、校内实践教学平台、系内跨专业一体化研究平台融为一体，协同发展。现已完成5项校企深度合作项目，4项“产学研”合作项目，30个校内实训项目，承接了13个省、市、院各类研究课题。

文传系：深圳民航凯亚公司与我院达成产学研合作意向

多维度人事管理和人才发展机制“双创新”工程的构建与实施项目所属单位：组织人事处项目负责人：胡钦华项目参与者：李海冬、赵颖娴、罗的庆、陆枫、李柱坚、喻可平、谢文君、孙福群、余国鑫、李钰

该项工作依托学院灵活的办学体制，以人事管理和人才发展为着力点，多维度地创新了人事管理和人才发展机制。工作成效体现在：节省行政管理和人力成本，预留人力资源发展空间，稳定师资队伍，规范人事管理制度，搞活选人用人机制，助推了教师的成长发展。

组织人事处：我院教师暑期赴美研修

整合校内资源，探索实践教学新途径项目所属单位：计算机与信息科学系项目负责人：李洪超项目参加者：计信系、总务处、图书信息中心、保卫处

根据建筑电气行业特色，利用总务处、图书信息中心、保卫办的现有资源，让学生提前接触专业，开展实践教学。该项工作的开展能充分利用校内现有资源，提高资源的利用率，降低办学成本，激发学生对专业的兴趣，将实践与实际应用零距离对接，为建立实景实验室探索了一条新途径。

计信系：电子教研室主任李洪超博士看望实习学生

以服务为宗旨，以创新为手段，创建高效务实的行政办公体系项目所属单位：学院办公室项目负责人：黄兢项目参与者：叶凯贞、朱赢讯、陈东汉、张银辉、李玉嵩、韦晓霞、杨壮鹏

从新校区的工作实际出发，探索与建立完善了高效务实的行政办公体系。该体系“以学习促进服务质量、以创新提高服务水平”为服务理念，以“分头主管交叉监督、一岗两人主辅兼备”为管理方式，建立督办信息、资源共享、信息交流三个平台。实践结果表明，该体系的建立使中间环节减少，工作效率加快，办公资源信息互通共享。

院办：我院对教职工进行公文写作知识培训

走多重创新之路，打造专业特色项目所属单位：机电工程系项目负责人：赵天婵项目参与者：殷素峰、曾月鹏、唐征玲、何伟、杨佳青等

多重创新内容包括开办“机电大讲堂”，组建“机电创新班”，拓展学生视野，接受新知识及前沿动态；与东莞时报联合举办“校园汽车文化节”，深入调研“汽车服务”新专业的市场需求与专业前景，拓宽学生就业面；对多门课程的教学、考核方式进行改革，确保课程目标的实现；教研室成立核心课程小组，突出专业重点；组织学生参加国家省、市比赛，检验学生专业知识掌握水平。

机电系：我院学子参加全国“高教杯”图学竞赛成绩喜人

学风预警机制的创建与推行项目所属单位：管理系项目负责人：帅建华、张佺举、吴春庚项目参与者：张洪、邓葵璋、贺冬怡、洪树权、吴运建、蒋明华、陈彬、李玉春、陈文丽

通过建立完善学风预警制度，对学风有了可操作、量化的评判标准，对部分学习主动性不强的学生有了干预的措施。通过学工社团、任课教师和学生干部的积极干预和教育，引导学生建设优良学风。通过班主任和任课老师的双重介入，使得学风评价更加准确和客观。学风预警不仅是对个人预警，也是对班级的预警，有利于形成班级的优良学风。

管理系：召开学风预警及干预机制启动大会

案例互动教学的尝试与创新项目所属单位：思想政治理论课教学部项目负责人：何鹏举项目参与者：彭先兵等思政部全体教师

发掘思政课教学论和心理学的理论基础，引入现代管理学的有关理论，改进“教师主导、学生主体”教学模式，构建“互为主客、交替主导、围绕主题、平等对话、多种媒介、网状沟通”的互动教学模式，建立常态化开展思政课互动教学的机制及其操作细则，重点探索了案例互动教学模式。案例互动教学的尝试，凝练出“以人为本、共同参与、平等对话、动态生成”的民主教学理念，改变把互动教学搞成应付听课和宣扬教改的临时秀的问题。

思政部：朱志德书记出席思政部案例教学研讨会

发挥专业优势，创建独立学院红旗服务型党组织项目所属单位：文学与传媒系项目负责人：孟颖项目参加者：李上文、刘浔、卢淑芳、李瑶

围绕“培育人文精神，共建和谐系部”的理念，结合文传系的特点，深入开展服务型党组织的创建工作。这一工作包括：健全党组织的服务机制，创新载体建设；拓展党组织的服务平台，增强党员的服务意识；发挥专业优势打造品牌党建项目活动，充分发挥党员在推动系部发展、凝聚人心、服务师生中的作用，为建设红旗服务型党组织提供保证。主要活动有：开展培育人文精神系列讲座和党员服务活动（教师党员“三进”活动、学生党员“三带领活动”），成立文传系党员志愿队，开展“广西支教活动”“高州孤儿关爱活动”。

文传系：我院文学与传媒系15名同学赴广西支教

全媒体在新闻宣传工作中的创新运用项目所属单位：新闻中心项目负责人：唐耀碧项目参加者：何鹏举、范保乐、石晨、周健

以培养新闻媒体类应用型人才为前提，以加强学院形象宣传工作为目标，运用全媒体技术与理念，提高效能，创造性地开展宣传工作。成立城市学院媒体中心，分设记者团、电视台、网络部、广播台，形成200余人的学生记者队伍。全媒体的建立，一是为宣传部增添了力量，减少了人员和经费的支出；二是使宣传工作有声有色，特别是电视台成立以来，先后制作了60多条新闻电视短片，开了城市学院的先河；三是及时跟进微博、微信、网站的舆论工作，树立正能量，传播学院好声音。教育厅网站已采用我们10多条新闻；官方微博粉丝达到3万余人；四是通过微博、微信等新媒体的呼吁，较快解决了乘车难、飘臭气、热水价格等关乎师生切身利益的问题。

宣传部：大学生记者与媒体记者联谊采风
