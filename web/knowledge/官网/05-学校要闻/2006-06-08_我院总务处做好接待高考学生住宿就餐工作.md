# 我院总务处做好接待高考学生住宿就餐工作

6月7日，是全国高考的日子。我院总务处为了配合我市高考工作的顺利进行，努力地做好接待高考学生住宿和就餐工作，其中有200名学生的住宿和400多名学生的就餐。

据悉，这次高考接待工作从６月６号下午开始到９号结束。来我院食宿的学生来自石龙中学和清溪中学。住宿的地点安排在学院招待所、专家楼以及部份学生的宿舍。在用餐方面，为了做到有序进行，我院特意把校内饭堂的2号窗口设为高考学生的专用窗口。饭堂前的标语使同学们有宾至如归的感觉。据饮食中心李主任透露，这次的高考配餐特别注意卫生安全，力求清淡可口。为做到饮食安全，食物安全检测比以前更为严格。此外，我院还专门开放大礼堂，供考生中午休息。在学生公寓处还粘贴了温馨的提示，让我校大学生为考生们营造一个安静、舒适的学习和休息环境。
