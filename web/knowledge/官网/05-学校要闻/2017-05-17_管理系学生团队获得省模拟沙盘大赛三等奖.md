# 管理系学生团队获得省模拟沙盘大赛三等奖

5月13日、14日，由共青团广东省委员会、广东省教育厅、广东省科学技术厅、广东省科学技术协会、广东省学生联合会主办，佛山科学技术学院承办，中国联合网络通信有限公司广东省分公司、新道科技股份有限公司协办的第十届“新道杯”企业经营模拟沙盘大赛顺利举行。

由管理系何滔、陈思钊、柳诗、曾嘉豪、杨俊平同学组成，王兴、李玉春老师悉心指导的乐水队代表我院参加了本次比赛。乐水队顶着时间紧、任务重的压力，获得了广东省模拟沙盘大赛三等奖。
