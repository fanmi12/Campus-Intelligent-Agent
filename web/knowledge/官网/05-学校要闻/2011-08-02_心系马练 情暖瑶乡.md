# 心系马练 情暖瑶乡

7月19日至22日，在院团委副书记罗文芳等老师的带领下，暑期精英培训班部分成员，赴广西平南县马练瑶乡马练小学开展“三下乡”义教活动。

本次义教活动围绕马练瑶乡小学各年级教学内容展开，分为室内教学和室外拓展2项。教学内容丰富多彩，有科普小知识、猜成语、看图说故事、文娱活动等。值得一提的是本次义教活动创新教学形式，由义教成员以小组为单位自由开展，充分发挥了成员自身特长和能力。义教成员在实践中及时总结和完善教学方式，一改传统课程的枯燥，加入许多活泼的教学元素，使学生们寓教于乐。

参与教学的成员感慨道：“马练小学的孩子们都很聪明可爱，从他们身上我看到了纯真美好的一面，我觉得我们的爱心还不够，以后要多参加这类活动，在帮助别人的同时也锻炼自己。在教学过程中，我们也学到了很多知识，增强了团队意识，并学会在短暂的时间里快速适应环境的能力。”

据悉，本次义教活动我院还向马练小学捐赠了一万元善款和一批书籍、文具等物品。
