# 2012年春季国际交换生开始报名

记者从有关部门获悉，我院2012年春季国际交换生项目现已开始接受报名。根据学院与美国北爱荷华大学签订的友好合作协议，我院可派学生参加北爱荷华大学2012年春季学期的国际交换项目，学习时间为2012年1月至5月。凡是我院本科二年级以上（含大二）学生皆可报名。报名截止时间为2011年9月22日（星期四），咨询及报名地点：4号楼423 外事办公室。

目前，我院已有三批交换生参与该项目，他们的优秀表现获得了两校的赞赏。
