# 我院举办2017-2018学年度优秀辅导员评选活动

5月25日下午，学院举办2017-2018学年度优秀辅导员评选活动。王卫平、章德胜、刘玉侠、林江龙等院领导和有关部门负责人、各院系（部）主任、党总支书记、副书记和辅导员出席了活动。院办主任杜鹏举、党务工作部副部长叶凯贞、学生处副处长罗文芳、人事处副处长张兰、就业中心主任江小卫担任评委，学生处副处长陈建新主持了活动。

10位晋级院内复评的辅导员对各自2017-2018学年度的工作进行了汇报。大家通过精心制作的PPT分享了自己的工作特色、方法和成绩，展示了我院辅导员队伍勤勤恳恳、兢兢业业、爱岗敬业的精神风貌。

章德胜副书记对辅导员们的工作成绩给予了充分的肯定，对大家的表现进行了精彩的点评。他指出，评选活动为辅导员们提供了一个很好的交流平台。

王卫平院长强调，辅导员应当立足于立德树人这一中心环节，牢牢抓住全面提高人才培养能力这个核心点，努力把学生培养成为“有理想、有本领、有担当”的中国特色社会主义事业建设者和接班人。

学生处将结合参评辅导员的材料和各个职能部门的综合评审得分，选出得分最高的七位优秀辅导员人选，并进行为期一周的公示。公示后，报院长书记办公会审核授予其年度优秀辅导员的称号，计划于9月份进行表彰。

据悉，本学年，我院辅导员队伍建设成绩喜人。近日，从教育部思政司网站传来喜讯，苗琳老师荣获全国辅导员年度人物入围奖进入公示环节。之前，苗琳老师获得“2017年广东高校辅导员年度人物”称号。此外，陈浩华荣获“2017年广东高校辅导员年度人物提名奖”称号和“最具科学精神辅导员”荣誉；辅导员何伊丽获“第七届广东高校辅导员职业能力大赛”三等奖。据统计，截止目前，本学年我院辅导员队伍共获得省级荣誉22项，指导学生获省级奖项17项，为历年最好成绩。
