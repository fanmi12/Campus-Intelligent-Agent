# 我院召开第十二次学生代表大会

5月9日，东莞理工学院城市学院第十二次学生代表大会在学术报告厅隆重召开。团市委领导艾树珍、严磊出席，院领导王卫平、章德胜、高香林、黄兢、周庆、刘玉侠，以及学生处处长杜鹏举，院团委书记罗文芳等参加会议。团市委、市学联、东莞理工学院、广东科技学院、东莞市汽车技术学校、广东创新科技职业学院等单位派代表到会祝贺。297名学生代表参加会议，并有28名代表列席。

大会在雄壮的国歌声中开幕。团市委领导艾树珍致辞。他充分肯定了我院学生会一年来所取得的成绩，特别为城院400多名踊跃参与苏迪曼杯志愿服务活动的同学热情点赞。

党委书记王卫平代表学院发表了重要讲话，并提出了三点希望：（1）突出重点，加强思想政治引领。（2）促进学生成长成才，加强素质拓展；。（3）突出为学生服务的职能，增强组织建设和创新创业意识。他指出，我们要牢记习近平总书记在北大师生座谈会上对青年学生提出的要求，胸怀家国天下，不负时代使命，勤学、修德、明辨、笃定，为实现中华民族的伟大复兴而努力奋斗。

第十一届学生会主席赖焕婷作了学生会工作报告，总结了第十一届学生会的工作，并希望下一届学生会能再接再厉，做得更好。院学生会常务副主席叶佳敏和院学生会生活部部长谭静欣分别作了提案报告和财务报告。大会审议并表决通过了《东莞理工学院城市学院学生会章程（修正案）》和《东莞理工学院城市学院第十一届学生会财务报告》。

据悉，大会共收到学生代表提案297份，提案内容涉及学院设施、校园文化、校园环境、后勤服务、就业创业、安全、学院教育教学等方面的问题。

参加新一届学生会竞选的候选人进行竞选演讲，并接受学生代表的提问。大会通过投票选举，李惠敏、曾翠玉、刘国华、黄子芬、孔佩珊、莫青霞、黄挺忠、杜航、萧瀚轩、吴瑜等10位同学当选第十二届学生会主席团成员。

大会还授予财经系、计算机与信息科学系、金融与贸易系“优秀系学生会”称号，为城市与环境科学系颁发“学生会工作进步”奖，向46名学生会干部，184名优秀学生会干事颁发了荣誉证书。
