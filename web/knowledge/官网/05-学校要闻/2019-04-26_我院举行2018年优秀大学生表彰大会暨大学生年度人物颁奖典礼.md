# 我院举行2018年优秀大学生表彰大会暨大学生年度人物颁奖典礼

4月25日下午，2018年东莞理工学院城市学院优秀大学生表彰大会暨大学生年度人物颁奖典礼在综合馆举行。

会上，学院办公室主任杜鹏举宣读了《关于表彰2017-2018学年先进班集体、校园十佳、优秀大学生、优秀学生干部及奖学金获得者的决定》，并进行了颁奖。

高香林副院长宣读了《关于表彰2018年大学生年度人物的决定》。会议通过VCR对朱泽林、翁秋婷等十位大学生年度人物进行了展示。他们为了梦想而不断努力拼搏，展现了新时代城院人的良好精神风貌。

大学生年度人物代表朱泽林同学在发言中，表达了自己欣喜的心情，感谢学院的培养，表示今后将更加努力，让这项荣誉实至名归。大学生年度人物代表翁秋婷表示，将一如既往地做到严格要求自己，不忘初心，砥砺前行。

广东省辅导员年度人物、艺术系党总支张宏渝副书记对学校的栽培和师生们的支持表示感谢，并希望学校能够涌现更多的优秀人物。他还献唱了《辅导员之歌》，赢得现场掌声雷动。

王卫平院长号召全体师生员工向受到表彰的师生学习，希望发挥榜样力量，促进学风教风建设。他说，同学们要有家国情怀，要立鸿鹄之志，借助学院这个成长平台，提升自己能力，努力取得更多优秀成绩，不负大学的美好时光。

助学单位、东莞联通城区分公司副总经理刘路东，学院董事长代表陈超群，学院领导黄兢、刘玉侠、林江龙，各教学单位和有关部门负责人，体辅导员、优秀班集体班主任、学生代表参加了大会。
