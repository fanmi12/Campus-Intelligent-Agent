# 我院男篮七胜两负夺得季军

历时28天、34场比赛精彩角逐后，“马可波罗瓷砖杯”2018年第三届东莞大学生篮球联赛，5月23日晚在东莞职业技术学院体育馆圆满落幕！我院男篮力战九场，以七胜两负夺得季军。

东莞职业技术学院队获冠军，东莞理工学院队获亚军。第4至第8分名别为广东科技学院队、广东创新科技职业学院队、中山大学新华学院队、东莞市技师学院队、广东医科大学队。

书记、院长王卫平，副书记章德胜出席了当晚举行的闭幕式。

本赛季，我院男篮参与的9场赛事中，小组赛阶段发挥依旧出色，以5胜1负、小组头名出线，但无奈在单场交叉淘汰赛中，惜败东莞职业技术学院，无缘进入冠军争夺。5月21日，我院男篮与广东科技学院展开季军争夺战，以88:61战胜广科队，夺得季军。

大赛闭幕式举行了颁奖仪式。我院男篮荣获第三届东莞大学生篮球联赛季军，体育教学部获得优秀组织奖。

此外，我院还获得最佳宣传奖、钱丽娜教练获得球队突出贡献奖，罗飞依、段健鹏、林伟添获得优秀校园记者奖，黄秋峰、刘海莲获得优秀校园主播奖，陈芷慧、詹梓玥获得优秀志愿者。
