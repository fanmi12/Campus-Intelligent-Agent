# 城市学院承办东莞地方高校会计知识邀请赛并获第二名

5月5日，由东莞市会计学会举办，城市学院承办的2011年东莞地方高校会计知识邀请赛在我院大礼堂举行。来自东莞理工学院、东莞理工学院城市学院、广东科技学院、东莞职业技术学院的4支代表队参与比赛。经过几轮激烈的角逐，广东科技学院代表队以525分的成绩夺取桂冠。城市学院以485分名列第二。东莞理工学院与东莞职业技术学院获得比赛三等奖。

本次邀请赛分为有问必答，计算技能比拼，90秒快速连答，互动抽奖问答，猜专业词汇词比赛，快速点钞，急速抢答，风险题等八个环节。比赛内容涉及会计账目设置、分类，会计实操，税法等知识。各参赛队伍表现出色，反应灵敏。特别是计算技能比拼环节，各队派出的一名代表在短短的一分钟内便完成了十组5到6位数的加减运算。参赛队员的优秀表现时时博得现场观众的热烈掌声。
