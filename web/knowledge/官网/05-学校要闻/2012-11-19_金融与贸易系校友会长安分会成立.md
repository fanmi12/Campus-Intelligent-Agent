# 金融与贸易系校友会长安分会成立

11月18日，经过精心策划和周密组织，我院金融与贸易系校友会首个分会长安分会成立。

成立会上，金融与贸易系主任米双红、副书记李阳桂与金贸系的毕业学生陈裕钧、蔡裕成、李颖思等校友进行了亲切交谈。他感谢校友们对校友工作的支持，并询问了校友们的工作情况，希望各位校友继续关心学院和金贸系的发展，有时间常“回家”看看。

校友们就人才培养方案、学生实践能力、学生考证等方面的问题畅所欲言，积极建言献策。
