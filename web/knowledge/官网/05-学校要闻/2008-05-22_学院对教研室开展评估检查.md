# 学院对教研室开展评估检查

5月21日，教研室评估专家组在教务处处长邓成良教授、专家组组长高香林教授的带领下，对机电工程系环境资源教研室进行评估检查。

机电工程系副主任、环境资源教研室主任孙成访博士向评估组作自评报告，汇报教研室基本建设、教研室评估指标体系要求以及教研室自评结果等相关情况。

评估组检查评估材料后，对环境资源教研室取得的成绩表示肯定，并提出了一些切实可行的建议，希望教研室继续加强自身建设，提升教学科研实力，在已有的基础上更进一步。

此次教研室评估检查，对加强教研室建设，更好地发挥教研室在教学组织、管理中的作用，使教研室的管理进一步制度化、规范化、科学化将会起到促进作用。
