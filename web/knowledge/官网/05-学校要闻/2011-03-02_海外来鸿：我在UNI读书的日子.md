# 海外来鸿：我在UNI读书的日子

尊敬的各位领导、老师，同学们：不知不觉来到UNI（美国北爱荷华大学）已经一个多月了。作为一名国际交换生，体验国外的学习与生活，这是莫大荣幸的一件事情。

北爱荷华大学（以下简称UNI）位于美国的中部爱荷华州，冬季比较严寒。记得下飞机走出机舱时，首先映入眼帘的是白皑皑的大雪，零下20多度，特别的冷，与我国东北地区差不多。

刚来时最大的感觉就是疲惫，也许是三十几个小时的航程和时差的缘故吧。这里负责接待的老师和同学很热情友好，很快就解决了我的食宿问题。在这里遇到了困难和不便，只要开口，美国的同学或老师都会很友好地帮助你。一些华人同学还教给了我一些小常识，使我很快适应了美国的生活。

UNI的教学生活设施完善齐备。每栋宿舍楼都设有厨房、文体活动室、电脑室、洗衣房等，每层宿舍楼都有电视、微波炉、冰箱、钢琴和桌球。以宿舍楼为单位经常开展各种不同的party，比如做冰激凌，邀请男女生一起跳舞等。校园里各种各样的海报吸引人的眼球，令人心动，有篮球赛、英语角、聚餐、点心制作、滑雪等活动。这些活动使我很快融入了这所大学，认识了许许多多不同国家的朋友。

为了深刻了解和体会中西教育的异同，我选学了四门课，其中两门与我自身的专业有关，即自然灾害、区域规划，第三门是《大学写作与研究》，第四门是自己的爱好《西方哲学》。这里的大学课堂氛围轻松，老师和学生自由讨论，一点都不介意“跑题”。美国同学给我的印象是，他们很在乎自己的感觉。比如在一起做小组作业，他觉得房间不舒服，便会马上说出来要求调换场所，老师和同学通常会给予理解和支持。美国学生上课非常认真，在课堂上打瞌睡的现象极其罕见，每个人都用笔不停地做笔记。师生关系相当和谐，老师会经常约学生见面或喝咖啡。如果学生遇到不懂的地方，老师会叮嘱学生一定要去办公室找他补课。老师布置的作业或考试的题目相当灵活。对于母语不是英语的交换生的我们来说答题是比较困难的，但却是一个难得的锻炼机会。我的第一份哲学作业就是写一份关于学习“苏格拉底与牛虻”一文的体会文章，以及我所欣赏的一位当代民主政治活动家的文章。教授要求以散文的形式写，并强调这篇文章只须写五页纸，要求相当高。老师写的评语很仔细，事后我也会带着批语去找老师讨论。我这一次作业的成绩是“B”，同学们告诉我这个成绩是不错的。

随着考试（每门课通常一学期会考2-3次左右）和作业的增多，我渐渐习惯了和亚洲同学一起熬夜做作业和备考，忙起来每天只睡4、5个小时，这样的学习虽累但很充实！

美国的文化是多元的，也很发达。当然这个“发达”不仅是指历史的悠久或底蕴的深厚，同时也包括他们创造更新的速度和对外来文化的吸收。对于这一点，我在签证时就有这样的体会。每个签证官必然会问你：“你为什么要来美国？”而他们想得到的答案只有一个，那就是你能为美国带去什么。

美国的大学生生活分为学习日和周末。学习日很忙很辛苦，周末就尽情地享受生活：party文化，bar文化应有尽有。当然这边宅男宅女也是有的。今年我是在美国过的春节，和当地华人一起看春晚，吃中国餐，欣赏了由学校华人学生会和当地华人联合会共同组织的联欢晚会。这些活动使我认识了10多个国家和地区的朋友，生活不再感到孤独。刚来美国时，我觉得离家很远，语言又不同，孤独感油然而生。留学生告诉我，他们“最大的感觉是孤独。”现在我终于明白了，所谓的孤独就是一张成长的兑换券，在挥霍的同时，你也就变得成熟了。
