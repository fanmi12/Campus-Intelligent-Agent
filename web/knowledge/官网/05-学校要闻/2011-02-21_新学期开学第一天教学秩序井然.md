# 新学期开学第一天教学秩序井然

今天，是我院新学期开学的第一天。全院师生以饱满的热情，开始了紧张的教学和学习工作。

上午8：30，教务处工作人员分组深入各班级，对教学情况进行全面巡查，各系部也组织班主任、辅导员检查上课情况。巡查结果表明，新学期第一天的教学秩序井然，未发现教学事故，任课教师准备工作充分，按时到堂授课；学生出勤率高，精神状态良好，听课认真，全院教学运行平稳有序。

另据学生处统计，截至21日中午，全院共有9314名学生返校，返校率为98.50%。各系部辅导员与未到校报到的学生均取得了联系，了解了具体情况，其中绝大部分同学将于近日返校。
