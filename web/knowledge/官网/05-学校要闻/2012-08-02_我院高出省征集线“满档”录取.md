# 我院高出省征集线“满档”录取

8月1日，我院省内本科B线征集志愿揭晓。我院在扩招一倍，总计划招生数扩至5011人情况下，文理科以高出省征集线11分“满档”录取。

招生录取工作中，东莞理工学院党委副书记黄碧莲，审计监察处处长汪璟，东莞理工学院城市学院院长杨敏林、党委书记朱志德多次看望指导招生工作。城市学院党委副书记朱冰、章德胜全程参与指导招生录取工作。

我院继续受到莞籍考生追捧 征集志愿提前“满档”

记者从省考试院获悉，今年面向广东招生的全国高等普通院校总计划招生预计将超过50万，比去年增加4万～5万。在名校林立， 2B院校同时扩招达数千人的情况下，我院在去年基础上扩招一倍以上，仍以高出省征集线11分 “满档”录取。据学生处副处长陈建新介绍，今年上省线第一志愿报考我院的考生，均满足填报的第一专业。

“与往年不同的是，今年我院从保证东莞考生入学机会的角度出发，取消了以往的区域限制，不再限定莞籍考生人数，这就使莞籍考生有了更多的入学机会。目前，招录的东莞籍学生达到了2351人，占录取总人数的50%，应该说基本满足了莞籍学生报考我院的意愿。”学生处副处长陈建新介绍。

专业设置合理，就业前景广阔，催生考生竞相报考

我院办学之初就坚持立足东莞经济社会发展的实际需要，结合学院实力，科学设置专业及人才培养方案：城市学院现有21个本科专业，多数专业是根据东莞支柱产业和城市现代化需要设立的；每个专业配备高学历、高职称、高素质的专业负责人；制定和实施学院专业建设规划，优化专业结构，扶持特色专业。

我院先后向社会输送毕业生13600多人，毕业后全部在东莞工作、创业,就业率高达98%。毕业生扎根东莞，服务于东莞经济社会发展，普遍受到赞誉。

从与招生办工作人员的交谈中，记者得知，7月31日，征集志愿伊始，招生办的电话一直忙碌不停，绝大多数考生都是询问我院的专业设置情况或了解想就读专业的录取情况。专业设置符合地方经济发展需要，就业前景广阔，催生了考生竞相报考我院。
