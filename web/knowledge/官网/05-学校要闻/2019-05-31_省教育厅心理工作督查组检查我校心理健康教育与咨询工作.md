# 省教育厅心理工作督查组检查我校心理健康教育与咨询工作

5月31日，由广东省高校心理健康与咨询专业委会主任邱鸿钟、省教育厅思政处科长周中桅、华南师范大学心理健康教育与咨询中心主任李江雪、广东省高校心理健康与咨询专业委会秘书肖孟琦组成的省教育厅大学生心理工作督查组莅临我校检查大学生心理健康教育与咨询工作。

汇报会上，学生处副处长蔡小锋从健全心理健康教育与咨询工作机制体制、队伍建设、特色创新、经费投入等方面，向督查组详细汇报了我校大学生心理健康教育与咨询工作开展情况。王卫平校长、章德胜书记和各有职能部门负责人、心理健康与咨询中心工作人员参加了汇报会。

随后，督查组分别与心理健康教育与咨询工作专职教师、学生代表进行了座谈。

督察组还来到商学院二级心理教育辅导站、学校心理中心等场所进行了实地考察、查阅资料、观摩心理健康教育课程。

在督查组意见反馈会上，专家对我校大学生心理健康教育与咨询工作的总体建设情况表示满意，对特色创新表示欣赏，对我校存在的不足提出了宝贵的意见。

王卫平校长表示，非常感谢督查组提出专业性的建议与意见，学校将制定整改方案，进一步加强和完善大学生心理健康教育与咨询工作。
