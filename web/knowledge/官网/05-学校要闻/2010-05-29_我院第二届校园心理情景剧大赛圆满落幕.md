# 我院第二届校园心理情景剧大赛圆满落幕

5月27日，由学生处主办、心理健康教育与咨询中心承办的“珍爱自我，让心灵绽放晴空”第二届校园心理情景剧大赛在大礼堂举行，10支优秀队伍参赛。

大赛开始前，学生处处长章德胜宣读《关于表彰2009-2010学年度“优秀心理工作者”“优秀心理委员”的决定》，宋艳等7名老师被评为“优秀心理工作者”，邱丽等21名同学被评为“优秀心理委员”。

艺术系的《求助》讲述的是一位与网友相恋而意外怀孕的女生到医院做人流手术的故事，告诫同学们不要因为短暂的幸福而使身体心灵受到伤害。感人的剧情和表演者卖力的表演使《求助》获得大赛一等奖。文传系参赛作品《冲破黑色世界的光》、金贸系《爱，一路伴随》作品获得二等奖，机电系《我的天空》、财经系《青春有悔》、管理系《生命！生命！》表演作品获得三等奖。

据心理健康教育与咨询中心副主任余琼老师介绍，此次心理情景剧的参赛作品都很精彩，通过舞台表演，反映了大学生心理特点和心理状态，让同学们观后有所启发、领悟，达到了宣传心理知识、提高心理健康意识的目的。

心理情景剧是一种团体治疗心理问题的方法，通常是由团体成员扮演日常生活情境中的角色，将自己的心理问题通过戏剧、小品等形式展示出来，在团体的互动中，学会表达感受，培养和提高团体成员的洞察力，发现、思考和解决自身的心理问题。心理情景剧内容取自学生的生活，形式生动活泼，参与性、互动性强，是开展心理健康的新途径。
