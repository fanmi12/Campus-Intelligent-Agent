# 686名师生无偿献血21万毫升

5月16日-18日，由东莞市中心血站、我院志愿队在学院联合举办了无偿献血活动，共有686名师生献血211900毫升。同时，学院志愿服务中心近50名志愿者积极在现场进行宣传和志愿服务工作。

我院师生的献血热情受到市中心血站的高度赞许。王若珩医生表示，城院师生参与积极性很高，志愿者除了帮我们分担工作外，还积极带头参与献血，精神可嘉。
