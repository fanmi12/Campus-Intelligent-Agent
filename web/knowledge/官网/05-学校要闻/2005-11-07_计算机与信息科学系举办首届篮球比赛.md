# 计算机与信息科学系举办首届篮球比赛

为期两周的计算机与信息科学系首届“斯伯丁杯”篮球赛，于11月2日在学生篮球场落下帷幕。技术科学部04级通信代表队技压群雄，获得冠军。

本次大赛由计算机系学生会主办，体育部承办。全系24个班级12支代表队参加了比赛。经过15场比赛的激烈角逐，04通信、03计算机、03软件工程和05计算机科学代表队进入决赛。

比赛过程中，运动员奋力拼搏，赛出了应有的水平。决赛双方紧密的防守、快速的进攻和默契的配合，赢得了全场观众阵阵掌声和欢呼声。

院学生处章德胜处长、丘永辉副处长、计算机与信息科学系主任牛熠副教授、书记廉玉忠教授以及赞助商斯伯丁专卖店代表出席了颁奖仪式，并为获奖代表队颁奖。
