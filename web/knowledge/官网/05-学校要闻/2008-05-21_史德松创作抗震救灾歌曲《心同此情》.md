# 史德松创作抗震救灾歌曲《心同此情》

5月12日汶川地震发生后，文学与艺术系史德松副教授连夜谱写了抗震救灾合唱歌曲《心同此情——为汶川地震而作》。

史德松副教授告诉记者，汶川地震牵动着所有人的心，我们迫切需要有一首这样的歌曲来为中国加油，为灾区鼓劲，用嘹亮雄壮的歌声为灾区人民祈福祝愿。

据悉，学院已经组成60余名师生合唱团进行排练，将在5月28日《五月的鲜花》晚会上正式演出。
