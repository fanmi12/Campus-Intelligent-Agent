# 谢明副教授参加全国独立学院机械类专业教育教学经验交流会

5月18日至20日，我院机电工程系谢明副教授应邀参加了在华南理工大学广州学院举行的“第一届全国独立学院机械类专业教育教学经验交流会”。 来自全国26所独立学院的46名代表就机械类专业人才的培养定位、培养方案以及办学特色等问题展开了讨论。
