# 广东省教育厅思政处袁本新博士来我院做专题讲座

4月20日，广东省教育厅思政处处长袁本新博士应邀到访我院，指导思想政治教育工作，并作了题为《走进心灵——当代大学生的精神生活》的专题讲座。党委书记朱志德，院督学陈丁堂、各系党总支副书记、专职辅导员、学生处、思政部老师参加了讲座。

讲座由党委宣传部部长何鹏举教授主持。

袁本新处长在讲座中从分析现今的社会乱象导入，指出当代大学生精神生活的重要性，讲解了何为精神生活，探讨了大学生精神生活环境、大学生精神生活样态，并着重论述了大学生精神生活的构建。袁处长的讲座从理论的高度对大学生精神生活作了系统剖析，使我院思想政治教育工作者们深受启发，对开展学生工作有很强的指导作用。

期间，东莞理工学院副校长安少华教授、校长助理邢大立副教授，城市学院院长杨敏林教授分别和袁处长探讨了高校思想政治理论课建设和学生管理工作。袁处长还对思政部思想政治理论课专项评估工作进行指导。
