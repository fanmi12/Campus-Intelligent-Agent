# 中山大学南方学院副院长唐燕一行来我院参访

4月24日，中山大学南方学院党委副书记、副院长唐燕女士一行15人来我院参观交流。院领导张林、麦绮琳及相关部门负责人热情接待了来宾，并在行政楼前合影留念。

在会议室，张林副院长向客人介绍了我院的办学情况和管理架构。随后，双方就高校开展党的群众路线教育实践活动、独立学院发展思路、制度建设、专业建设、人才引进、教学管理、学工管理、图书管理、后勤服务等方面的内容进行了深入交流。

会后，唐副院长一行实地参观了校园。
