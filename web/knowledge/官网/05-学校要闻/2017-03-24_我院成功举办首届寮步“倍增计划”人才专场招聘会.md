# 我院成功举办首届寮步“倍增计划”人才专场招聘会

3月9日，首届寮步“倍增计划”行动——城市学院人才专场招聘会在我院举行。

本次招聘会是由我院招生就业处与东莞市寮步镇民营科技局联合举办的。招聘会以东莞市“企业规模与效益倍增计划”为契机，精选30家寮步镇重点企业来我院现场招聘，共提供就业岗位500多个，吸引了二三百名毕业生前来求职应聘。招聘会现场，身着正装、神采飞扬的学子们手执简历，穿梭于各大企业招聘展位之间，仔细浏览各企业岗位要求及需求，寻找心仪的岗位。

我院院长、书记王卫平，副书记章德胜，副院长黄兢、周庆，以及寮步镇民营科技局局长钟达国、副局长韩柏泉等领导亲临招聘现场，进行观摩指导。双方领导充分肯定了招聘会的组织工作和招聘效果，并就如何进一步加强学校与地方、学校与政府、学校与企业以及产学研合作等方面交换了意见。

据了解，东莞市今年实施的“倍增计划”精选了200家试点企业。寮步共有17家企业纳入了试点，还有9家纳入后备试点企业。试点企业规模全部过亿，涉及机械装备、电子信息、新材料等几大领域。此外，寮步镇还选定30家企业作为镇“倍增计划”配套，加强政策扶持。
