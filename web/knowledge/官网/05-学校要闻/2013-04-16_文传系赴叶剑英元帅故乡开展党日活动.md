# 文传系赴叶剑英元帅故乡开展党日活动

4月13日为文学与传媒系党日活动时间。这一天,该系党总支组织全体党员到梅州市参观叶剑英元帅纪念馆和叶剑英故居。

在纪念馆，党员们认真听取了叶剑英同志生平事迹的介绍，观看了相关的教育短片，对叶剑英元帅传奇的戎马一生有了全面详细的了解。大家通过缅怀革命先辈，接受革命传统教育和爱国主义教育，进一步加深了对党的认识，坚定了理想信念，激发了爱国、爱党、爱民热情。

下午，全体党员到嘉应学院客家研究院参观学习，研究院副院长肖文评教授详细介绍了研究所的发展情况和所取得的主要研究成果。研究院丰富的馆藏和研究成果引起了老师们浓厚的兴趣。
