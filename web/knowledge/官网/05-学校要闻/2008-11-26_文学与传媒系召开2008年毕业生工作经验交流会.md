# 文学与传媒系召开2008年毕业生工作经验交流会

11月24日，文学与传媒系在学术报告厅召开2008年毕业生工作经验交流会。就业办主任江小卫老师，文传系党总支书记孟颖老师、各毕业班班主任和毕业班学生参加了会议。

就业办主任江小卫老师在会上向300多名毕业生介绍了当前大学生的就业形势。他说，全球金融危机给大学生就业带来一些影响。但是，中央对此采取了许多应对措施。就东莞而言，影响并不大。他希望同学们端正就业态度，及时调整心态，做好就业前的心理准备。
