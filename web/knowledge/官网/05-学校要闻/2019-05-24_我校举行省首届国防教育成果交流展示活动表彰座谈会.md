# 我校举行省首届国防教育成果交流展示活动表彰座谈会

5月23日下午，我校举行广东省第一届学校国防教育成果交流展示活动表彰座谈会。校领导及相关职能部门负责人会同全体国旗护卫队队员、指导老师参加了表彰座谈会。会议由后勤保卫处处长王锦锋主持。

5月8日，在广东省第一届学校国防教育成果交流展示活动上，我校国旗护卫队在108所参赛队伍中，以标准规范的动作、昂扬的精神风貌脱颖而出，获得交流展示活动一等奖。会上，后勤保卫处副处长刘维仝详细介绍了此次参赛过程和取得的成绩，并作了全面总结。

副校长刘玉侠宣读表彰决定。

副校长周庆为获奖队员颁发荣誉证书。

校党委书记章德胜为获奖队员颁发荣誉证书。

团委书记李瑶、指导老师王守滨发表了个人感想。国旗护卫队队长潘可淇等几位同学分享了他们在国旗护卫队的心路历程和未来发展的规划。

全体与会人员观看我院国旗护卫队参赛视频，一起回顾那个激动人心的时刻。

校长王卫平向我校全体国旗护卫队员们表示衷心的祝贺。他指出，同学们在国旗护卫队中的历练也是一种学习，对形成良好的生活、学习习惯有着重大促进作用，这也是一笔宝贵的人生财富。希望国旗护卫队队员们继续努力，不仅在学校和赛场上绽放光彩，还要将赛场上的风采和热爱国旗、热爱祖国的精神带出城院，为社会服务，实现更远大的人生理想和社会价值。
