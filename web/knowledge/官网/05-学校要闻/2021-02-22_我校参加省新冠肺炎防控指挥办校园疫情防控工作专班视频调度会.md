# 我校参加省新冠肺炎防控指挥办校园疫情防控工作专班视频调度会

2月20日，广东省新冠肺炎防控指挥办召开校园疫情防控工作专班视频调度会。省委教育工委书记、省教育厅厅长景李虎出席会议并讲话。我校校长王卫平、党委书记章德胜和有关部门负责人参加了视频调度会。

景李虎厅长在会议中强调，要高度重视开学季疫情防控工作，压实“四方责任”。一是按照“四精准”“六分”“一独立”“三全”“五管”校园疫情防控措施等方面要求抓紧抓实抓细，毫不松懈地做好校园管理、人员跟踪排查、重点人群隔离监测等工作；二是要根据学生、教师活动的空间顺序，加强防范指引和引导；三是要求各学校开展彻底的校园爱国卫生运动；四是要加强家校联系，加强心理健康教育；五是要加强校园门口和周边的治安和安全管理工作；六是要备齐应急物资，急方案，分层分类防治；七是压实工作责任，责任到岗，责任到人，全部网格化，精准化。

视频调度会后，校长王卫平、党委书记章德胜强调，各单位要坚决贯彻落实会议精神，做好开学疫情相关工作。会议还商讨了新学期错峰返校分批报到的方案，以及加强校园卫生工作和学生心理健康教育等措施，确保师生安全有序返校。
