# 第二届大学生职业规划报名突破2000人

我院第二届大学生职业规划大赛2007年5月10日全面启动并网上报名。据统计，截止7月15日，报名人数已达2079人，其中有1100人参加测评，部分同学已经完成作品。学院就业指导办公室副主任江小卫老师建议，参加比赛的同学应利用暑假，多到相关行业实践或采访相关人士，以获得更为具体、准确的职业信息，尽早完成作品。
