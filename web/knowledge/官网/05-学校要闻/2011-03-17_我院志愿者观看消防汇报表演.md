# 我院志愿者观看消防汇报表演

3月16日，我院志愿服务中心的67名志愿者在院团委老师的带领下，前往黄旗山观看东莞市消防汇报表演。

来自各镇街的消防官兵为观众们带来了精彩的汇报表演并传授了许多消防安全知识和遇险自救办法，使观众受益匪浅。

省公安厅副厅长郑东，省消防总队队长雷盛武，东莞市政府副市长成洪波等领导出席并观看了表演。
