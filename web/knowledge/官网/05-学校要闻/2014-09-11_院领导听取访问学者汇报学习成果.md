# 院领导听取访问学者汇报学习成果

9月6日，我院在行政楼312会议室召开首批访问学者学习成果汇报会。林岩、李玲玲、张灿灿三位老师向院领导王卫平、章德胜汇报了学习收获与学习体会。

据悉，林岩等三位老师受学院的派遣，分赴清华大学、广东外语外贸大学、中南财经政法大学访学研修，时间是一年。他们在汇报中表示，一年的访学经历，使自己收获很大，拓展了知识面，开阔了视野，见识了校外教师的风采与教学方法。

党委书记王卫平、副院长高香林听取了他们的汇报，肯定了访问期间的表现。院领导认为，外出访学形式很好，有利于教师的成长发展，有利于学习借鉴兄弟院校的教学经验，今后应长期坚持下去。

教务处处长牛熠、组织人事处副处长李海冬参加了会议。

另据了解，第二批访学教师陈益云、黄岳钧已于今年9月分赴中央财经大学、华南理工大学。
