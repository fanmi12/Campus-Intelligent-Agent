# 我校成功举办2021届毕业生校园招聘会

10月29日下午，东莞理工学院城市学院2020年首场线下综合类专场招聘会在学校锦绣会场隆重举行。

东莞市人力资源服务中心副主任吴德阳、东莞市人力资源和社会保障局寮步分局局长刘俊桢、副局长钟坚玉，学校领导以及就业相关负责人来到现场积极询问了毕业生的就业意向和准备情况，并详细了解了用人单位的招聘情况和人才需求。

受疫情影响，我校加强了疫情防控工作，所有现场人员需通过粤康码、行程卡、学校开具的通行证以及体温不超过37.3℃的疫情防控标准方可入场，且需佩戴口罩。进出等候及参会期间均保持1.5米以上距离。虽然口罩隔离了人的身体距离，现场招聘和应聘的热情却没有退怯。

现场，我校多名领导亲临现场指导工作，保安和志愿者在会场出入口维持秩序，招聘人员热情地给应聘的学生发招聘单，求贤若渴。各企业将参展信息挂在墙上，蔚为大观。毕业生们身着正装，捧着精心准备的简历，充满自信地与企业招聘人员交流，参加面试。热门企业的招聘摊前更是排起了长队，招聘现场人山人海却秩序井然。

据了解，在本次综合类专场招聘会，我校联合智通人才连锁集团从众多家报名的优质企业中精心挑选了120家企业参会。

我校一直以来致力于应用型人才培养，服务地方经济社会发展，本场招聘会为毕业生与用人单位搭建了双向选择的平台，进一步引导和促进我校毕业生更高质量更加充分的就业，是我校统筹抓好疫情防控和学生就业工作，确保2021届毕业生稳就业工作的重要举措。
