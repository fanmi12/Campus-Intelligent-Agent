# 王卫平校长带队走访教师公寓 关心关怀新进教师

人才是大学发展的第一资源，是立校之本、强校之源，我校历来高度重视人才的引进和培养。9月7日下午，王卫平校长在鸿发教育投资集团副总经理李奎山、后勤保卫处副处长蔡小锋等后勤相关负责人陪同下赴我校教师公寓看望新进教师。

王校长一行进入新进教师新家，一一查看并与新进教师进行亲切交谈，关心他们的住宿和生活情况，耐心的听取新进教师们的心声及他们的生活、工作情况。

交谈中，王校长表示，安居才能乐业，来到城院就是城院人，希望各位老师在城院快乐生活、开心工作。同时王校长指示后勤部门一定要耐心听取大家的意见，脚踏实地的干好后勤服务工作，为城院师生提供更好更稳的后勤保障。
