# 东莞理工学院城市学院隆重举行建党百年颂“启·航”大型校园经典诵读晚会

为激发同学们爱国爱党的热情，塑造学生自信自强的优良品格，我校在5月20日晚，在学术报告厅隆重举行建党百年颂“启·航”大型校园经典诵读晚会。东莞理工学院城市学院副校长周庆、名誉院长宋秋敏教授、学生处副处长、城建与环境学院党总支书记罗文芳，智能制造学院党总支副书记何珊珊、学生处思政科副科长詹海都、城建与环境学院团总支书记梁丹丹、文学与传媒学院党总支书记、副院长陈跃、党总支副书记王炯贤等领导嘉宾莅临晚会。

晚会一共分为三个篇章，上篇主题为“建党伟业”。开场《红船，从南湖启航》的诵读者以红船讴歌党，赞颂了广大革命先驱为中华民族开拓道路和党领导下的国家如初升的太阳充满希望。在《可爱的中国》中，朗诵者饱含深情，为我们的祖国母亲高歌。“执政为公，砥砺前行再！”建党百年之际，文传学院陈跃老师亲自为祖国书写赞歌。他用湘语致敬开国大典，告白祖国，一首《苏幕遮 开国大典》声情并茂，激发了观众们的爱国热情，深深震撼了观众们的心灵。

中篇主题为“奋翼时代”。在《奋斗的青春》中，文传学院学生党支部用情景演绎的方式展现了习近平主席在梁家河的七年知青岁月。“因为，你从梁家河走来！因为，你心中始终装着人民群众！因为，要为人民做实事是你不变的信念！”《你从梁家河走来》带给了青年学生们榜样的力量。在《我的南方和北方》中，朗诵者带观众领略了南方北方的美景，表达了对祖国大好河山的热爱。下篇主题为“追梦中华”。“我要用城院的故事，去书写那湾区春潮的壮阔景象。”由城院学子创作的《我的城院我的梦》表达了对城院的热爱，情感丰富的朗诵抒发着对青春的畅想。“又是春潮拍岸时，中国道路宽广壮丽，抑制不住的勃勃生机啊！”一首《又是春潮拍岸时》，以春潮簇起花期，恢弘的气势充满对党和国家满载星辉的未来的坚信。朗诵者激情昂扬地献上一首《百年颂歌》，在这建党百年的伟大日子里，每一个人都为中华而骄傲。接着，艺术团风烙舞队为观众带来舞蹈《灯火里的中国》，婀娜的舞姿让观众仿佛看到了万家灯火，歌舞升平。随后，文传学院和智能制造学院师生党员代表为观众们带来了原创小品《国旗下党旗下成长的我们》，小品致敬了革命先辈和辛勤奉献的党员同志，正因为他们的初心不改，才有了在国旗下党旗下茁壮成长的我们。“家是最小国，国是千万家。”最后，晚会在一首温馨的《国家》里圆满落幕。

拔新引领，扬帆起航。本次“启·航”大型校园经典诵读晚会给观众们带来了一场精彩绝伦的诵读表演，带领师生们站在岁月的起点，重温了建党百年的光辉历程，感悟了中华民族不屈不挠的奋斗精神，鼓励着我校师生为更加灿烂辉煌的明天奋斗。
