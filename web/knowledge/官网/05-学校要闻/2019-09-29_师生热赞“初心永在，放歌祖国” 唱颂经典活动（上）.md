# 师生热赞“初心永在，放歌祖国” 唱颂经典活动（上）

这是一场意义非凡的爱国主义教育活动，充分展现了城院学子的爱国情怀和当代大学生的精神风貌!

——艺术学院党总支副书记 张宏渝

师生的歌声唱出了对祖国的热爱，唱出了时代的主旋律，唱出了不忘初心、牢记使命的信念。豪迈澎湃的歌声荡漾在校园中，让师生们真切感受到党的关怀，整个校园营造着爱党、爱国、爱人民的温馨氛围，极大激发全校师生工作与学习的热情。

——智能制造学院 陈劲文老师

我们放声歌唱《国家》《我和我的祖国》，这正是方志敏所渴求的“欢歌代替了悲叹，笑脸代替了哭脸，富裕代替了贫穷，健康代替了疾苦”的“可爱的中国”！“今天，我们比历史上任何时期都更接近、更有信心和能力实现中华民族伟大复兴的目标！”

——18级文学与传媒学院汉语言文学4班 王佳仪

参与这个活动我感到很荣幸，通过这次活动增加了我们城院师生的爱国之情，让我们对祖国的未来充满期望，引以为傲。

——智能制造学院机械设计制造及其自动化2班 徐达

通过看新闻，我感到非常震撼，学校举行如此大型的活动，动员了这么多的师生来参加，感受到学校对广大师生开展爱国主义教育活动的重视。我没有亲眼见证这一壮观的场景，感到非常可惜。

——19级文学与传媒学院网络与新媒体专业4班 周妃燕

我参加了“初心永在，放歌祖国” 唱颂经典活动，深深地体会到了祖国的强大和强烈的民族自豪感。通过活动，我为自己是中国人而感到骄傲，内心油然而生的责任感，为美好中国而奋斗。我爱你，中国！

——智能制造学院机械设计制造及其自动化2班韦 启泰70载如歌岁月，70载风雨兼程，70载砥砺奋进！我爱祖国母亲！祝愿国泰民安、繁荣昌盛！

——18级艺术学院音乐表演2班 黄耀辉

“初心永在，放歌祖国”唱颂经典活动， 气氛极其震撼。能在新中国成立70周年之际为她献上我最诚挚的祝福，身为演出者感到自豪！祝愿伟大的祖国繁荣安康！

——18级城环学院人文地理与城乡规划1班 韩静

参加活动的时候，我的心情澎湃。我和我的同学们虽然来自五湖四海，但我们都是中国人。几千人一起为祖国母亲放声高歌，都是满满的激动和自豪。我是一个中国人，有着一颗火热的中国心。我以我的祖国为自豪！

——智能制造学院机械设计制造及其自动化2班 刘书杰

活动表达了城院师生的爱国热忱。看着巨型的国旗，一起唱起歌颂祖国的经典红歌，心中的热血在汹涌澎湃，一种爱国主义情怀和自豪感油然而生。国家强大了，百姓才能安居乐业，我们才会有上大学接受教育的机会，祖国永远是我们最坚强的后盾。我爱我的祖国！

——16级城建与环境学院城乡规划2班 方贵盛

活动举办得非常有意义，提升我们城院师生的爱国情怀。我希望学校今后多举办爱国教育活动，让更多的学生一起参与进来。祝福我们伟大的祖国繁荣富强！

——19法学院法学专业 卢思婷
