# 机电工程系召开教学工作会议

3月27日，机电工程系在机电楼308会议室召开教学工作会议，全系教职工参加了会议。

会上，系主任黄健求教授首先代表全系师生员工欢迎周梓荣教授加盟机电系。接着，黄主任在会上传达了学院的有关文件精神，对一些工作重新进行了明确的分工和人员的安排。他希望老师们要保质保量完成今年的任务。要解放思想，不断创新，为学院的发展贡献自己的力量。
