# 学院召开暑假工作会议

7月7日，院长安少华教授在学院召开的暑假工作会议上要求各部门要平平安安过暑假，认认真真完成工作。

院长安少华教授在会上强调，学生放假了，机关工作、后勤工作一点也不能放松。对于计划性工作和临时性工作，各部门要按部就班、保质保量地完成，并要有一定的预见性。教学部门要落实教学任务，保证教材到位；基建部门要保证图书科技信息中心建设及教学楼改造等重点工程的顺利开展；总务处要认真做好校园后勤保障和环境整治工作，切实加强食堂的卫生防疫检查力度，确保食物和用水的安全，力求以优美的校园环境、良好的校园风貌迎接新学期的到来；学生处要按计划安排好学生暑期实践活动，并提前策划迎新和军训工作，还要妥善安排好留校学生；保卫办要加强消防、治安等各项工作的检查，认真做好校园安全保卫工作，确保在校各类人员人身安全和学院财产安全；实验中心要利用假期完成招投标工作，并尽快投入使用。

会议由院办主任王玉主持。
