# [科技文化艺术节]“知法于心，守法于行”

5月22日，由院团委主办、政法系团总支学生会承办的城市学院第二届法律知识竞赛决赛在学术报告厅拉开帷幕。

本次决赛以“知法于心，守法于行”为主题，普及法律知识，提高学生法律维权意识。

决赛分为个人必答题、集体必答题、抢答题、风险题以及观众回答题。经过激烈的角逐，财经系以220分的总分夺冠，文传系和管理系荣获二等奖，机电系、政法系和金贸系分获三等奖，管理系获优秀组织奖，艺术系，高职部，计信系和城环系荣获优秀奖。11级工商管理一班梁枫儿和11级国际会计二班洪湘柔同学获“优秀个人”奖。
