# 黄兢副院长一研究课题获全国教育科学 “十三五”规划重点项目立项

近日，全国教育科学“十三五”规划重点项目——“社会变迁进程中青少年价值观的发展与影响机制研究”项目完成课题立项工作。我院副院长黄兢副研究员、硕士生导师作为该项目中的“社会变迁过程中的青年价值观形成机制研究”专项课题研究的主持人，承担着这一课题的研究任务，研究时间为2017年6月至2019年12月。

据了解，“社会变迁进程中青少年价值观的发展与影响机制研究”项目的研究团队由中山大学、中国地质大学（武汉）、华中科技大学等知名高校专家学者组成。项目包含两个研究主题：一是社会主义核心价值观内涵研究。分为社会主义经济、政治、文化等领域的价值诉求研究；体现和谐社会理念的价值要求研究；弘扬中华民族优秀文化传统，借鉴人类有益文明成果，实现内容与形式的完美结合研究等三个专题。二是社会主义核心价值观与青少年思想政治教育比较研究。分为社会主义核心价值观与大学生思想政治教育的关系研究；社会主义核心价值观如何引领高校思想政治教育研究；在大学生思想政治教育中贯彻落实社会主义核心价值观的方法研究等三个专题。

“社会变迁过程中的青年价值观形成机制研究”专项课题负责人黄兢副研究员表示，该课题研究的实施将从内涵与机制、现状与评价、方法与优化等多方面丰富和发展社会主义核心价值观研究。此次承担全国教育科学“十三五”规划重点项目的课题研究是学院科研发展的一个里程碑，是对学院百年名校建设提出的学科交叉、融合发展理念的有效落实，将为学院进一步加强高水平科研平台建设、组建高水平科研团队打下坚实基础，有助于提升我院大学生思想政治教育及相关学科的影响力。
