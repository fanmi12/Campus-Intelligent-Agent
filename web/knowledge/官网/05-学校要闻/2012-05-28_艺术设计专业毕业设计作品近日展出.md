# 艺术设计专业毕业设计作品近日展出

5月28日，文学与传媒系艺术设计专业毕业设计作品在4号楼大厅展出。

指导老师王宁介绍说，本次展出的是2009级艺术设计专业毕业学生的创作作品共分为27组，所展出的作品以“设计东莞”为主题，以东莞传统文化、节日、特色企业等为创作素材，在同一主题、不同表现方法的设计作品中，无不凝结了同学们的设计灵感和智慧。如以“龙华腊肠”、“茶山公仔”、“莞香曲”及“绣荔风情节”等题材的设计作品，都是以东莞传统文化为素材，融合全新的、多元化的数字设计理念，展现出了东莞千年古邑名城所特有的文化。在创作的过程中，许多同学还与杏林春、艾娅衣柜、米薇家屋饰品有限公司等东莞著名特色企业合作，为其设计出形式新颖、具有各企业文化特色的作品，受到企业的好评。

毕业作品展获得师生们和社会人士的好评和肯定，参观者络绎不绝。记者在现场看到了一幅贴有“此画已售”的作品，据作者邓毅强同学介绍，作品展出不久，就有一位社会人士愿出钱买下来。
