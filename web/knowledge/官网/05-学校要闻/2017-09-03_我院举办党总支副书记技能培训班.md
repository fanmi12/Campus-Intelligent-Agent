# 我院举办党总支副书记技能培训班

8月31日，我院学生处在大学生活动中心举办党总支副书记技能培训班。11个院系党总支副书记和学生处、招生就业处、团委等部门相关人员参加本次培训。

章德胜副书记出席活动并讲话。他在开班动员中，对各院系党总支副书记提出四点要求：一是要政治强。各党总支副书记勿忘党员身份，协助党总支书记做好教师、学生党支部建设，积极开展各项活动；二是业务精。副书记要全身心投入学生工作中，同时要动员引导专业教师、辅导员加强学生思想政治教育，共同做好学生工作；三是能干事。在工作中要积累经验，同时要结合时代的发展，主动运用新媒体、新方法来做学生工作，注重方法创新；四是干实事。扎扎实实把事情做好，并且要深入挖掘、不断总结提炼，打造各院系特色校园文化品牌。

党务工作部副部长叶凯贞、人事处副处长李海冬应邀作了专题讲座。

叶凯贞副部长结合自身学习、工作经历，以《副书记如何引领学习型团队建设》为题，分析了《西游记》唐僧团队中各种人员的角色定位，指出一个优秀的团队建设，需要做到团结合作、分工明确、领导示范与利益共享。各院系党总支副书记要做好领头羊的作用，在工作中团结一切力量，为校园文化建设做出更大的贡献。

李海冬副处长以《副书记的工作定位与职业发展》为题，通过对各种文件内容的解读，明确了院系党总支副书记的角色定位和工作内容。通过分享自己从事党总支副书记的工作经历及如何开展学生工作，建议大家在学生工作中，要结合各院系专业，兼顾多个专业需要，注重特色宣传，打造院系学生活动文化品牌。

学生处副处长罗文芳主持了培训活动。
