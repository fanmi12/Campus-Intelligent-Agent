# 城环学子荣获2019年广东省结构设计大赛中三等奖

5月31日-6月2日，由广东省大学生结构设计竞赛委员会、广东省土木建筑学会主办的2019年广东省结构设计大赛在深圳大学举行，共有19所高校的38支队伍参赛。

大赛以搭建山地模型为主题，我校城环学院派出两支队伍参赛。经过3天的模型制作、称重、现场加载，我校两支参赛队伍均获得大赛三等奖。

大学生结构设计大赛旨在培养当代大学生创新思维、创新意识、团队意识和实践能力，加强各院校的交流。
