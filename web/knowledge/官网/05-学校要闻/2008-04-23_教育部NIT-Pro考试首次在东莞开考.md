# 教育部NIT-Pro考试首次在东莞开考

4月18——20日，教育部NIT-Pro考试在东莞市理工学院城市学院举行。这是被教育部考试中心指定我院为NIT-Pro考试考点以来的首次考试。

考试分为主观题和客观题两部分，考试流程严格按照教育部考试中心的要求进行。教育部官员担任巡考，新东方工作人员单人监考。

考场要求十分严格，所有计算机的USB端口都被封死，局域网都被禁掉。

参加本次考试的人数为52人，主要是城市学院计算机与信息科学系2005级软件置换班的学生。据考生反映，这种考试方式十分新颖，模拟了项目开发环境，测试了实际运用能力。
