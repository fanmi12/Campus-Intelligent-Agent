# 我院党校第二十期培训班开课

3月24日，东莞理工学院城市学院院党校第二十期培训班于行政楼112会议室进行，143名入党积极分子参加本次培训。

本次培训班由学院院长、党委书记王卫平同志以“适应新常态，努力培育与践行社会主义核心价值观”为题开讲。课上，王院长引入“习式常态”内容借以告诉积极分子们做人做事既要讲战略，又要讲战术，在追求效率同时也要追求质量，要求大家要在新常态下践行“三严三实”，发扬稳实向上精神。

培训班第二讲，由党委宣传部部长何鹏举同志主讲，带领大家共同学习“论党性修养的元问题”。何部长从“我是谁”和“我为什么”出发，引导大家务必提高个人的党性修养，并回顾入党誓词，从而加强爱国主义情怀，勇于承担责任。

据悉，党校第二十期第二次培训课将于3月31日开讲。
