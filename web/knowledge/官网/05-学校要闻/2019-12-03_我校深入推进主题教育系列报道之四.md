# 我校深入推进主题教育系列报道之四

主题教育有竟时，自我革新无穷期 ——商学院、体育教学部、马克思主义学院奋力推进主题教育冲刺跑2019-12-03发文单位：学校要闻

如今正是第二批“不忘初心、牢记使命”主题教育开展关键期，要跑好主题教育“冲刺”，把住舵、盯住事、抓住人、绷住劲，确保提升主题教育成效。

在学习习近平新时代中国特色社会主义思想和开展“不忘初心、牢记使命”主题教育中，我校商学院、体育教学部、马克思主义学院为提高广大师生的素质教育，进行师生共建政治理论交流平台的创新实践。

为党育人 为国育才

自今年9月下旬以来， 随着“不忘初心、牢记使命”主题教育不断深入，极大地激发了体育教学部全体老师的工作热情，在努力完成繁重的教学任务同时，大力筹办校园运动会，积极参加大学生篮球联赛省大学生三人篮球锦标赛、东莞大学生篮球联赛、广东省大学生跆拳道锦标赛、广东省大学生足球锦标赛、、省大学生乒乓球锦标赛、粤港澳大湾区体育联盟排球赛等各类赛事，并取得了优异的成绩。

我校参赛师生在一系列重要体育竞赛和体育活动中不畏艰难，勇于登攀，顽强拼博，奋斗不止的坚持和一次次精彩的亮相充分展示了城市学院体育人崭新的精神风貌，同时也用他们辛勤的汗水谱写着我校群众性体育活动蓬勃开展以及体育运动训练新的篇章。

体育教学部还组织参加了的“我和我的祖国”摄影展活动，效果良好，老师们用手中的相机和对祖国的爱完成了一幅幅主题鲜明，思想性艺术性都较强的摄影作品。

聚焦实际问题 凸显部门特色

今年9月主题教育启动以来，商学院按照学校的部署认真开展工作，通过创建“党员先锋岗”、师生党员“结对共建”和课程思政建设等举措深入推进主题教育，确保主题教育取得实效。

商学院通过设立“教学、科研、服务、管理”党员先锋岗，让师生党员亮身份、亮职责、亮承诺，以此来提高党员的服务能力、服务效率、服务质量，达到了优化服务、转变作风、群众满意的目标。让每名党员牢记党员第一身份，发挥党员先锋模范带头作用。通过“党员先锋岗”创建工作，激发党员牢固树立“一个党员就是一面旗帜，一个岗位就是一份责任”的意识，引导党员立足岗位作奉献，争先创优当模范，彰显党员的精神风貌，促进党组织和广大党员更好地联系和服务群众，进一步推动商学院各项工作的顺利开展。

商学院积极创新党员培养和管理模式，开展师生党员“结对共建”项目。“结对”的师生党员负责联系一个班级，通过走访班级课堂、学生社区，了解学生学习和生活的情况，为学生解决实际问题。项目开展以来，师生党员每周走进课堂、深入宿舍指导学生学习，关心学生生活，得到了同学们的一致好评，营造了良好的校园氛围，充分体现了我党全心全意为人民服务的宗旨，展示了师生党员的引领和示范作用。

为贯彻落实习近平总书记在全国高校思政教育工作会议和思政教师座谈会上的重要讲话精神，构建具有我校特色的“同向同行”思想政治教育课程体系，11月初，商学院召开“课程思政”建设工作研讨会。会上，商学院认真部署“课程思政”相关工作，要求每个教研室遴选2门专业课作为试点课程，将思政教育融入教育教学全过程，推动实现“三全育人”。

10月底，商学院领导班子带队深入各个教研室和学生工作队伍，以实地走访、听取汇报、座谈交流等方式，开展专题调研，现场办公，对能现场解决的问题马上提出整改措施，梳理汇总问题清单，制定专项整治方案，明确目标任务、责任分工、进度时限。

11月中下旬，为更好地落实我校垃圾分类定点投放工作，提高学生们的环保意识，商学院学生党支部先后开展“垃圾分类知识讲座”、“垃圾分类，从我做起”晨读活动、“党员先锋领风尚，垃圾分类践初心”主题志愿服务等活动。

11月21日，商学院邀请上海交通大学陈宪教授作题为“科技创新与湾区经济发展启示”的讲座，开拓视野、更新理念、提升意识起到重要作用。

商学院通过公众号、官方网站开展主题为“党员先锋系列报道”、“辛勤园丁系列报道”、“学习强国达人亮相”、“学习路上”等系列报道，通过广泛宣传，弘扬正气，展示了党员的良好形象。

商学院党总支为保证各项工作按照既定路线开展，结合了该院师生的特点，找准主题教育的“契合点”，落实支部责任，坚持问题导向扎实开展学习教育。

高举理论旗帜 坚守初心使命

马克思主义学院在学校主题教育启动后，根据上级党组织要求严格开展工作。9月26日迅即召开本院主题教育部署动员会，以专题党课形式明确主题教育的目标、要求、关键与核心，强调要把学习教育、调查研究、检视问题、整改落实四项重点措施贯通起来，坚持把学和做结合起来、把查和改贯通起来，边学边查边改，以学促研、以研促查、以查促改。学院主题教育领导小组发挥带头作用率先学、深入学，多次集中开展习近平总书记重要讲话精神和指示批示精神学习交流。

10月17日，马院党支部集体前往东莞市党建文化主题公园开展革命传统教育。在主题公园浓厚的党建文化氛围中，老师们回首新中国成立70年、中国共产党成立98年来的光辉历程，共同探讨“中国共产党为什么能”等问题，认为根本原因之一就是不忘初心、牢记使命，始终坚持弘扬革命传统、赓续红色基因是重要原因之一，通过现地参观学习，更清醒地认识到作为党员的责任担当，坚定了砥砺奋进的决心。为贯彻主题教育学原著、读原文、悟原理要求，10月21日马院全体老师集体重温马克思主义经典文献《共产党宣言》，通过这一重要纲领性文献感悟共产党人的初心和使命，坚定理想信念。

为筑牢育人阵地，提升党建与思想政治教育实效，马院就课程思政、党的建设“以政治建设为统领”两大课题开展调查研究，以文献研究为基础，结合实地走访、座谈交流等方式，形成专题报告，为学校课程思政建设、加强党的建设提供参考。

马克思主义学院牢牢把握主题教育各项任务，树立问题意识，突出问题导向，采取“解剖麻雀”的方式分类检视问题，分类解决突出问题,不断把主题教育推向深入。针对党员干部自身存在的思想根子问题，坚持以抓具体、抓深入的作风开展主题教育，奔着问题去、盯着问题查、对着问题改，力求过程扎扎实实、效果实实在在。

马克思主义学院在做足主题教育“规定动作”的同时，用心设计自选动作，结合学院实际，力求突出马院特色，力争创新出彩。作为高校意识形态主阵地，树立先行意识，坚持领学领干、学深学透，支部理论学习更扎实，学习内容多而不杂、形式多元，有自学、会议学、专题党课学、研讨式学习等，形成“9+X”理论学习格局。10月下旬组建习近平新时代中国特色社会主义思想理论宣讲团，16位骨干教师备好17个宣讲主题，积极向其他二级学院帮学、送学、促学，在课堂主渠道之外进一步发挥价值引领与传播作用，展示马克思主义理论学科的魅力，通过宣讲服务其他支部的同时，促进自身学深悟透，学用结合强化使命担当。

为了增进实践育人成效，推动以文化人、以文育人，马院会同党务工作部、学工部、团委共同推出思想道德素质大赛，引导学生以书法、动画或海报、摄影方式抒发爱国爱校情怀，商请文传、创设、计信三学院分头专业化承办，要求每位思政课老师深入参与到活动当中，积极鼓励、指导学生参赛，增强教师一切围绕学生、关照学生、服务学生的意识，密切师生关系。

纵观商学院、体育教学部、马克思主义学院自“不忘初心、牢记使命”主题教育开展以来，始终坚持不懈将党的“初心”摆在首位，不断通过抓党建工作促进教师队伍建设，带动学校德育工作，加强校风、教风、学风，以热爱学生、教书育人为核心，努力促进学校各项事业不断地往前发展。
