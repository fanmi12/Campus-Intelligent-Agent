# 口碑效应显现，湖南招生第一志愿高分出档

8月4日，湖南省第三批本科B类开始录取，我院在湖南省招生计划46人，全部第一志愿高于分数线出档，文科最低分：456，高出分数线：3分；理科最低分：395，高出分数线9分。

据悉，截止于8月4日，已有湖南、河北、四川、福建、浙江、湖北、广西完成录取，其他省份还在录取中，整个录取工作将于8月下旬结束。

学生处孔增强副处长介绍，湖南省是我院省外计划投放第一大省，2014年投放计划46个，占外省总计划的15%。学院十分重视这一工作，招生办还派人员参加湖南招生咨询会。根据学生报考情况看来，我院在湖南的口碑很好。
