# 总决赛我们来了！

5月24日晚，2017DUBA半决赛开战，我院男篮客场对战东莞职业技术学院，凭借出色的发挥以87:70力克对手，顺利打进总决赛！

半决赛上，主队先发制人，由6号李想进球率先打开战局。我方19号叶锐城通过抢断，进球得分予以回应。随后，7号黄志陆一记漂亮的3分球更是鼓舞士气，使我方以20:15在第一节领先。

第二节东职队欲赶超比分，19号李冠聪开场连中两球，一度将比分拉近。我方迅速做出调整，加强防守，由7号黄志陆与8号张俊各投出的两记三分球，将比分拉开差距，以44:33再度领先。

易边再战，我院继续保持上半场的火热手感，打出了一波8:0的小高潮。对方叫出暂停做出调整后，收效甚微。第三节结束时，我院以68:48高出20分的优势进入末节。

第4节，东职队重提士气，18号李贤纳与19号李冠聪的上篮，多次造成我方失误。我方做出暂停进行调整后，利用双后卫不断冲击对方防守，19号叶锐城单节坎下12分，再次牢牢掌握比赛节奏。而这时的主队却体力疲惫，进攻乏力，失误连连。最终，我院以87:70晋级决赛，将于广东科技学院队会师巅峰之战。

球员数据方面，我院19号叶锐城发挥出色，拿下全场最高39分。
