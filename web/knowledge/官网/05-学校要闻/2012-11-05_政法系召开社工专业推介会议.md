# 政法系召开社工专业推介会议

10月18日， 政法系召开社会工作专业推介会。系主任刘杰教授，东莞市民政局社会工作科科长郭薇出席会议。盲人社工、我院07届社区管理专业优秀毕业生、东莞市首届公益创投“盲友之家”项目负责社工叶照明以及社工教研室全体教师参加了会议。

会上，郭薇科长从东莞社会工作的发展现状、谈到了东莞社会工作人才的需求信息，鼓励学生坚持自己的选择，做好职业准备。在互动环节，学生踊跃提问，郭薇科长和叶照明师兄以及专业老师一一做出解答。

会后，郭薇科长还和社会工作教研室老师就合作细则进行了交流，并表示将重点支持我院社会工作专业，以培养更多的社会专门人才。
