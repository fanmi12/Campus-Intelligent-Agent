# 政法系学生考研传喜报

汗马耕耘有矢志，硕果飘香又一年。在2017年全国硕士研究生考试中，政法系学子努力拼搏、锐意进取，取得了优异成绩，共有12名学生顺利通过了国家分数线。同时，还有4名同学已获澳门科技大学面试，有望获得继续深造的机会。

据了解，政法系始终狠抓学风建设，重视人才质量培养，把激励学生考研作为学风建设的抓手之一，以带动全系浓郁学风的形成。政法系鼓励学生向更高学术境界攀登，考研上线和录取人数也在逐年攀升。
