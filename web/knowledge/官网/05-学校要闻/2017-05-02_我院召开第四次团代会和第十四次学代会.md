# 我院召开第四次团代会和第十四次学代会

4月23日，共青团东莞理工学院城市学院第四次代表大会暨东莞理工学院城市学院第十四次学生代表大会，在学术报告厅胜利召开。

团市委书记李亚鹏、团市委学校部部长卢雪霞、东莞理工学院团委书记黄金和、广东科技学院团委副书记杨少发、东莞市汽车技术学校团委委员黄桂华等领导应邀出席了会议。

我院院长、党委书记王卫平，党委副书记章德胜，副院长高香林、黄兢，党委委员杜鹏举，院团委书记李瑶，各院系（部）党总支书记、副书记，有关部门负责人等，以及286名学生代表、32名列席学生代表参加了大会。

上午九点，在雄壮的国歌声中，共青团东莞理工学院城市学院第四次代表大会拉开序幕。

团市委书记李亚鹏致辞，对本次大会的胜利召开表示热烈祝贺，对我院共青团的工作给予了高度评价。他希望我院共青团牢牢抓住改革机遇，加快推进学校共青团和学生会的改革发展。

院党委副书记章德胜在讲话中，充分肯定了我院共青团自上一届团代会召开以来取得的成绩，强调团学工作应以思想引领为核心部署工作任务，坚持以“三个坚持”为驱动创新工作方法，期望新任团委委员能够“继团学精神，承团学责任”，立足本职、勤学实干，为我院共青团工作与发展作出贡献。

院团委书记李瑶宣读《2016-2017年度东莞理工学院城市学院团学组织工作先进集体和优秀个人》表彰决定，并进行了表彰。

学生处副处长罗文芳代表共青团东莞理工学院城市学院第三届委员会，向大会作题为《凝聚青年力量，共筑城院战线，为努力推动我院共青团工作的改革发展贡献青春力量》的工作报告。报告强调，团学工作要坚持以思想引领为主线，把握立德树人的根本任务，做好成长服务，助推青年成长成才，夯实团建工作，增强团的覆盖面和凝聚力。报告还结合当前共青团改革发展形势和总体思路，对我院共青团今后工作提出新的要求。

院团委书记李瑶书记宣读了《第三届委员会工作报告的决议》，强调我院共青团改革要以“凝聚青年、服务大局、当好桥梁、从严治团”为基础格局，努力实现我院共青团工作的新跨越，做到在传承中创新，在创新中发扬。

万文双、卢效坚、李瑶、陈秀佳、陈浩华、吴秋华、何健星、何珊珊、郑一诺、黄嘉莹、蔡超明十一人当选为共青团东莞理工学院城市学院第四届委员会委员。随后，召开了第四届一次全体委员会，会议选举出李瑶担任团委书记，陈浩华担任团委副书记、郑一诺担任学生副书记。

当日下午，我院还召开了第十四次学生代表大会。

第十三届院学生会主席孔佩珊代表院学生会，在会上作了《东莞理工学院城市学院第十三届学生会工作报告》。院学生会副主席陈鑫怡作了第十四次学生代表大会提案工作报告，针对学生代表提出的关于饭堂管理、宿舍管理、学院安全、网络管理、教务考勤、卫生后勤等方面的问题给予了答复。

大会听取、审议并通过了《东莞理工学院城市学院学生会章程》（修正案）、《东莞理工学院城市学院第十三届学生会财务报告》。选举梁震星、区叙钰、莫芷晴、王秋爽、刘涛、陈宏钊为第十四届院学生会主席团成员。黄嘉莹（团委委员）当选为学生会主席，梁振星、区叙钰、莫芷晴、王秋爽、刘涛、陈宏钊当选为学生会副主席。聘任王彦娜、孙辉、林蓉三位老师为院学生会副秘书长并颁发聘书。

大会对优秀学生干部干事、优秀部门进行了表彰。
