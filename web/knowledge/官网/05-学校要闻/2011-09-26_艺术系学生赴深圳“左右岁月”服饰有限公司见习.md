# 艺术系学生赴深圳“左右岁月”服饰有限公司见习

9月23日，艺术系10级服装设计专业的同学，在林岩、李秀琴、洪飞老师的带领下前往深圳“左右岁月”服饰有限公司见习。

“左右岁月”服饰有限公司设计总监冯世宏先生热情接待了我院师生，并带领师生参观了公司的展示大厅。冯总监希望同学们要把课堂所学的知识和市场调研结合起来，适时了解消费群体的审美情趣、流行趋势和市场的需求。只有这样，才能设计出完美的服装款式。参观完展示大厅，冯总监又带领师生们观摩版房和机房，让同学们了解服装企业所使用机器的性能、型号以及所使用的制版软件等。

冯总监表示，近几年服装产业发展迅速，对服装设计专业人才的需求大大增加，服装设计专业的就业形势良好，并欢迎同学们来公司实习和就业。

据悉，深圳市“左右岁月”服饰有限公司成立于2007年，隶属惠州新天健服装集团公司，是集设计、生产和营销为一体的现代化时装公司。集团公司从事时装生产、贸易，员工1800多人，年生产能力1100万件，年产值11亿人民币。
