# 大型校园广播剧《我在回忆里等你》阳光网上线

10月19日，广播剧《我在回忆里等你》剧组在东莞广播电视中心会议室举行东莞阳光网上线发布暨表彰大会。城市学院新闻中心的主任何鹏举、东莞广播电视台新闻综合频道总监李斯轩出席了会议。

会上，东莞电视台最受观众喜爱的广播主持人、该剧导演杨希宣布了广播剧《我在回忆里等你》杀青及阳光网正式上线的相关信息。接着，副导演刘哲老师、音乐指导林伟伦老师、演员指导兼女主角臧莹竹老师、文案组王凌卿老师以及各组长分别做工作总结。

东莞广播电视台新闻综合频道总监李斯轩在讲话中，对我院师生在广播剧中所做的工作表示高度的肯定。称赞道，东莞理工学院城市学院参加该剧录制的师生在前期策划、海选演员、文案组稿、音乐制作、节目录制等一系列工作中，表现了“出乎意外的专业水平和职业道德”。会议还为广播剧的征文获奖者、广播剧的突出贡献者分别颁发了表彰证书，在获奖的40名师生中，城市学院占35人。

据悉，广播剧《我在回忆里等你》是东莞高校创制的首部大型校园广播剧，由东莞广播电视台、东莞理工学院与我院师生联手重磅制作。广播剧通过东莞广播调频1008hz首播，覆盖全广东省，并在东莞理工学院广播站、城市学院广播站和莞城校区广播站重播，历时长达一年。
