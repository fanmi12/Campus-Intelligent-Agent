# 中央民族乐团“高雅艺术进校园”广东首站在我校举办

为增强文化自信，坚持以美育人、以文化人，丰富校园文化生活，深化美育教学改革，共同推动中华优秀传统文化传承发展，由教育部、文化和旅游部、财政部主办，广东省教育厅、中央民族乐团和广东高校承办“高雅艺术进校园—中央民族乐团广东行”正式拉开序幕，11月21日晚，首场演出在我校学术

报告厅隆重举行。

学校采取线上线下同步进行，报告厅内座无虚席，两万名师生在线观看，欣赏了一场听觉与视觉共享、艺术与音乐完美结合的宏大盛宴。

学校执行董事陈超群，校长陈明，党委书记章德胜，常务副校长方伟华，副校长刘玉侠、周庆、李海冬，广东医科大学，广州新华学院、广东科技学院、东莞职业技术学院、广东创新科技职业学院等在莞高校，东莞市小坑村委会、寮步电信有限公司等领导和嘉宾出席音乐。东莞知名主持人、语言文化学院郭戈老师主持音乐会。

据了解，中央民族乐团成立于1960年，是文化和旅游部直属的国家级艺术院团。拥有国内外规模最大、民族乐器最完备的民族管弦乐队和全国唯一的职业民族合唱队。

乐团一直致力于弘扬和传承民族音乐文化，积极创作出了许多优秀的音乐作品，为中华传统文化的继承和发扬作出了卓越贡献。他们的演奏和表演水平屡获殊荣，在国内外音乐界中树立了崇高的地位，被誉为“中国第一，世界唯一”的乐团。

今晚登场演出的乐团是中央民族乐团民族合唱队“国风”男声重唱组和“锦瑟”女声重唱组、室内乐“俪人行”乐团与“青衫渡”乐团等。

中央民族乐团民族合唱队是我国唯一一支具有浓郁民族风格的国家级职业民族合唱队。

该合唱队历史悠久、底蕴深厚，曾荣获第六届世界青年联欢节金质奖章和第十三届世界青年联欢节最高荣誉金奖。

中央民族乐团女子室内乐团“俪人行”、男子室内乐团“青衫渡”是乐团近年来举全团之力打造的两个室内乐团，是中央民族乐团致力于推动民族音乐小型化、多样化、创新性发展的重要成果，自成团以来，他们受邀参与了众多国家级活动。

冬奥迎宾、“相约北京”“艺汇丝路”、中亚峰会文艺演出、第三届“一带一路”国际合作高峰论坛《丝路同行》文艺演出等活动中，他们用极具东方色彩的旋律，为外国元首、政府首脑、王室成员、国际组织负责人、驻华使节等展示了中国音色的美丽和魅力，给外宾们留下了深刻印象。

音乐会在“俪人行”与“青衫渡”两大室内乐团共同演奏的《四海欢腾》下拉开帷幕，它那欢快的节奏与悦耳的旋律瞬间就吸引住了在场的观众们。

“青衫渡”乐团演奏的《光明行》

引入了现代音乐元素，旋律铿锵、气势豪迈，尽显阳刚之气、豪迈之风。

“俪人行”乐团代表之作《踏歌》也为我们讲述了

“彩绘散乐浮雕”的故事。

“国风”男声重唱组演唱的男声六重唱《莫妮山》《香巴拉并不遥远》歌声嘹亮、厚重。

在《香巴拉并不遥远》的旋律中透露着深邃而温暖的感觉，仿佛引领着听众远离尘嚣，与灵魂陶醉在香巴拉的梦幻中。而《莫尼山》则以其激昂澎湃的节奏和豪情万丈的歌声，勾勒出雄壮壮美的山脉景色，让人心生向往和震撼。

巾帼不让须眉，“锦瑟”女声重唱组带来了《红颜劫》《一杯美酒》。

《红颜劫》那柔美动人的歌声，纤细的音色，让人仿佛置身于古老而优雅的文化中。《一杯美酒》的演唱和谐共鸣，优雅而动人，展现了酒与情感交融的浪漫氛围，引发了观众们心灵深处的共鸣。

手持古琴，轻抚琴弦。《流水》琴音如泉水流淌，古朴而动人，将观众们带入了一个静谧而美丽的世界。

扬琴、琵琶、古筝三种乐器共同奏响下的《弹词韵》细腻而柔和，仿佛诗人笔下的画面在耳边跳跃，使人心境渐次开放，沉浸在无限的美丽氛围中。

陕北民歌《信天游》在中阮、笛子、鼓的共同奏响下流露出浓厚的黄土高原气息，凸显出陕北大地的豪迈和热情。

全体演奏家带来的混声小合唱《青玉案·元夕》和《从军行》优美而动听，将观众带入古典诗词的世界，让人感受到古代文化的魅力与内涵。

随后，由“俪人行”和“青衫渡”两大室内乐团共同带来的室内乐《敦煌》，将古老而神秘的敦煌文化融入音乐中，给观众带来别样的艺术享受。

最后，在声乐与乐队联袂演唱的《我和我的祖国》，呈现出一幅壮丽而感人的场景。

演唱者们以深情的歌声，表达对祖国的热爱与自豪，在场的每个人都深深被音乐所触动。

“走近大师，感受经典，陶冶情操，提高修养”，此次，中央民族乐团通过高雅艺术进校园这一载体，传递各民族优秀的音乐文化艺术，为城院校园带来了良好的文化氛围，陶冶了师生情操，提高了学生审美和人文素养，加深了大学生对中华优秀传统文化的认识和喜爱，切实增强了大学生民族自豪感和文化自信。
