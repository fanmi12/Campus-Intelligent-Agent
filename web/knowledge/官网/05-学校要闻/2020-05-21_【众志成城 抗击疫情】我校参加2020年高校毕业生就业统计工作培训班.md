# 【众志成城 抗击疫情】我校参加2020年高校毕业生就业统计工作培训班

为提高就业工作人员就业精准统计工作能力，进一步强化高校毕业生就业数据的收集、报送、统计和分析工作，5月20日，广东省教育厅召开2020年高校毕业生就业统计工作培训班，省高等学校毕业生就业指导中心主任陈东海出席会议并讲话。

我校在大学生活动中心6E222会议室设立分会场，就业中心全体人员及各二级学院就业辅导员参加了培训。

省高等学校毕业生就业指导中心陈主任通报了截止目前为止广东省平均就业率，表示今年我省高校毕业生就业形势依然复杂严峻。他指出，各高校需优化网上就业服务，加强毕业生就业统计监测，及时跟进困难毕业生帮扶工作，切实落实“一生一策一导师”政策。

会上还通报了《广东省教育厅关于做好2020年广东省高校毕业生报到证签发和就业信息报送工作的通知》的文件精神。结合就业信息报送工作的具体流程，以院校端和学生端为例，详细介绍就业创业智慧服务平台的具体操作。

培训结束后，就业中心带领就业辅导员集中学习省厅下发的文件，并且通过现场交流互动，分享就业统计工作的先进经验，有针对性地解决就业统计工作中的疑难问题，进一步提升就业队伍的整体素质和业务能力。
