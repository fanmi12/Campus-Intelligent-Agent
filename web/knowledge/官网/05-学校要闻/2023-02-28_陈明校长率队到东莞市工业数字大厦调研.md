# 陈明校长率队到东莞市工业数字大厦调研

恰逢中共中央、国务院《数字中国建设整体布局规划》发布之际，为深入了解数字经济新业态对商科人才的需求，积极探索和拓展商科数字化人才培养的新内涵、新模式、新路径，促进应用型、复合型、创新型人才培养高质量发展，2月28日，东莞城市学院校长陈明，副校长陈葆华率队赴东莞市工业数字大厦调研，校长助理、商学院院长罗卫国，教务处副处长鞠晓红，商学院党总支书记李梦丹、副院长肖文锋、张洪等16人一同前往。

陈明校长率队调研一行合照

东莞市首席信息官协会会长张庆云及秘书长林建乐对我校调研小组一行的到来表示热烈欢迎。大家在协会秘书长林建乐的带领下参观了大厦数字化转型推广中心展厅，并听取了对展厅的筹建思路与定位目标，赋能方法论，及展厅的数字商超、数字医院、标杆企业展示等工作内容的介绍。

陈明校长一行参观展厅

在交流座谈会上。张庆云会长为大家介绍了协会的基本情况，并从数字化部署、策略、现状、需求等方面进行了详细介绍。新道科技广东分公司总经理黄堪敬就多主体协同育人、现代产业学院建设、数字化平台建设等进行了分享。商学院院长罗卫国教授介绍了东莞城市学院的专业设置和商学院应用型商科人才培养模式。

交流座谈会

与会人员就数字化人才培养改革需求，从课程体系开发、学生实习基地建设、教材编写、科研项目合作、教师提升培训、毕业生岗位拓展等方面展开了深度的交流与讨论。

陈葆华副校长谈到，在技术变革和数字化经济的浪潮中，许多企业的实践已超前于高校课堂教学，学院要重新梳理并修订人才培养方案，做到理实合一，培养适应时代发展的数智化新商科人才。

陈葆华副校长

陈明校长表示，东莞市首席信息官协会在数字化技术、管理运营、市场理念、战略部署等方面勇立潮头，其改革创新的精神值得认真学习。学院要在新理论与新实践深度融合方面做出探索，服务于数字经济发展战略，为企业数字化转型提供复合型人才。

陈明校长

据了解，东莞市工业数字大厦由市工信局与松山湖管委会主导建设，由东莞市首席信息官协会与光大We谷共同承建和运营，是东莞市打造数字经济产业创新生态的首个数字化转型汇聚平台。目前，大厦已入驻数字化企业服务商超60家，包含美云智数、阿里云、锱云科技、中望CAD、数码大方等数字化转型优质服务商，涵盖24种以上数字化转型产品，包括研发设计、经营管理、生产制造、售后服务、中台、安全管理、信息基础设施、智慧园区等。
