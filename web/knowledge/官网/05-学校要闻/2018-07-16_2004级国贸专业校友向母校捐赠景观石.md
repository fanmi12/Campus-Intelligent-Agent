# 2004级国贸专业校友向母校捐赠景观石

7月14日上午，我院2004级国贸专业校友景观石捐赠揭幕仪式在5A钟楼门前举行。院办主任、学院校友会秘书长杜鹏举，金贸系主任米双红、党总支书记赵书山、副书记万文双，学院教师代表以及校友代表等出席了仪式。捐赠仪式由校友、2004级国贸同学林玉东主持。

“是母校成就了今天的我们，是母校让我们的人生从此与众不同。”2004级国贸校友代表陆正祥在发言中，表达了对母校的感恩之情。他表示能在毕业10周年之际，重返母校、拜望恩师、参与捐赠，心情十分激动，希望捐赠景观石能够为师弟师妹们树立感恩、团结的意识，增强对母校的荣誉感。

金贸系主任米双红代表学院欢迎大家的到来，并对学院的发展做了介绍。

师生代表们共同为景观石进行揭幕。景观石安置于5A钟楼前，刻有“德慧双修”四个字，寓意着“修德行，修才慧”，寄望城院学子德慧双修。

杜鹏举秘书长带领校友们参观了校史馆，介绍了学院的发展历程和发展成果。他表示，要进一步加强与校友的沟通联络，密切与校友之间的合作，并祝愿校友们取得更辉煌的成绩。

当天下午，50多名2004级国贸校友和杜鹏举、李阳桂、王成军，杨亚娟等老师还举行了师生茶话会。老师们对校友的到来表示热烈欢迎，感谢校友对母校的关注和对老师的惦念，并送上对校友的美好祝愿。校友们分别介绍了自己在这十年中所取得的成绩，分享了各自酸甜苦辣的故事。
