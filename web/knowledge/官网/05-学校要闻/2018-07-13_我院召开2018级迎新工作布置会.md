# 我院召开2018级迎新工作布置会

7月12日下午，学院召开2018级迎新工作布置会。院领导王卫平、章德胜、刘玉侠，相关职能部门负责人、各院系党总支副书记等出席会议。

学生处副处长罗文芳主持了会议，并介绍了今年迎新工作的新变化，即采用“数字迎新”模式。包括绿色通道申请、新生入学教育、财务缴费、在线选择宿舍等迎新工作内容将可在“数字迎新”系统上提前完成，实现迎新数字化管理，迎新过程统筹管理也将更加便捷高效。罗文芳副处长表示，数字迎新系统通过资源整合，将让管理部门工作更加高效，实现由管理转向服务，增强服务意识，提高服务质量，让同学们更加便捷地完成入学手续，增强同学们对学院的认同感。

罗文芳副处长还一步介绍了2018级整体迎新工作分工和迎新系统内容更新安排，并就迎新前期准备工作、总体安排、部门职责等进行了安排和说明。

与会人员就迎新工作有关问题，进行了商讨和分工。

章德胜副书记强调，各职能部门要全力配合迎新工作。他还要求，在迎新系统使用前要对系统进行充分的测试，确保系统的可用性。同时做好后备方案，以防万一。

刘玉侠副院长对后勤管理部门的迎新前、中、后期各项工作做了安排和部署。

王卫平院长在讲话中，要求各部门人员要各司其职、通力协作，确保各项工作顺利完成，让迎新工作为学生和家长留下良好的印象。
