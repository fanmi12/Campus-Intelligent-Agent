# 我院赴深圳大学开展“混合教学模式改革” 专题调研

10月31日下午，高香林副院长率领由教务处处长赵书山，副处长赖忠孝、鞠晓红及工作人员组成的调研学习组，赴深圳大学进行交流学习，以进一步深化我院教学改革，探索混合教学模式改革工作。

深圳大学教务部副主任、教师发展中心主任、慕课办主任孙忠梅主持了交流学习会。双方围绕“在线课程的建设与管理”等工作进行了深入的交流和探讨，并就共享信息达成了共识。

调研学习组还参观了优课联盟在线教育有限公司。优课联盟是由深圳大学牵头创办的在线教育平台，该平台在线课程130门，国内高校使用率名列前茅。调研学习组重点了解了优课在线教育平台的功能、在线课程制作流程等情况。
