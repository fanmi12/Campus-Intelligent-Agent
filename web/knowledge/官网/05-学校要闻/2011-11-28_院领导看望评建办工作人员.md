# 院领导看望评建办工作人员

省专家组对我院评建工作给予了充分的肯定和高度的评价。11月25日，院领导安少华、程发良在相关部门负责人的陪同下，专程来到评建办公室，看望慰问全体工作人员。

学院领导充分肯定了评建办公室的工作和所取得的成绩。安院长说，评建办工作人员在人手少、时间紧、任务重的情况下，出谋献策，精心组织，为学院的迎评促建工作作出了贡献，出色完成评审准备工作，是一支能干事的队伍。他进一步指出，专家组虽然高度赞扬了我院八年办学所取得的成效，但我们的工作并不十全十美，还存在这样或那样的问题。希望评建办根据专家组的意见，综合归类、制定方案，组织相关专业和部门认真整改、继续完善。要进一步提高我院的办学水平，迎接下一步的办学水平评估。
