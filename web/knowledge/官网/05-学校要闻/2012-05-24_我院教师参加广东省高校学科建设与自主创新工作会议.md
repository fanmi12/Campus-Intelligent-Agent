# 我院教师参加广东省高校学科建设与自主创新工作会议

5月22日，广东省政府在华南师范大学（大学城）召开了高校学科建设与自主创新工作会议，省长朱小丹、教育部副部长杜占元、副省长陈云贤、教育厅厅长罗伟其出席了会议，并做重要讲话。各地市的市长、教育局长，省内各高校校长，我院副院长高香林、教务处处长邓成良参加了会议。

本次会议主要是围绕贯彻落实国家全面提高高等教育质量工作会议和省第十一次党代会精神，以加快部署我省高校学科建设与自主创新工作，推动全省高等教育事业发展上新水平为主题，向高校部署学科建设和自主创新工作。省长朱小丹指出：当前和今后一个时期，高等教育要从规模扩张的外延式发展向质量提升内涵式发展转变，建设一流学科，打造创新高地，大力推进我省由高等教育大省向高等教育强省迈进。要优化高等教育结构，创新人才培养模式，加强师资队伍建设，提升科学研究能力，加强文化传承创新，改革高等教育管理体制。要在彰显办学特色优势、教育教学改革、引育高层次人才、协同创新、提升高等教育软实力、加快建设现代大学制度等六个关键环节上取得新突破。
