# 省助学工作管理中心领导莅临我院指导工作

座谈会< 专家组实地查看贷款学生档案

专家组肯定我院学生工作阳光大厅工作5月24日下午，广东省助学工作管理中心卓越副主任率助学贷款管理工作考核小组一行5人莅临我院检查指导工作。院党委副书记朱冰、学生处和财务办相关人员参加了工作情况汇报会。

会上，考核小组听取了我院助学贷款总体工作情况汇报，内容涉及我院助学贷款工作的体制建设、宣传教育、贷款管理、绩效评价、创新研究、信用档案建设6个方面。

在了解我院助学贷款管理工作基本情况之后，考核小组还分别与各系部负责助学贷款管理工作的辅导员和学生代表进行座谈，并实地查看贷款学生档案室，查阅助学贷款的有关文件和资料。

经过座谈和实地考察，考核专家组充分肯定了我院在国家助学贷款工作方面付出的努力和取得的成绩。卓副主任认为，我院的工作机制、考核机制比较完善，把助贷管理工作部门设在学生工作阳光大厅，做到了阳光、公开、透明。他对我院受助贫困生所展现出来的精神面貌赞许有加，认为学生们阳光向上、讲诚信、自强自立，并且有一颗感恩的心。最后，专家组还对我院助学贷款工作如何更好地发挥育人功能、形成一个常态化、制度化的管理机制等方面提出了宝贵的意见和建议。
