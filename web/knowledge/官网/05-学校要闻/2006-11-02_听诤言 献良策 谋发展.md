# 听诤言  献良策  谋发展

10月31日，学院在315会议室召开座谈会，就如何实现工作重心转移、上水平、创特色等问题，听取老教授们的真知灼见。学院领导安少华、朱志德、程发良以及人事处夏勇处长出席会议。

参加座谈会的一些老教授，有的曾见证过学院发展的初始阶段，有的曾经在原单位担任过院、系领导，办学、教学和管理经验丰富，是搞好城市学院的骨干力量。

东莞理工学院副院长、城市学院院长安少华教授代表学院欢迎各位到学院工作，感谢大家在工作上的支持与帮助。安院长还向老教授们通报了学院的发展和建设情况。他说，“五年上水平、创特色”的任务更加艰巨，难度更大，欢迎各位老教授多出主意、想办法，促使学院继续健康发展。

与会人员根据以往的经验，结合城市学院的工作实际，就图书馆和实验室建设、培养青年教师等方面发表了很多很好的意见。有的教授说，科研、教学两个轮子要联动，青年教师一年至少要发表一篇以上的学术论文；对科研成果要进行重奖；课时量计算要科学合理。有的教授建议，学院要请中外重量级的专家学者来校讲学，介绍学术界最新动态；图书馆要造成标志性建筑，馆藏图书量要进一步扩大；要建设一至两个有特色的重点实验室，积极探索厂校联办实验室的路子；尽快改造教学场地，更新教学设施设备。有的教授希望学院加强学生的理想和前途教育，激发他们学好专业理论和知识的热情；引进“双师型”教师，从政策导向上引导青年教师学业务，提高教学水平。
