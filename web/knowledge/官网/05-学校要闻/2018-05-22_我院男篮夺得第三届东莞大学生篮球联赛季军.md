# 我院男篮夺得第三届东莞大学生篮球联赛季军

5月21日晚，备受关注的第三届东莞大学生篮球联赛季军争夺战在我院举行。我院男篮主场对阵广东科技学院队（以下简称“广科队”），以88∶61夺得本届大联赛第三名。

甫一开场，广科队率先夺得球权，13号张启帆拿下第一球。我方球队随即连连发动进攻，打出一波13∶0的小高潮。10号黄明健、19号叶锐城更是在队友的帮助下，连续突破打成2+1。半场结束时，我方以49∶23领先。

易边再战。经过调整的广科队再次开场进球，逐渐找到感觉。我方经过调整，多次外线三分得手，没给对方喘息的机会，以71∶44结束第三节。

末节比赛，我方4号李鹏杰开场跳投三分球。广科队不甘示弱，20号陈志峰、21号杨志杰多次快攻得手。我方攻防交替，不断突破对方内线，保持领先20分+的优势。最终以88∶61夺得第三届东莞大学生篮球联赛季军。

钱丽娜教练接受采访时表示：“对这场比赛我们非常重视，做好了所有的准备工作。老队员在赛场上发挥了他们的优势，在攻防上面都比较重视，而且严格执行了赛前的部署。年轻球员上场也不胆怯，敢打敢拼，新老球员配合得非常好。”
