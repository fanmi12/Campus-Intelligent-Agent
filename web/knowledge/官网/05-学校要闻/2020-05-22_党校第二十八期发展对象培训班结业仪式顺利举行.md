# 党校第二十八期发展对象培训班结业仪式顺利举行

5月21日下午，我校第二十八期发展对象培训班结业仪式在企业微信平台举行。学校党委书记、党校校长章德胜、组织（统战）部副部长卢淑芳及培训班全体学员参加了本次结业仪式。结业仪式由卢淑芳副部长主持。

会上，卢部长介绍了培训班的完成情况。本期党校培训班首次采用网络培训的方式开展，经各二级党组织严格选拔、推荐，共有293名入党发展对象参与，经过为期一个月的培训学习，最终有284名学员通过了党校考核，顺利结业。

章书记宣读了本期优秀学员名单，对通过量化考核指标评选出的27名优秀学员进行了表彰。

卢部长强调，党校培训虽然已经结束，但各位学员仍要持续地进行政治学习，并不断提升自己，将党校的优良学风、严格组织纪律、进取精神带进学习、工作中，以实际行动争取早日加入中国共产党。

会上，全体学员还共同观看了本期参训学员代表的学习心得分享。
