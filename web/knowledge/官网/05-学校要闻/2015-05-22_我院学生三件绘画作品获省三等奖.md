# 我院学生三件绘画作品获省三等奖

广东省教育厅近日公布广东省第四届大学生艺术展演作品评选结果，我院陈晓彤同学的《控制》、罗丽敏同学的《水知道》、李慧雯同学的《欲望》三件荣获广东省第四届大学生艺术展演活动艺术作品类（绘画）“三等奖”。

据悉，广东省第四届大学生艺术展演活动以“我的中国梦”为主题，在全省高校中分别组织开展了艺术表演类、艺术作品类、艺术教育科研论文高校校长书画摄影、“我和大艺展”大学生征文等五大项目的展演活动，我院共选送了7份绘画作品，最终有3件绘画作品获奖。
