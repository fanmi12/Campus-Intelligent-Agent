# 城市与环境科学系赴珠三角地区五高校调研

参观广东工贸职业技术学院的测量及遥感实验室

合影留念

为落实城市学院新校区专业建设与实验室建设规划，城市与环境科学系相关专任教师、实验室人员在系主任肖红飞教授的带领下于6月下旬至7月上旬先后分别赴华南理工大学、华南师范大学、佛山科学技术学院、东莞理工学院以及广东工贸职业技术学院等兄弟院校进行了深入调研。

调研主要以座谈会、参观实验室的方式进行，我院教师与兄弟院校在专业（学科）建设、人才培养方案、实验室建设及实验教学、应用型创新人才培养等方面进行交流学习。

教师们反映，此次调研受益匪浅，不仅开阔了视野，而且在安全工程、资源环境与城乡规划管理两个本科专业的本科教学评估及培养应用型人才方面取得了宝贵经验。
