# 我院一教改项目获省教育厅立项

近日，省教育厅向全省高校发布2008年度广东省高等教育本科教学改革项目立项的情况。据悉，经教育厅严格评审，共确定了65项资助项目、116项非资助项目。其中，我院管理系教师吴运建博士申报的《独立学院创业管理教学课程体系研究与实践》项目顺利入围非资助项目组。

该项目是我院08年院级教育教学改革立项项目课题，也是我院获得的第二项省级教育教学改革课题。项目主要是对我院创业管理班课程体系建设开展研究，对全省高校开展创业教育具有指导意义。
