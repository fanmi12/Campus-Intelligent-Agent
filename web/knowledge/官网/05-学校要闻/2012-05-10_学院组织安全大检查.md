# 学院组织安全大检查

5月8日，学院综合治理办公室组织学生处、总务处、基建办、保卫办、新闻中心等部门负责人进行安全工作大检查。

检查人员严格按照省厅《关于开展突发事件风险隐患排查和整改工作的通知》要求，认真排查安全隐患，对检查中发现的安全隐患提出了初步整改措施。参检人员要求相关单位进一步明确安全职责，强化安全管理，认真整改，切实保障师生安全和财产的安全，维护学院正常的教育教学秩序。
