# 机电系召开2008级迎新大会

9月16日，机电工程系在学院大礼堂召开2008级迎新大会，500多名新生参加了会议。

会上，机电工程系主任黄健求教授对新生的到来表示热烈的欢迎，介绍了机电工程系的基本情况。

机电工程系党总支副书记谢明副教授、副主任孙成访博士向新生提出希望：要求新同学树立正确的人生目标，以正直和诚信的态度对待学习和人生，把握大学生活的分分秒秒，自觉自立，充实自我，学业与健康并重，快乐充实地度过大学美好时光。

新生班主任宋雪晶博士代表全系教师，系学生会主席吴中华同学代表全系学生，祝福新同学在城市学院学业进步，万事如意。
