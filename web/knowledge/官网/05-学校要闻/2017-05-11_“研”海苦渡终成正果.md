# “研”海苦渡终成正果

夏季来临之际，一封来自南华大学的安全工程研究所硕士录取通知书，也为我们带来了陈冠同学一段励志的考研故事。

临渊羡鱼，不如退而结网

将时间的指钟拨回到2016年的3月，大三下学期的陈冠处在规划未来的十字路口上。

就在某天晚上，他像往常一样刷起了朋友圈，突然，手指划到了师兄朱海的微信头像上，一张考研高分成绩单的截图深深吸引了他的目光。放下手机，辗转反侧，心里暗自思忖起来：“高学历对自己总有益处，自己前三年并没有学到太多知识，何不用考研来充实自己？”于是，在师兄的鼓励下，他下定决心考研。

不可三天打鱼两天晒网

登山没有捷径，一步一个脚印。考研也是如此。

为此，陈冠为自己量身定做了“进击周计划”。“暑假以前，我主要复习英语和数学，之后就是政治和专业课。”他解释说，制定周计划，压力没那么大，也更加详细具体，每一次完成一周计划目标更有前进动力。

然而，对于陈冠来说，数学是摆在他面前最大的拦路虎。他深有体会地说：“我先把张羽的高数和李永乐的线性代数教学视频看两三遍。第一遍主要听老师讲解知识点，然后独立去做视频里的例题，接着将自己做的结果和老师讲解的进行对比总结。”同时，他还开启了刷题模式，前前后后做了近2300题，并且把200道错题归纳起来反复研究。他说：“有时心态会‘爆炸’，只能停下来缓冲一下。调整心态后，隔天再战。”

不知不觉，考研进入冲刺的最后2个月。每天十几个小时的学习让他十分疲倦，并且临近毕业，一些琐碎的事情也令人分心。尽管如此，师兄的鼓励、老师和同学的期望、自己前期的努力萦绕在他脑海，于是，他一咬牙，心里想道：“再苦再累，再拼一下就过去了！”

满载而归，梦想将再次远航

今年3月，陈冠以总分291（英语46 政治58 数学71 专业课116）的成绩共超出了该专业国家线31分，被南华大学安全工程专业录取。到今天，当时的兴奋之情仍在，陈冠说道：“十分开心，自己的努力没有白费，也非常感谢一路上陪伴自己的老师、同学、家人们，尤其是朱海师兄和系主任肖红飞教授。”

同时，他建议考研的师弟师妹：一是要目标明确，择好院校；二是多找“研友”和考研成功的师兄师姐联系交流，掌握好应试技巧；三是要调整好心态，遇到困难不放弃，坚持到底。

谈到未来，陈冠表示这两年跟导师学习好专业知识。条件允许的话，考取博士，再上一层楼。
