# 40余项省级“大创”项目通过院内结题评审

5月24日下午，研发处组织召开了2017年省级大学生创新创业训练计划项目结题评审会。学院15位教学工作委员会委员参加了会议，会议由副院长高香林主持。

会上，研发处处长赵书山介绍了今年待结题的省级“大创”项目的基本情况及结题的评审标准，要求各位专家从学生参与度、项目完成度、成果与项目的关联度等多个方面对项目结题材料进行审核评定。经教学工作委员会委员严格把关反复商议，并分组审议、集中投票表决，最终申请结题的53项省级“大创”项目中有45项通过院内评审，8项暂缓通过，另有3项项目终止研究。
