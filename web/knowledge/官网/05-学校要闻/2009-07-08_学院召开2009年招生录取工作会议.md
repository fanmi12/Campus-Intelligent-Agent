# 学院召开2009年招生录取工作会议

7月8日，我院招生工作领导小组在405会议室召开2009年招生录取工作会议，对招生录取工作进行了安排部署，明确了各小组的职责和分工。

会上，院党委副书记、招生工作领导小组副组长朱冰，传达了广东省2009年普通高校招生录取工作动员大会的精神。在省招生录取工作会议上，广东省副省长宋海和教育厅厅长罗伟其对2009年普通高校招生录取工作分别做了重要指示，强调各院校录取工作要按“公平、公正、公开”的原则，实施“阳光工程”，“办人民满意的高考”；要成立由党政一把手领导的招生工作领导小组和建立“阳光招生”录取制度；录取现场要严格管理，非录取工作人员不得进入录取现场干扰录取工作。

朱冰副书记要求，我院参与招生工作人员要认真学习贯彻落实省招生录取工作会议精神，坚持“公平、公正、公开”的原则，严把录取标准，严肃招生纪律，严格执行“阳光工程”，做到“依法行政、依法治招”。
