# 校企联谊谋发展，合作双赢谱新篇——金贸学院与国信证券举行校企合作座谈会

随着我国高等院校教学改革的不断深入，校企合作成为了我国高等教育发展的重要战略之一，校企合作是我国现代高校教学改革、创新和发展的新方向。为进一步加强与企业的合作，在产学合作结合上取得突破并实现学校与用人单位合作共赢，贯彻科教兴国与人才强国战略， 9月15日，东莞城市学院金融与贸易学院与国信证券开展校企合作座谈会，参会人员有国信证券人事部主管麦宇娴、人事部助理钟奕曼、理财顾问陈泽銮，金融与贸易学院院长赖忠孝、副院长侯瑞瑞、党总支副书记万文双。

会上， 国信证券来宾表示，国信证券愿意同东莞城市学院进行深度合作，此次会议是一次全新的开始，在后续发展阶段中会接连召开讲座、招聘会、主题会和宣讲会等一系列活动。

赖忠孝院长提出，希望通过校企合作为社会、为企业培养复合型人才、应用型人才，同时为毕业生提供更多的就业实习机会，更好的为地方经济建设和社会发展实现人才培养目标，提高人才培养的质量，最终实现双方互利共赢。赖院长还提出，双方要紧密联系，积极行动，推进校企合作，落到实处，共同发展，并根据实际情况挂牌，城院实习基地，城院就业基地。院长表示，天道酬勤，汗水凝金，随着校企合作步伐的加快、范围的拓展，校企双方必将带来更多的合作、实现互利与共赢，通力合作，共担重任，再创辉煌。

侯瑞瑞副院长希望校企合作双方能够通过此次合作取得一定的成果转化，得到一举四得的效果。她希望广大成员更加积极作为，在奋斗中彰显担当，在合作中共谋发展，以国家发展和本校教育为己任，努力服务于国家战略需求和学校改革发展，为推进学院建设助力加油，为中华民族伟大复兴和人类文明进步作出新的更大贡献。

万文双书记表示，希望国信证券能够给到实习学生一定的保障，包括实习工资待遇等基础，为将来校企长期合作做铺垫。希望在与企业的深度合作中，找准定位，办出特色，革故鼎新，提升质量，让师生们听到企业的声音，实现企业文化进校园，使我们的学校能培养出更多适应企业需求的高素质劳动者。

双方达成初步校企合作共识，希望能够在近期开展企业宣讲进课堂活动，为将来校企合作打下基础，也希望校企双方精诚合作、共担使命，携手为国家发展和民族复兴作出更大贡献。
