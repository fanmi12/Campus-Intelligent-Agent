# 我校举行2024年学生管理与就业工作会议

为全面贯彻落实立德树人根本任务，进一步规划新学期工作目标和思路，确保各项学生工作有序、高效进行，3月1日下午，我校2024年学生管理与就业工作会议在行政楼112会议室举行。学校常务副校长方伟华，副校长康贤刚，校长助理孔增强，学生部副部长（主持工作）林蓉，学生部副部长、后勤保卫部副部长刘智航，学生部副部长、武装部副部长刘维仝，学生部副部长、团委书记范琪，以及各二级学院院长、党总支书记、副书记，全体辅导员，学生部各科室工作人员在主会场参加会议，全体班主任在线上参会。会议由校长助理孔增强主持。

会议首先由学生部副部长（主持工作）林蓉作2024年学生管理就业工作报告。报告结合推进学校学生工作的高质量发展目标，围绕学工队伍建设、就业网格化管理、一站式学生社区建设、共青团品牌建设、国防教育与大学生征兵等做出新学期工作部署。报告指出，2024年学生工作要把握新形势、新任务和新要求，回顾总结成功经验，大胆突破创新，笃定实干，砥砺前行，为学校高质量发展做出新的贡献。

学生管理与就业工作责任书签署仪式也在会上举行，由副校长康贤刚分别与各二级学院院长签署就业工作责任书，与各二级学院党总支书记学生管理工作责任书。此次工作责任书的签订，进一步明确了各学院学生工作职责，形成了“统一领导、齐抓共管、各尽其责”的工作局面，为全面开启新学期学生工作发展新征程压实任务、传导责任，为学生工作目标任务的顺利完成奠定了基础。

随后，商学院党总支书记李梦丹、人工智能学院党总支书记唐洁分别进行就业工作和学生管理工作经验分享。

副校长康贤刚发表总结讲话。他指出，要紧紧围绕学校学生工作的高质量发展目标，进一步做好学生管理与服务工作。一是要健全机制，齐抓共管。各二级学院要明确职责，统一思想，凝心聚力，整合资源，汇聚力量，形成合力，对本学院全体学生的思想政治教育和日常管理全面负责，共同做好学生管理与就业工作。二是要深入学生，精准思政。进一步落实班级责任田制度，真正把育人工作做深、做实、做细，做出实效、做成品牌特色，共同促进学生工作高质量发展。三是要忠诚事业，以生为本。高校思想政治工作关系着培养什么样的人、如何培养人以及为谁培养人这个根本问题，全体学工人应当立足于立德树人这一中心环节，牢牢抓住全面提高人才培养能力这个核心点，时刻坚持以生为本，时刻关注大学生全面发展，时刻关注每一位学生个体成长。

会议最后，常务副校长方伟华对全体学工人作出重要指示。他强调，新学期伊始，全体学工人员要迅速投入工作，树牢以学生为中心的工作理念，严守安全稳定底线；学生部和各二级学院要强化工作压力传导和责任落实；学生工作一定要下沉，积极实践学工人“进课堂、进教室、进宿舍”，密切关注学生动态及需求，做到管理有水平，服务有温度，安全有保障。

此次会议进一步明确了新学期学生工作的重点思路和目标任务，切实提升了我校学工队伍的凝聚力和执行力，为新学期深入推进学校高质量发展奠定良好基础。与会人员纷纷表示，将以本次会议为契机，以更加饱满的热情、更加务实的作风，为实现我校学生工作高质量发展努力奋斗！
