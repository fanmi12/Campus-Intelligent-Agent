# 高职部赴广东轻工职业技术学院学习取经

4月22日，高职部组织全体教师，由书记黄研晖和副主任谢俊率队，前往广东轻工职业技术学院电子通信工程系考察学习。

考察团受到广东轻工教务处主任廖俊杰教授和电子通信工程系秦文胜主任的热情接待。双方就高职教育的形势和发展方向交换了意见。秦文胜主任介绍了院、系的总体概况、通信工程监理专业的教学模式以及企业直接参与到学院的招生、专业建设、教学实习、学生管理、毕业分配全过程，设立奖学金支持学科建设的作法。据悉，该院通信工程监理专业的教学模式，适用了市场对工程监理人才的需求，采取全额订单式校企合作培养模式，使学生真正意义上做到了顶岗实训和实习，毕业后直接到企业就业，是高职教育的成功范例。

黄书记和谢副主任表示，广东轻工职业技术学院是国内职业教育的先进单位，很多经验值得我们借鉴与学习，希望通过向兄弟院系的学习与交流，能逐步形成具有我们城市学院自身特色的培养模式。全体教师们表示，通过学习参观加深了对高职办学思想、教育理念的理解，为今后的实验室建设、专业建设、学生管理等工作找到了学习榜样。

会后，高职部老师参观了广东轻工职业技术学院广州校本部和南海校区的实习工厂和实验室。
