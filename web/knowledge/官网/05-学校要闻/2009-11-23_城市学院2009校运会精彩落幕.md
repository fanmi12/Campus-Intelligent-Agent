# 城市学院2009校运会精彩落幕

为期2天的2009年校运会在频频捷报声中落下帷幕。据总裁判长、体育教学部主任赵涛副教授介绍，本届运动会的竞技水平和比赛成绩优于历届，并有7名同学分别刷新了我院5项田径竞赛项目的记录。20日下午，学院在田径场隆重举行了闭幕式，为运动会的精彩落幕表示庆贺，为优秀运动员庆捷颁奖。

东莞理工学院副校长、城市学院院长安少华，学院领导班子成员朱志德、程发良、朱冰、张林，院督学陈丁堂及中层主要负责人出席了闭幕式，并为团体总分前三名和获得“体育道德风尚奖”的代表队颁发奖杯和锦旗。

两天来，运动员们秉承“更高、更快、更强”的奥运精神，以最佳的竞技状态参与比赛，挑战自我，挑战校运会记录，赛出了成绩，赛出了水平，赛出了风格，充分展示了城院学子努力拼搏、追求一流的时代风采。据了解，共有7人次打破了5项校运会记录，分别是男子组110米栏政法系的叶志龙和金贸系的观水根；女子组跳远金贸系的黄宝诗；女子200米文传系的卢锡玲；男子3000米政法系的陈景光；男子组三级跳远金贸系的观水根和陈集成。

据悉，金融与贸易系代表队获得学生组团体总分第一名，管理系代表队和高职部代表队分获第二、三名。教工组团体前三名分别是机关二和后勤工会代表队、机关三和保卫代表队、教辅工会代表队。管理系代表队和财经系代表队分别获得学生组“体育道德风尚奖”，后勤工会代表队和文艺代表队（文传系与艺术系）分别获得教工组“体育道德风尚奖”。

闭幕式结束后，各代表队的运动员披着落日的霞光，带着胜利的喜悦，高举队旗沿操场巡游狂欢。
