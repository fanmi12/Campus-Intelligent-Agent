# 我院获广东省高校党课课件比赛三等奖

近日，广东省高校党课课件和基层党组织活动创新案例评选结果公布，我院艺术系党家立老师制作的《红歌话党史》荣获赛三等奖。

据悉，本次活动由省委教育工委主办，全省各高校共报送党课课件173个，基层党组织活动创新案例77个。

由广东省教育工委组织的此次党课课件评比活动，旨在更好地加强大学生理想信念教育，坚定中国特色社会主义道路自信、理论自信、制度自信，引导大学生增强责任感使命感树立社会主义核心价值观。
