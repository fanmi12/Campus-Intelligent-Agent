# 青年教师暑期社会实践活动报道系列之二

为进一步使教职工认识东莞、了解东莞、服务东莞，东莞理工学院城市学院于今年暑假期间，组织全院一百多名青年教职工走出校园，走进企业单位，进行为期两周的暑期社会实践，让青年教师亲身感受东莞经济社会高速发展的脉搏，在社会实践中学习充电、完善自己，提高素质，从而更好地肩负起教书育人的重任。

我院此次青年教师暑期社会实践活动，受到《东莞日报》等媒体的争相报道。8月1日，各报都在头版或者重要版面的显著位置、并配发超常规的大幅照片进行了报道。《东莞日报》用半个版面的篇幅和图片，对我院在企业、事业单位等进行社会实践的青年教师暑期社会实践活动进行了报道，特别吸引读者的眼球，使“城市学院青年教师暑期社会实践、了解东莞、认识东莞、服务东莞”这一新闻事件在社会和学院师生中产生了良好的舆论效果。

据媒体报道，我院组织青年教师进行暑期社会实践的做法，有利于青年教师融入东莞社会，更好地利用自身的理论知识，为东莞推进经济社会“双转型”献计出力。
