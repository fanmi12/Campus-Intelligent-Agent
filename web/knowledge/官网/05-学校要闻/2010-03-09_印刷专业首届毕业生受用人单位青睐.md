# 印刷专业首届毕业生受用人单位青睐

印刷专业学生在彩桥公司实习（资料图片）

机电工程系印刷专业首届毕业生就业形势喜人。

07印刷技术专业学生于去年进入华厦集团彩桥印刷纸品有限公司实习，经过一个学期的实践锻炼，专业知识和技能水平得到了提高，具备了较好的专业技术素质，受到用人单位的青睐。据悉，该专业首批23名毕业生，已有19名同学找到满意的对口单位，提前参加了工作（其中另有4名同学准备参加专插本考试）。
