# 我院2012届服装设计专业毕业作品发布会于昨成功举行

6月7日晚，我院2012届艺术系服装设计专业毕业作品发布会于在学院大礼堂举行。院党委书记朱志德、副书记朱冰、副院长张林出席发布会。

本次作品发布会以“沸点”为主题，分三节展示。在为时两个小时的作品展示中，观众们掌声不断，喝彩声也络绎不绝。

据悉，最受观众好评的还是由吴倩莹同学设计的《小天使的嫁衣》以及张艺仪同学的《童趣》。

《小天使的嫁衣》的设计灵感来源于天使的传说，设计者吴倩莹希望穿着天使嫁衣的孩子们是人间最美丽的小天使，《童趣》则集中展示了童装活泼的一面。两份作品均以童真为主题，并由孩子来担任模特。孩子的纯真与活泼将作品要表达的内涵演绎得恰到好处，博得观众一片喝彩声和掌声。台下的观众纷纷举起手中的手机、相机不停地拍摄。一位老师一边笑一边对身边的同事道：“好萌，好可爱。”另外，充满浓郁民族风的《飘--飖》、《怡湘绣》也颇受观众好评。

09级服装设计专业的班主任兼指导老师林岩老师告诉记者，这些毕业作品是学生们从上学期着手准备的，他们花费了很多的心血。艺术系的主任邓星明教授也说道：“服装设计专业的同学平时很低调，但他们不鸣则已、一鸣惊人，他们每次都给我带来震撼。这些服装都是同学们自己设计并制作的，其中有的是一针一线缝出来的。这让我很感动。”同样感动的还有艺术系的胡家方老师，她说：“他们都很棒，服装设计很棒，做模特的同学也很棒，我很感动。”
