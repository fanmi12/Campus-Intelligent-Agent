# 我校举行2019年毕业典礼暨学士学位授予仪式

6月21日，我校在综合馆隆重举行2019年毕业典礼暨学士学位授予仪式。

在主席台前排就座的领导有：东莞理工学院党委副书记、城市学院董事吕琦元，广东鸿发投资集团有限公司副总裁、城市学院董事黎建烨，广东鸿发教育文化集团有限公司总经理、城市学院董事长代表陈超群，城市学院校长王卫平、党委书记章德胜，副校长高香林、黄兢、周庆、刘玉侠，校长助理林江龙。各二级学院领导，各单位负责人，以及毕业生班主任、教师代表、毕业生家长代表和全体毕业生共聚一堂，共同见证5434名学子毕业的荣耀时刻，分享开启新征程的喜悦。

毕业典礼由副校长高香林主持。

在庄严的国歌声中，毕业典礼拉开了帷幕。

王卫平校长代表学校向2019届毕业生代表颁发了毕业证书。

章德胜书记宣读了《关于表彰2019届优秀毕业生的决定》及《关于授予蹇铭会等54名毕业生“立志奖”的决定》。

杜雪雯等266名同学被授予“2019届优秀毕业生”荣誉称号。蹇铭会等54位同学被授予“立志奖”。吕琦元副书记、陈超群总经理分别向受到表彰的同学颁发了荣誉证书。

毕业生代表、金贸学院2015级陈虹同学发言，她说：“今天，我们的未来将从城院启航，驶向希望。过去这些幸福的回忆是我们通往幸福未来的起点，指引着我们朝着各自的梦想前进。”

毕业生代表、文传学院2015级张梓晴同学发言表示，大学四年明白了何为青春、何为拼搏，何为有为青年。她说：“明天我们将站在一个新的起点，继续追梦四方，始终向阳生长！”

校友代表、2008届金贸学院学子林玉东在发言中，回顾了自己的工作历程和经验，寄语师弟师妹们：“道虽近，不行不至；事虽小，不做不成。不要嫌弃行业好不好，任何工作都能创造出超人的成绩。珍惜每一份工作，每一份岗位。”

校友代表、2016届文传学院学子丁乐石说：“希望大家认识到这个世界正在以指数级发展，要以积极乐观的心态来接纳这个世界的变化……只有打开眼界，敞开胸怀，最终才会成为你们立足于自己人生最重要的底气”。

教师代表、金贸学院张超老师深情寄语：“请你记得要坚持学习，加强锻炼，不断充实自己，学以致用，把握细节。在新的岗位上，踏实工作、发挥特长、锲而不舍、敢于创新；勇于担当、学会包容、懂得感恩、以诚待人。”

教师代表、商学院肖文锋老师分享感悟：一要虚心学习，二要学会做人。他希望毕业生谨记母校“学而知不足”的校训,关心、支持母校的建设,做一个有梦想、有激情、有责任感的人。

黎建烨董事代表董事会和麦照容董事长向毕业生表示衷心的祝贺！“逐梦新时代，同学们将成为美好生活的奋斗者、社会变革的参与者、民族复兴的见证者。希望同学们志存高远、坚定理想信念；脚踏实地，艰苦奋斗；开拓创新，不忘城院精神，谋大格局、立大志向、干大事业!”

王卫平校长在致词中，寄语同学们：“新时代呼唤奋斗，奋斗成就幸福和梦想。”他说：“与你相识，三生有幸。无论时光如何改变，让真诚永远!无论世事如何变迁，让善良永远!无论眼前还是天边，让美好永远!无论距离近还是远，让朋友永远！”“希望大家别忘了读万卷书不放手，唯有不断读书学习，不断总结反思，才有提升！”

在学位授予仪式上，2019届毕业生们身披学位袍，逐个登台。王卫平校长等领导为全体毕业生一一进行正冠拔穗，并合影留念。
