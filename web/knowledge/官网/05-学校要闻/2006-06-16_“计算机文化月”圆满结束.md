# “计算机文化月”圆满结束

我院团委主办、计算机与信息科学系承办的“计算机文化月”活动圆满结束，6月11日，该系在学院活动中心举行颁奖晚会。院学生处处长章德胜副教授、计算机与信息科学系主任牛熠博士、院团委副书记杜鹏举老师出席了颁奖晚会。

经过专业老师对获奖作品的评定，黄敬全、黄沛明、霍志广三位同学分别获得“Flash大赛”、“摄影大赛”、“网页设计大赛”一等奖。颁奖晚会进行了电脑知识有奖问答，专业教师对获奖作品进行了点评。

据悉，此次“计算机文化月”系列活动历时两个月，内容有“网页设计大赛”、 “Flash大赛”、“摄影大赛”、“CS大赛”四个项目，其中前两项是计算机与信息科学系的传统项目。
