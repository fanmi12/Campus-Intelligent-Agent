# 教育部杨贵仁司长视察我院

安少华院长向杨贵仁司长（图左三）介绍我院近几年来建设发展情况

杨敏林副院长向杨司长汇报新校区规划及建设进展情况7月25日，教育部体育卫生与艺术教育司司长杨贵仁一行视察我院。

安少华院长向杨司长介绍了我院近几年来建设发展情况。他说，城市学院坚持“依托母体保质量，面向市场谋创新，服务东莞求支持，追求卓越创品牌，科学发展作贡献”的办学指导思想，紧紧依托理工学院，服务地方经济社会发展，内强质量，外树形象，得到了东莞老百姓和各级政府的好评，从创办时招生几百人发展到了万人规模，并自筹经费新建了图书信息科技大楼。如今，广东鸿发集团投资近20亿元在松山湖大道旁建设了城市学院新校区，为城市学院发展提供了新的动力和空间。

随后，在安少华、黎建烨、朱志德、杨敏林、张林等城市学院领导的陪同下，杨司长一行参观了新校区。杨敏林副院长向杨司长汇报了新校区规划及建设进展情况。黎建烨董事就鸿发集团体育项目建设、功能拓展等问题向杨司长求教。杨司长指出：“鸿发集团体育项目的建设，关键是基础设施和名教练，要引进有特长的体育健将，以名教练带动项目发展，并根据实际情况，与国际接轨，发展竞技类的项目，以竞赛推动项目发展。从中学到大学一条龙培养，依托城市学院高等学院打造体育品牌。”

视察完后，杨贵仁司长称赞学院在软硬件方面所取得的成绩，并对学院实现新的发展，建设新校区表示赞赏。
