# 我院对2014级新生心理委员进行技能培训

11月13日,我院心理健康教育与咨询中心对14级新生心理委员进行技能培训。心理中心专职咨询师余琼、陈浩两位老师就“如何做一个称职的心理委员”这一主题做了辅导报告。

陈浩老师指出，心理委员要及时了解本班同学的心理情况并及时上报有关部门。余琼老师在报告中要求心理委员讨论为什么要当心理委员、心理委员的职责是什么等问题，同时她还重点解读了心理委员工作月报表的填写方式。最后，余琼老师与心理委员共同分享了四句话，即：“把自己当成别人，把别人当成自己，把别人当成别人，把自己当成自己”。

本次培训旨在指导心理委员如何提高工作能力，成为一名优秀的心理委员，充分调动他们的积极性，协助学院开展学生心理辅导工作，及时掌握学生的心理健康情况，进而提高学生的心理健康水平。
