# 我院党政机关干部参观全国检察机关惩治和预防渎职侵权犯罪图片展览

5月19日，学院领导朱志德、程发良、朱冰及部分机关处室负责人，赴东莞市图书馆参观“法制与责任——全国检察机关惩治和预防渎职侵权犯罪图片展览”。

一幅幅图片，一个个案例，一组组数据，深刻地揭示了渎职侵权犯罪的严重危害性和恪尽职守、廉洁自律的重要意义，使参观人员深受教育。朱书记指出，此次展览主题鲜明，内容丰富，具有很强的警示作用。我院机关工作人员要通过参观，加强对预防和惩治渎职侵权犯罪法律法规的学习，增强法制意识和责任意识，牢记全心全意为师生服务的宗旨，恪尽职守，做到依法履职，勤政廉政，并不断提高依法行政的能力和水平。

据悉，此次展览由最高人民检察院主办，东莞市人民检察院承办，也是第一次以惩治和预防渎职侵权犯罪为专题的全国性展览。展览共分“宗旨?使命”、“犯罪?危害”、“惩治?成效”、“警示?启迪”、“预防?治本”、“建设?发展”6个专题展区，图文并茂，全面系统地宣传了党和国家关于惩治和预防渎职侵权犯罪的方针、政策、法律法规，集中展示了检察机关反渎职侵权工作的重要举措。
