# 【征战2017DUBA】我院男篮首战告捷

第二届东莞大学生篮球联赛（DUBA），“战火”重燃！

4月19日下午，我院男篮坐镇主场，首战迎战广东亚视演艺职业学院

（以下简称：亚视学院）。凭借强大的整体实力，我院以86∶34的巨大优势胜出，取得第二届DUBA的开门红。院长、书记王卫平，体育教学部主任邢红林亲临现场观战助威。

一声哨响，亚视学院先发制人，由5号李颖建中投获得全场首分。我方迅速做出回应，球员们冲击禁区，赢得罚球，并在外线寻找机会取得进球。而亚视学院也不甘示弱，多名球员打出“2+1”比分。

第二节，我方加快了比赛节奏，打出一波8∶0的小高潮。亚视学院请求暂停换人改变战术，连取4分。但我院依旧攻势如潮，多次快攻得手，尤其5号黄荣斌手感滚烫，连突带投单节砍下11分，以46∶22的绝对优势结束上半场。

中场休息期间，我院啦啦队为观众带来了精彩纷呈的表演，获得了现场的阵阵欢呼，点燃了赛场氛围。

易边再战，落后方亚视学院通过防守拼抢加快比赛节奏，由6号林俊威和16号马兴松发起进攻。我方5号黄荣斌依旧保持火热手感，凭借身高优势通过内线强打造成杀伤。团队犯规的困境加上体力上的劣势，亚视学院频频失误。

第四节，我方采取外线组织攻式， 19号叶锐城、10号黄明健以及23号肖晓锋的出色表现串联起进攻。客队方面，12号林柏松与4号吴俊锋凭借中投予以回应，只可惜为时已晚，最终我院以86:34高出52分的绝对优势总结赛事。

球员数据方面，我方5号黄荣斌发挥出色，打出全场最高23分和9篮板。（文/刘润涛 罗飞依 朱凯朗 肖泽鑫 图/王湘玲 刘悦童）
