# 我院在全国大学生智能建筑工程实践技能竞赛获佳绩

11月10日-12日，第九届“亚龙杯”全国大学生智能建筑工程实践技能竞赛在江苏盐城工学院举行。我院建筑电气与智能化专业冯晓璐、黄燕佳、朱泽林、谢伟彬、李曦、赖梓文同学(指导老师：陈振伟、李洪超、贺婉如)荣获大赛团体三等奖，冯晓璐、黄燕佳同学分别荣获个人建筑电气设计一等奖。

全国大学生智能建筑工程实践技能大赛是由高等学校建筑电气与智能化学科专业指导委员会主办，竞赛分为实践技能竞赛与建筑电气设计竞赛两项，全面考查选手的实践能力和创新能力,吸引了全国40所高校参赛。
