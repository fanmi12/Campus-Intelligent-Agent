# 院领导看望慰问春节值班人员

2月3日（农历正月初一），上午9：30，院长安少华、党委书记朱志德、副院长张林、院办副主任黄研辉等一行，在学院后勤、保卫相关负责人的陪同下，先后来到校门卫室、实验中心、配电房、教工餐厅、学生公寓等学校部门值班室，看望慰问节日期间值班的教职员工。领导们每到一处，都与值班人员亲切交谈，询问他们的生活和工作情况，并给大家派发了新年利是，送上了新年的第一声祝福。
