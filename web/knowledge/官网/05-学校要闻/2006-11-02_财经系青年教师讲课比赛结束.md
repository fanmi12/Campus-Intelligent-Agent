# 财经系青年教师讲课比赛结束

10月29日，财经系青年教师讲课比赛结束。共有14位青年老师参加比赛，比赛采取抽签排序、专家现场打分的方式进行。

比赛结果，张灿灿和鞠成晓老师荣获一等奖，并被推荐参加全院的青年教师讲课比赛。肖珊、郑阿泰老师荣获二等奖，朱莹、胡志萍、杨亚娟老师荣获三等奖。比赛结束后，举行了颁奖仪式。
