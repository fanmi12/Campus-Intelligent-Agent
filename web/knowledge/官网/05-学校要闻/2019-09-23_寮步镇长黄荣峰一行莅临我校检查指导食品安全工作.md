# 寮步镇长黄荣峰一行莅临我校检查指导食品安全工作

9月22日上午，寮步镇长黄荣峰率领镇市场监管局、寮步镇教育局一行莅临我校食堂检查指导食品安全工作。后勤保卫处处长王锦锋、饮食服务中心主任李山河等陪同检查。

黄荣峰镇长一行重点查看了学校食堂、后厨、仓库等食品安全重地的食品安全情况，针对我校食品留样、三防措施、餐具存放、后厨卫生、仓库安全管理等进行了详细查看,并提出了安全防患的意见和建议。王锦锋处长记录了相关意见，表示将按照食品安全管理条例的要求认真整改落实到位，不断提升我校食品安全工作。
