# 学院召开学生代表座谈会

6月26日，我院在4号楼315会议室召开学生代表座谈会，听取学生关于学习、生活、思想等方面的意见和建议。出席座谈会的有学术副院长程发良教授，教务处处长邓成良教授、总务处处长翟耀明、实验中心主任李奇副教授、院办副主任黄研晖、院团委书记丘永辉老师，以及各系30余名学生代表。

会议由教务处处长邓成良教授主持。座谈会上，同学们积极发言，气氛热烈，发言内容涉及学院的课程设置、课程选修的方式方法、宿舍的后勤保障、校园网络建设、课室的硬件配置等问题。程发良副院长和各部门负责人对代表们提出的意见进行了解答，表示将进一步努力，使学院各项工作和谐有序更快更好地开展。
