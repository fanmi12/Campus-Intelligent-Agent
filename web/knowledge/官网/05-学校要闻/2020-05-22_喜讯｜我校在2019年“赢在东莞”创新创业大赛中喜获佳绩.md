# 喜讯｜我校在2019年“赢在东莞”创新创业大赛中喜获佳绩

历时7个月的2019年“赢在东莞”东莞科技创新创业大赛暨第二届粤港澳大湾区青年创新创业大赛学生组决赛于5月11日落下帷幕，比赛吸引了市内外优质参赛项目2469个，累计奖励项目443个，累计奖金金额9757元。据不完全统计，累计获得创业投资近20.13亿元。

我校各级领导高度重视，遴选多个优质项目参赛，其中来自金融与贸易学院的大学生创业团队袋番薯校园购在竞争中脱颖而出，代表学校与多个知名高校创业团队同台竞技，通过艰辛努力，在比赛中荣获大学生组三等奖荣誉称号。

本次比赛对我校大学生创新创业教育是一次检阅，今后我校将继续加强创新创业教育力度，不断丰富教学方法，多渠道、多形式开展大学生创新创业教育和大学生创业实践活动，以赛促学，注重典型引领，做好保障工作，形成全校齐抓创新创业工作的强大合力。
