# 西南政法大学博导李龙教授来我院讲学

10月23日，西南政法大学博士生导师、民事诉讼法学专家李龙教授应邀来我院政法系做“民事诉讼法修改之解读”的专题讲座。讲座由政法系主任、党总支书记刘杰教授主持，法学教研室老师、法学专业2010—2012级部分同学共计300余人参加听讲课。

李龙教授从民事诉讼法修改的历史背景出发，对民事诉讼法新增加的、修改的、删除的相关制度作了全面的介绍、剖析，重点对修改民事诉讼法的“三个理念”和新增的“六种制度”进行了系统、深入浅出的阐释。

同学们反映，李教授的演讲内容富含哲理、启迪智慧，演讲风格幽默、诙谐、风趣，是一次高水平的法学学术盛宴。
