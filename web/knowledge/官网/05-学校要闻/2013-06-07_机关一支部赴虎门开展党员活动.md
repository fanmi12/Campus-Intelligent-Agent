# 机关一支部赴虎门开展党员活动

为庆祝建党92周年，进一步增强党组织的凝聚力，加深了对东莞历史的了解，6月6日，机关一支部组织党员赴虎门镇参观海战博物馆与林则徐纪念馆。

本次党员活动中，同志们参观了鸦片战争海战陈列室、虎门海战半景画馆和硝烟池等，深刻感受到了我国军民在虎门销烟、英勇抵抗英帝国主义战争中表现出来的崇高民族气节和英雄气概，真切的理解了“弱国无外交”，“落后就要挨打”。在场的党员纷纷表示将以更大的热情搞好本职工作，不断提升服务学院教育教学工作水平和服务东莞的能力。
