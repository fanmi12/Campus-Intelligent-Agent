# 叶凯贞、陈晓萍老师参加广东省普通高校第五十期思想政治教育骨干高级研修班

10月30日-11月4日，财经系党总支书记叶凯贞和学生处思政科科长陈晓萍参加广东省普通高校第五十期思想政治教育骨干高级培训班学习。

本次培训，特邀了香港高校学生事务管理专家、学者为培训班做有关高校学生事务管理的理念、模式，高校学生事务管理者的职业伦理，香港高校学生事务管理的事务及绩效评估，香港高校书院制及其核心要义等方面的专题讲座。两位老师在几天的培训中，分享学习了兄弟院校同行们的成功经验，学习了好的作法，拓宽了视野。
