# 学院召开会议表彰优秀保卫人员

9月15日下午，城市学院安全保卫工作总结、动员、表彰大会在410会议室召开。院党委副书记朱冰和总务处副处长周林冲参加了会议。

会上，院保卫办主任王现府对第七届大运会期间的安保工作进行了总结，并布置了新生入学报到期间保卫办的各项工作任务。

院党委副书记朱冰对保卫人员为学校所作出的努力给予了充分的肯定，代表学院对他们表示感谢，希望大家能为学院作出更大贡献。她同时表示，本学期全院学生将达到7000人，安保工作的压力更大，责任更重，希望保卫人员统一认识，优化配置，合理调度，做好学院的安保工作。

学院还对优秀保卫人员给予了表彰和奖励。
