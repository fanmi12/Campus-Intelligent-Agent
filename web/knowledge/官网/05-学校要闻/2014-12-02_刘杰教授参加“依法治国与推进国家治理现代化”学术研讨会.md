# 刘杰教授参加“依法治国与推进国家治理现代化”学术研讨会

为落实党的“十八届四中全会”精神，深圳市委于2014年11月29—30日在深圳市五洲宾馆举行了“依法治国与推进国家治理现代化”的学术研讨会。京、津、沪、港、穗等地一批法治理论与国家治理研究知名专家汇集鹏城，我院政法系主任刘杰教授以论文作者的身份与会。中国社科院李步云、香港科大丁学良、中国政法大学郭世佑、中央党校辛鸣等著名学者就“依法治国”与“国家治理现代化”作了大会主旨发言，与会代表对“依法治国、执政党的依法执政、法治政府、法治与文明、法治与改革、国家治理体系和治理能力现代化、社会治理与政社分开、公民社会”等问题以分组和“圆桌论坛”方式进行了交流与探讨。
