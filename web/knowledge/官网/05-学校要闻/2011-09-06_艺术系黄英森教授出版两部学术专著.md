# 艺术系黄英森教授出版两部学术专著

日前，我校院黄英森教授的两本学术专著《歌曲创作新思维》和《歌曲修改范例剖析》，已由中国戏剧出版社出版发行（2011年7月第1版）。

《歌曲创作新思维》150千字，该书从歌曲的主题创作、歌曲中的结对成双规律与逢三而变规律、歌曲的结构、二部歌曲写作等方面进行了阐述。其中关于歌曲中的结对成双规律与逢三而变规律问题，在同类书中暂未发现与论述。

《歌曲修改范例剖析》作为《歌曲创作新思维》姐妹篇出版，全书分三章，对46个谱例进行修改并加以点评，此书不但对修改提炼作品有较大的帮助，对歌曲创作技法也有强化作用。

据悉，《歌曲创作新思维》已做为艺术系音乐表演学生本学期的教材。
