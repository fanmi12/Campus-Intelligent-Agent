# 刘树基应邀为我院师生作形势报告

5月15日，东莞市政协主席刘树基同志应邀为我院专家、教授及大学生作形势报告。

学院领导安少华、朱冰、张林，近年进校工作的陈丁堂、罗余才、米双红、魏玉、刘杰、夏立明、赵书山等教授，以及1600多名大学生参加了报告会。党委书记朱志德主持报告会。

刘主席自始至终参与了东莞的改革开放，见证了三十年的成就与变化。他在题为《东莞经济社会发展的现状与展望》的报告中，以具体的数据、生动的故事、风趣幽默的语言，回顾总结了东莞改革开放三十年来的发展历程、建设成就与经验，对东莞经济社会“双转型”作了高瞻远瞩的展望。

在报告中，刘主席把1978年、1998年、2008年这三年全市的生产总值、财政总收入和全市各项存款余额等三大经济指标分别进行了比较，认为东莞改革开放以来的经济发展经历了起步、腾飞、提升与转型四个阶段，从虎门签订全国第一份“三来一补”的合同到全面招商引资，从“第二次工业革命”到“经济社会双转型”。这四个阶段的划分，为师生清晰地勾勒出了东莞的发展轨迹。

作为东莞改革开放的决策者、执行者，刘主席对东莞的发展历程有着深刻的体会与感悟。他把东莞经济社会发展的动力归结为国际资本大循环、优越的地理位置和国家改革开放的政策，得益于天时、地利与人和。刘主席强调指出，今后东莞经济社会的发展必须坚持五大理念：遵循社会主义市场经济规律，积极践行科学发展观；科学发展的第一要义是发展；注重城市形象，更要注重城市的效益；注重工业立市，也要注重经营城市；树立人民政府形象，建设服务型政府。

报告结束之后，师生们就东莞人口增长、社会转型、文化建设、贫富悬殊、土地资源利用等问题请教了刘主席，刘主席一一回答了大家的提问，并表示今后愿意就东莞的经济社会现象和问题与大家作进一步的交流。

本次报告会为城市学院大讲堂第十七讲。
