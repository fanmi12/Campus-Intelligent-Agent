# 中山大学新华学院来我院考察交流

12月19日，中山大学新华学院党委副书记蓝永金等一行11人来我院考察交流。院党委书记朱志德，院办主任黄兢、组织人事处处长胡钦华、学生处副处长杜鹏举等相关人员在法商楼5A123会议室与来宾进行了座谈。

座谈会上，双方就学生思想政治教育工作开展情况、学生党建及学生党员素质拓展情况，校园文化建设及学生活动中心规划、学风建设、辅导员队伍建设等方面内容进行了比较详细的交流。

蓝副书记一行还先后参观了我院教学管理大楼、图书馆、综合馆、学生宿舍、运动场等校园建筑设施，对我们优美的校园环境和鲜明的办学特色表示赞赏，表示今后要与我院加强联系与交流，共同促进两校的发展。
