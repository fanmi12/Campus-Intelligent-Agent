# 我院到艺术培训学校进行专业宣讲

1月10日，广州大学城艺术培训学校邀请我院学生处副处长孔增强做专业宣讲报告。

孔副处长对我院的办学情况和艺术专业做了介绍，回答考生关心的热点和焦点问题。广州大学城艺术培训学校是广州大学城内规模较大的一所艺术培训学校，参加本次报告会的学生近420人，许多学生表示希望到城市学院深造。

据悉，我院表演专业（含音乐和舞蹈方向）的校考时间初定为3月15-16日在新校区进行。请考生们注意，同去年一样，报考我校表演专业应先在网上进行预报名，预报名系统将于近期开放。
