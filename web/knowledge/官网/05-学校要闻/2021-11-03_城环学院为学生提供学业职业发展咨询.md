# 城环学院为学生提供学业职业发展咨询

为促进城环学院教学相长、改善学风，本学期城建与环境学院设立学业职业发展咨询室开展了咨询服务，得到了学院教师的大力支持和同学们的广泛关注。截至目前，学业职业发展咨询室十月份已接待近20次批次，十一月份仍在火热进行中。

从10月11日开始，城环学院在教学楼8C322设立学业职业发展咨询室，优先挑选专业技能强业务水平高的党员教师组成咨询团队，为学业困难的同学提供“一对一”“多对一”“一对多”等多种形式的靶向学业帮扶。

针对城环学院学生基数大，一些专业科目分数较低的实际情况，城环学院通过教师会议调研分析，征集意见，集体研讨等方式形成学业帮扶计划，并初步建立学业职业谈话机制。

“有些科目较难，就算是自己预习复习也很难弄明白。听课的时候我知道自己在学习中仍存在很大的不足，但又没有找到恰当的方法使自己得到有效的提升，所以希望通过参加咨询，得到老师的一些建议和学习方法，让自己的以后努力不再盲目，在大学四年中真正有所收获。”主动预约咨询的李同学说。许多同学在与老师交谈后纷纷表示大有所获，老师耐心、细致的解答能够帮助他们明晰接下来的学习规划与生活规划。同时，参与咨询的老师认为这种形式的交谈能更了解学生的需求和困惑，及时调整教学模式。

城环学院院长肖红飞表示，设立学生学业职业发展咨询室是学院“我为群众办实事”主题教育开展以来的重要举措之一。前期通过调研摸底，聚焦学生反馈的困难，从服务着手，设立学业职业发展咨询室，帮助学有所困的同学。这种学习方式不仅拉近师生的距离、解决学生困惑，也是提升学院学生升学、就业质量，解决学生因学业困扰产生心理问题的有效途径。

咨询室的开放为老师和同学之间搭建了更有力的沟通桥梁，并且有效地拉近了师生之间的距离。此次活动得到城环师生的一致认可，扎实推进“学党史，办实事”走深走实。
