# 我校五月教职工生日会圆满举行

为持续深化幸福城院建设，厚植人文关怀氛围，切实增强全体教职工的归属感、幸福感与凝聚力，5月21日，5月份集体生日会如约而至，新一轮生日会全新升级、焕新启幕，在延续暖心初心的基础上创新形式、丰富内涵、细化服务，让校园温情更有温度、人文关怀更具质感。

活动开场前，击鼓传花暖场游戏烘托出轻松欢快的现场氛围。由学校党委副书记、校工会主席、副校长李海冬敲响花鼓，花束在各位教职工的欢声笑语中快速传递；鼓声落定后，持有花束的寿星教职工依次上台领取惊喜礼品，收获了工作与生活中的一份温馨惊喜。本次活动特别邀请新传媒与艺术学院梁贝老师担任主持人。

“祝大家生日快乐！”学校党委书记魏东初上台送上祝福，每场生日会中，学校领导亲临现场，为当月寿星教职工送上真挚祝福与暖心寄语，感谢全体教职工坚守教育初心、深耕育人一线，为学校高质量发展默默耕耘、无私奉献。

随着熟悉的《生日快乐》旋律响起，点缀着鲜花与蜡烛的生日蛋糕缓缓推出，当天生日寿星代表上前，许下对生活与工作的美好期许，在热烈的掌声中切开满载祝福的蛋糕。学校还为每位寿星精心准备了定制礼品，将关怀与温度送到大家心坎上。

整场生日会氛围轻松愉悦，欢声笑语不断，大家一边分享香甜的蛋糕，一边畅谈工作感悟与生活点滴，在轻松融洽的互动中拉近了彼此的距离，也感受到了“城院大家庭”浓浓的归属感。不少寿星表示，这次提质升级后的集体生日会，细节更贴心、氛围更暖心，收到的不仅是生日祝福，更是学校对教职工的牵挂与重视，今后会带着这份温暖继续前行，以更饱满的状态投入到育人工作中，为学校建设发展贡献更多力量。

党委办公室陈东汉老师说，“今天一早收到工会的祝福信息，告诉我今天是我在城院工作的第6899天，心中莫名感慨。感恩城院见证了自己六千多天的日日夜夜，感谢城院每年给予我们的生日祝福，祝愿城院的事业蒸蒸日上，大家越来越好。”信息化与实验中心黄嘉振分享，“一起吹蜡烛、一起切蛋糕的感觉太棒了！能和大家在同一天分享这份喜悦，我们这个城院大家庭真的像家人一样亲密！”

过去一年的生日会活动，始终坚守温情底色，流程简洁暖心、氛围温馨融洽。经典的生日歌合唱、集体许愿切蛋糕、专属礼品派送、自由畅谈互动等环节，成为每场活动的温情标配。通过集体生日会，真正把学校的关怀与温暖送到每一位教职工身边，有效营造了团结和睦、温暖向善的校园“家文化”。

据了解，在总结常态化办会经验、倾听教职工心声、收集多元意见的基础上，新一轮教职工集体生日会从形式创新、内容丰富、场景多元、体验提质等维度全面优化升级，让集体生日会更具特色、更有温度、更富新意。温情不止，初心如故；焕新前行，聚力成长。教职工是学校发展的基石与底气。未来，工会将持续立足教职工需求，不断优化活动形式、丰富活动内涵、提升服务品质，以更暖心、更精细、更多元的文体关怀活动，搭建情感联结桥梁，凝聚全体教职工向心力，激励大家以更饱满的热情、更昂扬的姿态深耕教育事业，携手共创学校高质量发展新篇章。
