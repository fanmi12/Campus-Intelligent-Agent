# SYB创业管理城院班第二期圆满结业

5月4日，创业管理城院班举行第二期结业典礼仪式。自今年3月13日以来，SYB创业管理城院班已经开办了两期。首期52名学生，第二期30名学生，分别来自管理系、计信系和机电系各个年级。

东莞市SYB创业管理城院班由东莞市人力资源局主办，城市学院继续教育中心、东莞市博宇培训学校主办，城市学院管理系承办。SYB创业培训项目是国际劳工组织（ILO）和中国人力资源以及社会保障部积极倡导的专门为创业者、中小企业“量身定做”的社会化创业教育平台。

SYB创业管理城院班的课程由创业经验丰富的创业导师讲授，小班教学，采用参与性互动教学模式，模拟实际创业过程。通过该课程，有创业意愿的同学可以演练开办企业的各个步骤，完成自己的创业计划书。

在前二期创业班具体教学过程中，教师引导同学们结合顺丰速递、西树泡芙、LED灯等实际项目进行操作，同学们理论联系实际，受益匪浅。创业班还充分利用周末的时间，召开企业家创业沙龙，让同学们与企业家亲密接触交流，学习解决创业实际问题的具体办法。
