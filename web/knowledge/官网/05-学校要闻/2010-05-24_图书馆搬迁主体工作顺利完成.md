# 图书馆搬迁主体工作顺利完成

尽管刮风下雨，但仍然阻挡不了师生们的搬迁工作。

用手提、车推，30万册馆藏图书就是这样顺利完成转移的。

书本整理上架5月22、23日，400名学生志愿者与图书信息中心的老师共同努力，将图书馆的大部分书籍搬运到了新馆。尽管时有大雨，但由于准备充分、组织周密，整个搬迁工作始终有条不紊，顺利完成任务。至此，图书馆搬迁工作的关键部份已经完成。

传统的图书馆的图书搬迁方式是先将图书下架、打包，再搬至新馆，拆包后重新上架排架，整个过程耗时多、浪费大、闭馆时间长。而本次搬迁，图书馆周密计划，科学组织，采取点对点，即从老馆书架直接搬至新馆书架的办法，既免去多重环节的人力物力损耗，又可以保证图书一次性有序到位。在搬迁中，参与搬馆的师生始终热情高涨，不辞辛苦，紧张有序，充分展现了城院学子的良好精神风貌。
