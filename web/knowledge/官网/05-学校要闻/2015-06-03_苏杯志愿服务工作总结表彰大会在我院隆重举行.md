# 苏杯志愿服务工作总结表彰大会在我院隆重举行

5月30日，“2015年vivo?苏迪曼杯世界羽毛球混合团体锦标赛”志愿服务工作总结表彰大会在我院隆重举行。团市委书记、组委会委员李亚鹏，团市委副书记、组委会志愿者服务部部长何俊聪、市文明办副主任粱杰，东莞理工学院城市学院副院长黄兢等领导出席了大会。来自东莞各高校和社会各界的志愿者代表参加了会议。

会上播放的由城市学院协助制作的“苏杯”志愿服务回顾短片，让到会人员为之动容。感人的短片不仅定格了每个温暖的笑容，也展示出东莞精神风貌。何俊聪副书记在工作总结中指出，不同领域的人才加入了“苏杯”志愿服务的队伍，充分体现了东莞城市的包容度和“苏杯”的向心力。

来自我院的赛会志愿者郑金鸿在会上与大家分享了自己的志愿服务体会，他说，“苏杯是我人生志愿服务的开始。虽然，我们能常常见到很多大明星，但为了坚守岗位我们常常抵抗诱惑，对自己喜欢的球员明星‘视若无睹’。请向坚守岗位至最后一刻的自己致敬！”

大会对东莞理工学院、东莞理工学院城市学院等14个突出集体和125个赛事服务之星进行了表彰，并颁发奖匾或证书。其中，我院郑金鸿、汪思婷等77名学生被评为“赛会志愿服务之星”。

团市委书记、组委会委员李亚鹏指出，本届苏迪曼杯的志愿者，不仅用他们热情周到的服务保证了赛事的顺利进行，还用他们任劳任怨、坚忍不拔的精神感动了来自世界各地的嘉宾。世界羽联主席、世界羽联裁判组特意向本届赛事的志愿者发来感谢信，新华社等中外媒体纷纷都为志愿者点赞。
