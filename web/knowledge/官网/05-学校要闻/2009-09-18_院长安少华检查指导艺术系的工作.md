# 院长安少华检查指导艺术系的工作

9月17日，院长安少华在学院办公室主任王玉、发展联络中心主任杨光强的陪同下，到艺术系检查指导工作。

艺术系总支书记丘永辉向安院长汇报了迎新等工作情况。听完汇报后，安院长对艺术系的开学迎新工作表示满意。在谈到“国庆、院庆、迎新文艺晚会”节目排练情况时，安院长指出，本次文艺晚会，艺术系的师生担任了大部分的演出任务，责任重大，任务光荣。希望大家发扬吃苦耐劳的精神，认真排练好每一个节目，以此推动教学工作，给全院师生奉献一台精彩的文艺盛宴，充分展示艺术系师生多才多艺的风采。
