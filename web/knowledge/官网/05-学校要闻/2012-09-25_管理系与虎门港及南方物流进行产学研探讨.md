# 管理系与虎门港及南方物流进行产学研探讨

9月15日，虎门港管理委员会专业市场办主任张志勇主任、王淑琴博士、南方物流常务副总经理陈少鹏到访我院管理系，与管理系领导、教师举行产学研协作会议。管理系主任张佺举教授、书记帅建华教授等系领导及部分教师参与会见。

会上，双方就如何开展产学研合作、学生进入企业实习等问题进行探讨，为我院人才培养提出了宝贵意见。管理系教师也运用自己的专业知识，对虎门港的发展、以及虎门港参加全国物流博览会的相关细节问题提出一些建议。
