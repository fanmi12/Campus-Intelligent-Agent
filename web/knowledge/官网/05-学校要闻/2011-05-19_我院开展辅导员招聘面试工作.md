# 我院开展辅导员招聘面试工作

黎建烨董事、张林副院长看望面试人员5月18日，我院在图书馆对辅导员应聘人员进行考核。本次考核分笔试、面试两个环节进行，其中笔试部分涵盖行政能力测试、辅导员岗位专业知识考试和心理测试三个部分。

院长安少华教授，城市学院董事、广东鸿发投资集团有限公司副总裁黎建烨，党委副书记朱冰，副院长张林，人事处处长夏勇等领导，到现场看望面试人员并向他们提问。

辅导员招聘工作于今年4月正式启动，在报名时间内，先后有来自全国相关高校的研究生和本科生130多名报名应聘。

据了解，辅导员招聘工作领导小组将根据笔试、面试成绩和心理测试结果等因素综合考虑，确定初步人选。
