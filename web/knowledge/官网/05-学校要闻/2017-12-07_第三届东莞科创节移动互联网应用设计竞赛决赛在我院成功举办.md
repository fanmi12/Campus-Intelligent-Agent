# 第三届东莞科创节移动互联网应用设计竞赛决赛在我院成功举办

12月5日下午，由东莞市教育局、东莞市科学技术局、东莞市人力资源局、共青团东莞市委员会主办，我院团委承办的“第三届东莞市大学生科技创新节—移动互联网应用设计决赛”在学术报告厅举办。来自我院 “逆袭二进制团队”脱颖而出,与东莞理工学院“Doi多意团队”并列第一。

东莞市教育局高等教育办公室主任罗灼民、东莞团市委学校部部长卢雪霞，我院院长王卫平、副书记章德胜、副院长周庆出席了活动。东莞市广播电视台总工程师苏哲新、东莞市计算机学会会长胡选子、东莞信大融合创新研究院技术部部长梁进山以及我院教务处处长牛熠、计信系主任廉玉忠担任大赛评委。

9支队伍参加了决赛，分别围绕“项目介绍”和“答辩环节”进行了精彩的作品展示。经过激烈角逐，逆袭二进制、Doi多意团队并列摘获了本次决赛的一等奖，毅优团队、Aimcool和神奇宝贝队获得二等奖，天际工作社、蓝鳍队、知心队以及理工666团队获得三等奖。
