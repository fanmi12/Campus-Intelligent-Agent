# 政法学子喜获2017年全国大学生商务谈判大赛三等奖

11月4日-5日，2017年“国泰安杯”全国大学生商务谈判大赛总决赛在北京市首都经济贸易大学成功举行。政法系15级行政管理专业颜怡雯、郑婉琳、肖开云、周晓清、陈灵等5名同学组队参赛并获得三等奖，指导老师韦朝毅获得“优秀指导教师”称号。

据悉，本届大赛由全国经济管理院校工业技术学研究会沟通与谈判委员会主办、首都经济贸易大学承办。总决赛共有50支队伍参赛，参赛对象包括本科性、研究生和韩国代表队，主要来自中国政法大学、中南大学、首都经济贸易大学、江西财经大学等院校。
