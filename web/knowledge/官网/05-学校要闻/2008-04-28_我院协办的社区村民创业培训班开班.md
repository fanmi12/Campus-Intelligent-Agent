# 我院协办的社区村民创业培训班开班

学院发展与联络中心杨光强主任作动员讲话4月24日，由东莞理工学院城市学院牵头、东莞市劳动局和东城区樟村、堑头社区共同协办的村民“创业培训班”开班。

该班学员由60多名待业村民组成，主要是进行创业及就业前的培训教育，课程内容包括创业观念教育、实用劳动技能培训、到相关单位见习等，以帮助他们尽快地就业或重新走上工作岗位，推进两社区的经济社会双转型工作。

此次活动也是我院开展“社区共建活动”的重要内容之一。城市学院发展与联络中心还将继续开展一系列相关活动，为共建和谐社区出一份力。
