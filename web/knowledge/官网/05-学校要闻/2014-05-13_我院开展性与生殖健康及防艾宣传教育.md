# 我院开展性与生殖健康及防艾宣传教育

5月9日，新苗社会工作服务中心与东莞市幸福家园公益项目发展中心合作的“大学生性与生殖健康及艾滋病预防宣传教育公益行动项目，在学生活动中心、寮步社会工作服务中心启动。

从北京远道而来的玛丽斯特普国际组织中国代表处项目官员罗楠担任主讲人。此次培训的内容有：1、性与生殖健康的基本知识；2、青少年性教育的理念和价值观；3、性教育的培训方法和技巧。

罗楠指出，性教育对大学生非常必要，应该在公开场合进行，有利于加强同学们对性的正确认识。通过一天半的培训，参训志愿者感到获益匪浅，感叹自己上了人生第一堂“性教育课”。
