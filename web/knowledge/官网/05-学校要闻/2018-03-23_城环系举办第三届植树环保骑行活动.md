# 城环系举办第三届植树环保骑行活动

3月22日下午，城环系举办第三届“绿色骑行，骑乐无穷”植树环保骑行活动，倡导“节能环保、低碳出行”。刘玉侠副院长、后勤处处长王锦锋，城环系主任肖红飞、党总支书记宋欣荣及150多名师生参加了活动。

城环系CHPINK舞蹈队的精彩表演拉开了序幕，领导和师生代表共同植下两株“许愿树”，为校园增添了靓丽色彩。

肖红飞主任致辞表示，举办环保骑行活动，通过多种途径传播环保新理念和，应绿色出行，提高师生们环保意识。

剪彩仪式后，骑行活动开始，师生们一饱满的热情向同沙水库和佛岭湖出发，一路领略大自然的靓丽春色。
