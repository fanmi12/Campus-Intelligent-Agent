# 学院教工献爱心  捐款赠衣援灾区

最近，湖南、贵州及我省部分地区遭受了雨雪冰冻灾害，灾区许多群众面临缺衣少被等生活困难。我院积极响应省委办公厅、省政府办公厅 “送温暖、献爱心”的号召，从2月25号开始，在教工中开展了向灾区群众捐款赠衣的活动。

活动开始后，全员教工积极响应。截至发稿时止，学院工共捐款11943元，衣物、棉被共2000余件。近日，这些钱物将送至灾区。
