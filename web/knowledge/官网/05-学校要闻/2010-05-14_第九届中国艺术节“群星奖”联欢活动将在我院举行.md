# 第九届中国艺术节“群星奖”联欢活动将在我院举行

协调会现场

演出剧照（资料图片）5月12日，我院对协助“九艺节”组委会举办“群星奖”联欢活动作出工作协调安排。党委副书记朱冰，院办主任王玉、副主任黄研辉，宣传部部长何鹏举，总务处处长李奇，艺术系党总支书记丘永辉，财务办主任黄甜源，团委书记杜鹏举等相关职能部门负责人出席会议。

“九艺节”创办于1987年的中国艺术节，是我国规模最大、水平最高的艺术盛会，本次九艺节在广东举行。本次“群星奖”是文化部为繁荣群众文艺创作，促进社会文化事业繁荣发展而设立的全国性的社会文化艺术政府奖。“群星奖”评奖范围分为作品类和项目活动类,共评选出330个“群星奖”,将从作品类和项目类获奖对象中推出100个“群英之星”。本届艺术节组织优秀艺术家演出小分队下基层演出，让优秀的剧目成果与人民群众共享。28支优秀艺术家小分队演出31场，于5月10日至25日在广州市举办，并在深圳、佛山、东莞、中山市分会场演出。其中，“群星奖”联欢演出将于5月23日晚在我院举行。
