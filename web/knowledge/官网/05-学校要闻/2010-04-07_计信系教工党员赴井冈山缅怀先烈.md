# 计信系教工党员赴井冈山缅怀先烈

清明节期间，计算机与信息科学系党总支组织教工党员及民主党派人士，到井冈山参观红色圣地，缅怀先烈。

4月4日清晨，教工们怀着对革命先烈无比崇敬的心情，首先瞻仰了井冈山革命烈士陵园，祭拜革命先烈，对烈士陵园里的每一幅先烈的照片，每一段先烈的事迹，都非常认真地看，仔仔细细地记在笔记本上。接着，教工们又先后参观了井冈山革命博物馆，毛泽东同志学习和工作过的地方——茅坪“八角亭”，朱德与毛泽东会师的宁冈县“会师桥”、“会师广场”，贺子珍同志纪念馆。

通过参观，教工们一次次深刻地体会到革命的艰辛和幸福生活的来之不易。
