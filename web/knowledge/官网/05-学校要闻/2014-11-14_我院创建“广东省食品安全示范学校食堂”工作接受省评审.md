# 我院创建“广东省食品安全示范学校食堂”工作接受省评审

11月10日，广东省食品药品监督管理局、东莞市食品药品监督管理局、寮步镇食品药品监督管理分局组成评审小组对城市学院荔香园食堂申报创建“广东省食品安全示范学校食堂”工作进行评审。党委书记王卫平、院长助理麦绮琳、总务处处长翟耀明和副处长陈辉陪同。

省、市、镇三级食品药品监督管理职能部门的领导、专家及工作人员，实地查看了食堂的硬件建设、生产制作流程与规范等实际情况，查阅了食堂管理的规章制度、索证、留样及培训等文字材料，并对员工进行了情况了解和调查。评审小组充分肯定了我院开展“广东省食品安全示范食堂”创建工作所取得的成绩。

据悉，新校区建成以来，我院对食堂建设与卫生工作十分重视，落实了食品安全责任制，建立健全食品安全管理制度及资料记录，规范了食品采购行为和食品加工操作流程。
