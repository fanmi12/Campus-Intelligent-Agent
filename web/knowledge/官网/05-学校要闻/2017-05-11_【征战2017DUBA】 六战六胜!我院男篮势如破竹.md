# 【征战2017DUBA】   六战六胜!我院男篮势如破竹

5月10日晚，我院男篮再次迎战广东亚视演艺职业学院队，客场以78:52缔造不败金身，创下六战六胜不俗战绩。

比赛伊始，我方率先抢得球权，以一记3分入球率先打开战局。接着又投中两记3分球，拉开比分差距。对方不甘示弱，凭借内外线的默契配合，打出了一波小高潮，反超比分。第一节结束，我院以13:14稍微落后。

第二节，对方欲乘胜追击，由14号谢晋立开场进球。我方经过及时总结经验，迅速做出调整，打出一波14:0，并以32:20的优势进入下半场。

易边再战，我院继续保持强劲势头，火力全开，牢牢掌握着比赛的节奏，拉大比分。

第四节，对方奋起直追，一度攻势强劲。但我方及时调整状态，再次掌握比赛节奏，并打出一波11:0的小高潮，最终将比分定格在78:52，以高出26分的优势战胜广东亚视演艺职业学院队。
