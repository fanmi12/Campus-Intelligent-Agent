# 赵书山副教授应邀参加广东省行政管理学年会

2月4日-25日，政法系副主任、广东行政管理学理事赵书山副教授应邀参加广东省行政管理学会2011年年会暨政府执行力与公共财政绩效管理研讨会。

会议就“政府执行力与公共财政绩效管理”问题展开广泛的讨论。与会人员认为，坚持理论与实践相结合，深入研究公共财政绩效管理，不断提升政府执行力，是当前当前行政管理研究的重点内容之一，也是构建幸福广东对财政的基本诉求。赵书山副教授就上述问题同与会专家进行了广泛的交流。

据悉，本次会议得到省委、省政府的高度重视，省委常委、组织部长、省行政管理学会会长李玉妹，省人大常委会副主任钟阳胜到会并分别讲话，省财政厅厅长曾志权到会致辞。来自国家财政部、北京大学、中国人民大学及省内各市、县（区）政府主管财政领导、财政部门负责同志及省属科研院校专家学者200余人参加了会议。
