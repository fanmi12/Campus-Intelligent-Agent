# 外语系学子在全国大学生英语竞赛中斩获佳绩

5月20日，全国大学生英语竞赛决赛（广东赛区）在广东财经大学举行。全省45所高校共有44450名同学参赛，经过层层选拔，289名同学参加了决赛。我院选手在决赛中发挥出色，陈梓键、利睿、罗秋雨、李晓琳在B类（英语专业本科生）中荣获一等奖、廖超民（商学院）、邓紫珊（文传系）在C类（非英语专业本科生）中荣获一等奖。

赛前，外语系指导老师严洁、李玲玲、金萍，黄璐、黄燕丽、阮春颜对参赛选手们在听、说、读、写、译、等方面进行了细致的训练，提升了参赛选手们的知识储备和专业技能。
