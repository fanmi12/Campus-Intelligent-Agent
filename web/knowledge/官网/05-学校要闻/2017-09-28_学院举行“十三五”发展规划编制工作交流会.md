# 学院举行“十三五”发展规划编制工作交流会

9月28日下午，学院“十三五”发展规划专项及二级教学单位发展规划编制修改意见反馈及交流会在行政楼212会议室举行。王卫平、高香林、黄兢、周庆、刘玉侠、林江龙等院领导和各部门、各院系（部）负责人参加了会议。会议由黄兢副院长主持。

研究与发展规划处处长赵书山汇报了学院“十三五”发展规划编制工作情况。他对二级教学单位发展规划编制工作的有关情况进行了反馈，指出了存在的问题，提出了修改意见和建议，对下一步规划编制工作进行了安排。

院长助理林江龙就“十三五”期间学院教学建设发展做了专题发言。他结合自身实践和经验，对学科专业建设、应用型人才培养、课程构建等改革与探索，与大家分享了自己的构想。

教务处处长牛熠、人事处副处长李海冬、学生处副处长罗文芳分别就“十三五”期间学院专业综合改革及人才培养规划总体要求、师资及管理队伍建设总体要求、校园文化建设规划总体要求进行了汇报。

王卫平院长在总结中，要求各部门、各教学单位在编制发展规划中，结合专业建设综合改革的要求和省教育厅即将推出的普通高等学校本科专业评估工作的有关精神，借鉴国外高校先进的教育理念，推进学院教育教学改革和发展规划的编制工作。他强调，学院“十三五”发展规划作为纲领性文件，是学院未来几年的工作指南，大家要充分认识到其重要性，给予高度重视，以问题为导向，向改革要动力，增强发展目标与改革措施的协调性。他希望大家按照学院统一部署，结合学院整体发展规划，认真做好专项发展规划的修订编制工作。
