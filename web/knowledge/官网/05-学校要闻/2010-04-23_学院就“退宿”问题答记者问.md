# 学院就“退宿”问题答记者问

近日，有学生反映说，学校要求莞城、东城、南城、万江户口的学生下学期要退宿，这会给学生带来不便。记者就此问题采访了学生处和总务处有关负责人。他们表示，本次的退宿问题，完全自愿，无强制之意。希望学生和家长全面理解文件精神，不要因此产生误会。

我院属于地方院校，其中80%的学生是本地生源，部分学生有实行走读的意愿。学校对学生住宿有严格的规定，一年级学生不能走读必须住校，必须集中军训和参加早读与晚修。对于二年级以上、家住在莞城、东城、南城、万江大城区附近的学生，经家长同意，本人申请，符合相关规定的，经学校批准允许其走读。

学院每年暑假都要调整和维修学生宿舍，排除安全隐患，这是一项例行性工作。每年暑假前，学校都会向学生发出相关的通知，对有意愿走读并符合退宿条件的同学进行调查摸底。为此我院职能部门学生处、总务处于2010年4月12日

联合下发了《关于做好2010年下半年退宿的通知》的文件。该《通知》并没有强制学生退宿，而是明确了对于家住东莞市大城区及附近镇区的同学“可实行走读”，“部分毕业班的学生，为方便实习，也可以退宿”的规定。

据悉，有关系部正在向学生做解释工作，希望同学们正确理解“退宿”文件精神，安心学习。
