# 刘仁、聂秀东博士受聘我院讲座教授

9月26日，学院在大礼堂举行聘任仪式，聘请刘仁、聂秀东两位博士为讲座教授。院长安少华教授为他们颁发了聘书。

据悉，刘仁博士1996年毕业于东莞理工学院，1999年至2002年就读于香港理工大学，获工商管理硕士学位，然后又在该校获工商管理博士学位，研究方向为管理和物流。他具有十年以上的工厂生产管理、市场营销和物流管理经验以及海外工作经历，现就职于得利钟表制品有限公司。

聂秀东博士2001年师从北京大学杨岳全教授攻读经济学博士学位，曾参与商务部“出口名牌发展战略”等多项国家课题研究，发表过多篇论文。1999年至2001年曾在教育部工作，现就职于北京大学光华管理学院。
