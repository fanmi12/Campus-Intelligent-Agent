# 我院艺术类考生单招考试圆满结束

考生进行视听练耳考试

舞蹈基本功考试

器乐演奏考试3月19、20日，我院举行艺术类考生单独招生考试。据悉，共有184人次报考我院相关专业。今年我院艺术类单招考试的对象主要是广东省的考生，影视表演专业重新开设并招生，共有22名考生报考该专业。

考试在四号教学楼8楼舞蹈厅、6楼演唱厅及图书信息大楼1楼表演厅同时进行。音乐表演专业考试科目有歌曲演唱、器乐演奏、视唱练耳、才艺展示、命题表演；舞蹈表演专业的考试科目有剧目、基本功、才艺表演、即兴表演、视唱练耳；影视表演专业的考试科目有语言表达、才艺表演、形体展示、命题表演。据考官黄英森教授介绍，今年考生总体素质较好，综合能力也比较强。
