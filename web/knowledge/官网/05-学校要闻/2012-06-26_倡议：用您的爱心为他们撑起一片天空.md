# 倡议：用您的爱心为他们撑起一片天空

“一方有难，八方相助”是我国的传统美德，也是社会主义新时期和谐社会、共同发展的积极体现。今年是我省实现扶贫开发“双到”三年目标的决胜之年，也是我省积极应对国外复杂严峻的经济形势、保持经济社会平稳健康可持续发展的关键一年。

为了保障贫困群众的基本生活，6月30日，2012年“广东扶贫济困日”活动将在全省范围内广泛开展。为此，我院定于6月28日上午在4号楼大厅组织爱心捐款活动。根据学院的规定，机关工作人员、员工代表参加现场捐款。院工会倡议大家用自己力所能及的力量，奉献无价的爱心，用您的真诚为贫困人员撑起一片天空！

据悉，各系部教师及学生爱心捐款时间为6月26日-6月28日，由系部组织。
