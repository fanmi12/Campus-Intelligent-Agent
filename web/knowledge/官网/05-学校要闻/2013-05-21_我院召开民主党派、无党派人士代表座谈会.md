# 我院召开民主党派、无党派人士代表座谈会

5月18日，我院召开民主党派、无党派人士代表座谈会，党委朱志德书记、副书记朱冰出席座谈会。

会上，朱志德书记充分肯定了学院各民主党派和无党派人士在学院的建设和发展中做出的重大贡献，他指出，我院各民主党派和无党派人士在教学、科研和管理等工作中担任着重要的工作，发挥了重要的作用，为学院的改革发展作出了贡献。希望民主党派和无党派人士为学院发展建言献策、反映问题、争取各界支持。朱书记还传达了4月15日广东省委统战部召开的全省民办高校、独立学院统战工作会议精神。这次会议要求，全省各民主党派和无党派人士要把握正确方向，坚定政治立场，围绕广东省“三个定位、二个率先”的发展总目标，自觉服务于全省中心工作。朱志德书记要求民主党派和无党派人士和其他教职工一起，自觉维护学院的形象和利益，凝聚力量，共同发展。

与会人员希望学院要充分发挥独立学院的体制机制优势，并就招生、专业设置、实践教学、教师培养、干部任免等问题发表了意见。
