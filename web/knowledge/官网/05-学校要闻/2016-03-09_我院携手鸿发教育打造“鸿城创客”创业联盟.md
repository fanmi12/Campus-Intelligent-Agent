# 我院携手鸿发教育打造“鸿城创客”创业联盟

3月7日上午，由我院携手东莞市鸿发教育投资有限公司打造的创业联盟“鸿城创客”揭牌暨启动仪式在行政楼二楼举行。王卫平、章德胜、高香林、黄兢、周庆、刘玉侠、麦绮琳等院领导与鸿发教育公司陈超群总经理、夏为民副总经理出席了揭牌仪式。

陈超群总经理在揭牌仪式上致辞，表达了对“鸿城创客”大学生创业联盟的重托与期望。

在热烈的掌声中，王卫平院长与陈超群总经理为鸿城创客进行了揭牌，并参观鸿城创客基地。

随后，“游吧团队”、“互?创意团队”、“梦?魅文化教育工作室”、“城院文化创意工作室”等学生创业团队与“鸿城创客”签署了入驻协议，并进行了相关路演及团队介绍。
