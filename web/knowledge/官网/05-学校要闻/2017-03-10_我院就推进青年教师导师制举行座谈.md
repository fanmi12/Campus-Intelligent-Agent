# 我院就推进青年教师导师制举行座谈

3月8日下午，教师发展中心就2016-2017学年青年教师导师制推行情况举行坐谈会。学院副院长、教师发展中心主任刘玉侠，教务处处长牛熠教授、张兰副教授，督导组宋欣荣教授、李上文教授，以及本期青年教师导师制的导师和青年教师代表参加了本次座谈会。教师发展中心副主任李海冬主持本次会议。

李海冬副主任通报了本学年青年教师导师制的中期检查情况，并对青年教师导师制有关管理办法进行了讲解，重点介绍了日常实施、中期检查与期终考核三个实施环节的相关考核操作办法。

导师们与青年教师就目前青年教师导师制的考核情况，以及日常培养指导中的具体问题，包括各青年教师入职第一年的培养工作重点，青年教师日常教学工作遇到的实际问题，如何引导青年教师开展有效教学，提高课堂管理能力等，进行了细致的交流。

刘玉侠副院长代表学院对致力于青年教师成长发展的导师们，表示衷心的感谢；并强调各教学单位要切实有效地推进青年教师导师制的实施；青年教师也要多学多问，主动向导师请教，尽快提升自身专业能力，胜任教学岗位。
