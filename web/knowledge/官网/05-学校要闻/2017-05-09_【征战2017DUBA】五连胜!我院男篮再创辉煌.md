# 【征战2017DUBA】五连胜!我院男篮再创辉煌

77:65！

DUBA进入第七轮，5月8日下午，我院男篮主场再次战胜中山大学新华学院队，取得联赛五连胜！

当日赛事，可谓精彩纷呈。我院率先抢得球权，并由7号黄志陆一记3分球启幕。对方不甘示弱，立马予以回应进球得分。第一、二节，双方打得不分上下，比分不停交替，也屡有3分球进篮的精彩表现。结束时，我院以27:33暂败下风。

中场休息的“校园3分王”游戏活动，吸引观众参与，一展身手，活跃了现场气氛。

第三、四节，我方队员默契配合，发起反击，使对方乘胜追击的策略落空，不仅多次抢断对方，也多次造成对方失误，罚球得分。同时，10号黄明健与0号黄泽彬屡次突破对方防守，赢得上篮投球，掀起一泼又一波的进攻小高潮。距离比赛最后3分钟时，将比分反超至67:65。此时，对方虽然拼抢积极，但效果却显得束手无策。而我方内线外线火力全开，打出一波10:0的高潮，将比分终结在77:65，战胜中大新华队，完成大逆转。

据赛后统计，我院10号球员黄明健再次发挥出色，拿下全场最高25分。客队15号球员欧泽然也表现不俗，为团队拿下23分。
