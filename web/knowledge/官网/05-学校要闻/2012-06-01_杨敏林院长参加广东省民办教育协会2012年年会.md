# 杨敏林院长参加广东省民办教育协会2012年年会

5月30日，杨敏林院长赴珠海参加广东省民办教育协会年会（2012）。本次会议由民办教育协会主办，金网国际教育管理集团承办。

中国民办教育协会会长王佐书，省教育厅副厅长王斌武，省民办教育协会会长许学强出席会议并做重要讲话。

各地市教育局分管民办教育的领导，省内各民办教育机构、民办学校等相关负责人参加了会议。

会议以“广东民办教育政策创新与内涵发展”为主题，组织会员单位深入学习领会国家、广东省“中长期教育改革和发展规划纲要（2010—2020）”以及2011年中国民办教育发展大会提出的“提高质量，办出特色，推动民办教育优质发展”的精神，对我省民办教育特色发展、高质量发展、规范发展，特别是当前民办教育办学理念、发展方式和学校管理模式如何适应国家经济社会发展需要等问题进行研讨。
