# 我院举办安全知识培训讲座

6月15日，我院在学术报告厅组织学生举行安全知识培训讲座。院长王卫平、副院长周庆参加了活动。

活动上，寮步公安分局泉塘派出所张南星副所长作了“以案说防”之禁毒、防诈骗、校园贷安全知识讲座；东莞市消防局防火处李乐顺教官作了“安全防范知识及消防安全知识”专题讲座。

两位特邀嘉宾立足于各自精湛的专业知识和丰富的工作经验，用一个个活生生的真实案例，讲授了相关安全知识。他们也一再强调树立安全意识尤其重要。

王卫平院长、周副院长分别讲话，他们从不同角度阐述了校园安全对广大学生的重要性，希望同学们除了要学好专业知识外，也要重视对安全知识的学习。

后勤保卫处负责人袁秀美主持了培训讲座。
