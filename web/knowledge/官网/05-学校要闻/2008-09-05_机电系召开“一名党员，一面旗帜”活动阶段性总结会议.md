# 机电系召开“一名党员，一面旗帜”活动阶段性总结会议

9月4日，机电工程系在机电楼会议室召开学生党支部会议，学生党员、预备党员参加了会议。

会上，学生党支部书记孔增强老师对上学期的支部工作进行了总结。孔老师认为，在学生党员中开展“一名党员，一面旗帜”活动，发挥了学生党员的先锋模范作用，对营造优良的学风班风、构建和谐文明的校园具有积极的意义。希望同学们继续努力，为党旗增光添彩。
