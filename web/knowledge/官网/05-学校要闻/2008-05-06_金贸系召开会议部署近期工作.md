# 金贸系召开会议部署近期工作

5月5日，金贸系在6304召开全体教师会议安排部署近期工作。会议由金贸系主任米双红教授主持。

米主任指出，金贸系近期工作任务繁重，主要有：按照学院08年上半学期期中教学检查的要求，做好各项准备工作迎接检查；虚心向兄弟系学习，进一步开展党员教育活动，加强党员活动室建设，规范党员活动材料的分类与整理；国贸、金融教研室应按照《东莞理工学院城市学院教研室管理暂行规定》及教研室评估各项指标，及时解决建设中出现的各种问题，把教研室评估工作落实到个人；要确保保险高峰论坛顺利召开，充分体现论坛特色。米主任要求全系教师认真做好近期的各项工作，不能顾此失彼。

他进一步指出，临近期末，要把工作重点转移到毕业论文的指导审查与毕业实习鉴定的填写上来。

金贸系教师表示，要聚精会神地做好本职工作，加强团结，以优异成绩迎接学院考评。
