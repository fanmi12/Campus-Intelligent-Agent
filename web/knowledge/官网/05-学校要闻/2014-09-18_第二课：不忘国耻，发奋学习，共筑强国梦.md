# 第二课：不忘国耻，发奋学习，共筑强国梦

在“九一八”前夕，我院邀请海军某部将军秦兴和少将在综合馆为2014级军训新生作国防知识讲座。据了解，秦将军曾任沙角部队政委、东海舰队政治部副主任、南海舰队政治部副主任、广州舰艇学院政治部主任、海军指挥学院政治部主任及海军潜艇学院政委，曾多次来我院讲南海的历史由来，痛斥外国列强企图侵占这片海域的狼子野心。

秦兴和将军一出场，5000多名军训学员起立，以热烈鼓掌欢迎首长的到来。秦将军说，走进高等学府的殿堂，就像走进了新的学旅生涯。随后，他和同学们先来个四季约定：约定在春天，让大学生活过得充实；约定在夏天，集中精力，付出汗水，学好知识；约定在秋天，有所收获；约定在冬天，迎接人生的春天，确定人生的方向，迎接新的征程。

接着，秦将军结合自己在部队46年的军旅生涯，给同学们讲了三个问题：一、叙利亚、乌克兰等国动乱的国际影响；二、周边国家政治危机对我国所造成的严峻的安全形势，企图遏制中国发展的阴谋；三、国防建设的重要性。“战争态势已经从冷兵器时代转化为向海陆空一体化的战争，对此我们要有充分的思想准备和足够的物质基础，掌握和平的主动权。我们的国防力量在发展强大，但也应清醒地看到我国与发达国家的差距，我们必须迎头赶上去。你们是祖国的新一代，未来终究靠你们，祖国在呼唤人才！”讲到这里，秦将军热切希望同学们不忘国耻，不让历史悲剧重演，中国要强大起来，立于世界民族之林，不能丢失一寸国土与海疆！你们要珍惜大学四年的学习时间，努力学知识、学军事、强素质，随时为祖国的建设、领土的完整贡献力量。

秦将军报告让同学们产生了共鸣，全场曾响起29次掌声。
