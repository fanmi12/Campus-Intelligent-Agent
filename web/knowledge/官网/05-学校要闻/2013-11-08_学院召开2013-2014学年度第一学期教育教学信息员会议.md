# 学院召开2013-2014学年度第一学期教育教学信息员会议

11月6日，城市学院2013~2014学年度第一学期教育教学信息员会议在7B201教室召开，高等教育研究与评价中心陈丁堂督学、王锦锋副主任、聂映中教授、陈玲玲老师以及全体信息员参加会议。

与会人员首先学习了《东莞理工学院城市学院教育教学信息员工作管理办法》。陈丁堂督学、聂映中教授分别就教育教学信息员的意义、工作方式和要求向信息员做了详细的讲解。

会议还表彰了2012~2013学年度的27位优秀信息员。王锦锋副主任向院学生教育教学中心主席、副主席、各系信息分中心主任颁发了聘书。

信息员们表示，要认真做好信息员工作，为建设良好的学风、教风贡献自己的力量。
