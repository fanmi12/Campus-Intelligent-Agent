# 我院携手中国航天科技集团协同创新发展

3月21日，由我院作为牵头单位组建的东莞制造业设备智能化协同创新发展中心，经过近两年的运行，今日正式揭牌，中心核心协同单位中国航天科技集团公司第九研究院第十六研究所所长、研究员万彦辉博士、东莞市铭丰包装品制造有限公司赖沛铭董事长和刘军副总经理，副院长高香林教授、教务处处长牛熠教授共同为中心揭牌。该中心在成立过程中得到了东莞市科技局、东莞市机电工程学会、东莞市电子学会、东莞市自动化学会等单位的大力支持，目前正在积极申报省级协同创新发展中心，争取获得省级认证。

据悉，东莞制造业设备智能化协同创新发展中心将面向东莞制造业在转型升级中对设备智能化自主创新的需求，汇聚科研院所的创新资源和区域产业集群优势，推动体制机制改革与创新，实现区域经济社会发展和学院整体创新能力提升的双赢，力争建设成为具备持续研发能力，对东莞及周边地区制造业设备智能化产业发展具有示范性的协同创新平台及应用型人才培养实践基地，最终将本中心打造成打造服务于东莞及周边地区制造业设备智能化创新发展的高地和示范区。

揭牌前，院长杨敏林教授、党委书记王卫平教授等学院领导会见了嘉宾。杨院长向客人介绍了城市学院的发展现状，并就协同创新发展问题与万彦辉所长和赖沛铭董事长进行了交谈。杨院长期望中国航天科技集团公司第九研究院第十六研究所能够充分发挥航天优势，充分借助协同创新这个平台不断加强与城市学院的深度合作实现人才、资本、信息、技术等创新资源的共享。万彦辉所长表示研究所有信心将这个平台打造成服务东莞乃至珠三角地区的桥头堡，发挥自身优势为珠三角地区的制造业转型升级和智能化作出贡献。

教务处副处长赵书山副教授、计算机与信息科学系主任廉玉忠教授、机电工程系主任赵天婵教授、城市与环境科学系主任肖红飞教授，协同创新中心的团队首席责任人李洪超博士、刘林泉博士、刘武辉博士、张宏辉博士等参与会见，并在揭牌之后陪同各位来宾实地考察了协同创新中心的操作室。
