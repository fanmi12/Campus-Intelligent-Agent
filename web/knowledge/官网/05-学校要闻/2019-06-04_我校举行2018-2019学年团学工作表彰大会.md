# 我校举行2018-2019学年团学工作表彰大会

6月3日，我校在学术报告厅举行2018-2019学年团学工作表彰大会。党委书记章德胜、副校长周庆会同相关职能部门负责人、学校团学干部、学生组织代表、青马学员参加了会议。会议由校团委副书记陈浩华主持。、校团委书记李瑶作了2018-2019学年度团学工作总结报告。报告指出，我校积极开展以党建带团建工作，各项改革都取得阶段性成果。

团委副书记陈振伟宣读了《关于表彰2018—2019年度东莞理工学院城市学院团学组织先进集体和优秀个人的决定》，外国语学院、艺术学院等获“优秀基层团学组织”荣誉称号，2017级环境工程1班团支部等49个单位获“优秀团支部”荣誉称号，符云港等164名同学获“优秀共青团干部”荣誉称号，王子琪等574名同学获“优秀共青团员”荣誉称号，“星火相传，花开半夏”韶关新丰第一小学服务队等获“灯塔实践团队”荣誉称号，“英译中华文化，共筑育人灯塔”教育关爱服务团队获“优秀团队”荣誉称号，陈浩等两名老师和傅杰强等两名同学获“先进个人”荣誉称号。

大会还对在2018年广东省高校“活力在基层”主题团日竞赛中，获得百优项目的2016级英语（商务方向）5班团支部等7个团支部，获得千入围项目的2016级汉语言文学高级文秘2班团支部等15个团支部进行了表彰。
