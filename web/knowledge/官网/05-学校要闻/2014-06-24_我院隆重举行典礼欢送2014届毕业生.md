# 我院隆重举行典礼欢送2014届毕业生

6月21、22日，我院在新老校区隆重举行典礼，热烈欢送3110名2014届本专科生学成毕业，向获得学士学位的学生颁发学位证书，为他们的大学生活画上圆满句号，踏上人生新的征程。

设在大礼堂、综合馆的两大会场，洋溢着欢笑与不舍。毕业生们首先观看了DV短片，当年校园生活的精彩瞬间，美好的青春时光再次呈现在眼前。

东莞理工学院党委副书记吕琦元，城市学院董事长麦照容、理事黎建烨，城市学院领导杨敏林、王卫平、张林、赵涛、陈丁堂、章德胜、麦绮琳及教务处长、各系部主任出席典礼仪式并在主席台就坐，共同见证这一庄严而欣喜的时刻。毕业典礼由副院长高香林主持。

董事长麦照容、院长杨敏林等领导分别为毕业生颁发毕业证书、学位证书和优秀毕业生荣誉证书。

在学士学位授予仪式上，1511名本科生身穿学士服，头戴学士帽，踏着轻快的步子，带着毕业的喜悦，依次走上主席台，接受院长杨敏林的正冠与拨穗，完成正式步入社会的“加冕礼”。

董事长麦照容在专科生毕业典礼上，不仅发表了深情感人的祝辞，还向毕业生颁发了以个人名义制作的纪念牌匾。他的寄语是：理想就是价值，目标就是动力，求知就是享受，奋斗就是乐趣，务实就是作为，风险就是人生。愿您前程似锦，鹏程万里！

院长杨敏林代表学校和全体教职工，向毕业生表达了最衷心的祝贺和最美好的祝愿。他说，几年的大学生活，记录了你们人生最为宝贵灿烂的时光、也见证了你们的甘苦与忧乐，记录了你们在课堂上诵读诗书探究真知的倩影，记录了你们在实验室里全神贯注探索奥秘的身影，记录了你们在湖边情窦初开海誓山盟的背影……，这些美妙的时刻都值得珍藏。今天你们就要毕业了，这意味着美丽而忧伤的离别时刻也即将到来！同时，大学之外更为精彩的人生也在等待着你们，那里有你们期待的事业、爱情、家庭、生活……，但是，我也要提醒你们，社会没有学校这么单纯，前行的路上充满挑战与竞争，甚至还会遇到陷阱和苦难。这也正是你们毕业后，让我们最为牵挂的地方。

在这离别之际，杨院长对毕业生们提出了殷切的希望：希望同学们时刻铭记母校“学而知不足”的校训，不断地学习，不断地向你们未来的老师、同事、领导、朋友，甚至陌生人学习；不断地从书本、网络、实践中进行学习，不断地丰富、提升自己的人生智慧，游刃有余地去应对一切人生难题。希望同学们学会为人处世，修养“好品德”，修炼“好本领”，养成“好态度”，锤炼“好心志”。希望同学们继续做好学问，智慧谋事，不断领悟为人处世的道理和方法，修炼并完善自我，探寻和积累“立身处世、达济天下”的人生智慧。希望同学们常回母校看看。

教师代表文传系宋秋敏博士、计信系王宽福老师也给毕业生们送去了衷心的祝福，他们感人肺腑的发言得到了毕业生们长久而热烈的掌声。毕业生代表苏德银、麦振峰同学表示，感谢董事长的寄语、院长的希望、老师们的祝福，美好的大学校园生活，我们将永远珍藏在记忆里，永远不忘恩师的教诲，永远记住母校给我们提供的成长平台。
