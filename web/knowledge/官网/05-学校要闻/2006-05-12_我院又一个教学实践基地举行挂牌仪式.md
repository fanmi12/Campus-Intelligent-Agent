# 我院又一个教学实践基地举行挂牌仪式

3月16日，我院党委书记朱志德同志、副院长林世俊教授、机电系主任黄健求教授来到东莞市金业机械有限公司。在公司厂长陪同下举行“东莞理工学院城市学院教学实践基地”挂牌仪式。

据悉，东莞市金业机械有限公司主要是作为我院机电系的教学实践基地之一。今后，我院将与东莞市多家企业合作建立“东莞理工学院城市学院教学实践基地”。
