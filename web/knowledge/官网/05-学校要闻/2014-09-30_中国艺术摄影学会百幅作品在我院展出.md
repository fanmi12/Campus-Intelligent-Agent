# 中国艺术摄影学会百幅作品在我院展出

在中华人民共和国成立65周年、城市学院建校十周年之际，9月30日，中国艺术摄影学会部分会员100多幅优秀摄影作品在我院图书馆中厅展出，其中包含我院顾问杨元惺先生的10多幅摄影作品。这些作品，其创意手法多样、题材视角广阔、精神内涵丰富，不仅给我们带来愉悦的视觉享受，更充分映射出摄影人的创作灵感，极大反映出美的真谛。摄影作品并非简单的视觉再现，它融入了摄影家的思想与情感，用画面体现出对大自然奇美景色的赞许、对异域风情的好奇、对祖国山河的热爱。

据悉，中国艺术摄影学会是由文化部主管，民政部注册的国家级社会团体，协会主要工作是弘扬社会主义文化，为摄影工作者和广大摄影爱好者提供有效的学习创作和交流平台。

本次作品展展出时间从10月1日至10月20日，欢迎师生员工及摄影爱好者前去观赏。
