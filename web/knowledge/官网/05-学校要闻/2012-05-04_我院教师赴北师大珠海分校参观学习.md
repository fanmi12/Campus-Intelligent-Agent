# 我院教师赴北师大珠海分校参观学习

4月26日，我院艺术系主任邓星明教授、马新川教授带领舞蹈、影视表演方向专业教师，前往北京师范大学珠海分校艺术与传播学院参观交流。该校艺术与传播学院院长桂青山教授，副院长、党总支书记蔡申教授，副院长王跃教授以及相关部门负责人热情接待我院教师。

两校老师就艺术专业的人才培养方案、课程设置及教学相关的问题进行了深入的交流，并参观了该校的艺术教学设施。邓主任表示，两校均属独立学院，学习交流很有必要，此次参观学习收获很大。桂院长也表示，希望两校建立长期合作关系，不定期地进行交流，多联系，多往来。
