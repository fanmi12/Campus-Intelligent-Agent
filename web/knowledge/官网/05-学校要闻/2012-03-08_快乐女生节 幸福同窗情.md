# 快乐女生节 幸福同窗情

3月8日，男生们应该记住的日子——女生节。行动年年有，今年特别多。这一天，男生们神秘行动，各显奇招讨女生欢心；女生们惊喜连连，享受着公主般的待遇。校园里到处弥漫着快乐的气氛，上演一幅幅温馨动人的画面。

女生，“你就是我的唯一”

“oh baby，你就是我的唯一……独自对着电话说我爱你……我已不能爱你多一些……”动人的歌声从教学楼下传来，一首《唯一》唱出了所有男生的心声，也让女生们坐不住了。一个个激动地涌向窗口，等待着她们的是更多惊喜。只见几十个男生们围成两个心型，里外两层，大声地表白。女生们，感动了，疯狂了，她们有的在拍掌兴奋的狂叫，有的拿着手机拼命挤向窗台拍照，有的抓紧时间上微博晒幸福.......讲台上，也不知道何时响起浪漫的音乐，教室里的女生如痴如醉。而此时，楼下的男生集体大喊：“女生们，女生节快乐！！”掌声里，女生们带着三月最灿烂的笑颜。

微博，浓缩的都是爱

打开手机，进入微博客户端，一点刷新，里面全都是关于金融1234班男生惊天地泣鬼神的浪漫举动。黎同学的微博转发量不到10分钟就达到70多条。而其他系的同学都纷纷抛来羡慕的话语，直夸该系的男生太浪漫，女生太幸福。

@城院新校区金贸系：今天早上，金融专业的全体男生做了一件惊天地，泣鬼神的事件：男生大心围小心，场面温馨；女生爬窗围观，看着惊心；男生高歌唱唯一，女生欢喜；女生拍照齐欢呼，男生激动；爷们放声高喊：女生节快乐！现场的我们都被激动了，金融的女生们，你被感动了吗？
