# 我校举办新进教师入职培训活动

9月1日，55名来自全国各地的新进教师参加了由教师发展中心组织的入职培训。校长王卫平、副校长兼教师发展中心主任刘玉侠出席了开班仪式。

新进教师在人事处副处长张兰带领下，举行了入职宣誓。此次培训为期一天，安排了教师成长与发展、职业发展规范、现代教育技术等内容，将专题讲座与实操培训相结合，实操性较强。

王卫平校长向新入职教师表示热烈欢迎，期待大家在新的工作生活中不断进步，为城市学院带来新的活力。他强调，作为新时代高校教师要守住政治底线，严格遵守《新时代高校教师职业行为十项准则》，尊重学生个性，鼓励学生多元化发展，做学生的引路人；关注与研究课堂教学，打破传统教学方法，积极开展教学改革；兼顾自身进步与学校发展，荣辱与共，砥砺前行。

章德胜书记作了“师德修养与教师发展”专题主讲。他希望新老师们不忘初心，牢记使命；立足本职，教书育人；志存高远，爱岗敬业；创新立德，争做“四有”好老师；做学生的领路人，当学生健康成长的指导者和引路人；以主人翁的态度投身学校各项发展事业，为学校改革发展奉献智慧和力量。

副校长刘玉侠作学校发展与教师成长专题主讲，回顾了学校发展历程、办学理念和办学特色、办学成果、教师发展成果等，并解读了学校未来发展规划和发展愿景。

教务处处长赵书山解读了教学管理制度，财务处吴凡老师解读了财务管理制度，人事处副处长李海冬解读了人事管理制度，图书信息中心副主任陈显龙解读了馆藏资源利用,现代教育技术中心主任叶浩波讲解了多媒体教学设备使用。

另外，现代教育技术专题培训还邀请了雨课堂教学客户端培训专员开展实操培训。
