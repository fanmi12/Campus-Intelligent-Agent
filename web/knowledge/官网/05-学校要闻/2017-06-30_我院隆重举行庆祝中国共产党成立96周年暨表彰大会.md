# 我院隆重举行庆祝中国共产党成立96周年暨表彰大会

6月29日上午，东莞理工学院城市学院在学术报告厅隆重举行庆祝中国共产党成立96周年暨表彰大会。王卫平等院党委委员和院领导，全体教职工党员及学生党员代表参加了大会。会议由院党委副书记章德胜同志主持。

在庄严的党旗面前，院党委委员杜鹏举作为领誓人，带领学院新党员入党宣誓，老党员重温入党誓词。

大会宣读了《关于表彰2016－2017学年度先进基层党组织、优秀共产党员和优秀党务工作者的决定》，对财经系党总支、管理系党总支、文传系党总支、机关一支部、思政部党支部等5个基层党组织授予“先进基层党组织”称号；对宋艳、范琪、付妍、李钰等4名教工党员授予“优秀党务工作者”称号；对梁丹丹、黄文、罗萧等38名教工党员授予“优秀共产党员”称号；对郭君君、杨转佳、杜敬安等34名学生党员授予“优秀共产党员”称号，并颁发牌匾、荣誉证书。

优秀学生党员代表、财经系2017届毕业生蔡婉玲同学在大会上发言，回顾了自己从申请入党到成为一名优秀学生党员的成长历程，她回顾了自己在财经系学生党支部工作的点点滴滴。她表示，在党组织的培养下，锻炼了自己的能力，磨练了自己的性格，思想上有了质的飞跃。今后将继续以优秀共产党员的标准严格要求自己，努力学习，扎实工作，不辜负母校的培养，不辜负老师的教诲，为党的事业努力奋斗。

先进基层党组织代表、管理系党总支书记卢淑芳在大会上介绍了管理系党建工作的有关情况，重点从“重视‘三会一课’制度，增强党员四种意识；加强民主建设，促进系部和谐稳定；坚持党建引领促发展，营造积极向上的氛围；落实党员服务计划，发挥党员先锋模范作用”四个方面，介绍了管理系党总支在党建、科研、教学、学生竞赛、校园文化活动等领域取得的经验和成绩。

大会上，院长、党委书记王卫平回顾了96年来，党在革命、建设、改革的伟大历程和取得的伟大成就。他强调，重温党的历史，讴歌党的丰功伟业，就是要更加明确我们肩负的职责和使命。同时，王卫平书记还简要地总结了一年来，学院党委在贯彻落实党中央、各级党委的方针、政策，思想政治理论学习和党的建设等各方面取得的成绩与经验。

王卫平书记要求学院全体党员向受到大会表彰的优秀党员学习，希望全体党员牢记入党誓词，兑现誓言承诺，在“两学一做”学习教育中做表率，“廉洁自律，干干净净做事，明明白白做人”，不断开创学院党建工作新局面，推动学院各项事业健康发展，努力把我院建设成为特色鲜明的高水平应用型本科高校！
