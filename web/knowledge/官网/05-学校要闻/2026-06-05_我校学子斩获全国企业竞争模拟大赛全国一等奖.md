# 我校学子斩获全国企业竞争模拟大赛全国一等奖

5月30日至31日，2026年全国企业竞争模拟大赛全国总决赛在华北理工大学隆重举办。我校商学院物流与供应链管理系2023级物流管理专业1班、2班学生组建的琴心写艺团队，历经初赛、复赛、半决赛、资格赛多轮严苛角逐，从供应链决策赛道1800余支参赛队伍中突破重围，成功跻身仅3.5%晋级率的全国64强总决赛席位。

在全国总决赛的激烈比拼中，团队凭借扎实的专业功底、科学的决策思维与默契的团队协作，斩获供应链决策赛道全国一等奖。本次佳绩，既是我校省一流物流管理专业建设成果的生动彰显，也是《供应链管理》课程教学质量的有力印证，更是我校学子深耕专业、笃学善践、勇于争先的精神风貌与综合素养的绝佳展示。

全国企业竞争模拟大赛是国内高校极具影响力与专业性的特色商业模拟赛事，入选中国高等教育学会《全国普通高校大学生竞赛分析报告》官方竞赛目录，具备极高的学科认可度与赛事含金量。赛事由中国管理现代化研究会、高等学校国家级实验教学示范中心联席会经管学科组指导，中国管理现代化研究会决策模拟专业委员会主办，聚焦商科专业应用型人才培养，以真实企业运营场景为依托，搭建高校学子锤炼专业能力、创新思维与实战能力的优质平台。

2026年全国企业竞争模拟大赛共设置企业决策、企业运营、供应链决策、数智沙盘四大赛道。其中，供应链决策赛道聚焦实体企业供应链全流程运营，模拟大型牛奶生产企业的商业化运作模式，涵盖5类奶制品生产、5大渠道市场销售的完整业务场景。参赛团队需自主完成销售预测研判、合作渠道筛选、原材料采购规划、生产设备配置、生产计划排布、人力资源调配等全链条供应链决策，沉浸式模拟企业一年半周期的完整运营流程，最终以投资回报率（ROI）为核心指标评定赛事名次，全方位考核学生的供应链全局规划、数据分析、风险把控与战略决策能力。

赛事实践与专业教学深度融合，是商科专业知行合一育人理念的核心实践载体。通过本次赛事历练，学生得以沉浸式认知现代企业供应链的完整运营体系、组织架构与岗位职能，深度理解多部门协同运作的核心逻辑。同时，学生将课堂所学的计划管理、采购管理、生产管理、物流管理等专业理论知识落地应用于真实商业场景，熟练运用供应链SCOR模型完成业务拆解、局部优化与全局统筹，真正实现了从理论记忆、知识理解到实战应用、创新优化的全方位提升，有效夯实了专业核心能力，塑造了系统化的商业思维与供应链全局观。

本次备赛参赛工作由我校《供应链管理》课程负责人史祎馨老师牵头统筹，联合邹亮老师组建专项指导团队，科学制定系统化备赛培训方案，全程精准指导学生备赛参赛。两位指导老师深耕《供应链管理》《ERP》等核心课程教学，教学内容与赛事考核维度高度契合，为团队备赛提供了扎实的专业支撑。经学生自主报名、层层筛选，最终确定2023级物流管理专业秦子翔、陈依婷、林文欣三位同学组成参赛团队，冲击全国总决赛。

本次赛事为两位指导老师与参赛学生的首次参赛经历，无过往备赛经验可借鉴。为突破瓶颈、补齐短板，指导老师率先深耕赛事规则、钻研竞赛系统、拆解决策逻辑，同步组织学生全程参与主办方线上专项培训，逐模块梳理赛事核心要点。每轮模拟练习赛后，师生团队及时开展复盘总结，深度剖析各项决策对企业成本、利润、交付效率、库存管控的核心影响，依托Excel数据分析工具搭建专属分析模型，持续优化销售预测精度、安全库存配置、人力与设备规划方案，不断提升团队决策的科学性、精准性与有效性，为晋级总决赛、斩获大奖筑牢坚实基础。

历经多轮模拟训练与省级、国家级赛事的层层淬炼，三位参赛同学磨合出高效有序的分工协作模式，形成了各司其职、互补共进的作战体系。队长秦子翔统筹全局、把控整体战略方向，熟练操作采购、运营、销售、生产四大核心业务模块，精准统筹全流程决策；林文欣专注动态数据监测，实时跟进赛事特殊提示、仓库运营、财务报表等核心信息，同步更新关键数据，为团队决策提供精准数据支撑；陈依婷聚焦数据核验复盘，逐项核对各项填报数据，严控数据偏差，保障所有决策落地精准无误。科学的分工、严谨的态度与默契的配合，成为团队斩获佳绩的核心关键。

回望数月备赛参赛之路，三位同学在赛事淬炼中收获的不仅是荣誉与奖项，更实现了专业能力、协作能力、心理素质的全方位成长。备赛初期，团队配合生疏、思维各异、理念有别，在一次次磨合探讨、复盘优化中，逐步打破协作壁垒、凝聚团队共识，成长为优势互补、彼此信任、高度契合的作战集体。在高压、高强度的赛事比拼中，三人锤炼出沉稳严谨的处事定力与高效协同的协作思维，深刻吃透供应链全流程岗位职能与专业核心要求，真正做到了以赛促学、以赛促练、以赛促长。

此次赛事获奖，是我校坚持“理论教学+实践育人”融合式培养的丰硕成果，也是省一流物流管理专业建设提质增效的重要缩影。长期以来，我校物流管理专业始终立足应用型人才培养目标，深耕商科实践教学改革，坚持以学科竞赛为抓手，打通课堂教学与行业实战的壁垒，将专业知识、行业标准、岗位需求融入赛事实践，持续锤炼学生的专业核心能力与创新实践素养。未来，物流与供应链管理系将持续深化产教融合、赛教融合，依托物流管理一流专业建设平台，搭建更多高水平学科竞赛与实践创新平台，以各类赛事赋能人才培养，助力学子在专业领域深耕精进、逐梦前行，持续输出高素质、应用型的物流与供应链管理专业人才。
