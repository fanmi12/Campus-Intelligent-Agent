# 我院学子在省第十届武术精英大赛夺金

暑假期间，在海珠市体育中心举办的广东省第十届武术精英大赛上，我院武术队员获得4金2铜的骄人佳绩。

据了解，广东省第十届武术精英大赛由省武术协会、省少数民族体育协会联合主办，是国家推广武术的一项重要赛事，旨在推动岭南武术文化发展、大力普及群众体育运动。比赛设立百余个比赛项目，吸引了301个单位、6188人参加，是历届规模最大、水平最高的一次盛会。

我院武术队在教练李秋生老师的指导下，3名运动员一共获得4金2铜的骄人佳绩：卢慧芝同学获得陈氏传统太极拳金奖，规定器械32剑金奖；赵俊威同学获得自选传统太极拳金奖，传统太极短器械铜奖；莫建荣同学获得自选传统太极拳金奖，规定器械32剑铜奖。
