# 何涛、李嘉琪同学获市青年创业大赛“二等奖”

1月5日，由共青团东莞市委联合市经信局、松山湖经发局举办的“电商创业?圆梦东莞”2013年东莞市青年创业大赛总决赛在东莞市松山湖控股大厦一楼多媒体室举行，我院何涛、李嘉琪同学参加了总决赛并夺得 “二等奖”及5000元的扶持基金。

“电商创业?圆梦东莞”2013年东莞市青年创业大赛为期三个月开展，分为初赛、复赛和总决赛三个环节。青年11月和12月分别举行了初赛和复赛，我院共有21支队伍参加了该项大赛。经过激烈的角逐，我院何涛、李嘉琪同学组建的“1+7”参赛队伍顺利进入了总决赛并喜获佳绩。

据悉，“电商创业?圆梦东莞”2013年东莞市青年创业大赛所有入围总决赛的队伍均有机会获得推荐入驻创业孵化基地，符合条件的还可以获推荐列入东莞市经信部门的支持电子商务发展的扶持计划。
