# 我院学生在广东省高校第四届化学化工实验技能大赛中获奖

11月9日至11日，由广东省化工学会、广东省教育厅高等教育处、广东省化工学会高校化学化工专业委员会联合主办的“中鼎—铭科杯”广东省高校第四届化学化工实验技能大赛在东莞理工学院举行。

我院城市与环境科学系学生张丹纯、杨中志、黄文暖在比赛中获得三等奖。

据悉，全省共有22所高校、67名选手参加了本次比赛，我院是首次组队参赛。化学化工实验技能大赛旨在提高大学生化工实验操作能力，为广东省各高校师生提供一个学习交流化工实验水平的机会，激发学生热爱化学的热情。化学化工实验技能大赛已成为我省高校大学生最重要学科竞赛之一。
