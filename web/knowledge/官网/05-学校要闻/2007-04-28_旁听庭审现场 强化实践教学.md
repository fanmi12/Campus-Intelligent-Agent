# 旁听庭审现场 强化实践教学

4月27日上午，社科系法学本科专业学生一行36人在吴春庚老师的带领下到东莞市中级人民法院旁听行政诉讼庭审。

东莞市中级人民法院本次共审理两起行政诉讼案，历时3个多小时。同学们通过旁听活动，对行政案件的判决审理有了直观的了解，纷纷表示，旁听庭审不仅增长了对庭审程序的理解，提高对案例的分析能力，而且极大地调动学习法律的兴趣，激发了学习《行政法与行政诉讼法》课的热情，同时同学们也希望院、系多提供类似的实践机会，提高学习的实效性。
