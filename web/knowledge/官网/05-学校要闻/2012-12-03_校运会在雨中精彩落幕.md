# 校运会在雨中精彩落幕

风在刮，雨在下，运动会照常进行，运动健儿们比赛热情不减。两天的运动会，在风雨声中完成了所有的比赛项目，于11月30日下午精彩落幕。

院领导杨敏林、朱志德、朱冰、陈丁堂、章德胜、高香林出席闭幕式，盛赞今年的运动会精彩激烈，别有一番情趣。感谢体育教学部科学应对、周密部署，使运动会完美收官。

运动会总裁判长、体育教学部主任邢红林教授宣布获奖名单。据悉，金贸系代表队双双夺得全年体育竞赛总分第一名、学生组团体总分第一名，财经系代表队位居第二名，城环系代表队位居第三名。金贸系代表队还获得了男子团体总分第一名，女子团体总分第一名则由财经系代表队获得。总务处、城环系代表队并列教工组第一名，教辅代表队和文传系代表队学分别获二、三名。财经系、艺术系荣获学生组“体育道德风尚奖”，机关一代表队、管理系代表队获教工组“体育道德风尚奖”。

“雨幕中的校运会，犹如一幅动态的彩色水墨画，流淌着几分诗情与画意。”文传系杨衍明同学说，“不经历风雨，怎能见彩虹。”在两天的比赛中，参赛队员、啦啦队员不顾风寒雨大，或冒雨进行比赛拼搏，或为参赛同学鼓劲加油，其情其景，生动感人。高职部王伟杰同学不仅是校篮球队队员，还是铅球爱好者，去年他以10.55米的成绩打破了铅球校运会记录。今年，在极为不利的气候环境中，他仍然保持了去年的竞赛成绩。
