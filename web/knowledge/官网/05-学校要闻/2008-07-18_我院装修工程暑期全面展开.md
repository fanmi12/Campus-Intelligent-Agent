# 我院装修工程暑期全面展开

备受师生关注的教学楼装修工程已进入紧张的施工阶段。这些工程包括教学楼2、3 、5、6号楼，教学楼4号楼7楼排练厅，图书馆，饭堂，学生宿舍1号楼及樟村教学生活园教学楼室内装饰装修等。

据基建办叶树标主任介绍，这次教学楼的内部装修，充分体现和谐校园、人文校园的理念，设计风格简单大方，与校园环境协调统一，属中档次装修。目前，已完成30%的装修工程量。室内屋顶，墙面初装修以及楼梯等项目的装修也同步展开。教学楼外装和室内装修所用材料严格按照国家环保标准。为保证教学楼的装修质量和效果，基建办制定了严格的工程质量管理制度，聘请学院安全技术管理等专业的10名学生，担任暑期校园装修工程质量监理员，以确保施工质量，按时完成，不出差错。

据了解，为实现我院“上水平，创特色”的目标，院领导及基建办工作人员曾先后到香港大学、广州大学城、华南理工大学等院校学习取经。

据乙方工程队负责人介绍，整个装修工程于7月8日开始，预计工期35天。确保在9月1日前交付使用。
