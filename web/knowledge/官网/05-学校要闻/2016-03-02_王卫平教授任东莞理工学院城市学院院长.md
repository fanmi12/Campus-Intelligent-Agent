# 王卫平教授任东莞理工学院城市学院院长

3月1日下午，东莞理工学院城市学院中层干部（扩大）会议在行政楼112会议室召开。会议通报2016年东莞理工学院城市学院董事会第一次会议决议，宣布聘任王卫平教授为城市学院院长。

东莞理工学院校长李琳、党委副书记吕琦元、副校长杨敏林，以及东莞理工学院城市学院董事长麦照容、董事黎建烨等领导出席会议。

会议由东莞理工学院党委副书记吕琦元同志主持。

黎建烨董事代表东莞理工学院城市学院董事会通报2016年城市学院董事会第一次会议决议。麦照容董事长为城市学院新任院长王卫平教授颁发聘书。

麦照容董事长发表热情洋溢的讲话，他衷心感谢东莞理工学院长期以来对城市学院的关心和大力支持，衷心感谢前任院长杨敏林教授为城市学院筹建和稳定发展作出的巨大贡献，希望新任院长王卫平带领学院管理团队在机遇和挑战面前做得更好，把城市学院的各项工作推上新台阶。

东莞理工学院校长李琳教授发表了重要讲话，他希望城市学院借助办学母体——东莞理工学院全力建设高水平理工科大学的契机，在城院领导班子的带领下，团结广大教职员工，群策群力，抓住机遇，再创辉煌。

前院长杨敏林教授发表了深情的讲话，他回顾了在城院工作的难忘岁月，衷心感谢城院董事会、东莞理工学院、城院广大教职员工的理解、信任与支持，衷心祝愿城院的明天更美好，并表示将一如既往地关注和支持城市学院的发展。

新任院长王卫平教授发表了就职感言，他衷心感谢城院董事会、城院广大教职员工的信任，衷心感谢杨敏林同志对城院发展的无私奉献。他表示，要以身作则，努力做一个有人格魅力的人，在管理与服务工作上力求做一个“明白人”；带头聚精会神搞城院建设，一心一意谋城院发展。
