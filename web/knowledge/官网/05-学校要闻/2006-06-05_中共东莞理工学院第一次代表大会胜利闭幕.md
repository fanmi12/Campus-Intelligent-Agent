# 中共东莞理工学院第一次代表大会胜利闭幕

6月4日上午10时30分，中国共产党东莞理工学院第一次代表大会圆满完成会议预定的各项议程，顺利闭幕。刘树基同志主持了闭幕式。东莞市委组织部副部长陈柏南同志、新当选的党委委员和党代表、特邀代表等出席了闭幕式。

经过充分讨论和民主审议，大会通过了党委工作报告和纪委工作报告，通过选举王江水、安少华、刘树基、李忠红、邹晓平、杨振标、杨晓西、黄碧莲（女）、戴炳源（按姓氏笔画排列）等九位同志当选为中国共产党东莞理工学院第一届委员会委员。邓耀林、汪璟（女）、黄碧莲（女）（按姓氏笔画排列）三位同志当选为中国共产党东莞理工学院第一届纪律检查委员会委员。

大会号召，全院各级党组织、广大共产党员和师生员工要在学院党委的领导下，更加紧密地团结在以胡锦涛同志为总书记地党中央周围，以邓小平理论和“三个代表”重要思想为指导，全面落实科学发展观，结合东莞市社会经济文化发展地战略部署，居安思危，认清形势，进一步解放思想，振奋精神，开拓创新，实现学院持续健康发展，为早日把我院建成具有创新特色的名牌地方院校而努力奋斗！

大会在雄壮的《国际歌》声中结束。
