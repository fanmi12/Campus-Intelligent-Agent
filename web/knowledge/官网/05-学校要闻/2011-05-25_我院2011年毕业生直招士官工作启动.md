# 我院2011年毕业生直招士官工作启动

近日，根据东莞市军分区的统一部署，东莞理工学院武装部的工作安排，我院2011年毕业生直招士官工作已全面开展。

据悉，2011年士官直招报名时间是5月21日至31日。本次士官直招对象为机电系机械设计与制造及其自动化，计信系电子信息工程，高职部通信技术专业的男性应届毕业生。凡以上专业的男性应届毕业生，且年龄为18-24周岁（专科生不超过23周岁）的均可报名应征。报名地点：院学生处，联系人：凌继峰，电话：22680850、13827295144（理工/城院）短号：62169。
