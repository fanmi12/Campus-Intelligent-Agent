# 银联“闪付”登陆我院

我院移动支付继微信支付、支付宝之后，再添新军——银联卡“云闪付”。至此，学院食堂一机具有三种移动支付的“聚合支付”功能。5月18日，中国银联“云闪付”支付功能正式在我院上线使用，在学院各饭堂窗口均可使用具有“闪付”功能的银行卡或手机下载中国银联APP“云闪付”进行消费。同时，中国银联投入20万元开展消费返利优惠活动。

学院财务处经过精心调研和策划，强化“智慧城院”服务功能，本学期初推出了微信支付、支付宝等移动支付功能，受到了广大师生的好评，使师生在校园消费更为便捷。

5月，财务处联合中国银联和学院学生会共同推出了银联卡“云闪付”支付功能，在学院食堂等消费窗口开辟了银联卡“闪付”支付和中国银联APP“云闪付”移动支付的支付方式。为方便师生了解和使用新的移动支付功能，院学生会从本周起到6月底开展“银联二维码支付，超超超超省的！”宣传活动。中国银联更是投入20万元为使用“云闪付”的师生进行为期一个月的返利活动，凡是在食堂使用银联卡“闪付”消费达5元以上就会随机返还2元，返还的金额可在食堂消费。
