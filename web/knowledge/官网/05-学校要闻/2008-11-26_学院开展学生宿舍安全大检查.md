# 学院开展学生宿舍安全大检查

11月25日，学生处、保卫办、院学生会组织宿管中心及院系学生自律会200名师生，对学生宿舍的安全进行了大检查。

检查人员对1366间学生宿舍逐楼逐房地进行了检查。在检查中，检查人员一边宣传安全知识，一边排查安全隐患，听取学生和宿管员的意见与建议。同时，还收缴了违规使用的90多件大功率电器。

据学生处赵秋萍老师介绍，被收缴的大功率电器将集中存放在辅导员值班室，待本学期结束时返还给同学。
