# [群众路线教育]我院召开“查摆问题、开展批评”环节工作会议

6月5日，我院党的群众路线教育实践活动领导小组在212会议室召开工作会议。会议传达广东省委教育工委“群众路线教育实践活动工作交流会议”精神，印发《关于调整党的群众路线教育实践活动查摆问题、开展批评环节工作安排的通知》文件，部署“查摆问题、开展批评”环节下一步的工作。党委委员、院内各单位党政主要负责人参加了会议。会议由党委书记王卫平主持。

王卫平书记传达省教育工委教育实践活动工作交流会议精神。他指出，广东省委教育工委为了进一步推动全省高校教育实践活动的深入开展，安排 8所高校在会上介绍有关经验。省委教育工委最新的指导意见与典型单位的经验，对我院下一步的工作具有示范指导作用。

王卫平书记强调，各单位要高度重视“查摆问题、开展批评”环节的工作，全体党员、干部要认真贯彻落实广东省委教育工委指示精神，紧密结合学院实际，坚持时间服从质量的原则，把好活动质量关。认真做好专题民主生活会和各专题组织生活会的准备工作。撰写“对照检查材料”要紧扣主题，开门见山，突出重点，既要联系工作实际，又要触及思想灵魂。要正视矛盾和问题，讲真话、讲实话；要认真思考，正面回应干部群众所提出的意见，拿出实实在在、明确具体、便于操作的整改措施。

王卫平书记要求，要进一步学习领会习近平总书记系列重要讲话精神特别是在兰考调研指导教育实践活动时的重要讲话精神，以“为民、务实、清廉”为主题,狠抓作风建设。坚持边学边查边改，促使党员、干部作风的进一步转变与典型单位的经验,促使党群干群关系进一步密切。
