# 王卫平书记、院长为学生上思政课

3月26日上午，王卫平书记、院长在7A309为政法系2016级社工专业学生上了一场生动的思想政治理论课。

王卫平书记以《高举新时代中国特色社会主义伟大旗帜——努力学习贯彻党的十九大精神》为题，向同学们传达了党的十九大精神。王卫平书记通过八个方面的讲解，让同学们较好地学习和掌握了党的十九大精神。这八个方面是：党的十九大主题以及主要成果、习近平新时代中国特色社会主义思想、过去五年的历史性成就和变革、中国特色社会主义进入新时代、我国社会主要矛盾已经发生变化、两个一百年奋斗目标的战略部署、我国经济社会发展重大战略部署、坚定不移推进全面从严治党。

王卫平书记还从中央层面、地方层面及学校层面的动态和要求，带领同学们深入学习、努力贯彻党的十九大精神。王卫平书记传达了全国“两会”的精神和成果，要求同学们坚持以习近平新时代中国特色社会主义思想为指导，全面贯彻落实党的十九大和十九届一中、二中、三中全会精神。

王卫平书记还语重心长地指出：作为新时代的大学生，应树立新时代、新起点、新作为的观念，在思想、行动上积极响应党中央和国家的号召，争做新时代的合格劳动者和创造者。他希望同学们坚定理想信念，志存高远，脚踏实地，勇做时代的弄潮儿，在实现中国梦的生动实践中放飞青春梦想，在为人民利益的不懈奋斗中书写人生华章！
