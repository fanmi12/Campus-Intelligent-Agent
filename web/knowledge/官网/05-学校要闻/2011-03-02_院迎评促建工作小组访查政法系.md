# 院迎评促建工作小组访查政法系

2月28日，迎评促建工作小组组长李先庆副教授率评建办老师访查了政法系法学、行政管理两个申报授权专业迎评促建工作的开展情况。

政法系有关人员向院迎评小组汇报了评建工作情况。系主任刘杰教授就专业建设与发展规划、本科教学工作、实验室和实习基地建设、师资队伍结构等具体事项与评建办的老师们进行交流，提出了一些建设性意见。危兆宾博士和林晓老师根据本专业的特点，提出了专业负责人及外聘教师的教研科研成果归属、实践教学环节实施等问题。

李先庆副教授充分肯定了政法系的评建工作。他指出，现阶段迎评工作要贯彻《东莞理工学院城市学院新增学士学位授权单位评审佐证材料目录的通知》精神，各教学单位要在3月10日之前收集好相应的佐证材料，按照《系级教学管理档案目录》做好各项迎评具体工作。李先庆副教授还结合政法系专业实际就实验教学及电子政务实验室建设等问题与该系教师进行了深入交流和探讨。
