# 院羽毛球队参加全国大学生羽毛球锦标赛

第十七届全国大学生羽毛球锦标赛于7月26日-31日在湖南师范大学举行，本次比赛由中国大学生体育协会羽毛球分会主办，湖南师范大学承办，是我国大学生羽毛球最高水平赛事。

本届比赛共有来自全国89所高校1067名运动员参赛。他们当中不乏国内羽坛高手如鲍春来、郑波等老牌世界冠军，还有近两年涌现出的羽坛新秀。我院是此项赛事创办历史上唯一一支参赛的独立学院队伍，作为首次参加全国大型赛事的队伍,我院男单选手周宇、男双选手黄德才、曹智杰均打进男子组32强,这个成绩对我院羽毛球队来说有着划时代的意义，同时也是对教练员、运动员长期辛勤训练的肯定。
