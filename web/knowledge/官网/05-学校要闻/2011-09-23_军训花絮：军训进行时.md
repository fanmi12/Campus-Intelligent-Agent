# 军训花絮：军训进行时

300“女兵”练习旗语操

整齐划一的队列训练

拉歌300“女兵”练习旗语操9月20日上午，运动场上，英姿飒爽的300名“女兵”手持红黄彩旗，以方阵形式列队，跟随教官不断变换着挥旗姿势，并进行方阵变换，挥旗显示着力量。

“女兵”们用自己有力的肢体动作所诠释的正是海运队伍中的“语言”之一“彩旗语”。据教官介绍，以立正姿势为起，左手向上抬45度为“A”，90度为“B”，135度为“C”……每一个动作都代表一个字母，共有27个。其使用方法是以动作表现出字母，以此拼出汉语拼音以达到传递信息的目的。

教官介绍，彩旗语在海军队伍中是重要的通讯“国际语言”，即使在通讯工具不断发展的今天，舰队在海面执行任务时，双方都以彩旗语来快速传递信息。由于其具有优秀的保密性、隐蔽性、利于秘密通信等特点，至今仍是海军官兵的一项必修课。

据悉，精彩的彩旗语表演将在9月28日的晚会中演出，届时，我们将能一睹这“海上语言”的风采。

“快乐训练法”让军训变得快乐有趣9月20日，是我校军训的第二天，军训场上出现了别样的训练法——快乐训练法。

与昨日不同，今天教官们一改“严厉”的训练方式，通过唱军歌、拉歌、讲英语等轻松有趣的训练方式让同学体会现代军人风貌及训练的乐趣。

军训场上军歌嘹亮

“11连，very good !”。9月20日中午，11连的同学们在训练场上与教官互动口号，并高唱军歌《人民海军向前进》。

11连的王甫教官采用了军歌、口号的形式调动了学生的军训热情。他指出，只有真正调动了学生的兴趣和积极性，才能真正达到军训的目的。他希望通过趣味训练法，提升同学们的兴趣，让同学们更好地传承军人的精神，发扬不怕苦、不怕累的精神。

细微之处现关心17连的教官李珂明在同学的眼里和蔼可亲。他提倡军训也要注意身体，不要硬撑。同时，也主张快乐训练法，即少批评、少惩罚，让同学们更能适应。但在训练时，教官也不失严格，仍然手把手耐心教导同学们做好每一个动作。

对于这样的快乐训练法，同学们纷纷表示很受用：“木有压力，军训，hold住！”
