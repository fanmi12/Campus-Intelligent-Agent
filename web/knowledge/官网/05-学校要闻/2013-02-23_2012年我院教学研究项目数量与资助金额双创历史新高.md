# 2012年我院教学研究项目数量与资助金额双创历史新高

2012年我院教学研究项目获省、市立项数目及财政资助金额，双双创下历史新高。

据了解，去年我院共有57个项目获得广东省高等教育质量工程项目立项。其中，教育教学改革项目3项，大学生创新人才培养实验区项目1项，大学生实习基地项目1项，工程训练中心项目1项，大学生创新创业计划训练项目50项，共获省财政资助104万元。

另外，学院还获得广东省民办教育专项资金项目1项，获省财政资助100万元。获东莞市民办教育专项资金项目1项，市财政资助经费为50万元。据统计，我院全年共获省、市财政资助254万元。
