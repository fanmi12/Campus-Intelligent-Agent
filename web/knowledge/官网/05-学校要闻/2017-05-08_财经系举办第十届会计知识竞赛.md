# 财经系举办第十届会计知识竞赛

5月5日，财经系在学术报告厅举办了第十届会计知识竞赛决赛。高香林副院长前往祝贺，教务处处长牛熠、财经系主任罗卫国、财务处处长余竹根、管理系书记卢淑芳，以及东莞理工学院张新建老师、东莞职业技术学院陈少华老师观看了比赛。

罗卫国主任在致辞中，肯定了会计知识竞赛在磨砺中不断地跨越与完善，有效地将专业知识的学习延伸到了课堂之外，创造性地开辟了每年历时两个多月的教学第二课堂。他鼓励同学们在本次大赛中巩固所学，学以致用。

经过初赛激烈角逐，追梦三人行、头脑风暴队、缘梦队、积极队、突击队等五支队伍脱颖而出，进入决赛。决赛分为60秒快速连答、急速抢答、眼明手快、实操技能大比拼以及风险题环节等五个环节。第一个环节60秒快速连答和第二个环节急速抢答，一开始便让比赛陷入了紧张而激烈的氛围中，其中头脑风暴队凭借快速而准确的答题效率，率先拿下了55分的加分，以255分暂居第一名。在“眼明手快”环节中，选手们表现优秀，上演了一场手指翻飞的“速度与激情”。辨别各国的货币也成为了比赛的一大亮点，现场观众答题拿真钞的互动环节也将气氛推向高潮。

经过激烈竞争，最终头脑风暴队脱颖而出，荣获本次会计知识竞赛决赛冠军; 追梦三人行、积极队以良好的成绩获得第二名；缘梦队、突击队获得第三名。此外，经过七天的系部微信公众号平台投票累计票数显示，追梦三人行夺得了最受欢迎团队奖。

据了解，财经系自2007年起举办会计知识文化月，今年恰逢十周年。活动包括会计知识竞赛、财会技能宣讲会、会计职业发展规划宣讲会、会计知识讲座、财会技能趣味游园会、“金手指”财会技能大赛等，成为财经系最具代表性的专业活动，深受师生好评。
