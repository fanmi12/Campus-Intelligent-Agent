# 《我在回忆里等你》——广播剧海选火热进行中

9月22日，由东莞广播电台主办，城院广播台承办的“广播剧海选活动”正式开始。据悉在海选开始前，就已有120名同学报名。

本次海选引起了新老校区各年级同学的广泛关注，来自2011级的欧海欣是女作家辛夷坞忠实粉丝，尤其对《我在回忆中等你》情有独钟，因此第一时间报了名。 来自2009级人力资源管理专业的沈欣欣经验丰富。沈同学十分钟爱表演、主持、唱歌等文艺活动。对于广播和主持，她有着一颗充满激情的心。寮步校区的一名2011级新生的突然到来让现场的评委们都很震惊。原来这个2011级的女孩子叫做贡文文，是在微博上得知这次海选活动的，海选当日，她向辅导员和教官请了假，欣然赶往海选现场。

据悉，本次海选人员分为演员组、文案编辑组及音乐剪辑组。其中文案编辑组主要负责剧本的编写，演员组负责角色演绎，而音乐剪辑组则是负责音乐的挑选和剪辑工作。

本次大赛的初赛和复赛将在10月份进行，敬请关注！
