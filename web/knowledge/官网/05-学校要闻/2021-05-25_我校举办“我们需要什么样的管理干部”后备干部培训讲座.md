# 我校举办“我们需要什么样的管理干部”后备干部培训讲座

5月21日下午，我校开展中青年后备干部专题培训。校党委书记章德胜作“我们需要什么样的管理干部”专题讲座。

章书记引用习近平总书记在2020年秋季学期中青年干部培训班的精神讲话，希望各位后备干部学习领会习近平总书记重要讲话精神，必须牢记初心使命，勇于担当作为，善于攻坚克难，不断提高解决实际问题能力，努力把解决实际问题作为打开工作局面的突破口。章书记指出，为应对现代高等教育的发展变化，年轻后备干部应加强学习，要努力提高政治能力、调查研究能力、科学决策能力、改革攻坚能力、应急处突能力、群众工作能力、抓落实能力等七种能力。章书记强调，广大后备干部们要主动适应现代高等教育出现的各种新情况、新问题，在新的发展时期要树立现代大学理念，促进教育创新，强化“一个意识”，即服务意识；树立“二个观念”，即科学发展观和正确的政绩观。善于捕捉时机，抓住机遇，从全局的高度来设计规划，制定目标，谋划未来，促进各项工作的全面、协调发展。章书记希望，年轻干部要切实提高解决实际问题的能力，在提升自身能力素质中固本强基，必须稳扎稳打向前走。要敢于担当、在真抓实干中开拓新局。
