# 城市学院2014年教职工排球赛落幕

11月13日，经过半个多月的精彩对决，我院2014年教职工排球赛在综合馆落幕。机关一代表队夺得第一名，第二名由计信系代表队夺得，第三名花落教辅代表队。

决赛当天，机关一对体育教学部，两支队伍藏龙卧虎，比赛过程中精彩不断，最终体育部以3:0领先机关一，根据比赛规则，机关一和体育部并列第一名。

计信对教辅的比赛看点多多。比赛前两局，计信队以2:0领先教辅，第三局教辅队不甘示弱，硬是把比分追平。计信队凭借过硬的技术把比分拉大，夺得本次排球比赛的第二名。
