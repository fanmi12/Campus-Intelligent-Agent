# 四教师走上管理工作岗位

我院一批青年教师脱颖而出，成为教学和管理骨干。最近，方妙英、尹建明、杜鹏举、刘红艳老师被学院任命为有关科室负责人。

这四位同志都是最近三年先后在我院参加工作的青年教师。方妙英，女，广东东莞市人，2005年10月毕业于英国巴斯大学，硕士研究生学位，任人事处人事科副科长；尹建明，男，广东东莞市人，2005年7月毕业于华南师范学院，硕士研究生学位，任人事处师资科副科长；杜鹏举，男，河南新郑市人，毕业于河南理工大学，曾担任河南理工大学经济管理系学生会主席，学士学位，任学院团委副书记；刘红艳，女，广东梅州市人，毕业于星海音乐学院，学士学位，任学院工会办公室副主任。
