# 我院一研究项目获国家自然科学基金立项

2012年度国家自然科学基金项目立项结果近日揭晓。由我院院长杨敏林教授为负责人研究的项目“低温余热除湿的分布式能源系统及其集成机理研究”获准立项。

据悉，该项目为面上项目，研究经费80万元，是我院首次获得的国家自然科学基金项目。至此，我院获得的国家社会科学基金项目、国家自然科学基金项目均实现了零的突破。
