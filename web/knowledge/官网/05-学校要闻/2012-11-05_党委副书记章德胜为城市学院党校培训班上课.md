# 党委副书记章德胜为城市学院党校培训班上课

10月25日，城市学院党校第十三期培训班第二课分别在新老校区开讲。老校区由党委副书记章德胜同志做党课报告，新校区由宣传部部长何鹏举教授再做党课报告。近500名发展对象参加听报告。

章副书记的培训课以“做最好的自己，做合格的党员”为主题，通过形象生动的个案给同学们讲述了作为一个城院人，应结合自身实际情况挖掘自身的潜能。只有做最好的自己，才能做一名合格的党员。同学们应该在学习和实践中不断提高自己，努力学习党的知识，端正入党动机，向党员学习，充分发挥模范带头作用。

最后，章副书记介绍了入党的相关要求。
