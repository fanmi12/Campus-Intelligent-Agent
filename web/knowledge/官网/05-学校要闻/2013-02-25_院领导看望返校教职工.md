# 院领导看望返校教职工

23日、24日是教职工返校报到的日子。上午9时，院领导杨敏林、朱志德、朱冰、张林、陈丁堂、章德胜、高香林、麦绮琳在院办主任黄兢的陪同下，到机关各处室、各教学系部看望上班的教职工，为大家送上新春的祝福。他们看到各单位正在积极准备开学工作，教职工们情绪饱满，满脸阳光，感到非常高兴。

据悉，各部门在岗教职工返校率达百分之百。各单位在返校的第一天就召开了工作会议，安排部署新学期的工作。

院领导们感谢大家在过去一年里为学院所作出的贡献和努力，期望大家在新的一年里团结协作，克服困难，创造新的业绩，为学校和东莞地方经济的发展多作贡献！
