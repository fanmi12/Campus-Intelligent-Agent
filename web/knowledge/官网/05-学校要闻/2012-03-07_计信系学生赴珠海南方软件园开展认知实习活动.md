# 计信系学生赴珠海南方软件园开展认知实习活动

3月3日，我院计信系软件工程专业42名同学，在白晨明、彭义春老师的带领下赴珠海南方软件园开展认知实习活动。

珠海永亚软件培训中心市场部兰州平经理和张涛经理带领师生们参观了珠海南方软件园各经济实体，并介绍了软件企业的学员、职工的生活、工作环境以及已入驻软件园的国内外知名软件企业。兰经理针对同学们比较关心的软件产业发展及计算机专业学生的就业问题为同学们做了详细的描述，阐释了软件产业的大好前景，提醒同学们要“学以致用”，加强实践能力训练。
