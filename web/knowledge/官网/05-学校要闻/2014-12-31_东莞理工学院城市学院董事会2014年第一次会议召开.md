# 东莞理工学院城市学院董事会2014年第一次会议召开

12月29日，城市学院董事会2014年第一次会议在城市学院召开。

会议审议并通过了东莞理工学院城市学院董事会部分成员调整安排。聘任东莞理工学院党委副书记、校长李琳，东莞理工学院党委副书记吕琦元，城市学院党委书记王卫平，广东鸿发投资集团有限公司副总裁麦建红，东莞市鸿发教育投资有限公司总经理、城市学院院长助理麦绮琳为东莞理工学院城市学院董事会董事；李琳担任副董事长；免去杨晓西、王江水、安少华、麦燕娣、麦燕红的董事会董事职务。
