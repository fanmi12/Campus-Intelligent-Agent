# 我院召开本学年度心理工作总结暨表彰大会

6月15日晚，我院2016-2017学年度心理工作总结暨表彰大会在学生活动中心招聘大厅顺利召开。学院副院长周庆和学生处副处长罗文芳、学院团委书记李瑶、管理系党总支书记卢淑芳，以及学院全体专兼职心理老师、外聘咨询师和学生心理干部近200人参加了大会。

一段精彩的视频短片，回顾了过去一年学院心理工作的精彩活动和工作亮点。

对过去一年的心理工作和成果，学院心理健康教育与咨询中心主任余琼作了总结报告。

一批先进集体和先进个人受到大会表彰。财经系和管理系等两个二级心理辅导站被授予“优秀二级心理辅导站”荣誉称号；计信系和金贸系联合举办的第二届心理微电影大赛荣获优秀精品培育项目一等奖；计信系肖桓健等50位学生心理干部荣获优秀心理干部荣誉称号。

大会还对在第二届积极开展心理主题班会和第五届原创心理漫画大赛中，表现突出的集体和个人进行了表彰。获得优秀的心理干部代表和优秀二级心理辅导站代表分别做了总结发言。

深圳市原本教育研究院副院长孙合龙老师等七名知名心理专家被聘请为我院特邀心理咨询师。

罗文芳副处长在讲话中，对全体心理工作者提出了两点工作要求：一是要将学院心理工作摆在重中之重的位置，高度重视学院心理健康教育工作，确保校园的安全稳定；二是携手营造和谐人际关系氛围，每一个人都能够重视自身心理和身体健康，开心每一天，自信每一天，阳光每一天。
