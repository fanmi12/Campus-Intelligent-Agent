# “两学一做”专题学习教育网上线

由中央组织部主办、共产党员网承办的“两学一做”学习教育官方网站——“两学一做”学习教育网(http://lxyz.12371.cn)近日开通。

“两学一做”学习教育网是发布中央关于“两学一做”学习教育部署要求、推送学习内容、报道做法成效、宣传先进典型的网络平台。网站开设学党章党规、学系列讲话、做合格党员、工作部署、动态播报、观点评论、工作实务、党务问答、线上交流等栏目，全面及时地反映“两学一做”学习教育的开展情况。

学院主页“专题链接”栏目链接了“两学一做”学习教育网，欢迎广大党员积极

登录专题网站或输入网址（http://lxyz.12371.cn）登录学习。
