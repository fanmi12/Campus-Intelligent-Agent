# 揭牌！我校联合苹果成立“Swift Coding Club”

近日,我校联合苹果教育团队成立“Swift Coding Club”,并在图书馆举行了授牌仪式。

成立“Swift Coding Club”，旨在为学生提供实践iOS生态开发的平台，响应数字化时代对移动开发人才的需求。

信息与实验中心主任陈显龙、图书馆副馆长袁秀美、Apple中国教育行业客户总监王浩淼、Apple中国资深技术顾问马泉伟等相关人员出席授牌仪式。

授牌仪式现场，Apple中国教育行业客户总监王浩淼为大家详细介绍了Swift Coding Club项目。陈显龙主任对Apple一行表示热烈欢迎，并详细介绍了学校的基本情况、人才培养目标和特色等方面。随后双方对Swift Coding Club项目的拓展以及合作方式上进行深入探讨。

据悉，Swift Coding Club是一个全球性项目，主要是提升高校学生App开发技能，通过Swift Coding Club探索新技术、构建自己的App、建立人脉圈来寻找职业机会等，并有机会参加Swift Student Challenge项目。其中包括清华大学、北京大学、中山大学、华南理工大学等重点大学参与项目。

项目将给予全程培训、辅导并提供竞赛平台，每月/每季将组织线上、线下沙龙活动，通过活动交流，增加Swift Coding Club成员的开发能力。

近年来，学校始终坚持“创一流大学，办百年名校”，矢志打造一所创新性、应用型、国际化、特色鲜明的高水平大学的办学目标。紧紧围绕人才培养目标，持续深化教育教学改革，为国家教育事业高质量发展贡献力量
