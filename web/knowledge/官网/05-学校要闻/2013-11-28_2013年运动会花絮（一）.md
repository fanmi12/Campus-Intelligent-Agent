# 2013年运动会花絮（一）

“为了幸福你们太着急了”

——大学生记者：王源源

“为了幸福你们太着急了”，裁判员激动地说着。院领导们用羽毛球拍托着一个大大的皮球，参加“托起幸福”的比赛。还没等到裁判员打发令枪，他们就着急地抢先跑了。“托起幸福”这个项目寓意我们的院领导不辞辛苦，甘于奉献，用最真切的关怀托起我们城院莘莘学子的幸福。

一步一个脚印

——大学生记者：钟和芬

看，在布满阳光的赛道上出现了数个黄色大脚印，视线随着脚印前移，看到各系部领导已经做好开赛准备，只待枪声响起！啪！各赛员迈出了幸福的大脚，赛道旁响起了激烈的加油声，瞬间融入了“你追我赶”的气氛中，裁判员激昂的解说到：“脚踏实地的寓意就是印上每个脚印到达终点！”比赛气氛愈加热烈，每一位赛员都在赛道上用力印下他们快乐的脚印。看着这激烈的场面，裁判员情不自禁地喊到：“一步一个脚印的行动，每一步都要用点力气！”各系部领导都脚踏实地的踏入终点，就像他们一步一个脚印工作一般。

梦想启航

——大学生记者：龚玉杰

迎着温暖的阳光，城院新校区迎来了第三个校运会。开幕的表演可谓吸引观众眼球，由600多名的大一新生组成“梦想启航队”，穿着划一整齐的蓝色队服，挥舞着手中的扇子。手中的扇子不停地摆动，时而摆出2013的图案象征着2013级的新生为城院注入了新的血液；时而摆出城院的英文简称，预示着他们将在城院开启梦想之航。队伍流动着，瞬间出现了人群的十个圈圈，象征着城院十个系部，也预祝城院十周年的生日。看，现在队伍摆出了翱翔的海鸥，就像飞向梦想的蓝天。他们祝愿着城院广大学子将在这里健康成长。

2013届城院校运会首金出炉

——大学生记者：陈敏仪

校运会不仅仅是学生的运动盛会，更是老师们的运动盛会，它是属于整个城院的！

开幕式完满落幕后，本届校运会的第一场比赛如火如荼地在田径场上进行着——教职工“托起幸福”大赛。

老师们在赛场上意气风发，学生们则在赛道的两侧为自己的老师呐喊助威或者在终点那等候着老师的凯旋而来。

最终，朱冰老师和杨敏林老师以5.17秒的成绩并列“托起幸福”比赛的第一名，摘取了2013届城院校运会首面金牌！

粉丝“来袭”

——大学生记者：陈嘉琳

校运会的第一天，运动场上人头攒动。缕缕发丝在寒风中飞扬，学子们的呼喊声却愈喊愈大。看！足球场上教工们正在进行着激烈的二人三足赛。

一马当先的是一对男女教工，目光再聚焦，原来那靓丽的身影是文传系的苗琳老师。随着比赛的激烈进行，赛场边几名文传系数媒专业的女同学正举着海报卖力地为苗琳老师呐喊助威，她们兴奋地说：“我们是苗老师的忠实FANS！”。加油声逐渐变大，女生们随着老师的步伐加油到终点。

“加油，加油，呼……我们赢了”数媒的女生们欢呼着，脸上满是喜悦。而一旁的苗琳老师，雀跃地说：“像飞一样。”此刻，她们的笑声在风中回响!

寒风冷冽 文传递温

——大学生记者：梁珮琦11月28日上午，在看过了12和13级阵容庞大的师生团的精彩绝伦的开幕式表演后，各项赛事也在紧张筹备中的开始了。

“请各位跑100米的同学到起点准备”主持人在主席台上宣布着。由体育部的干事的带领下，一群英姿飒爽的运动健儿进入了我们的视线。一声声的枪响下，他们个个如离弦的箭般冲向终点，每个人脸上都露出必胜的神情。

在比赛进行一半时，“有同学大腿抽筋了，有谁会紧急处理吗？快来。”一位文传的同学焦急的喊着。只见一位女同学手抱大腿痛苦的坐在草地上，文传的啦啦队的同学们都一脸担心的在旁边照料。一位身穿运动服的女同学二话不说拨开人群立刻向伤者走去，用熟练的手法为她按摩，压腿。一边问着“哪里还痛？有没有好一点？”见伤者一脸痛苦，她便立刻把鞋子脱了，站在伤者腿上帮他舒展身体。直到受伤的同学情况好点了，她才放下心。

据了解，受伤的同学和帮助的女同学分别是商英的叶易凌和汉语言的钟添凤。她们分别是这一组的第一和第二名。虽然互不相识，但在比赛中钟同学那真诚关心同学的友爱之心，感动了在场文传的各位同学。让我们在寒冷的早晨便感受到了丝丝温暖。更体现了运动会中友谊第一，比赛第二，重在参与的精神。

机电霸“黄”花给力

——大学生记者：陈欣茹

当广播员宣布教工组８ｘ６０接力赛即将开始的时候，各系的老师就集中到了主席台前的跑道上准备比赛。身穿运动服的机电系黄老师最能吸引大家的眼球，只见她在不断地抖动手脚，放松肌肉，一会把手举到头上，用力拉直，站在旁边的我们似乎都能听到手指关节拉响的声音，可见黄老师对比赛的重视度有多高啊！

紧接着，指挥员说各系老师准备的时候，黄老师就做好了准备动作，跨好马步，挺直腰板，伸开有力的手臂，把手臂绕过指示牌，再伸开手掌，拇指向上，准备接棒，这每一个动作都是准确至极的，黄老师这机电系霸＂黄＂花的称号可真是当之无愧。比赛在激动中进行着，激情的赛场加油声给我们的老师带来了精神上的支持，黄老师也不甘落后使出浑身解数，一个箭步，就在一个快门按下的时间里已经把棒传到了另一位队友的手中，现场瞬间沸腾，同学们呼喊道“老师加油”。

最后当记者再次见到黄老师的时候，黄老师说：“希望机电系加油，这次比赛自然也希望可以拿第一啊！”说完后黄老师迈着轻松的脚步离开赛场，也给运动场留下了一串动听的笑声。

决战60秒

——大学生记者：吴炳然

校运会首日，男女教师组一分钟跳绳比赛九点钟后相继在篮球场展开激烈角逐。清晨微雨过后，气温较低，但无损热情。比赛一开始，“刷刷”的绳子挥舞声伴随教师们上下跳跃驱散了一点寒气：选手驾轻就熟，众人卖力“加油”，裁判念念有词……这些平时深藏不露的老师们一个个卯足了劲，轻身如燕，矫若游龙，一改以往讲台上授业解惑满腹经纶的严肃形象，让人叫绝之余倍感亲切。“女生组在跳绳这一项目上表现更佳。”裁判员对记者说。

比赛结束，经过统计，吴士田与龙乐源老师以171次的成绩并列男子第一，女子组张利敏则以181次的出色表现傲视群芳，遥遥领先。
