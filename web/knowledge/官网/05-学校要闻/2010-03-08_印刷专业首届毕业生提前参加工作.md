# 印刷专业首届毕业生提前参加工作

印刷专业学生在彩桥公司实习（资料图片）

机电系印刷专业23名实习生全部被东莞市桥头镇彩桥印刷纸品有限公司录用为正式职工，春节后已上班工作。

据悉，这批学生是印刷专业首届毕业生，于去年10月进入华厦集团彩桥印刷纸品有限公司实习，时间为一年。由于他们专业对口，实习期间吃苦耐劳，善于钻研印刷技术，深得用人单位的好评，实习期间就与该公司签订了聘用合同。
