# 院领导与留校学生吃团年饭共迎新年

又是一年除夕来，每年学院总有一些同学由于各种原因不能回家过年。“每逢佳节倍思亲”，学院领导考虑到学生们的需要，特别准备了丰盛的团年饭，与同学们团聚，共贺新春。

1月22日中午，东莞理工学院城市学院院长安少华、党委书记朱志德、副院长张林带领总务处、学生处、院办、保卫办、莞城校区管委会部分老师员工与30多名留校学生一起，在老校区教工饭堂吃团年饭，共迎新年。

席间，院领导与学生们频频举杯，向他们传达新年的问候与祝愿，希望他们在新的一年里学业进步，身体健康。浓浓春意，款款深情，同学们也纷纷向领导们表达自己由衷的喜悦和对母校细心关怀的谢意。

餐后，同学们在饭堂唱起了卡拉ok，一片欢歌笑语。学生处还特别为同学们准备了新年利是，给他们送上一片祝福。
