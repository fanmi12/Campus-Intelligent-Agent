# 我院举办首届生涯认知体验日活动

4月18日，我院“首届生涯认知体验日”活动在综合馆举办，院领导王卫平、黄兢、周庆到场祝贺。东莞市教育局、东莞一中、东莞市第五高级中学、厚街中学、济川中学、万江中学、塘厦中学、常平中学、第六中学、广东亚视演艺职业学院、广东医科大学、广东酒店管理职业学院等学校领导、老师及我院学子近800人参加了活动。

黄兢副院长为开幕式致辞。招生就业处处长孔增强介绍了本次体验日的基本情况。

会上，王卫平院长向东莞市双赢智业企业管理咨询有限公司、中国平安人寿保险股份有限公司东莞中心支公司、平安普惠企业管理有限公司东莞分公司、深圳金拱门食品有限公司、广东智通人才连锁股份有限公司授予了“生涯教育合作单位”牌匾。

活动分为“自我探索”、“职业探索”和“行动计划”三个游戏区域，共设九个游戏，通过引导学生在游戏以及和生涯执行导师互动中，接受生涯意识的启蒙，从中学会自我探索、职业探索、职业规划。

据了解，我院是东莞首个举办此类创新性活动的院校，也是独立院校中首个自主举办生涯体验活动的院校。本届体验日活动创造了我院就业工作的“四个第一次”：第一次作为大学生职业规划课程的有效延伸，突破传统讲授式的课程教学模式，鼓励师生走出课堂；第一次以体验游戏让学生直接体验生涯知识，感受生涯魅力；第一次从“人职匹配”与发展的实际出发，搭建“校-企-师-生”多方面参与的平台；第一次邀请热衷于大学生生涯教育的名优企业，探索校企合作共赢模式。
