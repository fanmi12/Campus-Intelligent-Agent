# 我院师生踊跃为患病学生朱建伍捐款

连日来，计信系在全院开展了为患肾病综合症的朱建伍同学募捐活动。到目前为止，共收到捐款6.6万元。

据活动负责人邓邦荣同学介绍：朱建伍同学来自湖北省枣阳县一个偏僻的小乡村，他非常乐于助人，作为科技部部长的他，除了负责设计、维护系网络主页，组织各种大小型的科技竞赛活动，闲时还常常帮助其他同学维修电脑,并且是计信系电脑维修队的创始人。09年寒假，他被发现患肾病综合症，这一种治愈难度大、复发率高的综合疾病，他现在不能如期归校，只能继续在医院接受治疗。而且，他家里的经济状况也十分窘迫。

据悉，捐款活动还在进行中，首笔捐款将于近日汇给朱建伍帮助他战胜病魔，早日康复。
