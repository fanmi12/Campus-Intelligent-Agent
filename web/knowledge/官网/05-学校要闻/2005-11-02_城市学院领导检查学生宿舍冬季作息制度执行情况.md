# 城市学院领导检查学生宿舍冬季作息制度执行情况

11月1日晚，在城市学院党总支书记朱志德、副书记朱冰的带领下，学生处全体老师和学生会50多名学生干部到学生宿舍楼检查同学们的作息情况。

昨天是我院实行冬季作息制度的第一天。按照《东莞理工学院城市学院学生宿舍管理规定》的有关规定，每周日至周四晚23：30至次日的06：30各学生宿舍楼准时关门和断电。

朱书记一行深入到全院9栋学生宿舍进行检查。晚上23：20分的三声断电提示长哨一过，同学们纷纷合上书本、关闭电脑准备就寝，各宿舍楼秩序良好，期间没有学生大声喧哗。

大部分的新老同学对冬季作息制度的实行表示认可和理解。05级人力资源管理的温智敏同学说：“每天晚上准时断电可以保证大家按时休息，第二天上课更有精神。”

据了解，为了保障学院冬季作息制度的顺利执行，学生会纪检部成立了自律会，负责检查学生宿舍楼断电后的秩序情况。
