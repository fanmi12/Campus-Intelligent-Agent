# 我院举行2017年治安、消防安全目标管理责任书签订仪式

为全面做好2017年治安综合治理及消防安全工作，12月21日，学院与院内各单位签订了2017年治安综合治理目标管理责任书及消防安全目标管理责任书。院长王卫平、副院长周庆及各单位负责人出席了签订仪式。

此次责任书明确提出各单位2017年度目标管理工作任务，要求各单位将治安综合治理及消防安全工作切实纳入日常工作计划。同时，学院将把该项工作任务纳入各单位考核指标体系之中，确保治安综合治理及消防安全工作落到实处。

后勤保卫处负责人袁秀美、副处长刘维仝汇报了2016年度我院治安综合治理及消防安全工作。

王卫平院长在总结讲话中，要求各单位要从思想上重视安全工作，防范于未然，保障学院各项工作有序开展。

会议由周庆副院长主持。
