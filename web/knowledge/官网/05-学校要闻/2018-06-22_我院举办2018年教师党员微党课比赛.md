# 我院举办2018年教师党员微党课比赛

6月21日下午，我院2018年教师党员微党课比赛迎来决赛，10位选手在行政楼112会议室进行了巅峰对决。学院党委书记、院长王卫平,党委副书记章德胜，副院长高香林、黄兢和广大师生党员代表一起观看了比赛。

学院办公室主任杜鹏举、党务工作部副部长叶凯贞、新闻中心主任熊劲松、人事处副处长张兰、思政教学部党支部书记史雍真担任现场评委。

来自计信系党总支选手贺丹等10位教师党员选手，通过精心制作的PPT展示和精彩娴熟的演讲，分别围绕“牢记时代使命，实现乡村振兴”、“党员志愿少年时，知行合一践青春”，“功成不必在我—不忘初心、牢记使命”、“青年的楷模、学习的榜样”、“端正入党动机，树立青年信仰”等主题，传授了党的理论知识，分享了自己的学习心得与体会。

经过激烈的角逐，创设陈浩老师获得一等奖，金贸系费长江、外语系蔡超明、政法系徐媛媛、城环系刘子瑜老师获得二等奖，电智院周杨景、计信系贺丹、机关第四党支部姜海波、商学院邓葵璋、文传系李祥老师获得三等奖。

据悉，学院党委将所有讲稿、课件及比赛视频存入学院党校课程数据库，并在各基层党组织推广学习。同时，推荐优秀选手代表学院参加省级微党课比赛。
