# 宋秋敏老师荣获“广东省民办教育优秀教师” 称号

近日，2014年广东省民办教育协会年会暨优秀教师表彰大会在广州召开。我院文学与传媒系宋秋敏老师获得“广东省民办教育优秀教师”荣誉称号。

据悉，此次评选活动由广东省民办教育协会组织发起的，受表彰的教师是我省民办教育教师队伍中的杰出代表。此次受表彰的优秀教师共294人，其中民办高校教师43人。

据了解，宋秋敏老师2008年6月博士毕业后进入城市学院工作,2012年10月南京师范大学中国语言文学博士后出站；2009年12月获得中国古代文学副教授资格。现兼任中国词学会理事、深圳市儒家文化研究会理事。多年来，宋博士致力于古典诗词在当代的现实意义与实用价值研究，发表专业论文70篇，出版学术专著两部。
