# 大运会莞城校区工作协调会在我院召开

3月21日，省第七届大学生运动会莞城校区工作协调会在我院4#315会议室召开。

东莞理工学院宣传部长、大运办副主任李培经同志首先介绍了广东省大运会的基本情况：本届大运会有98所高校参加，运动员人数达8531人，两项数目都是历届之最。其次，他讲到本届大运会的定位是：绿色环保、人文大运。办好这次大运会须具备的五要素：①、场馆设施要素，②、安全保卫要素，③、媒体宣传要素，④、组织服务要素，⑤、成绩要素。第三，他介绍了目前筹备进展情况，涉及到莞城赛区大家要做好的工作：①、是运动员吃、住、交通的安排；②、是宣传文化工作；③、是环境卫生和安全保障工作。他指出，做好大运会的工作要有大气、要细心、具体，抓好落实。

城市学院、成教学院领导和有关部门负责人参加了会议。
