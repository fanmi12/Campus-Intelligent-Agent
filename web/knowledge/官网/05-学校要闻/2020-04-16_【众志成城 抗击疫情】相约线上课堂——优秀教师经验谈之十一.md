# 【众志成城 抗击疫情】相约线上课堂——优秀教师经验谈之十一

我校坚决贯彻落实教育部、省教育工委、省教育厅的重要部署，从3月起全面开展线上教学活动，全体任课教师坚守岗位、锐意创新、勇挑重担，全力做好线上教学工作。前十期我们精选刊发了三十一位优秀教师线上教学经验谈后，在全体教师中产生了良好的反响，受到广大师生的欢迎和点赞。今天刊发第十一期，推介艺术学院臧莹竹、外国语学院刘娜、文学与传媒学院郭戈三位老师的线上教学心得体会，供大家分享。

外国语学院刘娜老师线上教学心得体会：经过了几周的线上教学，慢慢地把握住了新的教学节奏。在讲解课文的同时，评论区和聊天框即时可以看到同学们的回应，对比课堂教学，互动和反馈更加迅速，教师可以随时调整讲课的重点及要点。课前发布任务，课堂精炼讲解，课后布置作业，线上线下紧密结合。任务和作业形式也不再局限于纸质书写作业，可以更加多样化，例如视频作业，在线作业等。虽不在同一个教室，但网线的两端，将教师与学生紧密联系在一起。

艺术学院臧莹竹老师线上教学心得体会：一场疫情打乱了全国上下所有学校开学的节奏。上好网课，实现线上教学成了我们这学期最大的考验。由于表演专业的特殊性，我们的教学方式与学生的互动性较强。我先从网上学习了相关专业的线上课程，总结经验，结合本学期的教学任务及时调整教学方式。课前做好充分准备，课程中通过直播+会议的模式完成教学（直播模式时主要进行示范及知识点讲解，会议模式时进行线上小组讨论和答疑），课后布置作业让学生发表演视频进行知识巩固。

目前学生积极性较高，学习主动性强，线上教学顺利进行。隔离病毒，但没有隔离学生求知若渴的心灵，也没有隔离老师们对教育的满腔热忱，更没有隔离老师对学生无私的关爱。停课不停学，教师和学生一同学习，一起成长。每一名老师和学生都相信，风雪过后，室外依然会阳光明媚。

文学与传媒学院郭戈老师线上教学心得体会：我的体会是：直播网课是以所授课程内容为主体，以网络音视频传输为载体，以电视（视频）节目直播为手段，以广播（音频）节目直播为辅助，让以上各种技能有机结合并服务于教学活动，让学生通过新的授课形式，结合互联网思维，理解知识要点。

需要授课教师不仅对所授课程驾轻就熟，同时也要对所使用的直播设备、直播思维运用自如。要求教师的综合能力很强并富于创新。线上授课形式决定了其属性为去中心化的互联网思维模式，更适合启发式教学。

线上教学也适合于语言类课程。因为现在正是网络视频直播时代的开端，让学生们在课堂上就开始进行正规的直播实践训练，有利于日后应对社会发展的大趋势。
