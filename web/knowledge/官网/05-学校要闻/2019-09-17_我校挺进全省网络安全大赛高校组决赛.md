# 我校挺进全省网络安全大赛高校组决赛

第三届广东省“强网杯”网络安全大赛自8月23日开赛以来，我校图书信息中心组建的“东莞城院网安小组”战队一路过关斩将，进入广东省高等院校组前20强，挺进决赛。

本次大赛是省内最高规格的网络安全赛事，是由广东省委网信办、省教育厅、省科技厅、省工业和信息化厅、省公安厅、省国家安全厅、省通信管理局联合举办，参赛对象来自省内各党政机关、关键信息基础设施运营企业、网络安全相关企业和各高等院校，并以组队的形式参加。

我校是全省独立学院和东莞地区高校中唯一一支进入决赛的队伍（详见决赛队伍名单）。
