# 喜讯！我校四个专业喜获学士学位授予权

近日，《广东省学位委员会关于公布2021年新增学士学位授予专业名单的通知 》（粤学位函〔2021〕4号）下发，我校舞蹈编导、投资学、秘书学、工业设计四个专业顺利通过省学位办组织的学士学位授予专业评审，获得学士学位授予权。本次4个本科专业顺利获批学士学位授予权，是上级教育主管部门对我校教学质量、专业建设、人才培养的充分肯定。

我校于2020年9月启动新增学士学位授予专业审核工作，根据上级文件要求成立学校学士学位授予备案工作领导小组；制定实施方案；多次组织校内专家对受评专业进行检查，各专业根据检查中发现的问题逐项改进；邀请知名同行专家及学位教育管理专家对送评材料进行评审；召开学校学位委员会会议对各专业进行集中评审；根据评估专家意见进一步整改，并将备案材料上报至举办方东莞理工学院，经评审公示后上报广东省学位委员会。

截至目前，我校经教育部批准（备案）专业共45个，具有学士学位授予权的专业共38个。新获得学士学位授予权的专业将从2021届毕业生开始授予学位。接下来，学校将继续加强专业建设，努力提升人才培养质量，为地方经济发展人才需求和粤港澳大湾区建设培养高素质的应用型人才。
