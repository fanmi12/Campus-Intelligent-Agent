# 创院举行“记?印象”微世界大赛颁奖典礼

5月11日晚，由创意设计学院主办的“记? 印象”微世界大赛颁奖典礼及首映式在学术报告厅隆重举行。

在kpop韩流舞队火热的开场舞之后，典礼以“动静之间，光阴具现”为主题，将对入围的八部静态电影和七部微电影进行了首映及颁奖。

何靖雯同学获得静态电影一等奖，她以一句“真诚高于技术”分享给现场观众。微电影部分，作品《争分夺秒》、《一路有你》、《窃听风云4》、《当风筝遇上风》也各有斩获，其中《窃听风云4》荣获最受欢迎及最佳摄影两大奖项，《争分夺秒》获得最佳影片奖。

东莞市依米文化有限公司负责人分别将“依米”最佳男女演员奖颁给了微电影《窃听风云4》的欧阳启盛同学和《诚实的约会》的钟泳雯同学。

据介绍，本次大赛展现了城院青年人用镜头诠释梦想的激情，丰富了校园文化生活，提高了同学们对现代科技的运用、锻炼实践的能力，促进了校园影视文化艺术的繁荣与发展。

后勤保卫处负责人袁秀美、院团委书记李瑶和创院党总支书记何鹏举教授、副书记彭俐老师，与同学一同分享了这场视听盛宴。
