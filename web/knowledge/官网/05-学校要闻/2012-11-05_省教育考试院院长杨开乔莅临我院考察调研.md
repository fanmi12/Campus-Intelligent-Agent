# 省教育考试院院长杨开乔莅临我院考察调研

10月23日，省教育厅党组成员、广东省教育考试院院长杨开乔一行莅临我院考察指导工作，受到院长杨敏林、党委副书记章德胜、副院长高香林的热情接待，黄兢、陈建新、杜鹏举、孔增强等相关部门负责人在法商楼5A123会议室参加了座谈会。

会上，杨敏林院长简要汇报了学院的办学发展情况。杨开乔院长在听取汇报后用“三个非常高兴”肯定我院的工作，即有先进的办学理念、优质的校园环境、喜人的招生规模。同时，他也对学院的发展提出了期望：希望在现有基础上，进一步完善教学设施；注重内涵发展，办出水平、办出特色；积极探索人才培养模式改革。他还表示，省教育考试院会一如既往地支持城市学院的发展，全力做好服务工作。

最后，杨敏林院长感谢教育考试院长期以来对我院的支持，表示一定会落实省教育考试院领导的指示精神，统一思想，开拓进取，把学院的办学水平提上一个新的台阶。
