# “知法言道，正气扬”暨抗战胜利七十周年演讲大赛圆满落幕

5月19日，我院 “知法言道，正气扬”暨抗战胜利七十周年演讲大赛决赛在学术报告厅举行。院党委书记王卫平和400多位师生观看了比赛。

经过为期1个月的初赛、复赛、复活赛后，11名选手进入本次决赛。决赛演讲题目分为文字题和图形题，以抗日战争胜利70周年为主题，从不同的角度进行演讲，包括“关于老人跌倒扶不扶的讨论”、“关于食品安全的讨论”和“关于弘扬抗战时期顽强不屈的精神”等。

经过近两个小时的角逐，李志标同学以其朴实、生动的深情演讲，获得第一名；黄迪睿和彭江海分别获得第二名和第三名；贺涛和郑茜壬获得特别奖；李演文、汪雨辰、陈皇城、陈蒙蒙、成超和康乐伟获得表现优秀奖。

据悉，本次大赛是第二届全院性的演讲比赛。大赛采用了新颖的“导师制”培训方式，并以全场师生共同投票的方式评定名次。
