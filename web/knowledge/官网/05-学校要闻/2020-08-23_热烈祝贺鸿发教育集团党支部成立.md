# 热烈祝贺鸿发教育集团党支部成立

2020年8月15日，在中共鸿发集团党委的正确领导下，经中共莞城街道委员会批准同意，广东鸿发教育文化集团有限公司党支部正式成立了。

上午9:30时，鸿发集团党委召开党委换届选举大会。经民主选举，会上选举产生了鸿发集团党委新一届委员，鸿发集团副总裁、城市学院董事黎建烨同志当选为党委书记，教育集团总经理、城市学院董事长代表陈超群同志当选为党委副书记。

会上，由鸿发集团党委委员陈冠一同志宣读了中共莞城街道委员会《关于同意成立中国共产党广东鸿发教育文化集团有限公司支部委员的批复》。

随后，鸿发教育支部召开了支部选举会议，经民主选举，产生了党支部第一届委员，蔡小锋同志当选为支部书记，张俊玉、叶钰萍两位同志当选为支部委员。

鸿发教育集团历经十年，成立了公司党支部，表明公司在逐步走向成熟、走向壮大。相信在鸿发集团党委的坚强领导下，鸿发教育党支部将落实落细做好各项工作任务，扎实推进党组织建设，积极发挥党员引领和党支部战斗堡垒，以党建为公司快速发展“保驾护航”。
