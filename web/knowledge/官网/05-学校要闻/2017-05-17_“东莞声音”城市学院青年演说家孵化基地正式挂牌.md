# “东莞声音”城市学院青年演说家孵化基地正式挂牌

5月16日下午，“东莞声音”东莞理工学院城市学院青年演说家孵化基地挂牌仪式，在行政楼112顺利举行。东莞市精神文明建设办公室梁杰副主任、东莞市国税局松山湖分局黄湘梅副局长、“东莞声音”发起人王德青等嘉宾，学院党委副书记章德胜,院长助理、创意设计学院院长林江龙及有关部门负责人参加了仪式。

据“东莞声音”联合发起人、首届“我是演说家”全国十二强章早儿老师介绍，“东莞声音”城市宣讲团是以宣传“社会主义核心价值观”、传播东莞好故事、传递东莞正能量为主题的公益活动，得到了东莞市文明办、团市委的大力支持，正在东莞市各行各业中逐步开展。其中，“东莞说”青年演说家训练营——社会主义核心价值观进社区志愿活动，已经获得了2017广东省大学生创新创业创训计划项目立项。

挂牌仪式后，“东莞声音”青年宣讲团城市学院青年演说家孵化基地的学员代表，开展了主题为“我们，90后”的演讲活动。他们以“90后”青年的视角，以城市文化融合的参与者、城市文明的传承者、城市创新的践行者、城市发展的建设者的身份，讲述东莞文化、讲述东莞青年、讲讲述东莞故事，激起了大家的共鸣。
