# 八大企业将在我院招聘大学毕业生

5月24日(周日)上午9时30分，东莞市八德电子有限公司、东莞市东坑合利美电子电器有限公司、东莞市科成信息科技有限公司、上海科建管理咨询有限公司东莞分公司、东莞市骏友电子科技有限公司、宜欣有限公司（东莞桥头石水口宜欣塑胶厂）、东莞大器五金电子有限公司、敬业（东莞）印刷包装厂有限公司等单位，将在城市学院四号楼二楼(学生处门口场地)举行校园招聘会，诚招大学毕业生。参会的八大企业将提供超过60个岗位,望广大应届毕业生积极应聘。
