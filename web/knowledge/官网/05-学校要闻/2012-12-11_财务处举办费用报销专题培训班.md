# 财务处举办费用报销专题培训班

为了让教职工了解财务报账程序，提高工作效率与质量，财务处于12月4日举办了费用报销专题培训班。

副院长高香林出席会议并对与会人员提出了三点要求：一、全体教职工应树立成本效益观念，坚持实事求是的原则，严禁弄虚作假；二、财务人员应做好服务工作，积极配合各系部开展工作；三、各系部和财务处应在相互沟通和理解的基础上齐心协力把财务报销工作做好。

财务处徐世胜运用图例对报销流程、票据填写、审批权限等方面进行了讲解，同时对财务处人员分工及工作职责、对外报账的时间安排做了详细说明。

财务处处长余竹根针对各系部教工提出的问题一一做了解答，并提出“服务、严谨、廉洁、高效”的服务承诺。

据了解，财务处近期出台了一系列便捷服务措施，包括设立意见箱和窗口服务内容标识牌等。
