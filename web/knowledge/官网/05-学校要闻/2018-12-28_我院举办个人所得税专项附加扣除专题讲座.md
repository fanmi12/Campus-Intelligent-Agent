# 我院举办个人所得税专项附加扣除专题讲座

12月27日下午，我院财务处在学术报告厅举办个人所得税专项附加扣除专题讲座，旨在为广大教职工更好地了解新政策，切实享受到个税改革的红利。院领导高香林、周庆、刘玉侠和教职工一道聆听了讲座。财务处处长余竹根主持了讲座。

税务专家、东莞市税务局所得税科负责人黄焱应邀作了专题讲座。她从子女教育、继续教育、大病医疗、住房贷款利息、住房租金、赡养老人等六个专项附加扣除进行了详尽的政策解读，同时对个人申报个人所得税专项扣除的时间、办理途径、汇算清缴等事宜进行了详细的说明。

12月22日，国务院正式发布了《个人所得税专项附加扣除暂行办法》，从2019年1月1日起，包括子女教育、继续教育、大病医疗、住房贷款利息或者住房租金、赡养老人等六项专项附加扣除政策正式实施。专项附加扣除的施行将更好地兼顾纳税人的收入水平和负担能力，使税制更趋于公平合理。
