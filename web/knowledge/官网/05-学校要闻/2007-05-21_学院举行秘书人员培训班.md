# 学院举行秘书人员培训班

5月20日，学院在4号楼315会议室举办秘书人员培训班，参加此次培训的学员有各系、处室的行政秘书共30余人，学院行政副院长张林副教授出席培训班并讲话。

本次培训的内容有：秘书科

黄隆顺老师讲述秘书人员的基本素质、基本要求、学院办公办文的流程和规章制度；新闻中心

唐耀碧老师讲述文书写作的基本要求和必须注意的要点；院办副主任黄研晖老师介绍学院即将推行的办公自动化系统有关要求；图书信息中心

杨胤纲老师介绍办公自动化系统的使用方法。

学院党委委员、院办主任王玉表示，秘书培训班将继续办下去，以提高我院办公效率和办公质量。
