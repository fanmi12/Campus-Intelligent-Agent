# 我院召开第三届学术委员会会议

9月13日，我院在行政楼505会议室召开了城市学院学术委员会三届一次会议暨2012年学院职称申报评审会，会议由学院学术委员会副主任高香林副院长主持。

会前，张林副院长宣读了《关于东莞理工学院城市学院学术委员会委员调整的通知》，并就委员产生的程序及组成作了说明。高香林副院长介绍了学院2012年职称评审工作的总体部署和具体安排。

会上，人事处处长、学术委员会秘书胡钦华向参会委员介绍了2012年的职称申报情况。据悉，今年我院申报各类职称人员共有43人，其中申报中级职称36人，申报副高职称7人。

院学术委员会对我院2012年申报职称人员的资格及其相关材料进行了认真的评议，并票决了全体申报人员的相关参评资料。
