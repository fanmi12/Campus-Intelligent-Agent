# 我院召开2015年暑期赴台研修动员会

7月14日上午，我院在行政楼212会议室召开2015年赴台研修动员会。学院领导王卫平、章德胜、高香林、刘玉侠和暑期赴台研修的34名教师参加了会议。

会上，王卫平书记作了动员讲话，要求赴台教师认真学习台湾先进的教育理念，学有所获、学以致用，确实推动我院各学科专业的发展。

据悉，今年暑期安排了14个专业方向的34名教师进行为期一周的赴台研修，分别到台湾义守大学、德明财经科技大学、龙华科技大学、嘉南药理大学等4所高校的相关专业进行深入交流，内容涵盖示范教学、专业讨论、对接交流等方面。
