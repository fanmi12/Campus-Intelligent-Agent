# 弘扬中华文化  学习世界知识

7月2日，东莞理工学院城市学院赴美游学启程仪式在学术报告厅举行。28名赴美游学的学生和3名领队老师，以及由11名干部和教师组成的考察团，共计41名成员参加了仪式。院长安少华教授出席仪式并致辞, 行政副院长张林博士主持会议。游学教师和学生代表分别发言。

安院长向各位即将赴美国北爱荷华大学游学的学生表示祝贺并亲切寄语。他说，大家是城市学院第一批赴美游学的学生，这次海外游学活动具有重要的意义，不仅为同学们开阔眼界，提高自己创造了机会，也为我院进一步开展国际教育合作打下基础。这是时代赋予高等教育的新特点和新要求，大学生要学会在开放的环境下充实和发展自己。希望同学们成为星星之火，将海外游学学到的先进文化和理念运用到学习生活中，为东莞经济社会建设与国际接轨做出贡献。同时，安院长对同学们提出希望：一要珍惜机会。赴海外学习是时代发展对人才培养提出的要求，每个机会的背后有老师们的辛勤付出和学院宝贵资源的支持。二要做一个积极的沟通者，身在海外，要展现中国大学生的风范，为城市学院增光添彩。三要细心观察，学会思考，将自身的经历转化为终身受益的知识。四要将经历与同学们分享，影响周围的同学，共同成长。五要遵纪守法，高高兴兴出发，平平安安返回，圆满完成海外游学任务。

据悉，我院游学团将于7月13日出发，学生游学团将在美国28天，将与美国北爱荷华大学进行学术交流，游学团成员将通过讲座、听课等各种方式，体验美国大学生学习生活，同时还将游历美国芝加哥、华盛顿、洛杉矶等地。
