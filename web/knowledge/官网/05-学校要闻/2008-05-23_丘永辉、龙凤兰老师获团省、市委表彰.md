# 丘永辉、龙凤兰老师获团省、市委表彰

近日，院学生处副处长、团委书记丘永辉老师被评为2007——2008年度广东省优秀团干部，发展联络中心龙凤兰老师被评为东莞市优秀青年。

据申报材料介绍，丘永辉老师在工作中紧紧围绕学院“上水平、创特色”的办学目标，开展团的活动，以及丰富多彩的校园科技文化活动和与外校的文化交流；注重大学生综合素质的培养，组织学生参加暑期“三下乡”社会实践。他在工作中，加强对青年志愿者服务队的指导。经过他和全校团员青年的共同努力，取得了一定的成绩。

龙凤兰老师念完高中后只身南下到广东打工，凭借自强不息的意志，先后以优异的成绩取得法学大专、本科学历，最终获得西南政法大学法学硕士学位。在城市学院工作期间，担任“创业实验班”班主任，积极探索新时期东莞大学生的培养模式，受到学生及家长的肯定和赞扬。
