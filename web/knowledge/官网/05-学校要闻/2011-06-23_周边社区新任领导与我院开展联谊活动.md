# 周边社区新任领导与我院开展联谊活动

6月20日，樟村、堑头、梨川社区新任领导和我院在樟村社区居委会开展联谊活动。院长安少华、行政副院长张林及部分机关处室负责人应邀出席会议，与樟村、堑头、梨川社区的新任领导欢聚一堂，共谋学院与社区的新发展。

学院与社区就开展专题联谊活动、社区居民培训、大学生就业、共建平安社区等合作项目进行了深入的探讨和交流。
