# 高职部“低碳生活”宣传设计比赛作品获好评

5月28日，高职部“only one world——低碳生活宣传设计大赛”在四号楼大厅落幕。本次比赛共收到100多件参赛作品，除实物作品外，还有效果图及FALSH、DV、PPT、网页等电子类作品。参赛学生充分发挥自身的想象力，为倡导低碳生活出谋划策。获奖作品的展出，引来众多师生前来观看，获得了良好的宣传效应。
