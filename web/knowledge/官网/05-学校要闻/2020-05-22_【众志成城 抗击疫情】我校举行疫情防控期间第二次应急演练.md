# 【众志成城 抗击疫情】我校举行疫情防控期间第二次应急演练

根据《广东省教育厅关于开展全省学校学生返校疫情防控模拟演练的通知》精神，为进一步提升学校学生返校疫情防控、突发情况应急处置能力，切实维护师生员工生命安全和身体健康，严防新冠肺炎疫情在校园的传播与扩散，在充分总结首次疫情防控演练经验的基础上，5月21日下午，东莞理工学院城市学院开展了第二次疫情防控应急演练。

本次演练对学校入口、教学楼、食堂等重点场景进行现场模拟。主要聚焦“进入校门的发热学生紧急处理”、“上课期间师生身体出现异常状况处理”、“学生饭堂内就餐流程”等多个场景。全体校领导、疫情防控工作领导小组成员、二级单位相关工作人员参加了本次疫情防控应急演练。

下午3点，校长王卫平宣布演练正式开始。演练包括学生入校身份确认、行李消杀、体温筛查、进入课室、食堂就餐等环节，模拟返校全过程。为应对报到中可能出现的各种情况，学校按照“进入校门发现疑似症状”、“上课期间师生身体出现异常状况”、“学生饭堂内就餐流程”等情况制定了详细的工作方案。

校党委书记章德胜在演练总结时指出，2020年春季学期开学既有重要的教育意义，更有重大的政治意义，全校上下要进一步统一对学生返校复学工作的正确认识，抓好疫情防控各项工作。此次演练态度认真、场面逼真、程序较真，既检验了学校对疫情应急现场突发状况的处置能力，又检验了学校返校复学工作方案和疫情防控应急预案的科学性和可操作性，为开学复课提供了坚实的保障。全校各单位、部门要充分考虑到各种可能出现的问题，确保返校前准备充分、返校时井然有序、返校后安全平稳，坚决守护校园平安，筑牢校园防疫之墙。
