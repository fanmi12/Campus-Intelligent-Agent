# 为逝者致哀   愿生者坚强

这一刻，异常静默。降了半旗的校园上空，只有警报声在呜咽。

5月19日下午2点28分，天沉沉，雨纷纷。校园里朗朗的读书声暂停了，平日的欢声笑语也停止了。全院师生肃穆地站立，怀着悲痛的心情，以默哀的方式向在汶川地震中不幸遇难的同胞表达哀思。

三分钟的时间里，一切仿佛都静止了，只有虔诚的祝福在所有人的心中涌动。愿逝者安息，更愿生者坚强！
