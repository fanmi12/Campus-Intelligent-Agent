# 红通通的荔枝 大家共分享

初夏六月，城市学院中心湖畔荔枝缀满枝头，飘香校园，沁人心脾，为美丽的校园增添了一道独特的风景线。今日，总务处将采摘下来的红宝石荔枝让师生品尝。

新校区自启用以来，总务后勤有计划地进行着校园绿化建设，湖畔的荔枝林在后勤人的精心呵护下，今年长势良好、硕果满枝头。为了让师生员工都能品尝到新鲜美味的城院荔枝，6月25日，后勤职工采摘下一筐筐的荔枝，并装箱打包分发到学院各个部门及鸿发集团，让大家共同品尝。
