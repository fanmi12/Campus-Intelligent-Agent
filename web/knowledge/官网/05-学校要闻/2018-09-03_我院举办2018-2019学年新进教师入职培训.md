# 我院举办2018-2019学年新进教师入职培训

9月2日，教师发展中心组织51名新进教师参加入职培训活动。院领导王卫平、章德胜、高香林、黄兢、周庆、刘玉侠、林江龙，以及学院办公室主任杜鹏举，教务处处长赵书山，人事处副处长李海冬等参加了入职培训开班仪式。教师发展中心副主任张兰主持开班仪式。

本次入职培训为期一天，共设8个专题讲座，涵盖师德师风、校情校史、政策规范、教学观摩、多媒体设备使用等主题，内容丰富，形式多样，旨在帮助新教师尽快适应我院的工作和生活，更好地实现角色转变，尽快融入学院完成教育教学任务。

学院历来重视师德师风建设，并作为新教师培训的重要内容。王卫平院长强调，师德师风是立校的根基，教师的职责是教书育人，是知识的传授者，也是学生的引路人，教师职业道德的好坏直接影响着学生的发展；作为一名高校教师，要坚守道德底线，要品德立身、立德树人，以高尚师德、人格魅力、学识风范教育感染学生。他强调，教师不能光固守三尺讲台，要时刻关心国家大事与时事政策，要有政治意识、大局意识、核心意识、看齐意识。

副院长刘玉侠就我院发展历程、办学理念和办学特色、人才培养成效、教师发展成效作了具体讲解，解读了学院未来发展规划和发展愿景。她还介绍了教师发展中心基于教师成长的梯度培养体系与促进教师教科研能力成长的支持制度，对新进教职工们也提出了殷切的期望。

本次培训邀请了2018年学院讲课比赛一等奖获得者杨宇老师、二等奖获得者丛珊老师分别为新教师上了精彩的教学示范课。
