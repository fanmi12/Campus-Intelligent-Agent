# 5000新生举行军训红歌大合唱

“九连，来一个！来一个，九连！”，9月13日晚拉歌声此起彼伏，2015级5000多名新生齐聚城院操场拉开“红歌大合唱”比赛帷幕。

比赛现场，一连的同学们摇晃着手机闪光灯——“闪亮”登场，宛若一片璀璨的星海，引来了阵阵欢呼。

三连艺术系的同学也不甘示弱，前排十几位女生齐刷刷的一字马毫无压力，七八位同学的优雅地跳着舞，瞬间引爆全场，赢得了阵阵掌声。

十二连整齐洪亮的歌声，吸引了全场的目光。“我们是祖国的好儿郎”的歌声，震人发聩，令人印象深刻。

红歌大合唱，除了“花招”，细节也必不可少。十三连连连喊出了军训的口号——“助力强军梦，托举中国梦”。而九连分成四个方阵，将连旗围在中心。

压轴登场的十六连，再一次点燃现场热情。由12名女生、3名男生组成队列绕着十六连一路跑一边喊：“战争来的时候，我们就是男人！”引来阵阵掌声。紧接着，先是两名女生表演单手翻跟斗，随后两名男生跳起了街舞，引起大伙的吆喝，气氛热烈。

经过评委评选，三连（艺术系）和十二连（计信系）获得一等奖，四连、九连、十三连及十五连获得了二等奖，十连、一连、十六连及二连获三等奖。

获奖十二连连长葛教官表示，这是他带的最成功的一届学生，“参赛曲《中国海军陆战队之歌》练的时间不长，都是靠拼凑零散的时间去练习。这次比赛歌声的洪亮程度是意料之中的，因为比较多男生，大家都很有朝气。但对最后获得的名次还是比较意外。”

艺术系团总支副书记李瑶代表评委们发言时表示，大赛十分成功，各个连不仅在声音、音准上有所体现，更体现了各连的作风纪律。

最后，十六个连的全体同学合唱了城院之歌，“虎门早潮澎湃在心田，黄旗山风吹佛着校园……”合唱比赛在响彻云霄的歌声中落下了帷幕。
