# 我校开展2021年秋季学期疫情防控应急演练

为落实《关于做好2021年秋季学期学校疫情防控工作的通知》（粤教防组[2021]11号）文件精神，提高学校疫情防控应急能力水平，保障师生平安返校，学校于8月23日开展秋季学期疫情防控应急演练，学校校长王卫平、副校长刘玉侠出席活动并观摩了现场演练。寮步镇疾控中心相关工作人员应邀观摩演练并点评。

本次演练对学校入口、教学楼、图书馆等重点场景进行现场模拟。主要聚焦“进入校门的发热学生紧急处理”、“上课期间师生身体出现异常状况处理”、“图书馆入馆流程”等多个场景。

演练内容包括学生入校身份确认、行李消杀、体温筛查、进入课室、进入图书馆等环节，模拟学生返校全过程。为应对报到中可能出现的各种情况，学校按照“进入校门发现疑似症状”、“上课期间师生身体出现异常状况”、“图书馆入馆身体出现发热现状”等情况制定了详细的工作方案。

此次演练各部门相互配合、态度认真、场面逼真、程序较真，检验了学校对疫情应急现场突发状况的处置能力。学校开展疫情防控应急演练是应对新冠疫情处置的重要技能提升活动和准备工作，通过演练压实责任，明确分工和责任，强化协作与配合，以进一步完善相关预案和应对措施，进一步提升我校新冠肺炎疫情应急反应和处置能力，确保返校前准备充分、返校时井然有序、返校后安全平稳，坚决守护校园平安，筑牢校园防疫之墙。
