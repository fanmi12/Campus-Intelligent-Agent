# 【众志成城 抗击疫情】我校校领导深入走访各二级学院

5月28日，校领导王卫平、章德胜、高香林、黄兢、周庆、刘玉侠在各职能部门负责人陪同下深入走访各二级学院，并为各二级学院带去抗疫物资，凝聚广大教职工同心战“疫”，助力学校复学复工。走访期间，各校领导分别对各二级学院询问了工作情况，了解二级学院教职工核酸检测和毕业生返校工作情况，对在岗教职工表示感谢，鼓励大家继续发挥党员先锋模范作用，坚决打赢疫情阻击战，促进学校各项事业不断向前发展。

校长王卫平在职能部门负责人的陪同下先后到双创学院、创意学院和计信学院走访慰问在岗教职工，分别向双创学院主任陈婷，创意学院院长王锦锋、党总支书记何帅以及计信学院院长牛熠、党总支书记廉玉忠等人了解返校师生情况，并赠送了防疫物资。

党委书记章德胜在职能部门负责人的陪同下先后赴马克思主义学院、体育教学部走访，分别向马克思主义学院副院长石志民、党支部书记史雍真，以及体育教学部主任王艳云、党支部书记刘健等人了解部门近期工作情况，并赠送了防疫物资。

高香林副校长在职能部门负责人的陪同下，来到商学院慰问疫情期间坚守岗位的任课教师、辅导员和行政人员并与商学院领导卢淑芳、郑阿泰、卢效坚及全体辅导员进行了座谈，并赠送了防疫物资。

副校长黄兢在职能部门负责人的陪同下，来到法学院和艺术学院，分别听取了法学院党总支书记江小卫、党总支副书记曾惠娴、艺术学院院长陈建新、艺术学院党总支书记向智星等人的情况汇报，并赠送了防疫物资。

副校长周庆走访了文学与传媒学院和金融与贸易学院，分别听取了文学与传媒学院院长宋秋敏、党总支副书记苗琳及金融与贸易学院副院长赖忠孝、党总支书记米双红、党总支副书记万文双等人的情况汇报询问了毕业生相关的工作情况，并赠送了防疫物资。

副校长刘玉侠先后走访智能制造学院、城环学院和外语学院，分别询问了智能制造学院党总支书记唐洁，城环学院院长肖红飞、党总支副书记曹镭，外语学院院长赵东林、党总支副书记都振华等人的情况汇报，并赠送了防疫物资。
