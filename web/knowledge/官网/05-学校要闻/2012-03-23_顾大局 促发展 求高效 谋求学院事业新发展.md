# 顾大局 促发展 求高效 谋求学院事业新发展

3月22日，东莞理工学院在我院4315会议室召开城市学院过渡工作会议。会议宣布成立东莞理工学院城市学院过渡工作领导小组及成员名单，以及各工作小组负责人名单。东莞理工学院党委书记周致纳要求各工作小组和城市学院各单位要积极配合“过渡”，做到过渡工作与学院日常工作两不误。

东莞理工学院党委书记周致纳，校长杨晓西，党委副书记吕琦元，副校长安少华、戴炳源等领导，市财政局、市国资局、市审计局有关领导出席会议。东莞理工学院城市学院各部门主要负责人与会。会议由吕琦元副书记主持。

会上，校长杨晓西宣读了东莞理工学院关于成立东莞理工学院城市学院过渡工作领导小组的决定文件。据悉，过渡工作领导小组下设七个工作小组，即：综合组、教学组、学生组、人事组、资产组、财务组、审计组。

东莞理工学院副校长、城市学院院长安少华在会上指出，城市学院过渡工作领导小组责任重大，任务艰巨，他希望城市学院各单位要积极配合支持，将任务逐项落实到人，使过渡工作有条不紊地开展，确保平稳有序过渡。

周致纳书记在会上发表了讲话。他说，城市学院八年办学成果丰硕，这是东莞理工学院党委行政、城市学院全体教职员工共同努力的结果。为了贯彻落实教育部26号令，更好地适应东莞市提出的高水平崛起的战略要求，确保城市学院平稳过渡，东莞理工学院校党委决定成立城市学院过渡工作领导小组。他强调指出，在过渡期间，希望各部门、各单位要积极协调配合，做到过渡工作和日常工作两不误。全体教职工要顾大局，促发展，求高效。党员干部要带好头，在过渡工作中发挥党员模范带头作用。
