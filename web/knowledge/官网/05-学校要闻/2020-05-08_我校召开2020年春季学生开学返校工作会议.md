# 我校召开2020年春季学生开学返校工作会议

5月7日下午， 我校2020年春季学期学生返校工作会议在行政楼212会议室召开。校领导班子成员、各行政教辅单位负责人参加了会议。

学校党委书记章德胜对学校前一阶段疫情防控工作进行了回顾，对学生开学返校的整体方案和工作要求等方面进行了部署。他强调，学生开学返校疫情防控工作关乎每位师生的生命健康，关乎整个校园乃至社会的稳定和谐。当前开学返校工作时间紧、任务重，统筹做好疫情防控和开学返校就要“谋在细节，重在落实”，要严格遵照学校的工作部署，结合毕业班学生的实际情况，稳妥做好第一批学生返校工作，将返校工作稳扎稳打落在实处，交出一份满意的答卷。

会上，各行政教辅部门负责人针对我校学生返校准备工作作了详细介绍，并集思广益完善、优化返校工作中防疫细节工作。

校长王卫平在讲话中，要求全体教职工深入学习贯彻习近平总书记关于疫情防控工作的重要指示批示和讲话精神，做好打持久战的准备，坚决打好防疫保卫战，层层压实责任，稳妥有序地做好学生开学返校工作。
