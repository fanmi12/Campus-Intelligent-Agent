# 我校落实2020年度全省征兵工作视频会议精神

7月2日上午，省教育厅召开2020年全省大学生征兵工作电视电话会议。会议传达学习了全国大学生征兵工作电视电话会议和全省征兵工作推进会议精神，通报表彰了2019年度全省高校征兵工作先进单位和个人。6所高校代表介绍了经验做法和工作打算。省教育厅二级巡视员邱克楠总结了去年我省大学生征兵工作情况，并就抓好今年大学生征兵工作进行了动员部署，提出了明确要求。省教育厅、省征兵办相关人员以及全省高校分管领导、征兵工作人员参加会议，我校设立了分会场。校长王卫平、党委书记章德胜会同相关处室负责人和二级学院负责征兵工作的党总支书记和副书记参加了会议。

视频会议结束后，我校召开了2020年征兵工作会议。会上，武装部副部长刘维仝汇报了2019年我校征兵工作并介绍了本年度征兵工作进展。去年，我校共有92个在校生和毕业生参军入伍，被评为东莞市征兵工作先进单位。

武装部部长王锦锋对我校本年度征兵工作进行了部署，他表示：国家出台了一系列的政策，目的是让更多的大学生投入到军营，为国防事业添砖加瓦。做好征兵工作，是我校为国防和军队建设提供坚实的人才支撑。各相关部门在做好疫情防控工作的同时，要担起大学生征兵工作责任，精准施策、紧密配合，为推进军事人员现代化、提升部队战斗力补充优质兵员。

党委书记章德胜在动员讲话中指出：学生参军入伍，不仅是体现了我校学生爱国主义情怀，更是学生离开校园走向更高的发展平台。他强调：严格执行廉洁征兵有关规章制度，做到以身作则、服务学生。校内各职能部门要严格按照上级文件精神，把应征入伍宣传到位，搭建好学生离校进军营这座桥梁，鼓励更多的有志青年参军入伍，报效祖国。
