# 我校与东莞天安数码城共建科产教融合基地揭牌

为进一步整合力量推进科技成果转化、整合产业力量、培养适应产业发展创新性、应用型高素养专业技术人才，5月18日下午，在东莞天安数码城举行科产教融合基地揭牌仪式。我校校长陈明与天安数码城集团副总裁、东莞天安数码城董事总经理何文共同为基地揭牌。东莞市苏锦食品有限公司董事长蒋卫卫，东莞天安数码城常务副总经理高煜、天安数码城FABIE产业研究中心主任杨道军、产业研究员黄法奇，我校副校长李海冬，数字经济学院执行院长侯瑞瑞，学生处副处长、就业中心主任林蓉等领导及学院教师代表等共同见证揭牌仪式。

本次揭牌是在我校数字经济学院与东莞天安数码城经过长期的校企合作的基础上的进一步深化，双方共同建设的科产教融合实训基地，将充分依托我校数字经济学院与东莞天安数码城优势资源，围绕科研工作、人才培养、课题申报、成果转化、学生就业等方面，通过建立沟通机制，搭建科产教平台以及共同举办多种形式的活动等措施，推动基地发展，实现双方的产学研深度融合，支撑东莞及粤港澳大湾区经济社会发展和产业转型升级。

揭牌前，我校一行在何文总经理、蒋卫卫董事长等陪同下参观了东莞南城天安数码城和东莞市苏锦食品有限公司等园内优秀企业代表。

天安数码城（集团）有限公司成立于1990年，总部位于深圳，由深圳国资委旗下深业集团（HK.0604）和香港天安中国有限公司（HK.0028）各占50%合资成立。33年来在全国14个城市开发、运营和管理23座园区，服务逾10000家创新型企业，与100多家行业优秀企业、知名商业机构和服务机构结为战略合作伙伴，挂牌上市企业100余家，拟上市企业100余家。

东莞天安数码占地419亩，规划总建筑面积103万平方米，总投资超过50亿元。截至2023年4月，园区工商注册企业2380家，国家级高新技术企业141家，国家专精特新"小巨人"企业2家，省专精特新企业30家，省工程中心7家，市倍增企业8家，市协同倍增企业5家，区倍增企业12家。年产值超200亿元，直接创造就业岗位2万多个，是致力于打造东莞城市中心区融科技产业用房、总部楼、公共服务平台以及优质商务配套于一体的首个“企业公园”。
