# 我院召开2013年度教学实践基地代表座谈会

12月27日，2013年度教学实践基础代表座谈会在教学管理大楼103、212、407会议室分三小组同时进行。学院教学主管副院长高香林及系部负责人参加座谈会。来自虎门港等37家教学实践基地代表应邀参加了本次座谈会。座谈会由教务处处长牛熠主持。

座谈会上，高香林副院长向与会代表介绍了学院发展情况，对实习基地多年来在学院专业发展、学生实践能力培养等方面给予的大力支持表示感谢。并现场举行了新增实践基地代表现场签约、授牌仪式。城市与环境科学系主任肖红飞代表学院与东莞市安全生产监督管理局麻涌安监分局黄汝球局长互签了“城市学院教学实践基地”协议。政法系主任刘杰代表学院与东莞市社会救助站袁伟华站长互签了“城市学院教学实践基地”协议。

会议期间，虎门港王淑琴总工程师、新文传媒集团严永松总监、顺丰快递石从坚经理、立信会计师事务所陈清平经理、大同机械有限公司刘超总经理、东莞博思电子数码科技有限公司周建荣总经理、东莞环亚影视广告有限公司刘权总经理、东莞市安全生产监督管理局道滘分局黄汝球局长、东莞市检察院姚凤玲副科长等，就实践基地建设、应用型人才培养、实习见习等具体事宜也先后发言，对今后如何开展学生教育实习进行了探讨，充分肯定了我院各专业毕业生在工作岗位上的优秀表现,希望与学院保持长期友好的合作关系，继续拓宽合作渠道，为学院的人才培养提供支持和帮助。代表们在座谈中强调，在教学中要培养学生拥有坚实专业基础知识，养成认真、务实、艰苦朴素工作作风，希望毕业生能具有较强的动手能力、沟通能力、组织管理能力。

座谈会在和谐、融洽的气氛中结束。本次座谈会的举办，对我院依托校外实习基地，加强实践教学环节，培养学生实践动手能力，提高学生综合素质将起到积极的促进作用。
