# 我院2008届校园招聘会筹备工作启动

为搭建高校毕业生与东莞企、事业单位供需交流平台，促使08届毕业生充分就业，学院定于3月15日举办“城市学院2008届大型校园招聘会”，本次招聘会由城市学院主办，东莞理工学院学生处、东莞市中心人才市场、东莞市外商投资企业协会协办，目前各项筹备工作正在紧锣密鼓地进行。

其中我院有1600多名应届毕业生和东莞理工学院有2600名应届毕业生，预计参加本次校园招聘会的本、专科毕业生将有4000人，涉及工学、理学、管理学、经济学、法学、文学、商学、教育学等八大学科中的50多个专业。

院就业指导办公室已向各系部下发通知，要求各单位就业指导小组要充分重视本次招聘会，认真做好本系（部）毕业生的宣传、组织工作，召开毕业生动员大会，加强毕业生诚信教育，指导毕业生准备好应聘材料。
