# 天津市教育委员会来我院调研

10月23日下午，天津市教育委员副主任徐广宇、中职处处长狄建明、财务处处长陈长征等一行六人莅临我院访问、调研。

我院院长王卫平、董事长代表陈超群、党委副书记章德胜等领导热情接待了来宾，并陪同客人参观了校史馆。天津客人乘坐电瓶车参观了校园，对我院优美的校园环境表示赞赏。

双方在行政楼505会议室进行了座谈，就独立学院未来发展趋势及分类选择等方面进行了交流探讨。学院办公室主任杜鹏举、研究与发展规划处处长牛熠、教务处处长赵书山参加了座谈会。
