# 我院教师赴江西理工大学交流调研

3月30日，教务处处长牛熠教授、计信系主任廉玉忠教授、图书信息中心副主任陈显龙等一行赴江西理工大学参观学习交流。江西理工大学电气与自动化学院长刘飞飞教授、副院长王祖麟教授等院领导热情接待了我院学习考察组。

此次交流，双方主要就应用型人才培养模式及方案实施进行了深入的探讨，刘飞飞院长、王祖麟副院长分别着重介绍了江西理工大学应用型人才培养模式以及“3+1”卓越工程师的培养及实施过程。

据悉，江西理工大学是一所以理工为主，工学、理学等八大学科协调发展，研究生教育与本科教育并举的教学研究型大学；是教育部卓越工程师计划试点单位、国家级大学生创新创业训练计划单位。其电气与自动化专业是教育部人才培养模式创新示范区，也是教育部第二批“卓越工程师”培养单位。
