# 【众志成城 抗击疫情】相约线上课堂——优秀教师经验谈之十七

我校坚决贯彻落实教育部、省教育工委、省教育厅的重要部署，从3月起全面开展线上教学活动，全体任课教师坚守岗位、锐意创新、勇挑重担，全力做好线上教学工作，展现了良好的师德师风。前十六期我们精选刊发了四十九位优秀教师线上教学经验谈后，在全体教师中产生了良好的反响，受到广大师生的欢迎和点赞。今天刊发第十七期，推介计算机与信息学院胡良兰、法学院何秀青、创意设计学院陈丽娜三位老师的线上教学心得体会，供大家分享。

计算机与信息学院胡良兰老师线上教学心得体会：线上教学比课堂教学花费的时间和精力更多。在课前挑选合适的视频提供给同学们观看，直播课程中对视频内容梳理重点和难点。答疑变成随时随地，企业微信在线十几个小时，真是煮菜的间隙都能插空回来回答问题。打字无法解决的问题语音解决，语音无法解决的问题远程协助。不过看着活跃的直播间，满怀欣慰！

法学院何秀青老师线上教学心得体会：线上教学时间观念强，课程内容需要精准安排。一是每次课的教学目标明确，告诉学生要解决的问题是什么；二是讲授内容简明概要，重点突出，让学生对需要掌握的重要理论与技能有深刻印象；三是依据教学目标，精心设计与学生互动环节和布置习题，激发学生学习兴趣，保持认真学习态度。

教师寄语：同学们，与老师一起共同克服困难，珍视线上学习的时光，探索线上学习的无限可能，充盈抗疫战疫力量。

创意设计学院陈丽娜老师线上教学心得体会：一场突如其来的疫情，打乱了我们的工作与生活，开学日期一推再推，但学生的学习不能因此而停。在省教育厅和校、院两级的统筹安排下，我们战疫情、抓教学，作为一名普通教师，既是挑战也是机遇。

首先面临的就是技术上挑战。平时观摩MOOC、刷抖音觉得很轻松，但真正实操起来，却发现近几年学校人事部门组织的慕课培训竟是那么重要。

另外，线上教学带来了完全不同的体验，讲课方式方法、课程的设计、教学节奏的把控，每个环节都是学问。而且现场学生都未必能吃透，线上真的行么？另外还有五花八门的评论和不得不感谢的美颜。如果没有这次“被迫”，不知何时会来“首秀”。

教师寄语：守得云开见月明。
