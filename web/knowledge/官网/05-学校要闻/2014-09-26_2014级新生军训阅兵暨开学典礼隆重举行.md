# 2014级新生军训阅兵暨开学典礼隆重举行

由5000多名军训学员组成的方阵，以昂首阔步的姿态迎接着初升的骄阳，一股青春的激情在田径场上空迸发。晨风中，国歌嘹亮，国旗飘扬，军威雄壮。

9月25日上午9时，我院2014级新生军训汇报表演暨开学典礼在田径场隆重举行。东莞理工学院党委副书记吕琦元，城市学院董事长麦照容、董事黎建烨，全体院领导出席，各系部、机关各处室主要负责人参加大会并在主席台观看了军训汇报表演。

阅兵展现城院学子风采

党委书记王卫平在军训团团长韩加强中校的陪同下检阅了2014级军训新生。“为校争光”的口号此起彼伏，同学们军训的喜悦、辛苦，都凝结在这简短而充满力量的口号声中。

随后，18个学生连队方阵在雄壮的军歌声中依次正步通过检阅台，向领导和军训官兵汇报军训成果。各方阵军姿挺拔，军容严整，动作流畅，口号响亮，充分展示了2014级大一新生良好的精神风貌，赢得了全场阵阵热烈的掌声。

军训是成功的，达到预期目的

军训团团长、承训部队首长韩加强中校做军训总结。他说，10多天来，同学们刻苦训练，听从指挥，先后进行了军体拳、分列式、阅兵式、素质拓展等军事项目的训练，接受了国防知识和安全知识等方面的教育。韩团长认为，这次军训是成功的，效果是好的，完全达到了预定的目的。同学们通过军训，磨练了意志，强健了体魄。

为表彰先进、树立典范，军训团决定对一批先进连队、优秀个人进行表彰。本次表彰分为内务、宣传报道、歌咏比赛、军体拳、团体总分等7大项，另有170多名同学分获军训积极分子荣誉称号。

40名新生获得奖学金

伴随着庄严的国歌声，鲜艳的五星红旗缓缓升入空中，正式拉开了2014新生开学典礼的序幕。大会首先表彰了一批优秀新生，根据2014年秋季招生资料及入学成绩排名，城市与环境科学系汤穗念等20名同学分别获得2014年优秀新生奖学金一等奖，每人奖金2万元，财经系李俊荣等20名同学分别获得二等奖学金，每人奖金1万元。

东莞理工学院党委副书记吕琦元，城市学院董事长麦照容为获奖者颁奖。40名获奖学生在同学们钦佩的眼光中走上主席台领奖。

书记解答：大学是什么，为什么上大学？

党委书记王卫平教授向新生致辞，他在讲话中以长辈、师长、“平哥”三重身份，就“大学是什么”、“为什么上大学”、“怎样度过四年的大学时光”三个问题做了解答，并提出三点希望，引起大一新生的强烈共鸣，多次报以热烈的掌声表示赞同。

一、大学可以锻炼同学们的意志。“大学是青春飞扬的舞台，是智慧的殿堂。大学可以磨练你的意志，人生就是一个不断磨练的过程。”王书记强调，“你们唯有在大学一年年一月月一日日的磨练中，才能真正学会求知、学会做人。”

二、大学需要爱的付出。王书记指出，大学的学习不像中学，追求的是系统深入、厚积薄发。我们不能不变，但也不能天天变，而要以不变应万变。大学的学习要有思考，要触动心灵，能够鼓舞精神，这样才是有价值的学习。因为爱自己所学，所以付出；因为付出了，你们必须更爱。

三、大学可以凝聚人生的情谊。凡是人格健全的大学生，心智成熟的大学生，都会认可大学同窗四年的同学之情是多么的重要，多么值得珍惜。王书记坚信，一个完善的人，健全的人，不仅仅是有知识的人，还应是对自然、对人，对事，都有感悟的人，更是重情义的人！
