# 开学首日全院教学工作秩序井然

2月25日，我院新学期正式开学。

上午8时半，在学院院长王卫平、副院长高香林带领下，教务处、督导办及各教学单位领导深入教室、实验室，全面检查了新学期第一堂课的教学工作情况。整体上，全院教学秩序良好。教师教学准备充分，讲课富有热情，课堂效果好。学生能按时到课，精神饱满，认真听课。各教学场地的教学设施、设备运行正常。

据介绍，为保证新学期顺利开学，开学前教务处分别组织召开了教学单位主任及教学秘书会议，专门就开学的各项工作进行了认真布置和安排；教务处、实验中心、后勤保卫处等部门对学院教学楼及各实验、实习场地的设施、设备进行了全面检查；图书信息中心组织完成了教材发放工作；各教学单位领导、老师高度重视，精心做好了开学相关准备工作。
