# 我院学子获省大学生预防艾滋病同伴教育“魅力讲师”大赛三等奖

5月26日下午，广东省第四届大学生预防艾滋病同伴教育“魅力讲师”大赛决赛在中山大学南校园举办。我院学生处新苗社会工作服务中心成员温晓龙、练嘉慧、欧惠琪名列大赛前20强，其中，温晓龙同学荣获大赛三等奖，这也是民办独立院校学子获得的最佳成绩。可喜的是，我院已连续三年荣获该项赛事“最佳组织奖”

大赛由广东省教育厅、省卫生和计划生育委员会、共青团广东省委员会联合主办，中山大学承办，吸引了全省70所学校500多名师生代表参与现场活动。省教育厅副巡视员邱克楠也出席了本次活动并做了总结讲话。

经过激烈角逐，评选出10名选手进入决赛。我院温晓龙同学以毒品为参赛课题，凭着其敏锐的思维和稳定的发挥赢得在场评委的一致认可，成功晋级决赛并喜获三等奖。
