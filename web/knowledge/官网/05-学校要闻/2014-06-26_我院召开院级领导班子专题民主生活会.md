# 我院召开院级领导班子专题民主生活会

6月25日，我院领导班子专题民主生活会在行政楼505会议室召开，会议由院党委书记王卫平主持，全体院领导和院党委委员参加了会议。东莞理工学院党委副书记吕琦元、东莞理工学院党委组织部副部长杜应发到会指导。

民主生活会上，王卫平书记首先介绍了我院开展党的群众路线教育实践活动的基本情况，代表学院领导班子作对照检查发言。王卫平书记在发言中指出，我院领导班子在党的群众路线教育实践活动中，认真学习党的政治原则、政治立场、政治观点和路线、方针、政策，在思想上政治上行动上同以习近平同志为总书记的党中央保持高度一致；认真贯彻执行党的政治纪律和中央“八项规定、六项禁令”，对照“四风”查摆问题，深刻剖析问题产生的原因，明确了今后的努力方向和整改措施；建立整治“四风”长效机制，营造风清气正的校园氛围。

民主生活会上，全体学院领导班子成员进行个人对照检查发言，对照党章，对照廉政准则，对照改进作风要求，对照群众期盼，对照先进典型，查找存在的突出问题。领导班子成员之间开展了严肃认真的批评和自我批评，从党性强不强、工作实不实、要求严不严等方面指出对方的问题和不足，帮助分析原因，提出改进建议。民主生活使领导干部受到一次严格的党内生活锻炼，达到“团结—批评—团结”的目的。

东莞理工学院党委副书记吕琦元对专题民主生活会情况进行了点评。他指出，城市学院党委认真组织开展党的群众路线教育实践活动，体现了党组织在独立学院的政治保障和战斗堡垒作用，理顺了党的组织系统，发挥党员的先锋带头作用，建立了政治生活制度。这次专题民主生活会上，批评和自我批评开展得很到位，达到会议的目的。要认真梳理在党的群众路线教育实践活动中反映出来的问题，明确努力方向，制定务实管用的整改措施。要把群众放在心上，认真解决联系服务群众“最后一公里”问题。要坚持中国特色社会主义办学方向，牢牢把握意识形态的思想政治工作，巩固党的群众路线教育实践活动成果，支持学院提高教学科研和行政管理水平，开创学院改革发展的新局面。
