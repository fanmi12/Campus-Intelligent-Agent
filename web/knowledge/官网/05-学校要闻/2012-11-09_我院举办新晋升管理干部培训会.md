# 我院举办新晋升管理干部培训会

11月8日，由组织人事处举办的我院新晋升管理干部培训会在行政楼212会议室召开。院督学陈丁堂、党委副书记章德胜为培训会做了专题讲座。院长杨敏林、党委书记朱志德，组织人事处处长胡钦华、院办主任黄兢，以及25名新晋升管理干部参加了此次培训。

陈督学作题为《高等学校的管理思想》的专题讲座。陈督学开门见山地指出，高校管理究竟是什么，我们怎样管理高等学校，然后分析了高校教师的一般心理特征。他认为管理高等学校，就必须努力处理好几个关系：一是“关心人”与“关心事”的关系，二是“管”与“不管”的关系，三是“内行”与“外行”的关系。

章副书记作题为《我们需要什么样的管理干部》的专题讲座。章副书记从高等学校管理干部服务的必要性出发，指出管理干部要增强服务教学、服务教师、服务学生的意识，并从去除官本位思想、提高责任意识、加强技能培训、提高工作效率、引入竞争机制、规范制度建设、增加沟通交流、优化工作环境等八个方面介绍了如何增强服务意识。

培训会上，杨院长高度赞扬了我院管理干部的工作能力与工作成绩，并提出了四点要求：一是要树立主人翁意识，克服打工心态；二是要增强服务意识，树立“以人为本”的管理理念；三是要增强全局意识，积极主动探索独立学院的管理规律；四是要增强学习意识，不断提高自身综合素质和能力。

朱书记对本次培训会做了总结，并对参加的培训干部提出了四点要求：一是要加强对政治理论的学习，二是要加强对业务的学习，三是要向有经验的同志学习，四是要有好的工作作风。

本次培训会，使我院新晋升管理干部统一了思想，明确了责任，增强了信心，也增进了我院新晋升管理干部的交流，取得了较好的效果。
