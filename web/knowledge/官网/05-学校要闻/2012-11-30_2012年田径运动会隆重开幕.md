# 2012年田径运动会隆重开幕

11月29日，我院2012年田径运动会隆重开幕。妆扮一新的田径场显得隆重热烈，激情四射。“每天锻炼一小时，健康工作50年，幸福生活一辈子”；“发扬更高更快更强运动精神，共建和谐幸福校园”等巨幅标语光鲜夺目，点明了本次运动会的举办宗旨，1200多名运动员向大会展示了力与美、刚与柔、团结拼搏的青春风采。加油助威声、欢呼祝贺声响彻运动场上空。

东莞理工学院党委副书记吕琦元，学院领导杨敏林、朱志德、朱冰、陈丁堂、章德胜、高香林出席开幕式。

下午2时30分，运动会在雄壮的国歌声中拉开帷幕。紧接着进行了裁判员、运动员入场式。在嘹亮雄壮的运动员进行曲伴奏下,国旗队、院旗队、鲜花队、彩旗队、裁判员队、运动员队依次通过主席台，他们彰显着各自的特色，以昂扬的精神、矫健的步伐、自信的风采，接受院领导的检阅。

党委副书记章德胜致开幕辞。章副书记指出，我们要全面贯彻党的教育方针，共同建设和谐幸福校园。这次校运会是我院竞技体育、群众体育运动成果的盛宴，是磨练意志、强健体魄、促进师生德智体美全面发展、弘扬体育运动精神的再动员，是课堂教育教学的延伸。运动会的举办，有利于提高师生身心健康水平，有利于学生全面发展、自我完善，有利于培养勇往直前的勇气和毅力，有利于弘扬更高更快更强的体育运动精神。希望广大运动员赛出水平，赛出风格，赛出成绩，向新的目标冲刺。

运动员代表戴凤珠和裁判员代表郑越明先后发表誓言，表示要奋勇争先，再创佳绩，热情服务、公正裁判。

随后，进行了由我院体育教学部教师自编、自排，2012级新生参与的团体操表演。在古典优雅的音乐伴奏下，“武动”城院的太极拳似行云流水、气贯长虹；集体武术棍表演姿势舒展，动作灵活，体现了城院人阳刚之美；《跆拳道品势集体操》将跆拳道的基本动作与健美操完美结合，英姿飒爽刚健有力。伴随着熟悉优美的音乐旋律，2012级480名同学表演的“怒放青春”团体操，一个个呼啦圈好像美丽的花环，构成了一道亮丽的风景线，不断变换队形，汇编成一朵朵阵容庞大的“花蕾”，彰显着城院学子青春活泼的风采，也表达了城院人与时俱进、铸造辉煌的美好愿望。开幕式的压轴好戏是500余名教职工的广播操表演，他们认真的态度和标准的动作，赢得一阵阵欢呼与掌声。

开幕式之后，运动员冒着凛冽的寒风，在毛毛细雨中展开了各个项目的角逐。

据悉，为期两天的运动会将进行100米、200米、400米、800米、跳高、跳远、铅球等项目的比赛。同时运动会还为教职工设立了一分钟跳绳、慢骑自行车、网球掷准、二人三足等趣味运动比赛项目。
