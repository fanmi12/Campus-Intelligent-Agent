# 办学主体搬迁平稳过渡　各项工作有序展开推进

城市学院办学主体搬迁两个月来，各项工作平稳交接，有序有效展开推进。

本学期之初，城市学院面临办学主体搬迁、一校两区、5000名大一新生入驻等新情况，教学、管理、保障工作难度加大，对各级领导和管理人员的能力与智慧是一次重大考验。学院党政班子在东莞理工学院党委行政和董事会的领导下，沉着应对，大胆决策，周密部署，职能部门协同配合，从而使搬迁工作平稳过渡，教学、管理、保障等工作实现整体推进。

新生的报到、军训、上课井然有序，开局良好。有资料显示，新生报到率达到94%以上，居全省同类院校前列。开学第一天，教师、学生、教材到岗到位率分别达到100%。新生早晚自修积极性高，无迟到早退现象。学生社团招新场面火爆，高招迭出，800名新生入围面试。图书馆、教学楼、运动场馆夜晚灯火通明，排练、晚修、运动、学习的学生众多，各得其乐，呈现出浓浓的氛围。

学院根据新情况的需要，对院领导的分工进行了调整，职能部门的责权利明确清晰。教学系部、管理班子齐备，一批中青年干部走马上任。该院适时成立莞城校区工作部，调整充实教学工作委员会、学术委员会、督导委员会，使这些组织更具权威性、代表性和学术性。党的组织建设、工会等工作也有条不紊地开展。

学院各项工作的开展，离不开后勤的保障。学生的餐饮接待量与服务质量同步提升，学生就餐率处东莞高校中上水平。教学管理楼按时交付使用，内部设施调试完毕，网络、空调、电话、供水供电正常。综合馆、琴房隔音改造工程完工，一批钢琴等教学设备投入使用，教师公寓正在抓紧工程扫尾，即将完工启用。

目前，该院正在强力推进教学工作评估，并以此为抓手，促进办学整体水平和教学质量的提高，实现学院新一轮发展。
