# 我院学子荣获第七届广东大学生节能减排工业设计大赛二等奖

6月11 日，由共青团广东省委员会、广东省教育厅、广东省科学技术厅、广东省科学技术协会、广东省学生联合会主办，华南理工大学承办的第十一届广东大中专学生科技学术节之“南网杯”第七届广东大学生节能减排工业设计大赛圆满落幕。由我院城环系方伟成老师指导，黄祈栋、黄宇宏、陈康胜、廖雨微和何春婷等五名同学的团队科技类作品《一种组合式垂直流人工湿地装置的研制及其对生活污水处理效果研究》荣获大赛二等奖。

据悉，第七届广东大学生节能减排工业设计大赛初赛阶段共收到来自全省29所本、专科院校的参赛作品238份，其中科技类作品196份，社会实践类作品42份。评审组由华南理工大学、中山大学、暨南大学、华南农业大学、广东工业大学、广东技术师范学院推荐的节能减排相关行业9位专家构成。评委依据作品的创新程度和先进性、技术含量和可行性、预期经济效益和推广价值、主题吻合度等标准进行评分，共评选出20份作品进入本次比赛的决赛。
