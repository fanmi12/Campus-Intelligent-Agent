# 院领导深入樟村校区指挥排渍看望慰问师生

5月7日

上午，院长安少华带领院办公室主任王玉、学生处处长章德胜、总务处处长李奇、保卫办公室主任王现府，深入樟村校区指挥排渍工作，看望慰问这里的师生员工。

这天凌晨，东莞市遭遇几十年一遇的暴雨，据气象部门报告，局部地区降水量达到194毫米，许多地区出现排水困难的现象。记者在现场看到，樟村和堑头社区部分居民家中积水达到80厘米。受暴雨影响，樟村校区4号宿舍楼后面部分围墙倒塌，大雨冲刷带下来的泥沙将下水道堵塞，造成2号、3号宿舍首层进水，二层个别宿舍也有倒灌现象，给师生生活带来极大不便。安院长等院领导清晨得知这一情况后，第一时间赶到樟村校区指导排水及清淤工作，逐门逐户地看望慰问这里的师生员工。他安慰大家要沉着冷静，全力投入排渍和保洁工作。经过几个小时的紧张工作，这里很快恢复了正常。

据东莞气象台预报，未来几天将仍有暴雨来袭。相关部门提醒广大师生要注意关好门窗，及时关闭家用电器，保障人身和财产的安全。
