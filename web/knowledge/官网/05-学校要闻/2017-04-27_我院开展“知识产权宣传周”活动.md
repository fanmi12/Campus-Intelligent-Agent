# 我院开展“知识产权宣传周”活动

4月20日，我院“2017年高校知识产权宣传周”活动拉开序幕，这次活动主题为“创新创造改变生活 知识产权竞争未来”。

4月26日是知识产权日。我院研究与发展规划处、图书信息中心、党务工作部和各院系（部）等单位携手合作，在校内通过举办知识产权展、开展大学生科技文化论坛等多种形式，利用各类媒体平台、宣传栏、条幅等广泛进行宣传活动。

20日下午，政法系教研室主任田路老师作客城院大学生科技文化论坛，在模拟法庭7A102教室举办了题为《身边的知识产权之著作权》的讲座，向同学们讲述了何为知识产权、著作权的保护、著作权具体权利等相关的知识产权知识。

田路老师从“著作权保护什么、著作权不保护什么、哪些作品在我国受保护”等，介绍了著作权的相关知识。田老师在“著作权保护什么”中，特别详细地讲述了著作权的核心条件——独创性，通过分析“独”、“创”两字，让同学们了解了著作权保护内容。通过黑棍小人案例、庄羽诉郭敬明案、琼瑶诉于正案等案例进行分析，还播放了《法律讲堂》中有关“山寨喜洋洋”一案的视频，加深了同学对著作权的认识。

据统计，截止到今年3月，我院共申请了专利40余项，其中30项已获授权，其中发明专利5项，实用新型专利13项，软件著作权12项。
