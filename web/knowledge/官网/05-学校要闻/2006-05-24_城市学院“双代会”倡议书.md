# 城市学院“双代会”倡议书

倡议书全院教职工朋友们：在校本部通过学士学位评估的时候，在学院从“打基础、上规模”向“创特色、上水平”转型的关键时期，城市学院召开了第一届教职工代表大会暨工会会员代表大会。我们受大家的委托，出席了本次会议，共同描绘学院宏伟蓝图，感到无尚光荣和责任重大。

会议期间，我们听取了安少华院长所作的《与时俱进，开拓进取，为建设省内一流、追求卓越的本科独立学院而努力奋斗》的工作报告，学习和审议了大会所有的报告和决议。会议期间，我们回顾走过的历程，豪情满怀，倍受鼓舞。建院的三年，是自强不息的三年，是意气风发的三年，是高歌猛进的三年，是成果喜人的三年。三年来，在学院董事会的领导下，在院领导的带领下，全院教职工同心同德，拼搏进取，取得了令人瞩目的成绩。

机遇与挑战并存，希望和发展同在。当前，东莞经济快速发展，人才需求量很大，当地市民要求其子弟接受优质的高等教育的欲望与日俱增。但是，我们也清醒地看到，独立学院不断增多，境外大学进军内地教育市场，国家对独立学院各项政策进行收缩和规范，这些势必对我院的招生和发展带来一定的影响。我们必须审时度势，乘势而上，把握机遇，着眼未来，化不利因素为有利因素，把学院进一步做大做强。为此，我们倡议：爱校敬业，尽职尽责。

忠诚教育事业，热爱本职工作；认真贯彻执行党的教育方针，遵循教育规律，履行教师职责，积极参与学校的各项改革工作。

严谨治学，勤奋自强。

不图虚名，从严治学，从严执教。工作中精益求精，努力提高教学质量和学术水平。

教书育人，关心学生。

认真备课授课，严肃课堂和考试纪律，倡导优良学风。了解、关心、爱护和尊重学生，做学生的良师益友。

为人师表，举止端庄。

加强修养，以身作则，严于律己，表里如一，真诚坦荡，模范遵守社会公德。仪容仪表整洁大方，言谈举止得体端庄，自觉杜绝一切有失教师身份的言论和行为。

作风正派，坚持真理。

力戒急功近利，弄虚作假，投机取巧。敢于抵制任何形式的剽窃、抄袭他人教学科研成果的不正之风，坚决反对学术腐败。

遵纪守法，履行义务。

贯彻执行《教育法》、《教师法》、《高等教育法》以及学校的规章规范，坚持依法从教，自觉履行教师应尽的义务，主动弥补教学和管理工作等环节中的不足。

团结协作，顾全大局。

学习和倡导社会主义荣辱观，发扬集体主义精神，树立全局观念，正确处理个人与集体与学校的关系。克己奉公，淡泊名利，自觉维护学校的利益与荣誉。

朋友们，学院为我们构建了坚实的发展平台，我们一定能在这个舞台上演奏出最美的人生乐章。让我们坚持不移地依托母体保质量，面向市场谋创新，服务东莞求支持，追求卓越创品牌，科学发展作贡献，满怀信心，携手并肩，竭诚尽智，拼搏奉献，全力投入到学院的各项建设之中，为把学院办成有地方特色、省内一流、追求卓越的本科独立学院而努力奋斗！
