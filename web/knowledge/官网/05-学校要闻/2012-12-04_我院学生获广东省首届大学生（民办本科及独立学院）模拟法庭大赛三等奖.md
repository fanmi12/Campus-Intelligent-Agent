# 我院学生获广东省首届大学生（民办本科及独立学院）模拟法庭大赛三等奖

12月1日，广东省首届大学生（民办本科及独立学院）模拟法庭大赛决赛暨颁奖典礼在广东培正学院举行。政法系10级法学班郑佳岱、邱桂静、陈加尧、姚玉姗、谢兰娟、刘燕媚6位同学参加了本次大赛并荣获“三等奖”。

本次模拟法庭大赛由广东省犯罪学研究会、广东省民办教育协会、民办高校校长联席会共同主办，广东培正学院承办。据悉，参加本次比赛的有北京师范大学珠海分校、北京理工大学珠海学院、广州大学松田学院、广东培正学院等五所民办本科和独立学院。
