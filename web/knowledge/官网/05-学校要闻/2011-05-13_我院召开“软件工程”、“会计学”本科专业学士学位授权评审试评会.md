# 我院召开“软件工程”、“会计学”本科专业学士学位授权评审试评会

5月12日，我院在4315会议室召开东莞理工学院城市学院“软件工程”、“会计学”本科专业学士学位授权评审试评会议。副院长程发良教授、院督学陈丁堂教授出席会议。东莞理工学院、城市学院部分学科带头人以及相关部门领导参加了会议。

程副院长就试评专家组的工作计划、工作程序及时间安排做了说明。他希望专家组成员对参评专业严格把关，积极指导，多提意见。

会后，评审专家分组到财经系和计信系听取“会计学”、“软件工程”专业负责人关于专业自评情况的汇报并分小组进行评审。评审结束后，专家组向受评专业反馈了评审意见。
