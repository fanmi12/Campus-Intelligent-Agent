# 城市学院新校区第一期工程竣工启用

新校区装饰一新，迎接新生到来。

历时半年时间建设完成、书写了建筑史上“东莞速度”的东莞理工学院城市学院新校区，今天全面竣工并投入使用。9月17~18日，来自省内外4000多名2011级新生将到新校区报到。

由东莞理工学院与广东鸿发投资集团有限公司合作举办、占地面积达1200亩的城市学院新校区，总规划建筑面积66万平方米、在校生2万人。新校区遵循融“山、水、树、人”为一体的规划理念，以生态性、保育性为开发建设原则，注重以人为本，建筑实用性与建筑自身的精神品质相结合，为东莞理工学院城市学院百年名校的品质作奠基。同时，通过“生态—规划—景观—建筑” 整体设计，使校园内建筑群与自然山水地形有机融合，建筑风格充分体现了岭南建筑特色，独树一帜。

2010年10月，新校区一期工程“三通一平”工作正式启动。2011年2月底，广东鸿发投资集团有限公司下属企业的4支建设中队、3000多名施工人员正式进入工地。经过不到半年时间的建设，建筑面积达45万平方米的新校区一期工程全面完工，一个现代化的大学校园呈现在东莞寮步香市这片热土上。

此次投入使用的建筑，有公共教学大楼、三栋系部教学大楼、图书馆、学术报告厅、综合馆、游泳馆、六栋学生宿舍、学生活动中心、学生食堂及运动场、篮球场等。

园林景观也是新校区的一大亮点。新校区以中央湖景为中轴线，将园林景观和建筑群按此中轴线展开建设。中央湖景利用天然洼地优势进行建设，并收集周边山体将带来的自然雨水以解决湖水来源问题，并保留了湖旁的荔枝园林，配以园林绿化、修建小道、园林景观灯，形成了新校区一道独特的园林景观。
