# 花絮之一

城院，我来了9月13日9时，前来报到的新生络绎不绝，综合馆内人山人海。来自湛江的新生吴海颜同学便是其中一位，与其她学生不同的是，她在没有父母的陪伴的情况下，独自一人提着大小行李来到城院。李惠茵与梁志文两名志愿者，热心地对吴同学进行报名指导，并接过了她手中的行李。当问及为何没有家人陪伴时，吴海颜笑着说：“父母说我长大了，是一个独立的人，所以我与好朋友相约来城市学院。”在记者的追问下，吴同学羞涩地说：“刚到这个陌生的环境有点害怕，但看到师兄师姐的热情我有了亲切感，也深感自己独立了。”报到注册后，吴海颜还邀请志愿者李惠茵合影留念。（作者：肖田佩 摄影：欧迪鹏）

丝带传承文传情

熙熙攘攘的综合馆里，各色服装的志愿者穿梭其间，热情地帮助大一新生们报到注册。有那么一群人，手腕上都有一条绑成蝴蝶结的丝带。别致的丝带在他们的手上跟着指引新生。

“我们是文传系的，丝带人手一条。男生是蓝色的，女生则是红色的。”热情的同学介绍说，手腕上或蓝或红的丝带不仅是文传志愿者的标志，也寓意着文传系的精神：“我爱文传，代代相传”，演绎着互相友爱的一个个故事。

据了解，文传系共来了200名志愿者，这丝带也将让文传学子的同学情代代相传。（摄影：陈方怡）

一路上的师兄师姐的帮助9月13日上午7时，我院迎新工作正式启动。

到处都是忙碌的身影。校团委学生会的志愿者不厌其烦地给新生、家长回答各种问题。志愿者主动帮着拎行李，一路谈笑风生。新生细声地叫着“学长学姐”，老生们也开心地介绍这介绍那。

一位办理完报到手续的新生说：“热心的学长学姐帮着我搬行李、领物品，给了我亲切感。”一位北方的家长表示，一开始担心小孩适应不了南方的生活，学姐们热情的服务打消了我的顾虑，对小孩以后的大学学习生活充满期待。

今天上午整个的迎新工作总体情况较好，新生和家长对迎新工作普遍感到满意，并不断称赞学校优美、住宿环境好。（作者：张家豪、胡志聪 摄影：欧迪鹏）

【我有话说】

【学生】“今天七点多就从家出发了，因为不怎么认识路，所以花的时间比较长。”家住道滘的一名新生告诉记者，因为之前没有来过学校，今天上学时间花了大概四十分钟。“感觉学校真的不错的，环境很漂亮。到师兄师姐们很热情，一路上为我们新生提行李、指方向。”当被问到对大学有什么憧憬时，她微笑着说：“希望能多一点了解学校的社团活动，选择自己喜欢的。”

【家长】

Q “两位是从哪里过来的呢？”

A “我们家在浙江湖州，前天坐了21小时的动车，到东莞的茶山镇下车，然后在乘巴士来到学校。”

Q“觉得学校环境怎么样？”

A“环境很好！”两位家长笑道，“教学楼、宿舍都很漂亮、干净。”

Q“有什么想对儿子说的呢？”

A“哈哈，希望儿子在大学四年好好念书，毕业时能够找到一份好工作。”

【工作人员】

Q “今天几点钟到会场呢？”

A“闹钟六点半就响了，早上七点前已经到了综合馆。我们前几天已经开会、培训了，迎新准备工作还是很充分的。”

Q“对这一届新生有什么印象呢？”

A“他们都比较独立，像是入场报到、提行李回宿舍，大多是自己一个人完成，这一点很好。大学是一个培养独立性的时期，从踏入校门的一刻就应该开始。”

Q“有什么想对师弟师妹们说的吗？”

A“欢迎来到城市学院，希望你们能度过充实的大学四年。（不忘说一句：饭堂是我们的。）”

来到城院，我们长大了13日早上，校道两旁彩旗飘扬，校园广播回荡着迎宾音乐，早晨的空气里弥漫着青春的气息。此时，一位穿着黄色上衣的短发女孩，拉着大大的黑色行李箱，背着鼓鼓的彩色背包，手里还缠着一个咖色的便利袋，庞大的行李与瘦小的身影形成了鲜明的对比，让人不自觉地在密密麻麻的人群里注意到她的身影。

“我来自辽宁的，哈哈，我想自己能做的事情自己做啊，不想麻烦父母。”这位辽宁女孩爽朗地说。说完之后她继续转过头朝宿舍走去。她一边迈着欢快的步伐，一边回答记者问题：“我是自己坐车到东莞汽车总站，然后打的到学校北门的，师兄师姐很热情，给我指路，觉得大家都很亲切，很开心。”

最后，这位辽宁女孩表示，希望以后在学校能快乐地生活，认真学习，做自己喜欢的事。 （作者：陈欣茹 摄影：欧迪鹏）
