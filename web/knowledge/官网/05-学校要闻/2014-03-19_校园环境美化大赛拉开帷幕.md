# 校园环境美化大赛拉开帷幕

3月13日，我院学生处主办、院学生会生活部承办的“美化校园环境，营造文明氛围”校园环境美化大赛拉开帷幕，9个系的400多名同学积极参与，竞相为本系环境区的美化贡献一份力量。

由院学生处思政科陈晓萍老师、院团委陈浩华老师、后勤物业中心黄桥柱老师组成的评分团为各系的环境区评分。

财经系的同学们或结伴打扫卫生，或相互协作清洁垃圾，清洁工作有条不紊地进行着。据汇报，财经系实到人数超出预期。董志威同学表示他是听室友提及这次活动的，感觉很有意义，便志愿投入到清洁队伍中。

陈晓萍老师表示，此次活动是为了响应教育部“爱学习，爱劳动，爱祖国”的号召，是加强学生环境美化意识和德育教育的一项长期工作。

最终，金贸系凭借总分93分的优秀成绩居榜首，财经系以1分之差屈居第二名，管理系和政法系并列第三名。

院学生会生活部部长钟启林透露，校园环境美化大赛本学期共设三次检查评比，分别在第4周、第8周和第13周。内容包括公共环境区清洁情况，教室区、宿舍区、饭堂区、会议或晚会结束后场地的卫生保洁情况。
