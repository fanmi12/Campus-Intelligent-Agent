# 我校召开大学英语四、六级考试考务协调会

6月4日，教务处组织召开2019年上半年大学英语四、六级考试考务协调会。主管校领导、各主要工作小组负责人及考务工作负责人员参加来会议。

会议成立了以王卫平校长为主考、高香林副校长为副主考的考务领导小组。

教务处处长赵书山介绍了此次大学英语四、六级考试的总体情况，对考试工作进行了统一部署。

王卫平校长、高香林副校长强调了加强全国大学英语四、六级考试考务工作的重要性，要求各工作小组认真细致对待各项准备工作，确保本次考试顺利进行。
