# 我院举行海外实习实践基地揭牌仪式

9月26日下午，我院海外实习实践基地揭牌仪式暨2017-2018学年项目发布会在国际交流中心新址举行。中国对外友好合作服务中心代表华南大区项目经理苏安江先生，学院副院长刘玉侠、院长助理林江龙出席了揭牌仪式。参加活动的还有各单位及院系（部）负责人。

国际交流中心负责人陈峰与苏安江经理为海外实习实践基地揭牌。

刘玉侠副院长对海外实习实践基地正式挂牌成立表示热烈的祝贺。她说：“揭牌仪式标志着我院开启了对外国际交流学习的新征程，将进一步推动我院国际化办学目标。”

苏安江经理在致辞中，介绍了中国对外友好合作服务中心的有关情况，对城市学院的支持与合作表示感谢，希望通过双方共同的努力，继续源源不断地为社会培养大批的具有竞争力和认可度的优秀人才！

国际交流中心负责人陈峰就2017-2018年度培训项目进行了发布。

据了解，目前，我院已与中国对外服务友好中心等建立起合作关系，开展了包括赴美国带薪实习、赴斯里兰卡非盈利性组织国际志愿者实习等项目。通过海外实习实践基地的建设，有助于扩大我院学子国际视野，增进文化交流，促进国际化办学。
