# 开赛！第十一届全国大学生数字媒体科技作品及创意竞赛广东省赛区在我校启动！

5月20 日，第十一届全国大学生数字媒体科技作品及创意竞赛广东省赛区启动会在我校举行，来自全国智能科技数字媒体、创新设计领域的著名学者专家、企业家及高校师生代表齐聚一堂，共话赛事发展。本届竞赛由中国人工智能学会主办，中国人工智能学会科普工作委员会、中国人工智能学会女科技工作者工作委员会、中国计算机学会虚拟现实与可视化技术专委会联合协办，并获得了虚幻引擎中国的鼎力支持。广东省赛区由我校和广东工业大学共同承办。

我校副校长陈葆华教授主持启动会

广东省民办教育协会常务副会长张耀荣，教育部高等学校动画、数字媒体专业教学指导委员会委员、北京林业大学信息学院淮永建教授，全国大学生数字媒体科技作品及创意竞赛秘书长刘华群，中国计算机学会虚拟现实与可视化专委会执行委员、虚幻引擎大中华区教育总监褚达，广东省动画、数字媒体教指委副主任委员、广东工业大学艺术设计学院副院长汤晓颖教授，教育部高校动画与数字媒体专业教指委委员，广州美术学院动画专业学科带头人陈赞蔚教授，广东省动画、数字媒体教指委秘书长廖向荣；格瑞科技(广州)有限公司董事长陈英，澳门城市学院助理教授彭俊；我校执行董事陈超群，常务副校长方伟华，副校长陈葆华、李海冬，教育部动画与数字媒体专业教指委委员，创意设计学院乡村振兴学院院长郭冶教授，人工智能学院名誉院长牛熠；创意设计学院执行院长何帅等领导和嘉宾出席了启动仪式。大赛各省赛、分赛区代表以及广东工业大学、山东财经大学、延边大学、福州大学 、江西财经大学、武汉商学院、暨南大学、广东白云学院等高校师生代表近400人齐聚一堂，共参大会。副校长陈葆华主持启动仪式。

领导致辞

常务副校长方伟华教授致开幕辞

学校常务副校长方伟华教授致开幕辞。他介绍了学校和创意设计学院的基本情况，他指出，计算机、通信和广播三大传统信息系统领域的融合，产生了基于数字互动的媒介汇流和产业整合现象，数字媒体附加的“创意经济”时代正在到来。他回顾与中国好创意大赛组委会的缘分，相信本次论坛能进一步推动创意设计相关专业的学科建设，推进数字产业化和产业数字化，培养应用型、创新型、复合型人才，为我国数字创意产业发展作出新的更大贡献。

广东省民办教育协会常务副会长张耀荣对大赛的顺利开展表示热烈的祝贺，他用两个故事与大家分享了“智能时代”发展的重要趋势以及未来人才在面临智能科技时的发展路径。他指出广东省民办协会一直致力于推动民办教育事业的发展，积极支持数字媒体科技教育和产业发展，为广大学生提供了更广阔的学习和实践平台，希望数字媒体科技产业会继续蓬勃发展，成为引领和推动经济社会发展的重要力量。

教育部高等学校动画、数字媒体专业教学指导委员会委员、北京林业大学信息学院淮永建教授宣读广东省赛区成立。

广东省民办教育协会常务副会长张耀荣、东莞城市学院执行董事陈超群以及淮永建教授、刘华群秘书长、褚达总监、汤晓颖教授、郭冶教授、陈赞蔚教授、廖向荣教授、陈英董事长、彭峻助理教授、李海东副校长、牛熠教授、何帅执行院长共同为大赛剪彩。

大赛组委会秘书长刘华群宣读了成立《全国大学生数字媒体科技作品及创意竞赛（广东省赛区）专家委员会》文件。汤晓颖担任广东省赛区专家委员会主任委员，何帅担任专家委员会秘书长，方伟华、牛熠、陈赞蔚、郭冶、廖向荣担任副主任委员，成骏、汪凌、汪欣、许吉锋、何新闻、李小东、刘亚军、吴学云、罗漫、陆丹、杨乾明、杨磊、涂先智、徐志伟、贺锋林等担任专家委员会委员，并颁发聘书。

随后举行了“AIGC背景下艺科融合人才培养论坛”，由广东省赛区专家委员会秘书长、我校创意设计学院执行院长何帅主持论坛。

教学指导委员会委员

教育部高等学校动画、数字媒体专业教学指导委员会委员、北京林业大学信息学院淮永建教授作《元宇宙和ChatGPT背景下数字艺术创作》主题分享。他介绍了元宇宙技术发展、Chat GPT人工智能大语言模型技术发展；重点介绍了人工智能AIGC技术以及在数字艺术内容创作应用，并对未来基于元宇宙沉浸式交互技术、AI智能化建模和数字内容设计生产发展趋势进行展望，探讨了未来艺术、科技和内容生产的融合方式以及数字艺术交叉学科的发展方向。

褚达虚幻引擎大中华区教育总监

虚幻引擎大中华区教育总监褚达作《虚幻引擎与数字内容生成》的主题分享。报告从数据整理，互联生态系统，协作和跨平台体验等十个方面介绍了虚拟引擎在数字科技方面的应用，分享相关实例，并希望能通过更丰富的创意来补充3D实时交互技术，使每个人都能通过这项技术获得更好的体验，同时也希望这项技术能更好地帮助学生在未来对应技术改革。

下午，在学术报告厅举行了“全国大学生数字媒体科技作品及创意竞赛”国赛、省赛赛事组织研讨。全国大学生数字媒体科技作品及创意竞赛秘书长刘华群教授主持研讨会。

学校常务副校长方伟华教授致辞。他提到了早年办学和参加相关比赛的经历，这些经历对他的工作和治学方面都产生了积极的影响。并对近年来比赛的发展方向进行分析，认为比赛应该更注重实践能力和创新能力的培养，而不仅仅是对知识的考核。此外，他提出应当注重参赛学生的心理状态，培养学生自信心、正确的竞争心态等。
