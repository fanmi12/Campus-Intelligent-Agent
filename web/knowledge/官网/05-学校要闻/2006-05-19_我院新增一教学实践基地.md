# 我院新增一教学实践基地

5月18日，城市学院教务处处长邓成良，文学与艺术系主任张林，学生处副处长、招生办与就业指导办副主任陈建新以及40多名师生在大岭山镇东江纵队纪念馆，举行“东莞理工学院城市学院教学实践基地”挂牌仪式。

邓处长代表学院感谢东江纵队纪念馆对我院教学工作的支持，希望该馆对我院实习学生进行严格的实习管理指导。

东江纵队纪念馆是广东省实施南粤锦绣工程的重要项目之一，东莞市打造文化新城的重要举措。馆区占地面积53319平方米，建筑面积4000平方米，陈列了丰富翔实的东纵在革命战争年代进行艰苦卓绝斗争的历史照片、文物和史料。陈列馆共分9个部分，展出的革命文物140多件，图片450多幅，雕塑、油画、版画等艺术作品20多件，是缅怀革命先烈进行革命传统教育的重要课堂和内容。

挂牌仪式后，师生们参观了东江纵队纪念馆，观看了东江纵队战斗场景的情境模拟电影以及资料图片。
