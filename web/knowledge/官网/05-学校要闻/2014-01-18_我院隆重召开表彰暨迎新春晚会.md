# 我院隆重召开表彰暨迎新春晚会

1月17日，我院在综合馆举行表彰暨迎新春晚会，表彰2013年“十大工作创新奖”、“校园教工十佳”，迎接2014年的到来。晚会开得隆重简朴，虽然没有了往年的抽奖、酒宴环节，却依然洋溢着欢快祥和喜庆氛围。

出席本次晚会的嘉宾有东莞市老领导刘树基、姚锦柏，省政协委员、原东莞理工学院党委副书记、校长杨晓西，东莞理工学院党委副书记吕琦元，东莞理工学院老领导张遐龄、欧阳禹湖、周文媛、钟剑辉、王素其、包树元、王江水、黄碧莲，东莞理工学院城市学院董事长麦照容、黎建烨，城市学院老领导朱志德、朱冰，市政协科研文卫体和文史委员会主任李炳球。

会议还邀请了东莞理工学院莞城校区管委会、东莞市鸿发教育投资有限公司等单位的负责人，曾经在城市学院工作过的院（处）负责人。

与会嘉宾和我院教职工一道观看了文艺演出。

大会首先举行了表彰颁奖仪式。党委书记王卫平宣读了我院关于表彰2013年城市学院“十大工作创新奖”获奖项目和“校园教工十佳”人员名单的决定。刘树基等老领导分别为获奖单位代表及“十佳教工”颁奖。

会上还播放了城院电视台制作的贺岁DV短片与文艺演出。据悉，所有演出的节目都是由教工和院领导自创自编自演的。无论是电视短片还是文艺节目，都是教职工以纪实的手法，运用各种文艺形式，充分反映了我院教职工在过去一年里，按照学院提出的“提升能力、确保质量、改革创新、稳健发展”的工作思路，在教学、科研、育人、管理、服务地方、建设与发展等方面所取得的骄人成绩及精神风貌，也表达了“城院人”在新的一年里踌躇满志再续新篇的决心。
