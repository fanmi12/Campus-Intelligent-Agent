# 【“十八大”专题】发挥专业特色，树城环先锋形象

12月20日，城环系于莞城校区3309室召开第十一期预备党员转正大会暨学习十八大民主生活会。83名学生党员同志出席会议。

会议严格按照预备党员转正相关程序，通过了预备党员的转正申请。

随后城环系全体学生党员在辅导员曹镭老师的带领下共同学习了十八大报告中的主要内容，并对科学发展观、生态文明建设、提高党员建设的科学化水平等重点主题进行了认真讨论和总结。

最后，城环系党总支副书记张海勇总结发言，他要求全体学生党员要深刻领会十八大的有关会议精神，特别是要加深对中国特色社会主义、生态文明建设、科学发展观等主题的认识，不断提高自己的理论修养，坚定共产主义理想信念；并与现实生活相结合，保持共产党员的先进性，充分发挥共产党员的模范带头作用，为全院师生做好事、做实事。
