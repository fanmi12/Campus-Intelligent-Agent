# 李晓宇：在赛场上展现最好的自己

六场小组赛场分都在两位数以上！凭借着2.03米的身高优势频频扛起球队内线进攻的大旗，助力我校男篮在第四届东莞大学生篮球联赛中取得小组赛全胜战绩。

很难想象，这是一位大一新生，并且是第一次参加大联赛的场上“新人”，一出手能够取得这么好的成绩。在六场比赛中，2019级新生李晓宇同学，凭着拼搏的精神与实力证明了这一切。

李晓宇，我校男篮有史以来最高“海拔”的队员，将继续努力训练，在篮球场上挥洒汗水、再创高光时刻。

坚持初心，赛出最好的自己

高中时作为篮球校队队员，李晓宇对篮球的热爱开始与日俱增。选择城院男篮是他坚持热爱，在大学新阶段的再一次出发。

暑假被城院录取时，李晓宇就主动联系校篮球队队长，表达了自身想加入校队的意愿。李晓宇说:“学校男子篮球队有着很好的训练氛围，带给了自己全新的训练方式与方法。在收获了一群志同道合的兄弟之外，最为重要的是让自己传承了球队的拼搏精神”。

作为篮球城市的东莞，每年都会举办众多大至国际、小至镇街的各类篮球比赛。

大学之前，远在湛江六中的李晓宇就早有耳闻，而当真正站在大联赛的球场上时，心里还是有些紧张，害怕表现不好。李晓宇分享了他初登大联赛的心情。作为场上“新人”，李晓宇最想做的就是尽快融入球队，承担起最基本的防守与篮板任务。他说:“通过比赛，教练钱丽娜老师指出了自身防守时移动速度太慢，进攻篮板拼抢时不够积极等不足之处”。“每场比赛结束后，大家都会回看比赛视频，找出漏洞和不足以及对手的优点，不断进行交流学习改善，提升自我能力”。

站上球场，全力以赴

小组赛取得六连胜，这个成绩足以令人称赞。李晓宇却对此却有着不一样的看法。小组赛的收官之战对阵东莞理工学院队，第一节时球队遭遇了开赛以来的最大分差。

李晓宇回味当时的情景:“虽然处于劣势，但我们心态并没有被影响，依旧按照教练的指示，组织好每一次进攻与防守，积极抢下每一个篮板，一步一步地追上比分，并不知不觉地反超对方。取胜的关键就是拼搏精神以及渴求胜利的信念，让球队最终实现反超并且赢下比赛”。

当记者问及球队谁最让自己感动时，“那就是队长了”。生活中，队长是他不可多得的知心朋友；球场上，是他坚信的队友。李晓宇对队长邓浩宏同学的感谢溢于言表。在采访时，李晓宇还特别谈到了叶锐城、黄荣斌两位师兄。他们已经在工作了，作为毕业校友的球员重返赛场。李晓宇代表球队表示，感谢师兄们为了学校而兼顾工作和比赛，以及在球场上对年轻球员耐心的指导和引领。李晓宇表示，球队所有队员一定会竭尽全力给两位师兄“再挂一次牌”（夺冠），作为最好的毕业礼物送给他们！

无惧挑战，迎难而上

在去年半决赛中，城院男篮抱憾输于东职队，无缘决赛。如今，半决赛又将交锋东职队。李晓宇提到最多的是对赛制、对手的不熟悉，只能通过老队员的经验传授以及观看比赛录像了解对手。

对 “赢一场就能晋级总决赛，输了就只能争三四名了”的赛制，李晓宇决心“背水一战”。从他的言语与表情里，记者看到了我校男篮的拼搏精神。无论是队长邓浩宏为救球而不惜双膝重重落地，亦是师兄黄荣斌一开赛就带着手伤征战，城院男篮人身上就有一股不可磨灭的血性。

李晓宇认为，身为一名运动员应具备努力、踏实、责任心、坚持不懈、不言放弃、努力拼搏等精神，在赛场上展现最好的自己，为学校争光，为自己大学生活带来点色彩。
