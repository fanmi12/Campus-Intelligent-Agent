# 广州新华学院一行来我校交流

5月19日下午，广州新华学院常务副校长肖化一行8人来我校交流。我校常务副校长方伟华、副校长李海冬以及人力资源部、财务资产处、学校办公室等部门负责人参加了交流活动。

交流会上，方伟华常务副校长代表学校对肖化常务副校长一行来访表示热烈欢迎。双方就机构岗位建设、教职工结构设置与管理、薪酬体系建设等问题进行广泛探讨，并就绩效改革以及高校建设深入研究交流。

肖化常务副校长对我们的热情接待表示衷心感谢，并诚挚邀请我校领导回访广州新华学院。

方伟华常务副校长表示，此次交流会，探讨了问题，交流了经验，达成了共识，加强了相互之间的了解，增进了双方之间的关系，加深了两校之间的友谊，希望通过此次交流活动，推动双方共同进步发展，实现互利共赢。

陪同肖化常务副校长考察的有广州新华学院督学刘东远、人力资源管理处处长林源、财务总监吴赛金、财务处处长黄荣芳、人力资源管理处副处长郑锦伍、刘穗、校长办公室副主任张强。会前参观学校沙盘，会后参观图书馆、学术报告厅等校园设施。
