# 我院举办“信息时代的教育教学改革” 培训讲座

11月2日下午，学院教师发展中心在学术报告厅举办“信息时代的教育教学改革”专题培训讲座。学院领导、中层干部和专任教师等参加了培训。

培训讲座由教育部高校教师网络培训中心专家库“微格教学”专家、武汉轻工大学教师发展中心主任张胜全教授主讲。张教授从信息时代背景下教育教学改革的方向，讲解了教师角色的转化，“以教师为中心”转变为“以学生为中心”的教育教学理念，着重从学习方式、教学环境、教学设计、信息技术在教学中的应用等方面，为参训教师带来了一场精彩、实用的讲座。

据了解，此次培训活动旨在全面贯彻新时代全国高等学校本科教育工作会议的重要精神，坚持“以本为本”，推进“四个回归”，全面提升我院教学能力，促进教育教学改革。
