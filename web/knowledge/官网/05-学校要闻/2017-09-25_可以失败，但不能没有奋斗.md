# 可以失败，但不能没有奋斗

“我名字中的‘韦’取自‘韦编三绝’，有静心勤奋读书的意思。”

今年我院招生成绩喜人，生源质量再次获得显著提升，更多优秀学子选择了城市学院。外语系商务英语专业的叶韦静就是其中之一，她以文科并列第一名的优异成绩获得了我院2017年新生奖学金。

与其他新生一样，叶韦静对自己四年大学的校园也充满好奇和憧憬。机缘巧合之下，叶韦静选择了城市学院。当第一眼看到城院时，她觉得自己的激动心情难以形容：“很大，很漂亮，人也很多。”怀着对大学和校园未知的新鲜感，叶韦静把校园逛了一遍又一遍，因为每一栋建筑每个景点都将是自己大学的一部分，都将为自己的大学带来难忘的记忆。

在叶韦静看来，和刚刚过去的中学生活相比，大学的学习生活精彩与否将更多的取决于自己的选择。叶韦静告诉记者，英语其实是高考成绩中最差的一门，但却偏偏选择商务英语专业，就是想挑战自己。“越是短板就越要增强，与其逃避不如直接面对它”，她说，“我可以接受失败，但绝对不能接受未奋斗过的自己”。当提及万一发现自己对英语专业课程不感兴趣该如何办时，叶韦静坚定地说：“已经下定决心去做了，其它的就都不是事。”对商务英语专业，叶韦静也有着自己的见解，“起码将来能认识更多外国朋友，能更好地了解世界”。

“大学，想得到什么，四年后我能留下什么？”这是每个初入大学的人都会思考的问题，叶韦静也不例外。她表示，将会努力让自己的生活变得充实多彩，会参加学院团学组织来锻炼自己。她希望接触更多人来锻炼自己，同时也希望能收获几份美好的“闺蜜情”。
