# 市委徐书记督办牛熠处长的提案办理工作

在今年东莞市政协十二届二次会议上，市政协委员、民进会员、城市学院教务处处长牛熠教授和民进会员、东莞理工学院教授刘川写出的提案《关于完善东莞水乡特色发展经济区地方干部政绩考核评价指标，建立十镇一港联动考核机制的建议》，受到市委及市委书记徐建华的高度重视，被列为市委书记督办的重点提案。

6月6日，徐建华书记主持召开市委书记督办市政协重点提案调研座谈会，专题听取牛熠委员这一提案办理情况的工作汇报。

会上，市水乡办汇报了提案办理情况，各有关部门、牛熠委员以及市政协提案委的同志就如何办好这一提案发了言。

徐建华书记强调，要加快建设水乡特色发展经济区考核评价机制，以考核评价机制为导向，进一步推动水乡经济区的科学发展、转型发展；以督办座谈会为契机，推动提案办理工作取得更大实效。
