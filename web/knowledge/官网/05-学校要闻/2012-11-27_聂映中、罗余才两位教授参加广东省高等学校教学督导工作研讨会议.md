# 聂映中、罗余才两位教授参加广东省高等学校教学督导工作研讨会议

第七届广东省高等学校教学督导工作研讨会11月23日至24日在河源召开。中山大学等102所广东高校、200多人参加会议。我校聂映中、罗余才教授与会。

会上，我院介绍了督导工作的体制和方法。许多学校的代表都表示，认为我院的督导工作有特色，做的比较好。我院两位教授也和其他一些高校代表进行交流，学习到不少经验。这些经验将有利于我院进一步加强督导工作，促进教学质量的提高。
