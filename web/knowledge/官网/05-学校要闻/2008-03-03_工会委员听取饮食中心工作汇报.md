# 工会委员听取饮食中心工作汇报

2月29日，院工会教工饭堂伙食监督小组，在410会议室听取总务处副处长马兴顺、饮食中心主任李柏生、饮食中心主任助理兼餐厅经理徐婷、总务处办公室主任助理李应坚关于教工食堂的工作汇报。

马兴顺副处长向委员们介绍了教工饭堂的管理模式、原料采购监督流程以及2008年1月11日伙食监督小组会议的整改情况。

参会的工会委员们对教工饭堂饮食卫生安全、饭堂管理规范化建设工作提出了意见与建议。

饮食中心负责人表示，虚心接受监督小组的意见，进一步加强食品卫生安全的监控，将饭堂工作流程、原材料采购、教工饭堂每月收支等情况定期向教工公布，接受大家的监督。
