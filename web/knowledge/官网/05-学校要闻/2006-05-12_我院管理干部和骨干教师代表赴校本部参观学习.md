# 我院管理干部和骨干教师代表赴校本部参观学习

5月11日，我院党政领导带领学院中层管理干部和骨干教师代表共80余人赴校本部参观学习。

校本部在会议室举行了欢迎仪式。东莞理工学院副院长安少华教授、院长助理戴炳源博士先后致辞表示热烈的欢迎。东莞理工学院教务长林养素教授介绍了校本部学士学位评审情况。

欢迎仪式之后，我院参观人员分成14个小组，分别到校本部对口部门进行学习交流。
