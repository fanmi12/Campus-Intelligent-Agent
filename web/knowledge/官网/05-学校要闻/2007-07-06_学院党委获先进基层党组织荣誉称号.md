# 学院党委获先进基层党组织荣誉称号

东莞理工学院党委下发《东理党[2007]20号》文件，城市学院党委等5个单位授予为东莞理工学院先进基层党组织称号。

文件指出，在2006—2007学年中，各基层党组织坚持以邓小平理论、“三个代表”重要思想为指导，全面落实科学发展观，紧紧围绕学院中心工作，求真求实，锐意进取，努力工作，有力地推动了学院各项工作的开展，为学院的改革发展和稳定提供了坚强的政治保障。
