# 加强考风考纪教育，树立诚信自律风气

为落实学校有关考试的各项规定，进一步加强考风建设，严肃考纪，营造良好的考试环境，6月26日，财经系在5号阶梯课室召开了考风考纪教育大会。

会上，通报了有关学生作弊、旷课的处分情况，公布了财经系历年来作弊、旷课的学生名单，宣读了被处分学生的悔过书。高香林教授对期末考试提出了希望和要求：要求学生统一思想，提高认识，避免侥幸心理；考试就是考人品，考水平，考公平；要求广大学生要以勤奋好学、实事求是的态度对待期末考试，做诚实守信的大学生。最后，他祝愿同学们在期末考试中考出好成绩。
