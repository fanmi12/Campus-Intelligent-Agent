# 新同学，请留意收取入学通知书

新同学们，请保持高考前填报的地址及通讯方式的畅通，近日留意收取入学通知书。

我院广东省内考生的4000多份的入学通知书已于今天（8月14日）下午通过EMS特快专递寄送，预计同学们过2天陆陆续续收到。省外及美术类考生的录取通知书也将于下周内寄出。同学们可在特快专递寄出后的第二天到招生信息网（http://zsb.ccdgut.edu.cn/）查询录取通知书快递单号。

今年，我院在外省招生的最后一个省份是黑龙江省，8月14日该省6名同学通过录取，标志着我院2014年招生录取工作圆满结束。

至此，2014年我院共录取新生5395人，比2013年还多42人，录取人数再创我院新高。同时，2014年我院在本科扩招后首次省内普通类招生线上超计划完成招生任务，实现了质和量的飞跃，为我院建院10周年献上一份厚礼。

据学生处主管招生工作的孔增强副处长介绍，今年寄给新同学的特快专递里，除了入学通知书、报到须知及相关政策手册以外，还有学长为师弟师妹们精心制作的《城市学院手绘地图》，让同学们提前身临其境，感受城院。
