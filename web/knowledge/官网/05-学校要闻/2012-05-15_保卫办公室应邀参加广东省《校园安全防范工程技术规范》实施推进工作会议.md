# 保卫办公室应邀参加广东省《校园安全防范工程技术规范》实施推进工作会议

5月11日，我院保卫办公室主任理阳阳，汤剑平老师受邀参加广东省《校园安全防范工程技术规范》实施推进工作会议暨广东省技防专家库会议。此次会议由广东省公安厅、广东省教育厅联合举办，全省数百名安防专家和教育系统保卫处长、全省重点中小学主管校长参加了会议。广东省公安厅何广平副厅长、广东省综治办张庆宏副主任、公安部科技信息化局李明甫处长、省教育厅安保处陈日文处长、广东省公安厅办公室科技信息化处王诗军副处长等领导出席了本次会议。

据悉，此次会议是2012届中国广东国际社会公共安全产品博览会系列活动之一，我院保卫办参会人员此行特别参观了广东省网络安全重点实验室，学习了解先进安保知识，共建和谐校园。
