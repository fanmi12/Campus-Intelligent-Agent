# 学院领导与留校师生一起过新年

学院教职工餐厅洋溢着节日喜庆的气氛。院领导宴请留校师生共进团年饭，共庆2010年新春佳节。

朱书记代表院党委和行政向寒假留校的师生致以新春的问候。

学院领导来到学生当中，举起手中的酒杯向学子们送上节日的祝福。

安院长亲切慰问勤工俭学的学子，举杯共饮，祝愿他们在新的一年，学业有成。

院领导来到餐厅厨房，看望慰问一年来辛勤忙碌的厨师们。

除夕夜，院领导与师生观赏了绽放在城院夜空的焰火。

精彩一瞬，色彩斑斓。

农历腊月三十，学院教职工餐厅洋溢着节日喜庆的气氛。中午，院长安少华、党委书记朱志德、副院长张林、院督学陈丁堂等与春节留守学校的教职工、同学一起同吃团年饭，共庆2010年新春佳节。

宴会开始前，院领导亲切慰问了正在餐厅厨房忙碌团年饭的厨师们，安院长竖起拇指盛赞道：“你们是厨师级的教授级，为全院师生提供了美味可口的饭菜，你们辛苦了。在新春佳节之际，我代表学院忠心地向你们表示感谢！”

宴会上，朱书记代表院党委和行政向寒假留校的师生致以新春的问候，祝愿大家新年愉快、万事如意。随后，领导们来到学生当中，举起手中的酒杯向学子们送上节日的祝福。席间，安院长与在坐的同学们亲切交谈，详细询问他们的生活、学习和社会实践情况。院党委办公室主任王玉代表学院为每个留校师生派发了过年红包。

特殊的团年饭，送去的是平常的问候，留下的却是温暖人心的感动！经贸系叶少华同学寒假期间在光大证券公司实习，她说，今年是第一次没和家人团聚过年，在学校团年，让她感受到了学院大家庭的温暖。同学们纷纷表示，学院领导和老师们无微不至的关怀和周到细致的安排让他们体会到了新年的温暖和幸福。

除夕夜，学院还开放了学生活动中心供学生观看春节联欢晚会；岁末12点钟声敲响之际，院领导和师生一同在操场上还观看了焰火。
