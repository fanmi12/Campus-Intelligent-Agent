# 我院少年儿童载歌载舞庆“六一”

少年儿童载歌载舞庆“六一”

大人小孩打成一片，歌声不断，笑声不断。

好高兴，这么多的叔叔、阿姨陪我们过节日。

终于得到心仪的礼物。

5月28日，在六一国际儿童节到来之际，院工会在卡拉OK厅举办了别开生面的教职工子女才艺大赛。

孩子们多才多艺，表演形式丰富多彩，有歌曲、舞蹈、绘画、讲故事、武术、健美操及乐器独奏，其中有4岁的儿童背诵《三字经》，14岁的小孩弹奏古筝，无所不能，尽显风采。比赛持续了两个小时，现场的掌声、笑声不断，其乐融融。
