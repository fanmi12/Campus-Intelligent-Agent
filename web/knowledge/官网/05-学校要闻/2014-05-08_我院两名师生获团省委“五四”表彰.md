# 我院两名师生获团省委“五四”表彰

日前，院团委从团省委《关于表彰2013-2014年度广东省优秀共青团员、优秀共青团干部、十佳团县委书记、百佳团支部书记、五四红旗团委（标兵）和五四红旗团支部（标兵）的决定》（团粤发〔2014〕8号）获悉，我院团委书记罗文芳老师被评为2013—2014年度“广东省优秀团干部；市学联执行主席、城市学院原院学生会副主席叶晓彤同学被评为2013—2014年度广东省优秀共青团员。

在过去的一年里，我院团委紧紧围绕团的主业和根本职责，扎实推进各项工作，取得了良好的成绩，此次表彰是团省委对我院共青团工作的充分肯定。
