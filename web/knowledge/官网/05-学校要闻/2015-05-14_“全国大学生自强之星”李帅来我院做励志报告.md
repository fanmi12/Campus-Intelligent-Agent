# “全国大学生自强之星”李帅来我院做励志报告

5月11日，“全国大学生自强之星”、“河南省优秀大学生”、北京卫视栏目《我是演说家》四强选手李帅应邀到我院学术报告厅做励志演讲。他演讲的题目是《谁说我们做不到》。

李帅首先与大家分享了他不同于一般同龄人的成长经历，因为身体缺陷，在人生道路上受到许多人的嘲讽，但他永怀梦想。他坦言，做人要有梦想才会有追求。他说，我们虽改变不了世界，但可以改变你我的生活态度。不要相信命运，要不懈地努力。

李帅劝告同学们，现在社会上的诱惑太大，要懂得如何抵制诱惑。也许生活中常常会有人不停地告诉你，这些事情你做不到，因为他们也想让你变得和他们一样，不要为之去努力。这时候你要坚守自我，用成功告诉他们：谁能说我们做不到！

李帅的演讲幽默风趣，富有人生哲理，使现场的气氛十分活跃，不时获得同学们的热烈掌声。他的生动特殊事迹，更使同学们深受感动与教育。

据介绍，李帅出生时就被确诊患有先天性成骨不全病症，俗称“脆骨症”或“玻璃男孩”。24年来，他骨折不下百次，不能走路，甚至连站着都会导致骨折，命运注定他的一生将要在轮椅上度过，但他却有坚强的骨气。在高考前三个月，他意外骨折了，本来可以考取清华、北大，但他最终选择了一所大专院校。上大学后，他开始写小说，一天写4千字，最多的时候可以写2万字，一个暑假写了24万字。

大二的时候，李帅应《鲁豫有约》节目组的邀请，当现场嘉宾，从此他便开始了屏幕人生。接着，又参加了北京电视台《我是演说家》的比赛，最终获得全国第四名的优异成绩。
