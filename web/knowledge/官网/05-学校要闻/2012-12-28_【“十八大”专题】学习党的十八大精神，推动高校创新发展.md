# 【“十八大”专题】学习党的十八大精神，推动高校创新发展

12月27日，学院党委在学术报告厅举行党的十八大精神报告会，组织党员学习党的十八大精神。东莞理工学院党的十八大精神宣讲团成员、思政部主任李洪君教授，在报告会上做了主题为“学习党的十八大精神，推动高校创新发展”的辅导报告。

党委书记朱志德主持报告会，300多名教工党员和学生党员代表参加听报告。

李洪君教授的报告内容丰富，观点新颖，概括全面，详尽地介绍了党的十八大的历史意义，重大成果、以及报告中的新思想、新观点、新部署、“小康社会”、“五位一体”、“党的建设”等方面的内容，传述了东莞理工学院党委关于学习贯彻党的十八大精神的意见，联系实际谈了自己的学习体会。报告会历时一个半小时，会场座无虚席，不时响起会意的笑声和掌声。

李洪君教授在联系实际谈到东莞高等教育创新发展问题时指出，党的十八大对文化建设和高等教育提出了明确的任务和更高的要求。我们要从实际出发，科学制定规划，扎实推进改革，切实改善管理，抢抓机遇，乘势而上，有力推动建设，坚持“服务东莞，创新发展”的方向，办人民满意的高等教育，为全面建设小康社会作出应有的贡献。
