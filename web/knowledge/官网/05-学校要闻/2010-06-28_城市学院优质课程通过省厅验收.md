# 城市学院优质课程通过省厅验收

院督学陈丁堂在会上展示我院《基础》课程建设的成果

在6月25日召开的广东省高校思想政治理论课第二批优质课程验收会议上，我院《思想道德修养与法律基础》（以下简称《基础》）课程顺利通过验收,并获得“优秀”。

据悉，在这次会议上，全省高校共有20门立项建设的优质课程参加验收，其中仅有5门获得优秀。

院督学陈丁堂教授、思政部副主任石志民副教授参加会议，并在会上展示了我院《基础》课程建设的成果，汇报课程建设的主要措施与成效，现场演示该课程网站的建设情况，并回答了专家组提出的问题。

经过几年的建设，我院《基础》课程建设形成鲜明的特色，取得显著的成效，受到省教育厅思政处有关领导和省专家组的称赞。
