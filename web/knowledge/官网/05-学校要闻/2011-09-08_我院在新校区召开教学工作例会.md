# 我院在新校区召开教学工作例会

9月7日，我院新学年第二周教学工作例会在新校区法商大楼一楼会议室召开，院领导安少华、杨敏林、程发良，院督学陈丁堂与各系部主任，新校区管委会领导麦绮琳、黄研晖、胡钦华出席了会议。会议由程发良副院长主持。

与会领导听取新校区教学硬件建设基本情况的汇报，并就新校区的建设情况、教学管理及管理模式等问题进行了研讨。会议还就加快新校区建设工作、保障迎新工作的顺利进行以及确保接下来各项教学工作的顺利开展等事项达成共识，各部系主任均表示将全力以赴、克服困难，确保新校区各项教学工作的顺利进行。

例会上，安少华院长对新校区的各项工作成绩表示肯定，对新校区及各系部接下来的工作将面临的挑战与压力表示理解。他希望学院领导和各系部主任多到新校区开展工作并形成制度，有比较固定的工作时间，并通过多思考、多研讨、多献策，尽学院集体的能力与努力把迎新工作和新校区的教学与管理工作做好、做扎实、做出成效。
