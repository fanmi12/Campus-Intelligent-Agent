# 我院校外实习基地又添新成员

6月16日，我院城环系主任肖红飞教授、教务处实践教学管理办公室副主任黄志文及城环系实践办主任朱伟超一行3人赴广州南方测绘仪器有限公司东莞分公司实习基地挂牌。

广州南方测绘仪器有限公司1989年成立于广州，历经发展，已成为一家集研发、制造、销售和技术服务为一体的专业测绘仪器、地理信息软件产业集团，稳居中国测绘仪器及软件行业第一位。产品出口到全球100多个国家和地区，跻身世界行业4强。

双方通过交流进一步加深了了解，增强了互信，并在实习、教学等方面进行了深入探讨，并在如何组织东莞地区高校测绘论坛，开展高校测绘比赛，以及测量员培训等方面达成共识。南方测绘东莞分公司庄伟焱经理表示，今后可为校方短期免费提供相关专业实习仪器，赞助校方举行测量实练操作或比赛，以及到校为学生进行实际外业测量培训。
