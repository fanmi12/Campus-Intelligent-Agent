# 图书馆邀请评估专家指导迎评工作

6月24下午，我院特邀知名图书馆学专家、广东商学院图书馆馆长习万球研究馆员来我院做“高校图书馆评估工作”的专题讲座。

习馆长通过横向比较中美两国的高校评估工作，纵论我国高等教育评估的发展历程，进而高度概括了高等教育评估工作的重要性。习馆长以广东商学院的图书馆迎评工作为例进行了全面而深入的介绍，还特别指出了有关图书馆迎评工作的注意事项。

会后，城市学院图书信息中心主任陈伟表示，习馆长的精彩演说对我院图书馆的迎评工作具有指导意义，并鼓励全体工作人员积极投入到迎评工作中去。
