# 教务处采取实际行动落实教学工作会议精神

3月23日上午，程发良副院长召集教务处负责人开会，听取各负责人在第二届教学工作会议中收集到的意见和建议，并要求教务处对教学工作会议及时进行总结，针对会议中代表们反映的问题提出解决的对策，采取相应的措施。按照部署，李先庆处长助理撰写了第二届教学工作会议纪要。谭汪洋副处长撰写的《关于落实2009年教学工作会议精神的措施》的文稿，从构建内部教学质量保障体系、加强师资队伍建设工作、加强实践教学工作、完善院、系、教研室三级教学管理体制、做好09版专业人才培养方案的落实工作等5个方面提出了具体的措施。这两个文件将下发给相关单位并组织实施。

3月25日，教务处组织召开了教学工作例会，会议传达了广东省优质教学资源建设与应用研讨会的会议精神。邓成良处长就09版人才培养方案中发现的问题进行了通报。经过讨论，由各系部首先对本单位的人才培养方案进行修改，教务处再组织相关人员对全院的人才培养方案集中进行修改。
