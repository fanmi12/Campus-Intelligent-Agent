# 羽毛球国际裁判长雷铭基先生来我院培训羽毛球裁判员

11月15日，李永波羽毛球学校总经理、中国唯一的羽毛球国际级裁判长雷铭基先生亲临我校培训学生羽毛球裁判。

这次培训是为我院承担12月份即将在东莞市李永波国际羽毛球学校举行的全国羽毛球俱乐部甲级联赛和世界羽联比赛做准备。

据了解，李永波国际羽毛球学校是迄今为止全世界最好的羽毛球学校，学校的校长乃中国羽毛球届的鼻祖、中国国家队终身名誉教练汤仙虎先生，学校的技术指导也均是清一色的国字号教练。在10月份刚刚举行的亚洲青少年羽毛球锦标赛中，我们学院的志愿者出色的完成了比赛的服务工作。在这次培训中，我院学生对新知识渴望的热情也给雷铭基先生留下了深刻的印象。

雷铭基经理在与体育教学部主任邢红林教授的交谈中表示：愿与我院长期合作，为推动东莞市羽毛球运动的发展而共同努力。
