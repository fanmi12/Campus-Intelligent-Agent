# 学院举办第三次心理讲座

5月10日，学生处心理健康教育与咨询中心国家二级心理咨询师黄威老师，为09级、10级学生做了题为《非诚勿扰——大学生恋爱心理解析》的讲座。

黄威老师在《我心永恒》这首熟悉而动人的哀婉音乐中向在座的同学提出一个问题：问世间情为何物？同学们对此提出了自己的见解。黄老师顺着大家的思路用简单而生动的方式解释了“爱情”在心理学上的概念。黄老师展示两张关于大学生恋爱动机的调查表，总结出“大学生谈恋爱并非都是为了爱情”这一结论。他指出大学生恋爱中常见的心理问题，主要有自卑心理、羞怯心理、嫉妒心理、猜忌心理以及暗恋或单恋心理，并切合自身经验为这些心理问题开出“药方”。最后，黄老师以一个生动的例子为切入点，给在座的同学提出建议：恋爱一定要真心。

据悉，黄威老师研究生毕业华南师范大学，是国家二级心理咨询师。这次讲座旨在帮助学生认识大学生恋爱心理，帮助大学生解决在恋爱中可能产生的心理问题。
