# 广东省高校“平安校园”第七考评组莅院考评

12月1日，由广东省高校“平安校园”第七考评组王玉学组长一行4人来我院考评创建“平安校园”工作。党委书记王卫平、副书记章德胜、院长助理麦琦琳、相关部门负责人参加考核工作汇报会，向省考评组汇报我院“平安校园”创建工作。章德胜副书记主持会议。

会上，王卫平书记向考评组汇报了我院校园安全工作。考评组听完汇报后，查阅了我院创建平安校园队伍建设、措施落实等工作的相关资料，检查了我院的监控室、警务室、学生宿舍和化学品仓库。
