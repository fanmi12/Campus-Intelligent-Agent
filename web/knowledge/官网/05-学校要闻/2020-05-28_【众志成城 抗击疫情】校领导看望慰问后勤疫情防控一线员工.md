# 【众志成城 抗击疫情】校领导看望慰问后勤疫情防控一线员工

5月26日，王卫平校长在后勤保卫处副处长蔡小锋、刘维仝，组织部副部长卢淑芳的陪同下来到疫情防控一线，慰问后勤员工。

在学校大门、食堂及教学楼，王卫平校长与后勤一线工作人员进行了亲切交谈，代表学校为坚守在疫情防控一线的工作人员送上关怀，并对大家疫情期间的工作表现给予了高度赞赏。

王卫平校长提出，要将学校疫情防控作为常态化的工作，为学生返校复学及各项工作开展提供更加有力的后勤保障。
