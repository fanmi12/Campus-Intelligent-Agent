# 立德树人喜结硕果  体教结合助力考研

近日，我校智能制造学院学生、校乒乓球队队员张潘同学以优异成绩考取华南师范大学体育教育硕士研究生的消息传为佳话。

我院乒乓球运动队是体育教学部重点培养发展的优秀运动队之一。近年来，体育教学部不断强化课程思政，突出立德树人，把努力培养德、智、体、美、劳全面发展的新时代社会主义事业接班人和建设者为己任，在体育教学和运动训练等方面都呈现出良好的发展态势，张潘同学跨专业考研成功无疑是一次新的突破。

校乒乓球队在梁小龙老师的全身心投入之下，各队员认真学习，勤奋训练，在全市、全省乃至全国的比赛中屡获佳绩。

7月2日张潘同学返回学院，为体育教学部领导和老师送来致谢锦旗，感谢四年来体育教学部领导的悉心关照，教练员的精心栽培。

张潘是我院2016级学生，也是我院乒乓球队的主力球员。在校期间，该生一方面认真学习本专业课程，另一面在体育教学部乒乓球教练梁小龙老师的指导下练习乒乓球。四年来，该生在多项乒乓球比赛中屡创佳绩：2016年获得东莞市第四届大学生联赛的冠军。2017年广东省大学生锦标赛混双第四名。

2018年代表我院在第九届中国大学生阳光体育乒乓球赛获得第三名，获全国一等奖。

2019年在广东省大学生运动会获得混双亚军。

面对毕业后的发展，梁小龙教练鼓舞张潘继续深造。在教练员的帮助下，通过自身的不断努力，张潘深入学习乒乓球相关的体育专业知识，最终成功考上了华南师范大学。

一花独放不是春，百花齐放春满园。张潘同学的绽放只是开始，体育教学部将继续深入贯彻“体教结合”思想，精耕细作，培养更多优秀学生。
