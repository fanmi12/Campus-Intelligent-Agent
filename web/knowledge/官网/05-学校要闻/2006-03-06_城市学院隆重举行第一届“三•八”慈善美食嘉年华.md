# 城市学院隆重举行第一届“三•八”慈善美食嘉年华

3月5日，我院举办首届“三•八”慈善美食嘉年华活动，庆祝即将到来的“三•八”妇女节。学院领导、教职工、各系各班的学生、院学生会各部门以及各协会都参加了这次活动。

当天上午，从行政办公楼—饭堂—学生宿舍的校道两旁整齐有序地摆满了桌椅和太阳伞。下午2：30,学院党委副书记朱冰同志宣布，城市学院第一届“三•八”慈善美食嘉年华正式开始。

90个营销摊点，装扮得五光十色；各种美食琳琅满目，香气诱人；美食广告更是眼花缭乱，让人目不暇接；平时幽静的校道成了美食天堂。一天的绵绵阴雨并没有影响同学们对这次活动的热情。同学们制作的美食，有家乡的特色菜，有自制的糕点，甚至连平时只能从小摊上才能买得到的小吃，在这里也可以品尝到。记者采访了一个做棉花糖的同学，问他制作难不难。计算机与信息科学系的何钊威同学说：“以前看别人卷棉花糖很简单，其实要亲手做就不容易了。”

美食嘉年华还进行了文艺表演。大家熟悉的YMCA表演了火辣劲爆的现代舞，街舞、台拳道等节目的表演更是异彩纷呈；由各系派代表提供的工艺品、鲜花等的拍卖，活跃了现场气氛。在活动上同学们既饱口福又饱眼福。

最后，晚会还评选出了慈善美食嘉年华活动美食大奖、最佳组织奖、爱心大使奖，党委副书记朱冰、学生处长章德胜、团委书记丘永辉为获奖单位颁发了锦旗和纪念品。

据悉，美食节共收到善款9900多元，这些善款将交给爱心基金会。
