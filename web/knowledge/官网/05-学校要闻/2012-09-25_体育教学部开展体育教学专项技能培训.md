# 体育教学部开展体育教学专项技能培训

为配合学院教学质量工程建设，进一步加强体育教学部教师的教学技能，提高体育课教学质量，9月14日，体育教学部在艺高羽毛球馆对全体教师进行羽毛球教学理论与方法的培训。

此次培训由该部羽毛球专任教师组织备课和讲课，所有教师就羽毛球课的教学方法、手段进行了交流与探讨。据教学部主任邢红林教授透露，体育教学部将强化教学专项技能，以提高教育教学水平。
