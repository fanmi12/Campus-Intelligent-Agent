# 两门省级精品课程通过学院专家组验收鉴定

10月29日，学院组织两个专家组分别赴思想政治理论课教学部、城市与环境科学系，对“十一五”期间学院获得的省级教育质量工程项目开展项目结题验收。据悉，“十一五”期间，我院有3个教育质量工程项目获得省教育厅立项，其中两个省级精品课程《思想道德修养与法律基础》、《环境保护与可持续发展》已经建设完成。经过听取项目组汇报、查看课程网站、查阅纸质材料、专家质询与反馈等环节，专家组认为两个省级精品课程通过项目组创造性工作，已完成课程建设的计划、目标、任务，通过验收。

学院近期将验收情况在教务处主页上进行公开展示。思想政治理论课教学部、城市与环境科学系也正在根据专家的意见进行整改，迎接省教育厅专家组的验收。

据悉，本次专家组组长分别由东莞理工学院思政部主任李洪君教授和机械工程学院院长钟守炎教授担任。
