# 高香林、陈丁堂督查评建工作

本报讯（通讯员 蔡秀亮）自第二阶段评建工作开展以来，副院长高香林教授、院督学陈丁堂教授等院领导与教务处助理处长李先庆老师、评建办公室副主任王锦峰，深入系部检查评建工作。

在听取文传系主任邓星明教授关于文传系教学工作评估及数字媒体艺术学士学位授权专业评估工作的情况汇报后，高副院长要求；一是要理清思路，全系上下同心协力搞评估；二是要明确责任，分解任务，把工作落实到位；三是要实事求是，认真总结在自评过程中发现的不足与问题。

陈督学传达了省学位办公室关于学士学位授权专业评审的有关文件精神，并就数字媒体艺术学士学位授权专业简况表的撰写提出了修改意见。

院评建办认为，院领导对文传系的意见，对全院各单位的评建工作具有重要的指导作用。
