# 我院老师到大朗镇看望暑期实践学生

7月29日，管理系党总支副书记吴春庚老师、社科系程建新老师到大朗镇看望我院参加社会实践的学生。两位老师和大朗镇团委副书记刘家驱同志与部分学生进行了座谈，并在许多方面给与了指导。

据悉，今年的暑期社会实践活动比往年更贴近实际，更具特色，适逢今年是中国改革开放三十周年和奥运年，我院学生以“和谐社区·你我齐参与”为主题，开展了创业实践行动、感悟生命、趣味运动会、环保宣传、爱心修路、中小型企业法律环境信息调研等一系列活动。
