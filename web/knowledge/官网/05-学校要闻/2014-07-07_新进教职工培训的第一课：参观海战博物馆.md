# 新进教职工培训的第一课：参观海战博物馆

我院开展新进教职工培训工作。7月3日，人事处组织部分新进教职工参观海战博物馆、虎门威远炮台、东莞博物馆、可园等东莞历史文化景点，领略了东莞市区及镇街的经济社会发展成果。

人事处谢文君老师和新进教职工中的黄庆泉和叶伟东老师一样都是东莞本地人，一路上他们当起了讲解员，向外地的新进教职工介绍自己的成长历程、介绍东莞的社会经济情况、风土人情。外地的新进教职工也分享自己对家乡的认知，并与东莞做对比，互相沟通，描绘自己眼中的东莞。

一天的时间，大家对东莞有了进一步的了解。黄庆泉老师调侃自己说，虽然是土生土长的原居民，可惜从没来过可园，不知道东莞还有这么好的历史人文景观，他还说，自己还是很小的时候来过威远炮台，时隔多年，更能感受到历史的沧桑给东莞带来的沉淀，服务家乡任重而道远。外地的新进教职工也表示，通过今天的参观学习，能加快自己融入城院、融入东莞的过程，坚定自己扎根城院、服务东莞的信心。

今年的入职培训7月2日开始，院领导杨敏林、王卫平、张林、陈丁堂、章德胜、高香林、麦琦琳等出席了开班仪式。院长杨敏林还亲自新进教职工介绍了办学理念及办学特色。曾获学院讲课比赛一等奖的文学与传媒系陈跃老师和曾获广东省高校思想政治理论教学课青年教师教学基本功比赛获得一等奖的思政部王芳仪老师为新进教职工做了示范教学。

据人事处介绍，本次培训的29名教师中，有两位是教授，有五是留学回国研究生。接下来，他们还将参加7月13日在华南师范大学举办的为期半个月的2014年高等学校教师岗前培训班。
