# 文学与艺术系团员敬老院献爱心

3月25日，文学与艺术系30名团员，冒着蒙蒙细雨前往石龙镇敬老院看望老人，参观东莞市首家镇级慈善捐助超市。

在敬老院，团员们与老人和孤儿欢聚一堂，其乐融融。他们为老人和孤儿表演了文艺节目，赠送了食品和衣物，进行了面对面的交谈。接着，他们参观了石龙镇慈善捐助超市。石龙镇的有关领导为同学们介绍了超市的成立、发展和意义，以及所带来的社会效益。参观之后，同学们作为义工帮助慈善超市搬运货物。

本次活动得到了石龙镇民政部门的大力支持，以及石龙星湖酒店的赞助，石龙电视台作了新闻报道。
