# 我院录取第一批新生

7月5日，外省的艺术生提前批开始投档，两名来自新疆维吾尔自治区的考生成为我院录取的第一批学生，这也标志着我院新生录取工作正式拉开帷幕。

据悉，根据各省招生时间安排的不同，内蒙古、山东、江西、广西、新疆、四川等省市的考生均会在近段时间出档。而广东省艺术类的提前批招生录取工作将从7月27日开始，2B院校将于7月28日展开招生录取工作。

据悉，城市学院今年有42个本、专科专业对外招生，这些专业涵盖工、理、文、法、经、管、艺等学科门类。2010年全院招生计划总计2400人，其中本科1280人，专科1120人。学院将严格执行教育部、省、市招办“学校负责，招办监督”的录取政策，以考生的高考成绩为依据，坚持公平、公正、公开的原则，择优录取。
