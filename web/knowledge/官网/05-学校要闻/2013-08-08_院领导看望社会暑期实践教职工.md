# 院领导看望社会暑期实践教职工

7月30日，学院党委副书记章德胜分别赴东莞市普惠社会工作服务中心、广东莞信律师事务所和东莞市禾田品牌策划有限公司，代表学院看望慰问我院参加2013年社会暑期实践的教职工。

章德胜副书记详细了解了参加暑期实践教职工的实践活动情况，鼓励大家认真参与到实践单位的工作中，通过产学研相结合的方式，将在校外实践所见、所学，应用回日常的教学和工作上面，推动我院 “双师型”教师的发展和应用型人才的培养。

据悉，今年的社会暑期实践是我院首次以教职工个人自主申报、学院审核的形式进行。个人的自主申报，使教职工的实践更能贴近所在岗位的需要，更有效提高教职工个人实践积极性。
