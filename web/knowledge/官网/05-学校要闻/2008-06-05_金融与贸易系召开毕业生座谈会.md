# 金融与贸易系召开毕业生座谈会

6月3日，金融与贸易系在5303课室举行毕业生座谈会。系主任米双红教授、党总支书记龙卫洋博士、负责毕业生工作的相关老师及80余名毕业生代表参加了座谈会。

座谈会上，同学们结合自己在校期间的学习生活与老师们进行了亲切的交谈，并从教学、管理、学生今后发展方向等方面提出了中肯的意见与建议，毕业同学们的热烈发言，表达了他们对学院人才培养及发展建设的深切关心。

米主任和龙书记对同学们的意见作了解释和回答。他们希望同学们走上工作岗位后，要自强不息，继续学习，不断提高自身的综合素质，努力适应社会的发展，毕业后要“常回家看看”，继续关心和支持母校的发展，为母校增光添彩。
