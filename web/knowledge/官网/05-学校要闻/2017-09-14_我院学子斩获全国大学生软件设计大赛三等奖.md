# 我院学子斩获全国大学生软件设计大赛三等奖

近日，我院计信系软件工程专业学子在第六届“中国软件杯”大学生软件设计大赛决赛中脱颖而出，斩获本科组三等奖。

据了解，该项比赛是由工业和信息化部、教育部以及江苏省政府联合主办，面向全国高等院校在校生的一项全国性赛事。大赛参赛范围、影响力为全国同类赛事之最。大赛旨在引导大学生积极参与软件产业实践活动，赛题分为本科研究生组和高职组。据悉，今年全国共有4205支队伍报名参赛，覆盖600多家高校，约200支队伍进入了决赛。

我院计信系软件工程专业梁家星、王明浩、沈鑫三位同学的参赛作品《分布式爬虫系统》顺利进入决赛。在南京决赛中，在指导教师王浩亮老师的指导下，同学们经过认真准备，沉着应对，将本作品的技术特点、创新方案、应用前景等进行了生动展示和讲解，得到了评委的一致认可，取得本科组三等奖的优异成绩。
