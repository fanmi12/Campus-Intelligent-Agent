# 我院《思想道德修养与法律基础》教案获省教育厅三等奖

广东省教育厅主办的全省高等院校《基础》课优秀教学片和优秀教案评审结果揭晓。我院社科系思想道德政治理论课教研室参赛教案《思想道德修养与法律基础》获得三等奖。这是我院第一次获得省教育厅教案奖项，也是本次赛事获奖高校中唯一一所独立院校。
