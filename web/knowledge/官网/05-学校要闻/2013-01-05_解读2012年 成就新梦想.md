# 解读2012年  成就新梦想

2012年城市学院校园十大新闻评选揭晓了！

十大新闻是我们城院人智慧的结晶，凝聚了一万多名师生员工的辛勤汗水，也是硬实力、软实力、创新力的综合体现，值得分享，更值得珍藏！

每一条新闻的背后都有一个精彩完美的故事，也都预示着明天美好的发展前景！

城院梦城院人富于梦想，放飞希望，并不懈地追梦、圆梦，把梦想和希望变成现实。

办学之初，城院人的梦想是“三年打基础，五年扩规模，建设省内一流的独立学院”。第五年，梦想实现了，学生规模由500人发展到了一万人。

2009年，东莞理工学院与广东鸿发集团投资有限公司签约合作举办城市学院，由鸿发集团斥巨资异地选址建设新校区。2011年，梦想又实现了，新校区奇迹般地建成了：占地1200多亩，42万平方米建筑面积，规划在校生的规模为2万人。2011年9月入驻的大一新生超过4000人。

2011年，城市学院董事会提出了“办一流大学，创百年名校”新的办学目标和宏伟设想。第三个梦想的开局之年，实现了开门红，发展势头出奇的好。2012年的“十大新闻”，就是其中的一个缩影。

好新闻这几年，在校内媒体出现频率最多的词是：争创一流、唯一拥有······2012年，更是达到了高潮。

我院及17个专业，双双获得学士学位授予权。据了解，全省17所独立学院中，只有7所高校专业评审通过率达100%。这说明城市学院办学水平和教育教学质量的整体水平又上了一个新台阶，省专家评估组称之为广东省独立学院中的”黑马“。相继进行的思想政治课建设评估，也获得省专家组的高度赞赏，认为城市学院不比本科院校弱，是全省同类院校中的一个“标杆”。

2010年，时任东莞市委书记刘志庚赴省任副省长之前，莅临我院视察指导工作，接着新任市委书记徐建华履新不久也来到我院。这说明城市学院的建设发展、和谐稳定，在市委领导的心目中有着重要位置。

我院的研究课题双双获得国家自然科学基金立项和国家社会科学基金立项，这是东莞这座城市的骄傲，更是城院人的骄傲。

新生报到率达到94.7%，位列全省同类院校的前列。这在全部招收本科生的新情况下，能达到如此高的报到率实属不易。

思政部教师王芳仪老师在广东省思政课青年教师讲课比赛中力挫群雄，从200位选手中脱颖而出获一等奖，这也是思政部获此殊荣的第二位教师。

城市学院大学生男子篮球队在广东省第十二届大学生男子篮球联赛甲组比赛中，战胜中山大学等高校获得第三名，这个奖牌的含金量是可想而知的，不能不说也是全省独立学院的一种光荣。

一批本科生以全国考生中的第一、二名的成绩，考取中山大学、暨南大学等名校相关专业的硕士研究生。这样的成绩也是值得人们深思的。

办学主体平稳过渡，更显示出决策者和管理者有较强的行政能力、指挥能力、协调能力与执行能力。

正能量十大新闻是城院人以苦干实干精神和正能量干出来的。王芳仪老师就是其中的一个典范。为了备赛，她利用假期备课3个月，查阅了大量的资料，制作了精美的课件，反复进行试讲，因备赛劳累过度而不幸流产。

这些新闻事件，对一般高校而言，可能算不了什么，但对羽翼未丰的城院人来说确是了不起的事情。同时，这些新闻事件，为我院今后发展奠定了坚实的基础，同时也提出了更高的标准。我们深信，城院人一定会以正能量创造更多的新闻，延续昨天的故事，再创明天的辉煌。
