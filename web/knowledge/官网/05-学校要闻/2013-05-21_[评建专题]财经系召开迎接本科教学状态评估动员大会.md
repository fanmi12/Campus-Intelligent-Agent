# [评建专题]财经系召开迎接本科教学状态评估动员大会

5月20日，财经系在7B301召开迎接省专家组对我院本科教学状态实地评估动员大会，号召全系师生以新的精神风貌、更高的工作热情、更大的干劲做好迎评工作，形成人人关心、人人参与、人人有责的工作氛围，接受专家组的指导和评估，扎扎实实做好本科教学工作。

会上，财经系党总支副书记唐洁老师传达了学院对本次教学工作状态评估的部署和要求。她希望大家将思想和行动都统一到“评建”的攻坚战上，发扬“寸金”精神，从我做起，身体力行，知行合一，为评估赢得高分。
