# 学院召开考取研究生毕业生座谈会

今年我院学生考研取得喜人的成绩。6月26日，我院考取研究生的毕业生与考研辅导班的老师廉玉忠、赵书山、谭汪洋齐聚315会议室，分享考研喜悦，畅谈考研体会，寄语考研学生。

院领导朱志德、高香林，院办主任王玉、培训中心主任李丽娟老师出席会议，并向同学们颁发了奖金。

记者从会议上获悉，今年我院共有18名同学考取了研究生，考试成绩都很优秀，其中李苏杰、赵晋宜同学分别以笔试第一、二名的成绩考取暨南大学、中山大学相关专业的研究生。印刷专业有3名同学一同考取全国印刷类顶尖级学府北京印刷学院。

同学们在发言中深情地表示，感谢院领导、老师和同学们的关怀与支持。

“自信+毅力+智慧=成功”。谭汪洋老师用形象的公式总结概括了同学们考研的成功经验。

党委书记朱志德勉励同学们说，你们是城院的骄子，更是城院的名片，希望你们在新的起跑线上，发扬考研精神与作风，迎接未来人生中的各类“大考”和挑战，学真本事，再创佳绩。
