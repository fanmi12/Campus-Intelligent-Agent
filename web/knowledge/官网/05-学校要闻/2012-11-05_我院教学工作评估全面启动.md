# 我院教学工作评估全面启动

继学士学位授权评审之后，我院又迎来一场更大的硬仗，即省教育厅对独立学院教学工作的评估。10月25日，我院在学术报告厅召开迎接省厅对我院教学工作评估动员大会，全面部署评建工作。院长杨敏林教授在会上要求，我们要聚全院之心、集全院之智、举全院之力，全面推进评建工作，切实把我院教学工作提高到一个新的水平，促进学校发展。

学院领导杨敏林、朱志德、朱冰、张林、陈丁堂、章德胜、高香林、出席会议。

全院副科级以上干部，副高职称以上教职工，博士，各系部教研室主任参加了会议。

会上，副院长高香林教授、院督学陈丁堂教授分别宣读了院系教学工作自评工作方案，对学院评建工作做了系统的安排部署。

院长杨敏林教授就如何搞好评建工作在会议上着重强调：一、统一思想，振奋精神，高度重视教学工作评估；二、学好文件，找准差距，在内涵建设上下功夫；三、周密部署，真抓实干，认真落实各项评建任务。

杨院长在讲话中指出，全力以赴做好评建工作，是我院今明两年工作的头等大事。教学评估工作是促进我院提高教学质量的重要举措，是我院规范教学管理、提高教学水平、完善教学质量保障体系的最佳平台，是提升我院办学水平、逐步实现发展目标的良好机遇，是凝聚人心的有效形式。在评建工作中，我们要坚持“以评促建，以评促改，以评促管，评建结合，重在建设”的方针；要深刻理解评估方案“四个促进，三个基本，两个突出，一个引导”。即：“四个促进”是促进办学经费投入，促进办学条件改善， 促进教学管理规范，促进教学质量提高；“三个基本”是指办学条件基本达到国家标准，教学管理基本规范，教学质量基本得到保证；“两个突出”是突出服务区域（行业）经济和社会发展，突出培养应用型人才的办学定位；“一个引导”是引导参评学校构建并逐步完善内部质量保障体系，形成不断提高教学质量的长效机制。

杨院长表示，我院教学工作评估的各项准备工作现在已全面启动。评建工作既是对我院办学水平的一次鉴定，更是对各级领导干部、全体共产党员和广大师生员工精神风貌的一次全面检验。我们坚信，有上级部门的亲切关怀，有各单位（部门）的具体落实和团结协作，有全体师生员工的共同努力，我们一定能够圆满完成教学工作评估的各项任务，夺取教育厅独立学院教学工作评估的好成绩。

党委书记朱志德研究员主持会议。他最后强调，这次评估既是教学工作的评估，也是对办学工作的全面评估；评建工作不仅仅是阶段性的工作，更是常态化、经常性的工作；既关系到学院今后的发展，也关系到每个教职员工的切身利益。我们要齐心协力、分工合作，共同打好这一硬仗。

记者从会议上获悉，根据省教育厅《关于开展我省独立学院教学工作评估的通知》的要求和学校总体工作安排，我院在2013年6月底前必须完成教学工作自评，省教育厅将在学校自评工作基础上，视情况需要组织专家进校现场考评。本次评估我院共设立了一级指标7个，二级指标22个，观察点44个。在省厅评估之前，学院将组织校内外专家展开自评，包括学院对系部、系部对教师的评估。
