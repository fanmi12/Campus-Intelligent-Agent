# 我院举行迎新生暨军民联欢晚会

9月24日晚，“中信I卡之夜”城市学院迎新生暨军民联欢晚会在我院田径场隆重举行。中国科协中南集团董事长、城市学院顾问杨元惺先生，东莞理工学院党委副书记王江水同志，东莞理工学院党委委员、副院长、城市学院院长安少华教授，学院其他领导和沙角部队全体军训教官出席并观看了晚会的文艺表演。

本次晚会不仅有同学们表演的独唱、现代舞、健身操、相声、诗歌朗诵，还有军训教官的军体拳表演。东莞理工学院党委副书记王江水同志为大家表演的硬币魔术博得了阵阵掌声，将晚会推向高潮。

晚会在一首合唱《手牵手》中圆满结束，整台晚会持续约两小时。晚会结束后，出席晚会的领导上台与全体演员握手并合影留念。

本次晚会由中信银行东莞分行赞助，在晚会开始前，杨元惺顾问代表学院向来自革命老区的4名通江籍新生颁发免学费牌匾，我院党委副书记朱冰同志向中信银行东莞分行代表王志雄先生赠送了牌匾。
