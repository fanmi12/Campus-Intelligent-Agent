# 政法系召开2011届毕业生实习动员大会

为了切实做好实习生的实习指导工作，确保实习生在实习阶段取得成效，引导毕业生树立正确的就业观、择业观，2月24日，政法系在学术报告厅召开2011届毕业生实习动员大会。政法系主任刘杰教授、全系教师及2011届毕业生参加了会议。

会上，教学实践办主任王雄文副教授强调了实习纪律和安全问题，详细介绍了实习表格的填写要求。

刘杰主任对实习指导老师和同学们提出了殷切期望，希望实习生树立刻苦耐劳的精神，强化自律意识，正确处理好各种关系，为以后的就业创造有利条件。
