# 管理系党总支组织学习十八届五中全会精神

中国共产党第十八届中央委员会第五次全体会议已顺利闭幕，为学习贯彻会议内容与精神，我院管理系党总支于10月30日在5A325会议室组织学习第十八届五中全会精神。管理系党总支副书记卢淑芳主持了会议，系主任张佺举教授，全体教工党员和民主党派教师、无党派教师代表参加了会议。

卢淑芳副书记就五中全会内容与精神，并结合管理系实际情况，做出了深入、全面的讲解，要求认真执行并学习全会的决议和精神，紧跟党中央的步伐，深入贯彻党的精神与指示。她还强调，作为人民教师，更应该学习好、了解好，在以后的教学工作中，能越做越好，为学院、为管理系的发展贡献自己的力量！

会上，与会人员进行了深入讨论。下一步还将组织管理系学生党员、党建、团学干部等也将参与学习。
