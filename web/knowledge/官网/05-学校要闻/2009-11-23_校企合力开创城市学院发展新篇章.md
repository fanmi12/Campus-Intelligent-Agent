# 校企合力开创城市学院发展新篇章

周致纳代表我校向广东鸿发集团投资有限公司董事长麦彦桐赠送纪念品。

杨晓西代表我校向广东鸿发集团投资有限公司赠送纪念品。

广东鸿发集团投资有限公司向我校赠送纪念品。

11月12日，东莞理工学院城市学院第二届董事会举行系列活动。

新老董事欢聚一堂 共商城院发展大计

东莞理工学院城市学院第二届董事会与上届董事会、监事会成员欢聚一堂，叙友情，论形势，共商城市学院发展大计。

出席座谈会的领导嘉宾有：东莞理工学院城市学院第二届董事会名誉董事长：广东鸿发投资集团有限公司董事长麦彦桐、我校党委书记周致纳，东莞理工学院城市学院第二届董事会全体成员，前任董事会、监事会成员程发良、钟剑辉、邓耀林、何献青、刘文成等。

周致纳在座谈会上表示，感谢上届董事会、监事会全体成员的集体努力，为城市学院发展奠定了良好的基础。

艰苦奋斗 与时俱进 迈向全国一流独立学院

当晚，第二届董事会举行了庆祝活动。东莞理工学院城市学院第二届董事会名誉董事长：广东鸿发投资集团有限公司董事长麦彦桐、我校党委书记周致纳，东莞理工学院城市学院第二届董事会全体成员，我校领导黄碧莲、邹晓平、戴炳源，东莞理工学院中层干部、教学单位主要负责人和东莞理工学院城市学院中层干部、教学单位主要负责人参加了活动。

麦彦桐、周致纳、麦照容、杨晓西先后在活动中致辞，并互赠纪念品。

周致纳在致辞中介绍，东莞理工学院城市学院第二届董事会名誉董事长、广东鸿发投资集团有限公司董事长麦彦桐先生是一名有着56年党龄的老共产党员，在新中国的历次变革中，麦彦桐先生紧紧抓住历史变革的契机，积累基础，艰苦创业，尤其是在改革开放时期，创设了广东鸿发投资集团,奠定了东莞本土企业的领先地位。

周致纳指出，麦彦桐先生这一种艰苦奋斗、与时俱进的精神气质值得大家学习。

周致纳表示，东莞理工学院引进广东鸿发投资集团合作举办东莞理工学院城市学院，是根据国家教育部第26号令而制定的战略措施，也是城市学院在新的历史发展时期的优化选择，广东鸿发投资集团的雄厚财力和优秀的企业文化，必将有力地帮助东莞理工学院城市学院实现创办全国一流独立院校的战略目标。(原载东莞理工学院 11月17日 新闻网)
