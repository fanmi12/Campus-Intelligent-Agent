# 行走莞邑古村　领略东莞人文

5月8日，城市学院十周年校庆系列活动之《名师讲坛》暨大学生科学文化论坛第五十一讲：“岭南山水间散落的明珠——东莞古村落保护与发展纪实”专题讲座在我院7Ｂ201教室开讲。

本次活动由教务处、文学与传媒系、东莞民间文化青年学会联合举办，受到东莞日报、东莞时报、东莞电视台、大粤网、东莞阳光网、文化周末报等多家媒体的广泛关注，对我院培养应用型人才，致力于强化学生的本土文化知识的传承，让学生从更宏观更深广的视角了解家乡的历史文化表示认同。

中国古村落保护与发展专业委员会成员、“东莞文化发现之旅”组合李培军（巨野子木）和李翠薇（醉红颜）担任主讲。两位老师首先以图片的形式，展示了他们与城市学院东莞民间文化青年学会同学们的结缘之旅，并介绍了中国古村落的保护与现状。

讲座中，他们围绕“什么是古村落？”、“为什么要关注古村落？”和“东莞古村落的现状如何？”等五个话题展开了详细的讲解。以东莞“谢氏大宗祠”为例，讲述了东莞古村落悠久的历史和多年行走莞邑村落的趣闻趣事。东莞市住建局蔡育新科长多次“抢麦”补充发言，与在座师生分享了他多年建设村落的心得体会。

两位老师还现场回答了同学们提出的关于“古村落的转型与外来文化的关系”等问题，并与同学们进行了互动。

据悉，李培军和李翠薇老师经过多年田野式的行走、搜索与发现，积累东莞多个古村落的特殊历史文化，合著有《东莞印象》、《东莞城迹》等书籍，为莞邑古村落留下宝贵的人文记录。
