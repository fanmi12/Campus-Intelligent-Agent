# 我校大学生艺术团助力东莞“篮球之夜”

5月6日晚，2019东莞“篮球之夜”活动在东莞市文化馆举行，领导嘉宾、球队成员、文艺骨干以及球迷、市民等近3000人共同参加了这场盛会，庆祝2019年CBA和WCBA的总冠军同时花落东莞。

我校大学生艺术团40多名同学在团委书记李瑶带领下应晚会邀请献上了精彩的舞蹈表演为“篮球之夜”助兴，庆祝东莞球队在CBA和WCBA夺得双冠，受到了现场球迷的热捧。
