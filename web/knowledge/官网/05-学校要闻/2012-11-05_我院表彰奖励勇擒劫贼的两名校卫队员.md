# 我院表彰奖励勇擒劫贼的两名校卫队员

10月18日，城市学院办公室发文做出决定，对勇擒劫贼的校卫队员季汉斌、胡远见给予表彰奖励，每人奖励现金1000元。

据悉，今年9月24日，我院两名校卫队员季汉斌、胡远见在校园巡逻执勤时，抓获一名盗窃我院教学设备的犯罪嫌疑人。经询问，该嫌疑人曾多次在其他学校行窃。

文件指出，季汉斌、胡远见同志积极履行岗位职责，有效地保护了学院财产安全，表现出强烈的责任感和勇敢无畏的作风，为创建“平安和谐校园”作出了贡献。
