# 【服务东莞·创新发展】思政部开展“服务东莞、创新发展”主题学习讨论活动

7月5日，思政部在2201课室开展“服务东莞、创新发展”主题学习讨论活动。党委书记朱志德研究员，思政部主任何鹏举教授及全体教师参加了学习活动。

与会人员认真学习了相关文件，尤其认真研读了成洪波书记在“服务东莞、创新发展”学习讨论活动动员大会上的讲话，座谈讨论了“服务东莞、创新发展”的现实意义与内容，并按照学院要求进行了工作部署。

朱志德书记在讲话中强调，“服务东莞，创新发展”的核心是做好本职工作，高质量地完成教育教学任务，为东莞经济社会发展培养高素质人才。他希望各位老师通过学习活动，认清形势，深切领会成洪波书记提出的“提高教学质量、善待师生、理顺治校结构、主动服务东莞”的精神实质，统一认识，贯彻落实，为东莞、为城院的发展贡献力量。
