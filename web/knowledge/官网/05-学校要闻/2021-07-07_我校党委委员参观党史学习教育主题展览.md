# 我校党委委员参观党史学习教育主题展览

7月7日上午，我校党委委员到图书馆二楼展示区参观“学党史感悟思想伟力，开新局凝聚城院力量 ”党史学习教育主题展，进一步推进我校党史学习教育走深走实。党委书记章德胜现场当起讲解员，向校党委委员们进行介绍。

党史学习教育开展以来，学校党委和二级党组织精心组织、扎实推进，在师生中掀起学习热潮。据了解，截止到7月初，学校党委开展第一议题学习12次，扩大学习会4次，学习专题19项，思政第一课7次，专题发言9次，革命传统学习4次，有力引领和推进了我校党史学习教育。全校25个党支部开展专题学习178次，专题宣讲培训256次，革命传统教育50次，主题党日活动75次。广大干部和师生员工在学习教育中，切实做到学史明理、学史增信、学史崇德、学史力行。

学校各基层党组织对标对表，根据学院和专业特色，推陈出新，创新学习教育方式方法，开展了红色电影展映周，红色影视配音大赛，“讲好入党故事，传承红色基因”活动分享会，红色革命家书育读比赛，书画创作大赛，大型校园经典育读晚会，“书记读书日”以及“唱响主旋律，歌声献给党”快闪活动，向党说说心里话和升国旗仪式。其中国旗护卫队在广东省学校国旗护卫队交流展示活动中，荣获一等奖。在广东省第十四届大中院校“百歌颂中华”歌咏比赛中，我校取得合唱组二等奖，歌手组三等奖的好成绩。我校精心组织的参赛队伍，在全国民办高校党史学习教育知识竞赛中荣获一等奖。

学校多措并举，把“我为群众办实事”作为党史学习教育的重要内容和突出抓手。通过走访、座谈会等多种形式，深入师生群众，着力解决师生员工“急难愁盼”问题，完成校园卫生环境改造、智慧食堂建设、物业管理水平提升及基建改造工程，对全校供水系统进行改造，开展心理教育健康与咨询，组建“红色志愿服务队”，在新冠疫苗接种，核酸检测等方面服务师生、服务地方，累计举行了57场次志愿活动，学校为教职工购置意外险、重疾险和企业年金，购买教工子女社保，解决教职工子弟入读问题。

在展览厅，还开辟了“党员学习角”，给师生党员们提供党史学习教育相关的书籍书刊，党史学习教育简报等。“向党说说心里话”的墙板上，张贴着师生党员对党的祝福，对未来在党的指引下，做好为党育人、为国育才的话语。

随后，学校党委一行到3B教学楼，参观了计算机与信息学院党总支党史学习教育主题展。计算机学院通过“党史学习教育文化回廊”，展示了历届党代会等党史主题，百年党史精彩瞬间，党总支党史学习教育开展和教育成果等。

各二级学院党总支也将组织本单位党员前往主题展参观学习。本次展览由党政办牵头，党委宣传部、组织（统战）部、后勤保卫处、教务处、学生处、计算机与信息学院、马克思主义学院等多部门、跨单位联合协作，精心策划推出。
