# 我院举行2017-2018学年心理工作总结暨表彰大会

6月21日下午，我院2017-2018学年心理工作总结暨表彰大会在学术报告厅举行。

会议通过视频短片重温了过去一年学院心理工作的亮点和荣誉。心理健康教育与咨询中心余琼主任用“暖心、乐心、慧心”对本学年的心理工作进行了总结。

大会对一年来表现突出的先进集体和先进个人进行表彰，包括第六届原创心理漫画大赛获奖选手及优秀组织单位，5?25心理健康节精品培育项目获奖组织单位及优秀指导老师，48名优秀心理干部，优秀校外心理咨询师、优秀二级心理辅导站及二级心理辅导站优秀指导老师，以及荣获心理工作省级荣誉的师生。

大会中优秀二级心理辅导站代表分享了一年来的工作经验和心得体会。

学生处副处长罗文芳肯定了学院心理工作中取得的突破和成绩，提出要加强家庭、学校及社会的联动及合作，打造城院“阳光学工队伍”，确保校园的安全和稳定，让每一位城院学子平安、健康、阳光、自信地度过每一天。
