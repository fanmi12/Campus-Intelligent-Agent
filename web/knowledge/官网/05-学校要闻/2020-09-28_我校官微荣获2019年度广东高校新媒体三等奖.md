# 我校官微荣获2019年度广东高校新媒体三等奖

据广东高校新媒体联盟《关于奖励广东高校新媒体影响力前三十名高校的通知》文件显示，我校官方微信公众号荣获2019年广东本科高校官微三等奖。

近年来，网络新媒体平台已然成为十分重要的传播手段，我校党委也高度重视新媒体宣传工作，推进校内各级各类媒体平台融合发展，建立适应融合发展的体制机制，实现在内容、渠道、平台、建设、管理等方面深度融合，树立一体化理念，形成一体化的组织结构、一体化的采编流程、一体化的传播体系、一体化的管理体制，努力构建大宣传格局。一方面，大力落实学生在新媒体时代下的多方面能力培养，在官微等新媒体平台方面注重管理运营，完善自身的制作审核流程，力求向外界提供更加多元、丰富的内容；另一方面立足校园，面向师生，不断强化新媒体建设，坚持内容与手段的创新，用心书写我们城院的故事。

百尺竿头更进一步。今后，学校也将继续加强在网络与新媒体方面的相关建设，紧紧抓住媒体融合发展带来的机遇，不断提升自身媒介素养，适应全媒体时代对宣传工作带来的深刻变革，秉持着“改”的精神、“闯”的劲头、“干”的行动，挖掘好校园内发生的鲜活素材，讲好校园师生故事，向各界展示更加真实、立体、全面的新时代学校风貌。
