# 我院召开学习胡锦涛总书记“七•一”讲话座谈会

7月6日，学院领导、系部中层干部、思政部教师代表聚会315会议室，热议胡锦涛总书记“七?一”重要讲话。

与会人员通过座谈讨论一致认为，胡锦涛总书记的重要讲话，高度总结了我们党90年来领导中国人民夺取革命斗争、国家建设和改革开放事业伟大胜利的基本经验，是指引党和国家今后一段时间建设中国特色社会主义事业、推动国家科学发展的重要文献，振奋人心，令人警醒。

党委书记朱志德要求：“我们一定要认真学习领会，把讲话精神真正贯彻到学校工作、服务青年大学生的学习生活中去。”

院长安少华表示，总书记在讲话中，不仅阐述我党“三件大事”及成功经验、历史使命，更重点强调了青年干部和青年人才的建设，这是党对青年人的关怀，也是对青年工作者、教育工作者提出了新的期望。我们必须用科学道理、正确思想来教育青年，对青年进行爱国主义和共产主义理想的教育，使他们以振兴国家作为自己的责任，用自然科学和社会科学的知识武装头脑，更好地为党和国家的事业贡献力量。

安院长指出，当代大学生是青年中的重要群体，思想活跃，需求多元。学生的稳定就是最大的稳定。我们要从学校和学生实际出发，积极探索学生管理工作的新模式，充实和加强学生工作者队伍，改善后勤保障服务工作，满足他们各方面的需求。当前要重点做好三个方面的工作：一是招生工作，尽力满足考生求学深造的愿望；二是新教师岗前培训工作，提高他们教书育人的能力；三是选聘专职班主任，充实学生工作者队伍。

会议由党委委员、办公室主任王玉主持。党委委员、人事处处长夏勇做了工作布置。
