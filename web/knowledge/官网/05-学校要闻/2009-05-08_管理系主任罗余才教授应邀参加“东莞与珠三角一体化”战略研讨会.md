# 管理系主任罗余才教授应邀参加“东莞与珠三角一体化”战略研讨会

4月28日，由市社科联、市委党校联合主办的“东莞与珠三角一体化”战略研讨会在市委党校新校区举行，管理系主任罗余才教授应邀参加了会议并作大会发言。

来自市社科联、市委党校、东莞理工学院、城市学院的专家学者以及市直机关有关负责人共30余人参加了会议。与会人员就东莞在珠三角一体化中的地位和作用、东莞城市新的定位、如何实现东莞与珠三角地区的城市在产业、环保、交通、治安等方面对接等问题进行热烈的研讨。

罗余才教授就“加快东莞物流发展规划、促进东莞物流业发展”做了主题发言，他认为东莞的现代物流业应与香港、深圳的物流业错位发展，以虎门港的建设为龙头，发展内外水路运输，向综合型干线港发展；要借鉴发达国家产业簇群的运作机制和经验，依托产业发展的聚集优势, 以产业链为纽带，扩大物流业的发展规模，打造珠三角物流业的簇群。罗教授的一席发言得到了与会专家的赞同。

据悉，我院物流专业已开设6年，是我院的重点发展专业和服务东莞的特色专业。在《珠江三角洲地区改革与发展规划纲要》确定将东莞定位为珠江三角洲新兴物流城市后，我院物流专业受到社会各界的广泛关注。3月20日，我院与虎门港签订产学研合作协议，共同培养物流业人才。4月18日，《东莞日报》整版刊登了我院罗余才、王兴、洪树权、张洪等老师的文章，全面分析了东莞发展物流业的优劣势，并提出了解决应对的措施。另外，《东莞日报》也特别开设了“佺举看物流”专栏，邀请我院张佺举教授为该专栏的撰稿人。一系列的行动和措施，充分体现东莞物流业发展前景广阔，我院的物流专业必将为东莞建设新兴物流城市作出突出贡献。
