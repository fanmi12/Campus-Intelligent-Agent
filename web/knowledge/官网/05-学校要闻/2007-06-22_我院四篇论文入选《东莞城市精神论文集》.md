# 我院四篇论文入选《东莞城市精神论文集》

最近，由中共东莞市委宣传部、东莞市社会科学联合会共同编辑发行的《东莞城市精神论文集》一书中，采用了城市学院社会科学系老师的四篇论文。

入选的论文及作者是：石志民副教授的《市民素质与城市精神》、黎诚老师的《关于“城市精神”的几点思考》、刘飞凤老师的《城市精神内涵析要》、陈海华老师的《东莞城市精神的内涵》。
