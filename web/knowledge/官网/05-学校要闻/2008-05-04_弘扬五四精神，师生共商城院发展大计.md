# 弘扬五四精神，师生共商城院发展大计

4月29日，学院在四号楼315会议室召开了题为“弘扬五四精神，师生共商城院发展大计”学生座谈会。

院长安少华教授，副院长程发良教授，学生处处长章德胜副教授，学院团委书记丘永辉老师出席和参加了会议。参加会议的学生代表均为院系的学生干部。会议由党委副书记朱冰同志主持。

座谈会气氛和谐热烈，学生代表们针对学院的学风、后勤、宣传和保卫等方面提出了富有建设性的意见。

安院长在会上肯定了学生干部的工作成绩，通报了学院的近期工作情况和发展动向，鼓励同学们要继承和发扬“爱国、进步、民主、科学”的五四精神。他最后强调，青年大学生应该要有强烈的历史使命感，担当起历史的重任，刻苦学习，奋发图强，做城市学院的建设者，做祖国的接班人。
