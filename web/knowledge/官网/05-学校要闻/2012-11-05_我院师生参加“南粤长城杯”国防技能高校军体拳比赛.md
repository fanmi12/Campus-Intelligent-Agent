# 我院师生参加“南粤长城杯”国防技能高校军体拳比赛

10月27日，在我院保卫办刘维仝主任、学生处凌继峰老师的带领下，我院20名2012级新生代表在广州大学城参加2012年广东省“南粤长城杯”国防技能（普通高校军体拳）比赛。

本次比赛由省委宣传部、教育厅、省军区、省国防教育办公室共同主办，中国人民解放军特种作战指挥学院、华南理工大学承办。据悉，我院是东莞地区唯一一支高校参赛队伍。比赛中，我院12级电子信息工程2班王金鑫等20名同学，以军人的气质、饱满的精神出场，为本次比赛交上了一份圆满的答卷，并荣获三等奖。
