# 70名青年教职工暑期开展社会实践活动

为使青年教职工更好的认识东莞、了解东莞、服务东莞，我院将在暑假期间组织70名青年教职工进行为期两周的暑期社会实践与服务活动。这次活动的目的，主要是让青年教师亲身感受东莞经济社会高速发展的脉搏，在社会实践中锻炼、完善自己。

这次参加社会实践的都是35岁以下、毕业后参加工作时间不长的教学、教辅和院机关中的青年教工，其中大部分是硕士、博士。实践时间为两个星期。学院要求，教工选择的实践单位，要与所学专业相应对口，以顶岗或伴岗的方式进行实践锻炼。每个教师要写实践日记，结束后要提交实践总结报告。据悉，这些教工均已落实实践单位。

机电系的宋雪晶博士毕业于北京理工大学，她的顶岗实习单位是东城区日菱电梯厂。宋博士说：“这样的顶岗实践活动形式非常好，对青年教师很有必要。因为我是毕业后直接到高校参加工作的老师，实践操作能力有待进一步加强。这样的顶岗实践活动能使我边实践、边学习，将理论运用于实践，对以后的教学有好处。”
