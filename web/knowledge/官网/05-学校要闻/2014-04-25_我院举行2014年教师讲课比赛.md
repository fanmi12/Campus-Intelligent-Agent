# 我院举行2014年教师讲课比赛

为提高教师的教育教学水平，提高教师课堂教学质量，我院于4月24日举行了2014年青年教师讲课比赛。

据悉，本次比赛共有19位教师参赛，按抽签顺序轮流讲课，每人讲授时间为20分钟，评审专家按仪态仪表、普通话、板书或PPT、教学目标、内容、方法、重难点内容等项目评分。当场公布比赛成绩。

在比赛中，老师们同台竞技，各显其能，把自己的教学特色展示得淋漓尽致，或幽默风趣，或严谨细密，或师生互动。其中，有的借助生动的PPT或视频动画，有的恰到好处地运用语言、富有感染力的表情动作及生动有趣的讲解，有的利用数据图、课外延伸阅读丰富讲课内容。文学与传媒系宋秋敏博士用诗意般的语言，引经据典，讲授了《定风波》一词。她深情地解读了痴情女子的一片痴心和思夫之情，点评了柳永词之“俗”以及其中的宋词雅俗文化，引得现场好评。

一番激烈角逐之后，文传系宋秋敏老师、计信系王宽福老师获得比赛一等奖。
