# 省委党校吕艳红博士来校做学习习近平总书记讲话精神辅导报告

4月24日，广东省委党校“金牌授课教师”吕艳红博士应邀做客“城市学院大讲堂”第四十九讲，为我院师生做学习习近平总书记系列讲话精神的辅导报告。

吕艳红博士围绕党的执政主题、执政目标、执政主线、执政思路、执政方略、执政支点、执政理念这七大关键词，就“文化崛起的重要性”、“复杂的中美关系”、“中国梦”、“反腐”、“公关利益与社会公平”六个问题，从理论到实际，畅谈了自己学习习近平总书记系列讲话精神的收获与体会。

吕博士说，每一届新的领导都有不同的谋略和新的举措，这些举措、政策都是从研判国际国内形势后所推出的，执政的目标和基点是为了“社会公平正义”、“人民幸福”。

讲座中，她重点谈到十八以来一直备受关注的中国梦和反腐的信心问题。她的许多新观点，得到我院师生的赞同。例如：实现中国梦，文化的崛起很重要；中国梦可分解为经济梦、家庭梦、精神梦和业外梦；民族好，国家好，大家才会好。她引用《西游记》中的例子指出，中国反腐“长久不衰”的原因是受人情文化的影响，党和政府现行的一些政策措施让百姓树立了反腐的决心、信心和勇气。

对于社会公平与公共利益的问题，吕博士认为，要把握改革和发展的关系，创新动力机制和平衡机制，力图使社会更加公平正义。

党委书记王卫平做了讲座的总结，并对与会人员提出了希望。他希望各单位、各部门全体教职工要用习近平总书记的重要讲话精神指导我院的群众路线教育实践活动，加强“教风、学风、管理与服务工作作风”的建设。
