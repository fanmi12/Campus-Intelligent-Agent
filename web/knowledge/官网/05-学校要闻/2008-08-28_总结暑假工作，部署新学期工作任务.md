# 总结暑假工作，部署新学期工作任务

为了做好开学迎新准备工作，开创新学期工作新局面，学院于8月27日召开了各系（部、处、办）党政主要负责人会议，总结暑假工作，部署新学期的工作任务。

会上，程发良副院长、朱冰副书记、张林副院长分别通报分管战线暑假期间完成的工作任务和新学期的重大工作安排；院办王玉主任汇报了即将召开的全院中层干部会议的筹备方案；朱志德书记就有关系部的组织机构调整、宣传工作、开学迎新工作和省精品课程申报等工作做了讲话。

会议认为，暑假期间，我院进行大规模的基础设施的建设与改造，取得了可喜的成绩。如科技图书信息中心大楼破土动工，2、3、5、6号教学楼进行高档次的装修美化和设备更新，重新布设了全校的电线和网线，维修改造学生宿舍和饭堂等，我院的办学硬件建设又登上了一个新台阶。今年招生工作超额完成任务，为解决扩招后新生的食宿问题，学院想尽办法做了大量的准备工作。很多部门和教职工放弃暑假休息，积极工作，为学院的发展做出了贡献。

院长安少华教授在会上做了总结讲话。他说，今年暑假，我们是苦在其中，也乐在其中。现在奥运会结束了，暑假也过完了，各级领导要集中思想，集中精力，全力做好开学迎新准备工作。在新学期里，我们务必在稳定、发展、创新上下功夫、用气力、出绩效，为全院师生创建良好的学习生活环境。为此，开学之前一定要做到教师到位，教材到位，保证开学后教学秩序不乱，生活秩序不乱。各系部和院机关有关部门在迎新活动中，要结合各自的特点，做好宣传、接待等方面的策划工作，着力营造良好的文化氛围。各系部要关心教职工的切身利益，及时解决新进教职工的实际困难。加大人才引进工作力度。
