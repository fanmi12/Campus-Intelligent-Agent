# 团市委评估小组检查评估我院共青团工作

12月19日，由团市委组织、团市委副书记何俊聪及东莞四大高校团委书记参加的评估小组，莅临我院检查评估共青团工作，受到党委副书记章德胜、团委书记罗文芳的热情接待。

团市委评估小组参观了团委及学生会办公室、学生工作阳光大厅，了解了学生的办公经费及活动开展情况，听取了团委书记罗文芳对我院共青团工作和所取得的成绩进行的汇报。评估小组对我院共青团的工作表示了充分的肯定，并希望我院在今后的工作中，认真总结经验，带领和团结广大学生及青年团员为建设和谐社会、幸福小康献计出力。
