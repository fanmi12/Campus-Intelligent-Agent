# 张超同学成东莞高校捐献造血干细胞第一人

今日上午，我院计信系2014级计算机科学与技术专业一班张超同学在广州军分区广州总医院完成造血干细胞捐献，顺利平安返校，成为东莞高校在校学生捐赠造血干细胞第一人。王卫平院长、章德胜副书记亲切会见了张超同学，院团委书记李瑶、计信系党总支副书记宋艳参加了会见。

从大一开始，张超同学就参与献血活动，并成为干血细胞捐献自愿者。本月初，张超同学与一患者配对成功，于17日-22日赴广州军分区广州总医院进行造血干细胞捐赠。在打了4天的动员针剂后，昨日经过长达6小时的采集，共捐285毫升造血干细胞的悬浮液。

章德胜副书记对张超同学无私奉献的大爱精神和勇气给予了高度的赞扬，表示这不仅是张超同学个人的光荣，也为学院赢得了荣誉。

王卫平院长对张超同学勇于捐献造血干细胞、为学院增添荣誉，表示感谢！他还亲切地询问了张超同学的身体状况，并安排计信系照顾好张超同学的学习生活，调养好身体以便顺利完成毕业论文答辩等学业。

张超同学对学院和领导关心表示感谢。他表示，捐献非常顺利，全过程并未出现不适。对自己的大爱行为，他认为像平常献血一样，并没有特别之处，今后还将继续为社会爱心。

据了解，在我国造血干细胞捐赠记录上，张超同学为东莞高校第一人，东莞市第40例，广东省第605例，全国第7331例。
