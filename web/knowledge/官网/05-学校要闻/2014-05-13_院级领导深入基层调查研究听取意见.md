# 院级领导深入基层调查研究听取意见

自2月26日党的群众路线教育实践活动启动以来，我院院级领导根据分工，分赴系部调查研究，采取多种形式听取党员干部及教职员工的意见，为第二环节的“查摆问题、开展批评”奠定基础，促进教育实践活动向纵深发展。据悉，在近一个月的时间里，共收集整理了100多条意见。

根据上级的统一安排部署，我院于2月26日正式启动党的群众路线教育实践活动。在搞好第一环节学习教育的同时，学院领导按照分工联系的基层单位，采取“面对面”与“背靠背”相结合、“个别听”与“集体谈”相结合、“走进群众听”与“组织群众评”相结合的方法，广泛听取党员、干部及教职工的意见与建议。

在听取意见的过程中，党员、干部及教职工联系学院的工作实际，回顾学院10年来的发展历程，认真总结分析办学经验与问题，寻找解决的办法与对策。据悉，全院95%以上的教职工参加了院领导召开的各种类型的座谈会。学院领导认真记录大家的意见，学院教育实践活动 领导小组办公室分门类别地进行整理。据了解，这些意见归类为11个方面共118条。

最近，党委认真分析研究了这些意见和建议，要求各级领导干部要以虚心、诚心和严肃认真的态度对待群众提出的意见。凡是不利于学院发展的问题、“四风”问题和关系群众切身利益的问题，应以积极的态度立学立改。对群众反映突出的问题，要抓紧研究，争取早见成效。对牵涉面广、重大复杂的问题不拖不等，上下协力，联动整改，让群众看活动的效果。

党委书记王卫平（中）在体育部调研
