# 学院召开会议布置暑期工作

7月7日，学院在4315会议召开了暑期工作安排会议，院领导、各系（部）、机关、后勤部门以及新校区管委会各部门负责人参加了会议。

会上，副院长、新校区管委会主任杨敏林就新校区暑期各项工作任务安排情况进行了通报。与会各部门负责人逐一就与本部门相关的新校区暑期工作任务进行了确认并通报了有关工作的进展情况。同时，对于抽调有关人员下学期到新校区工作，各部门负责人分别针对自身实际人员情况，提出了人员安排方案及人员补充请求。

安少华院长表示，今年学院面临着迎接学士学位授权评估和新校区建设、新生入驻新校区等多项重要工作，工作任务多，时间紧，压力大。全院各部门要充分利用暑假的时间，科学合理安排好人员调配，认真做好评建、新校区建设、招生等各项工作，要提早筹备制定好迎新、军训、新学期开学等工作方案。

安院长指出，要做好各项工作，关键要抓好人员、经费、责任“三个”落实。他强调，抽调到新校区工作的人员，尽量通过内部调配进行解决；解决不了的，各部门要将行政、教辅人员缺口数及补充计划报人事部门汇总，由人事部门制定招聘条件及招聘办法报学院及管委会研究审定；财务部门要提前做好暑期加班人员的经费落实工作；全院各部门要将各项工作任务落实到人，明确责任及分工，全面细致完成好暑期各项工作任务。

会议由副院长张林主持。
