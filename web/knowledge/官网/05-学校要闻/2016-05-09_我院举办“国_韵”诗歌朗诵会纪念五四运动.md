# 我院举办“国?韵”诗歌朗诵会纪念五四运动

5月5日晚，一场文学经典、国学古韵在我院学术报告厅“穿越时空”而来——由共青团东莞理工学院城市学院委员会主办、文学与传媒系承办的我院“国韵”诗歌朗诵会，给广大师生带来一场别开生面的文化盛宴。

晚会舞台两边的巨型书卷、屏幕的上方摇摆着璀璨的灯光、舞台周围缭绕的“祥云”、按照诗文意境而变换的背景影像，“制造”出震撼的“穿越”视觉。

一开场，悠扬的笛、箫、古琴的旋律飘扬就在舞台的上空，意境唯美。在谢友祥教授等老师的带领下，同学们身着古服，手执竹简，席地吟诵《论语》篇章，展现了中华文化的源远流长、博大精深。由师生同台演绎的《子曰》、《关雎》、《蒹葭》、《桃夭》等14部经典诗文，为在座500多名观众呈现了“国韵”的传奇魅力……

谢友祥教授扮演孔子的形象，其精妙言语、渊博和厚积薄发的大家风范潜移默化地传达着古代伟大教育家、思想家的声音，感染了在座的每一位观众。谢友祥教授以一句“孺子可教也”，让台上台下融为一体。

李瑶和苗琳老师为大家带来的《蒹葭》朗诵，时而高唱，时而低吟，二人宛如水墨画中走出来的窈窕淑女，身姿摇曳，若即若离，以情入诗，以意动人；

陈跃和吴士田老师朗诵的《桃花源记》声情并茂、娓娓动听，为舞台更添绚丽的一笔。

如此众多的国学作品舞台上进行一一展现，师生的“传统”表演形式，古代诗歌和现代诗歌的相互结合，让观众们在感情基调和声调上体验诗歌与国学的不同韵味。

据了解，为了本次“国韵”诗歌朗诵会，参演老师和同学们齐心协力从选题、选服装、训练和彩排，先后花费了2个月的时间来筹备。赛后，贾静波老师表示，老师和同学们能从内到外把握“型”和“韵”是很不容易的，整场朗诵会的效果非常好，“型”“韵”齐全，水平很高。

我院党委副书记章德胜等领导和各系师生代表观看了本次诗歌朗诵会。
