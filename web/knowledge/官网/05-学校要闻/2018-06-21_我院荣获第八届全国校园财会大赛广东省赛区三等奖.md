# 我院荣获第八届全国校园财会大赛广东省赛区三等奖

6月14日,第八届中华会计网校杯全国校园财会大赛广东省复赛在于在广东金融学院举行，来自省内16所高校财会学子参加了比赛。我院由冯晓玲、黄金凤、邓琼波同学组成的代表队荣获广东省赛区三等奖，指导老师鞠成晓、宋慧敏组被评为本次竞赛优秀指导老师。
