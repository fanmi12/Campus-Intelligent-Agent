# 《方亮说事》节目主持人方亮再来城院授课

5月4日，东莞电视台著名栏目《方亮说事》主持人方亮来我院，为大学生记者团、广播站、《城市绿洲》报的同学们做业务讲座。

方亮从三个方面介绍了自己的编辑、主持人工作的体会与经验。他介绍说，编辑是节目的灵魂，编辑要善于与记者沟通交流，了解和掌握播音主持人的风格。记者的稿件要具有适用性、趣味性、时代性。一个好的节目主持人要了解编辑思想，多动笔多听音乐。

在互动环节，同学们踊跃发言，纷纷就自己感兴趣的问题请教了方亮。
