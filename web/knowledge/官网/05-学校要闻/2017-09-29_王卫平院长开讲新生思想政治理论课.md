# 王卫平院长开讲新生思想政治理论课

9月27日下午，院长、书记王卫平教授在教学楼7A610为2017级汉语言文学专业新生上了一堂生动的思想政治理论课——当代大学生如何培育和践行社会主义核心价值观。

王院长分析当代大学生有“怕吃苦、认识能力有限，但精力旺盛”等特点，介绍了大学的教育方式、生活方式与高中时期相比所发生的“质”变化，强调同学们从迈入大学开始就要积极培育和践行社会主义核心价值观。

讲课中，王院长介绍了毛泽东思想的精髓和主要特点，强调毛泽东思想是中国共产党集体智慧的结晶。他分析了“常态”和“新常态”的区别，引导同学们在新常态下发扬党的优良传统，更好地理解社会主义核心价值观的内涵。

通过对延安精神、“三严三实”专题教育和社会主义核心价值观内涵等的生动讲解，王院长倡导同学们在新常态下，从具体的学习生活中做起，从一点一滴做起，从日常的活动中，树立远大目标和崇高的理想努力培养和践行社会主义核心价值观。
