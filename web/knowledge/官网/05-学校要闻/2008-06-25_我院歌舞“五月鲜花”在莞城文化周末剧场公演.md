# 我院歌舞“五月鲜花”在莞城文化周末剧场公演

6月21日，一场由我院文学与艺术系师生共同演出，大型歌舞节目“五月鲜花”，首次登陆东莞文化周末剧场，面向社会公开演出。演员们倾情表演独唱、钢琴独奏、舞蹈、小品、时装表演、诗歌朗诵等节目。

居民张女士对记者说，这次的演出票价还比较贵，前座100元，后座50元，但是节目精彩，花几十元看大学生演出值得。

据悉，演出现场座无虚席。
