# 我院召开会议传达贯彻东莞理工学院第二次党代会精神

9月29日，我院在法商大楼会议室召开中层干部（扩大）会议，传达贯彻执行东莞理工学院第二次党代会会议精神。

东莞理工学院党委委员、城市学院院长杨敏林主持会议。

党委书记朱志德在会上介绍了东莞理工学院第二次党代会大会盛况及会议主要精神。朱志德书记说，这次会议开的隆重、热烈、圆满、成功，是一次解放思想、实事求是、承前启后、继往开来、凝心聚力、团结奋进的大会，我们要认真学习好、传达好、贯彻好会议精神。

杨敏林院长在会议上要求，一、全院各级党组织要把学习贯彻党代会精神作为当前一项重要的政治任务抓紧抓实，让广大党员和教职工都了解和掌握大会的精神及提出的各项任务；二、认真学习市委书记徐建华、东莞理工学院党委书记成洪波在大会上的讲话，以及会议文件；三、要联系实际，就城市学院发展的奋斗目标、工作思路展开讨论，达成共识，制定措施，形成合力，开创新的工作局面。

会议还对国庆、中秋假期的工作做了安排和强调。
