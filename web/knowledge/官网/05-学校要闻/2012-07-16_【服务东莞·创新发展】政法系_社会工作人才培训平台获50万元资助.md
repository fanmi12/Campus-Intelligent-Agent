# 【服务东莞·创新发展】政法系:社会工作人才培训平台获50万元资助

据悉，东莞理工学院城市学院近日获得东莞市教育局下拨的民办学校扶持专项资金50万元，用以建设东莞社会工作人才培训平台。

东莞社会工作人才培训平台是我院政法系社会工作教研室主办，主要用于社工专业实验教学、社工实践、社工研究、社会调查及其他用途的多功能社会工作实验室，主要服务于社会工作专业实验教学和学生实习需要，以及服务东莞的要求。该平台包括两个实验室：计算机辅助电话调查实验室和社会工作实验室；分为5个基本功能区：教学演示兼实务服务区、实务服务区、观察区和监控区和调查室。为社会工作专业的社会个案工作、社会团体工作、社会心理学等多门课程提供支持服务。

社会工作教研室主任周巍博士说，有了这笔资金的支持，社会工作人才培训平台的建设将得到有力保障，将为东莞本土社工事业的发展培养更多创新型、应用型的社会工作专业人才，更好地服务东莞社会建设。
