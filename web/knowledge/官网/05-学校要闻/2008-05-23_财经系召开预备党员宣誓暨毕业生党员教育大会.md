# 财经系召开预备党员宣誓暨毕业生党员教育大会

5月22日，财经系在5307召开预备党员宣誓暨2008届毕业生党员教育大会。

会上，系党总支副书记叶凯贞老师要求学生党员在校时要按照党员标准严格要求自己，毕业后要兢兢业业做事，诚诚恳恳做人，为母校争光添彩。

学生党支部书记唐洁老师在会上介绍了移转党组织关系的有关程序。

会后，与会党员缴纳了“特殊党费”5178元，支援四川地震灾区。
