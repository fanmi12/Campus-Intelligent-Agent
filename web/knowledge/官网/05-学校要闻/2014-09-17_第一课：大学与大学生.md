# 第一课：大学与大学生

9月15日，党委书记王卫平为军训学员上第一课，畅谈大学的功能、大学生如何成长成功。王书记深入浅出、风趣幽默、富有哲理和生活情趣的报告，受到新同学们的好评，40多分钟的课程中，掌声响起了十多次。

王书记结合城市学院发展实际，从大学的起源讲到中外最早的大学，从现代大学讲到大学的内涵。史料丰富，数据翔实，观点鲜明，图文并茂，让同学们大开眼界。

他说，何谓大学？大学就是“大人之学”。“大人之学”中的大人，一是指成年之人；二是指大学培养的人才是具有伟大人格、道德芳表、修己治人、风动草偃、以平天下为最高目标的大人。我们今天在座的大学生现在正属于第一种大人。只有做好了第一种大人，才有资格晋升为第二种大人。

王书记表示，大学要有大楼，大学要有大师，大学要有大气，大学一定大成。

如何才能成才成功呢？王书记认为：一是要找准自我定位，二是分清大学与高中的区别，三是要记住几个哲理，即：漂亮不等于健康，财富不等于快乐，知识不等于能力，优秀不等于成功，成功不等于幸福。大学生的成才可分为两个阶段：第一阶段是大学生活环境下的成才，这是真正成才的基础；第二阶段是社会生活环境下的成才，这是指经过社会实践的磨练和洗礼，走向成熟，成为对社会真正有用的人才。

新同学们现在正处于大学生活环境成才阶段，应该是德、智、体、美、劳全面发展，为今后走向社会打好基础。总之，一个人的成才，1%是天资，99%是血汗。

王书记还介绍了成功的一个判断标准：你有本事（成才），有人说你有本事，说你有本事的人有本事。
