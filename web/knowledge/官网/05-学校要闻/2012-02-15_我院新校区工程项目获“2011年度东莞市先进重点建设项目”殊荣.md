# 我院新校区工程项目获“2011年度东莞市先进重点建设项目”殊荣

我院新校区建设项目再获殊荣。在2月14日召开的东莞市“三重”（重大项目、重大产业集聚区、重大科技专项）建设工作会议上，我院新校区工程项目被授予“2011年度东莞市先进重点建设项目”荣誉称号，新校区管委会综合部副部长黄兢同志被授予“2011年度东莞市重点项目建设工作先进个人”荣誉称号。

这两项由东莞市委、市政府颁发的荣誉称号，再次证明我院新校区建设所取得的巨大成绩获得了市委、市政府和社会各界的高度评价与肯定。

据了解，在此次东莞市“三重”建设工作会议上，市委、市政府对2011年度市属60个重点建设项目进行了总结，共评出10个市先进重点建设项目，我院新校区建设项目是其中之一；同时，大会还对全市31位市重点项目建设工作先进个人进行了表彰。我院新校区管委会综合部副部长黄兢同志工作表现突出，被授予“先进个人”荣誉称号。

据悉，自2009年4月东莞理工学院与广东鸿发投资集团有限公司签约合作举办城市学院，就决定另辟新址建设新校区，并获得了东莞市委、市政府的大力支持。2011年2月，东莞市人民政府审议并通过东莞理工学院城市学院新校区为东莞市2011年重点建设项目和2010年省扩内需项目。

我院新校区一期工程，自2011年3月全面开工建设到9月全面竣工并正式投入使用，东莞理工学院和广东鸿发投资集团有限公司始终坚持“高起点、高标准、高质量”，在不到半年的时间里，完成建筑面积高达45万平方米，创下了东莞建筑史上的“奇迹”。这一建设成就，在2011年8月也被刘志庚副省长（时任东莞市委书记、市人大常委会主任）盛誉为“东莞速度”！

据统计，我院新校区一期工程完成总投资额超过10亿元，较2010年申报建设投资计划翻了一番。

此次我院新校区工程项目被授予“2011年度东莞市先进重点建设项目”荣誉称号，是市委、市政府对东莞理工学院及城市学院和广东鸿发投资集团有限公司，在深入学习、践行科学发展观，为东莞实现 “文化强市”的战略目标、大力发展高等教育事业所做出的突出贡献的肯定；是东莞市实现高水平崛起，继续推进“三重”建设的标杆之一。
