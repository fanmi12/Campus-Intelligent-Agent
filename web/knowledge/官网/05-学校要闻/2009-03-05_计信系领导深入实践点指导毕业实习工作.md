# 计信系领导深入实践点指导毕业实习工作

牛熠主任（左二）看望实习学生现场指导实习工作3月4日，计算机与信息科学系牛熠主任、葛卫清副书记、马立权教授、陈显龙老师一深入广东易事特电源股份有限公司、东莞东莞索威计算机科技有限公司、东莞网等企业看望实习学生现场指导实习工作。系领导所到之处，一一了解实习生的实习情况，询问学生的生活情况、安全保障等方面问题。

广东易事特电源股份有限公司，人事部和制造部的相关负责人反映，城市学院的实习生，态度端正，不怕吃苦，学习虚心，有时还公司员工一起加班。学生也反映在企业里学到了很多东西。在东莞网络和索威计算机科技有限公司实习的学生，已很快进入了开发角色，与公司技术人员一道完成公司的项目受到企业的好评。东莞电信设计院负责人表示，欢迎优秀实习生成为他们的正式员工。

牛主任鼓励同学们，要充分利用这个机会，努力工作，争取在实习单位赢得就业机会。
