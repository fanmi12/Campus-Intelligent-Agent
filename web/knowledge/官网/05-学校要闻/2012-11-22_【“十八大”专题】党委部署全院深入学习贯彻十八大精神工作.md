# 【“十八大”专题】党委部署全院深入学习贯彻十八大精神工作

11月22日，学院召开书记、院长办公会议，进一步学习领会党的十八大精神，就全院深入学习贯彻工作进行研究部署。

学院领导杨敏林、朱志德、朱冰、张林、陈丁堂、章德胜、高香林参加会议。

与会人员紧密结合工作实际，就深刻领会和贯彻党的十八大精神谈了体会。大家一致表示，要紧密团结在以习近平总书记的党中央周围，认真学习贯彻党的十八大精神，把党的十八大提出的各项目标任务落到实处，促进学院的发展。

会议就进一步深入学习贯彻党的十八大精神作出部署。学院党委要求，要按照中央和省、市委、东莞理工学院党委的统一部署，组织党员和广大师生认真学习贯彻党的十八大精神。各单位要把学习贯彻党的十八大精神作为当前和今后一个时期的首要政治任务。要运用多种形式，推动党的十八大精神进班级、进课堂，入脑入心。各级领导要带头学习，集中一定时间，原原本本地学习党的十八大报告和中国共产党党章，全面领会精神。要组织开展专题研讨，加强对党的十八大提出有关重大理论、实践问题的宣传与研究，帮助广大师生加深对党的十八大精神的理解。各单位在学习过程中，要联系本单位的工作实际，学以致用、用以促学，切实把党的十八大精神落实到全面推进各项工作上来，确保取得实实在在的效果。
