# 计信系与动漫公司合作开展毕业实习实训

3月1日，计算计与科学信息2009级学生毕业实习实训开班仪式在莞城校区实验楼606室举行。系主任牛熠教授、实践办主任白晨明老师、专业教师和旨尖动漫公司的培训专员参加了开班仪式。

牛熠主任对毕业实习期间的工作进行了布置，他希望同学们高度重视实习的过程，不迟到、不旷课，利用本次实习机会提高自己的动手能力，圆满完成实习任务；虚心学习，实现人生价值，认真总结实习体会，写好实习报告。

本次实训是该系与东莞旨尖动漫科技有限公司合作开展的，以课程置换的形式运作。实训过程的教学任务由旨尖动漫公司的培训专员提供并指导，09级学生将利用一个月的时间参加全部游戏动漫方向的实习项目和实岗训练。
