# 政法系召开参加全国司法考试经验交流暨动员大会

1月6日，政法系在1-301教室召开参加全国司法考试经验交流暨动员大会。政法系06法学全体同学和法学教研室老师参加了这次会议。

会上，政法系主任刘杰教授指出，司法考试是法学专业学生的头等大事，只有通过司法考试，才能从事职业律师、法官、检察官等工作。06级法学是我院首届法学本科班，恰逢08年司法改革，允许在校生参加今年的司法考试，希望同学们抓住机遇，积极备考。政法系将把司法考试备考作为今年的工作重点，组织同学们集中进行学习和培训。

会议邀请了2008年通过司法考试的系友付鹏、周珊、孙志鸿同学介绍复习备考经验。

法学教研室主任危兆宾博士要求同学们早作准备、早动手，结合自身实际，制定复习计划。

据介绍，国家司法考试是国家统一组织的对从事特定法律职业人员的资格考试，是法律从业人员的通行证，是法学学子走向职业法律人的唯一通道。这次经验交流会得到北京中天学校东莞分校（司法考试培训学校）的大力支持，他们免费为06级法学班同学提供了法理学、民法、刑法、行政法相关司法考试资料。
