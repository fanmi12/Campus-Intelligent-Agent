# 东莞市委常委杨晓棠点赞我院大学生创新创业作品

4月26日，2018/2019赛季CBA总决赛第一回合在东莞篮球中心举行。当天下午，东莞市文化广电旅游体育局与广东宏远篮球俱乐部有限公司举办了篮球嘉年华活动。由我院商学院、创意设计学院联合指导的大学生创业项目粤动（体育用品）文化创意有限公司应邀参加了在东莞日产体育中心举办的此次活动，首次进行作品展示，并受到了体育爱好者的高度肯定和喜爱。

在活动现场，我院项目展销摊位吸引了东莞市委常委、宣传部部长杨晓棠的关注，他对城市学院创新创业教育及取得的成果给予了充分的肯定，对城院大学生独立设计的文创产品给予高度赞赏。他希望同学们能够结合东莞文化传统，使作品更能体现东莞体育之乡、篮球之乡的特色。

东莞文化广电旅游体育局局长陆世强，副局长朱伟光、吴邵文等领导也前来参观、指导。他们肯定了项目的创作设计理念，指出作品能与中国的传统艺术文化相结合，色彩绚丽，极具美感，对传统文化宣传起到推波助澜的作用，实现传统美与现代美的完美结合。同时，对我院学子更加深入地开展好创新创业教育，创作出更多优秀的作品寄予了厚望。
