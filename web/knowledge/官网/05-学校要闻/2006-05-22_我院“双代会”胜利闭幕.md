# 我院“双代会”胜利闭幕

5月20日下午，东莞理工学院城市学院第一届教职工代表大会暨工会会员代表大会在雄壮的《国际歌》声中落下帷幕。

在各位代表的共同努力下，大会圆满地完成了会议的各项议程。 各代表团团长汇报了各团的讨论情况。全体代表举手表决通过了学院工作报告、工会工作报告和工会财务报告。

大会选举产生了城市学院第一届工会委员会。

会议期间，第一届工会委员会召开会议，选举章德胜为工会主席，孙成访、黄研晖为副主席；何鹏举为提案工作委员会委员，廉玉忠为教学科研工作委员会委员，刘红艳为生活福利委员会委员，黄研晖为妇女工作委员会委员（兼），李玲玲为青年工作委员会委员，刘红艳为文体工作委员会委员（兼）。

会议举手表决通过有关部门决定。

5：30时，大会举行闭幕式。我院党委副书记朱冰致闭幕词。
