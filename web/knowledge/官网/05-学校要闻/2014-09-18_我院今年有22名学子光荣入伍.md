# 我院今年有22名学子光荣入伍

日前，历时两个多月的2014年夏秋季征兵工作圆满结束，我院共有22名同学光荣入伍。

通过宣传发动，精心组织，我院学生踊跃报名，报名参军创历史新高，共计报名有500多人。男女生比例为4:1。从年级来看，2013级的学生最多。

为了细致深入地做好征兵工作，学生处积极与省教育厅、东莞军分区、东莞理工学院武装部对接，对入伍学生的学费补偿、停学等政策落实工作进行跟踪服务。因此，我院2013年征兵工作获得广东省教育厅一等奖。

据了解，我校正在服役的校友中，已有4人成为或即将成为军官，他们是2012年级金贸系宋柏万，08级城市与环境科学系黎自立，09级影视表演林子明，10级政法系刘国伦。

院党委章德胜副书记（左3）与入伍学生合影
