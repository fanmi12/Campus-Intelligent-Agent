# 我院召开教学、行政秘书座谈会

安少华：要把教学（行政）秘书工作岗位作为关键岗位来建设

“一个系部工作的正常运作，离不开教学、行政秘书人员的辛勤工作，今后学院要把教学、行政秘书工作岗位作为关键岗位来建设！一个优秀的领导都是先从基层干起的，积累基层工作经验非常重要。” 院长安少华在昨日召开的教学秘书、行政秘书座谈会上寄语教学秘书和行政秘书。

党委书记朱志德，副院长张林，人事处处长夏勇，财务办主任黄甜源出席会议。

会上，教学秘书、行政秘书就职业培训、教学管理、自身业务建设等问题发表了意见与建议。

安院长首先肯定了大家“干一行、爱一行、专一行”的职业精神，并表示要多召开一些座谈会，了解教学、行政秘书的工作状况和合理诉求，随时掌握他们的思想动态。学院将尽快加强岗位定编工作，打通管理岗位和教学岗位互转，使有能力的老师可以通过竞争谋得更高的职位。对于他们的要求与建议，院领导希望职能部门通盘考虑加以解决。
