# 我院社工专业学生就业走俏东莞

8月20日，南方都市报以《首批“莞产”社工就业，形势大好》为题，对我院第一届“社工班”的就业情况进行报道。

今年被称为“史上最难就业季”，社工领域却是别样风景。报道中指出：东莞对社工专业人才的需求正处于上升阶段，社工经验还在摸索和积累当中。

据悉，我院第一届社工班52名学生约40位最终都选择了社工岗位，在受访的12家社工机构中，有11家招收了应届大学生，有的更是一次性招了20位。社工教研室主任王海洋对社工专业持乐观态度，有资料表明，政府购买社工岗位、项目的力度将会加大本土社工人才需求更旺。
