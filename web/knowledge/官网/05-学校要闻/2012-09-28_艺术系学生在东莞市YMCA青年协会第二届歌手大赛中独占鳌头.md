# 艺术系学生在东莞市YMCA青年协会第二届歌手大赛中独占鳌头

东莞市YMCA青年协会第二届歌手大赛于9月23日在东城文化周末剧场拉开帷幕。据悉，参赛选手是来自东莞各高校的大学生，参与者众多。经过近一个月时间的层层选拔，有15名选手进入决赛，其中我院占据9个名额。

经过激烈的角逐，我院参赛选手包揽了前六名，其中11级音乐表演专业的鲁志垚同学、09音乐表演专业的魏宝同学、09音乐表演专业赵延峰同学分别获得了冠亚季军。
