# 省高校党建考核小组来我院检查工作

12月27日下午，按照省委要求，省高校党建述职评议考核小组来我院开展现场检查工作。院党委书记王卫平、党委副书记章德胜参加了现场检查活动。

核查小组按照相关评分指标体系，对我院2017年党建工作材料进行了仔细检查，对管理系、财经系党总支基层党组织的建设情况进行了实地检查。
