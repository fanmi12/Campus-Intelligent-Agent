# 我院获批5项国家级大学生创新创业训练计划项目

近日，教育部下发《关于公布2014年国家级大学生创新创业训练计划项目名单的通知》（教高司函[2014]58号），公布了2014年国家级大学生创新创业训练计划项目，我院申报的5项国家级大学生创新创业训练计划项目全部获批。至此，我院获批的国家级大学生创新创业训练计划项目达到10项。

大学生创新创业训练计划项目内容包括创新训练项目、创业训练项目和创业实践项目三类。项目负责人均由学生担任，在老师的指导下，3-8名学生组成的项目组自主完成创新性研究项目设计、研究条件准备和项目实施、研究报告撰写、成果（学术）交流等工作。

据悉，我院已将大学生创新创业训练计划项目纳入学院2014-2016年“创新强项工程”建设规划。通过大学生创新创业训练计划项目特别是国家级大学生创新创业训练计划项目的建设实施，培养学生的创新意识和创业能力，为大学生未来创业做好准备。同时，通过项目训练，让学生将所学到的理论知识与实际运用有机结合起来，培养出具有创新、创业精神的高素质应用型人才。
