# 何鹏举部长赴京参加广东省学习秘书培训班学习

图为会议现场5月23日至31日，中共广东省委宣传部在北京举办的全省党委中心组学习秘书培训班，参加培训的有各县(市)区、地级市直各部门、大专院校、大型企业单位400余名党委(党组)中心组的秘书。我院党委宣传部部长何鹏举副教授也参加了此次培训班的学习。

培训期间，大家认真学习了《珠江三角洲地区改革发展规划纲要（2008~2020）》，以及中央和省委关于加强和改进党委中心组学习等文件精神。

国务院参事、国务院应急管理专家组组长闪淳昌等专家学者，分别就深入学习实践科学发展观、加强党员干部理论学习、搞好新形势下的党委中心组学习等问题进行了专题辅导；省委宣传部副部长蒋斌就今年全省党委中心组的学习进行了安排部署。培训班还围绕提高党委中心组学习秘书的服务保障能力，提高党委中心组理论学习的兴趣与效果进行了研讨交流。

与会人员还参观了天下第一村——华西村，听取了原村党委书记吴仁宝关于华西村的情况介绍。
