# 粤浙三院校联合参访我院

4月17日，来自广东外语外贸大学、广东外语外贸大学南国商学院和浙江越秀外国语学院三所高校联合访问团莅临我院，对新、老校区进行参观访问。

当日，广东外语外贸大学原党委书记、校长徐真华，广东外语外贸大学南国商学院董事长丁小军、副院长赖立志，浙江越秀外国学院校长杨银千、副校长何建乐等一行14人，在东莞理工学院党委书记周致纳、校长杨晓西、副校长安少华，城市学院院长杨敏林、院党委书记朱志德等领导的热情陪同下，参观了我院莞城校区及新校区图书馆、物理实验室、金工实习车间等。

据了解，去年11月下旬，徐真华教授作为我院新增学士学位授予单位和专业审核实地评估专家委员会主任，全程参与了评估工作。当时，通过实地评审，专家组形成了这样的共识——“城市学院是广东省新办本科院校里的一匹黑马，是名符其实的后起之秀。”随后，广东省学位委员会颁发“粤学位〔2011〕13号”文件——《关于批准广东省独立学院新增学士学位授予单位和专业名单的通知》，东莞理工学院城市学院通过学士学位授予单位评审，17个本科专业全部获得学士学位授予权。

正是这次难忘的评审经历，徐真华教授推荐并率领广东外语外贸大学南国商学院和浙江越秀外国语学院两所独立院校，前来我院参观、交流，互相取长补短。我院办学9年来的显著成果和各项工作都给客人留下了深刻的印象，双方就办学与建设相关经验进行了座谈交流。
