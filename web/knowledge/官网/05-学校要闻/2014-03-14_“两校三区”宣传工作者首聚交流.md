# “两校三区”宣传工作者首聚交流

3月13日，东莞理工学院党委宣传部、城市学院党委宣传部、莞城校区新闻中心全体工作人员，在东莞理工学院聚会学习交流，共同探讨新闻媒体资源整合等工作。我院宣传部全体工作人员参加了会议。

座谈会上，两校三区的宣传工作人员对报纸、电视、广播、网络以及新媒体等宣传工作进行了充分的交流，并针对校内外宣传、校园文化品牌建设和学生媒体中心建设等工作中存在的问题展开了讨论。大家一致认为，两校三区的宣传工作一定要紧密结合，进一步实现资源共享；加大对学生媒体中心的培训和建设力度；加快微信、微博平台建设，搭起师生、各校以及社会沟通的桥梁；宣传工作要接地气，抓典型，推亮点，扎实做好内外宣工作；突出主题，正确把握社会主义核心价值观，教育和引导师生践行党的群众路线，进一步加强校园文化品牌建设；围绕中心、服务大局、改革创新，积极推动在莞高校宣传部门建立一个统一的平台，互相学习、推动与融合，充分发挥高校宣传力量。

东莞理工学院宣传部何献青部长主持本次活动。她指出，“两校三区”的宣传工作要通力合作，既各自打造特色品牌，又全盘考虑塑造好整体形象。
