# 【学习“十八大”专题四】学生处召开系部总支副书记会议

11月12日，学生处召开各系部总支副书记会议，学习十八大的会议精神。与会人员联系工作实际，就学生工作思路、工作方法展开讨论，并就学风建设、宿舍管理、班级管理、校园文化建设、心理健康教育等方面研究了措施和办法。

大家表示，学生工作要贯彻和落实“以生为本，德育为先”的工作理念，致力构建“全员育人，全程育人”的工作格局，为学生的成长、成才和校园的和谐、稳定做出贡献。
