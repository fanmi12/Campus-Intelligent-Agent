# 金贸系教师看望毕业实习生

近日，金融与贸易系主任米双红、总支书记龙卫洋带领该系全体老师，分赴各镇区看望实习学生，了解他们的实习情况和存在的问题，并与用人单位就人才培养模式的创新进行了沟通。

系主任米双红在厚街、虎门等地勉励学生要立足岗位，克服困难，以一流的工作成果回报用人单位、学校和社会。龙书记对大朗、常平实习生的工作情况十分满意，鼓励他们要百尺竿头更进一步。
