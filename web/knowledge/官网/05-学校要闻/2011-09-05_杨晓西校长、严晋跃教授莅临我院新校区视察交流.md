# 杨晓西校长、严晋跃教授莅临我院新校区视察交流

随着9月17日新生入学的临近，我院新校区备受社会各界的广泛关注。9月2日上午，东莞理工学院杨晓西校长、瑞典皇家理工学院严晋跃教授一行，在我院杨敏林副院长的陪同下，来到我院新校区视察、交流。

当天，杨晓西校长和严晋跃教授首先来新校区北门视察，并先后参观了综合馆、游泳馆、操场、学生宿舍、食堂、学生活动中心、图书馆等雄伟的建筑群；一路上，严晋跃教授还饶有兴致地不时用iPad 2摄影，记录自己所见的美景。

来到图书馆前的中央湖景小桥上时，严晋跃教授对新校区的景观及岭南特色的建筑群，赞叹不已，表示不虚此行，并与杨晓西校长、杨敏林副院长等领导合影留念。

随后，杨敏林副院长细致地从我院的发展历程、新校区的诞生、选址、规划、建设及现状、未来发展目标等情况向杨晓西校长、严晋跃教授一行做了详尽的介绍。严晋跃教授仔细地聆听了相关介绍，并不时插话就感兴趣的话题进行交流、探讨，用严教授的话说，“要认真学习城市学院及新校区建设的成功经验，不能辜负此行！”
