# 东莞市委副书记刘树基莅临我院考察指导工作

3月17日,东莞市委副书记、东莞理工学院临时党委书记刘树基同志莅临我院考察并指导工作，受到我院董事长杨晓西教授、院长安少华教授等领导的热情接待。

刘树基同志在我院领导的陪同下，参观、考察了我院的校园环境、硬件设施。董事长杨晓西教授、院长安少华教授向刘书记汇报了学院招生、教学、科研、发展规划等方面的情况。

刘书记对城市学院的工作给予充分肯定，他指出作为教育强市，东莞到2010年高等教育毛入学率要达到60%，城市学院肩负着重要任务。市里几套班子领导都有共识，要支持城市学院大力发展，为东莞经济社会快速可持续发展培养更多、更好的人才。他指出，城市学院要按照万人大学的规模，认真做好规划工作。
