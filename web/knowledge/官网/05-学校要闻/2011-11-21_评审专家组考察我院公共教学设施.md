# 评审专家组考察我院公共教学设施

专家考察我院电子实验室

专家询问物流实验室实验课情况

专家考察金工实习中心11月21日上午，广东省学位委员会副主任、省教育厅巡视员罗远芳教授，省学位委员会评审委员会主任徐真华及专家组成员在院领导安少华、朱志德、程发良、张林的陪同下考察我院图书信息中心、实验中心等公共教学设施。

专家组听取了图书信息中心主任陈伟对图书馆基本情况的介绍。图书馆讲解员楼晶汇报了图书馆一站式服务、大开放管理模式、各楼层的功能与布局、数字化图书馆建设、社会化服务等基本情况。专家组对图书馆大开放式的区域管理模式、市情资料室整合地方文献资料工作及开展丰富多彩的读书文化活动给予了高度评价。

专家组还听取了实验中心主任周梓荣关于实验中心基本情况的介绍。先后参观了非线性编辑实验室、印刷实验室、电子创新实验室、物流实验室、金工实习中心等地。专家组成员查阅了学生的实验报告和实验记录。在全开放式的电子创新实验室，专家们对本科生参与项目研究及创新实践活动尤感兴趣，详细询问了参加研究及创新实验的人数、时间和效果。专家组对我院学生创新设计制作的作品取得全国大学生电子设计大赛一等奖表示赞许。

在金工实习中心，正值学生上金工实验课，专家组成员与学生进行了交流，在数控车床车间，正在做实验的一些同学向专家组汇报了这个学期做实验的情况和体会，演示了操作数控编程的步骤，并把用数控车床制作的卡通形象物实习作品赠送给了专家组成员。

专家们考察结束后，对我院公共设施的建设和利用工作给予了充分肯定与赞扬。
