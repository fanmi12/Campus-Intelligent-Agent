# 我院举行辅导员技能大赛

4月12日，辅导员技能大赛”在新校区7A115举行。

大赛分为工作总结、书籍介绍、现场提问三个环节。来自各系部的11位辅导员老师在各自的演讲环节中充分发挥自己语言魅力，展示系部的辅导员工作理念及学生工作品牌活动，交流学生工作的体会和经验。管理系陈文丽老师的“因材施教，全面发展”，金贸系万文双老师的“和同学们一起学习，一起成长”，艺术系邓雁虹老师的“我相信，相信自己的梦”，金贸系黄威老师的“教育无他，唯爱与榜样而已”等主题介绍，获得了与会人员的热烈掌声。在现场提问环节中，辅导员老师们面对学生或尖锐或深奥的问题，沉着应答，亮点频现。

院学生处赵秋平老师为大赛做了点评。她认为，参赛辅导员素质较好，是一支胜任学生工作的师资队伍。

院学生处副处长陈建新、团委书记杜鹏举、文传系党总支书记孟颖等出席大赛并担任评委。
