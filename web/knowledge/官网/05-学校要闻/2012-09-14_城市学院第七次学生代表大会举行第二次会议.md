# 城市学院第七次学生代表大会举行第二次会议

9月13日，东莞理工学院城市学院第七次学生代表大会第二次会议在学术报告厅举行，287个学生代表出席会议共商学生会工作大计。55名学生列席了会议。

学生处副处长、团委书记杜鹏举致开幕词。他对大会的召开表示了热烈的祝贺，并预祝大会圆满成功。

大会按照规定的议程，选举产生了第九届城市学院学生会主席团成员。城市与环境科学系潘泳霖同学、政法系林志聪与金融与贸易系赖焕婷同学光荣当选。据悉，在投票之前，他们分别进行了竞选演讲。由于他们服务学生指导思想明确，工作思路清晰，工作成绩得到认可，演讲语言风趣幽默，从多位候选人中胜出。

党委副书记章德胜在会上发表了重要讲话。他在讲话中首先肯定了上一届院学生会一年来的工作，对今后工作提出了明确的要求。他希望院系学生会要在各级党组织的领导下大胆开展工作，充分发挥“自我教育、自我管理、自我服务”的职能，以广大学生为服务对象，维护和保障学生的权益，反映学生的呼声与诉求，做学生联系院系领导的桥梁与纽带，积极开展有益于大学生健康成长的科技文化体育艺术活动，为建设活力城院、幸福家园、百年名校作出贡献。

会议还审议并表决通过了东莞理工学院城市学院学生会章程（修正案），宣读了学生代表提案。
