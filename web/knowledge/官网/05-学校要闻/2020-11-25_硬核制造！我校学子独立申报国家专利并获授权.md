# 硬核制造！我校学子独立申报国家专利并获授权

日前获悉，我校智能制造学院创新中心2016级学生林润杰、袁振廷等同学，独立申请专利“一种柑橘去芯除果肉机内夹具的制作方法”授权。两位同学是“攀登计划”和大创项目及挑战杯主力成员。

同时该专利集成了3D打印、模具设计、机构设计以及运动学控制原理等技术，此技术有力的支撑了“挑战杯”“互联网＋”等竞赛项目。该成果得到了指导老师张攀峰以及辅导员大力支持，是校级重大科研培育项目孵化重要成果之一。
