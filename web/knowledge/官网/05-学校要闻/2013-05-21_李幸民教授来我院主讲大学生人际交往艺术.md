# 李幸民教授来我院主讲大学生人际交往艺术

“如何成为一个受欢迎的人？”5月20日，学生处心理健康与咨询中心为我院学生送来了一场心灵雨露，邀请国际中华应用心理学研究会理事、知名心理咨询专家李幸民教授在学术报告厅为我院大学生主讲大学生人际交往的艺术。

李幸民教授表示，生活中任何人都离不开他人。人际交往也是大学生一门必修课。同学们要成为一个受欢迎的人，应做到以下几点：1.陶冶、约束个人的品性和修养；2.谦恭自律，不要争强好胜；3.和风细雨，不要出口伤人；4.得理饶人，不要针锋相对；5.尊重他人，不要“官气”十足；6.检点言行，不要打探私事。

李教授深有感触地说：“30年后，你会发现，大学同学的关系就像酒一样愈久愈醇香，要珍惜同学情、师生情。”

李幸民教授衷心祝愿每位同学都能成为一个受欢迎的人，将来进入社会后就能纵横驰骋，得心应手，众人相助。

据悉，此次心理讲座是院“5 ? 25”心理健康活动月的活动内容之一。
