# 文传系举行第三届情景模拟招聘会

为提高毕业生的应聘和就业技巧，让在校毕业生提前感受招聘现场的紧张氛围，并了解应聘礼仪及细节。11月6日，文传系在学术报告厅举行第三届情景模拟招聘会。招聘会邀请了东莞市语言工作委员会办公室、智通人才市场、平安保险公司的嘉宾及系友吴庆松、张晓敏担任评委。文传系2012届256名毕业生参加了本次模拟招聘会。

活动以志愿报名的方式选出15名学生作为招聘会的模拟选手，以3人为一组，分成5个小组开展模拟招聘。活动共分三个环节，第一环节是职业形象展示，选手们分别展示站姿、坐姿、握手、交换名片等礼仪，同时进行职业着装展示，充分展现了应聘者良好的精神面貌。第二环节是现场面试，首先应聘者进行简短的自我介绍；然后是压力问答，评委们根据选手所应聘的岗位进行针对性提问，应聘选手做出机智快速的专业应答；最后是评委就应聘者的简历，应聘演讲及其优缺点进行点评。第三环节是总结，评审团代表智通人才市场的王茜女士就每位选手在应聘过程中的着装、简历、仪态等方面给予总结点评，并针对这些问题进行分析和指导，指出同学们面试时应注意的细节。

本次模拟招聘会让毕业生们更加深入了解目前的就业市场形势，更清晰的剖析自己，弥补不足，发扬优点，调整就业心态，提高应聘能力和就业竞争能力，为自己将来走向社会做好准备。
