# 学工团队党员教师全部挂牌上岗

为加强基层服务型党组织建设，强化服务功能，促进基层党组织由“管理型”向“服务型”转变，我院学工团队自9月27日起实行“挂牌上岗”制度，学工团队全体党员教师挂牌上岗。

挂牌上岗的对象包括学生处、团委全体老师以及各院系（部）党总支副书记、辅导员。学工队伍全体党员统一挂上标有自己姓名的胸牌，小小胸牌警示学工团队在今后的工作中做到“亮身份、明责任、做表率”，旨在为学生提供更加精准的服务，同时接受同学们的监督。

学生处副处长罗文芳表示：学工干部要转变观念，从管理学生转变为服务学生。同时，作为思想政治工作辅导员，更要勇于亮出党员身份，立起先进标尺，树立先锋形象，成为“身正为范”的践行者。

据介绍，学工团队实行“挂牌上岗”这一制度有利于体现党员教师的党性原则，提升我院学工队伍服务的精准度，更好地为学生提供了便利，也让学生们更加了解身边的老师，拉近学生与老师之间的距离。
