# 各学院领导深入军训场地慰问2020级参训新生

军训期间，各二级学院院长、党总支书记、副书记、辅导员和班主任都纷纷到军训场地，看望新生并进行慰问。

智能制造学院1月7日下午，智能制造学院院长连元宏，党总支书记、副院长殷素峰同辅导员一行看望六连1、2排的军训教官和学生。由于近日天气多变，气温骤降，连院长特别询问了军训学生的身体健康情况，表达了对同学们的关心，亲切嘱咐同学们要注意保暖，调整作息，保证睡眠，以最好的状态面对军训，以最优良的面貌进行训练。殷书记强调，军训是一个培养良好生活习惯的好机会，希望同学们能够继续保持早睡早起的规律作息，在适应了军训的强度后，以更好的精神面貌面对未来的学习与生活。

计算机与信息学院1月8日上午，计算机与信息学院院长牛熠、党总支副书记张鸣乐到场查看新生军训情况，并对参训教官及新生进行慰问。牛熠院长感谢参训教官的严谨负责，并对他们辛勤的工作表示衷心感谢。牛院长看到学子们动作规范整齐，步调一致，军训新生个个精神抖擞、身姿挺拔，表示欣慰，希望同学们将军训中培养出的优良品质延续到今后四年的大学生活中，不畏艰辛，砥砺前行。

文学与传媒学院1月8日上午，文学与传媒学院党总支书记、副院长陈跃同教师、辅导员一行看望十连1排、2排的军训教官和学生。陈书记说军训是一个磨炼自我意志的过程，也是高校人才培养方案的一项必修课，大一的同学们必须拿到军训学分。他希望同学们要把军训的收获淬炼成一种精神，在学习生活中也应如军训期间一般，不畏困难，并养成锻炼身体的习惯。陈副院长还强调应加强纪律性，敦促各位同学军训不能迟到、早退。梁慧钰老师希望同学们在接下来的军训里要坚持做到安全第一，并做好保暖工作和每日的考勤。

城建与环境学院1月11日下午，城市与环境学院院长肖红飞、党总支书记罗文芳、副院长郭文显、副书记曹镭一行人心系军训场上的莘莘学子，冒着寒风来到军训场上看望正在军训的教官和学生，给教官和学生送去了温暖的问候。肖红飞院长亲切慰问了城环学院参加军训全体学生，向教官表达了感谢。肖院长亲切询问同学们的军训情况，叮嘱同学们要注意防寒，注意保暖，保重身体，勉励同学们要刻苦训练，努力学习，养成良好的行为习惯，充分展现新时代大学生的优秀风采，争取在军训汇报表演中取得优异的成绩。党总支书记罗文芳向军训的同学和教官送去了亲切的问候，勉励同学们在军训中锤炼自我，增强党性修养，积极向党组织靠拢，认真完成军训的各项任务，在军训中取得优异的成绩。

外国语学院1月11日下午，外国语学院院长赵东林、党总支书记刘浔、副书记都振华、辅导员段妍君来到训练场上给予同学们诚挚的问候与温暖。赵院长对同学们在军训中展现出来的良好精神面貌表示赞扬，并勉励大家要在军训中提升自己的意志品质，克服军训困难，圆满完成军训任务。刘浔书记给大家加油打气，同时叮嘱大家多多注意防寒和保暖。训练结束后，老师们为同学们送来了巧克力，让同学们感受到学院的温暖，不仅仅是对同学们刻苦训练的激励，更是对同学们未来大学生活的殷切希望和祝福。

艺术学院

艺术学院院长陈建新与党总支书记康慧丽前往学1训练场地慰问正在军训的新生同学们。

我院领导看到同学们作风优良，英姿飒爽，不忍心打扰其训练，而在远远的一旁微笑着观望，一直等到教官发布休息指令时才开始渐渐走近。

坐下开始休息，喝水的同学们看到陈院长和康书记来了，惊喜不已，顿时响起热烈掌声，“老师好”三个字响彻云霄。康书记亲切地走近学生并问道“同学们，这几天训练累不累？”同学们齐声呐喊：“不累！”有位女同学小心翼翼地说：“但是很冷”。顿时一大片笑脸开始浮现，给现场增添了别样的温暖。

康书记说道：“同学们这几天辛苦了，寒风瑟瑟的天气，能够坚持训练，是一件很不容易的事，大家一定要注意保暖”，随后，康书记强调，这次军训是对同学们的纪律性和意志力的大考验，坚持到最后，同学们一定会收获更加成熟和自律的自己。康书记不仅讲述了军训的意义，也阐明了军训的主要目的之一是要培养同学们的爱国奉献意识与团结合作精神。

陈院长最后发言时，不仅回顾了自己艰苦的大学军训时光，也指出了艺术学院连队有着光荣的历史和传统，往年不少项目都是拿第一的。他激励同学们要有拿第一的冲劲，要有不服输的气魄，要共同努力，把咱们1连打造成人数少，但个个都是精英的特种连队，要学会克服自己惰性，要有勇于力争第一的魄力。

此次学院领导对军训新生的看望与慰问，既使同学们感受到了学院的温暖，也有助于促使同学们养成“咬定青山不放松”的韧劲。

创意设计学院12日下午，创意设计学院院长王锦锋同辅导员一行看望新生。王锦锋向军训的新生表示了诚挚的慰问，并鼓励同学们克服军训中的困难，在训练中展示出军人不畏艰辛、勤奋刻苦的精神，体现出军人的气质。老师们为我院正在军训的同学们发放热饮，希望他们能刻苦训练，度过一个有意义的军训。

商学院13日上午，商学院院长罗卫国、党总支书记唐洁、副书记李梦丹和辅导员一行来到2020级新生军训场地，给同学们带来真挚的问候并送来了温暖的红糖姜水，让同学们在寒冷的冬日感受到学院的温暖。罗院长首先对教官们的辛勤教导表示感谢，他对同学们在军训中不怕苦的精神表示赞扬。他希望同学们在接下来的军训中可以继续配合教官完成军事训练任务，坚持刻苦训练，并在军训汇报中取得好成绩。唐书记叮嘱同学们在军训结束返乡时，要继续坚持健康打卡，如实的汇报健康状况；要继续做好防护措施，避免去中高风险地区；要加强运动，提高身体素质。同时也呼吁同学们积极参与家乡的抗疫活动。她希望大家都平平安安，待春暖花开之时，再与大家相见。

金融与贸易学院1月13日上午，金融与贸易学院院长赖忠孝、辅导员李钰到训练场查看20级金贸学院新生军训情况，并对带训教官及新生表示慰问。赖忠孝在讲话中首先对新生认真参训的精神表示肯定。他说：“今年的军训是“别具一格”的，没有夏日的酷暑却有冬天的严寒，但从同学们的作风纪律、精神面貌及训练动作的整齐划一等方面可以看出军训成效显著，同学们具备着作为金贸学子的良好精神风貌，希望大家同学们能够持之以恒、再接再厉。赖院长鼓励同学们在军训回家后依旧保持军训期间养成的自律，蜕变成更好的自己。

法学院1月14日上午，法学院党总支书记江小卫，党总支副书记曾惠娴，与辅导员、班助们一行前往法学院20级军训场地看望军训教官和学生们。老师们同时带来了温热的豆奶，为冬训中的同学们送来温暖。江小卫书记表示，军训是一次很重要的过程和经历，希望同学们不仅能收获强健的身体，还能以此磨练坚强的意志和培养团结协作、不怕苦不怕累的精神，为这人生中重要的一堂课画上圆满的句号。
