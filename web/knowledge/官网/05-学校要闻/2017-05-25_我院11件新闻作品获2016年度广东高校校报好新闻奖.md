# 我院11件新闻作品获2016年度广东高校校报好新闻奖

5月24日，由广东省高校校报研究会主办的“2016年度广东高校校报好新闻评选活动”评选结果揭晓。我院共有11件新闻作品分别获得二等奖、三等奖。

根据本次评选办法，我院《城市学院报》编辑部精心挑选了14件作品参评，共获得消息类二等奖、三等奖各1项；标题类二等奖三等奖各1项；通讯类三等奖2项；摄影类二等奖2项；言论类三等奖1项；专题类二等奖、三等奖各1项。
