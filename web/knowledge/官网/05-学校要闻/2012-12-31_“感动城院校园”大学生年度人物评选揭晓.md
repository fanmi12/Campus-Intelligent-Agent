# “感动城院校园”大学生年度人物评选揭晓

“我算是今天这个舞台上最年老的学生的，专科三年、本科两年。其实每个人都会有自己的人生观、价值观。这些年来我一直奉行着“勿以善小而不为，勿以恶小而为之”人生信条。年度道德风尚人物财经系09级会计学1班李淦奇同学如此深情地分享着他的获奖感言。

11月27日，由我院团委主办、财经系承办的“城院榜样，你我模范”2012年东莞理工学院城市学院“感动城院校园”大学生年度人物评选活动颁奖典礼在学术报告厅隆重举行。我院团委书记罗文芳老师、各系部团总支书记以及辅导员代表参加了颁奖盛典。

团委书记罗文芳老师在颁奖典礼上宣读表彰文件。罗老师指出，学院领导的重视关怀和大力支持，一定会给大家带来了无穷的精神力量，激励着大家奋力前行。青年学生要以他们为榜样，共同模范，不断超越自我、成就辉煌。

经过评选委员会近一个月的选拔与评选，最终有7名学生获此殊荣。他们分别是“年度志愿人物”叶建忠、“年度领袖人物”黄健帮、“年度科技人物”何志豪、“年度艺术人物”谢昊佳、“年度道德风尚人物” 李淦奇、“年度自强人物”吴华培、“年度博学人物”林真铨。我院金融与贸易系团总支荣获本次评选活动的“最佳组织奖”。

据悉，本次评选的结果是由微博投票和评选委员会专家的意见综合评定得出。他们的相关事迹将在微博公示。
