# 艺术系领导赴东莞市科技博物馆看望实习学生

4月26日，艺术系主任邓星明、党总支书记丘永辉专程赴东莞市科技博物馆看望艺术系07级影视表演专业部分实习学生。

系领导在了解了学生在实习单位实习的情况的同时，还掌握了市科技博物馆对人才的需求信息。实习单位负责人黎坚对我院实习学生在实习期间的精神面貌、专业素养及创新思维方等面给予了高度的评价。
