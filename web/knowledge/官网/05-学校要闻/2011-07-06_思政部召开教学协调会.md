# 思政部召开教学协调会

7月6日下午，为加强课程建设，规范教学秩序，保证教学质量，迎接本科学士学位评估和思想政治理论课专项评估工作，思政部在1202课室召开教学协调会。院督学陈丁堂教授，思政部主任何鹏举教授、副主任石志民副教授及思政部专兼职教师28人参加了此次会议。

会议要求，思政课教师要以胡锦涛“七一”讲话精神为指导，树立大局意识、责任意识、阵地意识，坚持正确舆论导向，使学生树立正确的世界观、人生观、价值观。要认真研究教材，依据教学大纲要求，实现教材体系向教学体系的转化，联系学生实际，按时按质完成教学任务。要努力提高自身业务素质，围绕教学和东莞政治、经济、文化和社会发展制定自身科研计划。会议还对备课、上课、实践教学、考试、作业及试卷批改等教学具体环节提出了具体的规范要求。
