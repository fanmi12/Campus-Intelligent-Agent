# 管理系与广东联通东莞分公司进行合作洽谈

9月15日，广东联通东莞分公司朱法武副总经理携省、市两级公司部分领导来我院管理系，并就大学生创业教育、联通与管理系合作等问题进行了磋商。管理系主任张佺举教授、书记帅建华教授等系领导热情接待了来宾。

座谈会上，张主任向客人介绍了管理系的专业特色、培养特点、师资力量等基本情况，双方就如何开展合作进行了洽谈，并达成了合作协议。协议内容包括，由广东联通东莞分公司将赞助管理系2012年迎新系列活动的费用，合作开展大学生创业教育活动。
