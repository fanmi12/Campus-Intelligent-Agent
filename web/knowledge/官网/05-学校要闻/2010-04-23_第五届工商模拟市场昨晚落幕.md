# 第五届工商模拟市场昨晚落幕

4月22日，第五届工商模拟市场闭幕式在第一饭堂前坪举行。现场人头涌动，聚集几百名的师生前来观看闭幕演出。但受天气状况影响，模拟市场摊主们营业时间将推迟至4月23日22时30分。

一场男生机器舞拉开表演的帷幕。女生青春现代舞、还有09级三位男同学的劲舞将现场的气氛推向一波波的高潮。

据悉，表演结束后，主持人宣布了此次工商模拟市场活动所评出的奖项，其中有综合奖、最佳摊位奖、最具营销潜力奖、最佳美味奖、绿色经营奖，以及优秀创业计划书奖。志愿队摊位、爱心摊位2212元的利润全部捐献给红十字会，送往西南、青海玉树灾区。管理系工商模拟市场委员会还捐出5610元给城市学院爱心协会，作为资助贫困生的基金。
