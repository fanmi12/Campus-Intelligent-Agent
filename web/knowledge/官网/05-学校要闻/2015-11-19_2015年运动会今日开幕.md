# 2015年运动会今日开幕

“运动健康 畅想快乐”——东莞理工学院城市学院2015年运动会，11月19日开始在田径场隆重举行。

东莞理工学院党委副书记吕琦元，城市学院董事黎建烨，城市学院杨敏林、王卫平等院领导及各处、系部主任，以及全体运动员、裁判员和师生代表参加了运动会开幕式。

随着训练有素的花束队、彩旗队、裁判员方阵、各系部方阵、教工方阵、后勤部方阵迈着整齐划一的脚步走过主席台接受检阅，运动会开幕式拉开帷幕。

各系方阵的表演精彩赢得掌声迭起。其中，艺术系方阵一出场便吸引观众的注意，前排女生身穿舞蹈服，旋转、跳跃，优美的舞姿获得了阵阵掌声。而金贸系的方阵队员，用绿色的伞撑出一个个变化的图案，象征着希望和活力。

高香林副院长为校运会致开幕词，希望全体运动员发扬体育精神，赛出风格、赛出水平，赛出友谊，力争把本届运动会办成一个文明、团结、安全、欢乐的运动会。

运动员代表和裁判员代表现场郑重地进行了宣誓，将以严肃的态度对待运动会的各项比赛。

随后，传统团体操表演把开幕式推向了高潮。以“和谐中国”为主题的呼啦圈表演，“幸福城院”为主题的花球啦啦操表演，“悦动生命”为主题的跳绳表演和“彩色畅想”为主题的彩带表演，可谓精彩纷呈，复杂的队形变换、动感的舞步、青春的跳跃、缤纷的彩带随风飘扬，尽情地展示了我院学子的青春活力与运动之美。
