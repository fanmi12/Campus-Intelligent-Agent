# 喜报！我院2018年文理科投档线再创新高

7月17日晚，广东省本科最低省控制线上文理类正式投档，我院2018年文理投档线再创新高。

文科投档人数2110人，投档分数线为466分，高于省控线23分，文科最高分539分。理科投档人数2620人，投档分数线为395分，高于省控线19分，理科最高分461分。

根据投档情况来看，今年考生报考我院热度持续高涨，且高分段生源大幅度增加，越来越多的优秀学子选择东莞理工学院城市学院。文科、理科投档分与省控线分差再创新高，这体现了广大考生和家长对我院办学综合实力的充分肯定。

截止发稿前，我院招生录取工作正在紧锣密鼓进行，具体录取结果请密切关注我院招生就业处官方网站、官方微信平台。
