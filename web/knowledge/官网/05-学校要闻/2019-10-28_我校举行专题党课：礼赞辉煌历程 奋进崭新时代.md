# 我校举行专题党课：礼赞辉煌历程  奋进崭新时代

为深入开展“不忘初心、牢记使命”主题教育， 10月24日，马克思主义学院副院长石志民以《礼赞辉煌历程 奋进崭新时代》为题，在行政楼323会议室为我校党员干部讲专题党课。学校党委委员、二级党组织书记、党支部书记参加了活动。

石志民副教授以新民主主义革命时期、社会主义革命和改革开与和社会主义现代化建设时期三个阶段为线索，回顾了中国共产党在近百年艰辛的奋斗历程。

“以史为鉴可以知兴替”，石志民副教授提醒全体党员同志，学习党史、国史是共产党员的必修课，广大党员干部要通过对历史的深入思考做好现实工作，常“照镜子”，查找差距，反思自身不足，加强党性修养。
