# 我院党校举办第二期入党积极分子培训班

3月16日，我院党校第二期入党积极分子培训班在大礼堂举行开学典礼，院党委副书记朱冰同志参加开学

典礼并发表讲话。她说，“本期培训班共570多名学员，由我院各个班级的学生入党积极分子组成，大家要珍惜

上党校的机会，认真学习理论知识和党章内容。 ”

开学典礼仪式后，社会科学系主任何鹏举副教授担任第一课的主讲，他为学员们做了题为“如何做一个合

格的学生共产党员”的专题报告，并就世界格局、国家发展、保持党的先进性、以及如何构建和谐

社会深入浅出地做了讲解。用深刻的理论结合大量生动的事实，加深了学员们对党的认识和

信念。

据悉，该培训班分为五次讲座，前四个讲座由老师授课，最后一课是结业考试。
