# 我院召开党建与思想政治教育研究会2017年年会

12月28日下午，学院召开党建与思想政治教育研究会2017年年会。院领导王卫平、章德胜、高香林、黄兢、刘玉侠，院党委委员杜鹏举出席了会议。党务工作部副部长叶凯贞主持了会议。

王卫平书记指出，党的十九大是在全面建成小康社会决胜阶段、中国特色社会主义进入新时代的关键时期召开的十分重要的大会。最近，学院印发了《学习宣传贯彻党的十九大精神总体工作方案》以及《党的十九大宣讲行动实施方案》，全院各级党组织要把学习宣传贯彻党的十九大精神作为当前和今后一个时期的首要政治任务，认真做好学习培训、宣传教育、调查研究各项工作，为我院的教育教学改革、内涵式发展提供强大精神动力和良好的思想舆论氛围。

王卫平书记强调，每位教育工作者都要进一步提高思想认识，不断增强责任感、使命感、紧迫感，努力探索新形势下思想政治教育工作的新方法、新途径，为学院建设提供有力的理论支持和思想保障，推动我院大学生思想政治教育工作迈上新台阶。

章德胜副书记作了学院党建与思想政治教育研究会工作情况报告。他指出，研究会的指导思想是：深入学习贯彻习近平总书记系列重要讲话精神和党的十九大精神，紧紧围绕学院中心工作，着眼于提高党建研究水平和推动党建创新实践，充分发挥研究会的思想库和智囊团作用，提供强有力的理论支撑，推动学院党建与思想政治教育工作更快更好地发展。

章德胜副书记提出，当前和今后一个时期，研究会成员要认真学习贯彻习近平总书记系列重要讲话精神和党的十九大精神，紧密围绕我院中心任务，找准位置、有所作为、体现价值，使研究会真正成为我院党建与思想政治教育的人才培育基地、经验交流平台、理论研究阵地，成为院党委开展党建与思想政治教育工作的参谋部、智囊团，为构建和谐稳定校园、促进学院改革发展稳定做出积极的贡献。

会上，思政部副主任石志民对党的十九大精神进行了宣讲。

学院副院长、研究会副会长刘玉侠宣读了2017年年会优秀论文的表彰决定。

获奖代表史雍真、詹海都向与会同志进行了研究成果与经验分享。
