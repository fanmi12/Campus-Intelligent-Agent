# 学院召开中层干部会议部署全年工作

2月14日，学院在315会议室召开中层干部会议。会议的主要议程有：一、院办、教务处、总务处和实验中心汇报开学工作情况；二、副院长林世俊教授通报开学教学情况；三、常务副院长程发良教授通报城市学院董事会一届二次会议情况、2005年工作总结和2006年工作要点。

院长安少华教授在会议上发表了讲话。他说，寒假期间，有关职能部门做了大量的工作，使春节过得喜庆、欢乐、祥和、安全。开学的各项准备工作扎实，教学秩序有条不紊，一切运转正常。他强调，今年学院喜事、大事多，任务艰巨要求高，我们要有足够的思想准备。如学生规模要增加到近8000人，新增设的法律、物流、会计专业下半年要招收新生，艺术专业要单独实行招生，学报即将创刊，教师住房改革将要开展，承办广东大运会东莞赛区运动员的食宿与足球比赛，迎接校本部党代会召开，这些工作我们务必如期出色地做好。他要求，院、系及各职能部门要围绕“三年打基础、五年创特色”的指导思想，根据以上主要任务早规划，细安排，扎实工作，开拓创新，以期取得令人满意的成效。
