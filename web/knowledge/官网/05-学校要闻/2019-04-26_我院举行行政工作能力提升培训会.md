# 我院举行行政工作能力提升培训会

我院OA办公系统正式启用。4月25日，学校办公室在行政楼212举行行政工作能力提升培训会，校内各单位行政工作联络员参加了

OA办公系统培训。

学校办公室主任杜鹏举主持会议。他指出，学校OA办公系统的应用将外来文处理、校内发文、用印用车申请等各类行政办公流程搬到线上，将极大地提高行政办事效率。希望各行政工作联络员作以本次培训会为契机，将OA办公系统向本单位同事进行宣传与指导，尽快将系统普及到全校每个办公室，切实提高办公效率。

会上，办公室工作人员对OA系统各个模块功能的操作流程进行了详细地讲解。参训人员积极发言，相互交流经验。

据介绍，学院OA办公系统已正式启用，网址链接：http://oa.ccdgut.edu.cn:8090/，教职工可根据个人工号登录和密码使用。
