# 热情周到，只为你的到来

9月5日、6日，是我院2015级新生报到的日子，也是5400多名新城院人认识学院、与学院建立感情的第一次接触，并由此开启四年大学时光。为珍惜这难忘的第一次接触，学院全体迎新工作人员和850名志愿者以热情周到的服务迎接新同学。

校园里，“热烈欢迎2015级新同学”、“小师弟师妹，We are 伐木累（family）”等大红色迎新横幅醒目且内容活泼；校广播电台不间断的迎新播音，为新生和家长提供指引；一块块活泼生动的迎新展板、一张张富有创意的宣传海报，成为了一道道亮丽的风景线。

校园里，处处是热情爽朗的笑脸，志愿者们顶着烈日为新生和家长提供周全、热情的服务，到处洋溢着青春的气息。驶入校园的车辆数以千计，但在交警、校卫和志愿者的指引下，却多而不乱，有序地驶进驶出；在校道上，到处都是为新同学和家长提供帮助的志愿者，帮助新生拿行李、协助办理入学手续，带领他们找到各自的宿舍，态度热情、细致负责。

学院各系（部）、各单位更是齐心协力通力合作，尽最大努力给新生和家长提供最好的服务。汽车站火车站迎新、新生接待、报到服务、医疗救助、交通引导、安全巡逻等各项工作有序进行，干净整洁的校园、阴凉处搭起的凉伞……处处彰显着热情、细致的迎新服务。
