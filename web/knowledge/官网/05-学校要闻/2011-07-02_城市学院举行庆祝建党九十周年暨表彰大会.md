# 城市学院举行庆祝建党九十周年暨表彰大会

7月1日，东莞理工学院城市学院庆祝中国共产党成立90周年暨表彰大会在大礼堂隆重举行。东莞理工学院党委领导周致纳、杨晓西、安少华，城市学院党委领导班子成员朱志德、朱冰、王玉、夏勇、章德胜等出席了会议。大会由党委委员、院办主任王玉主持。

大会在雄壮的国歌声中开始。院党委委员夏勇同志宣读了院党委《关于表彰2010—2011学年度先进基层党组织、优秀共产党员和优秀党务工作者的决定》。文学与传媒系等3个党组织荣获“城市学院先进基层党组织”称号，何岸等33位同志荣获“城市学院优秀共产党员”称号，黄阳辉等3位同志荣获“优秀党务工作者”称号。东莞理工学院、城市学院领导为受到表彰的先进集体和先进个人颁奖。

这次表彰的先进基层党组织和优秀共产党员、优秀党务工作者，是全院各级党组织和党员、党务工作者的优秀代表，充分体现了新时期城市学院共产党人的精神风貌。院党委在表彰决定中号召全院共产党员、党务工作者、各系部党组织，要向先进集体和优秀个人学习，深入开展创先争优活动，积极发挥基层党组织的战斗堡垒作用和党员的先锋模范作用，为实现城市学院新的发展作出更大的贡献。

优秀党员代表袁宇志同学、文学与传媒系党总支书记孟颖老师在会上做了发言。他们感谢党组织对自己的关心和培养，表示在今后的工作中继续努力，模范带头，取得更大的成绩。

党委书记朱志德在会上发表了讲话。他在简要回顾中国共产党90年的奋斗历程后表示，中国共产党不愧为伟大的、正确的、光荣的党，是领导中国社会主义革命和社会主义建设事业的核心力量。我们要在党的领导下，坚持改革开放，发展市场经济，接受执政考验，为教职工谋幸福。

朱书记强调，当前，我们在迎评促建和新校区建设等工作中，要发挥党委的政治核心作用、战斗堡垒作用，发挥党员的先锋模范作用，推动学院工作再上新台阶。我们要准确把握创先争优的主要内容，夯实科学发展坚实基础。牢固树立创先争优的经常性观念，推动学习实践活动向深度和广度发展。把创先争优与我院当前的“迎评促建”和“新生入驻新校区”的工作结合起来，统筹协调，提高思想认识，推动学院科学发展，要十分重视党员的作风建设等问题。

大会结束后，全体党员还观看了精彩的文艺演出。动听的歌声、优美的舞蹈和深情的朗诵，仿佛让大家又回到我们党的峥嵘岁月，感受到我们党的光辉历程和伟大创举。

会议之前，还举行了新党员集体宣誓和老党员重温入党誓词仪式。
