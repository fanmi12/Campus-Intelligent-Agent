# 2019年级新生奖学金获得者的心声(上）

9月7日上午，在学校举行的2019级新生开学典礼暨军训开训仪式上，梁虹钰、刘施荣等40名同学获得2019年优秀新生校园奖学金，受到大会表彰。

随后，记者对19名获得新生奖学者的同学进行了采访，来听听他们的获奖感言：很感谢学校给予我的奖学金，获得这份光荣的奖励，我十分激动。为了不辜负学校的一片心意，在今后的学习岁月中我会更加的努力，携带着期望努力成长。

——19级智能制造学院机械设计制造及其自动化1班 刘家昊

这是对我的一种激励，支撑着我不断充实自己，完善自己。在未来的大学四年，我将认真学习专业知识，提高自身综合能力；认真学习好专业课程，积极投身社会实践，增加社会实践经验；积极参加学校或院系组织的各类实践活动。完善自我，学会做人。

——19级计算机与信息学院计科1班 王昊

能获得新生奖我是很意外的，刚开始阳光学工的学姐给我电话时候我还以为是骗人的。我希望以后继续努力，得到更多的奖项，体会到更多不一样的风景。

——19商学院会计7班 谢慧玲

能获得新生奖学金，确实感觉有点意外!我要继续努力学习，迈过英语这个坎，争取拿到奖学金。还要多考证，不要出现证到用时方恨少的情况。

——19级计算机与信息学院 软件工程3班 唐俊杰

开学典礼非常隆重，我能获奖也觉得很意外。现在的我还有很多东西要努力，努力做到最好，向着我的理想不停地前进!

——19级外语学院英语3班 冯启会

站在新生领奖台上的我激动不已，也更加激励了我在未来的四年中能够成为更好的自己。我对城院充满好奇的同时也决定将更加努力，学好专业知识，为城院争光！

——19级法学院法学四班 钟盈

高中时的努力没有白费，我很荣幸能够获得学校新生奖学金。获得奖金并不意味着未来的学习会变得轻松，反之我要继续努力学习，继续争当一名优秀的大学生！

——计算机与信息学院计算机科学与技术2班 谭应杰

对于获得这个成就，我感到非常自豪。同时也将今后的学习生活中继续努力，不断深入探索与思考，争取获得更多的荣誉。对于城院这个新的大家庭，我希望能为她做出更大的贡献，希望能在城院过得更加快乐！

——智能制造学院机械设计制造及自动化2班 袁敬锋

（大学生记者 姚星 郑淑君 温海琳 陈晓欣 詹钰莹 张子璇 杨文浩 曾香洲 徐怡清 魏静 黄燕菲 罗思琪 杨文浩 ）
