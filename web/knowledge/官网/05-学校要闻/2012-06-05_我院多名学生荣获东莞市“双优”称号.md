# 我院多名学生荣获东莞市“双优”称号

5月4日,团市委、市教育局授予我院李伟健、曹嘉聪、陈浩标、方嘉玲、杜晓君、汪淼和郭子华同学“东莞市优秀学生团干部”称号，授予蔡裕宏、郑楗澔、彭耀昌、吴志江等18位同学“东莞市优秀学生团员”称号。

据悉，本次东莞市共有80名同学获得“东莞市优秀学生团干部”称号，350名同学获得“东莞市优秀学生团员”称号。
