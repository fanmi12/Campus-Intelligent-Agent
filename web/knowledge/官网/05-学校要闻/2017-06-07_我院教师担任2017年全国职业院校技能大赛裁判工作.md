# 我院教师担任2017年全国职业院校技能大赛裁判工作

6月3日，2017年全国职业院校技能大赛在江苏省无锡商业职业技术学院举行。我院金融与贸易系赖忠孝教授受邀参加了该项赛事高职组“互联网+国际贸易综合技能”比赛的裁判工作。

据了解，全国职业院校技能大赛是由教育部发起，联合相关部门、行业组织和地方共同举办的全国性职业院校学生技能竞赛活动。“互联网+国际贸易综合技能”比赛是今年新增赛项，包括外贸业务能力、外贸跟单能力和外贸商务沟通能力三个竞赛模块，集中考察选手的B2B跨境电子商务平台推广、进出口业务商务沟通与磋商、进出口业务实践应用、跨境电商营销、客户服务及团队合作等技能点。来自全国27个省、市、自治区的72支代表队、288名选手参加了这次比赛。
