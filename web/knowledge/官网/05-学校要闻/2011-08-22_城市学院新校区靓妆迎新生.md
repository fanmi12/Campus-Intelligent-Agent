# 城市学院新校区靓妆迎新生

我院新校区各单体基建工程已进入收尾阶段，其中学生食堂已于8月19日正式启用。教学楼、学生宿舍、图书馆、综合馆、学生活动中心、运动场等单体建筑也将于本月底前全部竣工交付使用。教学设备及后勤设施正在陆续安装、调试，园林绿化及道路也在紧张施工之中，开学前的各项准备工作已基本就绪。9月17日、18日，我院新校区将迎来近5000名2011级新生入驻。
