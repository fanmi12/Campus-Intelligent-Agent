# 院长召开新生班干部代表座谈会

10月28日，学院在315会议室召开了新生班干部代表座谈会，听取新生对学院工作的意见和建议。院长安少华、党委副书记朱冰、院办主任王玉、学生处处长章德胜出席会议。

会上，班干部代表踊跃发言，充分肯定了学院的工作，同时也对后勤、环境、实验教学、图书信息等方面的工作提出了一些意见和建议。

安院长听取了同学们的发言后表示，学院办公室要收集整理同学们的意见和建议，下发各职能部门。有关部门对存在的问题要限期进行整改，为同学们营造更加和谐、舒适的学习、生活环境。
