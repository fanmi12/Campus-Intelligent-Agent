# 学院召开毕业生就业供需新闻发布会

2月29日，学院在315 会议室召开2008届毕业生就业供需新闻发布会暨媒体记者答谢会。东莞电视台、东莞阳光网、东莞日报、广州日报、南方都市报、南方日报、文化周末7家媒体的12名记者应邀与会。

院长安少华教授、副院长张林博士到会场与媒体记者进行了座谈交流。安院长说：“十分感谢各媒体对城市学院的关心和支持，你们为宣传城市学院和扩大城市学院的社会影响做了大量的工作。新机制学院的发展不仅需要政府的支持，更需要社会各界的关注，特别是媒体的宣传。今年，学院的发展将服从当地社会经济的需要，积极参与现代化建设，进一步服务东莞的“双转型”。同时，我们也期待各新闻媒体一如既往地关注学院的发展进程。”张林副院长表示，“媒体对学院的报道是客观准确的，表扬的报道鼓励我们进步，批评的报道促进我们改进工作，今后我们一定配合协助媒体的工作，营造良好的舆论宣传氛围。”

会上，就业办主任江小卫老师向记者们介绍了我院2008届毕业生的就业供需情况：今年学院共有1600多名应届毕业生毕业。3月15日将举办“城市学院2008届大型校园招聘会”，届时包括东莞理工学院2600名应届毕业生在内共约4000人参会，涉及工学、理学、管理学、法学、文学、教育学等八大学科50多个专业。

党委宣传部部长何鹏举副教授在会上通报了以往各媒体对城市学院的报道情况，他说：“从2004年7月至2008年1月，各大媒体共发表各类新闻稿件219篇（次），其中不乏‘千人大考场’、‘集体婚礼’、‘职业规划大赛’等深度报道。”他还向记者通报了学院今年计划要办好的十件实事和年内将开展的重大活动等情况。

记者们对即将举行的招聘会和今年学院的各项活动表现出浓厚的兴趣，表示要给予关注和报道。
