# 我院召开2017年士官直招暨义务兵再动员会议

6月20日下午，我院在教学楼3A118举行2017年士官直招暨义务兵再动员会议。各院（系）负责征兵工作的辅导员和学生代表参加了会议。

学院征兵工作站凌继峰老师就今年士官直招工作进行了安排，重点动员符合条件的毕业生报名参军。据介绍，今年士官直招专业涉及我院电子信息工程、计算机科学与技术、软件工程、土木工程四个专业。有意向报名士官直招的同学可到行政楼113办公室报名，报名截止日期为6月30日。

在义务兵再动员征集方面，凌老师强调，今年义务兵征集目前还处于动员和报名阶段，各单位要加强宣传力度，特别是对2017届毕业生的宣传工作。今年，在学校报名义务兵入伍的同学可到各院（系）辅导员老师处报名，截止日期是6月30日。

另据悉，我院定于7月3日8:30—18:30，在行政楼一楼113办公室开展初检、初审工作。如没来得及报名的同学，还可现场报名。
