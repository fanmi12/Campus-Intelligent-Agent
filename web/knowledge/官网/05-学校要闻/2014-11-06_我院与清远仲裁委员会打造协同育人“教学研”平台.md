# 我院与清远仲裁委员会打造协同育人“教学研”平台

11月4日，我院政法系系主任刘杰教授、主任助理危兆宾副教授、实践办主任王雄文副教授一行3人赴清远仲裁委员会东莞中心，举行实践基地授牌仪式并签订合作协议。

清远仲裁委员会东莞中心作为法学专业第10个教学研实践教学基地，每年可接纳20名以上的学生参加民商事仲裁毕业实习。同时，在学院领导的指导下，我院顺利成立“东莞理工学院城市学院商事仲裁研究中心”，此中心将成为政法系师生与仲裁实务部门协同育人的“教学研”平台；我院政法系刘杰教授、危兆宾副教授、王雄文副教授也被聘为清远仲裁委员会第三届仲裁员。

据悉，政法系首次与民商事仲裁机构签订合作协议，因应了越来越多的民商事纠纷通过仲裁来解决的发展趋势，进一步拓展了我院政法系法学专业应用型人才培养的广度和深度，也为“请进来、走出去”的人才培养模式提供了范例。
