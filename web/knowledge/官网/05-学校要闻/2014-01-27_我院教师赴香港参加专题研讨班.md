# 我院教师赴香港参加专题研讨班

2014年1月18日至22日，我院10位老师赴香港参加由香港理工大学举办的大学行政事务管理及学生事务管理专题研讨班。

研讨班在香港理工大学授课，两个班根据不同的研讨主题安排课程。香港理工大学曾庆忠副校长、工程学院院长文效忠教授、人文学院院长黄居仁教授，及香港中文大学崇基学院院长梁元生教授等15名专家为两个班献上了14场精彩的专题报告，内容涉及香港高校管理模式、素质教育、高校策略性发展、校企合作、高校团队建设、人力资源管理、学生发展模式、学生管理、就业及心理辅导、服务学习等方面。听取报告之余，老师们在香港理工大学的创新馆、纺织及制衣学系，香港城市大学的图书馆进行了实地考察，与管理人员及香港的大学生深入交流。大学行政事务管理研讨班还参加了邵文杰博士的“领导人提升技巧”专题户外团队建设活动。

在研讨班上，老师们对香港高等教育的现状、管理模式及运作有了系统深入的了解，香港理工大学的诸多先进的管理理念，亦让老师们获益良多。诸如“学专业、建事业、行志业”的素质教育、多维度的高校文化建设、重视外界参与的策略性发展规划模式、注重培养资助欲望的基金会运作策略、校企双赢的校企合作模式、充满人文关怀的人力资源管理、激发创新与优质服务的激励机制、注重全面发展的“全人教育”等。

赴港学习的老师们表示，香港高等教育跻身世界一流水平，其先进的办学理念及管理经验有许多值得借鉴；本次学习不只是开阔视野和增长见识，也对城市学院的改革创新提供了思路、激发了灵感；一定要把这次学习的宝贵经验及先进理念推广到校园去、带进工作里，促进学院的改革发展。
