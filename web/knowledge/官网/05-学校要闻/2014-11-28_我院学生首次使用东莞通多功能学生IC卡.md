# 我院学生首次使用东莞通多功能学生IC卡

近期，随着东莞的公交运输系统的提升，地铁的启用，原来的学生公交IC卡已不能满足现实需要。根据教育局《关于进一步完善学生公共汽车IC 卡办理工作机制的通知》（东教安函〔2014〕23 号）文件精神，我院于本学期10月、11月分别办理了5194张新的东莞通IC卡。

据有关媒体报道，东莞地铁预计在2015年年底开通试运行，新的东莞通IC卡可在公交、地铁东莞通公司指定的消费点通用。

据学生处相关负责人介绍，目前还有部分同学未办理新的东莞通IC卡（特别是旧卡换新卡），为方便符合办理条件的同学们能全部使用新的东莞通IC卡，结合我院实际情况，将在12月10日对东莞市户籍（含入学时转入我院户籍）的同学进行第三批次办理，请有关同学在规定的时间内到各系辅导员处办理。
