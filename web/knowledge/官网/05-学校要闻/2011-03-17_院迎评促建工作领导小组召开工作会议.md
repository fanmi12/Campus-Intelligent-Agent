# 院迎评促建工作领导小组召开工作会议

3月15日，学院在315会议召开迎评促建工作领导小组工作会议。迎评促建工作领导小组组长安少华、朱志德，副组长程发良、朱冰、张林、陈丁堂及小组成员参加了会议。

会议听取了“迎评促建”工作办公室秘书长李先庆关于我院迎评促建工作进展情况、存在问题、下阶段工作安排的情况汇报；审议并原则通过了迎评促建工作办公室拟定的迎评促建工作责任书、评议促建工作领导小组成员岗位职责等有关文件。

会议要求，迎评促建工作办公室要根据会议精神，对文件进行修改后实施。

会上，院长安少华教授作了重要讲话。他强调，全院各部门、全体教职员工要进一步统一思想，充分调动教职员工的积极性，明确分工，落实责任，严格按照学院确定的工作部署，与青年教师教学基本功培训等活动有机结合，扎扎实实开展迎评中的各项工作。
