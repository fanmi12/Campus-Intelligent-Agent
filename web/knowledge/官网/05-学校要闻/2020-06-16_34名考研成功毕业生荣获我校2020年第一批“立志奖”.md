# 34名考研成功毕业生荣获我校2020年第一批“立志奖”

受疫情影响，部分高校2020考研录取结果公布时间推迟，截止至6月8日，我校第一批统计共有34名毕业生成功考取硕士研究生。在6月15日 “云”毕业典礼上，我校对这34名考研成功的毕业生进行了表彰。

在录取高校中，不乏暨南大学、广东外语外贸大学、华南师范大学、广州大学、深圳大学、华南农业大学等国内知名高等院校，也有爱尔兰都柏林圣三一学院、澳门城市大学、澳门科技大学等境外高校。

一直以来，我校非常重视学生考研工作，将考研工作作为推进学校学风建设的重要抓手，扎实做好各项考研服务工作。学校设立了考研奖励制度，激发学生的学习和考研热情；各二级学院积极组织各类考研交流会，形成良好的学习氛围。
