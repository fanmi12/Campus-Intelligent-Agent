# 我院召开教学秘书培训交流会

11月18日至19日，我院召开了教学秘书培训交流会。教务处全体人员及各教学单位秘书参加了会议。

教务处处长牛熠介绍说，组织教学管理人员培训是教务处学年度的重点工作。从本学期起，学院将教学单位行政秘书与教学秘书岗统一调整为秘书岗，要求秘书重新分工，共同承担院系级相关的教学管理工作。

会议表彰了2016-2017学年“优秀教学秘书”，授予外语系孔昱、城环系徐杏嫦、政法系刘彬等三位教学秘书“优秀教学秘书”称号。

教务处副处长鞠晓红、赖忠孝根据《教务运行工作操作指导手册》，分别对学籍考务、教务教材、实习实践、教研教改等教学工作的流程进行了讲解。教务处各科室工作人员对日常工作中的重点和难点，进行了讲解和剖析。

王卫平院长出席了会议并讲话，他高度肯定了教学秘书工作的重要性。他指出，我院教学秘书是连接学院和师生的桥梁。在新形势下，教学秘书被赋予更多的责任，希望大家不断提高自身素质，积极做好教育教学管理与服务工作

培训中，与会人员从工作实际出发进行了经验交流，提出了相关的意见和建议。

会议由教务处副处长鞠晓红主持。
