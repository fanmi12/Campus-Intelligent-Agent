# 台湾高雄应用科技大学周至宏教授来我院访问交流

5月17日，台湾高雄应用科技大学讲座教授周至宏教授莅临我院访问交流。

在电子工程与智能制造学院院长陈中政教授的陪同下，周至宏教授与该院全体教师及学生代表进行了座谈。双方就人工智能技术的发展与应用、教师科研课研等方面进行了交流与探讨。周至宏教授还参观电子工程与智能制造学院实验室，与师生进行交流导。

下午，周至宏教授作客我院大学生科学文化讲坛，在学术报告厅举行了“计算智能/人工智慧在智慧制造的发展与应用”主题讲座。电智院、计信系和机电系的师生代表聆听了他的报告。

周至宏教授为师生们介绍了工业制造和工业4.0的目标与战略，通过各种实际案例阐述了智能制造、工业4.0等未来发展前景。他还分享了自己以及团队目前正在研究的问题，为师生们以后的科研工作提供了很好的研究思路与方法。
