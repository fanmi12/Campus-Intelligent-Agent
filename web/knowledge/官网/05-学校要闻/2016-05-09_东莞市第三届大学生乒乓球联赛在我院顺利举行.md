# 东莞市第三届大学生乒乓球联赛在我院顺利举行

5月7日，由我院和东莞市乒乓球协会联合主办的东莞市第三届大学生乒乓球联赛在我院成功举行。省乒协副主席兼广东财经大学党委副书记袁新满，东莞报业传媒集团东莞日报副社长、东莞时报总编谭军波，东莞理工学院党委副书记安少华，东莞市体育局副调研员邱业千，以及我院院领导王卫平等出席了大赛开幕式。

本届比赛还邀请了2010年国际乒联职业巡回赛总决赛双打冠军、2010年伦敦奥运会男单第四、2014年亚运会男双亚军、正在备战2016年里约奥运会的香港队的乒乓球运动员江天一莅临现场指导，并现场示范。

本届大学生乒乓球联赛，共有广东医科大学、东莞理工学院、东莞职业技术学院、中山大学新华学院、广东科技学院、广东创新科技职业学院和东莞理工学院城市学院等高校、17支参赛队伍、153名运动员参加。比赛类型为团体赛，其中包括有男子单打、男子双打、女子单打、混合双打。

大赛在世界冠军江天一的一记气势非凡的开球中，拉开战幕。赛场气氛十分活跃，高潮迭起，运动员们精湛的球技、顽强的拼搏精神和友好的比赛风貌，为观众们带来了一场体育竞技的盛宴。经过激烈的比拼，我院和广东医科大学、东莞理工学院、广东科技学院共4支代表杀出重围出进入决赛问鼎冠军。在决赛的强强争锋中，广东医科大学代表队依靠技高一筹和过硬的心理素质捧走本次乒乓球团体赛的冠军奖杯，我院乒乓球代表队荣获亚军，广东科技学院代表队荣获季军。我院另一支代表队获得第5名。

体育教学部邢红林教授告诉记者，本届比赛旨在更好地展示东莞大学生体育精神面貌，增进高校之间的友谊，促进大学生乒乓球项目的发展，提高大学生乒乓球运动水平。
