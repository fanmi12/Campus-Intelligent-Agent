# 2013年我院科研教研项目获资助金额再创新高

2013年，我院一批项目获得省、厅、市立项，项目资助经费达273.65万元。

获资助项目中，56个获2013年广东省质量工程项目，共获资助 136.5万元。包括1个实验示范中心、1项专业综合改革试点项目、1个大学生校外实践教学基地、3项高等教育教学改革项目以及50项大学生创新创业训练计划项目。

特别值得一提的是，我院申报的“机械设计制造及其自动化”专业建设项目在激烈的竞争中脱颖而出，获得广东省民办教育专项资金高等教育资助，并于2013年获得专项资金110万元。据悉，我院是东莞地区唯一一所获得该项资金的民办高校。

我院还有4个2013年广东省高等学校学科与专业建设专项资金项目（学科科研类）被批准立项，共获得专项资金9.5万元，其中人文社科项目1项，育苗工程人文社科类2项，育苗工程自然科学类1项。

此外，我院2013年还获得11项东莞市社科规划项目，科研经费12万元，广东省社科规划项目后期经费5.65万元。
