# 我校开展消防安全演练

今年“119”消防宣传月活动的主题为“防范火灾风险，建设美好家园”。为增强我校师生消防安全意识，提升消防安全处理能力、自救互救能力，11月7日下午，我校在田径场举行2019年消防安全应急疏散演练活动。寮步消防中队领导，学校领导王卫平、章德胜，鸿发教育集团公司副总经理李奎山，以及学校有关部门负责人、教职工代表、校内商铺代表和2019级全体新生参加了活动。

王卫平院长在致词中，对寮步消防中队对我校的大力支持表示感谢，并强调做好消防安全工作的重要性。希望广大师生能通过消防安全演习，提高自身安全意识，掌握消防安全知识。

此次消防演练分为如何使用灭火设备、被困人员解救、消防栓灭火器灭火、消防设备参观与体验等五部分内容。寮步消防中队向同学展示灭火器和消防水带等日常灭火技能，现场对消防器材功能及使用常识进行详细讲解示范。

消防演练上，同学们在多个场合进行了模拟火灾现场逃生体验。红十字会进行了现场心肺复苏教学与指导。

整个演练组织有序、分工到位、有条不紊，提高了师生的安全防范意识，也使同学们基本了解了灾害发生时的应对措施，提升了防火自救的能力，为创建平安和谐校园奠定了良好的基础。

（大学生记者 温清 罗思琪 段健鹏 王龙琪 梁慧心 杨流浩 陈梓聪 罗炜恒 崔育祯）
