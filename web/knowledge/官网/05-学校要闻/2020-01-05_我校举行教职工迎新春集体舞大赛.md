# 我校举行教职工迎新春集体舞大赛

一元复始，万象更新。1月4日晚，综合馆内华灯张彩，喜气洋洋。全校教职工齐聚一堂，举行2020年教职工迎新春集体舞大赛载歌载舞，迎接新春的到来。

东莞理工学院党委副书记、城市学院董事吕琦元，城市学院董事长代表、广东鸿发教育文化集团有限公司总经理陈超群，城市学院老领导朱志德、林世俊、朱冰、张林、黄研晖等，以及学校领导和全体教职工共同参加了此次舞蹈大赛。

机关二直属工会舞蹈《哒哒》，在幽默、欢笑中揭开了大赛的序幕。由全校各工会小组、分工会精心组织的15支参赛队伍，从独具一格的舞蹈装束、别出心裁的舞蹈动作、幽默风趣的氛围设计，精彩的表演将大赛的气氛一次又一次地推向了高潮。在欢声笑语中，向全体教职工传递了新年祝福，展示了舞蹈艺术的魅力和教师风采。全体校领导更是激情参与其中，为晚会增添了别样的欢乐。

经过评委的现场评分，艺术学院、体育教学部、机关一直属工会喜获一等奖，法学院、机关二直属会、创意设计学院分工会荣获二等奖，文学与传媒学院、智能制造学院、计算机与信息学院、金融与贸易学院分工会荣获三等奖，城建与环境学院、外国语学院、商学院、马克思主义学院、教辅直属工会荣获优秀奖。
