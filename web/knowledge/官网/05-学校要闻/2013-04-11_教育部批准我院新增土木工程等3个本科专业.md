# 教育部批准我院新增土木工程等3个本科专业

近日，教育部公布了2012年度普通高等学校本科专业设置备案或审批结果，我院申报的土木工程、建筑电气与智能化、财务管理3个专业获得了批准，可自今年秋季开始招生。

城市与环境科学系主任肖红飞教授介绍说，土木工程专业是根据我院办学单位广东省鸿发投资集团有限公司建议申报的，并将依托鸿发公司的资源开展办学，拟采取订单式人才培养模式。鸿发公司表示，该专业的学生在校学习空余时间可安排到集团的相关部门见习，毕业后也可去公司就业。
