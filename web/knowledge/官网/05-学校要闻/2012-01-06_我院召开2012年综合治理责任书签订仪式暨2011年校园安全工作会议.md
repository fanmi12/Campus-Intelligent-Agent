# 我院召开2012年综合治理责任书签订仪式暨2011年校园安全工作会议

会场朱志德书记与各部门负责人签署2012年治安消防综合治理责任书

张林副院长为在2011年度治安消防工作中表现突出的部门颁奖

张林副院长为优秀校卫队员颁奖1月5日，我院在4315会议室召开2012年综合治理责任书签订仪式暨2011年治安消防综合治理总结表彰会议。学院领导朱志德、张林及各职能部门负责人、莞城公安分局、东正派出所、樟村派出所负责人出席了会议。

会议由院办主任王玉主持。

会上，保卫办公室主任理阳阳传达了广东省教育厅关于高校治安综合治理会议的精神。张林副院长安排布置了2012年学院保卫工作，并为在2011年度治安消防工作中表现突出的图书信息中心、学生处、管理系、政法系、金贸系等5个奖单位颁发了奖状和奖金。

朱志德书记与各部门负责人签署了2012年治安消防综合治理责任书。明确了“安全第一、预防为主”的工作方针和“谁主管、谁负责”、“一岗双责”的原则，落实了本部门领导和岗位负责人“创建平安校园”的工作职责。

与会各单位负责人分别对校园及校园周边的治安状况发表了意见。与会的公安局、派出所负责人通报了目前治安工作状况，并表示，要进一步加强警民联合，密切合作，定点巡逻，严厉打击校园周边的违法犯罪行为，共建平安社区。

张林副院长在总结发言中充分肯定了学院2011年度的治安消防综合治理工作。他强调，2012年要进一步深刻认识综合治理工作的重要性和必要性；建立群防群治，警区社区联动机制；进一步做好安全宣传教育工作，力争让每一位师生员工树立安全防范意识，掌握必要自我防范技能；进一步提高管理水平，加强校卫队队伍建设，全面建设平安校园。
