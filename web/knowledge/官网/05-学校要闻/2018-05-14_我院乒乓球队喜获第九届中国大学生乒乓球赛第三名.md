# 我院乒乓球队喜获第九届中国大学生乒乓球赛第三名

5月12日至13日，全国第九届中国大学生阳光体育乒乓球赛在河北唐山举行。我院乒乓球代表队获得第三名,勇夺全国一等奖。这也是东莞市高校在乒乓球赛事上所获的最高奖项。

本届赛事由中国大学生体育协会主办，中国大学生体育协会乒乓球分会执行主办。比赛采用男、女混合团体赛制。清华大学、中国政法大学等几十所高校派出队伍参赛。

我院乒乓球队共派出6名运动员参加本届比赛。在小组赛上，我院乒乓球队分别战胜了上海大学队、中国政法大学队、武汉大学乒乓球队，以小组第一名的成绩进入全国八强。在淘汰赛上，以3∶1战胜华北水利大学队，强势进入全国前四强。在半决赛上，我院乒乓球队2∶3惜败给清华大学队，最终获得并列第三名和全国一等奖。
