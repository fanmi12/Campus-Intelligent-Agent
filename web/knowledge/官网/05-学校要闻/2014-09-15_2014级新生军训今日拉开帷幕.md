# 2014级新生军训今日拉开帷幕

9月15日，军训第一天，时而秋阳似火，时而狂风大作、暴雨倾盆，但军训的学生热情不减，各种训练如期进行。

清晨，校园处处涌动着“海浪花”，一队又一队的军训队伍整齐地行进在校道、田径场、篮球场，队伍整齐有序，学子英姿勃发。方阵队伍中，有的唱着嘹亮英武的军歌，有的喊着雄壮整齐的口号。

上午9时，学院在田径场举行了2014级新生军训动员大会。党委书记王卫平、副书记章德胜、副院长高香林，军训团团长韩加强中校、副团长陈建新以及参谋长黄磊出席了军训开幕式。

章德胜副书记作军训动员讲话。他首先欢迎同学们选择了城市学院，来到城院大家庭，感谢部队官兵热情支持学生军训工作。接着他对军训学生提出了三点要求：一、端正态度，做好吃大苦、流大汗的思想准备；二、发扬革命传统，学习军人作风，刻苦训练；三、严守纪律，参加各种活动。

在军训现场，记者采访了金贸系谭咏欣同学。他高兴地对记者说：“当军人，是我多年的梦想，今天我在城院梦圆了，终于成了一位‘军人’。我军训，我快乐，我成长。”城环系刘永航同学表示：太阳晒黑了皮肤，但磨练了意志。军训这一段历史，值得永远珍藏。据悉，他身高1.95米，是连队的排头兵，成了众人瞩目的人物，因此他训练处处带头，也特别认真，成了同学们的楷模。

据记者了解，今年训练的内容包括队列、素质拓展、军事理论课教育、国防知识与安全知识教育、阅兵、唱军歌、内务卫生，以及各种文体活动非常丰富。训练期间，共和国将军、学院领导、公安干警将为同学们做报告。

承训部队海军沙角部队共派出了50多名官兵指导学生军训。
