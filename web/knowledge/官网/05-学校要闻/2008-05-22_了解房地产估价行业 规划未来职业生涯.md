# 了解房地产估价行业  规划未来职业生涯

5月22日，一位莞籍企业家——东莞市正中联行土地房地产评估有限公司总经理张学勤登上学院学术报告厅，为同学们主讲《房地产估价与经济生活》。

张经理在讲座中向同学们详细介绍了房产评估行业的历史与发展前景，结合东莞实际分析了房地产估价与经济生活的重要关系。他还毫无保留的将自己的成功经验与同学们分享，与大家共同探讨了估价行业的未来发展趋势，以及如何才能成为一名合格的房地产估价师。

讲座的新颖内容引起了同学们的极大兴趣，纷纷举手提问，张经理一一予以了回答。

最后，张经理鼓励同学们说，“房产估价是一门新兴行业，是东莞经济转型中迫切需要的现代服务业，欢迎同学们尽早规划自已的职业生涯，投身于房地产估价行业，干出一番大事业。”

本次讲座为大学生科学文化论坛2008第五讲，由教务处李丽娟老师主持。
