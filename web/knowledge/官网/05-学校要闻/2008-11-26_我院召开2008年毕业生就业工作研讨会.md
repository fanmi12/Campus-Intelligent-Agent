# 我院召开2008年毕业生就业工作研讨会

11月25日，学院在410会议室召开2008年毕业生就业工作研讨会。院党委副书记朱冰，学生处处长章德胜，团委书记丘永辉，院就业办主任江小卫以及各系党总支书记、辅导员出席会议。

受全球金融危机的影响，大学生就业遭遇到“寒冬”。如何在12月6日举行的城市学院校园招聘会上为大学生雪中送炭，成为这次会议的中心议题。会上，章德胜处长传达了院长安少华关于做好2008年就业工作的指示精神。他指出，各系要从服务学生的立场出发，认真做好就业组织工作，帮助学生以积极的态度应对严峻的就业形势。

会议认为，我院毕业生就业需强调以下几个问题：一是要进一步提高大学生综合素质，增强大学生对企业的“忠诚度”；二是提高就业认识，把就业工作作为检验学生工作的“终极成果”；三是拓宽就业思路，学生要勇于到企业基层去工作，敢于挑战自我，通过创业找出路；四是尽量调整实习和上课时间的冲突，保证学生找工作与学习不受影响。

金融与贸易系龙卫洋博士认为，应把提高毕业生的就业积极性摆在首位，大学生应做社会的先行者，提高自主求职的意识。

江小卫老师在会上作了动员。他说，“大学生就业工作的前提是做好准备工作，这是一个系统工程，需要各系各部门通力协作，为社会提供高素质、讲诚信的人才。”
