# 省教学名师黎斌教授应邀来我院讲学

2月16日晚，教育部精品课件课题负责人，广东省思政课名教师、教指委委员，湛江师范学院黎斌教授应邀来思政部讲学，受到党委书记朱志德研究员、院督学陈丁堂教授的热情接待。

黎斌教授在新校区5A425会议室与思政部的全体老师、东莞理工学院思政部部分教师共30余人进行了座谈交流。他详细介绍了国家级课件《思想道德修养与法律基础》的制作及使用方法。黎教授还用自己的亲身经历讲述了从青年教师到优秀教师经历的五个发展阶段，分别是模仿阶段、自成风格阶段、学术化提升阶段、现代技术阶段、艺术化自如阶段。他勉励青年教师要具备爱—热爱本职、志—志存高远、思—勤思博学、勤—勤奋刻苦、韧—坚韧不懈、借—巧借外力、新—创新进取七种良好品德和素质。

思政部彭先兵老师说：“听黎教授的报告，不但学习了课件制作的方法和思路，还从黎教授身上学习到严谨治学的精神，明确了自己的发展方向和路径，真是受益匪浅啊！”

2月17日上午，黎教授审阅了思政部思政专项评估资料，和思政部主任何鹏举教授交流了思政教学和管理、课程建设等方面的经验。
