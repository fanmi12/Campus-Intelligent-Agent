# 我院在全国高校移动互联网应用创新大赛中获奖

12月3日，由教育部科技发展中心主办的第四届全国高校移动互联网应用开发创新大赛在中国地质大学（武汉）圆满结束。

经过激烈的角逐，我院电子工程与智能制造学院刘运城老师指导的学生团队荣获应用挑战赛三等奖，蒋文美老师指导的学生团队荣获应用挑战赛优胜奖。

本次大赛以“移动互联与应用创新”为主题，旨在提高大学生移动互联应用与解决问题的能力，着重培养大学生的合作意识与创新精神。大赛吸引了来自浙江大学、武汉大学、华中科技大学、中南大学等428所高校的2760支队伍报名参赛，经过选拔最终有331支队伍进入全国总决赛。
