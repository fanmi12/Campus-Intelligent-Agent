# 机电工程系部署新学期党建工作

2月25日，机电工程系在机电楼308会议室召开“解放思想，真抓实干”为主题的党建工作会议布置新学期党建工作。会议由党总支书记黄健求教授主持。

会上，黄健求书记首先传达了院党委关于开展对各基层党组织工作量化考评预检工作会议精神，表示要积极做好预检工作。教工党支部书记谢明、学生党支部书记孔增强先后对2007年教工和学生组织发展工作进行了回顾与总结，宣读了2008年党员发展工作计划。

最后，黄书记强调，新学期的工作要以“解放思想，真抓实干”为主题，以邓小平理论和“三个代表”重要思想为指导，牢固树立和落实科学发展观，以良好的精神状态和扎实的工作作风，加强党员的思想建设和组织建设，促进组织工作进一步规范化。
