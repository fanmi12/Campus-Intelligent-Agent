# 教学督导组召开机电城环系学生座谈会

10月30日，教学督导组在机电楼308室召开学生代表座谈会。教学督导组组长邵润堂教授及成员熊嗣斌教授、陈常祥副教授、谢明副教授以及学生代表参加了会议。座谈会由谢明副教授主持。

座谈会上，与会同学对教学计划安排、课程设置、教材选用、授课内容、教师授课水平等各方面各抒己见，与会教师认真记录并耐心解答了同学们的相关问题，对同学们关心学院发展、积极提出意见和建议给予了充分的肯定。

本次座谈会，为师生间的沟通交流搭建了桥梁，也为今后我院教师改进教学方法，提高教学质量提供了参考。
