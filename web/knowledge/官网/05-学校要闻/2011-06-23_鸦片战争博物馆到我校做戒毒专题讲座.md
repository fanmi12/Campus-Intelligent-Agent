# 鸦片战争博物馆到我校做戒毒专题讲座

为配合6?26世界禁毒日宣传，6月22日，鸦片战争博物馆宣教部曾红林副主任来我院为学生做了“珍爱生命 远离毒品”戒毒专题讲座。

讲座介绍了常见毒品的种类及特性、吸毒的原因，并运用震憾的视频向同学们展示了毒品的危害。

据同学反映，讲座深深地震憾了他们的心灵，让他们更加认识到毒品的危害，坚定了抵制毒品诱惑的信念。

据悉，鸦片战争博物馆是我院思想政治理论课教学部社会实践基地，曾于上周在我院开展了为期一周的戒毒专题图片展。
