# 【服务东莞·创新发展】学院召开党委扩大会议专题研究“服务东莞、创新发展”主题学习讨论活动

为了认真贯彻落实东莞理工学院党委关于开展“服务东莞、创新发展”主题学习讨论活动的通知精神，7月2日，学院召开党委扩大会议，专题研究部署我院学习讨论活动。

与会人员认真学习了袁宝成市长的经济形势报告，理工学院党委书记成洪波的动员报告，以及东莞理工学院党委关于开展“服务东莞、创新发展”主题学习讨论活动的通知，并结合城市学院工作实际，提出了贯彻落实的意见。会议决定，成立以院长杨敏林、党委书记朱志德为组长的学习活动领导小组及其工作机构。要求有关部门迅速起草和下发开展学习讨论活动的文件，对学习讨论活动的指导思想、讨论内容、实施步骤及工作要求提出具体的意见与安排。定于7月5日召开全院教职工大会进行全面动员。

会议要求，各级党组织和全体教职工，在主题学习活动中一定要提高认识，明确意义，认真组织，联系实际，积极创新活动内容和形式，扎实有效学习讨论和整改，不走过场，不搞形式主义，通过学习活动进一步提高学院的教育教学质量。
