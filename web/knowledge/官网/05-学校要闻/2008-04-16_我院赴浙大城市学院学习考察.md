# 我院赴浙大城市学院学习考察

4月14日，学院党委书记朱志德副研究员一行10人赴浙江大学城市学院考察访问。参加考察的成员有：学生处处长章德胜副教授，教务处处长邓成良教授，图书信息中心主任钟兴恭教授，党委宣传部部长何鹏举副教授，财务办公室主任黄甜源等相关部门负责人。

考察团受到浙大城市学院院长王立人教授、党委书记胡礼祥教授的热情接待。胡礼祥教授介绍了浙大城市学院的总体情况，王立人院长与朱书记就独立学院的发展，特别是教育部26号令对独立学院的影响及应对措施、发展方向交换了意见。

朱书记指出，浙大城市学院是中国独立学院的领航者，很多经验值得我们借鉴与学习，今后学院将派出更多的干部与老师去参观学习。王院长表示，双方应加强联系，相互学习，共同进步。

双方相关部门还进行了对口交流学习。
