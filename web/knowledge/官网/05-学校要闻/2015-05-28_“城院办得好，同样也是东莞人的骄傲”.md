# “城院办得好，同样也是东莞人的骄傲”

5月27日，我院邀请东莞市中学校长召开座谈会，就我院的发展与人才培养等方面征求意见和建议。这是我院召开第三次举办中学校长座谈会。虎门中学、东华高级中学、光明中学、实验中学、第五高级中学等17所中学校领导，以及特邀嘉宾东莞市星宇高分子材料有限公司董事长赖淦荷参加了座谈会。学院领导杨敏林、章德胜、高香林、黄兢、周庆、刘玉侠、麦绮琳到会听取校长们的意见与建议。

会上，党委副书记章德胜就我院近一年的重点工作作了回顾与总结，并对去年座谈会上校长们所提建议的落实情况进行了通报。

校长们对一年来我院在学科专业建设、招生就业、国际交流合作、应用型人才培养模式改革、机制体制改革协同创新等方面取得的成绩表示赞赏。第五高级中学叶照伦校长感触颇深地说：“城院办学质量提升很快，城院办得好，同样也是东莞人的骄傲”。

在座谈中，校长们对我院工作提出了许多宝贵的意见和建议。他们认为，应加大招生宣传力度，对专业介绍要详实、易懂，明晰对口就业岗位；充分利用新媒体，运用考生和家长喜闻乐见的视频形式进行宣传，让更多的人认识、了解城院；切实加强国际交流与合作，为更多的学生提供出国学习机会；做好大学生职业规划和就业指导工作，加强学生职业道德教育；与中学加强师生互动交流，把城院风采带到中学去，让中学生了解城院。

杨敏林院长主持会议。他对校长们的建言献策表示衷心感谢，学院将认真落实各项建议，共同为东莞教育事业的发展作出新贡献。

会后，校长们还参观了校园。
