# 图书信息中心举办图书馆资源利用知识讲座

10月30日，图书信息中心在4#611室，举办图书馆资源利用知识首场讲座，图书信息中心主任陈伟研究馆员以“图书馆的昨天、今天与明天”为题，介绍了图书馆的起源与发展历程，然后以上海图书馆、中国国家图书馆以及宁波万里图书馆为例，介绍了现代图书馆的特点以及图书馆未来的发展趋势，结合现代图书馆的管理理念以及发展趋势，对城市学院新图书馆的构建和管理模式进行了展望。讲座紧凑而精炼，气氛凝重而热烈。

据了解，图书信息中心还将举办五场图书馆资源利用知识的培训讲座。
