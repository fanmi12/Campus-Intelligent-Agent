# 安少华院长：在新的人生阶段，实现新的成长，创造新的精彩

开班仪式现场

安少华院长：在新的人生阶段，实现新的成长，创造新的精彩。

“人生的精彩，在于不断的追求和成长。大学是人生重要的阶段，只有勤奋学习才能取得成功，实现人生的精彩！”9月8日，东莞理工学院莞城校区2011级新生骨干培训班，在我院图书信息大楼506室举行开班仪式，东莞理工学院副校长、城市学院院长安少华教授出席开班仪式，并为40多名新生骨干上了第一节培训课。

安院长说，今年东莞理工学院在原来招生计划外追加近千个招生计划，满足了广大上线考生特别是东莞考生就读东莞理工学院的愿望。新追加的近千名学生将在莞城校区就读一年，这一年里，你们将有机会体验到优质舒心的服务，共享城市学院丰富多彩的校园文化。同学们大多来自东莞本地，也是新生中的佼佼者，提前走进大学校园，提前接受大学文化的熏陶，希望你们在培训中培养团结合作、乐于奉献的精神，为新生入学提供优质服务，并勇于承担服务东莞、传承本土优良文化的义务。

安院长指出，高考成绩只能代表过去，不能说明未来。来到大学，大家又站在同一起跑线上，大学不同于中学，中学是老师追着学生走，大学是学生围着老师转。清华大学校长梅贻琦说过：“大学者，非有大楼之谓也，有大师之谓也。”他提出了“从游”这一生动的比喻，老师为大鱼，学生为小鱼，以教师的高尚品行来自然地引导学生，达到“不为而成”，才是高明的教育方法。所以，同学们要增强信心，培养自学能力，把握和利用好莞城校区提供的教育资源，勤奋学习，完善自我，在新的人生阶段，实现新的成长，创造新的精彩。

安院长最后强调，莞城校区位于市中心，周边环境比较复杂，也存在较多的诱惑，希望同学们要“hold住”，提高自我控制能力，自觉抵制不良诱惑，认真对待社交和网络，正确处理好学习与工作、学习与娱乐的关系，努力使自己成长为有利于社会的优秀人才。
