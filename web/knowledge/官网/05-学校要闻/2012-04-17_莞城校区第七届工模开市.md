# 莞城校区第七届工模开市

章德胜副书记宣布第七届工模开市

工模从不缺人气“小老板”卖力推销

我院第七届工商模拟市场于16日下午5点半在莞城校区第一饭堂广场前举行开幕仪式，管理系主任罗余才教授在开幕式上致辞，宣布莞城校区工模市场正式开市。院党委副书记章德胜、院督学陈丁堂、教务处处长邓成良、学生处副处长陈建新、院团委书记杜鹏举以及副书记罗文芳出席了开幕式并为本届工商模拟市场剪彩。

工商模拟市场是我院校园科技文化艺术节的重头戏之一。作为一个动手实践的活动平台，一直颇受校内外人士关注。本届工模结合了我院“一个学院，两个校区”的实际情况，以团队合作为主旨，确定了“携手经营，创业共赢”的主题。

美食摊位再拔高价头筹，新校区更胜旧校区

据管理系学生会副主席、本届工模委员会莞城校区副主任卢引璋同学介绍，莞城校区共设摊位103个，其中80个是学生摊位；新校区参与竞投的摊位共64个。摊位竞投会上最高叫价摊位依然“花落美食区”：莞城校区最高价摊位以1460元成交，新校区则达到1750元。但是同去年2200元的最高价记录相比，今年莞城校区的工模市场竞争并不是非常激烈。而在学院重心工作逐渐移往新校区的形势下，可以预见下个星期在新校区的工模将比老校区更为热闹。

新形势，新方案

在继承传统工模举办方式的基础上，本届工商模拟市场明显比往年有新的特色。

首先是在两个校区分开的形势下，确定了新老校区各设市场的新方案，但仍坚持了“合二为一”的主旨。即：开幕式在莞城校区举行，闭幕式则于本月26日在寮步校区举行，并由管理系团总支、学生会成员组成的“第七届工模市场管理委员会”统筹规划。其次，新增“优惠政策”与“最佳团队奖”，这也是考虑到“两个校区”的应对方案。最后，则是对“微博”这一影响力日益扩大的宣传渠道的合理利用，开设了工商模拟市场的专门微博。

据了解，如果连续下雨，工商模拟市场管理委员会将会根据实际情况决定延长摆摊时间。
