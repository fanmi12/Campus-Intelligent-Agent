# 教辅党总支、高职部党总支赴彭湃故居参观学习

5月21日，教辅党支部、高职部党总支组织党员赴海丰县参观中国第一个红色政权成立根据地、有“东方莫斯科”之称的——红宫、红场及彭湃故居。

教辅支部党员通过此次红色之旅的参观学习，追寻先烈足迹，缅怀革命家的光辉业绩，增进了党员间的了解与交流，并对今后扎实地开展工作，推进“创先争优”活动的开展具有很好的促进作用。

据介绍，红宫、红场位于汕尾市海丰县城，是全国重点文物保护单位和爱国主义教育基地。1927年12月1日，彭湃领导的农民革命运动在此召开5万人大会，庆祝中国第一个苏维埃革命政权海陆丰苏维埃政府成立。彭湃故居始建于清朝末期，彭湃同志于1896年10月22日诞生于此，并在这里度过了童年和青少年时代。1925年故居遭反动军阀焚毁。1986年，国家文物局拨款按原貌重建。
