# 喜讯！我校辩论队先后战胜华农、华师，斩获大赛冠军！

近日，由东莞市司法局长安分局、长安镇法学会、镇委人才办、共青团长安镇委员会主办，镇人社分局协办的长安镇第二届“奉法杯”政法院校辩论锦标赛决赛在长安镇图书馆文化学堂圆满落下帷幕。

我校辩论队先后战胜华南农业大学、华南师范大学辩论队最后获得冠军！

本次政法院校辩论锦标赛主要面向粤港澳大湾区及周边高校政法专业大学生，最终吸引了

华南理工大学、广州大学、华南农业大学、广东外语外贸大学、暨南大学珠海校区、华南师范大学法学院、广东工业大学、华南师范大学马克思主义学院、东莞理工学院法社学院、广东技术师范大学、广东金融学院、广州华立学院和东莞城市学院共13所大学（学院）派员组队参赛。

13支参

赛队伍通过线上线下形式，历经初赛、半决赛和决赛的激烈角逐，东莞城市学院校辩论队闯入决赛，对阵广州大学辩论队，奉献了精彩纷呈的法治文化盛宴。

参加本次比赛的队员有：张仕堃、朱子康、郝文杰、赵子怡、马瑞蔚，其中张仕堃同学获得2次单场最佳辩手，郝文杰同学获得2次单场最佳辩手，朱子康同学获得1次单场最佳辩手。

本次辩论赛的结果令人意外，这是校队第一次在这样高手云集的比赛中斩获冠军。去年校队在初赛就已惜败出局，今年初赛的积分战中排名也并不靠前，在8进4的淘汰赛中还对上了第一届奉法杯冠军队伍华南农业大学。

但校队依旧顶住压力，冷静应对，积极备赛，一路披荆斩棘，勇往直前，最终成功进入4强。

4强的对手华南师范大学法学院辩论队同样不容小觑，在只有一晚备赛时间的情况下，5位同学依旧积极备赛，充分准备，最终挺进决赛，在与广州大学辩论队这一知名辩论强队的对决中不落下风，最终

以一票之差险胜，获得了比赛的冠军。

一路走来，校队的比赛历程虽跌宕坎坷，但依旧一往直前，希望校队在今后的各类比赛中继续斩获佳绩。
