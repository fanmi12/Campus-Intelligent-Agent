# 东莞理工学院城市学院第二期学生公寓租赁协议签约

2005年8月5日，东莞理工学院城市学院与东莞市东升工贸有限公司签定协议，双方就学院第二期学生公寓的租赁和管理等达成一致。这为学院明年新生入学作了住房准备，也是学院快速发展的物质基础。今年学院学生数将达到五千人，住房将饱和。明年将达到八千人，新生住房必须提前准备，协议签约是当务之急。
