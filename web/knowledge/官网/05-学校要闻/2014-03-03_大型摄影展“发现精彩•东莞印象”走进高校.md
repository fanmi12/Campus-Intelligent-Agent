# 大型摄影展“发现精彩•东莞印象”走进高校

2月28日，由市委宣传部主办、东莞日报社承办的“东莞印象”微摄影展览在东莞理工学院城市学院展出。这个时代元素鲜明的主题一推出，无不吸引众人的目光。几天来，许多同学纷纷前来观看，纷纷称赞这是一次高水准的展览。

据了解，自2013年3月1日至10月31日，承办方东莞日报已征集了将近6000组作品，其中《吻别》、《小红豆的粤剧梦》等69部优秀作品脱颖而出。

有学生指出，这次微摄影大赛以灵活新鲜的方式出现，推动了更多优秀作品的诞生，在另一个层面上也呼吁大众倾心留意身边的风景与生活中不起眼的事物，都有自我的风采。其中，我院大学生摄影部部长何颖欣看后表示从该次摄影展中看到了摄影者们多角度捕捉的精彩事物、唯美的画面、角度别致的拍摄效果、虚实相衬的表达艺术、深刻的主题表达都值得我们学习与借鉴。更有13级摄影爱好者钟佩瑶同学在观看过后聊有感慨的谈到，这次摄影展以绝对的水平向外界展示出最美东莞的风采，将事物的动态美与静态美都把持有度捕捉下来，别出心裁的摄影主题更是让我深深感受到最美的东莞印象。参赛者以其独特的视角捕捉生活的点滴精彩，成了2013年最具魅力的东莞印象。跟随他们的镜头，我们将目光投射到东莞这个万象更新的城市，关注它的音容笑貌，感受到了东莞的时代脚步。
