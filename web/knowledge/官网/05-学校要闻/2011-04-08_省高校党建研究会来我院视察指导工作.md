# 省高校党建研究会来我院视察指导工作

4月8日，省高校党建研究会民办学院分会会长丁纪平一行7人来我院视察指导党建工作，受到学院党委书记朱志德、党委办公室主任王玉、党委宣传部部长何鹏举等的热情欢迎。

座谈会上，朱书记向来宾介绍了我院党建工作的情况。他说，我院的党建工作始终以服务教书育人为核心，在基层党组织建设、党员教育管理以及发挥党员先锋模范作用等方面做了大量的工作，取得了明显的效果，连续几年获得东莞市委和东莞理工学院党委授予的“先进基层党组织”称号。学院每年对各基层党组织进行民主考核和年终量化测评，促进了基层党建工作朝着制度化、规范化发展；制定“发展党员实施细则”，狠抓落实，严把学生党员质量关；组织学生党员和入党积极分子参加东莞市环境卫生大检查，服务东莞地方，发挥党员先锋模范作用。

丁会长充分肯定了我院的党建工作，认为城市学院机制灵活，党政领导班子团结进取，教师队伍稳定，工作成效明显。他希望我院以创先争优活动为抓手，进一步加强基层党组织建设，切实推动党建工作再上新台阶。

会后，丁会长一行在朱书记的陪同下参观了图书馆。
