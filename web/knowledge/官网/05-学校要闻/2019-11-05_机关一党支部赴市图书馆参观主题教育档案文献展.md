# 机关一党支部赴市图书馆参观主题教育档案文献展

为进一步开展革命传统教育，11月1日下午，机关一党支部组织党员干部赴东莞市图书馆参观“不忘初心、牢记使命”主题教育档案文献展。

“不忘初心、牢记使命”主题教育档案文献展以中国共产党团结带领人民取得革命、建设、改革、发展的辉煌成就为主线，分为“探求真理”“坚守初心”“勇担使命”“践行宗旨”“从严治党”等五个部分，精选约400件中央档案馆、广东省档案馆馆藏的珍贵档案和广东红色教育、改革开放实践方面的文献档案，生动展示中国共产党为中国人民谋幸福，为中华民族谋复兴的伟大历程。

通过参观展览以及重温入党誓词，大家认真学习贯彻习近平总书记关于学习党史、新中国史的重要论述，增强了“守初心、担使命”的思想自觉和行动自觉。
