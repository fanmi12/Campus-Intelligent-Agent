# 心心相连系团学，熠熠生辉耀财经——财经系三八节举行团学大联谊

3月8日，财经系团学成员在综合馆举行以“心心相连系团学，熠熠生辉耀财经”为主题的团学联谊活动。

即使阴云布满天空，也遮掩不了同学们参与活动的热情，早早来到综合馆等待活动的开始。辅导员杨军、黄静惠等老师也全程参与其中。黄静惠老师发表了开幕词。

全体团学干事分为六个小组，分别进行大冒险和馆内拓展活动。大冒险环节中，同学们在校园里搜索目标给饭堂阿姨和宿管阿姨送上妇女节的小心意。室内拓展活动也在干部的指引下很好地举行，欢乐的笑声弥漫在整个综合馆内。
