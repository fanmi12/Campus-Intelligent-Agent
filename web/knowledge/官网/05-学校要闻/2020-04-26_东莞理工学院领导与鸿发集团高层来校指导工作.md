# 东莞理工学院领导与鸿发集团高层来校指导工作

4月24日上午，我校举办双方东莞理工学院、广东鸿发投资集团有限公司领导一行，到我校调研指导疫情防控和安全稳定工作并召开座谈会。东莞理工学院党委书记成洪波、副书记吕琦元，广东鸿发投资集团有限公司董事长、城市学院董事会董事长麦照容，广东鸿发投资集团有限公司副总裁、学校董事黎建烨，董事长代表陈超群，学校校长王卫平、党委书记章德胜、副校长刘玉侠等出席了座谈会。

学校主要领导就学校党建引领、疫情防控、线上教学、师生春季返校安排、学校转设等方面的工作进行了汇报，并回答了领导们提出的有关问题。

成洪波书记在讲话中对我校疫情防控工作情况表示满意。成书记强调，上级教育主管部门高度重视高校的疫情防控工作，城市学院要贯彻落实好教育部、省教育厅、各级政府的工作要求，切实提高政治站位和思想认识，始终坚持党建引领疫情防控工作，充分发挥党组织的战斗堡垒作用和党员先锋模范带头作用，全面加强校园管理，做好校内师生生活服务保障，做好延迟开学期间学校网络教学各项工作，充分发挥城院优势，全力做好毕业生就业工作，提供精准帮扶，加强疫情防控健康知识宣讲和心理疏导，加强网络舆情监测引导，坚决打赢师生生命安全保卫战。

麦照容董事长在讲话中对学校疫情防控工作及取得的初步成果给予了充分赞扬。新冠肺炎疫情暴发后，学校领导带头、党员在前，辅导员班主任坚守、学生有为，麦照容董事长代表广东鸿发集团、代表城市学院董事会，向全体师生员工致以崇高的敬意和衷心的感谢。他表示，鸿发集团和学校董事会永远是学校最坚强的后盾，将全力支持学校的疫情防控工作，切实维护好广大师生利益，切实保障广大师生的生命安全和身体健康。麦照容董事长就学校前期的转设准备工作也给予了肯定，并表示鸿发集团将继续举全集团之力，全力支持城市学院的健康稳定发展，严格按照国家教育部和省教育厅的要求，认真做好转设工作。转设之后，鸿发集团将坚持公益办学、回馈社会的初心，继续加大办学投入，进一步提升教师待遇，为学子们提供更好的学习生活环境，依托城院这一摇篮，进一步拓展办学空间，努力实现“办一流大学、创百年名校”的办学目标，携手开创东莞理工学院城市学院改革发展新局面。

会后，麦照容董事长还与学校领导班子进行座谈，听取了学校近期工作运行情况汇报，勉励大家共克时艰，求真务实，锐意进取，凝聚工作合力，把工作谋在实处、把责任压到实处、把问题督在实处，坚决打赢疫情防控阻击战，全力做好学校转设工作。
