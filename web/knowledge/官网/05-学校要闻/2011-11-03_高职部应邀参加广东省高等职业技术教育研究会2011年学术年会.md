# 高职部应邀参加广东省高等职业技术教育研究会2011年学术年会

10月29日至31日，广东省高等职业技术教育研究会2011年学术年会在河源市举行。我院高职部黄研晖书记率该部教师参加了本次年会。

会议由河源职业技术学院承办，来自全省40多所高职院校的150多名院领导和教师代表参加了会议。会上，我院老师并就高职人才培养模式、在高职人才培养过程中如何加强实训等问题与代表们进行了交流。
