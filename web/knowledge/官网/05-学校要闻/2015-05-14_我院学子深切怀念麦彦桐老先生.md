# 我院学子深切怀念麦彦桐老先生

城市学院鸿发奖学金创立人麦彦桐老先生于5月7日不幸病逝。我院曾获得“麦彦桐奖助学金”的学生自发地聚集在学生活动中心217会议室，追思麦老先生对莘莘学子的深情关怀与无私资助，表达对麦老先生的无限怀念。

当天，天空阴沉，雨雾朦胧。会场哀乐低回，桌上摆放着麦彦桐先生的遗照，以及心形白蜡烛，同学们手持白纸花向麦老先生遗像深情三鞠躬。

接着，同学们发言回忆麦老先生生前尊师重教、扶贫帮困的感人善举，特别感恩他为城院学子设立了“麦彦桐奖助学金”、“麦彦桐励志助学金”，支持学生完成学业。

据了解，“麦彦桐奖助学金”于2011年设立。
