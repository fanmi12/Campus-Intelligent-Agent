# 我院开展学年度工作绩效考核与民主测评

6月28日，我院召开2017-2018学年度工作绩效考核与民主测评会议。

当天下午，对教学单位及其负责人召开了绩效考核民主测评大会。13个教学部门负责人根据绩效考核的指标和内容，分别汇报了本单位的特色工作、存在问题，以及下学年工作改进计划及工作部署。

学院民主测评团成员听取了各单位的绩效述职报告，并进行了公平、公正地评分与投票。教学单位教学管理人员列席了民主评测大会。

王卫平院长充分肯定了各单位本学年的工作成效，同时也要求各单位要多“走出去”，开阔视野，提升境界，努力促进院系（部）的进一步发展。
