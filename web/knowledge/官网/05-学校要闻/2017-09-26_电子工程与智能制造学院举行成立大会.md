# 电子工程与智能制造学院举行成立大会

9月25日下午，我院电子工程与智能制造学院成立大会暨第一次全体会议在3A118举行。院长、书记王卫平,党委副书记章德胜,院长助理林江龙出席了成立大会。

学院党委副书记章德胜宣读了《关于成立电子工程与智能制造学院及相关人员的任命通知》和《关于成立电子工程与智能制造学院党总支及相关人员职务任免的通知》。

电子工程与智能制造学院院长陈中政、党总支书记葛卫清在讲话中，表示有信心在学院的大力支持下，认真做好电子工程与智能制造学院的建设、相关专业建设与人才培养等各项工作。

王卫平院长对电子工程与智能制造学院的成立和老师们的加盟表示祝贺，希望全体教师在陈中政院长的带领下，齐心协力、克服困难、勇于创新，紧紧围绕我院本学年的重点工作，扎实开展各项工作，尤其是要加强人才培养，积极推进教学改革。

会上，陈中政院长与老师们进行了交流，同时提出了电子工程与智能制造学院的发展方向和特色。葛卫清书记对近期的主要工作进行了部署。
