# 社会实践出奇招  保险专业上“战场”

7月2号，金贸系成立了保险创业俱乐部，并与中国人寿保险东莞分公司、中国平安保险东莞分公司两大保险公司达成长期合作协议。保险创业俱乐部首批150多名成员来自保险专业及其他专业，他们分别组成中国平安班和中国人寿班，将于近日前往上述两大保险公司实习。

据悉，中国平安和中国人寿曾多次派出经理和培训讲师来金贸系培训学生，金贸系也组织老师多次前往公司商洽，并组织保险专业学生去公司参观学习，为正式组建保险创业俱乐部做了大量的铺垫工作。7月3日下午15：00，在六号教学楼二楼，中国人寿班和中国平安班的学生参加了开班仪式，并由中国平安和中国人寿两大保险公司派出精干讲师进行公司介绍和专业培训。仪式结束后，学生被分别派往中国平安与中国人寿保险公司继续接受培训，培训合格后立即进入保险公司一线实习，并成为保险公司的准员工。

保险公司负责人表示，参加此次实习的同学被视为准员工，以后毕业求职时将优先考虑录用。

金贸系主任米双红教授透露，金贸系保险创业俱乐部的创建有利于保险专业学科建设，保险创业俱乐部活动将延展到整个教学环节中，成为保险专业教学与实践的特色工作。金贸系保险创业俱乐部全部由学生自己组织和管理。本次假期实习同学将自动成为保险创业俱乐部的首批成员。

金贸系党总支书记龙卫洋博士说，此次活动是金贸系暑假社会实践活动的重点项目，旨在进一步加强理论与实践相结合，加强学生的实践动手能力，让学生过一个充实而有意义的暑假，并使保险俱乐部与东莞各大保险公司的联系和合作更加密切。
