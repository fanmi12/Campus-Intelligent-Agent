# 黄明健：篮球是我的另一个女朋友

“小学二三年级的时候，我就开始打篮球了。那时候，村里没有其他的什么好玩的东西。大家又都爱看NBA，所以我总是跟着村里的大哥哥们去玩篮球，那球比我人还大些。”谈到自己与篮球的初次接触，黄明健脸上写满喜悦。

黄明健在我院男篮已经待了三年。这三年里，他参加过广东省大学生篮球联赛、第九届大运会、市级联赛和上届东莞大学生篮球联赛。他坦言：“大学之前没有关于篮球的荣誉，虽然参加过村里篮球赛，但都是做‘篮领’，别人叫我怎么做就怎么做，不会打球。到大学进了学院篮球队，篮球就成了我生活的一部分。大一恰好参加了校运会，也是做篮领，跟着师兄一起打球。当时感觉师兄特别的厉害，很想上场打球，但是能力还没有达到，后来就特别认真地加强训练。”

在球队三年了，黄明健如今是名副其实的“老腊肉”，在团队中也发挥着举足轻重的作用，越来越多的同学开始注意到了他。“我现在的风格就是跑。跑动，我是跑跳型的。跟着我们‘球王’叶锐城打，他叫我怎么打就怎么打，他叫我跑我都不敢站着。我觉得要谈打球‘秘籍’的话，打篮球最重要的还是训练吧。要想把球打好就要训练，不断地去训练，不断地去努力，去提升自己。”

只要是比赛，就会有输赢。这也是比赛会有压力的原因。而对于这些压力，他坦言：“压力能让我在场上保持紧迫感。大家都说是比赛就会有输赢，但我就会想为什么赢方就不能是我们呢。”

有的人认为，把篮球打好，其实是很困难的事情。但黄明健觉得，“把简单的事情做好就是不简单。其实，打篮球有时候也挺简单的，就是投篮，然后就是跑动。只要你懂了之后，就挺简单的。但你要把它做好，就真的不简单了。像NBA，要做好就是真的很难。”

DUBA已经到了总决赛阶段。在这期间，黄明健不断地增加自己的训练，改变自己的打法，不断地去突破，努力让自己变成一个更加全面的球员。 “球队并肩作战这么久，大家也开始进入了疲劳期，希望大家能够坚持下去，把冠军拿下来。也感谢教练那么辛苦，像对待孩子一样对我们，我们不会让教练失望的。”

从开始只能当个篮领球员，到现在已是主力的黄明健，他付出了很多的努力，也收获了很多的成功。他说：“篮球就是我的女朋友。”也正是这种心态，让他一直在努力在坚持。小编也祝愿黄明健能和他篮球“女友”越走越远，创作更多的辉煌。
