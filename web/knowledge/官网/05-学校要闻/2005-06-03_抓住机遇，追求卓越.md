# 抓住机遇，追求卓越

2005年6月2日下午，城市学院召开中层干部会议。会议由朱志德书记主持，程发良副院长通报院董事会有关情况，安少华院长作了重要讲话。安院长的讲话突出城市学院创办的历史机遇，强调城市学院的特色及目标：城市学院是理工学院跨越式发展的结果，应依托东莞产业优势，融入东莞城市发展，服务东莞百姓需要，追求卓越，创办一流独立学院。同时安院长还对城市学院所面临的问题作了详细分析，安排了下一步工作。与会者也一起探讨城市学院的发展方向与细节问题，大家纷纷表示，这次会议思路清晰，鼓舞信心。
