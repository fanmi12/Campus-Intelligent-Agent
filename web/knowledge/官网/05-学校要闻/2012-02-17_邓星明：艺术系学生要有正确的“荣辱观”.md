# 邓星明：艺术系学生要有正确的“荣辱观”

2月16日，艺术系在新校区召开学风建设动员大会。系主任邓星明，党总支书记丘永辉、副书记罗文芳等老师及2011级全体学生出席会议。

会上邓主任从上学期期末考试成绩说起，点名表扬了绩突出的几位同学，鼓励同学们向他们学习，摒弃不良的作风，形成你追我赶的学习氛围。他还结合艺术系学生的特点，提出“以勤奋好学为荣，以懒惰散漫为耻；以遵纪守规为荣，以违纪犯规为耻；以积极上进为荣，以消极落后为耻；以勤俭克己为荣，以贪图安逸为耻”的口号，希望同学们以此为警言督促自己努力学习，为自己的未来奋斗。罗文芳副书记强调学生干部是学生中的“领头羊”，必须起到模范带头作用。

会后，2011级全体同学在印有“学风建设，从我做起，奋发图强，争创一流”的横幅上签名并写下誓言，表示从今天开始，好好学习，为自己的未来努力奋斗，为艺术系争光添彩。
