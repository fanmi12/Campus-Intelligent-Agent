# 教育部检查组来我院检查指导工作

11月27日，由教育部学生司组织、各省教育行政部门参加的检查小组莅临我院，对我院2007年的新生学籍电子注册及相关工作进行检查。检查小组成员是广东省教育厅高教处的李昶科长、四川省教育厅学生处的樊建华科长和中国民用航空飞行学院的李蓉处长。

教务处处长邓成良教授向检查小组汇报了我院的总体情况，以及学籍学历管理政策的执行情况，汇报了我院07年新生学籍电子注册工作的完成情况，并对检查小组提出的相关问题作了详细的解答。

检查小组实地考察我院整个学籍电子注册工作流程的操作以及运行，查看了我院新生学籍电子注册的各项数据，并对相关工作提出了宝贵的意见。

在朱冰副书记的陪同下，检查小组参观了我院的校园环境，并对学籍学历管理政策的宣传以及《高校学生获得学籍及毕业证书政策告知》的张贴等工作表示满意。
