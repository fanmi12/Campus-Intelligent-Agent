# 我院新增金融学、社会工作两个本科专业

近日，教育部公布了2010年度高等学校专业设置备案或审批结果，我院申报的金融学、社会工作本科专业获批准增设，至此我院共有本科专业21个。

据悉，金融学本科专业代码为020104，学制4年，授予学位门类为经济学。2010年全国有31所高校申报了金融学，11所高校获批准增设。我院金融学专业设于金融与贸易系。该系系主任米双红教授认为，在东莞这座最具活力的制造业城市，设置金融学本科专业能更好地为东莞金融人才的培养服务。

社会工作本科专业代码为030302，学制4年，授予学位门类为法学。我院社会工作专业设于政法系。该系系主任刘杰教授认为，我院社会工作专业人才培养致力于提升地区的社会管理与服务水平，该专业可以进一步提升学院服务东莞的能力。
