# 我院拟录取147名专插本上线考生

记者从有关方面了解到，城市学院2010年本科插班生考试上线人数激增，比计划招生增加47人（计划招生100人）。学院决定并经省教育厅同意，拟全部录取上线考生。其中，城市学院考生95人，占上线人数的64.63%。

据悉，5月5-6日，广东省考试院将对上线考生审核确认后，正式发出录取通知书。
