# 一师一课一品牌  正当花红果硕时

我院采取“一师一课一品牌”有力措施，打造品牌课程，较好较快地提高了教学质量。据统计，我院已拥有院级重点课程18门，达标课程2000多门。其中“思想道德与法律基础”、“环境保护与可持续发展”课程还被评为广东省精品课程。据悉，我院是全省独立学院中唯一拥有2门精品课程的学校。

我院创办于2004年6月，是按新机制运作的地方性三本独立学院，其中80%的学生是莞籍。随着东莞的快速崛起，以及学院声誉的扩大，我院学生规模呈几何状急剧扩大。办学当初，师资队伍一时不能适应学院的快速发展，曾一度出现一个老师讲授3至5门课程的现象。为改变这一现象，学院在教师中广泛开展了“一师一课一品牌”的创建活动。学院要求，每一位专任课教师上好一门主干课程，并将这一课程打造成院、系、教研室的品牌课程。品牌课程的教学方法、教案、课件、教学实践基地、教学效果等必须是先进的或一流的。

为了达到“一师一课一品牌”的目的，学院面向全国高薪招聘教师，较快地建设了一支年龄、职称、学历、学缘结构比较合理适应教学需要的师资队伍。据了解，连同校本部的兼课教师，基本达到上级教育行政部门规定的最优师生比例。同时，学院还定期举办中青年教师讲课比赛，遴选服务东莞讲席专家，评选城市学院教学名师，组织教师参加全国和广东省教育部门的业务培训班学习或者到国内外著名高校进修学习，引导教师在职攻读博士学位。

“一师一课一品牌”创建活动的开展，大大提高了教师的教学水平和教学质量，打造了一批品牌课程。计算机与信息科学系牛熠、廉玉忠教授根据课程的需要，组织学生参加全国和广东省的数学建模、电子设计竞赛，多次获得国家级和省级的一、二、三等奖。该课程还与“新东方”建立了转换关系，吸引数千名学生主动选修“新东方”置换课程。我院广东省精品课程“思想道德与法律基础”授课人之一的思政部青年教师刘程雯，在广东省和粤桂琼等五省中青年教师思政课讲课比赛中，力挫群雄先后获得一、二等奖。财经系主任高香林教授将会计学课程讲义汇编成书，成为全国会计学精品教材，因此还获得5万元的奖励。政法系周巍博士结合讲课，成立了东莞市首家社工教学实践基地，即将获得市财政30万元的财政资助，副市长成洪波亲临现场为“基地”揭牌。政法系副主任赵书山副教授的行政管理学深受学生喜爱，学院运用他的一技之长，让他担任考研班的班主任。考研班的学生在他的组织和辅导下，考研成绩一年比一年好。

刘杰、危兆宾、王锦锋、王彩申、龙卫洋、李洪超、葛卫清、郭忠林、彭义春等老师教育的学生，成绩优秀，毕业后工作成效显著。2008年，我院学生全国司法考试通过率，位居东莞市参考单位之首。学生李苏杰、赵晋宜在2012年全国硕士招生考试中，初试成绩位居暨南大学法学专业、中山大学哲学专业全国考生中的第一、二名，我院已连续三年取得这样好的成绩。校友于佩今年从华南师范大学硕士生毕业后，又考取了美国南卫理公会大学的博士生，成为我院第一位留美博士生。
