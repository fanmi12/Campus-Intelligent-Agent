# 2012教职工排球赛圆满落幕

11月20日，我院2012教职工排球赛在排球场圆满落下帷幕。院长杨敏林、副院长张林、党委副书记章德胜等领导为获得前四名的球队颁奖。

本次的比赛不仅使我院教职工的身体得到锻炼，更彰显了我院教职工团结合作、顽强拼搏的精神风貌。体育部凭借半专业的技术和良好的体能素质以3：0的成绩战胜机关一，夺得比赛的冠军宝座，机关一屈居亚军。比赛过程中，双方队员们在一次次的进攻与防守中配合默契，或扣，或挡，或传，充分发挥了团队协作精神与努力拼搏的精神，把一幕幕精彩的的画面呈现给现场的观众，现场不时响起一阵阵热烈的欢呼声和加油声。第三、第四名的争夺战也激烈异常，最终计信系以3：1击败机关二，夺得本次比赛的季军，机关二位列第四名。
