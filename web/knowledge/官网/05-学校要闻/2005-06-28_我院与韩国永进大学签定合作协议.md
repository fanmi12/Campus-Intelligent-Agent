# 我院与韩国永进大学签定合作协议

（新闻中心通讯）今天（6月28日）韩国永进大学光临我院参观并与我院签定协议成为合作伙伴。早上9点30分，我院程发良副院长与韩国永进大学崔教授、郑教授在学院会议室会面并做了自我介绍，通过交流了解两院校的发展状况，增强合作意义。

会议上，程副院长介绍，我院现是国家本科独立学院，共有2242名在校生，而下一年将招收本科1300人，专科1800人，到2006年学生人数将会达到5000多人。而韩国永进大学现在已经有7126名学生，与我院相似的，都注重对理工类学生的培养。所以，两校有合作的基础。

会后，在我院领导热情引导下，韩国友人依次参观了我院的金工实验中心、计算机实验楼、化学生物系实验楼、食堂、活动中心等校园各处。他们对我院的教学设备非常满意，更加强了与我院合力办学的信心。

两院跨国合作能够促进学术交流，提高教学质量，希望通过合作能够培养出更多对社会有贡献的人才。

（实习记者 邹汉光 余晓蕾）
