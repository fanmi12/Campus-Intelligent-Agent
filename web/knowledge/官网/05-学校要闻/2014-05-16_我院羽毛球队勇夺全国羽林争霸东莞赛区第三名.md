# 我院羽毛球队勇夺全国羽林争霸东莞赛区第三名

3月22日，2014年全国“羽林争霸”羽毛球东莞赛区在东莞理工学院松山湖校区举行，我院派出三支队伍夺得三、四名。

据悉，“羽林争霸”大赛已覆盖全国30个省区市、195个地级以上城市，共有参赛队伍8500支、6万人参赛。

5月12日，由陈伟聪、谈泽雨、蓝志颖三位同学所带领的三支代表队，在赛场上力压广东医学院、广东科技学院、东莞南博职业技术学院，以及各羽毛球俱乐部，挺进八强。

最终，城院代表队一队、二队以大比分4：1 和 4:0领先广医一队和广医二队夺得三、四名。
