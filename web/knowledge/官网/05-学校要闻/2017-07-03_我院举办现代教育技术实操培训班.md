# 我院举办现代教育技术实操培训班

7月1日-2日，学院教师发展中心在7B201举办微课、MOOC、SPOC制作技术实操培训班，邀请了北京大学教育学院教授、博士生导师赵国栋为教师现代教育技术培训传授技术。学院重点课程建设项目、精品资源课建设项目负责人及自愿参与学习的老师共130人参加了培训学习。

开班典礼上，刘玉侠副院长作了讲话。她表示，这次现代教育技术专场培训受到学院领导的高度重视与大力支持，也衷心感谢北京大学博士生导师赵国栋教授及其团队到学院开展本次培训工作；她希望各位参加培训的老师刻苦学习，努力掌握现代教育技术的相关理论以及制作技巧，并应用到实际教学工作当中。

赵国栋教授首先以“从微课、翻转课堂到云课堂教学法概念与技术”为主题作了专题报告，阐述当代教育信息化对高校教学改革的深渊影响。在两天的培训期间，赵教授及其技术支持团队重点介绍“快课技术”，亲自演示、设计不同新型课件，对课程制作技术进行深入详细的讲解，包括对制作过程各阶段的应用技术进行拆分讲解、制作软件示范演练、现场指导教师录制微课等。

经过两天深度学习和实操演练，老师们都已基本掌握了微课的制作技巧，培训效果显著，切实提升了教师们的信息化教学水平。
