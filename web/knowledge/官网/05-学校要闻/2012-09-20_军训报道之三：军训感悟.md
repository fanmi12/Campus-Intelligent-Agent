# 军训报道之三：军训感悟

军训第一天

十八连 温婉莹

军训之前，我曾是满腔热血，迫不及待地想亲身体验大学的军训生活。经过一天的训练我深深地感到军训有苦也有乐，并能从中学习到无数有益的东西。

果然被学哥学姐所言中，“若是军训，必是晴天。”从8点集合开始，火热的太阳便吸引着我们大一新生的精华。在帅气教官嘹亮的口令下：稍息、立定、跨立、集合解散、整齐报数，动作做了一遍又一遍。军训中也不乏乐趣，当教官喊着“向左转”或“向右转”，有的同学左右不分转错时，便会惹来一片狂笑，被教官严厉批评后，我们便开始忍笑，还差点忍到内伤。

教官也有可爱的时候，比如当我们立正或摆手的位置不对时，他就会说：“姑娘，请把你的玉手……”看到我们的汗水一滴滴地流下时，他也不忍心看到我们这么累，马上让我们放松下来休息。教官真是太惹人喜爱了，坚强的外表下也有温柔的一面。

军训，首先教会我什么叫严肃，什么叫纪律，什么叫集体。这些点点滴滴都会让我们成长。军训，让我懂得太多、太多……

军训一阵子 享用一辈子

十四连 骆运磊

如果说人生是一本书，那么军训的生活便是书中最精彩的一页；如果说人生是一台戏，那么军训的生活便是戏中最吸引人的一幕。

今天开始了军训的第四天，自我感觉良好，就是天气有点热，顶着太阳站了一天军姿。

军训，如梦一般的开始。几天下来，我们学到的不仅是站军姿，走正步，练队形，更是强化了我们的一种意识，一种吃苦的意识，一种坚持的意识，一种团结的意识，一种遵守法纪的意识！其实这些已经太多太多，足以让我们一生享用。
