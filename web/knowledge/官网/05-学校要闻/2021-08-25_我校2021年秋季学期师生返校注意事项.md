# 我校2021年秋季学期师生返校注意事项

根据《东莞市2021年秋季学期开学前后学校疫情防控工作方案》以及《东莞理工学院城市学院2021年秋季学期师生返校工作方案》，我校学生返校安排细化如下：备注：具体返校名单和批次由各学院通知，继续教育学院学生由继续教育学院学工另行通知。

学生返校需要提前做好两件事，即【健康上报】、【学生返校申请】，具体要求如下：坚持居家隔离 并完成【健康上报】：2018-2020级学生（含专升本新生）返校前需要通过企业微信【健康上报】栏完成连续14天以上的健康打卡记录，2021级新生通过易班APP入学迎新栏完成健康打卡。原则上，如果出现连续3天以上未打卡的，将延迟返校。PS.健康打卡记录怎么截图，2018-2020级学生（含专升本新生）由辅导员后台查询学生打卡记录，筛查未规范完成健康打卡名单。2021级新生本人可以操作：下拉页面把名字放在顶格，点击查看打卡记录，截图即可，多页的下拉打卡记录分别截图。

提交【学生返校申请】：符合返校条件学生需要至少提前2天提交【学生返校申请】，按要求如实填写个人基本信息，上传当天【粤康码】截图、【防疫行程卡】截图和连续14天+健康打卡记录截图。注：请按自己所属的批次按时返校，如无法按规定时间返校的需要提前按规定提交请假申请。

（一）返校途中注意事项

1. 做好个人健康防护，记得全程正确佩戴口罩，避免在人员密集的地方逗留，避免经停疫情中高风险地区；

2. 妥善保存出行票据信息，以配合可能的相关密切接触者调查。

3. 一旦出现发热、咳嗽等症状，及时就医并第一时间报告辅导员、班主任。

（二）进校注意事项

1. 所有学生通过学校正门进入校园，接送车辆和送行人员请留步；

2. 到达校门口请提前打开企业微信返校审批通过界面和粤康码、行程卡，经门卫查验后后方可入校。

3. 积极配合门卫工作人员测温、行李消毒等工作；

4. 如有出现不适，需积极配合工作人员做好隔离工作。

（三）返校后注意事项当好

1. 根据疫情防控要求，所有省外返校学生需要落实三天两检，所有市外学生返校需要一次核酸任务。

2. 坚持每日健康上报，如实上报个人健康信息，当好自己健康第一责任人！

3. 积极参与爱国卫生运动，做好宿舍卫生清洁工作；自觉做好文明行动，不做“翻围墙进出校园”等违反学校规定的事情；

4. 学生返校后，严格校园出入管控，实行离校审批制度，除身体疾病等原因，学生不可离开校园；

5. 如若出现身体不适或粤康码黄码或红码的，须第一时间主动报备给辅导员、班主任。

（一）哪些人（重点人员）暂不返校：目前尚在境外地区、高风险地区及所在市、县（区）、中风险地区和重点关注地区的学生暂不返校，待所在地区降为低风险地区后再申请返校。

（二）能否提前返校：根据最新疫情防控政策要求，部分学生需要落实三天两检任务，为此请所有学生务必按照自己所属的返校日期返校。

（三）预订不到车票怎么办？个别学生返校交通安排确有不便的，由学生本人根据各自实际做好安排，并提前报告给辅导员，自行做好课程请假等安排，返校后积极配合落实三天两检和隔离措施。

（四）返校后能否离开校园：根据属地疫情防控要求，开学后要加强校园出入管控，实行离校审批制度，原则上，开学后前两周，所有学生不得离开校园，确因身体疾病等原因需要离校的，提交离校审批，经辅导员审批通过后方可离校。后续根据疫情形势和最新疫情防控政策适时调整。

（五）三天两检和一次核酸如何落实：“三天两检”是指在返莞后三天(72小时)内进行两次核酸检测，且两次核酸检测间隔24小时；一次核酸检测是指返莞后48小时内进行一次核酸检测。东莞市目前各大车站、高铁站有设置免费核酸检测，有需要的同学返莞后可以检测，开学后学校也会邀请医院进校集中开展核酸检测（具体安排另行通知）。

（六）重点人员开学怎么上课：目前学校前期排查发现我校重点人员尚不多，教务处已经做了统一部署，会安排任课教师通过多种渠道和方式方便延迟返校学生居家学习。请这部分同学安心居家，做好个人防护！
