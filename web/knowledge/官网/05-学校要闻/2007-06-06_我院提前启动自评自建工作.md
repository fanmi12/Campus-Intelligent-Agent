# 我院提前启动自评自建工作

为做好迎接教育部对普通高等学校独立学院教育工作的合格评估，学院于6月1日

在315会议室召开迎评工作动员大会，安排部署自评自建工作。会议希望全院教职员工以此为契机，全面提升办学品位，改善教学软硬条件，促进教育质量和教学水平的提高。

院督学林世俊教授在动员报告中指出，近两年，教育部将组织专家对我院教育工作进行合格评估。今年下半年，全国评估工作将在个别独立学院进行试点。教育部制定的评估体系（第六稿）中有6个一级指标，19个二级指标，41个主要观测点，评估结论分为“合格”与“不合格”。

会议认为，教育部开展的教育工作合格评估，这将是对我院教育教学工作的一次全面检阅，既是对我院发展的一次重大挑战，同时也是一次难得的机遇。通过评估，可以促进我院教育工作，拓展办学空间，提高可持续发展的竞争力；可以全面总结办学经验，找出存在的问题，理清工作思路，推动学院又好又快发展。因此，评估对学院创建成省内一流独立本科学院极为重要。

会议强调，全院师生员工要牢固树立“以评促建、以评促改、以评促管、评建结合、重在建设”的指导思想，充分认识自评自建工作的重要性，深刻理解自评自建阶段对我院发展的重要影响和意义。要未雨绸缪，提早启动自评自建工作。把评估方案中的指标体系作为“教科书”、“参照系”，深入学习，全面理解体系的精神实质。把评建工作与日常工作融为一体，着力攻克薄弱环节，增加对设施建设的投入。做好资料收集和文件归档工作。学院决定，投入1亿元资金，建设图书信息大楼和实验室等工程，进一步改善办学条件。在下个学期适当的时候，学院将成立评估工作办公室，院内各单位也要相应成立迎评工作班子，专抓迎评工作。全院教职工要做好迎评工作，以最佳的精神状态，扎实的工作成果迎接评估专家组的到来。

东莞理工学院教务处副处长

陈想平教授介绍东莞理工学院的迎评经验。学院高教研究与评估中心邢镇容教授解读“独立学院教育工作合格评估方案”指标体系的内容及其内涵。

东莞理工学院副院长、城市学院院长

安少华教授到会并作重要讲话。

学院副院长程发良教授主持会议，院领导及各系正、副主任，主任助理，教研室主任，教学秘书，院机关各处、室负责人，副科级以上管理干部共90人参加了会议。
