# 喜讯！我校女子排球队勇夺省大学生联赛冠军

近日传来喜讯，在2020年广东省第十届大学生排球联赛（甲组）上，由主教练张涛副教授以及侯城林老师带领的我校女排队获得女子甲组冠军。

11月14日-19日开始，由广东省教育厅主办，开平文化体育局承办的广东省第十届大学生排球联赛（甲组）在开平市体育中心举行。此次比赛，共有40多支球队参加，比赛共分为甲组（普通本科大学生运动队)、乙组(高水平运动员代表队）和丙组（专科院校代表队)三组，经过激烈角逐，我校女子排球队获得女子甲组冠军，这是我校女子排球取得的一个突破。

在小组赛上，我校与东莞理工学院、广东培正学院、暨南大学等高校被分配到一组，共同争取前两名出线名额。在第一场的比赛中，我校对阵东莞理工学院，以2比0的大比分取得胜利，第二场又以2比0完胜广东培正学院，在小组赛最后的一场1：2负于暨南大学，以小组第二出线。

在八进四比赛上，我校队员们迅速调整好状态，及时总结，以3比0的成绩完胜电子科技大学中山学院。

半决赛上，我校再次与暨南大学队相遇，虽然在小组赛上曾经输给对手，但在我校教练员在针对对方以进攻为主的特点，制定出稳扎稳打的风格，一分一分的咬着牙打，1：0取得领先，对方攻击更加凶猛，在激烈的比赛对抗中，两名主力队员郭雅洁、祝韻蕊在比赛中受伤，但两名队员带伤坚持比赛，又拿下一场，2：0，最后对方的心态完全被我校这种稳扎稳打、一分一分死抠的战术扰乱，最后3：0取得半决赛的获胜，进入到冠亚军争夺赛

决赛对手华南农业大学，被公认为赛前夺冠热门，他们平均身高在175厘米以上，比我校女排高近10厘米，曾取得过辉煌的战绩。赛前，教练组通过研究对方以往比赛的录像，制定出相应对策。鼓励女队放手去拼博，不要有思想包袱。狭路相逢勇者胜，在比赛场上，我校女排队员们，敢打敢拼，沉着迎战，打吊结合，紧咬比分，比赛一直处于焦灼状态，双方势均力敌，难分伯仲。在第一场的关键时刻，主教练张涛总是以近乎嘶哑喊声给女排队员加油，虽然女排队员带伤比赛，靠顽强的意志品质，最终以3比0赢得冠军。

赛后，主教练张涛副教授说，这次女排比赛虽然取得了冠军，赢得比赛并没有什么诀窍，一方面是女排队伍员日复一日的坚持训练，每个晚上还有周末，学三排球场都留下了队员训练的汗水，另外一方面，也是学校以及体育部老师的支持分不开，冠军是共同努力的成果。

张涛教练还说，通过比赛中，我们还加强了与各高校的交流，比赛有胜负，输赢无定数，以球会友，与其他兄弟院校也建议了深厚的友谊。

此次我校女排在省大学生排球联赛获得冠军，极大的增强了我校女排的信心和集体荣誉感，发扬了“女排精神”，展现了我校排球运动员积极向上的精神面貌和独特风采，以一份亮丽的成绩，向学校第三次党代会献礼。
