# 我院学子获全国大学生机械创新设计广东赛区一等奖

5月8日，第七届全国机械创新设计大赛（广东赛区）选拔赛在韶关学院举行。在“大众创新、万众创业”的主旋律下，我院机电系总共派出5支队伍参与比赛，共有3支队伍获奖，展示了我院在创新型人才培养中的成果。其中由学生陈清文、练家和、我院机电系劳锦豪、吴国茂组队（指导老师张锦荣、罗彦琦）的“自动分币装置”获得一等奖，并获得参加全国比赛的资格；由学生朱锦校 、陈清文组队（指导老师张锦荣、赵天婵）的“自动仓储装置”获得二等奖；由学生张展华、蓝少威、陈俊标、黎嘉涛组队（指导老师谭海欧）的“可升降物流车”获得三等奖。 据悉，全国大学生机械创新设计大赛是教育部、财政部批准和资助的全国性大学生学科竞赛，是国内最具影响力、培养学生工程实践能力和综合素质的大学生竞赛项目之一。本次广东赛区选拔赛，共有167项参赛作品、600名师生参赛，其中获得一等奖的16项获奖作品将参加7月20日举行的第七届全国机械创新设计大赛。
