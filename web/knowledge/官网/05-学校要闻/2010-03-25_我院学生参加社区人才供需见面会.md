# 我院学生参加社区人才供需见面会

3月24日，我院机电工程系20名毕业生，赴罗沙社区参加人才供需见面会。罗沙社区党支部书记翟俊，和顺建材商行总经理钟乐茹接见了我院师生。

见面会上，钟总经理带领同学们参观了公司，介绍公司的产品及发展概况，讲述自己的创业经历和创业感悟。她指出，公司用人主要是看重人的品质，“态度决定一切”。

应聘该公司绘图员岗位的同学，积极向公司的设计师学习取经，进行初步的现场面试。

据悉，罗沙社区及和顺建材商行对本次人才供需见面会给予了大力的支持和配合，提供专车接送师生，并表示将根据学生的意愿选择工作地点。
