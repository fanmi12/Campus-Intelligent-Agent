# 【服务东莞·创新发展】城环系：“服务东莞、创新发展”要结合教学工作进行

7月6日，系主任肖红飞教授主持召开城环系“服务东莞、创新发展”主题学习讨论活动动员会。党委书记朱志德莅临指导。

与会人员认真学习了相关文件和资料，以及成洪波书记在东莞理工学院“服务东莞、创新发展”学习讨论活动动员大会上的讲话。专任教师就资源环境与城乡规划管理和安全工程两个本科专业如何在“服务东莞、创新发展”活动中发挥各自优势进行了深入的研讨。

朱志德书记在讲话中强调，建设“六个东莞”是社会发展的需要，是市委市政府的工作重点，我们要全身心地参与，并为此作出应有的贡献。要通过“服务东莞、创新发展”主题系列活动的开展，加深对东莞的认识与了解，搞好教学工作，更好地服务东莞、服务城院。
