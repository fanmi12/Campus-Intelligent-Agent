# 总务后勤举办“迎新春联欢会”

1月18日，总务后勤400多名职工欢聚一堂，在荔香园4楼举办了“迎新春联欢会”，东莞理工学院城市学院王卫平、章德胜、黄兢、周庆等领导出席了联欢会，并为先进个人颁奖。

职工们还用精心准备的文艺节目祝福新春。饮食服务中心的开场舞《张灯结彩》拉开了联欢会的序幕，公寓服务中心的歌伴舞《鸿雁》、《小苹果》翩若惊鸿，美不胜收，充满灵动气息的《压力大》，引起了大家的共鸣。翟耀明处长、陈辉副处长、柳成荫副处长也即兴演唱歌曲为大家助兴，为大家送上新春的祝福，会间还穿插了2个互动游戏，吸引台下观众热情参与。
