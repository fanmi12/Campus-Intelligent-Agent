# 我院与加拿大昆特仑理工大学签署合作框架协议

3月24日，加拿大昆特仑理工大学一行三人再次到访我院，学院党委副书记章德胜、副院长高香林、院长助理麦绮琳亲切会见了来访客人，并进行了合作洽谈。我院的优美环境及办学以来的发展速度获得了来访客人的一致赞赏。

双方就两校学分互认、交流合作计划、互派考察团交流访问等问题进行了讨论，章德胜副书记认为两校合作可以分享相互的教学资源，开拓国际视野。双方洽谈气氛热烈，共同表达了建立良好合作关系的愿望。最后，高香林副院长代表签署了我院与加拿大昆特仑理工大学的合作框架协议。

据悉，昆特仑理工大学(Kwantlen Polytechnic University)建于1981年，在温哥华地区拥有四个校园是加拿大最大的公立大学，每年录取23000名学生。昆特仑理工大学提供超过140门课程的学士学位、副学位、文凭及证书。学校设有超过135种课程供学生选择，昆特仑理工大学的商学院获美国商学院联盟(ACBSP)认可，是加拿大最大的商学院之一。
