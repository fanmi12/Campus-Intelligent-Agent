# 共建校园网络   提升信息化水平

7月2日, 东莞理工学院城市学院与中国电信东莞城区分公司举行了城市学院校园网络建设签约仪式。城市学院院长安少华教授、学术副院长程发良教授、行政副院长张林博士和中国电信东莞分公司黄杰副总经理、余爱民副总经理、城区分公司齐军总经理出席了签约仪式。

签约仪式上，黄杰副总经理表示，保证按时按质圆满完成城市学院校园网络建设任务，并把城市学院校园网建设成高速、稳定、可持续发展的网络平台，使之成为各高校校园网的示范工程，全面提升城市学院的品牌形象。

城市学术副院长程发良教授和中国电信东莞分公司黄杰副总经理代表双方在仪式上签字。

仪式结束后，中国电信将正式向城市学院提供校园网组网服务。
