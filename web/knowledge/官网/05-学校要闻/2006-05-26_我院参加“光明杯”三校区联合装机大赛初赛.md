# 我院参加“光明杯”三校区联合装机大赛初赛

5月24日下午，由东莞理工学院计算机协会、广东医学院网络协会以及我院PCDIY协会共同打造的“光明杯”三校区联合装机大赛初赛在我院活动中心举行。

参加初赛的共有33支队伍，均按照规则采取一男一女搭配组队。一声令下，比赛正式开始，男队员负责装机，而女队员则要想方设法通过各种障碍和考验给男队员传送组装零件和工具。比赛采用计时制，完成装机耗时最少的队伍获胜。经过几轮的比赛，大赛决出最终名次，他们将代表城市学院参加决赛。具体如下：第一名：B&G （赵子贤 罗妙岚）

第二名：Machine （何政 李桂霞）

第三名：红魔头 （周应贺 王艳群）

道德风尚奖：砌砌整整 （叶永生 卢卓仪）

最合拍奖：尤敏 （罗伟荣 钟敏仪）

最具人气奖：V2 （黄国成 姜艳婷）

据悉，“光明杯”三校区联合装机大赛总决赛将于5月29日在城市学院大礼堂举行，三校区代表队将齐聚城院，一决高下。
