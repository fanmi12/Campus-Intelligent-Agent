# 我院第二个青年就业创业见习基地在台商子弟学校挂牌

10月29日，团委书记罗文芳带领团委干部、学生代表前往东莞市台商子弟学校生命力营地，举行城院青年就业创业见习基地签约、授牌仪式，受到台商子弟学校生命力营地教育中心主任许育彰、拓展教练龚明学的热情接待。

随后，双方就见习基地建设、见（实）习人员选派合作事项进行了交流座谈，达成了初步共识。

据悉，今年暑假期间，团委安排了一些在校大学生在台商子弟学校生命力营地实习，并与东莞市侨务局在此联合举办了2014年海外华裔青少年东莞夏令营拓展训练活动。
