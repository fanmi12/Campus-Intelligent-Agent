# 财经系获第六届“ 用友杯”全国大学生会计信息化技能大赛优秀奖

11月24日，工业和信息化部人才交流中心和用友新道科技有限公司共同举办的第六届“用友杯”全国大学生会计信息化技能大赛在广州城市职业学院举行。财经系肖珊老师带领袁沛仪、林真铨、张志伟、胡锦艺、邓映兰五位学生参加了本次竞赛，获得了“全国的优秀奖”和“广东省优秀奖”两个奖项。

本次竞赛采取以网络的形式，采用用友软件U872为平台，以考察学生对企业实际业务流程分析能力和信息处理能力为目的。比赛的主要内容有总账、报表、薪资管理、固定资产管理、应收应付管理、专家财务评估、供应链业务处理等。
