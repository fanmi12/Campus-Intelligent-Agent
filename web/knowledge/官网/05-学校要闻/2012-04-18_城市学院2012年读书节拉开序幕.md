# 城市学院2012年读书节拉开序幕

在“4．23”读书节期间，我院图书馆将举办“相约图书馆——参与?互动?共享”为主题的城市学院2012年读书节系列活动，该活动将在新老两个校区同时拉开序幕。

据悉，本次读书节系列活动将贯穿2012年全年，主要活动有：1、 “你好，图书馆——光影与文字之间” 图书馆摄影文字大赛；2、图书馆杯广东大学生英语口说大赛；3、图书馆毕业寄语“毕业墙留念”；4、资深学者专家讲座；5、数字资源宣传培训；6、“图书馆馆员知识技能竞赛”与“读者利用图书馆技能竞赛”等系列活动。这些活动旨在引领城院师生阅读学习的良好风气，促进优良学风校风形成，并引导同学了解地方文化，保护地方文化发展，加强图书馆与广大师生及地方社区的互动，丰富校园文化生活。
