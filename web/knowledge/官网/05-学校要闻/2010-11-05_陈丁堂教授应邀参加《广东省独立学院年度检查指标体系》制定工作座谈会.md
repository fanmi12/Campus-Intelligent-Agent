# 陈丁堂教授应邀参加《广东省独立学院年度检查指标体系》制定工作座谈会

11月4日，广东省教育厅组织的《广东省独立学院年度检查指标体系》制定工作座谈会在电子科技大学中山学院举行。院督学陈丁堂教授应邀参加了座谈会。

会议由省教育厅政策法规处副处长邵允振主持。省教育厅政策法规处处长黄爽在会上充分肯定了全省独立学院办学所取得的成绩，他对指标体系整体框架进行了介绍，并阐述了其制定依据、设计原则和主要内容。他希望通过这种自查自检的方式，能真正使各独立学院达到促建设、促改革和促发展的目的。

陈督学受安少华院长的委托，对《广东省独立学院年度检查指标体系》制定工作给予了充分肯定，同时也提出了一些具体的修改意见，所提意见被省教育厅采纳。
