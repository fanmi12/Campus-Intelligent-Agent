# 政法系召开专插本学生座谈会

9月27日，为了更真切了解本届专插本同学在学习生活中的所遇到的各种问题，为同学们营造更好的学习生活环境，政法系在7B102召开了2011级专插本学生座谈会。座谈会由系党总支副书记刘军老师主持。

刘军老师首先对成功专插本学生取得的成绩表示了祝贺，并希望大家在今后的两年中努力学习，争取顺利毕业并获得学位证书。刘老师还公布了班主任、辅导员、教学秘书的办公室地点和联系方式。座谈会中，专插本学生积极对学校教育教学工作建言献策，并如实反映自己在生活、学习等方面遇到的困惑，刘军副书记对同学们关注的问题给予较为详细的解答，对事涉及其他职能部门，无法现场回应的事情，他表示将及时反映沟通，并力促信息及时回馈。他也希望同学们能合理、理性地表达自己的声音和诉求，共建和谐美好城院。
