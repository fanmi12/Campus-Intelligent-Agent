# 我校在全省高校基层党组织党建工作创新案例评选中斩获佳绩

11月28日，省委教育工委公布了全省高校基层党建工作创新案例评选活动结果。我校党委的“全感知学习、全方位引领”获学校党委党建工作创新案例二等奖，创意设计学院党总支的“点燃党建红色引擎，助推师生成长发展”获基层党组织书记工作案例三等奖。

为深入学习贯彻习近平新时代中国特色社会主义思想，认真贯彻落实《广东省加强党的基层组织建设三年行动计划（2018-2020年）》，总结交流全省教育系统基层党组织党建工作的创新方法和成功经验，省委教育工委于今年8月初在全省教育系统开展了基层组织党建工作创新案例征集评选活动。

我校党委在全校组织开展“全感知学习、全方位引领”党建创新工程活动，充分调动广大党员干部和师生群众“听、说、读、写、看、做”的各种感知。开展了“信仰之声•书记读书日”领读活动、“弘扬爱国奋斗精神，建功立业新时代”师生微党团课比赛、《习近平的七年知青岁月》主题读书及征文活动（读与写）、“牢记时代使命，书写时代华章”学习进行时专题展览、红色主题专业实训课程等系列活动，充分运用媒体融合报道手段进行大力宣传和学习，调动了全校党员师生的积极性。既覆盖全体党员、做到党建带团建，又辐射全校2万多名师生，构建良好的校园文化氛围，实现党建全方位引领，推动学校事业又好又快发展。

创意设计学院党总支积极探索出在设计类专业课程中，将党的十九大精神润物细无声地传授给学生。结合专业特色，突出党的十九大报告中“坚定文化自信”的要求，将优秀传统文化，特别是红色传统文化与现实生活及工作中的相关因素实现有效结合，借助师生文创成果转化平台建设实现党的十九大精神的有机渗透，提升学生的思想政治素质。

此次获奖的创新案例充分展示了我校新时代党建工作的新做法、新成效，是我校夯实党建工作、提升党建质量的成果体现。
