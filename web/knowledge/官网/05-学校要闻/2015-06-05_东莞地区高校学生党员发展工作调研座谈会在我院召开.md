# 东莞地区高校学生党员发展工作调研座谈会在我院召开

6月4日上午，东莞地区高校学生党员发展工作调研座谈会在我院召开。省委教育工委组织处处长吴琦琳同志、副处长叶祝秋同志、主任科员任莉同志出席了会议，东莞理工学院、广东科技学院、东莞职业技术学院、广东创新科技职业学院、广东亚视演艺职业学院等六所高校党建工作的主要负责人参加了会议。

会议就东莞高校学生党员发展工作中的总体形势和具体问题进行了分析、交流。党委书记王卫平同志汇报了我院党建工作的总体情况和特色做法。

吴琦琳同志在会上作了重要指示。他指出，学生党员发展是高校党建工作的重要组成部分，必须加强。希望各高校切实重视党建工作，抓好学生党员发展工作，做到规范程序，严抓质量，培养好高质量的党员人才，为社会服务，同时要打造党建工作的品牌。

学院副院长、组织（统战）部部长黄兢同志参加了会议。
