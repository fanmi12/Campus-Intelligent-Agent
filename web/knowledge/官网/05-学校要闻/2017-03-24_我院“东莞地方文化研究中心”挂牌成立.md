# 我院“东莞地方文化研究中心”挂牌成立

3月23日下午，我院“东莞地方文化研究中心”成立挂牌仪式在文传系举行。

学院副院长黄兢和研究与发展规划处处长赵书山教授、图书信息中心副主任陈显龙、政法系黎诚博士、思政部石瑞丽博士，文传系主任宋秋敏教授、副主任陈跃、邓星明教授、谢友祥教授及教师代表，以及东莞地方文化研究中心主任贾静波博士参加了挂牌仪式。

贾静波主任作了《2015-2016年度研究中心工作汇报》，从东莞地方文化中心概况、工作开展情况、工作计划和展望等方面进行了汇报总结。

黄兢副院长讲话指出，东莞文化范畴很广，内容拓展空间大，希望中心积极探究其文化特色，为东莞地方文化的发展做出贡献。

仪式上，陈跃副主任和刘健老师还将合力整理的地方文化书籍《杜诗二字构辞类辑》

(莫任劬著)赠予东莞地方文化研究中心。
