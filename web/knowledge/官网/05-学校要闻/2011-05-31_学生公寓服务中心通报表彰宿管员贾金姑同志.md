# 学生公寓服务中心通报表彰宿管员贾金姑同志

近日，我院学生公寓服务中心做出决定，表彰奖励恪尽职守的宿管员贾金姑同志。

今年4月12日6时30分，两名可疑年轻女子形色匆匆混进了校内学五栋宿舍。正在值班的贾金姑同志发现后立即走上前要求她们出示证件，询问有何事找何人。两女子见状便想逃离现场。贾金姑拦住她们不许走出宿舍，并锁上大门，叫来110警察。

经警察询问，两女子系无业人员，准备趁学生未起床之机行窃。
