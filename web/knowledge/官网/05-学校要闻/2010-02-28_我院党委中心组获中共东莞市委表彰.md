# 我院党委中心组获中共东莞市委表彰

近日，中共东莞市委通报表彰了一批宣传思想工作先进单位、先进个人。我院党委中心组获得表彰，院党委宣传部部长何鹏举荣获2009年度党委（党组）优秀学习秘书。

一年来，学院党委紧密围绕中共中央和中共东莞市委的宣传工作部署，坚持以党的十七届四中全会精神和《纲要》精神为主线，切实联系学院发展实际，定期开展党委中心组学习讨论。全年举行了5次集中学习，编印了《<珠三角地区改革发展规划纲要>学习读本》、《十七届四中全会精神资料汇编》、《加强和改进新形势下党的建设》等学习资料读本，有效推动了党委中心组学习常规化制度化，统一了思想，取得了实效。
