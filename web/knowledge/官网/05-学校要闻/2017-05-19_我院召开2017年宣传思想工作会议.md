# 我院召开2017年宣传思想工作会议

5月19日下午，东莞理工学院城市学院2017年宣传思想工作会议，在行政楼112会议室顺利召开。学院全体院领导，各单位负责人、分管宣传工作负责人、宣传联络员，各党总支（直属支部）书记、副书记和党务工作部全体成员参加了会议。会议由学院党委副书记章德胜主持。

文学与传媒系等5个获得2016年度先进工作单位、管理系“工商模拟市场”等5个特色宣传工作、惠梦瑶等22位宣传工作先进个人，受大会的表彰和奖励。

党务工作部副部长叶凯贞同志作了《2016年宣传工作总结和2017年宣传工作思路》的报告。报告对学院2016年在政治理论学习、宣传报道工作等方面取得的经验和成绩，进行了总结。围绕学院中心工作，从加强思想政治引领、推进改革创新、；加强精神文明建设、加强学院宣传队伍和阵地建设、加大对外宣传力度等方面，对今年学院宣传思想工作作出了安排。

院长、书记王卫平在会上做了重要讲话。他对2016年学院在宣传工作上取得的成绩给予了充分肯定。王院长指出，宣传思想工作关系到意识形态建设、思想政治阵地建设、人才培养机制建设，是学院全局工作中的一项重要工作。在新形势下，就加强和改进我院宣传思想工作，王卫平院长提出了三点要求：第一，提高认识，明确要求，着力提高学院宣传思想工作的政治引领力；第二，加强领导，坚持立德树人，切实维护学校政治安全和意识形态安全；第三、必须增强阵地意识，讲述“城院好故事”，努力做好“人心”这篇大文章，凝聚人心永远在路上，凝聚人心靠大家。
