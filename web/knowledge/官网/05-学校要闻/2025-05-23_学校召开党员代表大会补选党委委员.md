# 学校召开党员代表大会补选党委委员

为进一步加强党委领导班子建设，提高党建工作水平，充分发挥学校事业发展中的党建引领作用，根据《中国共产党章程》和《中国共产党基层组织选举工作暂行条例》有关规定，经省委教育工委批准，5月22日下午，学校召开党员代表大会补选党委委员。会议由党委副书记、副校长李海冬主持，党员代表参加会议。

大会在庄严的国歌声中拉开帷幕。会议通过了总监票人、监票人名单，公布了计票人名单。全体党员代表以无记名投票方式对补选党委委员候选人进行差额选举。经当场计票，李振华、康贤刚、叶凯贞3名同志当选为东莞城市学院党委委员。

党委书记章德胜在会上对近年来党建工作成绩进行总结并表示充分的肯定。他指出，本次选举大会的顺利召开，是学校党委进一步加强党委领导班子建设、提高学校党建工作水平的重要举措。并对党委委员和党员代表们提出了希望，希望各位能继续发挥党员先锋模范作用，积极带动身边的同事，进一步巩固和扩大党建工作成果，为塑造立德树人新格局、实现学校高质量发展注入新的活力，开创学校党建工作和整体事业发展的新局面，为学校的长远发展贡献更大的力量。

会后新的党委班子合影留念并召开党委会，以无记名投票方式等额选举党委副书记，李振华、康贤刚当选为东莞城市学院党委副书记。
