# 王芳仪老师获2012广东省高校思政课青年教师教学基本功比赛一等奖

9月14、15日，广东省教育厅在广州举行了2012年广东省高校思想政治理论课青年教师教学基本功比赛总决赛，我院思想政治理论课教学部王芳仪老师参加了决赛，并喜获一等奖。

本次比赛共分学校初赛、省级复赛和省级总决赛三个阶段。经学校初赛，全省近130所高校的200多名思政课教师代表参加了省里的复赛，最终确定19名优秀教师进入总决赛，其中6人获得一等奖。在我院王芳仪老师等19位选手决赛时，现场有100多名来自全省各高校的新进思政课教师进行了教学观摩。王芳仪老师的授课以教学内容准确、教学思路清晰、教学语言精炼、教态自然大方、教学效果良好的综合表现赢得了评委的一致赞誉，也获得了在座观摩教师阵阵热烈的掌声。
