# “做人做事的第一要义是诚信”

11月2日下午，《与企业家面对面》——大学生就业创业沙龙第二期，在招聘大厅如期进行。东莞潇湘文化传播公司总经理、东莞比比印刷有限公司总经理、《潇湘文化》主编罗建云先生作为特邀嘉宾，与我院数百名大学生面对面分享了他的创业经验和创业心得。

罗建云结合自身经历，讲述了自己如何从一个来自农村、未读过大学的普通孩子蜕变成一个成功的创业者。他告知大家做人做事的第一要义是诚信，提醒大学生们不要盲目创业，要做自己喜欢的，要学会利用自己所拥有的优势来进行创业。

在分享环节，我院创业孵化基地创业学生及学生代表，分享了自己对于创新创业的观点和看法，台下同学们也就创新创业问题踊跃提问，现场氛围热烈。罗建云结合自身创业经验，详细解答了同学们在创业实际中遇到的各种问题，希望同学们有所感悟，找到属于自己的创新创业之路。

学院向罗建云颁发了“城市学院大学生就业创业导师”聘书，向东莞市潇湘文化传播有限公司授予了“城市学院大学生就业创业基地”牌匾。

当天，罗建云还向我院图书馆捐赠了一批精美图书。
