# 城市学院首届教职工篮球赛结束

11月17日，城市学院首届教职工篮球赛决赛在教工球场拉开战幕。经过激烈的拼杀，女子，机关队9：6战胜总务处。男子，总务处80：43战胜机关队。比赛结束后，观看比赛的学院党委书记朱志德、常务副院长程发良教授、副院长林世俊教授、党委副书记朱冰等为获奖球队颁发锦旗。

至此，我院首届教职工篮球赛圆满结束，各组名次如下：女子组

冠军：机关队

亚军：总务处

季军：计算机与信息科学系

男子组冠军：总务处

亚军：机关队

季军：财经系
