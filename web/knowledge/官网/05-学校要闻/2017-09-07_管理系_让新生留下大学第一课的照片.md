# 管理系:让新生留下大学第一课的照片

又是一年迎新报到，整个校园里都洋溢着浓厚热烈的迎新氛围。综合馆内，各院系都全力以赴为新生顺利入学提供周到的服务。

在“爆棚”的综合馆内，管理系迎新工作 “独树一帜”，引来了大家的关注。不少新生被定制的微信框成功“圈粉”，拿着自己的录取通知书和微信框合影拍照纪念。陈文丽老师告诉记者，“与微信框合影是为了让新生留下第一课的照片，同时也让其他师兄师姐能够回忆自己初到城院的报到时光。”（大学生记者 林伟棉）

你们的热情是新生最好的礼物

金秋九月，又是一年迎新季，城院迎来一张张朝气蓬勃的新面孔。

今天，虽阴天没有日晒，但依然有些闷热，拉着行李箱、扛着包的家长和新生们仍大汗淋漓。

“叔叔阿姨要不要喝水？这里免费提供饮用水哦！”随着从综合馆门前摊位传来的友好问候，校友会工作人员脸上洋溢着笑容，手里端着清凉的矿泉水赠给每一位有需求的家长和新生。原来，这里大大小小、瓶装或桶装的饮用水都是校友会出资为新生报到准备的。校友会还自制了精简版的“城院地图”作为礼物，为新生提供方便。

“这里不能停车”、“请往这边走”、“您是要去学八吗？”校道上，带着蓝色袖章、拿着旗子的交通指挥员耐心忙碌地疏导交通。来自院学生会勤工助学中心的阳同学表示，“我们主要负责指挥交通，防止校道交通堵塞，希望新生们有个愉快的开学日。”

在美丽的城院校园，忙碌的志愿者，为新生引路、搬行李、赠送小礼物，清洁阿姨不厌其烦的清洁地面；师兄师姐热情地为新生解答疑惑；保安叔叔认真负责地维持秩序…….你们的热情帮助，成为新同学们最贴心的入学礼。（大学生记者 崔飞虹）
