# 体育教学部总结成功举办校运会经验

城市学院2012年校运会成功举办，得到全院师生员工的一致认可，并获得院领导的充分肯定。运动会闭幕后，体育教学部组织全体教师座谈讨论，总结校运会的成功经验。

通过总结，他们认为，本次运动会得以圆满、顺利进行，凝结了教学部全体教师和各系部学生会体育部学生的辛勤汗水。其主要经验有四点：一是准备动手早。从本学期新生入学的第一周开始，体育部就进行了团体操的策划、设计、编排工作，多次进行专题论证，研究方案。方案确定后，组织了1400多名同学参加演练。二是周密组织，科学排练。体育部多次开会研究，精心布置，从教学的组织到课余时间的排练都进行了合理安排。三是加班加点，团结协作。团体操合排的时间都是安排在周末，体育部的教师连续四个周末加班加点工作，大家从没怨言。四是制定预案，确保圆满顺利精彩。今年运动会期间正赶下雨，尤其是校运会的第二天更是大雨倾盆，由于合理调度、科学安排，运动会照常进行，完成了所有的比赛项目。
