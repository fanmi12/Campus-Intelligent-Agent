# 全国政协委员李向玉教授受聘我校专家顾问并作专题讲座

5月13日，学校董事长麦照容先生向澳门理工大学李向玉教授颁发专家顾问聘书5月13日下午，我校新聘专家顾问、澳门理工大学李向玉教授莅临我校开展专题报告会，校领导、中层以上干部参加本次专题报告。执行校长李树英主持本次专题报告。

执行校长李树英对李向玉教授莅临我校指导表示热烈欢迎。李向玉教授现任澳门理工大学董事会主席，曾任澳门理工大学校长（1999-2018），第十一届、第十二届、第十三届全国政协委员。2019年，葡萄牙总统德索萨向李向玉教授颁发葡萄牙教育大勋章，嘉许他在教育事业及促进中葡文化交流等方面做出的贡献。他是中山大学历史学博士、里斯本大学荣誉博士、英国伦敦大学名誉教授，获澳门特别行政区政府2017 年度教育功绩勋章。专题报告开始前，李向玉教授向我校进行赠书，传授宝贵经验总结，执行校长李树英代表学校接受赠书。

李向玉教授对我校转设后的内涵发展、发展模式以及学校资源保障等方面给予充分肯定，以“不忘初心，牢记使命，努力不懈”为主题开展专题汇报。

李向玉教授回顾了澳门回归前后的个人工作履历，包括从担任澳门理工大学校长职务到当选全国政协委员。牢记政治协商、民主监督、参政议政的使命，履职尽责，作为港澳委员发挥双重积极作用。李向玉教授指出新时代发展是我国教育实现从教育大国到教育强国的重大契机，强调教育是强国的根本，是实现民族复兴伟大梦想的基础。

报告会上，李向玉教授还分享了在澳门理工大学任职校长二十年期间，致力于提升办学实力,改善学校管理的各项措施，高度重视教师队伍建设，鼓励与奖励教师读硕、读博；课程建设与祖国内地，甚至世界一流大学，即最高的学科标准比较对齐；要配合特区社会、经济发展需要，在专业建设、学术研究、师资共享、学生互换及国际会议等方面开展共建与探讨。

李向玉教授谈到东莞城市学院要打造成一所适合大湾区社会经济发展需要的、多学科的应用型大学，就要坚持改革，自立自强，走出具有中国特色的大学之路。

参会人员表示，李向玉教授扎根澳门理工大学建设，尽心尽力将澳门理工大学打造成大湾区著名高等学府，推动澳门高等教育发展，获得社会各界高度认可，对李向玉教授怀揣着一份对建设高等教育事业的执着、热情表示崇高的敬意；李向玉教授用实际行动诠释了“不忘初心，牢记使命，努力不懈”，激发了参与人员顽强拼搏、乐于奉献、敢于担当的精神。
