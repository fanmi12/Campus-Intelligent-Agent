# 春来实习忙 老师勤看望

新学期开学以来，管理系先后有318名大三学生、900名大二学生外出毕业实习和专业实习。为了及时了解和掌握学生的实习、生活情况，管理系定期组织老师到实习生比较集中的实习点看望同学们。

3月24日，管理系党总支书记徐中和教授、辅导员张宏渝、王成军老师及行政秘书陈成文老师一行四人，到东华物业上桥管理公司看望实习的学生，并详细了解了学生的实习情况。

3月25日，物流教研室主任张佺举教授、管理系党总支副书记吴春庚老师及李传国副教授、辅导员陈彬老师，冒着细雨到虎门镇华信物流有限公司看望实习学生。据了解，华信物流有限公司坐落在虎门镇北栅西坊工业区，是一家中型的物流公司，开展的业务包括海运、空运、快递、代理贸易进出口等方面。
