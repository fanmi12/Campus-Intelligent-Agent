# 院士莅校促发展，故地重游再添绿

2月26日，中国科学院徐建中、金红光二位院士莅校访问，并在杨敏林院长、黄兢副院长等领导的陪同下参观校园。

2013年，徐建中院士在“桂园”栽下了一棵桂树。一年来，经过同学们的精心呵护，小树茁壮成长，枝繁叶茂。当看到树上挂满了同学们写的许愿卡，徐院士感到非常欣慰，停下脚步为小树培土浇水，并同金红光院士一起又为我院“桂园”植下了一棵新桂苗。

访问期间，二位院士就我院的教学科研工作提出了许多指导性意见。

据悉，金红光院士现任中国科学院热物理研究所学术委员会主任，一直从事能源环境系统集成技术研究。他指出，可再生能源的发展需要三套马车，在全球能源短缺、倡导节能减排的背景下，要解决好环境污染问题，提高能源利用率，实现能源产业健康发展。
