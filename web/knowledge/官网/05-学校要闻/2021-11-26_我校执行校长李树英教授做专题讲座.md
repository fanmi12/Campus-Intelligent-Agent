# 我校执行校长李树英教授做专题讲座

11月25日下午，我校“教学知与行”讲座在学术报告厅召开，执行校长李树英教授做“教少一点，学多一点——大学课堂教学改进、创新与评价策略”主题讲座。校内各教学单位领导、教研室主任、教师代表，人事处、教务处、科技处、教学质量监测与评估中心等机关教辅负责人及督导成员共150余人参加本次讲座。本次讲座线上线下同步进行，线上培训由各教学单位组织全体教师参与。

李树英教授在著名高等学府担任教学、科研和大学高层行政管理工作三十二年，具有丰富的跨学科、跨文化、跨区域教学、科研、高校行政管理经验，在高等教育管理和实践方面卓有建树；深谙国际先进的教学和管理理念、模式和实践，是人文视域中的教育现象学的引领者和推动者，也是基于课堂的教研、课研和课堂学习研究模式国际知名学者。

李树英指出，信息时代的迅速发展带来了现代先进教育技术和手段的广泛应用，高校课堂教学彻底发生了改变；现代教师的角色更加多元化，不仅是讲坛上的圣者，更是学生身旁的指引者、“翅膀上的幽灵”、“机器中的灵魂”，教学方法要从教师满堂灌向学生自主学习改变。高校教师要不断探索课堂教学改进与创新，在“教少一点，学多一点”（“Teach Less, Learn More”，以下简称TLLM）教学理念指引下思考如何用恰当的教学方法提高课堂教学效果。

李树英认为，改革当前大学生评教体系是提升大学课堂教学质量的重要内容，以“基于学生学习成效的大学生评教体系”为切入点，围绕“评教”还是“评学”、“有效的老师”还是“好老师？”这两个问题，从多个维度分析了目前学生评教的问题根源所在，提出构建以成果导向教育（OBE）理论和布鲁姆的教育目标分类理论为理论基础的大学生评教体系，深刻理解“以学生为中心”的内涵，从“评教”到“评学”再到“间接评教”之转变，强调“学习结果”对教学的反馈，实施TOC教学大纲，运用新的学生评教量表，以此推动大学课堂教学改进与创新。

李树英指出，学校将加大对教学改进与创新的推进和支持力度，从支持教学创新的行动和项目、开展协同教学、试点同课异构混合教学、建立科目外评制度、实施有效教学的学生评教制度等方面进行课堂教学改革，提升课堂教学质量，从根本上进行自上而下的大学课堂教学改进与创新，推进我校教育教学高质量发展。

李树英为我校教师分享了最前沿的高校课堂教学改革经验，提倡并在大学课堂中践行TLLM教学理念。同时，李树英针对性地从学校、教师两个层面为我校今后课堂教学改革指出了改进路径。课堂教学改革的重点和核心在于教与学关系的根本性调整，要实现由以教为主向以学为主的转变，真正建立起以学为中心、为主线的新课堂。这次培训从理念、技术、方法和手段等方面给了大家以启迪，对课堂教学有了更新的认识，促进我们进一步探索教学改进与创新，不断提高课堂教学效果和人才培养质量。
