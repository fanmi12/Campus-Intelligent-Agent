# 【众志成城 抗击疫情】我们相约线上——主题征文选登②

我校重点关注学生在线学习的效果，切实保障网络课堂的教学质量。学校领导提出，“生活就像海洋，只有意志坚强的人才能到达彼岸，在这最艰难的时期，我们不仅要确保身心健康，同时积极利用这次‘网络教育’的机遇，主动适应学习方式、学习环境和学习形式的变化”。从3月19日起，我校组织了《我们相约线上》学生主题征文活动。第一期精选刊发部分优秀征文作品后，今天推出的是第二期作品选登。

一、疫情之下 相约线上

——外国语学院 黎惠珍

现在，新冠肺炎疫情防控形势依然严峻，为保证学生的学习进度，教育部提出“停课不停学，停课不停教”的要求，并且学校在第一时间制定了相应的网课计划，得到师生的积极响应。每天一到学习时间，学生老师都会准时出现在直播间，老师上课热情依旧，学生认真听讲、积极回应老师。即使老师是通过网络直播上课，却能让我有一种远隔不同地区，仿佛就在一个教室上课的感觉。但是，上网课也是一种新体验，更能考验我们的自律性。最后希望疫情赶紧过去，我们早日回到学校学习。

二、线上学习新模式

——计算机技术与信息学院 李前君

这是我第一次线上上课，也是我第一次在电脑上选修课。我认为这是很有必要的，通过学习大学生职业生涯规划和选修的经济与社会，让我受益匪浅，对自己的人生又重新好好规划了一下！同时在线上学习学校规定的课程时，我也觉得很新鲜，认为这是一个新模式。在听课的同时我们也会和老师多多互动，老师也会为我们解答我们所提出的问题。在这里还是要感谢所有老师，为了线上教育而准备了许久。在这里我也衷心希望疫情可以早早结束，我也想看到可爱的同学们！在上网课时，我们也会学会自我监督，不会因为不在教室而变得随随便便！

我认为所有老师为了此次网课都付出了很多，他们为了吸引学生的注意力想尽力各种办法，所以我非常感谢他们！

三、春暖花开时

——文学与传媒学院 罗梦茹

春天来了，花也开了。今年我们与城院，与学习，与春天，相约在线上……钟南山院士一句“乖乖待在家里”，开启了学生们的网课生涯，学院闻风而动，迅速地开展线上授课的学习模式。由此，我们在线上有了众多的学习资源，每天的问候语从“吃了吗”变成了“学习进度如何”。我们的网络直播答疑，课程要求的辅助学习APP如学习通、知到等，再由我们易班开展的课程，学得很充实，知识量大，让我收起了玩乐的心，沉浸在学习的幸福中。在这段日子里，我们没有面对面携手见证春暖花开，城院的花，却早已开在了我们心里。
