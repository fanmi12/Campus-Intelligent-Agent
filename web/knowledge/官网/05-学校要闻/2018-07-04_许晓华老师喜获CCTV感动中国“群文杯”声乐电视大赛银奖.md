# 许晓华老师喜获CCTV感动中国“群文杯”声乐电视大赛银奖

6月6日至10日，CCTV感动中国“群文杯”第八届声乐演唱电视展演比赛在中央电视台举行。我院计信系辅导员许晓华老师从初赛、复赛成功晋级总决赛，以一首充满哀怨诉说许仙与白娘子千年爱情的艺术歌曲——《断桥遗梦》打动了评委与观众，最终荣获民族组“银号奖”。

CCTV感动中国“群文杯”第八届声乐演唱电视展演全国总决赛，由文化部中国大众音乐协会主办，旨在发掘和表彰一批优秀的歌手。大赛分为美声、民族、通俗三种唱法，展演活动实况还将面向全国播出。
