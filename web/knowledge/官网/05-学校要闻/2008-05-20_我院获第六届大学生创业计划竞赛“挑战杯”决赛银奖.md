# 我院获第六届大学生创业计划竞赛“挑战杯”决赛银奖

5月16、17日，城市学院两支代表队在广东工业大学工学院举行的广东省第六届“挑战杯”毅昌科技广东大学生创业计划竞赛中获银奖。

他们分别是：由罗余才教授指导金融与贸易系江超武等5名学生组成完成的“奥粤体育活动策划有限公司”计划书 ；由唐洁老师指导财经系学生邓慧儿等4名学生完成的“爱宝宝早期教育有限责任公司创业计划书”。

据悉，本次竞赛是第二届广东大学生科技学术节的重要内容，全省共有66所高校参加，送交作品408件。作品涵盖了生物医药、化工技术及环境科学、 电子信息（硬件）和材料、电子信息（软件、网站）、材料科学、机械能源和服务咨询等八个学科类别。
