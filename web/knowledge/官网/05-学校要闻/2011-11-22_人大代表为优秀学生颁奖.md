# 人大代表为优秀学生颁奖

11月21日，一台不同民族、不同国家元素融合的大型歌舞晚会在大礼堂精彩上演，庆贺我院2010-2011学年先进集体、优秀大学生表彰大会的隆重精彩上演。与往年不同的是，今年的颁奖嘉宾则是刚刚当选东莞市第十五届人民代表大会的代表危兆宾博士、享受国务院特殊津贴的徐中和教授。

出席颁奖晚会的嘉宾和领导有：安少华、黎建烨、朱志德、杨敏林、程发良、朱冰、张林、陈丁堂、麦琦琳等。

会上，09会计学2班等16个班级获评先进班集体，麦肖君等1942名同学分获“校园十佳”、优秀大学生、优秀学生干部荣誉称号，邓翠容等70名同学分获“鸿发奖学金”、“鸿发励志助学金”，凌云等1406位同学分别获得校园各类奖学金。

国家一级演员、战士歌舞团演员、艺术系客座教授于乃久，城市学院艺术系、大学生艺术团、教工合唱团的师生，为大会盛情奉献了一台精彩的艺术大餐。表演节目中，有富有江南水系风情的歌舞《小城雨巷》，有反映新校区校园风光的舞蹈《走在山水间》，有由服装专业学生制作由学院模特队表演的服装秀。更值得一提的是，集合俄语、英语、朝鲜语、粤语几种语言的经典歌曲联唱，不仅给观众带来的是艺术的美感，更表现了校园的团结和谐与学术风格的包容。师生们欣慰地看到，成立不到一年的学院管弦乐队队伍扩大到50多人，水平更高了，演奏的老约翰?斯特劳斯名曲《拉德斯基进行曲》作为晚会的压轴戏。
