# 汕头大学蔡映辉教授来我院作专题讲座

4月21日上午，教务处举办了“教学管理与课程建设”专题讲座,邀请了汕头大学教务处处长蔡映辉教授进行主讲。院长王卫平、教务处处长赵书山以及各单位的质量工程项目负责人聆听了讲座。

蔡映辉教授结合汕头大学的教育教学实践，从三个方面进行了讲解：一是以应用型人才培养方案为抓手，做好本科教学工作。蔡教授说，汕头大学采取基于“OBE”（outcome based education,即成果导向教育）理念的人才培养模式，在教学管理和教学实践当中，围绕“学生受教育后将获得什么能力”来开展人才培养。

蔡教授认为，应用型本科高校应正确定位，突出办学特色，结合产业需求，明确培养目标，围绕培养目标来构建课程体系和改革考核方式。

二是如何做好课程建设。蔡教授认为，课程体系的构建，要进行利益相关者调查，多方面听取用人单位、学科专家、一线教师等的意见；课程计划的制定，应与培养目标紧密相连，根据培养目标来安排计划和设置课程。

蔡教授介绍了汕头大学如何推行新工科专业认证，采用CDIO工程教育模式，推动新工科专业的改造和发展。

三是关于精品资源共享课建设问题。蔡教授认为，要建设好一门精品资源共享课，一方面在于“建设”，即丰富和充实线上课程资源；另一方面在于“应用”，要做到课程资源能被学生真正用起来，提高线上资源点击率，实现线上师生互动，使得课程资源真正达到“共享”。

蔡教授与我院商学院院长罗卫国、创意设计学院院长助理何帅、机电系主任赵天婵、招就处处长孔增强就人才培养、教学团队建设、专业建设以及创新创业教育等方面的相关问题，进行了交流和探讨。
