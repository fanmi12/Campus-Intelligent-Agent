# 我院举行新进教职工入职培训

3月3日,学院教师发展中心组织新进教职工开展入职培训活动，20名新进教职工参加了培训。

王卫平、章德胜、高香林、黄兢、周庆、刘玉侠、林江龙等院领导及有关部门负责人出席了开班仪式。

王卫平院长在讲话中指出，新入职教师是学院建设与发展的新生力量，学院将通过营造良好的工作生活氛围，制定各项教师发展政策，促进每位教师的职业发展。他还强调了新教师入职培训的目的和意义，希望每位老师结合个人职业发展，加强自身的师德修养，提升业务能力，尽快融入城院大家庭，一起推动学院的改革与发展。

培训共开设了七个专题讲座。刘玉侠副院长就学院发展历程、办学理念及办学特色等作了详细地讲解，重点介绍了学院建设发展规划，对新进教职工也提出了殷切的期望。人事处副处长李海冬详细地介绍了学院最新改革的人事管理制度，包括部门与岗位设置、薪酬与福利、考核与绩效、教师培训制度等方面。教务处副处长鞠晓红介绍了学院各项教学管理制度，对日常教学中常见的问题作了细致地分析。为增强新入职教师的教学体验和提高教学技能，文传系副主任陈跃应邀作教学示范课。培训内容还包括东莞市情、东莞高等教育状况、学院科研政策、学院图书信息资源、多媒体教学设备使用等专题培训。
