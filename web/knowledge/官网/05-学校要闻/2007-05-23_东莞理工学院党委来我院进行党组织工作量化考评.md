# 东莞理工学院党委来我院进行党组织工作量化考评

5月21日，东莞理工学院基层党组织工作量化考评组一行在党委组织部副部长汪璟同志的带领下，来我院检查考评党建工作。

党委书记朱志德向考评组汇报了学院党委一年来的党建工作，党委副书记朱冰按照考评要点详细汇报了党委的工作，并提供了许多原始资料和记录。

汪副部长对我院的党建工作给予了高度评价，她指出，城市学院党委在校本部党委的领导下，取得了有目共睹的成绩，本次考评准备工作做得很充分，同时也对我院党委今后的工作提出了指导意见和建议。

朱志德书记表示，城市学院组织科、各总支（直属支部）要以这次考评为契机，对照检查，查漏补缺，不断完善，不断创新，力争各项工作上新台阶。院党委办公室要尽快制定我院基层党组织量化考评实施办法，下半年学院党委组织相关部门对各单位的党建工作进行量化考评。
