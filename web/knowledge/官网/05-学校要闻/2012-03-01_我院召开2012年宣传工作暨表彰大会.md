# 我院召开2012年宣传工作暨表彰大会

会场王玉主任为获奖者颁奖2月29日，我院在4#315会议室召开2012年宣传工作会议。院党委委员、院办公室主任王玉，院党委宣传部部长、新闻中心主任何鹏举，院办副主任、新校区管委会综合部副部长张琮出席会议。

王玉主任在讲话中指出，学院各单位要有新闻意识，积极宣传本部门表现突出的人和事。要充分利用网站等宣传渠道，开展宣传工作和学生思想政治工作。要注重营造校园宣传氛围，加强对外宣传，加强针对性，立足高起点，坚持高标准，力争高质量。各系部领导和广大师生员工要成为宣传工作的支持者、促进者和参与者，把宣传工作与本部门的工作、个人的教学业务、学习、生活有机结合起来，用自己的一言一行为学院塑造形象作贡献，为东莞高水平崛起献计出力。

何鹏举部长总结了2011年的宣传工作，并对2012年学院宣传工作做了安排。他强调，今年我院宣传工作的重点是加强思想政治工作，服务教学中心工作和任务，围绕社会热点进行宣传教育。

会议首先为2011年学院十佳优秀网站、建党90周年理论研讨会征文、建党90周年“党在我心中”征文、2011年度宣传报道工作先进个人、纪念建党90周年“红镜头”摄影比赛的获奖者颁奖。
