# 我院2014届毕业生初次就业率再创新高

根据广东省就业指导中心就业平台反馈信息显示，截至2014年9月1日，我院2014届3110名毕业生，初次就业率98.52%，再创历史新高。其中，本科生（1540人）就业率为97.73%，专科生（1570人）就业率为99.30%。

其中，有4个系初次就业率为100%，分别是财经、金贸、机电和计信；有30个专业初次就业率为100%，分别是会计、会计学、会计学（财务管理）、会计学（国际会计）、资源环境与城乡规划（城乡规划管理）、资源环境与城市管理、会计电算化、模具设计与制造、人力资源管理（专科）、机械设计制造与自动化、印刷工程、计算机辅助设计与制造、机具设计与制造、电子信息工程、计算机科学与技术、软件工程、计算机应用技术、计算机应用技术（电子商务）、保险（银行保险理财与证券投资）、国际经济与贸易、保险实务（保险理财与理赔定损）、国际商务、金融管理与实务、英语（商务英语）、英语、文秘、表演（舞蹈表演）、艺术设计（服装设计方向）、法学、社区管理与服务、文秘（法律事务）等。

从初次就业的平均薪酬来看，平均薪酬最高的系是城市与环境科学系，平均薪酬为2499元。平均薪酬最高的前3个专业分别是电子信息工程，平均薪酬2768元；文秘，平均薪酬2741元；保险（银行保险理财与证券投资），平均薪酬2729元。

从就业地区来看，有2590人选择在东莞就业，占总人数的83.3%。

就业中心主任江小卫表示，今后我院就业工作的重心是，在继续保持高就业率的基础上，将逐渐转向进一步提高就业质量、完善就业指导服务、加强就业指导课程教学、开展就业市场调研、毕业生就业跟踪和信息反馈等方面，充分发挥就业的导向作用。
