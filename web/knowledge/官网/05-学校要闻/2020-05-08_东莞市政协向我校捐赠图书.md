# 东莞市政协向我校捐赠图书

5月7日下午，东莞市政协向我校捐赠图书仪式在我校行政楼505会议室举行。市政协副主席、民盟东莞市委会主席程发良，市政协常委、文化文史和民族宗教委员会主任李炳球，市政协副秘书长黄薇，市政协文化文史和民族宗教委员会专职副主任江琳，市政协委员、寮步镇香市中学校长袁洪发，市政协委员、东莞市沉香协会会长、香城集团董事长尹丰田，我校校长王卫平、党委书记章德胜、副校长高香林、副校长刘玉侠等领导出席了捐赠仪式。捐赠仪式由副校长高香林主持。

程发良副主席表示，此次捐赠旨在为城院师生提供一批优质的东莞本土图书和丰富的精神食粮，让广大师生对东莞的历史底蕴和文化有更深层次的了解，同时希望双方未来有更深远的交流与合作。

李炳球主任表示，感谢学校领导对此次图书捐赠活动的重视和支持。近年来，市政协文化文史和民族宗教委员会围绕东莞历史文化名城建设工作，深入挖掘东莞深厚地域文化，致力于文史资料的收集和整理工作，整理出版了一大批莞籍历史名人资料的书籍，产生了良好的社会影响力。

校长王卫平代表学校对东莞市政协文化文史和民族宗教委员会表示衷心感谢。他指出，东莞理工学院城市学院作为一所地方大学，具有服务地方经济社会的功能，也有地方文化传承、文献资料整理收藏的职能和需要。这批图书对城院来说非常珍贵，不仅充实了我校图书馆藏，也将对学校相关学科的研究起到重要的助推作用，希望未来能够继续加强交流与合作。
