# 我校三位教师获聘联合培养研究生导师

7月8日，广东财经大学正式行文，聘任我校会计与金融学院副院长肖文锋教授、国家一流会计专业负责人耿玉成副教授为会计专业联合培养研究生导师，聘任创意设计学院院长何帅博士为设计专业联合培养研究生导师。这是我校继与暨南大学开展联合培养研究生工作以来的又一重大进展，标志着我校学科建设正在稳步向前推进。

广东财经大学始建于1983年，原名广东财经学院，起始办学层次为本科教育，1985年更名为广东商学院，1997年通过本科教学工作合格评估，2003年获得硕士学位授予权，2008年以“优秀”等级通过本科教学工作水平评估，2013年更名为广东财经大学，2021年获批为博士学位授予单位。经过40年的发展，广财已经建设成为一所学科特色鲜明、师资力量雄厚、办学效益显著、社会影响力和知名度较高的财经类院校，是广东省本科高校“新文科”建设指导委员会主任委员单位、广东省依法治校示范校和广东省大学生创新创业教育示范校。

广东财经大学已经与我校达成联合培养研究生协议，首期选定会计、设计两个专业，下一步在金融学、国际商务、数字经济等专业进行合作，将极大地促进我校数字商科各专业的发展与提高。
