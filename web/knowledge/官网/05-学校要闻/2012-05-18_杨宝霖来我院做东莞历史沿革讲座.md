# 杨宝霖来我院做东莞历史沿革讲座

5月17日，拥有“东莞历史文化之宝”美称的杨宝霖老师在我院新校区做东莞历史沿革讲座，文传系2011级本科班全体同学听取了讲座。

讲座中，杨宝霖老师借助自制的幻灯片，为同学们解读了东莞名字的由来，不同时期的东莞，东莞立县的历史，东莞割地的风波以及解放后东莞县属地的变化。讲座进入尾声的时候，杨宝霖老师还与同学们进行了互动交流，一一回答了同学们提出的问题。

参加讲座的同学表示，杨老师精彩的东莞历史文化演绎，让大家对东莞的文化历史有了更深入的了解，并以自己能在东莞学习与生活而感到荣耀。
