# 运筹帷幄  决胜未来

为了帮助大学生学习与掌握职业规划的基本方法，树立正确的成才观和就业观,东莞理工学院城市学院举办了第二届大学生职业规划大赛。9月20日，预选产生的 “十大职业规划之星”在大礼堂进行决赛，角逐代表学院参加省级比赛资格。

学院党委书记朱志德、党委副书记朱冰、行政副院长张林副教授、学生处处长章德胜副教授以及各参赛系部的主任和1000多名师生一起观看了比赛。文学艺术系马兴川教授、学生处副处长陈建新等10位老师担任评委。

决赛十分激烈。每位参赛选手的职业规划方向各不相同，有的想当一名高级电子工程师，有的想做电视记者，有的希望将来做一名资深传媒策划人，有的想成为经济学教授，还有的希望能自己创业做老板。舞台上的选手们不仅拥有多彩的梦想，而且有切实可行的计划。他们的激情陈词不时引来同学们的掌声。

本次大赛的主题是：规划精彩人生，打造锦绣前程。大赛从今年5月10日正式启动，城市学院共有2079名同学参加预赛。截至9月11日，经广东省第四届大学生职业规划大赛组委会确认，城市学院共完成作品1039份，提交作品人数在全省100多所高校中列第4名。

经评定，来自财经系的林智聪以90.4分拔得头筹，邓锦溏、潘嘉媚获得二等奖，其余7名选手获三等奖。财经系的唐洁老师和金融与贸易系王洁娟老师被评为优秀指导老师，计算机与信息科学系、机电工程系获得最佳组织奖。

我院十分重视学生的职业规划教育。在大学一年级开设了职业规划课，帮助同学们在进入大学校门时就能树立职业理想和学习目标，并成立了职业规划协会。各系部都安排职业规划辅导老师和指导员，帮助同学们制定职业规划。上学期，学院举办了两次职业规划讲座，邀请全国就业指导专家郝荣先生、广东省职业生涯规划大赛优胜者彭小康同学，分别为我院学子作了报告。学院还举行过模拟创业设计大赛，计划为每位学生建立职业规划档案，不断跟踪毕业生就业、创业情况。
