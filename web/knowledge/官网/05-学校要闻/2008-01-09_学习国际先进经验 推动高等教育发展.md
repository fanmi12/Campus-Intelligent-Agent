# 学习国际先进经验 推动高等教育发展

1月7日，市委宣传部、市社科联联合召开了主题为“以新一轮思想大解放推动东莞新一轮大发展”的座谈会，市委常委、市委宣传部部长王道平与来自全市社科理论界的学者参加了讨论。我院院长安少华教授、宣传部部长何鹏举副教授、社科系主任陈丁堂教授、学报编辑部主任徐世杰教授及社科系十名教师应邀与会。

与会学者结合东莞实际和工作实际，围绕省委书记汪洋和市委书记刘志庚的报告，从不同角度深入分析与探讨了为什么要继续解放思想、如何把解放思想作为推动发展的动力源泉等议题。

安少华院长在题为《学习国际先进经验，推动高等教育发展》的发言中认为，推动东莞新一轮大发展，就必须解放思想，放眼世界，学习国际先进经验，大力发展东莞高等教育。这几年东莞的高等教育发展很快，但比及国际发达国家和地区，比及东莞经济社会发展的需要还有很大的差距。我们要创新高等教育办学体制，在全国率先探索建立一所产权明晰、有民间资本参与、各种所有制并存、与香港大学或国际知名大学接轨的高水平、新机制的国际性大学。同时要积极扶持民办高校的发展，多渠道并进，全面提升东莞人才培养能力。

王道平部长在总结发言中指出，理论界和各单位要继续深入学习党的十七大、省委十届二次全会、市第十二次党代会及市委十二届二次全会的精神，以解放思想、实事求是的思想路线，激励全市广大干部群众从新的起点出发实现大发展大突破的热情。要联系工作实际，开展解放思想大讨论，打破常规，研究新问题，总结新经验，提出新措施，实现新的发展。

据悉，1月8日的《东莞日报》对安院长和何教授的发言进行了刊载。
