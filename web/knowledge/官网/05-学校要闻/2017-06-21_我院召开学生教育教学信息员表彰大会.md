# 我院召开学生教育教学信息员表彰大会

6月19日，我院2016-2017学年度学生教育教学信息员表彰大会在7B201召开，全体学生信息员参加了会议。

督导办对2016-2017学年度学生教育教学信息员工作进行了总结，肯定同学们一年来的工作成绩，并希望同学们再接再厉，共同推动我院教学质量的进一步提升。

优秀学生信息员代表进行了发言，分享了自己对学生信息工作的认识与体会。

督导办对获奖的同学们进行了表彰。
