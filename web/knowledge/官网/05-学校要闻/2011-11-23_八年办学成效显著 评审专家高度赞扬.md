# 八年办学成效显著 评审专家高度赞扬

“城市学院是广东省新办本科院校里的一匹黑马，是名符其实的后起之秀。”广东省教育厅胡振敏副巡视员在评审反馈意见会议上，用这句形象语言高度概括和评价城市学院这几年的建设与发展成就。11月22日下午，学院在学术报告厅举行专家评审意见反馈会议，听取专家们的评审意见，答谢专家对学院工作的支持与肯定。

评审专家组15位专家在主席台就座。

广东省教育厅胡振敏副巡视员从广州专程赴会并做重要讲话。

专家委员会主任徐真华教授主持会议并宣读了专家组的评审意见，工科组组长贾德民教授、文科组组长刘洊波教授分别反馈评审意见，刘琼发教授也谈了几点建议。

胡振敏副巡视员在会上表示，两天半的实地评审工作，程序严格科学，内容丰富全面，专家工作认真，评审意见客观。他说，通过评审，专家们一致认为，东莞市委市政府、东莞理工学院党委行政有远见，对城市学院支持力度大；城市学院领导班子团结务实，熟悉并遵循高等教育办学规律，抢抓机遇乘势发展；定位准确，目标清晰，发展态势好；鸿发集团办学有实力；师资队伍素质高，师生精神面貌好；制度健全，机制灵活，专业建设成效显著，人才培养质量高。可以这样评价，城市学院是广东新办本科院校里一匹耀眼的黑马，真正的后起之秀。同时，他也希望城市学院在第二阶段的发展过程中，取得更大的成绩，成为全省独立学院的标杆。

专家评审意见认为，城市学院与母体错位发展，办学的软硬条件较好；注重应用型、创新型人才的培养；形成了比较系统的、科学的教学、管理、科研、人才师资培养、教学质量监控体系；教风学风端正；自觉围绕服务地方经济建设大局开展实践教学和产学研活动；形成了自己的特色与品牌。

专家们希望城市学院要进一步凝炼办学思想，加强科研工作，提高青年教师的业务素质，注重培养学生的学习兴趣，帮助学生学好专业课程与理论基础知识。要依托母体，发挥优势，争取各方面的支持。要坚持开放办学，学习兄弟院校的办学治校经验。

院长安少华在会议上发表了热情洋溢的讲话，他深情感谢教育厅20多年来对东莞理工学院和城市学院的支持与关怀，感谢专家们几天的辛勤工作和客观的评价，表示要按照专家的意见，制定方案认真整改，促进学院又好又快协调发展。

东莞理工学院、城市学院董事会、城市学院、新校区管委会的领导周致纳、杨晓西、安少华、邹晓平、麦照容、黎建烨、朱志德、杨敏林、程发良、朱冰、张林、陈丁堂、麦琦琳出席了会议。

学院有关部门、各系部、各专业负责人，部分专任教师共300人到会听取意见。
