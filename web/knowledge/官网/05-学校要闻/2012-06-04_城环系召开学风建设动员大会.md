# 城环系召开学风建设动员大会

5月31日、6月1日下午，城环系分别在新老校区开展2012年学风建设动员大会。

会议邀请08级毕业班代表袁宇志与黄启祥介绍考研与成功考取公务员的经验与体会。两位同学指出，无论是学习还是生活，都要有目标，要珍惜时光，目标是一盏照亮前路的启明灯，它可以助你走上成功之路。

系主任肖红飞在会上强调，要明确学习的重要性，并以北大、清华等名校学子的典型激励学生，鼓励他们要向优秀学子看齐，端正学习态度，获得良好的学习成果。

据悉，城环系学生全部签订了“诚信考试承诺书”，表示要诚信参考，从自身做起。
