# 执行校长李树英教授应邀率队赴北京师范大学-香港浸会大学联合国际学院交流访问

9月1日－2日，我校执行校长李树英教授率队赴北京师范大学-香港浸会大学联合国际学院（UIC）交流访问，并应邀为UIC教师做学术讲座。

9月1日，执行校长李树英教授到达UIC，在UIC副校长黄华雄教授引导下参观了UIC校史展厅、全人教育艺术中心、学习资源中心、数学体验馆等。随后，双方开展座谈，双方就大学教学创新和学生发展的经验进行交流，并探讨了可能的双边合作。UIC副校长黄华雄教授，副校长毛亚庆教授，协理副校长兼通识教育学院署理院长左龙佩兰教授等参加座谈会。

9月2日，执行校长李树英教授用全英语为UIC广大教师作了主题为“Teach less, learn more: Report on university teaching innovation action research project findings”的学术报告。李树英教授介绍了颠覆性技术在教育中的使用，后疫情中的大学环境以及大学发展等高校教学创新的大背景。随后，他通过一些高校教学创新行动研究项目的实际案例，深入分析实施的难点及应对政策。他还就促进大学课堂的积极改革提出了建议。

我校执行校长李树英教授是中国教育现象学的领军学者，也是课堂学习研究、课程研究和教育行动研究等领域的的著名专家，曾在阿尔伯塔大学、香港中文大学、香港教育大学、澳门城市大学、南京信息工程大学等多所国内外知名高等学府大学从事教学、科研与行政管理工作，拥有丰富的跨文化、跨区域的教学研究及行政管理经验。

此次我校到UIC(北京师范大学香港浸会大会联合国际学院）交流访问，促进了双方之间的相互了解，为今后追求卓越教学的交流合作奠定了基础。学校副校长陈葆华、校长助理孔增强、教学科研部部长杨勇虎和图书信息中心主任陈显龙等陪同交流访问。
