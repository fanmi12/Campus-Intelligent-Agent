# 商学院赴利侨制罐有限公司交流合作

为实现人才培养与产业需求的精准对接，深化真实项目制的产教融合育人新模式，2026年3月20日上午，在东莞市人社局寮步分局的指导和对接下，商学院副院长张敏强，国际贸易系主任谭芬，数字营销系副主任黎贺桃，专任教师王婷、黄凯晴，就业辅导员李悦一行前往东莞市利侨制罐有限公司开展走访交流。

东莞市利侨制罐有限公司位于东莞市寮步镇，成立于2010年，专注于生产和销售马口铁包装盒，年销量达2000万个，产品广泛应用于数码、五金工艺品、食品等行业。企业拥有丰富电商、运营经验，并于2024年联合130多家企业成立网帮会，旨在帮助更多工厂拓展国内、国际销售渠道。为进一步加快销售进程，公司设立利侨电商AI新媒体基地，涵盖运营、直播、创业等功能。

座谈交流中，利侨制罐有限公司陈侨贤总经理介绍了企业发展需求及利侨电商AI新媒体基地的建设现状与未来规划，并表达了希望结合企业资源优势，加速推进与商学院资源对接、实现校企协同发展的合作愿景。商学院副院长张敏强表示，商学院始终坚持务实的理念，希望通过深度合作企业真实项目，引导学生在实战中锤炼专业技能、提升职业素养，真正实现学以致用。座谈中，双方围绕项目班、实践基地等多样形式展开探讨，推动商学院学生深度参与企业真实业务环节，由企业与学院共同跟踪指导。在企业负责人的陪同下，商学院一行参观了利侨制罐生产车间及利侨电商AI新媒体基地。企业丰富的业务资源为项目制平台的搭建提供了坚实基础，双方将共同构建教学练战一体化的成长空间，推动教师依托真实业务场景完善教学内容，学生在实战中积累职业经验，实现校企资源互补、互利共赢。

此次校企交流是商学院对项目式教学、真实项目进课堂的积极推进，通过“企业搬进校园、学生走进企业”的双向互动，为培养适应行业发展需求的高素质应用型商科人才打下坚实基础，也为专业建设与人才培养质量同步提升注入新动能。
