# 2012年迎新花絮之一：欢迎你，城市学院新主人！

每一朵鲜花都能绽放出自己独特的精彩，每一个城院的学子都会有自己不同的收获！欢迎你，2012级新同学，你们都是城市学院的新主人！

选择城院就成功了一半

记者团 邓绮苹

文周会是金贸系的新生。9月15日9时许，貌似娇滴的她居然单独一人提着厚重的行李箱，从茂名出发到达东莞汽车东站。笑容从未离开她半刻，自信的眼神充满着对大学的期望，她说：“东莞是个好地方！选择城院就等于成功了一半。”

管理系梁概茂同学在入学之前，就已经了解了学校许多信息。他对记者说：“我已经来过学校，到学校的公交车有49路和X13……”，他的“未雨绸缪”征服了在场的师兄师姐。

新生当了回“领导”

记者团 熊键清

“来学校的路上，一直有学校的志愿者为我们引路，我感觉自己像个领导受到了热烈的欢迎。”12级城环系林汉荣同学激动地说。

林汉荣来自广东茂名，虽然之前来东莞玩过好几次，但对东莞还是不熟悉，也没提前来学校踩过点。报到第一天，幸好一路上有学校师兄师姐引路，她和表哥得以顺利到校。第一天来学校就感觉自己是个“领导”，受到了如此热情的款待，真是过了把“领导”瘾。颇有领导风度的林同学对学校的评价是“整体感觉还不错！”

一人上学，全家上阵

记者团 熊键清

虽然如今上大学是件普通常见的事，但在上学报到的第一天，一些新生家庭还是隆重了一番。例如12级管理系的尹同学，就有父母、外祖父母、弟弟一起陪同来到学校报到。尹同学的爸爸说“不是怕她一个人来学校不熟悉不习惯，我们是寮步人，她是六中毕业的，可以说是对城院很熟悉，我们全家老少今天陪她只是给她打打气，希望她的大学生活有一个好的开始。”大学第一天，大群亲友团的陪伴，尹同学不孤单。相信她在以后的大学生活中，定会过得丰富多彩。全家上阵是开始。

难以割舍的母爱

记者团 邓绮苹

记者：“阿姨，您舍得女儿么？”阿姨的眼眶不知什么时候布满了泪光。

记者：“师妹，你舍得妈妈么？”师妹的嘴巴不由地开始向下弯曲。

这位来自浙江省的杨扬，是艺术系舞蹈表演的新生。东莞是她人生第一次出远门到达的地方。“以前读书都是在自己家乡，没有出过远门，今天我就想在学校住一晚。”杨扬母亲的话，大概也是众多家长的心声吧。

常言“可怜父母心”，其实，天下子女心也可怜，特别是离开父母的时候。但是，人相离了，心却不曾分过，爱更没断过。因为这份亲情之爱，总是难割难舍！

心系学生的领导和教授们

记者团 邓绮苹

迎接新生的这一天，领导们的身影也无处不在。他们时而观察着学生报到的情况，时而征询家长有没有不善不周，时而亲自上路指挥过往车辆，真是忙个不停。到下班时间了，学生没走，领导也没走……

各系系主任刘杰教授、米双红教授、牛熠教授、肖红飞教授、邓星明教授、张佺举教授、赵天婵教授、向智星教授、罗卫国教授都在迎新工作第一线坐镇指挥。看，那是政法系刘杰教授在与新生交流；看，这是艺术系向智星教授在与家长沟通……尤其影视表演专业的资深教授马新川老师，亲自在现场给每个新生派发名片，布置了作业。

红蓝丝扮靓城院

记者团 叶淑芳

在人来人往的校道上有这样一群人，女的手上系着红色的丝带，男的系着蓝色的丝带，顶着炽热的太阳，带着新生们认识校园，帮他们拿行李。走前一看，原来是文传系的一群志愿者。

“您们累吗？你们辛苦吗？”“累！辛苦！一年只有一次值得！”志愿者们异口同声地说：“我爱文传，代代相传！”丝带让他们相依相偎地一起，爱让他们一起无怨无悔地付出。

女儿圆大学梦 父亲重返东莞

记者团 叶淑芳

“十二年后的今天了，我又一次回到东莞！这里变化太大了！东莞有这么好的大学，真的很了不起！”文传系林炼琦同学的父亲感概地说。家在汕尾的林同学今年考上了城市学院，而他的父亲不顾路途遥远，也一起来到东莞这个地方。

第一次来到东莞，第一次来到自己的大学，林同学很兴奋，虽然顶着毒辣的太阳，手提一袋又一袋的行李，但她不觉得累，心里充满着对生活的好奇与期待。她说：“这里的环境很美，建筑也很特别，我感到很兴奋，我的大学生活可以过得很精彩！”

林爸爸十二年前有缘在东莞读师范学校，毕业后可以回到自己的家乡发展，在汕尾当了一名教师。他看着城市学院这些建筑物，不由自主地说：“十二年了！东莞变化很大，发展也是快，让女儿在城院读书，我们放心。”

也许是缘分的注定，冥冥中父女俩与城院有缘，与东莞有缘。

微笑立岗 温文尔雅

记者团 杜静欣

进出综合馆，总会看见一位保安和两个穿着白色裙子的礼仪小姐，面带微笑、温文尔雅地站在门口，给前来报到的新生及家长指示路径。

在入口，家长跟在学生的后面，像小学生中学生报到一样，直接跟随小孩进去，可是这次都遭到工作人员及礼仪小姐的劝阻：“你的小孩已经长大了，他一个人去报到就可以了。”大部分家长表示理解，就会说，“好吧，你自己去，我在外面等你”。为了让新生在城院的第一天就开始有独立自理的意识，维持好综合馆里面的秩序，工作人员便要求家长在外面等候，让学生自行报到。
