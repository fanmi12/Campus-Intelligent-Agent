# 宣传资料遭“哄抢”  城院学子受青睐

3月30日，东莞市（第八届）校企合作洽谈会在东莞国际会展中心举行，来自全国的250家院校和东莞本土1000多家企业前来参展进行交流与合作洽谈。

作为在校生规模最大的东莞本土高校，城市学院毕业生受到东莞本土企业的青睐。洽谈会伊始，学院展位前就已排满了前来咨询洽谈的企业代表，300多份宣传资料很快就被“哄抢”一空。交流中，很多企业反映招聘难仍是一个普遍的现象。“如何招到人才，如何留住人才，是我们企业发展过程中最头痛的问题。”一位企业人事经理坦言相告：“我们更愿意招聘像城市学院这样的东莞本土高校毕业生，他们的稳定性较好，不像外地毕业生的流动性那么大。”

据介绍，我院历来重视校企合作平台的建设，已连续参加了七届由东莞市人力资源局组织的大型校企合作洽谈会，与多家企业建立了校企合作关系。
