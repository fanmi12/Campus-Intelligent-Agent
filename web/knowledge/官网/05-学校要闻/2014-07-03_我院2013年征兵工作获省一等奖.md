# 我院2013年征兵工作获省一等奖

近日，记者从广东省人民政府征兵办公室获悉，我院获广东省教育厅2013年夏秋季征兵工作一等奖。

去年，我院认真贯彻习近平主席关于加强和改进兵役工作的重要指示精神，在学院征兵工作领导小组的领导下，周密筹划部署，狠抓工作落实，较好地完成征兵工作，2013年我院共计有25名学生光荣入伍。

2014年，我院征兵工作如期开展，截止2014年7月1日，我院征兵工作网上报名破历时新高，共计135人报名当兵，其中男生报名人数为124名、女生11名。
