# “东莞城市精神”研讨会在我院召开

为了进一步贯彻全市领导干部大会精神，推动新一轮思想解放和改革发展，把东莞城市精神的讨论引向深入，7月13日下午，市委宣传部、市社科联、东莞理工学院城市学院在我院315会议室，联合召开社科界“东莞城市精神”研讨会。

东莞理工学院党委副书记王江水应邀出席会议。参加研讨会的有市委宣传部副部长、市社科联主席陆世强， 以及东莞市社科界代表和我院部分教师。

会议由市社科联专职副主席王思煜主持。会上，与会人员分别从“家庭文明与社会文明”、“法治社会与城市精神”、“城市精神要以诚信力为基础”等方面发表了各自不同的看法。东莞理工学院田根胜博士就学院本土文化研究课题开展的调查情况在大会上作了发言。
