# 我院勇夺省大运会羽赛甲组团体总分第四名

5月20日-23日，广东省第九届大学生运动会羽毛球赛在广东外语外贸大学体育馆举行。我院羽毛球队夺得甲组团体总分第四名。

经过4天紧张激列的比赛，我院叶勇锋（机电系）获得羽毛球甲组男单第四名，沈咏欣（金贸系）和黄格仪（财经系）同学获得甲组女双第三名的佳绩。我院另一对女双队伍江嘉敏（金贸系）、陈佳旋（管理系）也以良好的表现获得甲组女子双打第五名的好成绩。

我院以团体总分1分之差落后于华南师范大学，位列甲组第四名。甲组团体总分前三名分别为中山大学、华南农业大学、华南师范大学。

同时，我院良好的精神面貌被组委会授予体育道德风尚奖（本届比赛共设立八个名额），教练员余乐老师获得了教练员体育道德风尚奖。

5月23日，学院党委副书记章德胜莅临赛场看望参赛运动员，对运动员和教练员表示慰问和祝贺。

据悉，本次比赛共有65所院校、866名运动员参加了甲组比赛，是省大运会历史上参赛单位最多的一届。
