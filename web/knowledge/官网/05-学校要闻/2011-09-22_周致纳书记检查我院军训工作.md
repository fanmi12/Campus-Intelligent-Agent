# 周致纳书记检查我院军训工作

周书记检查指导我院军训工作

周书记鼓掌肯定学生的良好表现9月21日下午，东莞理工学院党委书记周致纳、副校长李忠红一行来到城市学院新校区，检查2011级新生军训工作，并亲切慰问正在紧张训练的新生和承训教官。

在军训现场，周书记不断向城市学院副院长杨敏林了解军训的有关情况。周书记强调，今年参训新生人数多，军训责任大、任务重，各部门要切实做好饮食、医疗等后勤服务保障工作，确保军训工作圆满完成。当看到同学们认真、投入地完成各项队列训练时，周书记感到很欣慰，并鼓掌给予肯定。他勉励同学们要克服困难，刻苦训练，服从命令听指挥，以承训教官为榜样，高标准要求自己，努力完成军训各项任务，为自己的大学生活开个好头。
