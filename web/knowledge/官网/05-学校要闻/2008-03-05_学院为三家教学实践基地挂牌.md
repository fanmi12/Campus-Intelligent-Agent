# 学院为三家教学实践基地挂牌

学院为太平洋计算机科技有限公司挂牌

学院为东莞市万维网络科技有限公司挂牌

学院为东莞华兴科技有限公司挂牌3月4日，城市学院副院长程发良教授、计算机与信息科学系主任牛熠博士、马立权教授、高职部副主任谢俊等一行6人，专程驱车前往太平洋计算机科技有限公司、东莞市万维网络科技有限公司和东莞华兴科技有限公司，为这三家教学实践基地挂牌。

程院长一行受到了实践基地领导的热烈欢迎。他们同各实践基地负责人就学生实习目的、实习进度和实习中的一些问题进行了座谈交流。

程院长表示：“实践基地的挂牌为学生实践提供了便利，也为学生提供了发展平台。希望公司领导严格要求实习学生，多提供实习机会，让他们从基层做起，让他们增长才干与知识。”牛主任说：“据同学们反映，他们经常从实践过程中发现不懂的问题，再回到课本上用理论去解决。这样的学习方式效果好、收获大，消除了知识的盲区，非常感谢公司对教学实践工作的支持。”

华兴科技有限公司董事长张本胜赞扬我院的实习学生勤快肯干，能吃苦，动手能力和创新意识都很强，为公司补充了新鲜血液。他表示，他们希望优秀的实习生能留下来工作，成为公司的一员。

座谈结束后，程院长一行看望了正在实习的学生，鼓励他们认真实习，从一点一滴做起，不断提高动手能力。随后，校企双方在举行了挂牌仪式，并合影留念。

此次挂牌的三家企业均为东莞市信息产业的重点企业，分别以生产无限射频、开发计算机软件和建设维护网络运营为主营项目。

据悉，到目前为止，学院共有49个教学实践基地，为我院7600名大学生提供了良好的实习机会和实践场地。
