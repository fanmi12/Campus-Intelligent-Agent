# “妈妈”徐中和教授感动城院

6月24日，在2011届毕业典礼上，我院管理系徐中和教授作为教师代表发表了毕业赠言，令在场毕业生深受感动。

徐教授回忆了自己与毕业生大学四年中那一幕幕难以忘怀的场景和事件，用真情的倾诉和动人的事例，诠释了教师责任的光荣和真爱的伟大。徐教授对毕业生的未来寄予深切的祝愿，表示城市学院永远是同学们工作生活的港湾（全文见链接：徐妈妈的演讲稿）。

当徐教授讲到毕业班的同学在毕业酒会上抱着她难分难舍的哭泣，给她打电话却难以诉说心中的思念时，她的声音哽咽了，现场响起一片热烈的掌声。徐教授告诉毕业生“你们是城院教师舍不得、抹不去、忘不了、伤不起的永远记忆”，她忘情喊出“我爱你们，孩子们！”现场瞬间被点燃，气氛达到最高潮，台下掌声再次雷动，久久不能平息。

徐教授短短9分钟的讲话，学生们全体激烈的鼓掌达15次，两批学生上台为徐教授献上鲜花，高声呼喊“徐妈妈，我爱你”，师生间真挚而深沉的情谊感动了在场的每一个人。
