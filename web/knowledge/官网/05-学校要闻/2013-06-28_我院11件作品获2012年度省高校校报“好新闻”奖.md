# 我院11件作品获2012年度省高校校报“好新闻”奖

近日，2012年度广东省高校校报“好新闻”评选结果出炉。我院《城市学院报》编辑部选送的14件参赛作品中，有11件获得2012年度广东省高校校报“好新闻”奖。其中，4件作品分获二等奖，7件作品分获三等奖。

据分析，获奖作品有三个特点：获奖作品的数量增多，超过往年任何一年；重大题材、综合性的新闻占的比例大；新闻点抓的较准。不足的方面是以小见大、现场感强、生动有趣的新闻少。
