# 解放思想 精于谋划 勤奋工作 协调发展

城市学院樟村生活园区是在市政协主席刘树基的倡议与支持下建设起来的。两年来，他一直关注着生活园区的建设情况。5月15日，刘主席在为大学生作完形势报告后，不辞辛劳，在院领导的陪同下，又专程来到生活园区视察工作。当他看到面貌一新的生活园区时，不时地点头赞赏，对园区的规划与建设给予了高度的评价。

谈到东莞的高等教育时，刘主席说：“我过去经常说，当年东莞市政府用建一所大学的资金，建成了相当于三所万人大学：一万人的东莞理工学院，一万人的东莞理工学院成教学院，一万人的东莞理工学院城市学院。现在看来，这种战略思想是有远见的。城市学院的创办，完全顺应了东莞经济社会发展的要求，路子也是对的。”

在谈及当年创办东莞理工学院的体会时，他指出，作为一个单位的领导，要在其位，谋其政。过去，我担任东莞理工学院党委书记时，曾为学院的发展说了很多话。现在担任政协主席，我又为东莞市说话。希望安院长及城市学院的各级领导，要站在可持续发展的高度为学院说话办事。你们要精于谋划，勤奋工作；继续解放思想，抓住机遇，转换机制，充分利用周边的闲置土地改善办学条件，为学院的发展做出新的贡献。
