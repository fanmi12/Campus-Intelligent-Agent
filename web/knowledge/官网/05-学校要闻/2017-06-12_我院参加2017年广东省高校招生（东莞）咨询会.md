# 我院参加2017年广东省高校招生（东莞）咨询会

6月11日，我院参加了由东莞理工学院、南方日报东莞办事处主办的2017年广东省高校招生（东莞）咨询会。黄兢副院长，招生就业处孔增强处长及全体老师现场接受考试咨询与答疑。

当天，虽然天气炎热，并未影响考生和家长们高涨的热情。在我院招生咨询展位前，前来咨询的考生、家长络绎不绝。

现场咨询工作人员就我院招生专业特色、专业优势、就业前景、学费奖助政策等考生关心的问题一一做出解答，并热心地给予相关报考建议，对考生特别关心的住宿、出行、学费等问题做了详尽解答，让考生更好、更深入地了解我院。

据了解，本场2017年广东省高校招生（东莞）咨询会是2017年高考结束后全省首场招生咨询会，为考生及考生家长和参会院校搭建起了沟通和交流的桥梁。接下来，我院还将参加今年高校招生宣传期间的其他各场次咨询活动，切实做好招生宣传工作，努力提升生源质量。
