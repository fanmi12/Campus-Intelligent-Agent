# 广东省文旅厅原副厅长、一级巡视员陈杭一行调研指导我校非物质文化遗产工作

2025年5月12日上午，广东省文化和旅游厅原副厅长、一级巡视员陈杭一行莅临东莞城市学院创意设计学院，就非物质文化遗产（以下简称“非遗”）数字化建设工作开展调研。国家非物质文化遗产展览展示研究中心（华南展示基地）专家委员会副主任委员、文化馆发展研究院学术委员会委员、广东省文化和旅游厅原副厅长、一级巡视员陈杭，东莞理工学院非遗学院办公室主任杨亚南，东莞市社科院社会研究中心主任、副研究员于鹏杰，广东省非遗志愿者联谊会文体部副部长、东莞市非遗讲解志愿服务队队长陈颖等领导和专家参与此次调研活动。

东莞城市学院党委书记章德胜，校长李振华，执行校长方伟华，科研部部长杨勇虎，品牌与招生部部长（主持工作）叶云峰，创意设计学院院长何帅、党总支书记李梦丹、副书记许峰泓，等相关负责人陪同调研。

座谈会开始前，调研组一行前往创意设计学院进行实地考察。参观了创意设计学院新媒体数字内容创作教学与展示平台，了解前期非遗挖掘与影像类数字化成果和文化类产学研成果。随后，在广东省社科联岭南文化数字化研究中心，调研组通过互动体验的形式，深入了解了学院如何运用现代技术手段对非遗文化进行数字化记录和传播，体验平面视频转化三维人像技术、展示龙舟数字化成果、千角灯数字化成果、古典家具数字化成果、明代东莞数字化成果。

此外，调研组还参观了创意设计学院2025 届毕业生设计作品展，部分参展作品融入非物质文化遗产元素，通过现代艺术手法诠释传统技艺与文化内涵，展现了年轻一代对传统文化的传承与创新。展览不仅为大家带来耳目一新的视觉盛宴，也为非遗文化的传播注入了新鲜活力。

本次调研活动以一场座谈会拉开序幕。创意设计学院党总支书记李梦丹主持会议。

执行校长方伟华致欢迎辞，对调研嘉宾的到来表示热烈欢迎，并简要介绍了学校的整体情况和近年来在非遗保护与传承方面的探索与实践。执行校长方伟华随后就学校基本情况、学科建设及产学研合作成果进行了详细介绍。

座谈会上，创意设计学院详细汇报了非遗数字化建设工作。学院院长何帅首先做了总体介绍，重点围绕“数字化在地服务”展开汇报，展示了学院在非遗文化挖掘与保护方面的创新思路和实践成果。随后，李佩蒽博士、袁艺主任等多位老师分别从非遗文化挖掘、数字内容创作、光影技术应用及AI赋能文化资源建设等方面作了专题报告。

其中，李佩蒽博士分享了“非遗文化挖掘”的工作进展，袁艺主任和邓亚荣主任则重点介绍了非遗制作记忆、文化推广、产品开发等方面的内容。刘钧晖老师和陈汉林老师汇报了文化资源数字化内容创作项目。

在听取了各位老师的汇报后，调研组领导对东莞城市学院创意设计学院在非遗数字化建设方面取得的成绩给予了高度评价，并提出了宝贵建议。广东省文旅厅原副厅长陈杭指出，非遗保护与数字化建设是当前文化传承工作的重要方向，希望学院能够进一步深化产学研合作，在技术应用、人才培养和社会服务等方面发挥更大作用。此外充分肯定了学院在非遗数字化领域的创新实践，并建议未来可以加强与地方文化资源的对接，推动更多的成果转化落地，并且也肯定了学院近年来在非遗领域的深耕细作，认为学院已经培养出众多"单打冠军"式的人才和成果，展现了非凡的专业实力和创新潜能，但也希望学院能够整合资源、协同创新，在非遗项目的开发上形成"团体冠军"的整体优势。最后，陈厅长建议建立一个可视化统计量表，展示学校在非遗项目、相关课题和教学方面的成果，再者，拍摄一个记录短片，展示学校的非遗项目和科技元素，同时围绕非遗内容打造一个品牌，提升学校的影响力。

章德胜书记对创意设计学院的非遗文化和项目成果给予了高度评价，尤其是在传统工艺美术、民间艺术的现代转化等方面进行了有益探索。章书记在座谈会上发表讲话，指出学院在非遗文化传承与发展方面取得的成绩令人振奋，对未来进一步推动专业发展具有重要意义。章书记强调，非遗文化的传承和发展必须与现代教育深度融合，才能实现创造性转化与创新发展。

李振华校长表示，近年来学校在非遗文化和地方特色领域进行了深入探索。通过将非遗文化融入课程体系，学校不仅丰富了学生的文化素养，还为地方文化遗产的传承与发展注入了新的活力。同时，学校也在专业建设方面不断调整方向，努力与当地企业的需求相匹配。此外，李校长强调了校企合作的重要性。他认为，通过与企业的深度合作，既满足了企业发展的人才需求，也提高了学生的就业竞争力。

最后在轻松愉快的氛围中，调研组领导与学校负责人就非遗数字化建设的未来发展进行了深入探讨。大家一致认为，非遗保护工作需要多方协作、多维度推进，既要注重技术创新，也要加强社会参与，在保护传统的基础上推动创新发展。

本次调研活动的成功举办，不仅展示了东莞城市学院创意设计学院在非遗数字化建设方面的实践成果，也为各方搭建了良好的交流平台，为未来合作奠定了坚实基础。相信在社会各界的共同努力下，东莞乃至广东地区的非遗保护与传承工作必将迎来更加光明的前景。
