# 城院快乐体育节再掀全员健身旋风

作为本次科学文化艺术节的“当头炮”，快乐体育节继续秉承以往快乐体育，全民健身的宗旨，在全院又掀起了一阵健身旋风。

本次快乐体育节的主题为“迎奥运 齐健身”，从4月7日——4月28日结束，项目包括：趣味运动、跳绳、羽毛球、男子足球、网球、女子篮球、男子篮球、排球、乒乓球、拔河共9项。

球类运动是体育节的保留节目：三大球尽展体育运动的对抗性，每次进球得分都引发观众的热烈欢呼；乒乓球、羽毛球和网球展现了灵活多变的战略战术，飞舞在空中的小球牵动着每一个人的心。

传统项目拔河历久弥新，“团结力量大”这句话在这个项目上得到了最好的体现。不过，最吸引同学们眼球的莫过于趣味运动会，它包括过圈、双人跳绳接力、接力运球、齐心搬垫、同心协力，这些项目虽然运动强度不大，却在很大程度上考验着同学们的团体协作意识和身体协调性。

据悉，体育周开展的所有项目均决出前8名，第一名获奖杯，该奖杯具传承性，获胜者所在系部拥有一年的奖杯持有权，次年比赛时交还体育教学部，如在某项目中该系连续三年获得冠军，则该奖杯将由该系永久保存。

本次体育节由体育教学部主办，院学生会体育部、各单项协会承办。
