# “情感纠葛”后的心理健康教育及时有效

8月31日晚，我院发生了一起因情感纠葛引起的伤害事件。学院领导对此事非常重视，学生处及时地进行了调查和开展心理健康教育，取得良好的教育效果。目前，受伤害的学生及所在班级的同学思想情绪稳定。

事件发生后，学生处心理健康教育与咨询中心专职教师陈浩、王彦娜等，立即赶赴事发现场对目击者进行了心理干预制，定了心理健康教育的工作方案。

9月4日，心理健康教育与咨询中心主任余琼老师对事件的目击者、好友、室友、相邻宿舍的女同学进行了团体辅导，让相关同学得到了情绪宣泄。9月5日，学生处心理咨询中心与相关系部在该班开了一次主题班会。据介绍，伤者陈同学得到了很好的治疗，康复很快，两周后即可返校。余琼老师认为，处理情感纠葛要冷静理智，不可盲目冲动，“冲动是魔鬼”，最后双方都要吃苦果子。班会后，余琼老师请全班同学每人写一句祝福语送给陈同学，愿她早日康复。

据悉，学生处还制订了后续教育的工作方案。
