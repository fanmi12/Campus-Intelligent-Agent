# 千名学生同场竞技

监考老师领取试卷

监考老师逐一检查证件，核对考生身份

学院领导巡视考场

发现问题，举手提问

沉着应试7月5日，城市学院2009—2010学年度第二学期期末考试拉开帷幕。1000多名学生集中在4号楼大厅，进行同场竞技。

据教务处黄江英老师介绍，本次期末考试时间为7月5日-9日，共计646班次，180门科目。除千人考场外，还分设近40个小考场。
