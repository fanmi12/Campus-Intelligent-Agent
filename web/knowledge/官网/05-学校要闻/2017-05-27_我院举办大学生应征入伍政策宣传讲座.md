# 我院举办大学生应征入伍政策宣传讲座

5月25日下午，我院举办“大学生应征入伍政策宣传”讲座，邀请了东莞市人民政府征兵办公室艾登科中校作为主讲嘉宾。副院长周庆和各院（系）老师及学生代表参加了讲座。

讲座会上，播放了由学院征兵工作站凌继峰老师制作的宣传视频短片，展示了我院入伍同学的骁勇姿态，介绍了国家征兵条件、入伍报名流程和享受优惠政策等。

艾登科中校从自身经历讲起，阐述了大学生入伍对国家社会家庭和学生个人的重要意义，介绍了我国大学生入伍概况，解读了全国、全省和东莞市对大学生参军入伍优待政策。

周庆副院长指出，征集大学生入伍，是国家和军队现代化建设的重大战略决策。夏秋季入伍的一个重要目的就是使征兵与大学生毕业时间相衔接，为更多应届毕业生创造条件，实现了毕业离校门、入伍进军营的直通车。她要求各院（系）要加强宣传，鼓励适龄大学生报名参军，接受祖国的挑选，为我国的国防事业贡献自己的力量。

讲座结束后，东莞市人民政府征兵办工作人员和学院征兵工作站就同学们关心的入伍网上报名及征兵期间注意事项等有关问题，进行细致的解答。
