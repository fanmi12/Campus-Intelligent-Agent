# 工会组织女教职工“三八”踏春活动

绵绵春雨，润物无声。花开烂漫之际，3月11日我院工会为女教工组织了“以树的姿态独立，以花的明媚绽放”为主题的广州从化樱花踏春之旅。学院工会副主席王锦锋和来自各单位的40多名女教职工参加了本次活动。

当天上午，踏春团来到从化溪头村。满山遍野种植着各种果树，空气清新。村里袅袅升起的炊烟，俨然一幅山清水秀画。大家一般欣赏村里的风景，一边品尝各种小吃糕点，体验当地纯朴民风。

下午，在天适樱花悠乐园，细雨中，樱花新抽的嫩芽，粉红花瓣点缀其中，泥土上洒落粘着露珠花瓣，美不胜收，让人身心愉悦，流连忘返。大家纷纷感慨着大自然的美轮美奂，也为踏春之旅升华的友谊倍感愉悦。
