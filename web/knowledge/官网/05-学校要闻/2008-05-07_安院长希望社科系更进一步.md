# 安院长希望社科系更进一步

5月6日，院长安少华教授到社科系视察工作。他首先来到东莞社情研究中心，听取了该中心副主任周巍老师关于近期工作的汇报。听完汇报后，安院长充分肯定了“中心”所取得的成绩，希望他们要充分发挥学生的主观能动性，锻炼学生的实践动手能力；要定期在全院范围内对学生和教师的基本情况及心理状况做一个全面的调查，并将相关数据报学院做决策参考。

安院长还听取了社科系主任陈丁堂教授的工作汇报，他认为，社科系的教师工作责任心强，认真开展教学与学术研究，取得了很多有影响的成果。希望社科系在原有的基础上继续开展对社区管理与建设等问题的研究，百尺竿头，更进一步，为东莞经济社会双转型做出更大的贡献。
