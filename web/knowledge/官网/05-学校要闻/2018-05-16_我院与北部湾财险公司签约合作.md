# 我院与北部湾财险公司签约合作

5月15日下午,我院与北部湾财产保险股份有限公司举行合作办学签约仪式。周庆副院长等领导与北部湾财产保险股份有限公司东莞分公司负责人出席了签约仪式。

教务处处长赵书山介绍了我院保险学专业基本建设情况。他指出，此次与北部湾财产保险股份有限公司进行深度合作，旨在创新教学模式培养优秀的高素质保险专业人才。

北部湾财产保险股份有限公司东莞分公司副总经理黄郭彭表达了对保险专业人才的渴求，对合作办学培养应用型人才饱含期许。
