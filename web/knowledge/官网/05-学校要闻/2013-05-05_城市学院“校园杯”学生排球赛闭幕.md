# 城市学院“校园杯”学生排球赛闭幕

4月25日，东莞理工学院城市学院第一届“校园杯”学生排球赛在排球场顺利闭幕。

本次比赛由体育教学部组织实施，旨在提高学生的排球技术水平，促进体育课堂教学，丰富学生课余文化生活，增强学生的体质，为院排球队选拔优秀运动员。

经过为期两周紧张激烈的比赛，机电系代表队获得冠军，计信系代表队获得亚军，城环系代表队获得季军，政法系获得体育道德风尚奖。
