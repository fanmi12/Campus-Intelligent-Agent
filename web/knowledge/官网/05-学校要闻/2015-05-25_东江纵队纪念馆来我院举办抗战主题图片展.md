# 东江纵队纪念馆来我院举办抗战主题图片展

5月18日，由广东东江纵队纪念馆举办的“走进东纵”历史图片展在我院图书馆二楼展出。学院党委副书记章德胜和学生们共同观看了展出。

图片展按时间顺序分为“中国抗日战争的爆发”、“东江人民抗日武装的创建”、“东江抗日根据地的创建”、“华侨港澳同胞对东江抗战的支援”、“港九抗战与营救活动”、“敌后游击战争的发展”、“配合盟军夺取胜利”、“北撤山东转战南北”等八大部分。据悉，不少展出图片由“东纵”部分老同志及其后代提供。

观看展出的万佩珊同学对记者说，这些图片很值得一看，充分反映了当年抗日勇士不屈不挠的民族精神，让我们深感今天的幸福生活来之不易，理应倍加珍惜。
