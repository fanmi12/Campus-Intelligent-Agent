# 我院参加2014年广东省首场招生咨询会

6月15日，广东省2014年首场招生咨询会在阳江市阳江职业技术学院举行。来自全国的高等院校在宣传会上开展招生宣传，我院也派出工作人员参加了宣传，接受广大考生及家长的咨询。

我院今年将采取招生办统筹协调、各系部通力合作的招生宣传机制，积极参加部分省、广东省各地级市的招生咨询会议全面宣传我院的办学思路和办学成果。

据悉，今年广东省高考成绩放榜时间为6月25日前后，敬请广大考生关注广东省教育考试院相关网站。
