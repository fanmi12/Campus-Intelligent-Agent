# 省教育厅督查组到我院开展学生就业工作督查

4月23日，以广东白云学院副校长李望国为组长的广东省普通高校毕业生就业工作督查组到我院开展学生就业督查工作。

督查组专家在一天的督查时间里，听取了我院近年来学生就业工作的情况汇报，现场查看我院的就业办公场所、毕业生专用招聘和面试场地、就业政策宣传栏、就业心理咨询室、创业教育实践基地，组织召开应届毕业生代表座谈会、相关问卷调查，与毕业生座谈。此外，督查组还核查了就业工作相关资料，并就有关情况进行个别访谈。

督查组在反馈意见时表示，城市学院学生就业整体状况是好的，做了大量的工作，成绩斐然，但相对于社会和毕业生的要求来说，还有一定的提升空间。希望城市学院在“人员、场地、经费”等方面按有关文件加大投入提供保障；与政府做好对接工作，促使就业工作再上新台阶。
