# 我院开展宿舍安全检查工作

为了排查学生宿舍的安全隐患，确保学生生命和财产的安全，近日，学生处、保卫办、总务处、各系部辅导员及学生自律会的相关人员组成检查组，对学生生活二区进行了全面检查。

检查发现，部分同学仍有违规使用电饭煲、电吹风、电热棒等大功率电容器的现象。检查组成员耐心地向同学们宣讲消防安全知识和防盗注意事项。
