# 学院召开第五届工商模拟市场活动总结会

5月7日，学院在315会议室召开工商模拟市场总结会议。会议听取了城市学院第五届工商模拟市场管理委员会主任袁凤章同学的汇报。

据袁凤章同学介绍，本届工商模拟市场活动于4月19日开市，历时五天，共设学生摊位106个，商家摊位9家。几天的营销情况表明，工商模拟市场是城市学院特色教学的一个重要内容，是学生学以致用的大舞台，为参与者和组织者提供了极好的锻炼机会，受到学生的欢迎。学生参与的热情高，收获大，体会深刻，普遍盈利。据统计，盈利的摊主达到90% 。

袁凤章同学认为，本届“工模”活动有三个特点:一是主题鲜明，大力倡导绿色经营、消费理念。在营销活动中，加强了环境卫生工作与卫生监督，精心打造出了健康、绿色、卫生的校园风情街。二是购销两旺。整个市场设立了美食区、烧烤区、精品文化区等6大消费区。各摊主精心谋划,细心选料，用心制作，各色商品深受消费者的欢迎。虽然正值阴雨连绵，但由于经营有方，商品适销对路，90%的摊主盈利。三是管理有方。学院各职能部门通力合作，水电交通保障有力，市场运作正常，各摊主证照齐全。

院办、人事处、教务处、保卫办、管理系的有关领导,就如何办好下一届工商模拟市场发表了许多好的意见。
