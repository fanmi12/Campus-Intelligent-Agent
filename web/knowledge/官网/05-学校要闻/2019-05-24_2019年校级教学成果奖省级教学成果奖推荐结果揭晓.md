# 2019年校级教学成果奖省级教学成果奖推荐结果揭晓

5月20日，教务处根据《广东省教育厅关于开展2019年广东教育教学成果奖评审工作的通知》精神，组织校外专家开展了2019年校级教学成果奖评选及省级教学成果奖推荐评审工作，听取了成果申报人的现场汇报，对申报材料进行审查，并对申报人进行质询。

评审结果经教学工作指导委员会、校长书记办公会议审议通过，评选出2019年校级教学成果奖一等奖2项、二等奖1项、三等奖1项，推荐2019年校级一等奖1项、2017年校级一等奖1项申报2019年省级教学成果奖。
