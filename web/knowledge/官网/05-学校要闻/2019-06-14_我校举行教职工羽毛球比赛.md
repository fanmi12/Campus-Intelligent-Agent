# 我校举行教职工羽毛球比赛

6月13日，由学校工会组织的2019年“广发杯”教职工羽毛球比赛进入决赛。校党委书记、工会主席章德胜，副校长黄兢观看了比赛。

在历时两周、经过20多场次的角逐后，法学院与体育教学部以优异的表现并列获得第一名，智造院与机关二队分别获得第二名、第三名。

此次教职工羽毛球赛从6月3日开始，共有14支队伍、270余名球员参赛。比赛为羽毛球爱好者们提供了展现自我、切磋技艺的平台，使广大教职工以更健康的体魄和饱满的精神状态投入到工作之中。
