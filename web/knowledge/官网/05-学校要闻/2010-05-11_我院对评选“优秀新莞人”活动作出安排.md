# 我院对评选“优秀新莞人”活动作出安排

为贯彻东莞市评选“优秀新莞人”活动领导小组办公室文件精神，5月7日，学院在4405会议室召开职能部门负责人会议，研究部署我院开展评选东莞市“2010年优秀新莞人”的工作。会议由学院办公室主任王玉主持。

据悉，为鼓励在东莞工作期间表现突出的新莞人，推进东莞的经济社会发展，市委、市政府近日决定在全市开展评选“优秀新莞人”的活动。根据“评选办”的要求，学院决定于9月份之前，逐步开展宣传发动、发放填写《推荐表》、材料审核等程序性工作。
