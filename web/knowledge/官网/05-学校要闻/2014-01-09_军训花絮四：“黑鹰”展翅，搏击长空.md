# 军训花絮四：“黑鹰”展翅，搏击长空

“黑鹰”展翅，搏击长空

——大学生记者 孙钰银

统一整齐的黑色队服，严肃的纪律丝毫不逊色于军训学员们。亲爱的读者们，在13级军训中，你会在城院军训素质拓展训练中看到这么一支优秀的队伍—“黑鹰”队。他们就像直冲云霄、搏击长空的黑鹰一般，有着雄鹰一样的气魄。通过一轮轮的筛选，以及团学干事训练营长时间的培训，才打造成今天这支由16名优秀团学干事所组成的军训助理队伍。

为了让13级军训学员们在最短的时间里提高团结凝聚力以及相互合作的能力，三位专业培训师率领“黑鹰”队针对不同连队制定了不同的素质拓展项目。每天由这16名助理指导军训学员们完成不同的项目。

黑鹰队队员卜锦浩向记者反映，尽管训练辛苦，但是想到能引导和帮助学员们训练，感到很荣幸和欣慰。接下来的几天，我们仍将全力以赴地做好本职工作。

有一篇通讯稿是这样描写他们的：他们是生命力极强的黑鹰，奋力展翅，直击蓝天；他们是13级军训中不可或缺的重要团队之一。相信所有的军训学员们都会像他们那样，严于律己，心与天比高，做最骄傲的雄鹰。

拉歌大战

——大学生记者 王芬“十连。”

“来一个！”

“九连！”

“撤退！撤退！撤退！”

。。。。。。

站在正前方的教官拿着喇叭呐喊，底下的小军人们都附和着教官奋力的嘶喊。没错，这里就是足球场上激烈的拉歌大战现场。这些可爱的小军人们将白天的辛苦疲累都化作夜晚里高昂的歌声，个个连队都拿出自己吃奶的力气，歇斯底里的向其它连队拉歌挑衅，六连的教官甚至带着队员们来了个“大迁徙”，全体成员从跑道上转移到了足球场中央，高调的向十连发起挑衅。所有人的脸上都洋溢着兴奋，欢声笑语无处不在。

站军姿也是一种自我挑战

——大学生记者 陈欣茹

“双脚并拢,挺胸抬头,身体前倾,重心落于前脚掌,中指贴紧裤缝,拇指贴食指第二节,双眼平视前方。”教官重复强调这几条。一分钟,两分钟,五分钟,时间一分一秒地过去了，汗水打湿了前额的发丝。湖边吹来了一阵阵寒风，可是大家还是不为所惧，只是偶尔眨眨睫毛。或许大家想换个姿势,动一动腿脚，哪怕是一秒钟的弯曲，但是大家都知道那是不允许的。大家心里只有着一个共同的信念：坚持，挑战自我。

“站军姿是一种锻炼大家意志的方法，也可是说是一种自我挑战的方法”四连四排的班长说到。“当大家一起站成五列，每天早晨在散发着雾气的校道上站军姿的时候，尽管是很辛苦，可是还是很开心，我们每天都可以看到四排伙伴们努力的身影，希望在以后的几天中大家都能坚持下来，共同努力。”

今天你笑了吗？

——大学生记者 王芬

晨曦，鸳鸯湖边的校道上，十三连二排的同学们正在练习摆臂齐步走。也许是还没有睡醒的缘故，等队伍走出了几步远后，教官看到有个迷糊蛋一直处于掉队状态，低着头，走路歪歪斜斜的，好像风一吹就会倒下一样，教官走近了才发现，原来这位同学一直都在“闭目养神”中，气得教官直咬牙跺脚。

然后教官手舞足蹈的示范同学们各种搞笑的错误动作，可爱的模样惹得大家的困意都跑掉了，站着笑个不停。又一天的训练历程在这欢乐嬉戏中开启了。

小伙伴，好好干

——大学生记者 丁雪冰

落花纷飞的校园整日穿梭着一群清一色着军训服的新生群体，女孩子们嬉笑打闹的声音更增添了校园的活力。随处可见的是学子们踏着整齐一致的步伐向前方挺进，雄赳赳，气昂昂，豪情满胸怀。

日复一日，军训也逐步接近尾声，一丝莫名的紧张感也渐渐在队中萌生了，我们加快了训练的步伐，目光灼灼地觊觎2014年新生军训的桂冠。

相机咔嚓咔嚓，将我们这个大家庭的每个身影﹑每张面孔瞬间定格，变成一段美好的回忆。

今天，我看到了男生们与教官之间的亲密互动，既忍俊不禁又从中感受到一股暖意。人与人之间情感的建立，有时候就是这样如此的简单大方。我们都将从中学会如何巩固维系一个庞大的组织，这个过程需要爱与尊重、信任等等。

最美不过夕阳红，我们又在一阵嬉笑声中结束了一天的训练，或许会感觉很困很乏，但心却是暖暖的，小伙伴，好好干??????
