# 我院“优质生源基地”新添粤西三所中学

日前，我院“优质生源基地”建设新添徐闻中学、湛江市第二中学、雷州市第八中学三所中学，并建立起了长效合作机制，加强了与粤西中学的了联系，为共同培养优秀人才搭建了平台。

12月19日至21日，招生就业处孔增强处长等一行前往粤西地区，先后走访徐闻中学、湛江市第二中学、雷州市第八中学，为三所中学进行了“东莞理工学院城市学院优质生源基地”授牌。据了解，10多年来，这三所中学为我院输送了一批批优秀学子。他们习惯好、基础实、素质高，受到各院系的好评。

孔增强处长还回访了2009届优秀校友陈沿龙、傅萱。
