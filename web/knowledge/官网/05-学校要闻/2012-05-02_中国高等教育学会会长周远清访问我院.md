# 中国高等教育学会会长周远清访问我院

周远清会长（左）在“桂园”栽下一棵桂花树4月28日，教育部原副部长、中国高等教育学会会长周远清在院长杨敏林的陪同下对新校区进行参观访问。

在参观了新校区校园后，周远清会长还来到位于荔香苑前的“桂园”，和陪同访问的东莞理工学院原教务长林养素一同飞锹培土，浇水灌溉，亲自种下了一颗芳香四溢、生机勃勃的桂花树，并现场亲笔签名以示纪念。

随后，宾主双方还在法商楼一楼会议室座谈交流。杨敏林院长向周远清会长介绍了我院办学9年来取得的成就及新校区的建设与发展。

周远清会长对我院的建设、发展所取得成就给予了充分肯定，详细了解了我院的专业设置情况，对广受东莞地区欢迎的会计、社工等专业给予了高度关注，并根据东莞的经济特点提出了寄望和建议。他希望城市学院坚持特色，努力创办成为一座具有鲜明特色的现代大学。
