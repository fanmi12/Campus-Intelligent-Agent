# 我院召开2017年引博专项项目立项评审会

12月20日，学院召开2017年引博专项项目立项暨青年基金项目结题评审会。院领导王卫平、高香林、黄兢、林江龙以及第四届学术委员会全体成员参加了会议。会议由黄兢副院长主持。

研发处赵书山处长宣读了《关于调整第四届东莞理工学院城市学院学术委员会成员的通知》。

王卫平院长为新聘任学术委员颁发了聘书。

赵书山处长还介绍了今年到期青年发展基金项目结题情况及结题要求，院级重大科研培育项目（引博专项）立项要求、申报情况和校外专家评审结果，以及院级机构申报情况。

经学院学术委员会集中审议、投票表决，“青年教师发展基金项目”共有9项通过院内结题评审，1个项目未通过结题验收予以延期结题，2项项目论文待发表予以暂缓结题，5个项目终止研究，11个项目获准延期结题；“引博专项项目”共7项通过立项评审，其中自然项目类1项，人文社科类6项。此外，“机器感知与智能装备研究所”等三个机构获得院级科研机构立项。

王卫平院长指出，学术活动的开展离不开学术组织，院学术委员会作为院内最高学术机构，要担负起营造良好的学术诚信和引领学术道德风尚的职责。调整后的第四届学术委员会，专业分布、队伍结构更趋合理。各位委员要认真负责地参与学术评价，既要坚持原则、严肃认真，又要科学公正、实事求是，作出客观判断，切实引领和带动广大教师维护学术尊严、珍惜学术荣誉，营造学院自由开放、健康向上的学术氛围。
