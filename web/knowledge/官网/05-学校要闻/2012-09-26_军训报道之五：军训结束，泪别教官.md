# 军训报道之五：军训结束，泪别教官

26日上午，12级新生在校运动场进行了军训汇报表演并举行了开学典礼，为连续10天的军训画上了完美的句号。

久等用餐教官，只为合影留恋

开学典礼结束后，教官们在荔香园饭堂四楼厅堂内聚餐。而11点多，厅堂门外聚集了很多身穿迷彩服的12级新生。他们一群群结伴等候在堂内用餐的教官，不时把头向前探，寻找自己的教官。

“你们在这里等多久了？”“有一个小时了，我们10点多来吃饭，吃过饭就等到现在了。”“你们还要等下去吗？”“当然要啊，我们要和教官合影留念。”几个小女生在堂外静静等候着。曾同学激动地告诉记者说：“我们都很舍不得教官，一开始觉得教官很严、很凶，但后来慢慢觉得教官很好，很有人情味。在运动场上，有同学摔倒了，教官很关心，我们都很感动。我们今天汇演做得不是很好，但教官还反过来安慰我们。”时间过去了一个多小时，他们还在外等候着，而她们的同伴也去买糖果作为礼物送给她们亲爱的杨教官。

“你们很棒！”

闫旭教官高声向18连三排的学生说：“你们很棒！”

四楼楼梯的拐弯处停留了一大群同学，一位身穿白色军服的教官被迷彩服围在中间显得特别的突出，他是18连三排的闫旭教官。一大群学生围着教官一一要合影，你帮我拍，我帮你拍，“硬要”教官好好配合。其中三位同学还忍不住落泪了，教官是不停地安慰他们。

一群男生，一个手拿一袋苹果，一个拿着墨镜，特意拿着小礼物来送别和感谢他们的教官。“他对我们很好，我们舍不得教官，我们二排的同学还一起订了一个模型要送给教官，但因为没能及时送来，只能送到教官家了。”教官说，“你们都很棒，没有一点怨言，很能吃苦！”

“教官，谢谢你们，常来校园看看。”同学们一遍又一遍地感谢亲人解放军。13时25分，接送教官的车来了。这些教官们依依不舍地告别城院返回军营。
