# 【众志成城 抗击疫情】我校召开疫情防控工作会议贯彻落实全省教育系统防控疫情工作视频会议精神

2月4日上午，广东省教育厅召开全省教育系统防控新型冠状病毒感染的肺炎疫情工作视频会议。我校疫情防控工作领导小组成员及相关职能部门负责人在行政楼212会议室参加了视频会议。随后，我校召开疫情防控工作会贯彻落实视频会议精神，对我校开学方案进行了研究和部署。

在视频会议上，省委教育工委书记，省教育厅党组书记、厅长，省教育厅防控新型冠状病毒感染肺炎疫情工作领导小组组长景李虎同志介绍了全省教育系统疫情防控情况，详细解读了《中华人民共和国传染病防治法》《广东省教育厅关于全力防控疫情确保开学安全的通知》，并对进一步做好疫情防控工作提出了相关要求。

随后，我校当即召开了疫情防控工作会议予以贯彻落实。学校防控领导小组会议听取了防控工作情况及面临的困难和挑战的报告，对学校的开学方案进行了讨论、研究和部署。

会议要求，要全覆盖、无遗漏、精准掌握疫情防控重点地区的教职员工、学生分布情况；要全覆盖、无遗漏、精准掌握疫情防控重点地区的教职员工、学生在校内各院系、各年级、各班级分布情况；要全覆盖、无遗漏、精准掌握每个教职员工、学生，特别是疫情防控重点地区的师生返校前14天的身体健康状况，为开学工作打好基础。后勤保卫部门要不惜代价做好开学的各种物资储备、软硬条件的准备工作。

会议研究决定，学校将根据疫情形势和防控情况，科学研判后再确定具体分二级学院、分年级、分班级，分省份、分期、分批有序返校的时间，具体安排以学校正式通知为准。

会议强调，此次疫情防控工作事关重大，每位师生员工都要高度重视，要有政治高度和大局观，每位师生员工都有责任和义务配合学校的防控工作，特别是在信息填报和返校时间安排上，若出现不配合学校工作的，学校将依据《传染病防治法》、《公共安全法》及学校的相关规定对当事人给予通报批评、警告，甚至开除等处分。
