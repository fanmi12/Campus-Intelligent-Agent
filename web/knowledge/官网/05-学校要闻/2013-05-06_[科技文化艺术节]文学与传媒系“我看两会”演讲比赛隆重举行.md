# [科技文化艺术节]文学与传媒系“我看两会”演讲比赛隆重举行

5月5日，文学与传媒系第六届口语表达大赛“我看两会”在学术报告厅隆重举行。文传系系主任邓星明教授出席并观看了比赛。

据悉，比赛分为主题演讲、巅峰对决和终极挑战三个环节。在主题演讲中，选手们从食品安全、三农问题到医患关系、国民素质等方面讲述了他们对于两会的了解，对国家大事、生活要事的关心与思考。巅峰对决中，选手们以辩论的形式就当下热议的新闻展开激烈的对决。他们的沉着冷静和对时事的独特见解让台下的观众纷纷叫好。而最后的终极挑战，选手们更是使出自己最强劲的本领，分别就“两会”的内容作即兴演讲。

通过三个环节的激烈对决，李丽卿胜出夺得冠军，林娟玲、张宝莹获得二等奖，李祖辉、冯茜、陈晓慧获得三等奖。
