# 新校区开展“百年城院•百年爱心林”大型植树活动

9月3日，秋风习习，旌旗招展，我院新校区人声鼎沸，热闹非凡。一场旨在打造学院著名园林景观的“百年城院?百年爱心林”大型公益植树活动在这里紧张进行。

据悉，城市学院董事长麦照容，董事麦照平、麦燕红、麦燕娣，城市学院新校区筹建办副主任麦绮琳，广东鸿发集团及其所属公司以个人或企业的名义向新校区捐赠了十多棵、价值百万元的名贵树木。

位于新校区教学中心广场中心的一颗挺拔遒劲、气宇轩昂的百年秋枫，是由广东鸿发投资集团有限公司捐赠、麦照容董事长和董事麦照平、麦燕红、麦燕娣飞锹栽植的。

在图书馆大门前，麦照容董事长和麦照平董事又亲自培土种下各自捐赠的两棵高大俊朗的香樟。枝繁叶茂的香樟树与图书馆相得益彰，神韵初具，互为风景。

与此同时，董事麦燕红、麦燕娣、副主任麦绮琳及各分公司领导和嘉宾，分别在综合馆、校园北门、电子信息大楼、报告厅、学生食堂等处，种下了香樟、无忧树、桂木、母生树等一棵棵名贵树木，为新校区增添了一道道新的风景线。
