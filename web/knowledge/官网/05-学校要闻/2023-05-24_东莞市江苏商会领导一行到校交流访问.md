# 东莞市江苏商会领导一行到校交流访问

5月22日下午3时，东莞市江苏商会会长张锡林，党支部书记马锐，执行会长成兵、施元标，常务副会长庞爱华、张家贵，办公室主任杨书琴一行7人到我校进行交流访问。学校校长陈明，副校长陈葆华，校长助理孔增强、任广新，教学科研部部长杨勇虎、学生处副处长林蓉热情接待了张锡林会长一行，并在行政楼212会议室举行交流会。

会前，东莞市江苏商会张锡林会长一行在我校陈明校长的陪同下参观了我校图书馆、荔香园食堂、综合馆、智能制造学院工程训练中心、7C智慧教室、商科实训中心等学校教学与生活设施。东莞市江苏商会领导一行对我校的办学环境、生活设施和教学科研水平表示称赞。

会上，大家观看了学校的宣传片。陈明校长对东莞市江苏商会会长张锡林一行到我校交流表示热烈欢迎，他谈到，江苏在东莞企业有500家，实力雄厚，专业广泛，校企合作有很大的空间。希望双方能够加强校企合作，共同培养适应企业发展需要的人才，为企业输送更多适应产业发展需求的创新型技能人才做出贡献。

陈葆华副校长介绍了学校的基本概况、办学特色等情况。她表示学校目前设有14个教学单位，48个本科专业，建立了97个专业实验室、218个校外教学实践基地、24个校级科研机构，与20多家科研院所和企业建立了“产学研”关系。现有机械工程，工商管理2个省级重点培育学科，软件工程、设计学、社会工作、保险学4个校级重点学科。她表示，希望校企双方能深入合作、通过产教融合，互相促进，在人才培养的模式上能更切合企业需求。陈葆华副校长还提出双方成立企业创新研究中心的构想。

东莞市江苏商会会长张锡林对于我校办学以来取得的成绩和荣誉表示赞许。他表示，此次携部分商会会员单位到访，就是希望多了解我校应用型人才培养，希望双方在人才培养、校企合作、产教融合等方面开展合作，为企业输送更多适应产业发展需求的创新型技能人才。

与会的双方还就人才培养、教学科研等具体方面进行了深入交流。接下来，我校将与东莞市江苏商会进一步加强交流与合作，促进优势互补、加强资源共享，共同探索校企合作、产教融合的新模式，为提高人才培养质量，共同为经济和社会发展做出积极的贡献。
