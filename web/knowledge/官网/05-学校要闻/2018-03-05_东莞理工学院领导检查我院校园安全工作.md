# 东莞理工学院领导检查我院校园安全工作

新学期开学在即，3月4日下午,东莞理工学院党委副书记吕琦元来我院检查校园安全工作，并与王卫平、章德胜、刘玉侠等院领导及有关部门负责人进行了座谈。

在听取了我院校园安全工作汇报后，吕琦元副书记传达了上级党委的有关精神，要求认真宣传贯彻落实好党的十九大精神，进一步加强党的领导和建设，切实做好新学期的政治安全、网络安全、食品卫生、治安消防等各项安全工作，关爱师生，维护校园安全稳定，促进学院各项事业健康发展。
