# 学院对新校区实验教学设施的建设与管理工作开展大检查

近日，学院组织新校区管委会和实验中心有关工作人员对我院新校区实验教学设施的建设和管理情况进行了全面检查。

参加检查人员针对发现的问题与相关部门进行了沟通，提出了加快实验室建设和加强实验设施使用管理的意见和措施，特别是针对化学实验室配液系统、电子工艺实验室通风系统、金工实习工厂实习安全管理等提出了建议。

实践教学是培养应用型人才的主要手段，是培养学生实践动手能力和创新精神的重要方法。随着我院学生规模的迅速扩大和新校区学生陆续进入专业基础课学习阶段，开设的实践教学课程将越来越多。据悉，为保证教学需要，新校区已建、在建和拟建的实验室与实习中心达70多个，拟投入资金5000万元，完全能满足教学需要。
