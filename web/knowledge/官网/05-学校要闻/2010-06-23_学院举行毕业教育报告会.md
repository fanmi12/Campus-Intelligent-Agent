# 学院举行毕业教育报告会

“准备好了吗，同学们？”“准备好啦！”千余名2010届毕业生代表信心满满地向院长表示。6月22日，学院在大礼堂举行毕业教育报告会，院长安少华为毕业生上了在校期间最后的一堂课。

党委副书记朱冰主持报告会，1000多名毕业生代表听取了院长的报告。

他在题为“毕业同学们，你们准备好了吗”的报告中指出，每年的六月，是年轻人激情燃烧的岁月，中考、高考、大学毕业生就业找工作都集中在这个月，今年尤为特别，世博会、世界杯也正在火热进行中。由此联想到，大学好比是一场精彩的球赛，毕业生是球员，父母是球迷，老师是教练，社会是裁判。现在，同学们就要毕业了，即将开始下半场的比赛。

在讲到如何使下半场的比赛更为精彩时，安院长向毕业生提出三点希望：第一，追求心中的理想，坚持理想才会有做好事情的动力；第二，哨响中场，需要我们继续努力；第三，细节决定成败，今天的磨炼代表明天的收获。

安院长最后指出，同学们在今后的工作中，要充分利用好同学校友、师生情谊两大资源，加强同学校的联系，把自己的事业做大做强，为祖国的经济建设和社会发展服务。
