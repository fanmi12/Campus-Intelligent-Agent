# 【办学战略思想讨论之五】建设高素质的师资团队，谋求学院新的发展

高校教育是人文属性最强的事业，它集中体现在教书育人活动是一种人之于人的关怀与培养。教师通过传播自己的学识增进学生的知识，通过发散自己的情感和人格去陶冶塑造学生的品格，而学生正是在听取教师一次次教学讲授之中，一次次接触教师的谈话指导之中汲取营养逐渐成长的。这一项细致的周期长的培养人的工作，在耳濡目染、心与心的交流中进行，特别需要教师真情付出。因此教师是办学之本，办一所高水平的大学的关键建设一支高素质的教师队伍，学校无论是做重大决策还是抓常规管理都要牢记这一点。

建设高素质的教师队伍操作起来就是要让优质的教师进得来、用得好、留得住。“栽好梧桐树，引得凤凰来。”吸引各专业的高素质人才进校当教师；进来后能让他们集中精力安心教学，做到心系学校；让老师们热爱学校，以校为家，愿同学校的发展共进退。任何情况下都要避免教师队伍大进大出。要达到此局面，需要做到事业留人、待遇留人、制度留人。要让老师感受到城市学院的高层管理是在认认真真地办学，学院是蒸蒸日上向好发展的，年轻人在这里有干头、有奔头、有发展前途。学校的待遇相对较高，在一些细节问题上也体现出关心人、为师生着想，使老师们感受到有人情味很温暖。制定科学的管理制度，让制度既能约束人，也起到激励人的效果。

总之，用心地建设师资团队，凝聚人心、形成合力是关乎学院未来发展的一个重大课题。
