# 我校对口帮扶仁化县中小学教师信息技术提升培训顺利举行

根据省政府、省教育厅的相关文件精神，为积极推动基础教育深化改革和高质量发展，东莞城市学院积极发挥办学优势，主动聚焦问题，提出补齐短板的具体方案，结合仁化县中小学教师及学校办学的具体情况组织落实结对帮扶工作。11月24日至26日，东莞城市学院为韶关市仁化县中小学教师开展了信息技术提升培训。本次活动由学校教务处、教师教学发展中心具体组织和协调开展。

11月24日下午，韶关市仁化县中小学教师信息技术提升培训班共49位学员前往松山湖未来学校、西溪小学实地考察交流。培训班学员首先抵达松山湖未来学校，在校务办赵丽娟老师的带领下，大家参观了未来智谷服务中心、智创科普体验馆等特色主题空间。赵丽娟老师从办学历程、办学理念、办学特色等多个维度向学员介绍了学校的基本情况。随后，培训班学员来到寮步镇西溪小学参观学习，西溪小学校长谭贵新及行政人员热情接待并全程陪同，谭贵新校长向学员介绍学校整体情况，包括办校历史、生源、学校规划以及学校的教学教育理念等。

11月25日，培训班学员来到东莞城市学院参加信息技术提升专题培训活动。在培训活动的开班仪式上，陈葆华副校长代表学校对学员们的到来表示热烈欢迎，介绍了城市学院的办学特色和近年来取得的主要成果。同时，陈校长希望学员们经过培训，将所学信息技术更好地应用到实际工作当中。

本次培训主讲教师分别为我校语言文化学院刘智锐老师和图书信息中心陈显龙主任。刘智锐老师的培训内容包括国家中小学智慧教育平台的使用方法；钉钉平台个人版的使用技巧，特别是AI技术的使用；利用人工智能手段制作APP；情景教学法示范教学等内容。陈显龙主任向学员们讲解了人工智能技术在中小学教育教学中的应用，重点就ChatGPT软件在中小学教学中的应用做了细致讲解，引起学员们的极大学习热情，学员们亲自体验ChatGPT的强大功能后意犹未尽，收获满满。

在结业式上，仁化县一中周小宁老师代表学员发言，他说，通过培训，学习了许多新的信息技术知识和技能，接触了一些高效的学习方法和工具，对信息技术有了更深入的了解和掌握，相信在未来的工作中，在处理技术相关的挑战和难题时，学员们应该能够更加从容地找到最佳解决方案。信息技术提升培训让大家拓宽了视野，提高了技能，增强了解决问题的能力，这些收获将对我们的个人发展和职业生涯产生积极影响。在全体学员的积极努力下，在城市学院教务处和教师教学发展中心及有关部门和单位的配合下，本次东莞城市学院对口帮扶仁化县中小学教师信息技术提升培训工作顺利完成，所有学员圆满完成学习任务。

结业式上，陈葆华副校长为学员们颁发了结业证书。通过结对帮扶，实现了资源共享，经验分享，均衡发展，发挥了我校的辐射作用，也更好地体现了结对帮扶优势，助力培训班成员将学习成果应用于教学实践，提升教育质量，这些工作都极具现实意义。
