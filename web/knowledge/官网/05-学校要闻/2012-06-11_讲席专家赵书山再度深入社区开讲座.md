# 讲席专家赵书山再度深入社区开讲座

6月6日，由东莞市科学技术协会和东莞市麻涌镇政府联合主办的，题为“社区管理与服务”的（第二十二期农村党员干部科学素质系列培训）在麻涌大步社区举行。城市学院讲座专家、政法系副主任赵书山副教授应邀做专题报告。该镇科协系统的干部和基层（社区）党员干部250多人参加听报告。

赵教授着重讲述了农村社区建设、城市化过程农村社区向城市社区的过渡、社区管理与服务的模式及管理创新等方面的问题并就当前社区建设中存在的问题与党员干部进行了交流。

据悉，赵书山副教授还将陆续为厚街、黄江、大朗和万江等镇的基层党员干部做“社区管理与服务”系列专题讲座。
