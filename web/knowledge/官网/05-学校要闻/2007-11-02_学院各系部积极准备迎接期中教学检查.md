# 学院各系部积极准备迎接期中教学检查

为进一步改进教学工作，为迎接教育部对我院教育工作的合格评估作好准备，学院将于第9—11周（教学周）开展期中教学检查。

检查内容包括两个方面: 一是检查教师的教育教学工作，二是检查系（部）教学管理工作。采取听汇报、看材料、开座谈会的方法，客观评价各系（部）的教育教学工作。

检查的重点主要是各系（部）教学档案管理和实验教学的落实情况，其中包括管理规章制度、人才培养计划、课程教学大纲、实验室建设、实习基地建设、教学改革与研究、师资队伍建设情况，以及教学周历、师生考勤、作业批改、考试试卷、试卷分析、学生成绩等方面的文字记录材料。检查形式也从普查改为抽查，届时将临时检查，临时通知。

据了解，各系部对这次检查十分重视，都召开了迎检会议，制定期中教学检查工作计划。如计算机与信息科学系采取教研室先自查，系部然后再查的方法，防止出现“盲区”。机电系成立了期中教学检查领导小组，教师互评，查缺补漏。
