# 孔增强处长受邀作客东莞电台助力考生填报高考志愿

高考已进入填报志愿、选专业的关键时期，6月27日晚，我院招生就业处孔增强处长受邀作客“畅想1075”东莞电台交通广播，为广大高考考生及家长解读今年高校招生新政策，分析高考志愿填报误区，就考生家长关注的问题进行答疑解惑。

在节目互动中，针对考生和家长是“先选学校还是先选专业”、“哪些专业就业好”、“怎样防止掉档”、“如何循序渐进定位自己的志愿”等问题，孔处长就高考志愿填报方法和技巧、志愿填报的原则、如何规避志愿填报的风险、如何选择院校和专业以及就业趋势的分析等方面，详细地解答了考生家长的担忧和疑惑。
