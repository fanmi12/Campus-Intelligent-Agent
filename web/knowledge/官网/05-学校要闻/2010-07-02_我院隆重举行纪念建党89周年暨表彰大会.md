# 我院隆重举行纪念建党89周年暨表彰大会

表彰大会会场250名新党员庄严宣誓

领导为先进集体和优秀个人颁奖

党委书记朱志德在大会上讲话

优秀教师、学生共产党员代表发言7月1日，中共东莞理工学院城市学院委员会召开党员大会，隆重纪念中国共产党建党89周年，表彰2009-2010学年度先进基层党组织、优秀党员和优秀党务工作者。会议要求广大党员勇于探索加快转变经济发展方式，开拓进取，“创先争优”，教书育人，发挥先锋模范作用，为学院实现又好又快的发展作出新的贡献。

东莞理工学院党委书记周致纳，东莞理工学院党委委员、副校长、城市学院院长安少华出席了会议。城市学院党委书记朱志德、副书记朱冰及党委委员王玉、夏勇、章德胜在主席台就坐。党委委员、院办主任王玉主持会议。

大会首先举行新党员入党宣誓仪式。250名新党员面对鲜艳的党旗，在党委委员、学生处处长章德胜的领誓下，庄严地宣读了入党誓词。“此时此刻，我感到非常光荣，也感到责任的重大。”计算机与信息科学系新党员沈剑翘老师表示，一定要从思想上完全入党，教好书，育好人，为党旗添彩，为学院美好的明天奋斗。

会议认为，在过去的一年里，我院各级党组织和广大党员，在追求“上水平，创特色，树品牌，谋发展，创建省内一流本科独立学院”办学目标的道路上，积极开展“创先争优”活动，以教学为中心，以育人为己任，充分发挥了共产党员的先锋模范作用和党组织的战斗堡垒作用，涌现了一大批先进基层党组织、优秀共产党员和优秀党务工作者。为此，大会授予教辅党支部、文学与传媒系党总支、财经系党总支为先进基层党组织，吴运建等 40人为优秀党员，孔增强、李海冬为优秀党务工作者等荣誉称号。

党委书记朱志德在大会上发表讲话。他说，今天的大会，就是缅怀先烈，继承传统，发扬成绩，再铸辉煌。城市学院建院6年来，在东莞理工学院党委和行政的正确领导下以及党员同志的不懈努力，取得了令人瞩目的成绩。

在学院面临新一轮发展的形势下，朱书记要求各级党组织和广大党员，要深入开展“创先争优”活动，进一步推进学习型党组织建设。他进一步强调，开展“创先争优”活动，就是要以深入学习实践科学发展观、加快转变经济发展方式为主题，以创建领导班子好、党员队伍好、工作机制好、工作业绩好、群众反映好的“五个好 ”先进基层党组织，以争做带头学习提高、带头争创佳绩、带头服务群众、带头遵纪守法、带头弘扬正气的“五带头”优秀共产党员为主要内容，达到推动科学发展、促进社会和谐、服务人民群众、加强基层组织的总体目标。“创先争优”活动是学习、实践科学发展观的深入和延伸，同时也是在基层党组织和党员中开展的一项经常性工作。“创先争优”活动的重点是创新活动内容和形式，进一步提高党组织的战斗力和凝聚力。希望各级党组织和广大党员，要积极投入到“创先争优”活动中去，为构建和谐校园、为学院美好的明天而共同努力。
