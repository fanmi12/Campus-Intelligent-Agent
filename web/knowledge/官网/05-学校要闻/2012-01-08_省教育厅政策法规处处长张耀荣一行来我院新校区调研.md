# 省教育厅政策法规处处长张耀荣一行来我院新校区调研

张耀荣处长一行参观考察新校区图书馆1月5日，广东省教育厅政策法规处处长张耀荣、副处长石勰平等一行3人来我院新校区调研。院领导安少华、朱志德、杨敏林等热情接待了张处长一行。双方在法商楼会议室召开座谈会，就民办教育的办学发展问题进行了深入的交流与探讨。

座谈会前，张耀荣处长一行参观考察了新校区综合馆、报告厅、图书馆等教学设施。对新校区的建设和教育教学工作给予了高度评价。
