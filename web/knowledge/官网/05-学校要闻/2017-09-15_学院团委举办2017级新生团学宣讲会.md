# 学院团委举办2017级新生团学宣讲会

9月14日晚，由我院团委、学生会主办的2017级新生团学宣讲会在综合馆举行。

宣讲会上，院团委下设办公室、组织部、宣传部、第二课堂项目管理中心、大学生创新创业发展中心等五个部门，院学生会所属17个部门，各院系团委、学生会等组织分别通过生动的视频宣传、诙谐的情景剧、精彩的演讲等新颖活泼的形式，向新生进行了展示与宣讲，取得了良好的宣传效果。
