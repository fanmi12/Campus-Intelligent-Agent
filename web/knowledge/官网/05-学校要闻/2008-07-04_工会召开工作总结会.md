# 工会召开工作总结会

7月3日

下午，城市学院工会召开本学期工作总结会议，工会委员、工会小组长参加了会议。

工会专职干部刘红艳老师对本学期工会工作进行了回顾与总结。与会人员讨论了工会下学期工作、活动计划。最后，章德胜主席对本次会议做了全面的总结，强调了工会在学院董事会领导下的院长负责制管理模式中的地位与作用，指出教职工代表大会是教职工抒发民情民意和参与民主管理的重要阵地，并提出工会要在坚持搞好教职工喜闻乐见的常规活动的基础上有所突破，争取让更多的教职工参与到工会的各项活动中来，使工会成为全院教工的温馨之家。
