# 我校荣获第三届广东省学校国旗护卫队交流展示活动一等奖

5月8日，第一届广东省学校国防教育成果交流展示活动在广州科技贸易职业学院举行，共有来自广东省108所学校国旗护卫队参赛。我校国旗护卫队在刘玉侠副校长、后勤保卫处处长王锦锋、副处长刘维仝等带领指导下，以标准规范的动作、昂扬的精神风貌脱颖而出，荣获交流展示活动一等奖。

据介绍，为了在此次交流展示活动上取得好成绩，国旗护卫队平时加强刻苦训练，以“一日护卫国旗，终身无上荣光”为动力，用汗水铸就出了军人的威武雄壮气质，用奋斗的青春践行爱国主义精神，最终斩获一等奖。这次活动是由省教育厅、省国动委办公室、省人民政府征兵办公室、省军区战备建设局、省军区政工局联合举办的

当日下午，我校国旗护卫队返校时，王卫平校长会见了全体队员并合影留念。
