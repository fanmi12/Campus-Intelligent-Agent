# 这场比赛，我校成为晋级国赛的广东唯一民办高校

近日，传来喜讯！在“正大杯”第十三届全国大学生市场调查与分析大赛广东赛区（本科生组）总决赛在暨南大学落幕。我校数字经济学院参赛团队与暨南大学、深圳大学、广州大学、汕头大学、广东外语外贸大学等高校展开激烈竞争，凭借扎实的专业能力和出色的临场应变能力，力压众多211高校挺进13强、晋级国赛，成为晋级国赛的广东唯一民办高校。

团队合影

本次大赛共有45所高校共计549支队伍（被分为13个组）参加角逐，经过专家盲评，每组前两名总计26支队伍进入现场总决赛。东莞城市学院数字经济学院由方俊棠、段美伊、林茂佳、宋嘉怡、王梓欣同学组成的“掂过碌蔗小分队”成绩突出，顺利入围，对于团队负责人方俊棠同学而言，更是第二次率领团队闯入省决赛，并最终实现了新的突破。

赛后，老师们带着大家庆祝！他们吃着暨南大学的面包，纷纷表示要到天津去吃“狗不理”包子，吃天津“大麻花”！

会后庆功－吃饱以后再战天津

团队成员的朋友圈

这次能在省赛上取得突破，并进军国赛，得益于数字经济学院高度重视本次比赛。数字经济学院执行院长侯瑞瑞多次组织团队会议，了解参赛团队的具体情况，提出有针对性的建议和指导。陈孔艳、杨丽君、张超、熊炬成等专业老师在整个备战过程中认真指导、精心策划，从选题到数据处理，从分析方法到呈现形式，每一环节都详尽把关，确保作品的准确性和可信度。数字经济学院学工口全力配合满足参赛团队的演练场地、设备等方面的需求，并积极宣传推广参赛团队的优秀表现。团队成员们不负众望，针对校选拔赛发现的问题进行了充分深入的思考，制定详细的分工方案，反复演练，密切协作，互帮互助，不断完善和改进作品，最终推动作品达到最佳状态，在省决赛中发挥出色。

特别值得一提的是，团队成员们根据调研报告主题和PPT模板发挥创意，对参赛服装进行设计并开展数字化打印，获得了评委的一致好评。团队服装成为了本次比赛的一大亮点。这样的队服，太有创意了！

数字经济学院一直注重学生实践能力的培养，坚持以赛促建，数据育人，现已初步形成“研教赛创”的人才培养闭环，形成以“三下乡”社会实践调研的数据搜集端，全国大学生市场调查与分析大赛与广东省社会治理大赛的比赛与项目孵化端，挑战杯与互联网＋的大赛输出端，最后形成学生的项目创新创业端的人才培养闭环。

学校老师和同学们在一起

执行院长侯瑞瑞介绍：“数字经济学院在2022年暑期‘三下乡’社会实践活动收获荣誉颇丰，累计获得项目、个人荣誉共27人次。近两年我院累计获得国家级奖励15项，省级奖励24项。广东大学生科技学术季活动，由共青团广东省委员会、广东省教育厅、广东省科学技术厅等部门联合举办，我院2022年获省级奖励15项，其中特等奖2项（全省特等奖仅25项）。2023年第十七届‘挑战杯’哲学社会科学类社会调查报告校内选拔成功晋级决赛的14支队伍，有13支队伍来自前期调研比赛孵化的项目。2022年获历史性突破，挑战杯省赛金奖，同时孵化凌创科技电商公司，产学研一体化深入展开。”

“以赛促建，数据育人”正是数字经济学院一直秉持的理念，未来学院将继续深入推进人才培养模式改革，为学生提供更多更好的实践平台和机会，培育更多有实践能力和创新精神的优秀人才。

从赛事的准备、到校赛、省赛的结束，近半年时间展现了团队成员们的活力、努力和毅力，沁满了老师们的心血和付出。老师们表示，将继续努力耕耘，同时把这份热爱继续传递下去，共同温暖和鼓励孩子们不断前行，展现数字经济学院的育人成果和精神风貌。

从暨大回程时，同学们一路欢声笑语，回味着赛场上的难忘时光。

赛后，老师、同学们和业内专家一起庆功，同学们上纷纷说道，省决赛虽已过去，但绝不满足于此，一定要进军“狗不理”，在天津财经大学举行的全国总决赛中取得好成绩！

两个月后，期待他们从天津发回捷报！
