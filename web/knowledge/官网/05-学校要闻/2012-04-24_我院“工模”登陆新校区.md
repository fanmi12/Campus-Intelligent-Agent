# 我院“工模”登陆新校区

我院第七届工商模拟市场续上周在莞城校区成功举办之后，4月22日再度登陆新校区。

23日傍晚，工商模拟市场在新校区举办了隆重的开幕仪式，主题为“携手经营 创业共赢”。这也是工模首次在新校区举办。院长杨敏林，党委副书记朱冰，管理系主任罗余才教授，新校区管委会副主任麦绮琳及各部门负责人参加了开幕式，并为活动剪彩。

罗余才主任在开幕式上做了讲话。他表示，本届工模分别在新、旧两个校区错时举行，各具特色，活动不仅培养和锻炼了大学生管理和自主创业的能力，同时也让同学们通过实践对社会及市场的情况有所了解。管理系学生会分会主席张梦雅同学还向摊主代表颁发摊位营业执照。开幕式为现场师生呈上了精彩的歌舞、跆拳道表演以及激动人心的抽奖活动。

据悉，新校区工模市场共设有93个摊位，集美食、烧烤、时尚与综合为一体，分别位于荔香苑食堂正门广场及学5、学6宿舍间的小广场。
