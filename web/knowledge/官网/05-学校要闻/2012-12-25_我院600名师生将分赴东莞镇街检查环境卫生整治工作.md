# 我院600名师生将分赴东莞镇街检查环境卫生整治工作

按照市委市政府整治环境卫生的工作部署，进一步巩固整治环境卫生工作成果，12月22日，市环卫整治办在我院学术报告厅召开2012年东莞市下半年整治环境卫生工作大检查动员会议。

东莞市城市综合管理局副局长吴育新、我院宣传部部长何鹏举教授出席大会。市环卫整治办成员单位副科级以上干部，市环卫整治办全体工作人员，城市学院参检师生约700人参加了会议。

市环卫整治办谢庆辉同志向参会人员详细讲解了大检查的评分标准。

吴育新副局长、何鹏举部长在会议上先后讲话。他们强调，参检的学生都是党员、预备党员和入党积极分子，希望同学们利用这个机会，接触社会，接触实际，增强社会活动能力，丰富自己的实践经历和经验。要认真对照记分表进行检查与评分，做到客观公正合理。

据悉，本次检查活动将于12月25日进行，我院将有600余名师生参加，分赴32个镇街对所检社区进行地毯式全覆盖检查。
