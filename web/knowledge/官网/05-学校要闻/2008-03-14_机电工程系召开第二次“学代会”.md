# 机电工程系召开第二次“学代会”

3月9日，机电工程系第二次学生代表大会在五号阶梯教室召开， 百余名学生代表参加了大会。机电工程系主任助理谢明副教授、学生党支部书记孔增强以及兄弟系辅导员出席了会议。

团总支副书记李建平做了第三届团总支工作报告；第三届系学生会主席吴松向大会作学生会工作报告。

大会采用无记名投票的方式，选举梁鹤、吴中华、赵伟、曾可扬为新一届系学生会主席团成员。
