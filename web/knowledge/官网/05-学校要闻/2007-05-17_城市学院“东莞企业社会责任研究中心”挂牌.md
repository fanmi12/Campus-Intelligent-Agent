# 城市学院“东莞企业社会责任研究中心”挂牌

5月16日，学院在1号教学楼举行“东莞企业社会责任研究中心”揭牌仪式。广东省社会科学院研究员、广东省企业社会责任研究会会长黎友焕博士、城市学院学术副院长程发良教授参加了揭牌仪式。

黎友焕博士应邀在4号楼315会议室为我院师生作了题为“中国企业对企业社会责任的认识与实践”的学术报告，并对我院如何开展这一研究工作发表了指导性的讲话。

据悉，企业社会责任研究在西方发达国家中比较盛行，学科建设也较完善，在我国还刚刚起步，属于朝阳学科，但目前已越来越引起政府、企业、学术界、新闻媒体，特别是外向型企业的关注。
