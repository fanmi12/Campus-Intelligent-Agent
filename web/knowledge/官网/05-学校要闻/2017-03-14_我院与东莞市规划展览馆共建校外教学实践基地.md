# 我院与东莞市规划展览馆共建校外教学实践基地

3月9日上午，我院与东莞市规划展览馆

签约共建校外教学实践基地，并正式挂牌。教务处处长牛熠、城环系主任肖红飞等领导与市规划

展览馆王飞

馆长出席了签约挂牌仪式。

王飞馆长表示，今后愿意和我院进行多方面的合作，为学生提供更多的实习机会，并为我院学子预留了展示窗口。今后我院学生优秀的课程设计、毕业设计在该馆里进行展览。

据悉，城市学院是东莞市规划展览馆作为校外教学实践基地的第一家挂牌单位。当天下午就有2个规划班100多名师生前往进行参观学习。
