# 我院党建研究论文和课件获多项省级奖励

12月31日，广东省高校党建研究会民办院校分会2013年年会在广州城建职业学院召开。我院组织人事处组织科李海冬、李钰参加了会议。会议对高校党建研究会民办院校分会2013年优秀年会论文以及民办高校党课课件制作和说课比赛的获奖人员进行了表彰，我院费长江、彭义春、章德胜等同志的论文分别荣获二等奖、三等奖、优秀奖，何鹏举同志获课件制作大赛二等奖。

据悉，本次年会上还听取了省党建研究会第二届理事会的工作汇报，并换届选举产生了第三届理事会，我院被增选为常务理事单位。
