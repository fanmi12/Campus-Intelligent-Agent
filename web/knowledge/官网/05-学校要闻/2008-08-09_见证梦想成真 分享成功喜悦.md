# 见证梦想成真 分享成功喜悦

8月8日晚，学院大学生活动中心卡拉OK厅又一次热闹起来。近400名留校大学生齐聚一堂，在这里收看奥运会开幕式电视实况直播。

喜庆欢快的氛围，精彩完美的画面，多种时尚元素，深深感动了大学生们，大家时而欢呼雀跃，时而鼓掌祝贺，现场气氛非常热烈而喜庆。

同学们表示，这是一场高水平、有特色的开幕式，向全世界人民奉献了一台美妙的艺术大餐，很值得一看。整台晚会展示了中国人民的智慧与风采，充分表明了中国人民百年梦想实现了，北京成功了，我们为此感到骄傲与自豪。

据悉，今年暑假留校学生达到800人，是历年之最。他们大都是在学校里复习考研、暑期兼职或社会实践的同学。为了让同学们收看好奥运会比赛盛况，学院卡拉OK厅免费开放。
