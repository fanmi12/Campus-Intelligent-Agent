# 高香林副院长带队考察兄弟院校跨专业实训平台建设

为全面推动我院商科跨专业实训平台建设，10月27日至30日，高香林副院长带领财经系、管理系、金贸系、实验中心、教务处四个单位的负责人米双红、张佺举、罗卫国、朱国宪、赵书山等7人，先后考察了国内最大管理软件提供商、中国领先企业云服务提供商、用友集团重要成员企业——新道科技有限公司，以及与新道科技有限公司有着密切合作关系的北京林业大学、浙江理工大学和浙江财经大学东方学院。

用友新道科技有限公司长期致力产教融合，已与国内多所高等院校合作共建了5000多个实践教学基地。特别是新道倡导“融合力量、实践育人”，践行“把企业搬进校园”的教学理念，通过为院校提供信息化实验室、沙盘实验室、虚拟商业社会环境实践平台（单专业、跨专业）、企业实践案例、实训精品课程等，与院校共同开发经管类专业综合实践教学解决方案；通过参与人才培养方案优化、特色专业共建、实践教学师资研修等服务，推动教产有效融合；通过搭建线下实训与线上服务相结合的平台，打造职业梦想社区，现已成为中国最大的经管类实践教学解决方案提供商。

10月27日上午，高香林副院长一行在用友新道科技有限公司大区总经理张永红女士陪同下，详细考察用友新道产教融合研发成果，听取马德福高级副总裁做的《产教深度融合，校企全面合作——开拓中国院校经管人才培养新道》的专题报告，双方还就地方本科院校应用型人才培养模式改革、实训（实践）教学改革以及如何“把企业搬进校园”等问题进行了深入的交流和探讨。

从27日下午到29日，高香林副院长一行在用友新道科技有限公司副总裁、广东分公司总经理张海燕女士陪同下，又分别考察与用友新道科技有限公司有着长期合作关系的北京林业大学的“把企业（林业）搬进校园-北林虚拟商业社会环境综合实训中心”和浙江理工大学“跨专业综合和实训实习基地”。详细参观了两所大学的“虚拟商业社会案例开发中心”、“研发农林经管虚拟仿真实验平台”、“虚拟商业社会环境VBSE-跨专业综合实践教学平台”、“虚拟商业社会环境VBSE-创新创业实践教学平台”和“创新创业基地（实训实验室）”等。

浙江财经大学东方学院是浙江省最早成立的一所独立学院，与用友新道科技有限公司有着四年多的合作关系。10月29日上午，高香林副院长一行参观考察了该院的“跨专业综合实训中心”。东方学院冯睿副院长及实验中心金伟林主任详细介绍该院应用型人才培养方案的制定及实施情况，重点介绍了该院跨专业综合实训中心的管理架构、课程开发、实验（实训）组织以及跨专业实训人才培养方案、实践教学体系、综合实训执行情况等。随后，高香林副院长一行参观了该院的跨专业综合实训中心的实际运行情况，同时参观了该院的“金融实训中心”的“银行模拟实验室”、“证券期货模拟实验室”、“大数据实验室”和“货币与金融陈列室”。参观考察过程中，高香林副院长一行详细咨询了商科类实训基地建设、管理及实际执行中课能遇到的困难与问题，与对方进行了较为全面的交流和磋商，为城市学院进一步加大应用型人才培养模式和手段改革提供了参考意见。
