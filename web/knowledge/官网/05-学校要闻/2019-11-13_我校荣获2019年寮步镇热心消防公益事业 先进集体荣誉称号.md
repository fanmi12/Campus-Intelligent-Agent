# 我校荣获2019年寮步镇热心消防公益事业 先进集体荣誉称号

11月8日，寮步镇政府、镇消防安全委员会举行以“防范火灾风险，建设美好家园”为主题的“119”消防宣传月启动仪式。会议对2019年热心消防公益事业先进集体和先进个人进行了表彰。我校荣获2019年寮步镇热心消防公益事业先进集体荣誉称号, 后勤员工韩向东被评为2019年寮步镇热心消防公益事业先进个人。
