# 首次评估八个教研室获优秀

会计教研室等8个教研室，经过专家、教授的严格评估，近日被评定为优秀教研室。

为了健全和加强教研室建设，促进教研和科研的深入开展，指导教师搞好教学，进一步提高教学质量，今年4月，学院决定对教研室建设进行评估。为此，教务处制订了《城市学院教研室评估指标体系》。根据评估指标体系，每个系部自评上报了一个优秀教研室。5月16日，学院抽调16名教授、副教授，分成两个专家评估组，对各系（部）申报的优秀教研室进行实地评估。专家组通过听取教研室主任的汇报，对照《指标体系》查看相关资料，认定思想道德修养与法律基础教研室、法学教研室、软件工程教研室、工商管理教研室、国际贸易教研室、资源环境与城乡规划教研室、会计教研室、中文教研室为优秀教研室。
