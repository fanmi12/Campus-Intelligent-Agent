# 文学与艺术系首届辩论赛落幕

4月17日，文学与艺术系首届辩论赛总决赛在学术报告厅举行。

进入决赛的专科组辩手分别是正方06级文秘，反方07级音乐表演，辩题为《大学有没有必要安排新生上自习》；本科组正方辩手是05级汉语言文学（2）班，反方为07级新闻传播，辩题为《〈新劳动合同法〉实施对毕业生利大于弊还是弊大于利》。

经过一番唇枪舌剑，最后在专、本辩论中赛出的两支最佳辩论队分别是07级音乐表演班与05汉语言文学（2）班，07音乐表演刘思韵同学及07新闻传播刘琛琛同学分获专、本科组最佳辩手。

担任决赛评委的有：文学与艺术系主任陈庆祝博士、党总支孟颖书记、柯小瑜老师、贾静波老师、罗希明老师组成，出席嘉宾有党委朱冰副书记、就业办江小卫主任、院团委丘永辉书记、学生处赵秋萍老师及系辅导员、班主任等。

据悉，文学与艺术系首届辩论赛初赛历时一个多月，共举行了13场“学风建设”辩论赛。
