# 学院领导赴台湾高校访问，寻求深度合作

4月21日——26日，学院党委副书记章德胜带领继续教育中心（国际交流中心）、教务处、组织人事处干部赴台湾义守大学、嘉南药理大学、台中应用科技大学、淡江大学访问，就交换生、教师研修、教师互访、科研合作等领域事宜进行了交流。

在交换生合作的基础上，学院希望积极借鉴、引进台湾优质教育资源，利用台湾科技型大学的理念、模式来辅助我院应用型本科人才培养改革，逐步形成学校与国际高等教育发展相适应的开放办学格局，不断提升学校的人才培养规格和质量，深化应用型本科人才培养改革体制。

此行受到了台湾高校同行们的热情接待，纷纷表示欢迎我院教师到台湾高校做访问学者，并愿意派出教师到我院进行教学工作，还希望协同台商协会推进莞台高校“校—校—企”合作。
