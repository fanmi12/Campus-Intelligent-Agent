# 政法系学生到市法院旁听刑事案件审理

为了加强政法系法学专业学生对国家法律的认识，配合刑事法律实训课的展开，经东莞市中级人民法院同意，我系10法学和10文秘（法律事务）班108名同学赴东莞市中级人民法院旁听观摩了刑事附带民事案件的审理过程。

同学们观摩了法庭调查、举证质证、法庭辩论、被告人陈述在内的整个庭审过程。二个小时的庭审过程规范严谨，法庭秩序井然有序。在被告人最后陈述阶段，年仅30岁的被告表示忏悔，并转头对听审的同学说“有德无才是次品，有才无德是毒品”，希望同学以他为鉴，不要做危害社会的“毒品”。同学们大受触动，深受教育。

庭审过程中，同学们自觉遵守法庭规则，认真听审，结合课堂上学习的刑法和刑事诉讼法知识，专心听取公诉方和辩护人的陈述，观察审判人员、辩护律师的庭审表现，取得了刑事法律实训课预期的良好效果。在上了一堂生动的法律课同时，也给每一个同学敲响了遵纪守法的警钟。
