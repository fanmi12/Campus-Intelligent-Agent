# 机电系有8名学生考研上国线

近日，2013年国家考研分数线已经公布，机电系2009级机械设计制造及其自动化专业张碧涛、李明泽、高振宇、罗威 和2009级印刷工程专业聂鹏、陈艳艳、黄汝权、方明共8名同学超过了国家初试分数线。这些同学分别报考了华南理工大学、武汉大学、上海理工大学、南京理工大学、广东工业大学等知名院校。目前，这些上线的同学正在为复试做紧张的准备工作。
