# 我院召开2018年迎新工作暨新生军训工作协调会

9月1日下午，我院召开2018年迎新工作暨新生军训工作协调会。院领导章德胜、刘玉侠和相关职能部门负责人、各二级院系党总支副书记参加了会议。

罗文芳副处长就迎新工作的总体筹备情况和暑假进展作了情况汇报，重点讲解了2018年迎新工作方案的具体分工、工作职责及工作要点。各职能部门负责人就今年迎新工作所负责的工作的进展，进行了汇报与交流。

后勤保卫处处长王锦锋对今年新生军训工作作了整体部署，副处长刘维仝就新生军训工作方案作了具体解读。

刘玉侠副院长要求后勤保卫处要做好后勤服务，加强校园及周边环境治理，保证广大新生人身、财产安全。同时要加强宣传，运用多种宣传报道形式营造优美和谐的校园人文气息，努力让家长和新生满意，确保今年迎新和新生军训工作顺利、圆满完成。

章德胜副书记指出，迎新工作是学院形象的一次集体大展示，各职能部门要重视迎新工作，要向新生、家长和社会展示我院良好的第一印象。章德胜副书记强调要把校园安全工作放在第一位，全力做好开学和迎新、军训的各项保障工作。
