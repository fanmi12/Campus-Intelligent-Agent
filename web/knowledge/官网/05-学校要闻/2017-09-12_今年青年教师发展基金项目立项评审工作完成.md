# 今年青年教师发展基金项目立项评审工作完成

9月10日上午，我院组织召开了2017年院级青年教师发展基金项目立项评审会。来自华南理工大学、东莞理工学院、广东医科大学、广东科技学院等9名教授组成评审专家组进行了评审。黄兢副院长参加了评审会议。研发处赵书山处长主持评审工作会议。

据了解，今年我院教师共申报青年教师发展基金项目87项，其中自然科学类重点项目2项，人文社科类重点项目8项，自然科学类一般项目14项，人文社科类一般项目63项。

7月初，学院研发处于组织学院学术委员会成员对87项项目进行了网上初评。

评审专家组对项目申报材料进行了严格的审议，通过集中投票表决相方式，从87个项目中评选出30个项目作为2017年院级青年教师发展基金项目立项项目，其中重点项目5项，一般项目25项。立项评审结果已进入网上公示阶段。

据悉，为进一步提高青年教师参与科研工作的积极性，从今年起，我院青年教师发展基金项目对一般项目的资助金额统一提升至每项6000元，重点项目资助金额提升至每项10000元。
