# 我院2011级学生党员开展“分享与成长”图书漂流活动

6月5日，我院2011级学生党员“分享与成长”图书漂流活动在新校区举行启动仪式。2011级学生党员，学生自律会委员，学生工作助理参加了开幕式。

学生处陈彬老师介绍了图书漂流活动的起源、活动主要内容与具体要求。陈彬老师及各系部的辅导员分别向与会同学推荐了《中美体育电影文化观念的比较与嬗变》、《我的奋斗》、《这些人，那些事》、《平凡的世界》等书籍。
