# 深圳信息职业技术学院嘉宾考察我院

3月6日， 深圳信息职业技术学院科研处林光明一行莅临我院考察，教务处处长牛熠热情接待了客人。

双方就科研教学管理工作、校企合作机制体制创新、高校协同创新体制改革和数字化校园建设等问题进行了广泛的交流。林处长一行还考察了我院东莞制造业设备智能化协同创新发展中心的建设与培育情况，并就协同创新工作进行合作性交流探讨。

计信系廉玉忠主任、图书信息中心陈显龙副主任、教务处赵书山副处长和协同创新团队核心成员李洪超博士、刘林泉博士、张宏辉博士参加了座谈。
