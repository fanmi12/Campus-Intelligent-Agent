# 江小卫老师两部新教材列入普通高等教育“十二五”规划教材

我院就业指导与培训中心主任江小卫老师主编的两部教材《生涯发展与规划：原理-方法-实训》、《就业指导与创业教育：理论-实践-案例》，已顺利通过专家组立项审批，双双列入国家普通高等教育“十二五”规划教材，近期由北京理工大学出版社正式出版发行。
