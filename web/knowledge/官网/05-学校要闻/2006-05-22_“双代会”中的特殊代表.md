# “双代会”中的特殊代表

在城市学院第一届教职工代表大会暨工会会员代表大会上，第四代表团19名代表中的13名合同工成了会议上特殊的亮点。

5月20日上午11点10分和下午2点30分，第四代表团在团长钟兴恭老师的带领下，在学生处会议室分别举行了讨论会，学院党委副书记朱冰以普通代表的身份参加了会议。

第四代表团各个代表在会上都畅所欲言，非常的踊跃。在上午的讨论会上，与会代表就三个报告进行了热烈的讨论，他们一致认为院长安少华教授在“双代会”上作的学院工作报告实事求是，从实际出发，他们听了很受鼓舞和振奋。随后第四代表团讨论了工会主席章德胜同志作的工会工作报告，他们认为这充分体现了合同工政治地位的平等。下午的讨论会，代表们就后勤职工教育培训、合同工工资待遇、住房等热点问题展开了探讨。

党委副书记朱冰最后总结发言：通过这一次双代会，民主意识加强了很多，合同工作为正式代表，共同参政议政，消除了很多人为的隔阂，以主人翁的身份出现，共同协商发展大计。

饮食中心的代表张辉波向记者表示：“举行这样的会议很有意义，体现了学院关心员工，也体现了我们合同工的主人翁精神。”
