# 我院师生参加东莞市2014年下半年整治环境卫生工作大检查

12月23日，东莞市城管局在我院召开2014年下半年东莞市整治环境卫生工作大检查动员大会。党委书记王卫平、东莞市城管局局长唐耀文分别做了动员讲话。

据悉，我院师生已是第18次参加市政府组织开展的环境卫生整治工作，本次共有508名学生党员、入党积极分子和32位老师参与，分别到全市32个镇区进行走访、调查与计分。

12月24日，同学们在陪检员的带领下，开展检查工作。

此次检查的主要内容包括清扫保洁、门前“三包”、“治理六乱”、公共厕所管理、垃圾填埋、垃圾转运、环卫宣传等7大项。检查的重点部位是社区出租屋、居民住宅区、商铺、工厂区的环境卫生。

据参加过上半年大检查的同学们反映，许多镇区无论是环境卫生、环卫设备、基础设施、公共卫生、环境宣传等工作比以前做得更好。

党委书记王卫平高度称赞我院大学生积极参与东莞市整治环境卫生工作，认为这一活动既能体现学院服务东莞经济社会发展，又能为在校大学生提供接触社会、了解民生、检验自己的社会实践机会，应该继续坚持做好。
