# 我院举办高校户外综合技能挑战大赛

激情户外，挑战自我！5月26日下午，全省，乃至全国高校首次单校举办的大型户外综合技能挑战大赛——“东莞理工学院城市学院首届山鹰户外综合技能挑战赛”在我院隆重举行，共98支队伍、近1000名爱好户外运动的同学参加了比赛。

据大赛总负责人、户外综合课程领军教师陈勇军介绍，赛事包括车轮滚滚、越野跑、绳结操作、绳降、竹篮打水、帐篷搭建、拼图及炊具使用、急救包扎、装包及负重登楼、定向百米、骑跑交替及坐地起身等12个项目。

大赛虽然遭遇了暴雨天气，但选手们却激情不减，纷纷在运动场、校道、场馆上完成了各项比赛，展示了城院学子磨砺意志、强身健体、团结互助、坚持不懈的户外运动精神。

经过艰难的激烈角逐，由“嫑玊队”以46分07秒的成绩夺得大赛桂冠。

值得一提的是，本次大赛全部由我院户外运动学生38名领队自主策划与运作。据我院户外运动中心学生理事长雷义鑫介绍，他们3个月前就开始筹备赛事，从赛事赛制、规则、路线、裁判工作等等，以及医疗、赞助等方面都做了大量周密的计划与安排。他还表示，尽管对天气一直进行了关注，还是遇到暴雨天气，但这也符合户外运动的精神。在户外运动本来就会存在各种困难，这也正是户外运动的魅力所在。

我院体育教学部主任邢红林教授在接受记者采访时，对大赛组织和开展工作赞赏有加。他表示，此次比赛几乎全部由学生主导，赛事的成功举办证明了“他们非常棒”！展示了他们“为他人着想、有担当、坚持不懈”的精神，达到了我们开设户外综合课程的初衷与目标。

曾登顶珠穆朗玛峰、北京大学山鹰社原社长、深圳登山户外协会副会长曹峻先生作为嘉宾致辞，他赞扬道，如此大规模、单个高校举办的户外大型活动，在全国都绝无仅有。他建议将城市学户外综合课程的经验与举措推广到全国其他高校去。

此次赛事得到新浪网、东莞电视台、红牛维生素饮料等多家媒体及商家的鼎力支持。王卫平、章德胜、高香林、黄兢、周庆等院领导，以及相关系（部）、处等领导出席大赛开幕式。
