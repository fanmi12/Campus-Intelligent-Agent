# 喜讯！我校学子参加蓝桥杯全国大赛获奖

近日，传来喜讯，在第十四届“蓝桥杯”全国软件和信息技术专业人才大赛（广东省赛）上，我校学子共获一等奖2项、二等奖8项、三等奖10项。

其中，严宇泽同学获得C/C++程序设计大学B组省赛区一等奖，王浩霖同学获得Web应用开发大学组省赛区一等奖，这2位同学将代表我校，参加6月10日举行的全国总决赛。

我校高度重视此项专业技能大赛，人工智能学院精心组织师生参赛，陈强、邓美玲、胡纯意、王浩亮、杨胜利、王丽莉、张小玲、贺丹等老师指导学生参加了本次大赛。

赛前，老师们认真研读历届真题，分析比赛手册，组织模拟练习，针对发现的问题进行了充分深入的思考，制定详细的比赛方案，多次组织团队会议，针对比赛提出各类建议。经过师生长达半年多的共同努力，赛场上学生展现出了优异的分析和解决问题的能力，最终获此殊荣！

“蓝桥杯”全国软件和信息技术专业人才大赛由工业和信息化部人才交流中心主办的全国性大学生学科赛，大赛连续三年入围中国高等教育学会"全国普通高校大学生竞赛排行榜"竞赛项目榜单。“蓝桥杯”大赛共分为9个赛道：C/C++程序设计、Java程序设计、Python程序设计、Web应用开发、软件测试、嵌入式设计与开发、物联网设计与开发、单片机设计与开发、EDA设计与开发，涵盖当前主流的信息技术专业技能，是我院学科竞赛体系中的重要赛事。

一直以来，我校高度重视学生实践能力和创新能力的培养，坚持通过“以赛促学，以赛促教”方式，推动教学质量的提升，鼓励学生参加学科竞赛。

今后，我校将以此为契机，总结比赛成功经验，不断优化教育教学体系，进一步鼓励学生参加各类学科竞赛，为国家培养德、智、体、美、劳全面发展的高素质应用型人才而不懈努力。
