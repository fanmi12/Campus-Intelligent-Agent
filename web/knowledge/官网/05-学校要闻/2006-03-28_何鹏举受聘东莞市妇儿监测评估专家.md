# 何鹏举受聘东莞市妇儿监测评估专家

近日，我院社会科学系主任何鹏举副教授被东莞市妇儿工委聘为“东莞市妇女儿童发展规划中期监测评估专家组”专家，负责撰写《东莞市妇女儿童发展规划（2001—2010）中期监测评估报告》，并参与“两个规划”中期评估工作。

学院领导认为，教授、专家担任一定的社会工作，有利于加强学院与当地政府及有关部门的联系，进一步了解东莞经济社会发展情况，促进教学工作。
