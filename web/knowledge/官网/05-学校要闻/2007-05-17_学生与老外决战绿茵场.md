# 学生与老外决战绿茵场

5月13日下午，我院足球协会与一支由20名外国足球爱好者组成的“One for the road”在学院足球场进行了一场精彩的友谊赛。

前三节，双方经过激烈的对抗，足球协会1：3落后。第四节一开始，足球协会再失一球，此后足球协会改变打法，稳扎稳打地向对方阵地挺进，随后连进两球。在最后几分钟，由于足球协会的球员体力消耗过大，没能把握好机会，最终以3：4一分之差负于“绿林军”。

据悉，这支“绿林军”由以色列、美国、德国等国家的足球爱好者组成，均在东莞各企业工作。由于他们平时喜欢聚在酒吧里喝酒论球，酒吧老板一番好意，便组成了这支业余球队。
