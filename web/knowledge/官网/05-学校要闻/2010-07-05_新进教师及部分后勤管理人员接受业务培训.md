# 新进教师及部分后勤管理人员接受业务培训

7月2日，城市学院对本学年度新进教师及部分后勤管理人员进行为期8天的岗前培训。

据悉，在这批新进的教师中，大部分老师具有博士、硕士学历，或副教授以上的高级职称，其中有4名老师是从美国、英国和香港留学回来的硕士研究生。

培训之前，参加培训的人员与院领导、机关各部门和教学系部负责人齐聚一堂，自我介绍。

院长安少华为新进教职工作“市情、院情及学院发展”报告；程发良副院长、张林副院长、高职部主任林世俊分别作了教学管理、行政管理、教学艺术的专题讲座。

7月3日，参培人员参观了虎门镇、松山湖工业园区。

培训班要求，凡参加培训的教职工须提交“一年专业成长计划”或“培训心得体会”。暑假期间，暂未具备高校教师资格的老师将赴广州华南师范大学参加为期两周的教育课程培训。
