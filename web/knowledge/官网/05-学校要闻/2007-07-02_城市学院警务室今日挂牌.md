# 城市学院警务室今日挂牌

安少华院长和莞城公安分局局长吴晓(右)为警务室揭牌

张林副院长致词

学院、分局领导参观警务室

为进一步加强高校及周边治安防范和治安管理工作，密切公安机关与学院、民警与师生的关系，减少和预防校园治安案件的发生，保障师生有一个良好的校园环境，莞城公安分局决定在我院设立警务室。

6月29日，城市学院与莞城公安分局共同举行挂牌仪式，院长安少华教授、党委副书记朱冰、副院长张林和莞城区党委委员、公安分局局长吴晓出席了揭牌仪式。

学院警务室办公地点设在专家楼旁，配置一名民警，另有25名校卫配合警务工作。警务室的主要任务是及时受理报警求助，尽力为师生排忧解难，指导、配合学院做好安全防范工作。
