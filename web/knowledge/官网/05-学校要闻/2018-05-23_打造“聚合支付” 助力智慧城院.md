# 打造“聚合支付”  助力智慧城院

财务处处长余竹根

本学期以来，在学院食堂等场所消费时，师生明显感觉比以往更为方便、便捷。没带校园卡时，一部手机、一张银行卡大家也能轻松便捷地进行消费。这一切源自我院不断地打造、推进“智慧城院”系统建设，便捷的线上移动支付功能就是一个重要举措。

5月18日，财务处发出通知，在学院食堂等消费场所正式开通了银联卡“闪付”功能。这也是继续开通微信支付、支付宝之后的第三种支付功能，即银联卡“闪付”或银联APP“云闪付”二维码移动支付功能。由此，学院食堂基本建成了由校园卡、微信支付、支付宝和银联“闪付”和“云支付”等组成的“聚合支付”功能。

针对“聚合支付”的建设，学院财务处处长余竹根接受了记者采访，揭开了“智慧城院”系统建设的端倪。

打造一机三种支付的“聚合支付”

当前，以微信支付、支付宝为代表的移动支付消费模式已成为社会的“时尚”潮流，一场去现金化的消费支付变革悄然进行。余竹根处长认为，学院财务处要与时俱进，利用好先进的新信息技术,为广大师生提供便捷的财务服务。考虑到学院校园卡充值机器数量不足、设备老化零件更换困难、充值时间受到限制，师生充值不方便，以及线上支付盛行、财务现金管理等因素，财务处经过大量的调研后，开始精心筹划打造“聚合支付”服务功能。

余竹根处长告诉记者，经过资源整合，本学期初财务处和后勤保卫处完成移动支付机建设，在饭堂陆续推出了微信、支付宝支付方式。本月18日又联合中国银联和院学生会推出了银联卡“闪付”功能。基本完成了饭堂一机拥有三种支付方式模式的“聚合支付”，让师生在消费时有了更多的选择。

在方便师生的同时，财务处也对资源进行有效整合，此次与中国银联合作，对方投入20万元对师生进行返利优惠活动。凡是在饭堂使用银联卡“闪付”消费达5元以上就会随机返还2元，返还的金额可在饭堂消费。

余竹根处长介绍说，当前，聚合支付功能已覆盖了食堂、医务室、招待所等场所。今后，财务处还将联系更多的机构陆续在学院开展相关的惠利师生活动。

值得一提的是，我院开展的线上移动支付建设还受到社会关注和好评。近日，欣旺达电子股份有限公司是深圳一家拥有近3万名员工的上市公司，负责后勤的有关领导特地到我院调研食堂移动支付，以借鉴建设经验。

财务助力“智慧城院”建设

除了推行的聚合支付外，本学期开始，学校已经实现了线上电费的充值功能，方便了学生缴纳宿舍电费。在3月底举行的艺考，考生报名费也采取了移动支付的方式，为考生提供了便捷的服务。余竹根处长介绍说，“智慧城院”移动支付服务推出后，600多名艺术类考生通过移动支付缴纳报名费，非常便捷、高效。

余竹根处长透露，今后财务处还将逐步推出“校园卡”充值、校内外考生英语四六级考试、普通话考试、计算机资格考试、教师资格证考试及培训等的缴费提供移动支付，进一步增强“智慧城院”的服务功能。

目前，学院正在加大“智慧城院”系统建设步伐，汇集了OA办公系统、迎新系统、人事管理、教务系统、财务系统等多系统建设。余竹根处长告诉记者，财务处正在与有关部门加快迎新系统建设，对新老学生学费、住宿费等缴纳进行由现有的银行代扣向线上支付改革，为学生提供便捷的服务，也加强和优化财务建设与成本管理。
