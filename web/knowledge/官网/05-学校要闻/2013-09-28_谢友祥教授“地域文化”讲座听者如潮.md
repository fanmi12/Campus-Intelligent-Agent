# 谢友祥教授“地域文化”讲座听者如潮

9月26日，长期从事中国传统文化、地域文化和中国现当代文学研究的谢友祥教授在学术报告厅为文学与传媒系师生“培育人文精神系列讲座”上了第一堂课。他给同学们讲述客家文化独特的地域文化魅力。现场座无虚席，同学们对地域文化颇感兴趣，津津有味地认真听讲。

谢友祥教授运用层层递进的叙述形式，将抽象的“文化”具象化，以“地域文化——岭南文化——客家文化”为主线细细剖析地域文化的潜在底蕴，解析“地域文化”这一名词，引导学生主动去感悟丰富多彩的中国地域文化以及当今地域文化的宿命——文化的趋同性以及地域文化的加速消亡。在课堂上，他敢于提出自己对敦煌文化归类于地域文化的质疑，深刻阐述注重文化生态多样性的意义以及提出“推普废粤”的弊端。

谢友祥教授还全面概述了岭南文化的历史、名人、民俗文化、民间文学、艺术以及地方戏曲，追溯岭南文化的来源和发展过程。现场的同学积极与谢友祥教授互动，一同品读韩愈、苏轼和丘逢甲等著名诗人的名篇名句，由点及面地讲解地域文化的丰富性。从苏东坡的“日啖荔枝三百颗，不辞长作岭南人”，再到苏曼殊的“还卿一钵无情泪，恨不相逢未剃时”，无不感受到岭南文化因文化名人的贬流文化而独显魅力。同学们跟随着谢友祥教授流连于历史的轨迹，感受岭南文化的深刻内涵魅力，同时在品析岭南文化之时了解到人文精神的可贵。他指出，岭南文化作为地域文化的一个分支，其地位和价值不可小觑，呼吁同学们保护并弘扬独具地方特色的文化，加固中国文化博大精深的支柱。
