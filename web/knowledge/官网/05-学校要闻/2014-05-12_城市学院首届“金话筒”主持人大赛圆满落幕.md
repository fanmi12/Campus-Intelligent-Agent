# 城市学院首届“金话筒”主持人大赛圆满落幕

5月8日，由院团委主办，文传系举办的第一届院“金话筒”主持人大赛决赛在学术报告厅隆重举行，党委书记王卫平观看了本次大赛。

决赛分为模拟主持、情景配音、“我在现场”才艺演讲四个环节。9名参赛选手以相声的形式拉开比赛帷幕，独特的开场表演让观众们耳目一新。在模拟主持人环节中选手们以相亲节目、天气预报、晚会主持等风格迥异的主持形式，让观众领略了主持人的风采与魅力。《卧虎藏龙》、《十面埋伏》等大片的配音也难不倒选手们，诙谐幽默的语气像是给片中的角色赋予了新的灵魂；“我在现场”则是本次大赛的特色环节，选手们用外景主持的身份介绍各个“现场”，考验着选手们的语言组织及应变能力。

选手们用自己最佳的精神状态融入比赛，精心准备每一个环节，以冷静、沉稳姿态度接受了一次次挑战。各种难题丝毫没有难倒选手，现场气氛热烈，观众掌声不断。

比赛结束，全梦梦、邹文彬、郑忆铭分别夺得的金奖、银奖、铜奖，丁亦赫、蓝天翔、开雯、孙如梦、林娟玲分获得优秀奖，周维嘉获得最佳风采奖，郑亿铭获得 “我最喜爱的主持人”奖。

第一届院“金话筒”主持人大赛的举办，也让同学们对主持人这一职业有了更深刻的认识。
