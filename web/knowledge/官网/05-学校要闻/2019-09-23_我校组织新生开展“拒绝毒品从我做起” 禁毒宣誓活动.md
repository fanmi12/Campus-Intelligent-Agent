# 我校组织新生开展“拒绝毒品从我做起” 禁毒宣誓活动

9月20日，我校联合东莞市检察院、东莞市禁毒办、寮步镇禁毒办、寮步公安分局等单位，组织2019级新生开展了一场别开生面的“拒绝毒品从我做起”禁毒宣誓宣传活动。

寮步公安分局局长叶浩钿作了动员讲话。

全体新生和教师代表在寮步公安分局周少玲警官带领下，一起宣读了“拒绝毒品从我做起”的禁毒誓词，表明了拒绝毒品的决心。庄严肃穆的宣誓词如同警钟一般响彻云霄，告诫每位学子创造美好生活从远离毒品开始。

据悉，我校每年都联合相关单位开展各种类型的安全普法教育，其中“禁毒防毒”列为重点宣传教育项目中，将毒品预防教育与公民道德教育、普法教育、健康教育等有机结合，强化毒品预防教育工作，努力实现“学生不吸毒，校园无毒品”的目标。

后勤保卫处处长王锦锋主持了宣誓活动。
