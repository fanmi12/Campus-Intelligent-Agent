# 2015年东莞高校招生咨询会28日在我院举行

2015年高考已结束，填报志愿将是考生的心头大事。为辅导考生填报志愿，经东莞市教育局批准，东莞 市2015年普通高等学校招生咨询会议将于6月28日在我院综合馆举行。

据举办单位介绍，本次咨询会主要是为考生及家长提供与省内外大学见面的机会和咨询服务，帮助考生填报志愿，选读心仪中的大学。大会还将组织专家到场作“技巧填报志愿”主题讲座。

截止到6月9日17时，已有包括中央财经大学、中山大学等140所省内外高校报名参加会议。

据悉，东莞普通高等学校招生咨询会每年举办一次，已连续举办8年。历届咨询会议均在东莞市会展中心举行，在高校内举办尚属首次。我院各项筹备工作已在有序开展之中。
