# 刘杰教授喜获“全国独立学院法学教育突出贡献奖”

4月21日-24日，全国独立学院（含民办院校）法学教育2017年年会在南昌举行，来自全国46所高等院校的专家学者出席会议。会议表彰了一批先进个人，我院刘杰教授喜获“全国独立学院法学教育突出贡献奖”。

会议以“模拟法庭辩论实践教学与应用型法律人才培养”为主题，围绕独立学院法学专业法律职业技能培养、模拟法庭实践教学、法律辩论实训等内容进行了热列、深入的研讨。有关高校介绍了应用型法律人才培养的经验。与会专家还就应用型法律人才培养的热点、难点，切实加强模拟法庭实践教学与法律辩论能力的实训，充分调动教师与学生的积极性等方面达成了广泛共识。
