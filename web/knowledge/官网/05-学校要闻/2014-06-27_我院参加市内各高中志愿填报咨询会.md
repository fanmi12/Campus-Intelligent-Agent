# 我院参加市内各高中志愿填报咨询会

25日随着今年广东省高考成绩的公布，东莞市内各高中陆续召开志愿填报指导会，我院派出招生宣传人员前往常平中学、厚街中学、塘厦中学、石龙中学、万江中学、虎门中学、第四高级中学、东华高级中学、光明中学、第六高级中学、实验中学等高中参加咨询，接受广大考生和家长的现场咨询。

据悉，2014年广东省的志愿填报时间分为两个时间段。

第一时段：6月26日12：00－6月27日12：00。本时段填报需政审、面试、体检的提前批军队武警公安司法等院校（含普通高校国防生）志愿，需要填报军队武警公安司法等院校志愿的考生必须在本时段填报。

第二时段：6月27日14：00－7月1日14：00。本时段填报除提前批军队武警公安司法等院校以外的其他各批次、各科类院校志愿（包括提前批的其他非军队武警公安司法等院校志愿），所有考生（包括已在第一时段填报军队武警公安司法等院校志愿的考生）必须在本时段填报。具体的相关规定和要求请关注广东省教育考试院网站。
