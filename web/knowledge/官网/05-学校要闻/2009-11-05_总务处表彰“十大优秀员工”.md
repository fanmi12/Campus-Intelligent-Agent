# 总务处表彰“十大优秀员工”

会场李奇处长作总结讲话。

龙海燕书记作培训工作总结讲话。

李奇处长为获奖员工颁发了证书和奖金。

11月4日，总务处2009年员工培训总结暨“十大优秀员工”表彰大会在学术报告厅隆重举行，总务处处长李奇，总支书记、副处长龙海燕出席会议并讲话，总务处全体职工与会。

会上，龙海燕书记作了题为“脚踏实地做好身边小事”的培训工作总结讲话。她用生动的事例和总务处的具体工作阐述了做好身边的小事同样能成就不平凡的工作业绩的辩证关系。

受表彰的“十大优秀员工”，来自总务处的各个部门，在各自平凡的工作岗位上做出了不平凡的成绩，发挥了表率作用。李奇处长为获奖员工颁发了证书和奖金。

处长李奇作总结讲话，希望与会人员向“十大优秀员工”学习，进一步做好后勤保障工作，在日常工作、生活中，苦练内功，强根固本，多一点学习，少一点埋怨，将培训所学知识转化为生产力、创造力，不断提高服务水平。
