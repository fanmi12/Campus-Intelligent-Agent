# 秦兴和将军为新生作国防教育主题讲座

9月20日，城市学院大讲堂第38讲在新校区综合馆开讲，海军某部将军秦兴和，为2011级新生及来自沙角部队的军训团官兵作了一场别开生面的国防教育主题讲座。讲座由城市学院党委副书记朱冰主持。

秦兴和将军以《立志成才，为祖国更加强大而努力奋斗》为主题，用生动幽默、感情真挚的语言，要求新生要有坚定的爱国之心，时刻要有忧患意识，要冷静而清醒地看待日益严峻的周边形势，关注国防安全。秦兴和将军着重就“朝鲜问题”、“钓鱼岛问题”、“台湾问题”、“南海问题”等热点问题及我国日趋严峻的海洋权益冲突展开论述，告诫同学们“祖国周边并非高枕无忧，只有建设强大的国防才有可能实现长期的和平与崛起”。

随后，秦兴和将军就“前进中的人民海军”进行演讲和视频播放，引来同学们一阵阵经久不息的掌声，秦兴和将军号召同学们要有坚定的爱国之心，要有强烈的尚武精神，要有不屈不饶的使命意识，要有浓浓的感恩之心。秦兴和将军还将同学们的四年大学生活形容为“春夏秋冬”四个季节，赋诗一首——《咱们共同和四季有个约会》，通过声情并茂地朗诵与同学们共勉。
