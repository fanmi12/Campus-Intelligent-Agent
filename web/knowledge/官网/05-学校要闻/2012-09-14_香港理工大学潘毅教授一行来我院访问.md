# 香港理工大学潘毅教授一行来我院访问

9月12日，香港理工大学教授、博士生导师、中国社会工作研究中心副主任潘毅女士一行来我院参观访问。，受到政法系主任刘杰教授、副主任赵书山副教授的热情接待，双方就合作办学、社会服务、社会工作培训等方面交换了意见。

潘教授一行与社会工作教研室的老师和学生代表就企业社会工作进行了深入的交流与探讨。会后，潘教授还参观了普惠社会工作服务中心及中心所开展的企业社会工作及社区服务工作项目点。

潘教授一行对中心开展的服务项目给予了高度评价，同时也提出了许多中肯的意见。她表示今后将从工作人员培训、项目督导等方面给予大力的支持。
