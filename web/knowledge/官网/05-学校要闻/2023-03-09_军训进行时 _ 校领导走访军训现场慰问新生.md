# 军训进行时 | 校领导走访军训现场慰问新生

我校军训正在如火如荼地进行中，3月8日上午，校党委书记章德胜、常务副校长方伟华、校长助理孔增强、任广新校领导走访军训现场，看望正在军训的同学们。军训团副团长彭亮，学生处处长刘维仝等陪同走访。

在现场，学校领导们首先察看了同学们的军训状态，详细了解了他们的军训情况。军训团副团长彭亮介绍了2022级学生军训情况。经过数日的军训，同学们在各位军训教官的指导下，积极训练，刻苦钻研，克服了许多困难，按期完成了各项军训任务。

党委书记章德胜发表了讲话，他指出在这次军训中，同学们展现了极高的纪律性和团队协作精神，积极参加各项训练，通过刻苦训练，磨炼了意志，锻炼了体魄，增强了自信心，养成了良好的军事素质和纪律观念。他希望同学们接下来继续严格要求自己，用实际行动展现我校学生的素质和风貌。

常务副校长方伟华表扬了，同学们顽强拼搏、坚定意志、积极向上的精神风貌，展现出了我校学生的优秀品质和风貌。他鼓励他们在军训中保持良好的心态，以更加饱满的热情投入到训练中去，提高自身综合素质，为祖国的未来做出贡献。

学校领导们还观看了学生们的训练项目。同学们以饱满的精神、整齐的动作，完成了规定的训练，展示了我校学生在军训中所取得的丰硕成果和精神风貌。

学校领导的到来，为正在军训的同学们带来了鼓舞，振奋了精神，让同学们能够在今后的学习和生活中，继承军训中所展现出的拼搏精神和集体荣誉感，发扬团结协作精神，不断进步！
