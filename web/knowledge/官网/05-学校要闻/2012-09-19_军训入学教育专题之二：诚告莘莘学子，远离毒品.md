# 军训入学教育专题之二：诚告莘莘学子，远离毒品

“当今社会的诱惑很多，毒品就是其中之一。面对毒品，同学们要say no！”9月18日，我院邀请东莞市疾病预防控制中心副主任张巧利在综合馆为2012级新生做关于预防毒品和艾滋病的知识讲座。

张主任首先介绍了毒品的危害。她把吸毒前后的对比图和犯毒瘾时的行为表现的真实图片呈现给新生们看，引起了大家哗然和热烈的议论。一连的张同学说：“图片里的人太恐怖了，我以后是不会碰毒品的。”如此生动的介绍，引起了新生们的注意。接着张主任又讲述了毒品对个人、家庭和社会所造成的伤害，还现场深情地朗诵了一首《禁毒歌》， “诚告莘莘学子，远离毒品。”张主任还详细介绍了防治艾滋病常识。她说，普通的接触是不会被传染的，要学会理解和尊重艾滋病患者等。张主任的讲座图文并茂、形象生动，时不时获得学生们阵阵掌声。
