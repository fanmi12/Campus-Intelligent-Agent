# 市委副书记刘树基来我院作形势报告

11月3日晚上，我院举行《城市学院大讲堂》第四讲，特邀中共东莞市委副书记、东莞理工学院党委书记刘树基作形势报告。1600多名师生到会听取了刘书记的报告。

刘书记在回顾东莞撤县设市以来的1984、1994和2004三个时间段国民生产总值、财政收入及银行年末存款余额三大指标时指出，东莞已于去年完成由农业社会向工业社会的转变。支撑我市社会经济发展主要是三大因素：一是具有优越的地理位置；二是抓住了千载难逢的发展机遇（世界经济全球一体化、国际资本大循环、制造业大转移）；三是中央改革开放政策成全了东莞市各个因素的充分发挥。

刘书记在报告中指出，从近20年的实践来看，东莞市社会经济发展的内在因素是建立和完善了社会主义市场经济体制。社会主义市场经济可以分为两大部分来理解，第一部分是社会主义部分，即政治方面，它的特点是必须坚持社会主义方向，坚持共产党的领导，这是不能动摇的；必须以人为本，保障劳动者的合法权益；必须坚持效益优先、公平竞争的原则；必须创新劳动者的价值观念；必须建立相适应的社会保障体系。第二部分是市场经济部分，它的特点是：产权关系十分清晰；用市场调节手段调节市场；按资本进行分配和承担企业风险。在讲到东莞与外地的不同之处时，他说，这些年来东莞基本上不发展国有企业（银行等不在此例），对原有的国有企业全部进行改制，各镇、村有强大的集体经济，东莞老百姓都参加劳动和持有股份。刘书记在报告中引用了大量的历史事实，说明东莞市场经济的发展历程，并证明东莞市场经济在全国来说，是发展得最快，最成功的地区之一，是全国的典范。

会上，同学们就大学生就业、社会治安、地区之间发展不平衡等问题现场请教了刘书记，他都一一作了回答。

会议由学院党总支书记朱志德同志主持。
