# 学院召开思想政治理论课建设迎评动员会议

5月9日，学院在315会议室召开迎接省厅关于我院思想政治理论课建设进行评估工作动员会。学院领导杨敏林、朱志德、朱冰、张林、高香林，院督学陈丁堂出席会议。各部门负责人、各系部主任、党总支正副书记，思政部全体老师参加会议。

动员会由高香林副院长主持。

会上，张林副院长宣读了省教育厅关于对华南师范大学增城学院等12所高校进行思想政治理论课建设评估的文件，并详细介绍了与我院有关的评估安排。院办主任王玉宣读了我院迎接广东省高校思想政治理论课建设评估的工作方案。思政部主任何鹏举汇报迎接思想政治理论课建设评估的前期准备工作。

党委书记朱志德强调，做好思政课评估工作是为明年办学水平评估打基础，希望全院师生要提高认识，统一思想，高度重视，全体动员，全员参与，明确分工，全力配合，争取获得优秀的成绩。具体来说，思政部要制定出接待工作方案，教务处、思政部有关人员继续收集整理好有关教学档案和资料。

杨敏林院长在总结讲话中高度评价思政部在教学和管理方面所取得的成绩，认为工作基础好、起点高、亮点多，接着他要求把评建工作的目标锁定在“优秀”档次上。各单位要严格按照评估的要求做好准备工作，力求做细、做实。要以评促建，提高全院教育教学的质量。

据悉，学院还将于5月24日邀请省内高校思想政治理论课专家指导委员会的专家对我院思政课建设工作开展一次预评估。
