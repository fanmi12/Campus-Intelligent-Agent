# 我校学工团队参加2019年南方辅导员论坛

6月14日，2019年南方辅导员论坛在华南农业大学举行，我校党委书记章德胜率领学工团队参加了论坛。本届论坛对广东省2018年辅导员年度人物、提名奖、单项奖和入围奖获得者进行了表彰，其中，我校艺术学院张宏渝副书记荣获2018年广东省辅导员年度人物，何珊珊老师荣获广东高校最受学生欢迎辅导员称号，詹海都老师荣获广东高校最具科学精神辅导员称号。

本次论坛由广东省教育厅主办，高校思想政治工作队伍培训研修中心（华南师范大学）和教育部高校辅导员培训和研修基地（华南师范大学）承办。教育部思政司、广东省教育厅、海南省教育厅相关领导、相关高校领导、广东省高校学工部负责人出席了此次论坛。

据了解，此次论坛颁奖典礼环节由我校艺术学院党总支副书记张宏渝担任总导演，邝富强和王素娟老师担任节目《不忘初心》表演嘉宾。
