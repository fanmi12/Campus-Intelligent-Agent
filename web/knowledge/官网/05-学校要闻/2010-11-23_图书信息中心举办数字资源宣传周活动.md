# 图书信息中心举办数字资源宣传周活动

为了进一步提高图书馆数字资源利用率，充分发挥数字资源为教学、科研服务的作用，11月8日至17日，图书信息中心在电子阅览室开展了为期一周的数字资源宣传活动。

学院邀请中国知网、读秀、万方、慧科资讯、软件通、EPS数据平台等知名数据库培训师为师生介绍如何在海量资源中获取目标信息等方面的知识，并针对不同数据库的功能特点、资源特色、使用方法及技巧，通过FLASH演示做了精彩的讲解。

据悉，一周来电子阅览室座无虚席，老师和同学们积极参与讲座，认真听讲和做笔记，与讲课老师进行了互动。
