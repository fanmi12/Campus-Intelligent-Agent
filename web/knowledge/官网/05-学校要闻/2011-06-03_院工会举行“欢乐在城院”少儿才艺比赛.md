# 院工会举行“欢乐在城院”少儿才艺比赛

朱志德书记为全晨小朋友颁奖

为庆祝“六一”国际儿童节， 6月1日晚，院工会在图书馆小剧场举办了“欢乐在城院”教工子女才艺比赛，近150名教职员工及其小孩参加了活动。

小选手们各显其能，用不同形式、不同风格的精彩节目展示城院子女的幸福与快乐，既有生动有趣的故事，又有热情洋溢的拉丁舞，还有各种中西乐器演奏，更有1-3岁幼儿们的运气球比赛，他们的纯真，他们的笑容，他们的才气博得了家长们会心的笑容，也赢得了全场观众的阵阵掌声。最终，财经系陈益云老师的女儿全晨的拉丁舞表演获得一等奖。
