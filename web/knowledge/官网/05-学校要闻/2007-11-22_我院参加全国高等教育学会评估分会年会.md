# 我院参加全国高等教育学会评估分会年会

11月16日，我院高等教育与评价中心邵润堂教授代表我院参加了2007年全国高等教育学会评估分会年会。会议在北京师范大学珠海分校举行，全国50余所高校的教学管理及教学研究的领导及管理人员与会。

会议的主题是研讨学生评教问题。大会宣读了有关学生评教的8个专题报告，内容涉及中外有关学校关于学生评教的研究成果。邵润堂教授认为，这次会议对改进我院教学督导工作和学生信息工作将有很大帮助。
