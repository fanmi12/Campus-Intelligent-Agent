# 我校召开落实新时代美育工作协调会

6月20日，教务处组织召开落实新时代美育工作协调会。章德胜书记、高香林副校长和各有关单位负责人出席了会议。

教务处处长赵书山传达了《广东省教育厅关于转发<教育部关于切实加强新时代高等学校美育工作的意见>的通知》精神，提出了我校具体落实教育部美育工作的实施方案，对相关单位的工作任务进行了讲解，希望各单位对照总体要求按时做好美育工作的实施计划。

高香林副校长指出，各单位要根据教育部、省教育厅的有关文件精神，明确美育工作的总体要求及目标，落实重点任务，逐条对照落实，特别是围绕普及艺术教育、专业艺术教育两个重点领域，切实加强我校新时代美育工作。

章德胜书记强调，在教育教学方面，要加强专业艺术教育，开展面向全校学生的公共艺术课，使全体学生受益。在课外活动方面，要开展丰富多样的社团活动，将“请进来”和“走出去”相结合。各单位要高度重视美育工作，加以提炼、总结，加强宣传，打造我校美育工作特色。
