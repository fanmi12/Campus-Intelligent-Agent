# 我院又添一校外实习基地

3月8日，我院与东莞石龙红点纸类制品厂校外实习基地建设签约仪式在机电工程系举行。东莞石龙红点纸类制品公司总经理黄健明、学院教务处处长邓成良、机电工程系主任黄健求等出席了签约仪式。

会上，双方就印刷专业学生赴东莞石龙红点纸类制品厂实习的相关事宜进行了讨论，内容包括基地挂牌、实习教师的派遣、实习学生的管理等。黄总经理表示，他们将会为学生提供良好的实习条件，并期待与学院有更广泛的合作。
