# 周致纳、杨晓西来我院看望慰问教职工

周书记盛赞校训石“学而知不足”字体刚劲有力。

周书记一行与教职工亲切交谈，送上美好新年祝福，派发新年利是。

2月27日，是新学期教职工上班的第一天。这一天上午，东莞理工学院党委书记周致纳、校长杨晓西，在东莞理工学院副校长、城市学院院长安少华和党委书记朱志德等院领导的陪同下，亲切看望慰问我院教职工，了解开学工作准备情况。

周书记一行每到一处，与教职工们亲切交谈，送上新年的祝福，提出工作希望与要求。周书记语重心长地对院办工作人员说：“办学五年来，你们克服困难，取得了很大成绩。希望大家继续努力，乘势而上，牢牢把握发展机遇，创造新的业绩。”

他们离开学院时，叮嘱院领导转达他们的问候，祝愿师生员工元宵节快乐，工作顺利，学习进步，事业发达。
