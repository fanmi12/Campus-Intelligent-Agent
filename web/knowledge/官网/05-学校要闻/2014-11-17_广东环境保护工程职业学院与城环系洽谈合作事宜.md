# 广东环境保护工程职业学院与城环系洽谈合作事宜

11月3日，广东环境保护工程职业学院环境科学系系主任郭璐璐、环境工程与土木系副主任马承荣一行5人来我院参观访问，城环系主任肖红飞教授、热情接待了到访客人，并就专业合作交流事宜进行了洽谈。

据悉，广东环境保护工程职业学院隶属于广东省环保厅管理，行业办学特色显著，设有土木工程、安全工程等专业，与我院城环系有许多相同之处，存在需求的空间和合作办学的条件。此次交流主要从三方面展开：一是专插本招生相互沟通、相互宣传，形成良好的合作关系；二是促成双方在实训实验资源、实习实践基地以及就业单位等方面的资源共享；三是在科研申报或技术攻关方面形成合作关系。

通过交流，双方在产学研合作等方面已达成初步的合作共识。
