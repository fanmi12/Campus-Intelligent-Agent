# 暑期留校学生参加校园保卫工作

暑期来临，我院有29名男同学留校配合保卫科参加学校保卫工作。他们除了在教学楼、实验楼、饭堂、学术报告厅等各个建筑及主干道的出入口定点值班外，还定时分批巡查校园。据保卫科邓队长介绍，值班工作人员每人每岗都要做好值班记录，接班后必须对登记表上的项目逐项检查登记。他说，这29名同学具有高度的责任心，按时到岗，勤查常巡，能及时处理突发事件，表现出较高的素质。
