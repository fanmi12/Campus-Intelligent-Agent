# 我院团员踊跃参加“科学发展  青春畅想”青年论坛

为贯彻落实省委、市委提出“思想大解放，推动大发展”指示精神， 3月25日，学院团委率40名学生团员参加团市委在寮步广场举办的 “解放思想 ．青年争先”为主题的东莞青年论坛活动。同时，院团委还组织团员青年在网上开展了“科学发展 ．青春畅想”学习讨论活动。
