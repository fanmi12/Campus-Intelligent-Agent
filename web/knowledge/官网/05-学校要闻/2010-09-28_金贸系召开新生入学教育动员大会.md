# 金贸系召开新生入学教育动员大会

9月26日，金融与贸易系在大礼堂召开新生入学教育动员大会，系主任米双红教授、党总支书记龙卫洋博士、全系教师及全体2010级学生参加了会议。中华联合财产保险公司、中宏人寿保险公司、永尚节能科技有限公司的领导也应邀出席了动员大会。

米主任为新生介绍了出席会议的嘉宾和全体教师。嘉宾代表为新生分析了保险行业的前景，为新生今后的学习和择业提出建议，使新生对我系的实践教学有了初步的了解。国际贸易教研室主任王锦锋老师和保险教研室主任郭忠林老师分别为新生介绍了五个专业的培养目标、就业情况等，使新生对自己的专业定位有更明确的认识。系辅导员及教学秘书为新生介绍了城市学院的考勤制度、奖贷勤制度、学生活动管理等相关制度和要求。龙书记鼓励新生要多方面地融入大学生活，提高自己的综合素质。
