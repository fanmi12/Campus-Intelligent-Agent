# 社会科学系举行2008届毕业生联欢会

又是六月夏意渐浓，社会科学系2008届莘莘学子即将离开美丽的校园，踏上新的征途，开始新的挑战。在他们离别的前夕，6月13日，社会科学系在大礼堂举办了主题为“放飞梦想 开创未来”的2008届毕业生联欢会。

本次联欢会得到学院的高度重视，院党委宣传部部长、新闻中心主任何鹏举副教授，社会科学系主任、党总支书记陈丁堂教授，院学生处副处长丘永辉老师，新闻中心副主任黄隆顺副研究员，社会科学系党总支副书记石志民副教授及全系师生参加了联欢会。

系主任陈丁堂教授致词，代表全系师生表达了对毕业生的美好祝愿。

本次晚会吸引了系内外学生到场观看，会场座无虚席。晚会在《FOREVER FRIEND》温馨动人的歌声中拉开序幕，随着主持人的介绍，一个个精彩节目依次亮相舞台。其中，民族舞《乐韵》、现代舞《神起》、健美操《扇动》等舞蹈节目极度带动气氛，现场灯光闪烁，舞者技艺高超，让人目不暇接。07法学专业舞台剧《蒲公英的约定》，给观众带来了许多新鲜元素，留下了关于生命与人性的思考。歌曲演唱节目《我只在乎你》、乐器演奏节目《友谊天长地久》和小组合唱节目《祝福》，让即将毕业的同学们再一次怀念起过去那些欢声笑语的时候，怀念那些在校园一起走过的日子。社会科学系第二届学生会和团总支代表表演的诗朗诵《六月花开》，娓娓道出了依依的毕业情、城院情，场面动情感人。最后，晚会在大合唱《祝福》节目带来的温情与甜蜜中拉下帷幕。

晚会结束后，城院学院院长安少华教授与各毕业班同学合影留念。
