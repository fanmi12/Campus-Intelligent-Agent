# 展示城院学子风采  接受用人单位挑选

3月15日，城市学院2008年校园人才招聘会在4号楼大厅举行，我院和东莞理理工学院50多个专业的4000多名本（专）科毕业生到场应聘。一大早，前来应聘的学生就在东莞市工商银行等用人单位招聘点前排起了长龙。

举办招聘会旨在为毕业生提供更多的就业选择，为用人单位提供更畅通的选拔平台。本次招聘会不收取任何费用，免费为参会的单位提供展位和制作海报。当日共有140多家用人单位参会，主要是东莞本地的一些公司、学校和企业，其中有中国太平洋人寿保险股份有限公司、东莞市邮政局、东莞市苏宁电器有限公司等企事业单位。

同学们在了解用人单位相关背景、具体情况、未来前景之后，按自己的意愿选择面试，进而与用人单位进行了充分的沟通。整个招聘过程使得大学生们对用人单位人才需求特点、人才市场走向有了一定的了解。

据悉，学院高度重视学生就业工作，去年，07届毕业生就业率达到99.7%，绝大多数专业达到100%。

今年，由于新《劳动合同法》的颁布，企业的用工成本相对提高，因此各企业在招聘大学生时显得更加谨慎、理性。为了应对新的情况，学院对毕业生开展了相关内容的教育。比如，从大学一年级开始，对大学生进行职前教育，专门设立职业规划协会，举行模拟创业设计大赛，帮助同学们在进入大学校门时就能树立职业理想、学习目标，制定职业规划。学院还为每个学生建立职业规划档案，不断跟踪毕业生就业、创业情况。

本次招聘会由东莞理工学院城市学院主办，东莞市中心人才市场、东莞理工学院学生处、东莞市外商投资企业协会协办。
