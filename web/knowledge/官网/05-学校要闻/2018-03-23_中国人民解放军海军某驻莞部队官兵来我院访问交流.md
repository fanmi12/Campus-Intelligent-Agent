# 中国人民解放军海军某驻莞部队官兵来我院访问交流

3月22日上午，中国人民解放军海军某驻莞部队官兵一行75人来我院访问交流。

教务处副处长鞠晓红、后勤保卫处副处长刘维仝、院办行政科科长韦晓霞热情接待了来访官兵。在7A107教室，曹丽娟老师为官兵们主讲了《单片机的中断系统》，陈跃老师传授了“教学方法”，双方就教学经验进行了交流探讨。

来访官兵还参观了图书馆、商科虚拟仿真实践教学中心和创意设计学院。
