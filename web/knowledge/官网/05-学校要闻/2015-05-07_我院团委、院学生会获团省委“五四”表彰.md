# 我院团委、院学生会获团省委“五四”表彰

5月4日，共青团广东省委员会发布了《关于表彰2014-2015年度广东共青团优秀个人和集体的决定》，表彰一批优秀团组织和个人。其中，我院团委被授予“广东省五四红旗团委”称号，学生会被授予 “广东省优秀学生会”称号，管理系团总支副书记刘绮彤被授予“广东省优秀共青团员”称号，院学生会主席赖焕婷被授予 “广东省优秀学生干部”称号。

过去一年，院团委紧紧围绕学院中心工作，牢牢把握共青团工作的大方向，找准引领和培育青年的工作思路和方法，转变工作作风，推动各级团组织创新发展，在思想引领、校园文化、成长服务、组织建设、志愿服务、文体艺术等方面取得新的成绩，涌现了一批先进团组织和个人。
