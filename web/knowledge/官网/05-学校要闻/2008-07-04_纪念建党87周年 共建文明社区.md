# 纪念建党87周年  共建文明社区

为庆祝建党87周年，提高党员的理论水平和党性修养，应堑头社区党总支委员会的邀请，7月3日上午，我院社区研究中心组织石志民、程建新、林晓等老师赴堑头社区为社区讲党课，堑头社区支委、村委会副主任陈建华同志主持了会议，堑头社区40多名党员参加了会议。

此次社区党课由我院思想政治理论课教学部副主任、社会科学系党总支副书记石志民副教授主讲，主题为“中国共产党的发展历程与历史经验”。石志民副教授从“中国共产党成立的历史背景”、“中国共产党发展的曲折历程”、“中国共产党带领中国人民不断走向胜利的历史经验”、“中国共产党的历史对现在的启示”等四个方面，深入浅出地介绍了我们党从无到有、从小到大、从不成熟到成熟的发展历程，展现了党“挽狂澜于既倒、救民族于危亡”的历史使命感和和近现代中国波澜壮阔的历史画卷，受到堑头社区党员干部的欢迎。

堑头社区支委、村委会副主任陈建华同志认为，在建党87周年之际，重温党的发展历程、加强党员理论武装，非常及时也非常必要，广大党员特别是青年党员要不断加强理论学习，提高执政能力，以顺应东莞不断深化的改革开放实践，顺应东莞经济社会双转型的需要。社区要与城市学院密切合作，共建文明社区。
