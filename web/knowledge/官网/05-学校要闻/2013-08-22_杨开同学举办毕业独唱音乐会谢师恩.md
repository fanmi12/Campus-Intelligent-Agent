# 杨开同学举办毕业独唱音乐会谢师恩

“这场音乐会为我大学四年的学习生涯画上完美的句号。”6月14日，以“师恩如歌”为主题的杨开同学毕业独唱音乐会在学术报告厅举办。杨开美妙、清澈、银铃般的歌声及演唱技巧获得同学和老师的好评。

新鲜：学生举办独唱音乐会第一人

城市学院的文体艺术类表演活动非常丰富，但以学生个人名义举办的独唱音乐会还是第一次。

杨开是我院艺术系音乐表演专业大四学生，其平滑、匀净的声线，华丽灵巧的花腔技巧和出色的极限音域等特点，赢得了校内外音乐爱好者的高度赞扬和肯定。杨开曾在2011年第四届《中国小音乐家》全国评选活动中荣获“小音乐家”称号，2012年又获得广东省大学生科技文化艺术节声乐比赛“季军”。

歌声：技艺超群

音乐会上杨开共演唱了9首歌曲，其中8首为中外经典声乐作品，有《紫罗兰》、《我亲爱的爸爸》、《亲爱的名字》等。其中一首《春天的芭蕾》点燃全场高潮，她跳得深情，跳得沉醉，使人想进入她的世界，跟着她一起跳出这个春天里最真诚的一支芭蕾。还有《炫境》这首歌也是最让人印象深刻的，它将人声当成一种乐器，用花腔的方式支撑一首完整的声乐作品。这首歌的演唱难度不光在花腔上，慢板部分对音色的拿捏、意境的塑造、气息的感觉等都很考验歌者的基本功，而杨开的声音含蓄、浪漫、空灵、飘逸，整首歌只有一个“啊”字，却令人意犹未尽。

感恩：用歌声表达心声

“春天的花开了，夏天的蝉叫了，秋天的果熟了，冬天的雪飘了，老师我想你，想你，你是我最美好的记忆。”伴随着一曲《老师，我想你》历时一个半小时的音乐会也渐渐落下帷幕。

“老师，四年来一直对我悉心呵护，在学习和生活上都给了我很多很多的鼓励，谢谢你！”最后，杨开为她的专业老师康慧丽送上鲜花表示感谢。在筹备音乐会期间，康慧丽老师积极为她联系场地和筹备经费。两人深情相拥并都落下了热泪，大家都为这美好的师生情而感动。
