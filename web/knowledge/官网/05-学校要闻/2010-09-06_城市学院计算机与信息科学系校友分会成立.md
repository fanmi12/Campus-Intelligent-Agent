# 城市学院计算机与信息科学系校友分会成立

9月4日，城市学院计算机与信息科学系校友分会成立大会在7114会议室举行。学院校友工作办公室常务副主任江小卫，计算机与信息科学系主任牛熠博士，党总支书记廉玉忠教授，副书记葛卫清副教授，辅导员林胜凯、陈浩华、彭俐，以及校友会筹备组成员和来自各地的03级、04级、05级、06级计信系校友代表出席了本次大会。

大会推选产生了第一届校友分会领导机构人员。计信系03级学生李钜全任分会会长，系主任牛熠任顾问组组长。

校友分会会长李钜全代表校友发言，他深情回顾了学生时代的点点滴滴，感谢广大校友的信任，表示将团结和带领广大校友，积极开展各项活动，加强交流合作、互帮互助，充分发挥校友会的桥梁纽带作用，联系更多校友热心为母校的发展献计献策。

牛熠主任介绍了计算机与信息科学系近年来的建设发展以及在学科建设、专业建设、实验室建设等方面所取得的成果。他指出，校友会是校友联系母校的桥梁与纽带。加强校友会工作，搭建校友沟通平台，有利于促进学校和校友的发展与提高。他希望校友们加强联系，心系母校，干出成绩，为母校增光添彩，为母校的发展做出新的贡献。
