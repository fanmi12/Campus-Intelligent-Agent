# 我院今年计划招收5000名大一新同学

近日，省教育厅下达2013年全省高校招生计划，我院的招生计划超5000，与去年持平。新校区启用后，学位、师资、宿舍、饭堂、图书馆等资源都得到扩容，可容纳2万名学生学习生活。

新增专业

为了满足东莞人民接受高等教育的强烈愿望和社会人才市场的不断需求，我院在积极改善办学软硬条件的同时，适时增加热门专业，积极创办特色专业。我院现有招生专业为31个专业方向。今年上半年，经教育部批准，增设了建筑电气与智能化、财务管理和土木工程3个本科专业（方向），这3个专业（方向）都是考生报考的热门，参照其他高校来说，这几个专业都是热门专业，毕业生就业率较高。

新生奖学金 受惠面更广

我院自2011年起，设立优秀新生奖学金，奖金百万元。对考入我院分数超过上一批次（即广东2A分数线、外省当地二本分数线）以上的考生均一次性颁发优秀新生奖学金，其中文、理科前10名的考生获得2万元优秀新生奖学金，其他考生获得1万元优秀新生奖学金；同时对我院录取的省内2B分数线的文、理科前10名的考生将一次性颁发1万元优秀新生奖学金。

报考建议

根据2012的数据分析，凡是达到省公布的2B录取分数线的考生，第一志愿报考我院，录取机会是非常大的，基本为第一志愿专业录取，对报考我院志愿的考生。如果想被理想专业录取，建议在第一组志愿中填报东莞理工学院城市学院，同时最好加上服从专业调剂。考生在填报志愿时要注意：考生须根据自己的报考类别在规定时段的时间内上网填报志愿，逾期不报，责任由考生自负。漏报志愿（含志愿无效）的考生只能在录取阶段相应批次征集志愿时补报有缺额计划的院校志愿。本科各批次高校录取时，由于考生志愿不平衡，可能有部分高校未能在第一组院校志愿完成招生计划，因此，考生应在合理填报第一组院校志愿的同时，积极填报本科各批次第二组院校志愿，以提高被录取机会。
