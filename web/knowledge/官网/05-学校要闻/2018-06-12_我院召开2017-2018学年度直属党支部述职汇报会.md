# 我院召开2017-2018学年度直属党支部述职汇报会

6月11日下午，我院2017-2018学年度基层党组织量化考核工作汇报会议（直属党支部述职汇报）在行政楼407会议室召开。学院党委委员王卫平、章德胜、高香林、黄兢、杜鹏举和各直属支部书记出席了会议。

各直属支部书记围绕班子建设情况、党员学习教育情况、发展党员工作、日常管理工作、特色亮点工作等情况，依次作了8分钟的工作汇报。

王卫平书记对学院七个直属党支部的党建工作成绩给予了充分肯定。他表示，作为各直属党支部在日常工作任务重的情况下，发扬党组织的战斗堡垒作用和党员的先锋模范作用，为学院的发展做出了重大的贡献。他指出，本学年各直属党支部在党建工作上有了很大的提高和创新，希望大家相互学习、相互借鉴，共同提高。
