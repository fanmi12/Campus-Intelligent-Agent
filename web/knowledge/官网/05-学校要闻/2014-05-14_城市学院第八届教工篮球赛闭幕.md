# 城市学院第八届教工篮球赛闭幕

5月13日，伴随着裁判的一声哨响，城市学院第八届教工篮球赛决赛在教师公寓篮球场精彩落幕。

教辅代表队凭借自身优势与稳定发挥，在一、二节比分落后的情况下，适时调整打法，逆转局势，连连得分，最终战胜机关代表队，夺得第一名，机关代表队屈居第二名。

在三、四名角逐中，城环系代表队获第三名，财经系代表队获第四名。

据悉，本届教工篮球赛共有11支代表队、164名队员参加比赛。
