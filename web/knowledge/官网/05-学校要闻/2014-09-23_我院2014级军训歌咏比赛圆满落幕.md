# 我院2014级军训歌咏比赛圆满落幕

9月22日，我院2014级学生新生军训歌咏比赛在运动场举行。

各参赛单位的比赛曲目有两首，一首为必唱曲目《城市学院之歌》，另一首为自选曲目。或雄壮，或悠扬，新生们精神饱满，步伐整齐，歌声嘹亮，挥着飘扬的军旗，舞动着专属他们的激情与青春，向评委老师和观众展现了大一新生良好的精神风貌。

歌咏比赛为大一新生提供了一个展示自我的平台，这是信心和勇气的比拼。在运动场上，一首首铿锵有力、雄浑大气的歌曲追溯了战士们的峥嵘岁月，抒写着军人的壮志豪情。来自城环系6连的男兵们颇有军人气概的站姿，配以浑厚有力的男声，一首《练练练》瞬间响彻了整个球场。来自文传系16连的女兵们在教官萨克斯的伴奏下，整齐有力的女声悦耳动听，手里高举着鲜花，瞬间运动场上变成一片花海，赢来全场沸腾掌声。最后，压轴的艺术系18连不负众望，以近乎完美的专业水准倾情演绎了《我爱这蓝色的海洋》，迂回百转的音律，搭配着优雅有力的舞蹈，再度掀起全场高潮。

经过激烈的角逐，最终文传系16连和艺术系18双双以96.6的高分连摘得桂冠， 5连、14连荣获二等奖，4连、7连和13连获得三等奖。
