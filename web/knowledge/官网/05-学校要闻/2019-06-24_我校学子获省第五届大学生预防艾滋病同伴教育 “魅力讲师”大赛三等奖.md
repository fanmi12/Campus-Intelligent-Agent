# 我校学子获省第五届大学生预防艾滋病同伴教育 “魅力讲师”大赛三等奖

6月13日下午，广东省第五届大学生预防艾滋病同伴教育“魅力讲师”大赛在广东医药大学举行决赛。我校学生处新苗社会工作服务中心陈晓湛同学的《爱情36计》主题演讲荣获大赛三等奖。我校也连续四年荣获“最佳组织奖”。

本次大赛由广东省教育厅主办，省内数十所高校的191名青春健康同伴教育讲师参加了比赛，经层层选拔，共有10名选手进入此次决赛。我校陈晓湛同学向现场的观众朋友分享了情侣交往中例行的三条法则，成功晋级决赛并喜获三等奖。
