# 市公安局来我院检查指导危险化学品安全工作

3月27日下午，东莞市公安局联合寮步镇公安分局对我院危险化学品、易制毒及易制爆等危险化学品开展安全检查与指导工作。

后勤保卫处处长王锦锋、实验中心主任葛卫清对我院危险化学品在采购、储存、运送、使用、废弃处置等全过程的管控情况，做了详细汇报。

市公安局尹创业警官和寮步分局李坚炜警官对危险化学品从采购到废弃各个环节进行了指导，现场检查了化学品仓库和实验室，要求强化责任意识，提升政治觉悟，保障校园安全稳定。
