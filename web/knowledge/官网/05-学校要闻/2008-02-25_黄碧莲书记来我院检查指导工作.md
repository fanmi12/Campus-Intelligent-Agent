# 黄碧莲书记来我院检查指导工作

2月18日，东莞理工学院党委副书记、纪委书记黄碧莲同志、审计监察处处长邓耀林同志在院领导朱志德、朱冰、张林陪同下检查指导我院新学期工作。

黄书记向全院教工带来了新年的祝福，她充分肯定了过去一年中城市学院取得的成绩，对学院2008年纪检监察工作任务提出了指导意见。院党委书记朱志德同志向黄书记简要汇报了工作设想，并表示将一如既往的作好各项工作，取得更大的成绩。
