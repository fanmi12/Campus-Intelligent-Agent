# 我院举行创新创业学院揭牌仪式

3月14日下午，我院举行创新创业学院揭牌仪式。

王卫平院长在致辞中，对政府部门和社会各界给予我院的支持和关爱表示衷心的感谢!他指出，2018年4月我院成立创新创业学院，是在新时代、新形势下迈向高素质应用型人才培养的重要举措。学院将在应用型人才培养的发展中，紧跟时代潮流，适应社会发展需求，抓住粤港澳大湾区建设的大好时机，锐意改革，勇于探索，为大湾区建设作出应有的贡献。

随后，与会领导和嘉宾为创新创业学院进行了揭牌。

会上，创新创业学院还举行了第四届中国“互联网+”大学生创新创业大赛广东分赛获奖项目表彰暨第五届中国“互联网+”大学生创新创业大赛启动仪式，对获奖的6个团队进行了颁奖。

出席此次揭牌仪式的领导和嘉宾有：东莞市人力资源和社会保障局副局长吴柏安，市就业管理办公室创业服务科负责人马国彪，市人力资源和社会保障局寮步分局局长刘俊桢、副局长钟坚玉，学院董事长代表陈超群，众来达集团副总裁王柳芳，东莞市蚁巢科技企业孵化器有限公司总经理黄德玉等。

学院领导王卫平、章德胜等和行政教学单位负责人参加了揭牌仪式。揭牌仪式由创新创业学院常务副院长孔增强主持。
