# 台湾东华大学赵涵捷校长一行来访

3月13日下午，台湾东华大学校长赵涵捷、教务长林信锋、华语文中心主任朱嘉雯一行到访我院。院领导王卫平、周庆、林江龙以及教务处处长牛熠、文传系主任宋秋敏、港澳台事务办主任陈峰等热情接待了客人。

王卫平院长对赵涵捷校长一行表示热烈欢迎，介绍了我院办学历程、校园建设、学科专业建设、师资队伍、人才培养及国际交流等有关情况。赵涵捷校长介绍了东华大学基本概况和办学特色，表达了开展两校合作的愿望。座谈会上，双方还就两校开展师生交流等合作进行交流探讨。

赵涵捷校长一行还参观了校园、校史馆，与创意设计学院、文传系进行了交流互动。

据了解，台湾东华大学成立于1994年，共有寿丰、美仑、屏东三个校区，设有人文社会科学学院、管理学院等8个学院，在校学生10000多人。
