# “舞动城院”校园舞蹈大赛启动

3月27日，我院在教学楼7A118举行“舞动城院”校园舞蹈大赛启动仪式。艺术系党总支副书记李瑶以及各系团总支学生会主要干部参加了启动仪式。

李瑶副书记指出，本次舞蹈大赛是首次面向全院举办的舞蹈类专场比赛，在喜迎东莞理工学院城市学院建院十周年之际，为全院学生提供一个展示自我和锻炼自我的平台。同时，为了能够更加彰显“公平公正”的比赛原则，艺术系学生不直接参加本次比赛，但必须为各系部参赛队提供专业技术指导。通过此次比赛，一方面，锻炼舞蹈专业方向的学生对课堂所学知识的实践操作及运用能力，达到学以致用的效果；另一方面，通过学生对各系部参赛队的专业指导，将提升整场比赛的专业水平。

各系通过抽签方式抽取各参赛队指导老师，并在会后相互进行了沟通协调。
