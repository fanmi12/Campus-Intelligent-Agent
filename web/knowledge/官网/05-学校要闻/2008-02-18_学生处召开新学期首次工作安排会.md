# 学生处召开新学期首次工作安排会

2月17日，学生处在4#410召开新学期首次工作会，党委副书记朱冰、学生处处长章德胜、副处长丘永辉、副处长陈建新以及学生处全体工作人员和全体辅导员与会，宿管中心主任周衢和主任助理曾惠娴应邀出席。

章处长向全体学生工作人员致以新春的祝福，并布置了新学期的主要工作，包括学生的报到注册、学生宿舍检查、08年的招生准备工作、毕业生就业指导工作等。

丘副处长就开学的主要工作做了具体的安排。

最后，朱冰副书记作了总结性的讲话，她说，过去一年学生工作是比较成功的一年，在全体工作人员的共同努力下，我们在心理咨询、学生宿舍管理、毕业典礼文艺演出、迎新工作、就业指导以及新年音乐会等工作中都有所创新，并在07年“十大创新奖”的评选中取得了较好的成绩。她希望大家再接再厉，争取更大的成绩。

据悉，学院各职能部门都已做好了开学的准备工作。
