# 我校材料成型及控制工程专业获学士学位授予权

近日，广东省学位委员会公布了2019年新增学士学位授予专业名单，我校材料成型及控制工程专业获得学士学位授予权。截至目前，我校共有29个专业取得学士学位授予资格。

2018年9月，我校启动了新增学士学位授予专业审核工作。根据上级文件要求成立学校学士学位授予备案工作领导小组，制定实施方案，多次组织校内外及学位教育管理专家进行评审，召开学校学位委员会进行集中评议等系列举措，使材料成型及控制工程专业顺利通过省学位办组织的学士学位授予专业评审获得学士学位授予权。

新获得学士学位授予权的材料成型及控制工程专业将从2019届毕业生开始授予学位。
