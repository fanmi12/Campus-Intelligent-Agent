# 财经系召开第二阶段评建工作会议

11月15日，财经系在5A220会议室召开第二阶段评建工作会议。

副院长高香林教授出席会议并对财经系近期的工作提出了两点要求：（一）做好评建工作，按学院有关文件及评估指标收集整理资料，做好资料的建档工作；（二）开展好培养应用型人才的教育思想大讨论，设计出一套符合财经系学生的培养方案。高副院长希望财经系教职工要齐心协力，统一思想，把迎评工作落实到实处。

财经系主任罗卫国教授解读了“系部教学工作评估支撑材料”及“自查与整改”阶段有关文件，并对财经系评估支撑材料收集归纳整理工作进行了分工。罗主任指出，在做好教学评估是重点工作的同时也要抓好教风、学风、班风的建设，营造良好的学习氛围，做到教学与管理协调发展，把各方面的工作落实到位。
