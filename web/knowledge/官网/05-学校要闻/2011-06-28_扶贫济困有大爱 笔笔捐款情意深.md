# 扶贫济困有大爱 笔笔捐款情意深

6月27日，院工会组织全院机关人员在四号楼大厅举行“广东扶贫济困日”捐款活动。全院教工踊跃捐献爱心款项39096元，特殊工会会费1948元。同时，女教工们还积极响应院妇联“姐妹情深”10元捐活动的号召，捐献善款2440元。在团委组织下，我院学生也为本次活动捐款9377.30元。教工党员缴纳特殊党费4459元。截至今日，全院师生共计捐款金额为57320.30元。
