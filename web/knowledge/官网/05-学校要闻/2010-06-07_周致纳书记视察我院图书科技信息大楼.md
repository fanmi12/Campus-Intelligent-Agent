# 周致纳书记视察我院图书科技信息大楼

6月4日，东莞理工学院党委书记周致纳在城市学院院长安少华、党委书记朱志德、副院长程发良、党委副书记朱冰的陪同下视察新落成的图书科技信息大楼。

周书记一行首先来到位于四号楼旧图书馆四楼多媒体教室，向工作人员询问多媒体课室的建设情况。他说：“专家的设计成果，最终要接受实践的检验，听老师和同学们的反映如何。图书馆不仅要美观，更要好用。每个细节都要以师生使用方便为前提。”

随后，周书记与院领导又来到刚刚完成主体搬迁工作的新图书馆总服务台及阅览室。当他们看到图书馆8楼至12楼采用半封闭式，楼层之间用室内楼梯连接，顶楼采用透光性强的玻璃封顶，光线透明度好的设计与布局时，表示非常满意，给予了充分的肯定。
