# 学院召开新学期教学系部工作会议

8月28日，高香林副院长在315会议室主持召开了各教学系部负责人工作会议，研究部署新学期学院办学主体搬迁工作。院长杨敏林、书记朱志德、督学陈丁堂出席会议。

会上，院领导听取了教务处和各系部负责人关于新学期课程、教材、教师的落实情况，以及学院搬迁准备等工作的汇报。

杨院长强调：教学是学院的中心工作，要稳定教学秩序，提高教学质量。新学期我院将面对复杂的形势，新校区有4000多老生和5000多名新生以及老校区4000多名老生入学。 “一校两区”的新形势，对教职工人员提出了更高的要求。各系部负责人要进一步明确工作职责，加强沟通，理顺工作，同心协力做好办学主体搬迁工作，确保学院平稳过渡。要注重引导，完善制度，优化学院内部治理结构，充分发挥新机制在学院管理中的作用。

朱志德书记要求，教务处要确保新教材到齐，课程表要提前公布，任课教师人手一份。各部门要认真研究和部署新学期的工作。对当前存在的问题要认真整改，为广大师生提供优质服务。
