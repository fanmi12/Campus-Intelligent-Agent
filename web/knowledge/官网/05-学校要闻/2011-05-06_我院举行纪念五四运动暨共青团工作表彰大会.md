# 我院举行纪念五四运动暨共青团工作表彰大会

会场朱冰副书记为优秀团总支颁奖5月4日，城市学院2010—2011学年度团组织工作总结表彰大会在学术报告厅举行。院党委副书记朱冰，院党委宣传部部长何鹏举，学生处副处长邱永辉，院团委书记杜鹏举、副书记罗文芳等老师及300多名团员代表出席了会议。

杜鹏举书记宣读了《表彰文件》，并做了主题发言。他号召全院团员青年向先进集体和个人学习，将“五四精神”进一步发扬光大。会上，先进集体代表李海东老师和先进个人代表黄伟文同学与大家分享了工作经验。

据悉，共有643名优秀团员、150名优秀团干、21个优秀团支部、3个优秀团总支受到表彰。优秀团总支分别是文学与传媒系团总支、城市与环境科学系团总支、金融与贸易系团总支。
