# 2014工模花絮之三：吃货大作战

你最想吃什么呢？城院工模应有尽有，让我们吃货大队一起进攻城院工模吧！

这种满头大汗的炎热天气里，当然是要来一碗超大碗的水果刨冰了！工模上有很多的刨冰摊位，但是小编觉得，五号摊位的水果刨冰料多量足，味道特别好，在这种炎热的天气里能吃上一口新鲜水果加冰，真的透心凉的舒服啊！

想必大家都听说过潮汕牛肉丸，那么，在东莞哪里能吃到正宗的潮汕牛肉丸呢？答案就在城院工模上！三号摊位“胶己人”从千里迢迢的潮汕运来了最正宗的牛肉丸，配上了香浓的沙茶酱，一口咬下去，弹性十足，有人大赞：“这是可以用来打兵乓球的牛肉丸！”除了这些，还有晶莹剔透的水晶果，香脆的无骨鸡柳、晶莹剔透的水晶球、外酥里嫩的无米果，都是正宗的潮汕美食~

别着急，工模上可不只有一家地方特色美食！小编带你们上工模吃遍中国各地的美食~

首先，来到了游牧民族的烧烤美食摊位。还未到达就已经先闻见了浓烈的香味，羊肉串和牛肉串在烧烤架上烤得肉香四溢，旁边有一条条肉质鲜嫩的秋刀鱼，以及炒得滋滋作响的鱿鱼，更有前所未见的手割肉，小编刚开始看见名字被吓到了……这么一大堆肉食，绝对管饱！

如果你是吃腻了猪肉羊肉牛肉 这种"平常肉",那么小编给你介绍一个不平常的肉——鹿肉！黑龙江的漠河烤鹿肉，想必我们广东的娃都很少见过吧，何不如趁这个机会去试试！

吃烧烤，当然总是免不了吃烤生蚝吧！但小编这次带你们去吃的不是上火的烧烤，而是保留了最原始味道的蒸生蚝！鲜香滑嫩的生蚝大餐，一口一个停不下来啊！

蒸的美食其实还有一个，就是做工精致的蒸饺了！不仅是长相诱人，可以看见，一个饺子里的材料十足啊，不难想象，当我们一口咬下去，会有多满足！

吃完香喷喷的大餐，我们就来细品一下饭后甜品吧~在这次工模上，各种各样的甜品层出不穷，各种甜品摊位也是各具特色！小编觉得，最吸引人的地方，其实是这些甜品都是由美男美女亲手制作的哦！那就让我们来一一品尝吧~

看完小编给你们介绍的工模美食后，城院的吃货们是不是觉得身处城院福气满满啊？那就快来和小编一起进攻城院工模美食吧~吃货们，走起！！！
