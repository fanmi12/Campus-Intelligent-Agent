# 我院讲席专家王雄文副教授应邀为东莞市社会工作协会作专题讲座

10月24日，在东莞市国防教育训练基地主楼2号教室，我院讲席专家王雄文副教授应东莞社工协会的邀请，给东莞市2014年新晋社工见习督导进行专题培训。培训主题是《政府购买岗位模式下的法律关系定位与社工职业自主权的保障》。

王雄文副教授的讲座分为三部分：政府购买岗位社工模式的法律关系定位；当前政府购买岗位模式的实践与检讨；政府购买岗位社工模式下社工职业自主权的保障。

讲座结束后王雄文副教授与社工督导们进行了热烈的互动，回答了社工们普遍关心的热点和难点问题。
