# 我院在2018年广东大学生创业大赛摘得三银八铜

由团省委、省教育厅、省人社厅、省科技厅、省科协、省学联共同举办的2018年“挑战杯?创青春”广东大学生创业大赛终审决赛暨第十二届广东大中专学生科技学术节, 5月25日-27日在华南理工大学举行。我院团委书记李瑶、副书记陈振伟，商学院罗芳、陈文丽老师和三支入围终审决赛的队伍参加了决赛。

本次大赛共吸引全省128所高校的1594项作品参赛。经评审，进入终审决赛的作品共442项，我院的Honey Bees尤克里里教育交流平台项目、基于机器视觉的棒材质量检测及自动包装柔性系统项目、绿麦子助农公益平台三个项目进入现场答辩环节，并获得银奖。

据悉，我院共有16支参赛团队本次“挑战杯?创青春”广东大学生创业大赛，分为创业计划、创业实践和公益创业三大类，取得三银八铜的好成绩。
