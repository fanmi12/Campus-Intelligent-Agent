# 我院艺术类单考“两项创新”方便考生

城市学院2013年艺术类单考3月1日拉开帷幕，首日报名人数已超过了300人。

据了解，根据省教育厅的招生工作有关规定，我院今年艺术类单考试行“两项创新”办法，大大方便了考生。一是首次实行网上预报名，考生通过使用网上预报名系统，可直接上网报名。二是专业课考试时，考生也可预约来城院的考试时间。
