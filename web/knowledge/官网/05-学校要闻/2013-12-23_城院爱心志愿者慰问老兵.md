# 城院爱心志愿者慰问老兵

12月21日，我院文学与传媒系志愿队来到莞城区敬老院看望老兵，送去同学们征集到的新年祝福语,以及衣物、水果和营养品等礼物。记者也跟随他们一道听到了许多感人的老兵故事。

吴奶奶：四世同堂，生活比想象的好

吴奶奶是一位老兵的遗孀，丈夫在26岁时战死，她丈夫的名字就镌刻在东莞市人民公园纪念碑上。奶奶的小屋很温馨，家什摆设井井有条，墙上发黄的照片上镶着“吉祥如意，福寿康宁”的字样，见证着岁月的痕迹。吴奶奶亲切地和志愿者们交谈，虽已96岁高龄，但依然精神矍铄。“婆婆，老婆饼好不好吃啊？”“好食，我好中意噶！”奶奶开怀大笑，并竖起大拇指赞叹道。记者了解到，吴奶奶如今是四世同堂，儿孙绕膝。志愿者告诉奶奶，现在宣传力度加大了，会有越来越多的人加入到关爱老人的群体。奶奶再次竖起大拇指：“大家都很有心，你们要好好学习，我的生活请你们放心好啦，不用担心！”

卢爷爷：老人惊人的记忆力，让志愿者佩服得五体投地

卢贺年爷爷1934年生人，昨天刚从医院回来。“年纪大了，身体也不中用了，”他指指自己的腿说。平时不善言谈的卢爷爷在志愿者们热切期盼下打开了话匣子。老人思路清晰，说起过去的事仍记忆犹新，打土豪分田地的喜悦，饥荒年代的艰辛，社会主义建设时期的幸福生活溢于言表。1955年至1958年，他在佛山军分区当防洪兵。“为了响应彭德怀元帅的号召，参加建设社会主义，我没有告诉父母便去当了兵。”卢爷爷继续回忆说：“我们在大海里挖泥，背到坝边抬泥起坝，有时候还要用身体挡上去。”那年他22岁。复员后，卢爷爷被分配到汕头抗流5年，养过猪，种过地，在鱼塘大队记过工分，在水泥厂当过工人。如今老人仍与过去的战友有联系。

徐爷爷：一人当兵，全家光荣

今年75岁的徐昔辉爷爷可谓是敬老院中最为健谈的老兵了，言语中透露着满满的骄傲：“一人当兵，全家光荣！”从他口中我们得知，1956年至1960年他在福州军区，参与了抗美援朝战争。如今老人早已脱下戎装，在敬老院享受阳光，兴致好的时候就出门买东西，闲时在屋里看“七十二家房客”。老人拿出珍藏的军歌谱和这些年来的相片给志愿者们看。此时，一位同学兴致勃勃地唱起了歌曲“学习雷锋好榜样”。同学们将写有“老兵，虽然你脱下了军装，却永远脱不掉军人的本色；虽然你摘掉了军徽，却永远摘不掉赤子的忠诚；虽然你离开了战友，却离不开革命的友谊。告别了你战斗过的地方，我们的思念和祝福伴随你一同启航”的祝福语送给了徐爷爷。他高兴地收下了同学们的礼物。

志愿者告诉记者，这是一次成功的慰问，志愿者们深刻的感受到了战争年代的艰辛，亲眼见到了这些老兵们的生活现状。我们相信，这样的关爱之旅会一直延续下去。
