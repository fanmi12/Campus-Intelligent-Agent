# 文艺系顺利开展毕业生教育和离校工作

根据学院要求，文学与艺术系认真开展该系毕业生教育和离校工作。6月24日开始，相继开展了“赠人玫瑰，手留余香，情寄母校，真情回馈”的毕业生捐赠活动、“真情寄语”签名活动、合影留念、师生“茶话会”及聚餐等活动。

其中，毕业生捐赠活动与“真情寄语”活动，在3号楼举行，毕业生把自己的一些旧书捐给母校和师弟师妹，同时写下对母校的留念与感激之情，祝福母校的未来会越来越美好。

在福迎门大酒店举办的茶话会上，文学与艺术系主任陈庆祝博士，系党总支书记孟颖老师相继发言，祝愿毕业生们在未来的日子里一帆风顺，并希望毕业生文明离校，铭记自己是城市学院的学生，为母校争光，常回家看看。班主任及学生代表表演了节目，畅谈大学感触，场面十分感人，很多老师和学生都流下了眼泪。
