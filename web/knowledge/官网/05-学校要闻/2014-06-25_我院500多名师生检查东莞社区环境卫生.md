# 我院500多名师生检查东莞社区环境卫生

6月20日，我院根据东莞市城管局的邀请，组织500多名学生党员、入党积极分子，深入500个社区开展卫生大检查。同学们按照检查内容和计分标准，找问题，查卫生死角，公平计分，受到各镇区政府的好评和点赞。

检查出发之前，东莞市城管局在我院学术报告厅举行2014年上半年东莞市整治环境卫生大检查动员大会，城市学院党委书记王卫平在会上做了动员讲话，他要求同学们要认真开展检查，公平计分，提出整改意见。东莞市城管局副局长就这次检查的意义、方法、内容发表了重要讲话。

此次检查的内容包括：清扫保洁工作、门前“三包”，“六乱”，公共厕所管理，垃圾填埋场，垃圾转运站管理，环卫宣传7大项。检查的重点部位是出租屋、居民住宅区、商铺、工厂区的环境卫生。由同学们计分的项目有14项、共30分。

记者跟随师生队伍来到高埗镇实地采访。这个组20个同学分为十支小分队对朱磡村、三联村等19个村镇的环境整治卫生工作进行了走访、调查与计分。同学们在陪检员的带领下，严格按照评分标准对住宅区环境、公厕、城市垃圾桶、宣传栏等设施进行检查和评比。

计信系陈奇同学说，高埗镇无论在环境卫生、环卫设备、基础设施、公共卫生、环境宣传等工作比往年都做得更好。居民反映意见较大的是，市镇（区）政府对环卫设施的投入不足，环卫工人待遇较低，河港管涌中的污水排不出，产生的臭气使人生厌。

高埗组评分的结果是一个组为30分，一个组为29.72分。8个小组给了29.7分，点评情况是好的。

据悉，今年我院师生已是第17次代表市政府检查社区的环境卫生整治工作。本次参检的500多名同学由党员、预备党员和入党积极分子，同学们表示，参加这样的活动锻炼了自己，服务了社会，很有成就感。
