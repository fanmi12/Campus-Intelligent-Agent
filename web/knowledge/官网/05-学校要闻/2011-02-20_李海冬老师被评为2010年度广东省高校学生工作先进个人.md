# 李海冬老师被评为2010年度广东省高校学生工作先进个人

近日，广东省高校学生工作专业委员会下文通知称，我院文学与传媒系辅导员李海冬老师被评为“2010年度广东省高校学生工作先进个人”。

据了解，李海冬老师自2007年7月在东莞理工学院城市学院参加工作以来，一直担任文学与传媒系辅导员一职，兼任系党总支组织委员、学生党支部书记和团总支书记。工作期间，常怀感激之情，秉进取之心，视学生为亲人，踏实肯干，先后获得9项奖励，使所在系连续两年被评为学院“优秀基层党组织”和“优秀团总支”。
