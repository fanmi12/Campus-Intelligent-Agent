# 城市学院第二届董事会第四次全体会议召开

5月25日，东莞理工学院城市学院第二届董事会在东莞理工学院行政楼 1A403会议室召开第四次全体会议。

根据城市学院2011年在校人数将突破一万人的实际情况，学院董事会决定聘任杨敏林为城市学院副院长，主抓新校区的建设和日常运作。

会议强调，开学前三个月是新校区筹备工作的关键时期，全院教职工要努力工作，协调配合，整体推进，确保老校区迎评促建和新校区顺利开学两件大事圆满完成！
