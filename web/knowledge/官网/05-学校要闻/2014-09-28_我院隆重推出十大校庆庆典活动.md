# 我院隆重推出十大校庆庆典活动

记者近日从城市学院建校10周年校庆庆典活动办公室获悉，我院将定于10月18日举行校庆10周年庆典，将校庆纪念活动推向高潮。庆典这一天，学院推出十大活动，与大家共同分享盛事。

据校庆办有关负责人介绍，城市学院经过10年的建设发展，现已经成为一所现代化的大学，成绩来之不易，当以总结与庆贺。庆典活动本着隆重、热烈、简朴的原则进行，旨在通过校庆活动，进一步凝心聚力，把城院的事情办的更好。活动内容包括：召开校庆庆典大会，邀请市镇政府、东莞理工学院、战略合作单位和兄弟院校的领导，以及校友、家长代表出席大会；表彰校龄满10年的教职工，举行校庆文艺晚会，举办篮球文化节、“印象·城院”作品展、城市学院顾问杨元惺教授摄影作品展和十年教学成果展示；举行校史展厅剪彩仪式、时间囊启动仪式、十年校园景观揭幕仪式。

据悉，校庆各项活动正在紧锣密鼓进行中，有的已进入倒计时阶段。
