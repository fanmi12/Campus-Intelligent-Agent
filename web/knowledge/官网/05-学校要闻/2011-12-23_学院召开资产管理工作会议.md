# 学院召开资产管理工作会议

12月22日，学院在315会议室组织召开全院资产管理工作会议。副院长张林，院督学陈丁堂，东莞理工学院资产后勤管理处副处长王浩良出席会议。学院各部门主要领导及资产管理员参加了会议。

会议由学院办公室主任王玉主持。

本次会议的主题是“强化资产管理，保证国有资产安全”。院资产管理办公室主任周梓荣教授向与会人员报告了我院目前资产管理工作的现状，近几年所做的工作以及下一步资产管理工作安排，重点部署了一年一度的全院资产清查工作。王浩良副处长对城市学院近年资产管理工作给予了充分肯定，并表示东莞理工学院资产后勤管理处将全力支持此次资产清查工作。

张林副院长做了重要讲话，他认为资产办成立以来做了大量艰辛的工作，取得了巨大的成绩。今后的工作将更加艰巨、责任更加重大，希望全院各部门高度重视，相互协助配合，按计划完成资产清查工作，确保国有资产的安全与保值、增值。
