# 学院召开2012届毕业生代表座谈会

“已经找到工作的、专业对口的、待遇满意的请举手！”院长杨敏林表示，举手情况从一个侧面说明了同学们对学院办学思想、人才培养目标、教学质量的满意度。6月26日，学院在315会议室召开2012届毕业生代表座谈会。

院领导杨敏林、朱冰、陈丁堂、高香林出席会议听取毕业生代表的意见。

会议主持人、团委书记杜鹏举在归纳同学们的意见时说，与往年不同的是，今年的意见不再停留在吃住层面，都是一些“高精尖”的问题，都是良策妙计。这些意见包括：希望青年教师提高上课水平，进一步丰富学生认知实习的形式与内容；加强课程安排的整体设计；杜绝考试作弊现象，充分发挥学生的学习积极性；适当增加大四的课程；社会调查要与书本知识相结合，考试应与司法考试、考研、英语等级考试紧密结合；提高宿管员的服务质量，加强宿舍安全工作。

“同学们意见温柔婉转，但很中肯实在，是我们今后工作的着力点。”杨院长表示，我们将认真改正，把工作做得好上加好，同时也希望同学们一如既往地关心母校，支持学院的发展。
