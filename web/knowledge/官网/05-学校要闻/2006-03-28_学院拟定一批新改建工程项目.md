# 学院拟定一批新改建工程项目

院长安少华教授、副院长程发良教授、党委副书记朱冰带领后勤部门负责人，在检查校园建设时，拟定了一批新建和改建项目。

这些项目是，图书馆和观鱼台工程列入学院议事日程，正式启动前期准备工作，包括立项、选址和落实设计单位。改造校园大门花坛、校训石花坛、竹林山和“人才之星”四周的花坛，改种一些新的花木品种，做到一年四季花常开。校园大门的大王叶树之间安装吊花篮，学生公寓3．4．5号楼及网球场外围墙安装防盗网。其中有的项目待学院董事会批准后即可开工建设。
