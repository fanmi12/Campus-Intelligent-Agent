# 东莞市副市长喻丽君莅临我院调研

3月7日下午，东莞市副市长喻丽君在东莞理工学院党委副书记吕琦元陪同下莅临我院考察调研。我院院长杨敏林等领导向喻副市长介绍了我院校园建设、教学科研、人才培养、师资队伍建设等方面的情况。

喻副市长先后考察了我院教学管理大楼、图书馆、学生宿舍、综合馆、教学大楼、电子信息大楼及校园环境等，对我院校园建设给予了肯定，称赞学校“漂亮、精致、大气、实用”。喻副市长还询问了我院学科专业建设和在校学生的相关情况，强调发展学科专业建设要加强与行业、企业的合作，科研要紧密结合东莞产业转型升级，努力推进协同创新，服务东莞经济社会。

在工程实训中心、学生宿舍、综合馆的考察中，喻副市长与师生进行了亲切交谈，了解师生的工作、学习、生活情况。看到同学们认真、熟练操作机床，看到同学们在运动场上生龙活虎，喻副市长非常高兴，她叮嘱学院要支持学生发挥特长，培养学生的运动爱好，培养学生的团队意识，努力培养出高素质、高技能的优秀人才。喻副市长对教师们辛勤地为东莞教育事业奉献表示感谢。

喻丽君副市长对我院各项建设工作取得的成绩给予肯定，并提出了宝贵的意见，鞭策我院与时俱进，努力建设成特色鲜明的应用型本科院校。
