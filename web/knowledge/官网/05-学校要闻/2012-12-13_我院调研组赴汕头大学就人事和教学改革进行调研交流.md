# 我院调研组赴汕头大学就人事和教学改革进行调研交流

为了进一步深化学院内部改革，促进学院跨越式发展，12月11—12日，院党委副书记章德胜，组织人事处处长胡钦华，教务处副处长葛卫清及组织科、人事科、师资科人员，赴汕头大学就人事和教学改革进行调研交流。汕头大学党委常委何文标、人事处副处长刘明强、组织部副部长黄少斌及教务处副处长杜虹热情接待了我院调研组。

双方汕头大学的人事制度改革、绩效考核、人才培养、组织发展及干部管理等方面工作进行了深入探讨。
