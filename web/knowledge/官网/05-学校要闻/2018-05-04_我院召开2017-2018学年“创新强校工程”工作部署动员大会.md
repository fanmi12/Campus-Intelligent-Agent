# 我院召开2017-2018学年“创新强校工程”工作部署动员大会

5月2日下午，我院召开2017-2018学年“创新强校工程”绩效考核工作部署动员会。学院领导及各行政、教学、教辅单位负责人参加了会议，会议由黄兢副院长主持。

会上，研发处处长牛熠对我院四年来“创新强校工程”的绩效考核情况进行了详细汇报，对“创新强校工程”总体建设情况进行了认真总结，对省厅民办本科高校的绩效考核指标进行了对比剖析。

牛熠处长还

对我院“创新强校工程”绩效考核的一级、二级、三级指标的得分进行了细致解读，全面总结分析

了我院在同类院校中的优势以及存在的不足，并提出了有针对性的建议及措施。

与会人员分别就人才培养、师资队伍建设、科研体制机制改革、资源配置机制改革、社会服务、学生考研率等指标进行了讨论交流。

黄兢副院长对 “创新强校工程” 下一阶段的工作安排进行了布置。

王卫平院长重申了“人才培养是高等学校根本任务之一”的指导思想。他充分肯定了学院自开展“创新强校工程”建设以来取得的成绩，同时要求各部门要高度重视，充分认识“创新强校工程”的重要性和紧迫性，结合“创新强校工程”绩效考核情况，及时总结经验，认真分析考核指标体系，明确下一学年工作重点和建设目标。他还强调各部门要切实抓好落实，确保在规定时间内保质保量完成本学年的“创新强校工程”绩效考核工作。
