# 3000名新生地震逃生演习圆满成功

“因发生地震，现进行紧急疏散。”9月26日下午2点30分，城市学院学生饭堂和大礼堂突然传出了“呜——”的警报声。随着警报声，同学们迅速有序地奔跑疏散……不到3分钟时间，近3000名学生均安全疏散到空旷的操场，整个演习圆满成功。

这是城市学院2008级新生军训的一项新课程——“地震疏散逃生”演习。演习中，学生们在老师的指挥下，迅速而又有序地从各个疏散通道紧急撤离，有的同学双手抱头，有的弓下腰降低自己的身体重心。饭堂的1700余名学生和大礼堂的1200余名学生分别在1分01秒和2分30秒后安全撤离到空旷地带，疏散过程中没有发生拥挤、推搡现象，无一人受伤。

刚刚“逃生”成功的陈亮同学气喘吁吁地说，按照逃生通道的指引，我们很快就跑出来了。这样的演习很有必要，如果真的发生危险我们就知道应该这么做了。

本次演习总协调陈建新老师在接受记者采访时说：今年我国先后遭受雪灾、地震等自然灾害，凸显出灾情自救知识教育的不足和缺憾，高校有必要对大学生进行防灾逃生教育。通过演习，提高学生在面临突发事件的心理素质和逃生技能。

据悉，这次活动是我院首次进行“地震疏散逃生”演习，以后还将继续开展其他方面的逃生、自救演习。
