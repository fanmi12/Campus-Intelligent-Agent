# 章德胜书记为学生上第一堂思政课

深情高歌《幸福在哪里》、激情朗诵《有的人》……3月11日下午，学院党委书记章德胜为2018级金融学专业3、4班的同学们在7B316教室上了一堂精彩的思政课。

在这堂《思想道德修养与法律基础》课上，章德胜书记以《创造有意义的人生》为题，与同学们探讨了“幸福是什么”，进而引导同学们树立正确的幸福观、得失观、苦乐观、顺逆观、生死观和荣辱观。

讲到“幸福是什么”时， 章德胜书记还当场唱起了殷秀梅的歌曲《幸福在哪里》：“它在辛勤的耕耘中，它在知识的宝库里。啊！幸福就在你闪光的智慧里……”

在讲到如何树立正确的生死观时，章德胜书记又激情高昂地朗诵起臧克家的诗作《有的人》：“有的人活着，他已经死了；有的人死了，他还活着……”

在声情并茂、生动活泼的课堂上，章德胜书记告诫同学们要警惕和抵制错误的人生观，鼓励大家自觉将人生目标同国家和民族的前途命运紧紧联系在一起，最大程度地实现人生价值，成就精彩人生。
