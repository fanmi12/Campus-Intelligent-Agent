# 香港太平绅士王霖先生莅临我院参观指导

左四为王霖先生

王霖先生饶有兴趣的在校园中留影3月26日，香港太平绅士、东莞同乡总会荣誉会长、东莞市荣誉市民，曾为东莞理工学院筹办作出巨大贡献的王霖先生等一行莅莞，特地到我院参观考察。东莞理工学院副院长、城市学院院长安少华教授，副院长张林博士热情接待了王霖先生。

89岁高龄的王霖先生在安院长等陪同下，兴致勃勃的参观了学院校容校貌，并在多处景点留影纪念。王老先生对我院的巨大变化和快速发展，感到由衷的欣慰。
