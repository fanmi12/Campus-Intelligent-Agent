# 学习四中全会精神 推进依法治校进程

11月12日，城市学院大讲堂第五十二讲在行政楼112会议室开讲，本讲座邀请北京大学博士生导师湛中乐教授解读十八届四中全会会议精神。院领导王卫平、张林、陈丁堂、章德胜、高香林、麦琦琳出席讲座，机关各处室负责人、各系系主任及党总支负责人听取了湛教授的报告。党委书记王卫平主持讲座。

湛教授介绍了十八届四中全会的背景，重点回顾了近几届四中全会的会议主题，特别是对十八届四中全会“依法治国”方略的内容进行了详细解读。

湛中乐教授从依法治国又讲到了高校依法治校的必要性。他说，“国有国法，校有校规”。要加强大学章程的建设，完善大学治理架构，并依据大学章程建立大学治理体系与监督体系。建立院一级的教授委员会，依靠教授治校，充分发挥教授在学术组织中的骨干作用。要防止学校过度行政化。弘扬和培育大学精神，力求创新，既要加强学校与国家、社会的外部联系，又要兼顾与教职工、学生的利益，充分发挥学校的管理职能与服务职能，将法制精神贯彻于学校的教学管理之中。

他介绍说，这次四中全会还提出了“法制队伍专业化”的重大命题。城市学院政法系分为法学、行政管理和社会工作，专业比较齐全，学生未来就业前景良好。

湛教授的讲座思路清晰，观点鲜明，理论联系实际，对我院开展“依法治校”工作具有指导意义与现实作用。
