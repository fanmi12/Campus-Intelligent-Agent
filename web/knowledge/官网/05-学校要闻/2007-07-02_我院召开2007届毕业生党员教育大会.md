# 我院召开2007届毕业生党员教育大会

为了提高毕业生党员适应社会的能力，毕业后继续发挥党员先锋模范带头作用，学院党委于6月26日在大礼堂举行2007届毕业生党员教育大会。学院党委副书记朱冰同志和全院500多名毕业生党员参加了会议，会议由学院党委委员、院办主任王玉同志主持。

朱冰副书记向全体毕业生党员提出了要求和希望：一要珍惜党员身份，增强党员意识，时刻记住自己是一名共产党员；二要加强党性修养，争创“三有一好”优秀党员；三要按照党章严格要求自己。今后不论是继续学习还是工作，都要继续发扬党的优良传统，工作上尽职尽责，生活上严以律己。朱冰副书记还向同学们介绍了组织关系的保管、转移等注意事项。

通过教育动员大会，毕业生党员明确了自身的责任，坚定了信心，表示一定发挥党员模范作用，做一个合格的共产党员。
