# 我院举办思政课课堂教学创新研讨会

4月26日下午，在“理论有深度，实践有温度”的高度评价中，学院教师发展中心联合马克思主义学院顺利举办了教师发展大讲坛第四期——思政课课堂教学创新研讨会。

广东省高校思想政治教育研究会副理事长、华南理工大学博士生导师刘社欣教授应邀担任主讲嘉宾，深刻解读了习近平总书记在学校思想政治理论课教师座谈会上的重要讲话精神。他阐述了思政课特殊的教学要求和思政课教师的“强、深、新、广、严、正”的特殊要求。思政课教师要研究规律和遵循规律，要发现问题和直面问题，要内容创新和形式创新，推动思政课建设内涵式发展。

刘社欣教授结合思政课教学的成功案例和自己的教学经验，从思政课教学的困难性特点入手，在教学方法（导入法、深入法、游戏法等）、教学模式（研究型教学、问题型教学、实践型教学）等方面与老师们进行了深入的交流与探讨。

研讨会内容具体而丰富，为思政教师开阔了课程视野，强化了责任意识。与会教师积极发言交流，分享各自的教学经验和体会。教师代表周琳、向前、詹海都老师分享了思政课的授课经验。

此次研讨会旨在加强我院思政课教师队伍建设，增强课堂教学创新能力，提高思政课教师思想政治教育的理论素养和深度。马克思主义学院全体专任教师，学生处全体成员，各教学单位党总支书记、副书记、辅导员等参加了本次研讨会。
