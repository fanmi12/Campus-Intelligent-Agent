# 周致纳、杨晓西、安少华慰问师生员工

“给你们拜年，大家新年好！”2月16日，新学期开学第一天，东莞理工学院、城市学院领导向师生员工拜年，给大家送上新年的祝福和节日的问候。

上午11时，东莞理工学院党委书记周致纳，东莞理工学院院长、城市学院董事长

杨晓西教授，东莞理工学院副院长、城市学院院长

安少华教授，在我院领导朱志德、程发良、朱冰、张林的陪同下，先后来到学生处、图书信息中心、文学与艺术系、基建办等

单位向老师们拜年。

领导们每到一处，都受到师生员工的热烈欢迎。在走访慰问过程中，领导与师生员工互致问候，畅谈新年的感受与收获，谈论最多的是全国军民抗击雨雪低温灾害的动人事迹。当得知许多师生亲自参与“雪战”和慰问灾民的情况时，领导们感到非常欣慰，当即给予表扬并指出，这说明我们的老师与同学有很强的政治敏感性和自觉性，无愧于“人民教师”、“当代大学生”的光荣称号。师生们表示，不辜负领导的期望，好好工作，努力学习，进一步做好今年的工作，用实际行动支持灾区人民的灾后恢复工作。

据悉，大年除夕，学院盛情宴请了留校过年的学生，院领导还与学生同吃团年饭。新年第一天，院领导向节日坚守岗位的清洁工人、保安、饭堂工作人员拜年，分别派发了利是。

新年第一照。周致纳、杨晓西、安少华与我院领导新春合影留念

周致纳书记给教师派发利是，送上新年的祝福

教师用糖果盛情报答领导的关怀

安院长：“同学们，为新年的到来干杯！”

院领导与留校过年的学生同吃团年饭
