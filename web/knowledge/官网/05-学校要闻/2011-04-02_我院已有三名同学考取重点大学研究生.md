# 我院已有三名同学考取重点大学研究生

近日，我院考研学生传来喜讯。在重点院校自主划线复试中，政法系汤文杰、文传系朱梦雯、机电系袁雅倩三位同学分别参加了中山大学、华中科技大学和华南理工大学硕士研究生复试，并以优异的成绩被录取。其中，汤文杰同学喜获中山大学法学院全额奖学金，不仅免除学费和住宿费，还每月补贴400元。袁雅倩也获得华南理工大学三等奖学金5000元。

据教育培训中心主任李丽娟老师介绍，全国研究生入学考试国家分数线是3月30日

公布的，我院其余通过国家线的同学将于四月中旬分赴各报考学校参加复试。
