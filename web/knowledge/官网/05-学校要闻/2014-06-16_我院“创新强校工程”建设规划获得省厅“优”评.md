# 我院“创新强校工程”建设规划获得省厅“优”评

近日，广东省教育厅组织专家对各高校“创新强校工程2014-2016年建设规划”进行评审论证，我院“创新强校工程2014-2016年建设规划”获得专家好评，总体评价为“优”。在6项考察指标中，“指导思想、体制机制改革、建设内容、预期效益”4项指标被评价为“优”，“资金预算、保障措施”两项指标评价为“良”。

今年2月份，学院接到省教育厅有关通知后立即着手开展“创新强校工程”建设规划编制工作，先后多次召开编制工作会议，进行部署与分工。学院领导要求有关职能部门应按时完成编制工作，而且要将“创新强校工程”规划成为我院未来3年发展的纲领性文件与行动方案。

由于规划距离报省教育厅只有2个月的时间，因此编制工作面临时间紧迫、任务繁重、涉及面广等问题。为此学院进行了全院动员，各有关部门和各系部积极参与了编制工作。全体参编人员发扬严谨、认真、任劳任怨的工作作风，广泛调研，征求意见，科学论证，数易其稿，在4月底之前顺利完成了长达近5万字的规划编制工作。
