# 我院成功举办2018届毕业生校园招聘会

今日下午，我院2018届毕业生大型校园招聘会在运动场举行。300家企业携15000多个就业岗位前来选才纳贤，共吸引了我院及外校应届毕业生6000多人前来应聘。

东莞市人才办主任陈柏林、副主任吴德阳，寮步镇民营科技局局长韩柏泉，我院领导王卫平、章德胜、黄兢等亲临现场指导工作。

招聘会现场，200顶蓝色帐篷整齐排列在运动场，蔚为大观。毕业生们身着正装，捧着精心准备的自荐书，充满自信地与企业招聘人员交流，主动了解用人单位的情况，寻找心仪的工作。热门企业、岗位摊前更是排起了长队，现场人头攒动，秩序井然。

据招生就业处处长孔增强介绍，本次招聘会秉承“规模大、企业质量高、服务精”的原则，按照我院38个本科专业4800多名应届毕业生的有关需求，从1500多家申请企业中精选了300多家企业参会，共提供了15000个岗位。其中，经济贸易类(含市场营销)占25.1％，管理类占23.6％，工程技术类占18.5％，文秘艺术类占9.8％，其他类的岗位占23％。这与我院毕业生的专业相契合，极具针对性。

值得一提的是，参与企业提供的薪酬普遍高于去年，大部分岗位月薪高于4000元，总体平均较于去年提升了300-500元。同时，招聘会还增设了“校友企业专区”,并设置打印处为学生提供准备付印等服务。

我院校友、2007届毕业生行政管理专业李日欢现任东莞证券股份有限公司东莞东泰证券营业部总监。她从2012年接手招聘工作开始，每年都会参加我院举办的大型招聘会。李日欢总监告诉记者：“我们学院的毕业生求职意向会更加务实，定位比较精准，这是我们企业所看重的。”她还建议，应届毕业生不能先想着能赚多少钱，经验、人脉和实践经验都很重要，要懂得主动的去学习，培养自己的创新思维，在实践当中能够吃苦耐劳。

记者在现场看到，往年知名企业应聘者排长队“一花独秀”的景象不再，取而代之的是“群雄四起”。来自文传系毕业生余宙玲对记者说，在择业时，她会先优先考虑专业方向相关的企业，毕竟要学有所用，然后就是面试岗位的发展空间。来自城环系毕业生黄嘉毅说：“大多数毕业生都会优先考虑本专业，在这基础上再考虑多方面就业，先要谋求一份稳定的职业保证自己经济独立。”记者采访发现，大部分毕业生会优先考虑专业对口问题，其次是公司发展潜力，最后是地理位置。

针对我院2018届毕业生的就业心理与实际情况，孔增强处长建议毕业生应该本着“先就业再择业”的原则，从自身的实际来确实应聘的岗位，积极主动投入实践中去为自己增值，扎根于基层，积累自己的经验以谋求更好的发展。
