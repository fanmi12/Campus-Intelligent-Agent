# 我院阿卡贝拉清唱团闯进东莞“梦想·行动”活动12强

9月20日，共青团东莞市委员会、东莞广播电视台联合举办了2014“梦想·行动”东莞市青少年理想信念教育实践活动。经过5个月的宣传、征集、筛选，我院阿卡贝拉清唱团和男子篮球队来到了这个属于他们的实现梦想的舞台，经过激烈的角逐，“Weirdo”阿卡贝拉清唱团的出色表现赢得了在场观众的热烈掌声，并顺利晋级12强。

据悉，优胜者将于今年12月份在“梦想·行动”颁奖晚会上展示。
