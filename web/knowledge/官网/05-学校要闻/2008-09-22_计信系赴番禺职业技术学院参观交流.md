# 计信系赴番禺职业技术学院参观交流

受番禺职业技术学院软件学院贺平院长的邀请，9月19日，计算机与信息科学系主任牛熠博士，计算机与电子类专业的教授、博士，教研室主任以及部分教师一行到番禺职业技术学院软件学院参观交流。

座谈会上，贺平院长与牛熠主任相互交流了两院的专业设置、办学理念、人才定位、校企合作以及课程构建与开发等信息，希望加强校际间的交流与合作。

宾主双方的老师还就游戏设计专业建设、嵌入式技术专业建设、校企合作以及培养计划的修订等工作进行了深入的探讨与交流。

在贺平院长的陪同下，牛主任一行参观了番禺职业技术学院软件学院的实验室。
