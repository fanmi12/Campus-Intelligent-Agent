# 我校召开党建与思想政治工作例会

5月22日，我校召开党建与思想政治工作例会，部署近期相关工作。我校党委书记章德胜、副校长高香林、组织（统战）部副部长卢淑芳以及各二级党组织负责人参加了会议。

会上，卢淑芳就疫情期间如何发挥基层党组织战斗堡垒和党员先锋模范作用进行汇报，指出在疫情期间，学校党政领导靠前指挥，各二级党组织认真开展各项工作，为我校的防疫工作打下了扎实的基础。她从“提高认识、压实责任”“精心组织、合理安排”“主动作为、高效服务”“周密部署、积极应对”四个方面提出要求，希望各基层党组织和广大党员积极发挥战斗堡垒作用和先锋模范作用，认真落实习近平总书记提出的重要指示，把党中央各项决策部署抓实抓细抓落地，做好疫情期间的相关工作安排与管理，让党旗在疫情防控斗争第一线高高飘扬。

校党委书记章德胜强调，随着疫情防控进入常规阶段，毕业生返校在即，学校各级党组织和党员干部要细心谋划，精心组织，看护好我们的学生，进一步发挥战斗堡垒作用和先锋模范作用。同时要善于挖掘和发现身边党员的先进事迹和工作案例，相互学习共同促进。

章德胜在会上再次强调了近期政治安全和意识形态安全的12项重点工作，要求各级党组织高度重视，压实工作责任，加强风险防控，切实保障特别防护期间学校的政治安全与意识形态安全。
