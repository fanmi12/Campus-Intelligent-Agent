# 章德胜任东莞理工学院城市学院党委书记

元月16日下午，东莞理工学院城市学院召开中层干部（扩大）会议。东莞理工学院党委副书记吕琦元宣布了东莞理工学院党委的任命决定：章德胜同志担任城市学院党委书记，王卫平院长不再兼任城市学院党委书记。

王卫平院长在讲话中指出：坚决拥护东莞理工学院党委的决定，衷心感谢在就任城市学院党委书记期间，全体党员同志对自己的理解和大力支持。他表示将全力支持章德胜书记的工作，希望全体党员同志在章德胜书记的领导下，开拓进取、努力创新，全面加强学院党建工作。

章德胜书记发表了就职感言，他衷心感谢东莞理工学院党委对自己的信任与培养、城市学院董事会的认可与支持，感谢前任党委书记王卫平同志为城市学院的发展作出的重要贡献。他表示，坚决维护习近平总书记党中央的核心地位，以身作则，充分发挥政治核心作用，树立“四个意识”，坚持“四个自信”，带领全院党员同志为城市学院的党建和思想政治工作再创辉煌。

东莞理工学院城市学院董事黎建烨发表热情洋溢的讲话，他衷心感谢东莞理工学院长期以来对城市学院的关心和大力支持，衷心感谢前任党委书记王卫平同志为城市学院发展作出的巨大贡献，希望章德胜书记带领学院全体党员同志，把城市学院的各项工作推上新台阶。

吕琦元副书记在讲话中，对前任党委书记王卫平同志的工作给予了充分肯定，并分别对城市学院党委和章德胜书记提出了“四点希望”和“八个要求”，希望将学习贯彻习近平总书记在广东视察时的重要讲话精神作为当前学院党委的首要工作，坚持立德树人，扎根地方办大学，确保政治安全，发挥政治核心作用与政治保障作用。
