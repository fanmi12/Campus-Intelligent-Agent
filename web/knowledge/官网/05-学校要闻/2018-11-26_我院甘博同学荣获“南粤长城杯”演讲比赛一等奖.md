# 我院甘博同学荣获“南粤长城杯”演讲比赛一等奖

11月24日、25日，广东省第六届南粤长城杯演讲比赛决赛与颁奖仪式在中山大学举行。我院文传系学子甘博斩获大学组一等奖，同时我院也获得优秀组织奖。

本届大赛由广东省委宣传部、省国防教育办、省教育厅、省人社厅、省征兵办、省军区政治工作局、团省委联合举办，以“传承红色基因，汇聚强军力量”为主题，吸引了102所高校、53所技工院校、10多家驻粤部队等单位超过100万人参与，是历年规模最大、参赛人数最多、覆盖面最广的一次。
