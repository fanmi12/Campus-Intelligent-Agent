# 我院喜获第三届全国民办高校党的建设和思想政治工作优秀成果优秀奖

11月1日，教育部思政司、全国民办高校党建研究分会在大连东软信息学院举办了第三届全国民办高校党建工作论坛会，来自全国140所民办高校180 名学校党委负责人与会，会议以“落实立德树人根本任务，积极培养和践行社会主义核心价值观”为主题，共同探讨民办高校党建工作的新思路新方法。

会议公布了第三届全国民办高校党的建设和思想政治工作优秀成果评选结果并颁发了奖状。我院财经系党总支撰写的《理想与青春共成长——基于青年领袖理论的学生党员成长项目》荣获优秀奖。

教育部思想政治工作司副巡视员俞亚东，中组部组织二局五处处长谢玉峰，教育部发展规划司民办教育管理处处长曹志芳、辽宁省委高校工委专职委员、省教育厅党组成员花蕾等同志参加了论坛活动。
