# 我院两教授应邀参加西安研讨会

5月9日至12日，我院财经系主任高香林教授和郑阿泰副教授，赴西安参加由财政部中国财政杂志社主办的“会计学和财务管理专业教学创新与学科建设研讨会”。

与会人员均为全国各大高校会计和财务管理专业的老师。会议听取了中南财经政法大学会计学院张敦力副院长关于“高校财务管理专业学科建设与教学创新”的报告、西安交通大学管理学院副院长张俊瑞关于“会计学专业课程体系与教育教学改革”的报告，以及东北财经大学风险管理与研究中心副主任孙国光关于“精品课程建设体会与经验分享”的报告。这次学术研讨对高校加强学科建设和教学创新提供了很好的思路和方法。
