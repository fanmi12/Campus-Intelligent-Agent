# 我院召开迎评促建工作会议

5月18日下午，学院在315会议室召开迎评促建工作会议。院领导安少华、朱志德、程发良，院督学陈丁堂出席会议。各系部主任、各专业负责人、各专业评估专员和迎评促建办全体人员参加了会议。会议由院迎评办秘书长李先庆主持。

会上，各专业负责人汇报了本专业迎评促建工作的进展情况和存在的问题。

学术副院长程发良教授在会上做了专题发言。他说，学院“会计学”、“软件工程”专业的试评审工作井然有序，严肃认真，是一次“仿真模拟”。这两个试评专业相关人员为此付出了辛勤的劳动，准备是充分的，工作是扎实的，成效是有目共睹的。程副院长强调，评建工作中，系主任负有举足轻重的作用，专业负责人责任重大，评建专员关系重大，专业教师和其他教职工人人有责。

院长安少华教授在讲话中对本次试评审工作给予了充分的肯定，勉励大家要继续做好这项工作。系主任和专业负责人要高度重视评建工作，不仅要亲力亲为，还要讲究质量，注重细节。“专业简况表”和“自评报告”，要凸显特色和亮点。归根到底，高校的竞争就是特色和质量的竞争。我们要以学士学位授权评审工作为契机，深入开展教学改革，不断提高教学质量，培养具有鲜明特色、高素质的人才。
