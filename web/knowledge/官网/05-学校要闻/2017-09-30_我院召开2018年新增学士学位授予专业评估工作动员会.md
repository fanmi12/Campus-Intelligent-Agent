# 我院召开2018年新增学士学位授予专业评估工作动员会

9月29日下午，我院召开2018年学士学位授予专业评估工作动员会。王卫平院长、黄兢副院长和相关部门、院系的负责人及受评专业教研室主任参加了会议。会议由研发处处长赵书山主持。

赵书山处长就具体的评审备案工作作了详细的介绍和安排。与会人员就专业建设、师资队伍、教学管理、实验室建设等问题进行了深入交流和研讨。

王卫平院长指出，大家要按照广东省学位委员会关于新增学士学位授予专业备案工作的要求，认真开展自评工作，查找问题，以评促建，做好专业自评报告的撰写和支撑材料的整理工作。同时要结合广东省教育厅有关开展本科专业评估工作的文件精神，加强专业建设和管理，扎扎实实地把评建工作做好。

据了解，我院今年共有市场营销、环境工程、物联网工程三个本科专业开展学士学位授予专业备案工作，将于明年4月前接受省教育厅组织的专业评估备案审核。
