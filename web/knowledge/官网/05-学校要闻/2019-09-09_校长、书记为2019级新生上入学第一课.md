# 校长、书记为2019级新生上入学第一课

9月8日晚，校长王卫平、党委书记章德胜在综合馆先后为2019级新生上了入学第一课。

王卫平校长围绕“怎样欢快地度过大学四年”这一主题，指引新生四年大学生活。他详细介绍了学校概况后，强调学校不仅注重专业知识和技能的培养，也注重培养学生的文化素质和修养。他表示，在专业知识学习和能力方面，培养学生做到“脑子善于想，眼睛善于看，耳朵善于听，嘴巴善于讲，手脚善于动”。他说：“心动不如脑动、眼动、耳动，而脑动、眼动、耳动又不如口动和手动，因为口动和手动会带动全身动。”

王卫平校长还对新生行动计划的制定与实施提出建议：行动计划实施的关键是合理安排时间，坚持好的生活习惯。王校长寄语2019级新生，希望同学们在城院的日子里学会“拿得起、放得下、想得开”，并祝福大家在城院的四年里能够做到“吃得好、睡得香、笑得开”，努力成为德智体美劳全面发展的社会主义建设者和接班人。

党委书记章德胜以“争做时代先锋 谱写青春华章”为题，从“爱国、励志、求真、力行”四个方面倡导新生勇担大任，争做时代先锋。他强调，当代青年生逢其时，需要肩负起新时代赋予的责任。他还通过列举伟人事迹，为同学们树立了精神榜样，勉励大家“在美好的青春年华里应该为梦想奋斗，通过奋斗成为梦想的圆梦者，在奋斗中释放青春激情、追逐青春理想”。

章德胜书记还针对香港暴乱事件，强调青年大学生要爱党爱国，忠于祖国，忠于人民，坚决拥护党和国家的决策，对侵害中国主权的行为要敢于发声、勇于斗争。

章德胜书记希望同学们珍惜大好学习时光，不断从实践中出真知，更好为国争光、为民造福。对新生寄予四点期望：第一，心怀祖国，志存高远。第二，树立自信，敢于斗争。第三，勤学多思，求真务实。第四，砥砺德行，爱校敬师。
