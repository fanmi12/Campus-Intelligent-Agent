# 院团委荣获东莞市学校共青团工作“标兵单位”荣誉称号

4月25日，院团委从团市委、东莞市教育局《东团联发〔2013〕5号》文件中获悉，我院共青团工作获得共青团东莞市委、东莞市教育局授予的“标兵单位”荣誉称号，院团委书记罗文芳同志获东莞市学校共青团工作“优秀个人”荣誉称号。

2011—2012年，院团委在院党委和上级团组织的领导下，深入贯彻落实科学发展观，积极组织学生开展一系列专题活动，进一步提升学生综合素质。在开展志愿者服务、大学生暑期社会实践活动、校园文化艺术节、科技文化艺术节等活动工作中取得的成绩得到了团市委的充分肯定。同时，院团委不断加强自身队伍建设，开展学生干部培训活动，极大提升团学干部个人素质和工作能力，为院团委的发展奠定良好的基础。
