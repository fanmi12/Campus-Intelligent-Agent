# 招生警示

各位考生及家长：东莞理工学院城市学院办学五年来，遵循“三年打基础、扩规模，五年上水平、创特色”的办学理念，取得了令人瞩目的成绩，得到了广大市民及考生的高度认可。随着考生填报志愿及录取工作的开始。学院招生工作也将全面展开。我们将遵照公平竞争、公正选择、德智体美劳全面考核、综合评价、择优录取的原则，保证招生录取工作的公开、公平、公正。同时，我们也提醒各位考生及家长，我院未曾委托任何招生录取中介进行招生宣传、咨询、录取等工作，任何高考信息必须是通过省、市和我院招生办公室发布的信息方为有效，不可轻信任何高考录取中介机构，以免受骗上当，浪费钱财。
