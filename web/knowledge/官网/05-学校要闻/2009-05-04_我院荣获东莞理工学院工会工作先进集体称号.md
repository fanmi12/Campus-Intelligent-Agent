# 我院荣获东莞理工学院工会工作先进集体称号

4月29日，在东莞理工学院庆“五一”座谈暨工会工作表彰大会上，我院工会被授予“工会工作先进集体”荣誉称号，章德胜同志被评为优秀工会干部，刘红艳同志被评为“工会工作积极分子”。

会上，东莞理工学院工会主席黄碧莲充分肯定了工会工作所取得的成绩，指出了目前存在的问题。她希望与会人员继续做好工会工作，发挥工会代表的作用，为提高教学质量、促进学院协调发展作出新的贡献。章德胜同志作为先进集体代表在会上发言，向大会汇报了2008年城市学院工会工作和今年工会工作的打算与设想。
