# 在尝试“多元”的路上，甘之如饴

艺术系13级音乐表演2班林甘迪，近日被澳门城市大学葡语国家研究专业录取，成为艺术系建系以来第一个成功考取研究生的学生。

林甘迪,一位表面腼腆的女生，内心却有着无比丰富的艺术精神世界。在追求音乐的过程，她坚持不懈；在尝试多元的道路，她勇敢地迈出了自己的脚步。

选择葡语国家研究专业，就是其中一个很好的例子，她认为：“这个专业可以说是研究‘一带一路’发展战略的一部分，也是一个具有良好发展前景的专业。虽然这对自己来说是一个全新的挑战，但是我愿意去接受，也抱着积极的心态去面对。”

对于林甘迪来说，人生总是有很多不期而遇的惊喜，勇于尝试对自己来说就是最适合的专业，最正确的选择！

十年积淀换来的蜕变

林甘迪第一次接触钢琴，是在十年前。“学习钢琴的过程是很枯燥和艰难的，特别是熟悉一首曲子，做到心中有谱，眼里含情，需要花很多时间去反复练习。练习有时会是一个枯燥的过程。很多人在中途选择放弃，很庆幸，我坚持下来了。”而今，在毕业之际，她抓住了学校提供的保荐机会，成为一名即将就读于澳门城市大学的研究生，将在音乐之外，寻找更多有趣的学习方向。

时间是最有价值的本钱，充分利用之后方能实现飞跃。在过去的求学期间，林甘迪多次获得学院奖学金，也参加了各类活动，曾获华夏青少年艺术节优秀奖……最令她印象深刻的是曾到广州参加了一次全国青少年钢琴比赛，还获得了银奖，她说到：“那次比赛之后，使我对未来充满了信心”。

此次能成功迈向研究生的殿堂，最大的动力来自于她所坚持的“学习是我的兴趣，兴趣就是最好的老师”。

最想感谢是心无旁骛的自己

当聊到考研历程时，林甘迪说：“一心一意准备是必要的。在考研中，我首先在英语方面下足了功夫，其次参考国内外形势对具体科目进行详细搜集和全面了解。在过程当中，我也参加了学校的辅导班。在老师的帮助下，我不断提升了自己的知识水平。同时在准备的过程中，保持一个平静的心态，不要被就业的功与名左右，更不要把考研当作是一种压力。”

林甘迪还向记者提到在大三下学期作为交换生到台南应用科技大学就读的经历，这一次体验为自己到澳门考取研究生提供了很大的帮助，也是一种优势。台湾开放的环境更加能激发自己活跃的思维。此外，热情的台湾居民让她感到温馨和安心，也让她深刻体会到了港澳台的魅力。

用心体验生活的同时，专心致志于学习，有个明确的目标和方向是达到成效的指明灯。

尝试多元生活，丰富自己

从小时候始就热爱钢琴的林甘迪，在就读了音乐专业之后，发现音乐不仅仅局限于声乐和钢琴。这种新的发现让她醒悟原来世界是很多元的，这就促成了她希望突破局限从而开拓视野，展望大千世界的决心。

每做一件事之前，人们都需要给自己找到一个促成出发的理由。林甘迪也不例外，她说道：“我抱着拓宽自己视野的心态参加了这次考研。”社会是多元的，而生活的方式也可以是多姿多彩的。“我在台湾学习过程中，抓住了更多的实践和表演机会。在往后的日子里，我也会努力去接触新事物，学习新专业，与此同时也会坚持自己原本对钢琴的兴趣，不断丰富自己，积极投入到社会实践当中。”

以校训“学而知不足”为座右铭“在参加研究生面试过程中，澳门城市大学几位面试官的提问对我触动很大，我发现了自己还有许多不足的方面。”人生就是一个不断发现不足然后弥补不足的过程，记者从林甘迪身上看到了一种不断积极进取的生活态度。她把城院校训“学而知不足”当作自己的座右铭，同时坚持着“走自己的路，让别人说去吧”的洒脱个性。“在城市学院的大学生活是丰富多彩的，令人奋发向上，相信会使我终身难忘。”林甘迪眼里饱含的是无限的感激，“特别感谢城市学院接纳了我，给予我宝贵的机会到台湾学习，更重要的是感谢学校保荐我到澳门城市大学就读。”此外，“父母给我的支持和学院老师给我的帮助，是我成功的关键。”

对于即将接触的葡语专业，林甘迪表示十分期待，一件件新的事物构成了多元的生活，丰富多彩的生活又促成了阅历饱满的自己。

追求梦想的道路上，即使遭遇困难，依然甘之如饴；面对世间太多诱惑，弗求弗迪。她就是林甘迪。
