# 我院举办防灾减灾安全知识讲座

5月12日，东莞理工学院城市学院防灾减灾安全知识讲座暨寮步公安分局“以案说防”（电信网络诈骗）宣传讲座，在综合馆顺利举行。

讲座特邀泉塘派出所副所长张南星、东莞市地震局工程师李志能，分别为同学们讲解预防电信网络诈骗的知识和地震逃生的方法。

张南星副所长通过多个发生在同学们身边的电信网络诈骗案例，列举出电信网络诈骗的种种骗术，提醒同学们加强安全防范意识，提防校园电信诈骗。

李志能工程师通过PPT、视频等生动地为同学们展示了地震的危害，着重介绍了在不同情况下面对地震的逃生方法，并和校方组织同学们进行地震逃生安全演练，丰富了同学们防灾减灾的相关知识和逃生技能。

寮步镇泉塘派出所有关领导和我院院领导王卫平、周庆等出席了讲座。
