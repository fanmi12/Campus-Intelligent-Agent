# 计算机与信息科学系教学实践基地挂牌

3月18日，东莞理工学院城市学院计算机与信息科学系主任牛熠博士，书记廉玉忠教授、高职部副主任谢俊高级工程师一行，来到顺普科技（深圳）有限公司，举行院教学实践基地挂牌仪式。

仪式之前，牛熠主任一行与公司负责人和实习学生进行了座谈，他首先感谢公司对我系教学实践工作的支持，并鼓励学生珍惜实习机会，踏踏实实地做事，认认真真地学，从一点一滴做起，不断总结经验，提高动手能力。

随后，校企双方举行了挂牌仪式，并合影留念。挂牌仪式之后，该系师生参观了公司的研发中心和生产车间。
