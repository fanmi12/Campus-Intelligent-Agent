# 我校教师应邀走进腾讯微信总部作案例分享

11月19日，我校图书信息中心主任陈显龙、网络部部长伦志辉，应邀前往位于广州T.I.T创意产业园的腾讯微信总部，参加首届“企业微信助力高校搭建师生服务平台”华南高校优秀案例分享会。陈显龙主任作为嘉宾并作优秀高校案例分享报告。

会上，陈显龙主任就企业微信如何与高校的实际场景相结合、企业微信“虚拟校园卡”、企业微信与OA办公系统集成、企业微信通讯录的应用扩展、个性化消息推送、企业微信服务线上教学、疫情期间企业微信线上健康填报和入校审批、来访人员管理、校园通行码、图书馆自助借还等场景进行了技术分享，得到了与会人员的一致好评。

会上，大家就相关经验进行交流探讨。微信相关负责人表示将加大对我校案例的宣传，增强对我校资源投入和技术支持。

疫情防控期间，我校积极利用企业微信开发线上健康填报、入校审批、校园通行码等辅助功能，提供了较为准确、全面的数据支撑， 简化审批流程，提高了办事效率。

据悉，本次分享会共有来自华南地区的深圳大学、暨南大学、湖南大学等51所高校参加。
