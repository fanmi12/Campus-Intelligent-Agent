# 暑假期间我院学子斩获多项全国大奖

新学期到来之际，我院喜报频传。暑假期间，我院学子在2017年中国包装创意设计大赛、“神雾杯”第十届全国大学生节能减排社会实践与科技竞赛决赛等多个大赛获得多项大奖。

8月份在江苏省宿迁市举行的2017年中国包装创意设计大赛上，我院机电工程系印刷工程专业学生共获得17个奖项，杨玉春获得指导老师优秀奖。据悉，大赛是中国包装界权威赛事，是当前中国包装行业、包装教育界、视觉平面设计教育界备受瞩目的专业竞赛活动，也是教育部、国家职业教育专业教学资源库建设的重要组成部分，参赛对象包括各包装工程院校、美术设计院校、包装企业及日、韩、英、法、德等国的部分院校师生，本届大赛共收到5320件作品参赛。我院蔡明朗同学的《餐具系列包装的结构设计》获得本科学生组包装结构类二等奖；谢佳伟同学的《新春礼盒套装》、薛家明同学的《少女香水系列包装》、莫炯贤同学的《海陆空幼儿食品礼盒》、黄桂海同学的《外带食品便利性包装设计》、郑紫彤同学的《RIO鸡尾酒个性化包装》、叶勇锋同学的《怡宝水个性化包装设计》获得本科学生组装潢设计类三等奖；潘少玄同学的《橘色影视集团VI设计》、杨梓嘉同学的《“粤春江”酒楼VI系统设计》、黄晓曼同学的《“创意家居”有限公司VI设计》、黄琪同学的《音乐，让生活多点色彩》获得本科学生组平面设计类三等奖；王慧妍、刘秋文、黄旭鑫、刘丽敏、符凯程、周晓敏同学获得优秀奖。

8月11日在由教育部高等教育司主办、教育部高等学校能源动力类专业教学指导委员会和华北电力大学共同承办的“神雾杯”第十届全国大学生节能减排社会实践与科技竞赛决赛上，我院城环系参赛作品《一种组合式垂直流人工湿地装置的研制及其对生活污水处理效果研究》（学生：黄祈栋、黄宇宏、陈康胜、廖雨微、何春婷，指导老师：方伟成）荣获二等奖。据悉，全国大学生节能减排社会实践与科技竞赛是由教育部高等教育司主办、唯一由高等教育司办公室主抓的全国大学生学科竞赛。本届大赛吸引了清华大学、浙江大学、西安交通大学、上海交通大学等在内的343所高校参加，共计3190件有效作品，参赛人数超过16000人，参与高校数和作品申报数量均创历史新高。
