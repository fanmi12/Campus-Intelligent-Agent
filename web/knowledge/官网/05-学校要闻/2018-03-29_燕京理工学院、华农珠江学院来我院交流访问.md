# 燕京理工学院、华农珠江学院来我院交流访问

3月14日上午，燕京理工学院基建处处长马小栋，华南农业大学珠江学院办公室主任李绍球，中国中元国际工程有限公司教育建筑研究中心主任、总建筑师李东梅等一行5人莅临我院交流访问。刘玉侠副院长和后勤保卫处处长王锦锋、副处长袁秀美等领导热情接待了客人。

马小栋处长

一行参观了我院校园和校史馆，重点考察了学院的建筑设计与规划，深入学生公寓和食堂了解学生公寓、餐饮服务等服务与管理。

座谈会上，宾主双方就校园规划建设、学生公寓管理、食堂管理服务等方面的建设经验，进行了深入交流探讨。

马小栋处长

对我院统一的、富有岭南文化的建筑特色给予了高度称赞，对我院的学生公寓餐饮管理服务的理念和水平给予肯定。

广东鸿发教育文化集团有限公司副总经理夏为民出席了座谈会。
