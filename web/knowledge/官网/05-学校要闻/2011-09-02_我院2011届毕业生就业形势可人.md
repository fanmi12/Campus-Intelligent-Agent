# 我院2011届毕业生就业形势可人

广东省就业指导中心最新数据显示，截止到9月1日，城市学院2011届毕业生初次就业率达到93.89%，名列全省同类高校的前列。

从各系部的情况来看，就业率均达到90%以上，其中城市与环境科学系、管理系、艺术系、政法系达到95%以上。从各专业情况看，其中工商管理、印刷、计算机辅助设计与制造、商务英语、表演等专业的就业率达到了100%。

数据显示，我院专科生就业率为94.76%，本科生就业率为92.87%。毕业生就业渠道广泛，其中绝大多数毕业生在个体、私营、民营和外资企业工作，也有小部分在机关、部队、政法系统、事业单位、国有企业就职，或继续求学深造和出国留学。
