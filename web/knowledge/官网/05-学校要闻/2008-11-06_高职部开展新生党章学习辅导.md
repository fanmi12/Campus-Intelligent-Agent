# 高职部开展新生党章学习辅导

11月4日高职部在学术报告厅举行新生党章学习小组开班仪式。系总支书记黄研晖等老师出席了开班仪式。

黄研晖书记宣读了学院党委关于党建工作的有关文件，解答了为什么入党要要写入党申请书、如何向党支部写思想汇报、发展党员的工作程序等问题，介绍了入党誓词的变迁情况。

参加学习的同学表示，黄书记的辅导，使我们从中学到了许多知识，对当有了更深刻的认识和了解，更使我们从中坚定了入党的决心和信心。
