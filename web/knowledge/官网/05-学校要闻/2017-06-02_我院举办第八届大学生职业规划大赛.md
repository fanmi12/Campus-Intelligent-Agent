# 我院举办第八届大学生职业规划大赛

6月1日下午，我院第八届大学生职业规划大赛决赛在学术报告厅隆重举行。活动邀请东莞理工学院学生处路晓军处长、广东医科大学就业与创业教研室负责人林丽霞、广东科技学院就业指导中心陈婷副主任、东莞市弘智经营管理研究院院长尹利平，智通人才连锁集团人力资源部高级经理于海霞和我院学生处副处长

罗文芳、招生就业处江小卫主任担任评委。副院长黄兢、周庆出席了活动。

经过3个月的初赛及复赛的层层选拔，共有6名来自不同院系的选手晋级本次决赛。他们带着对未来的期盼，放飞梦想，畅谈未来，向大家展示了自己对于职业生涯的畅想——有的想成为英语翻译家、有的想成为市场总监、有的想成为总编辑。

经过激烈角逐，金贸系张娴同学凭借着对市场总监职业的精彩分析及扎实的专业知识脱颖而出，荣获冠军。计信系陈嘉慧同学、管理系的王香婷同学分别荣获二等奖；外语系李睿仪同学、政法系李灏同学、财经系杨佑杉同学获得三等奖。金融与贸易系张庆文老师荣获最佳指导教师奖，朱彩媚同学、袁子淇同学荣获大赛最具潜力奖。

据了解，本届大赛面向我院在校学生，旨在提高学生职业规划的意识，增强学生职业规划的能力。
