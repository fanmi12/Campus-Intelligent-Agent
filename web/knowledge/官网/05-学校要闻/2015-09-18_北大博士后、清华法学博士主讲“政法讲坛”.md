# 北大博士后、清华法学博士主讲“政法讲坛”

为不断加强学生内涵建设，促进应用型人才培养改革，政法系力邀政法领域知名学者，优秀业师，为同学们奉上精彩的知识盛宴。

开学至今，政法系已成功举办了三期“政法讲坛”，他们分别邀请了来自吉林大学法学院副教授淳于闻博士，清华大学法学博士、诉讼法研究中心副研究员戴鹏老师，中国人民大学博士、北京大学博士后杜洪波副教授前来主讲。三位嘉宾分别就“2015年司法考试之面对”、“ 《刑事诉讼法》修订重点内容剖析”、“ 《刑法修正案（九）》主要内容之解读”等各种热点问题作了理论联系实践的详细、独到讲解、剖析，对听众所提出的相关实务问题作了详尽、令人信服的解读。

参加讲座的同学们深受启发，纷纷表示司法考试在即，一定要努力调整自己，心态决定命运，轻松上阵，争取一战取胜。
