# 我院获批首个省级骨干辅导员工作室

3月13日-15日，教育部高校辅导员培训和研修基地（华南师范大学）举办“广东高校骨干辅导员工作室建设研讨会”。会上，我院艺术系党总支副书记张宏渝主持的“文化育人——校园文化活动指导工作室”获批成为广东省骨干辅导员工作室建设对象（共22个）并授牌，团委副书记陈浩华主持的“大学生思想政治教育工作室”获批成为培育对象（共28个）。

这次会议旨在贯彻落实习近平总书记在全国高校思想政治工作会议上的讲话精神，提升高校思想政治工作队伍素养，开拓新时期高校思想政治工作新局面。

15日上午，会议举行了授牌仪式，张宏渝老师作为建设对象上台接受牌匾。这是我院首个省级骨干辅导员工作室，也是省教育厅对我院辅导员工作的肯定和鼓励。
