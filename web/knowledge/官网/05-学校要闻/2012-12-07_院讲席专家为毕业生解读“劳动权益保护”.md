# 院讲席专家为毕业生解读“劳动权益保护”

12月6日，莞城校区学术报告厅座无虚席，我院大学生劳动权益保护专题讲座在这里举行，政法系300多名应届毕业生参加了这次讲座。

本次讲座由我院讲席专家王雄文副教授主讲。讲座内容分为大学生实习有没有权利获得工资，大学生实习期间受伤该谁担责，大学生与“零工资”就业，大学生求职中应注意的问题四个部分。王雄文副教授还就同学们提出的问题一一做了解答。
