# 我院认真传达学习习近平总书记在学校思想政治理论课教师座谈会上的重要讲话精神

3月18日，习近平

总书记在京主持召开学校思想政治理论课教师座谈会并发表重要讲话。21日下午，我院召开研讨会，认真学习习近平总书记重要讲话精神。院长王卫平、党委书记章德胜和有关部门领导及全体思政部教师参加了会议。思政部副主任石志民主持研讨会。

与会人员观看了习近平总书记主持召开学校思想政治理论课教师座谈会的新闻视频。思政部党总支书记史雍真进行了解读，从“党中央历来重视思政课建设的部署、习近平总书记重要讲话精神要点、对开好思政课的启示、如何贯彻与落实”等方面进行了阐述。

刘国建、何鹏举、石瑞丽、唐征玲、曾检成等思政课老师结合学院及工作实际，交流了学习习近平总书记重要讲话精神的心得体会。大家表示，学习了习近平总书记重要讲话精神后，备受鼓舞，倍感责任重大，将以习近平总书记重要讲话精神为指导，增强“四个意识”、坚定“四个自信”、做到“两个维护”，努力做一名合格的思政课教师。

章德胜书记表示，习近平总书记的重要讲话体现了总书记对思政课的重视，对广大思政教师的关怀。他指出，思想政治理论课是落实“立德树人”根本任务、培养德智体美劳全面发展的社会主义建设者和接班人的关键课程。学院全体思政教师要增强责任感和使命感，在教学过程中，多开展集体备课，统一认识，形成统一要求，达成共识，上好思政课。学院党委将按照习近平总书记提出的“八个统一”，全力支持思政部的工作，进一步推动思想政治理论课改革与创新。

王卫平院长表示，习近平总书记的重要讲话，立意高远、高屋建瓴、催人奋进，学院将扎扎实实推进思想政治理论课建设，研究和推进成立“马克思主义学院”，不断取得思政课教学改革和创新的新成果。
