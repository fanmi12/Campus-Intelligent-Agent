# 校运会竞赛项目变身“期货买卖”教学

运动会不仅是体育活动，还可以是金融投资活动！

没错！在上周五结束的校运会上，金融与贸易系老师不仅踊跃参与体育赛事，还将金融投资理念融入到运动会之中，推出了可以买卖的校运会期货合约，引起了师生的极大兴趣！

为了宣传校运会，鼓励师生积极参加运动会，金贸系老师将部分教师的参赛项目作为标的，设计为“期货合约”，推出了“杨亚娟100米赛名次期货合约”、“彭衡200米赛名次期货合约”、“任炼足球踢远名次期货合约”、“任炼足球踢远距离期货合约”等期货产品。

据介绍，在各项比赛结束之前，相应的期货合约都可以进行买卖交易。如果预测该老师会取得好成绩，可以建“多头”；反之，可以卖空该合约。在该运动项目成绩公布后，可以根据实际成绩和合约价格的价差进行结算。

金贸系教师将体育活动作为金融投资活动，完全模拟了实际期货合约的设计与交易过程，将抽象的期货合约现实化、生活化，有助于师生了解、学习和体验期货合约的魅力。

受此启发，金贸系不少班级也将班级参赛同学作为标的，设计为期货合约，尝试将体育运动和专业知识进行有机融合。

金贸系还着手计划在明年运动会召开开始之前，在学生中开展体育金融衍生品设计与模拟交易竞赛，不仅要推出体育期货合约，还要推出更为复杂的体育期权合约等金融衍生品。
