# 学院召开评建工作领导小组会议推选“评建”先进集体与先进个人

3月29日，学院在315会议室召开评建工作领导小组全体会议，推选“迎评”工作先进集体与先进个人表彰名单。

人事处处长夏勇在会上通报了各单位“双先”名单推荐情况。

会议认为，城市学院及其申报的17个本科专业双双获得学士学位授予权，这是一件非常了不起的事情，是全院教职工有效工作的结果，是大家共同的光荣。在“迎评”过程中，涌现出了一批先进单位和个人。

会议要求，全体教职工要继续发扬“迎评”工作中“务真求实、争创一流”的城院精神，以获得“学士学位授予权”为新起点，咬定“建设一流独立学院”目标不放松，再接再厉，促进学院各项工作再上新台阶。
