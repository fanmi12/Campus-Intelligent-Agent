# 【众志成城 抗击疫情】相约线上课堂——优秀教师经验谈之二十

我校坚决贯彻落实教育部、省教育厅、省委教育工委的重要部署，从3月起全面开展线上教学活动，全体任课教师坚守岗位、锐意创新、勇挑重担，全力做好线上教学工作，展现了良好的师德师风。前十九期我们精选刊发了一批优秀教师线上教学经验谈后，在全体教师中产生了良好的反响，受到广大师生的欢迎和点赞。今天刊发第二十期，推介计算机与信息学院李洪超、文学与传媒学院吴欢、创新创业学院李伟三位老师的线上教学心得体会，供大家分享。

计算机与信息学院李洪超老师线上教学心得体会：

（1）真正体验了线上教学工作的全过程，了解和掌握了一些线上教学方法和手段。

（2）通过线下课前预习、线上重点和难点的讲解以及课后知识点和习题讨论等多手段的运用，提高了学生学习效果。

（3）分析了线上教学和课堂教学各自的优缺点，促进了本人将线上教学的优势应用到今后的课堂教学中。

（4）线上教学工作中，最大的问题就是实验无法在网上进行，为了解决这问题，基于网络的虚拟仿真实验的开发工作就显得十分重要。

教师寄语：心系学生、情系教育。

文学与传媒学院吴欢老师线上教学心得体会：

1.整合慕课线上优质课程，提前进行课前引导。结合教材中的知识点，提前与学生沟通，明确任务和要求，做好学生的引导工作。

2.借助在线平台，实现教学角色翻转。在教学过程中，使用企业微信进行答疑解惑，同时采用提问的方式了解学生掌握知识的进展情况。

教师寄语：奋斗的人生最精彩。

创新创业学院李伟老师线上教学心得体会：通过挖掘企业微信的功能，线上直播教学极大地增加了大创课堂的互动，学生可以直接发弹幕进行提问，老师可以实时解答。课堂练习的时候，学生直接在线填表；课堂讨论的时候，学生可以直接连麦，所有人都能很清晰地听到，传统的大课堂，教师还要下去递话筒。教师可以把补充的案例或者其他知识点发链接到微信群，拓宽了学生的知识面。

教师寄语：直播让我们沟通零距离。
