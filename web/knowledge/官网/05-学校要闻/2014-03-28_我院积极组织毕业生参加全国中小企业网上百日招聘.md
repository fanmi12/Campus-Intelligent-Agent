# 我院积极组织毕业生参加全国中小企业网上百日招聘

为促进2014年高校毕业生的就业工作，近日，教育部、工业和信息化部联合举办2014年全国中小企业网上百日招聘高校毕业生活动，并向全国各高校发出通知。

据悉，该活动由工业和信息化部、教育部主办，中国中小企业信息网（www.sme.gov.cn）、全国大学生就业公共服务立体化平台（www.ncss.org.cn）承办。活动时间为2014年3月10日至6月17日。网上招聘主要是让高校毕业生了解中小企业，提高毕业生与企业对接成功率。活动期间，各高校毕业生都可从相关网站免费浏览查询和在线联系中小企业。

学院党委书记王卫平、副书记章德胜副书记就该活动作出批示，希望应届毕业生抓住机会，积极参加网上招聘活动。

从学院就业中心副主任林蓉老师处了解得知，为响应号召，针对2014届毕业生，我院聘请资深专家围绕“就业技巧”、“职业规划”为题先后开展了7场毕业生就业指导讲座。2013年11月、12月分别在新老校区举办大型招聘会，前来参与的企业超过600家，共1.2万个岗位供学生选择。就业中心还通过发布网上信息和日常相关招聘信息对系部、相关专业联系单位。据统计，去年从网上发布信息共招聘超过500家企业，共提供超过1000个岗位，从日常发布的相关信息每周至少招聘6至10个单位。近几年我院毕业生就业率达99%，学生就业前景好。
