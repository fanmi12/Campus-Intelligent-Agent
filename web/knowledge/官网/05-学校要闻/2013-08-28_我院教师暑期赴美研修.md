# 我院教师暑期赴美研修

暑假期间，党委书记、研究员朱志德一行10人到美国北爱荷华大学参加了15天的“如何成为卓越的大学教师”的培训活动。

本次研修活动主要是由Susan博士、Deedee博士两位老师组织授课和互动讨论。我院赴美人员先后听取了两位博士关于美国教育体制、美国高等教育和北爱高等教育概况、美国互动教学法、教学大纲的建设、教案的设计、教学评估和教学测评工具、北爱荷华大学教学所拥有的科技资源和对该科技资源的运用等方面的情况介绍，随堂听取了Shahina博士给学生上的关于微观经济学原理、Catherine 博士给学生上的关于妇女和性别研究的课程。培训之余，他们还与来自国内的在北爱荷华大学工作的高平副教授、何瑞博士后和董威志老师进行了座谈。应邀到当地居民家做客，对高平副教授家进行了探访。龙卫洋等老师拜会了美国芝加哥华人商会和芝加哥桃源保险集团有关人员，了解美国的投资与保险等。

研修人员了解到，美国高等教育有六个方面的特点：一是美国高等教育体系发达，具有高度市场经济化的特性。二是美国高等教育充分尊重高校的自治，很少对高校的治理进行干预，对私立大学干预更是甚少。三是美国高等教育非常尊重学生，将学生视为教育消费者，充分保护其权利，真正做到了以学生为本，所有制度设计、规则制定、课程安排、教学服务都围绕学生的学习权利而进行。四是成熟的师资队伍建设是美国大学不断发展的动力。五是美国的教学理念和教学方法比较先进，善于运用各种教学资源，激励学生主动、批判性学习。

美国的专家教授认为，一个卓越的大学老师，必须做到以下几点：必须非常了解其所教的科目，并知道如何简化和解释该科目的复杂理论；必须知道如何进行教学准备；必须对学生有更多的期望，而不是只关注课程学习成绩；能充分把握运用课堂教学的多种技巧，必须知道知识是构建的而不是灌输的，并能创造出一种自然的批判性的学习环境让学生主动学习；相信学生有能力学习并平等地对待每位学生；懂得从学生本身而不是从学科本身出发进行教学，并通过多种方式对学生进行客观评估。

我院研修人员认为，赴美研修学习开阔了视野，增长了见识，学习了解了美国先进的教学理念及教学方法。他们表示，要根据自己的专业特点，总结吸收美国同行们好的做法与经验，提高教育教学水平。
