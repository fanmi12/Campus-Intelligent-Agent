# 印刷实验室建成投入使用

印刷实验室经过实验中心与机电系印刷教研室近两个月的共同建设，已于近日投入教学使用。

据了解，实验室面积170平方米，分为印刷技术、颜色控制、材料检测三个模块。实验对象主要是印刷技术、印刷工程等专业的学生。现配有晒版机、冲版机、胶印机、丝印机、移印机、密度计、印版测量仪、分光光度仪、纸张平滑度仪、耐折度仪、光泽度仪、油墨粘度仪、色牢度摩擦仪等仪器设备，可开设PS制版、胶印机操作、丝网制版、丝印机操作、色彩管理、印刷品质量检测、纸张印刷适性检测、油墨印刷适性检测等实验项目。

实验中心通过精心谋划和多方协调，调整了部分实验室，成功解决了实验室用房紧张的问题。学院招标与采购部门积极督促供货进度，保证了实验室建设的顺利进行。学院发展与联络办公室主任杨光强同志还为实验室捐赠了两台价值十多万元的印刷机。

实验室负责人表示，印刷实验室的投入使用，可满足实验课的要求，让学生能接触到先进的专业设备。
