# 学院召开财务制度及费用报销培训会议

6月8日下午，学院财务制度及费用报销培训会议在行政楼212室召开。各行政单位负责财务报销人员、教学（辅）单位行政秘书、科（教）研负责人参加了会议。

财务处会计核算科副科长曹闺秀就学院财务相关制度、报销标准和流程、票据使用及填写要求、相关审批权限的规定以及财务处人员分工及职责等方面，作了详细的介绍。采购中心负责人谢彦也介绍了学院采购物资相关规定和流程。

财务处处长余竹根针对各单位日常报销工作应该注意事项作出补充说明，并解答了与会人员的提问。
