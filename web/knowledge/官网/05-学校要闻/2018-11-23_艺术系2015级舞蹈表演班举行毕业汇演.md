# 艺术系2015级舞蹈表演班举行毕业汇演

11月22日晚，以“今心为念，一生不变”为主题的2019届舞蹈表演班毕业汇演于我院综合楼华丽呈现。东莞市舞蹈家协会副主席姚佩禅，学院党委副书记章德胜和兄弟院校嘉宾、各院系师生观看了演出。

毕业汇演以《启程》拉开了序幕，铿锵与柔和交替，获得了观众的喝彩。《凤还巢情缘》融合了中国京剧之韵的，展示了中国文化的传统底蕴。由董玉坤、曹旭演绎的《汗沁贝勒格》展示蒙古民族女性高贵热情气质，也充分展示我院好客之情。女生演绎的《六月茉莉》展示了稳重的民族风情，男生演绎的《翻身农奴把歌唱》展示了藏族的草原气息。陈华慧、周淑娟、罗曦三人演绎了羌族舞蹈《心中的花儿纳吉》，婀娜优美的舞姿令观众陶醉不已。

舞蹈《彩虹桥》演绎了台湾一个信仰彩虹的土著部落奋力抗击日本帝国主义的故事，高尚的爱国情怀把演出再次推向了高潮……

晚会，在2015级舞蹈表演班全体师生共同演绎的舞蹈《生生不息》中划上了完美的句号,而“今心为念，一生不”变则是全班师生永恒的省略号。
