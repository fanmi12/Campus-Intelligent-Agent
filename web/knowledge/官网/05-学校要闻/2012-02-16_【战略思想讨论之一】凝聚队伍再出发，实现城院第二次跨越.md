# 【战略思想讨论之一】凝聚队伍再出发，实现城院第二次跨越

2011年11月20日至22日，这是一个可以载入东莞理工学院城市学院史册的日子。在这个重要的历史时刻，我院一万多名师生员工接受了广东省人民政府学位委员会办公室组织的“申请新增学士学位授予单位和专业实地评审”。2012年2月10日，省学位委员会做出决定，城市学院享有独立颁发学位权，17个本科专业全部获得学士学位授予权。

消息传来，全院师生员工人心振奋，欢欣鼓舞。它标志着我院已经圆满地完成了第一个历史阶段的任务，胜利进入新的发展阶段。

在这个新的发展阶段，我院面临着许多新的机遇与挑战。东莞市第十三次党代会提出了“高水平崛起，再领跑三十年，建设幸福东莞”的宏伟目标和战略要求；省教育厅领导要求我院在第二阶段中“要有一个较高的定位”，力争成为我省新建本科院校的“标杆”； 去年暑假中层干部学习班上，董事长麦照容提出了“创一流大学，办百年名校”的宏伟目标。作为办学者，我们如何将这些目标与要求变成客观事实呢？如何实现城市学院的第二次跨越？这是值得全院师生员工深思的问题。

安少华院长在2011年12月29日召开的教代会上对我院2012年的工作提出了明确要求，他饱含深情地发出了一个“凝聚队伍再出发”口号，代表了全校师生员工的共同心愿。笔者认为，我院在新的历史发展阶段，要凝聚队伍再出发，实现城市学院的第二次跨越，当前应着重解决好以下三个问题：第一，要完善现代大学制度

完善中国特色现代大学制度是国家《教育规划纲要》提出的明确要求，也是省学位办专家给我院提出的第一条建议。我院处在改革开放的前沿——东莞，面临着高校之间的激烈竞争。常识告诉我们，高校之间的竞争在某种程度上是制度的竞争。世界上很多一流大学之所以长盛不衰，就在于其有健全的、长效的制度作为保障。要把我院办成“百年名校”，必须建立现代大学制度，其中有两个必须重点解决的问题：一是依法办学，推进管办分离。要建立科学的大学章程，充分尊重办学自主权，真心依靠懂教育的人办学。这是现代大学的一个核心问题。

二是民主管理。独立人格，自由精神，乃是高等学校的灵魂。山东大学校长徐显明认为：“大学是自由者的乐园”。2007年5月14日，温家宝总理在同济大学演讲时说：“一所好的大学，不在高楼大厦，不在权威的讲坛，也不在那些张扬的东西，而在自己独特的灵魂。这就是独立思考，自由的表达。要通过讨论与交流，师生共进，教学相长，形成一种独特的学术氛围，并不断发扬，影响越来越多的人。这样，真正的大学就形成了，就会有一批有智慧的杰出人才出现，整个国家就有希望”。

回顾我院八年的办学历史，值得总结和肯定的经验很多，其中最重要的一条就是切实贯彻以人为本的思想，民主管理，追求卓越，构建和谐的精神环境。这次实地评审时专家组对我院师生的精神面貌给予了特别肯定，原因就在于此。

第二，要树立正确的办学指导思想

办学指导思想是一所学校的灵魂和顶层设计，对学校建设和发展具有特别重要的意义。在历次的评估中办学指导思想都占有很高的比分。实事求是地讲，在实际工作中，这是一个容易被人们忽略的问题，有的人甚至认为不过是一些不着边际的空话、套话和大话。这种看法是办学之大忌。从我院的实际出发，我们必须广泛开展教育思想大讨论，并切实解决好以下两个带根本性的问题：一是究竟把城市学院办成什么样的学校？如何办好这种学校？董事会提出了“创一流大学”的目标，但究竟什么叫“一流”？其具体的标准和要求（硬件与软件尤其是软件建设）是什么？ 应采取哪些措施达到这些要求？如何评估是否达到了这些要求？……这一切都必须有可操作的具体方案并付诸实施，理想才能变成现实！

二是要完善应用型本科人才培养模式。省学位办专家组在对我院不到900字的综合评语中，三处提到“培养应用型人才”；省教育厅领导胡振敏同志在我院不到15分钟的讲话中，也七次提到“培养应用型人才”问题。他在解释我院要有“较高的定位”时指出:“主要还是应用型人才培养。这次评估指标体系的设计，包括今后的教学工作评估，教育部将整个新办院校和独立学院基本上是作为应用型人才这个大类来考虑的……”他明确要求我院要“从应用型人才培养的角度，更好地为地方经济社会服务，特别是为东莞服务”。

我认为上述要求是正确的。从我院的实际情况看，完善应用型人才培养模式有一系列亟待明确和完善的问题必须予以解决，这些问题主要有：各专业人才培养目标与规格究竟是什么？它与重点大学和高职高专的同专业人才在知识结构、能力结构等方面的区别是什么？我们的课程体系如何与培养目标相吻合？实践教学体系如何完善？考试如何改革？师资、设备如何保障有力？我们要形成自己的办学特色，并尽可能在某一方面占领制高点，上述问题必须有比较明确的理论回答和实施方案。

第三，凝集人心，进一步优化师资结构和管理团队

这次实地评审中，省学位办专家组对我院重视师资队伍建设给予了充分肯定，同时也要求我院，要进一步优化师资结构，加强人才引进，重视中青年教师在学术上的发展，鼓励教师参加教学改革研究和科学研究，提高学术水平。

师资队伍对于办好大学的重要性是不言而喻的。

我国著名教育家杨福家在谈到建立现代大学制度时，认为现代大学除要有大师外，还应包括优秀的教师、学生和管理人员。

我院办学八年 ，在队伍建设方面创造了许多宝贵经验，这是一笔十分宝贵的财富，今后必须进一步完善、发扬光大。

我们相信，只要全校师生员工同心协力，一定能再铸辉煌，实现城市学院的第二次跨越！
