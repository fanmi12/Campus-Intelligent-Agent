# 省专家组本月22日莅校开展教学工作状态评估

我院教学工作状态评建工作已进入倒计时。记者从学院预评估会议上获悉，省教育厅专家组将于5月22日莅校对我院教学工作状态展开实地评估。

5月14日，学院在212会议室召开教学工作状态评估预评估会议。会议由党委书记朱志德主持，院长杨敏林教授做《院长工作报告》。院领导、系部主任、中层干部正职负责人参加了会议。与会人员对学院向省专家组汇报的材料进行了讨论。

会议要求，院内各单位要在学校评建工作领导小组的领导下，认真细致地做好迎评准备工作，确保专家进校考察评估工作顺利进行，圆满完成学院确定的评建工作目标和任务。
