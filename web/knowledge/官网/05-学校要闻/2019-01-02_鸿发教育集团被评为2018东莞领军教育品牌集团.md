# 鸿发教育集团被评为2018东莞领军教育品牌集团

2018年12月29日，东莞教育品牌盛典在东莞广播电视台一楼演播厅举行。广东鸿发教育文化集团有限公司被评为“东莞领军教育品牌集团”、东莞鸿发出国留学公司被评为“2018东莞金牌语言培训品牌”、广东鸿发教育文化集团有限公司总经理陈超群被评为“2018东莞教育杰出贡献人物”。

东莞广播电视台副台长黎树根表示，作为东莞本土最权威、最主流的媒体平台，举办本届教育盛典，发布东莞教育行业优秀品牌，旨在提升优秀教育品牌的影响力，展示东莞教育行业魅力，讲好东莞教育故事。黎树根副台长寄语，要做有温度的教育，传播正能量，相信在业界的共同努力之下，东莞教育事业定将继续焕发蓬勃生机。据介绍，东莞教育品牌盛典，是由东莞广播电视台主办，东莞轨道交通电视传媒有限公司承办。活动开展以来，在东莞教育培训界引起了广泛关注，得到了众多学校以及培训单位的大力支持和参与。评选先后经过自愿报名、候选名单公布、候选单位展示、市民公开投票、评委实地考察、专家评审和不记名投票等阶段完成，并通过广播电视和东莞轨道传媒网络渠道宣传，最大程度地提高参评机构的传播力和影响力。

活动当天，广东鸿发教育集团副总经理韩春华、留学公司总经理吴旻作为代表上台领取了奖项。

在过去三年，广东鸿发教育集团走上了集团化企业之路，并积极致力于扩大办学规模，让更多的学子享受到优质的教育资源；吸引更多更强的教育骨干力量热爱教育事业、投身教育事业、献身教育事业，助力东莞打造最优质的教育环境。
