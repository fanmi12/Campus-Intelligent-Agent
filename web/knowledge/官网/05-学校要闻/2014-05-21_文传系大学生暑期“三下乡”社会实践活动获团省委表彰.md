# 文传系大学生暑期“三下乡”社会实践活动获团省委表彰

我院文学与传媒系“来宾市六峰小学支教”实践分队被团省委评为“2013年广东大中专学生志愿者暑期文化科技卫生‘三下乡’社会实践活动优秀团队”；指导老师江玲荣获“2013年广东大中专学生志愿者暑期文化科技卫生‘三下乡’社会实践活动先进个人”称号。

据悉，我院2014年暑期“三下乡”社会实践活动即将启动，目前已进入活动项目申报阶段，欢迎广大同学申报项目。团委希望全院师生向受表彰的优秀团队和先进个人学习，积极组建队伍参加暑期“三下乡”社会实践活动。
