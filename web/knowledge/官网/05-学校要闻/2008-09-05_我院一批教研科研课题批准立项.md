# 我院一批教研科研课题批准立项

我院教师在教学过程中，宽领域、多角度开展教研、科研活动，将研究成果有机地融入教学实践，促进教学质量的提高。

一批教研科研课题批准立项

近日，城市学院教学工作委员会召开会议，对全院教师申报的80个院级教研科研课题进行了评估、审核。会议批准“教育教学改革与研究”项目24项，其中招标项目1个，重点项目3个，一般项目21个；批准“创新人才培养计划”项目14个，其中重点项目6个，一般项目8个；批准教材编写项目5个。

九大项目获优秀

据悉，学院教学工作委员会对2007年立项的各类院级教研、科研课题进行了结题验收。验收结果表明，大部分课题观点新颖，论据扎实，解决问题的思路与对策符合我院教学工作实际，顺利通过了结题验收。其中，分别以安少华、朱志德、叶凯贞、孟颖、霍金根、危兆宾、殷素峰、肖文峰、孙成访为项目负责人完成的9个课题被评为优秀课题。
