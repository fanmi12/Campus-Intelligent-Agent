# 我校2019年运动会再创两项赛事新记录

经过为期两天的激烈角逐，11月15日下午， 2019年校运会圆满完成所有赛事顺利闭幕。王卫平、章德胜、高香林、黄兢、周庆、刘玉侠、林江龙等校领导和各单位负责人出席了闭幕式。

在今年校运会中，法学院陈博慧同学以8.34米的好成绩打破了学生组女子铅球比赛记录，金贸学院张璟铭同学以21.45米的优异成绩创下男子背抛实心球学校新记录，充分展示了我校不断拼搏进取的体育精神。

在学生组团体总成绩方面，商学院以364分摘得桂冠，金贸学院、城环学院分别获得第二、三名。在教工组团体总成绩方面，城环学院夺得冠军，文传学院、艺术学院分别获第二、三名。

此外，商学院、城环学院获得学生组“体育道德风尚奖”，城环学院、机关一获得教工组“体育道德风尚奖”。

在健美操大赛中，法学院获得一等奖，文传学院、金贸学院和商学院获得二等奖，城环学院、艺术学院、外国语学院、计信学院、智能制造学院和创意设计学院获得三等奖。最佳“网络人气奖”则由商学院摘得。
