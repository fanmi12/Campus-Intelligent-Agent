# 东莞市旅游局领导一行来我院参观访问

6月15日，东莞市旅游局局长梁少虾率该局有关领导和市旅游饭店协会会长梁永雄一行来我院参观访问，并就进一步加强人才培养合作与我院交换了意见。院长安少华、党委书记朱志德等领导热情接待了客人。

梁局长高度评价了市旅游局与我院合作的“中国东莞旅游网英文网站建设”和“中国东莞旅游网改版调查”两个项目，并希望能与我院在旅游、酒店管理等专业人才培养相关项目进行合作。
