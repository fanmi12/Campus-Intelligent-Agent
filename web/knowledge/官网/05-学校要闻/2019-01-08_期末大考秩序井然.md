# 期末大考秩序井然

1月7日，为期一周的期末考试拉开序幕。

上午，副院长高香林等领导来到考场，查看学生作答情况以及监考教师监考情况。他要求从严治考，确保考试公平公正，努力做到以考风促学风，使考风考纪建设更上一个新台阶。

本次期末考试从1月7日上午开始，到1月11日下午结束，其中共设七场千人大考考场，共计科目159门，考生人数54252人次，监考教师达2035人次。

据了解，各教学单位考前对师生进行了考风考纪教育，为学生营造一个公平、公正的考试环境，确保期末考试工作顺利进行。考试期间，各教学单位领导对本单位的考试进行了认真巡查，教室卫生状况良好，座位布局合理，监考人员恪尽职守，考场秩序井然。
