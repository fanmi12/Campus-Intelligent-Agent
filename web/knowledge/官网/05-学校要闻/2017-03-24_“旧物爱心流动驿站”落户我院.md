# “旧物爱心流动驿站”落户我院

3月21日下午，由东莞市城矿再生资源环保促进中心联合我院莞益青年服务社举办的国家级大学生创新创业项目——旧物爱心流动驿站，在学院学生宿舍区举行了揭牌仪式。

副院长刘玉侠，研究与发展规划处处长赵书山，后勤保卫处负责人袁秀美，学生处罗文芳副处长，东莞市城矿再生资源环保促进中心工作人员，以及莞益青年服务社全体成员参加了揭牌仪式。

莞益青年服务社学生代表宣读旧衣物回收环保倡议书，号召同学们捐赠旧衣物进行环保回收，并介绍了捐衣流程。

与会领导现场捐出了自己的旧衣物，以自己的行动来鼓励学生们对旧衣物进行回收利用。
