# 政法系举行专插本经验交流会

5月19日，政法系在6号阶梯教室召开专插本经验交流会。学生处副处长陈建新，政法系党总支副书记刘军与会，今年成功通过专插本考试的刘学能、梁建发和蔡俊英同学到场介绍经验。

会上，刘军老师强调了专升本对专科学生的重要性，他要求专科学生要明确方向，努力争取获得更高学历。陈建新副处长给同学们介绍了有关专插本的注意事项和当今社会人才需求的特点。三位已经通过今年专插本考试的同学，分别介绍了他们的学习方法和经验，并给同学们提供了专插本考试的学习网址（www.cb398.com、www.studg.com）。
