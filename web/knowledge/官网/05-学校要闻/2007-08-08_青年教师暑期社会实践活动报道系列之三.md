# 青年教师暑期社会实践活动报道系列之三

对于我院的首次教职工社会实践活动，学院领导非常重视。为了解教职工社会实践活动的开展情况，同时鼓励教职工在实践单位更好的发挥个人特长，近期我院组织慰问小组到广东电动工具有限公司等五个教师实践点看望慰问参加暑期实践的青年教师。

8月2日上午，学院党委副书记朱冰、学院督学林世俊、机电系主任助理谢明、人事处尹建明等一行五人前往石龙西湖工业区广东电动工具厂看望正在参加暑期社会实践的五名机电系青年教师。

慰问小组到达时，何伟、曾月鹏、方琳、陈小艳、陈庆等五名实践教师正在闷热的机房里全神贯注地做着实验，此次实践他们承接了一项电动机降噪的攻关课题，这段时间他们通过反复的试验，已经大致摸清了问题所在，他们正努力制定解决方案。

慰问小组与广东电动工具厂曹家美总经理等领导及实践教师进行了座谈，在座谈上，曹总经理对实践教师的认真负责的态度和刻苦专研的精神作了充分的肯定，认为教师到企业实践是一个双赢的创新模式，希望能和我院建立长期的合作关系。林世俊督学对厂方领导的支持表示感谢，鼓励实践教师尽快完成课题。何伟老师介绍了实践期间的工作情况，并表示了尽快完成课题的决心。

8月3日上午，学院党委书记朱志德、学术副院长程发良、人事处处长夏勇等一行六人前往石碣隆泰实业股份公司看望管理系参加暑期实践的六名青年教师。

吴春庚、王成军、贺冬怡等六名教师在隆泰实业股份公司的人力资源部、财务部等多个部门进行实践。

隆泰实业股份公司的郭总经理接待了慰问小组，郭总对我院组织教师参加社会实践的创举大加赞赏，对教师们在实践中表现表示肯定。

郭总还陪同慰问小组和实践教师参观隆泰实业股份公司的各条生产线。

8月3日下午，由安少华院长亲自带队，前往东莞市图书馆慰问在该馆开展实践活动的教职工。

在慰问过程中，安院长一行受到了东莞市图书馆李馆长等实践单位领导的热烈欢迎。在座谈会上，李馆长向安院长详细介绍了东莞市图书馆目前的建设情况及今后的发展思路，并对我院教职工在其单位的实践工作表示感谢。安院长则表示，作为知识传播的主要阵地，高等院校与地方公众图书馆有着许多可以合作的地方；同样都是以“服务东莞社会”为宗旨的东莞理工学院城市学院和东莞市图书馆完全可以因势利导，在图书借阅、数据信息资源、公益知识讲座等文化活动上进行深度合作，更大地扩展两个单位的知识传播范围。

在座谈会后，李馆长等领导还陪同安院长一行亲切慰问了坚守在实践岗位上的7位教职工，鼓励他们把握好机会，拓展社会交际面，增强实践能力。
