# 2017届广东省高校毕业生就业形势预测调研座谈会在我院召开

为及早准确研判广东省2017届高校毕业生就业形势，11月18日，2017届广东省高校毕业生就业形势预测调研座谈会在我院举行。

广东省高等学校毕业生就业指导中心刘卓副主任、刘琨科长，东莞理工学院城市学院王卫平院长、院党委章德胜副书记，东莞地区五所兄弟院校主管就业的领导，以及来自东莞龙星玩具有限公司、恒宇仪器有限公司和智通人才市场的企业代表参加了本次座谈会，并就高校毕业生就业创业新形式、新要求和求职意向、求职心态，以及大学生专业知识与能力的培养等方面，进行了分析、讨论与交流。

我院招生就业处孔增强处长主持会议。
