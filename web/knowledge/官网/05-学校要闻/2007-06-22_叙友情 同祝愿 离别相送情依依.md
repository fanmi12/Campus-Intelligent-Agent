# 叙友情　同祝愿　离别相送情依依

在这离别的六月，城市学院的又一批莘莘学子即将告别母校，踏上新的人生征程。6月21日晚，由机电工程系、计算机与信息科学系、社会科学系隆重举行“07届毕业生欢送晚会”。

东莞理工学院副院长城市学院院长安少华教授、学院党委副书记朱冰、院办主任王玉、学生处处长章德胜副教授、机电系主任黄健求教授、计信系主任牛熠博士、社科系主任何鹏举副教授莅临晚会现场与毕业生共叙友情。

晚会开始前，各系毕业生代表发表毕业感言。他们在发言中深情地讲述了自己在母校成长的经历和感悟，衷心地感谢老师的教诲和同学的帮助，表示在以后的日子里要脚踏实地，努力工作，用自己的努力证明自己无愧于学院的教育。各系主任也寄语毕业班同学们，希望同学们要全方位地学习，创造性地工作，充满激情地生活。

随后，晚会在歌曲《第一天》的旋律中拉开帷幕，以《感恩的心》手语表演结束，为在座的师生献上了一场丰盛的视听盛宴。
