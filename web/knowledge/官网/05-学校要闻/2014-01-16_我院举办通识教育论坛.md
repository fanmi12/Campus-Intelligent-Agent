# 我院举办通识教育论坛

1月15日，思政部在5A427会议室举行主题为“大力开展通识教育，努力培养创新型人才”的通识教育论坛，论坛邀请广东省思想政治理论课教学指导委员会委员、广东药学院吕志教授为主讲嘉宾。

陈丁堂督学、思政部主任何鹏举教授、教务处副处长赵书山副教授出席会议，与会的有正副教授范新成、黄宗理、刘凤仙、史琳、刘大为、石志民、刘珍、王静、彭先兵，思政部全体专兼职教师参会。

论坛由思政部主任何鹏举教授主持。

吕志教授以“香港中文大学通识教育的现状与思考”为题，结合自身在香港中文大学一个多月的进修考察和研究，向老师们介绍了香港中文大学通识教育的基本情况、开展通识教育的目的、通识教育课程设计、课程特色、校方的投入与承担等问题，并举大量的实例来加以说明。吕志教授认为，大力开展通识教育是高等教育在新的社会经济政治条件下的必然选择，是教育和学习信息化、数据化、网络化的必然要求。通识教育通过拓展学生的知识视野，培养他们处理新问题的能力；通过引导学生自主思考亘古弥新的话题，培养他们思辨质疑的知识贵族的精神；通过帮助学生对中华和世界优秀文化的考证和选择性吸收，培养他们形成高雅的情商和宽广的视域；通过教育学生对个人、家庭、社会等身边琐事作细致入微的探索，培养他们形成入世的能力和正确的为人处世的路径；通过协同学生对自然、科技、创造的深入了解，培养他们实事求是的科学精神和踏踏实实的工作作风。他介绍说，香港中文大学的通识教育主要分为书院通识和大学通识两个部分，重在与人文对话、与自然和科技对话，基本特点一是读经典二是重对话，取得了很好的效果。他还认为，通识教育与博雅教育、素质教育、思想政治教育的特点分别是宽、雅、俗、高，各有优劣，我们应该根据自己的教育教学和学生的情况进行综合和借鉴。

与会的教授和老师纷纷就教学和研究实际谈了自己的看法，并与吕志教授进行了探讨。

何鹏举教授作论坛总结。他认为，吕志教授的主题报告非常精彩，让老师们了解了香港高校进行通识教育的基本情况，也为我校今后开展通识教育带来启示。他尤其提出，老师们要向香港的同行学习，兢兢业业，应把教育教学工作当成自己的事业而不仅仅作为职业对待，克服职业倦怠，努力开阔视野，优化自身，切实提升素质，应对挑战。
