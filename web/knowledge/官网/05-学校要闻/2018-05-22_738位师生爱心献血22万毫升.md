# 738位师生爱心献血22万毫升

5月15日-17日，东莞市中心血站和我院志愿队在学校联合举办了无偿献血活动，共有738位师生成功献血，合计献血量达222500毫升。

连日来，师生们踊跃前来献血，志愿者们则有序地组织同学们填表、体检、等候抽血等服务，并备有八宝粥、葡萄糖水等为空腹献血者补充能量。

据了解，东莞市中心血站和我院合作举办爱心献血活动已有8年之久。在这3天的“无偿献血”活动中， 738位师生成功献血222500毫升。
