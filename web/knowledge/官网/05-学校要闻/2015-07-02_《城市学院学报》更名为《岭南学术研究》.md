# 《城市学院学报》更名为《岭南学术研究》

6月30日，我院主办的综合性学术理论出版物《城市学院学报》经广东省新闻出版广电局审批同意更名为《岭南学术研究》。

更名后的《岭南学术研究》主办单位、办刊宗旨不变，常设栏目有：马克思主义理论与现实、东莞发展研究、城市发展与社会工作研究、管理理念与管理创新、金贸理念与会计实务、信息理念与网络管理、机电工程与数字化应用、环境理念与生态工程、岭南文化研究、独立学院发展与教学研究、思想政治教育与学生管理研究等。
