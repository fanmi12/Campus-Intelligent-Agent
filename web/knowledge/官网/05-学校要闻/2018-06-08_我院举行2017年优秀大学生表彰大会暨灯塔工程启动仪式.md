# 我院举行2017年优秀大学生表彰大会暨灯塔工程启动仪式

6月7日下午，我院在综合馆举行2017年优秀大学生表彰大会暨灯塔工程启动仪式。学院助学单位、东莞联通城区分公司总经理吕喜峰，学院董事长代表陈超群，院领导王卫平、章德胜、高香林、刘玉侠、林江龙出席了大会。各院系和有关部门负责人、全体辅导员、优秀班集体班主任、学生代表参加了大会。

高香林副院长宣读了《关于表彰2016-2017学年先进班集体、校园十佳、优秀大学生、优秀学生干部及奖学金获得者的决定》。

大会对先进班集体、校园十佳、优秀大学生、优秀学生干部和校园奖学金、鸿发奖学金、国家励志奖学金、国家奖学金获得者进行了表彰。

商学院2015级人力资源管理2班高颖欣同学作为国家奖学金获得者代表在大会上发言。她回顾了大学三年学习、工作、生活的历程和取得的成绩。她表示，在遇到困难挫折时，自己没有选择逃避和放弃，而是不忘初心，通过自己的努力变得更加美好，成为了自己所期待的样子。

章德胜副书记宣读《关于表彰2017年度大学生年度人物的决定》。

大会还对学院2017年度大学生年度人物进行了隆重表彰，通过播放VCR对每位年度人物平凡而又动人的事迹进行了一一展示，号召同学们向榜样学习。

“广东省大学生年度人物入围奖”获得者、艺术系2014级舞蹈表演陈玉丹同学在大会发言。她介绍了自己大学四年的成长心路历程和在舞蹈艺术上取得的各项成绩，分享了自己的成长经验与方法，讲述了自己与炫舞团的成长故事。她表示，四年勤奋学习，付出了大量心血和汗水，领悟了“不忘初心，方得始终”的真谛。

2017年广东省辅导员年度人物、全国辅导员年度人物入围奖获得者、文传系党总支副书记苗琳老师，饱含深情地分享了自己五年来辅导员的人生芳华。她说，“有德之师育有爱之人，学生是星，教师是火，星火灿烂，才能照亮银河。今后将继续与阳光学工同行，因为我与你们一样的相信，只要坚守，终会葵花满园！”

王卫平院长在致词中，号召全体师生员工向受到表彰的师生学习，发挥榜样力量，促进学风建设。他指出，2017年我院团学工作改革取得明显进步，城院学子在各类学科竞赛中捷报频频，并不断取得新突破。习近平总书记明确指出“大学是立德树人、培养人才的地方，是青年人学习知识、增长才干、放飞梦想的地方”。王卫平院长希望大家要时刻铭记“创一流大学，办百年名校”的初心，牢记立德树人的使命，莫负好时光，不忘初心，砥砺前行。

与会院领导还共同启动了灯塔工程。灯塔工程是由团省委、省教育厅、省学联联合启动的，是广东青年大学生思想的引领行动，旨在帮助在校大学生寻找到自己心中的灯塔，同时也帮助自己成长为能照亮他人的灯塔，最后以实现先点亮自己，再照亮他人的过程。
