# 学院召开2012年度党员领导干部民主生活会

1月17日下午，学院召开了以“学习贯彻十八大精神，坚持以人为本、执政为民”为主题的党员领导干部民主生活会。学院领导杨敏林、朱志德、朱冰、张林、陈丁堂、章德胜及高香林在民主生活会上做主题发言。东莞理工学院校长杨晓西、组织部副部长汪璟及部分我院行政负责人、教授、党外代表出席了会议。

会上，学院党员领导班子紧紧围绕民主生活会主题，结合学习心得、个人实际，认真开展批评与自我批评，并紧密联系班子和个人的思想、工作和作风实际，查找存在问题，明确努力方向，并就加强作风建设、保持党的纯洁性充分交换了意见，提出了初步整改方向。列席会议的同志就领导班子如何提高管理水平、加强沟通与交流等方面发表了个人建议和意见。
