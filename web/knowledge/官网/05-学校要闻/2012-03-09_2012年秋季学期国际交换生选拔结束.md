# 2012年秋季学期国际交换生选拔结束

国际交换生面试现场（右一为王十一同学）

城市学院与美国北爱荷华大学2012年秋季学期国际交换生选拔工作已于近日结束。经学生自愿报名、学院按照有关程序选拔，文学与传媒系09级汉语言文学（新闻传播）专业王十一同学被选定为城市学院第五批赴北爱荷华大学的国际交换生。
