# 安全工程专业学士学位授权评审会

4月16日，学院在行政楼212会议室召开学士学位评定委员会会议，对安全工程学士学位授权专业进行评审。学院学士学位评定委员会15位委员参加了评审会，会议由学士学位评定委员会办公室主任牛熠教授主持。

会议通报了以东莞理工学院高评中心主任陈想平教授为组长的评审专家组对该专业进行的实地评审意见。与会委员听取了安全工程专业负责人肖红飞教授关于该专业建设的基本情况、建设思路、师资力量、课程设置、教学管理、科研成果等方面的汇报，审阅了该专业的评审材料，对照新增学士学位授权专业评审指标体系进行了认真审核，一致认为，安全工程专业已具备新增学士学位授权专业的基本条件。
