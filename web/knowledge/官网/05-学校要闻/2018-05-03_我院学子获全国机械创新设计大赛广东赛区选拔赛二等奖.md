# 我院学子获全国机械创新设计大赛广东赛区选拔赛二等奖

4月29日，第八届全国机械创新设计大赛（广东赛区）选拔赛在华南理工大学举行。我院机电系派出5支学生队伍参赛，有4支队伍分获二等奖1项、三等奖3项。

据悉，全国大学生机械创新设计大赛是教育部、财政部批准和资助的全国性大学生学科竞赛，是国内最具影响力、培养学生工程实践能力和综合素质的大学生竞赛项目之一。本次广东赛区选拔赛由广东省教育厅主办,共有近200项参赛作品。
