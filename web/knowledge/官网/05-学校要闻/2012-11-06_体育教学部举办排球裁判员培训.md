# 体育教学部举办排球裁判员培训

为了丰富学生的课余文化生活，提高学生的体育实践能力，配合学校教职工的排球竞赛，2012年11月1日，体育教学部主任邢红林教授与曾爱明老师对学校刚成立的排球协会成员进行了排球裁判理论与实践培训。

参加裁判培训的22名人员称同学表示，通过此次培训，他们已经对排球裁判的知识有了初步的了解，以后会通过多种途径加强对排球裁判知识的学习与实践，把排球协会做好，丰富同学们的业余生活。
