# 我校召开2019-2020学年度绩效考核工作布置会

6月11日，2019-2020学年度绩效考核工作布置会在行政楼212室召开，学校领导和二级单位负责人参加了会议。会议由人事处张兰副处长主持。

张兰副处长汇报了2019-2020学年度绩效考核工作整体工作安排和主要变化，要求各单位严格按照文件要求按质按量完成绩效考核任务。

人事处李海冬处长强调了各单位要规范开展本学期绩效考核工作，严格把握时间节点和考核要求，公开、公平、公正地完成考核工作。

刘玉侠副校长指出，绩效考核改革与人事改革、薪酬改革是密不可分的，要秉承“重心下移，激励先进”的宗旨开展好本年度绩效考核工作。

最后，王卫平校长指出，各单位要借鉴试点学院的做法和经验，成立绩效考核工作小组，要把“顶层设计”和“摸石头过河”有序结合起来，确保本年度绩效考核工作圆满完成。
