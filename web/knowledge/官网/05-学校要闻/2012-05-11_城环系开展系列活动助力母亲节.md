# 城环系开展系列活动助力母亲节

5月的第二个星期天，又到了向母亲表达你我爱意的时刻。城市与环境科学系在母亲节到来之际，在新老校区同时开展系列活动，助力母亲节。

活动由“写下你想说的话”，“微博晒幸福”，“给妈妈的一封信”，“DV感想——妈妈与我”四部分组成。

5月9日，在“写下你想说的话”活动现场，组织者将事先准备好的小彩旗挂在周围，营造出一份温馨的氛围，并向过往的同学发放“心愿卡”——精美便利贴纸，请他们在纸上留言，写下自己对母亲的祝福，并将“心愿卡”贴在“心愿墙”上，五颜六色的“心愿卡”把“心愿墙”贴得满满当当。这些“心愿卡”将会于13日母亲节当天在老校区四号楼大厅和新校区校道上展出，让全院师生分享参与者对母亲的关爱和祝福。

值得一提的是，此次活动借力微博，发起“晒幸福”活动。活动参与者通过在城环系官方微博上写下想对妈妈说的话，与大家分享妈妈的感人事迹，或贴上自己和妈妈幸福甜蜜的合照。微博管理者每天抽取一名幸运者，转发其微博内容，并送上一朵康乃馨，向妈妈传达同学们的敬爱之情。

“给妈妈的一封信”活动将持续到5月底。参与者把平时想对妈妈说的话和想表达的感情通过书信的形式写出来，提交活动主办方。活动结束后将评选出一、二、三等奖，并替他们寄给家里，传递他们对母亲深深的思念以及祝福。“这是我第一次写家书，也是第一次向我妈妈表达我的爱意。我以前总是因为不听话惹妈妈生气，现在出门在外，远离妈妈身边，才深刻地体会到妈妈对我的爱！”来自资源环境与城市规划管理班的王同学寄出了一封1000多字的家书，并第一次在信中写出了“我爱你妈妈！”这句她一直想说却不好意思说出来的话。

“DV感想——妈妈与我”由城环系学生会成员在全院范围内采访师生关于母亲节的感想。据介绍，目前该DV视频已经初步拍摄完成，经过后期制作后将上传城环系网站和官方微博。

据城环系系主任肖红飞介绍，很多同学有爱妈妈的心，却不好意思对妈妈表达出来；心疼妈妈的辛苦付出，却没做出一些实际行动。在母亲节前夕，城环系开展一系列活动，目的就是要带动更多的同学勇敢地表达出对妈妈的爱，弘扬中华民族的传统美德。
