# 艺术系林伟伦老师获第25届国际合唱比赛指挥奖

第25届国际合唱比赛于5月17日在法国彭斯圆满落幕。林伟伦老师担任指挥的合唱团荣获本次比赛冠军，林伟伦老师荣获指挥奖，指挥奖在此次比赛中仅设两名。

此外，林伟伦老师于5月12日至16日在法国Charter、Jonzac、Royan、Pons等四个城市举办的音乐会上，担任指挥，获得好评。
