# [招生专题]我院省内线上第一志愿超计划完成招生工作

7月29日，我院2014年广东省普通类招生录取工作正式开始，第一志愿投档4432人，一次性超计划完成全部投档。

从生源数量看，我院东莞、省内投档双双呈几何级数增长。其中，莞籍考生第一志愿投档达1868人。省内外市考生第一志愿投档达2564人。

从生源质量看，今年仍有多人获“优秀新生奖学金”，莞籍占绝大多数，文科高于2A线考生的3人全部为莞籍考生，最高分为537分，超出2A线3分；理科高于2A线考生的9人中有6人为莞籍考生，最高分为510分，超出2A线7分，他们均有机会获得我院两万元的“优秀新生奖学金”。

从报考专业看，热门专业热度不减，新兴专业招生强劲，新增专业表现良好。今年会计学、商务英语专业继续火爆；尤其是土木工程专业计划招生200人，实际投档人数达到490人；今年新增的市场营销、环境工程、物联网工程专业招生情况良好。

院招生办友情提示：我院将在8月中旬寄出录取通知书，请广大考生互相转告，注意查收。
