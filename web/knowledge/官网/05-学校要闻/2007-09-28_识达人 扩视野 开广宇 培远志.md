# 识达人 扩视野 开广宇 培远志

9月27日晚，中国科学院的徐建中院士在城市学院的大礼堂以《从中学到大学》为题目作报告，和一千多名07级新生分享了一位他的院士求学经历。

当晚大礼堂座无虚席，气氛活跃，掌声此起彼伏。一个多小时的报告里，徐院士不仅向东莞的学子展示了物理学科领域的名人风采，也现身说法教导同学们要博览群书，多思考，多做习题，多问几个为什么。他还以自己的求学经历激励着同学们：关键要做一个有责任感，有抱负，有创新精神的人。

报告会由东莞理工学院城市学院党委书记朱志德主持，他代表城市学院对徐院士来我院讲座表示热烈欢迎和衷心感谢。他说：“徐院士作的报告没有空洞的说教和大道理，他以自己的亲身经历教导我们‘大学就是要大学特学’。徐院士非常关心当代大学生，下午飞机晚点，他还未吃晚饭就赶来为我们作报告。”在场的学生被徐院士的精神感动得起立鼓掌。

文学艺术系一名07级的新生说：“中央电视台教育频道有《百家讲坛》，凤凰卫视有《世纪大讲堂》，虽然我们学院是省级大学，但也有《城市学院大讲堂》，我也可以和电视上的名人面对面的交流，不仅开阔了视野，增长了见识，也使我有了树立远大理想的决心。”

据悉，去年2月份，徐建中院士曾来过城市学院的讲学作了“关于我国能源发展战略的思考”的学术报告，那是作为“科学与中国”院士专家巡讲团东莞报告会系列活动之一。
