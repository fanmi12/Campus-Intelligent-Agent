# 东莞市综合执法局与我院师生共商流动商贩管理对策

6月1日，应东莞市综合执法局局长赖源顺、副局长莫志强的邀请，我院东莞社情研究中心刘杰教授、危兆宾老师、周巍老师、李细香老师等师生，与综合执法局的同志共商流动商贩管理对策。

流动商贩的管理，是东莞市城管工作中的一件最令人头痛的事情，东莞市综合执法局已将此作为今年的十件实事之一来抓。今年下半年，该局将与我院东莞社情研究中心合作开展一系列的调研活动，共同探讨和研究流动商贩管理的新办法。
