# 我校召开党委理论学习中心组民法典专题学习会

为贯彻落实“八五”普法规划，根据全国普法办《2023年“美好生活·民法典相伴”主题宣传方案》部署要求，5月31日，我校在行政楼505召开党委理论学习中心组专题会议，集中学习《中华人民共和国民法典》。东莞城市学院法学院专任教师、广东闻仲律师事务所兼职律师、澳门科技大学在读博士丛珊应邀作专题辅导，带领大家深入学习民法典知识。党委委员、全体校领导、党委工作部门主要负责人等参加会议。会议由党委书记章德胜主持，校长陈明，党委委员、法制办主任孔增强进行交流发言。

丛珊老师以《民法典与高校治理》为主题，围绕产权保护、合同履行、校园侵权等几个重点内容展开，详细阐述坚持主体平等、保护财产权利、维护人格尊严、追究侵权责任等基本要求，不仅说明了民法典在实际生活中的重要性，同时还强调了学习民法典对于提升高校管理者法律意识和法治思维的积极作用，有助于高校管理者更好地依法治教、依法治校。

党委书记章德胜向丛珊老师的精彩讲解表示感谢。他指出，丛珊老师的讲解让大家更深入地理解民法典中的基本原则和法律规定。希望通过这次讲解，大家能够正确理解和运用民法典，为营造良好的校园环境奠定坚实的法治基础。

章德胜强调，党的二十大报告指出：“坚持法治国家、法治政府、法治社会一体建设，全面推进科学立法、严格执法、公正司法、全民守法，全面推进国家各方面工作法治化。”高校作为国家培养人才的摇篮，应充分做好民法典普法宣传教育工作，提高学生运用民法典保护自身权益的能力，不仅有利于促进学校的法治建设，还进一步推动学校法治工作的开展,为创建平安、和谐、文明的校园奠定坚实的法治基础。

校长陈明作交流发言。他从两个方面谈学习民法典的心得：第一个方面是民法典颁布的意义和作用。他表示，民法典的颁布是我国整体法治建设成就的重要标志之一，是法治适应时代发展的产物，是民族精神和时代精神的立法表达，它充分体现了人民的意志和意愿，是真正用来解决和调解现实生活中群众迫切需要解决的各种矛盾和问题，回应社会关切；第二个方面，他强调学校师生在学习民法典应该做好的三件事情：一是聚焦要义，学校组织师生员工全面学习并充分掌握民法典的要义内容，同时通过普法宣传，为社区群众提供帮助，加大民法典的普及和运用，让社区群众知法、懂法、遵法、守法；二是提高对民法典重要作用的认识，高校师生应该成为践行民法典的模范；三是要做好权益保护，充分利用好民法典来保护学校、师生员工的权益。

法制办主任孔增强交流时指出，全面学习、宣传普及民法典,对依法治校有着极其重要的意义。一个国家要真正实现法治，必须依靠包括广大师生在内的知识阶层来推动其法治化进程。学习和运用民法典是培养广大师生法治思维和法治意识的重要契机。首先，要积极引导广大师生做学习、遵守、维护民法典的践行者。其次，要提高广大师生的爱国守法意识。最后，要鼓励广大师生积极投身到民法典的宣传实践中。

章德胜在作总结讲话时强调，学习民法典，要坚持以习近平新时代中国特色社会主义思想为指导，全面贯彻落实党的二十大精神，深入学习宣传贯彻习近平法治思想，让民法典走到群众身边、走进群众心里，教育引导干部群众办事依法、遇事找法、解决问题用法、化解矛盾靠法，努力使尊法学法守法用法在全校蔚然成风。
