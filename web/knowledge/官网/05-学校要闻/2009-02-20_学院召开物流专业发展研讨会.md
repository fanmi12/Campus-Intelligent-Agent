# 学院召开物流专业发展研讨会

2月19日，学院组织管理系物流教研室教师在405会议室，召开东莞城市物流发展趋势与对策及城市学院物流专业建设研讨会。副院长程发良教授出席并主持会议，管理系主任罗余才教授、学院新闻中心主任何鹏举副教授及物流教研室所有教师参加了会议。

程副院长在会上指出，学院大力支持物流专业的发展，并将物流专业作为我院的重点专业加以扶持和建设。物流专业师生要借助东莞大力发展第三产业的契机，大力宣传物流管理对东莞经济的推动作用，为东莞物流产业的发展建言献策，提升我院物流专业的知名度。同时，要进一步加强物流实验室的建设。

会上，与会人员结合国务院《珠江三角洲地区改革发展规划纲要》和当前市政府对东莞“新兴物流城市”的定位，对物流专业的发展提出了自己的看法，认为应从教学和实践两方面入手，与虎门港和南方物流加强合作，以此为突破口，为东莞的经济发展做出自己的贡献。
