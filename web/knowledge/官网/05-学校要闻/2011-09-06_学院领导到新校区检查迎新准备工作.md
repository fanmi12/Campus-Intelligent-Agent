# 学院领导到新校区检查迎新准备工作

9月6日，院领导安少华、朱志德率各处室主要负责人赴新校区检查迎新准备工作，并在法商大楼四楼会议室主持召开迎新工作部署会议。

会议听取了新校区迎新工作准备情况汇报，并就迎新工作的具体方案和措施进行了分析和确认。院领导认为迎新工作方案全面、扎实、细致，想新生所想，具有人性化、可操作性强等特点。并要求各职能部门和迎新工作人员狠抓落实，为4700多名新生从接待、报名，到食住、学习等各个方面提供更加优质、舒心的服务。
