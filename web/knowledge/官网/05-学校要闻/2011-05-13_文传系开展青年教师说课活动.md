# 文传系开展青年教师说课活动

5月12日，文学与传媒系青年教师说课活动在3209举行。院督导组督导谢友祥、屠大华、李秀琴，陈玲玲4位老师担任评委，中文教研室的老师参加了说课活动。

说课活动旨在促进教师互相交流学习，提高教学水平，促进青年教师的成长与进步。韩方方、柯小瑜、黄璀、罗希明、钟丹5位教师是近两年调到我院工作的青年教师。他们各选取一门专业课进行说课。罗希明老师一开场便从“诗意地栖居在大地上”引出此次说课课程——《美学》。她娓娓道来，谈了对《美学》课程的认识，以及如何引导学生学好这门理论性较强的课程。其他4位老师从课程定位、教学目标、教学重难点、教学方法等几个方面陈述了自己对课程的理解。5位老师讲课的共同特点是，注重与学生的互动，巧妙地将讨论法、问答法、案例法融入教学之中。

屠大华教授为本次说课活动做了点评。她认为5位青年教师各有优点和不足，希望他们再接再厉，讲究授课方法与艺术，争取成为教学的中坚力量。
