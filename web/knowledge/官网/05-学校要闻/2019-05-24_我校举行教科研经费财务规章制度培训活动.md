# 我校举行教科研经费财务规章制度培训活动

5月23日下午，学校教科研经费财务规章制度培训会议在行政楼212室举行。副校长周庆、财务处处长余竹根、教务处副处长鞠晓红、教科研项目负责人及项目组成员参加了会议。

财务处吴凡老师就学校教科研经费、创新强校工程专项资金、质量工程项目及教改项目专项资金等六项财务规章制度，作了详细的解读。教务处关海仪老师介绍了学校教研项目的分类、管理范围和有关程序等。研发处付文玉老师对学校科研项目的类别、申报及使用等方面作了详细的解析。

余竹根处长在总结强调严格执行教科研经费财务规章制度的重要性，详细解答了大家提出的疑问，表示今后财务处将开展系列财务培训活动，为广大师生员工在财务方面提供更加完善的服务。

此次培训会议由财务处、教务处和研发处联合举办，旨在更好地为教科研项目教职工提供高效、便捷的财务报账及项目管理服务，进而提高教科研工作效率。
