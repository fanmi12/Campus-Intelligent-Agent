# 我校开始实施垃圾分类管理

为改善我校学生公寓卫生环境，推进垃圾分类投放工作， 11月6日下午，我校在行政楼407会议室召开垃圾分类专项协调会。校长王卫平、党委书记章德胜和有关部门负责人、各二级学院副书记，以及鸿发教育投资公司副总经理李奎山、美猪项目负责人参加了会议。

美猪垃圾分类项目负责人介绍项目背景及相关实施流程。

后勤保卫处副处长刘维仝就我校垃圾分类项目实施的相关工作任务进行分配和部署。

会议就学生公寓清洁员工的监督与管理问题、垃圾分类的有效宣传方法、垃圾分类投放等问题进行了讨论、研究。

王卫平校长表示，垃圾分类是件利校利师生、利国利民的好事。城院是我家，爱护靠大家，全校师生要树立良好的环保意识和责任。全面实施垃圾分类是一个循序渐进的过程，要把垃圾分类作为一种新的生活方式融入师生的日常生活当中。要做好打好垃圾分类持久战的准备，重在培养良好的习惯。学校将在源头上抓好垃圾分类的各项宣传、指导工作，将垃圾分类意识渗透到学生们的生活中，努力让校园更加洁净与美好。
