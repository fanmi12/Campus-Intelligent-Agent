# 陈伟当选广东图书馆学会理事并获课题

1月20日，广东图书馆学会第十届四次理事会议，增补我院图书信息中心主任陈伟研究馆员为广东图书馆学会第十届理事会理事。

广东图书馆学会是我省重要的社科学术团体，其任务是推动我省图书馆学的研究和图书馆事业的繁荣与发展，在全国图书馆界中有着重要的地位和影响。

陈伟研究馆员近年研究的课题较多，还出版过专著。最近，由他负责的课题《知识产权环境中的图书馆权利空间研究》被广东省文化厅立项。
