# 我院举行2017年教师讲课比赛

5月10-11日，我院2017年教师讲课比赛决赛在7A112举行，各系部选拔推荐的11名教师参加了决赛。本次比赛由教务处组织，得到了各系部的大力支持。以教学督导为主的五位专家担任本次决赛的评委。

参赛教师准备充分，精神饱满，以最佳的状态在大赛中展现了自己的才华和良好的教学基本功，充分展现了我院教师的精神风貌和专业水准。评委从教学内容、教学方法、语言表达、教学过程、教态仪表等方面对参赛教师进行了客观而全面的评价。经过激烈角逐，计信系曹丽娟获得一等奖，政法系钱小娟、计信系王宽福获得二等奖，外语系王歆军、艺术系臧莹竹、思政部李燕燕获得三等奖，文传系钟丹、金贸系陈孔艳、城环系田云丽、管理系邓葵璋、体育部彭国华获得优秀奖。高香林副院长为获奖教师颁发了证书。

教务处处长牛熠认为，讲好课是教师的头等大事，因此，我院连年开展教师讲课比赛很有意义。目前，青年教师在我院所占比例较大，提高青年教师队伍的教学水平，能够推动全院教学质量的改进。举办讲课比赛，可以激励广大教师进行教育教学研究，是提高教学能力的有效途径。
