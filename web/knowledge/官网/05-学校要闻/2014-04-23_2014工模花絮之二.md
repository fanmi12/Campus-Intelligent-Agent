# 2014工模花絮之二

为工模留一片净土

在“工模”小广场上，吃的、用的、穿的应有尽有，各种商品堆积如山，采购商品的师生川流不息，市场俨然成了人的海洋。

但是，记者在现场看到，市场所产生的垃圾堆积如山。在众多小食摊聚集的小广场上，垃圾桶还严重不够用。许多的一次性碗、竹签早已把垃圾桶们填得满满的，令负责环卫的叔叔阿姨们非常辛苦。在微信的朋友圈，转发着一张深夜里环卫叔叔拉着一车垃圾往校外走的图片。在夜色的衬托下，他的背影尤为艰辛。

工模不仅是为了锻炼学生的能力，它也在考验着我们每一个人的公德心。只要将手中的垃圾放入目所能及的垃圾桶而不随意丢弃，这样我们的工模才能拥有一个干净的环境。为了工模能有一片净土，为了环卫叔叔阿姨们的工作量少一点，让我们一起不乱弃垃圾，文明逛工模吧! （大学生记者：陈嘉琳）

行走“江湖”的技艺

“哇，这个学生姐好厉害！”一位可爱的小朋友站在一个工模摊位前称赞道。

循着小朋友的目光，就会发现101号摊位的摊主正在埋头奋力扎气球。

101号摊位的老板为了吸引顾客，她用自己的一双巧手能在瞬息间把气球扎成栩栩如生的小狗、可爱的喜娃娃或卖相甜美的糖果等等。

果然，不一会儿，就引吸了大批的同学前来购买。

当记者问到摊主刘师姐用了多少心思准备这项技能的时候，刘师姐俏皮地回答说，“嘻嘻，这是我们行走‘江湖’的技艺，当然要花心思，开市之前我学习了很久。”（大学生记者：陈敏仪）“专业贴膜30年”38号摊位的招牌特别吸引同学们的目光。一张白色的硬纸板上书写着“祖传贴膜”的广告牌。相对于其他摊位，真可谓是低调奢华有内涵，用摊主的话来说就是“用平凡来表现特别”。凡是看到这“专业贴膜30年”噱头的同学都忍不住笑了。队友们在灯光下用布擦掉手机上的灰尘，再用透明胶弄掉气泡，按步骤小心地将膜贴上手机。摊主对记者说：“向前五年，向后25年，专业贴膜30年，我们要一直贴下去，绝不能理解为我贴了30年手机膜啊！”摊主的队友也打趣道：“你爸贴电视机膜贴了30年！现在传到你手上了！”据了解，他们已经从大一的工模贴到了现在，技术也越来越成熟，真是言不虚传“专业贴膜30年”。 （大学生记者：肖田佩）“志愿摊位温情义卖”

在学六摊位后面，有一群身穿绿色马甲的摊主，他们是来自院志愿队、管理系志愿队以及文传系志愿队的同学们在不停地叫卖。走近摊位，便能看见暖人心的手绘卡通招牌以及象征爱心的“白鸽”。志愿者们热情地吆喝着“快来买呀，爱心义卖~商品有价，爱心无价”。琳琅满目的货品中有残疾人用手工制作的串珠工艺品，有文传系募集的一些二手物品以及志愿者们购买的一些纪念品。当一位女客户被用串珠制成的花所吸引时，志愿者们便一齐发力鼓励她购买，并且送上了“谢谢你们的爱心~！”的致谢语。院志愿队副队长杨家荣表示：“保持志愿者活动的热情很重要！”据了解，这次义卖由院系志愿队与莞城北隅社区综合服务中心合作，利用工模这一平台，将义卖出去的残疾人的手工艺品全部款项捐给社区，利用募集的资金给低保户以及孤寡老人购买日用品。（大学生记者：肖田佩）

饮品完胜星巴克9.5条街

走近125号摊位，只见帐篷上的标语夺人眼球：“给你一次环游马尔代夫的感觉”，并霸气地将自家的食品卫生许可证等执照“晒”出来。桌上摆着各种高端大气上档次的鸡尾酒瓶，一台现磨咖啡机以及各种调酒用的量杯。这家名为“谜路”的饮品店充满了时下流行的小资情调。当摊主用娴熟的手法摇晃手中器皿调酒时，围观人群都发出“好酷”的惊叹。调酒师用盐在晶莹的酒杯边沿抹上盐，依次倒入柠檬水、蓝橙酒以及薄荷酒，稍稍一摇晃，只见高脚杯中的液体立马变成了梦幻的蓝色，让人不禁联想起“海岛椰风”，还真有种马尔代夫的“赶脚”呢。（大学生记者：肖田佩）

雨中飘洒着歌声“电声乐队演出就要开始了，我们快去看吧。”

晚上9时，粉丝们陆陆续续来到舞台下欣赏音乐，意外发生了，天空突然送来了一场雨。为了不影响同学们的热情，乐手们冒着雨站在台上为观众表演。

雨却越下越大，然而意想不到的是，越来越多的人开始被他们热情的歌声吸引，打着雨伞成群结队的涌入现场，甚至有许多没有雨伞却仍然冒雨观看的忠实粉丝，大家一起跟着节奏挥舞着手臂、欢呼着为乐队加油，为这冰冷的雨夜增添了一丝柔情。（大学生记者：王芬）
