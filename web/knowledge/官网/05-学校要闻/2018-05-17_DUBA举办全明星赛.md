# DUBA举办全明星赛

5月15日晚，2018年东莞大学生篮球联赛全明星球赛在东莞市技师学院举行。来自东莞八所高校的17名优秀球员组成的“全明星”队对阵“CBA八冠王”广东宏远青年队，为大联赛呈现了一场精彩的篮球盛宴。章德胜副书记出席了明星赛活动。

我院男篮15号黄荣斌、17号邓浩宏入选全明星球赛，在赛场上有得分精彩表现。尽管高校全明星队打得可圈可点，但实力相差悬殊，最终以42∶94不敌宏远青年队。

全明赛上还举行了精彩的“三分王”大赛、“最强啦啦队”比拼等比赛，我院炫舞团啦啦队以精彩的表现斩获“最强啦啦队”评选亚军。
