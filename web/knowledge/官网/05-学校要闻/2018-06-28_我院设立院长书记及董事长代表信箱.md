# 我院设立院长书记及董事长代表信箱

为进一步拓宽师生、校友及社会各界人士与学院领导的沟通渠道，及时收集大家对学院发展的建议，了解和解决师生在工作、学习、生活等方面存在的问题和困难，6月26日起，学院设置了院长书记及董事长代表专用信箱，并首次公开院长书记及董事长代表电子邮箱。

院长书记和董事长代表信箱，挂置于行政楼一楼西门口处（面向映月湖）。

同时，学院网站还公布了院长书记、董事长代表的E-mail：校长书记邮箱: yuanzhang@ccdgut.edu.cn董事长代表邮箱:gddgcsxy@163.com院办近日发出通知指出，为学院发展及规范管理，真诚欢迎广大师生员工、社会各界人士积极参与学院管理，建言献策，多提建设性意见。
