# 珍爱自我  绽放青春  做魅力女生

“纯洁但不平庸，矜持但不拘谨，潇洒但不狂妄，真挚但不呆板，热情但不招摇，娇羞但不造作，浪漫但不轻浮，温柔但不盲从，博学但不傲慢，谦逊但不虚伪……”3月22日，东莞理工学院学生处副处长、心理健康咨询中心主任苏亚玲副教授在我院新校区学术报告厅做了“珍爱自我，绽放青春”的专题讲座，为2011级女生们的心理、生理、思想、健康，撑起了温暖的“保护伞”，引导同学们要自尊、自爱、自强、自立，懂得尊重自己、善待自己，做一个知性、自信的健康女生。

在近2小时的时间里，苏亚玲副教授从“什么是魅力”、“什么是女性魅力”、“什么是女生魅力”、“如何提高自己的魅力”四个方面，讲述了“魅力女生=美女+才女+淑女”的魅力法则。她还对女性素质、女性心理以及女性如何进行自我保护等方面进行了精辟的阐述。

苏老师的讲座既有理论的分析，又有案例的剖析。同学们听得津津有味，十分专注，不时响起热烈的掌声，气氛非常活跃。苏亚玲副教授在师生现场答疑、交流互动环节中，对女生们提出了许多关于生理、心理、爱情、学习、生活等方面的问题做了详细、真诚、精彩的回答，让在场的同学直呼过瘾和“给力”。
