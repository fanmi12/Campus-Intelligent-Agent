# 我院本科招生计划较去年增长近一倍

近日，记者从学院招生部门获悉，广东省2012年高校招生计划已经下达，我院本科招生计划为4180人，较去年本科计划招生规模2000多人扩大了近一倍，其中理科1920人，文科1982人。记者就考生和家长关心的一些热点问题，采访了相关领导。

据有关方面消息透露，城市学院是否招专科学生，最后结果尚未定论。我院意向还是希望招收大专学生，因为东莞考生仍有这个需要，目前我院正在积极争取。

我院属于第二批本科B类院校，往年录取办法是按地域招生，即设定区域计划，先定好莞籍考生招生人数，再确定市外考生招生人数，以此来保证莞籍考生的录取数量。而今年，针对广东各高校全面扩招的情况，莞籍考生的报考人数预计也将创新高，如果像往年一样实行区域限制既没有实际意义，还会在一定程度上影响莞籍考生的入学机会。我院从保证东莞考生入学机会的角度出发，正在酝酿取消以往的区域限制，不再限定莞籍考生人数，这就使莞籍考生有了更多的入学机会，这是东莞考生的“佳音”。但目前此措施尚未最终确定。

今年，我院各专业平均学费为每生每学年16000元。据了解，这个收费标准虽然较往年的平均学费13000元略有上调。“但我院学费水平在全省同类民办本科院校中仍然处于中下水平，相对来说是合理的。”招生办陈建新副处长介绍说。
