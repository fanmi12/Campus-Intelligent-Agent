# 我院艺术系教师艺术教育论文获多项省级奖

广东省第三届大学生艺术展演、艺术教育科研论文评选结果揭晓，我院艺术系教师有三篇论文分别获得一、二、三等奖。其中，马新川教授的论文《独立学院影视表演专业表演教学初探》获音乐类乙组一等奖，邓星明教授的论文《独立学院艺术教育的几点思考》获管理类甲组三等奖，史德松副教授的论文《独立学院音乐表演专业教学改革与发展路径再探索》获音乐类乙组二等奖。

据悉，广东省第三届大学生艺术展演是由团省委、省教育厅、省文化厅、省学联共同主办的，是我省大专院校的一场艺术盛会。艺术教育科研论文的评选，是对艺术专业教师综合素质和专业水平的集中展示。
