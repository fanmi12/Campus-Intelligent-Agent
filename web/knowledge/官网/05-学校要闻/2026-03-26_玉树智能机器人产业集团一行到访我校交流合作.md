# 玉树智能机器人产业集团一行到访我校交流合作

2026年3月25日，玉禾田环境发展集团副总裁、玉树智能机器人产业集团执行总裁杨波，玉树具身智能科技有限公司总经理郝嘉伦一行到访东莞城市学院，就智能机器人产业发展、校企协同育人等议题开展深度洽谈。学校执行校长方伟华，品牌与招生部部长叶云峰，新传媒与艺术学院院长于兰英及相关负责人出席座谈，双方凝聚合作共识，共探产教融合新路径。

座谈会上，方伟华执行校长致欢迎辞，向来访嘉宾全面介绍学校办学概况、学科建设特色及产教融合丰硕成果。他指出，依托民办体制决策快、落地实、调整灵的核心优势，学校在智能机器人专业建设中探索出“差异化布局、规模化培养、实体化合作”的特色突围路径。学校成立的优必选智能机器人产业学院，打破传统机器人专业边界，将研究与培养方向从人形机器人拓展至低空飞行等“大机器人”前沿领域，与周边高校形成错位发展、协同互补的产业人才培养格局；人才培养方面构建起“基础使用—编程控制—科研创新”三阶递进模式，让学生从掌握机器人基础功能到自主编程、再到科研竞赛创新，实现能力阶梯式提升。学校以务实的办学作风，打造出产教深度融合、标杆效应显著的人才培养“城院方案”，为新兴工科人才培养提供了高效落地的实践样本。

杨波执行总裁分享了玉树智能机器人产业集团在技术研发、产业应用等方面的成果，提出突破传统校企合作模式，围绕机器人大模型开发、数据标注、文创表演等领域深度联动，共建实训基地与专业认证体系，实现“毕业即上岗”。他希望依托学校体制优势，打造“学术研发—产业应用—商业落地”闭环生态，形成可复制的校企合作品牌，推动机器人行业标准化、规模化发展。

双方还就智能机器人产业人才培养需求、合作模式创新、科研成果转化等展开热烈探讨，交换建设性意见，为后续合作奠定良好基础。

此次交流搭建了校企双向赋能的桥梁，未来双方将发挥各自优势，在人才联合培养、科研合作、产业服务等方面深化合作，实现资源共享、优势互补，为智能机器人产业培育高素质应用型人才，助力粤港澳大湾区科技创新与先进制造产业升级。
