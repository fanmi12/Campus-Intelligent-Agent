# 我院大学生艺术团举行汇报演出

5月28日，学院大礼堂观众满座，节目异彩纷呈，歌声、笑声、掌声如潮。大学生艺术团在这里隆重举行“服务东莞、走进企业”汇报演出。

东莞理工学院院长杨晓西教授，东莞理工学院副院长、城市学院院长安少华教授和我院其他领导同志观看了演出。演出之后，他们走走上主席台与演员们亲切握手、合影留念并叮嘱同学们要虚心地向企业员工学习，演好每一个节目，并预祝大家演出成功，为学院争光。

这次演出，是落实学院“服务东莞求支持”的办学理念，扩大学院社会知名度系列活动之一，也是艺术团下企业演出之前的最后一次彩排。
