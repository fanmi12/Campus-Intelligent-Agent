# 【“十八大”专题】党委组织预备党员集中学习党的十八大精神

11月22日，城市学院党校在莞城校区大礼堂举办预备党员培训班，集中学习党的十八大精神，430多名预备党员和45名2012级新党员参加了培训。党委书记朱志德为同学们做了学习十八大精神的辅导报告。

朱书记把自己的学习体会概括为：“一面旗帜”，坚定不移高举中国特色社会主义伟大旗帜；“一条道路”，坚定不移走中国特色社会主义道路，既不走封闭僵化的老路、也不走改旗易帜的邪路；“一个理论体系”，中国特色社会主义理论体系；“一个目标”，确保2020年全面建成小康社会，实现国内生产总值和城乡居民人均收入比二〇一〇年翻一番；“五位一体布局”、12个组成部分、社会主义核心价值体系、“四大危险”。

朱书记还简要介绍了我们党几次修改党章的时间、内容、意义和指导思想。十八大将科学发展观确定为党的指导思想，并写进了章程，诠释了科学发展观的第一要义、核心、基本要求及根本方法。我们必须认真学习好、领会好。

朱书记从新一届中央领导班子成员的简历中分析出他们具有三大特点：一是大都有上山下乡的经历；二是他们的学历比前任更高；三是他们都有基层从政的经历。

朱书记在讲到党的基本知识时要求预备党员：必须讲政治，树立坚定的、正确的政治观，进一步提高思想素质和理论水平；必须增强党员意识，加强党性修养；必须按照党员的标准严格要求自己，在学习生活中起模范带头作用。

学院组织人事处余国鑫老师在会上作了“怎样才能成为一名合格的预备党员”的辅导报告。

通过这次培训，预备党员们进一步了解党的十八大精神，对党的组织、党的纪律、党员的权利和义务等知识有了进一步的了解。
