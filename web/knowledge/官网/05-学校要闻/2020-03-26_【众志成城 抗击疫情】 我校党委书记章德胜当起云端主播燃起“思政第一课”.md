# 【众志成城 抗击疫情】 我校党委书记章德胜当起云端主播燃起“思政第一课”

3月25日，我校党委书记章德胜现身云端做主播，结合新冠肺炎疫情大背景，为城院学子带来了一场“热气腾腾”的线上思政大课——《初心不忘齐奋斗、家国同在抗疫情》主题思政课。

章德胜书记从“一方有难，八方支援”是中国制度硬核的力量，是“中国精神”高度的使命，是“中国青年”有为担当等多方面进行诠释，向我校广大师生传递战胜疫情的正能量，增强了师生的“四个自信”。

我国防治疫情的“中国速度”和“中国力量”让世界惊叹。章德胜书记讲述了疫情时期，在党中央的坚强领导、统一指挥、统一协调、统一调度下，带领全国人民创造的一个又一个奇迹，启发大家深刻认识到中国特色社会主义制度的巨大优势。

谈到这场全民抗“疫”带来的启示时，章德胜书记指出，中华民族是具有伟大奋斗精神、伟大团结精神、伟大创造精神的民族，事实雄证了中华民族精神和社会主义制度优势。

疫情就是命令，防控就是责任。章德胜书记介绍，疫情发生后，学校坚决贯彻落实习近平总书记重要讲话和指示精神，按照中央决策部署和省市各级工作要求，把疫情防控工作作为学校头等大事来抓，坚决把师生生命安全和身体健康放在第一位，开展了一系列卓有成效的工作。他还介绍了我校师生和校友有组织、有纪律、有责任、有担当，奋战在抗“疫”一线的感人事迹。他说，青年学子是时代的未来，疫情当下，他们无惧逆行，用自己的才华与勇气表现出“中国青年”的有为与担当。

“青春不会辜负每一个勤恳努力的人，时代也不会辜负每一个砥砺奋进的人”，章德胜书记对同学们提出了殷切期望，“生活就像海洋，只有意志坚强的人才能到达彼岸，在这最艰难的时期，我们不仅要确保身心健康，同时积极利用这次‘网络教育’的机遇，主动适应学习方式、学习环境和学习形式的变化”。针对2020届毕业生，他强调，“毕业班的同学们要抓紧时间补齐自身短板，关注各种就业创业政策与网络招聘信息，为今年的毕业就业做好充分准备”。

章德胜书记最后动情地说：“在这特殊时期，希望大家多读书、读好书，从书中得知中外历史，了解人生百态，发现生活乐趣，不断提升自我、丰富自我，把生活过得生动且有意义。此刻，校园已经绿意盎然，我在这里等待着大家的归来！”

战“疫”，需要激发担当意识和家国情怀；战“疫”，需要众志成城的精神纽带；战“疫”，需要坚定打胜仗的信心和决心！在全民战“疫”的特殊时期，章德胜书记以这次疫情中鲜活的事例阐释马克思主义理论和习近平新时代中国特色社会主义思想，以及中国特色社会主义制度的优越性。

极富感染力的授课风格，动人肺腑的话语，贴近学生、贴近实际、贴近社会的选题，引起了学生们强烈共鸣。同学们纷纷表示，这堂特殊的思政课内容丰富、重点突出、视野开阔、讲解透彻，大家更加坚定了打赢这场疫情防控阻击战的信心。一位同学在留言中提到：“章书记的思政第一课使我很受启发。风雨如磐的党史无数次证明了中国共产党的伟大。在此紧要关头，中国共产党方显担当本色。作为一名新时代大学生，我将不断坚定‘四个自信’，传承战疫英雄们克险奋进、无私奉献的优良传统，奋力担当起时代赋予的光荣使命，书写无悔于国家和人民的青春华章。”
