# 院督学陈丁堂教授率队赴湖南大学考察学习

根据院长书记办公会决定，6月1日至4日，院督学陈丁堂教授率人事处和高教研评中心人员赴湖南大学考察学习院（系）目标管理责任制考核实施办法,受到湖南大学人事处李久学处长的热情接待。

据李久学处长介绍，湖南大学自2002年起已成功推行了两轮院（系）目标与绩效的管理，取得了一定的经验，新一轮综合管理与绩效评估工作正在启动。

湖大人事处还为我院提供了详细的目标管理责任制考核的相关资料。
