# 我校斩获7项省级心理健康教育工作奖

11月13日-14日，广东省高校心理健康教育与咨询专业委员会召开2019年学术年会。

会上，我校王彦娜老师荣获2018-2019年度广东省高校心理健康教育与咨询工作先进个人称号，余琼、王彦娜、柳林和赖巧珍老师荣获优秀论文二等奖达6项之多，获奖数量达历年之最。
