# 城环系召开维稳会议

5月12日，城环系在机电楼召开以“齐心协力，共创和谐”为主题的维护安全稳定工作会议，传达学院维稳工作会议精神。系学生会、团总支全体学生干部及各班班长团支书共50余人参加了会议。

会议开始前，全体师生起立默哀30秒，共同缅怀5.12汶川地震。会上，系团总支书记董雅洁老师强调了针对近期的H1N1流感病毒，要充分发挥学生干部的作用，畅通信息渠道，遇到问题早发现早处理。

系党总支副书记孔增强老师传达了我院维稳工作会议精神，并联系60年国庆、5.12地震、“八九风波”等，倡导全系学生要齐心协力共创和谐校园环境。
