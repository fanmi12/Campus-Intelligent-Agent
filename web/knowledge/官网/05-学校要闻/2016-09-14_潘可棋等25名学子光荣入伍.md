# 潘可棋等25名学子光荣入伍

9月12日，我院2016年送兵座谈会在行政楼212举行。院长王卫平、党委副书记章德胜，征兵工作领导小组全体成员，入伍学生以及家长参加了座谈会。会议由学生处杜鹏举处长主持。

今年我院学生报名参军非常踊跃，男生报名参军人数再度创新高达到1828人，女生达39人。截止发稿，我院共有机电工程系潘可棋、艺术系吴炜烽等25名同学经各地兵役机关批准入伍。

入伍代表潘可棋同学表示，感谢学校和家长们一直以来的支持。家长代表吴继超对学校为同学们搭建了去部队的桥梁，表示感谢！同时也希望同学们在部队服从命令、以实际行动来报答人民对他们的期望。

章德胜副书记代表学院为同学们颁发了入伍通知书，并赠送了纪念品。

王卫平院长在讲话中表示，在校大学生应该带头履行国家政治任务；部队是培养人的“大学校”，是锻炼人的“大熔炉”。希望同学们在部队，要保持良好的作风，确保素质过硬、政治过硬、军事过硬，将学校的知识带到部队，将来把部队的优良作风带回学校，为母校、家乡父老争光添彩。

据了解，入伍学生正陆续前往部队服役。
