# 我院隆重举行毕业典礼深情送别2012届毕业生

“我们毕业了！”欢呼声、祝福声在校园此起彼伏。6月29日，我院在大礼堂隆重举行2012届毕业生毕业典礼暨学位授予仪式，为1289名本科生的大学生涯划上圆满句号，欢送他们即将踏上社会开启人生新的征程。

学术副院长高香林教授主持仪式。仪式开始前，他首先介绍了在主席台就坐的领导，他们分别是：东莞理工学院校长、博导杨晓西教授，城市学院董事长麦照容、董事黎建烨，城市学院领导杨敏林、朱志德、朱冰、陈丁堂、张林、章德胜，教学系部主任黄健求、牛熠、罗余才、高香林、米双红、陈庆祝、邓星明、肖红飞、刘杰、何鹏举、赵涛。

九时许，伴随着雄壮的国歌声，2012届毕业生典礼暨学位授予仪式正式开始。

党委副书记朱冰宣读了学院表彰优秀毕业生的决定，杨晓西校长向毕业生代表颁发毕业证书，麦照容董事长为优秀毕业生代表颁奖。

院长杨敏林教授发表了热情洋溢的讲话。他动容地回忆了毕业生在母校的生活学习，认为同学们在学习中积累了知识，在活动中丰富了阅历，在服务中学会了担当，以优异的成绩完成了学业，其中还有一大批同学考取了硕士研究生、入党入伍、专升本或考取公务员，近九成的同学找到了工作。接着，他还深情地表达了对全体毕业生的良好祝愿，祝贺他们带着微笑走出校园，祝福他们带着信心踏入社会，祝愿他们带着希望迈向成功。杨院长感慨道，大学生活好似球赛的上半场，精彩的下半场在等待着同学们，只要不懈努力，就能把赢得灿烂人生的主动权牢牢掌握在你们手中。今后学院将继续为你们而牵挂，为你们而骄傲，也为你们的成功而喝彩。

优秀教师、文学与传媒系陈跃老师希望同学们做一个正直诚实的人，一个有近谋远虑的人，一个利人利己的人；要常怀感恩之心，敢担社会之责，争做栋梁之才！

今年考取华南师范大学的硕士研究生、文学与传媒系毕业生李山珍，代表全体毕业生表示：永不忘恩师的教诲，秉承“学而知不足”的校训，奋发有为，争作贡献，为学院争光添彩，常回家看看。

礼毕，院长杨敏林、党委书记朱志德及各系部主任一一为毕业生拨穗鼓励。

据悉，同时毕业的还有1300多名专科生。
