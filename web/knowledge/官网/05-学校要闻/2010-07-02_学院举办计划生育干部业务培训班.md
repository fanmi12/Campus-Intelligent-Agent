# 学院举办计划生育干部业务培训班

为了加强计生队伍的自身建设，提高院系各部门兼职计生干部的业务水平，6月29日，学院在315会议室举办兼职计划生育干部业务培训班。东莞理工学院计生办杨瑾老师到会指导。学院工会副主席、院办副主任黄研晖主持会议。

院计生办主任万玉君医师在会上解读了《国家计生法》、《广东省计生管理条例》，当前计生工作形势任务和要求，流动人口的管理与服务，优质服务与人口素质等方面的政策与知识。她还结合我院实际，强调了计生兼职干部的岗位责任。

东莞理工学院计生办的杨瑾同志在会议上介绍了理工学院的计生工作情况及做法。

据悉，为及时、快捷、简便、系统地掌握我院师生的计划生育情况，发挥我院网络优势，学院计生办近日设置了“学院计生管理工作登陆系统”，培训班还为计生干部介绍了该系统的使用操作方法。
