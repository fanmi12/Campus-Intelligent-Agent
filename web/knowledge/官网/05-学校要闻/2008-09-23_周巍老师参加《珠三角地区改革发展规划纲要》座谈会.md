# 周巍老师参加《珠三角地区改革发展规划纲要》座谈会

9月18日，我院东莞社情研究中心周巍老师，参加了由国家人力资源社会保障部等三部委举办的《珠三角地区改革发展规划纲要》座谈会，并就东莞社情研究中心近年对东莞就业和社会保障的相关调研作了汇报。

据悉，本次座谈会旨在征求为国家制定珠三角地区改革发展规划纲要提供参考意见。会议由东莞市委常委常务副市长冷晓明主持，主要参会人员为国家人力资源社会保障部规划财务司李刚副司长、发改委就业司胡德巧副司长、民政部规划财务司司长助理李长训所带领的《珠三角地区改革发展规划纲要》课题调研组成员，以及东莞市社保局、发改委、民政局、人事局、劳动局等相关部门的领导。
