# 北京理工大学珠海学院客人来访我院

6月29日，北京理工大学珠海学院党委副书记、副校长王文清一行4人来我院参观访问。党委书记朱志德，党委委员王玉、章德胜热情接待了来宾。

两校负责人在405会议室举行了座谈。朱书记首先介绍了我院学生党员的发展、基层党组织的建设情况及考核、组织活动的开展等方面的工作。客人们对我院实行发展党员票决制、党员目标管理制度、基层党组织年度量化考核等创新工作表现出极大的兴趣，认为值得借鉴和推广。

会上，朱书记还对即将在珠海召开的独立学院党建工作论坛提出了建议，客人们认为建议很好。
