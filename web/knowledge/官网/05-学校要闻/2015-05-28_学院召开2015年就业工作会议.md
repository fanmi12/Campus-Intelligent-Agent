# 学院召开2015年就业工作会议

5月25日，学院在行政楼212会议室召开2015年就业工作会议。党委副书记章德胜出席会议，学生处处长杜鹏举、院办副主任叶凯贞、院团委书记罗文芳，各系系主任、总支书记、副书记及辅导员参加会议。

会上，章德胜副书记宣读2014年就业工作先进单位表彰决定，并为受表彰的文学与传媒系、财经系、管理系颁发锦旗。

受表彰的先进单位介绍了经验，与参会人员分享。

学院就业中心主任江小卫通报了我院2014届毕业生就业的有关数据，对2014-2015学年就业工作做了全面的汇报。

章德胜副书记在讲话中指出，我院2014年就业工作特色鲜明，就业活动丰富多彩，在全体就业工作人员的共同努力下，取得了令人满意的成绩。对今后的工作，他提出了三点要求：一、要深化认识。各系要高度重视就业工作，把就业工作与学院的发展、与学生的发展紧密结合起来，相互促进；二、要明确责任。系领导要牵头，全员参与，强化目标，落实责任，切实抓好毕业生就业工作；三、要夯实基础。各系要重点做好人才培养工作，为毕业生走向社会奠定基础。

会后，学院与各系签订了《城市学院2016年毕业生就业工作目标责任书》。
