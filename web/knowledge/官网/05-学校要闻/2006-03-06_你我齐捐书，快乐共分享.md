# 你我齐捐书，快乐共分享

3月5日，我院图书信息中心在教工宿舍东面的治安亭设点接待前来捐书的院领导、教职工。经过多种渠道的捐书倡议宣传，来捐书的教师络绎不绝。

活动一开始，教师们就陆续拿来要捐的书，志愿者们通过联系提供上门取书服务。前来捐书的有城市学院院长安少华教授、副院长林世俊教授，还有活泼可爱的小孩童。在父亲的指导下，9岁小男孩路逸鸿也加入了捐书行列，他用稚嫩的声音说：“希望把看书的快乐与大家一起分享。”

据了解，从上午9时到下午4:30分，图书信息中心共收到捐书1132册。除了教师捐书外，图书信息中心还将组织学生以班为单位进行捐书。
