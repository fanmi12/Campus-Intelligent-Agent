# 市委、市政府召开高等教育现场办公会议

11月4日，东莞理工学院副校长、城市学院院长安少华教授，参加了市委、市政府召开的高等教育现场办公会议。会后，安院长向学院有关部门传达了会议精神。

安院长说，市委书记刘志庚，市长李毓全，副市长梁国英、吴道闻出席会议，市直机关有关部门、有关镇区，以及东莞理工学院等9所高校的负责人参加了会议。会议听取各高校关于目前存在的困难和问题的情况汇报，为高校“把脉”，现场解决高等教育中的困难和问题。

市委书记刘志庚在会上发表重要讲话，他说，当前，东莞高等教育存在的问题是定位模糊，师资薄弱，特色不够突出，培养模式单一，教育实践脱节。现场办公会议不只是解决实际问题，更重要的是体现了市委、市政府在实施“双转型”战略过程中，对高等教育的高度重视。

在谈及如何进一步办好东莞的高等教育时，刘书记强调，东莞不仅要建设成为经济大市，更要成为经济强市。东莞的高等教育要快速发展，成为东莞经济发展的“人才库”，技术创新的“发动机”，科学决策的“智囊团”。各高校在办学过程中，要坚持一个“核心”（以提高教育质量为中心）；抓住一个“关键”（优化结构）；突出一个重点（改革创新）；夯实一个“基础”（加强管理）；强化一个“结合”（高等教育与区域发展相结合）；营造一个“环境”（高等教育健康发展的环境）。要多元化办学，优化管理模式，贯彻落实好按新机制办学的政策。各高校要淡化行政化，克服官僚化；要充分发挥工会、教代会的作用。公办高校要坚持实行党委领导下的校长负责制，民办高校要实行董事会、理事会领导下的校长负责制。

副市长吴道闻主持会议并通报了东莞高等教育的基本情况。他指出，东莞市现有9所高校（含在建），近4万名学生，但与珠三角、长三角地区的城市相比，我们有一定的差距，与新加坡、香港比差距就更大了。为此，我们要把东莞打造成聚集人才的“高地”。希望各高校要做强品牌，办出特色，为东莞经济、教育“双强”城市争作贡献。
