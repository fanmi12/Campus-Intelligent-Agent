# 学院成立大学生创新创业发展中心

5月20日，城市学院大学生创新创业发展中心举行揭牌仪式。院长杨敏林，副院长高香林，院长助理麦绮琳，学生处副处长兼创新创业发展中心主任杜鹏举，校外顾问东莞市吴沫艺术策划有限公司董事长、创意总监吴沫，中天创意投资顾问有限公司副总经理何柏林，中国电信股份有限公司东莞分公司副总经理李亚斌到场祝贺。

伴随着由300名学生志愿报名组成的color run队伍的开跑，大学生创新创业发展中心正式启幕。杜鹏举老师向大家介绍了“中心”的活动宗旨与运作模式。据悉，“中心”位于学生公寓学7栋F1—F5。主要职责是：创新创业教育、工作调研及总体规划；制订大学生创新创业扶持政策与制度；大学生创新创业教育与培训；大学生创新创业项目开发、扶持与管理；校内外创新创业训练、实践基地建设与管理；大学生创新创业基金募集与管理；校园创新创业文化氛围规划与营造等。

杨敏林院长在讲话中指出，创新是时代的要求，是科学技术发展的灵魂，是人类文明进步的动力。为落实教育部提出的本科质量工程大学生创新创业训练计划，学院经过认真筹备成立了大学生创新创业发展中心，其目的是为同学们打造一个创新创业学习、交流、实践的平台，鼓励和扶持同学们开展创新创业活动。

杨院长对“中心”今后的工作提出了三点希望：希望各部门各单位协同配合，为“中心”保驾护航；希望社会各界鼎力支持，校企合作共同育人；希望同学们积极参与、成长成才。院长助理麦绮琳代表学院向中天创意谷代表何柏林副总经理授予创新创业实践基地牌匾。

副院长高香林教授为“中心”12位顾问颁发了聘书。高副院长指出，顾问团成员是由热心于大学生创新创业工作的老师、优秀校友、校外企业家等组成，具有指导、监督职责。
