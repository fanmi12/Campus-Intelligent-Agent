# 我院成功举办第三届“女生节”

湖波荡漾，春意盎然。3月6日，由团委主办、计算机与信息科学系承办的“城市学院第三届女生节”在新校区湖畔广场隆重举行。

下午3点，湖畔广场早已被同学们围得水泄不通。“捞金鱼”、“ 猜颜色”等十个游戏摊位吸引了近千名同学前来观看与参与。伴随着CM模特队激情的步伐和动感的音乐声，城市学院第三届女生节游园会拉开序幕。首先，书记团委罗文芳为活动致辞，“Happy Girls’Day”她给全院所有女生带来了节日的问候和祝福，并预祝城市学院一年一度的女生节取得圆满成功。接着，丰富多彩的节目接踵而来，吉他演奏、花样轮滑、魔术等个个精彩无比。现场的女生除了欣赏节目外，还可以玩游戏集积分或者通过互动抢答等赢得神秘奖品（智能手机、玫瑰花、巧克力、“都教授之吻”、“免费男友约会”、“我的搬水工”……）。

本次“女生节” 让校园充满了温馨和感动，既丰富了校园文化,活跃了校园气氛，同时也让每个城院女生都感受到自己的魅力与价值。
