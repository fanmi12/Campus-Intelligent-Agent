# 方伟华执行校长走访各二级学院 部署新学期高质量发展新蓝图

新学期伊始，为深入掌握各二级学院新学期工作部署，精准对接学院发展需求，方伟华执行校长先后走访创意设计学院、新传媒与艺术学院、国际教育学院、未来科技学院等二级学院。

走访创意设计学院

方校长出席创意设计学院院务会，明确本次会议核心议题是研讨敲定新学期20周具体工作安排，并结合学院发展实际，对新学期工作提出五点明确要求：一是强化师资队伍建设，严格明确各类教师考核标准，杜绝“躺赢”现象，鼓励教师主动开展跨专业学习、提升综合素养，精准把握高职称评定窗口期，助力教师快速成长；二是聚焦学科建设与学术提升，计划年内举办2-3场高水平学术会议，其中包含国际性学术交流会议，拟联合北京大学等高水平高校联合办会，进一步提升学院学术影响力，同时积极筹备新文科高峰论坛，凝聚发展合力；三是优化专业布局与规模保障，暂缓影视摄影与制作专业发展步伐，优先发力工科相关领域，全力确保学院3000人招生规模稳定，重点拓展视觉传达、新媒体等优势专业，打造特色办学品牌；四是完善管理与考核机制，严格参照学校“70%合格指标+30%审核指标+10%创优争先指标”的考核体系，由院长牵头与学校协商确定年度核心目标，杜绝“大锅粥”式考核，确保考核公平公正、可追溯；五是提前布局教学成果培育工作，着眼后两年教学成果奖申报，持续强化教学改革与成果宣传，以优质教学作品为支撑，不断提升教学质量与教案水平。

走访新传媒与艺术学院

方校长要求新传媒与艺术学院紧密结合学校地方性办学定位，找准自身发展抓手，走差异化发展道路，避免同质化竞争，推动学院内涵发展：一是以非遗学院和美育龙头研究单位为两大核心抓手，积极推动美育从艺术美育向学科美育转型，促进美育元素融入各学科教学全过程；二是聚焦发展瓶颈破解，着力推动产业项目向科研项目转化，严格参照学校考核体系，明确合格、审核、创优三类考核指标，充分发挥考核的导向激励作用；三是着力提升人才培养质量，聚焦20%优秀学生开展拔高培养，通过强化学生作品创作、加强实习实训指导、鼓励参与各类竞赛获奖等方式，切实提升学生就业质量与升学水平，同时引导教师聚焦专业领域，发表高质量学术论文，举办融合非遗元素的高端学术会议；四是加强团队建设，充分释放年轻新媒体团队的活力与创造力，放手让团队大胆探索、积极发展，学习创意设计学院团结协作、高效执行的优良作风，凝聚起推动学院发展的强大合力，引导学院领导从具体专业事务中脱身，聚焦统筹全局、谋划长远发展，全面推动学院整体办学水平提升。

走访国际教育学院

方校长对国际教育学院的国际交流合作、学生管理服务、合作办学等工作进行全面梳理，既肯定了学院在规范办学、稳步推进国际交流合作方面取得的显著成效，也针对当前面临的实际问题提出明确工作要求：一是扎实推进重点合作项目建设，稳步推进121项目、韩国交换生项目及中外合作办学相关工作，借助教育部同意121项目学生语言成绩延长至5-6月的利好政策，督促未达标学生加快语言准备进度，确保项目顺利推进；妥善做好24名韩国交换生的管理服务工作，积极协调解决交换生学分差异等实际问题，加强与相关学院的协同配合，推动各项工作有序开展。二是积极应对合作项目变动，针对部分合作院校停办合作项目、影响相关专业发展的情况，主动出击寻找替代合作院校，重点对接合适的高校，综合考量学费标准、办学环境、教学质量等因素，确保合作项目平稳衔接，切实保障学生合法权益。三是规范学生管理与相关手续办理，严格执行学生不出国相关审批手续，所有手续需经院长同意、盖章后报教务处备案，同时督促学生做好雅思等语言材料准备工作，确保3月按时上报相关资料，同步筹备交换生项目宣传资料，为学校招生工作提供有力支撑。四是深化中外文化交流融合，积极借鉴先进国际办学经验，不断完善全英文授课相关配套设施与教学体系，着力提升国际学生培养质量，全力构建“引进来”与“走出去”相结合的开放办学新格局。

走访未来科技学院

锚定未来赛道强化交叉融合

方校长明确未来科技学院的发展定位与建设方向，要求学院立足学校整体发展规划，聚焦未来技术前沿领域，强化学科交叉融合，打造特色发展优势，为学校新工科建设注入强劲动能：一是聚焦学科交叉融合，主动打破传统专业之间的壁垒，积极推动理工结合、工工交叉、工文渗透，聚焦前沿技术领域凝练自身办学特色，避免单一化发展，不断拓宽学科发展口径，打造具有核心竞争力的特色学科体系。二是强化人才培养与科研创新，坚持以学生为中心的办学理念，积极探索“本硕博”贯通培养等人才培养新模式，充分激发学生创新潜力，着力培养具有前瞻交叉思维的高素质科技创新人才；强化科研育人功能，推动科研成果及时转化为教学内容，鼓励教师聚焦关键核心技术开展攻关，力争产出一批具有影响力的代表性科研成果，提升学院学术影响力。三是加强师资队伍建设，着力打造一支学科背景交叉、学缘结构合理、对科技前沿具有敏锐洞察力的高水平教师队伍，引导教师把发现、培养青年人才作为重要责任，为青年教师成长搭建平台、提供支撑，助力青年教师快速成长成才。四是深化校企校地合作，积极汇聚科研院所、行业龙头企业等各方优质资源，搭建高水平产学研合作平台，推动前沿技术、交叉技术的科研攻关和应用场景创新，主动对接粤港澳大湾区未来产业发展需求，实现教育、科技、人才良性循环。五是强化示范引领作用，充分发挥自身在新工科建设中的优势，主动担当作为，带动相关学院协同发展，同时为其他学院提供技术支撑和办学经验借鉴，助力学校整体办学水平提升。
