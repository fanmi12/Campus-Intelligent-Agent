# 党委书记朱志德深入金贸系调查研究

11月4日，学院党委书记朱志德副研究员到金贸系调查研究，并参加了该系教师座谈会。

座谈会上，朱书记回顾了城市学院的发展历史，肯定了金贸系建系一年来的工作。他指出，在新的形势下，城市学院的发展面临着许多机遇与挑战。作一名教师，一是要做好本职工作，钻研业务，认真上好每一堂课；二是要结合教学搞好科研，多出成果，充实自己。

金贸系主任米双红教授代表全系老师表示，一定要认真理解和执行院党委的工作意图，发挥党员的先锋模范作用，努力工作，出色完成院领导交办的工作任务，使金贸系的工作再上一个新台阶。
