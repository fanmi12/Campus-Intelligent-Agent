# 团旗飘飘跟党走 五月鲜花遍莞邑

4月27日，东莞理工学院城市学院艺术团240名学生参加团市委、市青联、市青年志愿者协会、市学生联合会组织的 “青春奉献·和谐先锋——东莞各界青年隆重纪念中国共青团成立85周年大型文艺演出活动”。 这次文艺汇演是为了纪念五四运动85周年暨东莞建团80周年，展示东莞团员青年的青春风采和文化素养。

当天，黄旗广场团徽熠熠，团旗妍妍，诗乐激荡，歌舞生风。整台演出以“我与祖国共奋进、青春奉献新东莞”为主线，通过诗歌朗诵、旗海传递、歌舞合唱等形式，歌颂东莞志愿者服务社会、关爱弱者的无私奉献精神。

一曲合唱《歌唱祖国》拉开了汇演的序幕，我们怀着激情与梦想，在这里把自己最美的歌声，最美丽的风景展现给祖国，表达我们青年一代的风采；小品《情暖新莞人》让现场的观众开怀大笑，把整个汇演推向了高潮；《真心英雄》将“快乐与责任”融为一体，舞动欢乐，畅想青春；组歌联唱《青春岁月》呼吁广大青年强化责任意识，用青年独有的快乐心态和激情服务社会，弘扬“海纳百川、厚德务实”的东莞城市精神。

此次汇演，不仅是回忆，更是为了铭记，铭记我们的历史，铭记共青团所走过的路程，铭记五四服务精神，更好地怀揣梦想与激情，服务社会，让青春飞扬，让理想飞扬。
