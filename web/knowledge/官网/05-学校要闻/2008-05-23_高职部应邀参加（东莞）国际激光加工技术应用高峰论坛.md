# 高职部应邀参加（东莞）国际激光加工技术应用高峰论坛

5月16日，在高职部副主任谢俊和黄旭辉老师以及机电系谢明等老师的带领下，高职部06级计算机辅助设计与制造1、2班学生共45人应邀参加了在东莞科技馆举行的亚洲（东莞）国际激光加工技术应用高峰论坛。

该论坛聚焦了中国飞速发展中的中国激光加工市场，业内的知名专家、典型用户以及知名企业，就激光加工技术及产业发展规划、市场现状及发展、政策指导、应用热点及市场商机等热门话题进行了探讨，同时重点介绍激光技术的最新发展，探讨未来发展的趋势。

据悉，激光加工已广泛应用于汽车、电子、电器、通讯、航空、冶金、机构制造等国民经济重要行业，在提高产品质量、劳动生产率及自动化水平，降低污染、减少材料消耗等方面发挥着越来越重要的作用。据预测，2010年致2015年，光子产业更可能会取代传统产业。

同学们能参加如此高级别的会议，对于扩展专业知识视眼，了解专业前沿发展，是一次难得的机会。
