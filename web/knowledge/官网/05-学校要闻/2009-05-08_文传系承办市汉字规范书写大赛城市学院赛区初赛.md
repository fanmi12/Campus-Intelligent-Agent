# 文传系承办市汉字规范书写大赛城市学院赛区初赛

4月29日，东莞市汉字规范书写大赛城市学院赛区进行现场初赛。本次书写大赛由东莞市教育局、东莞市语委主办，共有六个类别，分别是软硬楷书、软硬隶书和软硬行书。

赛前报名火热，各系同学纷纷响应，积极准备。报名人数最多的字体是硬笔楷书，共有120余名同学报名参赛，竞争相当激烈。

比赛结束后，我院从参赛同学中评选出刘炽辉等12名同学（每个类别2人）代表学院参加东莞市汉字规范书写大赛的决赛。

附：东莞理工学院城市学院赛区入选名单

硬笔楷书：刘炽辉（文传系）、梁淑娟（文传系）；

硬笔行书：林雄锐（文传系）、李珂珂（政法系）；

硬笔隶书：布瑞雯（政法系）、陈羡银（管理系）；

软笔楷书：吕斯娴（金贸系）、钟妙容（文传系）；

软笔行书：赖剑鹏（政法系）、欧健文（城环系）；

软笔隶书：李敏华（文传系）、胡文剑（计信系）。
