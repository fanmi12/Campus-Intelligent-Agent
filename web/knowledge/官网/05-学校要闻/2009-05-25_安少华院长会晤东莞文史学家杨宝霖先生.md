# 安少华院长会晤东莞文史学家杨宝霖先生

5月21日，东莞理工学院副校长、城市学院院长安少华教授在东莞市情资料室亲切会晤东莞文史学家杨宝霖先生。图书信息中心主任陈伟和市情资料室负责人黎伟一起接待了杨老先生。

多年来，杨宝霖先生非常热心东莞历史文化的宣传和研究工作，并多次来我院为大学生讲学。安院长向杨老先生表示谢意。随后，大家就东莞人文历史资料的收集和利用工作交换了意见。
