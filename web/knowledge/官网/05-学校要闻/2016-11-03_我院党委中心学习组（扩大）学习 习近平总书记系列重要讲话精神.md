# 我院党委中心学习组（扩大）学习 习近平总书记系列重要讲话精神

10月27日下午，我院党委中心学习组（扩大）召开习近平总书记系列重要讲话精神学习会议，并邀请华南理工大学马克思学院院长刘社欣教授作了《学习讲话精神，实现中国梦想》的主题报告。院党委中心学习组（扩大）成员参加了学习活动。

刘社欣教授在解读习近平总书记系列重要讲话精神时，从“为什么学习”、“学习方法论”、“系列重要讲话的内在结构”、“系列重要讲话的读本”等六个方面进行了详细阐述。在解读习近平总书记治国理政新思想时，用“领子（责任当担）、扣子（核心价值）、鞋子（特色道路）、身子（打铁要自身硬）、位子（执政为民）”形象地概括出系列重要讲话的重大意义、核心要义、精神实质和科学内涵。

刘社欣教授还从“为什么要有中国梦”、“中国梦到底是什么”、“中国梦如何实现”等三个方面对“实现中华民族伟大复兴的中国梦”进行了独特的解读，指出“中国梦”就是“实现中华民族的伟大复兴”、“实现国家富强、民族振兴、人民幸福”。

在学习总结中，党委书记王卫平同志强调，大家要从刘社欣教授精彩报告中得到启发，进一步自觉深入学习领会习近平总书记的系列重要讲话精神，率先垂范，为实现伟大的“中国梦”尽到自己最大的努力。
