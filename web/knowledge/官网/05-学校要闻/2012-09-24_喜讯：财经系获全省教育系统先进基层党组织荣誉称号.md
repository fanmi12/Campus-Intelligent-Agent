# 喜讯：财经系获全省教育系统先进基层党组织荣誉称号

近日，中共广东省委教育工委下文对全省教育系统创先争优先进基层党组织、优秀共产党员等进行表彰，我院财经系党总支荣获全省教育系统创先争优先进基层党组织称号。

在创先争优活动中，财经系党总支在党员教育管理中注重创新模式，建立了《理想与青春共成长》“六个一工程”、入党积极分子思想汇报检查制度、班级党务工作指导员制度等多项制度，健全了党员长效教育机制，并扎实推进，取得了良好的效果。2010年，该总支曾获得城市学院十大工作创新奖。
