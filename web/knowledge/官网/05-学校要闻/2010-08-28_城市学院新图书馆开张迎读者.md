# 城市学院新图书馆开张迎读者

气势宏伟的图书信息中心大楼

以春夏秋冬四季色彩为主题装修布置的阅览区彰显自然气息

楼层之间相互连通，方便读者自由阅览

舒适明亮的自习区有近千个座位，满足学生的自习需求

自助还书机提供24小时全天候还书服务8月28日，城市学院新图书馆开馆，迎接读者。

据悉，新图书馆位于图书信息中心大楼7楼至13楼，馆舍面积约2万平方米，阅览座位2000个。8楼为图书馆总出入口，读者可在馆内各楼层自由选择阅览，图书馆工作人员在各阅览区为读者提供各种服务，让读者在馆内充分享受阅读的快乐。新馆内部各层分别以春夏秋冬四季色彩为主题进行装修布置，彰显自然气息。

新馆每天的开放时间为8：30至22：00，自习区24小时全天候开放。
