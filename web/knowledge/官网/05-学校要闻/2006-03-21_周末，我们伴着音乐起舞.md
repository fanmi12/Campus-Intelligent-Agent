# 周末，我们伴着音乐起舞

3月17日，在学生活动中心，我院师生伴着富有节奏的音乐翩翩起舞。整个舞池充满了爽朗的笑声，这是星期五晚上出现的令人陶醉的一幕。

20：00分，城市学院周末舞会正式拉开其神秘的面纱。这是周末舞会的第一次亮相。当晚，学生活动中心人头涌动，许多师生都慕名而来。学院为了让舞会更好的举行，特地请来了两位专业的舞蹈老师，在舞会现场教大家跳交谊舞。

当音乐响起，一些“舞”林高手早已欢快的起舞，而另一些舞技稍差或还没学过舞蹈的人则在老师的带领下，认真的练习基本功。虽然有些跳得并不是很好看，甚至显得笨拙，但跳舞者却完全乐在其中，而一边看热闹的师生也是大饱眼福，一副跃跃欲试的样子。于是，舞场的人越来越多，有朝气蓬勃的学生，有舞步成熟优雅的年轻教师，也有头发灰白的教师夫妇。

据悉，我院为丰富师生的文娱生活，以后的每周五晚上，都会举行这样的周末舞会。希望广大师生能积极投入到这个舞会中来。就像舞蹈老师所说：放开自我，让我们伴着音乐起舞。
