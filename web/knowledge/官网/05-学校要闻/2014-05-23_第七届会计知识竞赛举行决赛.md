# 第七届会计知识竞赛举行决赛

5月21日，我院会计知识竞赛决赛在综合馆拉开帷幕。东莞理工学院城市学院院长杨敏林、副院长高香林、财经系主任罗卫国、学生处副处长杜鹏举等领导出席并观看了比赛。

会计知识文化月是我院“科技艺术文化节”活动内容之一，也是一项富有城院特色的品牌活动，至今已举办了七届。

财经系主任罗卫国教授为比赛致辞。他表示，会计知识文化月活动的开展，不仅为城院学生提供了一个展示才智的平台，更为校园文化生活增添了新的内容，受到同学们的热捧，每年参赛的选手达500多人。

决赛共有7支队伍进入决赛，分为有问必答、急速抢答、点钞、计算技能比拼等7个环节进行。选手们认真准备，默契配合，比赛十分激烈。

在开场的有问必答环节中，28名选手全部回答正确，七支队伍打成平手，充分展现了丰富的财务知识和扎实的专业基础。点钞环节更是精彩不断，选手在赛前经过专业老师的指导、训练，点钞既快且准，被主持人调侃为“点钞机器”。

最终七队“冲锋队”以370分的总分夺冠，二队“名会天下”，一号“实战部队”分获二三名。三队“攻心计”以网络投票1016票拿下“最受欢迎团队奖”。

据悉，28名选手分别来自政法系、机电系、文传系、计信系和管理系，管理系获得会计知识竞赛最佳组织奖。
