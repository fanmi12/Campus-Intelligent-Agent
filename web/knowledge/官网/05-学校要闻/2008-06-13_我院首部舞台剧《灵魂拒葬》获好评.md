# 我院首部舞台剧《灵魂拒葬》获好评

“我只不过是死了”这句常人很难说出口的话在《灵魂拒葬》这部舞台剧中多次地以肢体语言出现。

6月12日，由我院文学与艺术系05级影视表演班表演的话剧《灵魂拒葬》在大礼堂上演。院长安少华教授，党委书记朱志德，文学与艺术系主任陈庆祝博士等领导嘉宾饶有兴致地观看了演出。

这部《灵魂拒葬》记录的是一个阵亡士兵拒绝埋葬的故事。一开场的紧张气氛就把观众带进战争的情境中，六个美国士兵持枪冲出舞台，四处“开枪”。突然“轰”的一声巨响，他们被炸死了。随后的一幕是一个上尉与士兵正要埋葬六个阵亡士兵的场面。不料这六个士兵突然站立起来并发出心声：“拒绝埋葬！”

上尉把这件事上报将军，而将军不顾一切地要马上埋葬他们，原因是将军出卖了他们，使他们被自己军队的炮弹击中而亡，这也正是他们不愿被埋葬的理由。

接下来，上演的一幕幕士兵的家人劝葬的6段剧情中，除了催人泪下的一段段对白外，演员们还展现出他们的舞蹈才能，恰恰、探戈、芭蕾以及现代舞使得他们的表演生动丰富，台下不时响起阵阵掌声。

据文学与艺术系马新川教授介绍，这部舞台剧是由一个美国反战作家创作，剧中不但表现出强烈的反战情绪，而且体现出男子汉的阳刚之气，极具震撼力，演员们对剧情的把握和表演极富张力。
