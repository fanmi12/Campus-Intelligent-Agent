# 理性表达爱国热情，集中精力搞好学习

4月20日以来，各系部相继召开党团员、学生干部会议，发动和依靠党团员及学生干部带领同学自学维护社会稳定，集中精力搞好学习，以优异的学习成绩报效祖国和人民。

社科系主任陈丁堂教授在该系学生干部会议上指出，广大学生要充分认识以达赖为首的藏独势力的分裂行径和打砸抢烧的不法罪行，更应该认清我们的根本利益，保持理性、清醒的政治头脑。不仅要有拳拳的爱国之心，还要有有容乃大的宽广胸怀。许多学生表示，激情加理性才是表达爱国热情的正确态度，要将爱国情感化为踏实工作、锐意进取、一心一意搞好学习的决心与行动。
