# 我院第二届董事会第7次会议顺利召开

7月2日上午，东莞理工学院城市学院第二届董事会第7次会议在新校区法商楼一楼会议室顺利召开。董事长麦照容、副董事长杨晓西及董事会成员出席了会议。

会议由麦照容董事长主持。

经过讨论研究，会议通过了《东莞理工学院城市学院章程》。章程明确，“坚持教育作为公益性事业，坚持追求卓越服务地方的理念，努力以一流的规划、一流的校园、一流的管理，推动城市学院建成国内一流的、服务东莞乃至全国社会经济发展的独立学院。”

会议还听取了院长杨敏林关于“城市学院2012年上半年工作总结及下阶段工作展望”的工作报告，肯定了上半年来学院的各项工作所取得的成绩,重点讨论、研究了校区搬迁工作中遇到的难点。要求在确保“稳定”的大前提下，做好搬迁工作，加快协调工程建设进度，确保下学期教学所需的实验室建设；尽快出台新校区教职工福利住房政策及加强生活配套建设；理顺治校结构，完善院长负责制，实现平稳过渡。

会议同意张琮辞去董事会秘书的职务，由黎建烨董事兼任董事会秘书职务，开展相关工作。
