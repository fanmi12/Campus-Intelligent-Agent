# 东莞市老领导莅临我院参观指导

2月13日下午，新学期伊始，原东莞市人大常委会副主任罗慧贻、张顺彩、李秀冰，原东莞市政协副主席周文媛、陈文敏等五位市老领导莅临我院新校区参观访问，受到东莞理工学院党委书记周致纳、副书记黄碧莲，东莞理工学院城市学院董事长麦照容、董事黎建烨、副院长杨敏林及新校区管委会领导的热情接待。

宾主双方在法商大楼一楼会议室举行了座谈，黄碧莲主持了座谈会。黄碧莲首先代表东莞理工学院及城市学院,对五位德高望重的前东莞政界巾帼精英的到来，表示热烈欢迎，并感谢各位老领导对两校的关心和支持。黄碧莲说，城市学院新校区能取得今天的成绩，离不开东莞市委、市政府和各级领导的大力支持。正因如此，刘志庚副省长去年在任东莞市委书记时曾两度亲临新校区建设现场调研，并盛赞其建设为“东莞速度”！

随后，五位老领导听取杨敏林副院长关于城市学院的发展历程后，对新校区的建设大为赞叹，称“不简单”、“不容易”！

张顺彩还深情地回忆起，当年举办东莞理工学院松山湖校区及利用莞城老校区举办城市学院的情景，表示城市学院的发展拥有良好的基础，也赢得了良好的社会口碑和知名度。而今新校区的建设也体现了“天时、地利、人和”，东莞理工学院与广东鸿发投资集团有限公司的强强合作，更是体现了东莞所办的大学“一所比一所漂亮”。

同时，五位老领导还对广东鸿发投资集团有限公司和麦彦桐先生及其家族为东莞公益事业和教育事业所做的贡献，致以崇高的敬意，盛赞麦彦桐先生此举功德无量。

座谈会后，五位老领导还参观了新校区。
