# 学院党委对年度党建工作开展量化考评

5月17、18日，学院党委对全院18个党总支（直属支部）2009－2010学年度党建工作进行量化考评。党委书记朱志德、副书记朱冰参加了考评。

考评分为系部、机关与教辅两个组进行。考评的内容是2009-2010学年度各党总支（直属支部）班子建设、党员学习教育、发展党员工作、日常管理工作、党员活动室建设、分党校建设六个方面。考评方法是交叉检查、打分。

党委书记朱志德参加了机关和教辅组的考评，副书记朱冰参加了系部组的考评。在考评中，考评组先听取各单位的工作汇报，然后重点检查有关基础资料的准备、收集、整理情况和落实党委的工作安排情况，并对部分单位在会议记录、发展党员、资料整理等基础工作方面存在的不足提出整改意见。

朱志德书记和朱冰副书记分别指出，实施基层党组织工作量化考评活动三年来，我院党建工作取得了长足的进步，基础工作越来越规范，学习、活动资料保存完整，各单位党组织有效地完成了党委的各项工作部署，发挥了越来越重要的作用。希望各总支（直属支部）继续努力，取得更大的进步。各党总支（直属支部）负责人作为本单位党建工作第一责任人，要常抓不懈，使我院党建工作迈上新的台阶。

各党总支（直属支部）负责人全程参加了考评。

据悉，学院党委将在纪念建党89周年活动中，对在此次考评工作中取得优异成绩的单位予以表彰奖励。
