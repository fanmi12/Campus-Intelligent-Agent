# 程发良副院长到城市与环境科学系检查指导工作

11月24日，副院长程发良教授深入城市与环境科学系检查指导工作，并召开教师座谈会听取意见。

座谈会上，系副主任孙成访博士向程副院长汇报了教学科研、人才培养计划的制订等方面的工作，以及近期和期末工作的安排与打算。

程副院长肯定了城市与环境科学系建系以来的各项工作，并对今后的工作提出了要求。他指出，在新的形势下，城市学院以及城市与环境科学系的发展面临着诸多机遇与挑战。虽然城环系组建不久，教师少，年龄结构偏轻，但各项工作已步入正轨，来势非常好。他还结合自己的成长经历，鼓励年轻教师一要做好本职工作，努力提高教学水平，认真上好每一堂课，站稳讲台；二要结合专业，积极申报科研项目，努力参与科研活动，全面提升自身素质，力争成为一名优秀的高校教师。

孙成访博士代表全系老师表示，一定认真贯彻落实学院领导的指示，不辜负学生的期望，发挥团队精神，努力工作，出色完成院领导交办的各项任务，力争使城环系的工作更上一层楼。
