# [科技文化艺术节]首届“鸿发杯”“我是辩手”辩论赛总决赛完满落幕

6月6日，团委主办、文传系承办的首届“鸿发杯”“我是辩手”辩论赛总决赛在学术报告厅隆重举行。鸿发教育有限公司副总经理刘玉侠、学院党委宣传部部长何鹏举、文传系主任邓星明莅临比赛现场。

辩论赛总决赛分为季军争夺赛以及冠亚军争夺赛两场。季军争夺赛的两支队伍都是文传系的，正方“倾城之辩”和反方“梦之队”双方围绕“自媒体时代，我们离真相越来越远还是越来越近”的辩题展开了精彩的辩论，双方辩手观点独特，妙语连珠，让观众拍手称赞。冠亚军争夺赛正方为金贸系“LOL”队、反方为城环系“绿色卫士”队，他们的辩题是“城市发展趋势将更多体现人类文明的趋同性还是差异性”。双方针锋相对、步步逼近，让现场气氛迅速升温，观众热烈的掌声将现场气氛推向了高潮。最后，金贸系LOL队夺得桂冠，城环系绿色卫士和文传系倾城之辩分别夺得亚、季军。

“鸿发杯”“我是辩手”辩论赛在鸿发教育公司的鼎力支持下自4月10日拉开帷幕，历时2个月，在各系部的热情参与和大力支持下画上了圆满的句号。本次辩论赛为同学们提供了一个展现自我，锻炼自我的平台，充分体现我院学子严谨的逻辑思维能力和较强的口头表达能力。
