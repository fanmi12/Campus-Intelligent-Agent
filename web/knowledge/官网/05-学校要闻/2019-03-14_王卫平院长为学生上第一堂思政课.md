# 王卫平院长为学生上第一堂思政课

3月14日上午，王卫平院长在教学楼7A308为2016级金融学专业的同学们上了一堂生动有趣的思想政治理论课——“继承发扬革命优良传统，做新时代合格大学生”。

王卫平院长重点讲解了我党革命优良传统的典范——井冈山精神、延安精神、西柏坡精神，鼓劲同学们继承和发扬革命优良传统。

王卫平院长联系实际从“国家、社会、个人”三个层面，介绍了社会主义核心价值观的内涵。他鼓励同学们在新时代积极努力培养和践行社会主义核心价值观，做个“说话让人喜欢、做事让人感动、做人让人想念”的人，做一个新时代合格的大学生。

王卫平院长还着重介绍了粤港澳大湾区建设的有关情况和重要意义。他结合东莞和我院的实际情况，对《粤港澳大湾区发展规划纲要》进行了讲解，希望同学们积极投身到包含东莞滨海新区建设在内的粤港澳大湾区建设之中。
