# 市政协副主席邝明子一行来我院调研

9月18日，市政协副主席邝明子、朱伍坤、吕兢等一行来到我院进行调研，受到东莞理工学院党委副书记吕琦元、城市学院董事黎建烨、城市学院院长杨敏林、城市学院党委书记朱志德的热情接待。

邝明子一行先后视察了我院新生入学教育现场、图书馆和物理实验室等，并与院领导举行了座谈。副主席邝明子在听取杨敏林院长有关学院办学情况汇报后认为，城市学院校园环境优美，师资队伍精干，现代化教学设备齐全，教学管理规范，成为了众多学子心目中的理想高校。市委、市政府、市政协对城市学院的发展一直非常重视，也非常支持。城市学院也不负众望，培养出来了东莞企业最需要、最适用的人才，对推动东莞经济、社会的发展起到了重要的作用。学院一半以上的学生是东莞籍，为东莞人子女提供了上大学的平台。邝明子等政协领导鼓励城市学院再接再厉，办成百年名校，为东莞人民造福。
