# 城市学院庆祝教师节篮球赛

体育教工队

教师联队

昨天晚上，我院体育教工队与院教师联队进行了一场激烈又精彩的篮球赛。上半场，体工队以27比4遥遥领先。下半场，联队改变打法，连连得分，一路紧追，打成平局后，又以34比32领先体工队。联队因身高不如对方，最终以2分之差屈居第二名。昨晚的篮球赛，为教师节增添了浓浓的节日气氛。
