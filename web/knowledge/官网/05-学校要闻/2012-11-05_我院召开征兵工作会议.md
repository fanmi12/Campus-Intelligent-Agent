# 我院召开征兵工作会议

10月29日，我院2012年冬季征兵工作会议在学生活动中心会议室举行，学生处副处长杜鹏举、孔增强、各系部总支副书记、辅导员参加了会议。

据介绍，今冬征兵的政策与往年略有不同。根据去年新修改的《兵役法》，从今冬起，国家取消了非农业户口青年征集比例限制。此外，有意向报名参军的学生必须先登录网址（http://zbbm.chsi.cn）在网上报名。入学前属东莞市生源的男生，应回各镇（街）报名，外地生源（包含入学后将户口转入本院）的男生可在原户籍地或学院报名应征。入学前属东莞市生源的女生，应在镇（街）和学院同时报名，外地生源（包含入学后户口转入本院）的女生可在原户籍地或学院报名应征。报名时间从即日起至11月6日下午17时止。在网上填写的时候，要填写真实有效的资料，同时打印《应征入伍高校毕业生补偿学费代偿国家助学贷款申请表》和《应征入伍高校在校学生补偿国家助学贷款申请表》。年龄方面，高职（专科）毕业生征集年龄可放宽至23周岁，本科级以上学历毕业生可放宽至24周岁。目前，网上征兵报名工作已全面展开。

会上，杜鹏举副处长就今年的征兵工作做了部署，他强调说，今年的征兵工作时间紧、任务重，征兵报名时间从即日起至11月6日截止，11月7日早上八点在饭堂一楼集中出发到东莞理工学院体检。各系（部）要重视今冬征兵工作，认真履行职责，做到不误时不误事，全力以赴抓好征兵工作，确保征兵工作安全、顺利、圆满完成。
