# 院领导与教授博士共谋学院发展大计

座谈会上各位新调(聘)进的教授、博士在作自我介绍

院领导在介绍学院定位，办学理念以及科研项目等情况3月15日，学院在315会议室召开座谈会，认真听取新调(聘)进的教授、博士对我院的意见和建议。

东莞理工学院城市学院院长安少华教授，党委书记朱志德，常务副院长程发良教授，副院长林世俊教授到会并发表讲话。

计算机与信息科学系党支部书记廉玉忠教授代表新进教授和博士首先发言。他说，城市学院是一所充满生机与活力、前景美好诱人的学院。这里的校风、学风、教风非常好，规章制度健全，学生虚心好学，学院领导班子团结务实。我们一定认真教书，精心育人，不断学习，更新知识，把爱心和知识奉献给学生，把毕生精力贡献给学院。廉教授还就工作、生活上的问题发表了意见。

院长安少华教授在讲话中首先表示，欢迎大家从祖国的四面八方来到城市学院，为了一个共同的目标走到一起来了。希望大家尽快融入到这个学院，融入到东莞这座城市，尽快适应这里的生活、学习和工作环境，共同把学院办好。要深入基层，到企业和乡镇去，到学生中去，紧密结合东莞和珠三角地区的实际开展课题研究。要以人为本，以德为先，为人师表，做教师的榜样，做学术上的带头人。

院领导还向教授、博士详细介绍了学院定位，办学理念、科研项目申报程序和东莞经济社会发展情况。
