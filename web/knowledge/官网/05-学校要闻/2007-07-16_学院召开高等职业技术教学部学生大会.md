# 学院召开高等职业技术教学部学生大会

为加强高等职业技术教学与管理工作，近日学院做出决定，成立城市学院高等职业技术教学部。7月13日，学院在学术报告厅召开高等职业技术教学部学生大会。东莞理工学院副院长、城市学院院长安少华教授，学术副院长程发良教授，学院党委副书记朱冰，教务处处长邓成良教授，学生处处长章德胜副教授，高等职业技术教学部党支部书记黄研晖，高等职业技术教学部负责人谢俊高级工程师出席了会议。会议由高职部党支书记黄研晖主持。

安院长在会上发表讲话，他说，学院十分重视高职层次的学生培养工作，成立高职部后，教学工作中的理论课仍然由所属系承担，实践技能课由高职部承担；高职教学要因材施教，相应调整教学管理模式，培养适合东莞经济社会双转型发展需要的“高级技能型人才”。安院长希望高职部的同学们正确理解学院的决策意图，共同努力打造城市学院高职教育的品牌。
