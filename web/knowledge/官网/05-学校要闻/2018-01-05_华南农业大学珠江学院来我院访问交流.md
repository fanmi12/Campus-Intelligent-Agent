# 华南农业大学珠江学院来我院访问交流

1月4日，华南农业大学珠江学院副校长林伟初一行12人来我院访问交流。副院长高香林、院长助理林江龙和有关单位负责人热情接待了客人。

双方就我院

商科虚拟仿真实践教学中心

建设等情况，进行了交流、研讨。高香林副院长、财经系主任罗卫国、管理系主任张佺举和商科实训教研主任黄庆泉老师，分别向来宾介绍了我院商科虚拟仿真实践教学中心的筹备过程、建设规模、功能作用，以及教学理念、教学目标等情况。

林伟初副校长肯定了我院商科虚拟仿真实践教学中心的建设经验和成绩，并希望两校之间保持

长期交流、学习，促进

共同发展。
