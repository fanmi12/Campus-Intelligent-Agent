# 校园涌动献血爱心热潮

24日下午4点，我校综合馆旁献血车前，自愿参加献血活动的同学排起了长长的队伍。商务英班的林燕玲同学表示，这是她第一次和朋友一起献血，虽然有点怕，但想到献血可以促进自己的新陈代谢机能，还可以救人，甚至可以挽救别人的生命也就不怕了。

在献血现场，还有一批志愿者，他们充当着绿叶，细心呵护着献血的红花。献血的同学填写捐血表遇到不明白的地方，志愿者们都会耐心地讲解，并维持现场的秩序，使献血活动井然有序。据统计，共献血53400ml。

据悉，本次献血活动是由文传系系志愿队与东莞寮步志愿队-城市学院EM志愿分队联合承办的。
