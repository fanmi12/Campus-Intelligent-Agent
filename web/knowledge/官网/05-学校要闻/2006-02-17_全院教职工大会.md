# 全院教职工大会

东莞理工学院城市学院2005—2006学年第二学期教职工大会本月16日在5号梯形教室召开。

党委书记朱志德主持会议，常务副院长程发良教授做了关于2005年工作总结和2006年工作要点的报告。副院长林世俊教授就开学情况和如何培养学生能力问题作了发言。最后，院长安少华教授着重强调指出：要出色地完成全年的目标任务，必须牢固地树立机遇意识、竞争意识、战略意识、品牌意识和资源意识。

安院长说，城市学院正处于跨越式发展的关键时期，我们必须认清形势，瞄准目标，自加压力，乘势而上。思想是行动的先导，牢固地树立“五种意识”是为圆满完成今年的目标任务提供有力的思想保证。他进一步指出，树立机遇意识就是树立机不可失，时不我待，抢抓机遇的思想；树立竞争意识就是树立逆水行舟，不进则退，敢为人先，勇争硬拼的思想；树立战略意识就是树立高起点、高标准，科学持续发展的思想；树立品牌意识就是树立追求卓越，追求一流，创办特色的思想；树立资源意识就是善于利用、整合和转化各种资源为自身发展服务。安院长最后强调，全院每个教职工都必须用这“五种意识”统一思想，牢固地确立这种适应新形势、新任务需要的办学理念。
