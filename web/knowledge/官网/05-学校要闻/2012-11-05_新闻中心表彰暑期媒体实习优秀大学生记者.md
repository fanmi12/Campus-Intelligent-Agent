# 新闻中心表彰暑期媒体实习优秀大学生记者

今年暑假期间，我院有40名学生分别在南方日报、东莞日报、东莞时间网、南方都市报、新快报、信息时报等14家媒体进行了为期两个月的新闻采访写作实习，有629篇、70余万字的新闻稿件被有关媒体采用或刊登，为“服务东莞”作出了贡献。

10月26日，新闻中心在7B301室召开会议，对冯敬等17位优秀大学生记者进行了表彰。

新快报东莞站站长杨英杰，南方都市报东莞站新闻部副主任李月刚，文传系主任邓星明，新闻中心主任何鹏举，院团委书记罗文芳，文传系党总支部书记孟颖，《城市学院报》主编唐耀碧等出席。大学生记者团，2012级新闻传播专业的200多位同学参加了会议。

汇报会上，刘若筠等8位实习生代表分别汇报了实习体会，与大家分享了他们在实习期间的酸甜苦辣。在南方日报实习的刘若筠同学，可谓是“高产记者”，累计发稿90余篇。“实习是一件很辛苦的事，由于带我的老师很忙，好几次晚上都加班到九点，刚开始是觉得比较辛苦，不过每次出去采访都会有不同的收获，或是感动、或是兴奋，所以我要珍惜老师给我的机会”。刘若筠的发言受到大家的好评。

新快报东莞站站长杨英杰、南方都市报东莞站新闻部副主任李月刚相继发表讲话，表扬了参加暑期媒体实践的同学，肯定了学生的新闻写作采访能力，他们提醒同学学习是一个长期的过程，要参与到“全民记者行列”中去发现新闻，记录生活，他们还表示欢迎同学们以后再次赴报社实习。
