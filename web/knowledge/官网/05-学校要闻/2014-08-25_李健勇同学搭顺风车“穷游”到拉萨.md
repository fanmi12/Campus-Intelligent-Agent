# 李健勇同学搭顺风车“穷游”到拉萨

8月22日，我院李健勇同学历经23天的顺风车“穷游”平安返校，顺利完成拉萨之旅。

李健勇同学与中学同学陈旭夕于7月27日从东莞出发，一路求搭沿途的顺风车，经广州、云浮、百色、昆明、丽江、大理、香格里拉，于8月13日到达目的地拉萨。白天，他们举着写有目的地的纸牌子，招手求搭过路顺风车，夜晚露宿帐篷。

8月18日，李健勇二人乘火车返回学校。

20多天的“穷游”，历经千辛万苦，他们收获了宝贵的人生经历。

据李健勇同学介绍，搭顺风车必须要有耐心和时间去等待，以及诚实可信的学生形象与交际能力，能够感动司机并成为他们的旅伴。
