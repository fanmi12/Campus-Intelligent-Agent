# 我院隆重举行庆祝建党94周年暨表彰大会

7月1日，我院庆祝中国共产党成立94周年暨表彰大会在学术报告厅隆重举行。院领导王卫平、章德胜、高香林、黄兢、周庆、刘玉侠和党委委员杜鹏举出席大会。

大会在雄壮的国歌声中开始。大会首先举行新党员入党宣誓仪式，与会的老党员集体重温入党誓词。

随后，章德胜副书记宣读学院党委《关于表彰2014-2015学年度先进基层党组织、优秀共产党员和优秀党务工作者的决定》。据悉，财经系党总支、文学与传媒系党总支、机关二党总支、机关三党总支等分获先进基层党组织称号，赵天婵、李瑶、雷镭、韦晓霞等四人获优秀党务工作者称号，耿玉成、李响、李晓霞、林健婵等43名党员获优秀党员称号。

会上，文学与传媒系党总支书记孟颖代表获奖单位及个人发表获奖感言。

接着，党委书记王卫平作重要讲话。他首先回顾了中国共产党94年的光辉历程，以及我们党发展壮大的历史经验。接着他从群众路线教育实践活动成果、党的思想理论建设、党风廉政建设、大学生思想政治教育、“师德师风”建设等八个方面总结了我院一年来所取得的成绩。

关于今后一段时期我院党建工作的重点，王卫平书记表示，要在党员干部中深入开展“三严三实”专题教育活动；进一步加强党务干部队伍建设、创新基层党组织建设，要进一步落实党建工作责任制，勇于担当维护学院和谐稳定的政治责任。

大会在雄壮的国际歌声中结束。
