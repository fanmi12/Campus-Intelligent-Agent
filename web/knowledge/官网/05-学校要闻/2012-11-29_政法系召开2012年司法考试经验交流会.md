# 政法系召开2012年司法考试经验交流会

11月28日，政法系在莞城校区2208课室召开2012年司法考试经验交流会。系主任、党总支书记刘杰教授,法学教研室主任危兆宾博士出席会议。

系总支副书记刘军老师首先介绍了该系2012年司法考试情况。系主任刘杰教授发表讲话，他首先祝贺12位同学通过了司法考试，并鼓励10级法学同学，要向师兄师姐学习，夯实基础，刻苦努力，团结奋进，争取在2013年的司考中取得更为优异的成绩。

张木超、伍仲强、陈丽娜、温敏敏、曹回贵5位师兄师姐分别介绍了司考备战的心得和经验，为在场的同学们提出了很多宝贵的建议。
