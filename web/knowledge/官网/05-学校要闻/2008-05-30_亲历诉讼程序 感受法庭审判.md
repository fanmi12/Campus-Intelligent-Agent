# 亲历诉讼程序 感受法庭审判

5月27日，社会科学系 06级法学和文秘（法律事务）全体师生，在法学教研室李奕老师的带领下到东莞市中级人民法院旁听庭审。

庭审开始前，主审法官提醒同学们要有目的、有重点的旁听，他说庭审要认定事实的证据，依照情节依法量刑，同时还要重视在庭审中告诉被告人所享有的相关权利的作用和意义。

本次审理的是一起刑事诉讼案件，同学们亲身经历了整个刑事诉讼庭审的程序。

现场观摩后，许多同学表示，旁听庭审使我们提高学习的实效性，也对即将举行的学院模拟法庭的“庭审”充满了信心。
