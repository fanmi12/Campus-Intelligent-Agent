# 我校召开2019-2020学年经费预算下达会议

11月5日下午，我校2019-2020学年经费预算下达会议在行政楼212会议室召开。校长王卫平、党委书记章德胜、副校长周庆和各单位负责人等出席了会议。

财务处处长余竹根主持会议，并对2019-2020学年的预算编制工作进行了汇报，对预算执行过程中可能出现的问题进行了解答。

副校长周庆指出，本次预算工作抓住重点、突出特色，提高了预算编制质量和效率。她强调，专项经费必须专款专用，集中有限财力保证重点任务的完成。预算在执行过程中要坚持“先预算后支出”的原则，强化预算执行的刚性和柔性。

党委书记章德胜要求，各单位认真贯彻“中央的八项规定”精神，禁止设立“小金库”，严格遵守学校的财务规章制度，反对铺张浪费。

校长王卫平总结强调，各单位在经费使用时要做到围绕绩效目标，强化预算意识，统筹兼顾，保证重点，突出特色，提高预算的执行效率。
