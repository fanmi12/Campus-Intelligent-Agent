# 我校举行“不忘初心、牢记使命”主题教育 专题学习会

9月29日上午，我校在行政楼212会议室举行“不忘初心、牢记使命”主题教育专题学习会。东莞市委主题教育第十一指导组组长卢淑贤及小组成员，学校主题教育领导小组成员参加了专题学习会。学习会由学校党委书记章德胜同志主持。

我校马克思主义学院党支部书记史雍真作了《共产党人的初心和使命》专题讲座。她从三个方面，深入阐述了共产党人的初心和使命就是“为中国人民谋幸福，为中华民族谋复兴”。

会议进行了“习近平总书记关于初心使命的重要论述”专题学习，学校领导班子成员分别汇报了自己的学习心得与思考。

党委书记章德胜以《把政治建设摆在首位，不断增强“四个意识”、坚定“四个自信”、做到“两个维护”》为题讲述了自己的学习收获和心得。他指出，学校领导干部要始终把政治建设摆在首位，要在党的政治建设上做表率，要带头树立牢固的政治理想、坚定的政治信念，要带头严明党的政治纪律、政治规矩，推动党的团结，要带头严肃党内政治生活、促进党内政治生态建设。

校长王卫平以《勇于自我革命，同一切影响党的先进性、弱化党的纯洁性的问题作坚决的斗争》，回顾了我党延安整风运动的主要精神和成绩，重申了“四个自我”、“五个力戒”，结合实际，号召全校党员密切联系广大师生群众，勇于自我革命，同一切影响党的先进性、弱化党的纯洁性的问题进行坚决斗争。

副校长高香林以《新时代要有新气象、更有新作为》为题，表示自己通过学习心里越来越清晰、越来越明亮，并鼓励师生做新时代的奋斗者，让自己的梦想大放光彩。

副校长黄兢以《中国共产党人的初心和使命，就是为中国人民谋幸福，为中华民族谋复兴》为题，指出我党的初心和使命是与西方政党的根本区别,并号召广大党员干部坚持立德树人，“以本为本”，办人民满意的大学。

副校长刘玉侠以《坚决整治形式主义、官僚主义，加强真抓实干的作风建设》为题，指出学校进入内涵式建设关键时期，要坚持问题导向，切实抓好作风建设。

党委委员杜鹏举以《坚持以人民为中心，把群众观点和群众路线深深植根于思想中、具体落实到行动中》为题，希望广大党员干部深入师生群众，以师生为中心，查找问题，着力解决师生群众的困难和问题，提高师生的满意度和获得感。

章德胜书记在总结时强调，深入开展“不忘初心、牢记使命”主题教育要紧紧围绕“守初心、担使命、找差距、抓落实”的总体要求，紧扣立德树人的根本任务，坚持边学习、边调研、边检视问题、边改进工作。各级党组织要尽快制定和启动主题教育方案，让包括学生党员在内的党员干部群众感受到主题教育取得实实在在的成效。
