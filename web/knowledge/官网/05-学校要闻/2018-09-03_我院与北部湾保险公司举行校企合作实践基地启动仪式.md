# 我院与北部湾保险公司举行校企合作实践基地启动仪式

9月3日上午，我院和北部湾财产保险股份有限公司强化校企合作共建的实践基地举行了启动暨揭牌仪式。

出席仪式的嘉宾有：广西壮族自治区政府驻广州办事处副巡视员莫育敏、广东鸿发投资集团董事长助理麦子俊、广东鸿发教育文化集团有限公司总经理陈超群、广东鸿发投资集团总裁助理兼投资部总监陈俊恺、北部湾保险公司董事长黄英钊、北部湾保险广东省分公司总经理詹科级等。我院领导王卫平、章德胜、高香林、黄兢、周庆、林江龙等出席了启动仪式。

王卫平院长指出，我院在2007年率先设立了保险学专业，是广东省17所独立学院中唯一设有保险专业的高校。为了创新保险专业的教育教学模式，今年年初，我院与北部湾保险公司签订了合作协议，共建实践基地。学生在老师和公司业务人员的共同指导下，理论结合实践，主动面向市场，经过四年的培养后直接实现了毕业与上岗的无缝对接。

王卫平院长表示，学校要上水平，创特色，离不开企业的支持。企业要发展，要创新，也需要学校提供人才。希望校企双方能够以实践基地为合作平台，不断在人才培养、师资培训、培训课程开发，以及保险科技研发上开展广泛合作，取得更为丰硕的成果。

黄英钊董事长在发言中，希望同学们能利用好这个平台，更好地将理论与实践相结合，不断开阔视野、提高自身综合素质，努力成为未来保险业的栋梁之才。他还希望通过大家的共同努力，把基地办实、办好、办出成效，实现互利共赢。

莫育敏副巡视员强调了保险对人们生产、生活方面的重要性，表示“有保险，人生才有尊严”。他希望同学们通过这个平台，能学得更多的保险知识和本领。他勉励校企双方通过资源互补、发挥各自优势，努力促进学生就业和成才，为社会经济发展作出贡献。

与会嘉宾和领导为校企合作实践基地进行了启动和揭牌仪式，并参观了实践基地和校园。

启动仪式活动还举行了舞狮、文艺等表演。

此次双方打造的实践基地具有仿真实际业务流程等特色。学生在校园开展仿真系统的保险营销管理实践，在老师和北部湾保险业务人员指导下，与客户面对面地沟通，通过保险方案设计、录入仿真系统、最终生成仿真保单。双方创新零距离就业能力培养模式，为培养优秀的保险专业人才开辟新路。据了解，此项仿真业务实践操作在全国本科院校保险专业中尚属首例。

据介绍，北部湾财产保险股份有限公司是在广西壮族自治区党委、政府的大力推动支持下，由广西金融投资集团，联合广东鸿发投资集团、武钢集团等区内外共13家大型企业共同发起的广西首家全国性法人保险机构。目前市场份额在全国87家财险公司中居第32位。
