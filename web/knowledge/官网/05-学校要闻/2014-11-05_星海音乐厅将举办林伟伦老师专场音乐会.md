# 星海音乐厅将举办林伟伦老师专场音乐会

广东省星海音乐厅、广东星海演艺集团将于11月29日晚在星海音乐厅举行林伟伦老师专场独唱音乐会。

据介绍，星海音乐厅是亚洲最重要的高雅音乐殿堂之一，以我国人民音乐家冼星海的名字命名的，也是众多国内外名团名家在中国演出的首选场馆。自1998年启用以来，星海音乐厅对演出者及曲目的挑选要求非常严谨。

林伟伦老师是我院艺术系音乐学讲师，声乐演员，中国声乐家协会会员，中国合唱协会会员，中国艺术医学协会会员，中国教育改革研究会高级会员，《中国教育改革论丛》副主编，广东省音乐家协会会员，广东省合唱协会会员。2000年考入星海音乐学院，师从流行音乐系主任罗洪教授、国家一级指挥陶文华。2002年，应邀为广东省星海音乐厅创办流行歌曲精品欣赏会，开创了流行唱法进入古典音乐殿堂的先河。

据悉，近几年星海音乐厅举办流行音乐专场会的不多，曾经举办过个人专场音乐会的只有李海鹰、林一峰、张敬轩、东山少爷、陈秋虹等。

在这次专场音乐会上，林伟伦老师将演唱16首歌曲，魏文超、彭雨菲、陈昊男等流行乐坛实力派歌手担任演出嘉宾。星海音乐厅位于广州市二沙岛。演出门票由星海音乐厅票务中心和广东文化票务网公开发售。欢迎我院乐迷们前往欣赏点赞。
