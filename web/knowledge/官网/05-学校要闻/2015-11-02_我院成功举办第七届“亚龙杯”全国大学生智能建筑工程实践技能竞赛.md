# 我院成功举办第七届“亚龙杯”全国大学生智能建筑工程实践技能竞赛

10月30日至11月1日，由住建部高等学校建筑电气与智能化学科专业指导委员会主办、我院与东莞市高技能公共实训中心共同承办、浙江亚龙教育装备股份有限公司和苏州浩辰软件股份有限公司共同协办的第七届“亚龙杯”全国大学生智能建筑工程实践技能竞赛在我院成功举行。来自清华大学、南京工业大学、西安建筑科技大学、北京建筑大学、广州大学等全国41所高校的代表队参加了本次比赛。本次技能竞赛包括硬件实操、软件设计等二部分，旨在考核选手们的实践能力和创新能力。

本次大赛中，我院派出了由李文栋、江炜轩、王登威、黄耀强、戴士集等五位同学组成的代表队，指导老师是李洪超博士、贺婉茹老师，并最终获得团体一等奖，江炜轩同学获得建筑电气设计二等奖。获得本次竞赛团体特等奖的是西安建筑科技大学代表队，获得团体一等奖的还有安徽建筑大学、华东交通大学代表队；安徽建筑大学城市建设学院、吉林建筑大学、吉林建筑大学城建学院、山东建筑大学、浙江科技学院以及苏州科技学院代表队获得团体二等奖；西安建筑科技大学华清学院、金陵科技学院、南京工业大学、郑州轻工业学院代表队获得三等奖。

住建部人事司何志方处长、广东省教育厅高等教育处郑文处长、高等学校建筑电气与智能化学科专业指导委员会主任委员、安徽建筑大学校长方潜生教授、城市学院党委书记王卫平教授和副院长高香林教授等领导嘉宾出席了颁奖典礼。

我院党委书记王卫平教授在颁奖典礼上发表了热情洋溢的致辞。安徽建筑大学校长方潜生教授在讲话中对41个参赛团队的积极参与给予肯定，点赞大赛为热爱智能建筑工程实践技能的学生搭建了一个良好的学习与交流平台，并称“亚龙杯”已成为本学科专业上的靓丽名片，希望大家继续努力，把这个名片打造成精品。

本次技能竞赛期间，组委会还安排了相关专业专家教授参加的学术论坛，对提高智能建筑相关专业的教育教学质量，对推动产学研合作，起到了积极的推动作用。
