# 【众志成城 抗击疫情】致全体师生的公开信

全校教职员工、同学们：根据上级要求，为了应对疫情发展的严峻形势，共同维护健康与生命安全，特向全校师生员工发出公开信，希望大家共同履行：

一、积极配合疫情防控工作。全体师生员工要认真做好自身防范，保持个人通信畅通，及时了解学校相关信息。配合工作人员的数据信息统计工作，准确填报个人相关信息，及时报告自身身体状况，全力配合学校做好疫情防控各项工作。

二、全体离校师生，严禁提前返校。根据《广东省人民政府关于企业复工和学校开学时间的通知》的文件要求，我校2019-2020学年第二学期开学时间顺延至2月24日以后，具体开学时间将另行通知，请密切关注学校官方微信。 目前校园已暂停开放，禁止外来车辆和人员入内。非学校统一工作安排，教职工和学生不得提前返校。校园内住户尽量避免或减少外出，配合后勤保卫处值班人员做好登记检查，同时做好每日信息报告工作。

三、加强防护，自觉居家隔离。近期（15天以内）有在防控重点地区居住、逗留经历或与防控重点地区人员有过接触的师生，按要求向学校准确报告有关信息的同时，要按相关指引主动居家隔离14天，居家隔离期间需每日如实向学校后勤保卫处王锦锋（联系电话：15999867089）报告体温等相关临床体征，并做好详细记录。

四、本人或者家人如被疾控部门告知为密切接触者，请保持镇定，积极配合进行医学观察，及时报告个人身体状况；如出现发热、咳嗽、乏力、干咳、气促、胸闷等不适症状，要立即自觉进行隔离观察，务必到当地政府定点医院规范就诊，并按要求报告个人接触信息和身体状况。

老师们、同学们，相信在各级党委和政府的领导下，在学校、社会、家庭和全体师生员工的共同努力下，我们一定能众志成城、战胜疫情，取得抗击疫情工作的最后胜利！

衷心祝愿全校师生员工新春快乐、幸福安康！

东莞理工学院城市学院2020年1月29日
