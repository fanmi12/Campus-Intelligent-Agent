# 思政部教师赴澳门等地考察学习

思政部老师于4月26日至27日赴澳门、珠海考察学习，参观了澳门大学横琴校区、澳门理工学院、吉林大学珠海校区、珠海市横琴新区。

在澳门大学横琴新校区，老师们在这里感受到了我国高等教育改革的新思路，通过建设澳门大学新校区，加强内地和澳门的教育和人才培养合作，服务澳门可持续发展及粤澳两地合作发展的需要，为区域长远发展提供强有力的人才支撑，探索粤澳高等教育合作新模式。

在澳门理工学院，老师们发现，学院的地方虽小，但影响却很大，超出内地的许多重点大学。澳门理工学院自特区政府成立以来，遵从“培养世纪人才，建设美好明天”的方针，采取了一系列有效措施，改进学院的各项工作。在特区政府的大力支持下，不断提高师资队伍的质素，聘请了一批具高级学位和丰富教学经验的教师任教，并对全院的课程进行了革新、完善和升级；创办、筹备了一批新的课程，建立了以本科教育为主的教学体制。

在吉林大学珠海校区，老师们和该校思政同行交流，感受到他们锐意进取，不断改革创新精神，学习他们为提高思想政治理论课教育教学的实效性采取的有效方法和思路。

老师们还对珠海、澳门的民风民情进行了实地感受，对一国两制、澳人治澳等基本政治策略有了更加深入的了解。

思政部学科带头人、院督学陈丁堂教授参加了本次活动，他认为，思政部应该多组织这样的考察活动，以加强理论和实践的结合，掌握改革开放的第一手资料，把握时代脉搏，增强理论教育的针对性和亲切感。
