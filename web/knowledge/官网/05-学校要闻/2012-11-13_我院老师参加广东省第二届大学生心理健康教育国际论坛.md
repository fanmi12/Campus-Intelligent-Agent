# 我院老师参加广东省第二届大学生心理健康教育国际论坛

11月7日至9日，学生处委派负责心理健康教育工作的辅导员徐媛媛、李响老师参加了广东省第二届大学生心理健康教育国际论坛。

此次国际论坛由广东外语外贸大学承办，广东省委教育工委副书记、省教育厅党组副书记景李虎，教育部高等学校文化素质教育指导委员会秘书长欧阳康，教育部高校心理健康教育专家指导委员会委员马建青等出席了本次会议。来自英、法、美等国的十几位知名心理学家和全国各地高校两百多名从事心理健康教育的老师参加了论坛。

据了解，论坛形式活泼，内容丰富，有主题报告、分论坛交流、专题工作坊等。国内外学者就大学生心理健康教育、心理危机干预，以及自己所研究的体会分别做了主题报告和工作坊讨论。
