# 我院隆重举行2012级新生军训汇报表演暨开学典礼

九月金秋，丹桂飘香；风云校园，军威雄壮。9月26日，我院在田径场隆重举行2012级新生开学典礼暨军训汇报表演。

出席大会的领导和嘉宾分别是：东莞军分区政治部主任叶春大校，沙角部队副司令员王书耀上校，东莞理工学院党委副书记、校长杨晓西，东莞市政府副秘书长金行中，东莞市教育局副局长黄金海，城市学院董事会及城市学院的领导黎建烨、杨敏林、朱志德、朱冰、张林、陈丁堂、章德胜、高香林。

“野蛮其体魄，文明其精神”

大会首先进行了军训汇报表演。5000名军训学生分列成50个方阵，伴随着雄壮的军乐声，昂首阔步，依次经过主席台接受检阅。接着同学们又相继进行了军体拳、旗语操等项目的表演。同学们的精神风貌和军训成果得到领导和部队首长的充分肯定。

承训部队首长、沙角部队训练部副部长周华东做军训总结。在总结报告中指出，十天来，同学们在训练中冒酷暑，顶烈日，“野蛮其体魄，文明其精神”，先后进行了队列、内务等方面的训练，接受了国防知识教育，效果非常好，完全达到了预期的目的，并涌现了一批先进集体和个人。为此，学院对他们进行了表彰。

寄语新同学：学而知不足

院长杨敏林教授在典礼仪式上讲话寄语新同学。杨院长说，明天你们就要走进教室，聆听导师的教诲，步入知识的海洋。这是你们人生中又一个新起点，将又一次燃起希望之光。希望同学们牢记和理解“学而知不足”校训。“学而知不足”校训，是诺贝尔物理学奖获得者杨振宁博士为我院亲笔题写。要使自己的知识不匮乏，唯有勤奋学习新知识，不断了解新技术，才能适应社会发展的需要，跟上时代前进的步伐。只要你们善于思考、勤奋学习、刻苦钻研，你们就会在城市学院展翅腾飞，书写人生最美好最灿烂的华章。

40名同学获116万元大礼

本次会议的又一看点是，为优秀新生颁发奖学金。据悉，杨开荣等19名同学分别获得一等奖学金，每人5万元，21名同学分别获得二等奖学金每人1万元。
