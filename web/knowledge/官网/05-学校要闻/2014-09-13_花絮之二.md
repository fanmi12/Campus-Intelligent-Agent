# 花絮之二

院贴吧最懂你，扇子送给你！

新生和家长一路舟车劳顿，终于到了学校。天气太热了，简直是汗流浃背。城院贴吧想新生所想，在综合馆门口摆设咨询摊位，为他们送上扇子，同时给新生们答疑解惑，为方便办理入学相关手续指点迷津。一个家长说道：“虽然一把小扇子不是什么大事，但却能让我们觉得消费很细心。”贴吧吧主黄粤说，扇子写有介绍贴吧的相关信息，既能让新生了解贴吧，又能起到暂时性解暑效果，所以何乐而不为呢！据统计，仅今天上午就派发出了3000把扇子。（作者：王源源 摄影：欧迪鹏）

饭堂阿姨免费供应凉茶“来，同学们，喝凉茶啦，免费的凉茶……”

刚来到荔香园，远远就听到阿姨在喊新同学们喝凉茶，阿姨对记者说，天气酷热，家长和新生们来到学校都不容易，荔香园特意在饭堂外免费送凉茶给大家解渴。其中一个家长对孩子说：“嗯，这学校挺贴心的……”“挺贴心”虽然不是什么华丽的词，但却让记者体会到家长对我们学校迎新工作的肯定。不知新生和家长们喝到凉茶的那一刻，有没有感到丝丝凉意呢？（作者：王源源 摄影：王源源）

城院校卫齐迎新

在迎新的日子里，校卫队员格外忙碌。在综合馆一楼报道门口就有这样一位校卫在主持工作，只见她穿着迷彩鞋，踏出八字步，稳住重心，每说出一句“请家长到外面休息室等候，让学生去报道”的时候，就觉得声音是从丹田处发出一样，浑厚而实在。

太阳升起来了，阳光直射着综合馆，折射出金色的光芒，也照到这位校卫的脸上和肩膀上的徽章上。汗水从额头一直流到脖子，忙得没顾上擦掉。突然，有一位家长径直进去帮孩子交学费报道，校卫快速迈出脚步，用手轻拉着家长，耐心解释道:“你好，家长是不能进去的，请你看看我们的温馨提示，大学生活是孩子步入社会的第一步，应该给他们独立完成报到的机会，麻烦您到休息处休息等候可以吗？”家长不好意思地笑了笑，止步了。

记者看到，校园里停放着几千辆大小轿车。经校卫队员与志愿者的疏导，交通畅通，井然有序。 （作者：陈欣茹）
