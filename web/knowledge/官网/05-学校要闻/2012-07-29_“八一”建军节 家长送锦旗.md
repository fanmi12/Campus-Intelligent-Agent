# “八一”建军节 家长送锦旗

英姿飒爽的邓华诗同学

邓华诗同学委托父亲为学院赠送锦旗感恩学院的培养

母校恩情永难忘。7月27日，在“八一”建军节来临之际，现服役中国人民解放军驻香港部队的我院文学与传媒系艺术设计专业邓华诗同学，不忘母校的培养和恩情，特意委托父亲从广州赶至东莞，为学院赠送了“拥军爱生、作育英才”的锦旗。学院党委副书记章德胜代表学院接受了锦旗。

邓华诗同学2011年参军入伍，在庆祝香港回归祖国15周年之际，她有幸参加了中共中央总书记、国家主席、中央军委主席胡锦涛对驻香港部队的检阅。中国人民解放军驻港部队是中国中央政府派驻香港特别行政区负责防务的军队。1997年7月1日，这支部队进驻香港特别行政区履行防务，部队由陆、海、空三军组成。
