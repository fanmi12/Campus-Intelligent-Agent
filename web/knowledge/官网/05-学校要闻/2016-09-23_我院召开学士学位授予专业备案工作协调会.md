# 我院召开学士学位授予专业备案工作协调会

9月20日下午，我院召开学士学位授予专业备案工作协调会。院长王卫平教授、研究与发展规划处赵书山处长副教授、城环系主任肖红飞教授、计信系主任廉玉忠教授、财经系主任罗卫国教授，以及各受评专业教研室主任参加会议。

赵书山处长就具体的评审备案工作，作了详细的介绍与安排。

王卫平院长指出，学院高度重视学士学位授予专业备案工作，各单位要以对学校负责、对学生负责的态度认真准备，完善相关材料，按时按质做好相关专业接受专家评审工作，力争新增专业全部通过省学位委员会的备案审核。据悉，我院“土木工程、建筑电气与智能化及财务管理”三个专业已全面开展学士学位授予专业备案准备工作，接下来将严格按照广东省学位委员会的有关要求进行备案工作。
