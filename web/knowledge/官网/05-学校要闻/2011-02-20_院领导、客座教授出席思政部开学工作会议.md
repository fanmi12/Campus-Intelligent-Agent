# 院领导、客座教授出席思政部开学工作会议

2月19日，思想政治理论教学部召开新学期首次会议，安排部署新学期的工作。海军少将、学院客座教授秦兴和将军，院领导安少华、朱志德、程发良，院督学陈丁堂出席了会议。

安院长对思政部2010年的工作给予了充分的肯定。他指出，思想政治教育工作关系学生的成长，是国家社稷大计。思政课专任老师必须要有理想、有信念、有激情，有较强的事业心和责任感。讲课时要做到普遍性与特殊性的有机结合，努力将教学与学生管理、教学规律、队伍建设、党建研究、哲学人文社会科学相结合。要注意体现思想政治教育的时代特色、地方特色、学校特色和教师自身特色，进一步提高我院的思想政治课教学水平。安院长还要求思政部做好迎接学士学位授予权评估工作和思想政治理论课专项评估工作。

会上，思政部主任何鹏举教授对去年的工作进行了回顾总结，安排部署了新学期的工作。
