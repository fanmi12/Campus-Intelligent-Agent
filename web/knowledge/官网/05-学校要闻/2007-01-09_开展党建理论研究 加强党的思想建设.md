# 开展党建理论研究 加强党的思想建设

在全院400多名党员的关注和支持下，经过几个月的紧张筹备，城市学院党建研究会于1月4日在315会议室成立。

成立大会上，中共东莞理工学院党委副书记王江水到会祝贺并发表了重要讲话，社科系主任杜鹏举副教授作党建研究会筹备工作报告。大会通过了党建研究会章程，选举产生了会长、副会长、秘书长和副秘书长，学院党委书记朱志德出任会长。会议还通报了2007年的工作计划和论文参考选题。

学院党建研究会的主要任务是，制定我院党建研究和思政工作研究规划，提出主要研究课题，组织会员进行党建和思政工作理论研讨及撰写论文，积极探索适合我院党建工作和思政工作的有效途径；研究我院党员、干部、师生员工的思想状况，及时综合、分析、归纳，为院党委决策提供党建工作和思政工作方面的信息依据，为进一步做好大学生思想政治工作提供信息支持和智力帮助；有计划地举办各种关于党建和思政工作研究的专题讲座、学术报告等活动。
