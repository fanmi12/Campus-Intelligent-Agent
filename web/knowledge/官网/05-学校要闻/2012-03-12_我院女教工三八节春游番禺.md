# 我院女教工三八节春游番禺

3月10日，院工会组织我院70余名女教工前往番禺开展为期一天的春游，庆祝国际妇女节。

当天，女老师们登上了美丽多姿的莲花山，游览了“人工无意夺天工”的石景奇观；进入了鲜花盛开的百万葵园，感受了浪漫花香的气息。城院姐妹们纷纷拿起照相机，在花的海洋中留下倩影。

院工会以“三八”国际妇女节为契机开展活动，丰富了女教工的业余生活，调整了工作节奏，使得她们能够以更充沛的精力和高昂的斗志，全身心地投入到紧张的教学工作之中。
