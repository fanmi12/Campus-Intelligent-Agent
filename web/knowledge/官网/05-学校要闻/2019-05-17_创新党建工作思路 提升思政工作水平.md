# 创新党建工作思路   提升思政工作水平

5月16日，我校召开党建与思想政治工作例会。会议现场设在广东省民办高校党建研究基地——广州华夏职业学院，学校党委书记章德胜和各党总支书记、副书记参加了会议。

此次会议是我校党建与思想政治工作进行的一次创新与探索，对会议地点、形式和内容都进行了改革尝试。章德胜书记在会上强调，学校党员干部和师生党员要坚持正确的政治方向，提高政治站位，各级党组织要创新工作方式方法，不断加强党的建设，积极做好思想政治工作，充分发挥好党组织在学校发展中的政治核心作用，努力促进学校各项事业的不断发展。

与会人员与广州华夏职业学院党政领导和相关工作人员进行了座谈，着重围绕党建与思想政治工作等方面进行了深入交流与探讨。

广州华夏职业学院校长邹建华、党委书记李曲生出席了座谈会，并介绍了学校办学、建设与发展和党建工作等有关情况和工作经验。

会议还组织大家参观考察了广州华夏职业学院党建与思想政治工作创新建设项目——华夏莲舍，以学习对方的先进工作理念、思路和方法。据了解，该项目是华夏职业学院与当地政府合作，对闲置农舍进行升级改造，并打造成为师生党员开展党建等活动与实践的平台。

会议还特别组织与会人员前往广州从化区吕田镇，参观了黄沙坑革命旧址纪念馆及东江纵队从化大队活动基地，重温革命历史，接受红色教育。
