# 广外马克思主义学院谢迪斌院长作客“城市学院科技文化论坛”

9月23日上午，广东外语外贸大学马克思主义学院院长谢迪斌教授作客“城市学院科技文化论坛”，为同学们带来一场以“历史的自责与现实的自信——党的历史与党中央治国理政新概念、新思想、新战略”的精彩讲座。

谢迪斌教授以建党95年的光辉历史为背景，介绍了我党走过的风雨历程。他列举了近代以来列强对我国发动的侵略战争，以一句“华北之大已容不下一张安静的书桌”为题引起学生的共鸣。他寄望各位同学勿忘国耻、振兴中华，做一个有理想有抱负的爱国之士。
