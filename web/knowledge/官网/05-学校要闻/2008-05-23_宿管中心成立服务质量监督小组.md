# 宿管中心成立服务质量监督小组

5月16日，学生宿舍管理服务中心在员工活动室召开服务质量监督小组成立大会。总务处章德胜处长、马兴顺副处长、各中心主任、学生处赵秋平老师、凌继峰老师、学生自律会干部代表参加了本次会议。大会由中心主任助理曾惠娴老师主持。

中心主任周衢和学生自律会主任陈逸斌同学分别就质量监督小组成立的目的、考核实施办法等作了介绍，并表示通过成立质量监督小组，将中心的各项规章制度落到实处。

章处长指出，中心在职能建设工作中取得了一些成绩，在总务处的工作中起了带头作用。希望宿管中心要加强与学生宿舍管理小组的沟通与合作，及时有效地处理了学生宿舍里的各种问题；并通过服务质量监督小组，把各项规章制度落到实处，提升学生宿舍管理服务水平，打造服务品牌。
