# 中山大学南方学院副院长郭小东教授来我院考察交流

5月8日上午，中山大学南方学院副院长郭小东教授率领该院教务部、财务部、人力资源部负责人一行4人，前来我院进行考察交流，受到院长杨敏林教授、副院长高香林教授等领导的热情接待。

宾主双方就音乐艺术专业建设有关情况，在新校区5A123会议室举行座谈会。 我院艺术系主任邓星明教授详细介绍了音乐表演的专业建设、教学安排、课程设置及师资队伍，以及艺术系多年来的定位、发展经验和成果等情况，并向客人介绍今年2月底，我院艺术类单独考试受到考生追捧的场景。郭小东副院长介绍，南方学院的音乐专业将于秋季正式招生，此行目的是向城市学院学习交流相关经验。座谈会上，双方还就发展音乐专业师资队伍建设、财务安排、教学安排等方面进行了交流、探讨。

座谈会结束后，宾主双方互赠礼物，并合影留念。
