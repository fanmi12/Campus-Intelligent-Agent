# 老领导纵论东莞高等教育及城市学院发展之路

座谈会会场

出席座谈会领导合影“社会经济发展需要人才支持，离开人才支持经济发展就困难了！”

“东莞高等教育事业发展非常快！自上世纪80年代到今天，实现了‘从无到有，从小到大，从低到高’的发展历程！”

“东莞理工学院与广东鸿发投资集团有限公司合作举办东莞理工学院城市学院，投资10多亿建设了城市学院新校区这么大、这么好的一座现代大学，非常有眼光，是件非常好的事！”

9月5日，东莞理工学院在我院新校区召开的老干部中秋座谈会上，一些老干部发表了许多见解和好的意见与祝愿。

“看到新校区的成就，我们感到非常高兴！”

中秋月圆，丹桂香飘。

东莞市政府、东莞理工学院老干部、老领导郑锦滔、姚锦柏、周文媛、张遐龄、欧阳禹湖、钟剑辉、王江水、王素其、包树元等一行，出席了座谈会。

座谈会期间，老领导们首先参观了我院新校区。当看到崭新、气派、独具特色的现代大学校园时，他们感到非常高兴。郑锦滔向大家表示，这种高兴来自内心的肺腑之言。

座谈会上，东莞理工学院党委书记周致纳对各位老领导的到来表示热烈欢迎，对老领导作出的贡献和对学院的关爱表示感谢，并向老领导表达了良好的祝愿。周致纳书记一边播放幻灯片，一边详细地向老领导介绍了东莞理工学院及城市学院的办学情况以及今年两院招生工作所取得的重大成就。

东莞理工学院校长杨晓西随后做了重要讲话，感谢老领导对学院发展的关心和支持。

“不但要建设好，更要管理好学校，培养出优秀的人才来”

在听取完周致纳书记的介绍后，老领导纷纷表示赞许，为东莞理工学院及城市学院的发展和今天的成就，感到由衷的高兴，并发表了自己的独特见解及对学院的期望。

郑锦滔在发言中，回顾了上世纪80年代未开始举办东莞理工学院的艰苦岁月，看到学院从当年“只招专、规模小”的情景发展到如今已发展成两个本科高等学院，规模翻了几倍，而由衷地感叹“东莞高等教育事业发展非常快啊！”他表示，如今东莞市的高等教育从无到有、从小到大、从低到高，为东莞的发展培养了大批人才，为东莞文化建设做出了贡献。

同时，郑锦滔还充分地肯定了城市学院新校区的建设发展成果 “不但要建设起来，还要大力办好，还要管理好，培养出优秀的人才来”，他还向在座的领导建议，发挥城市学院体制灵活的优势，向世界一流大学学习，把城市学院办成一所高水平的一流大学。

姚锦柏表示，东莞这座城市具有非常好的发展前景，社会经济得到长足发展。期待东莞理工学院及城市学院在东莞市委、市政府的重视和支持下，继续发挥在东莞高等教育界领头羊的作用，努力开创东莞高等教育事业现代化的新局面，培养更多优秀的人才。
