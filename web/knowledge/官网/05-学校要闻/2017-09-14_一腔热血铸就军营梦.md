# 一腔热血铸就军营梦

个人简介：李志伟，东莞理工学院城市学院2017级管理系物流管理专业2班的大一新生，即将到北京空军后勤某部队服役

一腔热血，让他毅然报名参军入伍。拳拳赤子之心，让他刚进大学校园又坚定地走向部队，走进军营生活。

“大学两年后可以再读，不当兵的话可能后悔一辈子！”这是我院2017级管理系物流管理专业2班新生李志伟的回答。

从高三开始，当兵的想法就在他的脑海里不断盘旋。高考结束后，他立刻报名参军入伍。但高中的学习生活十分繁忙，李志伟并没有过多的时间锻炼身体。高考结束后，为了提高自己的身体素质，达到参军的体检标准，他每天都坚持跑步，学着网络上的视频进行减脂训练。“我就是想到部队里去历练一下。一想到能够去当兵，现在还很激动，热血沸腾，可能每个男孩子都有一个军营梦吧！”

9月11日，我院新生正式军训的第两天，已入学军训的李志伟为了不影响训练，特意把手机锁在了宿舍的柜子里。但这良好的习惯却“愁坏”了远在湖北家中的父亲。当天上午，李爸爸接到当地武装部的通知，李志伟已正式成为一名军人，并要求李志伟第二日前来报到。李爸爸找到了辅导员陈文丽老师，通知他当天赶回湖北。于是，刚进入大学的李志伟又开始了自己军旅生活。

虽然，只经过短短两天的大学军训，但却给李志伟一次愉快的体验。美丽的大学校园也在他心中留下了深深的烙印。

谈及即将到来的军营生活，李志伟抑制不住激动。尽管面临高强度的新兵集训生活，李志伟表示， “军人，最重要的就是要有坚韧的品质，要能够吃苦耐劳！部队是一个很锻炼人的意志的地方，不管怎样我都一定会努力坚持。我决不是抱着玩的心态去当兵。只想做一名合格的军人，怕吃苦我就不会去当兵了！”。

李志伟对军营生活也有着明确的规划。“除了在部队里锻炼自己之外，还想抓紧时间学习努力去报考自己心仪的军校。即使不能考上军校，我也会在退伍之后回到城市学院继续学习。”

李志伟报名参军，与家人的支持密不可分。“不当兵，他会后悔一辈子的！”李志伟的父亲向记者道出了支持儿子当兵的理由。在他看来，当兵是一次难得的人生体验，不仅能为国防贡献青春，也能得到很好的历练。

李志伟即将踏上离家的旅途，前往部队报到。 “小伙子，好好干！”一句朴素而真挚的话语，深情地道出了一位父亲对儿子的殷殷期待。
