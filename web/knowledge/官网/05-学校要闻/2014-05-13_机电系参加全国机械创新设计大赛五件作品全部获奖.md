# 机电系参加全国机械创新设计大赛五件作品全部获奖

5月10日，第六届全国大学生机械创新设计大赛广东省赛区比赛在广东工业大学举行。机电系选送学生五件作品参赛，经过激烈角逐全部获奖，其中二等奖3个、三等奖2个，创机电系10年来参赛的最好佳绩。

据悉，全国大学生机械创新设计大赛是由教育部高等学校机械基础课程教学指导委员会举办、教育部和财政部联合资助的最具影响的全国性大学生竞赛项目之一。第六届全国大学生机械创新设计大赛（2014年）的主题为“幻?梦课堂”，内容为“教室用设备和教具的设计与制作”。大赛的目的是引导高等学校在教学中注重培养大学生的创新设计意识、综合设计能力与团队协作精神，提高学生创新思维、机械设计能力和工艺制作能力。由于大赛要求高，难度大，对参赛选手挑战性强，对参赛学校组织管理能力和指导老师科研能力都是极大考验，广东省赛区迎难而上的参赛学校仅29所，参赛作品共有205项。

这次参赛从准备到比赛历时一年，指导教师和参赛学生不畏辛劳、认真准备。所有参赛项目全部获奖，充分展现了机电系师生的创新能力和扎实的专业功底。
