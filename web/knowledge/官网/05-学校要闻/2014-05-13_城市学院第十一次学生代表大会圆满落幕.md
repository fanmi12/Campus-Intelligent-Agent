# 城市学院第十一次学生代表大会圆满落幕

5月10日，东莞理工学院城市学院第十一次学生代表大会在学术报告厅隆重召开。党委副书记章德胜出席会议，团市委、东莞理工学院、东莞职业技术学院、广东科技学院、广东医学院、广东创新科技职业技术学院派代表到会祝贺。

大会在庄严的国歌声中开始。章德胜副书记首先致词，他对上一届学生会的工作做了充分的肯定，对即将产生的新一届学生会提出了明确的要求，希望城院大学生在学生会的带领下，追求梦想，努力学习，奏出无愧于时代的青春乐章。

第十届院学生会干部陈琳琳和院学生会生活部部长钟启林分别作了第十届学生会的工作报告和财务报告。大会审议并表决通过了东莞理工学院城市学院学生会章程（修正案）。记者了解到，大会召开前半个月，学生代表以主人翁姿态积极撰写提案，为创建和谐校园、开创学生会工作新局面建言献策。据悉，大会共收到提案288份，学生会从中选出优秀提案在大会上作出解答。

参加竞选新一届学生会主席团的8位候选人，都精心准备了ppt，向全体代表进行了3分钟的演讲、2分钟问答，表达自己服务同学，丰富校园生活的理念和决心。学生代表用独特的视角，以提问的方式对候选人进行了现场考察。代表们优中选优，慎重投下神圣的一票，统计结果当场公布，杨仲宇、魏涵、廖彬及叶嘉敏、陈创平入选新一届学生会主席团成员。

据悉，288位学生代表统一身着正装，佩戴代表证，并在会前领取大会文件资料有序进入会场。第十届主席团成员轮流担任主持也成为大会的又一亮点。

为表彰先进、树立典范，经过院团委审核，大会还分别授予财经系、文学与传媒系、金融与贸易系“优秀系（部）学生会”称号。授予陈琳琳等45位同学“优秀学生会干部”称号，授予黄志豪等184位同学“优秀学生干事”称号。
