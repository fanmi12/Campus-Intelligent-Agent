# 金贸系学生党支部被评为省高校“三型”党支部

近日，中共广东省委教育工委公布2018年最终共确立的172个基层党支部为广东省高校学习型、服务型、创新型党支部（以下简称“三型”党支部）。其中，我院金贸系学生党支部被评选为广东省高校“学习型、服务型、创新型”党支部。

过去的一年里，金贸系对照“三型”党支部的创建评选条件，不断夯实基层党建工作基础，深入推进“两学一做”学习教育常态化、制度化，丰富活动内容，创新活动形式，拓展活动载体，使支部真正成为教育党员的学校、团结群众的核心、攻坚克难的堡垒。
