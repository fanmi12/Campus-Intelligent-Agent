# 我院举办现代教育技术专题培训

3月14日下午，我院在学术报告厅举行了现代教育技术专题培训。北京大学教育学院博士生导师赵国栋教授以《微课、MOOC与SPOC：从概念到制作技术》为题，为学院中层以上干部和任课教师们进行了培训。

赵国栋教授以生动、幽默的语言介绍了现代教育技术领域中翻转课堂、微课、MOOC和SPOC的基本概念，同时结合国内外优秀的典型设计案例，对微课、MOOC、SPOC各教学模式作详细介绍与对比。他认为，教师职业发展在互联网背景下，技术学科知识、教学知识与专业知识是教师职业发展的核心竞争力，个体网络软实力（POSP）已成为教师职业发展的新路径，教师可以利用互联网扩大个人的学术影响力。

讲座中，赵国栋教授还介绍了在国内高校已取得成功推广、认可程度较高的快课制作技术，向在座教师传授了制作微课、MOOC、SPOC的软件和制作技术。

通过培训，教师们纷纷认为参加本次培训讲座，收获颇丰，对互联网与教育技术背景下的教学方法、教学模式的改革创新有了更为深刻的新认识。

院长王卫平为赵国栋教授颁发学院教师发展中心校外教学导师聘书。人事处副处长兼教师发展中心副主任李海冬主持本次培训。
