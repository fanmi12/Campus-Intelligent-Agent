# 携手志愿者 传播正能量

3月20日，文学与传媒系志愿服务活动分享会在学术报告厅隆重举行。东莞理工学院城市学院陈丁堂督学、宣传部何鹏举部长、院报唐耀碧主编、文学与传媒系党总支孟颖书记、卢淑芳副书记、院团委李伟健老师、特邀嘉宾东莞广播电视台文艺中心张洁锋副总监及老师同学出席了此次分享会。

一段由学生录制的，反映志愿者爱心活动的视频向在场同学详尽展示了一年来文传系志愿者的活动片段。随后，卢淑芳副书记发表致辞，以一句“予人玫瑰，手留余香”表示对志愿者工作成果的认可。何文聪、陈梓凡、曾庆丽、苏泳仪四位志愿者获优秀志愿者代表荣誉称号，并与同学们分享了自己的心得感悟。

“因为被需要，所以幸福”。在这个承载爱的舞台上，参加过多次志愿活动的何文聪同学分享了他的最大收获：“Love is always the answer(爱是一切的答案)”；曾庆丽同学分享了一段她在广西支教期间与小贵锦之间关于“爱与遗憾”的感人故事：当得知眼前这个有着紫色嘴唇和手指的小孩患有先天性心脏病，志愿者第一时间着手为小贵锦寻找救助机构，在即将把这个被上帝遗忘的小孩接到广州治疗之时，却才知道小贵锦已经永远地离开我们了；文传系志愿队副队长陈梓凡在志愿服务的道路上一路寻找着“爱与诚”；充满爱心的苏泳仪通过救助流浪动物深刻体会到了，唯有去经历，才能懂得其中的纯粹。

东莞广播电视台文艺中心副总监张洁锋与志愿者们分享了属于她的“公益梦”，再一次把分享会推向了高潮。她结合亲身经历，分享了自己在志愿服务过程中的小故事，以此发出“每人心中都有一个公益梦”的感叹，并在交流互动环节中，回答了同学们提出的“如何分配日常工作与志愿服务活动的时间”、“如何进一步在生活工作中做公益”等问题。
