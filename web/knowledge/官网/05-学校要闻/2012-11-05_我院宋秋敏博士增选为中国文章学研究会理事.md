# 我院宋秋敏博士增选为中国文章学研究会理事

近日，文学与传媒系宋秋敏博士参加了中国文章学研究会会员代表大会暨第28次学术年会。此次学术年会在河北省北戴河召开，由中国文章学研究会主办，河北科技师范学院文法学院承办。大会交流研讨了文章原理研究、古代文章学研究、现当代文章学研究、文章教育研究等学术问题。

宋秋敏博士在大会上宣读了题为《论张裕钊论文书信中的的文章学观》学术论文，引起与会者的热烈讨论。在此次会议上，宋秋敏博士增选为中国文章学研究会理事。
