# 我院两歌舞节目助兴苏迪曼杯

2015年苏迪曼杯世界羽毛球混合团体锦标赛在东莞如火如荼地举行。在12日小组赛间隙，由我院艺术系自主创新的歌舞健身类节目《SUDIRMAN CUP》和《最炫小苹果》表演，为赛事增添一份靓丽色彩。

据了解，歌舞类节目《SUDIRMAN CUP》由我院艺术系杨志强老师自主创新编排，该节目紧扣赛事主题，利用羽毛球拍作为道具，并将流行舞、古典舞、民族舞有机融为一体，运用青春昂扬的旋律和激情四射的舞姿展示城市学院学生的精神风采；另一个节目《最炫小苹果》，是在国家体育总局颁布的八套健身操的基础上改编而成，既体现时代潮流，又融入自身特色。

杨志强老师介绍说，我院这两个节目在预演和预测赛中脱颖而出，获得来自中央电视台和东莞电视台导演们的青睐，并获得东莞市有关领导的特别点名赞许。

据了解，这两个歌舞健身节目还将在16日半决赛、17日决赛闭幕式上表演，为苏迪曼杯加油喝彩。
