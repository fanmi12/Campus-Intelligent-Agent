# 我院与台湾淡江大学签署交流合作协议

近日，我院继续教育中心（国际交流中心）与台湾淡江大学成人教育部分别代表两校，本着“平等互惠、优势互补、共同发展”的原则，就两校开展交流生、暑期研修班的事宜签署了合作协议。

继国立台中科技大学、台南应用科技大学、嘉南药理科技大学、台北海洋技术学院、义守大学后，我院与台湾交流合作的高校达到6所。

据悉，我院与台湾高校正在加强深度合作，除了交流生项目正在开展之外，学院拟派遣骨干教师、学院管理团队赴台湾高校进行暑期研修，充分学习台湾应用科技型大学的办学思路、专业特色和人才培养模式。嘉南药理科技大学、淡江大学校领导将于4月下旬造访我院，洽谈进一步合作事宜。
