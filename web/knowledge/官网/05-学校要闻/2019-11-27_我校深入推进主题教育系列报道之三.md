# 我校深入推进主题教育系列报道之三

问渠那得清如许，为有源头活水来 ——创意设计学院、计信学院、艺术学院开展主题教育活动掠影2019-11-27作者：贾 莘

发文单位：学校要闻

“不忘初心、牢记使命”主题教育开展以来，我校创意设计学院、计算机与信息学院、艺术学院结合实际，周密部署，坚持以目标问题为导向，深挖自身优势，把产学研、志愿者服务、内涵式学习与主题教育紧密结合，精心制定主题教育实施方案，推动主题教育取得实效。

精准发力破解课程思政难题

创意设计学院对照“为党育人、为国育才”的使命，找差距、抓落实。针对调研过程中发现学生对专业不了解、学习目标不明确、对未来感到困惑等问题，学院精准发力，依托学院自身专业技术优势，11月15日联合东江纵队纪念馆开展“情系东江革命路，薪火相传城院人”主题红色教育教学共建活动。

10月10日至25日，创意设计学院3个年级3个设计专业近900名在校生，在专业教师们的指导下，分组参观考察了东江纵队展览馆及遗址。他们先通过视、知觉的感知对东纵革命元素进行视觉化语言提炼，再与艺术设计理念融合、重组，设计出具有东纵精神和红色革命特色衍生品。创造出手机壳、明信片、体恤衫等500多套东纵主题原创产品，孵化出5个以东江红色文化元素为载体的“国潮”品牌。

在东江文创日常系列作品中：东江纵队纪念馆IP形象及卡通人物设计得形象惟妙惟肖栩栩如生；东江纵队主题印象徽章系列作品共有38枚，每个马口铁印章都是东江纵队革命先烈英勇斗争历史画面的再现；插画日历及日历卡片套盒不仅颇具东纵风格且兼顾了现代人的使用习惯；东江纵队牛皮纸袋和东江纵队革命纪录片光碟、立体纸雕组成的纪念礼盒不仅是对东纵文化内涵的发掘和观众参观游览需求的理解，更是对时代精神、流行文化的把握和共情。

创院党总支书记何帅告诉记者：通过组织开展实地调研、专家解读、师生设计、红色文创实物落地及展出等系列教学与实践活动，把东纵精神和红色革命文化元素引入设计学的基础、专业及实践课程中，让红色革命精神进课堂、进校园、进头脑，真正实现课程思政、作品思政，取得良好效果。

“主题教育”以学促做，“志愿服务”以做践学

在“不忘初心、牢记使命”主题的推动下，计信学院坚持问题导向，针对学生党支部的特点，以“志愿服务”为突破口，将主题教育与大学生坚定理想信念、积极奉献社会、精准帮扶结合起来，打造“以学促做、以做践学”深度融合发展的新模式，将学习成效迅速转化到实践中来。

计信学院师生党员每天坚持用手机APP或电脑PC等载体，加强时事政治学习。每周利用校图书馆和党务工作部下发的党报、党刊，了解党内外局势和国家发展趋势，深入学习党和国家的主要方针政策。每月组织全体师生党员集中观看红色电影，通过观影学习活动，让党员以更直观更生动的形式了解党的峥嵘岁月和发展历史，了解党全心全意为人民服务的宗旨。在每月先进人物事迹教育活动中，通过学习先进党员人物的光辉事迹，用看得见、摸得着、学得到的身边人、身边事影响和带动积极分子乃至全院学生，在全院营造出思进思上、向善向美的浓厚氛围。

服务弱势群体、彰显社会公德，结合自身技能和优势的开展多种形式的志愿活动是计信学院传统。参加志愿服务活动的频率、积极性以及力度，也是该院师生党员对自身党性和政治本色的重要要求。

学院学生党支部曾多次获得寮步镇者协会授予的优秀志愿服务单位荣誉称号。9月22日的中国沉香博物馆揭幕，9月27日“妇幼保”再出发，10月7日“爱徒.步”活动，10月23日至今每周一次的福利院“童伴”活动，11月2日慰问寮步老兵、11月15日烈士陵园纪念革命烈士扫墓等志愿活动，处处可见计信学院师生党员的身影。每次执行志愿服务任务，党员志愿者们都穿好小马甲，带上装备，热情投入。工作中他们积极配合寮步志愿协会人员，认真工作，有力的保障了每次志愿服务的顺利完成。在志愿服务的同时党员们也丰富了文化内涵，升华了精神世界。

“爱国主义是民族精神的核心，作为最具活力的当代大学生党员，既是先进文化的吸收者，也是中国未来的建设者。更应当不忘初心牢记使命，通过每次志愿服务活动深刻领悟党员的使命感和志愿者的责任感，不断成长和蜕变。现在全院上下都有一种乐于奉献不求回报，积极参与并乐在其中的氛围”，计信学院惠梦瑶老师如是说。

丰富内涵推动主题教育深入开展

为保证主题教育效果，艺术学院在学习教育的基础上，以深挖内涵为载体，有力推动师生党员主题教育往深里走、往实里走、往心里走。既立足主题教育，又聚焦爱国主义教育；既有规定动作，又考虑学生特点增加了自选动作。

艺术学院在校学生人数为学校各二级学院中最少，但因学生思想活跃，价值取向多元化，思想容易跑偏，管理难度很大。学院党总支聚焦主题，突出亮点，根据学院学生自身特点，把集中学习与自学、读原著原文学与总支委员及专家讲党课形式相结合，持续深入开展学习，深刻领会习近平总书记在“不忘初心、牢记使命”主题教育工作会议精神，精读党章党规和党史和《习近平新时代中国特色社会主义思想学习纲要》等。学院还组织了“弘扬爱国主义精神”、“坚定信念，理想起航”、“礼赞辉煌历程、奋进崭新新时代”等不同角度多层次的专题学习讲座。在此基础上，每周还开展一次集中研讨，大家积极发言、认真总结，取得了良好的成效。

10月31日，艺术学院师生党员共赴浮竹山革命烈士纪念园开展革命传统教育。教工党支部书记陈煜丽带领大家面向纪念碑肃立，向革命先烈默哀，并组织同志们重温入党誓词，向烈士致敬，表达对党无限忠诚、坚定跟党走的决心。回望波澜壮阔的革命岁月，学院负责人陈建新深情介绍了东纵先烈在浮竹山英勇战斗的场面，感叹当地村民建设、爱护烈士纪念碑的拳拳之心。大家纷纷表示，烈士们在自己最美好的年纪，为革命事业献出宝贵生命，我们要继承和发扬革命先烈崇高的奉献精神，把爱国热情转化为为党育人、奋力学习的实际行动。

11月1日下午，艺术学院党总支书记向智星、学院负责人陈建新带领全体师生党员前往东莞市图书馆参观“不忘初心、牢记使命”主题教育档案文献巡展。巡展以中国共产党团结带领人民取得革命、建设、改革、发展的辉煌成就为主线，共分为“探求真理”“坚守初心”“勇担使命”“践行宗旨”“从严治党”五个部分，精选约400多件中央档案馆、省档案馆馆藏的珍贵档案和广东红色教育、改革开放实践方面的文献档案，生动展示中国共产党为中国人民谋幸福，为中华民族谋复兴的伟大历程。观看展览时，大家从一张张泛黄的照片，一件件档案文献中共同追寻往昔，那些感人至深的革命情怀和革命先辈的伟大精神令大家唏嘘感叹。大家纷纷动情地拿起手机，把这一刻最想对党的表白分享到朋友圈……
