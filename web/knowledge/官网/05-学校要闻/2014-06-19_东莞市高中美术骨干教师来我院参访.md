# 东莞市高中美术骨干教师来我院参访

6月19日，东莞市第五高级中学、第六高级中学、塘厦中学、光明中学、第十高级中学、第二高级中学等中学的美术骨干教师来我院参观访问。

文学与传媒系的同行向参访客人介绍了数字媒体艺术专业建设情况及人才培养方案等。双方进行了深入的交流和探讨。

客人们实地参观了数字媒体艺术专业的专业实验室，对我院数字媒体艺术专业的师资和实验室硬件给予了高度的评价。

据悉，今年我院数字媒体艺术专业首次招收美术类大学生，东莞的美术特长生超千人。系主任李上文教授表示，热烈欢迎美术类考生报考城市学院，今年首批计划招生200人，文传系已经作好准备迎接新同学的到来，若报考人数超过预期，我们还可以向学校和教育厅争取追加指标。
