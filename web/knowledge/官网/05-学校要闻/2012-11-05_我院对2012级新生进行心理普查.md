# 我院对2012级新生进行心理普查

为了更好地了解2012级新生的心理健康状况，建立学生心理档案，便于对新生中存在的心理问题进行及时、专业的早期诊断和危机干预，帮助学生健康成长，我院学生处心理健康教育与咨询中心于10月16日、17日晚上6：30至9:00针对全院9个系部新生在电脑机房实行电子心理普，并于10月18日晚上进行了补测。据统计，全院共有4645名新生参与了此次心理测试。

各系部学生在工作人员的指导下，依次分批进入机房完成测试。此次测试是我院首次大规模地在机房实行电子心理普查，普查的内容比往更年完善。据学生处心理健康教育与咨询中心科长、国家二级心理咨询师余琼老师反映，接下来我院将针对此次心理普查的结果进行分析诊断。
