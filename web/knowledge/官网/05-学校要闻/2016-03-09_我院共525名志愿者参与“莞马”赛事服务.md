# 我院共525名志愿者参与“莞马”赛事服务

3月5日，2016东莞松山湖国际马拉松（简称“莞马”）志愿者培训班在广东医学院正式开班。未来数日，3400多名志愿者，将接受多个项目闭关培训。我院志愿服务中心指导老师万文双带领5名骨干成员参加会议。

据悉，2016东莞松山湖国际马拉松全长42.195公里，共1.5万人报名参加，其规模之大、范围之广、规格之高，都刷新了以往东莞马拉松的记录，所以对志愿者的服务质量提出了极高的要求。而我院共525名志愿者为本次莞马提供赛事组织和安保工作。3月10日，赛事专业人员还将在我院综合馆为志愿者进行系统培训。
