# 图书信息中心举办网络杀毒技术讲座

3月5日，图书信息中心邀请北京东方微点信息技术公司工程师朱云峰，为我院师生举办网络杀毒技术讲座

朱工程师针对我院教学、办公过程中网络病毒的具体情况，结合实际软件操作，详细介绍了微点网络杀毒软件的操作与应用。

据悉，微点主动防御网络杀毒软件已在我院部署完毕。该软件的推广使用将有效监控和遏制我院计算机网络病毒，校内师生可通过访问图书信息中心“网络服务”栏目或直接登陆

http://10.10.144.190，来下载并使用该杀毒软件。
