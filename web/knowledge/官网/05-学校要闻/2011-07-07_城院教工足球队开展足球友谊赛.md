# 城院教工足球队开展足球友谊赛

近日，我院教工足球队利用周末时间分别与机电工程系实习单位大同机械足球队、高品检测技术服务有限公司足球队以及由毕业生和校友组成的“321足球队”进行了3场足球友谊赛，最终教工队取得了一胜两平的好战绩。

据悉，教工足球队是学院工会组织，并由各系部教职工组成的，其目的是强健教职工的身体，丰富他们的课余生活，促进校内同事之间的友谊，加强与校外单位的沟通。足球队在与大同机械足球队、高品公司足球队的接触中，还为毕业生创造了就业机会，高品检测技术服务有限公司为城市学院2011届毕业生提供了3个就业岗位。
