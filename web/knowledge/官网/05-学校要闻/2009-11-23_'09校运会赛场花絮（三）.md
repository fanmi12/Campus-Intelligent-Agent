# '09校运会赛场花絮（三）

城院“女飞人”

最小的观众

大力水手“加油站”

忙碌的播音员

特别的运动员

运动会赛场上，有一位最特殊的、令人钦佩的运动员，他就是罗余才教授，管理系主任、系党总支书记，今年63 岁，是本届运动会年龄最大的运动员。

罗教授每届运动会都参加了。这次他没有像往年一样取得冠军或亚军，只是拿了男子60米跑第七名和男子400米跑第三名。赛后，他对记者说，本次比赛年龄分组安排有些改动，这次对手实力更强大，他参加的目的是锻炼身体，他说：“短跑适合年轻人，老年人没有那么好的爆发力，我觉得我比较适合长跑。”他平常每天早上6点都会来操场跑3000米。记者跟他交谈时，他指着看台上的一行标语说：“运动属于所有人，每天锻炼一小时，健康工作50年，幸福生活一辈子。”因为这个让他坚持每天锻炼。

对这次校运会评价，他说，校运会的关键是锻炼身体，重在参与。

家人助阵，无往不胜

运动场上有一群特殊的“啦啦队”，他们中有老有小，小的才三岁左右，他们的目光紧随着一个400米跨栏选手而跳跃。这位选手就是07级金贸系的赖丽贞同学，她轻松拿下了女子400米跨栏的第二名后，前来助阵的一家老小把她团团围住，有递水的，有递毛巾的，有询问身体状况的，兴奋之情溢于言表。她表示，自己擅长短跑，去年400米跑就拿过第一名。而今年的400米跨栏是第一次尝试，所以家人都前来助阵。

有着这样一群啦啦队，真可谓是力量倍增，无往不胜了。

大力水手“加油站”

成分：菠菜；配料：信心，毅力，勇气，坚强；适用人群：财经系全员；生产商：财经系学生会宣传部；生产日期：09年11月18日；保质期：永远。这个广告就是财经系在校运会期间隆重推出的“特制商品”——“大力水手加油站”。

这一独特的设计成为校运会一道亮丽的风景线，非常引人瞩目。整个“商品”是圆柱形的，周身用银色纸包裹住，特别显眼。

助威呐喊争冠军 妙笔生花鼓士气

“冷风挡不住我们的热情，奔跑在赛场上的你们，值得我们喊破嗓子”；“健儿们，用你的实力，用你的精神，去开拓出一片属于你的长跑天地”……各系大本营的“写手”们奋笔疾书，为运动员们写稿加油鼓劲，用激昂抑或煽情的文字传达他们对同学们的支持。虽是“方寸小纸内尽显文采”，却营造了你追我赶、奋力争先的竞赛氛围。城环系召集了20来位同学在大本营专门写稿。截止至第一天上午的统计，赛场广播站共收到上千份稿件。

校卫队荣获千五米前三甲

在教工甲组的1500米长跑赛中，3个穿着迷彩服的队员特别引人注目，他们跑得特别轻松，一路遥遥领先。他们就是校卫队保安员、勇擒飞车劫贼的英雄刘文兴、韦刚。赛后他们笑着对记者说：“我们是冲着前三名来的，这对我们来说很容易。”

女子跳远再创新纪录11月20日上午，在沙池进行了女子跳远比赛。金贸系的黄宝诗同学以4.39米的喜人佳绩刷新了去年4.36米的女子跳远记录，获得女子组跳远比赛的冠军。财经系的黄婉霞同学以4.19米成绩获得第二名。

据了解，19日的男子三级跳远比赛一、二名也是金贸系的学生。黄宝诗同学跳出4.39米的成绩之后，她十分兴奋，高兴地向记者透露，在第四、五轮比赛时，因为心情十分紧张，倍感压力，曾导致跳出来的成绩不如所愿，但由于好朋友的极力支持与鼓励，让她重拾信心，在决赛时发挥出了她真正的实力，一举夺冠！比赛过后，金贸系的同学争先恐后地向黄宝诗同学祝贺，她说：“能够赢得比赛，全是同学们的功劳。”

黄宝诗同学从小学三年级便开始参加大、中、小学校运会的跳远项目。她坦言自己是运动型女孩，同学都亲切地称她为 “player”。
