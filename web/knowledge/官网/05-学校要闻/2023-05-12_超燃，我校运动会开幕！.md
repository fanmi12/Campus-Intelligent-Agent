# 超燃，我校运动会开幕！

5月11日上午，东莞城市学院以“守正创新、立德树人，扬体育精神、展城院风采”为主题的2022年校运会在田径运动场隆重开幕。出席本次运动会的领导有校长陈明、党委书记章德胜、常务副校长方伟华、副校长刘玉侠、周庆、陈葆华、李海冬，校长助理孔增强、罗卫国以及各行政、教辅、教学单位负责人。通识教育学院院长王锦锋主持开幕式。

上午8时30分，伴随着雄壮的音乐，国旗护卫队方阵、校旗护卫队昂首阔步，英姿勃发，国旗护卫队擎着鲜艳的五星红旗率先入场，校旗方阵、各学院方阵、教职工方阵带着满腔的热情与活力紧随其后，依次走过主席台，展现了我校师生昂扬向上的精神风貌，赢得了热烈的掌声。

入场仪式完毕，全体起立，高唱中华人民共和国国歌。在庄严的国歌声中，全体人员注视着五星红旗冉冉升起。

陈葆华副校长致开幕辞。她代表学校向本届运动会的顺利召开表示热烈祝贺，向全体运动员、裁判员和工作人员致以诚挚问候。去年由于疫情的原因，对2022年校运会作了时间调整，如今运动会如期举行，离不开董事会强有力的支持，离不开领导的关心、工作人员的辛勤付出、以及运动员的辛苦训练。广大师生团结一致，终将战胜一切困难。她表示，一直以来，我校秉承“德智体美劳”五育并举的理念，将体育融入校园生活中，在竞技体育方面硕果累累，在各级各类体育竞赛中屡创佳绩。体育是“五育”的重要组成部分，也是综合素质养成教育的重要内容。希望参赛师生赛出水平、赛出友谊、赛出风格，充分展现城院人团结拼搏、奋发向上的精神风采。

运动员代表邓振涛进行了宣誓。他表示全体运动员要严格遵守比赛规则，坚决服从裁判，友谊第一、比赛第二，赛出水平，赛出风格，发挥出最佳成绩。裁判员代表江绮晴进行宣誓。她表示全体裁判员要恪守体育职业道德，认真履行裁判员职责，遵守竞赛规则，严格执裁，认真、公正、准确判决，圆满完成各项裁判工作。

陈明校长宣布运动会开幕。

接下来，活力四射的体育舞蹈华尔兹、武术操跆拳道、太极拳以及健美操类《魅力中国》等团体表演，为现场观众献上了一场精彩纷呈的视觉大片。

此次运动会分为教职工组和学生组两个组别，共有2000余名运动员参加了田径、群体两大类共55个项目的比赛。比赛时段分为11和12日两天。赛场上，裁判员公平公正执裁，认真服务师生，运动员们挥洒汗水、超越自我。他们顽强拼搏、勇往直前的身影成为运动会上一道道亮丽的风景线。
