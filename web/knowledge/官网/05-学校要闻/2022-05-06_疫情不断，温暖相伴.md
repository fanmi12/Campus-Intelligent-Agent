# 疫情不断，温暖相伴

近日，我校2022年春季学期师生返校工作有序开展，金融与贸易学院在严格遵循东莞市疫情指挥办规定及学校防疫要求下，根据学院实际情况，对于特殊情况学生一事一议。

学院领导得知2020级彭同学因2021年新生冬训期间受伤，诊断为右腿陈旧性髌骨脱位，休学一年，于今年复学至2021级，且右腿目前无法正常弯曲。该同学5月5日从江苏省南京市返校，学院全体老师在赖忠孝院长、张兰书记、侯瑞瑞副院长、李晓亮副院长、万文双副书记的带领下，迅速作出反应，主动和学生家长联系，确认学生航班信息、到校时间，亲自在校门口接送孩子、帮助学生核酸排队。开车接送孩子至学6宿舍、帮助彭同学铺好床铺、擦干净桌椅、将其安顿好，并且一一告知家长，让家长安心返回家中。

无论何时何地、疫情如何发展，我院全体教师时刻以学生为中心，坚持“爱在金贸、信在金贸、学在金贸”！
