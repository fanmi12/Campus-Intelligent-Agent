# 黄岳钧副教授受聘为省科学道德和学风建设宣讲团专家

日前，广东省科学技术协会、广东省教育厅联合公布了“广东省科学道德和学风建设宣讲团”专家名单。我院管理系黄岳钧副教授被选为宣讲团专家成员。

据悉，“广东省科学道德和学风建设宣讲团”将为共同推进广东省科技工作者和高校学生加强品格修养和道德自律、践行社会主义核心价值观、进一步优化学术诚信环境、树立良好学风等方面，进行宣讲。

黄岳钧副教授是华南理工大学人力资源研究中心访问学者、电子科技大学广东研究院重大项目管理顾问、市委会参政议政委员会副主任。长期从事高绩效工作系统、儒家人力资源管理系统及进化算法等方面的研究。
