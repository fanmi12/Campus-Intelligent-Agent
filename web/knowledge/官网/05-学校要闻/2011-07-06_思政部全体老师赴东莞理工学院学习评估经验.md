# 思政部全体老师赴东莞理工学院学习评估经验

7月4日，思政部全体教师在部主任何鹏举教授的带领下，赴东莞理工学院思政部学习评估经验，并参观了东莞理工学院迎评的资料及教学档案室建设情况。

东莞理工学院思政部主任李洪君、副主任孙艳萍分别介绍了做好本科学士学位评估和思想政治理论课专项评估工作的做法与经验，并联系实际提出了一些建议。

钱玉霞老师说，通过学习交流，老师们进一步明确了评估及课程建设的方向，对评估工作一些细节有了更加明确的理解和认识，为进一步做好迎评促建工作打下了基础。
