# 我院31名四川籍学子家人平安

“爸爸，妈妈，你们还好吗？有没有受伤？现在住在哪里？郊外？下雨怎么办？有吃的吗？我好担心你们啊……”余凤和家人通电话的时候，忍不住哭了。家在广元市元坝区的余凤，是城市学院０６级英语专业的学生，她家的房子在余震中彻底倒塌。家人都撤离到郊区。母亲在电话里安慰她，说政府已做了妥善安置，不用担心他们。

“一直到13号晚上，我才和父母联系上，谢天谢地，他们都好好的，只是食品和水供应紧张，担心余震发生，仍住在抗在指挥部提供的帐篷里。家在绵阳市的范军同学激动地说。12号下午，家乡的同学打电话给我说地震了，我开始还不相信呢，因为12号早上还刚刚和妈妈通过电话。看到电视、报纸等媒体都在报道地震，才知道事情真得很严重，晚上一下课我就打电话回家，怎么打都联系不上，结果再打电话回家，已经没有任何消息，我当时整个人就懵了，做什么都没心思了，只想回家看看他们啊。”

据老家在重庆的副院长张林博士介绍，地震发生后，学院非常关注四川籍学生的家庭情况，13号下午，院领导开会启动紧急预案，调查了31个川籍学生的情况，并对受灾地区的师生进行心理疏导，安抚情绪。各系组织学习预防地震的知识，开展赈灾募捐活动。据学生处赵秋平老师介绍，31名四川籍学生，分别是来自成都市、南充市、广元市、泸州市、宜宾市及通江县等距离震中较远的地区。据调查，有几位同学家的住房被震塌，所幸没有人员伤亡。

在座谈会上，张副院长鼓励同学们说，地震发生后，政府已开展了救援工作。当前我们应该用实际行动慰籍远在灾区的父母，首先要冷静下来，理智地面对现实，安心学习。其次要积极配合灾区重建家园，同时学院倡议大家捐款奉献自己的爱心。只要大家团结起来，众志成城，一定可以战胜困难。
