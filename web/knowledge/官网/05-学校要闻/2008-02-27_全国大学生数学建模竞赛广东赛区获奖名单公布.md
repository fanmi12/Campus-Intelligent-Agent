# 全国大学生数学建模竞赛广东赛区获奖名单公布

近日，广东省教育厅发文公布2007年全国大学生数学建模竞赛广东赛区获奖名单。据悉，全省共有49所高校、581支队伍参加了广东赛区的比赛，来自我院的10支代表队、30名同学参加了比赛。其中廉玉忠教授指导的计算机与信息科学系代表队（陈金华、陈坤旭、陈炳松同学组成）荣获省三等奖，其余9组获成功参赛奖。

全国大学生数学建模竞赛由教育部高教司和中国工业与应用数学学会共同主办，是全国高校规模最大、影响最广的高校学生课外科技活动，也是本科院校教学质量评估的一项重要指标。

通过这次竞赛，使参赛学生的创新能力、数学和计算机应用能力、论文撰写能力的得到提高。
