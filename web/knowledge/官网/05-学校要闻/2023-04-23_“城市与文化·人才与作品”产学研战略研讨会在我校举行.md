# “城市与文化·人才与作品”产学研战略研讨会在我校举行

为进一步加强学校与东莞市文学艺术界联合会（以下简称东莞市文联）的合作，推动东莞文化强市落地，提升东莞艺术人才培养水平，探索东莞艺术产业发展路径，4月15日上午，由东莞市文学艺术界联合会和东莞城市学院联合主办的“城市与文化·人才与作品”产学研战略研讨会在东莞城市学院学术报告厅举行。本次研讨会以“文艺人才培养·文艺作品孵化，实现产学研深度融合”为主题。东莞市文联党组书记、文联主席张彤飚，东莞市文联文联党组成员、专职副主席江祎霞，东莞市文联党组成员、专职副主席林玉秀，东莞市文联党组成员叶新源，东莞文学艺术院院长熊曦，东莞市第五高级中学校长杨志坚，东莞市塘厦中学副校长杨端，深圳光明中学艺体处主任李卫明，东莞市第六高级中学教务主任杨琼洲，东莞城市学院校长陈明，常务副校长方伟华，副校长陈葆华、李海冬，校长助理孔增强、任广新等领导和嘉宾出席研讨会。教学科研部、艺术学院、创意设计学院、人工智能学院等领导及师生300余人参加了研讨会。艺术学院院长张征主持研讨会。

常务副校长方伟华致辞。方伟华谈到东莞是一个海纳百川的城市，非常注重文化人才工作。东莞城市学院作为东莞地方高校，长期以来，坚持以共建、共享、共融的原则贯穿专业人才培养的全过程，形成了“育训结合、德技并修、产学研用”协同创新的专业人才培养新模式。他谈到，近几年来，学校艺术学院与东莞市文联及相关单位紧密联系，通过校企融合、搭建平台、项目合作等方式取得了一定的成绩。未来学校将形成产业联盟学院，从艺术着手，组成多个产业孵化中心，探索“政企校社”一体化人才培养模式，为粤港澳大湾区和东莞市文化强市做贡献，为社会培养更多高素质、应用型文化艺术人才。

东莞市文联党组书记、文联主席张彤飚致辞。他谈到当前随着经济社会发展，应用艺术领域正在飞速发展，东莞文化事业呈现蓬勃生机。东莞市文联在推动文化事业发展的过程中，始终把人才培养摆在发展全局的优先位置、核心位置，通过多种途径在文艺实践中锻炼人才，在项目支持中培养人才，推动东莞文学精品创作。未来，东莞市文联将与城市学院加强“产学研”合作，强化资源优势互补，构建产学研创新联合体，做大做强文化产业，探索出一条适合东莞艺术产业发展的道路，为东莞文化强市和经济社会高质量发展做出贡献。

随后，双方签署战略合作协议。东莞市文联副主席林玉秀和我校陈葆华副校长代表双方签订协议。

东莞市文联向我校授予“艺术人才培养基地”牌匾。李海冬副校长代表学校接受牌匾。

我校校长陈明教授向东莞市文艺评论协会副主席柳冬妩、东莞市戏剧家协会主席秦川、国家一级摄影师孟祥斌、东莞市电影电视家协会副主席穆肃、东莞市戏剧家协会副主席李建华等颁发客座教授聘书。

随后，相关专家进行了主旨演讲。东莞文学艺术院一级作家，东莞市文艺评论家协会副主席柳冬妩教授以“何为艺术”为题进行了分享。他从美国、法国、英国等欧美文学艺术发展历史，文学艺术作品的产生以及不同的专家学者对文学艺术的观点，并结合东莞城市化进程以及东莞涌现出来的城市文化、城市文学艺术作品的现象，指出文学艺术是不断发展的。文学艺术的对象等相关定义不是固化的，能呈现各种各样的可能性，希望广大学生努力学习，让文学艺术的未来充满更多的可能性。

东莞市戏剧家协会主席秦川教授以“文化强市建设中的戏剧力量”为题，从“为什么讲？”“广东省文化强省建设的六大工程”“东莞文化强市1274工程”“东莞市文联”“东莞市戏剧家协会”“零距离剧社”等六个方面进行了分享。他谈到我校是东莞市唯一一所具有表演专业的高校。东莞文化强市的发展，戏剧不可缺席。东莞市戏剧可通过与高校戏剧表演专业，镇街基地共建等方式提升戏剧品质，培养戏剧专业人才，为东莞市文艺繁荣提供人才支撑。

国家一级摄影师、影像博士、汕头大学硕士生导师孟祥斌以“影像赋能城市文艺事业发展”为题进行分享。他谈到东莞经过改革开放发展，成为“双万”城市，取得了巨大的成就。经济是血肉，文化是灵魂。城市的高质量发展还需要高质量的文艺为城市发展赋能。他谈到可以通过加大文艺人才培养，提升人才队伍的量与质，强化文艺团体与高校的合作，打破各类文艺壁垒，加强艺术融合，以影像专业为契机，实现不同门类多种艺术发展，利用影像传播艺术，打造城市IP等多种途径促进东莞文艺事业发展。

东莞市电影电视家协会副主席穆肃教授以“影视产业的后发路径选择”为题，他谈到影视产业的发展不仅可以带红城市的旅游景点，促进当地经济的发展，还可以提升城市的品牌形象。东莞未来可以从打造取景场地资源联盟，增加新时代的拍摄制作基地，引进更多的影视人才，加强聚合平台构建，吸引投资加强产业化运作等方面进行开拓。

北京大学、西北大学访问学者刘贝贝博士以“构建具有中国特色的传媒艺术发展策略”为题进行分享，她从“新思路：中国传媒艺术的现状与发展趋势”“新格局：构建中国特色的传媒艺术发展思路”“新路径：构建中国特色的传媒艺术实践路径”三个方面进行研讨。她分析了当前我国艺术院校发展现状面临着同类化、同质化的竞争，要想突破就需要通过技术融合、内容融合和平台融合的新思路，塑造在传媒内容上增加文化自信，利用互联网、AI等新技术的新格局，在实践中不断探索国际化的合作、媒体人才的培养、创新营销方式等路径。

东莞市戏剧家协会副主席李建华教授以“校园戏剧与社会同频共振联动发展”为题进行分享。他回顾了近几年来，东莞戏剧家协会与我校艺术学院的合作中，我校学生参与到东莞市相关作品中演绎演出的情况。他谈到校园戏剧是在校园或者表现校园的一种戏剧内容。校园戏剧具有贴近生活，找准定位，以学定教，可塑性强、耗资少等优势，并提出校园戏剧要引领思想，提升品格，走出校园，实战训练，打破围墙，资源共享等途径促进社会融合发展。

据了解，15日下午，本次产学研战略研讨会将在寮步镇西溪古村分会场继续举行，届时东莞各文艺协会代表、东莞城市学院骨干教师将分成音乐舞蹈音乐剧组和戏剧影视网络与新媒体组两个小组进行研讨。
