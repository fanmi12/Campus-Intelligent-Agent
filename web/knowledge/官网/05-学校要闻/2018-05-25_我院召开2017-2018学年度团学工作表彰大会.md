# 我院召开2017-2018学年度团学工作表彰大会

5月24日下午，我院2017—2018学年度团学工作表彰大会在行政楼112举行。党委副书记章德胜，创新创业学院常务副院长、招生就业处处长孔增强，党务工作部副部长叶凯贞，学生处副处长罗文芳、陈建新，院团委书记李瑶、副书记陈浩华、陈振伟，各院系党总支副书记、团总支书记，以及各团学组织的学生代表、青马学员代表参加了本次大会。

院团委书记李瑶进行了2017—2018学年度共青团工作汇报，解读了我院灯塔工程的实施方案。

院团委副书记陈浩华宣读了关于表彰2017—2018学年度团学组织工作先进集体和优秀个人的决定，授予陈宇炫等763名同学“优秀共青团员”荣誉称号，授予赖泽铭等169名同学“优秀共青团干部”荣誉称号，授予政法系团学组织等4个单位“优秀团学组织”荣誉称号，授予2015级土木工程1班团支部等70个单位“优秀团支部”荣誉称号，并为广东省志愿者暑期“三下乡”社会实践活动优秀团队及南岳村庄（整治）规划设计大赛优秀奖团队颁奖。

创新创业学院常务副院长孔增强为“青马工程”校外导师——客语创始人许可鹏颁发了校外导师聘书。院团委书记李瑶向团委学生干部颁发了聘书。

东莞市红十字会对我院张超同学捐献造血干细胞进行了表彰，向张超同学颁发了捐献造血干细胞荣誉证书。市红十字会

志愿者蒋浩宣读了受捐患者的感谢信。

张超表示，自己只是完成了一份力所能及的小事，希望有更多的同学参与进来，非常感谢学校、东莞市红十字会给予自己帮助他人的平台。东莞市中心血站向学院团委送上了感谢状。

章德胜副书记对张超同学无偿捐献造血干细胞给予了高度赞扬，号召广大团学干部和同学们向张超同学学习，并感谢他为学院带来的荣誉。他还代表学院党委向获得各种荣誉的团队、组织和个人表示衷心的祝贺，希望同学们树立正确的政治方向和服务意识，助力学院团学工作迈上新台阶。

当日下午，“城院青年说”还举行了首期 “与信仰对话”演讲。客语创始人许可鹏进行了主讲，他以幽默风趣的演讲风格，为同学们讲述了创业路上的种种艰辛与心路历程。
