# 我校举行2018年秋季赴台湾交流生表彰大会

5月23日下午，国际交流中心在行政楼112会议室举办2018年秋季赴台交流生表彰大会。

周庆副校长出席大会并致辞。她肯定了赴台学子在台湾交流期间的优异表现，表示学校将为同学提供更多的国际交流平台，鼓励同学们走出去，开拓境外视野。

商学院黄裕凌、法学院吕子欣同学相继分享她们在台湾交流的心得体会。她们表示，在交流学习中明白了“读万卷书，行万里路”的深刻含义，对自己的人生规划有了一个更清晰的认知。

大会向2018年秋季赴台的九位优秀交流生颁发了荣誉证书和奖学金。
