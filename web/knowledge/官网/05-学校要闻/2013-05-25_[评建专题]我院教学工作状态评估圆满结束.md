# [评建专题]我院教学工作状态评估圆满结束

随着专家意见反馈大会落下帷幕，我院历时三天的教学工作状态评估工作于5月24日圆满结束。专家组充分肯定我院重视教学工作状态建设，认为我院评建工作扎实，本科教学工作的中心地位稳固，办学条件优良，教学工作水平和人才培养质量较高，多项事业得到了新的发展。

几天来，专家们采取听、看、访、查的考察方法，听取工作汇报、随机听课、召开座谈会、查阅与评估相关的支撑材料(如人事档案、财务报表、毕业论文、设计等），考察了实验室、图书馆等教学设施。

24日下午4时，专家组在我院学术报告厅举行专家反馈意见大会。东莞理工学院副校长邹晓平教授出席了会议，城市学院董事黎建烨、学院党政领导、副高以上职称教师、副科级以上教学管理人员、教师代表参加会议。

专家组组长、五邑大学教务处处长董超俊教授主持会议并宣读了专家组评估结论，专家组成员华南理工大学计算机学院院长韩国强教授、仲恺农业工程学院经贸学院院长王厚俊教授、东莞理工学院教务处处长王卫平教授、东莞理工学院高等教育研究中心主任陈想平教授也分别在会上讲话。

专家们认为，城市学院办学成绩令人惊喜，领导班子团结，师资及教学设施能满足教学需要，办学定位和发展思路明确清晰，教学条件不断改善，教学资源利用率高，注重专业建设和教学方法的改革，致力探索人才培养模式改革，教学质量监控体系不断完善，学风建设成效显著。针对我院办学过程中存在的不足，专家组也提出了意见和建议。他们希望我院要进一步加快教学基本条件建设步伐；加强师资队伍建设，特别是青年教师的培养力度，打造结构合理的教师队伍；处理好规模与结构、效益与质量、保障与监控的关系，深化教学改革；积极开展人才培养模式、教学方法、培养方式与路径的探索工作；继续鼓励教师下基层进企业，提升实践教学能力，给中青年教师多提供深造与进修的机会及平台。

院长杨敏林教授致答谢词，他代表学院衷心感谢专家组提出的宝贵意见和建议，他认为，专家们的意见具有前瞻性、科学性和可操作性，为我院可持续发展指引了方向。他表示，学院将充分理解和体会专家们的意见建议，认真梳理，研究制定出整改方案；进一步规范管理，深化改革，强化质量监控，加大投入，优化育人环境，突出办学特色，服务地方经济建设和社会发展，切实提高办学水平和人才培养质量，把城市学院做大做强，办成人民满意的大学。
