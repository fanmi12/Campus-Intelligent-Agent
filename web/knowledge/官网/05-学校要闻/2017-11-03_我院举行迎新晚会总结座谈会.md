# 我院举行迎新晚会总结座谈会

我院2017级迎新晚会——“拥抱青春季，爱党爱祖国”于10月29日成功举办，反响热烈，受到广大师生的热捧。

11月2日，“2017级迎新晚会”总结会在行政楼407会议室举行，王卫平院长、章德胜副书记与晚会策划组织工作人员、演艺人员进行了座谈。

与会人员汇报了晚会的工作情况，总结了经验和存在的不足，提出了改进意见和建议。

王卫平院长、章德胜副书记对晚会的成功举办给予了充分肯定，指出迎新晚会是学院一年一度的文艺文化盛事，是学生重要的舞台锻炼与实践，希望大家总结好经验，各个部门相互配合支持，把迎新晚会办好，取取更大的成绩。
