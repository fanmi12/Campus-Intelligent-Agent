# 广东创新科技职业学院来我院交流党建工作

11月19日，广东创新科技职业学院党委书记麦韬芙一行12名党政管理干部来我院参观交流。党委书记王卫平、党委副书记章德胜等我院相关领导热情接待了到访客人。两院领导就民办高校党建工作的开展展开了深入细致的交流和探讨。

随后，麦书记等到访客人在我院宣传部长何鹏举、学院办公室副主任叶凯贞陪同下参观学院校史展厅及图书馆。

通过本次交流，两院领导均表示在今后应多加强交流，共同探讨东莞民办高校党建工作新思路。
