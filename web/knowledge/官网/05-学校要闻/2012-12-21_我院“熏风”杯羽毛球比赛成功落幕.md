# 我院“熏风”杯羽毛球比赛成功落幕

2012年“熏风杯”羽毛球比赛于12月20日成功落幕，本次赛事分为第一阶段的小组循环赛和第二阶段的淘汰赛。各系部运动员经过8天的奋力拼搏，最终政法系在决赛中战胜金贸系取得了比赛的冠军，财经系、文传系、管理系和机电系分列三、四、五、六名。羽毛球比赛过程中，参赛队员们表现出了积极拼搏、每球必争的良好体育风格，整个比赛精彩迭起。

羽毛球比赛闭幕式上，体育教学部主任邢红林教授和体育部老师给获奖的队伍和优秀的裁判员颁发了奖品和荣誉证书。邢红林主任表示，为了推动城院羽毛球运动的发展，丰富学生的业余生活，羽毛球比赛将作为品牌活动每年都举办下去！
