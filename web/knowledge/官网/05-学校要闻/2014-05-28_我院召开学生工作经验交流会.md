# 我院召开学生工作经验交流会

5月26日，由学生处举行的学生工作经验交流会在大学生创新创业发展中心召开。院党委副书记章德胜，学生处、院团委、各系及全体辅导员与从事学生管理工作的人员参加会议。学生处思政科科长陈晓萍主持会议。

此次交流会旨在为学工团队人员分享与交流有关学生工作提供一个分享和交流经验的平台，针对现在学生工作中所遇到的问题和困惑寻找解决或改善方法。

交流会上，九个系的党总支副书记分别用生动简练的语言和丰富翔实的资料，向全体参会人员详细介绍了本系部学生工作的整体概况、创新举措以及相关的工作经验，并提出了很多值得深入思考和持续探索的新话题，对各系的学生工作都具有一定的借鉴作用。

最后，学生处副处长杜鹏举对学生工作交流的必要性、重要性予以了充分肯定，并对经验交流会做了全面总结，希望各部门能相互借鉴与学习。
