# 期末考试今日开考

12月3日，2011—2012学年度第一学期期末考试拉开帷幕。经过元旦假期的休整和准备，同学们精神抖擞、胸有成竹地走进各个考场。上午9时整，首场考试正式开始，院领导朱志德、杨敏林、程发良等巡视了各考场。

据教务处统计，本次考试从1月3日持续到1月10日，在新老两个校区同时举行，共有一万多名学生参加，考试科目共计253门，涉及932个班。考试地点除老校区四号楼大厅和新校区综合馆两个千人考场外，还分设图书信息中心大楼考场、新老校区各教室。在教务处的精心组织下，首场考试考务工作有条不紊，秩序井然，考生及考务工作人员、监考老师都准时到达考场。
