# 我院召开2018-2019学年预算编制工作会议

6月13日下午，我院召开2018-2019学年预算编制工作会议。董事长代表陈超群，院领导王卫平、章德胜、高香林、黄兢、周庆、刘玉侠、林江龙，以及各二级单位负责人出席了会议。

财务处工作人员介绍了新学年预算编制的主要程序、预算经费的申报方法和工作要求。

财务处长余竹根对本学年预算编制工作进行了总结，并对预算编制过程中需要注意的事项进行了说明。

周庆副院长要求各单位对预算编制工作给予高度重视，结合本单位新学年的工作目标及重点认真开展预算编制工作，提高预算编制和管理水平。

王卫平院长强调，学院预算经费要做到有的放矢，紧密围绕学院的年度工作重点，确保重点工作的经费优先安排。
