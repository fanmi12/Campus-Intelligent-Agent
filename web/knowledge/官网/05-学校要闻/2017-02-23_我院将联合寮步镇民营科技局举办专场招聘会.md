# 我院将联合寮步镇民营科技局举办专场招聘会

3月9日，我院招生就业处

将携手寮步镇民营科技局联合举办首场“寮步镇倍增和重点企业专场招聘会”。目前已有30家企业报名参加，均为寮步镇新三板挂牌企业、上市后备企业、市倍增计划试点企业。

据了解，今年2月，东莞市政府为深入贯彻中央、省委省政府和市委市政府相关部署，提升东莞产业综合竞争力和可持续发展能力，实现东莞“跨越生产总值万亿元”

的战略目标，出台了《东莞市人民政府关于实施重点企业规模与效益倍增计划全面提升产业集约发展水平意见》（东府

[2017]1号），根据“选好选优，培优培强”的原则，目前已在全市选出200家试点企业，扶持培育试点企业以“倍增计划”中的各种集约化发展路径来提升企业综合竞争力，力争3到5年时间，推动试点企业实现规模与效益的倍增。其中，寮步镇共有17家企业被选为试点企业，与松山湖高新产业区并列第一。

我院作为一所地方院校，秉承“服务地方求发展”的原则，以“为地方经济与社会发展培养优秀人才”为已任，高度重视与地方政府和企业的合作。日前，我院与寮步镇民营科技局就加强校政校企合作、扶持学生就业创业等方面达成合作意向，并定于2017年3月9日联合举办首场“寮步镇倍增和重点企业专场招聘会”。
