# 我院2013届毕业生就业工作全面展开

近日，我院2013届毕业生就业工作全面展开，2013届毕业生将迎来就业择业的“旺季”。

我院2013届毕业生共有2520人，就业工作任务十分繁重。为此，学院高度重视毕业生就业工作，学生处已对2013届毕业生的就业工作提前进行全面规划和部署。莞城校区学工中心也多次召开学生工作会议，对各系部的毕业生就业工作提出具体要求。学生处有关部门编印了《2013届毕业生信息》，制作了校园招聘会《邀请函》向企事业单位发放，全面推介我院2013届毕业生。另外，学院还为2013届应届毕业生就业信息网的学生账户使用通道，及时下发《毕业生就业指南（2012年版）》、《毕业生就业推荐表》等就业材料，使应届毕业生尽快进入就业状态，及时了解就业信息。

据了解，我院将于12月8日上午9:00-13:00在莞城校区（学院路251号）举办“2013届毕业生供需见面会”， 有意向参会的单位可登陆我院就业信息网

http://csxy.dgut.edu.cn/job/下载本次供需见面会邀请函、《参会回执》等相关资料。
