# 我校法学院两名教师获聘东莞市法学会“双百”宣讲专家

近日，东莞市法学会发文公布“百名法学家百场报告会”（简称“双百”）宣讲专家，我校刘杰教授和李阳桂博士与来自市委党校、法院、东莞理工学院等单位的25人获聘为“双百”宣讲专家。

两位老师表示，将不断学习和研究习近平法治思想、民法典等内容，提高服务本领，以法护航东莞高质量发展，为法治东莞、平安东莞奉献力量。

刘杰教授

李阳桂博士

本次教师的入选，是我校积极参与法治实践的重要表现，也体现了社会各界对我校法学实力的认可，未来我校法学院将继续努力，不断提升法学专业能力和水平，为社会主义法治建设添砖加瓦。
