# 我院团干部唐征玲汕头挂职锻炼

今年3月我院机电工程系团干部唐征玲老师经学院推荐和团省委安排，分配到广东省汕头市潮南区团委挂职锻炼。

几个月来，他协助挂职单位先后成功举办了“展青春风采?谱幸福乐章”文艺汇演、“新潮南?新潮商”青年企业家论坛、“幸福广东?健康同行”体育健康知识竞赛等活动。在这些活动中，他展示了城院人的风采和能力，受到当地团员青年的好评。
