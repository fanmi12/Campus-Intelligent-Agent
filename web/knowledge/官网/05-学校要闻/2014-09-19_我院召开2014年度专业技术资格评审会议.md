# 我院召开2014年度专业技术资格评审会议

9月11日，我院在行政楼212会议室召开学术委员会会议，对申报2014年度专业技术资格的教师进行评审。学术委员会副主任委员高香林教授主持会议。

委员们严格按照文件的要求，本着严肃、认真、客观、负责的态度对申报材料逐份逐项进行认真的审阅和充分讨论，并对通过资格审查的申报人员进行评议和投票表决。

据悉，今年申报工作进行了改革，全部实行网上申报评审。经学院学术委员会评议投票通过的申报人方可获得帐号进入系统填写基本信息，将《申报表》、《推荐表》、论文代表作等材料扫描后网上送评。我院评审工作按照省、市有关文件精神，严格执行个人申报、教务处材料审核、组织人事处资格审查等程序，最终提交参评的共有30人，其中申报教授资格的2人、副教授9人、讲师（助理研究员）17人、实验师2人。

经学术委员会审议，委员们投票表决，本次会议同意上述人员向上级申报相应专业技术资格。
