# 我院召开新学期首次教学督导会议

2月23日下午，我院新学期第一次教学督导工作会议在行政楼207会议室召开。王卫平院长，研发处赵书山处长，教务处鞠晓红副处长，以及全体教学督导员参加了会议。

专职教学督导员宋欣荣教授对上学期的教学督导工作进行了总结，对本学期的教学督导工作要点及要求作了具体说明。鞠晓红副处长对教学督导员在上学期维护学院正常教学秩序和参加期中教学检查工作做出的贡献，表示感谢，并希望在新学期里，教学督导员在学院教风学风方面做出更多工作并对教学管理工作提出宝贵意见。赵书山处长希望全体教学督导员继续坚持督导工作原则，坚持常规督导与专项督导相结合，做好督导工作。

会上，各教学督导员就如何做好教学督导工作进行了认真、深入的研讨。

王卫平院长指出，教学督导员在提高学院教学质量方面发挥了重要作用。他希望教学督导员能够在新学期的工作中，继续围绕教风学风提高督导工作质量，并加强长期在教书育人工作上做出突出贡献的优秀老师的宣传工作，为学院全面提高教学质量做出新的贡献。
