# 我院隆重举行建党90周年暨科技文化艺术节闭幕式

晚会现场

歌舞《国家》

小品《又是满山荔枝时》

管乐合奏《北京喜讯到边寨》

出席晚会领导与演职人员合影留念

历时一个月的科技文化艺术活动月6月10日圆满结束。当天晚上，学院在图书馆广场隆重举行纪念建党90周年暨校园科技文化艺术活动月闭幕式。近500名学生为晚会奉献了活动月期间创作的歌舞、小品、器乐合奏等节目。

东莞理工学院领导周致纳、黄碧莲、安少华、李忠红，城市学院董事黎建烨，城市学院领导朱志德、程发良、朱冰、张林，院督学陈丁堂出席晚会并观看了文艺表演。

党委副书记朱冰宣读关于表彰活动月积极分子及优秀活动项目的决定。院学生会主席翁梓朋做科技文化艺术活动月总结报告。

科技文化艺术活动月已成为我院校园文化的一个重要品牌，也是集中展示师生员工文化智慧、艺术作品、科研成果的重要载体与平台。三十多天来，各类活动好戏连台、精彩纷呈、高潮迭起。据统计，仅以学院名义举办的“十大歌手”比赛、书画比赛、“党在我心中”征文比赛、心理情景剧比赛等活动就达17项之多。这些活动呈现出四大特点：一是主题鲜明。广大师生以“纪念建党90周年”、“校园幸福生活”为主题，以多种文艺形式颂党恩、诠释人生、憧憬未来。二是服务教学。艺术系的服装、音乐表演，文传系的艺术设计作品展示既是教学实践活动，毕业成果汇报，又丰富了活动月的内容。三是追慕时尚。纵观这些活动内容与作品，无不打上环保、节能、绿色、传统等新元素和新理念。四是雅俗共享。这些活动专业特色鲜明，艺术欣赏价值高，又兼顾了同学们不同的兴趣与爱好，因而参与人数众多。

晚会上，无论是唱歌、舞蹈，还是小品朗诵，都盛情歌颂共产党，感恩祖国，抒发对校园幸福生活的热爱。小品《荔枝满山时》的表演者党家立、藏莹竹，以出色的演技演绎了解放前的一个小故事，“荔枝满山时，人却不归来”，表演的也许是一个悲剧，但革命烈士用自己的生命换来了中国的解放，谁又不为之动容呢。由09音乐表演班表演的音乐情景剧《红色生命线》，集歌唱、舞蹈、朗诵为一体，体现了汶川地震的悲情、温情。一首《生死不离》更是感染了全场。由林伟伦和徐小华老师共同演唱的《国家》，以动听感人的歌声再次向我们阐述了爱国的定义。朗诵《再出发，第一棒》则表达了新一代青年人奋发向上，不断进取的精神风貌和决心。管乐合奏《北京喜讯到边寨》和大合唱《歌唱祖国》萦绕在城市学院上空，为整场晚会拉上帷幕。
