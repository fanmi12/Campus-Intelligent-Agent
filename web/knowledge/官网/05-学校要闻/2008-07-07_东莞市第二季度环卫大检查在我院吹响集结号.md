# 东莞市第二季度环卫大检查在我院吹响集结号

我院174名师生将于7月7日

至7月10日按照市政府部署奔赴“前线”（32个镇街 596个村社区），开展东莞市2008年第二季度环境卫生大检查工作，集结号已经吹响。

7月6日，市整治环境卫生工作领导小组办公室常务副主任徐少钢在学术报告厅为我院即将开赴一线进行环境卫生检查工作的174名师生进行动员并开展业务知识培训。

培训会上， 每位师生领取了一份2008年第二季度环境卫生大检查（村、社区）评分表，市环卫办工作人员针对评分表逐项进行了解释阐述，并结合第一季度检查的结果及案例图片规定了评分标准，要求参检人员在检查过程中，客观公正，不怕吃苦，为我市共建蓝天碧水的美好家园，实现“国家卫生城市”作出积极贡献。

据悉，我院参与的市环境卫生检查主要工作为全市动态管理部分，依据整治任务主要对包括清扫保洁、绿化养护、上门收集垃圾、门前三包、基础设施管理、“脏乱差”整治等内容进行检查和评分。
