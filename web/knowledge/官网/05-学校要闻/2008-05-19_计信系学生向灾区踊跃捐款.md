# 计信系学生向灾区踊跃捐款

5月16日，计信系在实验楼514室开展募捐活动，为汶川的遇难者默哀。在募捐现场，同学们发扬“一方有难、八方支援”的传统美德和无私奉献精神，慷慨解囊。伴随《爱的奉献》的歌声，各班学生纷纷把满载爱心和祝福的赈灾款投进募捐箱中，1500元、1000元、800元……在短短的1个小时里，共筹得捐款20027.1元。

06软件工程(1)班的古庆迈同学接受采访时说：“我们班的同学了解到灾区人民的情况后，都想为灾区尽自己的一份微薄之力，帮助灾区人们度过难关。当系里发出倡议后，同学们积极捐款，刚才我们班长已经把募集到的1900元赈灾款捐进了募捐箱。希望我们的爱心能够传递到灾区，也希望灾区人民早日重建家园。”
