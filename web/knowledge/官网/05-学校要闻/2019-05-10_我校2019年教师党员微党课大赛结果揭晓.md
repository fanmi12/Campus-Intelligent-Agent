# 我校2019年教师党员微党课大赛结果揭晓

5月10日下午，由党务工作部主办的2019年教师党员微党课大赛迎来巅峰对决。校领导王卫平、章德胜、高香林、黄兢、刘玉侠、周庆和师生党员代表一起观看了比赛。

此次大赛主题为“弘扬爱国奋斗精神，建功立业新时代”，旨在深入贯彻习近平总书记系列重要讲话精神，深入开展“两学一做”学习教育，鼓励党员干部上讲台、讲党课，谈认识、谈理解、谈体会，锻炼提升党员干部的学习力、表达力，推动教学相长，引导广大师生党员在新时代自觉弘扬践行爱国精神，为实现中华民族伟大复兴的“中国梦”努力奋斗。

来自金融与贸易学院党总支选手肖云等10位教师党员选手经过重重比赛，脱颖而出进入决赛。经过激烈角逐，法学院丛珊老师获得一等奖，艺术学院徐婷婷老师、法学院曹琴老师、城建与环境学院段昭老师获得二等奖，肖云、敖谦、陈诗琦、惠梦瑶、张燕、陈玲玲老师获得三等奖。
