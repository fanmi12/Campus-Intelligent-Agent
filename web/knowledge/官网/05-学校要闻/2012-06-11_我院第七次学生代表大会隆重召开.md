# 我院第七次学生代表大会隆重召开

6月9日，东莞理工学院城市学院第七次学生代表大会在大礼堂隆重召开，来自各系部的352名学生代表参加了会议。

城市学院党委书记朱志德，副书记章德胜出席会议。东莞理工学院学生会、东莞职业技术学院学生会、广东医学院学生会等院校的学生代表到会祝贺。

团委副书记罗文芳老师宣读表彰2010-2011学年优秀系部学生会和第八届院学生会优秀干部及优秀干事的名单。据悉，财经系、文学与传媒系和金融与贸易系获得了“优秀系学生会”称号。院党委宣传部部长何鹏举和学生处副处长丘永辉分别为获奖的单位及个人颁发证书。

院团委书记杜鹏举为大会致开幕词。他说，此次大会不仅是全院学生政治生活中的大喜事，更是一次朝气蓬勃的青春盛会。希望与会代表能够履行好自己的责任，以饱满的热情与主人翁精神开好会议，完成大会的各项任务，将大会开成团结鼓劲、创新务实的大会。

第八届院学生会主席翁梓朋在会上作学生会工作报告，部署下一年度的学生会工作。回顾了过去一年的工作报告。院学生会生活部部长苏冬雪向代表们报告了第八届学生会财务收支情况。与会代表对工作报告和财务报告进行了审议。

会议审议并表决通过了《东莞理工学院城市学院学生会章程》修正案。据了解，此次新章程共修改了6处。

新一届学生会主席团成员的选举，采取无记名的投票方式，从6名正式候选人中选举产生4名新一届学生会主席团成员。经过各位候选人的精彩演讲和投票，10工商管理陈静红、10保险陈琳琳，10会计叶晓彤和10建筑工程管理黄粤西成当选新一届主席团成员。

院党委副书记章德胜在会议上向与会代表提出了三点希望：第一，要加强青年大学生思想政治工作，帮助他们坚定理想信念。第二，竭诚服务全院青年，解决他们学习生活中遇到的实际困难。第三，要激励青年奋发有为，积极投身改革和经济建设。
