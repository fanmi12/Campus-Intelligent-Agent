# 学院召开中层干部会议

6月8日，我院在315会议室召开中层干部会议，安排部署期末工作。会议要求，各级领导干部及全体教职工，要以良好的精神面貌与工作状态，做好期末工作，谋划暑期工作和新学期开学准备工作。

党委书记朱志德主持会议。会上，院长杨敏林做总结讲话，院领导朱冰、张林、章德胜、高香林就所分管的工作分别做了安排。

会议认为，当前我院面临许多新任务、新情况和新问题。随着暑期的临近，期末工作的紧张繁重程度日渐凸现出来。3000多名本专科生面临毕业和就业，毕业答辩及各类考试考证相继进行，首次独立颁发学士学位证书。新学期又将迎来4000多名2012级本科新生，院机关及系部有一批工作人员和教师要到新校区上班，新校区一批新的学生宿舍、办公楼、饭堂、图书馆（扩建）即将投入使用。

为此，学院领导要求，老校区的“过渡”工作，要在东莞理工学院“过渡”工作协调小组的直接领导下，按照“适时”、“有序”的原则进行。一切工作都要从稳定出发，安全第一，未雨绸缪，按既定的工作思路“照常”进行。要兼顾新老校区的工作，兼顾期末与暑期、新学期开学准备三个时间段的工作，兼顾应急突发性工作与常规例牌性工作。

关于期末工作。要认真做好毕业论文答辩、期末考试、英语四六级和计算机等级资格证等考试工作的组织与考务工作；认真评选“三育人”先进个人与优秀党员、先进党组织；筹备开好“七一”表彰会、毕业典礼大会；做好毕业生离校思想教育工作，以及学士学位评审与发证工作。教务部门要及时下达新学期教师的教学任务，新专业要抓紧申报。新校区管委会要调整安排好各系部及行政机关的办公用房，配齐办公用品用具，教师公寓工程要抓紧扫尾。

关于暑期工作。继续做好“人才培养方案”的修订工作，人事部门要做好新教师的报到和岗前培训工作；招生部门要根据生源情况，及时调整招生计划，尽量满足东莞考生入学的要求。新校区管委会要丰富馆藏图书，新书要及时上架；进一步加强实验室、多媒体课室的硬件建设。新生宿舍要留有充分的余地。国有资产要造册登记，做到数物相符防止流失。

关于新学期开学的准备工作。新老校区要分别制订出新老学生和新教师入住、上课、生活、军训等方面的工作预案。
