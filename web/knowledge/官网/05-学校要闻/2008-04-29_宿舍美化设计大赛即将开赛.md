# 宿舍美化设计大赛即将开赛

为创建团结、文明、守纪、和谐的校园，院学生会自律委员会即将在全院学生中开展以“乘奥运之风，创文明宿舍”为主题的第三届宿舍美化设计大赛。大赛组委会希望同学们在搞好宿舍清洁卫生的基础上，把宿舍设计美化营造成温馨的学习生活环境，以提高学生的生活质量。

为使宿舍美化设计大赛举办成功，让更多的学生参与其中，亲身体验设计与制作的乐趣，自律委员会制订了宿舍美化设计大赛的比赛内容以及比赛宗旨：在搞好宿舍卫生的基础上，建设具有文明、个性、美化的宿舍；培养同学们团结协作的精神，热爱宿舍，以体现当代大学生的时代风采。比赛设置了诸多奖项，期待广大学生的积极参与。
