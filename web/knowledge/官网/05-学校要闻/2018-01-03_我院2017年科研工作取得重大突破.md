# 我院2017年科研工作取得重大突破

2017年，我院科研工作再次取得突破性进展，成果喜人。全年申报省（部）级、市（厅）级项目并获得立项的达80多项，科研经费投入超过400万元，两项专利顺利完成技术转让。

在这80多个立项项目中，何帅老师的“数字化背景下的非遗项目保护与传承研究——以龙舟制作技艺数字化传承为例”成功申报2017年度教育部人文社会科学研究青年基金项目，项目经费8万元，实现该类项目立项零的突破；李国栋老师的“明代东莞文学家陈琏研究”获批2017年度广东省哲学社会科学规划地方历史文化特色项目，获省级经费4万元；陈振伟、张燕、陈妹琼、陈玲玲、王素娟、彭国华、何帅森、危兆宾、牛文学等9位老师申报的2016年广东高校重大科研项目，2017年3月全部获得立项，9月又顺利通过开题评审；杨亚娟老师的“东莞民营企业创新发展的引领线路与辐射效应研究”、牛文学老师的“人本视角下流动老年人口社会融合问题研究”成功立项为广东省哲学社会科学“十三五”规划2017年度学科共建项目，截至目前该类项目成功获批已达11项；大学生创新创业训练计划项目方面，5个国家级和30个省级项目均顺利立项；东莞市哲学社会科学规划课题方面，2017年更有20位老师成功立项，创历年新高，其中贾静波、牛文学、曾检成、谢丽莎、彭国华等5位老师因研究成果突出，分获后期资助经费1万元；东莞市社会科技发展项目方面，今年共申报13项，成功立项多达12项，立项率高达92.3%，创该类项目立项率之新高。

此外，我院先后与中央政府驻港联络办深圳调研中心、东莞市教育局、科技局、市残疾人联合会、广东拓斯达科技股份有限公司、森科智能科技有限公司、中山市吉成五金制品有限公司等政府部门及多家企事业单位建立了合作关系，年度产学研合作经费首次超过70万元。郭文显、宋雪晶老师的两项专利顺利实现科技成果转化，获转化效益1.2万元，成为首批成功实施转化的科技成果。

研发处处长赵书山介绍说，一系列项目的成功立项和科技成果转化的顺利实施反映了教师科研水平稳步提升，标志着我院科研工作迈上了一个新的台阶。
