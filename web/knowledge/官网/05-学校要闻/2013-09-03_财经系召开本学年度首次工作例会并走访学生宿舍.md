# 财经系召开本学年度首次工作例会并走访学生宿舍

8月30日，财经系在5A220会议室召开本学年度第一次系部工作例会，全体教师参与了会议，就新学期教学任务的安排和迎新工作准备等问题进行了讨论和发言。31日晚上，罗卫国主任带领系全系辅导员重点走访了学7栋宿舍、专插本学生新搬迁的学4栋宿舍。

会上，系主任罗卫国教授通报了财经系上学年度的工作，全体教师共同分享了暑期交流心得。罗主任勉励大家要见贤思齐，不断改进系风、教风、学风。党总支副书记唐洁老师就该系专升本情况、宿舍搬迁情况、迎新准备工作进行了部署，要求班主任在新学期伊始要积极走访学生宿舍，关注学生的到校情况，并重点检查和关注涉及搬迁的宿舍，使搬迁工作顺利有序完成。妥善安排13级迎新工作，努力做好各项准备工作，确保开学正常进行。

在走访宿舍的过程中，罗卫国教授一行认真了解学生搬迁的进度，听取学生提出的搬迁建议和意见，询问网络设备等情况，强调寝室卫生、安全的重要性，并叮嘱学生们要注意养成良好的生活习惯，营造和谐的宿舍氛围。
