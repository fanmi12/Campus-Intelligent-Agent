# 我院召开新学期教学督导工作研讨会

3月8日，新学期教学督导工作研讨会在行政楼212会议室召开。高香林副院长及全体专职和兼职教学督导员参加了会议。

督导办副主任宋欣荣对上学期教学督导工作进行了总结，并对新学期教学督导工作进行了部署。

会上，专职和兼职督导员认真学习了《东莞理工学院城市学院实践教学工作规范（暂行）》文件精神，就即将进行“集中性实践教学”的专项督导工作进行了研讨。

高香林副院长充分肯定了教学督导员在多个方面发挥的作用，一是督促各教学单位认真落实各项教学规章制度；二是帮扶年轻教师更好地站稳讲台；三是提高教学效果。希望大家继续在协助学院完善质量保障体系、提高教学工作质量和水平等方面发挥作用。
