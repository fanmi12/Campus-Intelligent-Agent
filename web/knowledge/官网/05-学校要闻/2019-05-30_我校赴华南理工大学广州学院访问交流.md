# 我校赴华南理工大学广州学院访问交流

5月27日，高香林副校长率队赴华南理工大学广州学院就专业建设工作进行访问交流。教务处处长赵书山、副处长鞠晓红参加了交流活动。

华南理工大学广州学院副校长兼教务处处长林颖、副处长许淑贞等领导予以了热情接待，并就专业认证等专业建设工作进行了座谈。对方详细介绍了IEET工程及科技教育认证、IACBE国际商科认证的相关情况。

双方还就专业认证标准、培养方案的修订、整体时间规划、工作分配方案、实验室建设、自评报告撰写、毕业生的跟踪评价、认证中存在的问题等方面的工作进行了交流与探讨。
