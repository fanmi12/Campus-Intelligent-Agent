# 东莞理工学院隆重举行2006年迎春团拜会

1月6日，东莞理工学院在我院隆重举行2006年迎春团拜会。我院200多名教职工参加了团拜会。

晚上，我院大礼堂内外张灯结彩，会场布置的庄严喜庆。礼堂前坪四周摆满了各式糕点、酒水和瓜果。900多名与会人员在这里互致问候，嘘寒问暖。东莞市人民政府吴道文副市长和东莞理工学院院长杨晓西教授分别在酒会上发表了热情洋溢的祝酒辞。他们对东莞理工学院在过去的一年里所取得的成绩表示祝贺，希望学院在新的一年里得到更大的发展，并祝愿全体教职工新年快乐，工作顺利，身体健康。

酒会席间，吴市长和院领导来到教职工中，向离退休老同志和教职工们一一敬酒，共同品尝美酒和佳肴。此情此景，大家心情喜悦，频频举杯，开怀畅饮。

酒会之后，与会人员步入礼堂，又一次相聚在一起，共同观赏教职工们自编自演的文艺节目。文艺晚会上，我院教职工演唱的《保卫黄河》、《年轻的朋友来相会》、《游击队之歌》、《啊，朋友再见》，以及男女声对唱，男声四重唱等节目，获得了观众阵阵的掌声，使晚会高潮迭连不断。
