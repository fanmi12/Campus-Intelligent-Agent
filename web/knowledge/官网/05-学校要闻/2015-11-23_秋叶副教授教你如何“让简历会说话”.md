# 秋叶副教授教你如何“让简历会说话”

制作简历，是不是让你很头疼呢？！11月21日晚，城院大讲堂第59讲在学术报告厅举行，邀请了武汉工程大学秋叶副教授作了“让你的简历会说话”的主题演讲，与广大城院学子分享制作简历的技巧与心得。

秋叶副教授，真名张志，国内最活跃的PPT达人、微博红人、实战网络营销专家，出版过《和秋叶一起学PPT》等多部著作。他用富有感染力的声调和语气，紧紧抓住了在座同学们的注意力。针对大学生最头疼的简历问题，秋叶副教授以“为什么要制作好一份简历”为开头，围绕着制作简历的基本要素，如版面、字体等内容，利用好小图标的功能，向同学们展示出制作一份简历的独特见解，并生动的实例来讲解简历排版与构思的重要性，开阔了同学们的视野，也使现场同学们深深折服。同时，他还提出了制作“一页纸”简历的新理念——简明概要地列出自身最有优势的吸睛点是成功制作一份简历的基础。

秋叶副教授指出，简历不是制作出的，是用自己的实际行动“创造、书写、历练”出来的，要从大一就开始来“书写”，越早越早好！同时，他还为同学们推荐了可提供多方面职业知识的微信、微博账号，以及推荐的优秀创意简历网站，帮助同学们了解更多的职场信息和求职技能。对有需要的同学，他推荐上网易云课堂学习关于制作PPT的网络教程——《和秋叶一起学PPT》。

秋叶副教授还建言所有大学生要学会“阅读、思考、行动、总结和分享”，这对自己将来的就业和人生将有很大的帮助。他语重心长地指出，学生应学会独立思考，而不是一味地向别人寻求问题的答案。

在互动环节，秋叶副教授就同学们提出的疑问一一耐心解答，告诉同学们应该抓住机遇发展自己，利用好大学的时间多做能力规划，包括专业能力及软能力，以扩充自己，成为自身非常优势的加分项，从而使得就业选择面变宽。其幽默而又富含哲理的话语和事例，赢得了一阵又一阵的掌声和喝彩声。

在讲座开始前，秋叶副教授与我院教师、同学代表等就学术及大学生关心的问题在图书馆进行了交流座谈。
