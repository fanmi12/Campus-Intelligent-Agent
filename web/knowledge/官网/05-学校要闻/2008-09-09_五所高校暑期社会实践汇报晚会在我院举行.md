# 五所高校暑期社会实践汇报晚会在我院举行

9月7日晚上，中国移动广东公司东莞城区分公司在我院大礼堂举办“‘飞’一般的暑假——中国移动爱心传递”2008暑期社会实践汇报晚会。我院党委书记朱志德、共青团市委副书记李纲、中国移动广东公司东莞分公司副总经理谢惠仪、中国移动广东公司东莞城区分公司总经理周长爱等领导和嘉宾，以及来自东莞理工学院、广东医学院、东莞理工学院城市学院、南博职业技术学院广东亚视演艺学校五所高校数百名学生观看了晚会。

今年暑假，来自东莞五所高校的107名学生参与了“中国移动爱心传递”2008年暑期社会实践活动。在45天的时间里，同学们先后进行了企业文化宣传、编辑《“飞”一般的暑假》简报、中国移动青年VS大学生联谊篮球赛、移动（员工）VS校园（学生）趣味数据业务知识擂台赛、 “QC课题研究”评比、中国移动2008年暑期勤工俭学（社会实践）征文比赛、编撰《中国移动2008年暑期勤工俭学（社会实践）成长集》等实践活动。

晚会上，我院学生演出了自编的舞蹈、歌曲联唱、诗朗诵等节目。我院06级人力资源本科2班的潘美兰、06级工商管理1班的尹可为同学向与会人员分享了QC研究成果。移动公司的领导为社会实践优秀分子颁发了证书和纪念品。
