# 城环系开展校风建设辩论赛

为了响应学院建设优良校风、学风的号召，进一步提高学生学习的积极性和主动性，城市与环境科学系组织开展了辩论赛、主题班会、学风整顿等一系列学风建设活动。

作为开场秀的辩论赛，于11月1日在机电楼二楼拉开了帷幕。辩论赛围绕“大学是否应该限制上网时间”辩题展开辩论，双方辩手抓住重要辩点，针锋相对，唇枪舌剑，赛场气氛紧张激烈，却又不失风度。
