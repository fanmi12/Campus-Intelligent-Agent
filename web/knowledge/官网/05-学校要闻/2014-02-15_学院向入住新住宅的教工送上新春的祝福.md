# 学院向入住新住宅的教工送上新春的祝福

2月12日，总务处处长翟耀明、副处长陈辉，后勤公司副总经理柳成荫代表学院领导到教工住宅看望新入住的教工。

翟处长在看望走访中表示，我们代表院领导前来看望新住户，欢迎大家入住新教工住宅，学院将继续加强教师住宅的配套设施建设，搞好住宅区的物业管理，为教职工创造良好的生活环境，让大家安心教学和工作。他希望教职工们多提合理化建议，共同建设和管理好教工住宅区。

据了解，党委宣传部工作人员范保乐已于年前入住教工新住宅。范保乐对前来看望的总务处、后勤公司的负责人表示感谢，也感谢办学方和学院为教职工安心教学做了一件大好事。
