# 我院男篮挺进“八强”

5月15日下午，我院男篮迎来最后一场小组赛，主场迎战广东科技学院队。本场比赛受到各方高度关注，现场球迷满座，气氛热烈非凡。

经过连续征战，我院未能将胜果继续扩大，以59:88惜败广科队。但在八场小组赛中，我院以“七胜一负”的辉煌战绩进入DUBA八强，并将在“八进四”的交叉淘汰赛上，对阵广东创新科技职业学院队。

据悉，在5月19日、22日举行“八进四”交叉淘汰赛之前，第二届东莞大学生篮球联赛还将于5月18日举行“全明星”赛，分别由A组组成“王者队”、B组组成“荣耀队”进行ＰＫ对决，期间还将举行啦啦队表演和“三分球”大赛。
