# 我院举办地震消防应急救援演练活动

11月9日，我院开展“地震?消防应急救援”演练活动，旨在强化师生的安全意识，掌握消防、防震知识，在全院上下掀起“人人讲安全，处处抓安全”的热潮。

本次演练在运动场、游泳馆、学生宿舍等多个场地同时进行，4000名多学参与了地震疏散救援、被困人员解救、伤病人员自救互救、救援物资发放和消防栓灭火器的使用等项目演习，并进行了消防设备参观与体验。

随着地震警报声的响起，同学们按照老师们的指示有序地撤离灾难现场，转移到运动场空旷的避难所。从演练整体上看，师生组织严密，行动迅速、准确、有序。

东莞市地震局局长陈伟东指导和观看了演练活动，他对师生们的表现给予了肯定，并指出了个别同学在疏散过程中出现的问题。

刘玉侠副院长在总结发言中，希望广大师生能通过这次演练，提高自身安全意识，掌握安全知识。在灾难发生的时候，能做到自救，最大限度地减轻灾难带来的影响。

参与演练的2017级文传系吴娜琳同学表示，这次演练使她了解了地震逃生技能，火灾自救方法以及如何正确使用灭火器。身临其境地感受到了火灾和地震灾害的危险性，增强了自身的安全防范意识。

东莞市地震局副局长彭瑞、寮步消防大队大队长文理华、副队长罗健，寮步镇泉塘派出所所长刘锡佳和王卫平院长、章德胜副书记导等领导出席了活动。学院工会副主席王锦峰、学生处副处长罗文芳担任此次活动的总指挥官。
