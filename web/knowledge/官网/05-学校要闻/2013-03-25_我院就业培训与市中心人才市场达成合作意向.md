# 我院就业培训与市中心人才市场达成合作意向

3月25日，东莞市中心人才市场高校毕业生就业指导培训部符浩南主任莅临我院，受到学院就业指导与培训中心主任江小卫的热情接待。双方就毕业生就业培训、创业培训、大学生素质提升及其它合作事项进行了深入商谈，并就“资源共享、全面合作”问题达成了共识。

双方一致同意将于近期签署合作意向书。
