# 城市学院隆重举行新生军训汇报表演暨开学典礼

城市学院2011级新生开学典礼

周致纳检阅受训新生

院长希望同学们“认识自我、认识学校、树立信心、互相尊重、心怀感恩，不断进取，追求卓越！”

受训新生士气高昂地通过主席台

整齐的队列方阵逐一经过主席台接受检阅

女子匕首操表演300多名新生表演海军旗语操

领导为在军训各项目评比中获得第一名的连队颁奖9月28日，东莞理工学院城市学院2011级新生军训汇报表演暨开学典礼在新校区隆重举行。东莞市人民政府副秘书长金行中，东莞市教育局局长杨靖波，东莞市寮步镇党委书记何绍田，城市学院顾问杨元惺，西北工业大学、博士生导师史忠科教授，原中国人民解放军武警总队后勤部部长刘冀燕大校，中国人民解放军空军某局副局长王润全大校，东莞理工学院领导周致纳、黄碧莲、吕琦元、安少华，城市学院名誉董事长麦彦桐、董事长麦照容，理事黎建烨、王江水，院领导朱志德、杨敏林、程发良、朱冰、张林、陈丁堂、麦绮琳及院机关各处室、教学系部负责人，麦彦桐夫人曾群带、麦照平、麦燕娣、麦燕红等领导和嘉宾出席了活动。

4000多名军训新生接受检阅

上午9时，4000多名军训新生分成45个受阅方阵和4个表演方阵，整齐、严肃、士气高昂地聚集在新校区运动场上，开始接受领导检阅与军训汇演。院学生处处长章德胜与沙角部队军训团团长李广涛主持了军训汇报表演。

9时05分，东莞理工学院党委书记周致纳在军训团刘参谋的陪同下，检阅了受训新生。

随后，45个方阵依次排着整齐的队伍、迈着矫健的步伐，士气高昂地通过主席台，向在座领导和嘉宾展现了城院学子的青春活力。随后，4个表演方阵还奉献了一场精彩纷呈的军事训练汇演——女子匕首操、男子军体拳、素质拓展训练和海军旗语等科目表演，多次获得全场雷鸣般的掌声。经过严格的检阅， 4000多名新生在沙角部队军训团教官们的严格教导下，以优异的成绩圆满地完成了历时10天的军事训练任务。在军训汇演上，学院还公布了各军训项目的评选结果，并对获得各项目第一名的连队进行颁奖。

百万元重奖优秀新生

当日上午11时，学院还在综合馆举行了2011级新生开学典礼仪式。杨敏林副院长主持了开学典礼仪式。

仪式上，学院斥资88.5万元重奖2011级优秀新生，东莞理工学院城市学院名誉董事长麦彦桐向冯培健、章理、卓威、黄海、黄沛亮、黄灼辉、黎栩静、梁国杰、苏东英、谢泳芝、梁国柏等11名超2A录取线的新同学颁发了每人5万元的一等新生奖学金，周致纳书记和麦照容董事长分别向黄秋燕、李嘉玲等29名新同学颁发了每人1万元的二等新生奖学金，城市学院顾问杨元惺、东莞市教育局局长杨靖波、城市学院院长安少华分别向45名优秀新生颁发了每人1000元的优秀新生奖。值得一提的是其中6位获得一等新生奖学金同学的家长特地来参观开学典礼仪式，见证孩子们的这一辉煌时刻。

为感谢东莞市各级政府对城市学院及新校区建设的大力支持，周致纳书记代表城市学院特向寮步镇委书记何绍田赠送了牌匾，表达对寮步镇委、镇政府的感激之情。

“唯真求实，明德有为”八字赠城院学子

东莞理工学院党委书记周致纳、城市学院院长安少华、董事长麦照容先后在典礼仪式上发表讲话。麦董事长坦言：“我人生中最自豪的一件事，就是与东莞理工学院合作建设城市学院新校区。为此，我和我的家人将与学院全体教职工一道，将城市学院建设成为国内一流本科独立院校”。同时，他还将 “唯真求实，明德有为”八字赠与广大学子，与之共勉。

周致纳书记在讲话中代表东莞理工学院向城市学院圆满完成2011级新生军训及举行开学典礼仪式表示热烈祝贺，并向城市学院名誉董事长麦彦桐先生对东莞高等教育事业做出的重大贡献，表示崇高的敬意。周致纳书记希望广大新同学珍惜在新校区的大学时光，刻苦学习，早日成材，并相信“城市学院的明天一定会更加美好！”
