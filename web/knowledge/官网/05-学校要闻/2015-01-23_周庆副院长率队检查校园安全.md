# 周庆副院长率队检查校园安全

1月15日，周庆副院长率学院院办、总务处、学生处、教务处等相关部门负责人，对校园环境、教学楼、图书馆、学生公寓、饭堂和教师住宅等场所进行了全面的安全检查。

周庆副院长指出，寒假期间，校园安全工作不能松懈，各部门要认真落实安全制度，做好安全防范工作，营造祥和、有序、文明的校园环境。
