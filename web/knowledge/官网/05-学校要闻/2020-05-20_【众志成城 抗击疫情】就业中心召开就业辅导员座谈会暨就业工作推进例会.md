# 【众志成城 抗击疫情】就业中心召开就业辅导员座谈会暨就业工作推进例会

为传达贯彻省推进高校毕业生就业工作电视电话会议精神，保障疫情期间2020届毕业生就业工作顺利有效进行，5月18日，我校就业中心召开就业辅导员座谈会暨就业工作推进例会。会议由学生处处长杜鹏举主持。

学生处处长杜鹏举传达了省推进高校毕业生就业工作电视电话会议的精神，针对3-4月就业工作进行总结，并就各学院就业工作的具体情况与在座的辅导员进行了分享和交流。在交流中，各学院针对 “一院一策”具体的部署情况及存在的困难分别作了发言。

针对辅导员反映的毕业生就业积极性不足和收集就业信息难度大两个问题，杜鹏举处长明确提出：1.加强职业生涯规划，引导学生树立正确的就业观念。2.积极挖掘、积累和调动周边优质企业资源,提升就业“质”与“量”。3.理清辅导员个人职责，合理分工，形成合力。4. 强化网格化管理，保证信息传达通畅，建议以专业为单位建立沟通交流群，并动员专任教师参与就业工作，产教融合。5.树立党员先锋模范作用，发挥党员群体影响力。

就业中心林蓉主任针对5-6月就业工作进行了部署。她强调近期各学院应重点关注省“三支一扶”申报项目、毕业生调整方案、就业创业补贴申报、毕业生档案以及湖北籍、家庭困难学生的帮扶跟进工作。她还预告广东省教育厅2020年高校毕业生就业统计工作培训班的培训安排，并要求各学院就业辅导员按时参加。
