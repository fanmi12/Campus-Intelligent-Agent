# 2014年城院运动会今日开幕

天朗气清，惠风和畅。11月19日，我院2014年运动会在田径场隆重开幕。今年是我院建校十周年，所以把“十年城院，百年辉煌”作为此次运动会的主题。东莞理工学院城市学院领导杨敏林、王卫平、陈丁堂、张林、章德胜、高香林、麦绮琳，机关各处室、各教学系部负责人与4000多名运动员、裁判员共同欣赏了运动会开幕式盛况。

8点整，雄壮的国歌声在田径场上空奏响。国旗队、鲜花方队、彩旗队、裁判员队、各系运动员代表队、教工代表队的运动健将们踏着矫健的步伐依次入场接受检阅。各系部代表队在主席台前，用各具特色的方式展示青春风采和城院学子勇于挑战、敢于超越的城院精神。五颜六色的方阵，雄壮有力的口号，青春活力的表演使田径场变成了欢乐的海洋。

高香林副院长为开幕式致辞。他表示，我院要认真开展学生体育、竞技体育与群众体育运动，充分发挥体育育人功能。本次运动会以育人为本，促进学生成长为出发点，以“快乐奋斗，青春飞扬”为口号，做到“每天锻炼一小时”，力争“快乐工作五十年”，达到“健康生活一辈子”。希望运动员们奋力拼搏，赛出风格，赛出水平，充分展现城院人的风采。同学们要走出宿舍，走向运动场，努力提高自身的健康水平和身体素质。

运动员代表陈佳璇和裁判员代表陈家威先后宣誓，表达了积极参与运动的热情，要发扬“更高、更快、更强”的奥运精神，恪守体育道德，赛出水平，赛出风格。

运动会开幕式的重头戏是近2000名师生表演的大型团体操。团体操分为“祥和?太极”、“奋进?搏击”、“拼搏?武术”、“飞扬?青春”、“十年?翻花”五个章节。

在欢乐祥和的进行曲中首先表演的是城院校旗展示。180名学生手牵手簇拥在百余平方米的校旗周围，伴随院旗同时出场的是街舞和搏击操表演队伍。激情四射、活力动感的街舞表演为寒冬的早晨注入了青春的热力，迸发着城院师生蓬勃的朝气。200名大一新生表演的“搏击操”，以整齐的方阵、统一的着装、强劲的节奏、优美的动作，表达了城院学子对本届运动会热情而美好的祝愿。他们英姿飒爽、刚劲有力的顶膝动作与富有气势的呐喊，彰显了城院学子不甘示弱、顽强拼搏的优秀品质。整套动作凝聚着搏击操的精华“力量、灵活、信心”，同时也象征着城院的明天会蒸蒸日上，永远充满活力。阳刚有力的刀术、棍术、剑术操表演，一招一式尽显学子风采，更是让全体观众热血沸腾。

第四章“飞扬?青春”掀起了全场的高潮，300名大一学生组成红旗方阵，在操场上不时地交换队形，使田径场变成了一片动感十足的“红海”。

开幕式的压轴戏是翻花的表演，800名女生身着洁白的衣服，手持翻花扇，不断地变换着扇花的颜色，犹如一群大学生在知识的海洋中翻阅书本，追求知识，汲取精华。场上时而呈现出斑斓的“彩虹”，时而呈现绚烂的向日葵，最后翻花的造型酷似一个巨大的数字“10”，寓意城院运动会历经十年风雨，成就十年精彩。

开幕式之后，领导与嘉宾们在校旗上签名题词，各项比赛随之拉开序幕，运动员开始了各个项目的角逐。

据悉，为期两天的运动会将进行100米、200米、400米、800米、跳远、跳高、铅球等30个项目的比赛，运动会还为教职工准备了一分钟跳绳、猪八戒背媳妇，慢骑自行车，保龄球等趣味运动比赛项目。
