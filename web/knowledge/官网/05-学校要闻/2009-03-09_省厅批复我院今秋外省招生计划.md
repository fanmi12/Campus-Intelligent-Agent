# 省厅批复我院今秋外省招生计划

3月6日，广东省教育厅具文批复，同意我院今秋外省招生申报计划，继续在内蒙古、辽宁、黑龙江、江苏、浙江、安徽、福建、江西、山东、河南、湖北、湖南、广西、海南、重庆、四川、甘肃、新疆、甘肃19个省区招收150名本科新生。这一计划是广东省根据教育部2009年总体招生计划确定的。

据悉，我院同时上报的招生计划还包括：今年招生的总人数2500人，其中本科生计划招录1300人（包括专升本100人，外省150人）；专科招生计划招录1200人（包括普通高考960人，3+证书240人）。目前，这些计划尚待批复。
