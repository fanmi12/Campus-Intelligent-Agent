# 我校召开教师党支部书记学习培训会

11月8日下午，我校在行政楼407室召开了教师党支部书记学习培训会。党务工作部副部长叶凯贞、各二级学院教师党支部书记、直属支部组织委员参加了会议。

叶凯贞同志传达了近期上级党委关于教师党支部建设的有关要求，要求各教师党支部结合“不忘初心、牢记使命”主题教育，着力解决教师队伍建设中存在的突出问题.教师党支部要切实发挥政治把关作用和在教师思想政治工作中的主体地位，加强教师党支部书记能力培养，进一步提升支部书记谋划党建和业务融合能力。加强优秀教师党员发展工作，加大在高层次人才、青年教师中发展党员，提高党员发展质量。

党务工作部组织科陈雅琴老师讲解了我校发展党员工作实施办法，梳理了发展党员的“5阶段25流程”，以及实际工作中重要的时间节点。希望各教师党支部严格按照程序开展发展党员工作，及时将发展步骤录入党务系统。
