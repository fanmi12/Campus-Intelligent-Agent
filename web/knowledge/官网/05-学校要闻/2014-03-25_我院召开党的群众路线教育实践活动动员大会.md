# 我院召开党的群众路线教育实践活动动员大会

根据中央和省委、省委教育工委的统一部署，在东莞理工学院党委和省委教育工委指导组的指导下，3月24日，我院在学术报告厅召开党的群众路线教育实践活动动员大会。大会认真学习贯彻中央精神，对全院教育实践活动进行动员部署。东莞理工学院党委副书记吕琦元发表讲话，学院党的群众路线教育实践活动领导小组组长、党委书记王卫平作动员报告。大会由党委副书记章德胜主持。

党员、中层以上干部参加了大会。

深入理解中央和省委的精神

吕琦元对我院党委围绕扎实开展教育实践活动所做的大量有效的前期工作给予充分肯定，对开展好教育实践活动提出明确要求：一是要深入理解中央和省委的精神，以饱满的政治热情和良好的精神状态投入到教育实践活动中；二是要正确把握教育实践活动的基本要求，确保教育实践活动不走过场；为确保活动取得实效，他要求我院党委在“突出抓好马克思主义群众观点的学习教育，着力解决人民群众反映的问题，以整风精神大力弘扬批评和自我批评的优良传统，充分调动群众的积极性，把边整边改贯穿活动始终，切实发挥领导示范推动作用”等方面下功夫。三是要坚持高标准严要求，联系实际，把教育实践活动落到实处。在教育实践活动中要坚持问题导向，坚持教育实践并重，坚持边学边查边改，把学习教育贯穿始终，把整改落实贯彻始终，善始善终，善做善成，使教育实践活动各个环节工作有效衔接、相互贯通。

教育实践活动总的要求、重点、步骤与方法

王卫平指出，全院党员、干部都要紧扣要求，深入开展党的群众路线教育实践活动。要准确把握“为民务实清廉”的活动主要内容；要准确把握活动的主要任务，结合实际，从反对形式主义，反对官僚主义，反对享乐主义，反对奢侈之风等四个方面进行查摆整改；要准确把握“照镜子、正衣冠、洗洗澡、治治病”的活动总要求；要准确把握活动的步骤安排，重点抓好“学习教育、听取意见”、“查摆问题、开展批评”、“整改落实、建章立制”三个环节。王卫平强调，在活动过程中做到“思想认识、学习教育、查摆问题、落实整改、长效机制”五个到位。

把思想和行动统一到中央和省委的部署上来

王卫平指出，全院党员、干部要提高认识，深刻领会教育实践活动的重大意义。在全党深入开展党的群众路线教育实践活动是党的十八大作出的重要部署。习近平总书记强调，第二批党的群众路线教育实践活动是第一批的延伸和深化，要深刻认识第二批教育实践活动的重要性和紧迫性，切实增强思想自觉和行动自觉。基层单位同人民群众的联系更直接，其不良作风更直接损害群众利益、伤害群众感情。必须着力解决发生在群众身边的腐败问题，认真解决损害群众利益的各类问题，切实维护人民群众合法权益。习近平总书记的重要讲话,为我们开展好第二批教育实践活动提供了重要遵循，指明了方向。我们要紧密结合学院实际，深刻认识开展教育实践活动的重大意义，把思想和行动统一到中央和省委的部署上来。

重点解决“四风问题”

要从“四风”突出问题表现中认识开展教育实践活动的现实紧迫性。对作风之弊、行为之垢来一次大排查、大检修、大扫除。

总的要求是“照镜子、正衣冠、洗洗澡、治治病”；集中解决的问题是“四风”；基本方式方法是正面教育为主、开门搞活动、以整风精神开展批评和自我批评，并坚持领导带头；基本着眼点是整改突出问题和建立长效机制。

“照镜子”主要是要学习和对照党章，对照廉政准则和中央八项规定要求，对照改进作风要求，对照学院师生员工期盼，对照教育教学管理工作一线先进典型，查找宗旨意识、工作作风、廉洁自律方面的差距。

“正衣冠”主要是按照为民务实清廉的要求，严明党的纪律特别是政治纪律，敢于触及思想，正视矛盾和问题，从自己做起，从现在改起，端正行为，维护良好形象。

“洗洗澡”主要是以整风精神开展批评和自我批评，深入分析出现形式主义、官僚主义、享乐主义和奢靡之风的原因，坚持自我净化、自我完善、自我革新、自我提高，既要解决实际问题，更要解决思想问题。

“治治病”主要是坚持惩前毖后、治病救人方针，区别情况，对症下药，对作风方面存在问题的党员、干部进行教育提醒，对问题严重的进行查处，对损害师生员工利益的不正之风和突出问题进行专项治理。

“四风”现象在我院少数党员、干部中也不同程度地存在，主要表现有：（1）管理工作上，不求有功、但求无过，做表面文章、精神懈怠；工作不催不办、不推不动，执行不力,缺乏责任意识；缺少开拓进取、干事创业的精气神；为广大师生员工服务的宗旨意识不强,办事效率低，意志消沉,贪图安逸,甚至理想信念动摇。

（2）教风上，为人师表意识不够强，上课照本宣科,不问学生感受,不注重教学效果，对学生关爱不够，缺乏严谨负责、科学求是的学术品格。（3）学风上，态度不端正，自由散漫，得过且过，不求上进。

我们必须坚持从严治党,以无私无畏的勇气，对照党纪条规,深入剖析产生问题的原因,认真加以整改。

整个教育实践活动分为四个环节

王卫平根据党委的部署，对我院此次教育实践活动做了具体安排。他说，教育活动从2014年2月启动，暑假前完成各环节工作，8月底前完成总结。整个教育实践活动分为四个环节：第一个环节：制定方案、部署工作。时间是2014年2月—3月31日。

第二个环节：学习教育、听取意见。时间是2014年4月1日?4月30日。通过动员大会、专题会议、专题网站、专题宣传栏、院领导接待日等多种形式，采取集中学习、自学和研讨相结合的办法，重点抓好学习宣传和思想教育，深入开展调查研究，广泛听取干部、群众和师生意见。在此阶段，要注重结合实际抓学习教育，并且注意学习教育要与听取意见、解决问题同步推进；要认真学习和深刻领会习近平总书记3月17-18日在河南省兰考县调研指导党的群众路线教育实践活动时的重要讲话精神。

第三个环节：查摆问题、开展批评。时间是2014年5月1日?5月31日。围绕“为民务实清廉”要求，通过群众提、自己找、上级点、互相帮，认真查摆“四风”方面的问题，进行党性分析和自我剖析，开展批评和自我批评。

第四个环节：整改落实、建章立制。时间是2014年6月1日?8月31日前。针对存在的问题，提出解决对策，制定和落实整改方案。对一些突出问题进行集中治理；制定整改任务书、时间表，并在一定范围内公示；注重从体制机制上解决问题，使贯彻党的群众路线成为党员、干部长期自觉的行动；召开党的群众路线教育实践活动总结大会。

取得教育实践活动实效的几点要求

王卫平在讲话中要求各级领导干部、党员必须做到：一是要加强领导、落实责任。院内各单位党政领导，要深入发动党员、干部和师生群众抓落实，尽快制定本单位的行动计划，不打折扣、不走过场，确保教育实践活动健康顺利推进。

二是要严密组织，统筹兼顾。坚持围绕中心、服务大局,把开展活动与规范办学、提高教学质量、保持学院稳定、树立良好的教风、学风、校风结合起来。围绕加快建设适应和促进区域经济社会发展的特色鲜明的应用型本科院校查找问题和差距，落实整改，努力把活动成果转化为创新强校、改革发展的动力，让师生群众受益。通过教育实践活动引导党员、干部增强政治意识、大局意识、责任意识，提高服务发展、服务教学、服务群众的能力，认真做好今年各项工作,确保两手抓、两不误、两促进。

三是要讲求实效。要以问题为导向、教育实践并重、边学边查边改,把学习教育贯穿始终,把整改落实贯穿始终,使教育实践活动各个环节的工作有效衔接、相互贯通。确保活动不虚、不空、不偏,不走过场。

四是要做好宣传引导。高度重视宣传舆论工作，充分利用院报、校园网、宣传栏、各种新媒体等媒介，宣传中央和省委的决策部署，充分反映活动成效，总结提炼出值得推广的好典型。
