# 牛熠、廉玉忠二位博士、教授履任新职

学院近日决定，任命牛熠博士、教授为教务处处长，廉玉忠博士、教授为计算机与信息科学系主任。

3月25、26日，学院领导杨敏林、朱志德、章德胜、高香林分别在教务处、计信系宣布任命决定，出席任职单位教职工大会并作重要讲话。

牛熠处长、廉玉忠主任在见面会上表示，不辜负学院领导的信任和重托，一定把工作干好，让领导放心，让教工满意。

杨院长希望教职工要全力支持新任职干部的工作，新任职的干部也要加强学习，密切联系群众，发扬所在单位的优良传统，在学科专业发展、师资队伍建设等方面，做出新的成绩。

牛熠博士、教授（前排右一），廉玉忠博士、教授（前排左二）25日，教务处见面会会场26日，计信系见面会会场
