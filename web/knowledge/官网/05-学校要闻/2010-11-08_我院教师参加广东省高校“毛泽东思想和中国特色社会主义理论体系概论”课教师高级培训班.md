# 我院教师参加广东省高校“毛泽东思想和中国特色社会主义理论体系概论”课教师高级培训班

11月5日—6日，广东省高校“毛泽东思想和中国特色社会主义理论体系概论”课教师高级培训班在南方医科大学举行。全省129所高校的思政专家、学者及“毛泽东思想和中国特色社会主义理论体系概论”课教师参加了会议。我院思想政治理论课教学部主任何鹏举教授、王芳仪老师应邀参加了培训会。

会议就课程教学改革进展、课程修订意见、课程面临的困难和问题、深化课程体系、教学研究与教学设计研究、《概论》课程理论的逻辑分析与现实的问题解释等问题进行了广泛、深入和系统的交流。
