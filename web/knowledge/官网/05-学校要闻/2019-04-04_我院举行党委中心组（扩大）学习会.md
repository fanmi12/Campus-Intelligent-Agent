# 我院举行党委中心组（扩大）学习会

4月3日下午，学院党委中心组扩大学习会在行政楼112会议室召开。东莞市委宣讲团成员、东莞市委党校经济教研室主任查日升教授应邀作了“以粤港澳大湾区建设为纲、加快建设‘湾区都市 品质东莞’”的主题讲座。

学院党委委员、学院领导、各单位负责人、党总支（直属支部）书记、副书记、副高职称以上教师、全体辅导员和思政部教师参加了学习会。党委书记章德胜主持会议。

查日升教授在报告中着重介绍了粤港澳大湾区建设的重大意义和《规划纲要》的核心内容，阐述了粤港澳大湾区在国家区域发展战略中的重要地位。结合东莞地方社会发展实际，他进一步分析了东莞融入粤港澳大湾区的具体思路，为我院更好地推进相关工作提供了重要的启发。

章德胜书记指出，《粤港澳大湾区发展规划纲要》是指导粤港澳大湾区当前和今后一个时期合作发展的纲领性文件。全院教职工要认真学习贯彻习近平总书记关于粤港澳大湾区建设重要讲话精神，把思想和行动统一到以习近平同志为核心的党中央战略部署上来。各单位要联系工作实际，结合我院建设特色鲜明的高水平应用型本科院校的发展目标，思考如何在粤港澳大湾区建设的重大契机中，进一步抢抓机遇，提升学院内涵发展，提高人才培养质量。各党总支（直属支部）及有关单位要继续做好《粤港澳大湾区发展规划纲要》学习与宣传工作，开展形式多样、内容丰富的学习宣传活动，继续在校内形成良好的学习和舆论氛围，进一步推动广大师生积极投身新时代粤港澳大湾区建设的浪潮之中。
