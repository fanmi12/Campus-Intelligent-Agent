# 我院部署启动党的群众路线教育实践活动

2月27日，院领导办公会议上，党委书记王卫平传达省教育工委关于开展民办高校党的群众路线教育实践活动动员会议精神，研究部署我院党的群众路线教育实践活动。

2月26日上午，省教育工委召开了民办高校党的群众路线教育实践活动动员部署会议。会议上，省委教育工委书记、省教育厅党组书记、教育厅厅长罗伟其同志作了动员报告，提出了四点要求：一、统一思想，提高认识，深刻领会教育实践活动的重要意义和现实紧迫性。二、准确把握教育实践活动的指导思想和目标要求，集中解决民办高校办学过程中的突出问题。三、精心组织，周密部署，扎实开展学校群众路线教育实践活动。四、切实加强对教育实践活动的组织领导。

据悉，我院是第二批开展党的群众路线教育实践活动的高校。在院领导会议上，与会领导学习了党中央《关于开展第二批党的群众路线教育实践活动的指导意见》、《粤第二批深入开展党的群众路线教育实践活动实施方案》和《省委教育工委指导民办高校开展党的群众路线教育实践活动实施方案》等文件，研究拟定我院《关于深入开展党的群众路线教育实践活动实施方案》（草案），成立领导小组以及一些准备工作。

根据省教育工委要求，我院党的群众路线教育实践活动拟于2014年2月26日启动，8月底前结束。活动拟分三个环节开展：第一个环节，学习教育、听取意见；第二个环节，查摆问题、开展批评；第三个环节，整改落实、建章立制。活动的主要任务是，教育引导党员干部树立群众观点，弘扬优良作风，解决突出问题，保持清廉本色，使干部作风进一步转变，干群关系进一步密切，为民务实清廉形象进一步树立。

院党委要求，全院党员、干部和广大教职工要认真学习领会党中央关于深入开展党的群众路线教育实践活动的文件精神，进一步提高对开展教育实践活动重大意义和紧迫性的认识，按照党中央和广东省委要求，积极投入到教育实践活动中来。以改进工作作风、密切联系群众的实际行动，努力办好人民满意的教育，将我院建设成为适应和促进区域经济社会发展、特色鲜明的应用型本科院校。
