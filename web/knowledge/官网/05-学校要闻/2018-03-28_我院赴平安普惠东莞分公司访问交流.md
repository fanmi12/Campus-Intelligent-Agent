# 我院赴平安普惠东莞分公司访问交流

3月26日，副院长黄兢、招生就业处处长孔增强、就业中心主任江小卫等一行来到平安普惠东莞分公司参观交流，受到该公司总经理刘祖英的热情接待。

黄兢副院长此行旨在进一步深化与平安普惠公司的友好合作，拓宽学子就业平台，调研我院毕业生就业发展前景。

目前，我院有60多名毕业生在平安普惠公司工作。刘祖英总经理对我院毕业生的工作能力和表现给予了充分的肯定。她说，城院学生为人谦和、心地善良，能够很好地处理与同事和领导的关系，顺利融入大家庭。另一方面，城院学生专业理论知识扎实，学生在培训的过程中一教就会、一点就通，工作效率较高。

在刘祖英总经理的陪同下，黄兢副院长参观了平安普惠东莞分公司，听取了我院校友对工作环境及薪资待遇的介绍。校友表示，母校注重学生技能锻炼，学到了一生受用的本领，非常感谢母校的培养。

黄兢副院长对平安普惠东莞分公司企业文化及用人理念表示欣赏。他强调校企合作的重要性，指出我院高度重视毕业生就业工作，希望企业通过来学校举办宣讲会、专场招聘会等形式加强合作，同时促进我院对用人单位人才需求的了解，从而结合市场导向，更有针对性地培养人才。
