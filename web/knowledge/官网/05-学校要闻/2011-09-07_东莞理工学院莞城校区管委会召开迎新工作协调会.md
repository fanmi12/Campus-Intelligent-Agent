# 东莞理工学院莞城校区管委会召开迎新工作协调会

协调会会场

张林副院长率队检查东莞理工学院莞城校区新生宿舍

今年，东莞理工学院将有933名2011级新生在我院老校区(简称莞城校区)就读。为了切实做好迎新各项工作，确保新生安全顺利入学， 9月6日，东莞理工学院莞城校区管委会在我院315会议室召开迎新工作协调会。东莞理工学院副校长、城市学院院长安少华出席协调会。

会上，东莞理工学院党委委员、校办主任、东莞理工学院莞城校区管委会主任邢大立，解读了迎新方案，提出需要我院相关部门协助完成的一些工作。我院与会的部门负责人表示，迎新的前期准备已经就绪，将尽全力完善和优化相关工作。

安院长强调，迎新工作是展示东莞理工学院和城市学院形象、显示管理和教学能力的好机会，也是对各部门工作的检验。大家务必树立一盘棋的思想，集中精力，狠抓落实，不分彼此，争取把迎新工作做得更好。要以学生为中心，凡是对学生有利的事情都要大胆主动去做。要营造良好的校园氛围，让新生迅速融入大学生活。要克服困难，以饱满的工作热情迎接莘莘学子的到来,以高效优质的服务让新生满意、使家长放心。
