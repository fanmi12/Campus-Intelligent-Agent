# 中信银行、狄邦教育集团领导莅临我校考察调研

11月29日，中信银行广州分行党委委员程瑞，狄邦教育集团总裁张博文、副总裁王洁等领导一行8人莅临我校考察调研。

广东鸿发投资集团有限公司副总裁、学校董事麦建红，广东鸿发投资集团有限公司董事长助理麦子俊，广东鸿发教育文化集团有限公司总经理陈超群热情接待了客人，并陪同客人参观了校史馆及校园。

双方举行了座谈，就合作办学、项目运营、教学管理、师资团队等方面推进国际化教育进行了经验交流与探讨。
