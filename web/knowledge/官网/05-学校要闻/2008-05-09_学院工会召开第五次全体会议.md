# 学院工会召开第五次全体会议

5月8日，东莞理工学院城市学院第一届教职工代表大会暨工会会员代表大会在学术报告厅举行第五次全体会议。

与会代表认真听取了行政副院长张林博士关于《东莞理工学院城市学院人事管理制度改革方案》以及相关情况的说明。人事处副科长方妙英代表《东莞理工学院城市学院人事管理制度改革方案》课题组向代表具体介绍了《方案》的基本内容。

全体代表经过充分讨论，一致认为此方案制定合理，切实可行，符合本院的实际情况。该方案的实施，对机构设置、定岗定编、绩效考核、建立科学的薪酬体制，以及吸纳人才和学院的长远发展具有深远的意义。会议审议通过了《东莞理工学院城市学院人事管理制度改革方案》。

学院工会主席章德胜副教授主持会议。
