# 广东省教育考试院一行到我校考察交流

7月20日下午，广东省教育考试院副院长许顺兴，二级调研员郑建辉，原常弘、文宇、余楚龙一行五人到我校考察交流，并在六楼会议室举行交流座谈会。我校常务副校长方伟华，校长助理孔增强，学校办公室副主任冯江博，品牌建设中心副主任万文双，后勤保卫处副处长段妍君，纪委办公室主任陈东汉，后勤保卫处副处长刘智航，招生办公室主任何钊威等人陪同调研。校长助理孔增强主持本次座谈会。

座谈会上，方伟华副校长

代表我校

向许顺兴一行

到我校交流指导表示热烈欢迎。会议开始，招生办公室主任何钊威讲述了我校发展历程、办学愿景、办学使命等内容，并汇报近年来我校招生工作情况。他表示，我校在2023年招生规模持续破万，目前是创办校以来最大的在校规模，招生工作在扎实中推进，成效明显，总体呈现稳中向好态势。

方伟华副校长介绍了我校的整体资源建设、教学质量保障方式与招生机构配置。他表示，我校将积极总结与创新招生工作方法，靶向发力，做到“全校一股绳、宣传一张网、招生一盘棋”，全校各部门、学院把服务思想集中到、把具体行动落实到招生各项工作中来。同时，期待在广东省教育考试院的支持下，深入开展广东在粤的招生宣传工作，协同推进一流生源前置引导。

许顺兴对我校的热情接待表示感谢，回顾了我校历年来诸多教学成果，并给予了肯定。他提出，要重视招生宣传工作，塑造科学服务理念，从实打实中做好高校教育，从实际中构建学校口碑，为家长与学生“减负提质”，实现校园高质量发展。

会前，广东省教育考试院副院长许顺兴

一行在方伟华副校长的陪同下参观了学校沙盘。
