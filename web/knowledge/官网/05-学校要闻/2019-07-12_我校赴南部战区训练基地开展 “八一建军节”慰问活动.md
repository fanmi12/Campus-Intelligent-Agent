# 我校赴南部战区训练基地开展 “八一建军节”慰问活动

畅叙鱼水情谊，共话军地发展。“八一”前夕，校领导王卫平、刘玉侠率领学校慰问团于7月11日赴南部战区某训练基地开展“八一建军节”拥军慰问活动。

王卫平代表学校向基地全体官兵致以节日的祝贺和诚挚的问候。他表示，南部战区训练基地和我校一直以来保持着密切联系，驻地官兵历年来积极参与和支持我校的建设与发展，特别是为我校新生开展国防教育和军事训练作出了突出的贡献。学校将坚定不移地弘扬拥军优属的良好传统，积极推动学校与基地的建设与发展。

南部战区训练基地刁主任对慰问团的到来表示热烈欢迎。刁主任指出，基地与学校一直以来都保持良好的交流，全体官兵将以实际行动回报党和人民的厚爱，努力为促进城市学院创建百年名校作出更大的贡献。
