# 我院举办首届趣味应用文书大赛

4月26日晚，“玩转文书，以赛促学”首届趣味应用文书大赛决赛，在学术报告厅举行，这次大赛由院团委主办、政法系团总支学生会承办，李上文、陈晓萍、刘军、都振华、李阳桂、韦朝毅六位老师担任赛事评委。

决赛分为“你听我说、你问我答、你选我写、你看我抢”四个环节。六位选手不仅展示了自己优秀的作品，还对作答考题和抢答各类情景模拟题应对自如，比赛精彩纷呈，现场气氛紧张激烈。

经过激烈的角逐和评委的评判，15级法学1班周宇佳同学凭着稳定的发挥获得冠军，14级保险1班刘炳威同学获得亚军，15级高文2班唐樱艳同学获得季军。14级商英5班吴咏欣、15级高文2班胡越余、15级行管1班孙正权三位同学获得个人优秀奖。

政法系主任刘杰教授认为，举办应用文书比赛能够活跃校园文化生活，培养学生应用技能，为今后工作打下坚实的基础。这次比赛将应用文书同趣味结合一起，对培养人才也是一种创举。
