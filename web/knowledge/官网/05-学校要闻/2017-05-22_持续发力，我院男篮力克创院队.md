# 持续发力，我院男篮力克创院队

5月19日，DUBA“八进四”交叉淘汰赛首轮开战。我院坐镇主场迎来对手广东创新科技职业学院队，凭借第四节的节奏压制，我院以102∶84战胜对手。

首节比赛，对方4号梁达维就打出3+1，吹响进攻号角。我院19号叶锐城发挥出色，连投带罚带领同伴打出16∶6的小高潮。但创院不甘示弱，13号陈伟钊连续命中3记3分。首节战罢，我院以22-21略微领先。

次节开始，双方加快节奏，攻势如潮，比分也交替上涨，以46∶45结束上半场。

易边再战，我院先发制人，打出一波7∶0后，双方互有来回，分差一直保持在10分内。

三节结束时，我院手握9分优势以73∶64进入第四节，比赛也开始白热化。我院加快比赛节奏，里突外投，对方失误连连，不断将分差拉大，最终我院以102∶84拿下比赛，获得淘汰赛开门红。
