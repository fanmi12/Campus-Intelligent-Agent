# 【众志成城 抗击疫情】我校召开2020届毕业生就业工作推进会

为深入学习贯彻落实教育部关于应对新冠肺炎疫情做好2020届全国普通高等学校毕业生就业创业工作的通知精神，传达广东省2020届全省普通高校毕业生就业工作网络视频会议精神，切实做好疫情期间我校2020届毕业生就业工作，4月2日下午，我校召开2020届毕业生就业工作推进会，校长王卫平、党委书记章德胜出席会议、各相关职能部门负责人、各二级学院院长、就业中心全体老师参加会议。会议由学生处处长杜鹏举主持。

杜鹏举处长首先向参会人员通报了近期国家教育部、广东省教育厅关于加强2020届毕业生就业指导工作的文件精神，重点介绍了针对今年2020届毕业生的就业工作的总体部署，最后对毕业生就业状况监测工作做了动员。他指出，目前是抗击疫情的特殊时期，是学生求职择业的关键时期，大家的工作将会面临更多挑战。结合疫情期间工作重点，他对2020届毕业生就业创业工作提了四点建议：第一，各系要高度重视毕业生就业工作，制定符合本学院的工作方案，各环节分工联动，落实专人专岗，做到精准精细，落实落细到每一个毕业生，举全校之力做好今年就业工作。第二，疫情期间，毕业生就业工作和就业服务由原来的线下逐步转为线上，各二级学院要多措并举，开拓渠道，千方百计推荐毕业生就业。第三，强化精准统计，提升监测实效。第四，加强个性化指导，重点帮扶困难群体。

校党委书记章德胜在会议上强调：第一要提高政治站位，深入贯彻国家教育部、广东省教育厅关于加强2020届毕业生就业指导工作的文件精神，进一步认识当前就业工作的重要性。疫情期间就业工作该应该从五个方面推进:1、各系按要求成立工作小组，落实专人专岗，并且针对就业工作制定相应方案。2、实现“点对点，一对一”，建立“院系领导-辅导员-班主任-毕业生”联动模式，加强了解近期国家教育部及广东省教育厅的就业政策、就业平台，让毕业生切实了解学校为就业提供的信息与平台。3、各学院加强规范管理，保障就业工作顺利有序地进行。4、做好宣传工作，例如以《致毕业生的一封信》的形式，让毕业生了解到今年的就业形势、就业政策等，让学生们体会到学校的关怀。5、健全就业工作责任制，就业数据报送准确及时，严格按照国家教育部“四不准”条约，对弄虚作假或不达标者，将追究相应责任。

最后，校长王卫平针对就业工作提出了三个要求：第一，强化组织领导。要求各二级学院也相应组成由院长、书记、副书记带头的就业工作小组；第二，各学院要确保经费保障，院长须主动沟通协调；第三，将就业工作作为今年各个学院的重中之重。拟增加学校绩效考核中就业工作的分数比例。
