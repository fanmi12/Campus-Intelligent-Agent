# 迎绿色奥运  秀环保时装

6月5日，由学院团委主办、高职部承办的“迎绿色奥运，show环保时装”大赛在学院大礼堂举行。

学院党委副书记朱冰同志，院督学兼高职部主任林世俊教授，学生处处长章德胜副教授，院办公室副主任、高职部黄研晖书记，学生处副处长、院团委书记丘永辉老师等观看了本次环保服装设计大赛。

经过初赛，来自各系部的22套设计作品参加了决赛。与普通时装设计比赛不同的是，这次比赛的参赛服装都是用废弃的材料做成，既体现了“绿色奥运，环境保护”的奥运主题，又不失现代服装的风格。模特们用轻盈优美的步伐，展示了“环保”服装的别样韵味，赢得了评委和观众的好评。

经过激烈的角逐，最后，18号作品《绳结》获得个人作品一等奖，21号作品《Cinderala》、12号作品《绿精灵》获得个人作品二等奖。文艺系《蓝精灵》、高职部《美人鱼》、金贸系《雪地里的夏娃》分获系部作品一、二、三名。
