# 财经系召开第三届会计知识竞赛决赛暨表彰总结大会

决赛现场

陈督学为获奖学生颁奖5月13日，财经系第三届会计知识竞赛决赛暨表彰总结大会在大礼堂举行。学术副院长程发良教授、院督学陈丁堂教授莅临活动现场。

知识竞赛决赛分为有问必答、精打细算（点钞）、急速抢答、珠算、你来我往五个环节。经过激烈角逐，07级会计学2班选手技压群雄，夺得团体总分第一名。08级会计1班及07级国际会计2班分别取得团体总分的第二和第三名。大会对会计知识竞赛初赛的优秀个人和本次决赛的获奖团体进行了表彰。

据悉，会计知识文化月系列活动历时一个月，先后开展了包括会计技能证经验交流会、会计知识竞赛初赛、会计职业生涯规划座谈会、会计知识竞赛决赛等一系列活动。系主任高香林教授介绍，会计知识文化月系列活动有效地加强了财经系的学风建设，将专业知识的学习延伸到了课外，创造性的开辟了教学第二课堂，提高了同学们学习专业知识的兴趣，已成为具有一定影响力和城院特色的品牌活动。
