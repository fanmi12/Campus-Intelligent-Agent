# 我院举行个人所得税专项附加扣除申报培训

1月3日下午,个人所得税专项附加扣除申报培训会议在行政楼212会议室举行。

财务处长余竹根主持了会议，希望子女教育、继续教育、大病医疗、住房贷款利息、住房租金、赡养老人等六项支出符合条件教职工可依法享受专项附加扣除，认真做好个人申报。

财务处吴凡老师通过PPT讲解，剖析每一个填报环节需要注意的问题，现场指导个税联络员进行填报，希望大家将填报的方法及程序向本部门教职工进行传达。
