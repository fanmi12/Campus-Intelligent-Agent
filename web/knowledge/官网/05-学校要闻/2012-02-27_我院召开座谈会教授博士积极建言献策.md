# 我院召开座谈会教授博士积极建言献策

2月24日，我院在4315会议室召开“服务东莞高水平崛起，建设一流独立学院”座谈会，听取教授、博士对学院工作的意见，开展办学战略思想的大讨论，凝心聚力实现第二次跨越。城市学院全体领导出席会议，70多位教授和博士代表与会。

座谈会围绕如何服务东莞高水平崛起、建设一流独立学院这一主题展开了热烈的讨论。党委书记朱志德在主持会议时指出，召开座谈会的目的和宗旨，就是为了贯彻落实市委市政府提出的“东莞高水平崛起，再领跑三十年”的战略思想和奋斗目标，更好地为东莞经济社会的发展服务。我院顺利通过学士学位评估，获得学位授予权，取得了阶段性的成绩。在这样的形势下，我们要积极应对各种挑战和竞争，实现董事会提出的“建一流大学，办百年名校”宏伟蓝图，全院上下一盘棋，实现第二次跨越。这是当下每个城院人都要认真思考和关心的问题。开年的第一个会议，充分说明学院对这个问题的高度重视。

座谈会上，危兆宾、黄英森、罗卫国等教授、博士踊跃发言，畅谈自己的想法。他们表示，当前我们要认清形势，找准办学定位，凝心聚力，稳步前进。要处理好服务东莞与建设一流独立学院两者间的关系，充分发挥两者相互促进、相得益彰的作用。要进一步凝炼办学理念，创新管理机制，适应当前东莞经济社会的需求，科学设置学科与专业，加强精品课程的打造。进一步加大科研力度。注重师资建设，尤其要加强对青年教师的培养。要把对学生的培养教育放在首位，培养符合社会需要的人才。要大力整顿学风，加强学风建设，注重学院文化氛围的营造。老师们建议，学院应设置服务东莞的专门机构与研究中心，完善服务东莞的工作激励机制。开阔视野，加强国际化合作办学。彰显机制优势，进一步传承和发扬城市学院办学以来形成的优良传统和有益经验。凝聚人心，进一步提高师生的信心和热情。

院长安少华在听完大家的发言后表示，自己深为老师们全心全意关心东莞和学院发展的精神所感动，也为老师们深谋远虑的建议和以校为家的真情所触动。他说，学院的发展，关键就是要依靠有真才实学、责任感强、关心学院的教授博士。我们要调整心态，提高能力，努力营造良好的校园文化氛围，提高学院核心竞争力。安院长全面深刻的分析了当前国内的教育背景、办学环境以及民办教育异军突起的发展趋势，要求全体教师找准自身定位，找到稳步发展的突破口和着力点，在东莞高水平崛起的同时，实现学院“一流”的办学目标。
