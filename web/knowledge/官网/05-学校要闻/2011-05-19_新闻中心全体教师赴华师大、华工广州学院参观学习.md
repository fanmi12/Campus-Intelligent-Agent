# 新闻中心全体教师赴华师大、华工广州学院参观学习

我院新闻中心老师与华师大宣传工作负责人座谈交流

参观华师大校报编辑部

参观华南理工大学广州学院大学生广播站

参观华南理工大学广州学院汽车实验室5月18日，新闻中心全体教师在宣传部部长、新闻中心主任何鹏举教授的带领下，赴华南师范大学、华南理工大学广州学院党委宣传部参观学习。

我院新闻中心老师分别与两所学校宣传工作的相关负责人就中心组学习、校园文化氛围营造、校报编辑、网络新闻、广播站、摄影摄像、媒体联络、大学生记者团管理等方面进行了学习交流，并参观了两所学校的宣传部办公室、摄影间、广播台、实验室及校园。

我院老师通过参观学习，认为这两所高校都有值得我院学习的经验和做法。一是两校的工作人员非常年轻，且女同志多，他们敢作敢为，具有强烈的进取精神。二是宣传工作有声有色，华师大中心组定期举办高端论坛，论坛涉及的内容都是领导和师生共同关注的热点问题，各系部也有与专业紧密结合的讲座。凡是有讲座，必定座无虚席。广州学院校园电视台将校园新闻制作成电视片，及时地在学校播放。三是充分依靠学生的力量做好宣传工作。华师大大学生记者团的学生素质高、热情高、稿件采用率高。广州学院宣传部工作人员只有四女一男，大部分工作交给学生去独立完成，该校还为学生设置了很多办公桌椅和电脑。
