# 我院师生赴虎门海战博物馆参加纪念活动

2月26日，教务处副处长、讲席专家赵书山副教授，思政部刘珍副教授带领我院29名学生，到虎门海战博物馆参加“‘追忆先贤，重走古战场'——虎门保卫战173周年”纪念活动。

赵书山副教授受邀做了“浴血虎门?名垂青史?捐躯沙场?永存忠魂——纪念民族英雄关天培”的专题讲座。赵教授讲述了关天培临危受命的背景，筑牢南海长城的功绩以及在虎门海战中英勇捐躯的史实，为参加纪念活动的大、中、小学生以及部队官兵上了一堂生动而鲜活的历史课。

讲座之后，鸦片战争博物馆邢继贤副馆长向学生代表授战旗，带领百余名学生及部队官兵从海战博物馆出发，登临南山古战场，参观威远炮台、靖远炮台、威胜东台、炮台营房、镇远炮台等，感受英烈们的气息，体会虎门保卫战的壮烈。

刘珍副教授认为，这次活动不仅具有纪念意义，更具有教育意义，使同学们通过现地教学，亲身感悟，能够更深刻地了解鸦片战争这段历史，体会和培养爱国情怀、民族精神，更加牢记历史，珍爱和平，并围绕构建社会主义核心价值观，弘扬民族精神，向社会传递积极向上的正能量。
