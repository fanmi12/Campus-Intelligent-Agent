# 我院完成一批教学科研项目

4月30日，学院在315会议室召开2007年院级立项科研项目结题评审会议。院督学林世俊教授及学院教学工作委员会全体成员出席和参加了会议。会议由学术副院长程发良教授主持。

这次参加结题评审的有42个教育教学改革与研究项目，28个“创新人才培养计划”项目。会前，教学工作委员会的委员按照分工，对各项目主持人提交的结题资料进行了审理。在这次会议上，委员们向会议通报了各自的评审意见。会议认为，经过专家们的严格审查，大部分项目完成情况较好，科研水准较高，科研成果丰富，根据委员们的意见，批准结题。个别项目成果有待挖掘，需要调整后延期结题。

会议经过公平审议，评选了10个教育教学改革与研究项目为优秀项目。据悉，有关负责人表示，获得优秀项目课题的主持人，在今后申请院级科研项目时，可获得优先受理的待遇。
