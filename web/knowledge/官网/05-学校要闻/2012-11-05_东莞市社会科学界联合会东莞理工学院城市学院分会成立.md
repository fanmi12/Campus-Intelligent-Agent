# 东莞市社会科学界联合会东莞理工学院城市学院分会成立

11月2日，东莞市社会科学界联合会东莞理工学院城市学院分会成立。广东省社科联副主席林有能（左四），东莞市委宣传部副部长梁轼文（右四），东莞市社科联主席王思煜（左三）、副主席龙家玘（右一），出席揭牌仪式。

副院长高香林教授出任分会会长。
