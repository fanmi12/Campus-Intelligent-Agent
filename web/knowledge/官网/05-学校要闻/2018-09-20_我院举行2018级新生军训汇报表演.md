# 我院举行2018级新生军训汇报表演

9月20日上午，2018级新生军训汇报表演在学院田径场举行。91676部队徐卓上校、田建伟中校，学院董事长代表陈超群，院领导王卫平、章德胜、高香林、黄兢、周庆、刘玉侠、林江龙和军训团全体教官、指导员，各单位负责人，以及2018级新生参加了军训汇报表演。

在激昂的军乐声中，王卫平院长在徐卓上校的陪同下检阅了受训新生队伍。

迎团旗后，分列式正式开始。国旗护卫方队、军训团团旗和由2018级新生组成的19个连队方阵，在教官带领下，依次走过主席台，接受领导检阅。他们迈着矫健的步伐，英姿飒爽、神采飞扬，展示了2018级新生意气风发的青春活力和奋发向上的精神风貌。

在汇报表演中，受训新生进行了格斗术、盾牌反恐防暴、军体拳、匕首操、战伤救护、海军旗语等表演，赢得了观众热烈的掌声。

军训团团长田建伟作了军训总结讲话。他说，14天的军训生活里，同学们的成绩和进步都有目共睹。同学们在军训中，养成了团结协助的优良作风、令行禁止的纪律观念，磨练了坚忍不拔的品格意志。这些成果都是同学们人生道路上的一块重要基石，希望大家踏着这块基石迎接未来，以优异的成绩回报学校。

刘玉侠副院长宣读了《关于表彰2018级新生军训先进集体及先进个人的决定》。

大会对在军训期间表现突出、成绩优秀的集体和个人进行了表彰。

军训汇报演出结束后，教官、指导员和全体新生积极参与了因台风“山竹”而造成破坏的校园清理恢复活动，奉献爱心。
