# 石志民副教授参加教育部培训班学习

7月5日—7日，教育部在国家行政学院举办全国高校思想政治理论课骨干教师培训班。全国244所高校分别派员参加了培训。教育部部长周济、教育部社政司徐维凡司长在培训班做了生动精彩的讲话和学术报告。

根据广东省教育厅、城市学院的安排，社科系石志民副教授参加了这次培训。据悉，我院是唯一一所参加培训班的独立学院院校。
