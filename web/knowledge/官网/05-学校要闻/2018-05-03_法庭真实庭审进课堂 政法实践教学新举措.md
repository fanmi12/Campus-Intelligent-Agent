# 法庭真实庭审进课堂  政法实践教学新举措

4月26日下午，东莞市第一人民法院寮步法庭巡回审判在政法系7B102模拟法庭公开开庭审理案件。寮步法庭林玉坤庭长，学院教务处副处长赖忠孝，政法系党总支副书记高政及政法系300多名师生观摩了庭审。

在大学校园可以亲身感受真实的庭审，这让不少学生感到惊喜，早早就来到了模拟法庭现场等候。

在法官的一记法槌下，此次由借贷纠纷引起的诉讼案件正式开庭。双方律师各自代表当事人陈述诉讼请求。随后在证据提交和质证环节，原告与被告先后出示相关的证据提交法庭勘验，并对提交的证据进行法庭说明与质证。期间，针对案件中的关键证据，被告律师毫不示弱，也出示大量证据，进行反击。控辩双方针对“是民间借贷还是不当得利”进行法庭辩论，双方律师都拿出了专业水平，据理力争，让全场气氛达到高点。

最后，由于被告方对原告出具的“借条”证据存疑请求司法鉴定，当天庭审并未宣判，法庭将依法择期开庭。

观摩完庭审后，同学们纷纷点赞：庭审现场庄严的氛围让人很难忘，而自身对如何提高法律专业技能有了一个清晰的认识和理解。

林玉坤庭长在接受采访时勉励法学学生，要学法用法，不断地在案件工作中提升专业水平。他表示，今后会挑选更多较典型的案件来城市学院进行公开开庭，也欢迎城院学子利用课余时间到寮步法庭参与实训观摩。

此次活动把真实案件带进校园进行开庭审理，是政法系在实践教学环节上的又一重要举措。
