# 我院成立东莞市情资料室

为向学院师生提供一个了解东莞、研究东莞的信息平台，城市学院图书信息中心筹建了“东莞市情资料室”。7月3日，东莞理工学院副院长、城市学院院长安少华教授和学术副院长程发良教授为市情资料室揭牌。

资料室现已收集各种资料800余册。内容包括：政府机关、企事业单位、机关团体等各类公开出版或内部交流资料；莞籍人士的各类著作、手稿、日记、信函；非莞籍人士有关莞人、莞事的各类著作；东莞各类地图、宗谱、族谱和家谱；院内有关人员外出参观和学习交流的资料。

图书信息中心主任钟兴恭教授表示，，市情资料室将边建设边开放，开放时间暂定为每周周一、周三8:30－12：00和14:30—15:30， 地点为4＃317，欢迎广大师生前来查阅，并欢迎大家提供资料和信息。
