# 文学与传媒系第五届口语表达辩论赛圆满落幕

4月26日，文传系第五届口语表达大赛辩论赛总决赛在学术报告厅激烈开展。院长杨敏林、党委副书记朱冰到场观看了比赛。

本次总决赛分本、专科两场。第一场是本科组赛，由09级新闻传播为正方辩论“对舆论应以监控为主”，和11级新闻传播2班为反方辩论“舆论应以引导为主”。双方从传播学概论、社会现实等角度作为切入，阐明观点，并用大禹治水等例子形象比喻舆论的不确定性。经验丰富的09新闻传播以4:1的票数取胜。本场最佳辩手称号由林祎慧、刘若筠摘得，最佳风采奖称号由刘嘉琪摘得，钟彩云获得最佳应变奖。

第二场专科组赛同样精彩，正方10商务英语2班与反方11级商务英语1班就“林书豪的成功可不可以复制”展开了激烈的辩论。双方从 “复制”概念阐明辩题，并从林书豪的成功的性质作为交锋点。经过几番唇枪舌战，10商务英语以强大的气场与丰富的经验击败了对手，获得专科组冠军。本场最佳辩手奖是张裕华、李艳芳，最佳风采奖是林嘉欣，曾子莹获得最佳应变奖。

此次辩论赛历时一个多月，很好地提高了学生的思辨能力、良好的语言表达能力以及凝聚团队合作精神，并有助于推动浓厚的学术氛围和建设校园文化。

团委书记杜鹏举、文传系党总支书记孟颖、文传系党总支部副书记李海冬以及新闻中心刘哲老师、文传系陈东汉老师担任本次比赛的评委。
