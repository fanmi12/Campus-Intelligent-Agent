# 台中科技大学副校长谢俊宏率队来访

11月4日，台中科技大学副校长谢俊宏率教务长张宏吉等5个系的系主任、5位副教授来我院考察访问，随同来访的还有9名学生。院领导杨敏林、朱志德、张林、章德胜、高香林及有关部门负责人参加了此次接待活动。

双方首先在教学管理大楼212会议室进行了座谈，杨敏林院长先代表学院对台湾客人的到来表示欢迎并对学校情况作了简要介绍。谢俊宏副校长代表台中科技大学与我院签订了《合作办学意向书》。谢俊宏副校长副校长表示，随着人们生活水平的不断提高，社会老龄化越来越明显，如体育休闲、康复护理、美容保健等服务产业将越来越兴旺，建议学院从战略角度考虑开设此类专业。

会后，双方有关系（处）主要负责人分组进行了1小时的对口交流。台湾同仁实地参观了我院校园。

据悉，今年暑期我院各系部主任曾应邀访问了台中科技大学。
