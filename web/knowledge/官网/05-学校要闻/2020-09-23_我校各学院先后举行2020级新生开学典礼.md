# 我校各学院先后举行2020级新生开学典礼

9月20日-9月23日，我校各二级教学单位分批次举行开学典礼，校长王卫平以视频录播形式作了讲话，各学院党政负责人、教师代表出席开学典礼，与20级新生面对面交流。

（点击观看视频：王卫平校长寄语）

“无论昨天今天还是明天，只要有激情和梦想，永远是春天。”王卫平校长代表学校热烈欢迎2020级学子的到来，寄语新同学要在城市学院快乐生活、快乐学习、健康成长，收获满满。

各学院分批次举行开学典礼，组织形式多样的活动喜迎新生，仪式感十足。各院长们在典礼上作学院简况介绍，鼓励新同学们尽快进入新的学习生活状态，坚定理想信念，知行合一，做担当有为的奋斗者，谱写出精彩的青春华章。

各学院的

教师、学生代表也分别带来经

验分享，帮助新同学更快适应大学的学习和生活，展现出青年人昂扬向上的青春姿态。
