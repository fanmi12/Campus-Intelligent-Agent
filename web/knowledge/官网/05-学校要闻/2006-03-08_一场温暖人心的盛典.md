# 一场温暖人心的盛典

这名女生手中的百合花竞拍到600元的高价“天外来客”——外国友人也来光顾我院的“三•八”慈善美食节

为了庆祝一年一度的三八妇女节、筹善款，我院校园文化巡礼领导小组主办了美食嘉年华慈善活动。下午2点半，我院党委副书记朱冰同志宣布本次美食节正式开始。

当天，校道上被装扮一新，华丽而又精致，让平时安静的校园顿时沸腾起来了。那么请跟随笔者来领略一番本次活动的风采吧。

天外来客

站在广场中央环顾四周，只见从各摊位旁走过的人络绎不绝。花甲老人、幼稚孩童 、时髦青年都争相尝鲜。恨不得“一饮江湖水”。来自兄弟学校的学生们和部分学生家长们也往返于校道中，还有那广场边上的赞助商们，正热情地招待着每一位到访的客人。他们来到现场除了提供一些额外销售服务外，更重要的是宣传爱心知识。

百家争鸣

听，各位摊主的叫卖声让整个现场掀起了浪潮，一浪高过一浪。各种食物也是让人眼花缭乱。什么“果样年华”、“爱心三文治”、“计科烧烤——来自东北的问候”都吸引了大批顾客前来慷慨解囊 。有的摊主更加具有经济见识，推出了购物抽奖、送货上门、连卖带送等商业理念。让大家都不得不驻足选购，在饱餐秀色的同时，也还享受到更为周到的服务。盆景、鲜花、金鱼、服饰都出现在本次美食节的摊位上，琳琅满目。

情暖人间

晚上，本次美食节进入了最重要的环节——现场拍卖。来自各个系与赞助商们都送上自己的拍卖品。现场气氛非常活跃。一次次的举手叫价声，一次次的宣布成交。都让人感受到一股暖流入心田。虽然当时天空还在下着蒙蒙细雨，但这丝毫不会影响大家献爱心的热情。“只要人人都献出一点爱，世界将变成最好的人间。。。。。”熟悉的旋律再一次在大家的心中奏响了。

幕后天使

每一次精彩的演出都离不开我们可爱的幕后工作者，只要有需要他们的地方就能见到他们的身影，文艺演出、布置场地、工作检查站等等。来自黄振龙凉茶的负责对我们的学生工作者给予了高度的评价，他无论从工作态度还是工作效率方面都赞扬了我们的幕后天使们。

活动一直进行到晚上9点结束，本次美食节各系共筹得善款9000多元，此次活动取得圆满成功。
