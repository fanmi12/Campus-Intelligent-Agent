# 【众志成城 抗击疫情】我们相约线上——主题征文选登（22）

我校重点关注学生在线学习的效果，切实保障网络课堂的教学质量。学校领导提出，“生活就像海洋，只有意志坚强的人才能到达彼岸，在这最艰难的时期，我们不仅要确保身心健康，同时积极利用这次‘网络教育’的机遇，主动适应学习方式、学习环境和学习形式的变化”。从3月19日起，我校组织了《我们相约线上》学生主题征文活动，今天推出的是第二十二期作品选登，推介外国语学院陈舒楠、商学院施运欣、外国语学院邓杏琳三位同学的征文作品，欢迎大家踊跃来稿，积极参与讨论。

一、网课拉远师生的距离，却拉近了我们的心

——外国语学院 陈舒楠

这次疫情让我们勾起了心弦，产生了在家乖乖上网课的方式，因此拉远了我们与老师与同学的距离，但在我看来，网课拉近了我们与同学的不舍情谊，也拉近了我们与老师的互动之心。

网课让我们只能在线上交流，只能在线上见老师。每次上课，同学在课堂上很活跃回答问题，还会营造搞笑气氛，有一种好像回到大家一起在一个课室上课的感觉，虽然少了声音，但是心底里感到很欢乐。课后，有很多同学积极在群里问老师问题，学习氛围好像比以前更好了，网课虽然看似缺点多多，但其实也增进了我们同学的友情和与老师的师生情。

新闻网络上有很多关于网课的负面评论，如降低学习效率等等，但是经过这次疫情，网课让我们无形中学会了珍惜，学会了自觉，学会了自主研究性学习，让我们师生更广泛地讨论、交流、拓宽师生的知识面，网课拉近了彼此心与心的距离。

二、线上学习个人感受——新鲜、便捷、实用

——商学院 施运欣

受新冠肺炎疫情的影响，我们学生也因此改变了学习的方式，实行了“停课不停学”的线上学习模式。线上学习的模式，无论何时何地我们在家用电脑或者手机就可以进行学习，不用拿着书本走路半天到课室上课，而且不懂还可以看回放，既便捷又可以节约时间，同时线上的学习模式可以让我们更多地利用网上的资源，增加学习的广泛度，对于我们来说是实用的。

通过网络学习，让我们在特殊的时期受教。停课不停学，加油努力学习，让我们在未来的某一天相约学校！

三、多姿多彩的网课

——外国语学院 邓杏琳

不知不觉，我们已经上了快3个月的网课。在这3个月里，网课学习这种新颖的学习方法激发我的学习热情。对于我而言，课堂学习是最能集中精神学习的，但没有网上学习时大家参与度高或者说积极发言。

老师针对学生不认真听课、活跃度低，想出很多应对方法。每天上完课感觉好累但是又感觉很有充实感和满足感。其中，有三个老师的课最让我印象深刻：胡良兰老师每到操作课会安排任务给我们，我们可以选择跟她一起学习怎么操作word、Excel，会的同学可以先自己做，然后把自己做好的任务发到群上，前3名可加分。虽然这个过程很激烈，但是我们很多人都认真听课完成任务。还有余琼老师，上课会给我们几个案例，让我们分析，把自己的想法打出来，通过发言加分调动我们的积极性，大家通过直播分享自己的想法，在得分的同时学到更多知识。还有金萍老师，每天创新签到方式，在签到的同时还能学到很多知识点和单词。而且金萍老师鼓励我们给自己的同学讲课，例如每节课开始由学生评价一下时事热点，然后下一个同学讲5个语法题，最后由2位同学为我们演讲课文知识，老师在旁向我们答题解惑。

最后说一句，我真的很喜欢老师们的直播课。谢谢老师们辛勤地为我们备课，每次上课都煞费苦心地创新上课方式让我们更加积极地参与到课堂中。
