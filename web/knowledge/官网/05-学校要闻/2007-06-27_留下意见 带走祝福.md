# 留下意见 带走祝福

6月26日,为了听取2007届毕业生的意见和建议，再续母校情，学院在315会议室召开了毕业学生代表座谈会。学术副院长程发良教授、教务处处长邓成良教授、总务处副处长马兴顺、学生处副处长丘永辉、实验中心主任李奇副教授、高等教育研究与评价中心邵润堂教授出席和参加了会议。

会议由邓成良处长主持。座谈会气氛活跃，毕业生们结合自己在校的学习生活、求职择业、考研等亲身体验畅所欲言，交流了思想、工作、学习和生活等方面的收获和感受，充分表达了对母校人才培养及发展建设的关心，寄予了毕业生对母校的无限深情。程副院长代表学院感谢同学们为学校的发展做出的贡献，祝愿同学们走出校园后继续努力取得更好的成绩，并表示积极采纳同学们的建议，尽力为同学们服务，让同学们满意。
