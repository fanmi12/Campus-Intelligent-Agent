# 2014工模花絮之一：工模奇葩摊位你知多少？

看过《来自星星的你》，可你看过”来自星星的炒年糕“吗？江湖上有一种独门绝学叫”含笑半步癫“，可我们大城院的工模摊位上有一种美味叫”含笑半步丁“呢~~~

看过上面这个奇葩的摊位，你是不是以为就这么结束了？小编不会告诉你下面还有的~正所谓老祖宗的东西就是好，我们这里有祖传贴膜呢！我们还不成功不收钱啊，亲~（ps：小编弱弱地说一句：亲，你的祖宗好潮啊。。。）

说完了祖传宝，不如让我们来说说广大女性同胞都感兴趣的美男欧巴吧。话说，小编看到这样一个摊位，上面赫然写着”美男厨房“。小编当然第一时间走过去一探究竟啦~然后你猜，我看到美男了吗？额，我是不会告诉你结果的，有兴趣的妹子不妨亲自过来看看喔~

咳咳，那个，听说城院有很多土豪，本来小编都不怎么觉得的，但是，在亲眼看到这个摊位后，小编深深地believe了！听过iphone土豪金，你听过土豪金指甲油吗？（不管你听没听过，反正小编是没有听过。。。另外，小编不会告诉你我是从山里来的。。。）不是说土豪都是吃茶叶蛋的吗，怎么他们都开始转战指甲油了？

看到小编介绍的这些奇葩摊位，宅在宿舍嫌人多嫌天气热不肯出来逛工模的”闭家锁“和”居里夫人“们，是不是好想过来看看？各种稀奇古怪好玩好吃的商品在召唤你们有木有！有空的小伙伴们，快到工模的碗里来喔~更多精彩摊位等你发掘喔！
