# 学院召开2010年院校研究工作会议

4月30日，城市学院2010年院校研究工作会议在4405室召开，“院校研究”核心小组成员及各项目组负责人参加会议。

院督学陈丁堂教授主持会议，并对研究经费的安排与拨付作了说明。

会议确定了本轮院校研究的中期检查时间、结题时间、研究成果呈现形式等事项，讨论了院校研究的性质、内容与意义。会议认为，作为一种管理性、应用性的研究，要紧密结合城市学院和东莞的实际，联系独立学院改革发展的形势。通过这些研究帮助大家正确认识、诊断、分析和解决学院面临的现实问题，为院领导决策提供参考，进而促进学院管理工作的科学化和现代化。

据悉，本轮院校研究的项目，均由学院职能部门主要负责人和一些教学系的骨干教师承担，目的是为了对学院管理问题进行综合研究，发挥院校研究管理咨询的整体性功能。
