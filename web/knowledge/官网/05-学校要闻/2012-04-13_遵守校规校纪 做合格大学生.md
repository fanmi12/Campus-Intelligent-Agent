# 遵守校规校纪  做合格大学生

刚刚走进高等学府的同学，在对大学生活充满期待的同时，也还须面对许多未知的东西，如什么叫学分制，怎样才能拿到奖学金，有哪些规章制度。9月19日，学院在新生入学教育第三讲中就上述问题为同学们进行了解答。

学院学术副院长程发良教授介绍了教学和学籍管理等制度。他指出，城市学院对大一新生实行早读、晚修制度，教学上实行学分制，学有余力的同学可以选读辅修专业。

学生处处长章德胜副教授详细介绍了学生管理、奖学金设置、大学生评优和勤工助学等规章制度。

总务处副处长周林冲老师就饮食、住宿、医疗等后勤各项服务工作向同学们作了介绍。

会议由学生处副处长、团委书记丘永辉老师主持。

据悉，学院已向新生分发了学生手册，大学学习、生活的相关内容可以在手册上查询。
