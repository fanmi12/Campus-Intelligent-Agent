# 我院教师参加省高校外事暨港澳台工作会议

2011年12月28日至30日，广东省高校外事暨港澳台工作会议在惠州学院隆重举行。省教育厅副厅长魏中林、合作交流处副处长冯兴雷等领导出席会议。全省92所高校外事主管人员与会。我院外事办公室主任袁宇航参加了会议。

会上，冯兴雷副处长总结了广东省2011年高校外事工作情况，包括中外合作办学、国际交流改革试点评估、深化与港澳台合作等方面的成绩与不足，并提出了2012年的外事工作设想。他指出，高校要加大力度推动中外合作办学，扩大招收国际留学生规模，重点支持高职院校的中外合作项目，并将继续开展落实高校国际化调研与评价工作等。

魏中林副厅长在会上提出，要开展关于外事工作如何为高等教育发展服务的探讨。他认为普通高校应以培养“应用型人才”为发展目标，高校要与社会企业共同发展，协同创新。他强调，高等教育要积极推行国际化，积极吸纳优秀国际人才培养模式，加大力度推行中外合作办学，提倡观念和工作方式上的多元化发展。
