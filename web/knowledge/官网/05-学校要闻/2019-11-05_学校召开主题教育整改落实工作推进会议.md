# 学校召开主题教育整改落实工作推进会议

11月1日，我校召开“不忘初心、牢记使命”主题教育整改落实工作推进会议。学校党政领导、各有关机关教辅部门负责人参加了会议。会议由学校党委书记章德胜主持。

章德胜书记就主题教育开展以来，我校在检视问题、整改落实方面的工作情况进行了通报，并就下一步整改落实工作进行了部署。

章德胜书记指出，学校领导10月中旬分别组织召开了座谈会，广泛征集各职能部门、二级学院对学校各方面存在的问题及整改建议，积极采取“自己找、群众提、集体议、上级点”等方式，查摆差距找不足，体现了党政领导班子对学校基层意见的重视和对问题整改落实的决心。各职能部门应在分管校领导的指导下，对照两清单，确保检视出来的问题都能一一进行整改。短期内能改的立查立改、即查即改，一时解决不了的要盯住不放、限期整改。实实在在地拿出刀刃向内的决心和为师生解决问题的成效，使整改工作铿锵有力、掷地有声。

章德胜书记还传达了10月30日省委教育工委部分民办高校主题教育座谈会的会议精神，就会上指出的民办高校主题教育过程中存在的普遍问题进行了通报。强调我校各级领导干部应进一步对照检视存在问题，边学习边调研边检视，明确努力方向和改进措施，推动深入整改，把我校主题教育工作落地落实。
