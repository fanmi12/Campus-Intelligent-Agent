# 2019年莞台大学生夏令营在我校正式开营

7月7日上午，由东莞市莞台经济文化交流中心与我校共同举办的“品质东莞 携手未来”——第四届莞台大学生夏令营活动在我校正式开营。

东莞市台港澳事务局副局长王柏桃、副调研员谢春，市莞台经济文化交流中心副主任林华珠，东莞理工学院城市学院校长王卫平、副校长周庆和来自台湾、东莞两地高校的100多名师生参加了开营仪式。

周庆副校长代表我校对台湾师生的到来表示热烈欢迎，对主办方广东省台湾同胞联谊会、东莞市人民政府台港澳事务局等单位的大力支持表示感谢。她说，城市学院十分重视与台湾高校的交流与合作，6年来与台湾的多所高校保持着密切的合作，积极开展包括两岸师生交流在内的多个研修项目，促进了两岸师生和学术的交流。她指出，台湾与大陆同宗同源，加强两岸人民文化与教育上的交流是我们共同的责任和使命。我校将全力做好莞台大学生夏令营的各项工作，努力增进两岸师生的友谊与交流。

东莞市台港澳事务局副调研员谢春在致辞中说，莞台大学生夏令营是两岸青年搭建起增进共识、深化友谊的重要平台，也为东莞吸引港台青年学生来莞就业、创业，共同把握粤港澳大湾区的发展机遇提供了良好的契机。希望同学们秉承“两岸一家亲”的理念，相互交流学习，在相处中体味海峡两岸同胞同根同源、同文同种的中华文华之情，进一步增强对中华民族的认同感、自豪感，增进对两岸命运共同体的认知，勇于承担起时代和历史赋予的崇高使命。

据了解，此次莞台大学生夏令营共有台湾铭传大学、义守大学、中国文化大学、东华大学等高校的34名学生参与，他们将与东莞本土高校的54名大学生相互结伴，通过参访、体验、学习、体验等形式开展丰富多彩的交流活动。夏令营将走进可园博物馆、台商大厦、中科院云计算中心、松山湖青创基地等东莞多个名胜古迹和企业机构进行参访，深游广州、东莞两地，体验岭南风俗文化，饱览岭南风光，从各方面了解莞邑人文和经济发展情况，让台湾学子感受祖国的发展与变化。
