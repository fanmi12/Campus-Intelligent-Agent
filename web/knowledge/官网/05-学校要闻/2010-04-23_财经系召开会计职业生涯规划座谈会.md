# 财经系召开会计职业生涯规划座谈会

4月22日，财经系第三届会计知识文化月系列活动之会计职业生涯规划座谈会在五号楼阶梯室举行。东莞东正会计师事务所所长周华平应邀出席会议。

周所长对今年会计专业大学毕业生的就业前景做了展望，介绍会计专业学生不同的职业发展方向及其发展要求，并给在座的学生传授了一些学习经验。
