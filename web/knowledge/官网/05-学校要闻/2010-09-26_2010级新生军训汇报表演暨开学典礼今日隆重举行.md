# 2010级新生军训汇报表演暨开学典礼今日隆重举行

周致纳书记检阅受训学员

安少华院长在开学典礼上致辞

麦照容董事长为先进个人颁奖

女子格斗表演

男子军体拳表演

素质拓展训练9月26日，城市学院田径场红旗舞动，军歌嘹亮，口令雄壮，学院在这里隆重举行2010级新生开学典礼、新生军训汇报表演。

东莞军分区副司令员李建军，东莞理工学院领导周致纳、安少华，东莞理工学院城市学院第二届董事会董事长、广东鸿发集团总裁麦照容，城市学院院、系领导出席典礼并在主席台观看了军训表演，给军训先进个人和连队颁奖。

周致纳书记在军训团团长刘丰少校的陪同下检阅受训学员。随后，12个连队方阵迈着整齐划一的步伐，高喊嘹亮的口号，依次通过主席台，接受首长和领导的检阅。军体拳、女子防身操、旗令操等军训课目汇报表演更是激起观众一阵阵雷鸣般的掌声和欢呼声。

军训团团长刘丰做军训工作总结报告。

东莞理工学院副校长、城市学院院长安少华教授在开学典礼上致辞，寄语新同学。他首先感谢承训部队官兵严格科学的训练，欢迎新同学来到城市学院求学深造。接着，他勉励新同学要调整心态，适应新的学习环境，以饱满的热情迎接新的学习任务，顺利度过美好的大学时光，满怀收获走向社会。

党委委员、学生处处长章德胜主持会议。
