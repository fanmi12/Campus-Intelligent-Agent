# 三名90后大学生囊括新校区建筑物、景观及道路命名一等奖

会场朱志德书记为一等奖获得者颁奖

杨敏林主任为获奖者颁奖

出席会议领导与获奖者合影留念5月11日，城市学院新校区建筑物、景观及道路命名获奖作品颁奖仪式在4号楼315会议室举行。党委书记朱志德、城市学院新校区筹建办主任杨敏林、学院办公室主任王玉、党委宣传部部长何鹏举等领导参加了会议。

筹建办主任杨敏林主持会议，并宣读了《关于东莞理工学院城市学院新校区建筑物、景观及道路命名有奖征集活动获奖作者表彰的决定》，大会分别为获得一、二、三等奖、入围奖的作者颁发了荣誉证书和奖金。

朱志德书记表示，作为这次活动的评委之一，在评选过程中很受感动，东莞理工学院和城市学院的师生员工积极参与，其中，既有60多岁的老教授，又有刚入校的大学生，共收到了500余份作品，提交的作品质量都很高。新校区筹建办对作品按照建筑、景观及道路进行分类，并组织专家学者采取无记名投票的方式开展评审。评审结果是：刘敏茹、吴帅、石晓博三人获一等奖；黄健求、鞠小林、彭建钟等5人获二等奖；徐世杰、周杰、戚润明等9人获三等奖。

城市学院机电系主任黄健求教授一人获得两个二等奖，黄教授毕业于清华大学，虽到了退休年龄，仍坚持在教学管理第一线。他自豪地说，几年前理工学院征集命名时，我也获奖了，关心学校发展是每个师生的责任。值得一提的是，一等奖获得者全是90后的大学生。他们认为现在的大学生的个人发展需要有创新思维，创新思维能够让大学生开拓思维空间，提高自身的素质。文传系石晓博同学说：“机会是留给有准备的人。这次助我成功的便是充分的准备（收集资料）和活跃的灵感。”
