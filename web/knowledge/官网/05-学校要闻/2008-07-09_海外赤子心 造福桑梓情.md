# 海外赤子心　造福桑梓情

下午，东莞市侨捐项目监督管理工作总结会暨侨捐项目挂牌仪式在我院举行。会议由市政府副秘书长黄冠球主持。省侨办副主任朱尔武，市侨务局副局长陈国良，东莞理工学院副院长、城市学院院长安少华教授，东莞理工学院城市学院副院长张林博士，侨捐项目监管工作领导组成员及捐赠的部分港澳同胞及受赠单位代表参加了会议。

会上，陈国良对2007年侨捐项目监管工作作总结报告。省侨办副主任朱尔武作了重要讲话，他指出：侨捐项目是东莞市旅外乡亲支持家乡经济建设的巨大物资财富，是爱国爱乡、造福桑梓的丰碑，要充分认识到侨捐项目监督管理工作的重要性，要健全各种管理制度，保护华侨港澳台同胞、捐赠人的合法权益，激发广大海外侨胞、港澳同胞的关心和支持家乡建设的积极性，从而达到建设和谐侨乡的目的。

朱尔武、黄冠球向捐赠人、受赠单位分别颁发了《广东省华侨港澳同胞捐赠公益事业捐赠证书》和《广东省华侨港澳同胞捐赠公益事业项目确认证书》。侨捐项目监管单位与受赠单位代表签定了《广东省华侨港澳同胞捐赠公益事业项目监管责任证书》。

侨捐项目牌匾揭幕仪式前，院长安少华代表城市学院讲话，对广东省华侨港澳同胞为城市学院的发展所作出的捐赠公益事业表示感谢。

随后，与会领导、嘉宾及与会人员在学院四号楼前参加了侨捐项目牌匾揭牌仪式。
