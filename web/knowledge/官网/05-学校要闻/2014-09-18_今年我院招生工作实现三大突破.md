# 今年我院招生工作实现三大突破

9月18日的最终统计结果显示，我院2014级新生实际报到5126人，总报到率达到95.01%，再创历年新高，位居广东省同类院校第一名。

据招生办负责人孔增强副处长介绍，今年城院招生工作实现了三大突破：一是招生人数比上一年增加42人，总录取人数为5126人；二是生源质量提高，新生全部是线上第一志愿录取，其中还有一批新生的录取分数超过了二本线；三是新生报到率达到95.01%，再创历年新高。

这位负责人在分析今年招生工作实现“三大突破”原因时表示，五大主因促使招生工作再上新台阶。第一条，学院办学整体实力及社会知名度不断提升，为招生工作创造了条件，这是最为关键的一条。第二条，指导思想明确，招生工作思路清晰。即：立足东莞，面向全省，辐射全国。第三条，科学编制省外计划，对优质生源省份重点投放计划，提高录取和报到率，如海南省和湖南省。第四条，招生方法对路，盯住生源大户不放。在招生宣传阶段，学院多次召开市属中学校长会议，了解生源信息，宣传城市学院的办学条件。招生办工作人员、各系部有关铺导员深入全省生源重点地区，与考生面对面宣传学科与专业，宣传东莞的就业优势，坚定考生报考城市学院的信心。通过做工作，梅州市、湛江市、惠州市等地区填报我院的考生人数成倍地增加，其中有的高达3——4倍。第五条，宣传工作形象具体。据了解，90%的考生阅读过我院“空调学院”的新闻信息，其中许多考生是冲着“空调学院”而来的。
