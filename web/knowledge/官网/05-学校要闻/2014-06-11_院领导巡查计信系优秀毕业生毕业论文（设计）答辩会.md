# 院领导巡查计信系优秀毕业生毕业论文（设计）答辩会

6月5日，党委书记王卫平教授、副院长高香林教授带领教务处处长牛熠教授、副处长赵书山副教授、院督导聂映中教授，巡查了计信系2014届毕业生优秀毕业论文（设计）公开答辩会会场。

计信系论文答辩会主席由系主任廉玉忠教授担任，马立权教授、葛卫清副教授等多位资深专家担任答辩委员，当天，杨子靖、吴剑华、练勇彬、黄海波、吴国华、尹沛权等六位同学进行了现场答辩，计信系2014届毕业生代表和2011级部分学生到场旁听了答辩。
