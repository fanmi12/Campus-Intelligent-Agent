# 2012年迎新花絮之二

给孩子留点空间独立报到

记者：黎凤婵

我院新校区迎新第二年，依然实行 “新生独立报名”的规定。15日早上在报名点入口处，很多志愿者，后勤服务公司的工作人员排成“人墙”，一一将家长挡在场外。“不行，我得进去，你们得就让我进去吧，她万一把钱弄丢了，那就不好了。”来自广西柳州的李家长与志愿者在新生报名点的入口处争执起来，大二的志愿者努力向家长解释说，“抱歉，这是学校的规定，必须是让孩子一个人进去，不然里面秩序就会很乱。”最后女儿李佳文说了一句“爸，放心吧，没事的。”这才将该家长的情绪稳定下来。后来，看到李佳文顺利办完入学手续，一直站在门口等候的父亲才放下了心。“这个孩子没有单独办过这些啊，挺复杂的，怕弄不好。”

不过，有的家长还是很放心，来自石碣的王妈妈就很放心的和丈夫在报名点外的太阳伞下遮阳，“没事，咱家女儿没问题。”笑着说。自己独立报名，很多新生都表示没有压力，11级财经系的李佳文说：“以前自己是不小心丢过东西，但现在我上大学了，没有问题的。”

那个绿色的身影

记者：李梦妍、周小萍

下午四点多了，第一天的新生报到工作几乎接近了尾声，校园西门通过综合馆的校道上，仍然人来人往，一片繁忙的景象。在校道上，记者看到一个穿着绿色休闲服的人在指挥着来往迎新的车辆，他就是我们的杨敏林院长。

迎新这一天，车辆特别多。为了不影响交通，寮步镇派来了40多名交通协管员和城管队员前来支援。杨院长和院里的其他领导都很关心新生报到工作，大清早就来到了招生现场指导工作和疏导交通。每次我们想采访他的时候，杨院长就会笑着对我们说：“去采访各系部主任吧！他们很辛苦。”

各院系志愿者为新生导航

记者：黎凤婵2012级新同学刚刚入校，报到，入住、登记、吃饭、学前教育、对东莞和城院的心理适应等一系列事情也接踵而来，面对这些入学事项和工作，学校和各系部都做了积极的准备工作，为来校学生和家长提供各方面的导航服务，尽善尽美地完成迎新任务。

我院每个系部都组织了许多志愿者去帮助新生，他们穿着自己的系服或者佩戴着工作证，所以很容易辨认。他们接站，帮助搬行李、引导新生和家长们登记、随同新生办理各项手续。整个校园里，处处都有他们的身影。金贸系的志愿者韩超云说：“我今天早上6点就起床了，然后按照事先分配好的任务在综合馆里面做接待新生的工作。”财经系的志愿者陈仲鹏也感概说到：“在我大一入学很迷茫的时候，是师兄师姐帮助了我，所以现在我也要努力帮助我的学弟学妹。”

金贸脚印路标一路向北

记者：黎凤婵

从北门走进校园的马路上，我们可以惊喜地发现一些颜色各异的脚印指路标志——“欢迎你，金融与贸易系”，脚印明确地指向新生报到的目的地——综合馆。这是金贸系为了方便新生报到而设置的，因为从校门到办理报到手续的综合馆还有很长的路程，对于新生及其家长来说，这里还比较陌生，这些新路标的出现为他们提供了很大的方便，也体现了“金贸人”的人文关怀。“这样更加能让新同学充分感受到我们系对他们的热情，期待着他们能更快地融进金贸系这个大家庭。”学生会副主席饶晋凯介绍说，“真的很意外，很惊喜，我是打的包车过来的，下车后很茫然不知怎样走，结果低头就看见了这些路标。”金融学专业很多同学夸赞路标有创意。
