# 欢迎你，新同学!

城院敞开胸怀欢迎新同学的到来

亲爱的2011级新同学：欢迎你成为东莞理工学院城市学院的一员！九月是收获的季节，你们带着梦想与憧憬，怀揣父母及亲人的期望，即将从全国各地走进向往已久的城市学院，开始属于自己的充满激情的大学生活。大学是一个新的起点，一个新的开始。城市学院，这个崭新而美丽的校园，因为有了你们的身影，才充满生机、充满希望！我们热爱城市学院这个大家庭，亲昵地称呼自己为城院人。希望这个自豪的称号能伴随着你们茁壮成长，期待着你们在这个丰收的季节、在这个梦想开始的地方，拥有满满的收获。更期待你们以城院人的身份为城院带来新的骄傲！

大学不是奋斗的终点，而是生命历程中一条新的起跑线，是理想起航和梦想飞扬的地方。城市学院将提供给你们一流的硬件设施，深厚的师资力量，最核心的课程教育和优美大气的校园环境，为全体同学创造各种各样的学习和实践机会。城市学院将把国际化视野与专业精神的培养贯穿你们的大学生涯，帮助同学们完成今后继续发展的知识和能力储备。

我们的老师、师兄师姐，希望新同学们尽快完成从中学到大学的转变，适应大学的学习方法。在今后几年的时间里，要夯实基础，勤于思考，善于钻研，勇于实践，把学习知识与探索世界、研读经典与独立思考、传承文明与创新实践结合起来。陆游诗云：“纸上得来终觉浅，绝知此事要躬行”。希望同学们勤学好问，多读好书，养成独立思考的习惯。要善于交流，明辨是非，择善而从，努力培育自己良好的人格、高尚的境界、强劲的实践能力和创新能力。

一位毕业生家长曾对我们说，城市学院实现了孩子的梦想，也实现了许许多多家长对于孩子的梦想。城市学院的职责是把你们培养成为高素质的应用型、复合型、创新型人才，把学院建设成为一所一流的高校，为国家和社会的发展培养人才。那么，诸位同学的理想呢？

在这里，新楼迭起，湖畔飘香，俯仰间便能感受到东莞充满创造力、充满拼搏精神的人文气息。在这里，有知识渊博、风度儒雅的老师，有充满活力、积极上进的莘莘学子，为理想从四面八方走到了一起，秉承城市学院“学而知不足”精神，描绘着美丽的人生画卷。

可爱的同学们，带着你们的理想，带着城院的使命，在这所富有创造力的大学里，去体会学识的宝贵和人生的真谛吧！今天，你以城院为荣；明天，城院以你为荣。欢快的来吧，城院敞开胸怀欢迎你们的到来。
