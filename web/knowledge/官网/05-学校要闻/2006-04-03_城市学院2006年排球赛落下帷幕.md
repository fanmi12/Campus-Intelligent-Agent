# 城市学院2006年排球赛落下帷幕

经过两周的紧张角逐，3月30日下午，排球赛进入决赛，文学与艺术系、财经系争夺冠亚军，管理系与机电系争夺季军。

冠亚军之战精彩激烈，扣人心弦，为同学们献上了一道丰盛的运动大餐。来自文学与艺术系的7号队员表现抢眼，多次高位扣球连连得分。财经系的17号队员也同样博得观众喝彩，连连拦网成功。双方比分交错攀升，最终财经系以5：2险胜对方摘下桂冠。

比赛结束后，学院团委与体育教研室负责人为获奖单位颁发了锦旗。
