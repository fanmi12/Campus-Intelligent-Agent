# 物业管理中心职工冒雨抢修输电线路

近几天，小雨连绵，大雨如注。物业管理服务中心的水电维修人员冒雨抢修输电线路，确保校园用电。

在施工现场笔者看到，员工们披着雨衣，带着手套，任由雨水打在脸上、肮脏的淤泥弄脏全身，全然不顾地奋战在施工一线，每一道工序都井井有条，一丝不苟。

经过10多个小时的紧张施工，终于按时通电，受到了师生的一致称赞。
