# 城市学院2011年国际交换生成功交接

日前，城市学院2011年春季国际交换生赵晋宜同学，完成了在美国北爱荷华大学为期半年的学习任务返回学校。赵晋宜说：“在北爱荷华大学的学习虽然只有四个月，但却获益良多、感触深刻。我会非常珍惜‘交换生’的这段经历，希望有更多的同学能走出国门，开阔眼界，丰富阅历。”

据了解，赵晋宜在美学习期间，表现优秀，取得了较好的成绩，受到老师与同学们的好评。返校后，她将继续完成本校的学业。

据悉，城市学院2011年秋季国际交换生杨潇博已成功获得签证，将于8月中旬赴美国北爱荷华大学学习四个月。
