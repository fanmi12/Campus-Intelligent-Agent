# 我院2017年基层党建工作交出满意答卷

近日，《广东省委教育工委、广东省教育厅简报》今年第4期对2017年度党委书记抓党建述职评议考核排名靠前的高校进行了通报。我院榜上有名，在49所民办院校中排名靠前。

近年来，我院基层党建工作交出了一份满意的答卷。一是大力加强基层党组织建设，以思想建设、组织建设、制度建设、作风建设和党风廉政建设为重点，深入学习宣传贯彻党的十九大会议精神以及习近平总书记系列讲话精神，认真抓好学院思想政治工作。二是优化基层党政领导班子的年龄、知识和专业结构，不断壮大基层党组织干部队伍。三是认真做好基层党组织量化考核，以评促建互助提升。四是扎实深入开展“两学一做”学习教育，积极探索独立学院党建工作创新创优创强途径，为学院健康稳定和可持续发展提供坚强的思想、政治和组织保证。
