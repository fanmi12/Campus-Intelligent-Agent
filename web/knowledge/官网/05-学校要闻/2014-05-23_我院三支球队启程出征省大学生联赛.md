# 我院三支球队启程出征省大学生联赛

我院羽毛球、乒乓球、排球三支运动队即将启程赴广州参加广东省大学生联赛。出征之前，5月21日，学院在体育教学部会议室召开动员会，为参赛运动员送行。党委副书记章德胜、副院长高香林、体育教学部主任邢红林出席动员会。

章德胜副书记、邢红林主任勉励运动员时表示，此次我院派出三支队伍50多名运动员参赛，是为同学们提供一次学习锻炼、切磋球艺的机会。希望大家勇于拼搏、协作配合、尊重对方与裁判，遵守比赛规则，充分展示城院学子的风采，争取好的成绩，为学校争光。祝你们凯旋而归。
