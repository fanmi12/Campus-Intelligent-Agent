# “节约资源 保护环境”大型环保知识竞赛决赛昨举行

11月3日，“节约资源，保护环境”大型环保知识竞赛在学术报告厅举行决赛。院督学陈丁堂教授，党委宣传部部长、思政部主任何鹏举教授，教务处副处长谭汪洋副教授观看了比赛。

比赛分为必答、抢答、风险题三个阶段，环环相扣，妙趣横生。各队在激烈的交锋中各显风采，场面十分火爆、精彩。

经过几轮竞赛，城市与环境科学系喜夺桂冠，文学与传媒系、财经系获二等奖，政法系、机电工程系、金融与贸易系同获三等奖。管理系的邓子华等五位同学获得了优秀个人奖。

据悉，本次知识竞赛由思想政治理论课教学部主办，党委宣传部、教务处、学生处、城市与环境科学系协办。比赛内容以环保知识为主，诣在丰富大学生的环保知识面，提高环境保护意识，呼吁我院大学生重视环保，积极投身到保护环境的行列之中去。
