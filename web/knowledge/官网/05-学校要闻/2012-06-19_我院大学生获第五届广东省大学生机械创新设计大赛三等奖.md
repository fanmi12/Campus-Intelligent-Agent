# 我院大学生获第五届广东省大学生机械创新设计大赛三等奖

近日，第五届广东省大学生机械创新设计大赛在广州落幕。我院09级机械设计与制作及自动化专业学生陈伟洪、詹清源、张金城、冯智科设计的“高度可调节悬挂式晾衣架”获得三等奖。

据指导老师谭海鸥介绍，这是我院首次参加此次大赛。全国大学生机械创新设计大赛是由教育部高等教育司组织的全国大学生竞赛项目，是教育部、财政部通过“质量工程”持续三次资助的全国大学生竞赛项目之一，是具有广泛影响力的大学生学科科技竞赛，赛制为每两年举办一次。历届比赛以其理论要求的严谨性、题目要求的挑战性、动手实践操作的趣味性成为广大学子踊跃参与、充分展现自己才能的大舞台。本届大赛的主题为“幸福生活——今天和明天”；内容为“休闲娱乐机械和家庭用机械的设计与制作”，广东赛区共有华南理工大学、华南农业大学、广东工业大学、汕头大学、深圳大学等31所省内高校共162支队伍参加激烈的角逐。
