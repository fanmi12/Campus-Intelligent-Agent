# 我校召开第二届教职工代表大会暨工会会员代表大会第三次会议

7月4日，我校第二届教职工代表大会暨工会会员代表大会第三次会议在行政楼112会议室召开。校领导、第二届教职工代表以及来自各单位的列席代表参加了会议。会议由党委书记章德胜主持。

王卫平校长向大会作了校长工作报告，重点汇报了2018—2019学年学校重点工作完成情况，提出了2019—2020学年重点工作的思路和计划。

财务处处长余竹根作了财务工作报告，汇报了2017—2018学年财务预算执行情况和2018—2019学年财务预算情况。工会副主席王锦峰作了工会工作报告，汇报了2018—2019学年工作情况和下学年工作计划。

校领导章德胜、高香林、黄兢、周庆、刘玉侠分别向大会作了工作述职报告，就各自分管业务和部门2018-2019学年工作情况、存在的不足和下学年工作思路、目标与方向进行了汇报。
