# 我院学生会荣获“广东省优秀学生会”称号

近日，广东省学生联合会公布了“关于表彰2017-2018学年度广东省优秀学生会、优秀学生社团、优秀学生干部的决定”。我院学生会荣获2017-2018学年度“广东省优秀学生会”称号。

院学生会在院党委领导和院团委指导下，秉承“自我教育、自我管理、自我服务、自我监督”，以全心全意为学生服务为宗旨、坚持“从学生中来，到学生中去”的原则，成为学院联系学生的桥梁和纽带。

在过去的一学年，院学生会对各项制度进行了完善，积极响应全国学联改革方案，实现了权益维护与服务板块的建立，在思想引领、组织建设、素质拓展、学生社团、新媒体平台建设等工作中取得了良好的成绩。院学生会还成功承办了阳光心理健康工程“525心理节”、城院首届国际形象大使选拔活动、心愿瓶活动、第十一届现场书画创作大赛、第六届“情入诗五行?观百态人生”征文大赛、第三届思想道德素质大赛、饭堂厨艺比拼大赛、城社梦幻”社团嘉年华晚会、校园十大歌手、科技游园会等多项院级活动。
