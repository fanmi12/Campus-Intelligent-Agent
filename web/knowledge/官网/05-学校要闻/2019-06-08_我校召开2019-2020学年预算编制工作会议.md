# 我校召开2019-2020学年预算编制工作会议

6月6日下午，我校召开2019-2020学年预算编制工作会议。校领导王卫平、章德胜、高香林、黄兢、周庆、刘玉侠以及各二级单位负责人出席了会议。

财务处谢广宇老师详细介绍了新学年预算编制的主要程序、预算经费的申报方法和工作要求。

财务处长余竹根对本学年预算编制工作进行了分析总结，并对预算编制过程中需要注意的事项进行了说明。

周庆副校长要求各单位对预算编制工作给予高度重视，结合本单位新学年的工作目标及重点认真开展预算编制工作，提高预算编制和管理水平。

王卫平校长强调，学校开展预算编制工作时间紧、任务重。各单位要加强沟通联系，紧密围绕学校的中心工作，推进预算执行进度，按时完成预算编制工作。
