# 我院学生作为“市民记者”参观生猪宰前检疫检测情况

10月26日，《东莞日报》与东莞市农业局联合开展“市民记者”体验活动。我院大学生记者应邀作为“市民记者”参与活动，与市相关部门领导、报社记者一起参观了东莞市动物卫生监督所视频监控室和莞城生猪屠宰场。

同学们现场察看了检疫申报点建设、运猪车辆证照查验和登记流程、车辆入场消毒、药残抽检、无害化处理设备、视频监控系统等检疫检测过程。前任记者团团长朱佩珊同学向监管部门负责人提问：“怎么样才能让市民购买到放心猪肉？如何辨别私宰猪肉？”。在场的领导耐心地回答了她的问题：“购卖猪肉时，首先要看售卖猪肉的摊位是否证照齐全、有没有检疫合格证明等，其次看猪皮上是否加盖有红色检验检疫合格印章。不要贪小便宜，最好是到规范的农贸市场或者超市购买。”

东莞市动物卫生监督所负责人表示，将继续做好卫生宣传工作，加强卫生部门与市民间的沟通，确保食品安全。
