# 我院教工子女共庆“六•一”国际儿童节

5月24日，为庆祝“六一”国际儿童节，学院工会举办了以“长知识、开眼界，共成长”为主题的亲子参观东莞市科技馆活动，同时观看《同一生命》球幕电影。该活动共有50多个家庭的130多名家长及儿童参加了活动。每位参加活动的小朋友都获得一份精美的礼物。

一进科技馆，展现在眼前的是机器人音乐会，小朋友们被机器人精彩演奏吸引。科技馆里有丰富的好玩的好看的各种展品，大家沉浸在欢乐之中。

《同一生命》球幕电影讲述了多种动物从生命之初到成长所面临的种种危机和学习生存技能、生命延续的方法及自我牺牲的伟大精神。从该影片感受到科技带给大家视觉的冲击及对内容无限深思。
