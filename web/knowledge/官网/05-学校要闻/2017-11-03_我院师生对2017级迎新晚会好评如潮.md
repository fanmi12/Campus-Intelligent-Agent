# 我院师生对2017级迎新晚会好评如潮

我院2017级迎新晚会——“拥抱青春季，爱党爱祖国”于10月29日成功举办之后，引起了热烈反响，受到广大师生的热捧。让我们来听听他们的心声吧——刚走进运动场的时候，的确被现场给震撼到了。炫酷的灯光，华丽的舞台，特别是台上的屏幕，足足有五个！预想不到学校为我们新生布置晚会是这么的用心！表演也相当精彩！我为晚会点赞，为城院点赞！

——17级计算机与信息科学系 计算机与科学专业1班 周俊炜

每年的迎新晚会都丰富了校园文化生活，展示了城院师生们的精神风貌。今年晚会又从主题上切合了党十九大的胜利召开——拥抱青春季，爱党爱祖国。从爱党爱祖国的思想层面，展现了城院师生们激扬青春的靓丽风采。晚会节目内容丰富多彩，引人入胜，舞台布置精美而不奢华，集中体现了城院人不忘初心，奋力前行，为实现中华民族伟大复兴的中国梦而共同奋斗的毅力和决心！

——16级文传系新闻班班主任 范保乐老师

我着实被城院2017年“拥抱青春季，爱党爱祖国”的迎新晚会惊艳到了！五光十色的灯饰，歌声缭绕的舞台，尖叫声与欢呼声响彻云霄。为了让我们大一的新生感受到了城市学院的魅力。在此我为我们大城院疯狂打call！

——17级金融与贸易系 电子商务1班 尹煜桦

迎新晚会节目丰富，质量高！既有外来文化韩流舞蹈，也有本土文化《爱上东莞》。全场热情高涨，各个节目都超赞！

——17级城环系 自然地理与资源环境专业1班 何艺樟

迎新晚会灯光效果不错，每个节目表演质量优异！我感受到既有城院的教学特色，又感受到中国不断强大的魅力。让我印象最深刻的是那小品《地铁故事》，激发了台下的热情和兴奋。我相信大一鲜肉会更好的期待美好的四年时光！

——17级财经系财务管理4班 谭治国

晚会办得很成功，绚丽的舞台、美轮美奂的灯光效果、丰富的节目内容，一切的一切都在吸引着我们的眼球。晚会内容很精彩，我们不仅为劲歌热舞喝彩，而且也被温馨的家人代表所说的寄语感动，最后被唤起了心中的熊熊爱国爱党之火。那一晚，我们沉浸在欢乐的夜色中。

——17级文学与传媒系 秘书学1班 梅绮婷

当舞台的屏幕上再次呈现军训时的视频，脑海中闪烁出我们军训生活的画面，似乎还听到教官的敦敦教导。感谢学校的迎新晚会，给了我们一个难忘的夜晚。

——17级财经系 财务管理4班 王颖津

迎新晚会给我的第一感觉就是震撼与精彩。节目丰富多彩，有舞蹈、唱歌、走秀、小品等表演节目。令我印象最深刻的是声乐队唱的《爱上东莞》，唱得令人感动，虽然我对东莞并不熟悉，但是我既然来到了东莞上学，来到了东莞追梦，那么我会把东莞当成我的第二个家乡。

——17级金贸系 国际贸易与经济3班 何静怡

我觉得今年的迎新晚会很有创新，节目内容有深度，有力量，总体感受非常不错。《我们的故事》让我印象最为深刻。它讲述了平凡的城院人，不平凡的故事，他们每个人代表了不同层次的人追逐梦想的经历，值得大家学习。希望17级的学生们能够积极参加活动，好好学习，树立人生目标，朝理想奋发前向。

——17级外语系辅导员 蔡超明老师

我觉得迎新晚会很精彩、很成功。表演节目够丰富，演出人员也十分给力。但我觉得现场秩序可以再加好一些，希望明年会更好。

——15级外语系商务英语1班 谢静雯

去年在台下，今年在台上，整整两个月的时间，换来两分钟聚光灯的光芒，观众永远不知道演员背后付出了多少努力与汗水，一样的角度、一样的高度、一样的力度，都需要队员们的磨合。永远不会忘记联排的那天晚上，练习到凌晨一点钟，记得那天操场上依然灯火通明。我爱舞蹈，同样也爱着Kpop韩流舞队！

——16城环系城规2班 李雅婷

今年晚会我是主持人！去年的我站在台下播新闻，今年站上舞台做主持，算是感触很深了。从准备到演出，第一次彩排到凌晨一点，为了突出主题和风格，很多队伍都将原本编排好的重新排，为的是呈现更好的效果。我们每个人付出的努力都是值得的。

——16级城环系环境工程2班 庞思霖

看了好几年的迎新晚会，我觉得今年迎新晚会的形式较新颖，节目也很丰富，灯光更是靓丽迷人，还有台上的每位表演者都用自己最好的状态展示给学弟学妹们，这是值得发扬的精神，感谢所有的工作人员为我们贡献这场盛会！

——14级城环系土木工程5班 黄嘉毅

我们的节目《爱上东莞》在台上用时不到七分钟。，但过去四个月辛苦准备的画面如同走马灯一般在我们的脑海里不停回放。从上个学期末开始构思节目，到暑假提前回到空荡荡的学校来排练，再到正式演出。经历过节目的编排，打回，又再编排的我们越发小心翼翼地对待这次的演出机会。

一切都来之不易。能够登上迎新晚会的舞台顺利完成演出，这对于每个演员来说都如梦似幻。

—— 16级文传系新闻1班 许敏

对于一个即将离开城院的大四学子来说，观看迎新晚会一定是感慨万千。不同年级的同学们欢聚在操场，我能深切地感受到气氛的热烈，表演节目也十分精彩。在看到学弟学妹们在舞台上努力表演，“小鲜肉”们不停地喝彩，我知道，这是我看过最美的晚会，我想以后也会更想念丰富多彩的学校生活。

——14级管理系物流管理1班 陈翠雯

晚会现场气氛热烈，表演精彩，掌声阵阵。小品《地铁的故事》则以幽默的方式，传播正能量，同学们在欢笑的同时也颇有收获。和往年不同的是，今年的晚会多了许多校外的观众，他们其中有一部分是学生的家长，有一部门是附近的村民，可见学校的名气在辐射和影响着东莞。

——15级机电系机械设计及自动化专业4班 彭德康

说起迎新晚会，相信大家都跟我一样意犹未尽吧！从军训磨炼时光到新生运动会，再到迎新晚会，我都像如获珍宝般珍惜它，只因它是属于你我的独家记忆。正如主持人所言，一朝遇见，一生眷念。

——17级财经系 财务管理4班 吕锐坚

动感的音乐和绚烂的灯光拉开了晚会的序幕，就连空气也洋溢着喜悦的味道。优美的舞蹈表演与3D LED屏幕的配合，营造了高清和真实的舞台效果，让我们身临其境，身体随着节奏摆动起来，简直是视觉与听觉汇聚而成的华丽盛宴。

——17级文学与传媒系汉语言4班 李怡彤

模特队的大长腿、阿卡贝拉清唱团好听的歌声、韩舞与街舞的热舞组合、古筝的青花瓷等，看得出他们付出了很多的努力与汗水，用温暖与热情将我们包围。暖暖的，很贴心。所有的演员、工作人员，你们辛苦了，谢谢你们！

——17级文学与传媒系 汉语言4班 魏彩虹

迎新晚会上，一个个精彩节目让我们目不暇接。我也不由心生感想，在这聚光灯下的老师、师兄、师姐，表演出如此精彩的节目，背后到底付出了多少时间和汗水，才能达到这样的高度。所以我决定，要学习师兄师姐和老师们吃苦耐劳的精神，绝不放弃。

——17级电子工程与智能制造学院电子信息工程1班 李钊宇
