# 院长助理麦绮琳成为优秀青年莞商候选人

近日，2014世界莞商大会组委会从96份有效提名表中确定了30人为优秀青年莞商候选人，并在《东莞日报》（2014年5月6日第A06版）、东莞阳光网（http://www.sun0769.com/）和 “世界莞商”官方网站（http://www.wdef0769.com/）开展评选活动，欢迎师生们参与投票。

在30名候选人中，我院院长助理麦琦琳上榜。

据推荐材料介绍：麦琦琳现为我院院长助理、东莞市鸿发教育投资有限公司总经理，社会职务为世界莞商联合会会员、东莞市侨联归国留学人员联谊会会员。

她留学回国后，怀着“兴教助学、功在当代、利在千秋”的信念，便投身广东鸿发集团的教育事业，决心为东莞的高等教育事业做点实事，为东莞老百姓作点贡献。为了尽快熟悉教育管理工作，掌握大学教育规律，曾到市教育局机关学习和研究国家教育政策，多次到美国、加拿大、台湾等国内外知名大学考察学习办学经验。担任辅导员，亲身体验学生工作的责任与甘苦。参加筹建城市学院新校区和艾立森国际幼儿园，为“一校一园”后勤保障操心费力。新校区建成后，她与学院党政领导共同谋划实施发展大计，使城市学院学生规模逐年扩大，教育教学质量不断提高，后勤保障与管理日渐科学与完善，成为机构健全、结构合理的新型本科院校，受到社会各界的认可和称赞。

她还带动身边的人积极参与医疗、赈灾救危、扶贫帮困、助学兴教等慈善公益活动，实实在在地回报社会。

据悉，我院投资方广东鸿发集团子公司广东鼎峰地产集团有限公司总裁简建锋亦为候选人之一。

院长助理麦绮琳
