# 《地方院校举办的独立学院办学质量与特色探析》顺利出版

我院院长安少华教授主持的院级重点课题“独立学院办学质量和特色探析”，历时两年的研究后取得了丰硕的成果。该课题成果《地方院校举办的独立学院办学质量与特色探析》一书，于今年7月份顺利出版。

全书共约50万字，收录了55篇论文，作者既有学院领导，又有基层教职工。该书中从办学的理念思路、教学模式和管理、教学改革、学生工作、党群政工、人事组织、后勤财务、和谐校园建设等方面，探讨了独立学院在办学上如何确保质量、形成特色这一重要问题，既有宏观的思考，又有微观的探讨；既有理论的研究，又有实践经验的总结，展示了我院在办学中所取得的理论成果和实践成果。

据悉，该课题还获得了我院2008年教育教学改革与研究项目特等奖。
