# 新航道领军人物胡敏率团来我院演讲

5月15日，应东莞理工学院副院长、城市学院院长安少华教授的邀请，北京新东方创始人之一、新航道国际教育集团胡敏总裁等3名专家来我院演讲，为1000多名师生介绍个人奋斗经历和成功的体会。

第一位演讲者是马朝霞，英语成功学金牌讲师，悉尼大学英语教育和企业管理双硕士，悉尼大学雅思培训专家，多年坚持“激情教学法”。她演讲时全用英语，口若悬河，手舞足蹈，激情所致，不时跳下讲台和同学们拥抱。第二位演讲者是徐卡嘉，牛津大学硕士，雅思培训和咨询专家。他以切身体会讲述失败与成功的关系，以及如何设计自己和为目标而奋斗。第三位演讲者是胡敏，他的成功闻名全国。他一上台同学们就报以热烈的掌声表示欢迎。他演讲的内容凝重，感情中肯，思想深邃，富于经验。胡敏在演讲中向大学生们传授学习英语的四大策略，从新航道“我坚持、我胜利”的精神，引申到大学生的人生追求和实现理想的成功之路。

演讲结束后，大学生们拥上主席台，争相和专家们合影留念。财经系陈玲玲同学说：“听他们的演讲是一种高雅的艺术享受。”

院长安少华教授亲切地接见了三位专家，并向他们表示感谢。

新闻链接：胡敏15岁毕业于湘潭大学，19岁开始登大学讲台教学，28岁任北京国际关系学院副教授，多次应邀访问英国、日本和韩国；由他开创的雅思、四六级、考研等英语培训理念及教学模式在全国得到广泛应用，先后培训100多万人次。
