# 我院荣获广东省2017展翅计划评选活动优秀组织奖

11月12日，由广东省学生联合会主办，省青年创业就业基金会等单位承办的2017?展翅计划“首席实习生”评选活动决赛暨颁奖典礼，在华南理工大学广州学院举行。

我院团委组织438名同学报名参加该项评选活动，其中外语系陈慧珊、彭奕晴和计信系陈军名同学在全省7700多名同学中脱颖而出，入围百强选手并获得“优秀实习生”称号。我院荣获“优秀组织奖”。

据悉，2013年，共青团广东省委员会联合省人社厅、省教育厅等十家单位共同发起的帮助大学生就业创业能力提升行动——“展翅计划”，该计划已帮助30多万名大学生获得实习锻炼。
