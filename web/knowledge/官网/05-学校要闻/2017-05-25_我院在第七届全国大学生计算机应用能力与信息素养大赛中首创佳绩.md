# 我院在第七届全国大学生计算机应用能力与信息素养大赛中首创佳绩

5月20日至21日，第七届全国大学生计算机应用能力与信息素养大赛在中央民族大学举办。我院首次参加该项赛事，并取得了团体一等奖1项和一等奖2项、二等奖2项的好成绩。

本届大赛设立计算机基础、Office商务应用能力和专业英文三个赛项，以及本科、高职（专科）两大组别。通过激烈的技能竞技，我院代表队脱颖而出，取得了优异成绩。其中，胡良兰老师指导的邓浩锋同学获得本科组Office商务应用能力-文字处理全国一等奖；刘运城老师指导的张琪同学获得本科组Office商务应用能力-电子表格全国一等奖；潘玉茹老师指导的温嘉红同学获得本科组Office商务应用能力-简报设计全国二等奖；蹇柯老师指导的黄碧波同学获得本科组计算机基础赛项全国二等奖。同时，我院还获得Office商务应用能力赛项本科组团体一等奖。邓浩锋和张琪同学还获得8月份在台湾举行的海峡两岸对抗赛的参赛资格。

我院计信系计算机基础教研室从2016年11月本届大赛启动以来，经过全院宣传、动员、报名、培训、个人练习等环节。今年4月进行了两轮院校选拔赛，16级机械本1班邓浩锋、15级软工本1班黄碧波、15级金融本3班温嘉红和16级国贸本2班张琪等四位同学脱颖而出，首次组成我院代表队参加全国总决赛。

据了解，全国大学生计算机应用能力与信息素养大赛是由全国高等院校计算机基础教育研究会、全国高等学校计算机教育研究会、《计算机教育》杂志社等单位联合主办，旨在推动高等院校计算机基础教育教学改革与创新，培养学生解决问题能力、创新能力和国际交流能力，促进学生计算机应用能力和信息素养能力提升。本届大赛共有来自全国185支院校代表队，总计15000名学生参加。经过院校选拔赛，最终进入总决赛的院校代表队有165支，含28支台湾院校代表队，参赛选手561人。
