# 机电工程系举办青年教师讲课比赛

为贯彻学院“关于开展2012年青年教师讲课比赛的通知”精神，切实提高青年教师的课堂教学能力和教学积极性，11月08日,机电工程系在8A305教室举办了2012年青年教师讲课比赛。评委由系里相关专业的教授、副教授组成，比赛由教研室主任殷素峰主持。

参赛的六位青年教师准备充分，将比赛当成锻炼自己的一个平台，精心设计各个教学环节，整个比赛过程既严肃认真，又轻松活泼，充分展现了我系青年教师的精神风貌和专业水准。经过2个多小时紧张的角逐，评委们从教学内容、教学方法、语言表达、教学过程、教态仪表等方面为参赛教师打分，最后陈小艳荣获一等奖；曾月鹏、方琳荣获二等奖；张锦荣、罗彦琦、谭海鸥荣获三等奖。
