# 院领导走访系部了解迎评工作情况

程发良副院长（右一）在艺术系办公室了解暑期迎评加班工作的进展情况

张林副院长（中）与评建办秘书长李先庆（右二）在管理系办公室了解迎评工作情况7月14日上午，程发良副院长、张林副院长率领教务处和评建办相关工作人员分别到各系部了解暑期迎评工作的进展情况，对各系部加班的老师表示慰问，勉励大家继续做好迎评材料的准备工作。

据悉，根据省学位办会议精神，评估工作将提前到今年开展。7月9日，学院为此召开了专题会议，统一了思想，明确了任务，布置了工作。会上，程发良副院长做了工作布置，安少华院长做了动员报告。要求各系部通过7月10日至16日加班，完成第二阶段的评估准备工作，8月20日全体教师提前回校，9月份前完成全部迎评材料的收集整理工作。
