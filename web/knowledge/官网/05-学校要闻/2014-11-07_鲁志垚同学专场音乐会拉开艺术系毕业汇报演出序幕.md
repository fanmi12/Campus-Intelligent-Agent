# 鲁志垚同学专场音乐会拉开艺术系毕业汇报演出序幕

11月5日，艺术系在学术报告厅举办11级音乐表演专业鲁志垚同学专场音乐会。优美的歌声吸引了许多同学前来观看，整个学术报告厅座无虚席。团委书记罗文芳，艺术系林伟伦、梁贝、李瑶、杨志强等几位老师观看了鲁志垚同学的才艺展示。

音乐会在林伟伦老师的歌声中拉开帷幕，紧接着阿卡贝拉的《对你爱不完》将气氛点燃。音乐会主角鲁志垚先后倾情演唱了《残酷月光》、《天后》、《你要的爱》等歌曲，毕业校友用小提琴为他伴奏。鲁同学的演唱赢得听众阵阵喝彩，报告厅内掌声、欢呼声不断。

林伟伦老师发表感言，说:“鲁志垚是一个很有音乐天赋又很勤奋努力的学生。借用这个机会，也祝福11级即将毕业的同学们能顺利实习，顺利毕业，有更多的专场音乐会出现在今天的舞台上。”

“感谢城院，这四年来我收获了很多。很感谢各位恩师对我的帮助。”鲁志垚对记者表达了今天的感动。
