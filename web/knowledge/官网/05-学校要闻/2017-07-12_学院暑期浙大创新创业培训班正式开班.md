# 学院暑期浙大创新创业培训班正式开班

2017年7月11日上午，学院创新创业教育研修团一行30人在杭州市浙江大学举行开班仪式。培训单位浙江大学继续教育学院主任陈曦、学院办公室主任、研修团领队杜鹏举为本次研修作开班讲话。开班仪式上，陈曦主任对参加本次创新创业师资培训的教师表示热烈欢迎，杜鹏举主任对各成员提出本次研修的学习任务与要求，希望通过本次研修进一步提升学院创新创业教育教学能力与创业指导能力，摸索适合学院教学实际的创新创业教学模式。

开班第一天，浙大创新创业教育专家分别以“高校创新创业教育的思考与实践”、“高校创业教育的战略选择”、“国内创业现状：六个因素”为主题作专题汇报，对创新创业教育体系、课程设置、组织架构图、内容分层实施机制、与专业学科教育融合等基本问题进行详细讲解，内容翔实，充分体现了浙江大学在创新创业教育方面取得的优秀教学成果。教师们积极提问、发言，专家答疑，课堂气氛活跃，课堂教学效果显著。除以上培训内容外，接下来4天时间，将对创业融资、创业实践指导、创业项目路演、创新创业教育教学能力提升、大学生职业发展辅导与创业就业教育现状等专题进行深入学习。
