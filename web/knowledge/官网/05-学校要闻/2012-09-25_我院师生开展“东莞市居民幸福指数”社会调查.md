# 我院师生开展“东莞市居民幸福指数”社会调查

9月22日，受东莞报业集团委托，我院东莞社情研究中心周巍、赖沛东、何秀青三位老师带领09级社会工作专业、10级社会工作专业、10级文秘专业约100名学生，到32个镇区开展“东莞市居民幸福指数”大型社会调查活动。

据介绍，该调查是东莞报业传媒集团和东莞社工委联合举办“南粤幸福活动周”宣传报道工作的重要组成部分。调查结果将为政府及其相关部门了解和掌握东莞群众幸福状况提供参考资料。
