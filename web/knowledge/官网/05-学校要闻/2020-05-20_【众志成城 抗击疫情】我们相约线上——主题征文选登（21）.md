# 【众志成城 抗击疫情】我们相约线上——主题征文选登（21）

我校重点关注学生在线学习的效果，切实保障网络课堂的教学质量。学校领导提出，“生活就像海洋，只有意志坚强的人才能到达彼岸，在这最艰难的时期，我们不仅要确保身心健康，同时积极利用这次‘网络教育’的机遇，主动适应学习方式、学习环境和学习形式的变化”。从3月19日起，我校组织了《我们相约线上》学生主题征文活动，今天推出的是第二十一期作品选登，推介金融与贸易学院骆楚莹、外国语学院莫晓敏、外国语学院赖心怡三位同学的征文作品，欢迎大家踊跃来稿，积极参与讨论。

一、我们相约线上

——金融与贸易学院 骆楚莹

在家上网课的两个多月时间里，已经习惯了在家上课的节奏。在线上上课，虽说有时候因为网络问题，老师声音卡出电音，或者是同学们的样子卡出重影，学习效率也没有课堂上高，但还是挺有趣的。在线上上课能够更好的看清老师在写什么，不会像在课室那样因为“地理位置”不好而看不清黑板，能够更好地做好笔记，还可以看回放补充自己的笔记。我自己最喜欢的“网红老师”是我们的英语老师——贺力鹏老师。他讲课幽默风趣，他最喜欢的就是上课点同学回答问题，让大家时刻打起精神，不得松懈。在讲课的同时，他会给我们讲很多他丰富的人生经历，他会给我们介绍他曾去过的地方或者国家，开阔我们的眼界和知识面，穿插在课堂中，用他的经历让我们更好地理解课文，爱上英语。

二、线上学习心得

——外国语学院 莫晓敏

在这场抗“疫”斗争中，我们全院师生在防范疫情的同时，也不忘自己的本职工作。

这是一节别开生面的英语阅读课。说实话，我从来都没有想过在我的学习生涯中，会有用电脑上网课的一天。这次疫情让全国人民闭门不出，但是我们的“园丁们”却从来没有忘记他们教书育人的职责。即便是网课，老师还是认认真真准备好上课的材料，详细解读每一篇文章，耐心解答我们的问题，除了不像学校里那样近距离相处，其他方面也没有太大区别。在这次抗“疫”斗争中，我们全院师生自觉承担起自己的责任，为抗“疫”出一份力。

三、线上学习心得体会

——外国语学院 赖心怡

如今疫情当前，但中华民族能够在历史的长河经久不息源远流长，就是因为当需要的时候，我们总会有那么的一批人站出来，军人对抗战役，医者抵挡疫情，他们的无私无畏无欲，是值得我们敬佩尊敬的！也因为这一场的战疫，让我们得以线上学习的机会，实现了当时作文中的“如果有一天能在家学习”。

作为当代大学生，我们应当不信谣不传谣，响应国家号召，积极隔离，积极参与防疫工作，认真参与线上学习。而线上学习更加增强了我们自主学习的能力，培养了我们自主学习的精神，让我们养成了自觉的习惯。也让我懂得了“我们一生中会失去很多东西，唯独不能失去突围的勇气”的真谛。
