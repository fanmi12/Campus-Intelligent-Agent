# 首批11项大学生创业项目获驻孵化基地

3月26日下午，我院大学生创业孵化基地首批申请入孵项目答辩会在招聘大厅擂响了战鼓，来自全院各专业的17个创业团队为大家展示了一幅幅富有雄心的创业蓝图。

TDK跨国公司开发部高级经理李兴红，中国洁净技术协会工程师、静电控制技术工程师李生军，风险投资公司高管晏华，超过8年企业管理经验及逾十年的企业培训师经验、作为WSI集团讲师团队统筹人员的汪文玲老师组成的导师评审团，担任这次大赛的评审。

答辩会分为项目展示、公开答辩和导师点评三个部分，每个申请项目在15分钟内进行路演和答辩。在展示环节中，各创业团队通过PPT演示、实物演示等方式对创业项目进行了精彩的解说。项目负责人从容冷静的答辩，展现出了我院大学生对创业的坚定信念。评委们从多个角度进行提问，与选手们进行细致的分析，并给出了极具针对性的建议。

答辩会现场气氛浓烈，精彩纷呈，各团队也是极尽所能地将团队创业项目的优势展现在评委们面前。在“问与答”式的巅峰对决中，企业家们和雄心壮志的城院学子进行了一场精彩的思维碰撞。评委们对同学们的优异表现，赞叹不已，而评委们的睿智点评与建设性意见也让参赛项目团队受益匪浅。

经过导师评审团的评审决定，共有游吧文化团队、山脊户外俱乐部等11个优秀团队获得进驻大学生创业孵化基地的入场券。
