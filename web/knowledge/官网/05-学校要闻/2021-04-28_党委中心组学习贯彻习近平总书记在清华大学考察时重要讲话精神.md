# 党委中心组学习贯彻习近平总书记在清华大学考察时重要讲话精神

坚持以习近平总书记在党史学习教育动员大会上的重要讲话精神为重要指引，不断提高政治站位，扎实有效地推进我校党史学习教育工作。4月28日上午，学校党委理论学习中心组在行政楼505楼会议室召开学习会议，学习贯彻习近平总书记在清华大学考察时重要讲话精神、学习习近平总书记关于新发展阶段、新发展理念、新发展格局重要论述摘编，以及学习深化新时代教育评价改革总体方案。中心组全体成员参加了会议。党委书记章德胜主持了学习会。

在章德胜书记的领学下，学习贯彻习近平总书记在清华大学考察时重要讲话精神。4月19日，在清华大学建校110周年校庆之际，习近平总书记来到清华大学考察。他强调，百年大计，教育为本。我们要建设的世界一流大学是中国特色社会主义的一流大学，我国社会主义教育就是要培养德智体美劳全面发展的社会主义建设者和接班人。我国高等教育要立足中华民族伟大复兴战略全局和世界百年未有之大变局，心怀“国之大者”，把握大势，敢于担当，善于作为，为服务国家富强、民族复兴、人民幸福贡献力量。

学习会上，中心组成员还着重学习了习近平总书记关于新发展阶段、新发展理念、新发展格局重要论述摘编和深化新时代教育评价改革总体方案。

章德胜书记在学习会上表示，大家要深刻领会习近平总书记重要讲话精神的重大意义和指引作用，全面准确把握精神实质和丰富内涵，结合好党史学习教育和实际工作，推动习近平总书记重要讲话精神入脑入心、落地见效。

章德胜书记强调，学校党委要切实提高政治站位，加强组织领导，迅速掀起学习贯彻热潮，将习近平总书记在清华大学考察时重要讲话精神、党史学习教育在城院落地生根、开花结果。
