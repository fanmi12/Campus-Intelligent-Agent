# 商学院举行2019级云财务卓越班开班典礼

9月23日，我校商学院和新道科技股份有限公司共同建设的“财务管理（云财务卓越班）”举行开班典礼。新道2.0项目总监冯建中、广东区总经理黄堪敬，我校副校长高香林、招生就业处处长孔增强、商学院院长罗卫国和2019级云财务卓越班师生参加了典礼。

罗卫国院长主持典礼并致辞，指出我校是全国第一所与新道联合培养云财务管理会计师的本科高校，从去年开设云财务卓越班到现在，已收到很大成效。他把2018级云财务卓越班比喻为“黄埔军校”第一期，而2019级云财务卓越班是“黄埔军校”第二期。云财务卓越班将在云财务人才培养方案修订、实训环境建设、教学团队建设、社会服务建设等全过程中，围绕云财务创新链、特色产业链以及财务人才培养链进行结合，紧跟产业发展趋势，建设创新特色的财务管理专业，培养大数据时代下云财务管理专业人才。

黄堪敬总经理介绍了云财务卓越班的专业特色，从培养内涵和实习就业等方面，对云财务卓越班与普通财务管理专业的差异性进行了说明。他寄语2019级云财务卓越班新生：“梦想实现需要付出辛勤汗水，不断茁壮成长，终有一日可以展翅高飞。

典礼上，校企双方领导为学生代表佩戴专属徽章，并为荣获新道企业奖学金的2018级、2019级学生，以及获得新道企业奖教金的教师颁发了奖金与证书（详见获奖名单）。
