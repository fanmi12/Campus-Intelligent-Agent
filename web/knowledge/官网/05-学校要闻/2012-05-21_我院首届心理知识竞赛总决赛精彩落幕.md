# 我院首届心理知识竞赛总决赛精彩落幕

5月20日，“5?25”心理健康活动月首届心理知识竞赛总决赛暨心理工作表彰大会在学术报告厅隆重举行。党委副书记朱冰、章德胜，院督学陈丁堂教授等领导莅临比赛现场。

决赛分为“必答题”、“抢答题”和“风险题”三大环节，环环相扣，层层深入。十支参赛队伍你来我往，异彩纷呈。选手们团结协作，机智勇敢，沉着应对。经过激烈的角逐，金贸系一马当先，夺得桂冠。政法系、文传系获得二等奖。艺术系、管理系和财经系获得三等奖。城环系、高职部、机电系和计信系获得优胜奖。

比赛结束后，心理健康教育与咨询中心副主任余琼老师对“5?25”心理健康活动月进行总结。据余老师介绍，“5?25”心理健康活动月除了开展心理知识大赛外，还在新老校区各班级开展了主题班会、系列心理讲座、心理剧大赛，并开设了心理电影周。通过一系列的活动，传播了心理知识，使更多的同学能保持良好的心态，面对困难不退缩，更有勇气迎接每一个新的挑战。
