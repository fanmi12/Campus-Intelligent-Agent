# 我院新添南方外国语学校实习基地

副院长程发良（右一）与松山湖南方外国语学校负责人共同为实践基地挂牌5月8日，副院长程发良率实践办主任谢俊、文传系主任陈庆祝、英语教研室主任李玲玲和艺术教研室王宁老师赴松山湖南方外国语学校，与该校签署《东莞理工学院城市学院校外教学实践基地建设协议书》，并举行了实践基地挂牌仪式。

协议本着产学优势互补、互惠互利、共同发展的原则，为学生提供学习与实践场所。双方约定，每年11月份举行实习总结报告会。
