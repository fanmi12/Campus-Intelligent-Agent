# 东莞职业技术学院来我院考察交流

11月27日，东莞职业技术学院副院长杨云奇一行5人来我院参观图书馆，并就后勤管理、综合馆利用等方面与我院领导进行交流。

我院高香林副院长、总务处翟耀明处长、图书信息中心陈显龙副主任等热情接待了客人。双方就图书馆资源建设，休闲阅览空间的利用，图书馆办公用具与设备的购置，读者服务和开展读者活动等问题进行了深入的探讨。客人对图书馆借助咖啡厅“协同育人、服务读者”的经验，以及引入外部资金搞活校园文化活动的合作模式特别感兴趣。

随后杨云奇副院长一行还对我院综合馆多功能利用、后勤管理和资源的协同调度等方面的工作进行了实地考察和交流。
