# 金正昆教授应邀来我院传授礼仪知识与沟通秘诀

5月25日，全国知名礼仪与公共关系专家、博士生导师、中国人民大学国际关系学院外交学系主任金正昆教授，应中国移动东莞分公司之邀做客“中国移动手机悦读会?名家大讲堂”，在我院新校区报告厅做“社交礼仪与有效沟通”主题讲座，向在座师生传授社交礼仪与有效沟通的要点与“秘诀”。

金正昆教授指出，礼仪就是“求同存异”中的“同”，先从众，而后与众不同。因为世界的多样性，所以讲礼仪就是讲规矩、讲教养，就是为了有效沟通。同时，金正昆教授还抛出了“接待就是生产力”的论断，并指出接待工作中应注意的细节，从而促进有效沟通，达到接待工作的最终目的。

讲座中，金正昆教授还就大学生今后求职应注意的礼仪和沟通方式与技巧，传授了自己的经验。金正昆教授希望同学们在各种场合中，要“落落大方地起立回答”、“简单自我介绍”和“礼多人不怪”的重要性，并通过实例指出了求职者在求职过程中存在的误区与过失，注重有效沟通的技巧和智慧。
