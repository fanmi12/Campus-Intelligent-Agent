# 学院召开2008年学生工作会议

为认真贯彻学院中层干部会议精神，总结办学五年来的学生工作经验，确立新形势下我院学生工作的发展思路、努力方向和工作重点，11月15日，学院在学术报告厅召开2008年学生工作会议。院领导安少华、朱志德、朱冰、张林、陈丁堂出席会议，辅导员、班主任等近200名学生工作人员参加了会议。

党委书记朱志德首先致辞。辅导员叶凯贞、彭莉钧老师，班主任王晓春、黄江英老师，分别介绍了学生档案管理、学生信息化建设、班主任工作等方面的经验。大家认为，学生工作既繁杂艰巨又光荣重要，学生工作者必须具有强烈的爱心和高度的政治责任心，才能把学生工作做好。要责无旁贷地肩负起教育、管理、服务的三重责任，自觉成为学生思想的“指路人”，学业的“引导者”，情感的“守护神”，班级的“指导员”。

院督学陈丁堂和政法系党总支副书记石志民，针对大学生思想政治理论教育做了主题发言。他们认为，目前思想政治理论教育存在课堂教学与行为规范养成教育结合不紧的现象，应当建立理论教育与行为训练相统一的模式，关爱、尊重学生，高度重视社会实践和行为规范的养成教育。

党委副书记朱冰在会上发表了重要讲话。她说，五年来，学校各级党组织、学生工作部门，始终秉承“一切为了学生，为了学生一切，为了一切学生”的思想，高度重视学生教育和管理工作，始终把学生工作摆在突出地位，做了大量卓有成效的工作，学生工作取得丰硕成果。具体表现在：学生思想政治教育取得新成效；学生党团组织建设迈上新台阶；学生日常管理实现新跨越；招生就业工作取得新突破；贫困学生资助工作取得新进展；心理健康教育作出新尝试；校园文化建设进入新境界。

关于如何进一步做好我院学生工作，朱冰副书记讲了四点意见：一、更新教育观念，树立科学育人观，实现全员育人的工作格局。全院教职工要通过教书育人、管理育人、服务育人，形成人人关心学生、关心学生工作的良好氛围。二、准确把握独立学院学生的特点，增强学生工作的针对性和实效性。学院和学生工作者，要根据当代大学生特别是90后学生中出现的新情况和新特点，“因材施教”，改变工作作风和方法，创新形式和载体，扬长避短，服务学生。三、把握建设省内一流本科独立学院的内在要求，提高学生工作的创新性。这一创新不仅仅是工作方法上的创新，也是工作理念上的创新，工作手段上的创新。要潜心研究经济发达地区独立学院学生工作的特点与规律，围绕政治教育、心理健康教育、解困育人、招生就业等方面的难点和热点问题展开研讨，把学生工作做细做活做出成效。四、突出重点，不断开创城院学生工作的新局面。当前和今后一段时期的工作重点是：加强学生工作队伍的建设、学风建设、党团组织建设，抓好毕业生就业、困难学生资助、社会实践、心理健康教育和校园文化建设等工作。

院长安少华在听取各小组讨论情况的发言后，做了总结讲话。他希望全院教职工要高度重视学生工作，上下一心，齐抓共管，形成合力。学生处要继续加强以辅导员、班主任为骨干的学生工作队伍的建设，通过业务培训、经验交流等形式，提高他们的业务素质和工作水平。要通过例会制度，进一步加强对系一级学生工作的总协调。学生工作者要有光荣感和责任感，做事说话一言一行要对学生负责，处处做他们的表率；要树立正确的“学生观”，以学生为本，关爱学生的成长进步。

学生处处长章德胜主持了本次会议。
