# 工会组织女教职工欢度“三八”妇女节

3月10日，我院工会组织女教职工开展“寻味顺德地道美食，领略凤城悠久文化”主题活动，庆祝“三八”妇女节。刘玉侠副院长、工会王锦锋副主席和学院100名女教职工参加了此次活动。

活动参观了具有“广东周庄”美誉的逢简水乡。大家穿行于古屋祠堂，石板古道之间，探访有着历史底蕴的古桥，游览着独具岭南文化风情的桑基鱼塘，融入在“小桥流水人家”的唯美画卷之中。

活动还参观了“亚洲第一大牌坊”——顺峰山牌坊，游览了顺德博物新馆。围绕着“顺德人，顺德事”，大家充分感受了顺德这座充满历史韵味的城市，为顺德文化的底蕴所折服，被顺德人的精神所撼动。顺德特产美食小吃，自然不可错过。在华盖路步行街，大家一边参观岭南西洋骑楼群，一边品尝着街边美食，领略了顺德食物之鲜美、建筑之秀美，度过了一个愉快的周末。
