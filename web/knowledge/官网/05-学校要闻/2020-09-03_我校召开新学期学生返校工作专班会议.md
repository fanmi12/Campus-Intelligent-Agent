# 我校召开新学期学生返校工作专班会议

9月3日上午，我校召开新学期学生返校工作专班会议。校领导王卫平、章德胜、高香林、黄兢，各机关、教辅部门负责人和二级学院院长、党总支书记出席了会议。

章德胜书记传达了近期省委教育工委、省教育厅学生返校专班调度视频会议的有关精神，重点介绍了学生返校疫情防控工作的15点要求。他强调，要进一步层层压实疫情防控工作责任。学校2020年秋季学期学生返校工作专班领导小组全面负责、统筹疫情防控工作，承担主体责任；八个工作组各司其职，切实承担起各自领域的责任与担当；各级党组织及书记切实提高政治站位，统筹做好学生返校工作；学校已下发《东莞理工学院城市学院疫情防控期间有关管理规定》，各级党组织、各单位要严格遵照执行，全力做好秋季学期学生返校工作。

王卫平校长在会议上强调，各级党组织、各单位要压实各个层面、各个环节、各个岗位的疫情防控责任，落实好校内人员管理的责任，落实校内场所的分类管理，落实校内师生活动的规范管理，继续绷紧疫情防控这根弦，绝不能麻痹大意，主动担当作为，加强协调配合，形成工作合力，做好各项工作。
