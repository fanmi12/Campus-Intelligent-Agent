# 我院举行第七届创新杯乒乓球赛

3月28日-29日，我院第七届创新杯乒乓球赛在乒乓球馆举行。

赛事由体育教学部主办，共有来自11个院系代表队的99名选手参赛。比赛为团体赛，采用积分赛和淘汰赛相结合的方法进行。

比赛中，选手们表现出色，各式扣球、类旋转球、弧圈球，以及正反手之间的切换自如、左拉右打等都表现出了较高水准。

经过为期一天半的激烈角逐，商学院夺得本届创新杯乒乓球赛冠军。城环系、金贸系、文传系、原电智院、原机电系、计信系、创意设计学院分别获得第2-第8名。
