# 我院举行2017年学生党员微党课大赛

12月14日下午，由党务工作部主办，财经系党总支承办的“不忘初心，牢记使命”——2017年学生党员微党课大赛，在行政楼112会议室举行决赛。高香林副院长出席了大赛活动。院办主任杜鹏举、思政部副主任石志民、党务工作部副部长叶凯贞、学生处副处长罗文芳、团委书记李瑶担任大赛评委。

大赛结合线上线下传播渠道，创新学生讲“党课”方式，以“党课”为载体创新学生党员教育模式，进一步推动“两学一做”学习教育常态化，引导学生党员深入学习贯彻党的十九大精神，提升党员素质，增强党性修养。

决赛十二位学生党员身着正装，结合制作精美的PPT，通过讲党课的方式，声情并茂地对“不忘初心、牢记使命”进行剖析、讲解。参赛选手富有感染力的精彩表现打动了评委和观众，博得阵阵掌声。他们富有张力、活力的演讲，展现了当代学生党员坚定拥护党的信念，以及顽强不屈、艰苦奋斗的优良品质。

经过激烈角逐，来自文传系杨晓君获得一等奖，政法系钟春苗、财经系伍奕婷获得二等奖，外语系许悦、金贸系许进、创意设计学院赵顺弟获得三等奖。电智院陈军名、艺术系陈培玲、计信系巫嘉喆、管理学尹功雯、城环系容永飞、机电系戚博获得优秀奖。

据悉，本期微党课大赛获奖选手将组成城院学生党员党课宣讲团，走入学生群众中宣讲党的十九大精神。

各院系（部）党总支书记、副书记，学生党支部书记观看了比赛。
