# 2013届毕业生看过来（毕业典礼照片下载）

6月28日，我院在莞城校区隆重举行2013届毕业典礼暨学士学位授予仪式。1000多名学士学位获得者受到拨穗礼遇。

学士学位授予仪式分别在大礼堂、学术报告厅、小剧场进行。院长杨敏林教授，党委书记朱志德研究员，副院长张林博士、高香林教授等院领导为毕业生正冠拨穗。

为了帮助毕业生们珍藏这一精彩美好的瞬间，新闻中心组织专业工作人员及大学生记者，为每一位毕业生拍摄了学位授予仪式的电子照片，请同学们自行截图下载。感谢方凡、黄志荣、冯梓维、麦晓婷、袁宇虹、叶善球、黎嘉豪7位同学拍摄和提供照片。

附：请在校园网内，用右键“另存为”或下载工具下载后，修改扩展名为“.RAR”即可打开。。
