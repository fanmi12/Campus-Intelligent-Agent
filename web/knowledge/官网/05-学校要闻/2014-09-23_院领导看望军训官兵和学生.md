# 院领导看望军训官兵和学生

9月21日上午，杨敏林院长、王卫平书记、章德胜副书记、高香林副院长等到军训训练场慰问军训团官兵。

在教师公寓前，院领导看到六连的同学们正在打军体拳，便停下脚步给予表扬与鼓励。

杨：同学们，经过这几天的军训，大家都辛苦了，感觉怎么样？

新生们齐声回答： 好！

院领导的到来让正在休息的16连师生提起了精神。来自江苏连云港的一名新生主动与杨院长聊了起来。

杨：是不是很辛苦？

新生：是。

杨：为什么？

新生：因为平时都在家都没训练过，每天都军训。

杨：我看大家的精神状态很好，其实这就是军训的第一目标，要把军训状态调整好，调整到我们重新进入大学学习的状态，因为经过高考我估计大家都疯狂地玩了好几个月，我们要把这个状态调回来，读好这四年的大学，所以军训就是大学一个新的测试，新的准备。

城院之歌

听到一阵《城院之歌》的歌声，院领导们循声来到一个连队，并与在场练歌的同学们交谈了起来。

杜：同学们唱得有点小问题，气没上来。

杨：我们请杜副处长示范一下。

杜：我纠正一下第一句 ，同学们“澎湃”那两个词唱得跑调了，应该这样唱…

杨：同学们再学学，这个同学，你来领唱吧。

杜：大家音唱得不太准可以，但是气势一定要提上来。

接下来，院领导和同学们一起唱了起来……

杨：现在节奏感和毅力感都出来了，很了不起，给点掌声，鼓励一下。

不一样的军训

与在田径场上训练的新生们不同的是，在主席台上还有一群以另一种方式军训的新生。他们就是我们军训工作的后勤部队，其中一项重要的任务就是审核军训稿件，统计军训心得，学习军事理论教程。他们来自不同的连队，不同的专业。

院长：这个是要考试的吗？

教官：对，闭卷考试。

院长：他们掌握的理论知识会更多一些。

院长：你是负责宣传部的宣传，一天能收多少稿子？

新生：上千份稿件，每个连都有近百份。
