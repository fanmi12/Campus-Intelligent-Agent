# 我院第一届“双代会”隆重开幕

5月20日，东莞理工学院城市学院第一届教职工代表大会暨工会会员代表大会在五号阶梯教室隆重开幕。东莞理工学院党委副书记、院长、城市学院董事长杨晓西教授，东莞理工学院党委副书记王江水，东莞理工学院副院长、城市学院院长安少华教授，党委书记朱志德，常务副院长程发良教授以及各代表团团长在主席台就座。学院党委副书记朱冰主持大会。

参加本次大会的正式代表75人，列席代表2人，特邀代表16人。 大会在庄严的国歌声中开幕。

我院党委书记朱志德致开幕词。他说：本次大会的召开，是我院教职工政治生活中的一件大事，肩负着加强民主管理、促进民主建设的神圣使命。希望各位代表能进一步了解学院的发展全局，通过认真讨论，交流思想，集思广益，做到统一认识，群策群力，共同克服改革发展中的困难，促进学院的可持续快速发展献计献策。同时也希望新的工会领导班子，切实加强工会的各项建设，为进一步推进学院的民主管理、科学发展提供保障。

东莞理工学院工会副主席何献青、东莞理工学院团委书记彭晓波、城市学院团委书记丘永辉分别在大会上致贺词，衷心祝愿大会取得圆满成功。
