# 东莞理工学院城市学院召开2006年招生情况通报会

5月9日，东莞理工学院城市学院在315会议室召开2006年招生情况通报会。东莞市教育局考试中心负责同志和来自东莞市各镇区的40多所中学的校长、教导主任共80余人出席会议。

会议由城市学院党委副书记朱冰同志主持。城市学院常务副院长程发良教授向与会人员介绍了城市学院的办学历程、学院现状和发展前景。东莞理工学院学生处副处长刑大立、彭晓波和城市学院招生办主任郭梅柏分别通报了两所学院的招生情况。据通报，东莞理工学院和城市学院2006年分别招收本专科大学生2030名与2220名，其中本科招生数分别是1530名与1320名，专科招生数分别是500名与900名（含职高）。城市学院2006年新增加3个本科专业（会计学、物流管理、法学），还开设国际会计与工商管理两个本科方向，面向全国招生的外省省份由去年的10个增加到20个。

会议认为，随着两所大学办学条件的改善、师资队伍的加强和教学质量的提高，今年将会有更多的考生来东莞理工学院和城市学院求学深造。广东省教育厅公布的信息表明，去年，城市学院在省内同类院校中，新生第一志愿填报率、报到率均为最高。为了满足东莞人民子弟圆大学梦的愿望，为了达到东莞籍的新生占新生总数的70%的目标，希望各中学要认真做好对两所大学的招生宣传工作，帮助考生填好志愿，使考生能够在东莞求学深造，在东莞就业发展。

与会人员还就专业选择、收费、专升本、考研及优惠政策等方面的问题进行了咨询。
