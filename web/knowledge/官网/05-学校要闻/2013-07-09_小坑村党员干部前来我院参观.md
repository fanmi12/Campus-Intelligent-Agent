# 小坑村党员干部前来我院参观

7月5日，小坑村党员干部一行50余人在叶金庆主任的带领下前来我院参观、交流，受到城市学院党委副书记朱冰等领导的热情接待。

朱冰副书记对小坑村党员干部来我院参观考察表示了热烈的欢迎，对他们一直以来支持城市学院的发展表示衷心感谢，并向来宾们介绍了学院的情况。

总务处副处长、鸿育后勤公司副总经理陈辉陪同客人参观学院的行政楼、教学大楼等教学生活楼群。通过参观，党员们对我院有了更清晰的认识，纷纷表示将继续支持城市学院的建设。
