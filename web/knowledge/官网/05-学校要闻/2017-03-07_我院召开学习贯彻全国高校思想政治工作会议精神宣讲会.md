# 我院召开学习贯彻全国高校思想政治工作会议精神宣讲会

3月5日星期天下午，我院在行政楼212会议室召开学习贯彻全国高校思想政治工作会议精神宣讲会。副院长刘玉侠和相关部门负责人参加了宣讲会。

省委宣传部理论处处长丁晋清为大家详细解读了《中共中央国务院关于加强和改进新形势下高校思想政治工作的意见》的文件精神和习近平总书记在全国高校思想政治工作会议上的重要讲话精神，指出了

新形势下

高校党建和思想政治工作面临的新任务、新挑战。

党务工作部副部长叶凯贞主持了宣讲会。
