# 我院荣获省高校优秀校报展示活动评选三等奖

日前，经广东省教育厅指导，由省高校宣传思想工作专业委员会组织开展的“第四届广东省高校优秀校报展示活动”评选结果揭晓，我院荣获本科高校组三等奖。

据悉，该评比活动每两年组织一次。在本届评选中，由省内各大报刊媒体权威人士组成的专家组，对全省100多所高校2013年-2014年出版的报纸，围绕办报条件、数字校报建设、文章质量、编辑策划和版面设计等方面进行综合评比。活动共评出本科高校组一等奖4名、二等奖5名、三等奖9名。
