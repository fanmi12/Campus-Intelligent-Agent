# 大学校长祝贺小学生毕业

安院长出席步步高小学毕业典礼7月6日，莞城步步高小学2011届毕业典礼在我院大礼堂举行。院长安少华、院办主任王玉应邀出席典礼，与步步高小学的孩子们共同分享了成长的喜悦。

据悉，我院有不少教职员工的子女就读于莞城步步高小学。教务处黄江英老师代表毕业学生家长在典礼上讲话，她感谢步步高小学对城院下一代的照顾和培养。
