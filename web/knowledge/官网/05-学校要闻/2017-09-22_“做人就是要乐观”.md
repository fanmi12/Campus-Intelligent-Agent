# “做人就是要乐观”

陈满庭是我院城环系2017级土木工程专业的新生，也是2017年优秀新生奖学金理科第一名的获奖者。来自广州增城的他高考分数为457分，超了广东省的理科二本录取线将近100分。

在高三历次模拟考试中，陈满庭的成绩都很好，也一直很稳定，但命运似乎开了玩笑。在看到自己高考成绩时，“我当时懵住了，因为我的估分是有500多分，结果少了50分。”他说，好在与城市学院有缘，而且被自己喜爱的土木工程专业录取了。这个乐观自信的大男孩，对这结果还是感到很满意，学校的环境和氛围也是自己喜欢的那种。

作为独生子，父亲对他一直管教严厉，原来希望他能读临床医学。土木工程这个专业是父亲的朋友介绍的，经过进行一番了解，陈满庭下定决心要从事土木建筑行业。 “只有目标明确了，自己才会用心学习专业知识。”对于这充满挑战的专业，他笑道：“我不怕吃苦，我很有耐心。”

谈起高中生活，陈满庭觉得注重劳逸结合很重要。“我的高三生活比较有规律，不会‘开夜车’学习。”一周里，他有为期五天半的在校学习，周六晚上和周日则上补习班。在高二时，他曾和同学组建了一支足球队参加校内的比赛。他说，在大学也会继续踢足球。

大学开始生活了，他仍惦记自己的恩师。在得知自己高考失利后，恩师们给他送来关怀和鼓励。生物老师说过：“开心是一天，不开心也是一天，为什么不乐观点，开心地度过每一天呢？”每每遇到不开心的事，陈满庭都会激励自己：“做人就是要乐观。”

进城院半个多月，军训中为他们送蛋挞的暖心班主任，细心给他提供贴心帮助的班助，优美舒适的学习生活环境，都让陈满庭对大学四年充满期待。“最重要的是把专业知识学好，其次是参加一些能提升自我并符合我兴趣爱好的部门社团，再者就是去健身房锻炼自己的协调性、爆发力、冲击力。如果还有剩余时间，我会去做兼职，锻炼自己。”
