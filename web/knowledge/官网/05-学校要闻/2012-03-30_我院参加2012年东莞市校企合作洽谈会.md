# 我院参加2012年东莞市校企合作洽谈会

3月29日，由东莞市人民政府、广东省人力资源和社会保障厅主办，东莞市人力资源局承办的2012年东莞市校企合作洽谈会，在东莞国际会展中心举行，我院招生与就业办工作人员参加了本次洽谈会。

今年的洽谈会吸引了357家省内外中高职院校和技校进场设点，1200多家企业前来参会。在过去学校专场的基础上，增设了企业推介专场，由人力资源部门推介的160家重点企业和人力资源中介服务机构设展位，向学校代表推介，务求提高重点莞企的影响力以吸引更多优质学校前来洽谈合作。我院招生与就业指导办公室林蓉老师赴现场推介我院毕业生。在与各企业单位的洽谈中了解到，我院毕业生普遍得到企业的关注，学生们刻苦、耐劳的精神和在工作岗位上的出色表现得到用人单位的肯定，许多企业当场与我院达成合作意识，希望在往后的合作中能为对方输送更多优秀人才。
