# 机电系领导看望生产实习学生

根据机械专业的人才培养方案的要求，机电系10机械本科专业1、2班全体同学进驻企业，开始了为期3周的机械制造生产实习任务。9月13日，系主任赵天婵教授、副书记唐征玲、机械实验室主任张锦荣老师一行赴大同机械厂、东莞轴承厂探望生产实习学生，了解实习的具体情况。

赵天婵教授在现场对零件的加工工艺、加工定位、专用夹具的设计等方面知识进行了讲解，并希望同学们能借此实习机会来提升自己的实践能力，并使自己各方面的能力得到切实锻炼。

最后，系领导与实习单位领导共同探讨了完善示范性实习基地的建设事宜，为培养应用型人才服务东莞共同努力。
