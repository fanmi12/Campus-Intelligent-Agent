# 我院2013年本科教学基本状态数据采集工作进展顺利

我院2013年本科教学基本状态数据采集工作进行顺利。据悉，经过近两个月的工作，各部门材料的纸质版和电子版材料全部收集完成,网上填报的数据录入也基本完成，均已进入系统审核阶段。录入的数据量总表共有69张，文件24份，涵盖了固定资产、教学条件、师资、学科专业和课程等方面数万条数据。

根据《广东省教育厅关于开展全省普通高等学校本科教学基本状态数据采集试点工作的通知》（粤教高函[2013]140号文）要求，我院于去年11月份在全校开展了2013年本科教学基本状态数据采集工作。据了解，教育部今后将对全国高校实施“五位一体”的评估机制，即自我评估、院校评估、专业认证与评估、国际评估和教学基本状态数据常态监控。因此，教学状态数据是今后学院各级各类评估的基础性材料。这项工作涉及面广，责任重大。

为保证这项工作的顺利展开，我院于2013年11月11日成立了“东莞理工学院城市学院教学基本状态数据采集工作领导小组”，由学院高等教育研究与评价中心全面负责。

前一阶段开展的主要工作有：

一、组织有关部门工作人员认真学习《本科院校教学基本状态数据库指标内涵说明》和《数据采集系统指南》，强调了数据采集工作的意义及重要性，高等教育研究与评价中心完成了学院基本信息初始化工作，设置完成了学院各教学单位的专业信息。为职能部门建立了用户账号和密码，赋予相应表格的访问权限。

二、对各职责部门数据录入人员进行网上填报系统的培训。

三、收集和汇总了各责任部门提交数据的纸质文档和电子文件，并对各种数据进行了认真细致的审核。

由于这次独立学院教学状态数据采集工作是省教育厅首次安排开展的，因而系统不成熟，指标内涵不清晰，给数据录入工作带来了一定的困难。由于院领导的重视，各职能部门通力合作，工作人员不辞辛苦、加班加点，认真领会了上级文件精神及各项指标的内涵，因而工作进展顺利。
