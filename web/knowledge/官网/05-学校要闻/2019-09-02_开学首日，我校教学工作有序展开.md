# 开学首日，我校教学工作有序展开

9月2日是开学第一天，我校师生以饱满的热情和崭新的风貌迎接新学年的到来。

上午，在“我为祖国升国旗”主题教育活动结束后，王卫平、高香林等校领导与教务处、学生处等部门负责人深入校园和课堂，全面巡查教风、学风、后勤保障、教材使用等情况。各二级学院领导也对本单位教师到岗情况及学生出勤进行了检查。全校整体教学工作运行状况良好，教学秩序井然。任课教师精神饱满，备课充分，学生课堂反响良好，多媒体等教学辅助设施运行稳定。

据了解，今天起，校领导及校督导组专家还将陆续深入课堂开展随机听课，各二级学院也将持续进行教学督查，学生处也将组织相关人员对学生出勤情况、课堂纪律等方面进行抽查，共同打造良好的教学氛围。
