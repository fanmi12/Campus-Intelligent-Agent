# 开学第一天教学秩序井然

9月3日，新学年开学第一天。校园又呈现出人潮涌动、忙而有序的景象。

据教务处助理处长李先庆副教授反映，两个校区开学情况良好，教学秩序井然，任课教师及上课学生百分之百到岗到堂，课本也全部到位。上课老师有备而来，讲课引人入胜；学生听课认真，课堂纪律好。

院领导在教务、督导等部门工作人员的陪同下巡视了各教学区，他们对开学第一天的教学教务工作非常满意。

据悉，各教学系部负责人也分别深入课室检查各班开学情况。
