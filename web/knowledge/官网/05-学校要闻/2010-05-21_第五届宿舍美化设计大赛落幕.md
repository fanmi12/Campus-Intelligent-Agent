# 第五届宿舍美化设计大赛落幕

近日，我院第五届宿舍美化设计大赛圆满落幕。

一间间整洁美丽的宿舍在同学们的精心设计和妆扮下，一一展现在评委眼前。经过评委的认真评审，以《墨香•雅致》为主题的11栋309寝室和以《窝得出色》为主题的12栋418寝室获得一等奖。

“宿舍之美源于洁净，宿舍文明源于友爱”；“雅舍文明学子展鸿图，儒居静谧英才树新风”；“同室一屋是缘分,用爱滋润是本份”获得最佳文明标语。
