# 省厅专家来我院督导检查“心理”专项工作

5月28日，省高校学生心理健康教育专家指导委员会委员广州医学院李幸民教授、东莞理工学院心理咨询中心苏亚玲主任、深圳大学心理健康教育与咨询中心周红主任、深圳职业技术学院心理健康教育与咨询中心唐慧敏主任等专家来我院督导检查“心理”专项工作。

党委副书记章德胜、院督学陈丁堂陪同专家督导检查工作。

上午，4位专家听取了我院心理健康教育与咨询中心副主任余琼老师关于我院心理健康教育工作的情况汇报，并进行了心理咨询个案督导。下午，专家们观摩我院心理健康教育与咨询中心陈浩老师的素质拓展表演，参加师生座谈会与我院师生进行交流。

专家们在反馈意见中指出，城市学院心理工作领导重视，工作机制较好，心理个案处理结果体现了学院心理咨询师具有专业素养，拓展训练、个案研讨具有特色。最后，专家们对我院的心理工作也提出了一些指导性的意见。
