# 【众志成城 抗击疫情】我们相约线上——主题征文选登⑤

我校重点关注学生在线学习的效果，切实保障网络课堂的教学质量。学校领导提出，“生活就像海洋，只有意志坚强的人才能到达彼岸，在这最艰难的时期，我们不仅要确保身心健康，同时积极利用这次‘网络教育’的机遇，主动适应学习方式、学习环境和学习形式的变化”。从3月19日起，我校组织了《我们相约线上》学生主题征文活动，今天推出的是第五期作品选登，推介外国语学院郑诗韵、计算机与信息学院黄卓越、智能制造学院余浩峰三位同学的征文作品，欢迎大家踊跃来稿，积极参与讨论。

一、网课感受

——外国语学院 郑诗韵

“没有一个冬天不能逾越，没有一个春天不能到来”。

当宅在家一觉醒来发现自己的假期已自行充值后，并没有丝毫觉得幸福快活，而是开始想念我放在学校的课本、课外书、笔记还有小零食。在与同学念叨着我好久没学习的时候，一则消息从天而降砸向了我：3月2 号开启网课生涯。我无比兴奋。

要说到网红教师那非我班主任贺甜甜（因为笑得很甜所以拥有甜甜的名字——贺力鹏老师)莫属，他在上网课的前一天晚上带领着我们玩了企业微信的所有功能，并点名让我开摄像头聊天，于是我开启了憋了好久没说过瘾的小嘴巴霹雳叭拉唠嗑起来。虽然不知道他的网课形式如何，但从师兄师姐的朋友圈来看是相当的精彩。

线上学习的感觉没有面对面讲课来的融入，并且因为网络卡等原因效果未必很理想，不过我们听力老师曾婧恒老师会比在学校时多给我们休息的时间，我能很明显地感受到了效率的提高。但还是希望疫情早点结束，快点开学吧，我还是更想念我在宿舍的课本笔记呀。

二、新奇的网上教学

——计算机与信息学院 黄卓越2020年刚开始，一场疫情悄然在我们的身边蔓延，为响应国家号召，需要我们齐心协力战胜疫情，这是待在家里的我们急需一种新的方式来投入学习。网络教学成为我们学习的一个重要途径，网络发展至今天为我们顺利进行个人线上学习提供了极大的便利，虽然这是一种陌生的学习方式，但是我依旧有信心去适应这种新的学习方式。新的学习方式也会让我们遇到新的困难，比如不能与老师充分的交流，也许会因为网络问题而遗漏了部分的学习，但是我们都应保持积极的心态，办法总会比困难多，即使疫情笼上了一层阴霾，我们也应该积极面对，帮助国家战胜疫情，好好利用线上学习，在家也能学习到更多的知识。随着网络的不断发展，我相信线上学习在将来也会成为我们学习知识的一种重要方式之一。

三、观后感

——智能制造学院 余浩峰

线上学习时，观看了讲述中国近代史的视频，我的内心久久不能平静。一百多年前的中国，因为统治者的傲慢自大，使中国错过了人类文明史上轰轰烈烈的工业革命，又因为统治者软弱无能，使睁眼看世界的第一代中国人无奈沉寂在历史的长河中，最终使中国彻底落后于西方，沦为半殖民地半封建社会。

与探索救国道路的前辈们相比，我们今天生活在一个多么美好的社会！通过开放的互联网，我们可以领略世界的科技前沿，掌握世界的发展动态，更有无数的资料供我们学习、进步。

我深深明白，我们拥有这样美好的环境，是一代又一代进步的中国人用变革、用牺牲换来的。为了不再次落后于世界，实现中华民族的伟大复兴，不负前辈们的努力，作为新时代青年的我们，更应好好珍惜这来之不易的美好环境，努力掌握科技文化知识，努力建设祖国，为中华民族的伟大复兴添砖加瓦！
