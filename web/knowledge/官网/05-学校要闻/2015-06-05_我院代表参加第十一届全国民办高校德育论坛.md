# 我院代表参加第十一届全国民办高校德育论坛

5月28日-5月30日，第十一届全国民办高校德育论坛在河南郑州大学西亚斯国际学院举行。我院党委副书记章德胜、思政部副主任石志民参加了会议。

本次论坛以“加强中华优秀文化教育，弘扬社会主义核心价值观”为主题。会上，教育部思政司司长冯刚作了《践行和培育社会主义核心价值观与大学生思想政治教育面临的新形势》的主题报告，对当前思想政治教育的任务、方法及今后工作的重点等方面作了重要的指示与部署。他要求全国各地的高校要紧密围绕习近平总书记的“四个结合”和当前我国教育发展的新形势，做好大学生思想政治教育工作，将践行社会主义核心价值观落实到人才培养过程之中。

据悉，全国120余所民办高校和独立学院的260多名代表参会。
