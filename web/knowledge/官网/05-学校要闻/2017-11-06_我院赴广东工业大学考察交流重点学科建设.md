# 我院赴广东工业大学考察交流重点学科建设

11月3日，学院副院长黄兢、院长助理林江龙带队到广东工业大学发展规划处和机电工程学院考察交流。

广东工业大学是广东省高水平大学重点建设高校之一，学校共有3个省攀峰重点学科一级学科，7个省优势重点学科一级学科，5个省特色重点学科二级学科，其中，机械、信息、材料、化工四个学科为广东省“211工程”三期重点建设学科。

此次考察主要针对我院重点学科建设管理过程中，遇到的有关人员管理、经费使用、绩效考核等问题进行了交流和学习，并对广东工业大学机电工程学院的学科建设情况进行了调研和访谈。
