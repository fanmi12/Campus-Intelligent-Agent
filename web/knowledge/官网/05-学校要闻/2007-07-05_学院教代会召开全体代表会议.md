# 学院教代会召开全体代表会议

7月4日，城市学院教代会在学院学术报告厅召开全体代表会议，审议樟村教学生活园区改造装修方案和租用协议。

本次会议由工会主席章德胜主持。与会代表认真听取了行政副院长张林关于城市学院与东城区樟村红旗股份经济合作社、东城区堑头建筑工程有限公司签订的《关于城市学院樟村教学生活园区改造装修方案和租用协议》有关事宜的报告。代表们认为，协议切实可行，方案合理。

经过代表举手表决，会议通过了《关于城市学院樟村教学生活改造装修方案和租用协议》。
