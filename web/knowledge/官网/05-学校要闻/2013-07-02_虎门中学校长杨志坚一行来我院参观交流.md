# 虎门中学校长杨志坚一行来我院参观交流

6月28日，虎门中学校长、党支部书记杨志坚一行来我院参观交流，受到院长杨敏林、党委副书记章德胜的热情接待，并在教学管理大楼前合影留念。

在112会议室，章副书记向来宾们简要介绍了学院的基本情况及办学历程。

党委宣传部部长何鹏举教授应邀为虎门中学党支部活动日上了党课。
