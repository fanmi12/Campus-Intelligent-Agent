# “这位教官是咱师兄”

9月7日，完成注册报到的2015级新生开始了为期10天的军事训练。此次新生军训承训部队仍是城市学院的老朋友——沙角部队。

在此次沙角部队60多名承训教官中，有一个熟悉的面孔——英俊帅气、阳光开朗的大男孩，他就是从我院2012级文传系新闻传播专业走进军营的学周晓航。

从大学校园走向海军军营

如果没有参军，那今天周晓航和班上同学一样，成为大四的师兄了。

2012年9月，周晓航从家乡河南漯河来城市学院，成为一名城院人，在文传系新闻传播专业开始了自己钟爱的大学生活。周晓航的大学也同样是从军训开始，没有料到的是，三年前承训自己的教官，日后成为了自己朝夕相处的亲密战友；更没料到的是，今天原本是师兄的身份，又变成了师弟师妹们军训的教官。

再次回到母校时，那一年大学时光，又浮现在周晓航眼前。一切都那么熟悉，那么亲切。学6C419宿舍是要回去看看的，文传系也是要去走走的，同班同学也要抽空去聚聚……

虽然，只是一年的大学时光，但却很充实，收获很多。周晓鹏说起了自己竞选当班长的经历，参加辩论赛的情景，加入学校社团组织活动的故事……对大学生活充满留恋与不舍。

提起如何从大学生变成了军人的经历，周晓航说自己像每个男孩子一样都有一个军营梦想。不同的是，自己实现了。大一暑假时，父亲突然问他想不想去参军，当时家乡正在征兵，是个很好的机会。周晓航在兴奋中按父亲说的去努力试一试，结果自己优秀的身体素质和思想品行，真的让自己美梦成真。

周晓航对大二刚开学拿着入伍通知给同学们看时，他们惊讶、羡慕的神情，仍记忆犹新。

军营生活多姿多彩 大学经历如虎添翼2013年，恰逢我国征兵工作改革。周晓航刚到部队时，领导告诉他，你是刚出校门就进入军营。更让他兴奋的是，进入的还是曾经承训他大学军训的沙角部队，自己真正成为其中的一员。

在接下来紧张的9个月新兵训练中，大学的军训也让周晓航有了很好的基础，训练虽然艰辛、枯燥，但一切很快就适应了，并学得很好。

大学时学新闻传播的优势使周晓航在军营的生活变得多姿多彩，在以后的工作上更是如虎添翼。学以致用，周晓航很快就担纲起部队的各类新闻宣传报道任务，一篇一篇新闻报道见诸网站、报纸期刊，证实了自己的才能和实力，受到了部队领导的赏识。也是因为自己的特长，一年后，周晓航顺利转入部队机关工作，成为政治部一名政工干事。和其他战友相比，周晓航获得更多的外出学习、交流机会，更好地提升了自己的军事素质与技术才能。

2年来，周晓航已发表了200多篇文字、摄影、视频等各类新闻报道，并荣获“营嘉奖”和“团嘉奖”。

周晓航告诉记者，自己对母校有着特殊的情怀，将尽力把自己军事技能传给小师弟师妹，和他们度过这10天美好的军训时光。同时，由于自己非常热爱军营生活，今后将继续抓住机会、努力提升自己，争取在部队里寻求更好的发展。“当然，如果明年退伍的话，我还会回到城市学院完成我未竟的学业！”周晓航笑着说。
