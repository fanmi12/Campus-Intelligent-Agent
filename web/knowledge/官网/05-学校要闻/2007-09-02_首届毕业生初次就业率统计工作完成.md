# 首届毕业生初次就业率统计工作完成

经过学院就业指导办公室及各系二级就业指导小组工作人员的共同努力，我院07届毕业生就业率统计工作顺利完成。

根据省就业指导中心9月1日

的统计结果显示，东莞理工学院（城市学院校区）本科毕业生初次就业率为87.94%，专科毕业生初次就业率为84.90%；东莞理工学院城市学院专科毕业生初次就业率为85.71%，本、专科的初次就业率分别超过原计划（本科80%，专科75%）7和10个百分点。其中，就业率最高的是管理系的酒店管理专业，达 95.12%。

根据省就业指导中心的安排，各校总体就业率的上报及统计工作将于12月1日

结束， 12月10日向社会公布结果。
