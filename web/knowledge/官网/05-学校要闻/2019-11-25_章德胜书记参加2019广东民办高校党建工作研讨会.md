# 章德胜书记参加2019广东民办高校党建工作研讨会

11月22日上午，我校党委书记章德胜、创意设计学院党总支书记何帅赴广州华夏职业学院参加“新时代、新使命，民办高校党旗红”2019广东民办高校党建工作研讨会。

省委教育工委组织处处长廖荣辉要求广东省民办学校发挥办学体制优势，深入贯彻党的十九届四中全会精神，加强党的领导，将政治意识放在首位，立德树人，加强基层党组织建设，积极打造教工党支部书记“双带头人”。

广东省民办教育协会会长赵康作了总结发言，发言包括从深刻认识我省民办高校新形式、准确把握我省民办高校党建工作新任务、清醒认识我省民办高校党建工作薄弱环节和开拓创新全面加强我省民办高校党建工作等四个方面。

广州华夏职业学院党委书记李曲生、广东白云学院党委副书记易钢、吉林大学珠海学院党委副书记王玉娟就民办学校党建工作进行了经验分享。
