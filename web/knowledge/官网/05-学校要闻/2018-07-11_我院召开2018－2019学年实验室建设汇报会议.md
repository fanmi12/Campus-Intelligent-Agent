# 我院召开2018－2019学年实验室建设汇报会议

7月10日下午，我院召开2018－2019学年实验室建设汇报会议。院长王卫平、副院长周庆、院长助理林江龙，财务处、教务处和各申请实验室建设教学单位负责人、各实验室负责人参加了会议。

各院系（部）负责人通过PPT的形式，对本单位专业建设与发展、人才培养方案提出的实验室建设需求进行了汇报。

院领导听取汇报后，结合学院发展趋势，提出了针对性的建设意见。

会议由实验中心主任葛卫清主持。
