# 副市长唐庆涛一行来我院进行乒乓球友谊赛

5月6日下午，副市长唐庆涛一行来到城市学院莞城校区，与东莞理工学院副校长安少华等乒乓球爱好者进行了一场友谊赛。

友谊赛进行了近三个小时，领导们兴致勃勃，轮番上阵。唐副市长扎实的运动功底和高超的球技赢得在场观众的不断喝彩。来宾们对我院各项运动硬件设施和细致周到的服务给予了好评。
