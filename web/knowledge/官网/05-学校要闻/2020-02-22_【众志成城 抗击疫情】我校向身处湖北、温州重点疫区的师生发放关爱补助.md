# 【众志成城 抗击疫情】我校向身处湖北、温州重点疫区的师生发放关爱补助

疫情肆虐，城院有爱。今日，我校决定向身处湖北、温州重点疫区的本校师生发放800-1000元的关爱补助，共克时艰。当前，我校采取有力举措，积极开展每日疫情监控及报告，加强校园安全保卫、后勤保障，延迟开学、开展线上授课、调整学生实习的相关措施，举全校之力打赢这场疫情阻击战。同时，也尽己所能，积极捐款、筹集急缺医疗物资帮助湖北疫区度过难关。

（我校部署疫情防控工作）

为表达慰问之情，我校决定向身处湖北、温州重点疫区的教师、贫困学生每人发放1000元补贴，重点疫区的其他学生每人发放800元补贴。该项补助金将直接发放到受助师生的银行卡中。

疫情发生以来，我校随即成立防控新型冠状病毒感染的肺炎疫情工作领导小组，第一时间制定《东莞理工学院城市学院新型冠状病毒感染的肺炎疫情防控工作方案》《东莞理工学院城市学院新型冠状病毒感染的肺炎疫情防控应急预案》，积极开展防控工作，全覆盖、无遗漏、精准掌握疫情防控重点地区的教职员工、学生分布情况，掌握每个教职员工、学生，特别是疫情防控重点地区师生的身体健康状况，切实做好开学的各种物资储备、软硬条件的准备工作，按照教育部和省教育厅的部署延迟开学，做好线上授课。

（我校支援湖北红安抗击疫情）

在做好防疫工作的同时，我校师生还心系湖北疫区。在湖北黄冈市红安县发出请求支援物资时，金贸学院师生共筹集善款38604元，设法从美国为红安医院采购到200个N95口罩，并将剩余款项捐赠给红安县慈善会采购物资，缓解了红安部分物资紧缺状况。

可喜的是，我校易班发展中心建立的大学生积极发展计划之“抗击新冠专题学习课群”入选全国优秀教学课群宣传案例，也被评为全国抗击新冠病毒相关知识科普优秀课群。

当前正处于疫情防控工作的关键时期，我校将严格落实教育部“五个一律”等有关疫情防控工作的要求，继续保持高度警觉，加强统一指挥调度，做好联防联动，做好全校师生基础信息和健康信息的掌握和分析，加强教学运行保障，加强后勤物资保障，落实校园全封闭网格化管理，坚决打赢校园疫情防控阻击战！
