# 新时代里的新“知青”

10月27日，艳阳高照，小古村支书黄海清看着被挖掘机平整好的空地，眼神里露出喜悦与期待的神情。

小古村位于广东省河源市紫金县的大山里，全村298户人家依山而居，房子零零散散地分布在各处。和我国大部分农村一样，秋季的村庄呈现出一派安静与祥和，成片成片金色的稻田映衬出岭南乡村的勃勃生机。

半个月前，小古村到处还是随意堆放的杂物，四处分布着危房。“你看，这些危房、老旧得不能住人的空房，这次我们都把它清理了，计划在这建个广场。”黄海清对乡村规划志愿者介绍道。

“希望通过你们这次志愿活动，能改变村容村貌，提升村民的生活水平，建设好社会主义新农村。”驻村干部温伟华显然对小古村的发展有着更高的期望。

城市学院结缘乡村绘蓝图

黄海清和温伟华提到的志愿者，就是来自我院城环系人文地理与城乡规划专业的师生们。今年8月，他们通过自愿报名的形式参与了团省委主办的“我为美丽乡村绘蓝图”志愿服务活动。

“‘我为美丽乡村绘蓝图’活动，由省多个部门牵头主办，东莞理工学院城市学院作为东莞市唯一的一所参与高校，共派出了四支师生队伍，由专业教师带领学生，深入河源、清远等四个贫困村，开展乡村规划活动，用专业知识以志愿服务的形式推进省定贫困村村庄创建新农村示范村工作。”学院团委书记李瑶告诉记者。

“我们8月开始和对口村进行接洽，9月下村进行走村调研，摸排大体规划线路。这次深入现场，重点就是要看看七个自然村落当中具体的规划点。”指导老师刘敬贤告诉记者，这次小古村的规划工作将要持续2个多月。在野外实地调查后，还要和村书记、村民一起商量村落的布局、发展的意向，最后将结合村庄实际，制定出一份科学的规划文案和规划图。

“这个村子和我老家一样，年轻人出外务工，老年人和儿童留守在家中。老年人缺乏活动、运动场所，村庄的建筑布局较为凌乱，周边的基础设施比较差。”参与到此次活动的15级人文地理与城乡规划1班薛剑莹同学向记者讲述在她刚进入小古村时，她眼中的“乡村之殇”。

在中央农村工作会议上，习近平总书记就提出“中国要美，农村必须美”的论断。但对于大多数偏远的农村，“环境差、收入低、基础设施缺乏、留不住人”却是大多数贫困农村的一个通病。作为城乡规划专业的师生，对这一点有着更为深刻的感受。“我们希望通过此次志愿活动，运用自己所学的专业知识，加快小古村的建设，带动当地产业，比如旅游业、生态养殖等产业的发展，从而提高村民们的收入，改善小古村村民的生活质量。”刘敬贤老师说出了自己的愿景。

纸上得来终觉浅，绝知此事要躬行

在调查中，记者看到最多的莫过于参与志愿活动的同学们相互讨论相互学习的场景。“这个水电站是村里小学生通往学校的一条近道。根据我们所学的知识，它存在安全隐患，是不允许行人通过的。”参与此次活动的15级人文地理与城乡规划1班林砷同学说，“在山头下盖房是危险操作，危险系数非常大，尤其是泥土不稳定的山体。没有深入调查之前，我们觉得在现实生活中不太可能有这样的情景。但这次调研，就真的看到了这样的场面，让我感触良多。”第一次参与野外调查的同学们开始感受到了乡村建设的种种现实问题。

在每一天的野外调查中，老师同学们早早就要外出走访调研，一直到晚上11点还在开会讨论。“其实，同学们挺辛苦的。9月份这里还很热，村里走一趟，手脚上都会被蚊子叮满了包，身上也会‘挂彩’，经常被杂草和树枝刮伤。”刘敬贤老师告诉记者。“可是大家也觉得乡村实践挺有意义，因为以前没有经历过这种形式的实践学习。在学校学习书本里的知识觉得自己懂了，到了实地考察后，才发现自己根本没有完全明白。这样又回过头去继续翻书本，增强自己的专业知识。”

参与活动的同学们也觉得机会难得，能将所学运用于实践，用真诚的学习态度和专业知识去帮助村民，希望他们的生活能过得更加美好。

师生行动暖人心，精准扶贫补短板“我的女儿在广东海洋大学读书，听说家乡有了这样的变化，每天都要问我怎么样了。一有进展，她就特别开心哩！”村支书黄海清一遍倒茶，一遍侃侃而谈，“我们都希望村子能变美变好，过年时，年轻人回来团聚时，看着家乡变美变得富裕了，全村人其乐融融，多好啊！”

对于正在悄然改变的村庄，村民们也有着属于他们自己的小期待。“作为村里的带头人，我很感谢城市学院的师生们能来帮助我们小古村。看到师生们严谨的科学态度、认真负责的工作态度，我认为他们是把小古村当作了自己的故乡来建设，让人非常感动！”驻村干部温伟华透露出对城院师生们的感谢之情。

“怎样结合实际打造‘造血功能’的扶贫项目，比如输送生态养殖、水电施工等技术，如何提高村民的维护美化村庄的意识等等，这些都是我们今后更希望得到的‘资助’。”温伟华在和李瑶书记交流时说，“希望学院以后的志愿服务活动，能提前精准对接，了解服务对象最迫切的需求，结合专业知识，将志愿服务活动做好做实。”

小古村的新农村建设还在如火如荼的进行中，志愿活动也还在继续之中。

坐而思，不如起而行。我们希望城市学院城环系的师生志愿服务队将所学投身到实践之中，用“风物长宜放眼量”的视野，在广阔农村这片希望的田野上，建设“看得见山水、留得住乡愁、体现出特色”的美丽新农村……
