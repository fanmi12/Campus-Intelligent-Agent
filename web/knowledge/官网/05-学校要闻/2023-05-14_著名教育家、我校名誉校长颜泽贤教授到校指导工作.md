# 著名教育家、我校名誉校长颜泽贤教授到校指导工作

5月10日，著名教育家、高等教育管理专家，我校名誉校长颜泽贤教授到访我校。学校执行董事陈超群，校长陈明，党委书记章德胜，常务副校长方伟华，副校长刘玉侠、周庆、陈葆华、李海冬，校长助理孔增强、罗卫国、任广新等领导出席座谈会。

座谈会上，校领导分别从学校党建工作、教育管理、教学科研、师资队伍建设、品牌建设等方面作了汇报发言。

颜泽贤校长作了讲话。他谈到，看到学校一年来取得喜人的成绩，由衷感到高兴。他结合自身经历和高等教育发展规律，指出民办高校要善用机制特点，发挥体制优势，在董事会领导下，紧密团结，用心努力，找准学校战略定位，在大湾区实施错位发展，形成学校办学品牌与特色，并凝练大学精神，为实现“创一流大学、办百年名校”的愿景打下扎实基础。

执行董事陈超群代表董事会对颜校长一直以来为学校的发展出谋划策和鼎力支持表示由衷感谢，颜校长的发言对于怎么办好学校，办出特色，办出水平具有重要指导意义。他指出，董事会对学校发展给予大力支持，有信心，有决心助力把学校建设成为应用型、创新性、国际化，特色鲜明的大学而不懈努力，勇毅前行。
