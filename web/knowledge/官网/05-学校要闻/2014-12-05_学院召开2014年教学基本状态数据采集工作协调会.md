# 学院召开2014年教学基本状态数据采集工作协调会

12月4日，学院在行政楼212会议室召开2014年教学基本状态数据采集工作协调会议。各职能部门负责人、各单位数据采集工作人员参加了会议。

院督学陈丁堂主持会议。高教研究与评价中心副主任王锦锋传达了广东省教育厅2014年教学基本状态数据采集培训会议精神，并就我院开展数据采集工作的方法、步骤、内容和要求，以及省厅文件中的“时期数”、“时点数”等时间节点作了说明。

会议要求，各单位要高度重视数据采集工作，按时、保量完成任务。
