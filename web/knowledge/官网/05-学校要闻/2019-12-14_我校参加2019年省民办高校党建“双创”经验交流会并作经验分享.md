# 我校参加2019年省民办高校党建“双创”经验交流会并作经验分享

12月13日，由广东省高校党建研究会民办院校分会主办的2019年广东省民办高校党建“双创”经验交流会在广州城建职业学院举行，广东省委教育工委领导、省内民办高校党委书记及党务工作者与会。学校党委书记章德胜、商学院党总支书记卢淑芳、文学与传媒学院党总支副书记苗琳受邀出席本次经验交流会。

大会上，获得省党建“双创”标杆院系立项的我校商学院党总支书记卢淑芳就商学院新时代高校党建示范创建和质量创优工作作了分享。过去一年，我校商学院党总支在学校党委的领导下创新开展党建工作，凝聚合力，精准发力促“双创”，在政治建设、组织建设、队伍建设、制度建设等方面取得了新的突破。商学院党总支深刻认识到中国共产党党员对大学生思想引领的重要性，以“专业成才，精神成人”的政治教育理念，构建“三全”育人格局，全方位服务学生的成长成才，让理论学习生动有趣，让文化活动丰富多彩，让党员素质有效提升，在事业发展、服务地方方面，赢得了社会各界人士、民办高校的认可与点赞。

广东省高校党建研究会民办院校分会会长、广州白云学院党委书记刘剑锋在作总结时指出，我校商学院聚焦事业发展，把党委的政治核心作用充分发挥出来，在统领方向方面、筑牢政治根基方面、融入教育教学方面、在推动目标实现方面，把党建工作指向聚焦事业发展，在新时代党的建设方面做出了新的亮点。

随后，与会人员聆听了中山大学马克思主义学院王仕民教授作的十九届四中全会专题辅导，深入学习了党的十九届四中全会精神，并对制度进行了解读学习。

我校商学院党总支在2018年获省党建“双创”标杆院系立项，既是对我校党建工作和商学院党总支党建品牌创建的高度认可，也是我校按照省委教育工委委要求，加强和改进新时代党建工作，大力加强党的政治、思想、组织、作风和纪律建设，把党委政治核心作用突显在学校事业发展中，党建工作在新时期出现新亮点、新突破、新变化的重要体现。
