# 首都体育学院王宝成教授来我校作专题讲座

6月20日下午，首都体育学院国家二级教授、硕士生导师王宝成应邀来我校作《体育教学训练理念的发展与更新》专题讲座。

在两个小时的专题报告中，王宝成教授以博学的视野，博引旁证、妙语连篇，深入浅出地论述了体育教学训练理念的发展与创新，对体育教学改革的方向、目标、方法等都做了详尽分析。他鼓励青年教师要“杜绝盲从、敢于质疑、善于思考”，激励教师多读书、多积累、多创新，处理好“教”与“研”的关系，让学习和研究成为自身发展的动力源泉。

据介绍，王宝成教授历任首都体育学院科研处长、研究生部主任，现任全国院校体育教学训练研究会副理事长兼秘书长，长期从事体育教学训练理论与方法的研究，主持完成了14项国家体育总局招标课题，曾获得多项国家级优秀教学体育科技进步奖及国家优秀教材一、二等奖，在体育教学训练科学研究等领域有着很高的造诣。
