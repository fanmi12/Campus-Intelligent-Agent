# 学院召开考研动员大会

3月13日，学院在大礼堂召开2005级本科生考研动员大会，副院长程发良教授作动员报告，教务处处长邓成良教授主持会议。05级考研辅导班负责人黄乾辉副教授、前两届考研班负责人周巍老师在会上发言，共有一千多名学生参加。

程院长在动员报告中指出：“同学们报考研究生，有的是为了增加求职的把握，有的是为了转换专业，有的是为了进行更高层次的学术研究，无论你是出于哪种原因加入考研队伍，动机都是好的，学院都会全力支持，帮助每一个考研学子成就梦想。希望在座的同学们增强信心，勇于挑战高学历，根据自身的情况确定目标，尽早准备，争取成功。”

周巍老师总结了前两届考研班复习报考的经验和教训，他说：“院领导高度重视，教务处妥善安排，这是首届考研班取得成功的重要原因。英语和数学是考研成功的关键，要重视基础知识的学习。专业和学校的选择有一定技巧性，不要盲目追求热门专业与名校。”

黄乾辉副教授介绍了本届考研班的学习计划，希望同学们踊跃报名参加考研班，给自己一个改变命运的机会。

04届考研班班长翁新达以自己的亲身经历勉励师弟师妹：“复习考研不仅是对所学知识的检验，更是对人生的一次挑战，考研的过程一定会成为人生中一段美好的回忆。青春没有失败，希望有志于考研的同学为了梦想再搏一回。”

据悉，本届考研班已经开始报名，将于第五周开始集中自习，由黄乾辉老师开设的选修课《考研数学》已于第三周开讲。
