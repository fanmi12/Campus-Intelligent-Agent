# “光影青春”摄影作品评选揭晓

5月23日，由院团委主办、社团联合会与摄影协会承办的“光影青春”校园创作摄影大赛评选结果揭晓。

此次大赛共征集作品180幅，内容包括人像、风光以及纪实摄影等。本次比赛设一等奖1个，二等奖3个，三等奖6个以及优秀奖5个。评委老师对这次摄影大赛的部分作品予以了较高的评价。
