# 管理系党总支召开党员民主生活会

4月22日，管理系党总支召开民主生活会，组织党员学习《中国共产党党员领导干部廉洁从政若干准则》。

会上，党总支书记罗余才结合当前社会中存在的腐败现象，强调了学习的重要性和廉政制度建设的必要性，要求每位党员要洁身自好，率先垂范，做教师和学生的好榜样。

会议还通报了管理系09届毕业论文专家评审的意见。
