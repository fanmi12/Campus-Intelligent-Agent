# 我院考研学生上线人数为去年2倍

3月30日，国家教育部公布了2012年研究生招考复试国家分数线。城市学院考研班传来好消息，考研学生的初试成绩令人欢欣鼓舞。

据悉，有26名同学的总成绩超过了国家分数线，为去年的2倍。其中，文传系李山珍同学总分402分，位列考研班第一名，超出其报考的华南师范大学传播学专业复试分数（345分）近60分。政法系李苏杰同学、城市与环境科学系赵晋宜同学的成绩分别排在暨南大学、中山大学相关专业全国考生中的第一和第二名。

据了解，政法系已连续三年有考研学生（于佩、汤文杰、李苏杰）位居中山大学、暨南大学相关专业全国考生中的第一名。
