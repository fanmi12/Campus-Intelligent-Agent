# 我院3位教师参加省厅心理健康教育培训

近日，我院学生处心理咨询中心陈浩老师、财经系辅导员王洁娟老师及社科系辅导员杜丽老师，在珠海市参加了由广东省教育厅主办、中山大学承办的广东省高校心理健康教育骨干教师专业成长系列培训班（第一期）学习。

培训期间，学员们听取了心理学界的专家学者樊富珉教授、王建中教授、梁宝勇教授以及岳晓东博士的学术讲座，参观了中山大学心理咨询中心。

来自广东省各高校200多名专兼职心理学教师与辅导员参加了培训。
