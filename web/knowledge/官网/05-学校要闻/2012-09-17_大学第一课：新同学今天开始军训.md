# 大学第一课：新同学今天开始军训

9月17日，我院2012级新生军训拉开序幕， 4700多名新同学参加了军训。

上午8时30分，开训仪式在运动场举行。院长杨敏林、党委书记朱志德、党委副书记朱冰、章德胜等领导和沙角部队首长出席了典礼仪式。运动场上，身着海军训练服的同学们个个英姿飒爽、士气高昂，分成19个方阵整齐地排列在主席台前。8时30分，在一阵热烈的掌声中，来自沙角部队的军训团68名教官排着整齐威武的队列进入会场。

院长杨敏林教授做了动员讲话，他要求同学们学习和发扬军人的优良传统与作风，吃苦耐劳，严守纪律，磨练意志，争当标兵。

据悉，军训时间为10天，训练内容包括：队列、内务、国防知识教育，校规校纪和部队光荣传统教育，一切活动实行半军事化管理。
