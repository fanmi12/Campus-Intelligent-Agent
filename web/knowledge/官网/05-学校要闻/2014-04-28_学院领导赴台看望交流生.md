# 学院领导赴台看望交流生

4月21日——26日，学院党委副书记章德胜带领继续教育中心（国际交流中心）、教务处、组织人事处老师赴台看望了我院首批赴台交流生。29名交流生感谢老师们的探访，纷纷汇报了在台湾学习和生活情况。

大家普遍反映在台湾学习非常紧张，对选择的课程兴趣浓厚，收获相当大，已经适应了台湾教师轻松愉快、实用性强的教学模式。他们表示在台湾学习生活非常愉快，学生和老师们对他们十分热情友好。
