# 计信系学子第十届全国大学生智能建筑工程实践技能竞赛再获佳绩

11月2日至4日，第十届“亚龙杯”全国大学生智能建筑工程实践技能竞赛在安徽建筑大学举行。在贺婉茹、陈振伟、李洪超、杨子靖老师的指导下，我院计信系李曦、赖梓文、赖坤龙、蒋朝钢、苏新然、纪家满同学荣获大赛团体三等奖，李曦、赖梓文同学分获电气设计二等奖、三等奖。

据介绍，大赛是由高等学校建筑电气与智能化专业教学指导委员会主办，是一场高规格、高水平、高档次的学科专业竞赛，对进一步激发学生科学研究兴趣、挖掘学生创新潜能、提高工程实践能力具有重要意义。今年共有42所高校参赛，创历届之最。
