# 加强就业指导队伍建设，提高就业指导质量

为了提高我院就业指导工作人员的理论水平和实操能力，加强就业指导队伍建设，提高就业指导人员的素质，我院林蓉、赵秋平、唐洁、卢淑芳、李海冬、林胜凯、陈浩华、宋艳、刘军、唐征玲十位老师在广州市海之珠职业培训学校参加职业指导人员职业资格培训。

本次培训时间自3月22日至26日，共5天。培训内容包括：职业生涯发展与规划理论、咨询与指导、信息的采集与处理、职业素质测评与应用、职业设计与帮助实施、职业指导考核鉴定要求、职业咨询基础、职业生涯设计、职业道德、就业与职业发展、就业相关法律法规、如何指导大学生进行职业生涯规划、职业研究方法等课程。在学习中，参训老师对就业指导理论中的难点重点问题进行了探讨，提出了自己独特的见解，并对当前热门话题开展了热烈的讨论。

培训由广东省高等学校毕业生就业促进中心和广东省劳动厅联合举办，广东省各高校近200名职业指导人员参加了此次培训。
