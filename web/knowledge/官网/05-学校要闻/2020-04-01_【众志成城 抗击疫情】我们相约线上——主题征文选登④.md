# 【众志成城 抗击疫情】我们相约线上——主题征文选登④

我校重点关注学生在线学习的效果，切实保障网络课堂的教学质量。学校领导提出，“生活就像海洋，只有意志坚强的人才能到达彼岸，在这最艰难的时期，我们不仅要确保身心健康，同时积极利用这次‘网络教育’的机遇，主动适应学习方式、学习环境和学习形式的变化”。从3月19日起，我校组织了《我们相约线上》学生主题征文活动，今天推出的是第四期作品选登，欢迎大家踊跃来稿，积极参与讨论。

一、线上学习心得体会

——计算机与信息学院 肖崴

自新冠肺炎爆发后，各地区开学时间不断推迟，而线上教学弥补了学习上的空缺。由于这种开课方式对大部分老师以及同学们来说是新奇的，通过几周的线上学习，发现了与传统教学有许多不同，不谈学习环境的变化，光是没课本就让我们手忙脚乱，为了弥补这一不足，老师发了电子版的教材，但终归没有拿在手上，看起来很不顺心。为了解决这个问题，我认为把老师上课所划知识重点多抄几遍或许有效，所以我增加了做笔记的量。最后，我相信随着时间的流逝，我们对传统教学的怀念只会愈加的强烈，希望疫情早日过去，希望在前线奋战的白衣天使早日归来。

二、线上学习之我要上网课

——外国语学院 陈畅

“同学们，开始上课啦！”伴随着电脑屏幕中老师的演示图像，我们从未体验过的全新教学方式——“网络线上教学”就这么顺利的开始了。这次线上教学为我们带来了全新的学习体验，“方便”、“快捷”即是它的代名词，我们不再需要繁琐的书包、笔记本，甚至不需要出门，只需要一部电脑，和一个善于思考的大脑，就可以获得丰富的知识，这无疑是对我们自我学习能力的考验，但我始终相信英语中学到的那句名言“Where there is a will,there is a way ”！希望在这特殊的日子中，我们大家能够共同进步，利用好时间，创造更好的自我！

三、抗击疫情——我们相约线上

——文学与传媒学院 王玉珏

受疫情影响，学校采用线上教学的特殊方式，在网上开学。或许一开始大家会对这种学习方式感到不方便甚至会有点排斥，但随着这一个月来的直播课程，同学们也渐渐收心，习惯了网上教学，并能够很好地运用网络直播的功能来进行互动。疫情虽然切断了我们的回校之路，但却切不断同学们的求知欲望。无论是线上还是线下，大家听课听久总会有一点疲倦的情绪，但我很喜欢帅男勋老师的教学方式，他能在教学中很好地融入一些网络流行语，还会在下课的时候给我们播歌或看点小短片，这种方法有效地提高了同学们学习的动力。
