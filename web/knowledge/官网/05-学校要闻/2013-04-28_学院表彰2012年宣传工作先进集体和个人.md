# 学院表彰2012年宣传工作先进集体和个人

宣传工作要唱响“中国梦”、构建“城院梦”、为实现“我的梦”提供良好的舆论氛围

电视新闻片《城院公交调查》等8项宣传工作获创新奖

由大学生记者团拍摄的反映城院师生乘车难的电视新闻片，得到市镇政府职能部门的重视和解决，也获得我院2012年首设的宣传工作创新奖。4月27日，学院在学术报告厅召开宣传工作会议，表彰2012年宣传工作先进集体和个人。

会上，党委宣传部部长何鹏举做大会工作报告，总结去年的宣传工作，对今年的宣传工作作出安排部署。

党委书记朱志德在讲话中强调，今年的宣传工作，要唱响“中国梦”、构建“城院梦”，为实现“我的梦”提供良好的舆论氛围。朱书记对今年全院的理论学习、宣传内容、宣传形式、传播媒体等宣传工作提出了更高的要求。他希望宣传工作者要在丰富校园文化，构建和谐校园，扩大学院的影响和美誉度，陶冶学生思想情操，激发正能量，成就新梦想，传播好声音等方面，提供思想保证、舆论支持、精神动力和基础条件作出新贡献。

大会表彰了一批优秀通讯单位、二级网站、最受媒体欢迎的教师、优秀通讯员。获得宣传工作创新奖的项目还有：广播剧《我在回忆中等你》、大学生参加城市卫生检查、微博达人林伟伦老师、杨振宁赠书、城院官方微博、艺术系新生QQ群、学生处网站与微博联动等。

党委副书记章德胜主持会议。
