# 我院举办团中央课题答辩会暨新课题论证会

6月2日上午，我院团中央重点课题结题答辩会暨新课题论证会在学生活动中心举行。活动由大学生德育发展研究中心主办，研究与发展规划处赵书山教授、创意设计学院党总支书记何鹏举教授、教学督导办公室督导李上文教授、招生就业处处长孔增强副教授以及广东省名辅导员、广东医科大学林路生副教授担任评审专家。

会议上，由院团委副书记陈浩华老师就他主持的《精进体验教育的引导反思模式在独立学院学生骨干培养中的应用研究》重点课题，进行结题汇报和答辩。评审专家经过评审，高度肯定了结题报告中方法的科学性，也指出了该研究中需要进一步完善之处。

德育研究中心青年科研骨干万文双、曹镭、高政、詹海都、陈浩华四位老师进行了新课题开题报告。现场评审专家从选题意义、标题选定、研究方法和技术路线等方面入手，对各个课题申报书逐一进行点评，并为课题完善和改进提供了宝贵意见。
