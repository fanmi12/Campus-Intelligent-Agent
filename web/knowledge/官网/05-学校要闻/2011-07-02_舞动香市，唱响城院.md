# 舞动香市，唱响城院

大合唱《在灿烂阳光下》

演出现场观众如潮

快板《香满寮步》

小品《人约黄昏前》

歌舞《国家》

表演唱《苗岭连北京》

舞蹈《红旗飘飘》

寮步镇、东莞理工学院、城市学院领导与艺术团师生合影

“打竹板，响叮当，东莞是个好地方；城院寮步齐努力，香市文化美名扬……”，十几个姑娘们表演的俏皮清新的快板，使近万名观众沉浸在青春美妙的节奏中。7月1日，我院200名大学生应邀赴寮步镇文艺演出，与市民共庆党的九十华诞，唱响莞香文化。

东莞理工学院领导周致纳、杨晓西、黄碧莲、吕琦元、安少华，寮步镇、城市学院党政负责人共同观看了演出。

整场晚会历时2小时，高潮迭起，掌声不断。艺术系合唱队一首充满着希望与激情的歌曲《在灿烂的阳光下》，以磅礴的气势拉开了晚会的序幕。徐晓华老师激情挥撒红色裙海，独唱《永远跟你走》惊艳全场，表达了人民对党的无限深情，永远跟党走的信念。“月上柳梢头，人约黄会后”。马新川、党家立、康慧丽、臧莹竹四人倾情奉献的小品《人约黄昏后》，剧情跌宕起伏，表演感情细腻，感动了所有观众。舞蹈《红旗飘飘》更是活力十足，台上台下红旗飞舞，将晚会推上了高潮。无论是校园绿袖子组合的歌伴舞《苗岭连北京》，还是由校园歌手的廖冬冬、陈泽智等人的歌曲联唱，都显示出了城院学子的艺术魅力和青春风采。最夺人眼球的是风烙舞队的快板《香满寮步》，十几个姑娘们活泼俏皮，以清新的说唱方式娓娓道出了我院与寮步的“缘分”，说出城院的新校区的美好未来，更唱出了寮步独有的香市文化。

据悉，寮步镇从本地实际出发，实施了香市文化教育中心战略工程计划。据介绍，莞香树是一种名贵珍稀树种，其叶花果清香，具有安神作用，是古代香料之极品。目前，该镇已有近万亩莞香树。
