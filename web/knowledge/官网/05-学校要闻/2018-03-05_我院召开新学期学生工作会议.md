# 我院召开新学期学生工作会议

3月4日下午，我院召开新学期第一次学生工作会议。院党委副书记章德胜出席会议，学生处、招生就业处、团委、各院系负责学生工作的党总支书记或副书记参加了会议。会议由学生处副处长罗文芳主持。

章德胜副书记对学生工作进行全面部署，要求统一思想，落实立德树人的根本任务，在工作岗位上发挥最大的热情。学生处、团委要落实好新的一年学生工作计划，不断创新，抓住重点，多借鉴其他部门、同类院校优秀做法。同时，要随机应变，切实履行学生安全稳定的职责，维护好校园安全和谐稳定的大局。

各相关部门对新学期的学生返校注册、安全防范、宿舍管理、心理健康、创业就业等工作做了具体安排。

罗文芳副处长传达了全国学校安全工作电视电话会议精神，强调要重视校园意识形态暨安全稳定工作，关心学生的人身安全与财产安全，在意识形态上做好思想引领工作，努力创建平安校园。各个院系要落实好各项工作，以解决学生的实际问题为导向，全面做好学生服务工作。
