# 我院召开2012年新增专业申报专家论证会

4月19日，教务处在新校区召开2012年新增专业申报专家论证会。

东莞市建筑设计院、东莞理工学院、城市学院相关教授、博士出席论证会。与会专家经过论证讨论，提出了许多建设性指导意见，表示新增专业要突出传统专业的时代特点，符合低碳、绿色的环保要求，重在培养为当地社会经济服务的创新人才。

据悉，2012年我院新增的本科专业是财务管理、建筑智能及电气化、土木工程，新增的专科专业是社会工作。
