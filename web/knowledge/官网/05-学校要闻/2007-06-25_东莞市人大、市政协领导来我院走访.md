# 东莞市人大、市政协领导来我院走访

6月22日，东莞市人大常委会副主任李秀冰，市人大教科文卫华侨外事工作委员会主任方毓兰、副主任谭何女、副主任刘学高，市政协教科文卫体和文史委员会主任丁林枝等7名领导来我院走访，受到学院党政领导安少华、朱志德、张林的热情接待。

东莞理工学院副院长、城市学院院长安少华教授在315会议室向代表们汇报了办学四载的风风雨雨，实事求是地反映了教职工住房等发展中的问题和困难。

李秀冰副主任说，听了安院长的介绍，我们对城市学院这几年的发展变化有了进一步的了解。四年来，学院所取得的这些成绩，是东莞市委、市政府正确领导的结果，是东莞理工学院大力支持的结果，也是全院教职工共同努力的结果。学院提出的“打造省内一流的独立学院”的目标很有意义，完全符合东莞的实际。但是，要实现这一目标，必须要进一步加强办学软硬件的建设，不断提高教学质量，为东莞乃至广东省培养更多的合格人才。前进中的问题，需要方方面面的支持与帮助，有关部门和单位，要从政治的高度，体谅学院的困难，创造条件，提供方便，尽力把工作做好，保障教学和学生生活的需要。人大、政协会时时关注城市学院的发展，尽力协助解决发展中所遇到的困难和问题。

人大、政协领导在院领导的陪同下，参观了学院实验中心、学生饭堂和校外学生公寓基建工地。
