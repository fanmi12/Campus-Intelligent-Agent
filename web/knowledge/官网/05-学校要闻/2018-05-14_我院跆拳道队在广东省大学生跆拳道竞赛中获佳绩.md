# 我院跆拳道队在广东省大学生跆拳道竞赛中获佳绩

5月13日，广东省大学生跆拳道社团、俱乐部锦标赛暨广东省跆拳道示范团团员资格选拔竞赛在中山大学举行。我院艺术团跆拳道队荣获了大赛唯一的“优秀组织奖”，其中谭乔和郑富艺同学均荣获了54kg级第五名佳绩。

此次赛事吸引了全省及福建、香港等高校500多名大学生参与，其中包括了广东体育学院、暨南大学、厦门大学，香港科技大学、香港理工大学等高校参赛，可谓高手云集。

面对强大的对手，我院跆拳道队6名成员在王煜老师的带领下，没有丝毫的退缩，积极比赛，取得了不错的成绩。
