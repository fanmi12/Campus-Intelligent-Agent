# 【“十八大”专题】文传系组织入党积极分子学习“十八大”工作报告

11月9日，文传系在7B208教室举办第七期入党积极分子培训班，组织200多名学生学习胡锦涛同志在十八大开幕式上的讲话。

文传系党总支部副书记、学生党支部书记卢淑芳老师鼓励学生们要积极向党组织靠拢，课上要认真听讲，并表达了对学生们的美好祝愿。文传系刘仲生副教授为入党积极分子讲述了中国共产党党史、中国共产党探索发展道路以及中国特色社会主义理论等方面的内容，他要求入党积极分子认真学习“十八大”的文件，深入领会贯彻十八大会议精神，认真履行好入党积极分子的职责和义务。

参与培训的入党积极分子认为，能够在十八大胜利召开的同时举办培训班，组织学习“十八大”文件，接受党组织的教育，机会难得。他们表示，将在“十八大”的指引下，努力学习，做好本职工作，积极创造条件向党组织靠拢。

据悉，本期入党积极分子培训班将上三次党课。
