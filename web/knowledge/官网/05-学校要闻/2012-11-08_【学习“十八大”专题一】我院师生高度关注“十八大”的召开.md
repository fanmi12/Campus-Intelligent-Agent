# 【学习“十八大”专题一】我院师生高度关注“十八大”的召开

11月8日，中国共产党第十八次全国代表大会在北京隆重开幕。

上午9时，学院领导杨敏林、朱志德、朱冰、陈丁堂、章德胜、高香林与院机关干部纷纷来到会议室收看开幕式电视实况转播。各总支、直属支部也组织了没有上课的教职工和学生进行观看，聆听胡锦涛总书记的大会报告。

为了看好电视转播，院办专门下发了文件，对收看工作做了布置和安排。文件要求，广大党员和教职工要认真收看“十八大”开幕式的电视转播及其会议的其他新闻报道，组织好座谈讨论，分享大会成果，领会大会精神，统一思想，步调一致，紧跟党中央，全面建设小康社会。
