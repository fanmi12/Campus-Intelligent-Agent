# 我院开展新生消防安全教育

9月12日晚，新生入学教育系列讲座第二讲在综合馆举行，东莞市公安消防局防火处李乐顺教官为同学们作了题为“火场逃生如何自救”的消防安全教育知识讲座。

李教官以真实案例，结合日常生活，让同学们了解了火灾发生后消防员是如何开展救援行动的。李教官还科普了救援时的专业知识，介绍了救援工具的使用方法、对火灾中三种级别的烧伤如何判断和应对的措施、火灾中如何自救等知识。

整个讲座，李教官通过以真实的案例视频讲解和生动的介绍，让同学们了解火场逃生自救的重要性和相关自救方法。
