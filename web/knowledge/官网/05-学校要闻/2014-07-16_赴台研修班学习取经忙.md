# 赴台研修班学习取经忙

7月14日，党委书记王卫平率队的赴台研修班41位老师一到台湾高雄义守大学，放下行装，就开始投入紧张的学习取经。

研修班得到了义守大学萧介夫校长、颜志荣副校长等教学管理团队的热情接待。

荣誉校长傅胜利亲自为培训班上第一课:《义守大学之办学理念与发展》，完整的介绍了台湾高等教育的发展历程、路径与策略，讲解与剖析了义守大学“务实，创新，卓越，永续”的办学理念和全面培养学生“道德力，创新力，自学力，宏观力，就业力” 的办学思路。

按照义守大学的安排，接下来几天里，副校长、教务长、研发长、学务长等10余个行政、教学管理专家教授会从不同的角度，分专题进行介绍和研讨。

晚上，研习班老师们分小组开展讨论活动，及时总结交流学习心得。
