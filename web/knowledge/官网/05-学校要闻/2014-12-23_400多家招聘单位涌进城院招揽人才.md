# 400多家招聘单位涌进城院招揽人才

12月18日，东莞理工学院城市学院2015届校园招聘会在教师公寓小广场举行。本次招聘会共有432家招聘单位携8000个就业岗位进场。参加招聘会的学生有我院近4000名应届毕业生及1000多名外校学生。

据悉，招聘单位多数来自东莞各镇区，也有来自珠三角地区其他城市。招聘现场人头攒动，场面壮观。虽然寒风凛冽，但供求双方洽谈火热，不少应聘者手上拿着精心制作的简历，在摊位前认真浏览各企业的招聘广告，寻求心仪的求职岗位。鸿发教育投资公司等摊位前排起了长长的“人龙”，直至下午闭会时才打道回府。面试官们热情接待前来应聘的毕业生们，介绍公司的状况、福利待遇、晋升空间等方面的情况。

据学生处有关负责人介绍，本次招聘会有三大亮点：一是参会企业众多，总数超过往年。二是经济贸易（含市场营销）类岗位所占比例较往年大幅提高，约占56.6%；工程技术类岗位所占比例有所下降，约占11.1%；三是毕业生求职意向任锁定在行政机关、事业单位、外资企业或大型企业。

招聘单位中的“大热门”

在众多招聘企业中，东莞市鸿发教育投资有限公司最受求职者的青睐，其摊位前一直是熙熙攘攘。据了解，东莞市鸿发教育投资有限公司是广东鸿发投资集团旗下的一家子公司。面试负责人表示，这次主要是招聘英语、会计、管理、计算机、法律等专业的应届生，对英语要求较高。提供的岗位有项目管理、教育拓展及运营等。记者了解到，该单位面试官共收到400多份应聘书。

非毕业生眼中的招聘会

记者在招聘会现场发现，应聘者中有不少的是我院大一至大三的学生。2013级汉语言文学专业的梁同学向记者表示：“我想来看看与我专业对口的工作岗位多不多，有哪些新的要求，有利于适时调整学习计划，以适应人才市场的需求。”据了解，有不少的非毕业生是抱着这种心态走进人才招聘现场的。

当日下午5：30，招聘会在应届毕业生与招聘单位的双向选择中落下帷幕。招聘单位满载而归，体现了我院培应用型人才培养目标是正确的，毕业生们能与社会对接，为社会所聘用。

招聘会是毕业生专场？NO！

“你好，请问你们在求职时，最看重用人单位的哪些条件？”“抱歉，我们不是应届毕业生。”在他们的回答中，记者有了一丝惊讶，再看着他们手上的一叠传单，难道是为将来“热身”的？细问才知道，原来今年的招聘会招的不只是应届毕业生，还有寒暑假实习生。比如“华润万家”摊位前便贴出招收寒假实习生的通知。这样看来，招聘会不再是应届毕业生的专场了，只要有兴趣、有需求，大家都一起参加招聘会啦。
