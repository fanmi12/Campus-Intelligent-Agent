# 社会科学系召开教学经验交流会

11月15日，社会科学系教学经验交流会在4515室召开，城市学院院长安少华教授、党委书记朱志德及工作人员出席了会议。

会上，社科系思想政治教研室主任石志民、公共管理教研室主任赵书山、法学教研室主任王雄文做了本学期教学工作总结发言，刘珍、马莉、李喜梅、程建新等老师分别从不同的角度介绍了经验。

会上，学院党委书记朱志德作了总结讲话。他指出，教学经验交流会开得非常好。希望与会教师能将本次会议的收获渗透到今后的教学之中，以提高学生学习的积极性与主动性，推动城市学院学风建设再上一个台阶。
