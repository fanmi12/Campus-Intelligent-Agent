# 浦发银行东莞分行领导莅临我校考察交流

12月13日，浦发银行东莞分行行长王奕婷、东莞分行支行长王 斌、客户经理陈永富等领导一行3人莅临我校考察交流。

广东鸿发投资集团有限公司董事长助理麦子俊、资金部总监何超，我校副校长周庆等领导热情接待了客人，并陪同客人参观了校园。双方围绕我校校园建设、办学理念、发展战略等方面及合作事宜进行了交流。
