# 2014年学媒暑期实习总结与交流表彰大会召开

9月20日，2014年城院大学生暑期媒体实习总结表彰大会在行政楼112会议室举行。东莞理工学院宣传部部长何献青应邀出席会议，党委书记王卫平发表了讲话。会议还邀请了东莞各大专业媒体的记者到会与大学生做交流，10名暑期实习积极分子受到大会表彰。

会上，东莞日报新媒体中心主任谢晓波首先发言。他对我院29名暑期实习同学的表现给予了充分的肯定，并以自己的亲身经历言传身教，告诫我院大学生要有职业责任感，不断认识自身差距，广泛接触社会，不断进取提高。

12级新闻传播开雯和12级软工专业黄粤两名同学，与大家分享了暑期实习的心得体会，展示了各自的实习成果。

随后，大学生媒体中心的学生记者与媒体记者分组交流互动。

据悉，为积极响应院团委的暑期“三下乡”社会实践活动的号召，新闻中心组织了29名学生，分别到南方都市报、东莞日报新媒体中心、虎门电视台、新快报、大粤网以及寮步电视台等9家媒体，进行了为期一个半月的实习。据不完全统计，共发表作品600余篇，近30万字，这些作品已汇编成《大学生2014年暑期实践个人作品集》、《大学生2014年暑期媒体实习心得》两本成果集。
