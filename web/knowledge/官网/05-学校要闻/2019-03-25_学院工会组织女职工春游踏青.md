# 学院工会组织女职工春游踏青

为庆祝“三八”国际妇女节，3月23日学院工会组织女教职工赴深圳开展春游踏青活动。

当天，大家来深圳市当代艺术馆与城市规划馆参观“大潮起珠江——广东改革开放40周年展览”。在展馆内，大家认真参观了“敢为人先勇立潮头”、“增创优势砥砺前行”、“走在前列当好窗口”等三个部分的展览内容。作为改革开放的亲历者和受益者，大家对真实反映或生动再现改革开放历史和成就的照片、实物、场景等倍感亲切，或驻足细看，或拍照留影，或低声交流。

大家还来到茶溪谷踏青，该景区内负氧离子含量高，俨然一座天然的氧吧。大家三五成群，在五彩缤纷的娇艳花海中留下倩影，欢声笑语萦绕山谷中。

这次活动不仅让广大女教职工感受了学院的关怀，增进了同事之间的感情，进一步激发了女职工的工作热情。
