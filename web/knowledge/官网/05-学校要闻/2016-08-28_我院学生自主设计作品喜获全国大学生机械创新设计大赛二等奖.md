# 我院学生自主设计作品喜获全国大学生机械创新设计大赛二等奖

7月26日-29日，全国第七届大学生机械创新设计大赛的决赛在山东交通学院举行。由我院机电工程系陈清文等同学设计制作的作品——《自动分币装置》获得全国二等奖，创造了我院参加此项学科竞赛以来的最好成绩，实现了该项大赛全国决赛奖项零的突破。

据了解，此次参赛作品团队由机电工程系2013级学生陈清文、练家和、劳锦豪和吴国茂四位同学组成，罗彦琦、张锦荣担任指导老师。该团队自2015年6月组建以来，就着手进行《自动分币装置》作品的设计、制作与调试，于2016年5月8日在广东省赛区比赛中进入复赛，并获得广东赛区一等奖和参加全国大赛的资格。在广东赛区比赛结束后，参赛团队极针对比赛中专家提出的意见与建议进行了认真研讨，对作品进行了为期一个多月的优化设计和调试，最终获得全国二等奖。

据悉，我院也是广东省唯一一所独立学院进入全国大赛的院校。全国大学生机械创新设计大赛每两年举办一次，是教育部、财政部批准和资助的全国性大学生学科竞赛，是国内最具影响力、培养学生工程实践能力和综合素质的大学生竞赛项目之一。本届大赛以“服务社会——高效、便利、个性化”为主题；内容分为钱币的分类、清点、整理机械装置；不同材质、形状和尺寸商品的包装机械装置；商品载运及助力机械装置。大赛于2016年3月1日正式启动，共收到来自24个省市，包括哈尔滨工业大学、华中科技大学、吉林大学等638所高校、共计4154项作品。

我院机电工程系多年来重视学生实践技能的培养，积极推进本科教学质量工程建设、应用型人才培养模式改革和创新创业教育改革，成立机械创新实验室，建立学科科技竞赛团队，加强对学生科技团队的建设与指导，通过积极搭建机械类科技竞赛平台，为学生科技团队出成果创造条件。
