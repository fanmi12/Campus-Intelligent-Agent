# 人工智能学院与未来科技学院升学人数创新高 规模质量双突破

近日，2026年全国硕士研究生招生录取及境外高校申请工作接近尾声，人工智能学院、未来科技学院升学捷报频传、硕果累累！截至5月7日，本届毕业生共有64名学子成功上岸，升学人数创下历史新高，升学规模与院校质量实现“双突破”，用亮眼成绩书写了学院人才培养与学风建设的崭新篇章。

一、规模突破：升学人数再攀高峰，全员奋进创历史

本届升学人数达64人，较学院往年升学规模实现跨越式增长，远超往届同期水平，创下学院成立以来升学人数的历史新高。

专业全覆盖：升学成果覆盖计算机科学与技术、软件工程、数据科学与大数据技术、物联网工程、人工智能、机器人工程等学院全部本科专业，各专业升学人数均实现显著增长，形成“全员奋进、百花齐放”

的良好态势。

境内外双优：其中境内升学46人，境外升学18人，越来越多学子凭借扎实的专业能力斩获世界名校

offer，展现了学院人才培养的国际化竞争力。

二、质量跃升：名校录取百花齐放，优质资源遍地开花

本届升学学子被多所境内外优质高校录取，实现了“数量”

与“质量”

的双向跃升。

18名境外升学学子成功斩获世界百强、港澳知名高校录取

offer，既有悉尼大学、英国南安普敦大学、英国诺丁汉大学、英国谢菲尔德大学、马来西亚莫纳什大学等

QS世界百强的世界顶尖名校；

也有香港教育大学、香港都会大学、澳门科技大学、澳门理工大学、澳门城市大学等港澳地区重点院校；录取专业覆盖数据科学、人工智能、商业分析、软件工程、数码人文等前沿热门方向，充分体现了学院学子的全球视野与专业实力。

境内升学：优质院校广泛录取，学科实力备受认可46名境内升学学子被多所省内外重点高校录取，录取院校层次高、学科实力强，既有中国科学院大学计算机网络信息中心、中南林业科技大学、桂林电子科技大学、桂林理工大学、华南农业大学、深圳大学等全国知名院校；也有广东工业大学、华南师范大学、广州大学、东莞理工学院、广东财经大学等省内高水平大学；

录取专业聚焦人工智能、计算机技术、软件工程、大数据工程、人工智能教育等优势学科，充分彰显了学院在人工智能、计算机领域的人才培养质量得到国内高校的高度认可。

三、榜样引领：学风建设成效显著，逐梦路上携手同行

本届升学过程中，涌现出一批优秀学子榜样：大数据本2022-1班付吉丽、智能本2022-1班周堃涵等同学成功被悉尼大学录取；

同时，学院学子形成了“互帮互助、抱团备考”

的良好氛围，不同专业、不同班级的学子自发组建学习小组，共享备考资料、交流申请经验，涌现出2A-632、7A-511、7A-621、2D-306、2B-410、1D-302等学霸宿舍，多人成功上岸，用同伴互助书写了升学佳话，生动诠释了学院优良学风的传承与延续。

四、深耕育人：全流程赋能成长，全方位助力圆梦

亮眼成绩的背后，是学院多年来对人才培养与升学工作的深耕细作。学院始终坚持“以生为本”，构建了“动员引导

-过程帮扶

-精准指导”

的全链条升学支持体系：2026届考研誓师动员大会

早规划早引导：开展多场升学规划讲座、经验分享会，邀请往届升学学长学姐分享备考、申请经验，帮助学生尽早明确目标、科学规划；

精准化帮扶：建立升学学子台账，落实“一生一策”，对备考、复试、调剂进行跟进指导，为学子升学保驾护航。针对境外升学学子，开展一对一申请指导、文书润色与面试辅导；

展望未来，人工智能学院和未来科技学院将继续坚守立德树人根本任务，持续深化人才培养模式改革，不断优化学风建设与升学就业支持体系，为学生成长成才搭建更广阔的平台，为国家和区域产业发展输送更多高素质拔尖人才，续写学院人才培养工作的新篇章！
