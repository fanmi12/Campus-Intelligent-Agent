# 我院期末考试圆满结束

我院2007-2008学年第一学期最后一场考试，于今天下午5时顺利完成。本次考试从1月7日开始，共12个场次，考试地点主要分布在四号楼大厅和饭堂二楼。据教务处赵如瑜老师介绍，考试的总体情况良好，从试卷的审核、印制、装订，到考试的具体时间和考场安排，以及考卷的回收，各项工作都达到了规定的要求。

教务处在考试准备阶段加大了对考试试卷的审核力度，保证了试卷质量，对整个考试的具体安排做了细致的核查，并将考试安排的时间、地点和考试科目逐个通知到系、班和监考老师，确保了考试的正常进行。

考试期间，所有考务人员

和监考老师都提前半小时到达现场布置考场、领取试卷。监考过程中，监考教师认真负责，严格维护考场考试纪律。对于考试过程中出现的意外情况，教务处工作人员及时作出妥善处理，从而使整个考试过程没有出现任何特殊事故。

据悉，各任课老师正集中精力阅卷统分、装册存档。学生成绩近日将陆续在网上公布，成绩单也将邮寄到学生家里。根据教学计划安排，学院定于1月17日放寒假，2月18日开学。
