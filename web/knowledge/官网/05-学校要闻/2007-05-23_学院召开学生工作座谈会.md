# 学院召开学生工作座谈会

“各系每月召开一次学生大会，会议要由学生干部主持和讲评，为他们的成长多提供一些机会。”在学院5月22日召开的学生工作座谈会上，院长安少华教授向与会人员提出了明确的要求。

学院党委副书记朱冰向大会通报了本学期学生工作的情况。

院长安少华教授就如何进一步做好学生工作发表了重要讲话。他说，在坐的各系党总支副书记、院团委和学生处负责人及辅导员，是做好学生工作的骨干力量。要做好学生工作，必须要有激情，有爱心和责任心。建设好辅导员队伍，使之逐步做到职业化。积极探索学生工作的新规律和新特点，创新工作机制，为学生展现才华提供更多的平台，努力培养精英式人物。各系每月至少要召开一次学生大会，通报情况，表扬先进，批评错误。学生大会可以由学生会干部主持或讲评，总之，要为他们提供锻炼的机会。辅导员要加强业务学习，提高综合素质，深入到学生中去，与学生打成一片，了解和掌握他们的思想动态，解决实际问题，帮助克服学习和生活中的困难。
