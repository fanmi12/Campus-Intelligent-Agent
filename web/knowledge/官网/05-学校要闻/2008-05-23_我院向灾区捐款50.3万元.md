# 我院向灾区捐款50.3万元

5月12日，汶川发生8级大地震之后，学院迅速开展了“抗震救灾，众志成城，情系同胞，奉献爱心”的募捐活动。全院师生慷慨解囊，将笔笔善款汇入捐款箱。5月21日，在东莞市赈灾晚会上，全院教工再次向灾区捐款26万元。

截止5月22日16时，全院师生员工共捐献爱心善款50.3万元。

开展募捐的同时，机电工程系、文学与艺术系等单位还自发组织了义卖和烛光祈祷活动。所有党员还以“特殊党费”的形式进行捐款。
