# 我院成功举办第一届“图书馆杯”演讲与朗诵大赛

5月15日，由图书馆主办、“书香社”承办的城市学院第一届“图书馆杯”演讲与朗诵大赛在学术报告厅成功举行。文传系的温馨和林泳娴同学分别摘得朗诵组和演讲组的桂冠。

图书馆馆长陈伟在点评时说：“同学们坚持不懈的力量让我很感动，同学们的表现让我实实在在地感受到了做老师的幸福。套用梁启超的话语与同学们共勉：‘青年强，则城院强；城院强，则东莞强’！”
