# 我院专家点评东莞社会经济现象被中央电视台播出

11月20日，东莞电视台《今日莞事》报道的“皮贵肉贱 每天百吨桔子被扔”新闻中，我院金贸系副主任龙卫洋博士就此点评支招。此条新闻分别于 21日至22日的CCTV-1、CCTV-2、 CCTV新闻频道等频道多次播出。

近年来，我院服务东莞社会，为东莞经济社会“双转型”出谋划策，受到了企业和社会的肯定和好评，各类媒体多次进行了报道。这次是我院教师第一次出现在中央电视台的新闻。
