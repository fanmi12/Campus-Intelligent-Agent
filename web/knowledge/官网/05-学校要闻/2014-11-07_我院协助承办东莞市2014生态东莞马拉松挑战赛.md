# 我院协助承办东莞市2014生态东莞马拉松挑战赛

由东莞市体育局、东莞市生态园管委会、东莞市登山户外运动协会、东莞理工学院城市学院联合主办的2014生态东莞马拉松挑战赛将于11月9日8时至13时在东莞生态园举行。根据组委会要求，我院作为主办方将要派出一百多人的赛事志愿者、新闻报道团队及赛事裁判员。

为了更好的服务此项赛事，11月6日下午2时30分，2014生态马拉松挑战赛城市学院志愿者培训暨动员大会在教学楼7B607顺利召开。体育部主任邢红林、体育部教师陈勇军（赛事组委会委员、副总裁判长）以及学院志愿队队员们参加了本次会议。

体育学教师陈勇军老师介绍了赛事概况、解读了志愿者的职责与权利义务、细致讲解了应对突发状况的处理方法，并在现场通过模拟的场景演示各种紧急情况的应对方法。

体育教学部邢红林主任发表动员讲话，希望我院志愿者都能在本次活动中得到锻炼，为城院争光。
