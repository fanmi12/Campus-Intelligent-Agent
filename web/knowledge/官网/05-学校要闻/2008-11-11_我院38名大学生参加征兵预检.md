# 我院38名大学生参加征兵预检

冬季征兵命令发布以来，我院大学生积极报名应征，主动请求进军营承担保家卫国的神圣义务与职责。经过学院的初步审查与目测，今天有38名学生被批准参加了东莞理工学院武装部的预体检，其中有35人预检合格（8名女生，27名男生）。11月18日，预检合格者将赴东莞市国防教育基地参加体检。

据悉，今年东莞市的应征入伍者将去云南武警部队服役。
