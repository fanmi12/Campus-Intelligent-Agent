# 我院举办第三届英语演讲比赛

4月27日下午，我院第三届英语演讲比赛总决赛在学术报告厅举行。戚健、乐学玲、贺力鹏、李白茹老师担任赛事评委。

八位进入总决赛的选手闪亮登场，依次用流利的英语做简单的自我介绍。选手们流利的英语演讲、标准的发音、富有感染力的肢体语言，还有闪亮得体的服饰给选手们“助攻”，给评委老师及现场观众带来了一场听觉与视觉上的盛宴。

选手们分别围绕“My Top Concern”的主题展开演讲，就“追随内心”“环境”“家庭”等话题展开精彩演说，他们扎实的语言功底，纯正的发音，敏捷的才思赢得了如潮的掌声。选手们的表达或自然清新，或慷慨激昂，或引人入深思，为观众带来了一场听觉享受。

在现场随机抽取即兴演讲的题目环节，选手们分别对共享单车、校园欺凌、手机支付之类的时事热点，结合时政与自身看法，有条理性地回答了老师与现场观众的问题，生动幽默的回答博得台下阵阵掌声。

经过三个环节的激烈角逐，鲍新粤、靳若帆同学获一等奖，刘珊珊、梁兆豪、梅嘉儿同学获二等奖，陈玲珺、刘畅、宋富华同学获三等奖。鲍新粤夺得最佳台风奖，刘畅摘取了最佳人气奖。

外语系主任王锦锋介绍说，比赛旨在选拔优秀人才，代表我院参加省市以及全国级英语演讲比赛，为我院英语教学和应用积累经验。同时，比赛也丰富了同学们的课外生活，为同学们提供了一个展示自己的平台，调动了同学们学习英语的积极性。

外语系全体老师观看了比赛。学院团委对比赛进行了全程直播。
