# 我院各系部教职工入驻新校区

为尽快熟悉新校区的校园环境、教学环境及设施，把迎新工作做足做细做扎实， 首批34名来自我院各系部的系主任、教学秘书、辅导员及行政人员于9月7日正式进入新校区开展工作。

当日上午，各系部首批入驻教职工一早便来到新校区，并在法商大楼四楼会议室召开会议。杨敏林副院长等领导对大家的到来表示热烈欢迎，并就新校区建设、管理架构及迎新准备工作做了简短的介绍，希望各位老师尽快熟悉新环境，积极投入到新校区的迎新及今后的教学、管理工作中来。

随后，各系部人员在领取各自的办公室钥匙、办公设备后，迅速布置办公室、熟悉新校区环境。同时，新校区管委会及后勤部门也积极配合，为各系部新入驻新校区的职工解决好办公、食住、交通等问题。
