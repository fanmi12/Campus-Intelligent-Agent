# 王卫平校长开讲“思政第一课”：民族解放、国家强大、民族复兴靠谁人？

9月25日下午，校长王卫平走进7A106教室，他以”民族解放、国家强大、民族复兴靠谁人？”为题，为同学们开讲“思政第一课”。

王卫平校长首先抛出观点，问大家：“我们民族解放、国家强大、民族复兴靠谁人？”同学们纷纷发表自己的看法，王卫平对同学们的看法表示称赞，他指出“历史实践证明，需要靠伟大共产党、英明的领袖和英雄的人民！”

紧接着，王卫平校长分析到为什么民族解放、国家强大、民族复兴只能依靠以中国共产党为核心的坚强与正确领导。这是因为中国共产党的领导核心地位是由它的党纲决定的，而近代中国发展史进一步奠定了中国共产党的领导核心地位。自1949年建国以来，我们国家从一穷二白发展到初步建成社会主义工业体系中具有国际尊严的国家，人民逐步富起来，国家强大起来，无不是在中国共产党的坚强领导下进行的。今年中国新冠肺炎疫情得到有效控制彰显了中国共产党的伟大，彰显了中国共产党的坚强领导和强大的动员能力。当前的国内经济社会复苏和险恶的国际形势对策更离不开中国共产党的坚强领导。

王卫平指出民族解放、国家强大、民族复兴同时离不开英明领袖的领航。从1921年中国共产党的成立到如今，这99年间，我们党涌现了毛泽东、邓小平、习近平等多位英明的领袖，从使中国人民获得了解放到中国人民富起来，国家强起来，再到人们生活更美好，国家更强大，民族走向复兴，一步步走来，都离不开英明领袖的领航。

王卫平强调民族解放、国家强大、民族复兴还离不开英雄的人民。在今年的抗疫大考中，全国各省市迅速派出医疗队驰援湖北，医疗人员总数4.2万人。广东有2495名医护人员援鄂，20万名城乡社区党员干部昼夜值守，200万名党政机关企事业单位党员下沉一线。我们国家的抗疫取得的成绩，离不开英雄的人民。自1840年以来，我们进行的抗击外来侵略的战争、解放战争，直到改革开放，没有英雄的人民，就没有民族解放、国家强大、民族复兴。

在谈到作为一名大学生如何做新时代合格大学生时，王卫平强调在当前广大学生需要努力培育和践行社会主义核心价值观，树立“四个意识”，坚定“四个自信”，做到“两个维护”，积极投身到粤港澳大湾区建设中去，运用自己所学的专业知识，为实现中华民族伟大复兴的中国梦贡献自己的力量。

王卫平的授课既旁征博引、高屋建瓴、精彩纷呈，又语言生动、循循善诱、深入浅出、开拓了学生的视野与思维的同时，也给学生以深刻的启迪和深深的鼓舞。100余名学生和教师一同聆听了王卫平校长的讲课，学校党委宣传部副部长苗琳主持并聆听讲课。
