# 我校举办北部湾产学合作论坛及奖学金颁发典礼

11月14日下午，我校在学术报告厅召开了“北部湾产学合作论坛及奖金颁发典礼”。北部湾财产保险股份有限公司副总裁韦军辉、副总经理尹朝辉、人力资源总监李祥杰，校长王卫平、副校长周庆和相关部门负责人，金贸学院领导及师生代表参加了活动。会议由金贸学院副院长赖忠孝主持。

大会对一年来双方进行深度产学合作的先进个人、先进集体及北部湾保险优秀科研团队进行了表彰。

李祥杰总监表示，一年来，通过校企联动、校企共建，双方合作共建保险专业取得了良好的成效。校企产学合作以服务粤港澳大湾区保险市场，提高学生的职业实践能力和培养职业素质为目标，改革人才培养模式和教学模式，发展保险业，以校企共建创新模式，形成了校企共赢的局面。

韦军辉副总裁强调，保险行业未来发展需要创新变革，要有创新的品质和思维，从业人员需要学好专业知识，而东莞理工学院城市学院与北部湾财产保险股份有限公司校企共建的保险专业正是富有成效的创新变革。

王卫平校长对北部湾保险公司作出的贡献表示感谢，鼓励学生推进教育的“四个回归”，养成与人为善的团队意识，成为对国家社会有用人才。他希望广大教师牢记“天道酬勤”的古训，热爱教育，为人师表，全方位育人，为党的教育事业作出新的贡献。

据介绍，2018年9月，金贸学院与北部湾保险公司达成了高度战略合作，以现代保险行业人才需求为基本依据，瞄准粤港澳大湾区保险市场相关企业各岗位，以提高学生的职业实践能力和职业素养为宗旨，倡导以学生为本位的教育理念和灵活的教学机制，双方共建保险专业，通过综合和具体的保险实践活动，突出应用型本科教育的特色，全面提高学生的职业道德、职业能力和综合素质。
