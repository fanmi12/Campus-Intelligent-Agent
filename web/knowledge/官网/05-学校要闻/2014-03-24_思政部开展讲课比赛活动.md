# 思政部开展讲课比赛活动

3月20日下午4点开始，思政部以教研室为单位，分别在7C112、7C113课室开展讲课比赛的教研活动。

德育教研室的刘学勤、石瑞丽、孔青梅老师，原理教研室的彭先兵、林萍、李燕燕老师分别进行教学能力PK。

几位老师纷纷拿出自己的十八般武艺，展现自己教育教学的能力与热情。他们精心的教学内容设计、精彩的讲课技巧、完整清晰的逻辑思路、富有激情的语言艺术，把自己热爱教育事业和热爱思想政治理论课教育教学工作演绎得淋漓尽致。

比赛老师们各有千秋，优异的表现让其他作为评委的老师们一时难分伯仲，得到了黄宗理教授、刘凤仙教授、范新成教授、何鹏举教授的不断夸奖。

比赛进行的精彩激烈，老师们积极进行评课更是高潮迭起。评课分为比赛教师自评互评和其他老师点评两种形式，对比赛老师讲课过程中的优缺点进行点评，从内容到形式、从逻辑结构到教学细节、从理论演绎到案例选取分析、从课件制作到语音语速，进行一次又一次还原、放大、指指点点，并提出改进教学的意见和建议。

广东省青年教师讲课比赛一等奖获得者王芳仪老师认为，比赛要抱着平时讲课一样的心态，能够收放自如，要导入清晰、语速适中、图例鲜明、案例典型、联系实际，比赛时，更应该慎重准备，尤其要选用自己有自信把握比较准、内容熟悉、愿意讲且讲不厌、抓得住又放得开的章节。

东莞理工学院范新成教授认为，教学讲课比武可以提高任课教师的授课能力，培养教学人才。石志民副主任说，今天的分教研室比赛是初赛，教学部还将举行决赛，选拔优秀教师参加省里的教学比武和学校的讲课比赛。

时钟指向6点，老师们还在意犹未尽、交流经验。
