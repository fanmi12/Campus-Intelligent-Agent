# 政法系召开学生学习经验交流会

12月2日，政法系在3303课室召开“学无止境”学生学习经验交流会。

在交流会上，政法系上届学生会主席邹磊同学通过生动的语言及照片向同学们介绍了在美游学期间的所见所闻，以及在大学期间的学习体会。在“你问我答”环节中邹磊还回答了同学们提出的问题。

会后，邹磊表示，交流可以使同学们相互学习，共同提高，也有利于系统地总结自己的学习体会，并更好地规划未来。
