# 学院两部门赴深考察学习

深大图书馆张馆长（左一）介绍了他们的图书管理模式和经验3月4日，学院基建办主任叶树标及图书信息中心主任陈伟等一行8人，前往深圳市科技图书馆（深圳大学城图书馆）、深圳大学图书馆和深圳职业技术学院图书馆参观学习，受到考察单位的热情接待。

深大图书馆张馆长介绍图书管理模式和经验，以及深圳大学图书馆在建设、装修过程中遇到的问题，并对我院图书馆的建设提出了建议。

通过参观学习与交流，大家受益匪浅，认为外地的经验值得学习与借鉴，为我院图书科技信息中心大楼的建设、功能布局以及装修提供了可贵的参考信息。
