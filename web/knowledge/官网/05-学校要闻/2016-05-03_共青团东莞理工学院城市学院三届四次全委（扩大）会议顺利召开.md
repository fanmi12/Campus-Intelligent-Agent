# 共青团东莞理工学院城市学院三届四次全委（扩大）会议顺利召开

4月28日下午，共青团东莞理工学院城市学院三届四次全委（扩大）会议于学术报告厅顺利召开。院领导章德胜、黄兢出席了会议。

学院团委书记罗文芳作了团委工作报告，全面系统地总结了一年来我院共青团工作情况，并对下一阶段共青团重点工作进行了部署，提出要突出抓好思想指导，全力促进大学生创新创业，进一步推动校园文化建设。

大会对荣获“优秀团员”、“优秀团干部”、“优秀团支部”荣誉称号的同学进行了表彰；对“优秀团学组织”称号的管理系、文学与传媒系、财经系等单位进行了颁奖；为卸职委员李伟健和麦振峰颁发了荣誉证书。

学院党委副书记章德胜在总结发言中，充分肯定了各级团组织和广大团干部一年来所付出的辛勤努力，并结合当前的形势，为今后学院共青团工作提出了相关要求。
