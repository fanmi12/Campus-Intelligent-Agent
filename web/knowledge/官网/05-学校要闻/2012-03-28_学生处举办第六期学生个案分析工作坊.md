# 学生处举办第六期学生个案分析工作坊

3月22日晚，学生处在新校区学生活动中心举办第六期学生个案分析工作坊,主题为大学生心理危机干预。党委副书记朱冰出席会议。各系辅导员、学生处工作人员参加了工作坊。本次工作坊特别邀请了东莞理工学院学生处副处长、心理健康教育与咨询中心主任苏亚玲副教授担任主讲嘉宾。

学生工作坊自开办以来首次专门围绕大学生心理危机干预开展座谈会。会上，苏教授以翔实的案例、大量的细节，结合自己在工作中的思考对危机处理提出了自己的看法，提醒广大学生工作者在日常的工作中必须时刻保持危机意识，坚持对学生干部、学院的相关部门开展危机处理培训工作，制定和完善相关制度。与会人员就危机处理过程中的诸多问题，例如家属亲友处理、媒体应对、部分分工、善后处理等等问题与苏教授进行了充分沟通。

朱冰副书记做了总结讲话。她指出，工作坊这个平台，给了学生工作者提供一个交流经验的机会，要群策群力解决困难和问题，把学生工作做得更好。
