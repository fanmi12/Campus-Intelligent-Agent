# 我校举行第三届教职工代表大会暨工会会员代表大会第三次会议

为全面贯彻新时代党的教育方针政策，进一步落实省、市党组织关于加强工会组织建设，促进学校教育事业高质量发展，我校于5月21日下午在行政楼112举行2024年第三届教职工代表大会暨工会会员代表大会第三次会议。全体校领导、各部门的正式代表、列席代表等人员参会。会议由工会副主席叶凯贞主持。

学校执行校长方伟华作《学校工作报告》，他从党建工作，教育教学、教学评价改革，本科教学评估，师资队伍建设，科研工作，现代产业学院建设，招生工作改革，毕业生就业工作改革，二期工程建设，校园文化与学生社区建设等谈到了2024年东莞城市学院的工作要点。他提出今年正值学校建校20周年，是值得纪念的一年，也是关键的一年。他希望全体教职工同心同德、齐心协力，努力践行“创一流大学、办百年名校”的办学理念，积极探索民办高等教育高质量发展新路径，精准定位人才培养目标，深化教学方式改革，不断提升办学水平和服务大湾区经济社会发展的能力，助力广东教育高质量发展。

工会副主席叶凯贞作《学校工会工作报告》，她从工会的民主政治建设、提升教职工的获得感与幸福感、强化工会理论与业务学习及提升服务水平等方面，回顾了2023年学校工会的工作。她指出，在2024年学校工会将继续强化思想引领、把牢正确方向，加强民主建设、助推学校发展，完善服务体系、构建和谐校园，加强自身建设、推动工会创新，为学校高质量发展贡献工会力量。

随后，大会投票补选了学校工会委员会主席、董事会教职工代表。经大会投票选举，李海冬同志当选学校工会委员会主席、张兰同志当选董事会教职工代表

校党委书记章德胜作讲话。他指出教职工代表大会暨工会会员代表大会是落实教职工参与学校民主管理、民主监督的基本组织形式，也是学校各级党组织联系广大教职工的桥梁和纽带。会议期间，各位代表肩负全校教职工的重托，讲政治、顾大局，重实际、求实效。会议各项成果充分体现了学校坚持校务公开、民主管理的办学理念；充分体现了广大教职工在学校改革、发展及民主政治建设中的积极作用；充分彰显了广大教职工的主人翁精神和参与学校民主管理、民主监督的生机活力。他指出，今年是新中国成立75周年，是实现“十四五”规划目标任务的关键一年，也是我校建校二十周年、继续推进教育教学改革，推动学校内涵式建设与高质量发展的关键一年，机遇与挑战并存，动力与压力同在。希望全体教职工团结一心，踔厉奋发，勇毅笃行，以乘龙之势投入到学校工作中去，发挥自己的聪明才智和专业能力，全面贯彻党的教育方针政策，奋力开拓，锐意进取，深化教育教学改革，为学校建设创新性、应用型、国际化、特色鲜明的高水平大学而努力。
