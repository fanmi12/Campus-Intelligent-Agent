# 烛光映爱心 祝福传灾区

5月15日晚，在杜发游泳馆边的空坪上聚集了数百名学生，举行为四川受灾人民祈祷活动。

许多同学捧着点燃了的红色小蜡烛，围在一个用红色小蜡烛摆成的爱心图案的周围，共同唱着《祈祷》和《明天会更好》的歌曲，沉痛哀悼震灾中的死难者，表达大家对四川同胞的祝福与希望。

活动还邀请了川籍学生介绍家庭遭灾情况。听着他们感人的倾诉，很多同学不禁潸然泪下。

烛光照亮了校园。
