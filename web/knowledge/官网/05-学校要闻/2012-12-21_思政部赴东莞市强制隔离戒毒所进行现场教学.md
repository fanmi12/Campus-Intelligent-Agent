# 思政部赴东莞市强制隔离戒毒所进行现场教学

12月20日，思政部组织近300名2012级学生，在党委宣传部部长、思政部主任何鹏举教授、思政部副主任石志民副教授和任课教师的带领下，来到东莞市强制隔离戒毒所开展以“崇尚科学、珍爱生命、远离毒品、热爱生活”为主题的现场教学活动。

师生们参观了戒毒人员的生活区和“毒品的危害”禁毒教育宣传展厅，观看了有关毒品危害的视频及戒毒所学员编排的情景剧《爸妈，我要回家》，听了戒毒所学员讲述自己被毒品毒害的经历。活动中，同学们对毒品给吸毒者和社会所带来的危害，有了较全面的认识。

何鹏举教授引领全体人员进行宣誓：“崇尚科学，加强修养，拒绝毒品，珍爱生命，感恩父母，幸福生活！”

这次现场教学活动，是省级精品课程《思想道德修养与法律基础》的实践教学环节，旨在通过现场感受，现场说法，让同学们了解毒品危害，洁身自好，永不沾毒，进而深化对课程中“品德、修养、法律、自由”等抽象概念的认识。

刘同学的记事本记满了参观学习的笔记和感想，他对记者说：“震撼！警醒！回去后，一定会把自己的感悟感想告诉同学们，让大家都引以为戒，健康生活！”
