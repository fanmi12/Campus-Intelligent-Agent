# 我院喜获省首届高校防范非法集资微视频、海报设计大赛一等奖

6月22日，广东省首届高校防范非法集资微视频、海报设计大赛颁奖典礼在广州金交会盛大举行。本届大赛由广东省政府金融工作办公室、共青团广东省委员会、广州市金融工作局主办，广东省广晟金融控股有限公司协办，广州金交会投资管理有限公司、广东财经大学团委承办。我院团委宣传动员共申报了近160份作品，最终来自大学生媒体中心的钟思庆、莫世豪、赵颖聪和新闻中心指导老师莫玮娟的微视频参赛作品《黑白成片》在获微视频组一等奖；城市与环境科学系叶慧芳同学的《掉进钱眼，一发不可收拾！》获得了海报设计组一等奖；创意设计学院李嘉琪、冯家乐同学的海报作品获得了三等奖；此外还有创意设计学院的吴晓青、江书孟、黎心瑜、外语系方静敏同学的海报作品分别获得了优秀奖。

本届大赛以“防范非法集资”“防范违规校园贷”“防范各类金融诈骗”为主题。从3月启动以来，全省共有72所高校参加了本届设计大赛。经过评审团层层评审、严格的把关，分别选出了特等奖、一等奖、二等奖、三等奖和优秀奖。其中，我院是东莞地区在本届大赛的唯一获奖高校。

获奖学生钟思庆、赵颖聪与指导老师莫玮娟合影
