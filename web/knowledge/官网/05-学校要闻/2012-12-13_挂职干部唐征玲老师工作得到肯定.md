# 挂职干部唐征玲老师工作得到肯定

12月10日，院党委副书记章德胜，组织人事处处长胡钦华，教务处副处长葛卫清，代表学院探望我院在汕头市潮南区挂职任团区委副书记的唐征玲老师。

潮南区郑孟坚副区长代表潮南区委欢迎我院探望组的到来，并介绍了潮南区近几年来的社会经济发展情况。团区委马淼鑫书记对团区委组织结构、团的工作做了介绍，并对唐征玲老师的工作表现给予了高度肯定。马书记评价说，唐征玲老师踏实肯干，工作能力强，到潮南挂职九个月时间，给潮南的工作带来了新的发展。马书记还表示，希望通过挂职干部的桥梁作用，促进团区委与城市学院各方面的合作。

章德胜副书记代表城市学院感谢潮南区委政府、团区委对唐征玲老师的培养。他希望通过团委这个桥梁，在大学生志愿服务、大学生暑期社会实践等方面加强合作。
