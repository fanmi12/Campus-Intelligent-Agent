# 展巾帼风采 树管理新风

王晓春老师介绍管理系“巾帼文明岗”创建工作情况

检查组认真查看管理系“创岗”材料12月21日，东莞理工学院党委副书记黄碧莲、妇委会主任韦洛霞一行7人来我院检查指导管理系“巾帼文明岗”创建工作。城市学院院办副主任、工会妇委会主任黄研晖等陪同。

检查组听取了王晓春博士对管理系“巾帼文明岗”创建工作情况的汇报，仔细查阅了创建材料及成果。黄副书记对管理系的创建工作给予了高度评价，她说，管理系的创岗目标明确，创建口号响亮，活动内容丰富，方案细致具体，创岗措施有效，创建成效明显，领导高度重视，活动开展有特色，充分展现了巾帼风采，这些成功的经验值得推广与学习。

管理系女教师们表示，将以“创岗”工作作为新的起点，继续发扬“爱岗敬业、乐于奉献、锐意进取”的精神，紧密结合我院发展形势要求，恪尽职守，爱岗敬业，教书育人，奋发进取，不断地自我突破，自我创新，为服务社会做出新的贡献。
