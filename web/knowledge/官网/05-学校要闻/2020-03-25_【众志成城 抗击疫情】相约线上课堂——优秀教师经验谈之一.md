# 【众志成城 抗击疫情】相约线上课堂——优秀教师经验谈之一

新冠肺炎疫情是新中国成立以来最为重大的突发公共卫生事件，疫情是一次磨难，也是一次考验。在以习近平同志为核心的党中央坚强领导下，全党全军全国各族人民弘扬伟大的民族精神，齐心协力，共抗疫情，锻造了中国精神，凝聚了强大的中国力量。

我校坚决贯彻落实教育部、省教育工委、省教育厅的重要部署，从3月2日起全面开展线上教学活动，全体任课教师坚守岗位、锐意创新、勇挑重担，全力做好线上教学工作。广大学生学习热情高涨，积极投身到线上学习。广大师生的表现彰显了新时代的城院精神。从今天开始，我们精选刊发部分优秀教师线上教学经验谈，今天推出第一期，分别介绍商学院张洪、艺术学院林伟伦、文传学院柯小瑜三位老师的线上教学心得体会，供大家借鉴。

商学院张洪老师线上教学心得体会：线上教学已经进行到第3周，从最初的忐忑，到现在我和同学们逐渐适应并爱上了这一全新的教学方式，有几点小体会。

要开展好线上教学，首先要做好充分的课前准备，不仅是老师，还有同学。通常，我会提前3天将《课前公告》（学习指引）发布并置顶在企业微信群，指导学生观看线上课程，围绕关键词、重难点提前预习课程内容，适当设置一两个问题，带着问题去预习。其次，强化教学过程设计，增强课堂互动环节。一节课，时间并不长，老师和同学们都是面对屏幕，教学环节如何设计，在哪个地方展开讨论，如何引导和激励学生，调动他们的积极性，都需要仔细思考。第三，课后巩固。布置适当的作业，包括一两个开放型问题，让学生利用互联网查找，拓展知识面，发挥线上课程的优势。

虽然和同学们身处全国各地，因为线上课程，我们的距离更近了，大家在课堂中的讨论甚至有时候比在教室里更积极主动，我想下一阶段，引入“小组讨论”的会议形式，让线上教学更生动、有效。

艺术学院林伟伦老师线上教学心得体会：在线上教学开始之前，我通过网络方式向多位音乐名家学习，为新学期我的线上教学注入了新营养。科学结合音乐表演专业特性，我在大班课的线上教学是采用企业微信直播模式，通过不断的测试和改进最终能实现在课中把知识点、乐谱、音频文件、视频文件等合理有序地呈现在大部分学生手中的屏幕上，我在声乐小组课上则采用企业微信会议模式，并且在声乐小组课中同时借助“全民K歌”手机App让学生实现带音响效果的演唱，从而提高授课质量，现正继续学习和研究如何把线上课上得更好。

文传学院柯小瑜老师线上教学心得体会：经过三周授课实践，我谈谈自己的心得体会：

1、端正态度，认真以对。我尝试不同的教学模式，反复测试，确保授课效果。

2、形式新颖，内容丰富。我用企业微信群授课，用慕课堂布置作业，要求学生课外看视频。

3、及时指导，适时调整。学生的困扰来自对问题不理解和对操作软件不熟悉，我会有针对性地及时释疑。

4、课前预习，课后练习。课前我发放电子教材和课件，课后用慕课堂检查学生作业。

实践尚浅，我会继续努力前行！
