# 我校商科实验教学省级示范中心正式揭牌

12月23日，我校在5B一楼举行商科实验教学省级示范中心揭牌仪式。东莞市财政局班子成员、东莞市注册会计师协会党委专职副书记萧永清，东莞市财政局会计科科长黄云峰，东莞市注册会计师协会会长、党委副书记李怀继，学校副校长周庆，商学院院长罗卫国、党总支书记卢淑芳，以及用友新道科技有限公司、大信会计师事务所、中职信会计师事务所、唯美陶瓷等13家商学院校外实践基地代表和商学院教师参与了揭牌仪式。

商科实验教学示范中心于2016年立项为省级实验教学示范中心，2019年通过省教育厅结题验收。商科实验教学中心已经成为我校商科对外交流的主要窗口之一，累计接待省内外高校及单位交流访问40多批次，受到省教育厅等相关领导的高度肯定。
