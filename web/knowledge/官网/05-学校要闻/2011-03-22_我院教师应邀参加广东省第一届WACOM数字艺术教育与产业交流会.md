# 我院教师应邀参加广东省第一届WACOM数字艺术教育与产业交流会

3月17日至18日，由广州美术学院举办的广东省第一届WACOM数字艺术教育与产业交流会在广州科学城举行。我院文学与传媒系吴宇、龚红喜老师，新闻中心徐斌老师应邀参加了会议。

广州美术学院视觉与动漫艺术学院副院长王绍强介绍了学院教学规划及经验。中国3DSMAX大师陈大钢以纪录片《敦煌》为例，详细讲解了三维技术应用。交流会上，嘉宾们就数字艺术产业发展的困境与机遇作了深入探讨。美轮美奂的电影《阿凡达》场景设计、变幻莫测的《机器人》变形、世博会中国馆《清明上河图》等作品的3D制作技巧在本次交流会上一一揭秘。
