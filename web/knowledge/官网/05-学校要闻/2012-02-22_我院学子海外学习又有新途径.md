# 我院学子海外学习又有新途径

2月21日，广东教育国际交流服务中心东莞分中心（下称“东莞分中心”）在我院5号阶梯教室举办大学生海外实习宣讲会。

会上，东莞分中心负责人向与会师生详细介绍了大学生暑期赴美国参加带薪实习和赴美国、新加坡进行专业实习等项目的情况。

据悉，赴美带薪实习项目是我院与东莞分中心新开展的一个交流项目，旨在为我院学生提供一个广阔的海外实践平台，进而培养学生的独立自主能力。参与该项目的在校大学生可于暑假期间持J-1签证进入美国企业，进行为期三个月的社会实践。该项目受美国政府监管，在欧、美、亚其他国家及地区已成功运作三十多年。近年来，我国北京、上海、广州等不少高校已经成功组织学生参与该项活动，反应热烈。
