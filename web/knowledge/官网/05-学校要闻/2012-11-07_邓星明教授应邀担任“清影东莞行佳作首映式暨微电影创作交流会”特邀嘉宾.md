# 邓星明教授应邀担任“清影东莞行佳作首映式暨微电影创作交流会”特邀嘉宾

11月2日，由中共东莞市委宣传部主办，东莞广播电视台、莞城街道办事处承办，清华大学新闻与传播学院、莞城文化周末办公室、东莞阳光网协办的“发现精彩，东莞故事”原创DV大赛特别活动——“清影”东莞行佳作首映式暨微电影创作交流会在一片期待中拉开了帷幕。我院文传系系主任邓星明教授作为嘉宾应邀参加了此次盛会，并与清华大学新闻与传播学院雷建军副教授以及“80映像”、“莞少时”等多位东莞本土微电影制作团队导演就微电影的发展及遇到的问题进行了探讨。邓星明教授就微电影的题材及微电影的艺术标准等问题发表了自己的看法，受到与会领导和听众的好评。

东莞市委常委、宣传部长潘新潮等领导到会讲话并与嘉宾们合影留念。

近日，东莞日报、东莞阳光网等多家媒体对此次活动作了报道。
