# 杨宝霖与教师共同探讨《大学语文》教学工作

5月22日，东莞著名的文史学家杨宝霖先生莅临文学与传媒系，与中文教师共同探讨《大学语文》课程的教学。杨老先生对《大学语文》教材中与东莞文化相关的篇章进行了详细的介绍与解读。老先生以矍铄的精神，饱满的热情，严谨的思维，精简的话语，绘声绘色地讲解了东莞的文人、文学与文化。

杨老先生在谈到他最熟悉的“木鱼歌”时，即兴演唱了一段，既有雅唱，又有俗唱，进而引发了一轮热烈的讨论。

各位老师虚心请教杨老先生，提出了自己在教学中的疑惑，杨老先生认真而又耐心地一一分析解答，真正做到了知无不言，言无不尽。
