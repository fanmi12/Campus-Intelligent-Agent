# 学校党委理论学习中心组举行党史学习教育研讨会

7月4日，学校党委理论学习中心组（扩大）党史学习教育研讨会在行政楼401会议室举行，专题研讨学习习近平总书记在庆祝中国共产党成立100周年大会上的重要讲话精神，以及学校党史学习教育工作。学校党委委员、党史学习教育领导小组成员，各二级单位负责人等参加了研讨会。党委书记章德胜主持会议。

会上，传达学习了全省教育系统深入学习贯彻习近平总书记在庆祝中国共产党成立100周年大会上的重要讲话精神的动员会议视频会议精神。

与会人员对深入学习贯彻习近平总书记在庆祝中国共产党成立100周年大会上的重要讲话精神进行了交流、研讨。大家纷纷表示，要提高政治站位，增强政治意识，深入学习贯彻习近平总书记重要讲话精神，并作为今后党史学习教育的重中之重。大家认为，作为党员干部、党的教育工作者，要从党的百年伟大奋斗历程中汲取智慧和力量，用实际行动响应总书记、党中央的号召，更好落实立德树人根本任务，全面推进学校事业不断向前发展，办好人民满意的社会主义大学。

章德胜书记总结强调，全体党员干部、师生员工要把学习贯彻习近平总书记在庆祝中国共产党成立100周年大会上的重要讲话精神作为当前理论武装工作的最重要的政治任务，作为党史学习教育的核心内容、作为学校头等大事抓好抓实。

章德胜要求各党组织要在暑期放假前组织专题学习和研讨，把集中学习、个人自学等形式结合起来，认真学、反复学、结合实际学、带着问题学；在今后的工作中，充分发挥思政课主渠道和课程思政作用，推动习近平总书记重要讲话精神进教材、进课堂、进师生头脑；要广泛深入地开展习近平总书记重要讲话的宣传、宣讲、解读、研究，把习近平总书记重要讲话精神学习透、研究透、运用好，推动党史学习教育走深走实；要紧密联系工作实际，把学习“七一”重要讲话精神的成果转化为“为党育人、为国育才”，奋进新征程、建功新时代的实际行动。

会议还对学校下一阶段党史学习教育工作进行了研究，并对召开党史学习教育专题组织生活会进行了部署。
