# 科研部召开科研工作例会，共谋学校科研创新与发展

为推进我校科研工作高质量发展、提升学校整体科研水平，3月19日下午科研部于行政楼505会议室召开了科研工作例会。此次会议旨在总结上学期科研工作，探讨存在的问题，并规划未来的科研工作的方向与目标。东莞城市学院常务副校长方伟华、副校长康贤刚、科研部部长赖忠孝、科研部副部长李殿鑫、各二级学院院长及分管科研副院长参加了此次会议。会议由科研部部长赖忠孝主持。

赖忠孝部长回顾了上学期科研部的工作情况，明确了本学期的工作思路。他强调，在科研工作方面，要做好科研管理工作，优化项目过程管理，提高信息化程度；完善知识产权管理，促进成果转化；加强研究院建设工作，争取早出结果；完善和修订科研管理制度；优化学术讲座管理，调整学报出版模式；做好产学研工作和领导小组办公室日常工作。随后，与会人员就如何提高科研水平、加强科研团队建设、推动科研成果转化等议题进行了深入讨论。

随后，创意设计学院院长何帅阐述了对岭南文化数字化研究院开放课题的设想，并且对研究院后续的发展进行了详细的规划。

此外，李殿鑫副部长对博士工作站建设的设想以及后续科技大讲堂的安排进行了详细地阐述。

康贤刚副校长对粤莞联合基金申报相关文件进行了深度剖析。他表示要进一步加强科研团队建设，提高科研水平，培养独立承担科研项目、进行创新研究的能力，激发校内师生的创新思维，培育基础研究后继人才队伍，提升学校科研创新能力。

常务副校长方伟华做了总结讲话。

他指出高校科研工作是衡量高校水平的重在条件，科研工作是高校发展的重要支撑，要进一步加强科研管理，提高科研质量。他强调，各学院要紧密结合学科特点，发挥自身优势，推动科研创新与发展。同时，他希望广大科研人员要勇于担当，积极投身科研工作，为学校的发展贡献力量。

方校对未来的科研工作提出了要求：密切与相关科研主管部门的联系，主动做好服务；加强两个省级社科平台——大学与城市发展研究院和岭南文化数字化研究的工作，争取早出成果、出好成果；科研部要

走出去，实行开放管理，协助老师们做好科研工作；用务实的态度对学校相关科研管理制度进行完善和修订；做好线上科研管理工作，相关工作人员三天未给出意见视为自动同意，科研报销强调规范、合理，科研有心、过程有痕、开支有据；产学研工作要标准化、流程化，要能便于后续发展；要做好有组织的科研，科研通知要精准推送到每一个老师，做到人人皆知、人人参与，少花钱，办大事。广大师生要全心全意，上下努力，共同开创学校科研工作新局面，为学校的长远发展打下良好的基础。

此次会议的召开，为我校科研工作的进一步发展指明了方向。相信在全校师生的共同努力下，学校的科研工作将取得更加辉煌的成就。
