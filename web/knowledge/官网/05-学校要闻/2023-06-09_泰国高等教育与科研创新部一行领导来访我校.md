# 泰国高等教育与科研创新部一行领导来访我校

6月6日下午，泰国高等教育与科研创新部副部长、秘书长Danuch Tanterdtid（以下简称达努秘书长，副部级）等一行领导到我校交流访问。我校常务副校长方伟华，副校长陈葆华，校长助理、国际学院院长赵书山，教务处副处长鞠晓红，继续教育学院副院长王文静，国际学院副院长戚峻玮，全球交流合作处副处长、国际学院副院长魏航等参加会议。

交流座谈会上，我校常务副校长方伟华代表学校向泰国高等教育与科研创新部一行的到访表示欢迎，并介绍学校定位、办学理念、人才培养、国际交流、合作意向等情况；泰国高等教育与科研创新部达努秘书长致辞，希望为我校未来搭建与泰国高校间开展学术性交流的合作桥梁。

随后，双方现场洽谈合作交流项目。我校参会领导代表分别提出希望与泰国专业匹配或相近的高校开展中泰合作班，在相关专业进行本科2+2、3+1项目以及本硕连读项目合作；鼓励互派中泰学生交流和交换，促进中泰教育与文化的友好交流。双方希望推动中泰教师互访，在教师博士升学项目以及科研学术等方面深入合作；在未来进行中泰国际学院或者一带一路学院项目合作，共同推动中泰高等教育事业良好持续发展。

会后，双方代表共同合影留念并互赠纪念品。泰国高等教育与科研创新部一行领导参观校园，并对我校的校园环境、校舍建筑风貌、图书馆设计、校园学习氛围、便利学生的校园生活条件表示认可与赞赏。
