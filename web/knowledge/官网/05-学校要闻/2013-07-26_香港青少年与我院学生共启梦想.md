# 香港青少年与我院学生共启梦想

7月24日，由虎门镇归国华侨联合会主办，东莞阳一光文化传播有限公司承办的2013年香港青少年“筑梦虎门”夏令营活动在我院设项开展。

在参观了我校校园之后，来自香港和虎门的多名青少年营员们与我院学生进行梦想交流，共同开启梦想。他们一起用文字表达梦想，制作梦想板、填写梦想卡，并把每个营员的梦想收集起来，写上祝福，一同筑梦。最后封存起来，相约多年后邮寄给未来的自己，让大家回首当初的那份梦想，那份祝福，那份珍贵的成长历程。

活动结束后，来自香港的营员表示，“今天我们带着爷爷奶奶们的愿望来虎门、来东莞寻根，在这儿跟大哥哥大姐姐们一起绘画了梦想，将来也要跟他们约定一同去完成我们共同的梦想。”

来自我院文传系的虎门籍学生欧迪鹏同学也表示，“香港的朋友们跟我们同根同源是一家人，今天跟他们一起‘筑梦’、畅想未来，我们彼此进行了多方位了解，希望以后能继续互相学习、多多交流，一同追梦。”

本次夏令营活动有效的加强了东莞与香港文化的交流，特别是我院学生与祖籍虎门、生在香港的青少年朋友们在交流互动中增进了友谊，感受了历史，有利于共同传承中华文化，共筑壮丽的“中国梦”。

此前，营员们还参观了东莞展览馆、天安数码城、松山湖知名企业等场所。
