# 教育部批准我院开设安全工程本科专业

2月22日，教育部在网上公布2009年度高等学校专业设置备案或审批结果，我院机电工程系申报的安全工程本科专业获得批准，专业代码为081002，学制四年，授予工学学士学位。至此，我院本科专业增至19个。

据申报材料称，安全工程专业主要是培养从事安全技术及工程、安全科学与研究、安全监察与管理、安全健康环境检测与监测等方面的高级工程技术人才。
