# 我院第二届院级教学成果获奖项目出炉

本报讯10月31日，我院第二届教学成果奖评选结果揭晓。通过申请、初审、评审等参评程序，经院长、书记办公会议批准，共有10个项目获奖。其中特等奖1个，一等奖4个，二等奖5个。《<思想道德修养与法律基础>知行一体的校本教学模式》获特等奖，项目完成人为安少华、朱志德、何鹏举、刘珍和陈海华。

据了解，特等奖项目和4个一等奖项目将推荐申报广东省第七届优秀教学成果。
