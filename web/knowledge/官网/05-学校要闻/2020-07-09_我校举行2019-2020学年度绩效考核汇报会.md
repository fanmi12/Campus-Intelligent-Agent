# 我校举行2019-2020学年度绩效考核汇报会

7月8日，我校2019-2020学年度绩效考核汇报会在行政楼323会议室举行。董事长代表陈超群，学校领导王卫平、章德胜、高香林、黄兢、周庆、刘玉侠及二级单位负责人参加了会议。

会上，22个二级单位负责人轮流就部门总体工作情况、疫情防控工作落实情况、个人成长价值实现、未来发展期望等方面进行了汇报，充分展示了各单位党政工作的亮点和特色，总结了存在的不足，提出未来工作展望与规划。随后，校领导、各单位负责人进行了公平、公正地交叉评分。

王卫平校长对22个单位的汇报给予了充分肯定。他指出，新学年是事关学校发展大计的关键之年，各单位要根据绩效汇报总结经验和不足，保稳定促发展，配合好学校大局和总体部署，凝聚合力扎实开展好本单位工作，为学校发展贡献力量和智慧。
