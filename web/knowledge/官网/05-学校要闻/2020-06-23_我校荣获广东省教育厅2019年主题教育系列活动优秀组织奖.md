# 我校荣获广东省教育厅2019年主题教育系列活动优秀组织奖

近日，广东省教育厅公布了2019年“新时代、新作为——立志·修身·博学·报国”主题教育系列活动结果，我校共有6件作品荣获二三等奖，我校再次获得优秀组织奖。

据悉，我校积极响应省教育厅举办的主题教育系列活动，坚持以赛促学、以赛促发展。每年开展校级选拔赛，提前遴选优秀作品并推荐参加省赛。此次成绩的取得，与我校坚持立德树人根本任务，不断探索有效机制加强和改进大学生思想政治教育密不可分。一直以来，我校坚持以社会主义核心价值观引领校园文化建设，创新理想信念教育内容形式和方法途径，教育引导学生坚定信仰、信念、信心，增强履行新时代使命的政治自觉、思想自觉、行动自觉，培养担当民族复兴大任的时代新人，取得了良好的成效。

一、“追寻红色印记、传承红色基因”爱国主义教育类获奖作品

二等奖（30名）

二、“走基层看变化、我与共和国共奋进”社会实践调查类获奖作品

三等奖（40名）

三、“诵中华经典、凝报国之志”经典诵读类获奖作品

三等奖（40名）

四、“文化喜相迎、和谐宿舍行”新媒体创意类获奖作品

三等奖（40名）

五、“唱响中国梦、百歌颂中华”红歌演唱类获奖作品

三等奖（47名）

六、“回顾建国历程、摄取时代印记”主题摄影类获奖作品

二等奖（30名）

七、组织优秀奖（29名）
