# 我院召开广东省第十届大学生运动会参赛动员大会

4月18日，广东省第十届大学生运动会城市学院代表团动员大会在行政楼112举行。院长王卫平、副院长高香林会同有关单位负责人以及代表团成员参加了会议。

体育教学部主任王艳云对广东省第十届大学生运动会及我院筹备情况作了介绍。

学院副院长、代表团团长高香林作了动员讲话。他指出，参加四年一届的广东省大学生运动会是展示我院体育工作成效的重要窗口，学院十分重视。希望各位教练员、运动员要积极备战、刻苦训练、发扬体育运动精神，无论是在集训冲刺阶段，还是在赛场上，都要保持高昂的斗志和永不言弃的精神，遵守比赛规则和大赛纪律，努力争取获得好成绩，展现出城院学子的良好作风和精神风貌。
