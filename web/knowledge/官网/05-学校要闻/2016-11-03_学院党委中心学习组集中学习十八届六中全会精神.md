# 学院党委中心学习组集中学习十八届六中全会精神

11月2日上午，党委书记王卫平主持学院党委中心学习组理论学习，集中学习十八届六中全会精神。

党委宣传部部长何鹏举同志重点对《中国共产党第十八届中央委员会第六次全体会议公报》作了解读，十八届六中全会突出了一个“核心”和一个“严”字，即以习近平同志为核心的党中央和全面从严治党的鲜明主题。同时，他对人民网的《为全面从严治党提供行动指南—深入学习贯彻习近平同志关于党的建设的重要论述》、新华社社论的《全面从严治党，走在时代前列—写在党的十八届六中全会召开之际》、人民日报社论的 《坚定不移推进全面从严治党》等理论文章进行了讲解。

在学习总结中，王卫平同志强调，要以此次党委中心学习组理论学习为起点，结合“两学一做”学习教育活动，带头深入学习和领会十八届六中全会精神，牢固树立政治意识、大局意识、核心意识、看齐意识，坚定不移地维护党中央权威和党中央集中统一领导。同时，他要求大家紧密团结在以习近平同志为核心的党中央周围，把“四个意识”转化为“在党爱党、在党言党、在党忧党、在党为党”的实际行动，创造性地做好本职工作，不断开创学院工作的新局面。
