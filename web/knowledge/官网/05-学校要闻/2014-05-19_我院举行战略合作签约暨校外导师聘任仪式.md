# 我院举行战略合作签约暨校外导师聘任仪式

5月16日，东莞理工学院城市学院战略合作签约暨校外导师聘任仪式在我院学术报告厅举行。东莞市第一人民法院、社会工作协会等战略合作方代表、校外导师与我院300多名师生代表见证了签约授牌仪式。

院督学陈丁堂教授致辞。他代表学院欢迎各位嘉宾与导师的到来，感谢有关协会、机关、企业对我院教学实践工作的大力支持，并希望在今后的办学道路上，双方能合作愉快。这次签约的外聘导师，为城市学院注入了一股新的教学力量。

据了解，我院此次与7个教学实习基地、4个战略合作伙伴签订战略合作协议，聘请了24名兼职教授和兼职副教授。校外导师中，有的是市一级法院的资深法官，市检察院的领导，有的是公司的经理，更多的是公司企事业单位的优秀科研骨干，他们都具有高级技术资格或职称，理论知识与实践经验丰富。

副院长高香林教授、计算机与信息科学系主任廉玉忠教授、金融与贸易系主任米双红教授、政法系主任刘杰教授分别为外聘导师、战略合作单位授牌及颁发聘书。

签约授牌仪式后，东莞市中级人民法院审判委员会委员李倩、东莞展能信息科技有限公司总经理黄维东、市中级法院党组成员政工科科长黄春梅作为校外导师代表在会上发言。他们表示，很高兴能受聘为城市学院的校外导师，成为战略合作、教学实习基地单位。我们将竭尽所能，提供一切资源与条件作好导师工作，并认真做好实习生接待安排工作，指导他们完成实习任务。同时，还要完成学校交办的科研、教学任务，为培养应用技术型人才做一点实实在在的工作。
