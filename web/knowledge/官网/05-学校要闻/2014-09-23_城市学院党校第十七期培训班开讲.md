# 城市学院党校第十七期培训班开讲

9月18日，城市学院党校第十七期培训班在7C304开讲，全院63名入党积极分子参加了本次培训班。

培训班的第一讲由党委副书记、党校校长章德胜主讲。他从“回顾历史、把握现在、实现途径、展望未来”四个方面为入党积极分子阐述“中国梦”、“我的梦”的内涵。章副书记指出，实现中华民族的伟大复兴是中华民族近代以来最伟大的梦想，习近平主席以喜闻乐见的表达方式——“中国梦”代表广大民众对梦想的追求，十分接地气。同时激励新一代青年人要做时代的先锋，彰显中国精神，激发中国力量，努力开创中国的未来。

党委书记王卫平结合其自身的人生经历，为积极分子们阐述延安精神的时代特征，他说，延安精神及其原生态精神包括：抗大精神、延安整风精神、张思德精神、南泥湾精神和白求恩精神等，加强党性修养的锻炼，培养高度的政治觉悟感。

组织科副科长李钰就发展党员的流程及有关材料的准备做了说明。
