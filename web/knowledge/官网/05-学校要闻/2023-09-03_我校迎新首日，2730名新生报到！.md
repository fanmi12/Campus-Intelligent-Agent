# 我校迎新首日，2730名新生报到！

金秋时节 逐梦启航。9月3日，初秋的东莞城市学院，迎来2023级专升本的新同学。学校校长陈明，党委书记章德胜、常务副校长方伟华等领导在相关部门负责人的陪同下，了解新生报到情况，到宿舍看望新生，对选择来到城院求学的各位学子表示热烈欢迎。

在迎新报到现场，校领导认真倾听了各二级学院和相关职能部门的汇报，了解新生报到情况和流程。校领导对迎新工作给予了高度的评价，并对师生员工及志愿者的付出和辛勤工作表示肯定。各学院和部门在组织和安排方面都做得非常出色，为新生提供了一个良好的报到环境和服务。

校领导与新生们亲切交流，询问他们的感受和期待，鼓励新生们要珍惜在城院求学的机会，希望新生们能够树立远大的理想和目标，不断进取，积极投入学习之中，努力实现自己的理想和目标。同时，他们也提醒新生们要关注自身的全面发展，注重培养综合素质，树立正确的价值观和人生观，希望新生们在城院度过充实而有意义的大学时光，成为有用之才，为社会的发展和进步作出贡献。

据了解，今年，我校共录取专升本和普通高考（含港澳台）学生10575人，创历史新高。9月3日，共有2730名新生完成报到！接下来几天还会有新生陆续报到注册，我校将继续做好迎新工作，让学生入校安心、顺心、暖心。学校将继续为每一位新生提供优质的教育资源和良好的学习环境，帮助他们不断成长，为党育人、为国育才，培养更多适应社会发展的高素质应用型人才。
