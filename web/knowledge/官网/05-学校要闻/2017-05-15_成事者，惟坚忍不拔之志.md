# 成事者，惟坚忍不拔之志

早上，天蒙蒙亮，舍友还沉浸在梦乡，一位瘦小的女生早早起来洗漱，匆匆啃完几块面包背起书包前往图书馆；

8点到12点，一天之中最好的学习阶段，应用文写作、“专八”单词以及政治练习，书翻了一遍又一遍；

13:30，静音的闹钟微微一震，揉揉惺忪的双眼，她翻开了一套试卷……

18:00，解决完晚餐后，回到熟悉的位置，她吃了几颗胃药，看着周围稀稀落落的座位，开始小声背起了政治的重点；

23:00，离图书馆的闭馆音乐播放已经过去接近两个小时，她看看表，背上包离开了座位。

这便是我院13级外语系谢怡婷同学考路上，备考的一天……

开始：被时间助推的考研起跑

与大多数带着些许好奇与迷茫的新生不同，谢怡婷大一时便有了考研的规划。

“因为高考失利，我不想就这样过完四年大学，因此在大一的时候决心考研，更多是出于一种不甘心。”她还表示，多读一点书有好处，不仅能够让自己开阔思维，也能提升一下思想的层次。家里知道她考研的想法后，也给予了很大的支持。

但是真正到了这个可能决定人生转折点的时候，一贯坚定的谢怡婷却出现了迟疑。去年3月份就应该准备的考研，到8月份还摇摆不定。时间急迫，让她不断提醒自己必须要下定决心，没有资格再迟疑不决了。也就是在那个时候，谢怡婷正式投入到枯燥、艰难的备考之中。

过程：凤凰涅槃，一段非凡的经历！

孟子曰：“天将降大任于斯人也，必先苦其心志，劳其筋骨，饿其体肤，空乏其身，行拂乱其所为。”可是，上天给予谢怡婷的，却是常人难以想象的考验。

2016年11月26日，正在备考的谢怡婷开始出现了胃部不适的现象。这位一心在备考的女生丝毫不以为意。到了12月3日，她开始出现胸闷难以忍受的状况，并出现吐血的现象。

两天后，情况开始变坏，谢怡婷高烧不退，于是她被紧急送往东华医院。而这次住院，却令她回想起来都觉后怕。检查结果显示谢怡婷患上了严重的胃溃疡，更加令人震惊的是，因为之前不停地呕血，导致她身上的血液量仅仅只有正常人的1/3！可谓是站在生命极度危险的边缘。而这时，离考研还不足1个月……

正当周围人都觉得谢怡婷只能放弃的时候，这位坚强的大四女生经过短暂的住院与调理，以超乎常人的毅力又继续投入到了备考之中。她甚至还强忍着已影响到正常行走的胃痛，一直坚持到了笔试。

回忆起笔试，她微微苦笑，似乎历历在目。那一天倾盆大雨，谢怡婷拖着虚弱的身子赶赴考试，在潮湿的空气与隐隐的胃痛中，她一步步“挪”上了位于五楼的考试教室。“第一科政治考试，我几乎调整了十几分钟才开始能动笔，心态上已经是开始崩了。”据她透露，考完第一科时，父母都劝她不如别考了，但是自己却坚持了下来。“我平常就是一个不服输、不认命的人，I don’t want to be a sayer but a doer。”

结果：放弃成果，重头再来

功夫不负有心人。现在，谢怡婷以344分的成绩收到了来自澳门科技大学的录取通知书。但是，不服输的谢怡婷的决定，又再一次让人出乎意料——为了追求更好的平台，她决定再一次投入考研，目标剑指香港的名牌大学！

对于这一决定，谢怡婷说出了原因：“因为我报考的专业是英语笔译，所以相比较之下香港地区的相关专业会比澳门更有优势。”

谢怡婷表示，因为备考对于身心的压力很大，加上自己身体也不好，所以过程一定会非常艰难。但是她认为：“即便再难，也很值得，因为这是追求自己的人生方向。考研牺牲了很多，例如自己的身体状况。但是也让我得到了很多，首先就是自我的全面改变，其次便是结识了很多一同奋斗的朋友。”

建议：自律、自觉和自主地去考研

在谢怡婷看来，考研与高考最大的不同就是考研的备考过程不会有一个较大的群体来和你一同努力，也没有老师的实时监督，所以考研也是考验一个人的自律、自觉和自主的要求很高。

为了保证备考的质量，作为过来人的谢怡婷认为，每一个考研的学子都需要做到以下几点：

一、下定决心后，不要轻易地改变；

二、最好在2月份就决定好自己的考研目标

（包括学校和专业）；

三、准备前期多看考研帮里的经验帖；

四、一定要做时间计划表，短期和长期的都要做，而且必须要有执行力；

五、一定要劳逸结合，注意休息之余也要坚持锻炼——身体是革命的本钱啊！
