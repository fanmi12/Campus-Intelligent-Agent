# 我院新校区一期B区工程建设全面启动

新春伊始，我院新校区一期B区工程建设全面启动。来自投资方——广东鸿发投资集团有限公司下属的3支建设中队、1100多名建设工人，再次在新校区掀起了工程建设高潮，整个施工建设区域呈现出一派忙碌而有序的景象。

据悉，本期工程总建筑面积10万多平方米，共11个建筑单体，分别为教学管理大楼、教师住宅、幼儿园、图书馆（2期）、学生食堂和学生宿舍。目前,各个单体建筑已全面进入施工阶段。预计在5月份之前，一期B区工程将全部实现主体封顶；最早的单体建筑将在7月份之前完工；到8月底，一期B区工程将全面竣工。

据了解，新校区一期B区工程在建筑设计方面，继续坚持 “以人为本”的设计原则和理念，以整体社会效益、经济效益与环境效益三者统一为基准点，打造优质生态环境，为师生塑造一个环境优美、舒适便捷、人文和谐的校园环境和生活体系。
