# 我院荣获2017年东莞地方高校会计知识邀请赛二等奖

5月17日，由东莞市会计学会主办、东莞职业技术学院承办的“2017年东莞地方高校会计知识邀请赛”落下帷幕。我院代表队在财经系何文琴、黄庆泉两位老师的指导下，以总分第二名的好成绩获得大赛二等奖。

此次，我院由黄玉当、徐日勤、吴嘉仪等三位来自2014级CPA创新班的同学组队参赛，他们经过系里的严格选拔代表学院参赛，并获得总分第二名的好成绩，再次展示了我院学生勤学苦练、力争一流的精神风貌和扎实的专业能力。

据悉，东莞地方高校会计知识邀请赛在东莞高校中影响广泛，共吸引了东莞理工学院、东莞理工学院城市学院、广东科技学院、东莞职业技术学院、广东创新科技职业学院等5个高校参赛。
