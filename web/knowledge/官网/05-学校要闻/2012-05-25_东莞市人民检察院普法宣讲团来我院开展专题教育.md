# 东莞市人民检察院普法宣讲团来我院开展专题教育

5月24日，东莞市人民检察院普法宣讲团廖清平检察官应思想政治理论课教学部的邀请，来我院为学生做“明法慎行?快乐成长”的专题讲座。

廖检察官以药家鑫案件为引入，向同学们介绍了法律的基本常识，分析当前大学生违法犯罪的特点、原因和类型，并对如何预防大学生犯罪提出建议。讲座通过列举大量真实的案例，加深了同学们对法律知识的了解。最后，廖检察官勉励同学们要养成遵规守纪的习惯，培养乐观心态，明法慎行，快乐成长。
