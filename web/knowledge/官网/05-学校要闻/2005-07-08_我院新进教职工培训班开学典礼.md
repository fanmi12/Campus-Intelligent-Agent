# 我院新进教职工培训班开学典礼

（新闻中心讯）7月8日上午，我院新进教职工培训班开学典礼在四号楼315课室举行。东莞市委副秘书长吴镇成，城市学院领导安少华、程发良、朱志德、林世俊与及我院50多位新进教职工出席本次的开学典礼。

整个开学典礼在一片和谐、融洽、活跃的气氛中进行。吴镇成副秘书长首先给广大新进教职工介绍了东莞目前的一些具体情况、相关的政策，以及现场回答了教职工的问题，同时他勉励广大新进教职工：“来到东莞工作，大家都是东莞人，应尽快溶入东莞社会。”

安少华院长给广大新进教职工介绍了东莞理工学院城市学院目前的具体情况，发展的现状、潜力，以及未来的发展方向。同时他结合了东莞的情况与城市学院的独特条件，希望广大教职工能抓住机遇，努力工作，服务东莞。

林世俊副院长给大家介绍了教师岗前培训分组业务实训的具体组别、各组组长以及各组组员。
