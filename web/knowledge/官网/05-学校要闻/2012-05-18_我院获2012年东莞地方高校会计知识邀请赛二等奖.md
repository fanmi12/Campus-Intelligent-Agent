# 我院获2012年东莞地方高校会计知识邀请赛二等奖

5月16日，2012年东莞地方高校会计知识邀请赛在广东科技学院拉开帷幕。我院财经系魏鹏辉、张志伟、陈泽萍和邱智敏四位同学组成的城院代表队应邀参赛。

参加此次比赛的高校还有东莞理工学院、东莞职业技术学院、广东创新科技职业学院和广东科技学院。比赛分为“必答题”、“计算技能”、“60秒连答”、“点钞”、“抢答题”、“风险题”和“有奖竞猜”环节。经过激烈的争夺，广东科技学院获一等奖，城市学院与东莞理工学院分获二等奖，东莞职业技术学院与广东创新科技职业学院同获三等奖。
