# 我院召开2014年暑期大学生“三下乡”社会实践活动总结表彰大会

11月13日，院团委在学术报告厅召开2014年暑期“三下乡”社会实践活动表彰大会，表彰在暑期“三下乡”社会实践中表现突出的先进集体和先进个人。

会上首先播放了五支“优秀团队”的活动视频材料，“优秀团队”代表周连兴同学和吴瑜同学分别向嘉宾观众展示了暑期社会实践成果。

团委书记罗文芳宣读了团委关于暑期“三下乡”社会实践活动的表彰决定。经研究决定，李志成等872名同学获“社会实践活动积极分子”称号，陈文丽等5名老师获“社会实践活动优秀指导老师”称号，“东莞粤剧现状生存调查”实践小分队等5支团队获“社会实践活动优秀团队”称号。

党委委员、学生处处长杜鹏举讲话，对本次暑期“三下乡”社会实践活动取得的成绩表示祝贺，对今后的活动提出了三点希望和要求：一、发挥专业优势，组建专项队伍；二、学会推广宣传，推升实践效应；三、梳理实践成果，强化后续应用。

据悉，本年度暑期“三下乡”社会实践活动以“为祖国勤学修德·为实践明辨笃行”为主题，活动内容包括文艺演出、志愿服务、社会实践、下乡体验等四大方面，全院共收到48个申报项目，其中有27个项目通过立项，2103人参与统一立项的社会实践活动，其余1000多名同学参与系部、或班级、或当地镇街乡组织的社会实践活动。社会实践活动还与“展翅计划”相结合，为广大学生提供了更多的锻炼机会。
