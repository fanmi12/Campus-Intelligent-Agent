# 我院综合实力跻身国内独立学院百强

武书连“2013中国独立学院排行榜”排名显示，我院综合实力跻身国内独立学院百强院校行列，排名第57位，在广东省排名第7位。

武书连关于中国独立学院综合实力的排名，是中国管理研究院武书连主持研究的《2013中国独立学院评价》课题中的一项内容。

该课题还对全国独立学院教师创新能力、毕业生质量百强院校进行了排名。据悉，我院教师创新能力排名第27位，毕业生质量排名第60位。
