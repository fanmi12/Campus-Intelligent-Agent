# 首届感动城院十大故事揭晓

5月25日，大礼堂内座无虚席，掌声不断。城市学院首届“感动城院”十大故事颁奖晚会在这里隆重举行。

学生处处长章德胜、财经系主任高香林教授、就业指导办公室主任江小卫、院团委副书记杜鹏举等莅临晚会现场。

首届感动城院十大故事征集历时50多天，共收到来自8个系33份作品，评选出了13个候选故事在四号楼大厅进行公众投票。

首届感动城院十大故事颁奖晚会开始之前，首先播放了四川抗震救灾的DV短片，然后全场师生为5•12大地震中的遇难者默哀一分钟。

接着，晚会播放了十大故事的DV片，有讲述班集体温暖的《感动的心如此美丽》，有描述广播台36位成员点滴感动《The moment》，有歌颂志愿者默默无闻的《“绿色”真爱，传递无痕》，还有描写同学坚强品质的《她，傻得可爱》和有记述宿管员的《和蔼可亲的宿管》等，这十个故事主题各不相同，但却真实感人。这一个个发生在我们身边的真情故事，传递给我们一份别样的感动。感动城院十大故事组委会分别授予了故事的作者颁奖词和“首届感动城院十大故事”的奖牌。

最后，晚会在《让世界充满爱》的歌声中结束。

此次活动还受到东莞阳光网的大力支持。
