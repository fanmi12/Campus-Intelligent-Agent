# 省民办教育协会常务副会长张耀荣莅临我校调研指导

5月20日上午，广东省民办教育协会常务副会长张耀荣莅临我校考察指导，并在六楼会议室召开了座谈会。学校常务副校长方伟华，校长助理、学校办公室主任孔增强，品牌中心副主任叶云峰，发展规划与改革办公室主任助理姜海波以及学校法治办等相关人员参加了座谈会。

方伟华常务副校长代表我校向张耀荣常务副会长的到访表示欢迎，并介绍了学校的基本情况，依法办学、未来规划发展等方面所做的工作与构想。

张耀荣常务副会长认为我校从独立学院转设为民办本科院校以来主动适应教育改革发展趋势，扎实开展依法治校工作，取得了一定的成绩。他指出民办院校办学水平的提高是一个长期的过程，需要长时间的摸索与积淀。现代大学的治理需要制度来规范发展，通过依法治校，为全面提升办学水平和突出办学特色提供制度性保障。希望我校进一步创新人才培养模式，加大与地方产业发展融合力度，充分发挥优势，彰显特色，为广东教育事业的发展作出更大贡献。

座谈会前，张耀荣常务副会长出席了在我校举行的第十一届全国大学生数字媒体科技作品及创意竞赛（广东省赛区）启动仪式，并参观了学校沙盘。
