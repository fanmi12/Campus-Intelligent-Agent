# 《十全十美》栏目组与学生畅谈“品牌东莞”

2月21日，东莞广播电视台《十全十美》栏目走进城市学院学术报告厅，企业家、专家与学生共同畅谈“品牌东莞”。

据悉，《品牌东莞》节目希望通过与高校合作，把有代表性的企业家、专家及学者请到高校来，分析经济社会中的热点问题或新鲜事物，共同探讨如何打造“品牌东莞”，推进我市经济社会双转型。这次东莞广播电视台与我院合作录制了两期节目。内容分别是陈饰装饰设计这个新兴行业的企业代表、专家与我院艺术设计专业的学生进行对话，中山大学岭南学院财政税务系主任林江教授与东莞正太实业投资有限公司总经理黄海涛就目前房地产的现状及发展态势等问题进行交流探讨，同学们也就自己感兴趣的问题进行了提问。

“参与公共话题探讨能激发学习兴趣”

据节目编导介绍，他们选择与我院合作，一方面是由节目所走的高端路线决定的，另一方面是希望在校的大学生通过对节目的参与，能对自己将来可能从事行业的现状与需要有更深入的了解。该栏目将与我院有较长时间的合作，录制好的节目于每星期一晚上九点半在东莞广播电视台公共频道播出。

艺术设计专业07级学生李嘉敏同学说：“虽然是学艺术设计的，但之前并不知道自己以后能做什么，今天听了企业家的创业经历后，深受鼓舞，真的觉得自己要利用好学校的资源去学习，不能浪费这几年的时间。”对于学生参加这样的节目录制，林江教授认为“非常好”，能让学生对公共话题有更实际的了解，通过对公共话题的探讨，也更能激发同学们的学习兴趣。

“学院要在应用型与研究型间取得平衡”

林江教授同时也谈到了城院的定位问题，他表示，作为独立学位，城院既不同于高职院校，专业性、针对性很强，也不同于综合性的研究型大学，因此需要在应用型与研究型之间取得平衡。此外，学院可以考虑借助外力进一步提高教学质量，如选送教师外出学习，不一定就是要进修，也可以是对授课方式的交流学习等。也可以多请专家学者来就一些研究性、现实性的问题给学生作学术讲座，帮助扩大知识面，增加理性认识。

“学生要参加社会实践，更要学好基础知识”

林教授不但学术做得好，而且有很丰富的实践经验，1988—1997年还曾被借调到香港招商局集团工作。在谈到学习与实践的问题时，林教授说：“大学生需要参加社会实践，但更应该把基础知识学好”。他认为，四年的本科学习时间其实是很短暂的，学生的思想成熟度还不是很高，需要在学校里把基础的知识与理论学好、学扎实，这样才能对以后的实践有更好的指导作用。学院应该有计划地、科学地组织学生参与实践，避免实践的盲目性。
