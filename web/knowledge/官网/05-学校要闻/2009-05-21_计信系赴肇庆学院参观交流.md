# 计信系赴肇庆学院参观交流

应肇庆学院计算机与软件学院令锋院长的邀请，5月15日，计算机与信息科学系主任牛熠博士率软件工程教研室与电子信息工程教研室教师一行16人，赴肇庆学院计算机与软件学院参观交流，受到该院领导的热情接待。

座谈会上，宾主双方就专业培养方案、实践环节的落实、行政办公与资料档案管理、特色教育以及课程建设等方面进行了深入的交流和探讨。会后，令锋院长陪同我院教师，参观校园、实验室、资料室和校史馆。
