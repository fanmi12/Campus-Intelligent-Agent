# 学院召开2012年就业工作会议

5月31日，学院在315会议室召开2012年就业工作会议。院长杨敏林、党委副书记朱冰、章德胜，副院长高香林出席会议。各系（部）总支书记、副书记及就业指导工作人员与会。

会议由章德胜副书记主持。

会上，院招生与就业指导办公室主任江小卫老师通报了我院2011届毕业生就业的有关数据，汇报2011-2012年就业情况，对2012届毕业生就业工作提出总体要求。据悉，获得“2011年就业工作先进单位”的三个系（部）是：财经系、文传系和高职部。三个单位分别，介绍了就业工作开展情况及工作经验。据了解，我院2012届毕业生就业率（包括签约就业和意向就业）已达到85%以上。

杨敏林院长在讲话中高度肯定了我院的就业工作。他指出，我院的就业工作管理架构完善，体制健全；工作管理规范、高效；系（部）的就业工作各具特色，就业活动丰富多彩，在学院领导高度重视和坚强领导下，在全体就业指导人员的共同努力下，取得了令人满意的成绩。杨院长要求，一、在保持高就业率的同时，要进一步提高就业质量和就业满意度。二、各系（部）的领导要牵头，全员参与，强化目标，落实责任，切实抓好毕业生就业工作。三、要加强毕业生思想教育工作，关注毕业生特殊群体，维护校园的和谐、安全和稳定。四、做好2012届毕业生教育和离校工作，全力提供更优质的服务，使毕业生文明离校。

会后，学生处与各系（部）签订了《城市学院2012年毕业生就业工作目标责任书》。
