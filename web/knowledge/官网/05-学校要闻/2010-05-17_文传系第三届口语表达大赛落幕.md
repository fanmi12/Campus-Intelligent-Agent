# 文传系第三届口语表达大赛落幕

“道不辩不明，理不辩不清，抓住对方辫子，成就我方辩才。”5月14日晚，文学与传媒系第三届口语表达大赛本科组决赛在学术报告厅激烈开赛。

口语大赛首先进行的是表演赛，参赛人员分别来自于文传系不同的年级和专业。

2009年11月上映的灾难片《2012》曾一度走红，影片讲述的内容是2012年人类遭受着毁灭性的灾难。那么，2012年世界是否真的毁灭呢？就这一问题，表演赛的辩手们展开了激烈的争辩。在第三环节的攻辩小结中，正方三辩刘琛琛与反方二辩苗磊的争辩，唇枪舌剑，难分秋色,二人均获得“最佳辩手”称号。比赛结果是正方以85.60分战胜反方的84.20分。

2010年，这是一个网络文明极度发达的年代。在网络世界里，越来越多的网络用语正应运而生，并被广大网民接受。网络用语的产生和使用，是否有利于当今社会的发展呢？这是本科组决赛的辩题。正方是来自08高级文秘班的辩手，反方是来自07新闻传播班的辩手。在群众盘问阶段，原表演赛正方最佳辩手刘琛琛以及反方最佳应变辩手朱梦雯纷纷加入，使赛场一度沸腾。最终，正方以85.8分战胜反方83.8分。

文传系党总支书记孟颖对全场作出了细致、深入的点评，既赞扬他们的优点，也指出他们各自的不足并予以纠正。她说：“辩论是整体的合作，要通过辩论学到一些东西。”
