# 程发良副院长深入政法系调研实践实习基地建设工作

程副院长视察社会工作实践实习基地5月17日，学术副院长程发良教授视察政法系工作，听取政法系主任刘杰教授关于社会工作本科专业申报工作的情况汇报。该系社会工作教研室主任周巍老师，也向程副院长汇报了社会工作教研室建设的情况。听完工作汇报后，程副院长还来到政法系学生实践实习基地东莞市普惠社会工作服务中心调研。

在调研中，程副院长与在“中心”参观的东莞市司法局副局长吴敏、中堂镇党委委员郭陈明一行，就社会工作专业学生实习基地的建设进行了座谈。程副院长代表学院对实践实习基地的建立表示祝贺，对于各级领导的到来表示欢迎，他向客人介绍了城市学院的基本情况、发展成就和今后的工作构想。程副院长说，办好社会工作专业，加强社会工作专业学生实践实习基地的建设，是提高教师教学科研能力、提高学生实践动手能力的一项重要举措。我们将以此为平台，进一步做好服务东莞的工作，打造学院的品牌。

吴敏副局长感谢学院这些年为东莞做出的杰出贡献。他表示，将与学院精诚合作，共同建设好社会工作专业和普惠社会工作服务中心。
