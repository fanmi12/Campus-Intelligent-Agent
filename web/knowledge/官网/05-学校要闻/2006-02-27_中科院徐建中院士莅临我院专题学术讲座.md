# 中科院徐建中院士莅临我院专题学术讲座

本月25日上午，东莞理工学院城市学院大礼堂座无虚席，气氛活跃。中国科学院徐建中院士“关于我国能源发展战略的思考”学术报告会在这里举行。东莞理工学院城市学院和成教学院的领导、教职工及1000多名学生聆听了徐院士的精彩讲学。

在热烈的掌声中，徐院士就世界能源形势、能源在我国经济社会发展中的战略地位和存在的问题、节能和科学用能、可再生能源的开发利用等问题进行了详细全面的分析和介绍。徐院士强调指出，节能为本，多元发展，环境友好，保障安全是我国中长期能源发展战略科学规划的主旨，节能不仅仅是一种技术手段，更是一种观念和意识，是一种不可回避的战略选择，我国的能源利用必须坚持走可持续发展的科学道路。

专题报告之后，徐院士热情地回答了师生们提出的问题，并接受东莞电视台记者的采访。

东莞理工学院党委委员、副院长、城市学院院长安少华教授主持会议，他代表城市学院对徐院士来我院讲学表示热烈欢迎和衷心感谢。他说，徐院士的报告内容翔实，论理透彻，为我们带来了国内外最新的科学技术信息和科技理念，使我们大开眼界，深受启发。

徐建中院士在城市学院的讲学是“科学与中国”院士专家巡讲团东莞报告会系列活动之一。这次科普活动是由中科院、中宣部、教育部、科技部、中国工程院、中国科协主办，东莞理工学院、东莞市科技局和市科协承办的。
