# 第三届心理情景剧精彩开演，艺术系《心声》惊艳全场

章德胜处长为“优秀心理工作者”颁发证书

城环系《堕落的天使》剧照

艺术系《心声》剧照5月16日，城市学院第三届心理情景剧大赛在大礼堂精彩开演。院党委副书记朱冰、学生处处长章德胜等观看了演出。来自各系部的10支参赛队伍，以“阳光心灵，让心灵敞开一扇窗”为主题，精心编排了各具特色的心理情景剧。各参赛队伍纷纷使出“浑身解数”，充分展现自己。其中，艺术系以“大学生的攀比心理”为主题的心理剧《心声》惊艳全场，演员张碧斯等同学以出色的演技、惟妙惟肖的人物造型和真挚的情感，折服了评委与观众，以93.7的高分赢得比赛冠军。管理系的《红与黑之就业》、机电系的《大学生活》获得二等奖。赛前，大会为获得2010--2011学年度“优秀心理工作者”和“优秀心理委员”的师生颁发了证书。
