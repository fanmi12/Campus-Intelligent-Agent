# 我校教师参加中英高校新媒体产业高峰论坛

11月12日，由中山大学传播与设计学院和英国大使馆文化教育处联合举办的“中英高校新媒体产业高峰论坛”在中山大学举行。

本次论坛，邀请了十多所英国著名高校的创意产业、新闻传播等专业负责人、知名学者以及国内学界、业界的嘉宾参加。会议围绕创意产业发展现状及趋势、创意产业政策比较、创意媒体及产业教育策略等学术问题进行了研讨。

文传系教师王宁、吴宇及何帅受邀参加了此次论坛，并就数字媒体艺术专业发展方向等问题与参加论坛的东莞市委宣传部叶泽驹副部长和浙江大学传媒与国际文华学院副院长李杰教授进行了请教商讨。
