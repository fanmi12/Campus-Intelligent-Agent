# 学院今起考评基层党建量化工作

5月5日,学院党委开始对各基层党组织进行工作量化考评。

此次考评将按照《东莞理工学院城市学院基层党组织工作量化考评暂行办法》中规定的考评内容进行考评，主要是考评一年来各基层党组织开展工作的情况，重点是基础性、程序性和常规性的工作。考评项目包括班子建设、党员学习教育、发展党员工作、日常管理工作、党员活动室建设、党章学习小组建设等情况。整个考评过程分为自评、互评、审核、审批四个步骤。

学院党委高度重视此次考评工作。今年2月份，学院下发了《关于开展对各基层党组织工作量化考评预检的通知》，并对各总支（直属支部）进行了一次预检，对预检中发现的问题提出了建议，要求予以整改和充实。5月4日，学院党委书记朱志德副研究员主持召开了考评预备会议。

据悉，考评工作将于5月25日前结束，对在考评中取得优异成绩的单位，学院党委将在“七·一”表彰大会上予以通报表彰与奖励。
