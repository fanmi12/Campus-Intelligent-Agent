# 安少华院长到革命老区扶贫调研

7月11—14日，院长安少华教授一行四人，在四川省大巴山区巴中市通江县开展教育扶贫调研工作。

通江是当年红四方面军建立的川陕鄂革命根据地苏维政权政府所在地。红四方面军在这里曾一度发展到十万人，建立了有几百万人口的根据地，为红军顺利完成长征做出了巨大贡献。通江的自然资源十分丰富，但由于山区交通不便，制约了经济、教育和文化的发展，老百姓收入相对较低，子女考上了大学，有的因交不起学费而无法上学。安院长一行受到当地领导和群众的热情欢迎。
