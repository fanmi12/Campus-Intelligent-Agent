# 东莞市神星电脑科技有限公司捐赠我院卫星教室设备

，我院在315会议室举行签约仪式，接受东莞市神星电脑科技有限公司捐赠卫星教室的设备。城市学院学术副院长程发良教授，东莞市神星电脑科技有限公司翟少强副总经理，分别代表双方在合同上签字。

捐赠仪式由城市学院院办公室王玉主任主持，出席的嘉宾有东莞理工学院副院长、东莞理工学院城市学院院长安少华教授、城市学院学术副院长程发良教授、城市学院计算机与信息科学系主任牛熠副教授、东莞市神星电脑科技有限公司翟少强副总经理、东莞市神星电脑科技有限公司邹有能总工程师以及有关老师。

神星电脑科技有限公司是新东方IT职业技术教育的授权单位，教育部考试中心NIT-PRO培训基地。我院从培养应用型人才加强学生动手能力的需求出发，从2006年9月份开始与神星电脑科技有限公司对05级软件3班的50名学生进行课程置换，按照软件企业对人才的实际需求进行培养，已取得了良好的效果。为了进一步加强合作，提高课程置换的教学效果，在双方领导的亲自关怀下，经多次洽谈，达成了共建卫星教室的协议，按照该协议，神星电脑为我院捐40台电脑设备，并无偿提供卫星电视接收设备和新东方NIT-PRO课程的卫星电视频道节目。

据悉，我院是东莞第一家拥有卫星教学教室的单位。安少华院长等在仪式后与来宾亲切交流，安院长要求计算机与信息科学系和神星电脑科技有限公司进一步努力，在东莞发展卫星教育教学项目，发挥各自优势，实现学校、企业、社会、受教育者多赢。
