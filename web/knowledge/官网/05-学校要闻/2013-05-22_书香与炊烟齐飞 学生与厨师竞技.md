# 书香与炊烟齐飞  学生与厨师竞技

5月17日，后勤服务公司饮食服务中心主办的荔香园“优质服务月”之烹饪大赛在我院饭堂四楼火热开赛。

本次大赛共设置切配、烹饪和面点制作三个比赛环节，30位厨师和6名学生参加了比赛。

切配竞赛有15位选手参赛，比赛内容包括肉类切丝、土豆切丝、胡萝卜切丝和肾球花刀，要求选手在15分钟内完成作品，切配作品摆放在一个大圆桌上供评委观摩打分。

相对于切配来说，烹饪这一项技能则要复杂得多。11位参赛厨师被分为4个小组，每个小组要制作两道成品菜。评委从色、香、味、形、装盘、卫生以及营养和创新等六个方面进行评分。

面点制作是学生选手比赛，包饺子和装盘摆盘的设计。一等奖由政法系的伍晓红同学获得，二三名则分别由计信系谭家琪和艺术系王思强同学获得。

据了解，“优质服务月”是后勤饮食服务中心2013年特色活动之一，至今已举办两届了。活动内容有烹饪大赛、优秀窗口评比、员工篮球赛等。
