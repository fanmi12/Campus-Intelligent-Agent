# 我院举行大学生思想政治教育研讨暨职业生涯规划课集体备课会

2月27日下午，招生就业处在新落成的招聘大厅举行大学生思想政治教育研讨暨职业生涯规划集体备课会。王卫平院长、章德胜副书记、高香林副院长，教务处、学生处、招生就业处等部门负责人，以及各院系（部）负责学生工作的书记、副书记和《大学生职业生涯规划》课老师参加了本次备课会。

这次集体备课旨在打造一个符合我院实际、科学、有效、与时俱进的大学生思政大课堂。与会人员结合我院新版人才培养方案和最新调整的《大学生职业生涯规划》，对课程体系、课程内容、教学方法、作业考核进行了研讨和重新疏理，以进一步推动《大学生职业生涯规划》课程教学和科研工作。

章德胜副书记肯定了招生就业处为学生搭建就业服务平台所做的努力，并鼓励每一位学生工作负责人、辅导员勇于走上讲台，为学生职业规划和就业进行指导，释疑解惑，推动我院思政教育迈上新台阶。

招生就业处孔增强处长主持会议。
