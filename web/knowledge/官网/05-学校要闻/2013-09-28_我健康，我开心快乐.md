# 我健康，我开心快乐

10年来，我院心理健康教育一直遵循“真诚、保密、用心服务学生”的原则，以“促进学生内在精神的成长与完善，提高助人与自助能力”为工作目标，积极开展学生心理健康教育与咨询工作，取得明显成效。具体表现为：工作机制健全，学生心理健康，行为举止文明，学习风气浓郁，学生中从未发生自杀、自伤恶性案件。

建立工作机制，心理健康教育常抓不懈

建立一支专兼职心理健康教育工作者队伍，是做好学生心理健康教育工作的前提条件。学生处配有3名专职心理辅导教师，其中2人是国家二级心理咨询师资历，1人是国家三级心理咨询师。全院50多名专职辅导员均有硕士研究生学历，其中大部分有心理学的学习背景。自2011年至今，学院先后选送10多名系部辅导员参加国家咨询师培训班学习。通过培训，已有12人获得国家三级以上咨询师资格教证书，成为专职的心理咨询师，另有5人正在参加国家三级咨询员的培训。

从2009年开始，各个班级设立了一名心理委员，各系部指定一名辅导员负责心理健康教育工作。目前，全院已建立城市学院学生心理工作委员会、城市学院心理工作者协会、班级心理委员三支队伍，共有500多名心理健康教育学生骨干，定期召开党总支副书记、辅导员会议，分析思想动态，部署下阶段工作任务。他们活跃在各自工作岗位上，有效开展心理健康教育工作，被同学们称赞为“心灵使者”，学习的指导者和引路人。

我院非常重视学生心理健康教育工作，从经费、场地、人员等方面给予保障。城市学院心理健康教育与咨询中心有5间独立的办公室，分别为咨询室、团体辅导室、办公室。“咨询中心”设在学生活动中心二楼，各办公室布置得温馨浪漫，给人以家的感觉。学生反映，在这里有非常多的心理教育报刊杂志，可以敞开心扉与专业老师进行心灵的交流。

立足“四早”，争取教育工作的主动权

在开展学生心理健康教育工作中，坚持早介入、早预防、早教育、早干预的工作方针，及时发现心理苗头，取得事半功倍的效果。

每年10月份，“心理中心”对新生开展一次心理普查工作，了解他们的心理健康状况，建立心理档案，并结合面谈查出来的心理问题开展针对性的心理咨询与教育活动。各系部班级心理委员和心理辅导员向“心理中心”“一月一汇报”，及时反映所在系部学生的心理动态，定期做好排查工作。“心理中心”还与广州三甲医院、东莞三甲医院等医院开展合作，共同维护处于心理危机状态学生的心理健康，为有心理疾病、心理危机的学生开设绿色通道。开展多样化的心理健康教育与宣传活动，如定期开设心理讲座，举办“525”心理健康活动月，运用自办的心理报《心雨》和各种展板等宣传工具，对学生进行预防性教育。建立网上沟通交流平台、QQ群、微博，让学生发表意见宣泄情绪，提供信息。

今年8月31日晚上，我院发生了一起因情感纠葛引起的学生伤害事件。事件发生后，心理健康教育与咨询中心专职教师陈浩、王彦娜立即赶赴事发现场，对目击者进行心理干预。9月4日，健康教育与咨询中心主任余琼老师又对事件的目击者、好友和室友，以及相邻宿舍的女同学进行了团体辅导，让相关同学得到了情绪宣泄。9月5日，心理咨询中心与相关系部在该班召开了主题班会。会后，余琼老师要求全班同学每人写一句祝福语送给受伤同学，愿她早日康复。由于及时开展了教育工作，伤者及其所在班级的同学情绪稳定、冷静理智。

用心服务，以真情打开学生的心扉

心理教育工作者秉承“真诚、保密、用心服务学生”的工作原则，动之以情，为同学们提供了6个方面的服务工作：心理咨询。一是面谈咨询：心理咨询师针对同学们在学习、人际交往、情感、择业、适应等方面的问题，提供面对面的咨询服务，帮助他们更好地认识自我和实现自我，获得重新认识问题和解决问题的能力。面谈咨询有时是一对一的咨询，有时是几对一的咨询。二是团体辅导：针对某一具有同性质的团体，如人际关系的问题或情感问题等，运用适当的辅导策略与方法，通过团体成员间的互动，调整和改善相关问题，端正学习态度与行为处事的方式，增强适应能力。据统计，每年接访近 100人次以上。

心理测试。为需要了解自身心态的同学，提供相应的心理测试。每年10月的中下旬，“心理中心”对全院的新生进行一次心理测试，测试结果存入学生心理档案。

开设心理健康教育必修课。我院自2012年开始成立了心理教研室，为大一新生开设《大学生心理健康教育》必修课程，共16个学时。

心理讲座。根据学生需求，“心理中心”分别在院、系范围内有针对性地开展《人际关系心理学》、《大学生的情绪管理》等30多个主题的心理讲座。定期举办学生工作坊，就一些重大的学生工作问题进行理论探讨，及时分析思想动态，探讨应对措施。

心理健康活动月。每年4,5月份，“中心”开展全院性的心理健康宣传教育月活动，期间举行的活动有经典心理电影展播、专家系列讲座、现场测试与咨询、心理情景剧大赛、心理知识大赛等内容。

心理委员培训。“心理中心”定期为心理委员进行业务培训，对考核优秀的心理委员给予表彰。

大二学生刘同学害怕在公共场所说话，一说话就紧张，后来他又担心紧张会影响自己在同学心中的形象，因而背上了思想包袱。咨询师余琼通过咨询，了解到这位同学的表达能力没有问题，只是表达的状态不好。于是，她顺着刘同学所述的“紧张”问题，探测他背后的未知世界。原来小刘很在乎别人的眼光，怕自我的表现不好而影响他人对自己的评价，因为害怕就更加紧张，紧张了就表达不好。后来，余老师更换了一个场景，让小刘参加一次公共活动，并作为旁观者评价一位表达不够流畅的同学。小刘将心比心，认为那个同学尽力了，没有什么不对的地方，多练几次就会更好一些。即使表达不好，也是过眼云烟，并不会影响自己和他人的关系，过去我的那种心态都是由于自己过于敏感，对负面影响看得太重。通过几次咨询，小刘的“紧张”问题基本得到解决。后来他告诉余老师，在最近一次的班会上，他作为班干发言感觉比较轻松，讲话也流畅多了。
