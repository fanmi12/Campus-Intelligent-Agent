# 院工会开展庆“三八”有奖趣味活动

3月6日，为了展现学院女教职工的风采，以健康的身体素质和心理素质投身于工作中，活跃校园文化氛围，学院工会在教工宿舍前篮球场组织了以“迎阳春三月，展巾帼风采”为主题的庆 “三八”妇女节趣味活动。该活动共设10个游戏环节，吸引了200多名教工参加。

教工们表示，这次活动工会用心组织，老师们玩的很愉快。
