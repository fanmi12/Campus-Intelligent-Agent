# 第三届东莞金牌理财师评选大赛在我院启动

5月31日下午，由我院协办的第三届东莞金牌理财师评选大赛启动仪式暨高峰论坛在学术报告厅举行。东莞市银行业协会秘书长黄伟荣、保险行业协会副秘书长胡旭魁、证券机构协会副秘书长莫于蓝、信用与担保业协会秘书长何秀芬、互联网金融机构协会秘书长杨希、南方都市报东莞分公司总经理朱大尉等嘉宾及我院金贸系龙卫洋教授、郭忠林副教授出席了本次论坛。

上届东莞金牌理财师评选大赛个人组冠军得主李云霞在会上发言。国家高级理财规划师郭献和作了“当前经济形势下的资产配置”的主题演讲。

据悉，本次大赛是由东莞市银行业协会、东莞市保险行业协会、东莞市证券期货业协会、东莞市信用与担保业协会、东莞市互联网金融协会主办，南方都市报承办。作为协办单位，我院金贸系、财经系的100余名同学和东莞市各行业协会300多人参加了启动仪式。
