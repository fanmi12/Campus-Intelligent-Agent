# 东莞市精神卫生中心副院长黎柱培来我校开展心理健康专题讲座

11月25日下午，由学生处、人事处主办的“抑郁障碍”健康讲座在行政楼112会议室举行。此次讲座是心理助人能力提升工作坊第4期暨青椒工作坊第18期。学校党委书记章德胜和学生处心理健康教育老师、辅导员、班主任等140余人参加了此次讲座。

东莞市精神卫生中心睡眠心理科学科带头人、市精神卫生中心副院长黎柱培应邀担任主讲嘉宾。他分别从抑郁障碍的表现形式、诊断标准等切入点深度解析抑郁障碍的成因，并结合自身丰富的临床工作经验，充分利用精神卫生理论研究、个案实践和权威研究数据重点就如何识别抑郁障碍做了专业的讲解，并介绍了抑郁障碍的治疗方法。

我校辅导员陈浩和邱少华老师分享了两例抑郁障碍个案，黎柱培副院长对个案进行了答疑和点评，并从精神卫生专业的角度给出指导意见。

学生处副处长罗文芳主持了讲座，认为讲座内容丰富，专业性强，有很强的针对性、指导性，对我校今后有效预防处理抑郁障碍具有重要启示和促进作用。

章德胜书记向黎柱培副院长颁发了聘书，聘请为我校临床心理督导师。
