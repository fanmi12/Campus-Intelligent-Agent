# 东莞市“环境卫生杯”演讲比赛总决赛在我院举行

5月29日，由市整治环境卫生工作小组主办、东莞理工学院城市学院协办的东莞市“提倡文明新风，建设美好家园”为主题的“环境卫生杯”演讲比赛总决赛在我院大礼堂隆重举行。市城市管理局朱旭根、陈旭坚、各镇区分管领导、负责人及环卫（绿化）工人近800人观看了比赛，我院文学与艺术系150余名学生也旁听了比赛。

进入决赛的18名选手普通话标准，选用材料感人，演讲热情讴歌了市委市政府关于整治环境卫生科学决策，真实反应了东莞市环境卫生工作的现状。选手们的精彩演说，获得阵阵掌声，将比赛一次又一次推向高潮。最后，经过激烈角逐，由来自望牛墩镇的选手陈晓以《那片绿，那条河》荣获第一名。

参加旁听演讲的同学表示，我们都是东莞人，应该感谢并尊重环卫工人的辛勤劳动，从自我做起，从小事做起，为东莞早日实现天蓝、水碧、山青、地绿、风清、云秀，更加和谐，更加宜居，更加繁荣而努力。

演讲比赛的评委由市委文明委副主任宋媛和我院教师担任，文学艺术系党总支书记孟颖老师担任主评委。比赛开始前，我院行政副院长张林博士热情接待了前来参加活动的朱旭根和陈旭坚副局长。
