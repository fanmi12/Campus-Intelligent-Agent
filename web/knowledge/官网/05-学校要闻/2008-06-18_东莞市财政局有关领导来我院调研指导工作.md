# 东莞市财政局有关领导来我院调研指导工作

6月12日，东莞市财政局教科文科负责人刘坚枝一行来我院调研指导工作，参观我院教学楼设施和校园建设。院领导安少华、朱冰、张林以及财务办负责人与财政局领导进行了工作座谈。

安院长向市局的同志介绍了学院的基本情况、以及教学楼维修改造工程的准备情况与面临的实际困难。

刘坚枝对我院各方面工作给予了充分的肯定，对以往取得的成绩与贡献表示赞赏，同时，对学院在发展中面临的困难和压力也给予了充分的理解。表示，在今后的工作中将继续关注城市学院，在力所能及的范围内提提供帮助、支持，共同为东莞的教育事业作出新的贡献。
