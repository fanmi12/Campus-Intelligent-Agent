# 东莞市委《舆情信息专报》刊发我院的调查报告

为构建和谐社区、科学分析和妥善解决小区物业管理中的问题与矛盾，受东莞市委宣传部的安排，由我院东莞社情研究中心周巍、何鹏举、何秀青三位老师及陈少芬、莫敏怡、吴慧珍等同学参加的“东莞市城区住宅小区物业管理现状调查”课题组，撰写的《东莞市城区住宅小区物业管理现状调查报告》被编辑进东莞市委《舆情信息专报》。

《舆情信息专报》由中共东莞市委宣传部舆情调研科整理编印,其内容主要是反映东莞的总体舆论情况及重大社会动态，专供市委常委、市人大主任、市政协主席及副市长传阅的决策参考材料。
