# 我院喜获3项教育部产学合作协同育人项目

8月11日，教育部高教司公布了2017年度（第一批）产学合作协同育人项目获批立项名单（教高司函〔2017〕37号），我院共有3项本科教学项目获得立项：赖忠孝教授主持的“基于深莞惠一体化的跨境电子商务创新创业教育改革”获批创新创业教育改革项目；鞠晓红讲师主持的“基于深莞惠一体化的跨境电子商务实践体系建设”获批实践条件建设项目；彭衡讲师和何勇亭讲师联合主持的“跨境电商实训教程”获批教学内容和课程体系改革项目。

产学合作协同育人项目是教育部为了促进产学合作协同育人，着力培养适应产业发展需要的应用型、复合型、创新型人才，通过协调相关企业提供专项资金支持高校开展专业综合改革和大学生创新创业训练计划而设立的。我院成功申报立项，不仅为金贸系电子商务专业应用型跨境电子商务人才培养提供了更高的平台，还将对学院进一步创新产学合作协同育人机制、探索多样化的产学研合作模式、强化校企合作协同育人功能、彰显人才培养特色产生促进作用。

附件1：2017年第一批产学合作协同育人项目立项名单（我院在第141页）
