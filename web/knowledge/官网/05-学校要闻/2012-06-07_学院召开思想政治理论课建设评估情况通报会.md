# 学院召开思想政治理论课建设评估情况通报会

“城市学院思政课建设是全省独立学院的标杆单位，与全省普通本科院校相比也不弱。”省评估专家组组长李辉教授引用省教育厅思政处处长袁本新博士上述评语，高度评价了我院思想政治理论课建设工作。

6月6日，学院在315会议室召开会议，听取省思想政治理论课评估专家组反馈评估意见。

评估专家中山大学社会科学教育学院副院长李辉教授，暨南大学社科部主任程京武教授，华南农业大学思政部副主任杨乃良教授，广东工业大学马克思主义基本原理研究所所长刘国建教授，广州大学社科部副主任罗明星教授，城市学院董事长麦照容，学院领导杨敏林、朱志德、朱冰、张林、陈丁堂、章德胜、高香林出席会议。

通报会由党委书记朱志德主持。

李辉教授代表专家组向学院反馈意见。他指出城市学院思政课建设的亮点是，早在2006年就独立设置了思政课的二级教学机构，在全国同类院校，甚至在全省高校中都是走在前面的。思政专项经费2007年就已列入学院预算，时间比较早。这两个核心指标充分说明城市学院领导政策水平高，对思想政治理论课建设的重视程度高。

李教授肯定了城市学院思政课教育教学理念的创新之处，具体表现在：一是遵循青年大学生思想形成变化的规律及思想政治教育的规律，做到了理论教育生活化、自我教育常态化，取得了良好的教学效果，学生满意率高达98%；二是重视思政课教师队伍的建设，所采用的青年教师培养方略行之有效。学院通过名师点化、以老带新、社会实践、学术陶冶、深造学习等具有立体感的措施培养青年教师，使他们凝神静气地从事教学科研工作，并取得了粤桂琼等五省区青年教师讲课比赛二等奖、广东省青年教师讲课比赛一等奖的好成绩。

李教授还凝练了城市学院思想政治理论课建设上的两大特色：一是探索建立起了知行一体的思政课教育教学模式，适应当今社会对大学生的期待和家长对子女成长成才的期待；二是在独立学院初步确立了思政课的学科意识，有一个完整的师资队伍建设的规划，打造出了省级精品课程和优质课程，在全省独立学院中是独一无二的。

关于今后思政课建设的意见和建议，李教授希望城市学院要加强高水平学科带头人的培养力度；体制转换以后，要继续加大对思想政治理论课建设的支持力度；进一步规范和完善思想政治理论课建设经费的使用；支持和鼓励教师多参加社会实践及社会考察。

院长杨敏林代表学院感谢专家组的指导。他说，专家们肯定成绩实事求是，分析问题中肯具体。专家们为城市学院思政课建设指明了今后努力的方向和工作的着力点，具有较强的针对性和可操作性。我院将遵循以评促建、以评促改、以评促管、评建结合、重在建设的工作原则，认真采纳和消化专家组的意见和建议，并根据专家们的要求尽快制定和提出确实可行的整改方案，努力建设一支高水平的师资队伍，进一步加强教学基础设施建设，努力提高课堂教学质量，凝练课程特色，以思想政治理论课建设为着力点，努力提高我院思想政治教育教学水平，增强我院综合实力，推动学院各项工作再上一个新台阶。

学院各部门负责人，各系部主任、党总支正副书记，思政部全体老师，各系部辅导员参加会议。

会议开始前，麦照容董事长在杨敏林院长和朱志德书记的陪同下，与专家组成员进行了座谈交流。
