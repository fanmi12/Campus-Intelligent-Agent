# 两家大型公司进校园招聘毕业生

4月21日，星球国际资讯（香港）有限公司、广州市电购会展览服务有限公司（东莞分公司）与计算机与信息科学系、高职部毕业生举行见面会，现场招聘大学生。

两家单位负责人认为，我院学生综合素质高，善于人际沟通，工作热情高，具有较强的创新能力和工作能力。

这次见面会是在院领导亲自谋划下举办成功的，教务处做了大量的前提准备工作。
