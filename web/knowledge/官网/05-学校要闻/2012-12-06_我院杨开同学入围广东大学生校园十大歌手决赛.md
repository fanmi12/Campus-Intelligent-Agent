# 我院杨开同学入围广东大学生校园十大歌手决赛

近日，“声动校园”广东大学生校园十大歌手大赛第三赛区在东莞理工学院开唱。我院09级音乐表演班杨开同学，倾情演唱的歌曲《春天的芭蕾》，以47.327的高分荣获业余组第一名，成功入围广东大学生校园十大歌手的决赛。据悉，杨开将于12月12日赴广州参加决赛。

据了解，第七届广东大学生校园文化艺术节设“与信仰对话——唱响时代主旋律”、“与文化交融——感受校园魅力”、“与艺术同行——炫出多彩青春”三大系列活动，包括“声动校园”广东大学生校园十大歌手大赛在内的11个比赛项目。
