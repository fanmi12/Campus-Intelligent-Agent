# 我院连续5年获得征兵工作先进单位

近日，从2015年征兵工作会议上获悉，我院获得2014年度“征兵工作先进单位”。这是2011年至今我院连续5年获此荣誉。

2014年，我院有近500名学生响应祖国号召报名应征，经过各项检查、审核，最后28名同学光荣入伍。

目前，我院2015年度征兵工作正在启动中，各系可组织有意向参军的学生先网上预报名，根据网站提示如实填写相关内容，网址：http://www.gfbzb.gov.cn/。
