# 2011年绩效考核民主测评结果出炉

2011年12月28、29日，学院先后召开教学系部目标管理绩效考核及行政、教辅部门民主测评大会。

会上，院、系、机关、教辅主要负责人总结述职一年的工作绩效。测评代表根据述职情况，认真审阅评议工作总结和各项指标，按工作绩效和服务的满意度进行无记名测评打分。近日，测评的结果在学院4号行政楼公示栏进行了公示。从测评结果反映，广大教职员工对学院领导和各系部、机关、教辅部门2011年的工作表示基本满意，评分均超过80分。

据悉，教学系部平均分为84.37分，其中财经系88.19分，文传系87.49分，金贸系87.01分名列前三，最低的得分80.45分。系部主任系列中，财经系主任高香林87.93分，金贸系主任米双红86.69分，文传系主任陈庆祝86.60分名列前三，最低为80.70分。10个行政、教辅部门测评中，前三名为院办88.81分，图书信息中心87.66分，实验中心87.18分，最低为80.60分。其主要负责人中，实验中心主任周梓荣为87.65分，图书信息中心主任陈伟87.51分，院办主任王玉86.83分，最低80分。院领导测评最高分为93.68分，最低分85.36分，平均分为87.94分。
