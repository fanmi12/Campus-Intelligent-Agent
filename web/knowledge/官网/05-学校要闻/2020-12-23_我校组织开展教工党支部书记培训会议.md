# 我校组织开展教工党支部书记培训会议

为进一步深入学习贯彻落实习近平新时代中国特色社会主义思想、党的十九届五中全会精神，不断增强“四个意识”，坚定“四个自信”，准确把握高校基层党建和思想政治工作面临的新形势、新任务、新要求，提高服务群众能力和履职本领，加强基层党组织建设，12月17日下午，我校在行政楼407会议室开展教工党支部书记培训。学校党委书记章德胜，各基层党组织教工支部书记和各机关党支部代表参加了培训会。会议由组织（统战）部部长卢淑芳主持。

会上，学校马克思主义学院吕海红教授作党的十九届五中全会精神专题辅导报告。报告围绕五中全会召开的国际背景、“十三五”的伟大成就、五中全会基本情况、“十四五”规划和2035年远景目标要点进行了讲解，为参会各党支部书记深刻理解把握党的十九届五中全会精神作了一次深入的辅导。

城建与环境学院教工党支部书记郭文显副教授在会上作了经验分享。指出了教工党支部书记如何通过“双学双服务”和党业互融工作实践，找准党建工作定位，提高工作能力和水平等方面，增强服务能力，提升服务水平，并举例如何以党建工作引领，以项目为抓手，实现党建与专业发展互利共赢。

卢淑芳部长在会上作了教工党支部的工作实务专题报告，从《中国共产党支部工作条例》的意义、内容与如何做好新时代高校教工党支部的工作为切入点，对《工作条例》进行了全面而深入的解读。她指出，面对当前党建工作形势，各教工党支部书记应认真落实党要管党、全面从严治党的要求，确保《工作条例》各项规定要求落到实处，从而全面提升党支部组织力，强化党支部政治功能，发挥党支部的战斗堡垒作用。

章德胜书记为培训班作了开班致辞，并作了总结讲话。章书记指出，培训班的成立，是切实提升教工党支部组织力、战斗力、创造力和凝聚力，充分发挥党支部的战斗堡垒作用的重要举措。希望各党支部书记能够贯彻落实十九届五中全会精神，学习优秀党建工作经验，进一步夯实我校的基层党建工作，开创我校党建工作新局面。
