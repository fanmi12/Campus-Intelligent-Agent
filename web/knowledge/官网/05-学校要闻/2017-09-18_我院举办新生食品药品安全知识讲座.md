# 我院举办新生食品药品安全知识讲座

9月16日晚，2017级新生食品药品安全知识讲座在综合馆举行。

东莞市食品药品监督管理局寮步分局张茜、苏健荣、钟佩超三位工作人员分别为同学们介绍了日常食品、保健食品、药品以及化妆品的基本知识和有关的注意事项。她们通过相关案例、真实视频、产品图片等生动地介绍了食品药品领域的安全知识，提醒同学们要拒绝虚假宣传，安全进食，合理用药。
