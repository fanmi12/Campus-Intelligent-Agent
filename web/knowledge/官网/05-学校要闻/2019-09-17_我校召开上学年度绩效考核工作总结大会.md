# 我校召开上学年度绩效考核工作总结大会

9月12日下午，上学年绩效考核工作总结大会暨新学年绩效考核工作布置会在行政楼212会议室召开。学校领导王卫平、章德胜、刘玉侠和二级单位党政负责人参加了会议。

人事处副处长张兰汇报了上学年绩效考核工作整体实施情况，分析了绩效考核改革后近两学年各项考核指标的实施效果。人事处副处长李海冬分析了绩效考核工作取得的成效和存在的问题，并对新学年的绩效考核工作作出了计划安排。

刘玉侠副校长指出，通过绩效考核进一步促进学校、各部门及个人的发展，是教职工获得应有的劳动价值的体现。希望各单位进一步完善绩效考核实施制度，加强绩效考核的导向性作用，充分发挥绩效考核的杠杆作用。

王卫平校长肯定了自2015年至今实施绩效考核改革取得的成绩，对绩效考核的成绩和问题进行总结分析，要求各单位总结经验，提出建设性意见，并按照新学年绩效考核工作的要求和部署，贯彻落实好各项绩效考核工作。
