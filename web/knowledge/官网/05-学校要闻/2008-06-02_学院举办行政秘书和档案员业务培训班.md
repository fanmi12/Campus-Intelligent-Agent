# 学院举办行政秘书和档案员业务培训班

5月30日，学院在4#315会议室举办了2008年度行政秘书和档案员业务培训班。市档案局副局长吴汉成及其业务指导科张斌、东莞理工学院档案室主任高单飞老师莅临培训班并进行档案业务现场指导。我院行政副院长张林博士、院办主任王玉、各系部负责人出席了培训班开班仪式。

张林副院长强调，秘书、档案员工作非常重要，希望大家继续重视档案工作，为学院迎评作好准备，吴汉成副局长表示，高校开办档案员培训班很有必要，这是对全市档案工作的支持。他希望档案员掌握档案工作理论，整理、管理好档案。

会议结束后，市档案局张斌同志与东莞理工学院高单飞主任进行了归档装订示范，指导兼职档案员填写编撰目录，解答了各类问题。

当天下午，院办秘书科科长黄隆顺讲授了公文写作基础知识。
