# 城院毕业生“集体简历”亮相人才招聘会

“欢迎了解我们学校的优秀毕业生，企业可以通过就业办对接到他们。”在昨日上午举行由市人力资源局承办的第五届东莞市校企合作洽谈会上，我院就业办凌继峰向每位来访企业的负责人派发一本《2014年毕业生信息》，这本精美的册子上印有260多位优秀毕业生的个人简历。凌继峰笑称，这是学院给优秀毕业生制作的“集体简历”，希望将他们打包推荐给优秀企业。

“我叫刘恒飞，计算机与信息科学系学生，曾获国家励志奖学金、全国大学生数学建模广东赛区三等奖、全国大学生电子设计竞赛省二等奖，担任过系团总支副书记……”这本用铜版纸全彩印刷，厚达100多页的画册上，除了对学校各专业的简介外，最让企业主们关注的，就是我院260多位优秀毕业生的简历，每段400多字的简介上都配有毕业生的生活照。

这些毕业生是我院从每个专业综合测评成绩前列者遴选出的，另外还有学生干部和一些拥有外语、音乐、体育等特长的学生。凌继峰说，院领导非常重视此次校企合作洽谈会，因此专门制作这样一本“集体简历”，印刷了近千册。“希望能让我们的学生走出去，被企业发现，同时也展示学校的风采。”

“孩子们都好优秀，他们都找到工作了么，我们怎么可以对接到他们吗？”现场一位模具厂主一边翻着册子一边询问工作人员。工作人员介绍说，可以通过学校就业办联系到具体的同学。
