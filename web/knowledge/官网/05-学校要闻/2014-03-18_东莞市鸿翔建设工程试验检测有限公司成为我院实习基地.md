# 东莞市鸿翔建设工程试验检测有限公司成为我院实习基地

3月13日，副院长高香林、教务处处长牛熠、城环系主任肖红飞等一行4人，前往企石镇为东莞市鸿翔建设工程试验检测有限公司实习基地挂牌。广东鸿高建设集团有限公司副总经理徐世亮，检测公司总经理方清华，总工程师蓝玉伟参加了挂牌仪式。

双方还对共建城市建设专题实验室达成了共识，认为共建的实验室在满足学校教学的需要的基础上，要继续探索开展对外服务，才有更大的发展空间。
