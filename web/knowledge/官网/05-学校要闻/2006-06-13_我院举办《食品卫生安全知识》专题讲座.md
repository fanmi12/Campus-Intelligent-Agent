# 我院举办《食品卫生安全知识》专题讲座

6月8日，学院在3号楼408#举办了《食品卫生安全知识讲座》，饮食中心的员工参加了这次讲座。“中心”管理人员理论联系实际，以广州中医药大学最近发生的食物中毒事件作为反面教材，给员工上了生动形象的一课。同时，他们还就如何加强食品卫生安全管理、规范操作程序等问题提出了指导性意见。员工们普遍反映，这样的讲座非常好，希望今后多举办类似的讲座。
