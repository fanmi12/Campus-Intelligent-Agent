# 我院举办寮步专场综合招聘会

12月6日下午，我院与寮步镇人力资源局、寮步青年企业家协会、寮步商会和寮步电子商务协会合作，在招聘大厅举办综合类专场招聘会，吸引了50家优秀企业参加。

寮步镇人力资源局局长尹汝锋和我院副院长黄兢亲临招聘会指导工作。

招聘会由财经系精心组织策划，来自松山湖、寮步等镇区的50家招聘企业为我院毕业生提供了近600个财经、管理、金贸、外语、机电、计信等系相关专业岗位。1200多名应届毕业生着正装、携带简历，充满自信地挑选自己心仪的岗位。

尹汝锋局长在与师生交流时表示，城市学院作为东莞地方高校，也是寮步镇唯一的一所大学，寮步政府非常关心和支持城市学院的发展，希望学院培养出更多的优秀人才服务东莞、服务寮步。黄兢副院长指出，招聘会旨在与地方政府和企事业单位建立资源共享平台，为地方企业输送优秀的毕业生，实现共赢。
