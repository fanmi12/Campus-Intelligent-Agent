# 章德胜副书记看望岗前培训的教师

7月27日，学院党委副书记章德胜赴广州华南师范大学，代表学院看望慰问我院参加广东省高校教师岗前培训的30多名教师。

章德胜副书记详细了解了参加培训教师的学习与生活情况，鼓励大家认真学习，顺利通过岗前培训考核，早日拿到高校教师资格证。

据悉，今年是我院连续第8次组织新教师参加岗前培训，八年来已有逾400名教职工接受了培训并顺利走上高校工作岗位。
