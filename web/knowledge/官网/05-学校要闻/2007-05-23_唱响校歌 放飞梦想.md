# 唱响校歌 放飞梦想

继校徽确定之后，校歌又在校园唱响。由城市学院文学与艺术系史德松副教授作词、黄英森教授作曲的《城市学院之歌》最近被拟定为城市学院校歌。

为提升我院的文化内涵，展现大学生精神风貌，弘扬学院办学理念，2005年11月，学院面向全社会公开征集校徽校歌，共收到校歌选送作品100多件。经过全院师生投票，广东省著名词作家、作曲家和音乐指挥家的评定，史德松作词、黄英森作曲的《城市学院之歌》被拟定为我院的校歌。经过多次演唱，师生普遍认为歌词优美简洁凝练，朴素自然，曲谱节奏明快，旋律感人，充分体现了城院学子奋发向上的精神风貌。

学院有关领导表示，该歌还存在不足之处，热忱欢迎音乐爱好者帮助修改，对提出修改意见并被采纳者予以奖励。

附:《城市学院之歌》
