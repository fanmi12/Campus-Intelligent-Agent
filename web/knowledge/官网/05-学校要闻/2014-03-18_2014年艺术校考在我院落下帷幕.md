# 2014年艺术校考在我院落下帷幕

为期两天的2014年普通高校艺术类专业校考于3月15日在我院综合馆落下帷幕。本次招考有音乐表演和舞蹈表演两个专业，音乐表演的考试科目有歌曲演唱、器乐演奏、视唱练耳等；舞蹈表演专业的考试科目有剧目、基本功、即兴表演、视唱练耳等。据了解，预计录取人数与去年持平。

据学生处孔增强副处长介绍，今年网上预报名人数达到800人次，其中音乐表演较为热门。实际参考人数为653人，其中舞蹈表演101人，器乐表演115人，声乐表演437人。

院长杨敏林，副院长高香林，党委副书记章德胜等领导视察了艺考现场，并对志愿者的服务工作和考风考纪表示肯定。

艺术系主任兼主考官向智星教授表示，今年的学生素质从整体上看比往年要好，都有一定的表演基础，基本上是经过比较专业的培训，其中80％的考生是冲着城院来的。

据悉，为严格考风考纪，实现公开、公正、公平，学校对每个考场均进行全程录像。本次校考受到东莞媒体记者热切关注，东莞电视台还作了专题新闻。
