# 著名词作家郑南来我院参观访问

7月21日，中国音乐文学学会副主席、中国音乐家协会词刊编委、歌曲《我爱五指山我爱万泉河》、《大地飞歌》、《请到天涯海角来》词作者郑南先生来我院参观访问，受到东莞理工学院副院长、城市学院院长安少华教授的热情接待。

学院党委书记朱志德，副院长程发良教授，有关部门负责人王玉、何鹏举、陈庆祝，校歌曲作者黄英森教授与郑南先生在405会议室，就城市学院校歌创作等问题进行了座谈与交流。

在座谈中，安院长说，希望歌词能体现校训“学而知不足”和“追求卓越，跨越发展”的办学指导思想，体现 “海纳百川，厚德务实”的东莞城市精神。安院长还饶有兴趣地向郑南先生介绍了东莞独特的地域风情和民间传说。

郑南先生认为，校歌是一所学校的灵魂所在，是全体师生员工的共同心声，具有鼓舞士气、催人奋进、凝聚人心的作用。创作城市学院校歌，充分说明院领导非常重视校园文化。郑先生表示，愿意填写一首歌词供学院领导参考。
