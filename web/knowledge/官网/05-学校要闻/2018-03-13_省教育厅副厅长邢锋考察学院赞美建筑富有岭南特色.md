# 省教育厅副厅长邢锋考察学院赞美建筑富有岭南特色

3月9日，我院成功举办广东省本科高校教学工作研讨会。周密细致的会议服务受到与会人员的广泛赞许，优美的校园环境、完备的现代化校园设施也获得大家的点赞。

当天会议结束后，在学院董事长麦照容、院长王卫平，广东鸿发教育文化集团有限公司总经理陈超群，以及学院领导班子全体成员的陪同下，省教育厅邢锋副厅长、郑文处长对我院进行了调研考察。

麦照容董事长向邢锋副厅长简要介绍了学院建设的有关情况。邢锋副厅长对学院统一的岭南风格建筑群给予了赞美，对学院的建设成绩给予了肯定。

邢锋副厅长还重点考察了我院商科虚拟仿真实践教学中心和作为广东省“试点学院”建设单位的创意设计学院建设，详细听取了有关建设的情况报告，了解各项设施设备的功能和运行，并饶有兴致地参观了创意设计学院学生毕业设计作品展。
