# 艺术系召开《艺术欣赏》课程教学研讨会

2月19日，艺术系在图书馆303会议室召开《艺术欣赏》课程教学研讨会，院督学陈丁堂教授、艺术系全体教师参加了会议。会议由艺术系主任邓星明教授主持。

会上，与会老师结合富有特色的课堂教学，就教学目标、课堂环节，如何调动学生的学习积极性、优化课程设置等方面进行了探讨与交流。研讨会集思广益，既分析了《艺术欣赏》课程教学效果，总结了教学经验，又查找了教学中存在的问题和不足，进一步明确了今后艺术欣赏课程教学改革的方向。
