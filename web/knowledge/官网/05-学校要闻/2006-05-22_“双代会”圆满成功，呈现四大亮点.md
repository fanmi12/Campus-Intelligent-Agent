# “双代会”圆满成功，呈现四大亮点

这次会议开得非常成功，并呈现出四大亮点：一是校本部高度重视、关注和支持大会的召开。东莞理工学院领导杨晓西、王江水、安少华以及城市学院董事会、监事会全体成员都出席了会议并在主席台就座。二是在会议期间，学院请出席会议的全体代表对学院领导和行政管理部门主要负责人的德能勤绩进行测评。三是代表们参政议政热情高，会议前后撰写了大量的提案。提出了许多合理化建议，为我院民主建设打下了良好的基础。四是合同制工人第一次以正式代表的身份参加双代会。据统计，出席会议的合同制工人代表共计13名，他们代表学院后勤服务部门140多名合同制员工。
