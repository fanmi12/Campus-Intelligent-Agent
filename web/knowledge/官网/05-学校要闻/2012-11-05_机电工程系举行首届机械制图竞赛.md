# 机电工程系举行首届机械制图竞赛

10月25日，机电工程首届机械制图竞赛在7A201和7A202拉开帷幕，全系共有173名学生参与了竞赛。

本次竞赛主要是考察学生对机械制图的基本知识和技能掌握的牢固程度。竞赛内容分为两部分：第一部分是根据两个视图绘第三视图；第二部分主要是表达方法的改错，图中有同学们在平时中容易出现的错误，需要同学通过读图改正过来。竞赛结束后将产生一等奖10名，二等奖20名，三等奖30名。

机械制图是机电工程系最重要的专业基础课程之一，是机械专业学生必须熟练掌握的最基本的技能。机电工程系曾多次举办过二维和三维计算机绘图竞赛，但举办机械制图手工绘图还是第一次，此次竞赛学生主要面向大二刚学完机械制图的学生。据机电工程系主任赵天婵教授透露，学院将通过此次竞赛，选拔学生参与教育部制图教学指导委员会举办的 “ 中图杯 ” 全国大学生先进制图技术与技能大赛。
