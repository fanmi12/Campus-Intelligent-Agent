# 我院举办“五月鲜花?唱响城院”第二届校园合唱大赛

5月10日晚，五月鲜花?唱响城院”第二届校园合唱大赛在综合馆举行。院团委书记李瑶、艺术系副主任康慧丽、党总支副书记张宏渝、音乐教研室邝富强老师担任本次比赛评委。

大赛以“走进新时代，唱响中国梦”为主题，由艺术系师生进行指导排练的八支队伍参加了比赛。经过激烈的角逐，金贸系队荣获第一名，外语系、文传系队获得第二名，商学院、计信系和电智院队荣获得第三名，政法系、城环系和机电系队荣获的优秀奖。最佳人气队伍由商学院队获得，最佳指挥奖由艺术系刘家杰同学获得，黄志梁、汤伟川、陈依潮等六位同学荣获最佳导师奖。

此外，艺术系新成立的“春天合唱团”作为嘉宾演出团体首次亮相城院舞台，受到了全院师生的关注。
