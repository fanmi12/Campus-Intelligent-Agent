# 学院举行首届教工歌手大赛

为了丰富文化生活，展示教职工的亮丽风采，我院工会于6月3日在学院卡拉OK厅举办了教职工大赛。经过初赛的激烈角逐，共有15名选手进入决赛。

谭汪洋老师的《北国之春》唱出了浓烈的思乡之情；丛珊老师更是别出心裁，身着卡通小鸡服装演唱了一首发人深思的《我不想说我是鸡》；章德胜老师深情演绎《弯弯的月亮》再次掀起比赛的高潮；李珊珊老师拉唱的《我爱洗澡》颇有明星风采……台上选手们风格各异，争奇斗艳；台下拉拉队热情高涨，掌声欢呼声声声入耳。业余选手们的精彩表演引得专业歌手们歌兴大发，禁不住一展歌喉，高歌一曲。林伟伦老师和陈煜丽老师现场演唱了一首《相思风雨中》，丘永辉老师和特邀嘉宾王燕则现场演唱了《敖包相会》。

最后，胡静姝、陈伟鹏、凌继峰分别获得金银铜奖，黄江航等老师获城市学院十大歌手奖。
