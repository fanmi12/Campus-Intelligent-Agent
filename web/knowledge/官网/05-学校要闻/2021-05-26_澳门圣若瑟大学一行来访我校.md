# 澳门圣若瑟大学一行来访我校

2021年5月25日上午，圣若瑟大学副校长ALVARO BARBOSA和客座教授何锦辉到访我校进行访问交流。我校副校长黄兢、校长助理林江龙以及国际交流中心主任助理黄燕旋热情地接待了本次来访的嘉宾。

黄兢副校长对圣若瑟大学代表一行来访表示热烈欢迎，并对我校整体概况做详细介绍。在座谈会上，会议期间，双方就所在学校的办学理念、师资水平、学科特色等情况做深入交流，并针对如何进一步加强两校之间未来的合作交流发表观点。通过深入交流与探讨，希望充分利用两地高校所具有的办学特色为粤港澳大湾区建设和发展输送人才，争取在更广泛的领域取得新的突破。双方代表互赠纪念礼，座谈交流氛围融洽。

随后，来访嘉宾在黄兢等领导的陪同下参观校园,在参观创意设计学院作品展期间，创意设计学院王锦锋院长等为来访嘉宾详细介绍了优秀设计作品。圣若瑟大学代表一行对我校优美的环境和极具特色的教学设施表示赞赏，称赞我校学生的设计作品富有创造力，令人印象深刻。现场氛围十分愉悦。

此次访问交流虽然时间短暂，但双方收获丰富，我校代表与圣若瑟大学来访嘉宾进行了多方位的交流，为今后双方合作奠定了良好基础。
