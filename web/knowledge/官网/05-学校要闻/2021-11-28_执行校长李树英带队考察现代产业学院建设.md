# 执行校长李树英带队考察现代产业学院建设

2021年11月23日上午，我校执行校长李树英教授带队赴番禺职业技术学院交流。副校长麦绮琳，校长助理、商学院院长罗卫国，物流教研室主任张洪参加了此次交流活动。

首先，由番禺职业技术学院党委书记林洽生致欢迎词，对我校李树英执行校长、麦绮琳副校长及随行人员表示欢迎，并介绍了学校概况、专业设置、师资队伍建设等情况。李树英执行校长对番禺职业技术学院的热情接待表示感谢，说明此次调研的目的和希望交流的几方面问题。随后，番禺职业技术学院现代物流学院院长谭福河介绍了现代物流学院的基本情况，就专业建设、课程建设、师资队伍、现代产业学院建设等方面做了详细的介绍。双方围绕物流管理专业建设、京东现代智能供应链产业学院建设等展开交流。

座谈结束后，执行校长李树英教授一行人参观了番禺职业技术学院京东校园馆、物流实训基地，并听取了负责人的介绍。最后李树英执行校长对番禺职业技术学院的热情接待和经验分享再次表示感谢，希望今后在现代产业学院建设方面加强交流。
