# 城市学院在服务东莞中创先争优

为积极响应广东省委教育工委对全省创先争优活动的具体要求，我院以邓小平理论和“三个代表”重要思想为指导，深入贯彻落实科学发展观，围绕省委教育工委深入开展创先争优活动2012年工作要点来开展，做了大量的工作。其中我院积极开展“服务东莞”的各项工作，充分将我院优势人才资源与社会共享，为东莞的发展出谋划策。在具体的奉献中体现创先争优的精髓。活动开展以来，我院教师积极配合学院服务东莞的各项举措和要求，大力开展服务东莞各项工作，取得了较为显著的成绩。

一、 积极为政府及企事业单位出谋划策。

我院教师积极与校外企事业、政府单位联络交流，为其发展出谋划策，献计献力。部分教师在政府单位担任顾问、宣讲员、评估员、评委等，如文传系孟颖老师担任东莞市第二批语言文字规划示范校评估工作评估员。王雄文老师被东莞市普法办特聘为东莞市“六五”普法宣讲团宣讲员。财经系为东莞会计学会进行论文评审。金贸系参与东莞十二五服务业发展规划评审。艺术系多位老师为东莞众多演出活动出谋划策、排练指导，受到一致好评。赵书山副教授、程建新老师应邀参加广东省社会体制改革理论研讨会，为社会体制改革出谋划策。

另外，我院教师还积极与东莞各企事业单位合作，贡献力量。城环系与校外企业就可耐福绿色建材技术开展研讨会。政法系的普惠社会工作服务中心以及开展的法律咨询服务活动为东莞社会和社区工作做着默默的奉献。管理系组织部分教师对东莞市依时利科技有限公司设计激励与考核方案并帮助实施，取得了良好效果。刘林泉、葛卫清、张建平等老师作为广东企业科技特派员驻东莞铭丰集团。

此外，我院各系部还充分利用自己的资源和人力优势，积极对外承办大型活动，2011年，我院承办的大型活动达32次之多，其中，图书信息中心参与承办2011年东莞读书节。财经系承办了东莞高校会计知识竞赛邀请赛。

通过与政府和各企事业单位的积极合作，我院树先进，立品牌，不仅对各单位形成一定帮助，也提高了学院的知名度，到达互利双赢的效果。

二、 积极接受媒体采访，引领社会文化及舆论方向。

我院许多老师的身影时常出现在主流报刊和电视节目上，这些老师经常接受各大媒体的采访，就许多热点问题提供观点，发表自己的看法。据不完全统计，仅2011年一年，接受采访的次数就多达200余次。其中，城环系教师多次接受东莞电视台《生活大莞家》节目采访，就面条燃烧、三手烟、可乐喷泉等问题提供意见。财经系张灿灿老师就个人所得税、月饼税等问题接受采访，发表观点。我院赵书山副教授还成为东莞阳光网“焦点关注见证成长”十大新闻人物评选活动候选人。

此外，我院新闻中心在联系媒体采访方面也作出了较大的努力，全年共计协助社会媒体就热点新闻采访100多次，接待东莞电视台、东莞日报、东莞时报、南方日报记者100多次。为我院老师能更好的服务社会牵线搭桥。

三、与东莞社会需要相结合，大力开展相关科研项目

我院老师积极加大以服务东莞为主题的科研力度，把学术研究与当前社会热点、焦点问题相结合，真正做到科研为社会服务，大大提高了学术研究的实用性。

政法系周巍老师主持社科联课题：东莞社会工作发展中存在问题及对策研究，将关注点直接放到东莞新兴的社会工作领域。赖沛东老师主持社科联课题：东莞市居民幸福指数调查，对政府掌握东莞市民的心理状态和行为意识起到了一定的作用。王海洋老师主持社科联课题：东莞新生代农民工发展现状调查报告，思政部徐小娟老师主持社科联课题：构建幸福东莞视域下的新生代农民工社会消极情绪调查。都将研究重点放在了东莞发展重中之重的农民工问题上。此外，图书信息中心开展的课题：东莞地方文献的挖掘与整合模式研究。吴燕玲老师主持的市科技计划项目：基于物联网的汽车尾气实时监测系统的研制等科研项目也在一定程度上促进了服务东莞的理性思考和科学运作。

四、利用专业优势，为政府和企事业单位开展讲座。

我院教师充分利用自己的专业知识和专业技术，奔赴东莞各地，为政府和企事业单位开展讲座。

就社会民生方面，高教中心屠大华教授开展“家庭教育”讲座。赵书山副教授应樟村社区妇女学校之邀分别做“聪明智慧的妈妈从我做起”和“怎样理解孩子青春期的心理变化”讲座。思政部石志民老师为东莞市监狱服刑人员做题为“人生价值的思考”的讲座。周巍博士在东莞市重点青少年群体服务管理和预防犯罪工作中期评估汇报会上做汇报。

就一些专业知识和技术方面，政法系王雄文老师应邀赴长安行政办事服务中心讲学，主题是《行政许可法的理念和法律风险防范》。财经系老师应邀为宏远集团讲授财务会计知识。机电系给东莞出版印刷业协会作色彩管理讲座。计信系龙允聪作为专家在东莞广播电台参加电气节能讲座。

老师们的讲座，在一定程度上，满足了部分社区、企业、单位对专业领域知识的需求，很好的调动了高校教师走出校门，用所有知识为社会服务的热情，在东莞社会树立了良好的口碑。

从上述材料可以看出，我院在通过服务东莞的各项工作积极践行创先争优，紧紧围绕我省教育“创强争先建高地”中心工作，以迎接党的十八大和省十一次党代会召开为时间节点，突出重点，掌握节奏，比较好的调动了基层党组织和党员投身创先争优活动的积极性，取得了较大的收获。
