# 广东省人才开发与管理创新座谈会在我院举行

9月28日上午，广东省人才开发与管理创新座谈会在我院5A325举行。

参加座谈会的嘉宾有：广东省人才开发与管理研究会会长、华南理工大学工商管理学院副院长刘善仕教授，研究会副会长广东财经大学人力资源管理中心主任董福荣，研究会副会长、东莞理工学院经济与管理学院刘永安教授，研究会副秘书长邹标先生，东莞理工学院经济与管理学院石碧涛博士，东实集体人力资源部总监夏林幽先生、培训经理王胜军先生。

黄兢副院长代表学院致欢迎辞，并介绍了我院的发展情况。他指出，我院已实现了规模化招生的目标，为学科专业建设、应用型人才培养等方面奠定了良好的基础，希望专家们畅所欲言、献计献策。

研发处处长赵书山介绍了我院学科建设与专业建设、应用型人才培养等有关情况。管理系张佺举主任介绍了管理系和人力资源管理专业、工商管理专业的发展历程、主要特色。

刘善仕会长对我院学科专业建设取得的成绩表示肯定，希望能与城市学院开展合作，共同打造人才开发与管理研究、实践交流的共建、共享、专业平台。董福荣副会长指出，在学科专业建设方面应加大高水平、高素质人才培养及引进，注重团队建设。刘永安副会长表示将大力支持城市学院的人力资源管理专业、工商管理专业建设。夏林幽总监指出，学科专业建设需适应区域经济产业发展要求，提供独特的、精准的专业服务。

会议由张佺举主任主持。管理系卢淑芳书记、李玉春副书记以及人力资源管理教研室贺冬怡主任、黄岳钧副教授等参加了座谈会。
