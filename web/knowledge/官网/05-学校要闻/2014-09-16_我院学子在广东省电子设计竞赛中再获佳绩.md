# 我院学子在广东省电子设计竞赛中再获佳绩

9月10日，2014广东省大学生电子设计竞赛“可穿戴应用”专题竞赛在华南理工大学举行，本次大赛由广东省教育厅、全国大学生电子设计竞赛广东省电子设计竞赛组委会举办。本届大赛有华南理工大学、中山大学等省内46所高校，382支队伍参加比赛。我院学子获得七个奖项，其中二等奖一项、三等奖六项。

教师团队由总支书记葛卫清副教授、龙允聪高级工程师、李建辉等老师组成，11级电子信息工程专业30名同学组成了10个小组参加此次大赛。其中龙允聪老师指导的莫秋活、蓝福明、王政义小组获二等奖，李俊斌等其他6组获得三等奖。
