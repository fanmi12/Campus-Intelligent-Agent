# 我院召开2014-2015学年度民主测评大会

6月29日、30日，我院召开民主测评大会，分别对教学系（部）和行政教辅部门2014-2015学年度的工作进行绩效考核与民主测评。

会上，11个教学系（部）主任和11个行政教辅部门负责人根据《目标管理绩效考核任务书》的指标和内容，分别汇报了本单位2014-2015学年度工作的完成情况和工作中的创新与亮点、存在的问题和下一学年的工作计划等。

学院民主测评团成员、教职工列席代表、民主党派人士代表等听取了各单位的绩效述职报告，并采用量化打分的方式进行了评分与投票。
