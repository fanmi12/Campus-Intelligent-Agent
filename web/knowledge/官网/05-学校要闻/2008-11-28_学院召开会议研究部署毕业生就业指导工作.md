# 学院召开会议研究部署毕业生就业指导工作

为应对当前国际金融风暴引发的全球性经济衰退，以及东莞企业结构性调整、产业转型升级带来的较为严峻的就业形势，11月25日，学院在4＃405会议室召开院长、书记办公会议，研究部署2009届毕业生就业指导工作。学院党政领导安少华、朱志德、程发良、朱冰、张林，院督学陈丁堂以及院党委委员参加了会议。会议听取了学生处和就业指导办公室有关负责人关于学院2009届毕业生就业指导工作所面临的困难及应对措施的情况汇报。会议要求，面对新的就业形势，我院就业指导工作要着力抓好以下几个方面的工作：

一、要改变过去简单依赖政府行政部门牵头的模式，采取积极主动的策略，走出校门，走进企业，与在莞的企事业用人“大户”建立长期的合作关系；要充分发挥我院毕业生莞籍生源多、毕业生熟悉东莞经济社会发展的各种优势，积极向企事业单位推荐并输送大量优秀的毕业生。

二、要发挥我院教学实践（实习）基地熟悉毕业生特点及毕业生专业对口的优势，进一步了解教学实践单位的用人需求，搭建好用人单位与毕业生的信息桥梁，促使用人单位更多地接纳我院毕业生，实现双赢。

三、举全院之力，共同做好大学毕业生就业指导工作。充分发挥学生处、招生办公室及各系部负责学生工作人员所掌握的丰富的社会资源及学生资源的优势，调动全体师生的积极性，挖掘企事业单位中潜在的用人需求信息；要以学院的名义，邀请用人单位参与学院12月6日即将举行的现场招聘会，主动做好后勤服务工作，确保有一定数量并具有较好资质的用人单位前来参与招聘，为我院毕业生提供就业岗位。

四、要在全院各系部建立“就业信息员队伍”，进一步加强就业信息网络建设，确保各种就业需求信息的畅通。教务处及学生处要制定有关办法，为毕业生在大学最后一学期获得毕业实习、就业试用的机会，提供顺利完成学业、顺利就业的政策支持。

会议强调，全院上下要统一思想，迅速行动起来，认真贯彻落实会议的有关精神，举全院之力，进一步做好毕业生就业指导工作。

据悉，11月25日下午，教务处、学生处等有关职能部门在4＃410、4＃405会议室，分别紧急召开了关于做好毕业生就业指导工作的会议。会议按照院长、书记办公会议的要求，落实好各自的工作任务。与会人员表示，完全有信心有能力按照学院的要求，做好毕业生就业工作，争取全社会为我院毕业生提供更多的优质就业岗位。
