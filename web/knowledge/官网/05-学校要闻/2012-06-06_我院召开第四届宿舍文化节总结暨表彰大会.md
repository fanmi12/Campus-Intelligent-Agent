# 我院召开第四届宿舍文化节总结暨表彰大会

6月5日，我院（莞城校区）第四届宿舍文化节总结暨表彰大会在3407室举行。学生处副处长陈建新、总务处主任助理兼宿管中心主任周衢等相关领导、老师、各系辅导员出席本次表彰会。

经过学生投票和学生处、宿舍管理服务中心审核同意，授予贾金姑等7位宿管员为“宿管之星”荣誉称号。苏欣茹、钟亦川等14位同学荣获宿舍公益文明标语大赛奖。

会上，陈建新副处长对学生处、宿舍管理服务中心、自律会通力合作，互相配合，齐抓共管的管理模式及效果和变化给予了充分肯定。他同时强调，必须紧抓宿舍安全管理工作，让学生安心学习，舒适生活，身心受益健康成长，共同营造积极向上、清新高雅、健康文明的宿舍文化氛围，打造和谐校园，为大学生提供良好的住宿环境与条件，保障他们完成学业。
