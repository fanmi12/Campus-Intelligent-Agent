# 文学与艺术系音乐专业举行期中汇报音乐会

“城市学院，我们辛勤耕耘的地方。崇尚科学，放飞理想，追求卓越，继往开来，学而知不足，激情更澎湃。为了民族的崛起，我们永远不言败；为了祖国的富强，我们要开拓未来。”11月23日，文学与艺术系在大礼堂举行的音乐专业05、06级期中汇报音乐会上，校歌《城市学院之歌》首次唱响。院长安少华教授，党委书记朱志德，常务副院长程发良教授，副院长林世俊教授以及文学与艺术系400多名师生观看了音乐会。

如何对音乐专业的学生进行学习考核呢？同学们用动听的音乐作了回答。音乐会的节目，无论是独唱或合唱，古典与流行，还是舞蹈和演奏，每个节目都展示出同学们的专业水准，给师生们献上了听觉盛宴，让大家检验了他们的成绩。
