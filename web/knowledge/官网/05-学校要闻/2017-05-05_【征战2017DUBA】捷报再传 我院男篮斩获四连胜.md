# 【征战2017DUBA】捷报再传 我院男篮斩获四连胜

5月3日晚，我院男篮迎来DUBA第四场，客场对阵广东科技学院队（以下简称：广科队），以85:76战胜对手取得四连胜。

哨声响后，广科队先发制人，13号张启帆一记三分球拉开序幕。我方随即予以回应，10号黄明健在罚球得分后，再次冲破对方防守进球得分。第一节双方打得难分难解，我院以18:21暂时落后。

第二节，广科队欲乘胜追击，13号张启帆再次开场进球。我方调整到位，7号黄志陆快攻突破对方防守，将比分咬紧。第二节，双方攻防旗鼓相当，各有得失，最后以36:36结束上半场。

易边再战，我院男篮及时总结了前两节经验，改变策略，内外线火力全开，随着8号张俊的进球拉开攻势，打出了一波15:2的小高潮，以67:52的优势将比赛带入末节。

广科队第四节欲奋起直追，13号张启帆、7号卫展图各一记三分球掀起攻势，一度将比分缩小至4分。比赛进入白热化阶段，我方凭借良好的状态、默契的配合，最后以85:76战胜广科队，实现开赛以来的四连胜。

本场比赛，我方10号黄明健发挥出色，拿下全场最高25分。
