# 中山大学新华学院来我院交流访问

4月13日上午,中山大学新华学院财务处长张华英、副处长李宝玲一行5人莅临我院交流访问。

我院财务处长余竹根和财务处工作人员一起热情接待了客人。在行政楼212会议室，双方就民办高校的财务预算管理、薪酬制度以及信息化管理等方面内容进行深入的交流探讨。

会后，张华英处长一行还参观了我院校园建设。
