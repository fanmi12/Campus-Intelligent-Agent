# 艺术团举办三周年成果展

4月7日，学院艺术团在四号楼大厅举办大学生艺术团成立三周年成果展，共展出13块展板，内容包括：艺术团团标展，艺术团领导人风采展，艺术团历届晚会展，艺术团成员在各项领域获得奖项展，各队伍表演服装展，各队、各部门主要情况展，各队员艰苦训练风貌、各部员辛勤工作展以及感言小纸条等8个方面。

城市学院大学生艺术团自2005年成立至今，由当初的几支队伍发展到现在的11支队伍和4个部门，结构不断完善，规模不断扩大。经过老师辛勤指导和成员们的艰苦训练，艺术团在学院内外各大晚会上绽放光彩，多次服务东莞、走进社区，受到东莞市民的好评。

据悉，展览将持续4天，目的在于提供一个交流的平台，让师生们了解艺术团近年来取得的成果。
