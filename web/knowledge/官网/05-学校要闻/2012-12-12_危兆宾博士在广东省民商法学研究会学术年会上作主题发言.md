# 危兆宾博士在广东省民商法学研究会学术年会上作主题发言

12月8日，广东省法学会民商法学研究会2012年学术年会暨研究会换届选举大会在广州市举行。我院政法系危兆宾博士应邀与会作主题发言，并当选为研究会理事，他提交的学术论文获优秀科研成果三等奖。

大会期间，与会代表围绕会议主题，结合广东民商事法律适用的现状，就人格权法律制度的完善、资本市场创新发展中的法律问题等民商事热点问题进行了热烈讨论。

据悉，本届年会由广东省法学会民商法学研究会主办，暨南大学法学院承办。有来自中国人民大学、对外经济贸易大学、香港城市大学、香港中文大学、澳门大学、中山大学、广东省高级人民法院、广东省法学会、广东省律师协会及省内外20多所高校的100多位民商法专家和学者与会。
