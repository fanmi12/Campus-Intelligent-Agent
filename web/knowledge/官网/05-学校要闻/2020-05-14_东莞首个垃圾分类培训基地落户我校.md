# 东莞首个垃圾分类培训基地落户我校

5月12日，东莞市垃圾分类培训基地在东莞理工学院城市学院正式揭牌成立。这是东莞成立广东省垃圾分类培训学院东莞分院后，成立的首个垃圾分类培训基地，意味着东莞市生活垃圾分类工作正在加速驶入快车道。

出席活动的嘉宾有：东莞市城市管理和综合执法局局长郭怀晋、副局长叶志锋、董事长代表陈超群、校长王卫平、副校长黄兢等领导参加了揭牌仪式。

垃圾分类作为一项需要全民参与的工作，全程宣传引导很关键，垃圾分类培训基地的成立，将为下来开展教育培训提供有力支撑。

校长王卫平在致辞中表示，东莞理工学院城市学院非常荣幸能成为首个东莞市垃圾分类培训基地，这是城市学院实践教学改革、科研成果转化迈出的重要一步，也是学校服务地方、产业融合的重要体现，学校将以“强强联合、资源共享”的形式，整合全行业优势资源和师资力量，助力高质量推进东莞市垃圾分类工作，与市城市管理综合执法局共同推动东莞市社会文明建设。

董事长代表陈超群表示：我们将通过一系列的专题培训，划分业务知识宣讲模块、协同运作管理模块、综合管理技能模块三个专题，采取分批分层次向参训人员介绍当前垃圾分类的背景、现状、分类的必要性和近年来的制度、案例和做法，让更多的参训人员明白垃圾分类的“初心”和“使命”，引导全社会的每一员履行环境保护责任，让垃圾治理成为全市上下的社会新风尚、文明新习惯、家庭新美德，积极推动个人文明及社会进步，推进全市绿色生态可持续性发展。

局长郭怀晋在仪式上表示，东莞垃圾分类培训基地在正式揭牌成立后，要积极对接省垃圾分类培训学院，结合东莞市实际，设置操作性强、指导性强的培训课程，尽快按计划开展各项培训工作。依托专业知识优势，通过课题研究、科技创新等积极参与到东莞垃圾分类的各项工作中。希望学院依托本身的教学优势，努力打造东莞城市管理者的人才培养、输出的摇篮，为东莞垃圾分类的各项工作提供坚实的支撑。

据了解，该垃圾分类培训基地近期将开展第一期垃圾分类专题培训，整合行业优势资源和师资力量，通过采取线下专家授课、专题讲座、互动研讨、经验交流等方式，同时结合线上垃圾分类专题课程等多种形式，组织全市从事生活垃圾分类工作的城管系统干部、村（社区）工作人员、现场引导员等，开展多样化、多层次的培训活动。
