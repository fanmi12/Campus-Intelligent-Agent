# 我院第九届宿舍文化节精彩落幕

4月25日，我院第九届宿舍文化节闭幕式暨宿舍美化设计大赛决赛在学术报告厅隆重举行。总务处翟耀明处长、院团委罗文芳书记、学生处思政科陈晓萍科长、学生公寓服务中心柳成荫主任及黄小勇副主任以及各系负责学生宿舍工作的辅导员来到本次大赛现场。

本届宿舍文化节以“营造温馨舒适环境，体验别样精彩人生”为主题，举办内容包括第九届宿舍美化设计大赛、第二届“宿管之星”以及第一届“宿舍节水达人大赛”三个活动。

据悉，本次比赛历时20多天，经过激烈的初赛和复赛，最终有12间宿舍进入本次决赛。各参赛宿舍各出奇招，精彩的VCR和PPT演讲展现了“森林风”、“小清新”、“土木方砖”等百变风格，充分体现了宿舍浓浓的爱和“宿舍是我家”的深厚感情。最终以“绿色环保”为主题的4A420和“绿野仙踪”的4A515夺得本次宿舍美化设计大赛的冠军。彭冠三、龚颂梅等8位宿管获得“宿管之星”，12间宿舍获得“宿舍节水达人”称号，其中一等奖2间、二等奖4间，三等奖6间。

最后，院团委罗文芳书记对本届宿舍文化节进行总结。据介绍，本届宿舍文化节经过一个月的筹办和通过丰富多彩的评选活动，不仅丰富了我院广大学生的课余生活，同时也加深了同学之间的团结协作，增强了同学们的节水意识，更推动了我院宿舍文化的发展。罗书记强调了宿舍文化建设任重道远，希望同学们能继续传承在宿舍文化节中体现的实践能力、创新能力和团结合作的精神。
