# 张佺举教授担任2014年全国职业院校技能大赛省赛裁判长

5月16日，2014年全国职业院校技能大赛广东省选拔赛(高职组)“一体化物流方案设计与实施”项目赛在东莞职业技术学院开赛，来自广州、佛山、珠海、惠州等地市的35所高职院比拼3天。大赛组委会邀请我院张佺举教授和张洪、王兴老师分别担任裁判长或裁判。
