# 我院选派41名教职工赴台研修

7月4日，学院在212会议室召开了赴台研修动员大会。学院党委书记王卫平、党委副书记章德胜、副院长高香林出席会议，41位赴台研修的教职工参加会议。会议由党委副书记章德胜主持。

王卫平书记对赴人员提出了四点要求：一要维护形象，展现风采；二要加强学习，。开拓视野；三要学以致用，助推发展；四要保持沟通，注意安全。研修班学员要带着问题和想法去，带着经验和措施回，学成归来后，将所学所得在个人所在部门进行介绍，并运用到日常的教学管理当中。

据教师发展中心副主任李海冬介绍，举办本次培训班旨在提高我院应用性人才培养模式教学管理实践，加强我院同台湾高校的交流与合作。10天研修行程，6天是全天学习，内容包括台湾大学的办学理念、质量管理、服务地方机制、人事和财务制度设计、应用型人才培养的课程设置、学生创新创意创业能力培养等；2天到台湾其他大学参观交流，并将到创办义守大学的义联集团考察学习。

据悉，参加本次培训班的41位教师都是教学和管理一线的老师和干部，管理系吴运建博士、政法系危兆宾博士等都表示，期盼台湾研修行提升自己的教育教学能力，给学院应用型人才培养带来新的思路和借鉴。

台湾义守大学，原名高雄工学院，由烨联钢铁集团董事长林义守先生全额捐资创办，是台湾内少数理论与实务兼具，并有产业敏感度的综合型大学，是台湾办学水平最高的私立大学之一。
