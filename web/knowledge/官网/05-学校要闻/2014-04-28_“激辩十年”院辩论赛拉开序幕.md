# “激辩十年”院辩论赛拉开序幕

4月17日下午，由院团委主办，文传系辩论队承办的“激辩十年”院辩论赛初赛在教学楼7B516和7B517课室顺利开展。

此次初赛共有8支队伍，分两场同时进行。

第一场比赛的两组队伍是政法系对机电系、文传系对管理系，正反两方围绕“面对新闻真相，公众知情权和个人隐私何者更重要”这一辩题进行辩论。其中，文传系“酷炫队”用新闻传播的意义说明了公众知情权的重要性，以独特的视觉引领观众，说服观众。反方管理系则指出了法律文件对个人隐私与公众知情的保护问题来论证本方的观点。

第二场比赛的两组队伍是财政系对计信系、城环系对金贸系，两组队员围绕“中国电影好莱坞化是否有利于保护中国的传统文化”这一辩题展开辩论。赛场上，辩手们你来我往，妙语连珠式的一问一答，非常激烈。这次辩手们表现出优秀的辩风，举止落落大方，论述点清晰，为个人风采加分不少。

最后，机电系、文传系、财经系、金贸系取得了这次“激辩十年”辩论赛初赛胜利；最佳辩手分别是政法系袁锦清、管理系陈洁莹、财经系汪雨辰、城环系欧迪鹏。
