# 宋秋敏教授作客暨大“暨珠百年讲堂”

日前，文传系宋秋敏教授应暨南大学珠海校区邀请，在“暨珠百年讲堂”作题为《唐宋诗词与优雅生活》的讲座。

宋秋敏教授引入“活着?生活?生活艺术”的概念并诠释了其含义，然后再以探讨宋代读书人如何优雅地生活为切入点，通过讲述史实和赏析诗词的形式，对宋代文人生活的政治和经济背景进行了解析。

谈到唐宋词人的生活百态，宋秋敏教授认为，唐宋词人以欣赏和审美的眼光生活，他们热爱着郊游踏青、游山玩水、登临游览、泛舟垂钓等富有诗情画意的户外活动，享受着琴棋书画、金石古玩收藏、品茶饮酒、诗社集会等充满雅趣的室内活动。

1个多小时的讲座中，宋秋敏对唐宋诗词与优雅生活深度解说，使得大家对唐宋诗词与优雅生活两者之间的关系有了更深刻的认识，受众收获颇丰。

人物简介：宋秋敏，文学博士，教授，南京师范大学中国语言文学博士后流动站博士后，现中国词学研究会理事，深圳市儒家文化研究会理事。
