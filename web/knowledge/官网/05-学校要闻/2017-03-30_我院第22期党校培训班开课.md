# 我院第22期党校培训班开课

3月16日下午，我院第22期院党校培训班在7B211开课， 164名入党发展对象参加了培训。

院长、党委书记王卫平同志主讲第一课。王书记分析当代大学生的主要特点，重点阐述了长征精神、延安精神以及西柏坡精神，向学员们讲述了“三严三实”的内涵，鼓励大家积极培育和践行社会主义核心价值观，争当当代大学生的先锋模范。

党委副书记、院党校校长章德胜同志以“重温入党条件，明确党员标准；端正入党动机，主动接受考验”为题，着重强调：无论入党积极分子，还是预备党员，最重要的是秉承着全心全意为人民服务的初衷，端正自己的思想，指引自己前行，争当一名合格的党员。

课后，一位学员热情地向记者反映:“这堂党课让自己又有了新的体会，不仅聆听了学院党委的教诲，也明白了‘不忘初心，方得始终’的真谛，使自己在思想上与党组织更加靠近了。”

据悉，我院第22期党校培训课第二次培训将于3月21日开课。
