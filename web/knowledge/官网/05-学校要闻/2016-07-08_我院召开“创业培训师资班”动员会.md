# 我院召开“创业培训师资班”动员会

7月7日下午，东莞理工学院城市学院创业培训师资培训班动员会在5B208召开。王卫平院长、刘玉侠副院长等领导及培训班30位学员参加了会议。

为增强大学生创新创业教育工作，进一步扩大及提升创新创业教育师资队伍水平，更好地服务东莞地方经济，我院继续教育中心将于7月11日—20日举办SYB师资培训班（即：创业培训师资培训班）活动。培训活动邀请了知名专家高爱兰、刘凌等担任主讲老师。

刘玉侠副院长在动员会上做了讲话，提出要按“高标准、严要求、好成绩”的要求办好培训班。

据悉，东莞市人力资源局对本次培训活动给予了大力支持，并希望我院努力办成广东省创业培训精品班，打造出一支优秀的创业培训师资队伍。另据介绍，参加此次创业培训师资班培训的30位学员，均为我院高学历、高职称的精英人才。
