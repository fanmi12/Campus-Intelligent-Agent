# 文传系第五届主持人大赛决赛圆满落幕

5月10日,文传系第五届口语表达大赛之主持人大赛决赛在莞城校区学术报告厅上演。本次比赛共分为：中英文决赛选手亮相，英语主持人比赛环节，歌曲表演，中文主持人比赛环节，辩论队朗诵节目，颁奖及全体选手合影六个部分。

经过激烈角逐，中英文组获奖情况分别如下，英文组郭妍慧获一等奖，肖翠瑜获二等奖，王柱辉获三等奖；中文组黎祖辉获一等奖，谢珠、尹婉媚获二等奖，陆国耀、王飞越获三等奖；陈仿等7名同学获优秀奖；何文聪等两名同学获才艺奖；谢舜珠获最佳人气奖。

担任本次决赛的评委有文传系党总支书记孟颖老师、新闻中心刘哲老师、文传系辅导员李瑶老师、英语教研室张云老师和黄燕丽老师。同时出席本次大赛的还有文传系全体老师和各兄弟系部团总支学生代表。

据悉，东莞广播电视台全程对此次活动进行跟踪报道。
