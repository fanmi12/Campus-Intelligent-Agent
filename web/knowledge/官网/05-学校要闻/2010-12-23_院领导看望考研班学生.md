# 院领导看望考研班学生

寒冬时节，暖流涌动。12月22日，院领导安少华、朱志德、程发良在教务处处长邓成良的陪同下，来到考研辅导班看望在这里备考的师生，向他们带去了冬至的祝福和诚挚的慰问。

安院长对同学们考研的行动和备考的执着表示肯定。他说，考研的过程，是对自身意志的磨炼，也是一段无悔的、难忘的人生经历，只有亲自尝试了才能真正体会到其中的意义。能够潜心学习，勇攀高峰的精神是很可贵的，希望大家克服困难，认真备考。安院长还与同学们分享了他的考研经历，并提醒大家要注意身体，放松心情，以良好的状态迎接考试。

随后，学院领导和考研班的师生合影留念。

据悉，今年我院共有46名学生参加考研辅导班学习，他们将于2011年1月份参加全国硕士研究生入学统一考试。
