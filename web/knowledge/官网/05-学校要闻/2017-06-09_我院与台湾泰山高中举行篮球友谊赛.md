# 我院与台湾泰山高中举行篮球友谊赛

6月8日下午，我院男篮与到访的台湾泰山高中篮球队在综合馆上演一场精彩的友谊赛。

“友谊第一，比赛第二”。双方球员各显神通，在比赛中，你来我往，高潮不断，上演一场观赏性极佳的友谊赛。全场精彩不断，屡有三分球进篮，迎来现场掌声连连。经过四节的切磋，我院以82:103惜败给台湾泰山高中队。

据悉，泰山高中篮球队是台湾校园联赛前三名的球队，培养了许多优秀的篮球运动员。此次泰山高中篮球队与广东宏远队等举行邀请赛进行交流活动，我院也在受邀院校之中。
