# 我校红十字会会长周庆副校长带队赴东莞市红十字会交流学习

为进一步提升我校红十字队伍工作能力和业务水平，4月28日，东莞城市学院红十字会会长、副校长周庆带队赴东莞市红十字会进行学习交流。市红十字会副会长伍淑筠热情接待了我校一行。

校红会一行首先来到东莞市红十字会生命安全体验馆进行参观学习。东莞市红十字会常务副会长伍淑筠的亲自讲解，校红会一行人对红十字运动的起源发展、组织历史、服务宗旨等知识有了更进一步的认识和体会。在这所广东省内面积最大的生命安全体验馆内，我校一行亲身体验地震逃生、火灾逃生、高楼逃生、电梯安全、校园安全、交通安全、涉水安全、模拟灭火、心肺复苏、结绳救援、应急救护等十多个专题板块，通过身临险境的切身感受，继而主动思考，寻找和体验逃生避险、自救互救的方法和路径。

接着，双方开展了座谈会。我校红会向市红会汇报了学校红十字工作的开展情况，围绕“三救三献”、58人道日善款筹集、志愿服务等工作与市红会领导进行了交流探讨。今年，校红十字会将紧扣生命安全教育主题，深抓“救在身边”应急救护知识培训这条主线，通过建立学生志愿者队伍、开展宣传和志愿者服务活动等方面助力宣传和践行红十字精神和宗旨，传播健康理念，传递爱心奉献，着力打造城市学院亮点项目。

市红会领导对我校红十字工作给予了高度评价，并对我校红十字会事业发展思路给予高度认可，同时也希望学校能重点宣传人道精神，开展生命教育；鼓励青年大学生积极投身红十字人道事业，在其中培养中坚力量和领军人才；广泛组织开展红十字志愿服务，从而培养广大青年大学生的自我防护意识和责任意识，促进红十字青年工作的全面发展。

通过此次实地走访，进一步增强了学校红十字会与东莞市红十字会之间的联系和合作，双方希望未来能够开展更多的合作项目，建立常态化、长效化合作机制，共同推动人道主义精神和社会的进步发展。
