# 学院组织开展“六一”儿童节活动

5月23日，在学院工会组织下，全院200多名教职工携其小孩参加了麦鲁小城儿童职业体验乐园的游园活动。

孩子们在麦鲁小城亲身体验了警察、医生、消防员、蛋糕师等50多种职业。这些职业体验培养小朋友独立能力、自尊心，增强团队合作意识，让他们感受不一样的快乐成长体验。

学院还为每个家庭准备了一份精美的“六一“儿童节礼物——用孩子或家庭照片做成的拼图相框。
