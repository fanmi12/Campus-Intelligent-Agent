# 我校斩获广东省第三届“强网杯”网络安全大赛第三名

9月22日，第三届广东省“强网杯”网络安全大赛决赛在广东外语外贸大学举行。由我校图书信息中心伦志辉老师带队指导的“东莞城院网安小组”荣获高校组第3名。

本次大赛是省内最高规格的网络安全赛事，由广东省委网信办、省教育厅、省科技厅、省工业和信息化厅、省公安厅、省国家安全厅、省通信管理局联合举办。进入本次决赛的有中山大学、华南理工大学等高等院校，以及省内党政机关、网络安全企业共84支队伍。我校是全省独立学院和东莞地区高校中唯一一支进入决赛队伍，也是唯一获奖的独立学院。
