# 不忘初心，生命自绽芳华

11月4日晚，我院校友讲坛首场讲座暨第67期“大学生科技文化论坛”在7B301开讲，2009级商务英语专业优秀毕业生谭小洁向同学们分享了自己的人生历程与感悟。

开场前，谭小洁用流利的美式英语和大家亲切交谈，幽默风趣的语言引得在场学生掌声不断。随后，谭小洁回顾了大学时光时在摄影协会、YMCA歌手部及与外教Dustin讨论如何在新校区创办英语角的经历后，并讲述了自己作为交换生在美国的故事——通过自己不断的努力，抓住机遇，让留学美国从一个遥不可及的梦想变成真实。“一开始去到美国，沟通非常困难，生活有阳光，也有辛酸。但我告诉自己，要勇敢地走出自己的舒适区空间，迎接挑战！”在这段几起几落的往事，她的眼里泛起了泪花，获得了同学自发响起的鼓励掌声。

谭小洁还分享了她在参加CCTV“希望之星”全国大赛的心路历程，并传授了自己的口语学习经验，和对英语等级考试的建议等。

在互动环节，谭小洁鼓励学弟学妹们要“不忘初心，生命自绽放芳华”、“多思考，挑战自我，乐于助人，并且为自己是城院人而骄傲”！
