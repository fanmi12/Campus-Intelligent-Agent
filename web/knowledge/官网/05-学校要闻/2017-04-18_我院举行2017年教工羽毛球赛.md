# 我院举行2017年教工羽毛球赛

4月17日下午，历时三周的学院教工羽毛球赛在综合馆闭幕。经过激烈角逐后，教辅队和体育部并列获得第一名，政法系名列第二，金贸系位居第三。

据介绍，本次比赛共有13支教工队伍参加。比赛采用团体赛形式和三局两胜赛制，项目分为女子单打、男子单打、男子双打等五个项目。

赛场上，教工们身手敏捷地跳转腾挪，灵敏的反应，昂扬的斗志，博得了观众们的阵阵喝彩声。此次羽毛球赛既丰富了教职工们的业余生活，又促进了教职工们团结合作的精神。
