# 1∶0，我院男篮决赛旗开得胜

5月26日下午，2017年东莞大学生篮球联赛总决赛开战。我院男篮主场迎战，以82:73击败了广东科技学院队。总决赛采取“三局两胜”制，我院以1:0暂时领先。

首节，广科队先夺得球权，由9号罗耀德突破上篮以2:0率先开局。随后，我院19号叶锐城上篮造成广科阻挡犯规而罚球得分。其后，凭借队员的默契配合传球，5号黄荣斌再次上篮得分。广科队请求暂停，进行调整后，打出一波11:0的小攻势，在第一节结束时，以10:17领先。

次节伊始，我院迅速调整队形，快速退守和落好防守位置，应对广科队的攻势。在单节剩余2分钟，广科队进行2-3联合防守仍难以限制我院将比分追回。我院19号叶锐城再次扛起了球队的进攻大旗，频繁发动快攻，在第二节狂砍下14分，帮助球队以35:29实现反超。

易边再战，下半场广科队15号李宇曦、9号罗耀德发挥出色，相继得分，再度紧咬比分。而我院10号黄明健渐入佳境，与19号叶锐城默契配合合力贡献了14分，帮助球队继续保持优势。加快进攻节奏的广科队，未能阻止比分的进一步扩大。我院仍然以55:46的领先进入末节比赛。

末节，我院凭借出色且迅速攻守转换，10号黄明健开场便打出了2+1。落后的广科队依旧保留着主力阵容，9号罗耀德也打出了3+1的漂亮追击。最后一分钟里，广科10号袁旭华投出漂亮的一记3分，眼看希望尚存之时，我院7号黄志陆却随即连续进账6分，锁定胜局。最终，我院以82:73取得决赛的开门红。
