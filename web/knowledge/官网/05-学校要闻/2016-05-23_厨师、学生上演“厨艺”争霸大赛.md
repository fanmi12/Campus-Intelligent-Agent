# 厨师、学生上演“厨艺”争霸大赛

由后勤饮食服务中心主办、院学生会协办的第四届优质服务月之“面点比拼暨厨艺大赛”，5月19日在荔香园二楼餐厅举行，比赛的选手由各饭堂厨师及我院学生代表组成。

副院长周庆，学生处处长杜鹏举，总务处处长翟耀明、副处长陈辉等领导嘉宾莅临了活动现场。活动还吸引了大批感兴趣的学生前来观看比赛，并参与品尝参赛作品。

比赛分为食堂厨师的烹饪、面点和学生作品两部分进行。首先，由各食堂厨师代表，将各自的参赛作品供评委们品尝评分，随后邀请前来观赛的学生一起参与品尝。学生作品在食堂糕点师的指导下进行，同学们通过和面、制作、烘培出成品，体验了劳动的艰辛，享受了劳动的乐趣，见证了劳动成果。此次活动重在厨师和学生代表的参与，也为我院师生更进一步走进食堂、了解食堂，提供了良好的机会和平台。

周庆副院长要求饮食中心以这次活动为契机，进一步增强服务意识，提高厨艺水平；推动我员餐饮服务工作上水平更上一个台阶，为我院广大师生提供更加优质的饮食服务。
