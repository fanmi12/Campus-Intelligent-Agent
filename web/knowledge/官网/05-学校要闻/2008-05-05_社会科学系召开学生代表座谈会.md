# 社会科学系召开学生代表座谈会

4月29日，社会科学系在1303课室召开学生代表座谈会，听取学生意见。社会科学系党总支书记、系主任陈丁堂教授，党总支副书记石志民副教授到会听取了同学们的意见。

座谈会上，同学们用一分为二的观点指出了当前教学工作中存在的问题。他们认为，有的老师讲课理论性太强，授课跨度大、速度快，讲课内容与书本不一致，导致学生上课积极性不高，课堂气氛沉闷，学生感到枯燥、乏味；还有的学生指出，课室设备不完善影响了授课质量。还有的认为本学期学习课程太多，缺少时间进行复习和预习。

陈丁堂教授对同学们的建议和意见进行了点评。

石志民副教授传达了学院关于维稳工作会议的精神，再次强调稳定工作压倒一切，要求学生代表以身作则，排除干扰，专心学习。
