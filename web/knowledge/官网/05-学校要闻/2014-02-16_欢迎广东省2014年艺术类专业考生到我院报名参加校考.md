# 欢迎广东省2014年艺术类专业考生到我院报名参加校考

据《关于公布2014年我省普通高校招生艺术类专业校考院校及专业的通知》粤招办普〔2014〕1号文件确认，我院继续具有广东省艺术类专业校考资格。该文件指出，城市学院在2014年广东省高考艺术类招生时，可对其表演（音乐表演）、表演（舞蹈表演）两个专业组织校考。

据悉，我院校考报名时间是2014年2月25日--3月9日，考试时间定于2014年3月15-16日，具体考试相关事宜请登录网址查阅（http://csxy.dgut.edu.cn/zsb/ShowArticle.asp?ArticleID=7234）。
