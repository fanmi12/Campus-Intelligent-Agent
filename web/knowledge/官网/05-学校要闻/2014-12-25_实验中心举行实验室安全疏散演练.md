# 实验中心举行实验室安全疏散演练

12月22日，实验中心在3B实验楼举行了《东莞理工学院城市学院实验室安全疏散演练》，实验员、保卫办同志及安全工程专业2012级1班同学参加了此次演练。

“全体师生请注意，3B实验楼发生火灾，请大家不要惊慌，不要乘坐电梯。按老师的指挥有序安全撤离……”随着广播发出阵阵警笛声，实验楼全体学生在老师和工作人员的指引下，有序而快速地向安全区域撤离。工作人员随即拨打119报警，消防官兵随后到达现场，迅速展开“灭火救援”。最后，在消防官兵和全体师生的紧密配合下，人员全部撤离至安全区域，“大火”被及时扑灭，演练取得圆满成功。

通过本次实战演练，进一步提高和加强了我院教职工的安全责任意识，快速果断处理突发事件的能力，为实验室安全工作常规化、制度化奠定了良好的基础。

近年来，我院各级领导、部门高度重视实验室安全工作，狠抓规章制度落实，创建安全文化，开展了形式多样的安全教育活动，取得了显著的成效，安全形势一直保持着稳定良好的局面。
