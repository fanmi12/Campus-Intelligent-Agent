# 政法系把“模拟法庭”开设在中级人民法院

11月6日，政法系法学专业把“模拟法庭”搬到东莞市中级人民法院，为学生上了一堂生动的现实版断案课。此次活动得到了中级人民法院刑事审判二庭及东莞市同德社会工作服务中心负责人的大力支持，为我院学生提供了“实战”平台。

据悉，这次模拟审判的案子是法院已经宣判的真实案例。模拟法庭在开庭之前，同学们认真查阅了案卷，并撰写了庭上审判用语。

案情是这样的：被告人黄某、李某涉嫌抢劫。2013年2月8日下午，他们购买一把水果刀密谋抢劫私家搭客司机。当天晚上9点半，两人乘坐一辆私家车，在常平卢屋附近对司机实施抢劫。司机反抗，李某用刀将司机杀死，抢得现金120元及一部手机。

在模拟法庭上，政法系学生李明栓、蒋韶婷等15名同学分别扮演了审判长、书记员、公诉人、被告和法警等角色。同学们一个个正襟危坐、表情严肃，围绕案情引用法条、阐述法理，进行了一场生动而精彩的法庭审理表演。

在整个模拟审判过程，与真实的刑事案件审判程序基本相同，真实案件的原审法官也给予了指导。

同学们表示，这次活动让课堂知识得到了真实的应用，亲身体验了案件审判流程。

据悉，东莞日报、广州日报、东莞时报、东莞时间网等多家主流媒体报道了此次模拟法庭活动。
