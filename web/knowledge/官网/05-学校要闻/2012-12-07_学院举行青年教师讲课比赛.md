# 学院举行青年教师讲课比赛

12月6日，学院在7A114、7A115室举行了青年教师讲课比赛（决赛）。

本次青年教师讲课比赛分为初赛和决赛2个阶段，历时4周，共有143位青年教师参加了比赛。最后有19位老师进入决赛。

为了保证决赛的公平、公正性，教务处采取了提前一天通知评委，并把每组评委增加至12人，去掉最高分和最低分、参赛选手现场抽签决定分组和比赛顺序等措施。19位选手通过激烈比赛，黄璀、梁悦获得了一等奖，其余分获二、三等奖及优秀奖（具体名单附后）。

杨敏林院长、高香林副院长、陈丁堂督学分别为一、二、三等奖获得者颁发了证书和奖金。

2012年青年教师讲课比赛（决赛）获奖名单（同组排名不分先后）

一等奖：黄 璀、梁 悦

二等奖：胡静姝、陈光林、杨 玥、沈剑翘

三等奖：赵 影、王宽福、陈勇军、付佳荣、韩开军、庄瑞银

优秀奖：余 琼、陈东汉、周 琳、丁志清、李利民、陈小艳、张惠贻

杨敏林院长（左一）与一等奖获得者合影
