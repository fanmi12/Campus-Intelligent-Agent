# 客座教授、国家商务部吴国华副司长来我院调研

吴国华副司长（右1）参观新校区9月15日，我院客座教授、国家商务部副司长吴国华来我院调研。院长安少华给予了热情的接待。

在我院老校区，吴副司长参观了图书信息大楼，高度评价东莞市情资料室极具特色，称赞这是“高校图书馆的一大亮点，充分体现了高校服务地方经济、社会发展的功能”。随后，安院长陪同吴副司长驱车来到新校区。在听取了杨敏林副院长和黎建烨董事关于新校区规划、建设情况的汇报后，吴副司长对我院在短短几个月的时间里，建成了一座现代高等院校表示惊叹。
