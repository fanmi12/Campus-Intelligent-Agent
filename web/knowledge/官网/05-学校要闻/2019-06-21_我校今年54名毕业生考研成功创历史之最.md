# 我校今年54名毕业生考研成功创历史之最

今年，我校共有54名毕业生成功考取硕士研究生，成绩喜人，再次彰显了我校办学水平和综合实力的显著提高。6月21日，在毕业典礼上，我校设立“立志奖”对蹇铭会、吕佳纯等54名同学考研成功的毕业生进行了表彰。

据了解，在这批成功考取硕士研究生的同学录取高校之中，不仅有国内中山大学、暨南大学、广东外语外贸大学、华南师范大学、广州大学、湘潭大学、福建师范大学、江西师范大学和我国香港浸会大学、香港公开大学、澳门城市大学等知名院校，也有国外英国伯明翰大学、英国哈德斯菲尔德大学、日本宇都宫大学、澳大利亚悉尼大学、澳大利亚蒙纳什大学、法国诺欧商学院等国际知名大学。

对今年我校考研取得骄人成绩，教务处处长赵书山认为，这充分说明，经过多年耕耘，我校整体办学水平、学风教风、教研科研等都有了质的飞跃，师资队伍建设也有了显著的提升，招生生源素质也有较大的提升。也充分说明，我校在贯彻落实教育部新时代全国高等学校本科教育工作会议精神，坚持“以本为本”、“四个回归”，大力加强本科教育，加大人才培养方面取得了实质性成果。
