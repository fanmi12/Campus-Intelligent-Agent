# 学校“不忘初心、牢记使命”主题教育领导小组赴东纵纪念馆接受革命传统教育

9月28日上午，学校“不忘初心、牢记使命”主题教育领导小组赴广东东江纵队纪念馆开展革命传统教育活动。学校党政领导班子、各党总支（直属支部）书记等参加了活动。

上午9时，主题教育领导小组成员来到位于大岭山的广东东江纵队纪念馆，受到该馆宣传拓展部主任张俊等同志的热情接待。在党委书记章德胜同志的带领下，领导小组面对鲜艳的党旗，高举右拳重温了入党誓词，表达了为党的事业奋斗终身的决心。

学习会上，章德胜书记阐述了本次活动的重要意义，指出东莞是东江纵队的主要发源地和根据地，东江纵队革命先烈以坚定理想信念，维护中央权威，忠诚党的事业，坚守铁的纪律，与人民群众血肉相连，开展了艰苦卓绝的斗争，取得了伟大的胜利。这次学校“不忘初心、牢记使命”主题教育领导小组成员参观东江纵队纪念馆，就是要继承和发扬东江纵队高度的爱国主义精神和艰苦奋斗、不怕流血牺牲、一往无前的革命精神。全校党员同志要不忘初心，传承革命精神，自觉加强思想政治建设，有效提升自身的专业能力和工作水平；要牢记使命，坚持以习近平新时代中国特色社会主义思想为引领，发扬“东纵精神”，传承“红色基因”，奋力走好新时代的长征路；通过“不忘初心，牢记使命”主题教育，广大党员要率先垂范，爱岗敬业，用钉钉子的精神做好自己的本职工作，助推学校实现新时代教育发展新跨越；用春风化雨、润物无声的情怀教书育人，为国家输送合格社会主义建设者和可靠接班人，献礼新中国成立70周年。

领导小组成员聆听了张俊科长关于东江纵队纪念馆馆史及东纵精神的革命传统教育微党课，并跟随讲解员的步伐详细参观了纪念馆的各个展厅。

领导小组成员纷纷表示，经过本次革命传统教育，对东江纵队的历史与精神有了更深刻的理解和认识。通过缅怀革命先烈，学习、继承他们的崇高品质，沿着先烈的足迹砥砺前行，让我们更加坚定了理想信念，对开展好学校“不忘初心、牢记使命”主题教育有着重要的指导意义。
