# 我校召开“八一”建军节座谈会

今年是中国人民解放军成立92周年，在“八一”

建军节来临之际，7月3日，我校隆重举行庆祝“八一”建军节座谈会。校长王卫平、党委书记章德胜，学校相关部门负责人以及全校转、复、退教职工和学生代表70余人参加了座谈会。

座谈会伊始，全体与会人员齐唱中国人民解放军军歌。东莞市退役军人事务局代表、寮步镇退役军人事务办代表应邀出席了座谈会。

学生代表李文君同学汇报了从军的历程和返校复学的学习情况。

教职工代表、外国语学院院长赵东林分享了在部队的人生经历以及来到学校后的收获和感悟。

东莞市退役军人事务局移交安置与就业创业科科长钟汉钊对我校的拥军工作给予了肯定。

刘玉侠副校长对我校转、复、退教职工和学生表达了节日的问候，希望大家一如既往地发扬军人不怕苦、能战斗的优良传统，为学校建设继续贡献自己的力量。
