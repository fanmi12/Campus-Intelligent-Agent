# 我校召开2019年征兵工作动员会

6月5日,我校2019年征兵工作动员会议在行政楼112会议室召开。会议由后勤保卫处处长王锦锋主持。

退役士兵代表、学校国旗护卫队指导员姜祉卉同学在发言中，用“帼国不让须眉，谁说女子不如男”、“男儿何不带吴钩，收取关山五十州”的精神，鼓励同学们踊跃报名参军。

报名应征参军代表曹政财同学表示，在参观了部队的营地之后更加坚定了自己参军入伍的思想，并倡议同学们作为当代大学生应该带头参军，保家卫国。

后勤保卫处副处长刘维仝总结了2018年征兵工作及2019年征兵工作进展情况做了报告。我校2018年征兵工作经过新闻平台、微信企业号、班级会议、悬挂横幅和张贴海报、集中宣传动员以及在各职能部门的配合下，共有73名同学应征入伍，较好地完成了当年度的征兵工作，被省教育厅和省军区评为优秀征兵单位。

副校长刘玉侠就2019年征兵工作进行来部署，表达了全面做好本年度征兵工作的决心。

党委书记章德胜做了动员讲话。他要求校内各单位认真学习和贯彻落实习近平总书记关于建设“世界一流军队”重要战略思想，各司其职，做到特事特办、实事实办，全心全意支持和服务学生参军入伍，高标准、高质量完成2019年征兵工作。

刘维仝副处长传达了2019年全省征兵工作会议精神。征兵工作站凌继峰老师就本年度征兵工作对各学院负责老师进行了业务培训。

王卫平校长出席来会议。相关职能部门负责人，各学院副书记、辅导员以及学生代表共计150余人参加了会议。

目前，我校征兵工作进入了第二轮动员和报名阶段，有意向应征入伍的同学们可登陆全国征兵网进行报名。在征兵期间，校征兵工作站将协助同学们进行网上兵役登记、应征报名、资料打印等有关业务的办理和咨询。
