# 专注一心，孜孜以求

迷恋“澳门文化”的廖志毅，终于在今年2月与澳门科技大学结下了不解之缘。当3月底收到澳门科技大学金融学硕士研究生录取通知书时，他更加期待即将开启的读研之旅。

“澳门，对我来说，是一个神秘而又奇特的城市。”对大千世界满怀激情的廖志毅，在即将大学毕业面临读研抑还是就业时，他选择了前者，“当时就业目标还不是很清晰，我想，我需要一个平台去深造和成长。”然而，跨专业考研，对于计信系2013级电子信息工程专业学子廖志毅来说，并非一帆风顺。“金融学是澳门科技大学的三大优势专业之一，再加上考虑到今后就业的方向，我就选择了跨专业保研。”在保研意向书上，廖志毅在目标专业一栏填上了“金融学硕士”。

跨专业考研，对于本身金融学专业基础薄弱的廖志毅来讲，并非易事。由于一再犹豫不决，直到2016年12月，廖志毅才将目标院校及专业确定下来。廖志毅借来了《宏观经济学》《微观经济学》《资本论》等基础入门专业书籍，开始全身心投入备考。“那是我注意力最集中的一段时间，感觉自己从未如此专注过。”

经过两个多月的背水一战，2月18日，信心十足的廖志毅赴珠海参加面试。面试分为自我简介和问答两个环节，尽管激情满满，但面试中的一个小“乌龙”让廖志毅着实捏了一把汗。“当时，面试我的老师一连提了几个让我完全一头雾水的题目，把我紧张得手足无措，当时觉得再问下去自己肯定没戏了。”原来是面试老师将他的保研专业弄成了“应用经济学”，因而出现了如此尴尬局面。“知道是搞错了以后，我松了一口气。”回忆起来仍然心有余悸。

面试结束后的一个月，廖志毅在漫长的等待中期待着那一纸通知书。“面试当时感觉自己表现得一般般，但过后觉得还是很有希望能成功的。”当期待中的这一天真的来临时，“既是意料之中，也有小小的意外，就感觉自己的努力没有白费。”

谈及保研成功的优势，廖志毅调侃道：“可能是我面试时候比较厚脸皮，敢说敢讲吧。”但若没有之前的背水一战，又怎会博得幸运的眷顾呢？

经过这次磨炼，廖志毅给自己的保研之路总结了以下四点经验：一、平时的专业学习注重成绩绩点的提高；二、重视英语的学习，确保在本科期间至少攻下四级证书；三、积极参加各种比赛、活动，积累证书；四、多向考研或保研成功的师兄师姐取经。他还特别强调，目标院校和专业的确立一定要尽早，以避免陷入被动。

谈到自己的前景规划，廖志毅表示，首先将认真完成研究生学业，在将来争取做一名金融分析师，“希望将来能从事我所喜欢的工作，不辜负自己的努力。”
