# 我院喜迎5100多名新生入学

从9月7日开始，我院今年录取的5139名新生前来报到。

秋日校园，清凉唯美。经过精心布置，城院拱门高筑，彩旗招展，呈现一派喜庆气氛。

为方便新生报到，学院成立了迎新工作领导小组，在综合馆采用“集中接待、集中办公”方式为新生提供一站式报到注册服务。7日一早，校内车水马龙，迎新工作人员和学生志愿者各就各位，用热情、周到、细致的服务开始接待来校的新生和家长。

寮步镇政府对我院迎新工作继续给予大力支持，公安、交警、供电、工商等部门在新生报到期间，积极做好校园周边安全保卫、交通疏导、供水供电等工作，为迎新工作保驾护航。

据了解，今年我院录取招生5493名，其中普通类5139名，“专升本”学生354名。在5100多名新生中，学院再度迎来了18名“00后”，其中二名同学不满15周岁，成为全院年龄最小的同学。

据了解，今年我院招生再次取得历史性突破，新生生源质量再度提升。理科计划招生2218人，录取最低分数高出省线21分，录取分数最高为449分。文科计划招生2291人，录取最低分数高出省线9分，录取分数最高为479分。

另据了解，我院新增了工业设计、舞蹈编导、秘书学、投资学等四个专业，并联合美国中西州立大学及英国哈德斯菲尔大学首次推出金融学“2+2”国际班。
