# 开学首日学风浓厚

人勤春来早，新年新气象。3月5日，学院迎来新学期开学第一天，校园春意盎然，师生精神抖擞、活力焕发，开启了新的旅程。

上午8时30分，王卫平、林江龙等院领导和教务处、督导办、各教学单位领导来到教室、实验室，检查了新学期第一堂课的上课情况。从检查和各单位反馈的情况来看，教学秩序良好。教师教学准备充分，讲课有热情，课堂效果好。学生能按时到课，精神饱满，认真听课。各教学场地的教学设施、设备运行正常。

据悉，为保证顺利开学，3月3日，教务处分别组织召开了教学单位主任和教学秘书会议，对开学工作进行了认真布置和安排。教务处、实验中心、后勤保卫处等部门对教学楼、实验室、实习场地的设备设施，进行了全面检查。3月4日，图书信息中心也顺利完成了教材发放工作。
