# 我校教师在玉兰大剧院举行演出

5月20日晚，我校艺术学院王素娟副教授、邝富强、史博伦、王松联手在东莞玉兰大剧院给东莞市民和广大文艺爱好者带来一场大气磅礴的《咏·叹——中国经典诗词艺术歌曲专场音乐会》，使观众和广大艺术爱好者酣畅淋漓，感受艺术的陶冶，领略中国传统文化艺术的无穷魅力。本次音乐会由广东省音乐家协会副主席、东莞市音乐家协会主席崔臻和担任艺术总监，是东莞市“绽放的玉兰”艺术普及系列公益活动。

东莞市音乐家协会主席崔臻和老师，东莞市音乐家协会副主席刘友忠，东莞市音乐家协会副主席、南城文化服务中心副主任袁焕华，东莞市音乐家协会副主席刘汉超、那晓东，东莞城市学院副校长方伟华、科技处处长杨勇虎、教务处副处长寇有志，继续教育学院副院长刘亚雷、艺术学院院长张征、副院长康慧丽等领导出席了专场音乐会。

音乐会为听众们献演了19首中国古诗词声乐作品，其中包括唐代李白的《静夜思》《秋风词》《黄鹤楼送孟浩然之广陵》、高适的《别董大》、张继《枫桥夜泊》；宋代苏轼的《水调歌头》、陆游的《钗头凤》、辛弃疾的《青玉案·元夕》、蒋捷的《虞美人·听雨》、姜夔传谱的古曲《杏花天影》；元代贯云石的《红绣鞋·欢情》和清代王国维《蝶恋花·阅尽天涯离别苦》以及近代刘雪庵的《踏雪寻梅》、徐志摩的《山中》、樊孝斌的《枫叶之歌》、范曾《忆秦娥·恒山月》、艾青《我爱这土地》、席慕蓉的《父亲的草原母亲的河》等一首首脍炙人口的经典诗词。

我校抒情花腔女高音歌唱家王素娟和青年男中音歌唱家邝富强对古诗词歌曲饱含深情的演绎，与青年钢琴演奏家史博伦、青年小提琴演奏家王松的器乐演奏完美融合，袅袅余音，绕梁不绝，为观众们呈现了这场精彩绝伦的音乐会。

热爱音乐和古诗词的观众们亦跟随歌唱家的演绎而投入其中，他们会为李白思乡之情而惆怅，为李白、高适送别之时对友人的牵挂和不舍，展现出友情而动容；为《钗头凤》中陆游与唐婉凄婉的爱情绝唱而流泪。观众的情感随着歌曲的演唱而一次次的沉浸，为姜夔《杏花天影》所表现出对恋人的思念、《红绣鞋·欢情》中炽热甜蜜的恋情，《蝶恋花》中执手相看过渡到灯下的互相倾诉的重逢之悲苦，《我爱这土地》中爱的深沉，为《父亲的草原母亲的河》对草原家乡的爱恋和赞美而一次次的动容。

音乐会受到了在场观众的喜爱，多次响起热烈的掌声音。此次音乐会不仅让观众们欣赏了我校艺术教师的风采，也是我校艺术学院教师们的一次专业展示和对外交流，推进了我校美育工作和东莞市民文化艺术教育普及。
