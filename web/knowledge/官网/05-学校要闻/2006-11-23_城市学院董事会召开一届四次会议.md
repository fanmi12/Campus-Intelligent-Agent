# 城市学院董事会召开一届四次会议

11月22日,东莞理工学院城市学院董事会在行政楼315会议室召开一届四次会议。东莞理工学院院长、城市学院董事长杨晓西教授,东莞理工学院副院长、城市学院副董事长、院长安少华教授,东莞理工学院党委副书记王江水等董事和监事会全体成员出席了本次会议。

杨晓西董事长主持会议。会议听取了安少华院长关于新建图书信息中心大楼和院级领导班子及其架构调整的情况说明；一致同意图书信息中心大楼的资金由城市学院自筹解决,校本部给予一定的支持；同意城市学院院级行政领导架构为一名院长,两名副院长,不再设常务副院长一职；新任副院长的产生,按干部选任的有关规定和程序进行。
