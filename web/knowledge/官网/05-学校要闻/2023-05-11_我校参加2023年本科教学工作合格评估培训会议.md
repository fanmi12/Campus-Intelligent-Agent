# 我校参加2023年本科教学工作合格评估培训会议

5月6日，教育部教育质量评估中心组织召开2023年本科教学工作合格评估参评高校培训会议。我校副校长陈葆华，教学科研部、质量保障中心、人力资源部、财务资产处等职能部门负责人及相关工作人员以线上方式集中参加了培训会。

会上听取了教育部教育质量评估中心专家的辅导报告，让各高校对教学工作合格评估的背景、目标和要求以及指标体系的内涵有了更为深刻的认识和理解，促进学校进一步明确了评建工作目标、理清了工作任务、工作要点和工作程序，对指导我校未来几年合格评估的评建工作有很大帮助，参会人员纷纷表示，收获很大。

据了解，本科教学工作合格评估参评高校培训每年组织一次，旨在引导合格评估参评高校扎实做好评建工作，保障入校评估考察工作规范有序开展。
