# 财经系举办“感恩城院”手工制作大赛

5月20日，大雨如注，五号楼参观者却川流不息，财经系的“创意点缀财经 行动感恩城院”手工创意大赛吸引了许多学生前来观看。

参赛作品分别在5304、5305课室展出。这些作品样式缤纷，新颖独特，获得观众的好评。《双雀展屏》是用上百个拇指大小的蓝白纸折块镶嵌而成，开屏姿势优美，神态惟妙惟肖，意蕴城院奔向朝气而绚丽的明天。手抄报《爱在感恩》绘图细腻，字体美观，版面恰到好处运用暖色调粉紫，温馨和谐，表达出学生对城院衷心的祝福。贺卡《心声》平面卡片“心心相印”，象征城院学子祝福母校人才济济，桃李满天下。其他作品也各有特色，制作精美，创意独特，表现了同学们多才多艺的特点。

比赛评出了一等奖各三名，分别是：08会计6班的潘洁仪等三人组合的《心声》，08会计学1班吴馥莉、邓艳君的《爱在城院》，07国际会计1、2班黄玉清等同学的《双雀开屏》。二等奖有08国际会计2班招晓玉等同学的《Grateful》，06会计学2班何敏华的《情牵城院》，08会计4班卢敏的《心系城院》;三等奖有08会计学1班刘嘉炜等的《我爱城院》，08会计2班张文淇的《感恩城院》，07会计学3班萧嘉莉的《簇锦繁花》。另有数组同学获得了优秀奖。
