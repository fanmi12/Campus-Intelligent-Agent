# 郑甲申同学受聘奥运会工作人员

我院管理系05级人力资源管理班郑甲申同学，近日被奥运会射击管理中心调用，担任赛场工作人员，将于7月初赴北京奥运赛场工作。

奥组委于去年8月份开始在全国公开选拔竞赛管理人员。郑甲申同学经过激烈的初试和复试，最终在众多优秀竞争者中脱颖而出，于近日被奥运会正式征选为射击中心信息管理员。据了解，他是该竞赛项目在深圳市唯一一名被征用的工作人员。郑甲申同学将于今年7月初毕业后，直接奔赴北京奥运赛场工作。

据悉，郑甲申同学是国家一级运动员，在校期间曾任我院学生会副主席，是学院人力资源协会发起人之一。
