# 艺术系召开全系师生大会

会场安院长希望艺术系的师生要内强素质，外树形象，德艺双馨，品学兼优。

朱书记介绍了邓星明教授的工作经历和学术成就

邓教授表示要以学院创办全省一流的独立院校的目标为己任3月22日，艺术系在学院报告厅召开全系师生大会。院长安少华、党委书记朱志德出席会议并讲话。

艺术系党总支书记丘永辉老师主持会议。

朱志德书记在会上宣布了学院任命邓星明教授为艺术系主任的决定，并介绍了邓星明教授的工作经历和学术成就，他说，邓教授是中国高校影视学会会员、江西省文艺学会常务理事、江西省影视专业委员会常务理事。他从一名专业演员成长为职业编剧、市群艺馆文艺专干、大学文工团团长，并长期研究文艺理论，担任文艺比赛评委，完全有能力把艺术系工作做好。

邓教授首先感谢学院领导和全系师生对自己的信任，表示了将艺术系办成省内一流的独立学院艺术系的决心与打算。他说，艺术系是藏龙卧虎的地方，曾获得过许多奖项，为宣传学院、服务东莞作出了较大的贡献。希望艺术系学生在学好本专业课程的同时，加强语言表达和写作能力，努力提高自身的文化底蕴，做一名合格的大学生。邓教授还表示，以学院创办全省一流的独立院校的目标为己任，把艺术系办得好上加好。

安少华院长在总结讲话中，肯定了艺术系的工作，并希望艺术系的师生要内强素质，外树形象，德艺双馨，品学兼优。
