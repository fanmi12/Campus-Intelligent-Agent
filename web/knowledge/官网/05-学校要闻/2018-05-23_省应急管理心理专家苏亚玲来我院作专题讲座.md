# 省应急管理心理专家苏亚玲来我院作专题讲座

5月21日下午，学生处与人事处联合举办“大学生心理危机的识别与应对”讲座,邀请了广东省教育厅及东莞市政府突发事件应急管理心理专家、广东省高校心理健康教育与咨询区域中心专家委员会主任、广东省高校心理健康教育与咨询专业委员会副主任苏亚玲副教授担任主讲嘉宾。章德胜副书记出席了会议。

此次培训的对象为各院系副书记、辅导员、班主任及专兼职心理咨询师，旨在提高全体教职员工对心理危机状况的识别能力，增强危机发现的敏感性，提升心理危机干预技能。

苏亚玲副教授结合真实案例，讲解了什么是心理危机、心理危机的识别及干预。老师们表示，苏亚玲副教授的讲座非常 “接地气”，为大家在工作中如何应对危机状况提供了非常宝贵的经验和指导，也让大家在工作中树立起“危机”意识，学会用智慧的方法应对危机。

章德胜副书记向苏亚玲副教授颁发了“心理督导师”和“辅导员成长导师”的聘书。
