# 我校召开2019年重点学科建设推进及学科专业规划工作会议

5月16日，我校召开了2019年重点学科建设推进及学科专业规划工作会议。

谢小鹏教授对重点学科队伍建设与评估指标情况、2019年重点学科建设的工作计划、智能制造创新中心建设情况等进行了汇报了。他表示，机械工程重点学科目前已组建了比较稳定的骨干团队成员，并确定了三个研究方向，并制定了2019年重点学科建设的重点突破计划，明确了今后一阶段的重点建设方向。

研发处处长牛熠汇报了2021-2025年的学科专业规划。他从学校目前的学科专业现状、面临的机遇与挑战、存在的问题与不足、学科专业规划目标及保障落实等方面进行了介绍，并提出了打造学院“争一流、补短板、创优势、强特色”的智能制造类、新一代信息技术类、经管法类、特色文创艺术类4大学科专业集群规划。

学校董事长代表陈超群指出，学校将加大高层次人员引进力度，以加强学科专业建设的队伍，并优先保障教学需求。

王卫平校长强调，学校将继续推动重点学科建设。他指出，我校四个学科专业集群的提出紧紧抓住了东莞市及广东省的区域产业发展趋势，这将对提高人才培养质量起到良好的促进作用。

校领导高香林、黄兢、刘玉侠，以及有关部门和教学单位负责人出席了会议。
