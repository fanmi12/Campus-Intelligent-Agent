# 首届公寓心理文化专场活动圆满落幕

5月22日，由院学生处主办、文传系和学生处新苗社会工作服务中心联合承办的“首届公寓心理文化专场活动——幸福公寓·和谐人际”在学9宿舍区举行。学生处副处长孔增强、文传系党总支书记孟颖、学生公寓服务中心主任柳成荫、学生处思政科科长陈晓萍、文传系党总支副书记卢淑芳等出席活动的开幕式。

活动现场分为展示区、舒心阁、宣泄区和游戏区。展示区分别展示了心理常识、心理漫画作品以及笑脸照片，旨在使同学们了解更多的心理知识。舒心阁设立了新奇的投射卡，通过翻阅可以透视自己当前的心理状态，由老师给予解说和分析。宣泄区有树洞和宣泄器材，帮助同学们驱散负面情绪。游戏区有四个小游戏：顺序翻牌、玩转模型、盲人足球和“五颜六色”。心理活动首次走进公寓，吸引了众多学生前来参加。

据悉，本次活动是为加强公寓文化建设，促进心理健康教育，营造和谐融洽的公寓氛围，为同学们建立良好的公寓环境和人际交往创造条件。
