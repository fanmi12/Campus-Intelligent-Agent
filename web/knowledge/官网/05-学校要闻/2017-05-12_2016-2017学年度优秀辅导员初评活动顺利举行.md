# 2016-2017学年度优秀辅导员初评活动顺利举行

5月4日-9日，我院 “2016-2017学年度优秀辅导员”初评工作顺利举行。李伟健、曹镭、陈桂玲、惠梦瑶、徐媛媛、何珊珊、何伊丽、范淇、陈浩、邓雁虹、李玉春、苗琳、江玲等13位老师将作为初评优秀辅导员，参加本月下旬在校内举行的复评活动。

据了解，学院自办学以来，一直高度重视辅导员队伍建设。今年对优秀辅导员评选活动进行了改革创新。在院系初评环节中，参评辅导员先进行述职汇报，评委现场打分，再结合平时工作表现，评出院系优秀辅导员。再由胜出优秀辅导员参与全院评选活动。

本次初评活动中，辅导员们借助PPT演示，结合自身工作实际，从所带班级的实际情况出发，通过丰富的文字和图片资料进行汇报，阐释自己是如何开展大学生思想政治教育工作以及对工作的思考总结。

初评答辩现场，更是吸引了许多其他院系辅导员前来旁听,促进了辅导员之间的经验与心得交流。

另据悉，学生处已组织我院学生对李伟健等13位辅导员的工作开展情况，进行了民主测评。民主测评的结果将作为复评参考指标之一。
