# 我院荣获2008全国大学生数学建模竞赛大奖

获奖学生与指导教师廉玉忠教授（右一）合影

在2008年举行的全国大学生数学建模竞赛中，计信系学生刘坤明、梁柱辉、陈吉铜在廉玉忠教授的指导下，获得广东赛区二等奖，徐伟剑、李靖、蔡明明获得广东赛区三等奖。这是我院自2006年参加数学建模竞赛以来第三次获得大奖。

全国大学生数学建模竞赛是由教育部高教司和中国工业与应用数学学会共同主办的全国性竞赛，是全国高校规模最大、影响最广的大学生课外科技活动，也是本科院校教学质量评估的一项重要指标。通过竞赛活动，参赛学生的创新能力、数学和计算机应用能力、论文撰写能力得到了提高。
