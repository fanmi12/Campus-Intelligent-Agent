# 我院开展“知识产权”与“校园网贷”宣传教育活动

4月下旬至5月初, 学生处组织各院系对大一、大二、大三同学开展了“知识产权”与“校园网贷”宣传教育主题班会活动，以加强知识产权宣传与普及，教育和引导同学们树立正确的消费观念。

在各院系辅导员的精心筹备和指导下，知识产权与校园网贷主题班会纷纷开展起来。

各个班级根据专业的特点，开展了形式各样、内容精彩的主题班会。在政法系2014级社会工作3班，同学们结合专业相关知识，宣传普及了知识产权的相关法律知识。为了能让同学们更加清楚地了解校园贷的危害，管理系15人力资源1、2班专门举办了一场与“校园网贷危害”有关的情景剧，形象生动的表演、跌宕起伏的剧情、幽默风趣的台词，让同学们在欢笑中明白了校园网贷是什么，更清晰地了解它的危害。

此次“知识产权”与“校园网贷”宣传教育活动的开展，不仅解答了同学们对知识产权的疑惑，提高同学们的维权意识与尊重他人知识产权的意识，也让同学们了解到网络不法贷款的危害性，使同学们树立正确的价值观和消费观，提高风险防范意识，自觉远离网络借贷行为。
