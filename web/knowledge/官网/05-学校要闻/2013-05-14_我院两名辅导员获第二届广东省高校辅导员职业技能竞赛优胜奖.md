# 我院两名辅导员获第二届广东省高校辅导员职业技能竞赛优胜奖

第二届广东省高校辅导员职业技能培训暨竞赛活动5月7日—12日在北京师范大学珠海分校举行，我院计算机与信息科学系辅导员陈浩华与艺术系辅导员党家立双双获得优胜奖。

据悉，广东百余所高校共207名辅导员参加竞赛，人数比上一届翻了一翻，比赛也更加激烈。比赛内容包括自我介绍与展示、基础知识测试、写作（文书与微博）、主题班会、谈心谈话、案例分析等项目。
