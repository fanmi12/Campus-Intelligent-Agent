# 我院老师当选市侨联归国留学人员联谊会理事

6月9日，“东莞市侨联归国留学人员联谊会”（以下简称联谊会）成立大会在东莞市会议大厦二楼会议厅举行，中国侨联副主席王永乐、广东省侨联副主席华清文，市委常委、统战部部长李小梅等省市领导出席大会，并为联谊会揭牌。我院张林副院长、外事办主任袁宇航参加揭牌仪式。我院袁宇航老师作为城市学院留学归国教师代表当选为“东莞市侨联归国留学人员联谊会” 第一届理事会理事。

据悉，在我院近年招聘的教师中有曾在美国、英国、澳大利亚、香港等国家和地区留学的一批人员，同时，我院还定期派遣人员出国进修。这些具有海外留学背景的人才，为我院的发展注入了新的活力。

据了解，东莞是广东省第一个成立归国留学人员联谊会的地级城市。联谊会的官网也于当日正式启用。
