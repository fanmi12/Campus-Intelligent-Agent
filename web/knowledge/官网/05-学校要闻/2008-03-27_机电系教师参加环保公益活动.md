# 机电系教师参加环保公益活动

黄秋华老师正在讲解今年的冻雨雪灾天气的成因

孙成访博士正在讲解全球环境问题，呼吁市民保护环境，爱护家园3月15日,我院机电系孙成访博士、黄秋华老师应世博集团邀请,参加了在世博广场举行的 “世博源头•爱心暖流——保护同一片天空环保知识论坛”公益活动。参加这次活动的还有市环保局“创建国家环境保护模范城市小组”专员熊先生、世博集团副总经理房先生,200名城市学院学生和百余名市民。

这次活动的内容有,全球温室效应及雨雪天气强袭图片展览,乐助会慈善捐赠活动,保护同一片天空世博环保知识论坛,灾难教育电影和乐助会慈善义演活动。
