# 千余名学生参加我院艺术单考

广东省2013年普通高校艺术类专业单考城市学院考点23日34日在综合馆开考。

据学生处孔增强副处长介绍，今年报考我院艺考的网上报名的有1200人，现场报名的也不少，共计1123人次。此次招考有三个专业方向：音乐表演、舞蹈表演和影视表演。其中，考生报考音乐表演的比较多，约900人。

从今年开始艺术单考实行网上报名或预约来院的考试时间，这“两项创新”报名方式大大方便了考生，也得到了许多考生家长的认可，家长陪同考试的比往年明显少了许多。

团考大军 结队追梦

一大早就有一群学生乘坐大巴走赶来，涌向了综合馆的报到点。据记者了解，原来是培训机构星之苑的学生在其姚校长和10多名老师的陪同下参加我院的单考。

“我们的学生都是来自广东省各个地区的，今天就有150多个跟车过来，自行过来的有40多个。连续3年了，我们的学生都参加贵校的艺考，录取率也比较高。”星之苑姚校长介绍。

茂名双花 情系艺术

在报名核对处，有一对双胞胎特别引人注目。姐姐正拿着眉笔小心翼翼地为妹妹补妆、画眼线。她们是来自茂名化州的王冬俏和王冬贤。一身舞蹈服装，黑色的紧身运动裤和紫红色的上衣，头上盘着黑黑的长发。相对于其他考生，十八岁的她们个子虽不算高，但笑容灿烂，非常可爱。

“我们是双胞胎，报考了影视表演和音乐表演。爸爸很喜欢音乐，业余爱好是弹吉他。受爸爸的艺术熏陶，对音乐很感兴趣。”姐姐王冬俏娓娓道来。妹妹相对比较腼腆，微笑地站在姐姐旁边。

音乐梦想，复读作战

在家长等候室里，来自湛江的赖阿姨提着一个大皮箱，正静静地等候着考试出来的儿子。

“我儿子考的是声乐，他不是读艺术学校，只是普通高校。因为儿子喜欢音乐，去年考了一次但没有成功，复读了一年又来报考。”说到这里，赖阿姨叹了口气，说：“是啊，儿子很刻苦，，他提出复读时，我还不同意，后来看他很坚持也就同意了。”看得出，赖阿姨对她的爱子参加这次考试充满信心。

绿草守护 服务考生

“你好，请问你们已经网上报名了吗？”一名身穿绿色志愿服的志愿者亲切地向艺考生询问着。志愿者有的维持秩序，有的负责解答考生问题，有得帮忙提行李或考试器材，脸上总是带着笑容。

一位来自湛江的考生，很焦急地对志愿者说她忘记带五线谱了，不知如何是好。她在志愿者的帮助下，找到了打印的地方，终于拿到了五线谱，她非常感谢热情的志愿者们。
