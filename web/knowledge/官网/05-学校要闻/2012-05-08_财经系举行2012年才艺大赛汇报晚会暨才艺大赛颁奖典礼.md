# 财经系举行2012年才艺大赛汇报晚会暨才艺大赛颁奖典礼

5月6日，我院财经系“2012年才艺大赛汇报晚会暨才艺大赛颁奖典礼”在新校区学术报告厅上演。

院长杨敏林，副院长、财经系主任高香林出席晚会。新校区管委会综合部副部长黄兢，院团委书记杜鹏举、财经系党总支副书记叶凯贞担任嘉宾评委。

本场汇报晚会是财经系2012年才艺大赛的压轴大戏 ，晚会进行才艺大赛歌唱组和舞蹈组的决赛，以及才艺大赛其他赛事的颁奖，更有乐器组获奖选手的精彩演出。值得一提的是，晚会歌唱组的分数将由微博投票得分和现场评委评分两部分组成。

一首气势如虹、古典韵味十足的古筝曲《战台风》，拉开了晚会的序幕。而温柔动听的歌曲《不是故意》，活泼青春的《那些年》，以及热舞滚滚袭来的《百老汇三重奏》、《cry cry》、《Nobody》等充满大学生活力的舞蹈，更是把晚会的气氛推向高潮。同学们也为自己喜爱的选手送上了鲜花。

晚会尾声的一首《和你一样》，加上手语表演，展示了财经系志愿者的风采，让观众纷纷为之动容。

期间，晚会还进行了才艺大赛乐器组、书法组、手工组、摄影组和主持人大赛的颁奖仪式。

现场经过激烈的角逐，来自11级财务管理1班的邹新蓉以一首《不是故意》以及超高人气的微博投票夺得了歌唱组的冠军，舞蹈组冠军则有11级会计学3、4班的DGirl-Dark Girl组合摘得。

最后，财经系2012年才艺大赛在财经系辅导员、老师、工作人员以及选手们的《同一首歌》歌声中，圆满落幕。

据悉，财经系2012年才艺大赛历时近两个月，共分乐器组、书法组、环保手工组、摄影组、歌唱组、舞蹈组以及主持人大赛等七个类别。
