# 增城市正果镇百位领导莅临我院新校区参观考察

9月1日下午，增城市正果镇委书记黄沃波、镇长邓海军等一行100余位领导莅临我学院新校区参观考察。东莞理工学院城市学院董事、广东鸿发投资集团有限公司副总裁麦照平、黎建烨亲自接见。

在我院新校区考察过程中，东莞理工学院城市学院董事、广东鸿发投资集团有限公司副总裁黎建烨向正果镇领导详细地介绍了我学院新校区的投资、规划、建设、布局、工程进展等情况，并陪同正果镇百余位领导参观了学院气势恢宏的建筑群，给对方留下了极其深刻的影像。

随后，黄沃波书记、邓海军镇长等与麦照平副总裁前往广东鸿发投资集团有限公司总部举行了座谈会。该集团行政部总监叶俊向与会领导详细介绍了广东鸿发投资集团有限公司的基本信息、投资领域、发展战略、社会捐赠、党工建设、公司荣誉等情况。

黄沃波书记座谈会上发言，表示经过对我院新校区的实地参观考察以及对广东鸿发投资集团有限公司的了解后，“感觉很震撼，充分感受到了鸿发集团的实力”。他相信，只要正果镇委、镇政府能把握机遇，加强与鸿发集团的沟通与合作，便能使正果镇呈现新的面貌、焕发新的生机。据悉，广东鸿发投资集团有限公司在该镇投资建设有占地面积达100平方公里的“正果湖心岛”旅游区以及一家名为“聚龙庄”的旅游休闲农庄。
