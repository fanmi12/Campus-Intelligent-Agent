# 乒乓球协会举办首届东莞高校乒乓球联赛

4月19日，由东莞理工学院城市学院乒乓球协会发起的首届东莞高校乒乓球联赛在我院乒乓球馆圆满落幕。本届东莞高校乒乓球联赛全程由我院乒乓球协会组织策划，并得到体育教学部的大力支持。

上午10时，在开幕仪式上，我院体育部梁小龙老师发言致辞，参赛选手和裁判员分别宣誓。赛场上，选手们激情发挥，彰显出东莞高校学子的体育精神和良好竞技。

本次参赛队伍有东莞理工学院、东莞理工学院城市学、东莞职业技术学院、广东科技学院、广东创新科技职业学院、中山大学新华学院等六所高校代表队。比赛采取团体赛积分制，分男单、女单、混双三个项目，我院乒乓球健儿摘得第二名。
