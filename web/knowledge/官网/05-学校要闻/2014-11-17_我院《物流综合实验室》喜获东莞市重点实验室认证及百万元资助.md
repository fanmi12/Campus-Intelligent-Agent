# 我院《物流综合实验室》喜获东莞市重点实验室认证及百万元资助

根据东莞市科技局文件（东科[2014]-169号），我院“物流综合实验室”被列为东莞市重点实验室，并获得100万元资助。

据悉，该项目是2013年度东莞市唯一一项以高校为依托建设并获得资助的重点实验室。物流综合实验室升格为东莞市重点实验室后，将直接推动我院的物流人才的培养和科学研究工作上新台阶。同时，实验室的升级也必然会对东莞市的产业升级以及物流业持续发展提供智力支持平台。

据介绍，该实验室的负责人是我院管理系主任张佺举教授，学术带头人为教务处处长牛熠教授，主要研究人员包括管理系物流教研室6名教师以及计信系部分教师。

物流综合实验室始建于2007年，学院先后投入了500多万元添办教学实验设施与设备，打造成了具有领先水平的实验室。在满足基本物流实验的基础上，实验室增加了半工业化的立体仓库、工业工程模拟、物流系统规划模拟、物流仿真等物流综合管理模块和自动仓储、运输管理、供应链模拟等系统模块。同时，还建有ERP实验室、包装实验室、物流设计工作室以及物流增值实验室等。
