# 院领导看望新生及家长

上午9时，迎新工作进入高潮，综合馆人头攒动，各系报到点排起了条条“长龙”。东莞理工学院党委副书记吕琦元、城市学院院长杨敏林等领导来到迎新工作现场，看望前来报到的新生及家长，慰问参与迎新工作的师生。他们对井然有序的迎新工作表示非常满意。

吕副书记与杨院长先后询问了各报到点情况后，在新生报到处与两名金贸系新生谭咏欣、谢佩珊进行亲切交谈。当杨院长问到为什么会选择城市学院的时候，两人对杨院长说，学院的环境好，大家都称城院为“空调学院”。杨院长说，欢迎你们加入城市学院大家庭，我们会把城院越办越好，满足学生及家长对城院的要求。两个女生对学生社团十分感兴趣，学生处副处长杜鹏举得知这一情况后表示，期待有更多的学生加入社团，并透露在10月份各个学生社团将开启招新工作。吕副书记要求，城市学院要支持学生的个性发展，提高综合素质，让学生们快乐学习，学到一技之长。

记者了解到，谭咏欣、谢佩珊都是东莞本地人，两人约定一起报考城院。（作者：蔡冰儿 吴倩淳）
