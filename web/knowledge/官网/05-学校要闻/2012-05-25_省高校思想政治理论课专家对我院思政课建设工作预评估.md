# 省高校思想政治理论课专家对我院思政课建设工作预评估

5月24日，由深圳大学社会科学部主任刘志山教授，东莞理工学院思政部主任李洪君教授、副主任孙艳萍副教授，城市学院陈丁堂教授、李先庆副教授组成的预评估专家组对我院思想政治理论课建设工作展开预评估。

学院在学术报告厅召开了思想政治理论课建设预评估汇报会和情况通报会。东莞理工学院副校长安少华，城市学院领导杨敏林、朱志德、朱冰、张林、高香林出席会议。各部门负责人，各系部主任、党总支正副书记，思政部全体专、兼职老师，各系部辅导员参加会议。

刘志山教授介绍了预评估专家组的成员、预评估工作流程，并对我省思想政治理论课建设评估工作做了说明。

党委书记朱志德做学院思想政治理论课建设工作评估报告。朱书记从学院概况、思政课建设的基本情况、思政课建设的主要措施和成效等方面介绍了相关情况。报告认为，我院高度重视思政课建设，健全体制机制，积极创设良好的思政教育环境，充分发挥思想政治理论课主渠道、主阵地作用，不断加强师资队伍建设，提升教学水平。加强科研力度，强化科研意识，提高教师学术水平。通过努力，思政课的教学初步形成了鲜明的教学特色，即理论教育与行为训练有机统一的教学模式。通过规范思政课的课程建设和教育教学改革，教学效果突出，促进了学生的成长成才。

汇报会结束后，预评估专家组一行现场查阅了我院思想政治理论课建设的相关资料，实地考察了思政部的办公环境。

随后，预评估专家组组长刘志山教授向我院及与会人员通报了预评估意见。他指出，学院领导高度重视思想政治理论课建设，思政课教学工作井然有序，教学档案齐全，课程建设成效显著，教师队伍工作敬业，对我院思想政治理论课建设所取得的成绩给予了充分肯定。同时，他也指出了我院思政课建设工作存在的不足，并提出了宝贵意见和建议。

杨敏林院长在答谢辞中感谢预评估专家组从百忙中抽时间来我院进行预评估。我院将根据专家组提出的意见，抓紧时间整改，修改和完善迎评材料，迎接省专家组的正式评估。学院将一如既往地以评促改、以评促管、以评促建、评建结合、注重建设，以评估为契机，促进我院各项事业的全面发展。

据悉，省教育厅将于6月5日、6日对我院思想政治理论课建设工作进行正式评估。
