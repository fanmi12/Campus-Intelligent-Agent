# 我院学生创新创业训练工作成果丰硕

我院通过实施大学生创新创业训练计划，促进教育思想的转变，改革人才培养模式，强化对学生创新创业能力的训练，增强学生的创新意识、创业能力，为东莞及周边地区培养了一大批高素质应用型人才，取得了显著成效。

——积极开展就业创业教育。学院将就业指导课程写进人才培养方案，编写了《大学生就业指导与创业教育》教材，把创业教育作为重要内容纳入就业指导课程。通过举办就业讲座、创业大赛等形式，培养学生的创新精神和创业意识。

——近五年共设立大学生创新人才培养计划项目共90项。从2007年开始，学院每年都设置了“大学生创新人才培养计划”项目，同时还制定了《东莞理工学院城市学院“创新人才培养模式计划”实施办法》等文件，鼓励支持创新人才培养计划的有效实施。据统计，学院为上述项目的实施共提供资助经费近60万元。

——从2010年开始，学院开始设置了“大学生创新实验计划项目”10个，提供资助经费3万元。

——创新创业训练计划项目灵活多样。学院运用“挑战杯”、“精英训练营”、“大学生艺术团”、“大学生记者团”、“科技文化艺术节”、“精英班”等形式，组织学生进行创新实践能力的培养与训练。管理系相继举办创业班和工商模拟市场营销活动，已成为创业就业能力训练的品牌项目。2007年，学院先后投资800万元购置先进设备在计算机与信息科学系创建了电子创新实验室、软件工程与计算技术创新实验室。学院还与新东方教育科技集团合作，积极引进国家教育部推出的IT职业认证最有权威的认知项目NITPRO，针对企业岗位设计课程，实行全真案例教学，大力探索创新教育课程体系的改革。

——创新创业训练工作成绩骄人。由于学院高度重视对大学生进行创新意识和创新能力的教育与培养工作，办学水平与学生的就业创业与创新能力大大提高。近四年，我院学生在各项比赛中，先后获得国家奖项39项，省部级奖项108项。2008年，我院学生在全国大学生电子设计竞赛中获得一等奖。据悉，独立学院院校中我院是唯一获此奖项的单位。2011年在学士学位授予单位和专业评审中，我院17个本科专业获一次性通过。据省就业办数据统计，近四年我院学生就业率连年达到97%以上。近年，有不少毕业先后考取香港大学、中山大学等名牌大学的研究生。政法系于佩同学从城市学院毕业后，当年就考取华南师范大学硕士研究生，今年，他又考取美国南卫理公会大学的博士研究生。

大学生创新创业训练计划内容包括创新训练项目、创业训练项目和创业实践项目三类：创新训练项目适用于本科生个人或团队，在导师指导下，自主完成创新性研究设计、研究条件准备和项目实施、研究报告撰写成果（学术）交流等工作。

创业训练项目适用于本科生团队，在导师指导下，团队中每个学生在项目实施过程中扮演一个或多个具体角色，通过编制商业计划书、开展可行性研究、模拟企业实践、撰写创业报告等工作。

创业实践项目适用于学生团队，在学校导师和企业导师共同指导下采用前期创新训练项目（或创新性实验）的成果，提出一项具有市场前景的创新性产品或服务，以此为基础开展创业活动。
