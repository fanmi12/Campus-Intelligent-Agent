# 我院成立大学生记者团

2月28日,城市学院大学生记者团在315会议室召开成立大会。来自全院各系不同专业的36名新闻爱好者成为记者团的首批成员。

记者团在学院党委领导下开展新闻报道工作，业务上接受院新闻中心的指导，归口学生处管理。其主要任务是：配合学院中心工作，积极为院报、广播台、网络和省市新闻单位采写稿件，及时报道师生中的好人好事和校园的新变化、新发展；搞好通讯联络工作，充分反映全院师生的意见和建议。

成立大会上，学院党委委员、党委办王玉主任和学生处章德胜处长到会给记者团成员提出了希望和要求并为他们颁发了《记者证》。东莞日报记者程玮坚、刘爱林向大学生记者介绍了东莞日报《体育周刊》的有关情况。

会议由新闻中心主任周红兵主持。
