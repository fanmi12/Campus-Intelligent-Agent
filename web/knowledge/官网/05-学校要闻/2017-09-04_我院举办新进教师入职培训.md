# 我院举办新进教师入职培训

9月2日、3日，学院为28名新进教师在行政楼112举办了入职培训。王卫平、章德胜、高香林、黄兢、周庆、刘玉侠、林江龙等院领导和教务处、人事处、学院办公室等负责人出席了开班仪式。人事处副处长李海冬主持了这次培训。

王卫平院长在开班仪式上重申新教师入职培训的目的和意义，他表示学院将通过营造良好的工作生活氛围，落实各项教师发展政策，促进教师职业发展，希望各位新教师结合个人职业发展，加强自身的师德修养，提升业务能力，尽快融入城市学院团队，一起推动学院的改革发展。

入职培训共设八个专题讲座。刘玉侠副院长就我院发展历程、办学理念及办学特色做了宏观而深刻的讲解，并结合自身经历与新进教职工亲切交流，对各位新进教职工提出了殷切的期望。人事处副处长李海冬就我院最新改革的人事管理制度进行了详细的介绍；教务处处长牛熠作了教师职业发展专题汇报；教务处副处长鞠晓红对学院各项教学管理制度进行了细致的讲解。

此外，本培训内容还安排了东莞市情、东莞高等教育状况、学院科研政策、图书信息资源介绍等专题讲座，并邀请优秀教师作教学示范课讲解及教科研经验分享。

这次培训虽然时间短，但目标明确，内容丰富且具有针对性，参加培训的教师热情积极，反响良好。他们在接受记者采访时表示，通过本次培训，进一步加深了对学院的了解，明确了岗位职责和角色定位，坚定了个人和学院共同发展的决心。
