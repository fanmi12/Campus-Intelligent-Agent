# 我院印刷专业毕业生受企业青睐

2月12日，机电工程系印刷专业2012届本、专科毕业实习暨东莞新洲印刷公司招聘宣讲会在机电楼工厂举行。印刷教研室主任刘武辉博士，新洲印刷公司人事部和培训部负责人，印刷教研室部分教师与65名毕业生出席会议。

会上，印刷专业实践办主任尹建老师强调了实习纪律和安全问题，介绍了本专科毕业生毕业实习的安排与具体要求，希望同学们要高度重视实习工作，利用这次实习机会提高自己的动手能力。要吃苦耐劳，完成实习任务。要虚心学习，认真总结实习体会，写出实习报告。

东莞新洲印刷公司的负责人对同学们提出的问题做了详细的解答，并讲解了该单位招聘实习生的有关事项。

据悉，2012届印刷专业共有本、专科学生68名，在校学习期间基本掌握了印刷专业的理论知识和技能，包括东莞新洲印刷公司在内的多家印刷企业对我院毕业生给予了高度的评价，表示欢迎他们去企业顶岗实习和就业。
