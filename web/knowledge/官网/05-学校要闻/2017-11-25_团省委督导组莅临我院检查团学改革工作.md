# 团省委督导组莅临我院检查团学改革工作

11月24日上午，在团省委学校部部长、督导组组长廖庆春的带领下，广东省高校团学改革现场督导检查工作组一行5人莅临我院开展团学改革督导检查工作。院领导王卫平、章德胜、周庆，以及院团委专职团干、各院系团总支书记、学生干部代表参加会议。

会上，廖庆春部长阐明了本次督导的背景、主要内容、任务要求和重要意义。

院团委书记李瑶汇报了目前我院团学改革的进度和基本情况，并重点介绍了我院在“第二课堂成绩单”、“一试一优”工作激励机制等措施和特色亮点。

院长王卫平分别对团省委督导组的到来表示热烈欢迎，全力支持，积极配合做好督导各项工作。学院将认真落实督查组的反馈意见，切实推动改革措施落地。

督导组成员通过资料查阅、个别访谈等环节，对我院团学改革工作进行了全面了解，并进行了督导反馈。对我院在改革中的特色亮点工作，廖庆春部长给予了充分的肯定，就存在的不足和需要进一步努力的方向提出了意见和建议。

此次督导检查为进一步推进我院团学改革工作奠定了良好基础。学院团委将以此次督导为契机，扎实推进团学改革工作。
