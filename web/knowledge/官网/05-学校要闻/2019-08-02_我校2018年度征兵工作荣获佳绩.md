# 我校2018年度征兵工作荣获佳绩

8月1日下午，东莞市征兵工作会议在市行政办事中心召开，副校长刘玉侠、后勤保卫处副处长刘维仝与会。

会上，对2018年征兵工作突出的单位及个人进行了表彰，副校长刘玉侠被评为广东省征兵工作先进个人、我校荣获东莞市征兵工作先进单位。在2018年，我校圆满完成了征集任务。

据悉，我市今年征集任务为780名，其中女兵20名。东莞市委副书记、市长、市征兵工作领导小组组长肖亚非在会上强调，全市要落实好大学生征集“四优先”的政策，确保身体合格、政治合格的双合格大学生100%入伍。

今年，全市征兵工作于8月1日开始至9月30日结束，我校入伍学生上市站体格检查日期初步安排在8月13日。（作者：凌继峰，图：刘维仝）
