# 在2006届学生毕业典礼上的讲话

各位来宾、各位老师、同学们：今天，我们在这里隆重举行2006届学生毕业典礼。首先，请允许我代表学院，向圆满完成学业的370名毕业生表示热烈的祝贺！向辛勤工作、精心育人的全院教职工表示亲切的慰问和衷心的感谢！

同学们，在这几年里，你们伴随着学院朝气蓬勃的发展步伐，在城市学院度过了宝贵的大学生涯，取得了思想上、学业上的进步。今天，你们满载着学校和亲人的期望，从这里出发，又要开始新的更加壮丽的人生旅程。此时此刻，我与在座的同学、老师一样，心情十分激动，依依不舍。

作为你们的老师，我真诚祝福即将毕业的每一位同学。城市学院正是因为有了你们青春的身影和奋斗的足迹才变得更加精彩。你们不懈努力，积极进取，敢于拼搏，无愧于东莞理工人，无愧于城院人，无愧于当代优秀大学生。

作为学院的院长，我代表全体老师，对克服重重困难、顺利完成学业的同学们道一声：你们辛苦了，学院感谢你们！感谢你们对学院各项工作的支持与理解，感谢你们对学院的认同与呵护，感谢你们用自己的学识与行动，为创办具有创新特色的名牌地方院校所作出的贡献。

风劲帆满海天阔，俯指波涛更从容。在同学们完成学业，离开学校，即将踏入社会之际，我想提三点希望作为离别赠言，与大家共勉。

一、志存高远，终身学习。作为一名大学毕业生，首先要有远大的理想和抱负。大学毕业是人生旅途的一个新起点。在东莞这片充满活力的土地上，你们将面临很多的机遇和挑战。不论你们走到哪里，不论在什么工作岗位上，希望你们都能志存高远，热爱祖国，为民族的振兴和国家的富强而努力奋斗。树立终身学习观念，将学习作为一生的追求，在社会实践中不断充实和完善自己。

二、脚踏实地，勇于创新。要成就一番事业，并取得成功，不仅要有明确的奋斗目标，还要作不懈的努力。希望你们脚踏实地，爱岗敬业，诚信为人，勤勉工作，认真钻研，努力探索，把创新精神贯穿于自己事业的始终，争取有所创造，有所发明，在各自岗位上做出不平凡的业绩，为城市学院争光，为理工学院争光，为东莞争光！

三、自强不息，爱校荣校。母校是你们的家，你们曾在这里生活学习，成长壮大。诗人泰戈尔说：“无论黄昏把树的影子拉得多长，它总是和根连在一起，无论你走得多远，我的心总是和你连在一起。”此刻，我也要说，相信母校，你们前行的路上，母校会伴你一同成长。当你成功时，母校会为你欢呼，当你失落时，母校会给你慰籍。“海阔凭鱼跃，天高任鸟飞”。在这个伟大的时代里，希望同学们自强不息，不断超越自我，在平凡的世界里创造精彩的人生，开辟全新的一片天地。在今后的工作与创业过程中，要加强与老师、学长和师弟师妹们的联系，加强与母校的联系，多为母校的发展和建设献计献策！在学院的史册上留下辉煌的一页，让母校为你们而骄傲！

最后，祝同学们路路顺风，事业有成，前程似锦！
