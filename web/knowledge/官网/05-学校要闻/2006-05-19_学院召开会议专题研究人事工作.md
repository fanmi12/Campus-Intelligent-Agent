# 学院召开会议专题研究人事工作

5月17日，学院在405会议室召开会议专题研究人事工作。出席会议的院领导有院长安少华教授、党委书记朱志德和常务副院长程发良教授。安院长主持会议。

会议首先听取了人事处夏勇处长关于本学期人事处工作的汇报。

会议指出，人事部门应根据学院发展规模，按照职称、年龄、性别等比例参数制定出师资工作规划。要把引进具有高级职称的学科带头人和具有中级职称的人员作为工作重点。同时，要特别引进具有教学、管理“双肩挑”经验的人员。在原有人才引进审批程序的基础上，要增加新的审批渠道，提高引进工作效率，即求职简历可以通过教务处报主管领导同意后进入审批程序。

会议进一步要求，在近期内，学院要为各本科专业配备好教授和博士，并达到规定的指标要求。采取积极有效的办法，解决个别课程师资不足的问题，保障教学的需要。坚持外部引进与内部培养并重的原则，搞好教职工的继续教育工作，提高他们的学历和职称层次。提高教职工的福利待遇，进一步调动办学积极性。
