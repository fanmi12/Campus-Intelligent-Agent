# 学院召开“保障教学条件”座谈会

10月23日，张林副院长在行政楼407会议室主持召开“保障教学条件”座谈会。院办、人事处、教务处、新闻中心、总务处、财务处、实验中心、各系部主要负责人及部分教师参加了座谈，对教学、后勤、财务等管理工作提出了意见和建议，有关职能部门对一些情况作了说明，对部分意见和建议作了现场回答。

张林副院长总结时表示，此次会议效率高，城市学院主体搬迁后，各项工作都能正常运行，但也存在一些问题，大家对学院办公用房、学校网络、实验室建设、教职工住房以及财务等方面的意见和建议很好，各职能部门要尽快回复、处理。

张林副院长最后强调，各职能部门增强服务意识，提高服务态度，保证服务质量。

“没有老师和学生，就没有我们职能部门。所以我们要热情服务每一位老师，让他们感到自己就是城院的新主人！”
