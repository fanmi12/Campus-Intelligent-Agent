# 中国老区建设促进会领导到我院指导工作

与我院通江县籍学生合影

与院长安少华教授合影6月29日，我国老一辈党和国家领导人的子女虞大江、刘冀燕、陆健健等一行五人，在中国老区建设促进会副会长宋勤女士的带领下，来到我院看望在我院免费就读本科的革命老区四川通江县的10多名学生，参加了学院2008届毕业生毕业典礼，受到学院领导和学生的热烈欢迎。
