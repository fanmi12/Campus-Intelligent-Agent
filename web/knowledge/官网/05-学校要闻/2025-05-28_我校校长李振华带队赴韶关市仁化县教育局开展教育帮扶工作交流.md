# 我校校长李振华带队赴韶关市仁化县教育局开展教育帮扶工作交流

为进一步做好全口径全方位融入式帮扶工作，加强工作沟通和交流，5月23日下午，我校校长李振华带队前往韶关市仁化县教育局开展教育帮扶工作交流。仁化县教育局副局长邓伟强、仁化县教师发展中心主任谢普纲、仁化县董塘中心小学校长蔡政禧，以及东莞城市学院党委办公室主任叶凯贞、教务部副部长鞠晓红、语言文化学院副院长王宁等同志参加座谈。

会上，东莞城市学院党委办公室主任叶凯贞简要介绍了帮扶工作情况及下一步工作思路。她表示，前期的帮扶工作已构建起常态化共建机制，在学校管理、师资建设等方面成果初显，今年将按照工作计划继续推进帮扶工作。

双方探讨了今年暑期骨干教师培训方案，围绕培训目标、课程架构及实施路径展开积极交流，就强化师德素养、创新教学能力等模块达成初步共识。下一步将细化方案分工，确保暑期培训精准对接教师发展需求，为区域教育质量提升提供有力支撑。

会后，举行实践教学基地签约挂牌仪式。后续，我校将选拔优秀小学教育专业大学生开展实习帮扶。实习学生结合仁化县乡土与红色文化，协助开发特色课程，并协助当地教师开展教研活动，为学习困难学生提供课业辅导，助力当地教学质量提升。

未来，我校将发挥高校资源优势，完善精准帮扶运行机制。以课堂教学改革为突破口，驱动区域教育质量跃升；探索可持续合作模式，构建校地协同发展共同体，为韶关市仁化县基础教育建设注入新动能。
