# 学院隆重举行2006—2007学年度学生先优表彰大会

1月4日，学院2006—2007学年度学生优秀班级、优秀学生表彰暨学风建设总结大会在大礼堂隆重举行。11个先进班集体、校园“十佳”学生、1010名优秀大学生榜上有名。1081名大学生分别获得一、二、三等奖学金，奖金总额117万元。

学生处处长章德胜副教授主持会议，并宣读了学院《关于表彰2006—2007学年度先进班集体、校园“十佳”、优秀大学生标兵、优秀大学生、优秀学生干部及奖学金获得者的决定》。在热烈的掌声中，东莞理工学院副院长、城市学院院长

安少华教授，党委书记朱志德、副书记朱冰，院督学

林世俊教授，教务处处长

邓成良教授，院团委书记丘永辉老师分别向先进个人和先进集体颁发了荣誉证书。

会上，朱冰副书记作学风建设总结报告，她在报告中总结归纳了今年学风建设的作法与特点，肯定了受表彰的先进集体与先进个人在过去一年中所取得的成绩，同时希望他们继续保持成绩，戒骄戒躁，在今后的学习、生活中取得更好的成绩，号召全院同学向受表彰的先进集体与先进个人学习，切实把我院学风建设推向新阶段。

院长安少华

教授在会上作重要讲话，对获得先进集体、先进个人荣誉称号的班级与学生表示热烈的祝贺，对与会同学提出了殷切的希望。他说，中国已进入了一个新的历史起点，广东省将出现新一轮的大发展。为此，我们大学生要放眼天下，胸怀祖国，瞄准未来，树形象，长知识，强素质，引领时代潮流，当改革创新的先锋，做同学们的表率。

“十佳”学生财经系潘佳媚同学代表获奖者发言，表示将继续刻苦学习科学文化知识，重视加强实践技能和创新能力的培养，不断认识自己，提高自己，以更加优异的成绩报效学校、父母和社会。

据悉，本次会议上，还有2400多名同学获得国家、广东省及企业近300万元的助学金。
