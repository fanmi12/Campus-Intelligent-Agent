# 2013级新生昨日开始军训

1月4日，当太阳还未爬上山头，校园的田径场、林荫校道、鸳鸯湖边就出现了一道道亮丽的风景线：帅气的军服，威武的军姿，响亮的“一、二、三、四”口号声，整个校园沉浸在“海浪花”的世界中。我院2013级学生在这里进行紧张的军训。据悉，本次军训为期9天，军训内容包括：队列、内务、国防知识教育、校规校纪和部队光荣传统教育，一切活动实行半军事化管理。

上午9时，军训团举行开训仪式。4700多名大一新生身着统一的海军训练服，集聚在田径场上。院长杨敏林，党委副书记章德胜，沙角部队军训团团长周华东，以及各系党总支副书记等出席开训动员大会。

随着国歌声响起，庄严的五星红旗冉冉上升，军训学员深情地唱起了国歌。

升旗仪式结束后，章德胜副书记发表讲话，他代表军训师生热情欢迎承担本次军训任务的沙角部队官兵，感谢官兵们为学院带来了部队的好作风、好传统和过硬的军事技术。接着，他着重强调了军训的意义、作用、内容与要求。他说，通过军训，同学们要增强国防意识，学习军事技术，了解国际国内的形势，像解放军那样，敢于担当，学好知识，为实现强军强国之梦做贡献。希望同学们在军训中，不怕苦，不怕流汗，一招一式都要体现当代大学生的风采。

最后，杨敏林院长向军训团周团长授旗。红旗在风中飘扬，在团旗交接的一刻，全场掌声雷动。

据悉，本次军训共分为14个连队进行，设有勤务、新闻报导等后勤保障团队。1月12日举行阅兵式，各连汇报军训成果。
