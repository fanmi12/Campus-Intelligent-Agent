# 文传系成立数字媒体艺术专业建设指导委员会

为了从宏观上指导我院数字媒体艺术的学科发展，科学地把握该学科的专业方向，稳步地提高数字媒体艺术专业教学水平，10月23日，经学院批准，文学与传媒系成立了数字媒体艺术专业建设指导委员会。东莞理工学院文学院严前海教授、深圳大学田少煦教授、广州美术学院陈赞蔚副教授，广东韵华文化传播有限公司邹卫总裁等专家受聘担任委员会成员。

成立大会上，副院长高香林教授宣读城市学院关于成立数字媒体艺术专业建设指导委员会的文件。随后，高香林副院长给外聘专家发放聘书并与他们合影留念。

文传系主任邓星明教授主持召开该专业建设指导委员会第一次会议，向各位专家介绍了数字媒体艺术专业建设情况及存在的问题，并就数字媒体艺术专业人才培养方案进行了深入的探讨。
