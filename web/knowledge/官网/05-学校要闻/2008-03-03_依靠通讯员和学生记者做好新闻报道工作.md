# 依靠通讯员和学生记者做好新闻报道工作

2月29日，学院新闻中心召集学院各系部教师通讯员和大学生记者团全体成员在410会议室召开会议。党委宣传部部长、新闻中心主任何鹏举副教授在会上发表了讲话。

《城市学院报》主编唐耀碧老师在会上通报了去年各新闻单位采用我院新闻稿件的情况。他介绍说，2007年省市媒体发表城市学院新闻稿150多篇，媒体报道呈现出三大特点：数量多，影响大，效果好。与此同时，学院新闻报道工作和通讯员队伍建设有了长足的进步，这些都倾注了通讯员和大学生记者的心血，为塑造城市学院形象起到了积极的作用。希望大家继续围绕“解放思想”的主旋律、围绕歌颂改革开放30年等宣传重点多写稿，写好稿；整合校园媒体资源，发挥广播、网络、报纸的互补性，提高宣传报道的质量。

大学生记者团指导老师、江汉大学人文学院程汉民副教授介绍了本学期的培训计划和培训内容。他强调，新闻写作培训将搞好四个结合：理论与实践相结合，课内与课外相结合，讲授与研讨相结合，提问与答疑相结合。

会上，新闻中心主任何鹏举副教授说，要做好学院的新闻报道工作，需要大家的支持与配合，希望老师和同学们一如既往地热情地宣传报道新人新事。

据悉，新闻写作培训班将于本周开始，培训时间为周五晚上7：30 和周六上午9：00。欢迎有志于新闻写作的同学参加。
