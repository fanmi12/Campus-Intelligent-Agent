# 我院艺术类单独考试正式拉开帷幕

2月25日，我院艺术类单独考试正式拉开帷幕。考试从9：00正式开始，截止到下午16:30，来自省内外近500名考生报名考试。

学生处副处长陈建新老师指出：“考生从报名到考场，报名表一直由工作人员拿着，一对一的接待,考试现场抽题，并由纪检人员全程录像。我们做足了监考等考务工作，实现了公平、公正、公开的考务制度。”

天气有点冷，考场却很热

天灰灰，雨蒙蒙，但阴冷的天气却没有阻挡考生的参考热情。记者从密密麻麻的报名单上发现，大部分考生报考的是音乐表演专业。相比较而言，舞蹈表演和影视表演的考场要冷清一点。艺术系主任邓星明教授解释说：“历来都是报考音乐表演专业的较多，音乐表演对基本功、反应能力、身高，形体等方面的要求没有影视和舞蹈表演专业那么高，舞蹈表演的难度更大，要求更高。据粗略分析，生源大部分是省内的，而省内考生又有一半是东莞市的。因为省外的招生指标少，所以一般没有单独设考点。”

亲情友情齐上阵

记者发现，大部分考生都是三五成群结伴而来，有的由父母兄弟陪着，有的由老师朋友领着，有的由师兄师姐带着，很少有单独行动的。

来自阳江的20多位考生，前天就统一包车来到学府公寓。负责接待他们的艺术系大三学生林雪燕说：“为了能让他们考出好成绩，我们帮助考生提前进琴房练习。”

艺术系刚毕业的叶师兄亲自带着他的弟弟过来应考了。他说：“我是这里的毕业生，对母校很了解，确实学习到了不少东西，因此就推荐弟弟过来应考。”而他弟弟则透露，这次艺术单考只报了城市学院，真可谓是“孤注一掷”。对于哥哥的陪考，他自己内心也是充满感激的，表示会努力应考。

“团考”大进军

“昨天我就来到城市学院帮助学生们提前报名。我校学生报考城市学院人数最多，有150多人，大大超过深圳大学。这次是第一次组团来参加考试的。去年，我校也有一些学生考上了城市学院。学生不断称赞这里的师资和环境都很好，收取的学费也不高。我们这次包了三辆大巴组团过来的。”广州星之苑培训中心黄校长告诉记者。记者采访发现，本次单考很多考生都是组队组团前来参加的，一个团队少则3、5人，多则上百人，而考生选择城院主要的原因有以下几点：一是师资力量雄厚；二是环境优美；三是口碑好；四是离家比较近。
