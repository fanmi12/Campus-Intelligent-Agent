# 东莞市人民检察院宣讲团来我院开展廉洁修养专题教育

12月22日，东莞市人民检察院宣讲团房洁检察官应思想政治理论课教学部的邀请，来我院为大一新生做“廉洁修身，走好幸福人生”的专题教育，旨在提升大学生的法制观念、法律意识。

房检察官先向同学们介绍了刑事司法程序和检察院的职能，纠正了部分同学对检察院作用认识上的误区。接着，她着重讲解了廉洁的内涵、廉洁修身的重要性，大学生如何做到廉洁等问题，并列举了大量真实的案例，加深同学们对知识的了解。最后，房检察官勉励同学们要廉洁自律，争做模范公民。
