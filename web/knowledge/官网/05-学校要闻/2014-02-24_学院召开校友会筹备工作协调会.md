# 学院召开校友会筹备工作协调会

2月20日，我院在行政楼会议室召开成立校友会筹备工作协调会。会议由院办黄兢主任主持，各系（部）有关工作人员参加了会议。

据会议透露，为加强校友与母校之间的联系与沟通，本次会议决定各系（部）推荐4-5位校友作为首届理事会候选人；尽快做好成立校友分会、联系校友、建立校友信息数据库和宣传报道等工作，争取在今年3月底之前完成各系（部）校友分会成立工作。
