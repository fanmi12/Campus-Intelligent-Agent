# 我校师生在第六届全国大学生人力资源管理知识技能竞赛(精创教育杯)中喜获佳绩

第六届全国大学生人力资源管理知识技能竞赛(精创教育杯)暨高峰论坛于2021年5月15日-16日在广州新华学院举办。来自广东、广西、湖南、海南等地的53所本科院校同台竞技，切磋交流。我校商学院2018级人力资源管理专业谢伟杰、吴佩卿、叶顺昌、林学彬4位同学在贺冬怡、李凌洁老师的带领下取得历史性突破，斩获大赛综合一等奖，理论知识考评一等奖，软件经营模拟二等奖。

商学院代表队从3月初的院内选拔赛到5月份大赛的圆满结束，经过两个多月的摸爬滚打、集中备战、不断摸索、不断超越，终于在15日的9：00至19：00，历时十个小时的团队智慧大比拼中，抵住了强劲的竞争对手与高压的市场环境带来的压力，并积极采用应变方案，发挥平日训练成果，取得了突破性的成绩。

学校重视人力资源管理专业教学改革与创新，秉持“以赛促教、以赛促学、以赛育人”的理念，通过参加学科竞赛促进学生学以致用，培养学生创新精神与实践能力。通过本次大赛也展示了我校新商科人才培养的良好效果。
