# 机电系与东莞岳丰公司联手举办CAD设计大赛

机电工程系根据专业特点，与东莞岳丰科技有限公司联手举办电气插头插座CAD设计大赛，5月6日，岳丰科技有限公司总经理助理孙伟，应邀来我院为参赛选手介绍产品设计要求。

据悉，岳丰科技有限公司为台资上市公司，在东莞、无锡等地设有分公司，产品主要销往美国等国家。
