# 我院再添一家就业创业基地

7月13日上午，我院与平安普惠企业管理有限公司东莞分公司举行合作共建就业创业基地揭牌仪式。

学院副院长黄兢、招生就业处就业中心江小卫主任和平安普惠东莞分公司总经理刘祖英、人事培训部总监段文慧共同为“就业创业基地”进行揭牌。

双方此次合作的达成，将为学院在人才培养、毕业生就业等方面带来新的契机。
