# 我院第一届“我为英语狂”英语口语比赛总决赛

5月25日晚，我院第一届“我为英语狂”英语口语比赛总决赛在学院大礼堂隆重举行。本次比赛由文学与艺术系英语教研室和我院英语俱乐部主办。旨在丰富大学生的课余生活，增强同学们对英语学习的兴趣和主动性。

本次总决赛共有8名选手，比赛过程共有四个主要环节，它们分别是：选手自我介绍、以“I have a dream”为主题的现场演讲、以“校园活动和学习谁重要”为主题的辩论赛、“最具人气奖”现场投票活动。其间还有小游戏和歌唱表演两个节目穿插其中。最后，文学与艺术系主任张林副教授对此次总决赛作点评，他的短短一席话让在场的同学们受益匪浅。他用流利的英语说：“Generally speaking，this contest is a great success，but we have a long way to go to become a good speaker of English……”

经评选，获得本次“我为英语狂”英语口语总决赛的前三名分别是：文学与艺术系李小冰同学、机电系傅博同学和管理系傅萱同学。 随后，副院长林世俊、党委副书记朱冰书记等院领导分别为参赛者颁奖。
