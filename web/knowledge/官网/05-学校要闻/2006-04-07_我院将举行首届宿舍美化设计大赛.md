# 我院将举行首届宿舍美化设计大赛

近日，院学生会发出通知，将于4月20、27日举办城市学院首届宿舍美化设计大赛。这次大赛的目的是培养同学们美化宿舍、美化校园、美化生活的卫生与健康观念，展现当代大学生高尚的思想情操和精神风貌。

宿舍美化设计要有一定的艺术性，简洁整齐，艺术高雅，温馨浪漫。以宿舍为参赛单位，报名时间为4月6日至4月13日，评比日期为4月20日和27日。
