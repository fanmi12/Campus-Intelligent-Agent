# 学院举行机关教辅单位学年度考核民主测评会

6月26日，学院在112会议厅召开机关教辅2013-2014学年度民主测评大会。杨敏林、王卫平等院领导出席会议。

党委副书记、工会主席章德胜主持大会。

民主测评会上，11个机关教辅部门的负责人分别向大会代表进行述职，汇报本单位一年来的工作完成情况。各位代表成员按《东莞理工学院城市学院机关、教辅单位（服务对象）2013-2014学年度考核测评表》和《东莞理工学院城市学院机关、教辅负责人2013-2014学年度考核测评表》打分。

65名教职工代表对11个机关教辅部门负责人的工作绩效进行了民主测评。
