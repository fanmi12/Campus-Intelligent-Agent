# 我院举办招生工作人员业务培训班

为使录取工作符合招生的政策规定，学院于7月18日举办了参加远程录取工作人员培训班，学院招生就业办公室主任陈建新传达了教育部有关招生录取工作的文件精神。

学院党委副书记、学院招生领导小组副组长朱冰与会。她要求大家本着为学校负责、为考生负责的精神做好录取工作；工作细致有序，程序严格规范；努力提高生源质量；要严格遵守招生纪律，遇到问题要及时汇报，重大决策由学院招生工作领导小组集体研究决定。
