# 《乔将军逛市场》等三件作品获全国高校校报好新闻奖

12月20日，全国高校校报协会2012年年会在武汉市召开，会议公布了2011年全国高校校报好新闻的评选结果，我院有三件作品分别获得好新闻三等奖。

此次评选作品类别分为消息、通讯、言论、图片和版面五大类，每项各高校限报两件作品。文学与传媒系2011级林泽端同学采写的消息我院《2011年大学毕业生招聘会盛大空前》获消息类三等奖，文学与传媒系2011级朱梦雯同学采写的通讯《三个大学毕业生与一部本土电影》获通讯类三等奖，新闻中心张少炎老师拍摄的图片《乔将军逛“工模”市场》获图片类三等奖。
