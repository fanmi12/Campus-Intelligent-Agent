# 机电工程系召开专业建设会议

5月18日，机电工程系在8A313会议室召开了机械设计制造及其自动化专业建设会议。

会上，系主任赵天婵教授、实践办张锦荣老师、系总支副书记唐征玲老师等先后介绍了机制专业建设方案、实验室建设、学生学习调查及机制创新班活动计划、中图杯比赛的准备情况。与会人员就专业特色、专业发展规划、课程体系建设、教学方法及模式的改革、实验室和实践基地建设、师资队伍、产学研合作方式、学风建设措施等工作提出了建设性意见。
