# 【众志成城 抗击疫情】我们相约线上——主题征文选登⑥

我校重点关注学生在线学习的效果，切实保障网络课堂的教学质量。学校领导提出，“生活就像海洋，只有意志坚强的人才能到达彼岸，在这最艰难的时期，我们不仅要确保身心健康，同时积极利用这次‘网络教育’的机遇，主动适应学习方式、学习环境和学习形式的变化”。从3月19日起，我校组织了《我们相约线上》学生主题征文活动，今天推出的是第六期作品选登，推介文学与传媒学院李艳清、外国语学院何美琪、外国语学院叶文熙三位同学的征文作品，欢迎大家踊跃来稿，积极参与讨论。

一、预料与意外

——文学与传媒学院 李艳清

谁也想不到以前设想的网络学习竟然以今天这样的情况实现了。一个月以来的学习，对于不同的老师体现的效果不同。对于我而言，总体感觉还蛮好，在我身上甚至比在课堂还认真听讲，每一科都有专门的笔记本。不过课堂前后的视频任务比较多，需要自己多花时间完成，这点上比在学校线下复杂了。专业课的老师都挺好的，最喜爱的还属我们现当代吴欢老师的课程，声音甜美而且为人亲和，讲课还能看到我们评论区的留言并给予回答，这是距离缩短的好处，课后交给我们的阅读任务，书籍都是很不错的文学作品，丰富了我自己的阅读，非常感谢老师的推荐。如果突然通知我回学校上课，我可能还缓不过来，无论如何，珍惜网课。

二、观后感

——外国语学院 何美琪

看了三个近代史视频之后，我的心情久久不能平静。我看到了当时的清朝是多么的腐败，统治者是多么的愚昧，还沉浸在天朝大国的美梦当中！而当时的西方国家早已进行工业化，日益强大起来侵略我们的国家，古老的东方大国被迫卷进时代的潮流。当时少有的开明之士也被流放迫害，看着真令人痛心。落后就要挨打！最终大清朝也受到了血淋淋的教训！所以国家不能固步自封，没有一个国家能远离世界独自发展的，要不断改革创新！只有国强民富，才能立足于世界民族之林。

三、春已立，寒未散，共同抗疫，未来可期

——外国语学院 叶文熙

在观看了全国大学生同上一堂疫情防控思政大课后，我对如何履职，共同抗疫有了深刻的认识，明白“疫情就是命令，防控就是责任”。在这场与死神抗争，与时间赛跑的阻击战中，无数人为了守护人民健康，义无反顾。而作为当代大学生，我们要树立起家国情怀，热爱自己的国家，如同在此次疫情中许多90后、00后都义无反顾的奔赴武汉，贡献出自己的一份力，坚定不移把各项防控部署落到实处，我相信武汉会过关，中国会过关，必将夺取疫情防控的伟大胜利！
