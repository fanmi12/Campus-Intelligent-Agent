# 城市学院举行新生军训汇报表演与开学典礼

2005年9月26日下午，城市学院在大操场举行新生军训汇报表演和开学典礼。秋雨过后的天空阳光灿烂，近三千名新生在三名护旗手的引导下，迈着矫健的步伐，经过主席台。他们动作整齐、口号嘹亮、军姿威武。阅兵式之后，学院给军训先进集体与个人颁发了锦旗。接着，开学典礼在飘扬的国旗下进行。学院院长安少华教授致词，学生代表、老师代表也先后发言。东莞军分区司令员王福广少将、东莞理工学院院长杨晓西教授等领导参加了这次典礼。
