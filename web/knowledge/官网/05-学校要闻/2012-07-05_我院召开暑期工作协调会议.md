# 我院召开暑期工作协调会议

7月4日，我院在4315会议室召开会议，安排暑假工作。院领导杨敏林、朱志德、朱冰、章德胜，张林，王玉、夏勇出席了会议。各系、部、处领导参加会议。

院办主任王玉首先就暑假工作安排做了说明，重点强调了“服务东莞，创新发展”的相关调研活动以及部分教师及机关工作人员的搬迁工作的具体安排。

党委书记朱志德希望大家尽力配合学院，做好暑期各项工作。各部门领导要做好表率，完善过渡时期各项安排。

院长杨敏林强调，今年暑假涉及招生与过渡两项重要工作，希望各部门能紧密配合，有步骤地解决当前工作中存在的问题，要以成洪波书记提出的“把城市学院办好”为共同目标，保障暑期工作顺利进行。
