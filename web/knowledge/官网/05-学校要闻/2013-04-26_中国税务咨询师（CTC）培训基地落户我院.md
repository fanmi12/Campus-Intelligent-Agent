# 中国税务咨询师（CTC）培训基地落户我院

4月26日，中国税务咨询师（CTC）广东学习中心与我院就业指导与培训中心成功签约，标志着中国税务咨询师（CTC）职业培训项目实训基地正式落户我院。

据了解，中国税务咨询师由国家人力资源和社会保障部中国就业培训技术指导中心（China Employment Trainingruction Technical Instruction Center,简称CETTIC）认证、颁证，旨在培养熟练掌握国内外财税法规及各项优惠政策，根据企业发展目标和业务特点制定税务规划，依法统筹各项税务关系，确保国家税务政策贯彻执行，能够为企业经营、投资、理财、组织和交易等决策提供涉税方面的专业建议的高层次、复合型实战专业人才。
