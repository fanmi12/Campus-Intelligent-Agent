# 我院赴大连两所高校考察调研

一年之计在于春。为更好地做好《学院发展战略规划（2011-2020）》和学院今年各项重点工作，3月31日至4月2日，院长杨敏林、副院长高香林、院长助理麦绮琳、院办主任黄兢、组织人事处处长胡钦华等领导赴大连理工大学城市学院、大连东软信息学院两所高校进行考察调研。

这是继3月中旬对湖北两所知名独立学院考察学习之后，学院和部门领导再次积极走出去，进行学习调研，以提升办学能力与水平。

此次通过开展实地考察调研、组织召开座谈会等形式，详细考察了两校的学科专业建设、人才培养体系、师资队伍建设、薪酬体系及发展战略规划等情况，并对办学中共同遇到的问题进行了交流探讨。
