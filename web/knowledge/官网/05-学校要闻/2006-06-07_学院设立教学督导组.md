# 学院设立教学督导组

为了加强教学管理，强化监控机制，全面提高教育教学质量，完善院系两级教学质量监控体系，学院决定设立教学督导组。

6月2日，学院还下发了《东莞理工学院城市学院教学督导组工作管理办法（试行）》文件。文件对教学督导组的组织原则、职责权利和工作要求，作了明确的规定。

据悉，教学督导组成员由学院聘请学术水平较高、具有高级职称、治学严谨、教学经验丰富、熟悉高等教育教学业务、健康状况良好的退休教师或在职教师担任。教学督导组的日常活动归教务处管理。

秘书：梁克文；
