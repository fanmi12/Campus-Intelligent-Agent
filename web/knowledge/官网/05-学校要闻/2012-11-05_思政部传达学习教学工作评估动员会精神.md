# 思政部传达学习教学工作评估动员会精神

10月25日，学校教学水平评估动员大会之后，思政部在5A427会议室召开全体教师会议进行传达，并部署促建工作。

会议首先传达了学校教学工作评估动员会的会议精神，要求各位老师要认真配合做好准备。会议还通报了迎接省教育厅即将对我部省级精品课《思想道德修养与法律基础》进行检查验收的有关准备工作，布置工作任务。另外，会议还对日常教学工作进行了交流协调，要求各位老师做好迎接期中教学检查的准备工作，组织好已经经过第一次预赛入围的青年教师讲课比赛的初赛工作，落实“导师制”的相关负责人等。

最后，何鹏举主任总结发言，勉励各位教师，在时间紧，任务重的情况下，要统筹兼顾，团结一致，齐心协力，认真完成教育教学和各项研究、课程建设工作。
