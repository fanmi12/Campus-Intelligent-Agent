# 计信系数模竞赛、电子设计竞赛暑期培训开锣

8月20日，计算机与信息科学系的廉玉忠教授和王彩申高工在老校区实验楼集结30余名留校学生开展培训课程，旨在迎战开学初的数学建模竞赛和电子设计大赛。

此次培训课程将历时两星期，参加的学员是来自计信系和机电系大二、大三的留校同学。

历年全国大学生数学建模竞赛和电子设计大赛是我院对外参赛规模最大、影响最广的学生课外科技活动，对提高城市学院的社会影响力和社会知名度起到了良好的作用，迄今已多次获奖，也是我院教学质量评估的重要指标之一。
