# 教务处召开科研项目申报动员会议

3月5日，学院在315会议室召开2008年城市学院科研工作动员会。学术副院长程发良教授、教务处处长邓成良教授与会。凡有科研课题和今年有申报课题的教师近百人到会听取了报告。

会议对2008年学院的科研工作进行了部署，会议要求各课题负责人作好准备，迎接各类科技计划项目的申报。
