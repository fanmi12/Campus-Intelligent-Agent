# 赴台交流生聚会分享学习经验

9月4日，国际交流中心召开秋季即将赴台湾高校交流学习的29名大三学生行前教育会。

东莞市台湾事务局联络交往科刘伟锋科长与会并讲话。城市学院国际交流中心负责人叮嘱赴台交流生要珍惜学习机会，展现城院学子风貌，既要收获知识，更要收获友谊，充当好两岸友好交流的使者。

为了让同学们更好地了解在台湾高校的学习与生活，国际交流中心还组织赴台交流学习返校的师兄师姐介绍交流在台学习的经验与体会。他们表示，赴台学习不仅增长了知识，扩大了视野，体验到了台湾大学师生浓浓的人情味，还锻炼了独立生活的能力与毅力，是人生中难忘的一段学习之旅。
