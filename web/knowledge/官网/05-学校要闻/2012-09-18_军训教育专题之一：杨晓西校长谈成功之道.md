# 军训教育专题之一：杨晓西校长谈成功之道

“失败+投入的精力+投入的时间+抓住机遇=成功。”同学们以热烈的掌声表示赞同杨晓西校长关于“成功”的命题。9月17日，我院4700多名军训学生，在综合馆聆听了东莞理工学院校长、城市学院董事会副董事长杨晓西教授关于“成功”的指教。

如何才能走向成功呢？杨校长从三个方面进行了阐述：一、我的大学历程；二、大学的功能；三、走向成功的路径、方法和条件。在报告中，他运用图片、DV短片，以及爱因斯坦、居里夫人、袁崇焕、毛泽东、邓小平、李嘉诚、杨振宁等众多成功人士的生动事例，以及城市学院毕业生创业的典型，印证自己的上述命题。

杨校长认为，大学是名人名师荟萃的地方，是培养学生全面发展的地方。同学们要珍惜大学时光，把握好金色年华，走好人生征程。

杨校长建议同学们:一、充分认识本科、硕士、博士三个时段不同的学习任务。他希望同学们在本科期间，要学会分析问题并有解决问题的能力；读硕期间要学会发现问题并有解决问题的能力；读博期间要有提出问题并有解决问题的能力。二、设定好个人的奋斗目标，选准事业发展方向，咬定目标不懈追求。三、在学习方法上，要掌握牢固的基础知识；会独立思考，培养各种能力；善于向老师、同学学习；要博览群书，多去图书馆寻找答案。在为人处事方面，要与同学们友好相处，关爱同学和师长；正确认识金钱和家庭背景；自立自强、自尊自爱。

杨校长最后表示，成功就在你我身边，成功并不遥远。同学们为之奋斗吧，成功一定会属于我们！

院长杨敏林教授主持报告会。
