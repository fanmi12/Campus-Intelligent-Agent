# 我院学生干部培训班举行结业典礼

4月26日下午，城市学院第一期学生干部培训班结业典礼在5号阶梯教室举行。

参加培训班的学生干部每人都撰写了学习论文。经过评选，曾少烘等20名同学的论文被评为优秀论文，学习班为他们颁发了优秀论文证书。优秀学员代表在结业典礼会上介绍了学习体会和经验。

院团委副书记杜鹏举老师在会上作总结发言。
