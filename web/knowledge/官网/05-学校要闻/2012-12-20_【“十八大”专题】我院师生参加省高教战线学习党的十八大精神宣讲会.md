# 【“十八大”专题】我院师生参加省高教战线学习党的十八大精神宣讲会

12月18日下午，我院组织教职工到东莞理工学院松山湖校区参加广东省高教战线学习党的十八大精神宣讲会。省高教战线学习党的十八大精神宣讲团成员、广东工业大学政法学院院长谢迪斌教授作了题为“关键时期的重要大会”的宣讲报告。

东莞理工学院党委书记成洪波主持会议。广东省教育厅思想政治教育处副处长朱建华出席了宣讲会。

会上，谢迪斌教授从八个方面深入浅出地分析了十八大召开的背景，宣讲了十八大的主题和成果，畅谈了十八大报告的新思想和新举措，简洁地概括了十年来全国、广东、东莞的实践历程和历史成就，科学阐明了科学发展观的历史地位、指导意义和实践要求，生动解读了中国特色社会主义的丰富内涵和夺取中国特色社会主义新胜利的基本要求，系统介绍了全面建成小康社会和全面深化改革的目标、关于中国特色社会主义事业的总体布局和主要任务，深刻阐述了全面提高党的建设科学化水平的要求。

对于党对青年学生的关注以及教育者的责任，谢迪斌教授指出，青年有没有正确的“三观”（世界观、人生观、价值观），能不能保持“三个永远热爱”（永远热爱祖国、永远热爱人民、永远热爱中华民族），和每个高等教育工作者工作的有效性与针对性有着紧密的联系。教育者学习贯彻十八大精神，最终要联系到这个问题上来，落实到每个人的行动中去。

据了解，该场宣讲会由省委教育工委主办，东莞理工学院协办。除我校师生外，东莞理工学院、东莞职业技术学院和广东科技学院教职工代表共500多人聆听了报告。
