# 我院一课程被评为省级优质课程

5月25日，据广东省教育厅网站公布，我院院长安少华教授为负责人的《思想道德修养与法律基础》课程，被评为“广东省高等院校（本科）思想政治理论课优质建设课程”，同时还有中山大学的《毛泽东思想、邓小平理论和“三个代表”重要思想概论》等20个课程。

这一成果标志着我院课程建设登上了一个新的台阶，为实现学院“上水平，创特色”的奋斗目标作出了新的贡献。
