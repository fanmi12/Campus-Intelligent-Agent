# 我院“专插本”考生345人上线

近日，广东省教育厅发布了2012专插本录取分数线，即：文科类为260分/150分（五科总分/省统考三门总分，外语类按五科总分/省统考二门总分划线），理科类为230分/130分，外语类为250分/100分，艺术类为230分/120分。

据学生处陈副处长介绍，今年共有701人报考我院专插本，其中上线人数为345人，上线率接近50％。无论是报考人数还是上线人数，都是最高的一年。

据了解，专插本录取通知将于5月底发出。
