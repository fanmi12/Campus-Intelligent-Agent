# 我院09年督导工作会议召开

2月27日，学院在4#315召开09年督导工作会议，院长安少华教授、院督学陈丁堂教授出席了会议。

会上，高教研究与评价中心副主任邢镇容教授宣读了院督导工作条例及09年兼职督导员名单，安少华院长向兼职督导员颁发了聘书。院教学督导组组长邵润堂教授宣读了督导组成员调整的决定，对新学期督导工作作了部署和安排。据悉，督导组将分工科组、经管组与文科组，分别由邢镇容教授、邵润堂教授及屠大华教授担任组长。

安少华院长在讲话中充分肯定了督导工作所取得的成绩，他指出，督导部门要继续对学院的各项工作进行有效的监督和引导，加强对学院发展中的重大问题进行调查和研究，处理好与被督导部门的关系，及时发现问题，“开出处方”。要借鉴国内外知名大学督导的经验，发挥独立学院的机制优势，抓大事、抓方向，从制度上解决根本问题。他要求督导工作队伍成为有战斗力和权威性的团队，为提高教学质量把关支招，不断开创新局面，把督导工作做得更好。
