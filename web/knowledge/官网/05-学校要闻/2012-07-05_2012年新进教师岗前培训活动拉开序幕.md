# 2012年新进教师岗前培训活动拉开序幕

我院2012年新进教师岗前培训活动开班仪式于7月4日上午在新校区7B201隆重举行。来自全国各地的新加盟我院的45名新教师，与院领导班子、各系部主任及各行政部门负责人参加开班仪式。

张林副院长主持了开班仪式，并向新进教师一一介绍学院及系部、行政部门领导。45名新老师也逐一做了自我介绍，表达了对加盟城市学院的自豪感，并表示将在新的岗位上与城市学院共同成长。

杨敏林院长对新教师的加盟，表示热烈欢迎，并向他们介绍了城市学院的建设历程及未来发展规划。

朱志德书记、张林副院长、高香林副院长也分别作了《城市学院办学历史介绍》、《城市学院行政管理工作规范》、《城市学院教学管理工作规范》的报告，以帮助新进教师尽快熟悉和了解学院教学、管理方面等相关情况，顺利走上工作岗位、胜任本职工作，完成从知识接受者到知识传授者的转变。

培训活动还邀请了我院讲席专家赵书山副教授为学员作了《东莞经济发展转型与高等教育发展情况报告》的主题讲座，对东莞改革开放30多年的经济发展历程及东莞高等教育事业的发展情况做了详尽的介绍和分析，对当前经济转型面临的挑战以及为高等教育事业所带来的机遇做了深入浅出的分析，让新教师对东莞的经济与高教事业发展有了较为全面的了解。

据悉，本次岗前培训共分为四个阶段，接下来新进教师还将开展模拟教学及点评，参加广东省高等学校教师岗前培训等活动，学习相关高等教育学、心理学理论的相关知识，掌握高等教育的教学规律。
