# 肖红飞教授荣获广东省民办教育优秀教师称号

9月22日，广东省2012年民办教育优秀教师表彰大会暨庆祝教师节文艺演出在广东外语外贸大学云山会堂隆重举行。城市与环境科学系主任肖红飞教授、人事处长胡钦华参加了会议。

大会对广东省2012年民办教育优秀教师予以表彰。我院城市与环境科学系主任肖红飞教授荣获“2012年广东省民办教育优秀教师”称号，这是我院教职工首次获此殊荣。
