# 张宏渝老师荣获“2018年广东高校辅导员年度人物”称号

近日，从广东学工公众号获悉，教育部高校辅导员培训和研修基地发布了“2018年广东高校辅导员年度人物”、“最受学生欢迎辅导员”、“最具科学精神辅导员”、“最具新媒体影响力辅导员”等奖项获奖名单。我校辅导员张宏渝老师荣获“2018年广东高校辅导员年度人物”，何珊珊老师荣获“最受学生欢迎辅导员”，詹海都老师荣获“最具科学精神辅导员”。

“2018年广东高校辅导员年度人物”评选活动由广东省教育厅指导，广东省高校思想政治工作队伍培训研修中心（华南师范大学）、教育部高校辅导员培训和研修基地（华南师范大学）联合举办，共评选出“2018年广东高校辅导员年度人物”10名，提名奖30名，单项奖58名，入围奖92名。
