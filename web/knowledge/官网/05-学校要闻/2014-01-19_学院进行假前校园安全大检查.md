# 学院进行假前校园安全大检查

为确保学院假期工作的顺利开展，也为切实做好寒假期间学院安全保卫工作，保障师生生命财产安全，1月17日上午院长助理麦琦琳率领院办、总务处（后勤）、教务处、学生处、图书信息中心、实验中心等部门负责人对全校进行假前安全大检查，重点检查各区域寒假期间的安全工作落实情况，并对各区域提出假期安全工作的具体要求。

检查过程中，后勤公司领导要求对于发现的问题“小问题现场整改，无法现场整改的通知各部门跟进限期整改，要求各部门高度重视，把安全细节真正做到“横向到边，纵向到底”把一切安全隐患消灭在萌芽状态，确保实现“安全假期，平安假期”。
