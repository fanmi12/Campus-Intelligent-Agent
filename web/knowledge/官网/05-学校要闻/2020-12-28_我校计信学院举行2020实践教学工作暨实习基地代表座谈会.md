# 我校计信学院举行2020实践教学工作暨实习基地代表座谈会

12月25日下午，我校2020实践教学工作暨实习基地代表座谈会在3号楼顺利举行。东莞市科技局副局长肖铮勇，东莞理工学院计算机科学与技术学院副院长魏文红，我校副校长黄兢，教务处处长赵书山，副处长葛卫清、鞠晓红，计信学院院长牛熠，党总支书记廉玉忠等出席了此次会议。本次会议由廉玉忠主持。

牛熠院长介绍了计信学院专业设置、师生配置、人才培养模式，从校企合作的角度提出了一些人才联合培养的建议。

黄兢副校长就学校的发展规划进行了简要介绍，教务处就我校教学科研项目建设与获奖情况进行了介绍。科技局领导对学校毕业生就业工作表示关心，提出要加强毕业生就业工作，同时高度重视科技工作，抓好粤港澳大湾区发展历史机遇培养好科技人才。

出席座谈会的还有广州粤嵌总裁钟锦辉，东软睿道经理乐杰，长江科技总裁江新红，同晟体育总经理江星武，汇星智造总经理钟辉，高帝网络总经理彭伟鹏，中科院云计算机中心主任助力汪军，金蝶力创总经理刘建宁，中企云链副总经理邓锦溏，神州数码总监吕涛，华为行业代表黄琪、杨娜，信大融合创新研究院主任童珉，合众艾特总经理林列亮等企业代表。各位代表就校企合作，产业学院设置构想进行座谈。
