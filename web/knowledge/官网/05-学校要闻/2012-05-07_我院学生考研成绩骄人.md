# 我院学生考研成绩骄人

近日，我院有18名同学陆续被有关高校确认录取为硕士研究生。“骄人的考研成绩，从一个侧面反映了我院教学质量在大幅度提升。”培训中心主任李丽娟老师对记者做如是表示。

据李丽娟老师介绍，我院硕士研究生考试成绩一年比一年好，录取的人数今年又创新高。录取的学校有中山大学、华南理工大学、暨南大学、华南师范大学和北京印刷学院等名牌大学。其中，李苏杰、赵晋宜同学的笔试成绩，分别位居暨南大学、中山大学相关专业全国考生中的第一、二名。值得一提的是，机电工程系共有6名同学考取研究生，其中08级印刷工程班（第二届毕业生、全班只有28名同学）就有3人同时被全国印刷类顶级学校北京印刷学院录取。另外，赵晋宜等6名同学跨专业考研，说明他们的基础学科扎实，专业适应能力强。
