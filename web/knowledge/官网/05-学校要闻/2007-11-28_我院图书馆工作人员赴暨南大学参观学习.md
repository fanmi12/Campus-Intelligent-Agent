# 我院图书馆工作人员赴暨南大学参观学习

11月22日，图书信息中心主任钟兴恭教授和发展联络中心副主任兼基建科叶树标科长一行6人，赴暨南大学参观该校新落成的图书馆，受到暨大图书馆馆长助理江波先生热情接待。

暨大新图书馆于今年9月1日正式启用，建筑面积38180平方米，采取单一进出口，藏、借、阅一体化的大流通管理模式。除了多媒体阅览室、多媒体培训室、自助复印机、自助还书机等服务设施外，还配有独立的研修室，供有承担学校重点学科建设或重大科研项目的教职工以及代表学校参加各种竞赛的学生使用。同时，城院图书馆工作人员还参观了新馆的机房、数字资源建设室、特藏室、密集书库。

钟教授表示，参观学习暨南大学图书馆，是为我院新建的图书科技信息中心大楼取经。我院的新图书馆建筑面积达到2900平方米，将高标准、严要求，建设成硬件、软件一流的现代化的图书、科技中心，为学生学习成才、学校发展提供更好的条件。
