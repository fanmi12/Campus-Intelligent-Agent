# 2013新进教师岗前培训班开课

“教师要有‘三爱’精神，爱校如家、爱生如子、爱岗敬业。”7月3日，学院在行政楼112会议室举行2013年度新进教师岗前培训班，对教师们提出了上述要求。

据悉，今年新进的52名新教师，分别来自北京大学、华南理工大学、深圳大学、广西大学等全国知名大学，其中担任教学任务和辅导员的都具有硕士研究生或以上的学历。文学与传媒系李上文教授对写意花鸟和书法有很深的艺术造诣，曾有多幅作品获得国家、省、市奖励，曾是湖北省书画协会会员。

党委书记朱志德、副书记章德胜出席培训班并发表贺辞。他们代表学院欢迎新老师来到城市学院，从事高等教育教学工作，勉励大家要爱院如家、爱生如子、爱岗敬业，为学院的建设和发展贡献力量。

两天的培训中，新教师们先后听取了章副书记、教务处处长牛熠教授、管理系党总支书记帅建华教授、政法系副主任赵书山副教授关于组织人事工作、教学工作有关规章制度、教师职业生涯规划、东莞社会经济发展等方面的情况介绍。7月4日，新教师们还到三国野战基地开展素质拓展训练。

新教师们表示，要感恩城院，扎根东莞，献身教育，成就终身。新闻中心石晨老师说：“职业生涯规划教育这一课，使我们更加明确了自己的职业方向，找准了职业定位，有利于今后的成长发展。”
