# 金贸系举行迎新年晚会

“世界末日来临前，我要谈一场轰轰烈烈的恋爱，我要努力赚更多的钱和爸妈一齐度过末日，我要购买苹果六代，我要着带着单反环游世界。”金贸系的同学们用非凡的想象力，发表“末日宣言”，调侃着“世界末日”。

12月13日，金融与贸易系“告别2012? 诺亚方舟的爱”迎新年晚会在综合馆火热上演。背对着舞台，拱形的彩灯像彩虹，更像方舟，承载着与会人员度过“世界末日”。金融与贸易系主任米双红教授、党总支书记龙卫洋博士、院团委书记罗文芳等，与同学们一同携带“诺亚方舟”船票，登船参与此次“告别末日”之旅。

一男一女，一把吉他，一个手鼓配上默契十足的声线配合，一股清新的《爱要坦荡荡》迅速蔓延现场。风烙舞队带来充满西域风情的《阿拉伯之夜》舞蹈，金光闪闪的舞服、柔软的肢体动作配合着充满诱惑的眼神吸引了观众的眼球，欢呼声、掌声接连不断。在激扬律动的气氛中，穿着时尚环保服装的帅气靓丽模特们和金贸系辅导员联手为观众呈上了青春时尚的混搭show；辅导员一改平日严肃的风格，纷纷穿上可爱的衣服伴上可爱的舞蹈动作，引得同学们哈哈大笑；在烟幕环绕，古典伴奏中，模特们带来了美轮美奂的视觉冲击。别具一格的手指舞蹈《 soon we will be found》，舞动的白手套，整齐划一的动作，灵活的手指摆出种种图案，一会儿是绽放的花朵，一会儿是飞翔的白鸽，淋漓尽致的阐释了曲中之意。小品《清唱团》延续无厘头风格，用滑稽的动作表演及夸张的神态讲述了参加中国好声音的选手卢小居一路历程，既有少林武术，也有合唱队的实力合唱以及各种吐槽物价上涨的搞笑段子，赢得了阵阵喝彩。舞蹈精灵OLT用舞蹈诠释着大学生的青春活力，一系列的高难度动作high翻全场，接连的地板动作更是让观众们大为惊叹，将晚会推上高潮。三人深情对唱的《画心》演绎了爱情中的爱恨情愁，让观众如痴如醉。

“告别今天，我们站在新的起点；告别2012，我们书写新的辉煌；走向明天，走向蓬勃的希望，让每一颗青春的心都焕发出缤纷的色彩；走向未来，走向美好的祝福，让爱的诺亚方舟载上我们的梦想再次起航。”这是金贸系给予我们共同的祝愿。
