# 我院招生工作取得四大突破

从2017年广东省招生情况来看，东莞理工学院城市学院依然备受考生青睐，成绩喜人，多项数据创历史新高。昨天，招生就业处处长孔增强欣喜地告诉记者，我院今年招生工作取得以下四大突破。

一是省内普通类招生再上新台阶，文理录取分数线再创新高，其中理科录取分数最高为449分，高出省线89分，文科录取分数最高为479分，高出省线61分，生源质量大幅提升。

二是我院2017年整体招生计划为5504名，2017年本科插班生已完成招生354名。2017年普通招生计划5150名，创近年新高。

三是我院优化学科专业结构，积极拓宽专业口径，2017年招生专业达到38个，其中工业设计、舞蹈编导、秘书学、投资学为新增专业。

四是我院积极打造教育资源共享，打造国际化人才培养模式，为了培养应用型国际人才，实现办学国际化特色，我院联合美国中西州立大学及英国哈德斯菲尔大学首次推出金融学“2+2”国际班，采取“2+2”联合培养模式，学分互认，学位互授，实现国际和国内教育资源共享，打造全新国际化人才培养模式。
