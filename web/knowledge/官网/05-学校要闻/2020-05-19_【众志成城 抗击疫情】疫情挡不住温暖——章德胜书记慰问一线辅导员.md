# 【众志成城 抗击疫情】疫情挡不住温暖——章德胜书记慰问一线辅导员

为切实加强疫情防控工作,5月18日，学校党委书记章德胜在学生工作处处长杜鹏举、副处长罗文芳陪同下前往学生宿舍，检查我校疫情工作并看望进驻学生宿舍的一线辅导员。

为了更好开展学生返校后的工作，我校辅导员纷纷提前返回工作岗位，并严格按照学校规定做好入校申请或居家隔离的防护工作。章德胜书记亲切询问了辅导员们目前在校生活情况，详细了解辅导员们疫期间的工作状况，并对他们在疫情防控期间的表现给予了充分肯定。章德胜书记指出，我校学生返校在即，辅导员作为一线工作人员，要快速进入工作状态，全心全力备战学生工作，要充分了解并掌握学生动态。同时他强调辅导员不仅要保护好自己，更要把学生的健康安全放在首位，将上级布置的抗击疫情的工作落实落细。

新型冠状病毒感染的肺炎疫情自发生以来，我校高度重视疫情防控工作，全体辅导员对所有学生点对点疫情摸排，重点关注留校学生和湖北籍学生状态，通过易班和公众号宣传防疫知识，深入细致做好校园疫情防控工作。
