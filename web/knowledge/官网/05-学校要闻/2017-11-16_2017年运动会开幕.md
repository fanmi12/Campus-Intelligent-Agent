# 2017年运动会开幕

“发展体育运动，增强人民体质”——东莞理工学院城市学院2017年运动会，11月16日在学院运动场如期而至。

城市学院董事会董事黎建烨，城市学院王卫平、高香林、黄兢、周庆、刘玉侠、林江龙等院领导，各教学单位、各部门负责人，以及全体运动员、裁判员和师生代表参加了运动会开幕式。

上午，绿茵场上颇有“沙场秋点兵”的磅礴气势，冬日暖阳映衬着一张张朝气蓬勃的面庞，校园处处洋溢着青春的热情与活力。9时，我院航模协会奉上一场精彩的飞行表演。随后，伴随着激扬明快的音乐，在英姿飒爽的护旗队带领下，各具特色的鲜花队、彩旗队、裁判员方阵、各系部方阵、教职工方阵、后勤方阵依次走过主席台，接受检阅。各方阵气宇轩昂、精神抖擞，各以别具匠心的方式展现了我院师生的体育精神风貌。

王卫平书记在致辞中指出，近年来，我院体育教学工作成绩斐然，打造了户外综合技能特色课程，举办了两届户外综合技能挑战赛，树立了特色品牌；学院男子篮球队斩获第二届东莞大学生篮球联赛总冠军，充分展现了城院人团结拼搏的精神风貌。他希望广大师生员工以运动会为契机，“走下网络、走出宿舍、走向操场”，加强体育锻炼，提高身体素质，在运动中收获一个更好的自己。

运动员代表和裁判员代表先后庄严宣誓，表示将以严肃的态度、高昂的激情对待比赛。

黎建烨董事宣布“2017年运动会”正式开幕。

随着高昂、欢快的旋律，各院系呈上了一出唯美、动感的大型学生团体操表演：文传系高喊“我爱文传，代代相传”口号，激情而不失特色；财经系身披金黄色舞衣，手持拉拉球，充满无限的朝气与活力; 机电系出场音乐风格独特，舞蹈动作诙谐，趣味十足；计信系轻快的节奏，阳光向上；城环系，象征着团结；管理系满腔爱国之心，彰显了中国传统文化，以优美的舞姿庆祝十九大胜利召开；金贸系昂扬向上，激情澎湃；外语系节拍欢快，青春无限；创意设计学院服饰别具一格，表演精彩不断，为梦想呐喊；政法系态度严谨，体现公平公正，又不失青春活力；艺术系优美的表演，充分展现了“台上一分钟台下十年功”……

开幕式由体育教学部主任邢红林主持。
