# 我院教师应邀参加东莞市城建规划研讨会

3月27日,学院党委宣传部部长何鹏举副教授、机电工程系副主任孙成访博士、社科系总支部书记石志民副教授和机电工程系苏小欢、黄秋华、李国彬五位老师应东莞市城建规划局邀请,参加了东莞市城建规划局召开的“以城市化为统领，加快推进经济社会双转型”第二次研讨会。

参加这次研讨会的领导有分管环境和城建工作的梁国英副市长,市政府黎达潮副秘书长，社界专家学者，市城建规划局欧阳南江局长，以及市城建规划局相关领导和工作人员。

这次研讨会的主要议题是结合市委市政府在全市解放思想实践科学发展观动员大会上所确定的重点调研课题：如何以城市化为统领，加快推进经济社会双转型。该课题征求全市社界专家学者关于加强城市精细化管理、改造旧城旧村旧工业区、解决历史遗留问题等方面的见解和意见，形成社会各界共识，为市委市政府研究决策提供依据。
