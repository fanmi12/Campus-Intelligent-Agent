# 院长安少华教授为入党积极分子上党课

4月6日，院长安少华教授为我院第二期近600名入党积极分子培训班主讲第四堂党课。他讲课的题目是：始终站在时代前列，保持党的先进性。

他在回顾党的历史时指出，在中国社会发展的各个时期，中华民族都有一批站在历史潮头的革命分子，中华民族正是有了这样一批代表先进生产力和先进文化的先进分子队伍，唤醒了民众，发动了革命，推动社会不断进步。所以，中国人民最终选择了共产党，作为自己利益的忠实代表。

在谈到当代大学生的历史使命时，安院长说，青年大学生不仅要具有专门业务知识和创新能力，还应该是具有共产主义觉悟的先进分子。为此，他希望全体入党积极分子要认清国情，实践党的伟大宗旨；要以战略意识做好中国的事情；要树立“八荣八耻”的社会主义荣辱观，不断提高自身的政治素质和道德水平，争取做一个合格的中国共产党党员。
