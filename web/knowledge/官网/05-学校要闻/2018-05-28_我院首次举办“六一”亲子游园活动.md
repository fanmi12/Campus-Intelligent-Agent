# 我院首次举办“六一”亲子游园活动

5月26日上午，学院工会为庆祝“六一”国际儿童节，在教学楼一楼举办了亲子游园活动暨教职工子女书画展。250多名教职工及其子女参加了活动。学院工会副主席王锦锋出席了活动，与孩子们一道欢度“六一”儿童节。

本次活动益智有趣、形式多样，设有智力拼图、袋鼠跳、叠叠高和飞镖等12个游园项目，大朋友和小朋友们纷纷乐在其中。

活动还展出了我院教职工子女的70多幅书画作品。作品主题鲜明、色彩鲜艳，富有创意，充分展现了教职工子女不凡的想象力和创作力。
