# 有关方面就校园矿泉水的供应答问学生

10月14日，学院后勤处与“瑶寨山泉”水店经理杨志权召开座谈会，就学生反映校园矿泉水供应中的几个问题形成以下三点意见：

一、“瑶寨山泉”水店表示，原广告中提出“一年内一次性购买50桶水送一台饮水机”的承诺，学生可凭购买发票（50桶的数额）到水店领取饮水机。该广告宣传中有关促销的这一承诺，系文字表述有误，今后不再承诺这一办法，向广大学生表示歉意。

二、“瑶寨山泉”水店须进一步端正服务态度，提高服务质量，满足学生饮水要求。送水收费属市场行为，学院不作硬性规定。

三、学院鼓励市场竞争，允准多家水店进校园推销矿泉水，让消费者能够购买到不同品牌不同价格的矿泉水。
