# 我院举办就业系列专题讲座

3月19日，城市学院就业系列专题讲座第一讲在学术报告厅开讲。

根据教育部、省教育厅关于开展“企业精英进校园”的活动要求，我院近期将以“大学生生涯规划、就业指导、创新创业”为主题开展系列讲座（论坛），旨在利用校外（社会、行业、企业等）资源，搭建校企互动合作平台，进一步搞好大学生职业规划与就业指导的课程教学，营造良好的创新创业文化氛围，打造就业创业工作新亮点。

据悉，首场讲座嘉宾是东莞中心人才市场李子辉总监。
