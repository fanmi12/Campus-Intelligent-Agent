# 我院与市文化馆达成共建非遗文化合作意向

5月20日上午，2017年东莞“文化四季”之“非遗季”系列活动在东莞市民艺术中心举行。黄兢副院长和文传系宋秋敏主任应邀出席活动开幕式，并代表我院与东莞市文化馆确定了馆校共建非遗文化合作意向，再次凸显了我院对传统文化、东莞地方文化相关教研与实践的重视和支持。

在开幕式上，“非遗季”举行了东莞与九个城市的非遗墟市城际联盟成立仪式、馆校共建签约仪式和第四批市级非遗项目颁牌仪式等活动。除我院外，东莞广州美院文化创意研究院、东莞理工学院、东莞市电子科技学校等院校也与东莞市文化馆达成馆校共建非遗文化合作意向。

据了解，“非遗季”是东莞市文化馆开展的“文化四季”活动中的第二季，活动时间为5月、6月，是东莞市非遗保护工作创新举措的一次集中展示，得到社会各界的热切关注。“非遗季”期间，除每周六固定举办东莞非遗墟市外，还将持续上演多项主题活动，包括新昌鼓制作传承人叶任和纪念展、“中华第一灯”千角灯、大步巡游专题影像展，及非遗文创产品设计大赛、非遗精品展演、东莞龙舟月系列活动、非遗原创服装设计、非遗征文颁奖暨朗诵会等，这些项目示范性强、影响大、活动辐射广。
