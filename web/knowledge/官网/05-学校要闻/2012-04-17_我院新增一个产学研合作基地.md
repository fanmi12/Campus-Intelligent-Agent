# 我院新增一个产学研合作基地

4月17日，我院机电工程系主任黄健求教授、系总支副书记谢明副教授、实验（实践）办主任张锦荣老师、系办公室王晓玲老师，在机电楼308会议室与东莞精锐电器五金有限公司董事长、总经理陆学中、行政经理陈群举行了产学研合作洽谈会。

双方通过洽谈，确定了建立产学研长期合作的关系，并就人才培养、技术服务、实践基地建设等事项进行了交流，达成了共识。最后，东莞精锐电器五金有限公司董事长、总经理陆学中和我院机电工程系主任黄健求教授共同签订了产学研合作协议书。
