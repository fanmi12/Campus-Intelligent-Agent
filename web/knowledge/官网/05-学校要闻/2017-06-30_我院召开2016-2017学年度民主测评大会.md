# 我院召开2016-2017学年度民主测评大会

6月27日、29日，我院召开民主测评大会，分别对教学部门和行政教辅部门2016-2017学年度的工作进行绩效考核与民主测评。

会上，13个教学部门和14个行政教辅部门的负责人根据绩效考核的指标和内容，分别汇报了本单位在2016-2017学年度工作的完成情况、创新与亮点、存在的问题，以及下学年工作计划

等。

学院民主测评团成员听取了各部门的绩效述职报告，并公平公正的进行了评分与投票。教职工列席代表列席了民主评测大会。
