# 何帅老师应邀参加全国视觉传达设计教育论坛

何帅老师（右一）与北师大李中扬教授（左一）在第四届“设计之星”全国大学生优秀平面设计作品展上

由中国美术家协会主办，中国美术家协会平面设计艺术委员会承办，鲁迅美术学院协办的“2009全国视觉传达设计教育论坛”，6月19日在鲁迅美术学院大连校区举行。我院文学与传媒系何帅老师应邀参加本次论坛。中国美术家协会秘书长刘健教授、中国美术家协会平面设计艺术委员会执行主任陈汉民教授、中国美术家协会副主席、鲁迅美术学院院长韦尔申教授等200位专家学者参加本论坛。

与会嘉宾一致认为，本次论坛研讨了改革开放以来高等设计教育存在的缺陷，提出了在新的历史条件下高等设计教育的新要求、新思维和新理念。

据悉，全国视觉传达设计教育论坛是我国高等学校视觉传达设计专业教学研究与探索最广泛、最高层次的研讨会，我院是首次派出老师参加。
