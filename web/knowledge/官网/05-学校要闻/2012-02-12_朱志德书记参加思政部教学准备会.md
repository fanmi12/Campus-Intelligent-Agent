# 朱志德书记参加思政部教学准备会

为保证新学期教学工作的顺利开展和迎接6月份的思想政治理论课专项评估，2月11日，思政部在1203会议室召开教学准备会。党委书记朱志德、院督学陈丁堂出席会议。思政部主任何鹏举、副主任石志民及思政部全体教师与会。

会议总结了前阶段的迎评工作，对下一阶段的工作进行布置；对新学期的思政教学工作提出了具体的要求。何鹏举主任还传达了北京学习班关于2012年上半年“形势与政策”教学的精神，布置了新学期形势与政策课教学的工作。

朱志德指出，思政课专项评估工作是硬任务，涉及资料多、指标细，要协调全院的力量，鼓足干劲，以饱满的精神状态完成好此项工作中。作为一名思政课教师，上好课是立身之本，要善于学习，努力提高自身的理论水平，改进教学方式，运用体验式教学、案例式教学、小组讨论、参观学习等多种形式，有效地使社会主义核心价值观进课堂、进头脑。要注重科研工作，通过科研促进教学，科研要紧跟东莞“高水平崛起”的实际需要，以促进东莞经济、社会发展为着力点。

据与会老师反映，教学准备会统一了教师的思想，明确了任务，表示将确保教学质量，全力做好新学期的各项工作。
