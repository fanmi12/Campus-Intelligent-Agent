# 我院师生献唱“莞马”助威  原作单曲MV爆红网络

在“2016?东莞松山湖国际马拉松”即将开赛之际，由我院师生为赛事量身定制的原创单曲MV——《追逐梦想》，自首发以来在网络爆红，引发人气指数“爆表”，3月24日更是登上东莞电视台黄金档栏目《今日莞事》头条进行深度报道(《今日莞事》网址

http://v.sun0769.com/v4/play.action?id=490500339)。

《追逐梦想》，是由我院党委宣传部、东莞市团委，以及我院团委、大学生媒体中心电视台等单位为献唱“莞马”而制作的原创单曲MV，担纲演出、演唱的是我院人气学生社团——Acappella清唱团，而这首歌的作曲、编曲、作词、及后期MV制作均有我院师生一手包办。值得一提的是，该单曲还是一首人声伴奏演唱的歌曲。

《追逐梦想》自3月23日首发以来，截止目前，腾讯视频点击量已超26万次（腾讯视频网址

http://v.qq.com/page/d/c/c/d01894ck6cc.html），并吸引了东莞电视台、东莞广播台前来采访。 据院团委书记罗文芳介绍，《追逐梦想》MV制作完成之后，制作团体不但将其推送到腾讯视频、中国阿卡贝拉官微、中国国际马拉松官微和东莞国际马拉松组委会官微，还联合“城院贴吧”、“城院捕快”等校内自媒体和“流行东莞”、“东莞优莞通”等校外自媒体同步向公众推送，从不同视角进行宣传推广，引发了广泛关注。
