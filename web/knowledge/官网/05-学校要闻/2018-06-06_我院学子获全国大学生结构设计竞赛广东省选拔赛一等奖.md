# 我院学子获全国大学生结构设计竞赛广东省选拔赛一等奖

6月1日-3日，第十二届全国大学生结构设计竞赛（广东赛区）选拔赛在华南农业大学举行。我院城环系派出两支学生队伍参加了比赛，分别获得一等奖和三等奖，其中一等奖作品在“外观专项”的得分居全省第一。

全国大学生结构设计竞赛由国家教育部、住房和城乡建设部、中国土木工程学会联合主办，是中国高校创新人才培育暨学科竞赛评估的19项国内具有广泛影响力的赛事之一，属于国家级大学生A类竞赛。大赛是国内土木工程学科以培养当代大学生创新思维、创新意识、团队意识和实践能力为宗旨的高水平学科竞赛。
