# 红歌大赛：唱响红色旋律

9月18日晚，连续9天艰辛的军训和入学教育之后，军训中的新生们迎来了激情之夜——红歌大赛。大家唱响红色旋律，一展青春激情和爱国热忱。

当晚，红歌大赛尚未开始，17个连队在学院运动场两侧席地而坐，一遍遍练习拉歌动作和口号，相互打气加油。

一曲《黄河在咆哮》，一连率先开场，嘹亮歌声点燃了现场的热烈气氛。

校歌《城市学院之歌》演唱环节，伴着女生的翩翩起舞，动人的歌声赢得现场阵阵掌声。

四连列着整齐的队形，配上二重唱，精彩地演绎了《女兵谣》。五连手执黄橙相间的旗帜和五颜六色的荧光棒，富有节奏地挥舞起来，伴随着动人的歌声，让现场顿时沸腾了起来。

让现场观众肃然起敬的当属十四连。他们全力出击，歌声嘹亮，一曲红歌《强军战歌》让人宛如身处战场。演唱完毕，他们对“九一八”纪念日齐声感言：“今天是‘九一八’，是86年来我们不应该遗忘的民族劫难之日。热爱祖国，勿忘国耻！”

学院艺术团声乐队许敏献唱的《存在》、kpop韩流舞队的劲歌热舞，为红歌大赛增色不少。

在全场的欢呼声中，各连高举连旗，环场奔跑。经过大赛评委团打分，四连财经系的《女兵谣》获得第一名。
