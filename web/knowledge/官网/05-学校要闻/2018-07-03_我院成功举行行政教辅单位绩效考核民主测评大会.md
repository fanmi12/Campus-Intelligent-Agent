# 我院成功举行行政教辅单位绩效考核民主测评大会

7月2日下午，我院召开行政教辅部门及其负责人2017-2018学年度绩效考核民主测评大会。

会上，16个行政教辅部门负责人根据绩效考核的指标和内容，分别汇报了本部门重点工作完成情况、存在不足以及下学年工作设想。

学院民主测评团成员听取了各部门的绩效述职报告，公平公正地进行了评分与投票。

王卫平院长在总结讲话时，充分肯定了各部门这一年的工作成效，同时也对各部门新一年的工作提出了更高的要求，强调要注重大局观，工作要有突破，增强创新意识。
