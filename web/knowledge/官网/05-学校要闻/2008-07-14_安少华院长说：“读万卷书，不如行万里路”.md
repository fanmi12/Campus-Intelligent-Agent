# 安少华院长说：“读万卷书，不如行万里路”

7月13日，我院赴美游学团41名全体成员出发前往美国，进行为期28天的学术交流。

清晨，静谧的校园里，院长安少华教授、副院长张林博士早早便来到了人才之星，为游学团的师生送行。安少华院长语重心长地对同学们说：“要好好把握学院给你们提供的这个绝佳机会，古人说‘读万卷书，不如行万里路’，你们在游历过程中，一定要谦虚谨慎、虚怀若谷，学人所长，补己之短，团结互助，为我们城市学院争光，为中国当代大学生树立良好形象。”

为早日实现我院“上水平、创特色、谋发展、树品牌，建设省内一流本科独立学院”的奋斗目标，学院高度重视与国外大学的合作交流。对于此次游学过程，从最初的游学方案拟订，游学队员挑选，到签证办理，与美国北爱荷华大学方面的沟通等工作，学院领导给予了极大支持。
