# 让同学们赢在职场起跑线上

“金湾杯”第七届广东省大学生职业规划大赛，自4月7日启动以来，共有来自135所高校的15.1万名学生报名，提交职业规划作品11.4万份。在不到一个月的时间里，我院共有4286名学生报名，提交职业规划作品3416份，参赛人数和参赛作品数双双创下历史新高，参赛规模进入全省六强，受到省赛组委会的表扬。

在6月12日、13日举行的总决赛中，我院邓思如同学荣获本届大赛本科组一等奖,我院荣获“优秀组织高校奖”，我院招生就业处就业中心主任、大赛总负责人江小卫荣获“优秀组织者”奖，指导老师苗琳老师荣获“优秀指导老师奖”等获得集体和个人四项大奖。

为此，记者特地采访了本次大赛总负责人、就业中心主任江小卫。

记者：江主任您好！作为本届大赛总负责人，您有什么获奖感言？

江小卫：我院在高手如云、竞争更加激烈的全省总决赛中，一举获得集体和个人四项大奖，说实话，真的不容易呀！

记者：我院在本届大赛中获得了历史上最高成绩，您认为最主要的原因是什么？

江小卫：我们部门总结了一下，主要有以下五个原因：一是学院重视，主管院领导亲自“挂帅”。

大学生职业规划大赛是我院就业工作的一项重要工作和品牌活动，更是我院大学生职业规划与就业指导教学的重要补充和延伸，历来受到学院各级领导的高度重视。

“金湾杯”广东省第七届大学生职业规划大赛及我院第八届大学生职业规划大赛启动之初，学院就成立了职业规划大赛工作领导小组，由主管招生就业工作的黄兢副院长任组长，招生就业处孔增强处长和我任副组长，组员由各院系（部）负责学生工作的书记（副书记）组成。两个大赛由主管领导“挂帅”、招生就业处具体落实，各院系（部）支持配合，有条不紊，层层落实。

二是全员参与，充分发挥教研室作用。

就业指导教研室根据“金湾杯”广东省第七届大学生职业规划大赛要求，结合大学生职业生涯规划课程教学，要求所有任课老师，及时调整教学内容和教学重点，加强学生职业规划作品的撰写辅导，并发动全院学生，积极、主动、及时报名参赛。

三是线上线下，宣传工作全方位展开。

通过学院网站、招生就业处公众号、就业平台、就业中心Q群以及院内公告栏、张贴画、宣传单等方式，对“金湾杯”广东省第七届大学生职业规划大赛及我院第八届大学生职业规划大赛进行线上线下、全方位、全覆盖、持续不间断的宣传、造势，营造良好的大赛氛围。

四是点面结合，挖掘培育大赛好苗子。

通过前期严密的组织、发动及全方位的宣传工作，我院学子参赛热潮持续高涨。自4月初大赛启动以来，共有4286名同学报名参赛，提交参赛作品3416份，在全院取得了良好的效果。

通过初赛、复赛、面试、素质拓展以及省赛选拔赛等环节，层层筛选，从3416份参赛作品中，选出“征战”省赛的“种子”选手，并重点辅导，重点培养。

五是群策群力，上下一心备战大赛。

此届大赛，充分发挥了招生就业处、就业中心、就业指导教研室、职业规划课任课老师、学生处、团委等学工队伍，以及学生会、大学生职业发展工作委员会等学生组织的作用，各部门相互配合、相互支持、协同合作、共同发力。

此外，充分利用艺术系、文传系、计信系以及创设院等师资力量，对参赛选手的作品撰写、PPT制作、口才表达、舞台表演以及应变能力等各方面加强指导。

记者：您认为大学生职业规划大赛对毕业生就业工作有何意义？

江小卫：大学生职业规划大赛是大学生就业工作全程化中的重要一环，更是大学生职业规划与就业指导教学的重要补充和延伸。在帮助大学生加强职业规划意识、掌握职业规划方法、明晰人生目标、解决就业困惑等方面，大赛起到了积极的推动作用。

大学生职业规划大赛是我院就业工作的一项重要工作和品牌活动，进一步强化我院大学生职业规划理念的学习与实践，推动我院毕业生就业指导工作的深入开展。通过举办大学生职业规划大赛，有助于我院学生尽早树立职业规划意识、竞争意识和危机意识，以科学的态度规划自己的职业生涯，化“被动就业”为“主动择业”，让同学们赢在职场的起跑线上。

记者：您认为这次大赛对我院哪些方面将产生影响？

江小卫：我们的初衷并不是为比赛而比赛，而是想通过举办职业规划大赛的形式，全面推进我院大学生职业生涯规划教育。在省赛停办的这几年里，我们每年坚持举办院级的大学生职业规划大赛，取得了良好的效果，也积累了丰富的经验。

当然，职业规划大赛也是一个很好的展示平台和宣传窗口，特别是省级大赛，更是各大高校展示实力和形象宣传的平台。在本届大赛中，省教育厅、省高校就业指导中心和省高校毕业生就业促进会充分肯定了我院的宣传组织工作。通过本次大赛，我院的总体实力、形象、品牌都得到了很好的展示和宣传。这也是我们最大的收获。
