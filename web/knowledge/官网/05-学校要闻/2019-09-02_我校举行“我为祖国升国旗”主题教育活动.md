# 我校举行“我为祖国升国旗”主题教育活动

9月2日上午，开学第一课，我校隆重举行“我为祖国升国旗”主题教育活动。全体校领导、全体师生员工17000多人生身着正装，排着整齐的队列参加了升国旗活动。

王卫平校长主持了升旗仪式。

8时15分，学校国旗护卫队队员迈着整齐、昂扬的步伐，通过主席台来到旗杆下，在庄严的国歌声中，将鲜艳的五星红旗冉冉升起。全体师生向国旗行注目礼，表达了对祖国无限的热爱和崇高的敬意。

章德胜书记在讲话中强调，举行“我为祖国升国旗”主题教育活动，旨在进一步加强爱国主义教育，引导全校师生树立中国特色社会主义道路自信、理论自信、制度自信和文化自信，激发爱国爱党的热情。

值此新学期、新征程开始之际，章德胜书记代表学校党委提出了三点希望：一是希望爱国成为城院师生最鲜明的底色；二是希望全体师生树立远大理想，扎根人民，奉献国家；三是希望全体师生成为新时代的奋斗者。他还激励全体师生“永怀爱国之心、常怀报国之志、以爱国报国为己任”，不怕苦、肯吃苦，勇于担当民族复兴大任，不辱时代使命，做新时代的奋斗者，为实现“两个一百年”奋斗目标、实现中华民族伟大复兴的中国梦而努力奋斗！
