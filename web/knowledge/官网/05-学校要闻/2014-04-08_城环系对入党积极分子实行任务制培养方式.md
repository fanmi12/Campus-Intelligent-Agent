# 城环系对入党积极分子实行任务制培养方式

4月3日，城环系入党积极分子任务制管理启动仪式在7C208隆重举行。系党总支书记肖红飞、副书记张海勇等老师出席会议，城环系新校区全体学生党员、入党积极分子参加了本次启动仪式。

启动仪式上，系党总支书记肖红飞老师致辞，对城环系入党积极分子任务制管理培养方式给予了充分肯定，指出其是我系党建工作的又一特色，在党建工作方面提出的又一新举措。

学生党支部书记曹镭老师介绍入党积极分子任务制管理，将入党积极分子在考察期要完成的工作分为基础任务和核心任务。基础任务涵盖学习、活动、获奖、纪律等方面。核心任务包括，涵盖学习党章、党史、党的理论知识、时事在内的思想类任务；涵盖参加创业设计大赛、创业实践等在内的创业类任务；包括服务学校、服务社区、服务社会等项目的服务类任务；包括发表专业论文、制作科技作品、参加各科技类比赛等项目在内的科技类任务。入党积极分子必须在每学期，以3-4人为一个小组，在完成基础任务的同时，完成核心任务中的两个项目，其中核心任务中的思想类任务为必选项目。此活动旨在提高入党积极分子在思想素质和综合素质，切实提高党员发展质量。
