# 我院参加省厅思政课优质课程建设交流会

9月19日

至21日，省教育厅在顺德职业技术学院召开全省第一批优质课程验收暨第二批优质建设课程中期交流会。省厅副厅长李小鲁出席会议并讲话。我院督学、思想政治理论课教学部主任陈丁堂教授、副主任石志民副教授参加会议。

参加本次会议的有教育部社政司司长助理邓传淮，省教育厅思政处处长袁本新，广东省思想政治教育学会会长郑永廷，第一批17门优质建设课程和第二批20门优质建设课程的负责人及第三批20门优质建设课程的负责人参加会议。

会上，社政司司长助理邓传淮传达了教育部在今年7月份召开的全国思想政治工作会议的有关精神，对优质课程建设作了重要讲话。第一批优质建设课程的负责人对本门课程的建设情况进行说明、成果展示并接受专家的提问。我院《思想道德修养与法律基础》被列为广东省第二批优质建设课程，陈丁堂

教授代表课程负责人对课程建设情况进行了汇报，介绍了我学院领导和教师高度重视对课程建设，尽力改善教学条件，提高教学水平等情况。最后，郑永廷会长对第一批优质课程建设情况进行了总结和点评。他分别从教学队伍、教学内容、实践教学、网络资源、教学方法与手段、教学效果、课程特色等七个方面，对优质课程建设作了说明，要求全省各高校认真做好思想政治理论课的优质课程建设，为推动全省思想政治理论课打下坚实基础。
