# 我院举办2018级新生国防教育讲座

为坚定大学生理想信念，点燃同学们的爱国热情，9月10日晚，我院在综合馆举行2018级新生国防教育讲座。

讲座由刘玉侠副院长主持。东莞军分区副司令员陈泽华围绕素质教育和国防教育为新生们作了一场别开生面的报告。

陈泽华副司令员结合自身艰难的求学经历，用红军长征精神鼓励同学们要珍惜今天的美好生活。希望同学们充分利用身边丰富的资源，不懒惰、不懈怠，争做有思想、有能力、有道德、有文化、有纪律的“五有青年”。他说：“理想不是虚无缥缈的，人生处处都是起跑线。”改革开放的成果给了青年们一个前所未有的平台，大学更是实现人生理想的重要时期，同学们要感谢这个时代，在广阔的天空努力翱翔。

陈泽华副司令员以军队纪律为突破口，为同学们分析了我国军事实力的现状和发展前程。他指出，我国取得如此傲人的成绩实属不易，但大家依然要有忧患意识。以国家安危为己任，努力学习专业知识，将来贡献出自己的力量。

“一个没有国防意识的人，就像鸟儿没有翅膀。”陈泽华副司令员指出，在物质生活充裕的现在，青少年缺少毅力的磨练和坚定的信念。军训正好给新一代青年学生补上关键的一课，希望同学们珍惜这段来之不易的军训时光。
