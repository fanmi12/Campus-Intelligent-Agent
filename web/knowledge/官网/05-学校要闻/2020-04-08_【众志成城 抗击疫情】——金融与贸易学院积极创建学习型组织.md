# 【众志成城 抗击疫情】——金融与贸易学院积极创建学习型组织

在疫情防控期间，金融与贸易学院根据学校的部署安排，全体教师积极探索，认真备课，保证全院线上教学活动顺利开展。与此同时，全院教师在院领导的带领下，由教研室主任带动老师在课余时间积极参加各类线上学习培训，努力提升自己，营造了浓郁的“停课不停教，停课不停学”学习氛围，在探索创建学习型组织的道路上更上一层楼。

自开学以来，为了学习新型冠状病毒肺炎的相关防护知识，金贸学院全体老师参加了广东省教育厅组织的校园防控新型冠状病毒肺炎专题讲座线上学习，并将学习情况在学院工作群内进行了分享交流。

除此之外，各个教研室和学工团队都在积极学习专业知识，努力提升自己。

作为一名教师，正因为担负着教书育人的重任，所以更要关注自身的成长，金贸学院秉承“教学相长”的理念，在特殊时期，保质保量完成各项教学任务的同时，不断鼓励和组织全体老师积极参加线上学习培训，致力将金贸学院打造成一个注重内涵发展的学习型组织。
