# 杨振同副教授赴上海参加全国美国文学研究会第十六届年会

10月27日至29日，全国美国文学研究会第十六届年会暨学术研讨会在上海同济大学举行。文传系副教授杨振同应邀参加会议，提交的学术论文《复仇，也会闪耀出人性的光辉》在会上宣读。

本次年会由全国美国文学研究会主办，同济大学外国语学院承办。来自全国23个省市的120余所高等院校、研究所、出版社近300名与会美国文学专家、学者、青年教师及在校博士、硕士研究生参加会议。南京大学刘海平教授、王守仁教授、中国社科院外文所研究员盛宁教授、南开大学常耀信教授、北京外国语大学金莉教授、厦门大学杨仁敬教授、山东大学郭继德教授、复旦大学张冲教授等学界名流出席了这次研讨会，为会议增色不少。

在两天的会议中，与会学者围绕美学与政治的中心议题，对美国文学中的政治批评与美学批评、后结构政治批评的得与失、美国文学研究中的“重回审美”等内容进行了热烈交流与讨论。
