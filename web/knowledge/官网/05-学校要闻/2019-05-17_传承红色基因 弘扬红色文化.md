# 传承红色基因  弘扬红色文化

5月17日下午，我校在广东东江纵队纪念馆举行了东莞红色文化研究中心实践基地挂牌仪式。广东东江纵队纪念馆馆长王红星、宣传拓展部主任张俊，学校党委书记章德胜等领导和党员代表等参加了挂牌仪式。

王红星馆长介绍了广东人民抗日游击队东江纵队诞生的历史背景、发展历程和丰功伟绩，以及广东东江纵队纪念馆的有关建设情况。

章德胜书记表示，依托我校智力资源与东纵纪念馆红色资源优势，共建共享，传承红色基因，共同把东莞红色资源利用好、弘扬好。此次实践基地挂牌将为双方的深度合作搭建起了一个良好的研究与实践平台。

据了解，今年年初，我校成立了东莞红色文化研究中心，其目的和宗旨是通过全面搜集、整理东莞地方红色文化资源，以传承红色文化，弘扬红色精神。
