# 计信系三个本科专业试评估获良好

近日，学院组织有关专家对计算机与信息科学系软件工程专业、计算机科学与技术专业和电子信息工程专业进行院内试评。经过专家组的认真评审，三个专业的试评分数分别为90分、82分和81分，均达到了优秀的标准。

试评工作的流程是模拟正式评估工作流程进行的。专家组首先听取专业负责人的自评汇报，分别检查各专业的评估档案材料、试卷、毕业论文、实验室和图书等资料。检查结束后，专家组成员讨论检查结果、形成检查意见并给出试评分数。

本次试评是对前一阶段各专业迎评工作的总结和检查，更是对下一阶段迎评工作查缺补漏的指导。专家组在对计信系三个本科专业给予肯定的同时，也指出了在迎评工作各方面存在的细节问题，三个专业负责人及评估专员将总结此次试评中发现的问题，并制定出下一阶段迎评工作的计划，以期在正式评估时能取得最好的成绩。
