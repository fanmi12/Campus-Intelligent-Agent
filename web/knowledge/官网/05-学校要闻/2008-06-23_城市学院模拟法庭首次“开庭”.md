# 城市学院模拟法庭首次“开庭”

6月18日，法学专业首届模拟法庭在2309课室正式开庭。法学教研室和实践教学办公室全体老师莅临“庭审现场”，06法学专业全体同学参加了旁听。

本次模拟法庭是公开审理一起报复、指使他人放火破坏第三方生产经营的公诉案件。14名同学分别模拟法庭上的各种角色，模拟庭审准备、法庭调查、法庭辩论等庭审程序。

开庭后，“审判长”首先告知案件参与人有关事项及其所享有的权利，法庭调查阶段围绕案件事实进行调查、举证、讯问被告人、提请鉴定人和证人出庭作证；辩论阶段控辩双方围绕在证据的证明力、定罪量刑情节和刑罚适用等争议焦点展开辩论，控辩双方凭借雄辩的口才和扎实的理论功底使辩论异常激烈，将整个模拟庭审推向高潮。最后审判长落槌定音，模拟法庭庭审结束。

参与庭审的同学说，模拟法庭向我们展示了整个庭审过程，感知了庭审程序。

据悉，这次模拟法庭是根据《刑事诉讼法》实践教学的安排，在法学教研室李奕老师的指导下，由06法学专业同学自主组织的。事前，同学们还专门到东莞市中级人民法院进行过一次旁听。
