# 我院召开第二届教职工代表大会暨工会会员代表大会第二次会议

11月25日，东莞理工学院城市学院第二届教职工代表大会暨工会会员代表大会第二次会议胜利召开。

院领导王卫平、章德胜、高香林、黄兢、周庆、刘玉侠出席了会议。正式代表及列席代表参加了会议。特邀嘉宾广东鸿发教育文化集团有限公司总经理陈超群参加了会议。会议由章德胜副书记主持。

大会表决通过了《东莞理工学院城市学院职称评审制度》。

会议分别

听取了院长王卫平的《院长工作报告》、财务处处长余竹根的《财务工作报告》、工会副主席王锦锋的《工会工作报告》。

王卫平院长作《院长工作报告》

财务处处长余竹根作《财务工作报告》

工会副主席王锦锋作《工会工作报告》

与会人员合影留念
