# 学生处举办第一期学生个案分析工作坊

5月27日，学生处在卡拉OK厅举办学生个案分析工作坊。党委副书记朱冰、学生处处长章德胜、党委宣传部部长何鹏举及各系辅导员参加了工作坊。本次工作坊的主题为：因材施教，德育为先。活动采取系部案例介绍、自由讨论、专家点评支招的形式进行。

会上，章处长介绍了举办工作坊的作用和意义。这次活动旨在根据我院学生的实际情况，探索具有针对性的德育方法。计信系辅导员林胜凯、城环系的董雅洁老师分别介绍了案例，与会人员结合自己的工作经验纷纷发表了看法。特邀专家嘉宾院党委副书记朱冰同志、院督学陈丁堂教授和院宣传部部长何鹏举教授，也分别进行了精彩的指导和点评。

党委副书记朱冰要求各系部要真正有效地开展德育工作，寻找德育的有效途径，让学生自己获得内心的感悟，进而做出自己的选择。

院督学陈丁堂指出，我们爱护学生应该讲究方法。学生是年满十八岁的成人，学生工作者应该指导学生做出负责任的选择。

何鹏举部长与辅导员分享了当辅导员的工作经验与体会，以自己从“内燃机”专业的本科毕业生到“思政”教授的成长轨迹告诉大家，学生工作者不要自我设限，要认真地去思考和总结自己的工作经验，把工作和科研结合起来，在大思政的视野下，所有的老师都是德育工作者。

据介绍，学生个案分析工作坊是目前高校学生探讨德育工作的一种新的尝试。以工作坊的形式把学生工作者组织起来，其主要目的是对学生工作中出现的典型个案进行分析讨论，对解决得较好的案例进行经验交流，加以推广；对暴露出来的问题，争取能够给出一些建设性的意见。通过学生工作者的密切交流，创设一个依靠集体智慧解决学生工作的平台，打造一支具有团队精神的学生工作团队。“工作坊”由学生处主办，将成为学生处开展学生工作交流和学习的常规活动之一；活动分期分专题进行，每月一次。专题分为：学生心理问题、学生突发事件处理、辅导员的工作技巧、学生事务管理等。
