# 管理系组织师生代表参观深圳华为公司

6月30日，管理系组织老师和同学代表到深圳华为公司参观学习,高等教育研究与评价中心邵润堂教授也应邀参观。

华为公司非常重视这次参观，安排专门人员接待。公司的接待导游详细地为师生们介绍了华为自主研发的芯片、各种通讯设备及网络终端，以及各种营销方案和通讯行业的经验。在华为数据中心，师生们参观了华为企业网络、华为IT体系、华为全球监控网络中心和具有一流国际水准的培训基地。华为的物流中心相当宽敞，内设自动物流中心和立体仓库，办公实现了全面的智能化和机械化。

华为之行，使同学们大开眼界，看到了物流的广阔前景。
