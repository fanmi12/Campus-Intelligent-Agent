# 市城建局领导视察我院图书科技信息大楼基建工地

上图右一为市城建工程管理局局长丁海潮3月5日，东莞市城建工程管理局局长丁海潮来我院视察图书科技信息大楼建筑工地，院长安少华、党委书记朱志德、副书记朱冰热情接待了丁局长一行，并会同承建方青岛建筑集团公司相关负责人举行了座谈会。

座谈会上，丁海潮局长就我院图书科技信息大楼的建设提出了很多建设性的意见和建议。他十分重视工程建设的质量和进度，要求施工方在保证质量的前提下，确保工程如期竣工。在听取我院领导和施工方就工程建设过程中遇到的一些问题的反映后，丁局长表示，东莞理工学院城市学院是我市很有影响的一所高校，为东莞的教育事业作出了重大贡献，市城建工程局将协同其他部门尽力解决施工过程中遇到的困难和问题。
