# 我院举行《思想道德修养与法律基础》精品课程建设座谈会

7月6日，我院特邀华南理工大学思想政治理论课教学部首席教授、博导霍福广教授，华南理工大学新闻传播学院副院长、博导唐孝祥教授等参加在我院行政楼315会议室举行的《思想道德修养与法律基础》精品课程建设座谈会。

本次会议由院党委书记朱志德副研究员主持，党委宣传部部长、思想政治理论课教学部主任何鹏举副教授、社科系主任陈丁堂教授、思想政治理论课教学部副主任石志民副教授以及课题组其他成员参加了会议。

会议主要围绕如何巩固我院精品课程建设取得的成果，如何进一步加强我院的精品课程建设工作及申报省级精品课程注意事项进行了深入研讨。

会上，朱志德书记指出，精品课程建设是教育部 “质量工程” 中的一项重要内容，是在根本上提高教学质量进而提高人才培养质量的奠基性工作。学院党政领导长期以来十分重视精品课程建设，选取了《思想道德修养与法律基础》等四门课程作为重点打造对象，投入大量人力物力予以支持，以院长安少华教授为课程负责人的《思想道德修养与法律基础》课，由于工作扎实，建设有力，已于2007年获省级优质课程称号，取得了阶段性的成绩，并按照学院部署，今年申报省级精品，争取更上一个台阶。学院希望通过精品课程建设进一步提高我院人才培养质量，优化育人环境，激发师生工作学习的积极性和创造性。

陈丁堂教授认为，我院是按新机制运行的独立学院，在精品课程建设方面与名牌学院存在一定差距，我们必须走特色创新道路，依托地方经济建设优势，以服务东莞，培养适应地方经济发展需求人才为立足点，寻找理论教学与实践教学的最佳结合点，凸显我院在教学过程中所采取的校企合作联合办学新模式，加强学生社会实践能力，培养学生创新、创业意识，只有这样，才能将精品课程建设的基础打牢，为课程建设的亮点添彩。

在听取了我院精品课程课题组教师的相关工作情况介绍后，霍福广教授等人肯定了我院《思想道德修养与法律基础》精品课程的质量，认为材料翔实，准备充分，富有实效，达到了省级精品课的申报要求。并认为我院在实践教学过程中强调的养成教育、行为教育模式，是对《思想道德修养与法律基础》教学过程的一种创新与突破，具有示范性作用。霍福广教授等人还针对我院本次精品课程申报工作提出了一些建设性意见。

课题组成员对华南理工大学思想政治理论课教学部专家教授的帮助和指导表示感谢。
