# 周巍博士应邀到市新莞人服务管理局做专题讲座

9月20日，我院周巍老师应邀到东莞市新莞人服务管理局做“关爱他人? 共享幸福”社会志愿服务专题讲座。市新莞人服务管理局领导、32个镇（街）新莞人服务管理中心的主要负责人、新莞人社工、东莞市历届优秀新莞人代表等200多人参加。

周巍老师深入浅出地阐述志愿服务的重要性，东莞市近年来志愿服务的发展现状，近几年东莞市新莞人志愿服务队的发展背景、组织框架和服务成效，当前新莞人志愿服务所面临的问题，以及一些政策建议。周巍老师的讲课获得在座听众的好评。
