# 东莞理工学院城市学院2005-2006学年度工作会议召开

2005年8月22—23日，城市学院召开新学年发展会议。学院院长安少华教授主持会议，程发良副院长作《东莞理工学院城市学院2005-2006学年度工作报告》，朱志德书记作《东莞理工学院城市学院党总支2005-2006学年度工作要点》。城市学院院领导，系部处室中层干部，教授，博士等30余人参加了这次大会。会议围绕两个报告进行了热烈讨论，大家发言踊跃，纷纷献言献策，为学院发展出谋划策。

朱书记的报告从组织建设、思想政治教育、宣传工作、和谐校园等四大方面提出新学年构想。

程副院长的报告分别从贯彻落实科学发展观；坚持“质量立校”，推进教学改革，培养合格人才；深化学院管理体制改革；加强学生管理工作等七个方面做了新学年工作展望。

两个报告都突出质量立校、人才强校的办学思想，强调创新人才培养模式和管理体制，保障教学工作的中心地位，必将促进学院工作的新发展。

安院长在总结发言中强调，办好城市学院必须牢记：依托母体保质量；面向市场谋创新；服务东莞求支持；追求卓越创品牌；科学发展作贡献的办学思想，努力把东莞理工学院城市学院办成一所有特色的地方本科独立学院。

会议得到寮步镇党委的大力支持，会后与会人员参观了寮步三星电机和万科城市花园。
