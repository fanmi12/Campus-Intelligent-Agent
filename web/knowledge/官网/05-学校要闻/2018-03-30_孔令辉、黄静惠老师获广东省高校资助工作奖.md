# 孔令辉、黄静惠老师获广东省高校资助工作奖

3月30日上午，广东省2018年学生资助工作会议暨高校奖学助学工作专业委员会在广州召开。省教育厅副厅长朱超华，省教育厅学生助学工作管理中心主任薛彪，全省21个地市教育局，151所高校分管学生资助工作的校领导和学生处负责人参加了会议。我院党委副书记章德胜、学生处副处长罗文芳参会。

会上，汕头市教育局、华南师范大学等代表分别从如何做好精准资助、资助工作宣传入村入户、高校资助工作的深入发展等方面进行工作经验交流。

大会表彰全省高校资助工作2017年度先进工作者和资助工作者典型。我院孔令辉老师被评为2017广东省高校学生资助先进工作者，黄静惠老师被评为广东省首届百佳学生资助工作者典型。
