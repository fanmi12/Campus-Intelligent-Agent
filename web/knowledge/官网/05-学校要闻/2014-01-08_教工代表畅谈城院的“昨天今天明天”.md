# 教工代表畅谈城院的“昨天今天明天”

城市学院建院10周年庆典的脚步声越来越近。“这十年的风风雨雨、欢声笑语、桃李满天的艰辛与体会，值得城院人去总结与回味”。会议主持人党委副书记章德胜对本次会议的宗旨做了上述表示。1月6日，党委宣传部在行政楼407室召开新闻采访座谈会议，接受南方日报记者郭杨阳的采访。

对于办学十年的历程与成就，与会人员自豪之情溢于言表，喜不自禁，争先发言。

有“拓荒牛”之称、城市学院创办人之一的党委书记朱志德首先讲话。他说，在东莞理工学院正确领导下，经过“城院人”不懈的努力与探索，我院的办学思想、施教理念、治校原则、办学目标、发展路径越来越清晰，越来越鼓舞人心，并逐步变成了现实。他为了证实自己的观点，在讲话中列举了办学过程中涌现的许多经典关键词的内涵。如“三年打基础”、“五年上水平扩规模创品牌”、“办省内一流大学”、“百年名校”、“合同制”、“聘用制”、“年薪制”、“集体婚礼”、“生日礼物”、“服务东莞”、“应用型人才”、“一条主线”、“两大抓手”、“三个优势”、“五大战略”、“三位一体”、“三重保障”等等。

胡钦华、罗卫国、何鹏举、帅建华、杜鹏举、唐洁、石志民等同志联系工作和自身实际，畅想成长、立业、成家的过程与喜悦。他们之中，有的在2003年创办之初就入职，有的最近1、2年才加盟，有的从一个普通的教师成为了副教授或教授，有的从学士成了硕士或博士，有的从单身教工成了三口之家，有的由“月光族”成了有车有房月薪数千元的“土豪”，甚至认购了100多平米的教工豪宅，有的从备课教师成了省级精品课程或国家级科研课题的拥有者。

谈到城市学院“明天”的愿景时，与会人员更是信心满满，表示要发挥体制机制优势，依靠“城院人”的智慧和鸿发集团的实力，创造新的辉煌，写出新的篇章。
