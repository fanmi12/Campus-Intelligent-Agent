# 甲型H1N1流感防控工作不可掉以轻心

据通报，我国内地已确诊多例输入性甲型H1N1流感病例。国务院对此高度重视，多次强调和部署加强甲型H1N1流感防控工作。为做好防控工作，学院相关部门要求全院师生做到：

1、出现流感样症状时，请暂时不要上课，应及时就诊，以免传染给他人。

2、出现发热、咳嗽、喉咙痛等上呼吸道感染症状时，应停止上课，待症状消失及退烧后的第三天才能返校。

3、从受流感疫情影响地区返校的师生员工，七天之内应采取配戴外科口罩等预防措施。如出现流感样症状的应立即就医，并向医务所说明旅行史。

4、照顾病患的人应该配戴口罩，并进行自我检测，如有异常，应立即报告。

如有上述情况的师生员工请及时报告院医务所医生（电话：13809637726 15019990902 22680867）。
