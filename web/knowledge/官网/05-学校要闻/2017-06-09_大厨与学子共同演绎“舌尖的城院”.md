# 大厨与学子共同演绎“舌尖的城院”

6月8日下午，由后勤保卫处主办院学生会协办的“饮食服务中心第五届优质服务月——厨艺比拼&烹饪大赛”，在荔香园四楼举行。广东鸿发文化教育集团有限公司副总经理夏为民、韩春华，我院副院长周庆等领导出席了活动。

学院后勤保卫处负责人袁秀美致词表示，第五届优质服务月活动将秉承“健康、安全、环保”的饮食理念，践行“一切为了师生，为了师生一切”的服务宗旨，不断提高饮食中心的服务质量，为我院师生提供更为优质的服务。

当日下午，虽然夏日炎炎，但参赛的同学和厨师们却热情澎湃。大赛共设置学生厨艺比拼、厨师菜品展示两大环节，共有16名学生和16名厨师参加了比赛。赛事评委由领导嘉宾、学生代表和厨师组成，在对参赛的美食进行试吃品尝之后，按“色、香、味、营养和创意”等五个方面进行评分。

经过激励、富有乐趣的美食创作，黎锦慧、刘晓彤、张文静等十位同学的参赛菜品脱颖而出，获得学生组厨艺优秀奖；吴志勇、叶振贵、李云英等七位厨师获得厨师组的厨艺优秀奖，其中“酿鸡翅、铁板生肠、布袋豆腐、灯笼茄子”等10道美食作品最受师生喜爱。

大赛上，由后勤工作人员和大学生艺术团带来精彩的歌舞表演，成为了美食之外的又一道靓丽风景。

作为大赛协办单位的负责人、院学生会生活部副部长梁丽芳在亲身体验美食的乐趣后表示，“本次厨艺比拼大赛让师生们能够走进食堂，了解、体验学院餐饮工作的辛苦与乐趣，既活跃了校园美食文化氛围，又丰富了大学生的课余生活。”
