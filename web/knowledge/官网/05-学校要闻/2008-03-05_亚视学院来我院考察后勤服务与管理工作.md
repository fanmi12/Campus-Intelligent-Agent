# 亚视学院来我院考察后勤服务与管理工作

3月4日，广东亚视演艺职业学院一行7人在副院长刘国臻的带领下，来我院考察后勤服务与管理工作。

城市学院行政副院长张林博士热情接待了客人们，对他们的到来表示欢迎。总务处处长章德胜副教授、人事处处长夏勇博士，分别向广东亚视演艺职业学院介绍了我院总务后勤、人事管理等方面的情况。其间，客人们还到我院对口部门参观互动，学习交流。在安少华院长的邀请下，刘国臻副院长参观了樟村教学生活园区。

据悉，2005年7月，我院与广东亚视演艺职业学院签定了合作办学协议。借助亚视的影视艺术师资，培养我院05、06级影视表演及音乐表演专业的学生。
