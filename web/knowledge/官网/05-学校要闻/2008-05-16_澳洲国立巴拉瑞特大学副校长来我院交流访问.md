# 澳洲国立巴拉瑞特大学副校长来我院交流访问

5月14日上午，澳洲国立巴拉瑞特大学副校长Rowena coutts女士、校长办国际合作部副主任沈根生先生一行三人来我院参观访问。东莞理工学院副院长、城市学院院长安少华教授，城市学院副院长张林博士热情接待了来访客人。

Rowena coutts女士一行参观了我院的校园建设以及相关教学设施，详细介绍了澳洲国立巴拉瑞特大学的办学以及该大学与我国大学开展合作办学的情况，还就与我院合作办学等问题进行了深入的交流，希望我院教师到该大学交流访问。安院长对来访的客人表示欢迎，认为双方有很大的合作空间，期待与巴拉瑞特大学作深层次、多元化的交流。

新闻链接：巴拉瑞特大学是澳大利亚一所最新型的，发展最快的大学，具有135年提供高等教育和培训服务的历史。巴拉瑞特大学也是一所颇具名气的地区性大学，在巴拉瑞特市有三所分校，在好顺市、斯托市和阿拉瑞特市各有一所分校，六个分校全部坐落在维多利亚省内。巴拉瑞特大学在国内和国际上也具有其特色，她十分活跃地在国内外建立了广泛的合作关系和战略联盟关系。

巴拉瑞特大学在校注册生超过了两万两千人。他们就读高等学位课程和中等文凭课程。这些课程满足了本地区的多元化教育和培训需求。巴拉瑞特大学同时还注册有四千五百名海外学生。巴拉瑞特大学不但十分重视教学质量，而且也大力注重，有效地开发地区和农村问题的研究。

巴拉瑞特大学毕业生对在巴拉瑞特大学学习经历的满意程度一贯居于全澳大利亚首位。巴拉瑞特大学毕业生的就业率和起薪点高于全澳大利亚平均水平。今年八月，澳大利亚教育和培训部公布了全澳大利亚大学七项教学质量指标评比结果，其中，巴拉瑞特大学在教学质量方面被评为全维多利亚省内所有大学的第一，全国38所大学的七项教学质量指标综合排名第九位。

巴拉瑞特大学不仅在高等教育部而且在中等教育部多与本地区的企业界和工业界建立了密切的联系。巴拉瑞特大学最为重视开发那些有助于学生在高等教育部和中等教育部之间转学的课程，从而丰富了学生的学习机会，学生可以根据各自的兴趣选择课程。
