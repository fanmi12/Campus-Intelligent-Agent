# 省教育厅今起对我院思想政治理论课建设工作进行评估

根据广东省教育厅安排，6月5日组织高等学校思想政治理论课评估专家对我院思想政治理论课建设工作开展检查评估。

6月5日下午，省高校思政评估专家组莅临我院。专家组一行5人，由中山大学教育学院副院长李辉教授任组长，包括暨南大学程京武教授、华南农业大学杨乃良教授、广东工业大学刘国建教授、广州大学罗明星教授。学院在315会议室召开了思想政治理论课建设评估汇报会。省教育厅思政处处长袁本新、副处长朱建华、江存余科长，东莞理工学院党委副书记吕琦元，城市学院领导杨敏林、朱志德、朱冰、张林、陈丁堂、章德胜、高香林出席会议。各部门负责人，各系部主任、党总支正副书记，思政部全体老师，各系部辅导员参加会议。

吕琦元副书记感谢省教育厅对城市学院思政课建设工作的关心，希望专家组多提宝贵意见，促进城市学院思政课教学科研工作。袁本新处长代表省教育厅思政处讲话，他指出，城市学院思政课建设工作卓有成效，拥有省级精品课程，创新教学模式，很多经验值得其他同类型高校借鉴和学习。

党委书记朱志德做学院思想政治理论课建设工作汇报。朱书记从学院概况、思政课建设的基本情况、思政课建设的主要措施和成效等方面介绍了相关情况。

汇报会后，专家组组织召开了城市学院部分职能部门负责人座谈会和教师代表访谈会。

据悉，省教育厅本次对我院的思政评估工作为期一天半，内容包括思政课评估工作汇报会、师生代表座谈会、实地考察教学设施设备、查阅核实评估资料、现场观摩教学和评估情况通报会等。
