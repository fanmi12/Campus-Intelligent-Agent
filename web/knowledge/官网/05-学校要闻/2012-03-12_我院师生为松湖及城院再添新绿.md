# 我院师生为松湖及城院再添新绿

阳春三月，万物复苏，草长莺飞，到处呈现出一片欣欣向荣的景象。3月12日是一年一度的植树节，我院师生以实际行动迎接植树节的到来。

美丽校园添新绿3月12日清早，副院长程发良、张林率领机关各处室负责人代表，来到教工宿舍区参加植树活动。领导们自发组成植树小组，合力把树苗移入坑中，移正竖直，再用铁锹培土、夯实，为树苗浇水。经过一番努力，10株玉兰花树苗在和煦的春风中，昂然挺立，焕发出勃勃生机，为春天的校园增添动人的新姿。

院督学陈丁堂向记者谈了参加植树活动的感受：“参加植树，不仅让自己疏松筋骨、振奋精神，也给师生员工创造了一个良好的学习、工作和生活的环境。植树对于我们教育工作者来说，更具有深层的意义，十年树木，百年树人，通过植树活动不断提醒自己：牢记使命，教书育人，精心办学，源源不断地向社会输送合格人才。”

种下一颗树 传递一份爱3月10日，城市与环境科学系举行了以“种下一棵树，传递一份爱”为主题的3.12植树节活动，全院120多名师生在松湖花海种下了100株桃树苗。

植树活动作为城环系的品牌活动，今年已经是第三届。城环系主任肖红飞说：“城环系植树节所举行的一系列活动都是对‘环保’这一理念的积极响应，与我们系的专业相关，学生在参加活动的同时也加深了对专业知识和环境保护知识的理解和掌握。”

参加植树的同学们热情高涨，植树现场一派热火朝天的景象。3月10日刚好是2011级资源环境与城乡规划管理专业的颜雅芳同学的生日，她兴奋地对记者说：“在自己的生日参加这么有意义的活动真的很值得纪念，既为自己庆生，也为大自然增添新绿，为环境保护贡献力量，太有爱了！”
