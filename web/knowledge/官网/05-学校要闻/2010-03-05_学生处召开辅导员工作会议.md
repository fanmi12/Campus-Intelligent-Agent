# 学生处召开辅导员工作会议

学生处近日召开各系部辅导员会议，通报开学工作及各班主题班会召开情况。党委副书记朱冰出席会议并讲话。

会上，朱冰副书记要求各系部要高度重视班主任工作，班主任老师要亲自主持召开班会，清点学生报到注册人数，查明学生未报到的原因。辅导员和班主任要检查学生到课率，深入学生宿舍检查了解学习和生活情况，做好新学期的工作计划。

据通报，截止3月4日12：00，全院学生报到率为99.2%，未到校学生均已取得联系并查明了原因。90%以上的班级已召开班会。
