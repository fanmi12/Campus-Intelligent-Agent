# 本学期期末考试秩序井然

按照教学工作安排，我院本学期期末考试于7月4日正式开考，将于7月9日结束，据统计考生人数将达40387人次。

为了端正考风，严肃考纪，确保期末考试公平公正，考前教务处专门下发《关于2015—2016学年第二学期期末考试相关工作的通知》（教务〔2016〕37号），对整个考试过程作出了规范性要求。同时，学院还成立了由院领导、机关教辅部门负责人及院级督导员组成的巡视组，按照考试有关规定，对每场考试进行巡查。

截至发稿，在教务处的精心组织下，考务工作人员、监考老师均做到了尽职尽责，考生努力作答，考场秩序井然。
