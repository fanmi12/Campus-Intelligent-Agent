# 我院餐饮接待量与服务质量同步提升

“兵马未动，粮草先行。”我院饮食服务中心员工积极当好“先行官，”想学生所想，投学生所好，采取有力措施，提高服务态度，降低饭菜成本，增加菜肴花色品种。资料分析表明，学生早晚在餐厅就餐率达到60%，中餐则高达80%以上。据悉，与同类院校相比，就餐率居中上水平。

今年下学期开学以来，饮食服务中心增加了近5000名大一新生就餐的工作量。根据院领导关于饭堂经营“有序、快速、优质、保本”的指示精神，该“中心”在暑期就招收了40多名新员工，并进行了岗前培训。同时，还将四楼扩充为师生员工共用的餐厅。到目前为止，全院共有餐厅服务员工170多人，餐桌4300多张。据测算，服务员工、餐桌的数量与就餐学生的比例，达到了上级的有关规定。

在经营过程中，饮服中心参照兄弟院校的经验，建立和推行了“食材统一采购、分楼层经营、成本独立核算”的管理方法。目前，饭堂共设立了6个经营单位。这一办法的实施，大大提高了各楼层服务人员的工作积极性和服务质量。一是餐厅卫生清洁，窗明几净，餐桌即脏即擦、无油渍和废弃物。服务人员统一着装上岗，给人以宾至如归的感觉。二是服务态度满腔热情，花色品种不断翻新增多。各楼层为吸引学生前来就餐，纷纷推出特色服务及风味小吃各式面点，既有1—5元的大众菜，又有10元一份的套餐；既有广东风味小吃，又有免费供应的萝卜干、辣椒酱、香醋、生抽。三是在中午就餐高峰时段，招聘40多名勤工俭学的学生钟点工，协助卖饭打菜，从而减少了同学们的排队等候的时间。记者在现场看到，各窗口排队的“长龙”在几分钟之内就隐退了。

饮服中心负责人表示，饭堂工作还有许多不尽人意的地方，正在想办法逐步解决。待第二食堂明年启用后，这些问题都将迎刃而解。
