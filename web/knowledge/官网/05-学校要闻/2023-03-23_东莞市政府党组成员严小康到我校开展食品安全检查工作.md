# 东莞市政府党组成员严小康到我校开展食品安全检查工作

3月22日上午，东莞市政府党组成员严小康一行到我校开展食品安全检查工作，进一步强化食品安全监管，切实严防校园食品安全风险。寮步镇镇长黄荣峰，常务副校长方伟华及相关责任人陪同检查。

严小康一行先后到我校悦香园食堂一楼和二楼通过实地走访、查看资料等形式，详细了解我校食堂组织制度建设、食品安全管理架构、从业人员培训管理、食品原料进货来源、食品加工制作管理、食品留样、餐具清洗消毒、食堂设备管理及环境卫生等情况，并听取了相关负责人关于落实食品安全主体责任的情况汇报。

严小康要求，学校要提高政治站位，强化主体责任，从严从细落实食品安全管理规定；要提高对食堂巡查频率，提前发现问题，及时化解食品安全风险；增强底线意识，持续夯实食品安全基础，切实保障广大师生员工饮食安全和身体健康。

方伟华常务副校长表示，学校将以此次检查为契机，继续认真做好食品安全管理工作，进一步提高思想认识，落细落实“日管控、周排查、月调度”工作机制，切实担负食品安全主体责任，确保我校师生员工“舌尖上的安全”。
