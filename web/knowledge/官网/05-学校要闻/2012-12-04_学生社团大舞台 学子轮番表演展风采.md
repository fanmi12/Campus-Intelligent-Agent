# 学生社团大舞台 学子轮番表演展风采

12月3日，我院43个学生社团风采周开幕式在湖边广场激情上演。现场吸引了众多热情的同学驻足观看。

开场Show，一开始便紧紧抓住了在场所有人的眼球。ＹＭＣＡ协会带来的Jass舞蹈让现场ｈｉｇｈ了起来，伴随着动感的节拍，同学们的身体也跟着舞动起来。歌曲《梦想的翅膀》，让现场观众们如痴如醉，回味无穷。紧接着的跆拳道协会的音乐品势又掀起了一段狂潮，《跆拳ｓｔｙｌｅ》滑稽可爱的动作引得现场尖叫连连，该协会的教练组给大家带来了一场极具视觉冲击的盛宴，刚劲有力、整齐划一的动作，连续三脚横踢以及1米8高度的飞踢等特级表演无处不彰显着教练们一身真功夫的霸气，给力表演令人啧啧称奇。由众多俊男美女组成的YMCA模特队，带着青春时尚的气息，在充满动感的音乐中展现着独特的风采，带给观众以美与艺术的享受，再一次点燃现场气氛，赢得了台下观众的阵阵掌声。大学生职业规划协会的小品《招聘会》全方位演绎了一个大学生求职获得成功的历程。魔术表演的千变万化带着观众走进魔术的世界，亲眼目睹了一系列的不可思议。
