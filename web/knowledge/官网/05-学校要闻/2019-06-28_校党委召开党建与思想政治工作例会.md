# 校党委召开党建与思想政治工作例会

6月27日，校党委在金贸学院召开党建与思想政治工作例会。校党委书记章德胜，各党总支（直属支部）书记、副书记参加了会议。金贸学院院长米双红及其班子成员应邀参加了会议。

为深入开展“不忘初心、牢记使命”主题教育活动，金贸学院党总支书记赵书山进行了领学，作了“梦想从学习开始：金贸学院党总支着力打造学习型党组织”主题学习报告。他详细介绍了金贸学院党员干部深入学习贯彻习近平总书记关于学习的重要论述，通过学习经典原著、党群共读《共产党宣言》、开展“书记读书日”活动等举措，打造学习型党组织的经验和取得的成绩。

党务工作部副部长叶凯贞主持会议，总结了2018-2019学年学校党建工作，并对“不忘初心、牢记使命”主题教育活动和学校近期党建工作进行了部署。

校党委书记章德胜指出，学校党委结合“不忘初心、牢记使命”主题教育活动，首次将党建与思想政治工作例会放在基层组织召开，创新工作思路，加强基层交流，共同学习，旨在通过加强党建工作促进学校各项事业的发展。学校党委将加强党建与思想政治工作例会制度建设，使会议常态化，建立长效机制，为各党总支（直属支部）书记、副书记打造交流与学习的平台。

章德胜书记强调，党建与思想政治工作是各项工作的灵魂，只有搞好党建与思想政治工作，才能确保学校各项工作沿着正确的方向发展。各党总支（直属支部）书记、副书记责任重大，要切实增强党建与思想政治工作例会实效性，做到有特色有创新，充分发挥党建的指引和方向作用，推动学校事业不断向前发展。
