# 我校学子获“第二届全国大学生C语言程序设计大赛”佳绩

近日传来喜讯！在第二届全国大学生C语言程序设计大赛上，我校人工智能学院共有305名同学参赛，经前期周密筹划，最终取得了一等奖20项、二等奖45项、三等奖66项的好成绩，同时我院还被组委会评为优秀组织单位。

此次大赛由全国高等院校计算机基础教育研究会理工专业委员会支持，黑龙江省计算机学会、云南省高等学校计算机教学研究会等联合主办，旨在增强广大学生的编程能力和实践水平，增强创造力，营造浓厚的校园学术氛围，是实现跨地区、跨学校、跨专业人才培养的综合性赛事。本次大赛共有全国456所高校共计10975名高校大学生响应参赛。

我院C语言课程组为本次大赛做了周密部署，彭刚教授亲自发动，巩泊成老师全程指导、协调。通过广大师生的共同努力，最终取得佳绩！

主办方对于我院的参赛规模和组织情况给予了高度评价。参赛学生们在比赛前认真学习，积极备战，充分展现出我校学子的良好素质和扎实功底。

我校人工智能学院名誉院长牛熠教授表示，人工智能学院将继续坚持“以赛促学，以赛促教”方针，推动教学质量的提升，并根据本次比赛经验进一步优化教育教学体系，鼓励学生积极参加学科竞赛，为国家培养高素质应用型人才而不懈努力。
