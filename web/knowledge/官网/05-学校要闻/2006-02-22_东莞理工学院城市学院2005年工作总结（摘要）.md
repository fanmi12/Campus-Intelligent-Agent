# 东莞理工学院城市学院2005年工作总结（摘要）

2005年是我院发展史上具有关键意义的一年。我院在市委、市政府和东莞理工学院党委、行政的正确领导以及社会各界的大力支持下，不断提高教育质量，在管理机制、教育教学改革、学科建设、师资队伍建设和校园建设等各方面取得了新进展，总体办学水平上了一个新台阶。

一、抓住国家积极发展独立学院的机遇，总结经验，认清形势，依托母体办学，明确发展目标和工作思路。

我院在两年时间里，在校生人数从570人，迅速扩大到近5000人，2006年将达到近8000人规模。在"扩规模"上已实现跨越式发展，打好了获取规模效益的基础。为探讨学院的发展模式和规划发展前景，今年3月和8月，我院分别召开了城市学院发展研讨会和2005－2006学年度工作会议。明确了"三年打基础，五年见成效，经过一段时间的不懈努力，将城市学院办成具有地方特色、省内一流、追求卓越的教学型本科独立学院"的奋斗目标，确立了"依托母体保质量，面向市场谋创新，服务东莞求支持，追求卓越创品牌，科学发展作贡献"的工作思路。

二、在理工学院的领导和支持下，调整和完善组织机构设置，加强管理团队建设，落实董事会领导下的院长负责制。

1、经东莞市委、市政府同意，东莞理工学院党委批准，先后成立了东莞理工学院城市学院董事会、监事会，完善了城市学院的管理机构。根据学院发展需要，先后成立了学院学术委员会、教学工作委员会等学术权力机构，以及教师委员会、工会等民主管理机构。针对学院规模的不断扩大和现有专业的结构特点，进一步对学院的系、部机构进行了优化调整。

2、今年6月，理工学院从各部门抽调一批高学历、高职称的中层管理干部，确立为我院各系、处的主要负责人。同时，学院也从各部门中选拔了一批工作能力强、表现突出的优秀教师担任主任助理或教研室主任。

3、在理工学院党委、行政的直接领导下，按照董事会章程，我院召开了董事会成立大会暨一届一次会议，选举产生了以东莞理工学院党委副书记、院长、博士生导师杨晓西教授为董事长、东莞理工学院党委委员、副院长安少华教授为副董事长的第一届董事会。会议审议通过了《东莞理工学院城市学院董事会章程》，明确了董事会领导下的院长负责制的管理体制。同时，经市委研究同意，东莞理工学院党委批准，董事会聘任安少华教授为城市学院院长（法人代表），程发良同志为城市学院常务副院长，林世俊同志为城市学院副院长。

三、积极、稳步地推进以岗位管理为核心的全员聘用制，改革人事分配制度。

1、进一步改革人事分配制度，实行"按劳取酬，优质优酬"。实行全员聘任制，淡化职称、级别、身份观念，实现岗位聘任；完善社会保障和合约管理相关政策制度；建立和完善有效的激励机制；特别关注青年教职工的成长和培养。

2、进一步明确院系两级管理职能，理顺管理关系，下移管理重心。学院实施宏观管理，主要是政策制定、综合协调、监督检查，通过激励和惩处机制，有效地控制和指挥整体教学工作的正常运行。进一步健全系一级教学管理机构，明确系主任为教学管理工作第一责任人，下放管理权限，实行目标责任制。加强教研室建设，充分发挥教研室在教学管理工作中的基础作用。

四、在校本部有关职能部门的指导支持下，加大人才引进力度、师资队伍建设，教育教学改革取得新进展，确保教学工作中心地位。

1、注重师资队伍的建设与管理，以培训为主要方式，派遣部分教师外出学习，大力提高教师素质，强化师资队伍的建设和管理，初步建立起一支能站稳讲台，较好完成教学工作任务的师资队伍，提高了学院的整体教学水平。同时，组织中层干部培训，提高中层领导干部的管理水平。

2、采取各种有效途径，引进各类优秀专业人才。据统计，学院全年新聘（调）进教职工117人，其中正高7名，副高12名，博士5名，优化了目前我院的师资队伍结构。

3、根据市场需求，2005年新增了"社区管理与服务"、"安全生产管理"等专业，计划招收本、专科学生2820人，实际录取3094人，报到率为86％。同时首次面向湖南、湖北、山东、重庆等9个省市招生。截至年底，在校本、专科学生数为4859人。

4、修订和完善一批专业的教学计划和教学大纲，教学实践环节进一步加强。加强教学评估，在教师中开展评教评优活动，评选出2005年优秀主讲教师5名，提高了教学质量。

5、精心谋划，大力发展与国内外高校的合作办学，先后和韩国永进大学、英国赫特福德大学、日本信洲大学等国际知名大学洽谈了合作办学事宜，并签定了合作办学协议。与亚视演艺职业学院签订了联合培养学生协议，今年已有35名影视表演专业的学生在亚视学习。

6、狠抓学风建设，形成学风、教风良性互动的良好局面。

7、采取各种有效的形式，让城市学院走进社区，服务东莞。充分利用《东莞日报》、《南方都市报》《城市学院报》和学院网站等宣传媒介，扩大学院的知名度和美誉度。其中《城市学院报》已出版6期，学院主页从5月改版至今共发布新闻200余篇，浏览量累计达56828次。加强对外交流，接待了美国教育与经济研究中心总裁、首席执行官MarcS.Tucker先生率领的中国考察团一行，以及河北经贸大学经济管理学院、新加坡国际管理学院、香港资深商会、韩山师范学院等兄弟院校的来。

五、党的建设和思想政治工作得到进一步加强，党员综合素质不断提高

1、积极在党员队伍中开展以实践"三个代表"重要思想为主要内容的保持共产党员先进性教育活动。建立党员活动室，利用院报、广播、宣传栏、电子屏、网络等渠道，开展形式多样的宣教活动，不断地将学习教育活动引向深入，取得了良好的效果。同时，切实抓好各级领导班子建设。对全院各级领导干部进行多种形式的培训教育，建立健全了各项规章制度。不断完善党、团组织的设置和选举工作。11月，经东莞市委组织部批准成立党委后，又相继成立了"中国教育工会东莞理工学院城市学院委员会"、"共青团东莞理工学院城市学院委员会"等组织。

2、成立了分党校，举办了党委成立后的第一期入党积极分子培训班，培养入党积极分子285人。全年共发展新党员44人。其中，教职工党员1人，学生党员43人。

3、院领导和党委成员认真贯彻落实《反腐败实施纲要》和学习《两个条例》，积极开展党纪党风教育，组织党员干部观看了"广东省学习《中国共产党党内监督条例（试行）》报告会专题片"和《莲花正开-廉政文化进校园文艺汇演》等专题影片，切实加强反腐倡廉和党风党纪教育力度。

4、认真贯彻落实党中央、国务院《关于进一步加强和改进大学生思想政治教育的意见》和张德江书记在全省加强和改进大学生政治思想教育工作大会上的讲话精神，在全院学生中积极开展"立志、修身、博学、报国"的主题教育活动。特别注意根据学生的身心发展特征，开展喜闻乐见、丰富多彩的德育活动，把课堂教育与课外活动结合起来。

六、校园基础建设取得长足发展，办学条件逐步完善

1、基础设施建设工作进展顺利。完成了学院田径运动场，学生活动中心舞厅，学院接待室等多项工程的改造工作。投资300多万元的多功能报告厅的前期准备工作已基本完成。图书馆、二期学生公寓、单身公寓等一批设施的建设工作正在启动。

2、校本部的搬迁工作基本完成，顺利实现了莞城校区图书、后勤、保卫等部门和人员的平稳移交。

3、城市学院的新网页迅速启用。

七、校园文化丰富多彩

学院精心打造了"城市学院大讲堂"，邀请了外交学院副院长、博士生导师曲星教授、浙江大学知名学者李伯耿教授、中科院蔡睿贤院士、中国人民解放军国防大学副军职教官乔松楼教授等一批国内外具有一定影响力和知名度的专家和学者前来我院讲学，深受广大师生的欢迎。成功举办了广东省首届高校校际学生学术研讨会暨物流企业论坛、第二届共青团形象设计大赛、"三·八"善款美食节等多个校内文化艺术活动，提升了校园文化的学术品位，充分展示了当代大学生的风采。
