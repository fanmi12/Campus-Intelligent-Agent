# “奥运伴我行《形势与政策》知识竞赛”举行决赛

5月15日，由学院团委、学生处、思想政治理论课教学部等联合举办的“奥运伴我行《形势与政策》知识竞赛”在学术报告厅拉开帷幕。

进入本次决赛的共有社会科学系、文学与艺术系、机电系和管理系四支代表队。比赛分为必答题、抢答题和风险题三个环节。最后，社会科学系代表队、文学与艺术系代表队分获一、二名，机电系与管理系并列获第三名，文学与艺术系获最佳组织奖，社会科学系曾雪贞、陈汉成和文学艺术系蔡霭芳获最佳个人奖。
