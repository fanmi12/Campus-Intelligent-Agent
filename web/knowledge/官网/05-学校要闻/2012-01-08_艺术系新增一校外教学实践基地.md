# 艺术系新增一校外教学实践基地

1月6日，艺术系主任邓星明教授、系实践办主任梁贝老师、服装设计方向李秀琴、林岩老师一行四人，赴东莞市“山水乐人”服饰有限公司进行校外实践基地签约及挂牌仪式。

公司负责人热情接待了邓主任一行，双方就合作事宜进行了深入的探讨和交流。

据悉，东莞市“山水乐人”服饰有限公司一直致力于户外服装的研发与生产，是一家集高科技、新技术设计与开发、生产、销售、物流于一体的品牌公司，2003年创立了自主品牌CARAVA（喀尔沃）。
