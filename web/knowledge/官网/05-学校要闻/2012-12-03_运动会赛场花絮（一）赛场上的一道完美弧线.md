# 运动会赛场花絮（一）赛场上的一道完美弧线

雨幕中的校运会，犹如一幅动态的彩色油画，流淌着几分诗情与画意。

来自11级高职部的王伟杰，淡定从容，不紧不慢，只见他嚼着香口胶，半侧着身子，右手紧握铅球于耳边，左手高举空中，压低着身姿，在一个稳健的转身之后，奋力一掷，手中的铅球便在雨幕中划出一道完美的弧线。

“10.55米。”

“好！”场上的啦啦队欢呼着。

赛后，王伟杰高兴地说：“有啦啦队的呐喊助威，我更有动力。”王伟杰对铅球比赛很有自信，他说，虽然自己平时很少进行专业的训练，但很有灵性，加上有师兄指点，并且在比赛中和其他选手的交流，这次比赛胸有成竹。赛后，获得铅球冠军的王伟杰坦然地说，他最喜欢的运动还是篮球，他是院篮球队队员，“平时经常打球，锻炼身体，觉得自己的身体素质还是很好的”。与他轻松的交谈中，他以爽朗的声音谦虚地说道，自己不是篮球队的主力，篮球队还有很多比他更厉害的人。他表示，良好的身体素质是胜利的基石，嚼着香口胶可以让他缓解比赛的压力，会觉得很放松，好的心态才是致胜的关键。

在去年校运会男子铅球的比赛中，王伟杰以10.55米的佳绩打破了学院男子铅球的记录，今年他以同样的成绩成功卫冕，持平了自己保持的记录。王伟杰有些许遗憾地说，如果不是雨天场地比较湿滑，自己还可以发挥得更好，完全有可能打破校运会记录。

“明年，再看我的！”
