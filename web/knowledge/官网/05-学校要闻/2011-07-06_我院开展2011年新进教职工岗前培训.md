# 我院开展2011年新进教职工岗前培训

7月5日，我院2011年新进教师岗前培训在315会议室举行了开班仪式。

会上，广东鸿发集团副总裁、东莞理工学院城市学院董事黎建烨代表广东鸿发集团欢迎新进教师加盟城市学院，并向新进教师介绍了广东鸿发集团以及集团投资办学的初衷、办学理念等方面的情况。

副院长杨敏林教授、程发良教授、张林博士分别就新校区建设情况、院内教学管理工作规范、院内行政管理工作规范做了讲话。

院长安少华教授对新加盟城市学院的新教师表示热烈欢迎。他介绍了东莞的市情、城市学院的院情及发展现状，分析和阐释了学院定位与发展、人才培养模式等情况，让新进教职工对东莞市和城市学院的概况和发展有了一个较为清晰的认识，明确了今后努力的方向。安院长鼓励新进教师要热爱高教事业，做到德才兼备；要立足本职岗位，努力把自己锻炼成为教学能手；要做到教学与科研相结合，努力争取通过科研提升自我，实现人生价值；要关心学院的建设和发展，为维护学院良好的校风、教风和学风做出应有的贡献；要树立正确的学生观，“没有教不好的学生，每个学生都有自己的特点，老师要因材施教，善待学生，才能教好书、育好人。”

据人事处统计，今年我院7至8月份共招聘教师53人，其中：教授3人，副教授1人，讲师等中级职称9人；具有博士研究生学历的3人，硕士研究生学历的45人；海外留学归国人员3人。他们大部分为国内211重点大学院校毕业人员。40%的新进教师具有在省内外高校或国内知名企业的工作经历。
