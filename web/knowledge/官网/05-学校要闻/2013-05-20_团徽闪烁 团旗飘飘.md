# 团徽闪烁 团旗飘飘

5月18日，共青团东莞理工学院城市学院第三次代表大会暨第八次学生代表大会在综合馆胜利召开。来自各系部392名团员、学生代表，肩负着全院团员青年的重托，共商我院团员青年工作大计。

团市委书记助理罗燕帆同志、团市委学校副部长李达群、我院党委副书记章德胜等领导参加会议并发表讲话。

会上，党委副书记章德胜宣读了《关于表彰2012—2013学年度东莞理工学院城市学院团组织工作先进集体和先进个人、2011-2012学年度东莞理工学院城市学院学生会工作先进集体和先进个人的决定》。文学与传媒系、财经系、金融与贸易系、管理系获“优秀团总支” 的称号，10级保险（1）班等36个班级获“优秀团支部”称号。

学生处处长杜鹏举做共青团东莞理工学院城市学院第二届委员会的报告。报告回顾了过去四年了工作：一、思想政治教育工作取得新成效，团员青年的政治觉悟和思想水平不断提高。二、积极服务学院建设发展工作，充分发挥桥梁纽带作用。三、坚持以文化育人为主题，不断推动校园科技文化建设。四、社会实践活动继续深化，志愿服务工作广受好评。五、拓宽团的工作覆盖面，优化团学组织体系，加强团学组织自身建设。六、运用新媒体工具，加强团组织与各级学生组织和团员青年的联系，加强网络教育，引导青年成长成长。报告还对我院共青团今后五年的工作做了展望：希望各级团学组织和团员青年要坚持以先进理论武装团员青年，着力深化学生思想工作 ；要积极开展校园文化建设系列活动，增强校园文化氛围，提高学生青年文化底蕴；广泛开展以提升学生综合素质为出发点，着力深化学生成长服务工作深入开展大学生社会实践活动；要进一步深化组织体系建设，进一步夯实团的工作基础；要大力推进团组织网络化建设。

大会还选出了陈琳琳、罗文芳、李伟健、万文双、麦振峰、陈浩华为共青团东莞理工学院城市学院第三届委员会委员。蔡振航、赖焕婷、赖汝旺、陈文静、詹欢当选第十届城市学院学生会主席团成员。
