# 刘延申教授莅临我院指导工作

5月26日，我院客座教授、华中师范大学教育信息化研究中心主任刘延申教授，在东莞理工学院副院长、城市学院院长安少华教授的陪同下，莅临我院指导工作。城市学院学术副院长程发良教授、党委副书记朱冰、行政副院长张林博士等热情接待了刘教授一行。

多年来，刘延申教授非常关心和支持我院的建设与发展。刘教授在听取院领导关于办学情况的介绍后，对我院的发展方向、办学中存在的问题给予了指导；对即将兴建的图书科技信息大楼工程提出了宝贵意见。刘教授表示，作为东莞理工学院城市学院的客座教授，愿一如既往地为学院更好更快的发展提供各种帮助。
