# 关于全面核对学生宿舍信息的通知

各院系、各班级：为推进我院学生宿舍信息化管理，本学期将启用学生宿舍信息管理系统，届时住宿费用以及水电费信息等将直接实行系统关联，为确保学生权益，现决定开展全院学生住宿信息核对工作，相关要求通知如下：

一、核对对象

全院所有在校学生

二、核对时间2019年2月27日

-3月15日

三、核对内容

（一）核对内容：请各院系组织核对，以班级为单位，认真核对

院系、年级、班级、姓名、性别、学号、楼栋、房号、床位

等信息，重点核对住宿信息，确保信息精准无误。

（二）核对细则：以班为单位要求学生逐一核对，让每一个学生自己核对，具体核对细则如下：

1. 如果信息准确无误的，请签名确认；

2. 如信息有误的，需进一步确认是否属于私调宿舍，私调宿舍的督促搬回原宿舍并更新宿舍信息；非私调宿舍的，说明情况、更正信息并签名确认。信息更正需注明床位，示例：“1A101-A”。

3. 如发现有学生信息遗漏的，可在页尾空白处填写补充完整信息，系统编号留空。

特别提醒：系统编号不得更改；

三、工作要求

（一）提高认识，高度重视。

学生住宿信息关系到新生入宿安排（避免出现冲突），关系到学生住宿的缴费标准和水电费的收缴等，各院系要跟学生讲清本次核对工作的重要性，积极主动参与核对工作。

（二）仔细全面，确保精准。各班要对所有学生进行全面核对，积极到学生宿舍走访实地了解学生住宿情况，对发现的问题及时报告，确保学生住宿信息100%准确。

（三）规范程序 系统管理。核对完毕后，学生调整宿舍或床位需按相关程序进行申请，并以宿舍管理系统为准，如发现私调宿舍，将按相关规定进行处理。

四、材料提交：请各院系认真核对之后，填写宿舍信息核对表（系统核对版20190226），并将信息有误宿舍筛选出来提交纸质版和电子版各一份。电子版统一发到1625473753@qq.com。纸质版分管领导签字后送到学生处206陈妍老师处。提交时间：2019年3月18日17:00前。

学生处2019年2月27日
